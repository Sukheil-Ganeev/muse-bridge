# Библиотека навыков проекта (роутер)

В этом проекте есть встроенная библиотека: `.agents/skills-lib/` — 1400+
готовых навыков, каждый со своим `SKILL.md` (инструкции) и файлами.
Capy НЕ видит их список автоматически — эта папка не сканируется.
Единственный путь к ним — этот роутер.

## Железное правило

Перед ЛЮБОЙ предметной задачей (код, текст, таблица, билет, бот, дизайн,
анализ, реклама — что угодно, кроме короткого ответа из общих знаний):

1. Найди навык в библиотеке (как — ниже).
2. Прочитай его `SKILL.md` целиком.
3. Работай строго по нему. Если навык противоречит твоим привычкам —
   побеждает навык.

Запрещено отвечать «по-своему», не поискав навык. Поиск — это 2 команды,
он дешевле ошибки.

## Как искать (все команды — из корня репозитория)

Шаг 1 — быстрый поиск по указателю (имя + описание каждого навыка):

```bash
grep -i "ключевое слово" .agents/skills-lib/INDEX.md | head -n 10
```

Подбирай 2–4 синонима, если с первого слова пусто. Например, задача про
посты в Telegram: `telegram`, `smm`, `пост`, `контент`.

Шаг 2 — если в указателе глухо, ищи по полному тексту инструкций:

```bash
grep -ril "ключевое слово" .agents/skills-lib/*/SKILL.md | head -n 10
```

Шаг 3 — прочитай 1–3 лучших попадания целиком и выбери один:

```bash
cat ".agents/skills-lib/<имя-навыка>/SKILL.md"
```

Если подошло несколько — бери самый узкий под задачу, остальные держи
про запас. Если не подошёл ни один — так и скажи пользователю одной
строкой («в библиотеке подходящего навыка нет, делаю без него») и делай
без навыка, а НЕ выдумывай несуществующий.

## Как применять

- Дополнительные файлы навыка (references/, scripts/, assets/) лежат рядом
  с его `SKILL.md` — читай и запускай их так, как велит инструкция.
- Пути внутри старых инструкций могут указывать на машину владельца
  (например `C:\Users\londo\...` или `D:\Downloads\...`) — такого здесь нет.
  Используй смысл инструкции, а пути заменяй на локальные эквиваленты
  внутри репозитория. Если инструкция требует недоступный файл или секрет —
  остановись и спроси пользователя, не выдумывай содержимое.
- Не запускай ничего разрушительного (удаление, публикация, внешние
  отправки, трата денег) без явного разрешения пользователя в текущем чате.

## Частые точки входа (подсказки, а не замена поиску)

- Продажа билетов, события: `selling-event-tickets`
- Хранилище ключей и секреты: `api-keys-vault`
- Модель решений TypeSafe/Jev: `typesafe-ai`
- SEO/контент/гео: `write-seo-geo-content`, `research-keywords`, `audit-content`
- Telegram/боты: ищи по словам `telegram`, `bot`, `whatsapp`
