# Fusion — шпаргалка

Источник: https://www.youtube.com/watch?v=Ws0POWdvxu4 (AshyGray)

## Запуск

1. Один текст задачи → всем панелистам сразу, параллельно.
2. Панелисты друг друга не видят, файлы не трогают, интернет включён.
3. Судья сравнивает по 5 пунктам → пишет наряд.
4. Интегратор исполняет только по наряду → сверка с критериями.

## 5 пунктов судьи

Совпадения / противоречия / пропуски / уникальные идеи / слепые зоны.

## Шаблон наряда

- Цель:
- Входит:
- Не входит:
- Критерии приёмки:
- Шаги:
- Файлы:
- Риски:

## Когда

Да: развилки, архитектура, дорогие ошибки, неочевидные баги.
Нет: рутина, спешка, делимая задача.
