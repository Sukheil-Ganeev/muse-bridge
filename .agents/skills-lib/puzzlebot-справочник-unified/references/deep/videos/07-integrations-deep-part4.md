## Video 104: Sozdajom_Soobshchenija_Donaty_Oplatu
**Тема:** Автоматическая публикация сообщений пользователей в канале за донаты с использованием Integromat (Make)
**PuzzleBot-элементы:** Платежная система, конструктор, кнопка «Платеж», форма ввода, подписки на события (настройки бота), тип события «Форма ввода команд», функция «Выполнение только из клавиатуры»
**Категория:** Интеграции
**Ключевые техники:**
- Связка PuzzleBot + Integromat (Make) для автоматической публикации в канал
- Подписка на событие «Форма ввода команд» для отправки данных во внешний сервис
- Настройка Webhook в Integromat для получения данных от бота
- Использование модуля TelegramBot в Integromat для публикации сообщений
- Защита команды с формой ввода через «Выполнение только из клавиатуры»
**Шаги реализации:**
1. Подключить платежную систему
2. В конструкторе: стартовая команда -> кнопка «Платеж» (цена, переход при успехе)
3. Команда «Успех»: текстовый блок с вопросом + форма ввода для записи сообщения пользователя
4. В настройках бота: «Подписки на события» -> добавить подписку -> тип «Форма ввода команд» -> указать команду
5. В Integromat: создать сценарий -> Webhook -> Custom Webhook -> скопировать сгенерированную ссылку
6. В PuzzleBot: вставить ссылку Webhook в поле «Адрес» подписки, включить подписку
7. Отправить тестовый ответ на форму для активации Integromat
8. В Integromat: добавить модуль TelegramBot -> отправка текста -> указать токен бота, юзернейм канала, переменные из формы
9. Включить сценарий на постоянной основе
10. В конструкторе: включить «Выполнение только из клавиатуры» для команды с формой
11. Опубликовать и проверить полную цепочку: оплата -> ввод сообщения -> автопубликация в канале
**Полезные детали:** Integromat (Make) — внешний сервис для автоматизации. Для связи PuzzleBot с Integromat используется Webhook. Перед включением защиты «Выполнение только из клавиатуры» нужно отправить тестовый ответ в Integromat. Модулю TelegramBot в Integromat нужен токен бота для публикации. Метод работает для каналов и чатов.

## Video 111: Forma_Otzyvov_Podkljuchenie_NocoDB
**Тема:** Создание формы сбора отзывов в мини-приложении с сохранением данных в NocoDB
**PuzzleBot-элементы:** Мини-приложение (FormReview), заголовок (H1, по центру), описание (B1), формы ввода (текст, выбор варианта, загрузка файла), маска ввода (текст, телефон, почта, ссылка, число, крипто-кошелек, регулярное выражение), однострочный/многострочный тип, placeholder, обязательная форма, ограничение символов, клавиатура (кнопка «Отправить»), действие «NocoDB — Создать строку»
**Категория:** Интеграции
**Ключевые техники:**
- Создание формы сбора отзывов в мини-приложении с различными типами полей
- Подключение NocoDB для хранения данных из форм
- Настройка таблицы в NocoDB с соответствующими типами полей (single line text, multiselect, rating и др.)
- Привязка переменных из форм ввода к колонкам таблицы NocoDB
- Использование действия «NocoDB — Создать строку» для отправки данных
**Шаги реализации:**
1. Создать мини-приложение (например, FormReview)
2. Добавить заголовок (H1, по центру, например, «Получить скидку за отзыв»)
3. Добавить описание (B1)
4. Создать формы ввода: имя клиента (текст, однострочный), рейтинг (выбор варианта), скриншот (загрузка файла), ссылка на отзыв (маска «ссылка»), email (маска «почта»), согласие на публикацию (выбор варианта: да/нет)
5. Добавить клавиатуру с кнопкой «Отправить отзыв»
6. В NocoDB: создать базу (Create Page), дать название, создать таблицу с нужными колонками (имя клиента, рейтинг и т.д.)
7. В действиях мини-приложения: «Добавить действие» -> «NocoDB — Создать строку» -> выбрать базу и таблицу
8. Привязать переменные из форм ввода к колонкам таблицы
9. Опубликовать и протестировать
**Полезные детали:** NocoDB интегрирована напрямую в PuzzleBot. Формы ввода в мини-приложении поддерживают множество масок: текст, телефон, почта, регулярное выражение, число, ссылка, крипто-кошелек. Типы полей NocoDB: title, long text, number, decimal, attachment, checkbox, multiselect, single select, date, year, time, phone number, email, URL, currency, person, duration, rating, geometry, geodata, JSON, user. Переменные копируются из формы ввода и вставляются в настройки действия NocoDB. Видео записано в неформальном стиле (скринкаст с устным объяснением).
