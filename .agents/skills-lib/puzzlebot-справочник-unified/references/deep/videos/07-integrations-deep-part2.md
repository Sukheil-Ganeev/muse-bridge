## Video 44: 44_Delaem_Bota_Dostupom_Nejrosetjam
**Тема:** Проверка подписки на ресурс для доступа к нейросетям (ChatGPT) в боте, мьюты для неподписанных
**PuzzleBot-элементы:** Категории с приставкой "Mute", кнопка "Условия" (проверка подписки на ресурс), действие "Изменить категорию" (активация/деактивация), проверка подписки на ресурс (в кнопке), поп-ап сообщение, событие "Неизвестная команда", инлайн-клавиатура с действием "Ссылка"
**Категория:** ChatGPT/AI
**Ключевые техники:**
- Категории "Mute" для каждой нейросети: присваиваются неподписанным пользователям для блокировки доступа
- Кнопка условия с проверкой подписки на ресурс: при наличии подписки -- доступ, при отсутствии -- мьют
- Деактивация мьют-категорий при подтверждении подписки
- Активация мьют-категорий в исключающем правиле (нет подписки)
- Поп-ап уведомление при попытке доступа без подписки
- Галочка "Проверить подписки на ресурс" на кнопке
- Обработка события "Неизвестная команда" с проверкой подписки в последнем правиле условия
- Кнопка с действием "Ссылка" для перехода к подписке на ресурс
**Шаги реализации:**
1. Во вкладке "Модерация" создать категории Mute для каждой нейросети
2. В конструкторе настроить команду "Старт" с приветствием и кнопкой условия
3. Создать команду "Доступ" с действием деактивации всех Mute-категорий + текст о начале общения с AI
4. Создать команду "Подписка" с текстом о необходимости подписки + кнопка-ссылка на ресурс + кнопка "Начать общение" (с проверкой подписки и поп-апом)
5. Настроить кнопку условия: проверка подписки -> отправка команды "Доступ"; исключающее правило -> активация Mute-категорий + отправка команды "Подписка"
6. В условии для "Неизвестная команда" добавить проверку подписки в последнем правиле
7. Во вкладке "События" активировать "Неизвестная команда" с типом действия "Команда или условие"
8. Опубликовать и протестировать
**Полезные детали:** Мьют-категории -- это механизм PuzzleBot для блокировки отдельных команд бота. Каждая нейросеть привязана к своей команде, и мьют для конкретной категории блокирует доступ именно к ней. Количество нейросетей в боте постоянно пополняется -- актуальные названия команд по ссылке в описании видео. Видео является продолжением предыдущего урока по подключению ChatGPT.

## Video 47: 47_Integriruem_Google_Tablicy_Telegram
**Тема:** Интеграция Google Таблиц с Telegram-ботом: авторизация, запись данных пользователя, проверка наличия строки, обновление строки
**PuzzleBot-элементы:** Вкладка "Настройки" -> "Интеграции" -> Google Sheets, авторизация Google аккаунта, условие "Проверить строку" (поиск по user ID), действие "Создать строку", действие "Обновить строку", переменные (UserID.text, First Name, Last Name), формат "Переменный текст" (для кликабельных ссылок), инлайн-клавиатура, кнопка условия
**Категория:** Интеграции
**Ключевые техники:**
- Авторизация Google Sheets: Настройки -> Интеграции -> кнопка авторизации -> выбор аккаунта -> выдача всех разрешений
- Возможность подключения нескольких Google аккаунтов
- Условие "Проверить строку": поиск по столбцу user ID с полным совпадением переменной UserID.text
- Если пользователь есть в таблице -> направить на команду; если нет -> создать строку с данными
- Формат "Переменный текст" при записи -- для кликабельных ссылок в таблице
- Действие "Обновить строку" для изменения данных в существующей строке (например, статус заявки)
- Работа с выражениями и формулами при записи значений в ячейки
**Шаги реализации:**
1. Перейти в Настройки -> Интеграции -> Google Sheets -> авторизовать аккаунт, выдать все разрешения
2. Создать Google таблицу с заголовками (user ID, имя, фамилия, статус заявки и т.д.)
3. Создать условие "Проверка пользователя": проверить строку по столбцу user ID = UserID.text
4. Если найдено -- отправить на команду с заявкой; если нет -- создать строку с данными пользователя (формат "Переменный текст")
5. Создать команду "Заявка" с действием "Обновить строку" (записать статус "заявка подана") + текстовый блок
6. В стартовой команде добавить приветствие + кнопку с переходом к условию проверки
7. Опубликовать и протестировать
**Полезные детали:** Формат "Переменный текст" важен для корректного отображения кликабельных ссылок в таблице (например, ссылки на профиль пользователя). Если значение для ячейки не задано, оно не будет изменено при обновлении строки. Подробные правила написания выражений и формул -- по ссылке в описании видео. Можно подключить несколько Google аккаунтов к одному боту.

**Категория:** Интеграции

- Подключение Google Sheets: Настройки > Интеграция > авторизация Google-аккаунта (все галочки!)

- Автоматическая запись данных подписчиков в Google Таблицу через действие "Создать строку"

## Video 65: 65_Nastrojka_Rabota_Integracii_Bitriks24
**Тема:** Настройка интеграции PuzzleBot с Битрикс24 -- подключение CRM, синхронизация контактов и создание сделок через бота с передачей данных из форм ввода.
**PuzzleBot-элементы:** Настройки > Интеграция (Битрикс24), текстовый блок, inline-клавиатура, форма ввода (отправка сообщения, маска число), действие «Действие со сделкой» (создать сделку), переменные для записи полей сделки
**Категория:** Интеграции
**Ключевые техники:**
- Подключение Битрикс24 через вставку адреса и установку приложения PuzzleBot из маркета Битрикс
- Синхронизация контактов Битрикс24 с пользователями бота
- Передача значений форм ввода (текст, числа) в поля сделки CRM
- Создание дополнительных полей в сделке Битрикс для приёма данных из бота
**Шаги реализации:**
1. Перейти в Настройки бота > Интеграция > Битрикс24 > Настроить интеграцию
2. Создать/войти в аккаунт Битрикс24, скопировать адрес и вставить в PuzzleBot
3. Установить приложение PuzzleBot из маркета Битрикс24 (кнопка «Перейти в маркет»)
4. Указать поля и переменные для Telegram User ID и имени, нажать «Подключить интеграцию»
5. Активировать синхронизацию контактов во вкладке «Контакты»
6. В Битрикс24 создать дополнительное поле в сделке (тип «строка») для данных из форм ввода
7. В конструкторе: стартовая команда > текст > inline-кнопка «Бриф»
8. В команде «Бриф»: форма ввода (описание заказа, текст), форма ввода (сумма, число)
9. Добавить действие «Действие со сделкой»: создать сделку > воронка «Общее» > этап «Новое» > добавить поля с переменными из форм
10. Опубликовать и проверить в Telegram
**Полезные детали:** При подключении интеграции необходимо обязательно установить приложение PuzzleBot из маркета Битрикс24. Синхронизация контактов позволяет видеть пользователей бота как клиентов CRM. В полях сделки можно использовать переменные из форм ввода для автоматической передачи данных. Поле типа «строка» подходит для записи текстовых ответов из форм.
