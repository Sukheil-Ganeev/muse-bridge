## Video 83: Podkljuchaem_ChatGPT_Telegram_Botu
**Тема:** Подключение ChatGPT к Telegram-боту через ChatGPT PuzzleBot с настройкой лимитов (суточных, общих и по времени)
**PuzzleBot-элементы:** Интеграции (входящие запросы, подписки на события), API-токен, переменные (персональная и глобальная), модерация (категории), блок Timeout, условия с проверкой переменных и категорий, действие «Изменить категории», действие «Изменить переменную», inline-клавиатура
**Категория:** ChatGPT/AI
**Ключевые техники:**
- Подключение через ChatGPT PuzzleBot бота: генерация API-токена входящих запросов + подписка на исходящие сообщения
- Система тройных лимитов: суточный персональный, суточный глобальный, временной (один запрос в минуту)
- Использование категорий модерации для временной блокировки запросов через блок Timeout
- Команда должна называться «gpt if» (для ChatGPT) или «mj if» (для MidJourney)
**Шаги реализации:**
1. В настройках бота → Интеграции → Входящие запросы: сгенерировать API-токен, скопировать
2. Запустить ChatGPT PuzzleBot бота в Telegram, нажать «Подключить свой бот к ИИ», вставить API-ключ
3. Скопировать ссылку от бота; в настройках → Подписки на события → Добавить → вставить адрес, тип события «Любое сообщение», активировать
4. Во вкладке «События» отключить реакцию на неизвестную команду (временно)
5. Создать персональную переменную (лимит, число, по умолчанию 50) и глобальную переменную (общий лимит, число)
6. В «Модерации» создать 3 категории: для выключения реакции (2 шт.) и для ограничения запросов по времени
7. Создать 3 команды-уведомления: «прошло меньше минуты», «лимит исчерпан», «общий лимит закончился» (каждая с предложением купить Premium)
8. Создать команду «gpt if»: добавить блок Timeout (время между запросами), действие «Изменить категории» (деактивировать 3 категории), последовательность «После»
9. Создать условие с 4 правилами: (1) если лимит > 0 — отправить команду ИИ + активировать категории + уменьшить лимиты; (2) если лимит <= 0 — активировать мьют + отправить сообщение; (3) проверка наличия категории частых запросов; (4) проверка глобального лимита
10. Во вкладке «События» настроить неизвестную команду → отправить на условие
11. В ChatGPT PuzzleBot настроить роль бота (из примеров или свою)
**Полезные детали:** Команда обработки должна называться строго «gpt if» (ChatGPT) или «mj if» (MidJourney). Блок Timeout определяет минимальное время между запросами. Категории модерации используются как «флаги» для блокировки повторных запросов. Необходимо отключить реакцию на неизвестную команду перед настройкой, потом включить обратно с привязкой к условию.

## Video 85: Podkljuchaem_Nastraivaem_Rabotu_Integracii
**Тема:** Подключение и настройка интеграции с AmoCRM — контакты, лиды, синхронизация, уведомления, проверки и действия
**PuzzleBot-элементы:** Интеграции (AmoCRM), связки переменных (синхронизация), настройки лидов (финальный статус, несколько лидов, уведомления о смене этапа), проверки (наличие/статус/значение лида, наличие/значение контакта), действия (создать/изменить лид, создать/удалить контакт), форма ввода, текстовый блок
**Категория:** Интеграции
**Ключевые техники:**
- Авторизация AmoCRM через ссылку на личный кабинет
- Двусторонняя синхронизация переменных PuzzleBot и полей AmoCRM (кроме связок со стрелками — односторонние)
- Автоматическое создание несуществующих полей в AmoCRM
- Уведомления при смене этапа лида
- Проверки в конструкторе: наличие лида, статус лида, значение поля лида/контакта
- Действия: создать лид, изменить статус лида, изменить поля лида, создать/удалить контакт
**Шаги реализации:**
1. Скопировать ссылку на личный кабинет AmoCRM
2. В боте → Настройки → Интеграция → AmoCRM → «Настроить интеграцию» → вставить ссылку, сохранить
3. Нажать «Авторизоваться через AmoCRM», разрешить доступ
4. Настроить поля и переменные для записи (или оставить шаблон по умолчанию). Первая строка — Telegram User ID лиду, вторая — контакту
5. Вкладка «Контакты»: настроить синхронизацию, добавить связки переменных (PuzzleBot <-> AmoCRM)
6. Вкладка «Лиды»: настроить финальный статус, разрешение нескольких лидов, игнорирование лидов в финальном статусе, уведомления о смене этапа
7. В конструкторе: создать бота с формами ввода для сбора данных
8. В действиях: создать контакт (первым действием), затем создать лид, изменить статус лида, изменить поля лида (вставить переменные из форм ввода)
9. Опубликовать и проверить — сделка должна появиться в AmoCRM
**Полезные детали:** Все действия с контактами и лидами происходят на основе Telegram User ID — при изменении этого поля в AmoCRM действие не будет выполнено. Связанные переменные при активной синхронизации заменяют информацию в обе стороны (исключение — связки со стрелками). Можно задавать названия несуществующих полей — они создадутся автоматически. При включении «Игнорировать лиды в финальном этапе» уведомление на финальный статус не отправляется.

## Video 86: Podkljuchaem_Integraciju_NocoDB_Tablic
**Тема:** Подключение интеграции с NoCodeDB таблицами и настройка регистрации на мероприятия с записью данных
**PuzzleBot-элементы:** Интеграции (NoCodeDB), мини-приложение, форма ввода (текст, телефон), действие «Создать строку», inline-клавиатура, текстовый блок, обычная команда
**Категория:** Интеграции
**Ключевые техники:**
- Подключение к NocoDB через сервис nocodb.puzzlebot.top (только собственные таблицы PuzzleBot)
- Генерация API-токена в настройках аккаунта NocoDB
- Использование двойных фигурных скобок для вставки переменных в строку таблицы
- Сбор данных через форму ввода в мини-приложении с последующей записью в таблицу
**Шаги реализации:**
1. В боте → Настройки → Интеграция → NocoDB
2. Перейти на nocodb.puzzlebot.top, зарегистрироваться
3. Создать базу данных и таблицу с нужными столбцами (ФИО, Телефон, Username и т.д.)
4. В настройках аккаунта NocoDB → Токены → создать и скопировать токен
5. Вставить токен в настройках интеграции бота, сохранить
6. В конструкторе: создать команду «Успешная регистрация» с текстовым блоком
7. В стартовой команде: текстовый блок + inline-кнопка → переход к мини-приложению
8. Создать мини-приложение: заголовок + формы ввода (текст для ФИО, телефон для номера) + кнопка отправки
9. В кнопке отправки: действие «Переход к команде» (команда успеха) + действие «Создать строку» (выбрать базу/таблицу, заполнить столбцы переменными через `{{переменная}}`)
10. Опубликовать и проверить запись в таблице
**Полезные детали:** Интеграция NocoDB работает ТОЛЬКО с таблицами на nocodb.puzzlebot.top (собственный сервис PuzzleBot), а не с обычным NocoDB. Для записи переменных в столбцы таблицы используются двойные фигурные скобки: `{{переменная}}`. Маска ввода «телефон» автоматически валидирует формат номера.

## Video 87: Podkljuchaem_Integraciju_Sajtom_Tilda
**Тема:** Интеграция бота с сайтом Tilda — открытие сайта в мини-приложении и отправка команд по нажатию кнопок на сайте
**PuzzleBot-элементы:** Обычная клавиатура (не inline!), действие «Ссылка в мини-приложении», HTML-скрипт для Tilda, формат команд `#pbt_cmd название_команды`
**Категория:** Интеграции
**Ключевые техники:**
- Открытие сайта Tilda внутри мини-приложения через обычную (не inline) клавиатуру
- Вставка специального HTML-скрипта в код сайта Tilda (блок «Другое» → «HTML-код»)
- Формат ссылки на кнопке Tilda: `#pbt_cmd название_команды` — отправляет команду боту
- Названия команд должны быть латинскими буквами
**Шаги реализации:**
1. Создать сайт на Tilda (или использовать существующий), скопировать URL страницы
2. В конструкторе бота: открыть стартовую команду, добавить текстовый блок
3. Добавить ОБЫЧНУЮ клавиатуру (не inline — inline не подходит для обработки нажатий), действие «Ссылка в мини-приложении», вставить URL сайта
4. Создать обычную команду с латинским названием, добавить текстовый блок
5. Опубликовать изменения бота
6. В Tilda: добавить блок «Все блоки» → «Другое» → «HTML-код», вставить специальный скрипт (из описания видео)
7. На кнопке Tilda в поле «Ссылка» вписать: `#pbt_cmd название_команды`
8. Опубликовать изменения Tilda, проверить в Telegram
**Полезные детали:** ВАЖНО: для открытия сайта в мини-приложении используется именно ОБЫЧНАЯ клавиатура, не inline — inline-клавиатура не подходит для обработки нажатий кнопок на сайте. HTML-скрипт обязателен для связи кнопок сайта с ботом. Названия всех команд — только латиницей. Формат ссылки: решётка, pbt, нижнее подчёркивание, cmd, пробел, название команды. Способ применим к любому сайту, не только Tilda.
