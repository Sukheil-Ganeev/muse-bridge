## Video 01: 01_Privetstvennij_Bonus
**Тема:** Начисление приветственного бонуса новым пользователям бота с защитой от повторного начисления при перезапуске.
**PuzzleBot-элементы:** Переменные (персональные, числовой тип), Условия (проверка вызова команды), Команды, Действие "Изменить переменную", Группы переменных, Дополнительные настройки (выполнить до, эффект сообщения, удаление текущей команды, защита контента от пересылки), Копирование/вставка клавиатуры.
**Категория:** Переменные и условия
**Ключевые техники:**
- Создание персональной числовой переменной (Balance) с значением по умолчанию 0 для хранения баланса пользователя
- Использование условия "Вызов команды или условия" для проверки, получал ли пользователь бонус ранее
- Действие "Изменить переменную" с прибавлением числа (например, +7) для начисления бонуса
- Настройка "Выполнить до" -- сначала выполняется действие (начисление), потом выводится блок (сообщение)
- Копирование клавиатуры между командами через "Копировать клавиатуру" / "Вставить клавиатуру"
- Добавление эффекта к сообщению (огоньки, поздравление) для визуального оформления
**Шаги реализации:**
1. Создать персональную переменную числового типа (например, "Balance") со значением по умолчанию 0
2. Переименовать группу переменных для удобной навигации (например, "Категория пользователям > Промо > Баланс")
3. Вставить переменную баланса в профиль пользователя для отображения
4. Создать команду "Успешное начисление бонуса" с действием "Изменить переменную" (Balance + 7)
5. Настроить "Выполнить до" для действия, добавить эффект сообщения (огоньки), удаление текущей команды, защиту от пересылки
6. Создать условие проверки: "Вызов команды" -> "Успешное начисление бонуса"
7. Если команда была вызвана ранее -- отправить в меню (бонус уже получен)
8. Если не вызвана -- отправить в команду начисления бонуса
9. Все кнопки из Start замкнуть на это условие проверки
10. Протестировать: первый запуск -- начисление; повторный запуск -- переход в меню
**Полезные детали:**
- После создания переменной необходимо перезапустить конструктор, чтобы она появилась в списке доступных
- Переменные лучше группировать и подписывать, чтобы не запутаться при большом количестве
- Рекомендуется оставлять одну кнопку на экране начисления ("Вперёд за толкованием"), чтобы не путать пользователя
- Ограничение названия условия: не более 64 символов

## Video 12: 12_Uslovija_Knopka_Uslovija
**Тема:** Подробный обзор сущности "Условие" и двух её подтипов: "Обычное условие" и "Кнопка условия". Интерфейс, настройки, отличия.
**PuzzleBot-элементы:** Условия (Обычное условие, Кнопка условия), Правила (проверки + действия), Типы проверок (все проверки, любая проверка), Параметры проверок (задать количество, задать период, проверить другого пользователя), Типы периодов (количественный, датированный, календарный), Типы действий (все действия, случайное действие), Исключающее правило, Инлайн-клавиатура (кнопка условия), Дополнительные настройки (выполнение с текущей группы, случайная отправка, отображение в меню).
**Категория:** Переменные и условия
**Ключевые техники:**
- Обычное условие: вызывается как команда (по названию, переходам, кнопкой и т.д.)
- Кнопка условия: определяет настройки инлайн-кнопки, вызывается только через действие "Кнопка условия" в инлайн-кнопке
- Правило = проверка + действие; при вызове условия выполняется только одно правило
- Тип проверки "Все проверки" -- все должны пройти; "Любая проверка" -- достаточно одной
- "Задать количество" -- проверка на точное число вызовов (например, ровно 3 раза)
- "Задать период" -- проверка за временной промежуток (количественный, датированный, календарный)
- "Проверить другого пользователя" -- проверка по Telegram ID или юзернейму другого пользователя
- "Случайное действие" с настройкой вероятности каждого действия
- Исключающее правило -- последнее правило, срабатывает если ни одно другое не прошло
- Кнопка условия позволяет показывать разные кнопки разным пользователям (разные названия и действия)
**Шаги реализации:**
1. В конструкторе нажать "Добавить условие"
2. Дать название условию
3. Выбрать тип: "Обычное условие" или "Кнопка условия" (ВАЖНО: изменить тип после сохранения нельзя!)
4. Настроить дополнительные опции (выполнение с текущей группы, случайная отправка, отображение в меню)
5. Создать правило: выбрать тип проверки ("Все проверки" / "Любая проверка")
6. Добавить проверку: указать команду/условие, настроить количество, период, другого пользователя
7. Добавить действие: выбрать тип ("Все действия" / "Случайное действие"), настроить вероятность
8. Добавить исключающее правило для случая, когда все проверки провалены
9. Для "Кнопки условия": настроить название кнопки и её действие (ссылка, переход и т.д.) в каждом правиле
10. Связать кнопку условия: создать инлайн-клавиатуру -> добавить кнопку -> действие "Кнопка условия" -> выбрать условие
**Полезные детали:**
- Тип условия нельзя изменить после сохранения -- выбирайте внимательно
- Кнопка условия отображается только в списке при выборе действия "Кнопка условия" в инлайн-кнопке; обычные условия там не видны
- Типы периодов: количественный (относительно текущего момента), датированный (точные даты), календарный (относительно календарных значений)
- Пример кнопки условия: подписчик с активным сценарием видит кнопку "Ссылка на подарок", а без сценария -- кнопку "Регистрация"
- Проверка выполняется ДО отправки сообщения с кнопкой (на этапе формирования)

## Video 21: 21_Peremennye_Personalnaja_Globalnaja
**Тема:** Обзор вкладки "Переменные": персональные и глобальные переменные, создание, форматы значений и редактирование
**PuzzleBot-элементы:** Вкладка Переменные, персональные переменные, глобальные переменные, системные группы переменных, пользовательские переменные, форматы значений (текст, число, формула, ссылка, документ), интегрированные значения (HTTP-запрос, Google Sheets), действие "Изменить переменную", действие "Очистить переменную", операторы (заменить, прибавить, вычесть)
**Категория:** Переменные и условия
**Ключевые техники:**
- Синтаксис переменных: двойные фигурные скобки {{имя_переменной}}, латиница A-Z, цифры, нижнее подчёркивание
- Персональные переменные: индивидуальные значения для каждого пользователя (имя, баланс, баллы)
- Глобальные переменные: общие значения для всех пользователей (название бота, ссылка на сайт)
- Два типа значений: обычное (внутри бота) и интегрированное (GET-запрос, JSON-формат; через HTTP или Google Sheets)
- Форматы значений: текст, число, формула, ссылка, документ
- Формула -- сложное значение из нескольких переменных или математических операций
- Редактирование: через действие "Изменить переменную" (операторы) или ручное редактирование в модерации
- Для числовых переменных: оператор "заменить", "прибавить", "вычесть" и другие
- Для текстовых переменных: только оператор "заменить", значение в кавычках
**Шаги реализации:**
1. Открыть вкладку "Переменные" в боте
2. Выбрать тип: персональные или глобальные
3. Нажать "Добавить переменную"
4. Задать имя (латиница, цифры, андерскор)
5. Выбрать формат значения (текст/число/формула/ссылка/документ)
6. Выбрать тип значения: обычное или интегрированное
7. Указать значение по умолчанию
8. Добавить описание и группу
9. Для изменения переменной: в Конструкторе добавить действие "Изменить переменную"
10. Выбрать оператор и записать выражение
**Полезные детали:** Системные переменные редактируются только в тех местах, где были созданы (формы ввода, реферальная система и т.д.). Очистка переменной сбрасывает до значения по умолчанию. Для интегрированных значений через Google Sheets необходимо подключить Google-аккаунт. Формулы и выражения имеют свои правила написания (ссылка в описании видео).

## Video 38: 38_Parol_Ogranichenie_Dostupa
**Тема:** Установка пароля на бота и ограничение доступа к функциям для авторизованных пользователей
**PuzzleBot-элементы:** Категории (модерация), инлайн-команда (как пароль), текстовый блок, группы команд с ограниченным доступом, добавление в категорию (действие), переход через задержку (2 секунды), инлайн-клавиатура
**Категория:** Переменные и условия
**Ключевые техники:**
- Инлайн-команда с названием = пароль: бот реагирует только на точное совпадение текста
- Категория для авторизованных пользователей: присваивается при вводе правильного пароля
- Вторая группа команд с доступом только для одной категории: весь контент закрыт от неавторизованных
- Переход через задержку: после присвоения категории через 2 секунды перенаправляет в защищенную группу команд
- Любой случайный текст игнорируется, пока не введен точный пароль
**Шаги реализации:**
1. Открыть вкладку "Модерация", создать категорию для авторизованных пользователей
2. В конструкторе удалить стандартные команды, опубликовать
3. Настроить команду "Старт" с приветствием и запросом пароля
4. Создать инлайн-команду с названием = необходимый пароль
5. В этой команде добавить текстовый блок + действие "Добавление в категорию"
6. Создать вторую группу команд с доступом только для созданной категории
7. Во второй группе создать команды с контентом и инлайн-клавиатурой
8. В команде-пароле настроить переход через 2 секунды к команде из второй группы
9. Опубликовать и протестировать
**Полезные детали:** Механика основана на том, что инлайн-команда активируется только при точном совпадении текста пользователя с названием команды. Все остальные сообщения просто игнорируются. Вторая группа команд полностью недоступна без категории -- пользователь даже не видит её кнопки и содержимое.
