## Video 42: 42_Vyvodim_Statistiku_Chat_Bote
**Тема:** Сбор и отображение статистики: подсчет пользователей, переходов, оплат, уведомления администратору, учет источников трафика
**PuzzleBot-элементы:** Глобальные переменные (stats.*), персональные переменные, категории (модерация -- для администратора), кнопка "Условия" (проверка категории), действие "Изменить переменную" (прибавить), действие "Платеж", действие "Отправить команду или условие", вкладка "Вход" (ссылки для источников трафика), условия с проверкой источника, скрытие кнопки в исключающем правиле, отправка другому пользователю
**Категория:** Переменные и условия
**Ключевые техники:**
- Встроенные переменные статистики: stats.total.users, stats.today.users, stats.today.left, stats.total.payment.count, stats.total.payment.sum
- Создание собственных глобальных переменных для учета воронки (stats.sale.open, stats.sale.paid)
- Отдельные переменные под каждый источник трафика для раздельного подсчета оплат
- Категория "Администратор" для ограничения доступа к статистике
- Кнопка условия: проверка наличия категории; в исключающем правиле -- скрытие кнопки
- Уведомление администратору через "Отправить команду другому пользователю" (по юзернейму)
- Вкладка "Вход" -- создание многоразовых ссылок для отслеживания источников трафика
- Условие с проверкой источника трафика для раздельного подсчета оплат по каналам
**Шаги реализации:**
1. Во вкладке "Переменные" ознакомиться с автоматическими stats-переменными
2. Создать глобальные переменные stats.sale.open и stats.sale.paid (тип: число)
3. Создать отдельные переменные для каждого источника трафика
4. Во вкладке "Модерация" создать категорию "Администратор", добавить пользователей
5. В конструкторе создать команду "Статистика" с текстовым блоком и выводом переменных
6. Создать кнопку "Условия" с проверкой категории админа; в исключающем правиле скрыть кнопку
7. В стартовой команде добавить кнопку условия для доступа к статистике
8. Создать команду оплаты с действием "Платеж" + действие "Изменить переменную" stats.sale.open (+1)
9. В команде успешной оплаты добавить действие "Изменить переменную" stats.sale.paid (+1)
10. Создать команду уведомления администратору, подключить через "Отправить другому пользователю"
11. Во вкладке "Вход" создать многоразовые ссылки для каждого источника трафика
12. Создать условие с проверкой источника и увеличением соответствующей переменной
13. Опубликовать и протестировать
**Полезные детали:** Встроенные stats-переменные создаются автоматически и не требуют настройки. Все начинаются с префикса "stats", что удобно для поиска. Кнопка условия с проверкой категории и скрытием в исключающем правиле -- универсальный паттерн для разграничения доступа (кнопка не отображается у обычных пользователей). Уведомление администратору отправляется через галочку "Выполнить другому пользователю" с указанием юзернейма.

## Video 71: 71_Obzor_Formul_Vyrazhenij_Raboty
**Тема:** Обзор формул и выражений для работы с переменными: математические расчёты, операции с датами, склонение слов, форматирование чисел, регулярные выражения, случайные числа.
**PuzzleBot-элементы:** Переменные (формат «Формула»), действие «Изменить переменную» (последовательность «До»), формулы: AddDate, CurrentDate, DaysBetween, plure, DateFormat, random, match, round, ceil, floor, numberFormat; формулы в тексте
**Категория:** Переменные и условия
**Ключевые техники:**
- Формула-переменная для расчёта стоимости (цена * количество)
- AddDate(CurrentDate, 30) -- продление подписки на 30 дней от текущей даты
- DaysBetween -- разница между датами в днях
- plure -- правильное склонение слов по числу (возвращает число + слово)
- DateFormat -- форматирование даты (F -- полный месяц, M -- краткий, D -- день, m -- номер месяца, Y -- год)
- random -- генерация случайного числа
- match -- извлечение части строки по регулярному выражению (например, из startPayload)
- round(переменная, 2) -- округление до N знаков; ceil -- вверх; floor -- вниз
- numberFormat -- форматирование числа с разделителями тысяч
**Шаги реализации:**
1. Создать переменные для хранения значений (стоимость, количество)
2. Создать переменную-формулу: формат «Формула», записать выражение (например, price * quantity)
3. Действие «Изменить переменную» + AddDate(CurrentDate, 30) для подписки; последовательность «До»
4. Действие + DaysBetween для расчёта дней между датами
5. В тексте использовать plure(переменная, "день", "дня", "дней") для склонения
6. DateFormat(дата, "D F Y") для красивого вывода даты
7. random(min, max) для розыгрышей и случайных чисел
8. match(startPayload, "PB(.*)") для извлечения данных из реферальной ссылки
9. В тексте: round(переменная, 2) для округления сумм; numberFormat(число, 0, ".", " ") для разделителей
10. Формулы в тексте: `{{= выражение =}}` для расчётов без создания переменных
**Полезные детали:** Последовательность выполнения «До» важна -- действие с переменной выполняется до отправки следующих блоков. ceil округляет вверх, floor -- вниз до целого. В numberFormat первый параметр -- знаки после запятой, второй -- разделитель дробной части, третий -- разделитель тысяч. Формула match работает с регулярными выражениями для парсинга строк.
