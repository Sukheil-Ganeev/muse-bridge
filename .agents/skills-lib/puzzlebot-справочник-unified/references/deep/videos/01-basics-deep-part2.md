## Video 28: 28_Sozdat_Bota_Bez_Programmirovanija
**Тема:** Создание Telegram-бота через BotFather и привязка к PuzzleBot -- полный процесс с нуля
**PuzzleBot-элементы:** BotFather (системный бот Telegram), регистрация бота (/newbot), API-ключ (токен), сайт puzzlebot.top, авторизация через Telegram, привязка бота по API-ключу, вкладка Конструктор, команда Start, текстовый блок, обычная клавиатура
**Категория:** Основы
**Ключевые техники:**
- Регистрация бота: найти BotFather в Telegram (с галочкой верификации), команда /newbot
- Username бота: уникальный, обязательно заканчивается на "bot"
- API-ключ: копируется из сообщения BotFather после успешной регистрации
- Авторизация в PuzzleBot: через Telegram (нажать "Начать" -> перейти по ссылке)
- Привязка бота: вставить API-ключ на сайте PuzzleBot
- Первая команда: в Конструкторе открыть Start, добавить текстовый блок и обычную клавиатуру
**Шаги реализации:**
1. Открыть Telegram, найти BotFather (с галочкой верификации)
2. Нажать "Начать", написать /newbot
3. Ввести название бота
4. Выбрать уникальный username (заканчивается на "bot")
5. Скопировать API-ключ из ответа BotFather
6. Перейти на puzzlebot.top -> Личный кабинет -> Войти через Telegram
7. Нажать "Начать" в Telegram -> перейти по ссылке
8. Завершить регистрацию (ввести почту)
9. Добавить бота: вставить API-ключ -> подтвердить
10. Перейти в Конструктор -> команда Start -> текстовый блок + клавиатура
11. Опубликовать изменения и проверить в боте
**Полезные детали:** Обязательно проверять галочку верификации у BotFather -- существуют фейковые боты. Username должен быть уникальным во всём Telegram. API-ключ -- конфиденциальная информация, не делиться публично. После привязки бот сразу доступен для настройки в личном кабинете.

**Тема:** Авторизация (вход) в сервис PuzzleBot через Telegram -- с ПК и мобильного устройства

**Категория:** Основы

## Video 48: 48_Dublirovat_Perenosit_Chat_Bot
**Тема:** Дублирование и перенос бота между аккаунтами PuzzleBot
**PuzzleBot-элементы:** Вкладка "Настройки", кнопка "Дублировать бота", кнопка "Перенести бота", выбор вкладок для дублирования, дублирование отдельных групп команд, дублирование с заменой, удаление информации пользователей, перенос с ресурсами и администраторами
**Категория:** Основы
**Ключевые техники:**
- Дублирование бота: выбор бота из списка или вставка API-ключа (для бота на другом аккаунте)
- Выбор конкретных вкладок для дублирования (не обязательно копировать все)
- Дублирование отдельных групп команд конструктора
- При дублировании основной группы команд -- она создается с цифрой "2" в новом боте
- Дублирование с заменой: все данные целевого бота заменяются БЕЗ возможности восстановления
- Опция "Удалить информацию пользователей" у целевого бота
- Перенос бота на другой аккаунт по юзернейму
- Перенос с ресурсами и администраторами
**Шаги реализации:**
1. Открыть бота -> Настройки -> "Дублировать бота"
2. Выбрать целевого бота из списка или вставить API-ключ
3. Раскрыть "Вкладки для дублирования" и выбрать нужные
4. При необходимости выбрать конкретные группы команд конструктора
5. (Опционально) Включить "Дублировать с заменой" или "Удалить информацию пользователей"
6. Подтвердить дублирование
7. Для переноса: Настройки -> "Перенести бота" -> ввести юзернейм целевого аккаунта
8. (Опционально) Включить перенос с ресурсами и администраторами
**Полезные детали:** Функции дублирования и переноса доступны ТОЛЬКО на платных тарифах. При дублировании с заменой данные целевого бота удаляются безвозвратно -- будьте осторожны. При удалении информации пользователей бот сможет писать только тем, с кем ранее общался. При переносе бот полностью перемещается на другой аккаунт. Дублирование отдельных групп команд полезно для переноса конкретных сценариев без копирования всего бота.

## Video 112: Formatirovanie_Teksta_Blok_Komanda
**Тема:** Форматирование текста в блоке команды конструктора PuzzleBot
**PuzzleBot-элементы:** Блок команда, текстовый блок, форматирование текста (B — жирный, I — курсив, подчеркивание, зачеркивание, код, ссылка, цитата), панель форматирования
**Категория:** Основы
**Ключевые техники:**
- Использование встроенной панели форматирования текста в PuzzleBot
- Применение и снятие форматирования через выделение текста и кнопки панели
- Комбинирование стилей (жирный + курсив)
- Форматирование работает ТОЛЬКО через панель инструментов (не через Markdown-символы и не через HTML)
**Шаги реализации:**
1. Открыть блок команды в конструкторе
2. Выделить нужный текст
3. Использовать панель форматирования: B (жирный), I (курсив), подчеркивание, зачеркивание, код, ссылка, цитата
4. Для снятия форматирования: выделить текст и нажать ту же кнопку повторно
5. Для комбинации: выделить текст, нажать B, затем I (получится жирный курсив)
6. Для быстрого форматирования можно использовать Ctrl+B, Ctrl+I и т.д.
**Полезные детали:** Форматирование в PuzzleBot работает ТОЛЬКО через встроенную панель инструментов. Добавление звездочек (*) или HTML-тегов вручную НЕ форматирует текст. Нельзя форматировать пробел отдельно. Панель появляется при выделении текста. Кнопки панели: B (bold/жирный), I (italic/курсив), подчеркивание, зачеркивание, код, ссылка, два варианта цитат. Горячие клавиши (Ctrl+B и т.д.) также работают. Видео записано в неформальном стиле.
