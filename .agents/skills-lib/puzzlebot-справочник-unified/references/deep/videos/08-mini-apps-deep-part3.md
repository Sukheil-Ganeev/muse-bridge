# 08. Мини-приложения -- Глубокий справочник

## Video 94: Sozdaem_Mini_Prilozhenie_Otpravki
**Тема:** Создание мини-приложения для отправки заявок с записью данных в таблицы NocoDB
**PuzzleBot-элементы:** Интеграция NocoDB, мини-приложение, форма ввода, действие «Создать строку», интегрированные переменные (NocoDB), персональные переменные, дублирование ответа в переменную, блок «Стикер», заголовок
**Категория:** Мини-приложения
**Ключевые техники:**
- Дублирование ответа формы ввода в отдельную переменную (допнастройки формы)
- Создание интегрированных переменных типа NocoDB для каждого столбца таблицы
- Запись данных в NocoDB через действие «Создать строку» в кнопке мини-приложения
- Два мини-приложения: основное (форма заявки) и уведомительное (заявка отправлена)
**Шаги реализации:**
1. В NocoDB: создать таблицу с нужными столбцами (User ID — число, имя — текст, описание — длинный текст)
2. Создать персональные переменные для каждого столбца
3. Создать интегрированные переменные типа NocoDB для каждого столбца (база → таблица → столбец)
4. Создать мини-приложение с формой ввода: заголовок, поля ввода, кнопка отправки
5. В допнастройках формы: включить «Дублировать ответ в переменную» → указать переменную
6. В кнопке: действие «Создать строку» (выбрать базу/таблицу, заполнить столбцы переменными) + переход ко второму мини-приложению
7. Создать второе мини-приложение с сообщением «Заявка отправлена»
8. В стартовой команде: кнопка → переход к первому мини-приложению
9. Опубликовать и проверить запись в таблице
**Полезные детали:** Опция «Дублировать ответ в переменную» в допнастройках формы ввода позволяет сохранить ответ пользователя в отдельную переменную для дальнейшего использования. Интегрированные переменные NocoDB нужны для каждого столбца таблицы. Блок «Стикер» можно использовать для визуального оформления мини-приложения.

## Video 100: Sozdajom_Mini_Prilozhenie_Konstruktore
**Тема:** Полный обзор создания и настройки мини-приложения (Mini App) в Telegram-боте через PuzzleBot
**PuzzleBot-элементы:** Мини-приложение, текстовый блок, блок изображения (карусель), блок видео, блок стикер (TGS/JSON), блок заголовок, блок описание, блок строки, блок документ, клавиатура (обычная, инлайн, фиксированная), формы ввода (текст, дата, время, выбор варианта, загрузка файла), прямая и техническая ссылка, защита контента, кнопка назад, поп-ап перед закрытием, свайп вниз
**Категория:** Мини-приложения
**Ключевые техники:**
- Создание мини-приложения с уникальным названием
- Различие между прямой ссылкой (для пользователей) и технической ссылкой (для настроек BotFather)
- Включение режима Mini App в BotFather для работы прямых ссылок
- Защита контента (запрет копирования и контекстного меню)
- Настройка кнопки «Назад» с действиями (предыдущее мини-приложение, переход к конкретному, переход к команде)
- Карусель изображений при загрузке двух и более картинок
- Поддержка видео с YouTube, Vimeo, VK, Zen, RuTube, OK
- Формы ввода с множеством типов и настроек (обязательность, повторное прохождение, подстановка из переменной)
**Шаги реализации:**
1. Перейти в конструктор бота, нажать «+», выбрать «Мини-приложение»
2. Ввести уникальное название мини-приложения
3. Опубликовать для генерации ссылок (прямая и техническая)
4. В BotFather включить режим Mini App для работы прямых ссылок
5. Настроить дополнительные параметры: защита контента, кнопка назад, поп-ап, свайп
6. Добавить блоки контента: текст, изображения, видео, стикеры, заголовки, описания, строки, документы
7. Добавить клавиатуры (могут быть самостоятельными блоками, неограниченное количество кроме фиксированной)
8. Настроить формы ввода с нужными типами и параметрами
9. В команде Start создать кнопку с переходом к мини-приложению
10. Сохранить и опубликовать
**Полезные детали:** Одна картинка растягивается по ширине с сохранением пропорций; две и более — работают как карусель. Для платформы Zen нужно копировать особую ссылку (не из адресной строки). Стикеры поддерживают форматы TGS и JSON. Блок «Строки» подходит для личных кабинетов/профилей. Документы отправляются в личные сообщения бота. В мини-приложении клавиатура — самостоятельный блок (в отличие от бота). Для каждой кнопки можно настроить вибрацию. Форма «Выбор варианта» поддерживает настройки: количество вариантов, вид переключателей, варианты по умолчанию, отключение записи в переменную, вибрация при клике, изменение переменной при выборе. «Отправить один случайный блок» — отправляет один случайный блок из мини-приложения. Свайп вниз рекомендуется для мини-приложений с небольшим контентом.
