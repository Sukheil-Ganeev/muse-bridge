## Video 61: 61_Nastraivaem_Poisk_Vnutri_Mini
**Тема:** Добавление поиска по контенту внутри мини-приложения с настройкой отображения результатов
**PuzzleBot-элементы:** Блок "Поиск" в мини-приложении, поисковые настройки мини-приложения (заголовок, описание, ключевые фразы), группы команд, настройки области поиска (отдельные мини-приложения или группы команд), опции отображения (название мини-аппа, название группы, иконка блоков), дополнительные настройки (подставка мини-приложения), опция "Игнорировать в поиске по группе команд"
**Категория:** Мини-приложения
**Ключевые техники:**
- Блок "Поиск" ищет по текстовым блокам, кнопкам, изображениям и видео (если есть описание)
- Настройка области поиска: по отдельным мини-приложениям или целым группам команд
- Клик по миниатюре блока перемещает к нужному месту, клик по кнопке выполняет действие
- Поисковые настройки страницы: заголовок (вместо названия), описание, ключевые фразы для нечёткого поиска
- Подстановка мини-приложения -- его контент отображается как на текущей странице
**Шаги реализации:**
1. Создать мини-приложение с контентом (текст, кнопки, изображения, видео с описанием)
2. Добавить блок "Поиск" в мини-приложение
3. В настройках блока выбрать область поиска: конкретные мини-приложения или группы команд
4. Настроить отображение результатов: название мини-аппа, название группы, иконка блоков
5. В поисковых настройках каждого мини-приложения заполнить: заголовок, описание, ключевые фразы
6. При необходимости включить "Игнорировать в поиске по группе команд" для исключения страниц
7. Опционально: в дополнительных настройках подставить мини-приложение для отображения контента
**Полезные детали:** Изображения и видео попадают в поиск ТОЛЬКО если у них есть описание. Если найденный блок на текущей странице -- описание в поиске не отображается. Если на другой странице -- может выводиться название мини-аппа, группы или оба. Ключевые фразы позволяют находить страницу даже при нечётком запросе.

## Video 63: 63_Nastraivaem_Ssylki_Knopki_Mini
**Тема:** Создание короткой ссылки на мини-приложение, кнопки в профиле бота и кнопки Menu в боте
**PuzzleBot-элементы:** Техническая ссылка мини-приложения (конструктор), BotFather (команды: /mybots, /newapp, Configure Mini App, Menu Button), короткая ссылка на приложение
**Категория:** Мини-приложения
**Ключевые техники:**
- Копирование технической ссылки опубликованного мини-приложения из конструктора
- Активация кнопки мини-приложения в профиле бота через BotFather: My Bots > Bot Settings > Configure Mini App
- Создание короткой ссылки через BotFather: команда /newapp > выбор бота > название > описание > фото 640x360 > техническая ссылка > окончание URL
- Настройка кнопки Menu в боте: BotFather > My Bots > Bot Settings > Menu Button > Configure Menu Button > техническая ссылка > название кнопки
- Исправление бага с прямой ссылкой: добавление окончания короткой ссылки в прямую ссылку
**Шаги реализации:**
1. В конструкторе PuzzleBot перейти в мини-приложение и скопировать техническую ссылку
2. Кнопка в профиле: BotFather > /mybots > выбрать бота > Bot Settings > Configure Mini App > активировать > вставить техническую ссылку
3. Короткая ссылка: BotFather > /newapp > выбрать бота > название > описание > фото 640x360 (или GIF, или /empty) > техническая ссылка > задать окончание URL
4. Кнопка Menu: BotFather > /mybots > выбрать бота > Bot Settings > Menu Button > Configure Menu Button > техническая ссылка > название
5. Формат прямой ссылки: `https://t.me/UserNameBot?startapp=параметр`
6. Исправление бага (актуально на сентябрь 2024): в прямую ссылку вставить `/short_name` после юзернейма бота перед `?`
**Полезные детали:** Фото для короткой ссылки должно быть 640x360 пикселей. Баг Telegram (на сентябрь 2024): при переходе по прямой ссылке открывается основное мини-приложение вместо указанного -- исправляется добавлением окончания короткой ссылки. Кнопка Menu заменяет стандартную надпись "Menu" на кастомное название.

## Video 68: 68_Novaja_Funkcija_Mini_Istorija
**Тема:** Новая функция «Мини-истории» -- показ видео или изображений в формате Telegram-историй, а также обновления стилей текстовых блоков, заголовков и описаний в мини-приложениях.
**PuzzleBot-элементы:** Мини-истории (создание, загрузка медиа, кнопка с действием), блок «Карточки» (действие -- переход к мини-истории), текстовый блок (стили: предупреждение, раздел), заголовок (стили: экстра, H3), описание (стили: B1, B3), строки (загрузка изображения), кнопка к заголовку, inline-клавиатура
**Категория:** Мини-приложения
**Ключевые техники:**
- Создание мини-историй с загрузкой изображений/видео (до 50 МБ) через ID файла или прямую загрузку
- Привязка кнопки к мини-истории (например, ссылка на сайт)
- Интеграция мини-историй в мини-приложения через блок «Карточки» (действие карточки -- переход к мини-истории)
- Использование новых стилей текста: предупреждение (с изображением), раздел (с изображением/стикером)
- Добавление кликабельного текста или изображения к заголовку
**Шаги реализации:**
1. Создать мини-историю: нажать «+», дать название, загрузить изображение/видео (до 50 МБ)
2. Добавить несколько историй для слайдшоу-эффекта
3. Опционально: добавить клавиатуру с одной кнопкой (действие -- ссылка)
4. Создать мини-приложение > блок «Карточки» > добавить карточку > загрузить изображение > действие «Переход к мини-истории»
5. Оформить текстовые блоки с разными стилями (предупреждение, раздел)
6. Использовать разные стили заголовков (экстра, H3) и описаний (B1, B3)
7. Добавить кнопку к заголовку (кликабельный текст / изображение) с действием «Переход к мини-истории»
8. В стартовой команде: inline-клавиатура с кнопками перехода к мини-историям и мини-приложениям
9. Опубликовать и проверить
**Полезные детали:** Мини-истории работают как Telegram-истории -- можно переключать и останавливать. Максимальный размер файла -- 50 МБ. При стиле «Предупреждение» можно добавить изображение к тексту. При стиле «Раздел» доступны изображение и стикер. Блок «Строки» теперь поддерживает загрузку изображений.

## Video 69: 69_Novye_Funkcii_Mini_Prilozhenija
**Тема:** Новые функции мини-приложений: блок карточек (настройки размеров, помечание новых), попапы, блок «Подстановка», форма ввода типа «Список», подстановка в формах ввода с выбором варианта, блок HTML, кастомизация стилей, формулы в тексте.
**PuzzleBot-элементы:** Блок карточек (круглые/прямоугольные, авто/пиксели/проценты, помечать новые, перемещать просмотренные), попапы (с кнопкой / без кнопки), блок «Подстановка», форма ввода тип «Список» (вручную, файл, Google Sheets, NoCode), подстановка в формах ввода (тип «выбор варианта»), блок HTML (+ HTML в TagHead), кастомизация (цвета, шрифты, размеры), формулы в тексте (двойные фигурные скобки)
**Категория:** Мини-приложения
**Ключевые техники:**
- Настройка размеров карточек: авто, пиксели, проценты; один параметр точный + другой авто сохраняет пропорции
- Попапы двух видов: обычный с кнопкой и без кнопки (текст внизу экрана)
- Блок «Подстановка» для повторяющихся элементов (меню, контакты) из другого мини-приложения
- Форма ввода типа «Список»: выбор одного или нескольких вариантов, загрузка из 4 источников
- Подстановка контента мини-приложения в вариантах формы ввода (для уточняющих вопросов)
- Расчёты прямо в тексте: `{{= выражение =}}`
**Шаги реализации:**
1. Блок карточек: выбрать форму (круглая/прямоугольная), настроить размеры, включить помечание новых
2. Попапы: добавить действие «Показать попап», выбрать вид (с кнопкой / без)
3. Подстановка: добавить блок, ввести название мини-приложения для подстановки
4. Форма ввода «Список»: выбрать тип «Список», заполнить варианты (вручную / файл / Google Sheets / NoCode), настроить поле значения
5. Подстановка в вариантах: форма ввода «Выбор варианта» > дополнительные настройки варианта > подстановка
6. Блок HTML: добавить блок, заполнить код; в дополнительных настройках -- код в TagHead
7. Кастомизация: заголовок «Стиль» > «Кастомизировать» > задать цвета, шрифты, размеры, выбрать базовую ОС
8. Формулы в тексте: `{{= расчёт =}}` -- расчёты без создания новых переменных
9. В настройках бота > мини-приложения: добавить общий HTML-код для всех приложений (статистика)
10. Опубликовать и проверить
**Полезные детали:** В блоке «Список» поле «Значение» записывает данные в переменную -- можно подставить число для математических операций или оставить пустым (запишется название варианта). Кастомизация позволяет выбрать, дизайн какой ОС будет базовым. HTML в TagHead обычно используется для сервисов по сбору статистики. Подстановка в формах ввода подходит для уточняющих вопросов при выборе варианта.
