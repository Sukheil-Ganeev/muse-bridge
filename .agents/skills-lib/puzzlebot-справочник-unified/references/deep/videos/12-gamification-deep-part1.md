## Video 59: 59_Nastraivaem_Balans_Chat_Bote
**Тема:** Создание и настройка внутреннего баланса (баллов) в боте с начислением за подписку и анкету
**PuzzleBot-элементы:** Персональная переменная (число, баланс), категории (баллы за подписку, баллы за анкету), условия (проверка наличия подписки, проверка наличия категории), действие "Изменить переменную" (прибавить), действие "Изменить категории", инлайн-команды, кнопка "Условия" (скрытие кнопки), мини-приложение с формой ввода, инлайн-клавиатура (кнопка условия), стартовая команда
**Категория:** Баллы и геймификация
**Ключевые техники:**
- Создание числовой персональной переменной для хранения баланса
- Использование категорий как флагов: "получил баллы за подписку", "получил баллы за анкету"
- Кнопка типа "Условия" для скрытия уже использованных заданий (если категория есть -- скрыть кнопку)
- Начисление баллов через "Изменить переменную" > "Прибавить" > число
- Анкета в мини-приложении с формой ввода и переходом к команде результата
- Личный кабинет с динамическими кнопками (кнопка условия) которые скрываются после выполнения

1. Создать персональную переменную "Баланс" (формат: число) во вкладке "Переменные"
2. Создать категории "Баллы за подписку" и "Баллы за анкету" во вкладке "Модерация"
3. Создать условие проверки подписки: наличие подписки > прибавить баллы + присвоить категорию + показать результат
4. Создать инлайн-команду для запуска проверки подписки
5. Создать кнопку "Условия" для подписки: проверка категории > если есть -- скрыть кнопку, если нет -- показать инлайн-команду
6. Создать мини-приложение с анкетой (форма ввода) + команду результата (прибавить баллы + категория)
7. Создать кнопку "Условия" для анкеты: аналогично скрытие после выполнения
8. Создать личный кабинет с текстом (баланс через переменную) + кнопки условий
9. В стартовой команде переход к личному кабинету
10. Добавить кнопки возврата в личный кабинет во всех инлайн-командах
**Полезные детали:** Кнопка типа "Условия" -- мощный инструмент для динамического UI: можно скрывать задания, которые пользователь уже выполнил. Категории используются как флаги одноразовых действий. Для повторной проверки подписки в команде "Без подписки" добавляется кнопка, ведущая обратно на условие.

## Video 66: 66_Nachisljaem_Bally_Aktivnost_Gruppe
**Тема:** Автоматическое начисление баллов за активность участников в группе и вывод топа самых активных пользователей с использованием таблиц NoCode.
**PuzzleBot-элементы:** Переменные (персональная -- баланс, глобальная -- учёт баллов, интегрированная -- топ из NoCode), таблица NoCode, текстовый блок, inline-клавиатура, условие (проверка строки), действие «Обновить строку», действие «Создание строки», триггеры (изменение переменной, отправка текстового сообщения, отправка условия)
**Категория:** Баллы и геймификация
**Ключевые техники:**
- Использование интегрированной переменной для формирования топа участников из NoCode с сортировкой по убыванию
- Триггеры на ответы в группе для автоматического начисления баллов
- Условие с проверкой строки в таблице NoCode для обновления или создания записи
- Шаблон для вывода топа с именем, фамилией и суммой баллов
- Настройка удаления уведомления через 5 секунд
**Шаги реализации:**
1. Создать таблицу в NoCode с полями: имя пользователя, баллы (число)
2. Создать персональную переменную (баланс, число, по умолчанию 0)
3. Создать глобальную переменную (учёт баллов в группе, число, 0)
4. Создать интегрированную переменную (топ): тип глобальный, интеграция NoCode, выбрать базу/таблицу, сортировка по убыванию, лимит 3, шаблон с именем и баллами, разделитель -- перенос строки
5. Стартовая команда: текстовый блок с балансом + inline-кнопка «Топ»
6. Команда «Топ»: текстовый блок с переменной топа
7. Условие: проверка строки в NoCode по User ID (полное совпадение) > обновить строку / создать строку
8. Триггер 1: тип «Ответы», условие «Сообщение содержит» (фразы благодарности) > изменить персональную переменную (прибавить баллы) + изменить глобальную переменную + отправить уведомление (удаление через 5 сек) + отправить условие в Bot
9. Триггер 2: ключевое слово для вывода топа > текстовое сообщение с топом
10. Опубликовать и протестировать
**Полезные детали:** Галочка «Выполнить для пользователя, получившего ответ» критична -- без неё баллы начисляются не тому пользователю. В триггерах можно ограничить время до повторного срабатывания и количество срабатываний на пользователя. Разделитель для интегрированной переменной с переносом строки делает вывод топа читабельным.

## Video 67: 67_Nachisljaem_Bally_Polzovatelju_Vruchnuju
**Тема:** Создание кнопки для ручного начисления баллов администратором, видимой только пользователям с категорией модерации.
**PuzzleBot-элементы:** Глобальная переменная (ручное начисление), категория модерации, inline-команда, действие «Изменить переменную», форма ввода (выбор варианта, отправка сообщения), условие (проверка категории), действие «Отправить команду другому пользователю», блок тайм-аут, поп-ап
**Категория:** Баллы и геймификация
**Ключевые техники:**
- Условие с проверкой категории модерации для скрытия кнопки от обычных пользователей
- Отправка команды другому пользователю по юзернейму через действие «Выполнить другому пользователю»
- Форма ввода с вариантами фиксированных сумм начисления + вариант отмены
- Поп-ап для уведомления администратора об отмене
- Тайм-аут с индикатором печати текста перед выполнением команды
**Шаги реализации:**
1. Создать глобальную переменную для ручного начисления (число, 0)
2. Во вкладке «Модерация» создать категорию доступа к начислению и назначить администратору
3. Создать inline-команду начисления: действие «Изменить переменную» (баланс + глобальная переменная) > текстовый блок с уведомлением > кнопка «Личный кабинет»
4. Создать команду с клавиатурой: форма ввода (выбор суммы начисления из вариантов) + вариант «Отмена» с поп-апом
5. Вторая форма ввода: ввод юзернейма пользователя (тип «Отправка сообщения»)
6. Текстовый блок подтверждения (сумма + юзер) > inline-кнопки «Подтвердить» / «Отмена»
7. Команда подтверждения: тайм-аут 3 сек > действие «Отправить команду начисления другому пользователю» (по юзернейму из переменной)
8. Условие-кнопка: проверка категории модерации > показать кнопку / скрыть
9. Добавить кнопку-условие в личный кабинет
10. Опубликовать и проверить (окно админа + окно пользователя)
**Полезные детали:** Кнопка начисления скрыта от обычных пользователей через условие с проверкой категории. Пользователь получает уведомление о начислении баллов автоматически. Тайм-аут с индикатором печати создаёт визуальный эффект обработки. Функция отмены позволяет администратору прервать процесс на любом этапе.

## Video 82: Oformljaem_Liderbord_Telegram_Chat
**Тема:** Оформление лидерборда с медалями и автоматическая еженедельная отправка топа участников в группу
**PuzzleBot-элементы:** Глобальные переменные, функция MatchAll (регулярные выражения), действие «Изменить переменную», постинг с повторением, действие «Отправить команду или условие», выбор темы в топике
**Категория:** Баллы и геймификация
**Ключевые техники:**
- Использование функции MatchAll с регулярным выражением для разбора строк топа на отдельные переменные (ТОП1, ТОП2, ТОП3)
- Регулярное выражение: `/(.*?)(?:\n|$)/` — разбирает текст по строкам
- Настройка еженедельной автоматической отправки лидерборда через постинг с повторением
- Нумерация групп совпадений начинается с нуля (0 = первая строка)
**Шаги реализации:**
1. Создать глобальные переменные ТОП1, ТОП2, ТОП3 (текстовый формат) — по количеству мест в топе
2. Создать команду для записи значений переменных; добавить действие «Изменить переменную» для каждой переменной
3. В формуле использовать MatchAll: передать переменную с общим топом и регулярное выражение для построчного разбора
4. Для ТОП1 указать группу 0, для ТОП2 — группу 1, для ТОП3 — группу 2 (нумерация с нуля)
5. В дополнительных настройках действия установить последовательность выполнения «До»
6. Добавить изображение (по желанию) и текстовый блок с переменными ТОП1, ТОП2, ТОП3 для красивого отображения
7. Перейти в «Постинг», создать пост с датой/временем, в допнастройках добавить повторение и выбрать день недели
8. В действиях поста выбрать «Отправить команду или условие» и указать команду с ТОПом
9. Выбрать место отправки (группу/тему в топике) и запланировать пост
**Полезные детали:** Регулярное выражение подробно: `.` — любой символ, `*?` — минимальное количество (ленивый поиск), `(?:\n|$)` — не сохраняемая группа (перенос строки ИЛИ конец текста). Знак `$` обозначает конец текста, чтобы последняя строка тоже корректно считалась. Нумерация групп MatchAll начинается с 0, а не с 1. Можно отправлять в конкретную тему (топик) группы.
