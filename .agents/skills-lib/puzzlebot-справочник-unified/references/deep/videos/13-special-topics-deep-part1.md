## Video 16: 16_Chat_Bot_Obratnoj_Svjazi
**Тема:** Настройка бота обратной связи с функцией активного диалога между пользователем и владельцем бота.
**PuzzleBot-элементы:** Команды, Текстовый блок, Инлайн-клавиатура, Действие кнопки "Начало диалога", Вкладка "Диалоги", Команда /CP (управление диалогами).
**Категория:** Другое
**Ключевые техники:**
- Кнопка с действием "Начало диалога" активирует режим обратной связи
- Пользователь нажимает кнопку, пишет сообщение -- владелец бота получает уведомление
- Для ответа конкретному пользователю нужно отвечать на его сообщение (reply)
- Управление активными диалогами: команда /CP или вкладка "Диалоги"
- Завершение диалога доступно через интерфейс
**Шаги реализации:**
1. Создать команду (например, "Диалог")
2. Добавить текстовый блок с текстом (например, "Напишите нам")
3. Добавить инлайн-клавиатуру с кнопкой
4. Выбрать действие кнопки "Начало диалога"
5. Сохранить и опубликовать изменения
6. Пользователь в боте вызывает команду, нажимает кнопку "Начать диалог" и пишет сообщение
7. Владелец бота получает уведомление и отвечает через reply на сообщение пользователя
8. Для управления диалогами: команда /CP или вкладка "Диалоги" в панели
9. Завершить диалог при необходимости
**Полезные детали:**
- Обязательно отвечать на сообщение пользователя через reply (ответить на конкретное сообщение), иначе ответ не дойдет
- Команда /CP позволяет перейти к списку активных диалогов прямо в Telegram
- Вкладка "Диалоги" в панели PuzzleBot также показывает все активные диалоги
- Простейший способ организовать обратную связь без сложной логики

## Video 27: 27_Vkladka_Moderacija
**Тема:** Обзор вкладки "Модерация": управление пользователями, категориями, просмотр информации и событий
**PuzzleBot-элементы:** Вкладка Модерация, категории пользователей, таблица пользователей, фильтры (в боте, вышедшие, забаненные), настройка столбцов, поиск пользователей, информационное окно пользователя (общие, сценарии, категории, события, переменные, комментарий), массовые действия (блокировка, разблокировка, присвоение категории), экспорт в Excel, права и разрешения в ресурсах
**Категория:** Модерация
**Ключевые техники:**
- Категории: объединение пользователей для применения действий (права в группе, доступ к командам, рассылки)
- Категория "Без категории" не удаляется и не переименовывается
- Фильтрация: в боте, вышедшие (остановившие бота), забаненные; по умолчанию вышедшие и забаненные скрыты
- Информационное окно пользователя: 6 вкладок (общие, сценарии, категории, события, переменные, комментарий)
- Массовые действия: режим выделения для блокировки/разблокировки/присвоения категории нескольким пользователям
- Ранжирование по столбцам, буквы "С" (создатель) и "А" (администратор) рядом с именами
- Блокировка: в конкретном боте, ресурсе или во всех местах
- Изменение прав и разрешений для пользователей и категорий в ресурсах
- Экспорт списка пользователей категории в Excel
**Шаги реализации:**
1. Перейти на вкладку "Модерация"
2. Просмотреть список пользователей, применить фильтры при необходимости
3. Создать категории через кнопку "+"
4. Изменить категорию пользователя: нажать на категорию в таблице
5. Для просмотра информации: нажать на имя пользователя
6. Для массовых действий: троеточие -> режим выделения -> выбрать пользователей -> действие
7. Для экспорта: настройки категории -> скачать Excel
8. Для управления правами в ресурсах: перейти к ресурсу -> настроить права для пользователей/категорий
**Полезные детали:** Вышедшие пользователи -- те, кто остановил бота в Telegram (не удалил, а именно остановил). Пользователь может находиться в любом количестве категорий одновременно. Категории можно менять и автоматически через действия в других вкладках. Вкладка "События" позволяет отслеживать все действия с пользователем с фильтрацией по ресурсам и событиям. Комментарии о пользователях видны только администраторам бота.

## Video 45: 45_Delaem_Chat_Bota_Sluchajnyh
**Тема:** Создание бота для знакомств (Random Coffee): анкетирование, запись в Google Таблицы, случайная выдача анкет
**PuzzleBot-элементы:** Интеграция Google Sheets, форма ввода (текст, изображение), глобальная переменная (Number), персональная переменная (Random Number), условие (проверка длины текста), действие "Создать строку" (Google Sheets), блок "Слайдер" (тип Google Sheets), фильтрация по столбцу, вставка ID файла (изображение), инлайн-клавиатура, выражения и формулы
**Категория:** Интеграции
**Ключевые техники:**
- Анкета через формы ввода: текстовые данные + загрузка фото (маска ввода "Изображение")
- Ограничение длины текста до 1024 символов (лимит описания картинки в Telegram)
- Условие проверки длины переменной с перенаправлением на повторный ввод
- Глобальная переменная Number как счетчик/уникальный ID участника (прибавление +1)
- Персональная переменная Random Number с формулой случайного числа от 1 до Number
- Действие "Создать строку" для записи анкеты в Google Таблицы
- Блок "Слайдер" типа Google Sheets с фильтрацией по столбцу (номер = Random Number)
- Дублирование First Name / Last Name: текст для служебной информации + кликабельные ссылки для выдачи
- Последовательность выполнения "ДО" -- число рассчитывается до запроса данных из таблицы
- Блок изображения с ссылкой вместо ID файла (формат G) + описание с переменными
**Шаги реализации:**
1. Подключить интеграцию Google Sheets
2. Создать Google таблицу с заголовками: номер, данные пользователя, фото, описание, кликабельные имя/фамилия
3. Создать глобальную переменную Number (число) и персональную Random Number (число)
4. В конструкторе создать команду "Анкета" с формами ввода (текст + фото с маской "Изображение")
5. Создать условие "Проверка длины": если длина переменной About > 1024 -> "Лимит превышен", иначе -> "Лимит не превышен"
6. В команде "Лимит превышен" -- текст предупреждения + кнопка возврата к анкете
7. В команде "Лимит не превышен" -- действие "Изменить переменную" Number (+1), действие "Создать строку" в Google Sheets
8. Создать команду "Random" -- действие "Изменить переменную" Random Number (случайное число), последовательность "ДО"
9. Добавить блок "Слайдер" (Google Sheets) с фильтрацией по столбцу номера = Random Number
10. Добавить блок изображения с ссылкой и описанием из переменных таблицы
11. Связать команды кнопками, опубликовать и протестировать
**Полезные детали:** При удалении строки из таблицы порядок выдачи нарушается (номера не пересчитываются). Лимит 1024 символа -- ограничение Telegram для описания (caption) к изображению. Два варианта выдачи: фото + описание в одном блоке (до 1024 символов) или два отдельных блока (фото + текст, без ограничения). В таблице дублируются столбцы First Name / Last Name: одна пара для служебного использования (текст), другая -- для кликабельных ссылок.
