## Video 49: 49_Nastroit_Lid_Magnit_Telegram
**Тема:** Создание лид-магнита в Telegram-боте с выдачей подарка за подписку на канал (второй урок курса для разработчиков)
**PuzzleBot-элементы:** Обычная команда, текстовый блок, инлайн-клавиатура (ссылка браузер по умолчанию), блок изображения (вставить ID файла), тайм-аут (индикатор печати), действие "Отправить команду или условия", условия (проверка наличия подписки), исключающее правило, стартовая команда, события ресурса ("Пользователь подписался на канал"), партнерская ссылка
**Категория:** Группы и каналы
**Ключевые техники:**
- Загрузка изображения через команду `sp` в боте для получения File ID
- Проверка подписки на канал через блок условий с галочкой напротив нужного ресурса
- Использование тайм-аута с индикатором печати ("загружать фото") для оживления бота
- Настройка события "Пользователь подписался на канал" в ресурсе для автоматической реакции
- Вставка партнерской ссылки PuzzleBot через выделение слова и прикрепление ссылки
**Шаги реализации:**
1. Добавить канал как ресурс в личном кабинете PuzzleBot (кнопка "Добавить ресурс")
2. Создать команду приветствия с текстом-призывом и инлайн-кнопкой со ссылкой на канал
3. Загрузить изображение через бота (команда `sp`), скопировать File ID и создать команду с блоком изображения
4. Создать команду с текстом + тайм-аут 2 секунды + действие перехода к следующей команде
5. Создать условие с проверкой наличия подписки на канал
6. В условии настроить: при подписке -- отправить команду "выдать подарок", в исключающем правиле -- отправить команду "не подписан"
7. В стартовой команде добавить действие перехода к условию
8. В настройках ресурса (канала) активировать событие "Пользователь подписался на канал" с переходом к команде проверки
**Полезные детали:** Событие подписки на канал сработает только если пользователь уже запускал бота ранее. Для новых пользователей бот может написать первым только при обработке заявки на вступление. Для удаления стандартных команд: зажать Shift + выделить мышью + кнопка "Удалить". Эмодзи вставляются через правый клик мыши > "Эмодзи".

## Video 58: 58_Nastraivaem_Adminku_Dobavlenie_Kastomnye
**Тема:** Настройка доступа администратора, кастомные уведомления о диалогах, повторные уведомления через сценарии
**PuzzleBot-элементы:** Доступ администраторов (Настройки), уведомления, диалоги, кастомные уведомления с переменными, инлайн-клавиатура (ссылка на диалог, ссылка на ЛС), действие "Отправить команду или условия" с изменением места отправки (топик группы), события (начало/завершение диалога), категории (активный диалог), условия (проверка категории), сценарии (повторное уведомление), действие "Изменить категории", действие "Изменить сценарий", заготовленные ответы (команды)
**Категория:** Модерация
**Ключевые техники:**
- Выдача ограниченного доступа администратору (например, только вкладка "Диалоги")
- Создание кастомного уведомления с переменными пользователя и кнопками перехода в диалог
- Ссылка на диалог и на личные сообщения пользователя в инлайн-кнопках
- Повторные уведомления через сценарий с перезапуском + категория "Активный диалог"
- Автоматическое снятие категории и деактивация сценария при завершении диалога
- Создание заготовленных ответов через команды (вызов через "+" в диалогах)
**Шаги реализации:**
1. Настройки > "Доступ администраторов" > "Добавить" > настроить доступ к ресурсам и функциям
2. Создать команду с кастомным уведомлением: текстовый блок с переменными + инлайн-кнопки (ссылка на диалог, ссылка на ЛС)
3. Создать команду-обёртку с действием отправки уведомления в топик группы (изменить место отправки)
4. Во вкладке "События" настроить "Начало диалога": добавить действие команды с уведомлением
5. Создать категорию "Активный диалог" во вкладке "Модерация"
6. Создать условие проверки наличия категории "Активный диалог" с отправкой повторного уведомления
7. Создать сценарий: перезапуск при повторном вызове + пост через N минут + действие отправки условия
8. В событии "Начало диалога" добавить: присвоение категории + активация сценария
9. В событии "Завершение диалога" добавить: деактивация категории
10. Создать команды с заготовленными ответами для быстрой работы поддержки
**Полезные детали:** Заготовленные ответы вызываются через кнопку "+" в интерфейсе диалогов и название команды. Повторные уведомления реализуются через связку: категория + сценарий + условие. При завершении диалога категория деактивируется, что останавливает повторные уведомления.

## Video 64: 64_Nastraivaem_Chat_Bota_Obratnoj
**Тема:** Настройка чат-бота обратной связи для общения с пользователями через диалоги
**PuzzleBot-элементы:** Действие "Начать диалог" (в стартовой команде или в инлайн-кнопке), вкладка "Уведомления" (Настройки), вкладка "Диалоги" (Настройки: автозавершение, скрытие кнопки, игнорирование команд), вкладка "Диалоги" (просмотр переписки), вкладка "События" (начало/завершение диалога -- изменение текста уведомлений), инлайн-клавиатура (действие "Начало диалога"), текстовый блок
**Категория:** Модерация
**Ключевые техники:**
- Два способа начала диалога: автоматически при старте бота (действие в команде) или по нажатию кнопки
- Настройка уведомлений для администратора о новых диалогах
- Скрытие кнопки "Завершить диалог" от пользователя
- Настройка автоматического завершения диалогов через время
- Игнорирование вызова команд во время активного диалога
- Изменение стандартных текстов уведомлений через вкладку "События"
- Ведение переписки как через Telegram, так и через личный кабинет (вкладка "Диалоги")
**Шаги реализации:**
1. В конструкторе открыть стартовую команду
2. Вариант А (автоматический старт диалога): добавить действие "Начать диалог" + текстовый блок приветствия
3. Вариант Б (кнопка): добавить текстовый блок + инлайн-клавиатуру с действием "Начало диалога"
4. Проверить настройки уведомлений: Настройки > Уведомления > галочки на нужных пунктах
5. Настроить диалоги: Настройки > Диалоги > при необходимости скрыть кнопку завершения, настроить автозавершение, игнорирование команд
6. Опубликовать изменения
7. При необходимости изменить тексты уведомлений: вкладка "События" > "Начало/Завершение диалога" > "Настроить" > изменить текст
**Полезные детали:** По умолчанию пользователь получает стандартные уведомления о начале и завершении диалога -- их можно кастомизировать через "События". Переписку можно вести как через Telegram-уведомления, так и через веб-интерфейс вкладки "Диалоги". Скрытие кнопки "Завершить диалог" полезно, если хотите контролировать завершение только со стороны администратора.

## Video 75: 75_Obzor_Obnovlenija_PuzzleBot_Blok
**Тема:** Обзор крупного обновления PuzzleBot: блок-баннер, блок-разделитель, новые типы форм ввода (тестирование, опрос) в мини-приложениях, расширенные карточки (бейдж, прозрачность, показ определённой), обновления подстановок, спойлер в тексте, полупрозрачная клавиатура, действия в блоке видео, новые платёжные системы.
**PuzzleBot-элементы:** Блок-баннер (макеты, бейдж с переменной, тёмная/светлая тема, кликабельность, кнопка скрытия, выделение), блок-разделитель, форма ввода «Тестирование» и «Опрос» в мини-приложениях, карточки (бейдж, прозрачность, показ определённой карточки), подстановка (обёртка, условия), спойлер в тексте, полупрозрачная клавиатура, блок видео (действия: при запуске, после просмотра 95%, активация фиксированной кнопки), платежные системы (Prodamus, Robocassa, Ucasa, Stripe, Альфа-банк, Каспи -- рекуррентные и обычные)
**Категория:** Другое
**Ключевые техники:**
- Блок-баннер: бейдж с переменной (скрывается если значение пустое), адаптация под тёмную/светлую тему
- Карточки: бейдж динамический (из переменной), прозрачность для недоступных элементов, показ конкретной карточки по номеру или переменной
- Блок видео: действие при запуске + действие после 95% просмотра; активация фиксированной кнопки после просмотра
- Подстановка теперь поддерживает обёртку (отдельный визуальный блок) и условия во всех местах использования
- Новые платёжные системы: Prodamus, Robocassa, Ucasa для рекуррентных; Ucasa, Stripe, Альфа-банк, Каспи для обычных
**Шаги реализации:**
1. Блок-баннер: добавить, выбрать макет, загрузить изображение, заполнить заголовок/текст/бейдж (переменная), настроить кликабельность (весь баннер / только кнопка)
2. Блок-разделитель: добавить между смысловыми блоками для структурирования
3. Форма ввода «Тестирование»: добавить варианты, отметить правильные -- для квизов в мини-приложениях
4. Форма ввода «Опрос»: варианты без правильных ответов -- для сбора обратной связи
5. Карточки: добавить бейдж (текст / переменная), настроить прозрачность, указать показ определённой карточки
6. Подстановка: включить обёртку, использовать условия в действиях кнопок и формах
7. Текст: использовать стилизацию «Спойлер»; клавиатура: выбрать полупрозрачный стиль
8. Блок видео: настроить действие при запуске (изменить переменную) + действие после просмотра (активировать кнопку)
9. Настройки > Платёжные системы: подключить новые (Prodamus, Stripe, Каспи и др.)
10. Опубликовать и проверить
**Полезные детали:** Бейдж на баннере/карточке автоматически скрывается, если переменная пуста -- удобно для динамических статусов. Блок видео с порогом 95% позволяет строить учебные мини-приложения (разблокировка кнопки после просмотра). Баннер с опцией «Выделить» убирает отступы на iOS и добавляет на Android, визуально акцентируя блок. Часть платёжных систем ранее работала только через Telegram-интеграции, теперь подключается напрямую.
