# 09. Группы и каналы -- Глубокий справочник

## Video 108: Uchim_Chat_Bota_Reagirovat
**Тема:** Настройка реакции бота на бусты (голоса) в каналах, группах и форумах Telegram
**PuzzleBot-элементы:** Подключение ресурса, вкладка «События» (буст/забрал голос), текстовое сообщение, конструктор, условие с типом проверки «Голос для ресурсов», количество бустов, действие «Отправить команду или условие», исключающее правило, инлайн-клавиатура
**Категория:** Группы и каналы
**Ключевые техники:**
- Настройка реакций на события: пользователь дал буст / забрал голос / истек срок
- Создание условия для проверки наличия бустов у пользователя
- Разделение контента на «для бустеров» и «для остальных»
- Отправка ссылки на буст для мотивации пользователей
**Шаги реализации:**
1. Подключить бота к ресурсу (канал/группа/форум)
2. Перейти к ресурсу -> «События» -> настроить реакцию на буст (текстовое сообщение, включить реакцию)
3. Настроить реакцию на забранный голос / истечение срока (текстовое сообщение, включить)
4. В конструкторе: создать две команды — для бустеров и для остальных
5. Создать условие: тип проверки «Голос для ресурсов», выбрать ресурс, указать количество бустов
6. Основное действие: переход к команде для бустеров; исключающее правило: переход к команде для не-бустеров
7. В команде для бустеров — благодарность; в команде для остальных — уведомление + ссылка на буст
8. В стартовой команде: кнопка с переходом к условию
9. Опубликовать и проверить
**Полезные детали:** Бусты — это голоса, которые подписчики выдают ресурсам в Telegram. Условие проверяет конкретный ресурс и может требовать определенное количество бустов. Реакция на забранный голос позволяет оповестить администратора или выполнить действие (например, ограничить доступ). Ссылка на буст мотивирует пользователей поддержать ресурс.

## Video 109: Uchim_Chat_Bota_Stavit
**Тема:** Настройка постановки реакций (эмодзи) ботом на сообщения пользователей
**PuzzleBot-элементы:** Триггеры (в ресурсе), тип сообщения «Текст», тип условия «Сообщение содержит», фразы (ключевые слова), тип действия «Поставить реакцию», конструктор, форма ввода, блок «Реакция» (на ответ формы ввода), действие «Поставить реакцию» (в команде)
**Категория:** Группы и каналы
**Ключевые техники:**
- Автоматическая реакция на ключевые слова в ресурсе через триггер
- Постановка реакции на стартовую команду через действие в конструкторе
- Постановка реакции на ответ формы ввода через блок «Реакция»
- Три способа постановки реакций: триггер в ресурсе, действие в команде, блок реакции на форму ввода
**Шаги реализации:**
1. Подключить бота к ресурсу
2. Перейти к ресурсу -> «Триггеры» -> «Добавить триггер»
3. Настроить: тип сообщения «Текст», тип условия «Сообщение содержит», добавить ключевые слова
4. Тип действия: «Поставить реакцию», выбрать подходящую реакцию, сохранить
5. В конструкторе: создать команду с формой ввода
6. В форме ввода: добавить «Реакцию на ответ» -> выбрать блок «Реакция» -> выбрать эмодзи
7. В стартовой команде: добавить действие «Поставить реакцию» + «Отправить команду» -> созданная команда
8. Опубликовать и проверить: реакция в ресурсе по ключевому слову, реакция на старт, реакция на ответ формы
**Полезные детали:** Реакции — это эмодзи, которые бот ставит на сообщения пользователей. Три разных контекста использования: (1) триггер в чате/канале на ключевые слова, (2) действие в любой команде конструктора, (3) реакция на ответ формы ввода. Тип условия «Сообщение содержит» реагирует на наличие указанных фраз в любом месте сообщения.
