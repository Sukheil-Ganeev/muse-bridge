## Video 10: 10_Bot_Priem_Zajavok
**Тема:** Создание простого бота для приема заявок с формами ввода, несколькими видами клавиатур и уведомлениями.
**PuzzleBot-элементы:** Команда Start, Текстовый блок, Блок изображения, Обычная клавиатура, Инлайн-клавиатура, Формы ввода (с названием для статистики, переменными, реакцией на ответ, возможностью пропуска), Ссылка в кнопке, Переменные (подстановка имени пользователя), Статистика форм ввода.
**Категория:** Основы
**Ключевые техники:**
- Подстановка имени пользователя через системную переменную в приветственном сообщении
- Комбинирование обычной клавиатуры (навигация) и инлайн-клавиатуры (действия внутри сообщения)
- Кнопка с действием "Ссылка" для перехода на личный аккаунт (задать вопрос)
- Форма ввода с названием для статистики (не видно пользователю)
- Возможность пропустить ответ на форму ввода (в дополнительных настройках)
- Просмотр ответов: вкладка "Статистика" > раздел "Формы ввода"
- Работа с мобильных устройств: сервис полностью адаптирован
**Шаги реализации:**
1. Создать бота и привязать к PuzzleBot
2. Удалить шаблонные команды (Shift + выделить, удалить)
3. В команде Start: добавить блок изображения, текстовый блок с приветствием и переменной имени
4. Создать обычную клавиатуру с кнопками: Стоимость услуг, Заказ, Задать вопрос, и т.д.
5. Расставить кнопки перетягиванием
6. Заполнить команду "Стоимость услуг": текстовый блок + инлайн-кнопка с переходом к заказу
7. Заполнить "Задать вопрос": кнопка с действием "Ссылка" на личный аккаунт
8. В команде "Заказ": создать несколько форм ввода (вопросы для заявки)
9. Для каждой формы: название для статистики, переменная, реакция на ответ
10. В дополнительных настройках добавить возможность пропуска ответа
11. Опубликовать, проверить в боте
12. Уведомления приходят в Telegram, на почту и в личный кабинет
**Полезные детали:**
- Все переменные для подстановки доступны в базе знаний PuzzleBot
- Уведомления об ответах приходят сразу в Telegram, на email и в ЛК
- Для просмотра всех ответов: Статистика > Формы ввода > выбрать команду с формами
- Сервис адаптирован под мобильные -- можно делать ботов с телефона

## Video 23: 23_Konstruktor_Chast_2
**Тема:** Дополнительные настройки команд в Конструкторе: синонимы, группы команд, категории, действия
**PuzzleBot-элементы:** Синонимы команд (полное совпадение, частичное, начинается с, заканчивается, регулярное выражение), чувствительность к регистру, шанс срабатывания, условие на количество символов, выполнение только из клавиатуры, выполнение из текущей группы, отправить случайный блок, удалить команду после вызова следующей, защита контента, отображение в меню, действия (изменить категорию, действие в ресурсах, изменить сценарий, очистить корзину, диалог, изменить переменную, отправить триггеры, очистить статистику, работа со Spreadsheets, Bitrix24, удалить через время, удалить клавиатуру, уведомления, удалить сообщения, закрепить блок, отправить запрос), группы команд с ограничением доступа по категориям, вкладка Модерация для создания категорий, вкладка События
**Категория:** Основы
**Ключевые техники:**
- Синонимы: альтернативные фразы для вызова команды с 5 типами совпадения + шанс срабатывания + регистр
- Группы команд: создание отдельных групп с доступом только для определённых категорий пользователей
- Действие "Изменить категорию": замена категории пользователя при вызове команды
- Перемещение команд между группами через кнопку перемещения
- Защита контента от пересылки и сохранения
- Проверка подписки на ресурс как условие доступа к группе команд
- Событие "Нет доступа" -- сообщение при попытке вызвать недоступную команду (редактируется во вкладке "События")
**Шаги реализации:**
1. Открыть команду, раскрыть дополнительные настройки
2. Добавить синонимы: выбрать тип совпадения, ввести фразы
3. Настроить дополнительные параметры: только из клавиатуры, только из текущей группы, случайный блок, защита контента, отображение в меню
4. Добавить действия (категории, переменные, ресурсы и т.д.)
5. Создать категорию во вкладке "Модерация"
6. Создать новую группу команд через навигацию
7. В настройках группы задать доступ для категорий
8. Переместить нужные команды в группу
9. Опубликовать изменения в каждой группе
**Полезные детали:** Обширный список действий включает интеграции с Bitrix24 и Spreadsheets. Обычная клавиатура остаётся, пока не заменена другой командой. Категория "Без категории" -- стандартная, не удаляется. Можно задать проверку подписки на ресурс как условие доступа к группе. Действие "Удалить через время" позволяет автоочистку сообщений.

## Video 24: 24_Konstruktor_Chast_1
**Тема:** Базовый обзор вкладки "Конструктор": интерфейс, блоки, клавиатуры, создание первых команд
**PuzzleBot-элементы:** Вкладка Конструктор, обычные команды, миниатюры команд, блоки (текст, изображение, видео, аудио, документ, геолокация, контакт, медиагруппа), специальные блоки (форма ввода, таймаут, товар, список, результат, слайдер), обычная клавиатура, инлайн-клавиатура, действия кнопок (переход к команде/условию, ссылка, начало диалога, платёж, поп-ап, изменение сценария, подставить текст, поделиться текстом, веб-приложение-ссылка, веб-приложение-магазин), форматирование текста, спойлер
**Категория:** Основы
**Ключевые техники:**
- Интерфейс Конструктора: миниатюры команд с перетаскиванием, навигация по группам, режим выделения
- Блоки контента: текст, изображение, видео, аудио, документ, геолокация, контакт, медиагруппа
- Специальные блоки бота: форма ввода, таймаут, товар, список (промокоды), результат (тестирование), слайдер
- Блок "Список": подстановка одного элемента из списка (например, промокодов) при каждом вызове
- Блок "Результат": подсчёт правильных ответов формы ввода с типом тестирования
- Обычная клавиатура: одна на команду, сохраняется до замены, скрывается -- но не удаляется
- Инлайн-клавиатура: прикрепляется к блоку, остаётся в переписке, только в ней можно сделать кнопку-ссылку
- Форматирование текста: выделение и форматирование, лимит символов
- Тестовый шаблон удаляется через Shift + выделение всех команд + удаление
**Шаги реализации:**
1. Перейти во вкладку "Конструктор"
2. Удалить тестовый шаблон (Shift -> выделить все -> удалить -> опубликовать)
3. Создать обычную команду, задать название
4. Добавить блоки (например, изображение): загрузить файл, написать описание
5. Создать инлайн-клавиатуру: задать действие (переход, ссылка и др.) и название кнопки
6. Расположить кнопки по рядам перетаскиванием
7. В команде "Старт" добавить текстовый блок с обычной клавиатурой
8. Сохранить и опубликовать изменения
**Полезные детали:** Для ID изображения можно вставить ID вместо загрузки файла. Текст поддерживает форматирование при выделении. Контент можно скрыть под спойлер. Блоки можно копировать/вставлять/дублировать/удалять через меню. Очерёдность блоков меняется стрелками. Лимит символов отображается под текстом. Тестовый шаблон автоматически добавляется при привязке бота.

## Video 26: 26_Vkladka_Vhod
**Тема:** Обзор вкладки "Вход": многоразовые ссылки, промо-ссылки и реферальная система
**PuzzleBot-элементы:** Вкладка Вход, многоразовые ссылки (сайт-визитка, официальная телеграм-ссылка, ссылка на сайт, для стран с блокировкой, прямое открытие приложения), промо-ссылки (генерация пакета), реферальная система (переменная реферальной ссылки), категории бота и ресурса, команда при успехе/неудаче, ограничение переходов, срок действия, шаблон сообщения для входа в ресурс, статистика переходов
**Категория:** Основы
**Ключевые техники:**
- Три вида ссылок: многоразовые (постоянные), промо (одноразовые, ограниченные), реферальные (индивидуальные)
- Многоразовые ссылки: 5 разновидностей URL, добавление в категорию, команда при переходе, ограничение переходов и срок действия
- Промо-ссылки: генерация пакета уникальных ссылок, скачивание в текстовом формате или отправка в Telegram
- Реферальная система: переменная для генерации уникальной ссылки каждому пользователю
- Категории: можно одновременно добавить в категорию бота И в категорию ресурса (даже если пользователь не подписчик)
- Автоматическая отправка ссылок на вход в ресурсы при наличии категорий ресурсов
- Дополнительные ограничения реферальной системы: количество генераций на пользователя, запрет генерации без использования предыдущей
**Шаги реализации:**
1. Перейти на вкладку "Вход"
2. Для многоразовой ссылки: нажать "Добавить ссылку" -> выбрать тип -> задать название, категории, команду, ограничения -> запустить
3. Для промо-ссылок: нажать "Добавить ссылку" -> "Промо-ссылки" -> указать количество -> "Сгенерировать" -> настроить параметры
4. Для реферальной системы: добавить -> настроить переменную -> скопировать переменную -> вставить в текстовый блок команды в Конструкторе
5. Опубликовать изменения, проверить работу
**Полезные детали:** Ссылка создаётся остановленной по умолчанию -- необходимо запустить. При достижении лимита переходов ссылка автоматически отключается. Реферальные ссылки каждый раз генерируются разные (если не ограничено). Таблица переходов реферальной системы показывает: кто пригласил, кого и когда. Автоматическая переадресация при входе в ресурс. Повторная активация ссылки показывает сообщение об уже использованной ссылке.
