## Video 04: 04_Rassylka_Po_Pokupkam
**Тема:** Настройка рассылки с разными предложениями в зависимости от покупок пользователя. Бот проверяет, какие продукты пользователь уже оплатил, и предлагает только те, которые ещё не куплены.
**PuzzleBot-элементы:** Условия (проверка "Оплаченные платежи"), Команды ("Купить продукт А", "Купить продукт Б"), Рассылка с условиями, Оплата (платежи), Конструктор (визуальная схема команд и условий).
**Категория:** Рассылки
**Ключевые техники:**
- Создание условия с проверкой "Оплаченные платежи" для определения, какие продукты уже куплены пользователем
- Использование типа проверки "Все проверки" для одновременной проверки оплаты нескольких продуктов (Продукт А и Продукт Б)
- Сегментация пользователей: отправка разных команд/предложений в зависимости от статуса оплаты
- Создание отдельных команд для покупки каждого продукта ("Купить продукт А", "Купить продукт Б")
- Команда с продуктами как хаб для перенаправления на нужное предложение через условие
**Шаги реализации:**
1. Создать команды для каждого продукта: "Купить продукт А", "Купить продукт Б" с кнопками оплаты
2. Создать команды "Оплатили продукт А" и "Оплатили продукт Б" для подтверждения
3. Создать условие проверки оплаты: добавить проверку "Оплаченные платежи" с выбором платежей (Продукт А, Продукт Б)
4. Настроить правила: если оба продукта оплачены -- одно действие; если не все -- предложить недостающие
5. Использовать исключающее правило для пользователей, которые ничего не купили
6. Создать "Команду с продуктами" как точку входа, ведущую к условию проверки
7. Опубликовать изменения и протестировать
**Полезные детали:**
- Транскрипция видео отсутствует (без звука, экранная запись). Информация извлечена из ключевых кадров и описания
- Автор: Светлана Гизатулина (@G_Svetlana_E)
- Длительность всего 2:05 -- краткая визуальная инструкция
- На кадрах видно использование конструктора PuzzleBot с визуальной схемой связей между командами и условиями

## Video 15: 15_Knopka_Pod_Soobshchenie_Rassylka
**Тема:** Создание поста с инлайн-кнопкой и рассылка в бота, канал и чат одновременно. Обновление всех постов одновременно.
**PuzzleBot-элементы:** Постинг (создание поста, отправка, редактирование), Места отправки (бот, канал, чат), Инлайн-клавиатура (действие "Ссылка"), Ресурсы (каналы, чаты), Одновременное обновление постов.
**Категория:** Рассылки
**Ключевые техники:**
- Создание поста в разделе "Постинг" с отправкой сразу в несколько мест (бот + канал + чат)
- Инлайн-кнопка с действием "Ссылка" прикрепляется к сообщению
- Одновременное редактирование отправленного поста: изменение текста и ссылки обновляет пост во всех местах
- Функция "Отправить сейчас" для немедленной рассылки
**Шаги реализации:**
1. Подключить каналы и чаты как ресурсы (инструкция по подключению)
2. Перейти в раздел "Постинг", создать новый пост
3. Выбрать места отправки: бот (по умолчанию) + канал + чат
4. Добавить текстовый блок с текстом
5. Создать инлайн-клавиатуру, добавить кнопку с действием "Ссылка", вставить URL
6. Сохранить и нажать "Отправить сейчас"
7. Для редактирования: выбрать отправленный пост, изменить текст и/или ссылку
8. Сохранить и опубликовать изменения -- обновится во всех местах
**Полезные детали:**
- Каналы и чаты должны быть подключены заранее как ресурсы
- Редактирование отправленного поста обновляет его во всех местах одновременно (бот, канал, чат)
- Отправка в бота выбрана по умолчанию, дополнительные места добавляются вручную

## Video 57: 57_Kategorii_Otpravit_Soobshchenie_Raznym
**Тема:** Категории пользователей: создание, автоматическое присвоение и отправка постов по категориям
**PuzzleBot-элементы:** Категории (вкладка "Модерация"), действие "Изменить категории" (замена/изменение), инлайн-клавиатура (переход к команде), текстовый блок с переменной (юзернейм), постинг (отправка по категориям), стартовая команда
**Категория:** Рассылки
**Ключевые техники:**
- Создание категорий через вкладку "Модерация" (кнопка "+")
- Ручное присвоение категории: навести на пользователя > столбец "Категория" > выбрать
- Автоматическое присвоение через действие "Изменить категории" в команде (замена vs изменение)
- Отправка постов конкретной категории через вкладку "Постинг" (доступно только при отправке в бота)
- Разница "Замена" и "Изменение": замена заменяет ВСЕ категории, изменение -- только указанные
**Шаги реализации:**
1. Во вкладке "Модерация" создать категории (например, "Спикер" и "Слушатель")
2. В конструкторе: стартовая команда с приветствием и двумя инлайн-кнопками ("Спикер"/"Слушатель")
3. В каждой созданной команде добавить действие "Изменить категории" > выбрать соответствующую категорию
4. Добавить текстовый блок с подтверждением присвоения категории
5. Для рассылки: вкладка "Постинг" > "Новый пост" > место отправки "Бот"
6. В разделе категорий убрать "Любая", раскрыть список, отметить нужную категорию
7. Заполнить текст поста, выбрать время, запланировать или отправить
**Полезные детали:** Отправка по категориям доступна ТОЛЬКО если среди мест отправки выбран бот. Если отправка только в ресурс -- выбор категории недоступен. Категории полезны для: изменения прав в группе, ограничения доступа к командам, индивидуальных рассылок. Для просмотра списка пользователей по категориям: вверху страницы "Модерация" навести на текущую категорию и выбрать нужную.
