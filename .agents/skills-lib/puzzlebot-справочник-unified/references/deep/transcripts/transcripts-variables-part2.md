# Транскрипции: Переменные и условия

## Video 21: Переменные (персональная/глобальная)

В данном видео мы рассмотрим возможности вкладки «Переменные». Перейдем в бота и откроем саму вкладку. «Переменные» — это название функции, которая позволяет подставлять определенные значения индивидуально под каждого пользователя или для всех. Все переменные имеют общий вид. Для обозначения используются двойные фигурные скобки с двух сторон и буквы латинского алфавита разного регистра от A до Z, а также цифры и андроскор — нижнее подчеркивание — для названия переменной. Например, для приветствия пользователя по имени при входе в бота или группу. Разберем интерфейс вкладки. В левом верхнем углу мы можем выбрать, какие переменные будут демонстрироваться нам на экране — персональные или глобальные. В правом верхнем углу находится кнопка, с помощью которой мы можем создать переменную. В самом низу располагается кнопка. Нажимаем кнопку, создавая новую группу переменных. Теперь более подробно разберем сами переменные. Группы переменных бывают двух видов. Первый вид — это системные, созданные разработчиками или в других вкладках. Второй вид группы — это пользовательские. Это переменные, созданные пользователем, которые по умолчанию отображаются в основной группе. Системная группа содержит в себе несколько подгрупп. Попробуем создать переменную. Перейдем к созданию пользовательской переменной. Нажмем на кнопку «Добавить переменную». Все переменные делятся на два типа. Персональные – они хранят индивидуальные значения пользователя, например, имя пользователя, баланс, баллы в игре. И глобальные – они хранят общее значение для всех пользователей, например, название бота, ссылка на сайт, название кнопки. У каждой переменной есть значение, а каждое значение может быть одним из двух типов. Обычное значение – это значение, которое хранится внутри бота. Интегрированное значение – это значение, которое берется со стороннего сервиса путем GET-запроса. Ответ должен быть в JSON-формате. Также для интегрированного значения существуют два типа интеграции – через HTTP-запрос, либо через Google Sheets. Для использования последнего необходимо… …добавить Google аккаунт. Формат значения определяет тип значения, которое будет храниться в переменной. Существуют следующие форматы значения. Текст, число, формула – это сложное значение, формирующееся из нескольких переменных или содержащие математические операции. Ссылка может быть использована в кнопках с действием ссылка и в форматировании текста. Документ – это любой медиафайл. Формат значения. Формула и любые выражения с переменными имеют свои правила написания, о которых подробнее можно узнать по ссылке в описании. Значение по умолчанию – это значение, которое будет отображаться у пользователя, пока в переменную не будет записано другое значение или не будет изменено текущее. Описание – это текст, отображаемый только на вкладке «Переменные». Группа – это порядок отображения на вкладке «Переменные». Также стоит выделить такой процесс, как изменение переменной. Все переменные из системной группы редактируются в тех местах, где они были созданы. Формы ввода в конструкторе, реферальная система во вкладке «Вход» и так далее. Пользовательские переменные можно редактировать двумя способами. Через действие «Изменить переменную» или «Очистить переменную». Либо через ручное редактирование значения. С помощью ручного редактирования значения можно менять индивидуально для каждого пользователя. А действие «Очистка переменной»? Действие «Переменной» очищает дозначение по умолчанию. Изменение переменной через действие происходит во вкладке «Конструктор». Достаточно нажать на необходимую команду и добавить действие. Далее выбрать пункт «Изменить переменную». Ввести название переменной. Выбрать необходимый оператор. Затем вписать в графе выражения значение, формулу или другую переменную, которая должна изменить значение текущей переменной. При изменении пользовательской переменной с форматом число можно использовать универатральный оператор «заменить». Или использовать наиболее популярные операторы. Например, для уменьшения пери problema на 1 можно использовать оператор «вычесть» и прописать в поле выражения 1, или использовать универсальный оператор «заменить» и прописать название переменной минус 1. Оба этих варианта равнозначны. Для переменных с форматом «Текст» используется только оператора «Заменить». Например, в пользовательской переменной «MyDay» хранится любимый день недели пользователя. В нашем случае это понедельник. Для замены переменной на другой день, к примеру, вторник, в поле выражения после оператора «Заменить» нужно писать слово, используя кавычки «вторник». Отлично! Мы ознакомились с интерфейсом и возможностями вкладки «Переменные». А также научились их создавать и редактировать.

## Video 38: Пароль / ограничение доступа

В данном видео мы рассмотрим, как поставить пароль на бота. Рекомендую прежде посмотреть видео, указанное в описании, по созданию и привязке бота к сервису PuzzleBot и инструкцию по подключению чата или канала. Приступим. Откроем личный кабинет, перейдем в бота и выберем вкладку «Модерация». Для начала создадим категорию, которая будет присваиваться пользователю, если он ввел правильный пароль. Нажимаем на «плюс», вписываем название. Отлично, категория создана. Переходим к конструктору. Зажимая «шифт» выделяем все стандартные команды и удаляем их. Опубликовываем изменения. Открываем команду «старт», добавим текстовый блок, пишем приветственное сообщение. Создадим новую инлайн-команду и укажем в ее названии необходимый пароль. Добавим текстовый блок и в дополнительных настройках сделаем добавление в категорию. Создадим вторую группу команд. Укажем название и выберем доступ только для одной категории. Отлично, перейдем в нее, добавим инлайн-команду, укажем название, добавим текстовый блок и добавим инлайн-клавиатуру. Опубликуем изменения. Вернемся в основную группу. Сделаем команде с паролем переход через 2 секунды к команде из другой группы. Опубликуем изменения. Отлично, проверим работу бота. Попробуем ввести случайный набор фраз. А теперь отправим пароль. Отлично, мы получили доступ.

## Video 42: Вывод статистики в боте

В данном видео мы рассмотрим, как настроить сбор и отображение статистики, посчитать количество пользователей, переходов и оплат, а также добавить уведомления администратору и учет источников трафика. Но для начала нам необходимо создать Telegram-бот и подключить его к сервису PuzzleBot, а также подключить платежную систему. С подробной инструкцией вы можете ознакомиться по ссылкам в описании. Выберем нашего бота и перейдем во вкладку «Переменные». Выберем «Глобальные переменные». Здесь уже есть готовые переменные, которые собирают основную статистику по боту. Все они начинаются со слова «stats», поэтому префиксу их удобно находить в списке. Например, количество пользователей за все время — «stats.total.users», количество вошедших за день — «stats.today.users», вышедших — «stats.today.left», и активных пользователей за день — «stats.total.users». Есть и показатели по оплате — «stats.total.payment.count» и «stats.total.payment.sum». Эти переменные создаются автоматически, их не нужно настраивать вручную. Достаточно просто вывести их в нужной команде. Но если нужно посчитать, например, сколько человек дошло до оплаты или сколько раз открывалась продающая команда, можно добавить свои собственные глобальные переменные и использовать их для нужных расчетов. Для этого нажмем на кнопку «Добавить переменную». Выберем тип «Глобальная», зададим ей название, например, «stats.sale.open» и в формате значения выберем число. Эта переменная будет считать количество открытий продающей команды. Аналогичным образом создадим переменную для подсчета оплат «stats.sale.paid». В случае, если нам нужно понять, из какого источника трафика пришел пользователь и где произошла оплата, можно добавить отдельные переменные под каждый источник. Каждая из них будет называться «stats.sale.paid». Их будет считать количество оплат, пришедших с конкретной ссылки или источника. Перейдем во вкладку «Модерация». Здесь нам необходимо создать категорию для администратора, чтобы только он мог просматривать статистику. Нажмем на кнопку с плюсом и зададим название. Добавим в нее нужных пользователей. Эта категория понадобится нам позже. Мы будем проверять ее наличие, чтобы показать кнопку со статистикой только администратору. Выбираем вкладку «Конструктор». Для начала создадим команду, в которой будет отображаться статистика. Дадим ей название. Добавим текстовый блок и заполним его. Такой формат позволит быстро посмотреть основные показатели и сравнить результаты по разным источникам трафика. Теперь перейдем к созданию кнопки «Условия», которая будет проверять наличие категории администратора для допуска к команде. Добавим кнопку «Условия». И дадим ей название. В типе проверки добавим наличие категорий. И выберем созданную категорию. Добавим действие «Отправить команду или условия». Выберем нашу команду со статистикой. В исключающем правиле скроем кнопку. Таким образом, при наличии категории администратору будет отправляться команда со статистикой, а у остальных пользователей кнопка просто не будет отображаться. Перейдем к оформлению стартовой команды. Добавим текстовый блок и заполним его. Добавим Inline клавиатуру. Выберем действие «Кнопка условия». И выберем созданное условие. Таким образом, кнопка будет отображаться только у администратора. При нажатии на нее бот проверит наличие категории и, если доступ есть, отправит команду со статистикой. У обычных пользователей эта кнопка просто не появится. Перейдем к созданию команды с оформлением заказа. Дадим название команде. Добавим текстовый блок и заполним его. Теперь добавим Inline клавиатуру. Дадим название кнопке. И выберем действие «Платеж». Также заполним графу наименования платежа. Выберем валюту и укажем стоимость. Также введем название будущей команды, которая будет сообщать об успешном платеже. Также добавим действие «Изменить переменную». Введем название переменной «StatSaleOpen». Выберем действие «Прибавить» и укажем единицу. Эта переменная будет считать количество пользователей, которые дошли до этапа оплаты, но еще не совершили сам платеж. Раскроем автоматически созданную команду. Добавим текстовый блок и заполним его. Чтобы фиксировать количество совершенных оплат, добавим действие «Изменить переменную». Введем название переменной «StatSalePaid». И в выражении укажем «плюс один». Таким образом, при каждой успешной оплате значение переменной будет увеличиваться. И эти данные появятся в нашей статистике. Теперь перейдем к созданию команды с уведомлением об успешном платеже для администратора. Дадим ей название. Добавим текстовый блок и заполним его. Чтобы данное уведомление приходило после оплаты, раскроем команду с успешной оплатой. Добавим действие «Отправить команду или условия». И введем название команды с уведомлением. Мы можем отправить данное уведомление в определенный канал, либо же администратору. Для примера нажмем на галочку напротив пункта «Выполнить другому пользователю». И введем юзернейм администратора. Таким образом, после каждой успешной оплаты администратор будет получать уведомления с данными пользователя. Теперь нам нужно определить, откуда именно пользователи совершают оплату и с какого источника трафика. Для этого вернемся в нашего бота и перейдем во вкладку «Вход». Здесь создаются специальные ссылки, по которым пользователи попадают в бота. По каждой такой ссылке можно отслеживать источник, например, канал Telegram, ВК или сайт. Нажмем на кнопку «Добавить ссылку». Выберем многоразовую ссылку и дадим название источнику. Активируем ее. Повторим те же действия для другого источника. После этого мы сможем использовать эти ссылки для проверки источника в момент оплаты. И ввести отдельный подсчет по каждой переменной. Вернемся в конструктор. Теперь настроим условия, которые будут фиксировать оплаты по каждому источнику трафика. Для этого создадим условие и дадим ему название. И выберем наш первый источник. Также добавим действие «Изменить переменную». Выберем нашу переменную для первого источника. И прибавим единицу. Добавим второе правило. И повторим те же действия для второго источника. Таким образом, при каждой успешной оплате будет увеличиваться значение нужной переменной. Эти данные автоматически попадут в нашу команду со статистикой. Где можно будет увидеть, сколько оплат поступило из каждого источника. Раскроем команду с успешной оплатой. И добавим действие «Отправить команду или условия». Введем название нашего условия с источниками. Осталось добавить в стартовой команде кнопку для оформления заказа. Сохраним и опубликуем изменения. Проверим работу бота в Telegram. Перейдем по одной из созданных ссылок. Отправим стартовую команду. И совершим тестовую оплату. Чтобы убедиться, что оплата отображается в статистике правильно. После оплаты у администратора должно появиться уведомление о новом платеже с именем пользователя. Затем нажмем на кнопку со статистикой. В блоке «Статистики» мы видим обновленные данные. Увеличилось общее количество оплат. А также значение переменной, отвечающей за источник. С которого была совершена покупка. Так мы можем отследить, с каких каналов приходит больше оплат. Таким образом мы настроили сбор и отображение статистики. Научились считать количество пользователей, переходов и оплат. А также добавили уведомления администратору и учет источников трафика.
