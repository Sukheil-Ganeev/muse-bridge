**Q:** Можно ли одновременно принимать инлайн-кнопки и произвольный текст?
**A:** Легкого решения нет, но через "костыли":
1. Создать переменную-флаг "ожидает текст"
2. В команде с кнопками переопределить флаг
3. Переопределить "Неизвестную команду" -> условие проверки флага. Если ожидается текст -- записать, если нет -- "Я не знаю, как ответить"

### Интеграции

**Q:** Как опрашивать Google Таблицу каждые X минут?
**A:** Варианты:
1. **n8n** -- сценарии с таймерами через API (минимум 1 мин)
2. **Google Apps Script** -- триггер на новую строку или по времени
3. **Make (Integromat)** -- минимум 15 мин на бесплатном тарифе
4. **Apix-Drive** -- простая интеграция без кода

---

**Q:** Как подтягивать данные из Excel/Google Таблицы по кнопке?
**A:** 1. Создать интегрированную переменную из Google Таблиц с фильтрами (уникальная основа поиска, сортировка по дате, целевой столбец)
2. Условие для перепроверки привязки
3. В действиях приравнять интегрированную переменную к текстовой

---

**Q:** Google Sheets как база данных для PuzzleBot?
**A:** Она и есть БД. Интегрированные переменные бывают: по поиску и по адресу строки. Поиск обширный. Для анализа можно писать формулы прямо в блоке текст. Создать интегрированную переменную со значением "текст", поиск по user_id, вывод нужного столбца.

---

**Q:** Проблема с интегрированной переменной в мини-приложении (не загружается с первого раза)
**A:** Действия "До" в мини-приложениях выполняются не совсем "До", а "Между". Костыли: переход через промежуточное приложение для изменения переменной и переадресации. Или лучше получать данные из таблицы скриптом напрямую, без интегрированной переменной.

---

**Q:** Как реализовать циклический вызов команды?
**A:** В конструкторе запрещены зацикленные действия. Используйте форму ввода с параметром "Ограничение времени" (минимум 5 сек). Если пользователь не ответил -- условие проверяет, нужно ли повторить. Если да -- команда заново. Если нет -- переход к другой команде.

---

**Q:** Какую библиотеку использовать для распознавания типа файла?
**A:** Рекомендуется [file-type](https://www.npmjs.com/package/file-type). Определяет MIME-тип по magic bytes, не по расширению. Поддерживает Buffer и stream.

---

**Q:** NocoDB vs Google Таблицы -- что выбрать?
**A:** NocoDB рекомендуется в связи с новыми законами (данные на своих серверах). Преимущества: скорость чтения/записи почти моментальная, лимиты 10 запросов/сек. Документация: docs.nocodb.com. Позиционируется как альтернатива Airtable.

**Q:** Как передать права на бота заказчику?
**A:** Передать право владения в @BotFather и перенести бота на аккаунт заказчика в PuzzleBot (Настройки -> Дублировать/Перенести).

### Сообщения и тексты

**Q:** Как вывести аватар пользователя в мини-приложении?
**A:** HTML-код:
```html
<div style="display: flex; align-items: center; gap: 10px;">
  <img src="{{USER_AVATAR_URL}}" alt="Аватар"
       style="width: 60px; height: 60px; border-radius: 60%;
              border: 2px solid #1590b7;">
  <div>
    <span style="font-size: 20px; color: #333;">
      <strong>{{FIRST_NAME_TEXT}}, приветствуем</strong>
    </span>
  </div>
</div>
```

**Q:** Как объединить блоки (картинка + текст), чтобы чат не прокручивался вниз?
**A:** Объединить картинку с текстом (текст в описание, если не больше 1024 символа). Поставить таймаут на примерное время прочтения и только потом отправить аудио.

---

**Q:** Как правильно вставлять ссылки в текст бота?
**A:** В блоке текст выделите слова, во всплывающем окне форматирования выберите "ссылка", вставьте URL и нажмите Enter. Текст станет синим с подчеркиванием. Ссылки в чистом виде выглядят плохо.

---

**Q:** Сложный HTML-код не работает в мини-приложении PuzzleBot?
**A:** Более сложный код может не тянуть на страничке PuzzleBot (ограничения сервиса). Решение: разместить код на GitHub и открывать мини-приложение по внешней ссылке. Все работает как надо.

### Группы и каналы

**Q:** Как дублировать группу команд внутри бота?
**A:** Прямой возможности нет. Хитрый способ: дублировать в другой бот, потом из другого бота обратно. Дублируйте БЕЗ замены. Дублирование -- в настройках бота.

---

**Q:** Как настроить сценарий напоминания во всех командах?
**A:** В каждой команде перезапускать сценарий. В настройках сценария: отключить "отключить после выполнения" и поставить "перезапускать сценарий при повторном запуске".

---

**Q:** Как сделать обязательную подписку на канал перед доступом?
**A:** Добавить канал в ресурс. Две кнопки: "Подписаться" (ведет на канал) и "Проверка подписки" (ведет на условие с проверкой подписки).

---

**Q:** Как отследить подписку пользователя на канал?
**A:** 1. Создать команду с действием "Создать строку" в таблице
2. В конструкторе на ресурсе включить галочку "Пользователь подписался"
3. Добавить действие "отправить команду" -- которая создает строку. В команде можно не добавлять блок, достаточно действия

---

**Q:** Как сделать капчу при входе?
**A:** Форма ввода: в вопросе -- картинка или текст. Ответ -- текстом или кнопками. Далее через условие проверяете переменную на значение (точное соответствие). Если ОК -- пропускаете дальше. Если нет -- команда "не ОК".

---

**Q:** Новые правила Telegram: можно ли подключать не Telegram Stars?
**A:** Запрета на другие платежные системы нет. Но нужно чтобы выбор был у пользователя и оплата за Stars не была спрятана. Рекомендуется предоставлять оба варианта.

---

**Q:** Бот может первым написать пользователю?
**A:** Нет, если пользователь до вступления в ресурс не был в боте. Единственная возможность -- событие подачи заявки на закрытый ресурс (с жесткими ограничениями от Telegram).

### Общие вопросы

**Q:** Как автоматизировать сегментацию пользователей по категориям?
**A:** Критерии устанавливаете вы сами: по каналам входа, выбору в опросах, введенным данным. Категория присваивается в Действиях команды. Может измениться как ДО, так и ПОСЛЕ исполнения.

---

**Q:** Нужен ли /privacy для бота без форм ввода?
**A:** Стандартные данные (юзернейм, имя) отдает сам Telegram. При регистрации пользователь уже согласился по политике Telegram. Если есть формы ввода -- да, нужен. Если только стандартные данные -- необязательно.

---

**Q:** Где найти клиентов на создание ботов?
**A:** Лучше всего сарафанное радио. Делайте ботов "за спасибо", но с обязательным условием: вы видны как автор/создатель со ссылкой. Делаете много и разных, набиваете руку. Через время появятся клиенты.

---

**Q:** White Label (WL) для разработчиков ботов?
**A:** WL расширение к тарифу (puzzlebot.top/blog/JAO3CBYV2X):
1. Клиенты получают ЛК брендированный под вас на вашем домене
2. Оплату получаете вы, стоимость устанавливаете сами

---

**Q:** Как сгенерировать уникальный ID при создании строки?
**A:** Две числовые переменные. Начальное значение одной -- 0. Проверяем значение. Если пусто -- добавляем +1 к счетчику и присваиваем значение.

---

**Q:** Как сформировать документ из данных пользователя (шаблонный договор)?
**A:** Только через интеграцию со сторонними сервисами: формирование файла на внешнем сервере и отправка обратно через API.

---

**Q:** Формула для конвертации секунд в формат ЧЧ:ММ:СС?
**A:**
```
(floor({{SEC}}/3600))+":"+(floor(({{SEC}}-floor({{SEC}}/3600)*3600)/60))+":"+({{SEC}}-floor({{SEC}}/3600)*3600-floor(({{SEC}}-floor({{SEC}}/3600)*3600)/60)*60)
```
Результат: `1:2:3` (для `01:02:03` нужна доп обработка).

## Частые проблемы пользователей

- **Проблема:** Интегрированная переменная не загружается с первого раза в мини-приложении
  **Решение:** Переход через промежуточное приложение для изменения переменной. Или получать данные скриптом напрямую, без интегрированной переменной.

- **Проблема:** Бот не реагирует на триггеры в группе ("не удалось найти пользователя")
  **Решение:** Проверить настройку "действие выполнять пользователю, получившему ответ". Убрать или отвечать через кнопку "Ответить".

- **Проблема:** Google Таблицы перестают работать при массовой рассылке
  **Решение:** Ставить большое кэширование везде. Google допускает только 60 запросов/минуту. Рассмотреть переход на NocoDB.

- **Проблема:** Нельзя зациклить команды в конструкторе
  **Решение:** Использовать форму ввода с "Ограничением времени" (5 сек) + условие проверки. Или API запрос к PuzzleBot. Или сценарий с типом "Через".

- **Проблема:** Файлы загружаются в неправильном формате/размере через ЛК
  **Решение:** Загрузка через ID файла: команда `/cp` в боте -> "Загрузить файл" -> скопировать ID -> вставить в блок.

- **Проблема:** Пользователь ошибся при заполнении формы, хочет исправить
  **Решение:** По окончанию опроса выводить все ответы для проверки + кнопка "Редактировать" с переходом на нужную форму.

- **Проблема:** Кнопки в форме ввода удаляются после нажатия
  **Решение:** Использовать обычный блок с инлайн-кнопками. Каждая кнопка ведет на отдельную команду с формой ввода.

- **Проблема:** Ошибка 80 при оплате
  **Решение:** Превышен лимит дохода за месяц. Сбрасывается 1 числа. Или перейти на более высокий тариф.

- **Проблема:** Сценарий не работает при зацикливании
  **Решение:** Тип отправки должен быть "Через" (не "Сразу"), минимум 1 минута.

- **Проблема:** Как не засыпать пользователей уведомлениями от форм ввода
  **Решение:** Настройки -> Формы ввода -> Создать правило для объединения уведомлений.

- **Проблема:** Бот не пишет первым после подписки на открытый канал
  **Решение:** Невозможно, если пользователь не взаимодействовал с ботом. Единственный вариант -- закрытый ресурс + событие подачи заявки.
