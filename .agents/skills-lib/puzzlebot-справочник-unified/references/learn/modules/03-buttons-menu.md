# 03 -- Кнопки и меню

Справочный модуль: обычные и inline кнопки, кнопка условия, меню, слайдеры, popup, чекбоксы, callback data.

---

## 1. Обычные кнопки vs Inline кнопки

### Обычная клавиатура (ReplyKeyboard)

| Свойство | Описание |
|----------|----------|
| **Расположение** | Внизу экрана, заменяет системную клавиатуру |
| **Привязка** | К команде (одна клавиатура на команду) |
| **Поведение** | Сохраняется до замены другой обычной клавиатурой |
| **Действия** | Переход к обычным командам |
| **Скрытие** | Скрывается, но НЕ удаляется (вызывается повторно) |

**Создание:**
1. Откройте команду в Конструкторе
2. Внизу нажмите **"Обычная клавиатура"** (кнопка `Клавиатура`)
3. Добавьте кнопки, задайте действия (переход к командам)
4. Перетаскивайте кнопки для расстановки по рядам

**Элементы интерфейса клавиатуры (из OCR):**
- Кнопка `Клавиатура` -- раскрывает настройки клавиатуры
- Тип: `Обычная` / `Инлайн` / `Фиксированная`
- Действие кнопки: выпадающий список `Переход к команде или условию`

### Инлайн-клавиатура (InlineKeyboard)

| Свойство | Описание |
|----------|----------|
| **Расположение** | Прикреплена к конкретному сообщению (блоку) |
| **Привязка** | К блоку контента |
| **Поведение** | Остаётся в переписке навсегда |
| **Действия** | Переход к командам, ссылки, платежи, popup, диалоги и др. |
| **Уникальность** | Только в инлайн-клавиатуре можно сделать кнопку-ссылку |

**Создание:**
1. Откройте блок (текст, изображение и др.)
2. Нажмите **"Инлайн-клавиатура"**
3. Добавьте кнопку, выберите **действие** и введите **название**
4. Расположите кнопки по рядам перетаскиванием

## 2. Все действия кнопок

### Действия инлайн-кнопок

| Действие | Описание |
|----------|----------|
| **Переход к команде** | Переход на обычную или инлайн-команду |
| **Переход к условию** | Вызов обычного условия |
| **Кнопка условия** | Вызов кнопки условия (название и действие зависят от проверки) |
| **Ссылка** | Открытие URL (только в инлайн-кнопке) |
| **Начало диалога** | Активация режима обратной связи |
| **Платёж** | Кнопка оплаты (Telegram Stars, Робокасса и др.) |
| **Поп-ап (Popup)** | Всплывающее окно с текстом |
| **Изменение сценария** | Запуск/остановка сценария |
| **Подставить текст** | Вставка текста в поле ввода |
| **Поделиться текстом** | Отправка текста другому пользователю |
| **Веб-приложение (ссылка)** | Открытие мини-приложения по URL |
| **Веб-приложение (магазин)** | Открытие встроенного магазина |

**Текст действия в интерфейсе (из OCR):** `Отправить команду или условие` -- именно так называется действие в выпадающем списке при настройке кнопки.

### Действия обычных кнопок

Обычные кнопки переходят **только на обычные команды** (синие блоки).

---

## 3. Обычные команды vs Инлайн-команды

### Обычные команды (синие блоки)

- Содержат **несколько блоков** и **оба вида клавиатур**
- При вызове -- **отправляется новое сообщение**
- Универсальные -- подходят для большинства задач

### Инлайн-команды (розовые блоки)

- Содержат **один блок** и **только инлайн-клавиатуру**
- При вызове -- **заменяют текущее сообщение** (не отправляют новое)
- Условие замены: вторая команда должна быть инлайн и содержать **блок того же типа**
- При переходе инлайн -> обычная: будет отправлено **новое сообщение**

### Правила переходов

| Откуда | Куда | Результат |
|--------|------|----------|
| Обычная | Обычная | Новое сообщение |
| Обычная | Инлайн | Замена текста ответа бота |
| Инлайн | Инлайн (тот же тип блока) | Замена на месте |
| Инлайн | Обычная | Новое сообщение |
| Инлайн | Инлайн (другой тип блока) | Новое сообщение |

## 4. Кнопка условия

### Что это

**Кнопка условия** -- особый тип условия, который **определяет настройки инлайн-кнопки**. В отличие от обычного условия, кнопка условия может показывать **разное название и действие кнопки** разным пользователям.

### Создание кнопки условия

1. В Конструкторе нажмите **"Добавить условие"**
2. Задайте название
3. Выберите тип: **"Кнопка условия"**

> **ВАЖНО:** Тип условия (обычное / кнопка) нельзя изменить после сохранения!

### Настройка правил

Каждое правило содержит:
- **Проверку** -- какое условие должно быть выполнено
- **Название кнопки** -- что увидит пользователь
- **Действие кнопки** -- ссылка, переход, popup и др.

**Пример:**
- Правило 1: Если сценарий активен -> кнопка "Получить подарок" (ссылка)
- Правило 2 (исключающее): Если ничего не подошло -> кнопка "Регистрация" (переход к команде)

### Привязка к сообщению

1. В команде создайте **инлайн-клавиатуру**
2. Добавьте кнопку
3. Действие -> **"Кнопка условия"**
4. Выберите нужную кнопку условия из списка

> Обычные условия в этом списке НЕ отображаются -- только кнопки условия.

### Типы проверок в условиях

| Проверка | Описание |
|----------|----------|
| **Вызов команды или условия** | Была ли вызвана конкретная команда |
| **Наличие подписки** | Подписан ли на ресурс (канал/группу) |
| **Значение переменной** | Проверка значения переменной (=, >, <, содержит) |
| **Оплаченные платежи** | Оплачен ли конкретный платёж |
| **Категория пользователя** | Принадлежит ли пользователь категории |
| **Активный сценарий** | Запущен ли конкретный сценарий |
| **Проверка строки** | Наличие записи в Google Sheets |
| **Дата/время** | Проверка текущей даты/времени |
| **Start Payload** | Содержимое deep link параметра |

### Параметры проверок

| Параметр | Описание |
|----------|----------|
| **Все проверки** | Все условия должны быть выполнены (AND) |
| **Любая проверка** | Достаточно одного (OR) |
| **Задать количество** | Ровно N раз (например, вызвал команду ровно 3 раза) |
| **Задать период** | Проверка за промежуток времени |
| **Проверить другого пользователя** | По Telegram ID или юзернейму |

### Типы периодов

| Тип | Описание |
|-----|----------|
| **Количественный** | Относительно текущего момента (за последние N дней/часов) |
| **Датированный** | Точные даты (с DD.MM.YYYY по DD.MM.YYYY) |
| **Календарный** | Относительно календарных значений (сегодня, эта неделя, этот месяц) |

### Типы действий

| Тип | Описание |
|-----|----------|
| **Все действия** | Выполнить все действия в правиле |
| **Случайное действие** | Выбрать одно из действий по вероятности (настраивается %) |

### Исключающее правило

Последнее правило в списке. Срабатывает, если **ни одно другое правило не прошло проверку**. Стандартный паттерн "если найдено / если нет".

## 5. Кнопка меню (/)

Кнопка "Меню" в Telegram появляется автоматически при наличии slash-команд.

### Создание slash-команды

1. Создайте **обычную команду** с названием вида `/command`
   - Только **латиница и цифры**
   - Обязательно начинается с `/`
   - Длина до **32 символов**
2. Откройте **дополнительные настройки** команды
3. Включите **"Отображать в меню"**
4. Добавьте **короткое описание** (видно в списке команд)
5. Заполните команду контентом
6. Опубликуйте

### Результат

- В Telegram появится кнопка **"Меню"** (слева от поля ввода)
- При вводе `/` -- появляется список доступных команд с описаниями
- Дополнительно: создайте **инлайн-клавиатуру в Start** с кнопками перехода к тем же командам

> Список команд может обновиться с задержкой из-за кеширования Telegram.

## 6. Слайдеры через инлайн-команды

Слайдер -- цепочка инлайн-команд, заменяющих друг друга на месте.

### Пошаговое создание

1. Создайте **инлайн-команду** (розовый блок), назовите "Slider1"
2. Добавьте **медиаблок** с изображением и описанием
3. Добавьте **инлайн-клавиатуру** с кнопкой -> переход к "Slider2" (ещё не существует)
4. PuzzleBot **автоматически создаст** инлайн-команду "Slider2" с тем же содержимым
5. Откройте "Slider2", замените изображение и описание
6. Измените кнопку: переход обратно на "Slider1"
7. Опубликуйте

### Расширенный слайдер

Добавьте кнопки навигации:
```
[<< Назад] [1/5] [Далее >>]
```
Где "1/5" -- кнопка popup с текстом текущей позиции.

### Вызов слайдера

В обычной команде создайте **обычную клавиатуру** с кнопкой перехода к первой инлайн-команде слайдера.

## 7. Popup / Скрытое продолжение

### Создание popup-кнопки

1. Добавьте **инлайн-клавиатуру** к блоку
2. Добавьте кнопку -> действие **"Поп-ап"**
3. Введите текст всплывающего окна

### Popup с проверкой подписки

1. Добавьте кнопку -> действие **"Поп-ап"**
2. Включите **"Проверка подписки на ресурс"**
3. Выберите канал/группу
4. Впишите **текст для подписанных** (например: "Ваш промокод: ABC123")
5. Впишите **текст для неподписанных** (например: "Подпишитесь на канал, чтобы получить промокод")

> Popup -- встроенная функция Telegram (alert/toast). Текст ограничен по длине.

### Где использовать

- В боте
- В канале (через постинг)
- В группе
- Кнопка со скрытым продолжением может быть размещена где угодно

## 8. Чекбоксы через переменные

PuzzleBot не имеет встроенных чекбоксов, но их можно реализовать через переменные.

### Принцип

1. Создайте **числовую переменную** (например `check_email`) со значением 0
2. Создайте **кнопку условия**:
   - Правило 1: Если `check_email` = 0 -> кнопка "[ ] Email-рассылка" -> действие: изменить переменную на 1
   - Правило 2: Если `check_email` = 1 -> кнопка "[x] Email-рассылка" -> действие: изменить переменную на 0
3. Привяжите кнопку условия к инлайн-клавиатуре
4. При нажатии кнопка переключается между состояниями

### Множественные чекбоксы

Повторите для каждого пункта:
- `check_email` -- рассылка по email
- `check_telegram` -- рассылка в Telegram
- `check_sms` -- SMS-уведомления

Кнопка **"Сохранить"** внизу -- переход к команде с итоговой обработкой.

## 9. Callback Data

При нажатии инлайн-кнопки Telegram передаёт **callback_data** -- скрытые данные, связанные с кнопкой.

В PuzzleBot callback data формируется автоматически на основе:
- Действия кнопки (переход к команде, условию и др.)
- Идентификатора целевой команды/условия

### Применение

- PuzzleBot управляет callback data автоматически -- ручная настройка не требуется
- Для сложных интеграций через API используйте **подписки на события** (Настройки -> Подписки на события)
- При использовании **Start Payload** (deep linking): `t.me/botname?start=параметр` -- параметр доступен через переменную `{{START_PAYLOAD}}`

## 10. Действие "Начало диалога"

### Настройка обратной связи

1. Создайте команду (например, "Связаться с нами")
2. Добавьте текстовый блок: "Напишите ваш вопрос"
3. Добавьте **инлайн-клавиатуру** с кнопкой
4. Действие -> **"Начало диалога"**
5. Опубликуйте

### Работа с диалогами

- Пользователь нажимает кнопку и пишет сообщение
- Владелец бота получает **уведомление**
- Для ответа: **обязательно через reply** (ответить на конкретное сообщение)
- Управление: команда `/cp` в боте или вкладка **"Диалоги"** в ЛК
- Завершение диалога -- через интерфейс

---

## 11. Копирование клавиатуры

Чтобы не создавать одинаковые клавиатуры в каждой команде:

1. Откройте команду с нужной клавиатурой
2. Нажмите **"Копировать клавиатуру"**
3. Откройте целевую команду
4. Нажмите **"Вставить клавиатуру"**

Работает для обычных клавиатур.

## 12. Практические паттерны

### Обязательная подписка на канал

1. Кнопка **"Подписаться"** -- ссылка на канал
2. Кнопка **"Проверить подписку"** -- переход к условию
3. Условие: проверка подписки на ресурс
   - Если подписан -> основное меню
   - Если нет -> "Вы ещё не подписались, попробуйте снова"

### Кнопка с таймером (нажми или подожди)

1. По кнопке -- переход к команде + **остановка сценария**
2. Если кнопка не нажата -- сценарий отправляет пост через заданное время

### Удаление сообщения с кнопками

Нельзя удалить уже отправленное сообщение у всех пользователей. Рекомендации:
- Ставьте **"Удалить через время"** в действиях команды
- Или галочку **"Удалить после вызова следующей команды"**
- Для кнопок оплаты: редактирование суммы обновляет кнопку у всех (с подтверждением)
