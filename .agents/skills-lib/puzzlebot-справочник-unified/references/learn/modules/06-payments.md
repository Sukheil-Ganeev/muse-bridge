# 06. Оплата и магазин

## Обзор

PuzzleBot поддерживает приём платежей через множество платёжных систем, создание полноценного магазина с корзиной и доставкой, а также платный доступ к каналам/группам и подписки с автопродлением.

---

## Подключение платёжных систем

### Путь

Настройки бота -> **Платёжные системы** -> выбрать систему -> указать данные -> сохранить

### Доступные системы (30+)

| Категория | Системы |
|-----------|---------|
| Telegram | **Telegram Stars** (самый простой, без настройки BotFather) |
| Рекуррентные | Prodamus, Robocassa, Ucasa |
| Обычные | Ucasa, Stripe, Альфа-банк, Каспи |
| Через Telegram | ЮKassa, ЮMoney, Сбер и другие |

**Точные названия в интерфейсе (из OCR):**
- `Telegram Stars` -- кнопка `Оплата телеграм звезд`
- `Продамус` (Prodamus) -- отображается как `Продамус` в настройках
- `Яндекс.Деньги` -- старое название, сейчас ЮMoney
- Кнопки оплаты в боте: `Оплатить` / `ОПЛАТИТЬ`
- Типичные контексты: `Оплата курса`, `Оплата подписки`, `Оплата за доступ в группу`

### Telegram Stars

Самый простой способ оплаты:

1. Настройки -> Платёжные системы -> **Telegram Stars**
2. Установить галочку **"Использовать для платежей"**
3. Сохранить
4. Готово -- дополнительная настройка через BotFather не нужна

Стоимость указывается в звёздах. Не требует секретных ключей.

### Prodamus

1. Настройки -> Платёжные системы -> **Prodamus**
2. Указать номер кошелька и секретный ключ
3. Сохранить
4. Опция **"Открывать веб-приложение"** -- улучшает UX (оплата внутри Telegram)

### Другие системы

Для каждой системы:
1. Зарегистрироваться в платёжной системе
2. Получить ключи API / номер кошелька / секретный ключ
3. Ввести данные в настройках PuzzleBot
4. Сохранить

### Ограничения Telegram

- Оплата через встроенные сервисы Telegram: от **$1** до **$10 000**
- Правила: оплата через Telegram Stars не должна быть "спрятана" -- рекомендуется давать пользователю выбор

## Создание кнопки оплаты

### В Конструкторе

1. Открыть команду, добавить **инлайн-клавиатуру**
2. Действие кнопки -> **Платёж**
3. Заполнить:
   - **Название кнопки** -- текст на кнопке
   - **Наименование платежа** -- описание товара/услуги
   - **Валюта** -- выбрать (рубли, доллары, Telegram Stars и др.)
   - **Стоимость** -- сумма
   - **Команда при успешной оплате** -- название команды, которая сработает после оплаты
4. В команде успешной оплаты добавить нужные действия:
   - Изменить категорию
   - Изменить переменную
   - Активировать сценарий
   - Действие в ресурсах
   - Текстовый блок с подтверждением

## Платный доступ в канал/группу

### Способ 1: Прямая оплата + принятие заявки

1. В Telegram создать **пригласительную ссылку** с включённой функцией **"Заявки на вступление"**
2. В команде "Старт": текст + инлайн-кнопка с действием **Платёж**
3. В команде успешной оплаты:
   - Действие в ресурсах -> **Принять заявку на вступление**
   - Текстовый блок с подтверждением
   - Галочка **"Выполнение только из клавиатуры"** (защита от случайного вызова)
4. В настройках ресурса -> События -> **Заявка на вступление**:
   - Тип действия: Команда/Условие -> команда "Старт"

Поток пользователя: ссылка -> заявка -> бот -> оплата -> заявка принята автоматически.

### Способ 2: Оплата + категория + ссылка

1. Создать категории **"Доступ"** и **"Запрет"**
2. Команда оплаты: кнопка **Платёж**
3. Команда успеха: изменить категорию (добавить "Доступ", убрать "Запрет") + ссылка на канал
4. Условие: проверка категории "Доступ" -> если есть = ссылка; если нет = оплата
5. В ресурсе -> События -> Заявка на вступление:
   - Принять (допнастройки: категория "Доступ")
   - Отклонить (если нет категории)

### Автоудаление при остановке бота

В боте -> События -> **Пользователь остановил бота**:
- Действие: отправить команду удаления (действие в ресурсах -> "Удалить пользователя")
- Допнастройки: только для категории одобрения

## Платный доступ по уникальным ссылкам

### Промо-ссылки (вкладка "Вход")

1. Вкладка **Вход** -> Добавить ссылку -> **Промо-ссылки**
2. Указать количество ссылок для генерации
3. Настроить: категория, команда при переходе, ограничение переходов, срок действия
4. **Сгенерировать** -> скачать в текстовом формате или отправить в Telegram

Каждая ссылка -- уникальная, одноразовая. При достижении лимита -- автоматически отключается. Повторная активация показывает сообщение "уже использована".

## Подписки с автопродлением

### Ежемесячная подписка (через переменную "Дни")

1. Создать числовую персональную переменную **"Дни подписки"**
2. Создать категории **"Активная подписка"** и **"Неактивная подписка"**
3. Кнопка оплаты в стартовой команде

4. **Команда успешной оплаты:**
   - Прибавить дни к переменной (например, +30)
   - Изменить категории (Активная ON, Неактивная OFF)
   - Активировать сценарий
   - Текст + ссылка на канал (пригласительная с заявками)

5. **Сценарий подписки:**
   - Перезапуск при повторном вызове = ВКЛ
   - Снять "Завершить после выполнения всех постов"
   - Пост: "Через 1 день", повторение каждый 1 день
   - Действие "До": вычесть 1 из переменной "Дни"
   - Действие "После": отправить условие проверки

6. **Условие проверки:**
   - Правило 1: Дни = 2 -> напоминание с кнопкой оплаты
   - Правило 2: Дни = 0 -> подписка истекла

7. **Команда "Подписка истекла":**
   - Изменить категории (Активная OFF, Неактивная ON)
   - Удалить пользователя из ресурса
   - Деактивировать сценарий
   - Текст + кнопка оплаты

### Важные нюансы

- В сценарии: сначала вычесть день (До), потом проверить условие
- При досрочном продлении: дни **прибавляются** к остатку (не заменяются)
- Пригласительная ссылка с заявками обязательна для управления доступом
- В ресурсе: принимать заявку автоматически только при наличии категории "Активная"

### Альтернатива: ограничение по дате

1. При оплате: создать переменную `AddDate(CurrentDate, 30)` -- дата окончания
2. Сценарий ежедневно сравнивает текущую дату с переменной
3. Если даты равны -- выполнить блокировку (смена категории, отключение)

## Магазин

### Включение

1. Вкладка **Магазин** -> включить
2. Выбрать валюты (поддерживается мультивалютность)
3. Автоматически создаётся группа команд с 4 обязательными этапами:
   - Выбор валюты
   - Корзина
   - Доставка
   - Оплата

### Товары

#### Обычный товар

- Название, описание, категория
- Медиа (фото/видео/аудио) -- превью
- Цена по валютам (мультивалютность)
- Остаток, артикул (уникальный)
- Допнастройки: команда после покупки, изменение сценария, пропуск доставки, лимит на корзину

#### Электронный товар

- Тип: **Электронный**
- Список элементов (ссылки, промокоды) -- вставляются построчно
- Режим выдачи: **по списку** (каждому уникальный) или **без ограничения** (цикличная выдача)
- Переменная для вывода выданного элемента: вставить в команду после покупки
- Система отслеживает использованные элементы

#### Группы товаров

- Объединение по характеристикам (цвет, размер)
- В карточке товара: переключение между вариантами
- Отображение в одном блоке-карусели (слайдер)

### Категории товаров с характеристиками

1. Создать категорию (например, "Ноутбуки")
2. Добавить характеристики-шаблоны (например, "Вес", "Диагональ")
3. При создании товара в этой категории характеристики подставляются автоматически

### Блок "Товар" в Конструкторе

- Два режима: **слайдер** (листание в одном сообщении) или **блоки** (отдельные сообщения)
- Добавление: по отдельности или целой категорией
- Товары не дублируются даже при добавлении разными способами

### Блок "Товар" в мини-приложениях

- Расположение и количество в ряду
- Поиск по товарам
- Фильтры по характеристикам
- Избранные товары
- Рекомендации: "Товары добавить" (допродажи) и "Покупают вместе" (категории)

## Корзина, доставка, оплата

### Корзина

- Команда "Корзина" -- можно вызвать кнопкой или переходом
- Пользователь видит выбранные товары, количество, сумму
- Может добавлять/убирать товары

### Доставка

- Древовидные варианты с подвариантами:
  ```
  Доставка:
    Курьер (+ форма ввода адреса)
    Самовывоз:
      Адрес 1
      Адрес 2 (со скидкой на доставку)
    Без доставки (для электронных товаров)
  ```
- Изменение стоимости чека: понизить/повысить сумму
- Форма ввода "Выбор адреса" -- системная в командах доставки
- Ответы из форм ввода попадают в чек

### Оплата

- Древовидные варианты:
  ```
  Оплата:
    Наличный расчёт:
      Нужна сдача
      Без сдачи
    Безналичный расчёт
  ```
- Галочка **"Завершить оформление заказа без оплаты"** -- для оплаты вне бота
- Изменение суммы чека у вариантов

### Настройки магазина

| Параметр | Описание |
|----------|----------|
| Время/дни работы | Ограничение часов приёма заказов |
| Скрытие при нулевых остатках | Товар не показывается, если 0 |
| Отображение остатка | Показывать количество |
| Мин/макс сумма | Минимальная/максимальная сумма для оформления |
| Мин/макс количество | Ограничение позиций в заказе |
| Резервирование | Товары вычитаются из остатков при нажатии "Оформить" |
| Статус заказа | Этапы обработки с оповещением о смене |

### Заказы (4 состояния)

1. **Ожидают оплаты** -- заказ оформлен, оплата не поступила
2. **В процессе** -- оплата получена, администратор может изменить заказ
3. **Завершённый** -- заказ выполнен
4. **Отменённые** -- заказ отменён

## Промокоды и скидки

### Создание акции

1. Вкладка Магазин -> **Акции** -> создать
2. Тип: **Скидка** (автоматическая) или **Промокод** (вводится пользователем)
3. Для промокода: **общая фраза** или **генерация уникальных**

### Условия акции (все / одно из)

| Условие | Описание |
|---------|----------|
| Категория пользователя | Только для определённой категории |
| Сумма товаров | От/до определённой суммы |
| Количество позиций | Минимум/максимум товаров в корзине |
| Конкретный товар | Только при наличии определённого товара |
| Категория товаров | Только для товаров из категории |

### Действия акции

- **Изменение стоимости** -- отдельно для товаров, доставки или оплаты (понизить/повысить на сумму или %)
- **Добавление бесплатного товара** -- подарок к заказу
- **Дата отключения** -- автоматическое отключение
- **Количество использований** -- лимит

### Суммирование и приоритет

- **Суммирование** -- несколько акций складываются
- **Замена** -- новая акция заменяет текущую (с учётом приоритета)
- Приоритет: если новая акция имеет более низкий приоритет, действующая не заменяется

### Бейдж акции

На карточках товаров-участников акции отображается бейдж (текст или переменная). Автоматически скрывается, если переменная пуста.

### Важно

- Акция создаётся **выключенной** -- не забыть включить
- Промокод применяется к сумме **товаров**, но не к доставке (если не настроено иначе)

## Мультивалютный магазин

### Настройка

1. Вкладка Магазин -> включить -> выбрать **несколько валют** (например, рубли + доллары)
2. При создании товара: указать цену **в каждой валюте**
3. Команда "Выбор валюты" -- автоматически создаётся при включении мультивалютности

### Экспорт/импорт товаров

- Меню с тремя точками на странице товаров
- Формат: **CSV**
- Позволяет массово добавлять/обновлять товары

---

## Лимиты дохода

- Лимит дохода зависит от **тарифа PuzzleBot**
- Лимит указан на странице Тарифов
- Сбрасывается **1 числа каждого месяца**
- Ошибка 80 = превышен лимит дохода
- Решение: перейти на более высокий тариф или дождаться 1 числа
