# 05. Сценарии и автоматизация

## Обзор

Сценарии (вкладка "Автопостинг" / "Сценарии") -- инструмент для автоматической отправки сообщений каждому пользователю по индивидуальному расписанию, отсчитываемому от момента запуска сценария. В отличие от Постинга, где пост получают все одновременно, в Автопостинге каждый пользователь получает посты по личному таймеру.

---

## Создание сценария

### Шаги

1. Перейти на вкладку **Автопостинг** (Сценарии)
2. Нажать **Добавить сценарий**, открыть его
3. Настроить параметры:
   - **Автоотключение** -- сценарий отключается после выполнения всех постов
   - **Количество прохождений** -- сколько раз пользователь может пройти сценарий
   - **Перезапуск при повторном вызове** -- обнуляет все таймеры и начинает заново
4. Добавить посты, настроить тип отправки
5. Переключить статус поста из выключенного во включённый
6. Активировать сценарий

### Важно

- Сценарий создаётся **выключенным** по умолчанию -- не забыть активировать
- Пост также **выключен** по умолчанию -- переключить в "Запланирован"
- Время указывается по часовому поясу **владельца бота**, а не пользователя

### Навигация к сценариям (из OCR)

**URL:** `cp.puzzlebot.top` -> вкладка `Автопостинг` (Сценарии) в левом меню
- Кнопка: **Добавить сценарий**
- Настройки: Автоотключение, Количество прохождений, Перезапуск при повторном вызове
- Управление из конструктора: действие `Изменить сценарий` (тумблер вправо = запуск, влево = стоп)

---

## Типы отправки постов

| Тип | Описание | Пример |
|-----|----------|--------|
| **Сразу** | Отправляется немедленно при запуске сценария | Приветствие после оплаты |
| **Через** (от начала) | Через X дней, Y часов, Z минут от старта сценария | Напоминание через 3 дня |
| **Через** (в точное время) | Через X дней в HH:MM | Через 2 дня в 10:00 |
| **Точная дата** | Конкретная дата и время | 15.03.2026 в 12:00 |

---

## Повторение постов

В дополнительных настройках поста:

- **По дням недели** -- выбрать конкретные дни (Пн, Ср, Пт)
- **Через количество дней** -- повторять каждые N дней
- **Ограничение повторов** -- максимальное количество повторений

Пример: пост через 28 дней с повторением каждый 1 день, лимит 1 повтор = напоминание на 28-й и 29-й день.

---

## Задержки и таймеры

### Блок Тайм-аут (в Конструкторе)

Вставляется между блоками команды для паузы:

- Время задержки: от 1 секунды
- Индикатор: "печатает...", "загружает фото..." и др.
- Создаёт ощущение живого общения

### Таймеры в сценариях

Каждый пост имеет свой таймер от момента запуска сценария. Таймеры сбрасываются при перезапуске.

---

## Управление сценариями из Конструктора

### Действие "Изменить сценарии"

Добавляется в разделе **Действия** команды:

- **Тумблер направо** = запустить (активировать) сценарий
- **Тумблер налево** = остановить (деактивировать) сценарий

### Последовательность выполнения

- **До** -- действие выполняется до отправки блоков команды
- **После** -- действие выполняется после отправки блоков

Для управления сценариями рекомендуется последовательность **До**.

---

## Цепочки сообщений (автоворонки)

### Принцип

Серия постов с нарастающим временем отправки, образующая воронку:

```
Пост 1: Сразу         -> "Добро пожаловать!"
Пост 2: Через 1 день  -> "Полезный контент"
Пост 3: Через 3 дня   -> "Кейс / отзыв"
Пост 4: Через 5 дней  -> "Спецпредложение"
Пост 5: Через 7 дней  -> "Последний шанс"
```

### Дополнительные настройки поста

- **Добавить категорию** -- присвоить/сбросить категорию пользователю
- **Изменить сценарий** -- запустить/остановить другой сценарий
- **Для категорий** -- фильтрация: отправлять только определённым категориям
- **Действие в ресурсах** -- выполнить действие в группе/канале
- **Переход к команде** -- автоматический переход к команде после поста

## Напоминания

### Напоминание о невыполненном действии

1. В команде "Старт" добавить действие "Изменить сценарии" -> **активировать**
2. Создать сценарий с постом типа "Через" (например, 1 час)
3. Написать текст напоминания
4. В целевой команде добавить действие "Изменить сценарии" -> **деактивировать**
5. Логика: если пользователь выполнил действие -- сценарий остановлен; если нет -- напоминание приходит

### Ежедневные/еженедельные напоминания

- Пост с повторением: каждый 1 день (ежедневно) или каждые 7 дней (еженедельно)
- Снять галочку **"Завершить после выполнения всех постов"** для бесконечного повторения
- Включить **"Перезапуск при повторном вызове"** для обнуления при активности

### Автонапоминание о бездействии ("пуш")

1. Сценарий с постом "Через 7 дней"
2. Перезапуск при повторном вызове = ВКЛ
3. Запуск сценария в ключевых командах бота
4. Если пользователь активен -- сценарий перезапускается, таймер сбрасывается
5. Если неактивен 7 дней -- придёт напоминание

## Пароли и ограничение доступа

### Через инлайн-команду

1. Создать инлайн-команду с названием = **нужный пароль** (точное совпадение текста)
2. В команде: текст подтверждения + действие "Добавление в категорию"
3. Создать вторую группу команд с доступом только для этой категории
4. Настроить переход через задержку 2 сек в защищённую группу

Любой текст кроме точного пароля просто игнорируется.

### Через группы команд

1. Создать группу команд
2. В настройках группы задать доступ только для определённых категорий
3. Пользователи без категории не видят команды и не могут их вызвать
4. Событие "Нет доступа" редактируется во вкладке **События**

## Реакции на события (вкладка События)

### Доступные события бота

| Событие | Описание |
|---------|----------|
| Неизвестная команда | Пользователь написал текст, не совпадающий ни с одной командой |
| Начало диалога | Пользователь начал диалог с поддержкой |
| Завершение диалога | Диалог завершён |
| Пользователь остановил бота | Нажал "Остановить" в Telegram |
| Нет доступа | Попытка вызвать команду из закрытой группы |

### Доступные события ресурса

| Событие | Описание |
|---------|----------|
| Заявка на вступление | Пользователь подал заявку в закрытый канал/группу |
| Пользователь подписался | Новый подписчик ресурса |
| Пользователь отписался | Подписчик покинул ресурс |
| Новый пост в канале | Опубликован новый пост |

### Настройка реакции

1. Перейти на вкладку **События** (бота или ресурса)
2. Активировать нужное событие
3. Выбрать тип действия: **Команда/Условие**
4. Указать команду или условие для выполнения
5. В дополнительных настройках можно ограничить по категориям

## Условные сценарии

### Условие + сценарий

Сценарий может запускать проверку условий через действие поста:

1. Пост сценария вычитает 1 из переменной "Дни подписки" (последовательность "До")
2. Затем отправляет условие для проверки
3. Условие: если дни = 2 -> напоминание; если дни = 0 -> блокировка

### Зацикленный сценарий

- Тип отправки: **Через** (минимум 1 минута, не "Сразу"!)
- Снять галочку "Завершить после выполнения всех постов"
- Перезапуск при повторном вызове = ВКЛ
- Пост отправляет условие, которое может снова запустить сценарий

---

## Триггеры в группах/каналах

### Настройка

1. Перейти в подключённую группу -> вкладка **Триггеры**
2. Создать триггер:
   - **Тип сообщения**: Все / Текст / Медиа
   - **Условие**: "Сообщение содержит" + фразы
   - **Длина**: ограничение символов (> 0, < 5 и т.д.)
3. Действие: удалить сообщение / отправить текст / изменить переменную / отправить условие

### Параметр "Для категории"

В дополнительных настройках триггера: отключить тумблер для категорий, которые **не** попадают под триггер. Принцип исключения: триггер работает для всех, **кроме** отключённых категорий.

### Триггер начисления баллов

- Тип: "Ответы" с условием "Сообщение содержит" (фразы благодарности)
- Действие: изменить переменную (+баллы) + отправить уведомление (удаление через 5 сек)
- Галочка "Выполнить для пользователя, получившего ответ" -- критична

## Примеры готовых решений

### Воронка продаж

```
Сценарий "Воронка":
  Пост 1 (Сразу): Приветствие + полезный контент
  Пост 2 (Через 1 день): Кейс клиента
  Пост 3 (Через 3 дня): Спецпредложение -20%
  Пост 4 (Через 5 дней): Дедлайн скидки
  Пост 5 (Через 7 дней): Последний шанс
```

### Онбординг нового пользователя

```
Сценарий "Онбординг":
  Пост 1 (Сразу): Добро пожаловать! + инструкция
  Пост 2 (Через 30 минут): Первый шаг
  Пост 3 (Через 1 день): Советы и фишки
  Пост 4 (Через 3 дня): Опрос удовлетворённости
```

### Платная подписка (30 дней)

```
Сценарий "Подписка":
  Перезапуск при повторном вызове = ВКЛ
  Пост 1 (Сразу): "Подписка активирована"
  Пост 2 (Через 28 дней, повтор 1 день, лимит 1): Напоминание
  Пост 3 (Через 30 дней): Сброс категории в "Без категории" + блокировка
```

### Автоответчик при бездействии

```
Сценарий "Автоответ":
  Перезапуск = ВКЛ
  Запуск: в событии "Начало диалога"
  Пост 1 (Через 10 минут): Проверка условия -> если диалог активен -> повторное уведомление админу
  Деактивация: в событии "Завершение диалога"
```

### Ежечасная энергия (геймификация)

```
Сценарий "Энергия":
  Перезапуск = ВКЛ
  Снять "Завершить после выполнения"
  Пост 1 (Через 1 час): Действие "Изменить переменную" +5 энергии
  Повторение: каждый 1 час
```
