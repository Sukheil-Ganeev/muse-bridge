# 11. Постинг

## Вкладка Posting (полный обзор)

Вкладка **Постинг** -- инструмент для создания, планирования и управления публикациями в боте и подключённых ресурсах.

### Интерфейс

- **Левая панель**: список постов с фильтрами и датами. Рядом с датой -- количество постов
- **Правая панель**: модальное окно редактирования поста
- **Фильтры**: отправленные, в очереди, черновики + фильтр по дате

### Создание поста

1. Кнопка **Создать новый пост**
2. Модальное окно: добавить блоки (текст, медиа, инлайн-кнопки, опрос, викторина)
3. Блоки работают так же, как в конструкторе -- текстовый блок, изображения, видео, документы
4. Кнопки: только **инлайн-клавиатура** (обычную клавиатуру прикрепить нельзя)

### Настройки поста

- **Место отправки**: бот, один или несколько ресурсов (каналов/групп)
- **Дата/время публикации**: конкретное время или отправка немедленно
- **Категории/Аудитории**: фильтрация получателей (только при отправке в бот)
- **Защита от пересылки/сохранения**: запрет копирования контента
- **Отправка без уведомления**: пост приходит без звукового сигнала
- **Повторение**: автоматическая публикация по расписанию

### Статусы поста

- **Запланировать** -- пост уйдёт в очередь в указанное время
- **Черновик** -- сохранить без планирования
- **Отправить сейчас** -- немедленная публикация
- **Предпросмотр** -- проверить вид поста перед отправкой
- **Удалить** -- убрать пост

Для доступа к постингу ресурса: его нужно сначала подключить к боту.

---

## Публикация в несколько каналов одновременно

PuzzleBot позволяет отправить один пост сразу в несколько ресурсов.

### Шаги

1. Открыть бота, к которому подключены несколько каналов/групп
2. Перейти в любой ресурс > вкладка **Постинг** (или общий **Постинг** бота)
3. Создать новый пост: добавить текст, медиа, кнопки
4. В разделе **Места для отправки**: выбрать несколько ресурсов (отметить галочками)
5. Можно дополнительно выбрать **Бот** -- пост уйдёт и в ресурсы, и подписчикам бота
6. Сохранить и нажать **Отправить сейчас** (или запланировать)

Один пост -- множество каналов. При редактировании изменения применяются **ко всем ресурсам**, куда пост был отправлен.

## Реакции на постах

Кнопки-реакции добавляют интерактивность к постам.

### Создание реакций

1. В посте добавить **инлайн-клавиатуру**
2. Для каждой кнопки: тип действия **Реакция**
3. Вписать эмодзи реакции в поле значения (каждая кнопка -- своя реакция)
4. Сохранить пост

### Результат

- Под постом появляются кнопки с эмодзи
- При нажатии -- счётчик реакции увеличивается
- Пользователь может нажать одну из доступных реакций

Реакции работают и в боте, и в ресурсах. Эмодзи вписываются как текст в поле значения кнопки.

## Расписание публикаций

### Планирование отдельного поста

1. Создать пост
2. Выбрать дату и время публикации
3. Нажать **Запланировать**
4. Пост появится в фильтре **В очереди**

### Повторяющиеся публикации

1. В дополнительных настройках поста включить **Повторение**
2. Выбрать интервал: каждый день / каждую неделю / каждый месяц
3. Для еженедельных: выбрать конкретный день недели
4. Указать время отправки

Пост будет автоматически публиковаться по расписанию.

### Автоматическая публикация с действиями

Для сложных сценариев (например, еженедельный лидерборд):

1. Создать пост с датой/временем
2. В допнастройках добавить **повторение** и выбрать день недели
3. В **Действиях** поста: **Отправить команду или условие** > указать команду
4. Команда выполняет нужную логику (сбор данных, формирование текста) и отправляет результат
5. Выбрать место отправки: группу или конкретную тему (топик) в форуме

## Черновики

Черновики позволяют подготовить посты заранее без планирования.

### Работа с черновиками

1. Создать пост, заполнить содержимое
2. Нажать **Черновик** вместо "Запланировать"
3. Пост сохраняется в фильтре **Черновики**
4. В любой момент: открыть черновик > дополнить > **Запланировать** или **Отправить сейчас**

### Дублирование постов

Любой пост (отправленный, в очереди, черновик) можно **дублировать**:
- Создаётся копия поста для повторного использования
- Удобно для типовых рассылок с небольшими изменениями

---

## Редактирование опубликованных постов

Уже отправленные посты можно редактировать.

### Шаги

1. В фильтре **Отправленные** найти нужный пост
2. Кликнуть на миниатюру поста
3. Изменить текст в текстовых блоках
4. Нажать **Опубликовать изменения**

### Ограничения

- Можно **изменять текст** существующих блоков
- **Нельзя добавлять** новые блоки к уже отправленному посту
- При отправке в несколько ресурсов: изменения применяются **ко всем** ресурсам одновременно
- Кнопки инлайн-клавиатуры также можно редактировать

## Опросы и квизы

Опросы и викторины -- **уникальные блоки постинга**, недоступные в конструкторе команд.

### Опрос (Poll)

1. В посте добавить блок **Опрос**
2. Ввести вопрос
3. Добавить варианты ответов
4. Настроить: анонимный / не анонимный, множественный выбор

### Викторина (Quiz)

1. В посте добавить блок **Викторина**
2. Ввести вопрос
3. Добавить варианты ответов
4. **Отметить правильный ответ**
5. При ответе пользователь видит, правильно ли он выбрал

### Особенности

- Опросы и квизы отправляются **как отдельные сообщения** (не объединяются с текстом)
- Работают в боте и в ресурсах
- Результаты видны в Telegram (встроенная статистика)
- Эти блоки доступны **только в постинге**, не в конструкторе команд

## Действия при публикации

К каждому посту можно привязать **действия**, которые выполняются при публикации.

### Доступные действия

| Действие | Описание |
|----------|----------|
| **Отправить команду или условие** | Запустить команду конструктора для каждого получателя |
| **Смена категории** | Автоматически добавить/убрать категорию получателям |
| **Закрепление** | Закрепить пост в чате/канале |
| **Удаление** | Удалить пост через указанное время |

### Пример: еженедельный топ

1. Создать команду, которая формирует лидерборд (записывает переменные из NoCode, форматирует текст)
2. В постинге: создать пост > в **Действиях** > **Отправить команду или условие** > указать команду лидерборда
3. Выбрать место отправки (группа/топик)
4. Включить повторение (раз в неделю, конкретный день)

Действие выполняется **до** отправки поста, если в настройках действия указана последовательность **До**. Это позволяет сначала собрать данные, а потом отправить сформированный контент.

### Пример: рассылка с условием

1. Пост с действием **Отправить условие**
2. Условие проверяет подписку на канал
3. Если подписан -- ничего
4. Если нет -- отправить сообщение с предложением подписаться

Так можно напоминать отписавшимся о канале через рассылку бота.
