# 12. Баллы и геймификация

## Начисление баллов за активность в группе

Автоматическое начисление баллов участникам группы за сообщения, ответы, медиа, стикеры.

### Необходимые элементы

- **Персональная переменная** "Баланс" (число, по умолчанию 0)
- **Глобальная переменная** "Учёт баллов" (число, 0) -- для общего отслеживания
- **Таблица NoCode** с полями: имя пользователя, баллы (число)
- **Триггеры** в ресурсе для реакции на сообщения
- **Условие** с проверкой строки в NoCode (обновить или создать запись)

### Шаги настройки

1. Создать таблицу в **NoCode** с полями: имя пользователя, баллы (число)
2. Создать персональную переменную **Баланс** (число, 0)
3. Создать глобальную переменную **Учёт баллов** (число, 0)
4. Создать **Условие**: проверка строки в NoCode по User ID (полное совпадение)
   - Если строка найдена: действие **Обновить строку** (прибавить баллы)
   - Если не найдена: действие **Создать строку** (новая запись)

### Настройка триггеров

В ресурсе (группе) > **Триггеры** > **Добавить триггер**:

1. **Триггер на благодарность**: тип **Ответы**, условие **Сообщение содержит** (фразы: "спасибо", "благодарю", "помог")
2. Действия триггера:
   - **Изменить персональную переменную** (Баланс, прибавить N баллов)
   - **Изменить глобальную переменную** (Учёт баллов, прибавить N)
   - **Отправить уведомление** (текстовое сообщение с подтверждением, **удаление через 5 секунд**)
   - **Отправить условие** в Bot (для обновления NoCode)

### Навигация к триггерам (из OCR)

```
Ресурс (группа) → Триггеры → Добавить триггер
  Тип сообщения: Все / Текст / Ответы
  Тип условия: Сообщение содержит → [фразы]
  Тип действия: Изменить переменную / Текстовое сообщение / Отправить условие
  Настройки: Для категории (включить/исключить)
```

### Критически важные настройки

- Галочка **Выполнить для пользователя, получившего ответ** -- без неё баллы начисляются не тому пользователю
- Можно ограничить **время до повторного срабатывания** (защита от спама)
- Можно ограничить **количество срабатываний** на пользователя за период

### Виды активности для начисления

| Активность | Триггер | Баллы |
|------------|---------|-------|
| Ответ с благодарностью | Сообщение содержит "спасибо" | +10 |
| Текстовое сообщение | Любой текст в группе | +1 |
| Медиа-контент | Фото/видео в группе | +3 |
| Стикер | Стикер в группе | +1 |
| Ответ на вопрос | Тип "Ответы" | +5 |

## Ручное начисление баллов админом через NoCode таблицу

Администратор может начислять баллы вручную через скрытую кнопку в боте.

### Элементы

- **Категория модерации** для доступа к кнопке начисления
- **Глобальная переменная** для ручного начисления (число, 0)
- **Форма ввода** с вариантами фиксированных сумм
- Действие **Отправить команду другому пользователю**
- **Кнопка-условие** для скрытия от обычных пользователей

### Шаги

1. Создать глобальную переменную **Ручное начисление** (число, 0)
2. В **Модерации** создать категорию доступа к начислению, назначить администратору
3. Создать **инлайн-команду начисления**:
   - Действие **Изменить переменную** (Баланс + глобальная переменная)
   - Текстовый блок с уведомлением
   - Кнопка возврата в **Личный кабинет**
4. Создать команду с **формой ввода** (выбор суммы из фиксированных вариантов: 10, 50, 100 баллов)
   - Добавить вариант **Отмена** с **поп-апом** (для выхода без действия)
5. Вторая форма ввода: ввод **юзернейма** пользователя (тип **Отправка сообщения**)
6. Текстовый блок подтверждения (сумма + юзер) > инлайн-кнопки **Подтвердить** / **Отмена**
7. Команда подтверждения: **тайм-аут 3 сек** > действие **Отправить команду начисления другому пользователю** (по юзернейму из переменной)
8. **Кнопка-условие** в личном кабинете: проверка категории модерации > показать / скрыть

Пользователь получает уведомление о начислении автоматически. Кнопка скрыта от обычных пользователей.

## Списание баллов за доступ к контенту

Пользователь "покупает" контент за внутренние баллы, получая постоянный доступ через категорию.

### Логика кнопки-условия (3 уровня)

| Правило | Проверка | Действие |
|---------|----------|----------|
| 1 | Наличие категории "Доступ к продукту" | Сменить название кнопки, перейти к контенту (уже куплено) |
| 2 | Баланс >= цена продукта | Списать баллы, активировать категорию, перейти к контенту |
| Исключающее | Баллов недостаточно | **Скрыть кнопку** |

### Шаги

1. В **Модерации** создать категории доступа (например, "Доступ к гайду", "Доступ к уроку")
2. Создать **инлайн-команды** для каждого продукта (гайд, урок)
3. Для каждого продукта создать **кнопку Условия**:
   - **Правило 1**: проверка наличия категории > если есть -- сменить название кнопки на "Открыть" + перейти к контенту
   - **Правило 2**: проверка переменной Баланс >= стоимость > **Изменить переменную** (вычесть баллы) + **Изменить категорию** (активировать доступ) + перейти к контенту
   - **Исключающее правило**: действие **Скрыть кнопку** (баллов недостаточно)
4. Добавить кнопки-условия в **личный кабинет** (инлайн-команду)

После покупки кнопка автоматически меняет название и ведёт сразу к контенту (без повторного списания).

## Внутренний баланс (начисление за подписку, анкету и т.д.)

Система внутреннего баланса с начислением баллов за выполнение заданий.

### Создание системы

1. Создать персональную переменную **Баланс** (формат: число) во вкладке **Переменные**
2. Создать категории-флаги: "Баллы за подписку", "Баллы за анкету" и т.д. (во вкладке **Модерация**)

### Начисление за подписку на канал

1. Создать **Условие**: проверка **Наличие подписки** на ресурс
2. При подписке: **Изменить переменную** (Баланс, прибавить N баллов) + **Изменить категорию** (активировать "Баллы за подписку") + показать результат
3. Без подписки: предложить подписаться

### Начисление за анкету

1. Создать **мини-приложение** с формой ввода (анкета)
2. Команда результата: **Изменить переменную** (Баланс, прибавить N баллов) + **Изменить категорию** ("Баллы за анкету")

### Динамический личный кабинет

Личный кабинет с текстом (баланс через переменную `{{Баланс}}`) + кнопки-условия для заданий.

**Кнопка-условие для каждого задания:**
- Проверка категории (флаг выполнения): если есть -- **скрыть кнопку** (задание выполнено)
- Если нет -- показать кнопку с инлайн-командой задания

Кнопка типа **Условия** -- мощный инструмент для динамического UI: задания, которые пользователь выполнил, исчезают из списка.

## Лидерборд: форматирование с MatchAll, эмодзи, медали

### Создание интегрированной переменной для топа

1. Создать **интегрированную переменную** "Топ":
   - Тип: **глобальный**
   - Интеграция: **NoCode** (или Google Sheets)
   - Выбрать базу/таблицу
   - Сортировка: **по убыванию** (по столбцу баллов)
   - Лимит: **3** (или сколько мест нужно)
   - **Шаблон**: `{{Имя}} -- {{Баллы}} баллов`
   - **Разделитель**: перенос строки

### Разбор топа на отдельные переменные с MatchAll

Для красивого оформления с медалями нужно разбить общий топ на строки:

1. Создать глобальные переменные **ТОП1**, **ТОП2**, **ТОП3** (текстовый формат)
2. В команде: действие **Изменить переменную** для каждой:
   - ТОП1 = `MatchAll({{Топ}}, "/(.*?)(?:\n|$)/", 0)` -- группа 0 (первая строка)
   - ТОП2 = `MatchAll({{Топ}}, "/(.*?)(?:\n|$)/", 1)` -- группа 1 (вторая строка)
   - ТОП3 = `MatchAll({{Топ}}, "/(.*?)(?:\n|$)/", 2)` -- группа 2 (третья строка)
3. Последовательность выполнения: **До** (сначала вычислить, потом отобразить)

### Регулярное выражение подробно

`/(.*?)(?:\n|$)/`
- `.` -- любой символ
- `*?` -- минимальное количество (ленивый поиск)
- `(?:\n|$)` -- не сохраняемая группа (перенос строки ИЛИ конец текста)
- Знак `$` нужен, чтобы последняя строка тоже корректно считалась
- **Нумерация групп начинается с 0**, а не с 1

### Оформление с медалями

В текстовом блоке:
```
Топ участников недели

1. {{ТОП1}}
2. {{ТОП2}}
3. {{ТОП3}}
```

Добавьте изображение (баннер) перед текстом для визуального оформления.

## Еженедельная автоотправка топа

### Настройка через постинг

1. Перейти в **Постинг**, создать пост
2. Указать дату и время первой отправки
3. В дополнительных настройках: включить **повторение**, выбрать день недели
4. В **Действиях** поста: **Отправить команду или условие** > указать команду формирования топа
5. Выбрать место отправки: группу или конкретную **тему (топик)** в форуме
6. Запланировать пост

### Последовательность выполнения

1. Пост запускается по расписанию (раз в неделю)
2. Действие **Отправить команду** выполняется
3. Команда записывает текущий топ из NoCode в переменные ТОП1-ТОП3
4. Формирует текстовый блок с оформлением
5. Отправляет в группу/топик

## Чекбоксы через переменные (toggle on/off)

Переключаемые кнопки (чекбоксы) через переменные с иконками.

### Принцип работы

- Переменная хранит иконку: галочка (выбрано) или пусто (не выбрано)
- При нажатии кнопки значение переключается на противоположное
- Инлайн-команда перезагружается для обновления вида

### Шаги

1. Создать переменные **Icon1**, **Icon2** (текст, значение по умолчанию -- иконка галочки)
2. Создать **инлайн-команду** с текстовым блоком
3. Для каждой кнопки создать **кнопку Условия**:
   - Проверка значения Icon1: если галочка -- сменить на пустое + отправить инлайн-команду
   - **Исключающее правило**: сменить на галочку + отправить инлайн-команду
4. В инлайн-команде добавить кнопки типа **Кнопка условия**
5. Название кнопки содержит переменную: `{{Icon1}} Пункт 1`

### Режим радиокнопок (только один выбор)

Для режима "только одна галочка":
- В **исключающем правиле** каждой кнопки: при установке галочки добавить **сброс всех остальных переменных** (установить пустое значение)
- Результат: при активации одной кнопки все остальные автоматически деактивируются

### Обновление отображения

При нажатии:
1. Переменная меняет значение (галочка / пусто)
2. Действие **Отправить инлайн-команду** перезагружает текущее сообщение
3. Кнопки отображаются с обновлёнными иконками

## Реферальная система (начисление за приглашение)

### Настройка реферальной ссылки

1. Вкладка **Вход** > **Добавить ссылку** > **Реферальная система**
2. Настроить параметры: категория при входе, количество переходов
3. Запустить ссылку

### Переменные для реферальной системы

Системные переменные реферальной системы:
- Переменная с **ссылкой** (вставляется в текстовый блок для пользователя)
- Переменная **юзернейм создателя последней активированной реферальной ссылки** (глобальная)

### Начисление баллов за приглашение

1. Создать переменные: **Баланс** (общий) + **Баланс за рефералов** (отдельный подсчёт)
2. В команде при входе нового пользователя по реферальной ссылке:
   - **Изменить переменную** Баланс реферера (прибавить N баллов)
   - Действие **Отправить команду другому пользователю** (через глобальную переменную юзернейма реферера)
3. В отправленной команде: уведомление рефереру "По вашей ссылке зарегистрировался новый пользователь! +N баллов"

### Продвинутый вариант с условием

1. Создать условие: проверка -- набрал ли реферал определённый порог бонусов
2. Если набрал: отправить команду рефереру с награждением (например, доступ к закрытому контенту)
3. Если не набрал: ничего (или промежуточное уведомление о прогрессе)

### Формула для реферальной ссылки

Извлечение ID реферера из startPayload:
```
match(startPayload, "PB(.*)")
```

### Одноразовая реферальная ссылка

Для генерации уникальных одноразовых ссылок (например, платный доступ):
1. Вкладка **Вход** > **Реферальная система**
2. Установить **количество переходов = 1**
3. Вставить переменную ссылки в текстовый блок после оплаты
4. Каждому пользователю генерируется уникальная ссылка, которая работает однократно

## Формулы для геймификации

### Расчёты в тексте без переменных

```
{{= выражение =}}
```

Примеры:
- `{{= {{Баланс}} * 10 =}}` -- баланс умноженный на 10
- `{{= {{Баланс}} - 50 =}}` -- вычитание стоимости
- `{{= if {{Баланс}} > 100 ; "VIP" ; "Стандарт" =}}` -- условный текст

### Склонение слов по числу

```
plure({{Баланс}}, "балл", "балла", "баллов")
```
Возвращает число + правильно склонённое слово: "1 балл", "3 балла", "10 баллов".

### Случайное число

```
random(1, 100)
```
Генерация случайного числа для розыгрышей, случайных наград, квизов.

### Форматирование чисел

```
numberFormat({{Баланс}}, 0, ".", " ")
```
Результат: `1 234` вместо `1234`. Параметры: знаки после запятой, разделитель дробной части, разделитель тысяч.

### Округление

- `round({{переменная}}, 2)` -- до 2 знаков после запятой
- `ceil({{переменная}})` -- вверх до целого
- `floor({{переменная}})` -- вниз до целого
