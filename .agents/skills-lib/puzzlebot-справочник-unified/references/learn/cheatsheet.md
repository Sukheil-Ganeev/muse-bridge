## 2. Формулы и выражения

### Математические

| Формула | Описание | Пример |
|---------|----------|--------|
| `round(x, n)` | Округление до n знаков | `round({{price}}, 2)` |
| `ceil(x)` | Округление вверх | `ceil(3.2)` = 4 |
| `floor(x)` | Округление вниз | `floor(3.8)` = 3 |
| `random(min, max)` | Случайное число | `random(1, 100)` |
| `numberFormat(x, dec, sep_dec, sep_th)` | Форматирование числа | `numberFormat(1234.5, 2, ".", " ")` = 1 234.50 |

### Работа с датами

| Формула | Описание | Пример |
|---------|----------|--------|
| `CurrentDate` | Текущая дата | -- |
| `currentTimestamp` | Текущий timestamp | -- |
| `AddDate(date, days)` | Прибавить дни | `AddDate(CurrentDate, 30)` |
| `ADD_DAYS(date, n)` | Прибавить дни | `ADD_DAYS("03.09.2023", 4)` |
| `ADD_HOURS(date, n)` | Прибавить часы | `ADD_HOURS(date, -2)` (вычитание) |
| `ADD_MONTHS(date, n)` | Прибавить месяцы | `ADD_MONTHS(date, 1)` |
| `ADD_MINUTES(date, n)` | Прибавить минуты | -- |
| `DaysBetween(d1, d2)` | Разница в днях | `DaysBetween(date1, date2)` |
| `DAYS_BETWEEN(d1, d2)` | Разница в днях | `DAYS_BETWEEN("15.09", "11.09")` |
| `DateFormat(date, fmt)` | Форматирование даты | `DateFormat(date, "D F Y")` |
| `DATE_FORMAT(date, fmt)` | Форматирование даты | `DATE_FORMAT(date, "d F Y")` |

**Символы формата даты:** `D` = день, `m` = номер месяца, `M` = месяц кратко, `F` = месяц полностью, `Y` = год

### Работа с текстом

| Формула | Описание | Пример |
|---------|----------|--------|
| `plure(n, s1, s2, s3)` | Склонение по числу | `plure({{days}}, "день", "дня", "дней")` |
| `match(str, regex)` | Извлечь часть строки | `match({{startPayload}}, "PB(.*)")` |
| `match_all(str, regex, n)` | Все совпадения, n-ное | `match_all({{var}}, "/(.*?)(?:\n\|$)/", 0)` |
| `replace(str, old, new)` | Замена подстроки | `replace({{text}}, "а", "А")` |
| `if cond ; val1 ; val2` | Условная подстановка | `{{=if {{x}} > 5 ; "да" ; "нет"}}` |

### Формулы прямо в тексте

```
{{= выражение =}}
```

Позволяет делать расчеты без создания отдельных переменных.

Примеры:
- `{{= {{price}} * {{quantity}} =}}` -- расчет стоимости
- `{{= round({{balance}} / 100, 2) =}}` -- конвертация
- `{{= if {{x}} > 5 ; {{sfera1}} ; {{sfera2}} =}}` -- условие

## 4. Маски ввода

| Маска | Описание | Пример |
|-------|----------|--------|
| Текст | Любой текст | -- |
| Число | Только числа | 123.45 |
| Телефон | Формат телефона | +7 999 123-45-67 |
| Почта (Email) | Валидация email | user@mail.com |
| Ссылка | Валидация URL | https://... |
| Изображение | Загрузка картинки | File ID |
| Крипто-кошелек | Адрес кошелька | -- |
| Регулярное выражение | Кастомная валидация | См. ниже |

### Частые regex-паттерны

| Данные | Регулярное выражение |
|--------|---------------------|
| ФИО (рус.) | `^[А-ЯЁ][а-яё]+\s[А-ЯЁ][а-яё]+\s[А-ЯЁ][а-яё]+$` |
| Дата ДД.ММ.ГГГГ | `^(0[1-9]\|[12][0-9]\|3[01])\.(0[1-9]\|1[0-2])\.(19\|20)\d{2}$` |
| Телефон +7 | `^\\+7\s?\(?\d{3}\)?[\s-]?\d{3}[\s-]?\d{2}[\s-]?\d{2}$` |
| Email Gmail | `^[a-zA-Z0-9._%+-]+@gmail\.com$` |
| ИНН (10 или 12) | `^\d{10}$\|^\d{12}$` |
| Паспорт (ХХХХ ХХХХХХ) | `^\d{4}\s\d{6}$` |
| Номер карты | `^\d{4}-\d{4}-\d{4}-\d{4}$` |
| Ссылка VK | `^(https?://)?(www\.)?vk\.com/[a-zA-Z0-9_.]+$` |

## 5. Форматирование текста

| Действие | Способ |
|----------|--------|
| **Жирный** | Выделить текст -> кнопка B (или Ctrl+B) |
| *Курсив* | Выделить текст -> кнопка I (или Ctrl+I) |
| Подчеркивание | Выделить -> кнопка подчеркивания |
| ~~Зачеркивание~~ | Выделить -> кнопка зачеркивания |
| `Код` | Выделить -> кнопка код |
| Ссылка | Выделить -> кнопка ссылка -> вставить URL -> Enter |
| Цитата | Выделить -> кнопка цитаты |

**Важно:** Форматирование работает ТОЛЬКО через панель инструментов. Markdown-символы (* _ и др.) НЕ работают.

## 8. Лимиты и ограничения

| Ограничение | Значение |
|-------------|----------|
| Google Sheets: запросы | **60 запросов/минуту** |
| NocoDB: запросы | **10 запросов/секунду** |
| Telegram: caption к изображению | **1024 символа** |
| Telegram: текст сообщения | **4096 символов** |
| Telegram: оплата (встроенные) | **$1 -- $10,000** |
| Telegram: StartApp payload | **до 512 символов** |
| Название условия | **до 64 символов** |
| Slash-команда | **до 32 символов**, только латиница + цифры |
| Мини-история: размер файла | **до 50 МБ** |
| Фото для короткой ссылки | **640x360 пикселей** |
| Загрузка файлов через File ID | **до 2 ГБ** |
| Подтверждение ресурса | **в течение 20 минут** |

## 12. Синтаксис переменных

```
{{имя_переменной}}
```

- Только латиница A-Z, цифры, нижнее подчеркивание `_`
- Для числовых: операторы заменить / прибавить / вычесть
- Для текстовых: только оператор заменить (значение в кавычках)
- Интегрированные: GET-запрос (JSON) или Google Sheets / NocoDB
- Системные: редактируются только там, где созданы
