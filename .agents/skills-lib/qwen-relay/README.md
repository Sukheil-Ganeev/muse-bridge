# Qwen Relay — README

Навык консультации Qwen как внешнего советчика через Infron API.
Проверен в бою 15–16.09.2026: 10+ раундов (капчи, обход защит, глобальный план).

## Состав
- `SKILL.md` — канон: когда использовать, рабочий рецепт, правила ретрансляции.
- `references/cheatsheet.md` — шпаргалка: готовые команды и шаблоны вопросов.
- `references/faq.md` — частые вопросы.
- `references/troubleshooting.md` — что делать при 524, обрывах, 401.

## Быстрый старт
1. Прочитай `SKILL.md`.
2. Возьми шаблон вызова из `references/cheatsheet.md`.
3. Вопрос — дословно, ответ — дословно, ключ не печатать.

## Правила безопасности
- Значение ключа — только в памяти процесса, никогда в чат/код/доки/логи.
- Только free-модель `qwen/qwen3.8-27b:free` — ноль трат.
- Сырые JSON — только в persistent-пути (не `/tmp`: ребут его вычищает).
