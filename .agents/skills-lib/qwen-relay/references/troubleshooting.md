# Troubleshooting: Qwen Relay

## HTTP 524 (Cloudflare timeout)
Самая частая ошибка. Причины по вероятности:
1. Нет браузерного User-Agent → добавь `Mozilla/5.0 (Windows NT 10.0; Win64; x64)`.
2. Слишком длинная генерация → снизь max_tokens до 4000 и разбей тему.
3. Кратковременная перегрузка free-модели → подожди 2–3 минуты, повтори тот же вызов.
Диагностика: сначала крошечный probe (`say ok`, max_tokens 5). Если probe жив —
дело в размере запроса, дели его.

## HTTP 401 / invalid_api_key
- Проверяешь не тот endpoint (должен быть `api.infron.ai`, не dashscope).
- Ключ читается не из того файла (должен быть `.../Infron AI/API_KEY.txt`, строка `KEY=`).
- Проверь баланс: `GET /v1/balance` — должен ответить JSON с балансом.

## Пустой ответ / choices отсутствует
Прочитай тело ответа целиком — там JSON с `error`. Частые: rate limit
(подожди), неверное имя модели (должно быть `qwen/qwen3.8-27b:free`).

## Ответ не по теме / generic-вода
Free-модель потеряла нить (обычно в continue-хвостах). Не чинить цепочкой —
переспросить недостающее новым коротким вопросом с явным списком пунктов.

## Вызов висит >5 минут
Убей по таймауту (urllib timeout=280) и повтори. Если висят 3 подряд —
пауза 10 минут, затем probe.

## Потерял сырые ответы после ребута
`/tmp` вычищается ребутом. Всегда сохраняй JSON и тексты в persistent-пути
(проект или домашняя папка). Правило записано в SKILL.md.
