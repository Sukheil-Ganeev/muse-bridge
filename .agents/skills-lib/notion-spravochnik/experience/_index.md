## Критические уроки (топ-5)

### 1. Цены устаревают быстро
Notion провёл масштабное изменение цен в мае-августе 2025 (отмена AI add-on, унификация monthly/annual). При цитировании цен ВСЕГДА проверяй https://www.notion.com/pricing. Не полагайся на блог-посты -- они часто содержат устаревшие данные.

### 2. Database vs Data Source (API v2025-09-03)
Ключевое изменение: Database = контейнер, Data Source = схема + данные. При write-операциях используй `data_source_id`. При read-операциях API возвращает оба ID. Старые endpoints (`/databases/{id}/query`) работают, но deprecated.

### 3. Sharing = явный (explicit)
Интеграция видит ТОЛЬКО страницы/БД, явно расшаренные с ней. API НЕ имеет эндпоинта для программного шаринга. Связанные через Relation БД тоже нуждаются в sharing. Это самая частая причина 404 ошибок.

### 4. Два MCP -- один рабочий
Hosted MCP (mcp.notion.com/mcp) -- рекомендуемый и активно поддерживаемый. Open-Source (@notionhq/notion-mcp-server) -- not actively maintained, может быть sunset. Для Claude Code используй Hosted.

### 5. Webhooks -- сигнал, не данные
Webhook payload НЕ содержит фактические изменения. Это только уведомление (event type + entity ID). Для получения данных нужен follow-up API call. Доставка at-most-once -- можно потерять события.
