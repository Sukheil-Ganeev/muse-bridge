## Подводные камни

1. **`ГРУППОВЫЕ ЭКСКУРСИИ/НА САФАРИ/`** — ПУСТАЯ папка, фото сафари ищи в ИНДИВИДУАЛЬНЫХ
2. **`Instagram/`** — иконки highlights, не продуктовые фото
3. **`МОРСКОЙ КРУИЗ/`** — это dhow boats (групповая прогулка), НЕ аренда яхт
4. **`CRM системы стран/`** — 81 страна, но заполнена только ОАЭ
5. **БИЛЕТЫ/** — 232 папки, вызывает overflow метаданных, используй пагинацию
6. **Яхты для PDF/** — 250 папок, тоже overflow, используй пагинацию

## Качество и типы фото

| Суффикс/паттерн | Тип | Качество |
|-----------------|-----|---------|
| `*-topaz-sharpen.jpeg` | Улучшено Topaz AI | Лучшее |
| `*-topaz-face-upscale-2x.png` | Апскейлено Topaz AI | Высокое, ~1.7MB |
| `photo_YYYY-MM-DD_*.jpg` | Оригинал из мессенджера | Среднее, может быть личным |
| `Desert-Safari.jpg` | Продуктовое фото | Хорошее |
| `Astra Exterior 1.JPG` | HD фото яхты | Профессиональное, ~3.5MB |
