# Experience Index — Yandex Disk MCP

## Критические уроки (топ-7)

### 1. Instagram-файлы на диске = иконки highlights, НЕ фото
**Папка:** `фирменный стиль Дубаи/Instagram/`
- `11 индивидуальные.jpg` — это **иконка** с текстом "ИНДИВИДУАЛЬНЫЕ" в круге
- `11.1 индивидуальные.jpg` — та же иконка с **инвертированными цветами**
- `13 яхта.jpg` — иконка парусника, НЕ фото яхты
- **Вывод:** НЕ используй Instagram-файлы как фото продуктов

### 2. Большие папки вызывают overflow метаданных
- `get_metadata` для папок с >10 items возвращает огромный JSON
- Если результат >30K символов → автоматически сохраняется в temp-файл
- **Решение:** парси через Python: `json.load(f)[0]['text']` → `json.loads(text)` → `['_embedded']['items']`
- Кодировка файлов: UTF-8, но `print()` может не показать кириллицу → используй `sys.stdout.reconfigure(encoding='utf-8')`

### 3. Download URL временные — скачивай СРАЗУ
- URL из `get_download_url` содержат временный токен
- Срок жизни: ~30 минут
- **НЕ кэшируй** URL для повторного использования
- Скачивай через `curl -L -o "path" "URL"` сразу после получения

### 4. Правильная навигация к фото ОАЭ
**Путь:** `CRM системы стран/CRM система (ОАЭ)/`
- БИЛЕТЫ (232 папки) — аттракционы и парки
- ГРУППОВЫЕ ЭКСКУРСИИ (15 папок) — сафари, город, круизы
- ИНДИВИДУАЛЬНЫЕ ЭКСКУРСИИ (35 папок) — VIP варианты
- Фото лежат ВНУТРИ конкретных экскурсий, не в корне

### 5. Качество фото для презентаций
- `*-topaz-sharpen.jpeg` — улучшенные Topaz AI (лучшее качество)
- `*-topaz-face-upscale-2x.png` — апскейленные (большой размер ~1.7MB)
- `photo_YYYY-MM-DD_*.jpg` — оригиналы из мессенджеров (могут быть личные)
- **Проверяй фото визуально** перед использованием! Круизные фото могут быть личными кадрами клиентов

### 6. Яхты для PDF — именованные файлы (Exterior/Deck/Interior)
**Папка:** `Яхты для PDF/` — 250 яхт, каждая в своей папке
- Файлы именованы: "Astra Exterior 1.JPG", "Astra Deck 2.JPG" и т.д.
- **Exterior** — внешний вид яхты (для каталогов/карточек) ← ИСПОЛЬЗУЙ ЭТО
- **Deck** — палуба и зоны отдыха
- **Interior** — салон и каюты (как `arabian_pearl_yacht.jpg`)
- Папки с большим количеством фото: AK ROYALTY 136 FEET, AQUILA CATAMARAN 60 FEET, ASTRA 80 FEET
- **ASTRA 80 FEET** — имеет подписанные файлы (Exterior 1, Exterior 2, Deck 1-3) — лучший для поиска
- Фото HD ~3.5MB каждое, professional quality

### 7. МОРСКОЙ КРУИЗ ≠ Аренда яхты!
**Папка МОРСКОЙ КРУИЗ:** `CRM система (ОАЭ)/ГРУППОВЫЕ ЭКСКУРСИИ/МОРСКОЙ КРУИЗ/`
- Содержит фото dhow boats (арабских лодок) и каяков — это **групповая экскурсия**
- НЕ подходит для карточки "Yacht Rental" / "Аренда яхты"
- Для яхт используй папку `Яхты для PDF/` → ищи "Exterior" файлы
- **Отличие:** Морской круиз = групповой тур на деревянной лодке (150-300 AED). Яхта = приватная аренда (от 450 AED/час)
