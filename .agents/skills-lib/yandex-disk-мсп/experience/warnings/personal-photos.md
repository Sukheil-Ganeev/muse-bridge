# Warning: Круизные фото из мессенджеров могут быть личными фото клиентов

**Дата:** 2026-02-06
**Категория:** Предупреждение / Конфиденциальность
**Серьёзность:** Критическая

## Суть проблемы

На Яндекс Диске встречаются фотографии, полученные из мессенджеров (WhatsApp, Telegram). Их можно узнать по паттерну имени: `photo_YYYY-MM-DD_HH-MM-SS.jpg`. Такие фото могут быть **личными кадрами клиентов** — на них могут быть лица людей, частная обстановка, моменты отдыха.

## Как распознать

| Паттерн имени | Источник | Риск |
|--------------|---------|------|
| `photo_2024-01-15_14-30-22.jpg` | Мессенджер (Telegram/WhatsApp) | ВЫСОКИЙ — может быть личным |
| `Desert-Safari.jpg` | Продуктовое фото | Низкий |
| `Astra Exterior 1.JPG` | Профессиональная съёмка | Низкий |
| `*-topaz-sharpen.jpeg` | Обработано Topaz AI | Средний — проверить содержание |
| `*-topaz-face-upscale-2x.png` | Апскейл лица через AI | ВЫСОКИЙ — точно есть лицо |

## Где чаще всего встречаются

- `МОРСКОЙ КРУИЗ/` и `МОРСКОЙ КРУИЗ В ДУБАЕ/` — фото с круизов, могут быть снимки клиентов на лодке
- Папки экскурсий с фото формата `photo_*` — могут быть отчёты гидов

## Правила

1. **НЕ используй** фото с именем `photo_YYYY-MM-DD_*` в публичных материалах без проверки
2. **НЕ используй** файлы с суффиксом `face-upscale` — на них гарантированно есть лица
3. **Проверяй визуально** каждое фото из мессенджеров перед использованием
4. Для каталогов и презентаций предпочитай **профессиональные фото** (с понятными именами: `Exterior`, `Desert-Safari` и т.д.)
5. При сомнениях — **спроси Сухейля**, можно ли использовать конкретное фото
