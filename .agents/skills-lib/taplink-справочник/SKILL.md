# Taplink -- Мультиссылки и мини-сайты для туризма ОАЭ

## 1. Обзор платформы и тарифы

### Что такое Taplink

Taplink -- конструктор мультиссылок (link-in-bio) и мини-сайтов для Instagram, TikTok и других соцсетей. Основной сценарий: единая ссылка в профиле Instagram ведет на страницу со всеми контактами, услугами, формами и платежами.

- **Сайт:** taplink.at
- **Год запуска:** 2017 (Австрия)
- **Пользователи:** ~8 млн страниц создано
- **Mobile-first:** оптимизирован для просмотра со смартфона
- **Нет мобильного приложения** -- управление через веб-интерфейс (адаптивный)
- **11 языков** интерфейса (русский, английский, немецкий, испанский, итальянский, португальский, турецкий, китайский, хинди, индонезийский, японский). Арабский НЕ поддерживается. Контент страниц -- на любом языке.
- **AI-генерация:** создание страницы по описанию бизнеса за 5 минут

### Webhook формат данных

При новой заявке Taplink отправляет HTTP POST:

```json
{
  "action": "leads.created",
  "data": {
    "lead_id": "123",
    "lead_number": "45",
    "page_link": "https://taplink.cc/dubaitours",
    "tms_created": "2026-02-14 12:00:00",
    "records": [
      { "value": "Ahmed", "type": "3", "title": "Name" },
      { "value": "+971501234567", "type": "1", "title": "Phone" },
      { "value": "2026-03-15", "type": "3", "title": "Date" }
    ]
  }
}
```

### Node.js обработчик Webhook -> Telegram

```javascript
const express = require('express');
const crypto = require('crypto');
const axios = require('axios');
const app = express();

const SECRET = process.env.TAPLINK_SECRET || 'your_secret';
const BOT_TOKEN = process.env.TELEGRAM_BOT_TOKEN;
const CHAT_ID = process.env.TELEGRAM_CHAT_ID;

app.use('/webhook', express.raw({ type: 'application/json' }));

app.post('/webhook', async (req, res) => {
  const sig = req.headers['taplink-signature'];
  const calc = crypto.createHmac('sha1', SECRET).update(req.body).digest('hex');
  if (!sig || !crypto.timingSafeEqual(Buffer.from(calc), Buffer.from(sig))) {
    return res.status(403).send('Invalid signature');
  }
  const { action, data } = JSON.parse(req.body.toString());
  if (action === 'leads.created') {
    const fields = data.records.map(r => `${r.title}: ${r.value}`).join('\n');
    await axios.post(`https://api.telegram.org/bot${BOT_TOKEN}/sendMessage`, {
      chat_id: CHAT_ID,
      text: `Новая заявка #${data.lead_number}\n\n${fields}`,
      parse_mode: 'HTML'
    });
  }
  res.status(200).json({ ok: true });
});

app.listen(3000);
```

## 6. Webhooks и автоматизация

### Taplink НЕ имеет публичного REST API

Единственный программный способ получения данных -- **Webhooks** (исходящие HTTP POST). Taplink может только ОТПРАВЛЯТЬ данные. Нет API для управления страницами, блоками или аналитикой.

### Webhook-события

| Событие | Action | Описание |
|---------|--------|----------|
| Новая заявка | `leads.created` | Клиент отправил форму |
| Новый платеж | `payments.created` | Клиент оплатил |

### Верификация подписи (HMAC-SHA1)

Заголовок `taplink-signature` содержит подпись. Проверка:

```php
$data = file_get_contents('php://input');
$signature = hash_hmac('sha1', $data, 'YOUR_SECRET');
if ($signature === $_SERVER['HTTP_TAPLINK_SIGNATURE']) {
    // Подпись верна
}
```

### Retry Policy

8 повторных попыток: 5 мин, 15 мин, 15 мин, 1ч, 1ч, 2ч, 2ч, 4ч. Итого до 10.5 часов. HTTP-коды 100-299 = успех.

### Платформы автоматизации

| Платформа | Интеграция | Стоимость |
|-----------|-----------|-----------|
| **Albato** | Нативное приложение Taplink | ~на 30% дешевле Zapier |
| **Pabbly Connect** | Нативное приложение Taplink | Разовая оплата $249+ |
| **Make.com** | Через Webhook (Custom Webhook) | Бесплатно (ограниченно) |
| **Zapier** | Через Webhook (Catch Hook) | Бесплатно (ограниченно) |
| **ApiX-Drive** | Через Webhook | Ориентирован на СНГ |

### Схема автоматизации для туризма

```
[Клиент заполняет форму на Taplink]
    |
    v
[Webhook -> Ваш сервер / Make.com / Albato]
    |
    ├── [Telegram] Уведомление менеджеру
    ├── [Google Sheets] Строка в таблице заявок
    ├── [CRM] Новый контакт (AmoCRM / Bitrix24 / Notion)
    └── [Email] Автоответ клиенту
```

## 14. Production чеклист и домен

### Подключение кастомного домена (Business)

1. Купить домен (Namecheap, GoDaddy, REG.RU). Рекомендуемые зоны: .com, .ae, .travel, .tours
2. В панели регистратора: изменить NS-серверы на `ns1.taplink.cc` и `ns2.taplink.cc`
3. В Taplink: Настройки > Домен > ввести доменное имя
4. Ожидать DNS-обновление (1-48 часов)
5. SSL-сертификат -- подключается автоматически

- [ ] Тариф Business оплачен
- [ ] Аватар / логотип загружен (1080x1080 px)

- [ ] Форма бронирования тестирована -- заявка приходит
- [ ] Уведомления настроены (Telegram + Email)
- [ ] Платежная система подключена и тестирована
