# Taplink -- Решение типичных проблем (Troubleshooting)

---

## 1. Форма не отправляет данные / уведомления не приходят

**Симптомы:** Клиент заполняет форму, но менеджер не получает уведомление.

**Решение:**
1. Проверить тариф -- формы только на **Business**
2. Настройки > Модули > Notifications -- включен ли модуль?
3. Проверить канал уведомлений (Telegram/Email) -- правильно ли подключен?
4. Для Telegram: проверить, что бот не заблокирован, чат-ID корректен
5. Для Email: проверить спам-папку, подтвердить email (письмо от noreply@taplink.at)
6. Отправить тестовую заявку самостоятельно и проверить CRM Taplink (данные сохраняются даже без уведомлений)
7. Если Webhook: проверить URL (HTTPS обязателен), код ответа сервера (нужен 200)

---

## 2. Платежная система не подключается или не работает

**Симптомы:** Ошибка при подключении Stripe/PayPal, клиент не может оплатить.

**Решение:**
1. Убедиться, что тариф = **Business** (платежи недоступны на Basic и Pro)
2. Проверить API-ключи провайдера (Secret Key + Publishable Key для Stripe)
3. Один метод оплаты = один провайдер (нельзя "карты" и на Stripe, и на PayPal)
4. Переключить из тестового режима в рабочий (Production/Live)
5. Для Stripe в ОАЭ: аккаунт должен быть верифицирован, валюта AED настроена
6. Проверить: нет ли блокировки AdBlock/VPN у клиента
7. Протестировать оплату самостоятельно с реальной карты (минимальная сумма)

---

## 3. Кастомный домен не работает / SSL-ошибка

**Симптомы:** Домен не открывается, "Не удается установить безопасное соединение".

**Решение:**
1. Проверить NS-серверы у регистратора: должны быть `ns1.taplink.cc` и `ns2.taplink.cc`
2. DNS-обновление занимает 1-48 часов -- подождать
3. В Taplink: Настройки > Домен -- проверить, что домен введен корректно (без https://, без www)
4. SSL-сертификат подключается автоматически после DNS-обновления
5. Если больше 48 часов: удалить домен в Taplink, подождать 10 минут, добавить заново
6. Проверить: домен не заблокирован регистратором, оплата домена актуальна
7. Обратиться в поддержку Taplink через чат

---

## 4. Страница грузится медленно

**Симптомы:** Долгая загрузка при переходе из Instagram, белый экран.

**Решение:**
1. Оптимизировать изображения -- каждое < 1 MB, формат WebP/JPEG
2. Карусель: до 15 фото, каждое < 2 MB (рекомендуется < 500 KB)
3. Видео: только через YouTube/Vimeo (не self-hosted)
4. Убрать неиспользуемые блоки (архивировать или удалить)
5. Отключить автовоспроизведение видео (autoplay работает только на десктопе)
6. HTML-блок: минимизировать внешние скрипты и стили
7. Проверить через PageSpeed Insights (ввести URL Taplink-страницы)

---

## 5. Мобильная версия отображается некорректно

**Симптомы:** Блоки перекрывают друг друга, текст обрезается, кнопки не нажимаются.

**Решение:**
1. Taplink mobile-first -- открыть предпросмотр на телефоне
2. Проверить: не используете ли CSS с фиксированными размерами (px вместо %)
3. Custom Block: убедиться, что модульная сетка настроена для мобильных
4. Текст: не слишком длинные строки, размер шрифта >= 14px
5. Кнопки: минимальная высота 44px для удобного нажатия
6. HTML-блок: добавить `<meta name="viewport" content="width=device-width">`
7. Тестировать на реальном устройстве, а не только в браузере

---

## 6. HTML/CSS код не применяется

**Симптомы:** Вставленный код не отображается или ломает страницу.

**Решение:**
1. Блок HTML-код доступен на **Pro+** (базовый) и **Business** (глобальный)
2. Проверить синтаксис: закрыты ли все теги, нет ли ошибок в CSS
3. `<script>` работает, но DOM manipulation может быть ограничена
4. Использовать `!important` для CSS-свойств (Taplink имеет свои стили)
5. Тестировать на черновой странице перед публикацией
6. Не хранить API-ключи в HTML-блоке (видны в исходном коде)
7. При полной поломке: удалить HTML-блок, страница восстановится
8. Глобальный HTML (Business): добавляется в `<head>` -- для пикселей и мета-тегов, не для визуальных элементов

## 7. Аналитика (GA4/Метрика) не считает визиты

**Симптомы:** Ноль посещений в Google Analytics или Яндекс.Метрике, хотя страница работает.

**Решение:**
1. Проверить тариф -- аналитика только на **Pro+**
2. GA4: Настройки > Модули > Google Analytics -- проверить Measurement ID (формат G-XXXXXXX)
3. Яндекс.Метрика: проверить ID счетчика (только число)
4. Facebook Pixel: проверить Pixel ID + Access Token
5. Ожидать 24-48 часов после подключения (данные не мгновенные)
6. Проверить: AdBlock/uBlock не блокирует ли скрипты аналитики
7. В встроенном браузере Instagram: пиксели могут работать с ограничениями
8. Тест: открыть страницу в обычном Chrome, проверить через Facebook Pixel Helper или GA Debug

## 8. Webhook не отправляется / CRM не получает данные

**Симптомы:** Заявки есть в CRM Taplink, но не приходят на внешний сервер.

**Решение:**
1. Проверить: URL webhook начинается с `https://` (HTTP без S не работает)
2. SSL-сертификат на вашем сервере должен быть валидным
3. Сервер должен отвечать HTTP 200 (100-299 = успех)
4. Taplink делает 8 повторов (5 мин, 15 мин, 15 мин, 1ч, 1ч, 2ч, 2ч, 4ч)
5. Проверить SECRET PHRASE -- совпадает ли с настройками в коде?
6. Для Make.com/Zapier: убедиться, что сценарий активен (не в паузе)
7. Логировать все входящие запросы для отладки
8. Тест: отправить curl-запрос вручную на URL webhook

```bash
curl -X POST https://your-server.com/webhook \
  -H "Content-Type: application/json" \
  -d '{"action":"leads.created","data":{"lead_id":"test"}}'
```

## 9. Instagram не открывает ссылку Taplink

**Симптомы:** Клик по ссылке в Bio открывает предупреждение или не работает.

**Решение:**
1. Ссылка должна быть полной: `https://taplink.cc/username` (или кастомный домен)
2. Проверить: аккаунт Instagram не в режиме "Закрытый профиль"
3. Instagram иногда блокирует новые домены -- подождать 24 часа
4. Использовать кастомный домен (Business) вместо taplink.cc -- реже блокируется
5. Не менять ссылку слишком часто (Instagram может заблокировать)
6. Если блокируется: попробовать сократить через bit.ly или linktr.ee (как промежуточную)
7. Проверить: нет ли опечатки в URL

## 10. Блоки не отображаются после публикации

**Симптомы:** В редакторе блок виден, но на опубликованной странице -- нет.

**Решение:**
1. Проверить видимость блока: не архивирован ли? (иконка глаза)
2. Проверить расписание показа: блок может быть ограничен по дате/времени/дням недели
3. Блоки платных тарифов скрываются при даунгрейде (Pro -> Basic)
4. Нажать кнопку "Publish" / "Опубликовать" после внесения изменений
5. Очистить кеш браузера (Ctrl+Shift+R)
6. Проверить на другом устройстве или в режиме инкогнито
7. Секции (Sections): проверить, что секция не скрыта

---

## 11. Промокод или скидка не применяется

**Симптомы:** Клиент вводит промокод, но скидка не применяется.

**Решение:**
1. Промокоды доступны только на **Business** тарифе
2. Проверить: промокод активен (не истек срок действия)
3. Проверить регистр: промокоды могут быть case-sensitive
4. Убедиться, что промокод создан для правильного товара/формы
5. Клиент должен ввести код ДО оформления заказа (в корзине)
6. Для цифровых товаров: промокод применяется на странице оплаты
7. Создать новый промокод, если текущий не работает

---

## 12. Мессенджер-кнопки не отображаются у клиентов

**Симптомы:** Блок мессенджеров не виден у некоторых клиентов.

**Решение:**
1. Мессенджеры доступны на **Pro+** -- проверить тариф
2. **AdBlock / AdGuard** блокируют блок мессенджеров (известная проблема Taplink)
3. Решение для клиента: отключить AdBlock на странице Taplink
4. Альтернатива: дублировать WhatsApp как обычную кнопку Link:
   - Действие: "Open website"
   - URL: `https://wa.me/971XXXXXXXXX?text=Здравствуйте`
   - Текст кнопки: "WhatsApp"
5. Проверить: правильно ли введен номер телефона (без + в начале, только цифры)
6. Проверить: приложение мессенджера установлено на устройстве клиента
