# Taplink -- Часто задаваемые вопросы (FAQ)

---

## 1. Какой тариф Taplink нужен для туристического бизнеса?

**Ответ: Business** ($4.50/мес при годовой оплате, $9/мес при квартальной).

Для туристического бизнеса нужны формы бронирования, прием оплаты, кастомный домен, CRM и многостраничность -- все это только на Business. Pro ($2/мес) подходит для простой визитки с мессенджерами и фото, но без форм и платежей.

## 2. Можно ли принимать оплату в AED через Taplink?

**Да**, через **Stripe** (работает в ОАЭ с 2022 года). Stripe поддерживает AED как валюту обработки. Комиссия: ~2.9% + $0.30 за транзакцию. Также доступен PayPal и 60+ других провайдеров.

Для клиентов из России (Сбер) и Казахстана (Kaspi) -- используйте **ручную оплату** с инструкциями перевода.

## 3. Как настроить уведомления о заявках в Telegram?

1. В Taplink: **Настройки > Модули > Notifications**
2. Выберите канал: **Telegram**
3. Подключите Telegram-аккаунт (следуйте инструкции)
4. Выберите триггеры: "Новая заявка", "Новая оплата"
5. Сохраните

Теперь при каждой новой заявке вы получите мгновенное уведомление в Telegram с данными клиента.

Альтернатива: через **Webhook** -> свой сервер или Make.com/Zapier -> Telegram Bot API (для кастомного формата сообщений).

## 4. Чем Taplink отличается от Linktree?

| Критерий | Taplink | Linktree |
|----------|---------|----------|
| Блоки контента | 20+ (формы, карты, таймеры) | ~10 |
| Комиссия с продаж | 0% | До 12% |
| Русский язык | Да | Нет |
| WhatsApp/Telegram кнопки | Да (Pro+) | Нет |
| Кастомный домен | Business | Pro |
| Цена | от $2/мес | от $5/мес |
| Многостраничность | До 512 страниц | Нет |

Taplink -- лучший выбор для бизнеса, который продает услуги и принимает заявки. Linktree -- для простой страницы ссылок.

## 5. Можно ли сделать мультиязычный сайт (RU/EN)?

Taplink **не имеет** встроенной мультиязычности с переключателем языков. Решения:

1. **Основной язык + кнопки на другом** -- текст на русском, CTA-кнопки дублированы на английском
2. **Две отдельные страницы** -- taplink.cc/dubaitours_ru и taplink.cc/dubaitours_en
3. **Двуязычный контент** -- каждый блок содержит текст на обоих языках (RU / EN)

Интерфейс Taplink поддерживает 11 языков, но арабский НЕ входит в список. Контент на арабском можно размещать свободно, однако RTL-верстка не гарантирована.

## 6. Как подключить WhatsApp с автотекстом?

1. Добавьте блок **"Messaging Apps"** (тариф Pro+)
2. Выберите **WhatsApp**
3. Введите номер телефона в международном формате: `971XXXXXXXXX`
4. В поле "Шаблон сообщения" введите текст, который увидит клиент:
   `Здравствуйте! Хочу забронировать экскурсию`
5. Сохраните

При клике клиент попадет в WhatsApp с готовым текстом. Прямая ссылка:
`https://wa.me/971XXXXXXXXX?text=Здравствуйте!%20Хочу%20забронировать%20экскурсию`

## 7. Можно ли использовать свой домен?

**Да**, на тарифе **Business**.

1. Купите домен (Namecheap, GoDaddy, REG.RU)
2. Смените NS-серверы на `ns1.taplink.cc` и `ns2.taplink.cc`
3. В Taplink: Настройки > Домен > введите имя
4. SSL-сертификат подключается автоматически

Рекомендуемые домены: dubai-tours.com, dubaitours.ae, tours-dubai.travel

## 8. Как добавить Google Analytics / Яндекс.Метрику?

**Google Analytics 4** (Pro+):
- Настройки > Модули > Google Analytics > вставить Measurement ID (G-XXXXXXX) > Активировать

**Яндекс.Метрика** (Pro+):
- Настройки > Модули > Яндекс.Метрика > вставить ID счетчика > Активировать

**Facebook Pixel** (Pro+):
- Настройки > Модули > Facebook Pixel > вставить Pixel ID + Access Token > Активировать

Pixel автоматически отслеживает: клики на ссылки, переходы в мессенджеры, добавление в корзину, оплату.

## 9. Можно ли создать полноценный интернет-магазин экскурсий?

**Да**, на тарифе Business. Два варианта:

1. **Каталог товаров (Shop)** -- карточки с фото, описанием, ценами, корзина, checkout, промо-коды. Подходит для билетов в парки.

2. **Форма + платежи** -- форма бронирования с полями (дата, количество) + оплата. Подходит для экскурсий и яхт.

Taplink НЕ берет комиссию (0%). Комиссия только от платежного провайдера (Stripe ~2.9%).

## 10. Как настроить CRM через Zapier/Make.com?

Прямой интеграции с внешними CRM нет. Схема:

**Taplink -> Webhook -> Make.com/Zapier -> CRM (AmoCRM/Bitrix24/Notion)**

Настройка через Make.com:
1. В Make: создать Custom Webhook, скопировать URL
2. В Taplink: Настройки > Модули > Webhooks > вставить URL
3. Отправить тестовую заявку
4. В Make: добавить действие (Google Sheets, Telegram, CRM)

Для простых задач: **Google Sheets** как CRM -- каждая заявка = строка в таблице.

## 11. Taplink vs Tilda -- когда что использовать?

| Сценарий | Taplink | Tilda |
|----------|---------|-------|
| Мультиссылка для Instagram | Да | Нет |
| Мобильный мини-лендинг | Идеально | Можно |
| Полноценный сайт (10+ страниц) | Возможно | Идеально |
| SEO-продвижение в Google | Ограничено | Отлично |
| Цена | от $2/мес | от $10/мес |
| Скорость запуска | 30 минут | 2-4 часа |
| Навыки дизайна | Не нужны | Желательны |

**Рекомендация:** Taplink для Instagram-аудитории и быстрого запуска. Tilda -- если нужен полноценный сайт с SEO. Можно использовать оба: Taplink для соцсетей, Tilda для Google.

## 12. Как оптимизировать конверсию мультиссылки?

1. **Первый экран решает** -- аватар + краткое описание + CTA в первых 2 блоках
2. **WhatsApp кнопка вверху** -- 70%+ клиентов предпочитают мессенджер формам
3. **Конкретные цены** -- "Desert Safari от 150 AED" вместо "Узнать цену"
4. **Таймер на акцию** -- создает FOMO (Business тариф)
5. **Фото высокого качества** -- карусель с 5-10 лучшими фото
6. **FAQ отвечает на возражения** -- "Что включено?", "Можно ли отменить?"
7. **Минимум кликов до заявки** -- форма на главной странице
8. **Мобильная проверка** -- 90%+ трафика с телефона, проверьте отображение
9. **UTM-метки** -- отслеживайте, откуда приходят клиенты
10. **A/B тестирование** -- меняйте CTA-тексты, фото, порядок блоков каждые 2 недели
