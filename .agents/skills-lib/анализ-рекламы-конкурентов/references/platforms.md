## Meta (Facebook / Instagram)

### Источник
- **Meta Ad Library:** https://www.facebook.com/ads/library/
- **MCP:** `facebook-ads-library-mcp` (trypeggy, 191 stars)
- **Токен:** НЕ нужен

### Как искать
1. Перейти в Ad Library
2. Выбрать страну: `United Arab Emirates` или `All`
3. Категорию: `All ads`
4. Ввести имя страницы конкурента или ключевое слово
5. Фильтровать по языку (Russian, English), активности, медиа-типу

### Что смотреть
| Параметр | Зачем |
|----------|-------|
| Количество активных объявлений | Масштаб рекламной активности |
| Тексты объявлений | Офферы, УТП, призывы к действию |
| Креативы (фото/видео/карусель) | Визуальный стиль, качество |
| Даты запуска | Как долго крутится — значит работает |
| Количество версий | A/B тестирование |
| Таргетинг (страны, возраст, пол) | Кого таргетируют |
| CTA кнопки | WhatsApp / Сайт / Форма |
| Посадочная страница | Куда ведёт трафик |

### Особенности
- Можно смотреть ВСЕ активные объявления любой бизнес-страницы
- Данные доступны за последние 7 лет
- Нет данных по бюджетам (кроме политической рекламы)
- Самый богатый источник для анализа конкурентов

## Google Ads / YouTube

### Источник
- **Google Ads Transparency Center:** https://adstransparency.google.com/
- **MCP:** `google-ads-transparency` (если доступен)
- **Токен:** НЕ нужен

### Как искать
1. Перейти в Ads Transparency Center
2. Искать по имени рекламодателя или домену
3. Фильтровать по региону (UAE), формату, периоду

### Что смотреть
| Параметр | Зачем |
|----------|-------|
| Поисковые объявления (тексты) | Заголовки, описания, расширения |
| Display баннеры | Визуальный стиль, размеры |
| YouTube видеореклама | Формат (skippable, bumper), длительность |
| Регионы показа | Где таргетируют (UAE, RU, KZ) |
| Период активности | Сезонные паттерны |
| Посадочные страницы | Куда ведёт трафик |

### Особенности
- Показывает ВСЕ объявления рекламодателя за последние годы
- Нет данных по ключевым словам и бюджетам
- Для анализа ключевых слов — ручной просмотр поисковой выдачи

## TikTok

### Источник
- **TikTok Creative Center:** https://ads.tiktok.com/business/creativecenter/
- **Top Ads:** https://ads.tiktok.com/business/creativecenter/inspiration/topads/
- **Токен:** НЕ нужен

### Как искать
1. Перейти в Creative Center → Top Ads
2. Выбрать регион: UAE / Middle East
3. Категория: Travel & Tourism
4. Фильтровать по периоду и engagement

### Что смотреть
| Параметр | Зачем |
|----------|-------|
| Топ-объявления по категории Travel | Что работает в индустрии |
| Формат видео (длительность, стиль) | Тренды в формате контента |
| Хуки (первые 3 секунды) | Как привлекают внимание |
| Музыка и звуки | Трендовые аудио |
| CTR и engagement | Эффективность |
| Хештеги | Ключевые теги индустрии |

### Особенности
- Нельзя искать по конкретному рекламодателю (только по категории)
- Показывает лучшие рекламные креативы индустрии
- Полезно для вдохновения и понимания трендов

## LinkedIn

### Источник
- **LinkedIn Ad Library:** https://www.linkedin.com/ad-library/
- **Токен:** НЕ нужен (но нужен LinkedIn аккаунт)

### Когда использовать
- B2B конкуренты (корпоративные туры, MICE)
- DMC компании (Destination Management)
- Набор сотрудников конкурентами (косвенный индикатор роста)

### Что смотреть
| Параметр | Зачем |
|----------|-------|
| Спонсированный контент | B2B офферы |
| Формат (текст, видео, карусель) | Стиль коммуникации |
| Частота публикаций | Активность рекламы |
| Таргетинг (если доступен) | Целевые индустрии |

### Особенности
- Релевантен только для B2B-сегмента
- Для B2C туризма — низкий приоритет

## ВКонтакте

### Источник
- **Нет публичной библиотеки рекламы**
- VK API (публичные данные сообществ)
- Ручной просмотр ленты и групп конкурентов

### Как искать
1. Найти группу/страницу конкурента в VK
2. Просмотреть стену — промо-посты помечены "Реклама" или имеют рекламный стиль
3. Посмотреть обсуждения — вопросы клиентов
4. Проверить разделы: товары, фото, видео

### Что смотреть
| Параметр | Зачем |
|----------|-------|
| Промо-посты (с отметкой "Реклама") | Офферы, формулировки |
| Контент-стратегия | Частота, тематика, формат |
| Вовлечённость (лайки, комменты, репосты) | Что резонирует с аудиторией |
| Количество подписчиков и динамика | Масштаб присутствия |
| Товары | Каталог и цены (если есть) |
| Обсуждения | Вопросы клиентов, боли |

### Особенности
- Нет централизованной библиотеки рекламы
- Требует ручной работы
- Полезно для понимания контент-стратегии конкурентов на российском рынке

## Яндекс.Директ

### Источник
- **Нет публичной библиотеки рекламы**
- **Яндекс.Wordstat:** https://wordstat.yandex.ru/ (частотность запросов)
- Ручной просмотр поисковой выдачи

### Как искать
1. Открыть Яндекс в режиме "Россия" (или нужный регион)
2. Ввести ключевые запросы из списка (см. uae-tourism.md)
3. Зафиксировать рекламные объявления (верх и низ выдачи)
4. Перейти по ссылкам — оценить посадочные страницы

### Что смотреть
| Параметр | Зачем |
|----------|-------|
| Заголовки объявлений | Офферы и формулировки |
| Быстрые ссылки и уточнения | Дополнительные услуги |
| Посадочные страницы | Куда ведут, UX, конверсионные элементы |
| Позиции по ключевым словам | Кто доминирует |
| Яндекс.Карты (позиции) | Локальное присутствие |
| Яндекс.Wordstat (частотность) | Популярность запросов по сезонам |

### Ключевые запросы для мониторинга
```
экскурсии в дубае
билеты в парки дубай
сафари в пустыне дубай цена
бурдж халифа билеты купить
яхта дубай аренда
отдых в оаэ 2026
трансфер аэропорт дубай
абу даби экскурсии из дубая
```

### Особенности
- Нет API для просмотра чужих объявлений
- Только ручной анализ выдачи
- Wordstat даёт понимание спроса по сезонам

## X (Twitter)

### Источник
- **EU Ads Transparency:** через Twitter/X если доступно
- **Токен:** НЕ нужен

### Особенности
- Доступность ограничена (только ЕС-регион)
- Низкий приоритет для туристического бизнеса ОАЭ с СНГ-клиентами
- Использовать только если конкурент активен в Twitter
