# OBS Screen Recording — Справочник

Production-ready руководство по OBS Studio и альтернативам для записи экрана.

## Когда активировать

- Нужно записать скринкаст или видео-туториал
- Настройка OBS Studio (энкодеры, форматы, качество)
- Выбор программы для записи экрана
- Оптимизация размера видеофайлов
- Настройка аудио для записи (фильтры, микрофон)
- Сравнение OBS с конкурентами (Bandicam, Camtasia, ShadowPlay и др.)
- Решение проблем с записью (чёрный экран, рассинхрон, лаги)
- Конвертация видеофайлов (FFmpeg команды)
