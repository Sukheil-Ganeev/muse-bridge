# Опыт использования — OBS Screen Recording

## Критические уроки (топ-5)

1. **UTVideo/PCM = огромные файлы** — UTVideo (lossless) создаёт файлы в 24 раза больше H.264. Для скринкастов ВСЕГДА используй H.264 NVENC CQP 20.

2. **MKV спасает при краше** — MP4 файл будет повреждён если OBS крашнется. MKV сохраняет всё до момента краша. Потом Remux → MP4.

3. **30 FPS для скринкастов** — 60 FPS удваивает размер файла без заметного улучшения качества для записи экрана/туториалов.

4. **Аудиофильтры обязательны** — без Noise Gate и Compressor запись будет с фоновым шумом и перепадами громкости.

5. **NVENC не нагружает CPU** — если есть NVIDIA GPU, ВСЕГДА используй NVENC вместо x264. Нулевое влияние на производительность.
