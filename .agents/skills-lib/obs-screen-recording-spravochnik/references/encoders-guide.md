# Энкодеры и Rate Control — подробное руководство

Детальное описание всех энкодеров OBS Studio и методов контроля битрейта.

---

## x264 (CPU-энкодер)

Программный энкодер H.264. Работает на любом ПК, но нагружает процессор.

### Rate Control для записи: CRF (Constant Rate Factor)

| Значение CRF | Качество        | Размер файла | Применение          |
|---------------|-----------------|--------------|---------------------|
| 0             | Lossless        | Огромный     | Мастер-копия        |
| 15-17         | Визуально без потерь | Большой | Production, монтаж  |
| 18-20         | Отличное        | Средний      | Скринкасты          |
| 21-23         | Хорошее         | Умеренный    | Длинные записи      |
| 24-28         | Приемлемое      | Маленький    | Черновики, превью   |

### Presets (скорость кодирования)

От самого быстрого к самому медленному:

```
ultrafast → superfast → veryfast → faster → fast → medium → slow → slower → veryslow
```

| Preset    | Нагрузка CPU | Качество на бит | Для записи                |
|-----------|-------------|-----------------|---------------------------|
| ultrafast | Минимальная | Низкое          | Слабый ПК, фоновая запись |
| veryfast  | Низкая      | Среднее         | Стандартная запись         |
| faster    | Умеренная   | Хорошее         | Качественная запись       |
| fast      | Средняя     | Хорошее+        | Если CPU позволяет        |
| medium    | Высокая     | Высокое         | Только мощный ПК          |
| slow+     | Очень высок | Максимальное    | Не для реального времени  |

Для записи в реальном времени: **veryfast** или **faster**.

### Profiles

| Profile  | Описание                    | Когда использовать        |
|----------|-----------------------------|---------------------------|
| baseline | Без B-frames, совместимость | Старые устройства         |
| main     | B-frames, средняя сложность | Стриминг                  |
| high     | Максимальная эффективность  | Запись (рекомендуется)     |

### Рекомендуемые настройки x264 для записи

```
Rate Control:   CRF
CRF:            20
Preset:         veryfast
Profile:        high
Tune:           (пусто) или animation для анимации
Key Interval:   0 (авто) или 250 кадров
```

## NVENC (NVIDIA GPU)

Аппаратный энкодер на видеокартах NVIDIA (GTX 600+ / RTX серия).
Практически не нагружает CPU. Кодирование идёт на выделенном чипе GPU.

### Rate Control для записи: CQP (Constant Quantization Parameter)

| Значение CQP | Качество          | Применение           |
|---------------|--------------------|----------------------|
| 0             | Lossless           | Мастер-копия         |
| 15-17         | Визуально lossless | Production           |
| 18-20         | Отличное           | Скринкасты, геймплей |
| 21-23         | Хорошее            | Длинные записи       |
| 24+           | Приемлемое         | Черновики            |

CQP и CRF дают похожие результаты. CQP = 20 примерно = CRF 20.

### Presets NVENC (современные, OBS 28+)

| Preset | Обозначение | Качество | Скорость | Применение        |
|--------|-------------|----------|----------|-------------------|
| P1     | Fastest     | Базовое  | Макс     | Если GPU на пределе|
| P3     | Fast        | Среднее  | Быстро   | Стриминг          |
| P4     | Medium      | Хорошее  | Средне   | Запись по умолчанию|
| P5     | Slow        | Хорошее+ | Медленно | Качественная запись|
| P6     | Slower      | Высокое  | Медленно | Постобработка     |
| P7     | Slowest     | Макс     | Мин      | Оффлайн кодировка |

Legacy-названия (старые версии OBS): Quality, Max Quality, Low Latency Quality.

### B-Frames

- 0 — без B-frames (минимальная задержка)
- 2 — рекомендуется для записи (лучшее сжатие)
- 4 — максимальное сжатие (RTX 20xx+)

### Рекомендуемые настройки NVENC для записи

```
Encoder:          NVIDIA NVENC H.264
Rate Control:     CQP
CQP:              20
Preset:           P5 (Quality) или P4 (Medium)
Profile:          high
Look-ahead:       Включить (если есть)
B-Frames:         2
Max B-Frames:     2
GPU:              0 (основной)
```

### NVENC AV1 (RTX 40xx+)

Новый кодек AV1 доступен аппаратно на RTX 4000+. Даёт на 20-30% лучшее
сжатие при том же качестве по сравнению с H.264. Но не все плееры и
редакторы поддерживают AV1 (ситуация улучшается).

```
Encoder:     NVIDIA NVENC AV1
CQP:         22-24 (даёт качество примерно как H.264 CQP 20)
```

## AMF (AMD GPU)

Аппаратный энкодер на видеокартах AMD (RX 400+).

### Настройки AMF для записи

```
Encoder:        AMD HW H.264 (AVC)
Rate Control:   CQP
CQP:            20
Quality Preset: Quality
Profile:        high
B-Frames:       0 (AMF хуже работает с B-frames)
```

AMF в целом даёт чуть худшее качество на бит по сравнению с NVENC при
равных настройках. Для записи это не критично — CQP 18-20 компенсирует.

### AMF AV1 (RX 7000+)

Доступен на RDNA 3+. Настройки аналогичны NVENC AV1.

---

## QSV (Intel Quick Sync Video)

Аппаратный энкодер на встроенной графике Intel (Intel HD/UHD/Iris/Arc).

### Настройки QSV для записи

```
Encoder:        Intel QSV H.264
Rate Control:   ICQ (Intelligent Constant Quality)
ICQ Quality:    20-23
Target Usage:   Quality (или Balanced)
Profile:        high
```

ICQ — аналог CRF/CQP для QSV. Значения 20-23 дают хорошее качество.

QSV полезен когда:
- Нет дискретной видеокарты
- Нужно разгрузить дискретный GPU (для игр)
- Ноутбук с Intel + NVIDIA — можно записывать через QSV, оставив NVIDIA для игры

## AV1 — Программный (SVT-AV1)

Программный энкодер AV1. Очень требователен к CPU.

```
Encoder:     SVT-AV1
CRF:         25-30 (AV1 более эффективен, поэтому значения выше)
Preset:      8-10 (для реального времени)
```

**Когда использовать AV1:**
- У вас RTX 40xx+ (аппаратный NVENC AV1)
- Или RX 7000+ (аппаратный AMF AV1)
- Или мощный CPU (12+ ядер) для SVT-AV1
- Вам важен минимальный размер файла
- Совместимость с AV1 не проблема

**Когда НЕ использовать AV1:**
- Файлы пойдут в монтаж (не все NLE поддерживают)
- Нужна максимальная совместимость
- Слабый ПК без аппаратного AV1

## Rate Control — Подробный разбор

Rate Control определяет, как энкодер распределяет биты между кадрами.

| Метод | Расшифровка                      | Описание                                           | Для записи | Для стрима |
|-------|----------------------------------|-----------------------------------------------------|------------|------------|
| CRF   | Constant Rate Factor             | Постоянное визуальное качество, переменный битрейт  | Да         | Нет        |
| CQP   | Constant Quantization Parameter  | Фиксированный параметр квантования, перем. битрейт  | Да         | Нет        |
| CBR   | Constant Bitrate                 | Фиксированный битрейт, переменное качество          | Нет        | Да         |
| VBR   | Variable Bitrate                 | Переменный битрейт в заданных рамках                | Опционально| Да         |
| ABR   | Average Bitrate                  | Средний битрейт, варьируется покадрово              | Нет        | Редко      |
| ICQ   | Intelligent Constant Quality     | CRF-аналог для Intel QSV                           | Да         | Нет        |

**Ключевое правило:**
- **Запись** → CRF (x264) или CQP (NVENC/AMF) — качество приоритет
- **Стриминг** → CBR — стабильный битрейт для сети

**Почему CBR плохо для записи:**
CBR выделяет одинаковое количество бит для простых и сложных сцен.
Простая сцена (статичный слайд) получает лишние биты — раздутый файл.
Сложная сцена (быстрое движение) не получает достаточно бит — артефакты.

CRF/CQP автоматически адаптируются: меньше бит на простые сцены,
больше на сложные. Результат: меньший файл при лучшем качестве.
