# Конкуренты OBS Studio — Подробные описания

> Перенесено из SKILL.md (секция 4). Полные описания 9 инструментов.

---

## 4.1 Streamlabs (Streamlabs Desktop)

**Описание:** Форк OBS Studio с модернизированным интерфейсом и встроенными
виджетами для стримеров. Принадлежит Logitech.

**Цена:** Бесплатно (базовая) / $149/год (Ultra — без водяных знаков на оверлеях,
мультистрим, приоритетная поддержка, мерч-магазин)

**Плюсы:**
- Интуитивный UI, проще для новичков чем OBS
- Встроенные оверлеи, alerts, чат-бот
- Магазин тем и виджетов
- Селективная запись (можно исключить оверлеи)
- Поддержка OBS-плагинов (частично)

**Минусы:**
- Потребляет больше RAM и CPU чем OBS (на 30-50%)
- Подписка $149/год за полный функционал
- Только Windows и macOS (нет Linux)
- Меньше гибкости в настройках по сравнению с OBS
- Не всегда синхронизирован с последней версией OBS

**Для кого:** Стримеры, которым нужен готовый "из коробки" набор инструментов
и красивый интерфейс. Не лучший выбор для чистой записи экрана.

## 4.2 Bandicam

**Описание:** Специализированная программа для записи экрана, игр и устройств
захвата. Фокус на простоте и качестве записи (не стриминг).

**Цена:** ~$40 (бессрочная лицензия на 1 ПК) / бесплатная версия с водяным знаком
и лимитом 10 минут

**Плюсы:**
- Очень простой интерфейс, минимальная кривая обучения
- Оптимизирован для записи (не перегружен функциями стриминга)
- Рисование поверх экрана в реальном времени
- Запись конкретной области экрана
- Хорошая производительность, низкая нагрузка
- Аппаратное ускорение (NVENC, QSV, AMF)
- Встроенный режим скриншотов

**Минусы:**
- Только Windows
- Нет стриминга
- Платный (хотя разовая покупка)
- Закрытый исходный код
- Ограниченные возможности постобработки
- Меньше гибкости в настройке кодирования

**Для кого:** Пользователи Windows, которым нужна простая запись экрана без
возни с настройками. Учителя, создатели туториалов.

## 4.3 Camtasia

**Описание:** Комбинация записи экрана и полноценного видеоредактора.
Продукт TechSmith (те же, кто делает Snagit).

**Цена:** ~$300 (бессрочная) или $180/год (подписка)

**Плюсы:**
- Запись + монтаж в одном приложении
- Библиотека эффектов, переходов, аннотаций
- Callouts, zoom effects, курсорные эффекты
- Встроенные шаблоны для обучающих видео
- Экспорт напрямую на YouTube, Vimeo
- Quiz-интерактивность (для e-learning)

**Минусы:**
- Дорого ($300)
- Видеоредактор базового-среднего уровня (не замена Premiere/DaVinci)
- Тяжёлый (нагрузка на систему)
- Проприетарный формат проектов (.trec, .tscproj)
- Экспорт может быть медленным
- Нет поддержки расширенных кодеков (AV1 и т.д.)

**Для кого:** Создатели обучающих курсов и корпоративных видео. Когда нужно
записать и смонтировать "под ключ" без изучения отдельного NLE.

## 4.4 ShareX

**Описание:** Бесплатный open-source инструмент для скриншотов и записи экрана
в Windows. Мощный, но интерфейс перегружен.

**Цена:** Бесплатно (open-source, GPL)

**Плюсы:**
- Полностью бесплатный, без ограничений
- Скриншоты: область, окно, полный экран, прокрутка, OCR
- Запись экрана и GIF-анимации
- Автозагрузка на 80+ хостингов (Imgur, Google Drive, S3 и т.д.)
- Аннотации, редактор скриншотов
- Автоматизация (задачи после захвата)
- Portable-версия

**Минусы:**
- Только Windows
- Запись видео ограничена (используется FFmpeg)
- Нет аппаратного ускорения для записи (кроме FFmpeg-прослойки)
- Перегруженный интерфейс, сложно для новичков
- Нет стриминга
- Качество видеозаписи ниже OBS

**Для кого:** Разработчики, технические писатели — для скриншотов и коротких
записей. Не для длинных скринкастов или геймплея.

## 4.5 Xbox Game Bar

**Описание:** Встроенный в Windows 10/11 инструмент для записи экрана и
скриншотов, ориентированный на игры.

**Цена:** Бесплатно (часть Windows)

**Плюсы:**
- Уже установлен в Windows
- Нулевая настройка — Win+G → запись
- Низкая нагрузка (использует аппаратный энкодер)
- Фоновая запись (последние 30 сек/5 мин)
- Не нужно устанавливать ничего

**Минусы:**
- НЕ записывает рабочий стол и File Explorer (только приложения)
- Минимум настроек качества (30/60 FPS, стандартное/высокое качество)
- Нет выбора кодека, CRF, энкодера
- Нет фильтров, сцен, плагинов
- MP4 только (не crash-safe)
- Нет множественных аудиодорожек
- Запись только одного окна/приложения

**Для кого:** Быстрая одноразовая запись "прямо сейчас", без подготовки.
Запись бага в приложении, короткая демонстрация.

## 4.6 NVIDIA ShadowPlay (GeForce Experience / NVIDIA App)

**Описание:** Запись и стриминг через GPU NVIDIA. Использует выделенный
NVENC-энкодер, минимальная нагрузка на систему.

**Цена:** Бесплатно (только NVIDIA GPU)

**Плюсы:**
- Почти нулевая нагрузка на CPU (кодирование на GPU)
- Instant Replay — запись последних X минут (ретроспективная запись)
- Высокое качество при минимальном влиянии на FPS
- Простой интерфейс (Alt+Z)
- Автоматическое определение настроек
- Подсветка лучших моментов (Highlights) в играх

**Минусы:**
- Только NVIDIA GPU
- Минимум настроек (битрейт, разрешение, FPS — и всё)
- Нет CRF/CQP — только CBR
- Нет аудиофильтров, сцен, плагинов
- Нет множественных аудиодорожек
- Записывает только игры и полноэкранные приложения (desktop mode ограничен)
- GeForce Experience требует аккаунт NVIDIA

**Для кого:** Геймеры с NVIDIA, которым нужна запись геймплея "нажал и забыл".
Instant Replay — убойная функция для неожиданных моментов.

## 4.7 ScreenPal (бывший Screencast-O-Matic)

**Описание:** Облачная платформа для записи экрана, простого редактирования
и шаринга. Ребрендинг из Screencast-O-Matic.

**Цена:** Бесплатно (лимиты) / $4/мес (Solo) / $6/мес (Business) / $10/мес (Max)

**Плюсы:**
- Облачный хостинг для видео
- Простой встроенный редактор
- Запись экрана + вебкамера
- Автоматические субтитры (платные планы)
- Командная работа (Business/Max)
- Работает в браузере (для быстрой записи)

**Минусы:**
- Подписочная модель
- Качество записи среднее
- Ограниченные настройки кодирования
- Зависимость от облака
- Бесплатная версия: 15 мин лимит, водяной знак
- Функционал редактора базовый

**Для кого:** Образование, быстрые демонстрации для команды, когда нужен
облачный хостинг и простой шаринг ссылкой.

## 4.8 Loom

**Описание:** Облачный сервис для быстрой записи экрана и камеры с мгновенным
шарингом. Фокус на асинхронной бизнес-коммуникации.

**Цена:** Бесплатно (25 видео, 5 мин лимит) / $15/мес (Business) / Enterprise

**Плюсы:**
- Мгновенный шаринг ссылкой (без загрузки файлов)
- Запись экран + камера (bubble camera)
- Встроенная аналитика (кто смотрел, сколько)
- Комментарии, реакции, CTA
- Расширение Chrome для быстрого захвата
- AI-сводки и транскрипция
- Интеграция со Slack, Notion, Jira

**Минусы:**
- Подписка для полного функционала
- Ограниченное качество (до 1080p, нет настроек кодирования)
- Зависимость от облака и интернета
- Нет оффлайн-режима (полноценного)
- Не подходит для длинных записей
- Нет кастомизации кодеков

**Для кого:** Бизнес-коммуникация, Product Managers, удалённые команды —
быстрые объяснения вместо текстовых сообщений.

## 4.9 FFmpeg

**Описание:** Мощнейший CLI-инструмент для работы с видео и аудио.
Универсальный "швейцарский нож" мультимедиа. Open-source.

**Цена:** Бесплатно (LGPL/GPL)

**Плюсы:**
- Абсолютный контроль над всеми параметрами
- Автоматизация через скрипты и пайплайны
- Поддержка всех кодеков и форматов
- Минимальная нагрузка (нет GUI)
- Кроссплатформенный
- Пакетная обработка
- Основа многих других инструментов (OBS, ShareX используют FFmpeg внутри)

**Минусы:**
- Нет GUI — только командная строка
- Крутая кривая обучения
- Нет превью в реальном времени (без дополнительных настроек)
- Нет сцен, источников, переключений
- Сложная документация
- Трудно для начинающих

**Команды для записи экрана (Windows):**

```bash
# Запись экрана + аудио (Windows, GDI grab)
ffmpeg -f gdigrab -framerate 30 -i desktop -c:v libx264 -crf 20 -preset veryfast output.mkv

# Запись экрана через NVENC
ffmpeg -f gdigrab -framerate 30 -i desktop -c:v h264_nvenc -cqp 20 -preset p5 output.mkv

# Запись конкретного окна
ffmpeg -f gdigrab -framerate 30 -i title="Calculator" output.mkv

# Запись экрана + системный звук (через DirectShow)
ffmpeg -f gdigrab -framerate 30 -i desktop -f dshow -i audio="Stereo Mix" -c:v h264_nvenc -cqp 20 -c:a aac -b:a 192k output.mkv
```

**Для кого:** DevOps, разработчики, автоматизаторы — для скриптовой записи,
пакетной конвертации, CI/CD пайплайнов с видео.
