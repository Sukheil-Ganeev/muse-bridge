## 1. Готовые конфиги OBS (копируй и вставляй)

### Скринкаст / Туториал

```
Энкодер:        NVENC H.264 (или x264 если нет GPU)
Rate Control:   CQP
CQ Level:       20
Preset:         Quality
Profile:        High
B-frames:       2
Разрешение:     1920x1080
FPS:            30
Формат:         MKV (ремукс в MP4 после записи)
Аудио кодек:    AAC
Аудио битрейт:  160 kbps
Sample Rate:    48 kHz
Каналы:         Stereo
```

**Почему эти настройки:** чёткий текст и интерфейс, умеренный размер файла (~150-250 МБ/час), низкая нагрузка на CPU при использовании NVENC.

## 3. Команды FFmpeg для конвертации

### Ремуксинг (мгновенно, без перекодирования)

```bash
# MKV → MP4
ffmpeg -i input.mkv -c copy output.mp4

# FLV → MP4
ffmpeg -i input.flv -c copy output.mp4

# MKV → MP4 (с исправлением timestamps)
ffmpeg -i input.mkv -c copy -movflags +faststart output.mp4
```

### Конвертация с пережатием

```bash
# Универсальная конвертация в H.264
ffmpeg -i input.avi -c:v libx264 -crf 20 -preset medium -c:a aac -b:a 160k output.mp4

# Конвертация с GPU (NVIDIA)
ffmpeg -i input.mkv -c:v h264_nvenc -cq 20 -preset p5 -c:a aac -b:a 160k output.mp4

# Конвертация в H.265 (меньше размер)
ffmpeg -i input.mkv -c:v libx265 -crf 22 -preset medium -c:a aac -b:a 160k output.mp4
```

### Извлечение аудио

```bash
# Извлечь аудио без перекодирования
ffmpeg -i video.mp4 -vn -c:a copy audio.aac

# Извлечь аудио в MP3
ffmpeg -i video.mp4 -vn -c:a libmp3lame -b:a 192k audio.mp3

# Извлечь аудио в WAV (lossless)
ffmpeg -i video.mp4 -vn -c:a pcm_s16le audio.wav
```

### Обрезка видео

```bash
# Обрезка без перекодирования (быстро, но неточно)
ffmpeg -i input.mp4 -ss 00:01:00 -to 00:05:00 -c copy output.mp4

# Обрезка с перекодированием (точно до кадра)
ffmpeg -i input.mp4 -ss 00:01:00 -to 00:05:00 -c:v libx264 -crf 20 -c:a aac output.mp4

# Убрать первые 30 секунд
ffmpeg -i input.mp4 -ss 00:00:30 -c copy output.mp4
```

### Масштабирование

```bash
# Уменьшить до 720p
ffmpeg -i input.mp4 -vf scale=1280:720 -c:a copy output.mp4

# Уменьшить до 720p (сохранить пропорции)
ffmpeg -i input.mp4 -vf "scale=1280:-2" -c:a copy output.mp4

# Увеличить до 4K
ffmpeg -i input.mp4 -vf scale=3840:2160 -c:a copy output.mp4
```

### Склейка файлов

```bash
# Создать файл list.txt:
# file 'part1.mp4'
# file 'part2.mp4'
# file 'part3.mp4'

ffmpeg -f concat -safe 0 -i list.txt -c copy output.mp4
```

### Создание GIF

```bash
# Создать GIF из видео (10 секунд, 15 fps, ширина 480)
ffmpeg -i input.mp4 -ss 00:00:05 -t 10 -vf "fps=15,scale=480:-1" output.gif

# Качественный GIF (два прохода через палитру)
ffmpeg -i input.mp4 -vf "fps=15,scale=480:-1:flags=lanczos,palettegen" palette.png
ffmpeg -i input.mp4 -i palette.png -filter_complex "fps=15,scale=480:-1:flags=lanczos[x];[x][1:v]paletteuse" output.gif
```

## 5. Цепочка аудиофильтров

### Рекомендуемый порядок фильтров для микрофона

```
1. Noise Gate (Шумоподавитель)
   Close Threshold:  -40 dB
   Open Threshold:   -36 dB
   Attack:           10 ms
   Hold:             200 ms
   Release:          100 ms

2. Noise Suppression (Подавление шума)
   Метод:            RNNoise
   Уровень:          По умолчанию

3. Compressor (Компрессор)
   Ratio:            3:1
   Threshold:        -20 dB
   Attack:           6 ms
   Release:          60 ms
   Output Gain:      6 dB

4. Limiter (Лимитер)
   Threshold:        -3 dB
   Release:          60 ms
```

### Настройки для разных микрофонов

**Конденсаторный микрофон (чувствительный):**
```
Noise Gate Close:     -35 dB
Noise Gate Open:      -30 dB
Compressor Threshold: -18 dB
Compressor Ratio:     4:1
```

**Динамический микрофон (менее чувствительный):**
```
Noise Gate Close:     -45 dB
Noise Gate Open:      -40 dB
Compressor Threshold: -22 dB
Compressor Ratio:     2.5:1
```

**USB гарнитура:**
```
Noise Gate Close:     -38 dB
Noise Gate Open:      -34 dB
Compressor Threshold: -20 dB
Compressor Ratio:     3:1
Noise Suppression:    RNNoise (обязательно!)
```

### Быстрая проверка уровня

| Индикатор          | Уровень       | Статус          |
|--------------------|---------------|-----------------|
| Зелёный            | -60...-20 dB  | Нормально       |
| Жёлтый             | -20...-9 dB   | Оптимально      |
| Красный            | -9...0 dB     | Слишком громко   |
| Пик в красном      | 0 dB и выше   | Клиппинг!       |

**Цель:** пики речи на -12...-6 dB, тишина не выше -40 dB.

## 6. Чеклист перед записью

### Быстрый чеклист (2 минуты)

- [ ] 1. Закрыть лишние программы (браузер, мессенджеры, обновления)
- [ ] 2. Включить режим «Не беспокоить» в Windows
- [ ] 3. Проверить свободное место на диске (минимум 10 ГБ)
- [ ] 4. Убедиться что выбрана правильная сцена
- [ ] 5. Проверить аудио: говоришь — индикатор двигается
- [ ] 6. Проверить что десктоп аудио захватывается (если нужно)
- [ ] 7. Сделать тестовую запись 10 секунд и проверить
- [ ] 8. Убедиться что формат записи — MKV (защита от потери данных)
- [ ] 9. Нажать «Начать запись»

### Полный чеклист (профессиональный)

**Система:**
- [ ] Закрыть лишние программы и вкладки браузера
- [ ] Отключить уведомления Windows (Focus Assist → Alarms Only)
- [ ] Отключить автообновления (Windows Update, Steam и т.д.)
- [ ] Проверить свободное место: минимум 20 ГБ для длинных записей
- [ ] Проверить что запись идёт на быстрый диск (SSD)
- [ ] Убрать лишнее с рабочего стола и панели задач

**OBS:**
- [ ] Правильная сцена выбрана
- [ ] Разрешение и FPS соответствуют задаче
- [ ] Энкодер настроен (NVENC/x264)
- [ ] Формат записи: MKV
- [ ] Путь сохранения файлов правильный

**Аудио:**
- [ ] Микрофон выбран правильный
- [ ] Уровень микрофона: пики на -12...-6 dB
- [ ] Фильтры микрофона включены и работают
- [ ] Десктоп аудио работает (если нужно)
- [ ] Нет фонового шума / гула / эха
- [ ] Тестовая запись 10 сек — прослушать

**Видео:**
- [ ] Захват экрана / окна работает корректно
- [ ] Камера работает (если используется)
- [ ] Оверлеи на месте (если используются)
- [ ] Превью показывает правильную картинку

**Финал:**
- [ ] Тестовая запись 15-30 сек → воспроизвести → всё ОК
- [ ] Начать запись!

## 7. Быстрые решения частых проблем

| Проблема | Решение |
|----------|---------|
| Чёрный экран при захвате | Попробуй «Захват экрана» вместо «Захват окна», или запусти OBS от администратора |
| Лаги/фризы при записи | Снизь CQ Level до 22-24, уменьши FPS до 30, используй NVENC вместо x264 |
| Нет звука в записи | Проверь Audio Mixer: не замьючен ли источник, правильное ли устройство выбрано |
| Файл повреждён (0 КБ) | Записывай в MKV — он устойчив к сбоям. Для MP4 используй ремукс после записи |
| Рассинхрон аудио/видео | Настройки → Аудио → Sample Rate 48 kHz. Sync Offset в Audio Mixer |
| Высокая нагрузка CPU | Переключись на NVENC. Если x264 — поставь preset «veryfast» |
| OBS не видит камеру | Закрой другие приложения, использующие камеру. Перезапусти OBS |
| Запись прерывается | Проверь место на диске. Записывай на SSD, не на HDD |
