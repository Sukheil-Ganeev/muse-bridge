# Плагины OBS Studio — Подробные описания (топ-10)

> Перенесено из SKILL.md (секция 2.6). Подробные описания каждого плагина.

OBS поддерживает плагины через OBS Plugin API. Устанавливаются через
инсталлятор или вручную в папку `obs-plugins/`.

---

## 1. StreamFX
- **Что:** продвинутые фильтры, 3D-трансформации, blur, источники
- **Зачем:** размытие фона без зелёного экрана, 3D-перспектива
- **Ссылка:** github.com/Xaymar/obs-StreamFX

## 2. Move Transition
- **Что:** плавные переходы между сценами с анимацией перемещения
- **Зачем:** профессиональные переходы (объекты двигаются, а не просто переключаются)
- **Ссылка:** github.com/exeldro/obs-move-transition

## 3. Advanced Scene Switcher
- **Что:** автоматическое переключение сцен по условиям
- **Зачем:** автоматизация (переключение по таймеру, окну, макросам)
- **Ссылка:** github.com/WarmUpTill/SceneSwitcher

## 4. Source Dock
- **Что:** отображение источников в док-панелях
- **Зачем:** предпросмотр нескольких камер/сцен одновременно

## 5. obs-backgroundremoval (Live Background Removal)
- **Что:** удаление фона вебкамеры без зелёного экрана
- **Зачем:** чистый фон камеры (AI-модель, работает локально)
- **Ссылка:** github.com/occ-ai/obs-backgroundremoval

## 6. obs-websocket (встроен с OBS 28+)
- **Что:** WebSocket API для удалённого управления OBS
- **Зачем:** управление через StreamDeck, Touch Portal, скрипты
- **Версия:** v5.x встроен в OBS 28+

## 7. Input Overlay
- **Что:** оверлей клавиатуры/мыши/геймпада
- **Зачем:** показать зрителям нажатия клавиш (туториалы, геймплей)

## 8. obs-shaderfilter
- **Что:** кастомные шейдеры (HLSL/GLSL) как фильтры
- **Зачем:** уникальные визуальные эффекты (волны, пиксели, глитч)

## 9. Closed Captions (obs-localvocal)
- **Что:** локальные субтитры через Whisper AI
- **Зачем:** автоматические субтитры в реальном времени (privacy, без облака)

## 10. Source Record
- **Что:** запись отдельных источников в отдельные файлы
- **Зачем:** записать камеру и экран в разные файлы для монтажа
