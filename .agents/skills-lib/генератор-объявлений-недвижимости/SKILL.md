# ГЕНЕРАТОР ОБЪЯВЛЕНИЙ О НЕДВИЖИМОСТИ ОАЭ

## ВВЕДЕНИЕ

Этот скилл создаёт профессиональные объявления о недвижимости для рассылки через WhatsApp и Telegram. Объявления оптимизированы для турагентов, брокеров и клиентов рынка ОАЭ.

### Когда использовать

- Создание объявления о продаже/аренде недвижимости
- Форматирование информации об объекте для мессенджеров
- Рассылка по базе турагентов и брокеров
- Оформление карточки объекта недвижимости

### Поддерживаемые типы

**Жилая недвижимость:**
- Апартаменты (Studio, 1-5BR, Duplex, Loft)
- Виллы (Standalone, Semi-detached, Compound)
- Таунхаусы (End unit, Middle unit)
- Пентхаусы (Half-floor, Full-floor, Duplex, Triplex)
- Hotel Apartments (Serviced, Short-term)

**Коммерческая недвижимость:**
- Офисы (Shell & Core, CAT A, Fitted)
- Этажи зданий (Full floor, Half floor)
- Retail (Магазины, шоурумы)
- Warehouse (Склады, Light Industrial)
- Land Plots (Residential, Commercial, Mixed-use)

**Новостройки:**
- Off-plan (Apartments, Villas, Townhouses)

### Минимальные данные для объявления

```

## РАЗДЕЛ 1: СИНТАКСИС ФОРМАТИРОВАНИЯ

### WhatsApp

```
*жирный текст*           → жирный
_курсивный текст_        → курсив
~зачёркнутый~            → зачёркнутый
```текст```              → моноширинный блок
`код`                    → инлайн код
───────────────          → разделитель (15 символов)
```

### Telegram

```
**жирный текст**         → жирный
__курсивный текст__      → курсив
~~зачёркнутый~~          → зачёркнутый
`код`                    → инлайн код
──────────────────       → разделитель (18 символов)
```

### Универсальные элементы

```
▫️                       → маркер списка (используем вместо •)
💰                       → перед ценой
⚠️                       → важная информация
📍                       → локация
```

### Валюта и курсы

```
Основная валюта: AED (дирхам ОАЭ)
Курс: 1 USD ≈ 3.67 AED (фиксированный)
```

### Формат указания цен

**Аренда:**
```
💰 *АРЕНДА: 140,000 AED/год*
_(~11,700 AED/месяц)_
```

**Продажа:**
```
💰 *ПРОДАЖА: 2,450,000 AED*
_(~$667,000)_
_Service charge: 18 AED/sq.ft._
```

**Офисы:**
```
💰 *АРЕНДА: 150 AED/sq.ft./год*
_Итого: 750,000 AED/год_
```

```
1 sq.ft. = 0.0929 m²
1 m² = 10.764 sq.ft.
```

## РАЗДЕЛ 7: ТИПИЧНЫЕ ОШИБКИ

### Не делай так

1. **Слишком длинные описания** — WhatsApp обрезает превью
2. **Путать sq.ft. и m²** — всегда уточняй единицы
3. **Забывать про паркинг** — важно для всех типов
4. **Не указывать чеки** — критично для аренды
5. **Путать BUA и Plot** — для вилл это разные цифры
6. **Использовать эмодзи везде** — только 💰 и ⚠️
7. **Не проверять форматирование** — WA и TG разные

### Делай так

1. Короткие чёткие фразы
2. Структурированные блоки
3. Маркеры ▫️ для списков
4. Жирный для заголовков и цены
5. Курсив для описаний
6. Разделители между блоками

## РАЗДЕЛ 8: FAQ

**Q: Какой максимальный размер объявления?**
A: 15-20 строк для WhatsApp, до 25 для Telegram.

**Q: Использовать ли эмодзи?**
A: Только 💰 перед ценой и ⚠️ для важного. Остальные — по запросу.

**Q: Как указывать цену — в год или в месяц?**
A: Для аренды: основная цена в год, месячная в скобках. Для продажи: полная сумма.

**Q: Нужно ли указывать USD?**
A: Опционально, в скобках после AED. Курс 3.67.

**Q: Как быть с неполными данными?**
A: Запроси недостающую информацию. Минимум: тип, район, площадь, цена, контакт.

## РАЗДЕЛ 12: КАЛЬКУЛЯТОР ROI

При запросе расчёта доходности недвижимости (ROI, yield, окупаемость).

**Формулы:**
```
Gross ROI = (Годовая аренда / Цена покупки) × 100
Net ROI = ((Годовая аренда - Расходы) / Цена покупки) × 100
```

**Типичные расходы:** Service charge 15-25 AED/sq.ft., Maintenance ~1%, Agency 5%, Vacancy 5-10%

**ROI по районам:**

| Район | Gross ROI | Net ROI | Appreciation |
|-------|-----------|---------|--------------|
| JVC | 8-10% | 6-8% | 5-8% |
| Dubai Marina | 5-7% | 3-5% | 7-10% |
| Downtown | 4-6% | 2-4% | 8-12% |
| Palm Jumeirah | 4-5% | 2-3% | 5-8% |
| Business Bay | 6-8% | 4-6% | 6-9% |
| Dubai Hills | 5-7% | 3-5% | 8-12% |

**Формула аннуитета:**

M = P × [r(1+r)^n] / [(1+r)^n - 1]

/недвижимость marina 2br аренда 120000
/недвижимость downtown studio продажа 850000
/недвижимость palm villa аренда 500000 furnished
/недвижимость difc офис аренда 150/sqft 5000sqft
```

### Сокращения районов

| Сокращение | Полное название |
|------------|-----------------|
| marina | Dubai Marina |
| downtown, dt | Downtown Dubai |
| palm | Palm Jumeirah |
| jvc | Jumeirah Village Circle |
| jlt | Jumeirah Lake Towers |
| difc | DIFC |
| hills | Dubai Hills Estate |
| creek | Creek Harbour |
| bay | Business Bay |
| jbr | JBR / Jumeirah Beach Residence |
| silicon | Dubai Silicon Oasis |
| sports | Dubai Sports City |
| motor | Motor City |
| arabian | Arabian Ranches |

### Алгоритм парсинга

1. Разбить команду по пробелам
2. Определить район (первое слово после /недвижимость)
3. Определить тип (studio, Xbr, villa, townhouse, офис)
4. Определить операцию (аренда/продажа)
5. Определить цену (число или X/sqft)
6. Собрать опции (остальное)

**Валидация:** цена слишком низкая/высокая — предупреждение; район не распознан — спросить; тип не указан — "apartment" по умолчанию.

→ Подробнее (параметры, примеры парсинга): `references/быстрые-команды.md`

## РАЗДЕЛ 23: УМНЫЕ РЕКОМЕНДАЦИИ ЦЕНЫ

Помочь оценить объект по рыночной стоимости.

**Факторы:**
- Повышают: высокий этаж (+5-15%), вид на море (+10-20%), премиум отделка (+10-20%), близко к метро (+5-10%)
- Понижают: низкий этаж (-5-10%), вид на стройку (-5-15%), старое здание (-5-10%), требует ремонта (-10-20%)

**Формула:** `Рекомендуемая цена = Базовая цена района × (1 + сумма коэффициентов)`

→ Подробнее (шаблон рекомендации, примеры): `references/рекомендации-цены.md`
