## 7. АЛГОРИТМ ВАЛИДАЦИИ

### Порядок проверок

1. **Проверка типа** - корректен ли тип недвижимости
2. **Проверка района** - существует ли район
3. **Проверка площади** - в пределах диапазона для типа
4. **Проверка цены** - в пределах диапазона для типа+район
5. **Проверка цены/sq.ft.** - соотношение цена/площадь
6. **Логические проверки** - этаж, паркинг, ванные, чеки

### Уровни критичности

| Уровень | Действие | Пример |
|---------|----------|--------|
| ERROR | Запросить исправление | Этаж > этажности |
| WARNING | Показать предупреждение | Цена ниже рынка на 30%+ |
| INFO | Информационное сообщение | Цена ниже рынка на 10-30% |

### Пороги отклонения

| Отклонение от диапазона | Уровень | Действие |
|-------------------------|---------|----------|
| 0-10% | Норма | Продолжить |
| 10-30% | INFO | Отметить |
| 30-50% | WARNING | Предупредить |
| >50% | WARNING (strong) | Настоятельно уточнить |

## 8. ОСОБЫЕ СЛУЧАИ

### Когда НЕ показывать предупреждение

1. **Off-plan** - цены могут быть ниже рынка
2. **Distressed sale** - срочная продажа
3. **Новые проекты** - launch prices
4. **Branded residences** - цены выше рынка
5. **Signature units** - уникальные объекты

### Исключения по районам

| Район | Особенность |
|-------|-------------|
| Emirates Hills | Нет верхней границы цен |
| Palm Jumeirah | Вариация цен очень большая |
| DIFC | Премиум сегмент, высокие цены |
| Al Barari | Luxury, цены выше среднего |

### Новые районы (ограниченные данные)

- Dubai Creek Harbour
- Dubai South
- MBR City
- Dubai Islands
- Tilal Al Ghaf

Для этих районов показывать: "Данные о ценах ограничены для нового района"
