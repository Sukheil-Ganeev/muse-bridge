## Формула расчёта

### Базовая формула

```
Рекомендуемая цена = Базовая цена района × Площадь × (1 + Сумма коэффициентов)
```

### Пример расчёта

**Вход:**
- Район: Dubai Marina
- Тип: 2BR
- Площадь: 1,400 sq.ft.
- Этаж: 35/50 (высокий)
- Вид: Partial sea view
- Здание: 5 лет
- Состояние: Хорошее
- Меблировка: Furnished

**Расчёт (продажа):**
```
Базовая цена: 1,500 AED/sq.ft. (середина диапазона 1,200-1,800)
Площадь: 1,400 sq.ft.
Базовая стоимость: 1,500 × 1,400 = 2,100,000 AED

Коэффициенты:
+ Высокий этаж: +7%
+ Partial sea view: +8%
+ Меблировка: +5% (для продажи меньше влияет)
= +20%

Итоговая цена: 2,100,000 × 1.20 = 2,520,000 AED
Диапазон: 2,400,000 - 2,650,000 AED
```

**Расчёт (аренда):**
```
Базовая цена: 85 AED/sq.ft./год (середина диапазона 65-100)
Площадь: 1,400 sq.ft.
Базовая аренда: 85 × 1,400 = 119,000 AED/год

Коэффициенты:
+ Высокий этаж: +7%
+ Partial sea view: +8%
+ Fully furnished: +10%
= +25%

Итоговая аренда: 119,000 × 1.25 = 148,750 AED/год
Диапазон: 140,000 - 160,000 AED/год
```

## Сравнение с рынком

### Интерпретация результатов

| Разница с оценкой | Интерпретация | Рекомендация |
|-------------------|---------------|--------------|
| -20% и ниже | Очень выгодная цена | Проверить почему так дёшево |
| -10% до -20% | Ниже рынка | Хорошая сделка |
| -5% до -10% | Немного ниже | Нормальная цена |
| -5% до +5% | На уровне рынка | Справедливая цена |
| +5% до +10% | Немного выше | Можно торговаться |
| +10% до +20% | Выше рынка | Завышенная цена |
| +20% и выше | Значительно выше | Не рекомендуется |

### Когда цена может быть выше рынка

- Уникальный вид (Burj Khalifa, Fountain)
- Редкая планировка
- Только что после ремонта
- Срочная потребность покупателя
- Ограниченное предложение в здании

### Когда цена может быть ниже рынка

- Срочная продажа
- Банковский залог/аукцион
- Проблемы с документами
- Скрытые дефекты
- Плохие соседи
- Ожидается стройка рядом

## Особые случаи

### Off-plan

Для off-plan корректировки другие:
- Стадия строительства: чем ближе к сдаче, тем дороже
- Payment plan: чем лучше план, тем выше цена
- Застройщик: Emaar/Meraas +10-15% к средней цене

### Penthouse

Для пентхаусов:
- Базовая надбавка: +20-40% к цене обычных квартир
- Private pool: +15-25%
- Private elevator: +10-15%
- Duplex: +10-20%

### Villa

Для вилл важен:
- Размер участка (plot size)
- Приватность
- Corner plot: +5-10%
- Beachfront: +50-100%
