# AI-описание из фото

Подробное руководство по анализу фотографий недвижимости и генерации описаний.

---

## Алгоритм работы

### 1. Получение фото
- Пользователь присылает одно или несколько фото
- Claude анализирует изображение с помощью vision capabilities
- Формируется структурированный отчёт

### 2. Анализ изображения
- Определение типа помещения
- Оценка стиля и качества
- Выявление ключевых особенностей
- Анализ вида из окна (если виден)

### 3. Генерация описания
- Создание продающего текста
- Адаптация под целевую аудиторию
- Форматирование для мессенджера

---

## Промпт для анализа

```
Проанализируй это фото недвижимости и опиши:
1. Тип помещения
2. Стиль интерьера
3. Ключевые особенности
4. Вид из окна (если виден)
5. Качество отделки (базовое/среднее/премиум/люкс)
6. Мебель (furnished/unfurnished)

Формат ответа:
- Тип: [...]
- Стиль: [...]
- Особенности: [...]
- Вид: [...]
- Отделка: [...]
- Мебель: [...]
- Описание для объявления (1-2 предложения): [...]
```

## Определение качества отделки

### Базовое (Budget)
- Простые материалы (ламинат, стандартная плитка)
- Базовая сантехника
- Минимальный декор
- Стандартные светильники

### Среднее (Standard)
- Качественные материалы
- Хорошая сантехника (Grohe, Hansgrohe)
- Современный дизайн
- Встроенная бытовая техника

### Премиум (Premium)
- Мрамор, натуральный камень
- Premium сантехника (Villeroy & Boch)
- Дизайнерские светильники
- Бытовая техника премиум-класса (Miele, Gaggenau)
- Умный дом базовый

### Люкс (Luxury)
- Редкие материалы (оникс, драгоценные камни)
- Дизайнерская мебель (B&B Italia, Minotti)
- Кастомные решения
- Полная система умного дома
- Потолки от 3.5м
- Приватные удобства (лифт, бассейн)

## Шаблоны описаний

### По типу помещения

**Гостиная:**
```
_Просторная гостиная [площадь] с [особенность] и видом на [вид]_
```
Примеры:
- _Просторная гостиная 45 кв.м с панорамными окнами и видом на Marina_
- _Элегантная гостиная в современном стиле с камином и видом на море_
- _Светлая open-plan гостиная с высокими потолками 3.5м_

**Спальня:**
```
_[Прилагательное] спальня с [особенность] и видом на [вид]_
```
Примеры:
- _Мастер-спальня с гардеробной и en-suite ванной с видом на Palm_
- _Уютная спальня с балконом и видом на сад_
- _Роскошная спальня с панорамными окнами и видом на Burj Khalifa_

**Кухня:**
```
_[Стиль] кухня с [техника/особенность]_
```
Примеры:
- _Современная кухня с техникой Miele и островом_
- _Просторная кухня open-plan с итальянским гарнитуром_
- _Полностью оборудованная кухня Poggenpohl с видом на Marina_

**Ванная:**
```
_[Стиль] ванная с [материалы/особенность]_
```
Примеры:
- _Мраморная ванная en-suite с двойной раковиной и джакузи_
- _Современная ванная с rain shower и подогревом полов_
- _Spa-ванная с отдельно стоящей ванной и видом на море_

**Балкон/Терраса:**
```
_[Размер] [тип] с видом на [вид]_
```
Примеры:
- _Просторная терраса 50 кв.м с приватным бассейном и видом на море_
- _Уютный балкон с зоной отдыха и видом на Marina_
- _Панорамная терраса с 360° видом на город_

## Множественные фото

### Алгоритм обработки

1. **Анализ каждого фото отдельно**
   - Определить тип помещения
   - Оценить качество
   - Выявить особенности

2. **Определение общего стиля**
   - Единый стиль интерьера
   - Общая цветовая гамма
   - Уровень отделки

3. **Составление комплексного описания**
   - Начать с главного selling point
   - Перечислить ключевые особенности
   - Указать виды

4. **Выделение главных selling points**
   - ТОП-3 особенности
   - Уникальные преимущества
   - Вид (если выдающийся)

### Пример комплексного описания

**Вход:** 5 фото (гостиная, кухня, спальня, ванная, вид)

**Анализ:**
- Гостиная: современный стиль, панорамные окна, высокие потолки
- Кухня: открытая планировка, остров, техника Miele
- Спальня: мастер с гардеробной, en-suite
- Ванная: мрамор, джакузи, двойная раковина
- Вид: Marina, яхты, закат

**Комплексное описание:**
```
_Современные апартаменты с панорамным видом на Dubai Marina_

▫️ Open-plan гостиная с высокими потолками 3.5м
▫️ Кухня с островом и техникой Miele
▫️ Мастер-спальня с гардеробной и en-suite
▫️ Мраморная ванная с джакузи
▫️ Потрясающий вид на Marina и яхты
```

## Ошибки и как их избежать

### Частые ошибки

1. **Преувеличение качества**
   - Стандартную отделку называть "люкс"
   - Решение: Использовать объективные критерии

2. **Неверное определение вида**
   - Путать Marina view и Sea view
   - Решение: Marina = видны яхты, Sea = открытое море

3. **Пропуск важных деталей**
   - Не заметить балкон или особенности
   - Решение: Систематический чеклист

4. **Субъективные оценки**
   - "Красивый", "уютный" без деталей
   - Решение: Конкретика (площадь, материалы, бренды)
