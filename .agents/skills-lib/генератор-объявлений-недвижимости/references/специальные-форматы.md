# Специальные форматы объявлений

## 1. СРОЧНАЯ ПРОДАЖА (Distressed Sale)

### Когда использовать
- Владелец срочно уезжает
- Финансовые обстоятельства
- Цена значительно ниже рынка
- Быстрое закрытие сделки

### Шаблон WhatsApp

```

_Цена ниже рынка на [X]%_
───────────────
*ОБЪЕКТ*
▫️ [Тип] | [X] BR | [X,XXX] sq.ft.
▫️ [Ключевые характеристики]

*ПОЧЕМУ СРОЧНО*
▫️ [Причина: релокация/смена планов]
▫️ Готовность к быстрой сделке

💰 *ЦЕНА: [X,XXX,XXX] AED*
_Рыночная цена: [X,XXX,XXX] AED_
_Экономия: [XXX,XXX] AED_

⚠️ *УСЛОВИЯ*
▫️ Сделка до [дата]
▫️ Минимум переговоров
▫️ Документы готовы

*КОНТАКТ:* [телефон]
```

### Пример заполненного объявления

```

_Цена ниже рынка на 12%_

▫️ Вид на море, высокий этаж

*ПОЧЕМУ СРОЧНО*
▫️ Релокация владельца в Европу
▫️ Готовность к быстрой сделке

💰 *ЦЕНА: 2,200,000 AED*
_Рыночная цена: 2,500,000 AED_
_Экономия: 300,000 AED_

⚠️ *УСЛОВИЯ*
▫️ Сделка до 15 февраля
▫️ Минимум переговоров
▫️ Документы готовы

*КОНТАКТ:* +971 50 XXX XXXX
```

### Что включать
- Причину срочности (без негатива)
- Сравнение с рыночной ценой
- Дедлайн
- Готовность документов

### Чего избегать
- Слово "проблемы"
- Давление на клиента
- Ложная срочность
- Негативные формулировки

### Формулировки причин срочности

| Ситуация | Как писать | Как НЕ писать |
|----------|------------|---------------|
| Финансовые трудности | "Смена инвестиционной стратегии" | "Срочно нужны деньги" |
| Развод | "Изменение семейных обстоятельств" | "Развод, делим имущество" |
| Переезд | "Релокация владельца" | "Уезжает навсегда" |
| Долги | "Реструктуризация портфолио" | "Проблемы с банком" |

- "Только для наших клиентов"
- "Впервые на рынке"
- "Off-market"
- "Приватная продажа"
- "До публикации"
- "Pocket listing"

| Уровень | Описание | Условия показа |
|---------|----------|----------------|
| Standard | Редкий тип недвижимости | Запись на просмотр |
| Premium | Off-market + редкость | Proof of funds |
| Ultra | VIP владелец | NDA + POF + предквалификация |


### Расчет показателей

```
Gross ROI = (Годовая аренда / Цена покупки) × 100%
Net ROI = ((Аренда - Service Charge - Расходы) / Цена) × 100%
```

### Типичные расходы для расчета Net ROI
- Service Charge: указан в объявлении
- DEWA подключение: ~2,000 AED
- Страховка: ~0.1% от стоимости
- Обслуживание: ~1-2% в год

### Популярные Payment Plans

| Тип | Структура | Когда выгодно |
|-----|-----------|---------------|
| 80/20 | 80% до сдачи / 20% при сдаче | Быстрое строительство |
| 60/40 | 60% до сдачи / 40% при сдаче | Средний вариант |
| Post-handover | Часть после сдачи в рассрочку | Для инвесторов |
| 1% monthly | 1% в месяц в течение строительства | Низкий входной порог |

### Типичные бонусы застройщиков
- DLD waiver (4% экономия)
- Service charge на 1-3 года
- Мебель в подарок
- Отделка Premium
- Регистрационный сбор
- Парковочное место бесплатно

## Советы по использованию специальных форматов

### Общие правила
1. **Честность** — не создавайте ложную срочность или эксклюзивность
2. **Цифры** — всегда подкрепляйте заявления конкретными данными
3. **Дедлайны** — указывайте реальные сроки
4. **Документы** — будьте готовы подтвердить информацию

### Когда использовать какой формат

| Ситуация | Рекомендуемый формат |
|----------|---------------------|
| Цена ниже рынка на 10%+ | Срочная продажа |
| Объект не в листинге | Эксклюзив |
| ROI выше 6% | Инвестиционный |
| Строящийся объект | Off-plan |
| Несколько покупателей | Аукцион |
| Продажа 2+ объектов | Пакет |

### Комбинирование форматов

Можно комбинировать элементы разных форматов:
- Срочная + Инвестиционная (срочная продажа с арендатором)
- Эксклюзив + Off-plan (закрытая продажа до запуска)
- Инвестиционная + Пакет (портфель с расчетом ROI)
