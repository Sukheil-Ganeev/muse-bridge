# Сравнение объектов недвижимости

Справочник по созданию сравнительных таблиц для клиентов, инвесторов и семей.

---

## Когда использовать сравнение

| Ситуация | Тип шаблона |
|----------|-------------|
| Клиент выбирает между 2-3 объектами | Базовое сравнение |
| Инвестор анализирует ROI | Инвестиционное сравнение |
| Семья ищет жильё с детьми | Семейное сравнение |
| Краткосрочная аренда vs долгосрочная | Финансовое сравнение |
| Off-plan vs Ready | Сравнение новостроек |

## Формулы расчёта

### Цена за sq.ft.

```
Price per sq.ft. = Total Price / Area (sq.ft.)

Пример:
1,800,000 AED / 1,450 sq.ft. = 1,241 AED/sq.ft.
```

### Gross ROI (валовая доходность)

```
Gross ROI = (Annual Rent / Purchase Price) × 100

Пример:
(110,000 / 1,800,000) × 100 = 6.1%
```

### Net ROI (чистая доходность)

```
Net ROI = ((Annual Rent - Expenses) / Purchase Price) × 100

Расходы включают:
- Service charge: 15-25 AED/sq.ft.
- Maintenance: ~1% от цены/год
- Agency fee: 5% от аренды
- Vacancy: 5-10% от аренды

Пример:
Аренда: 110,000 AED
Service charge: 1,450 × 17 = 24,650 AED
Maintenance: 18,000 AED
Agency: 5,500 AED
Vacancy: 5,500 AED
Итого расходы: 53,650 AED

Net ROI = ((110,000 - 53,650) / 1,800,000) × 100 = 3.1%
```

### Payback Period (срок окупаемости)

```
Payback = Purchase Price / Annual Net Income

Пример:
1,800,000 / 56,350 = 31.9 лет (без учёта appreciation)
```

## Best Practices

### 1. Выбор критериев сравнения

**Для аренды обязательно:**
- Цена (год/месяц)
- Площадь и цена/sq.ft.
- Локация
- Вид
- Меблировка
- Доступность

**Для покупки обязательно:**
- Цена и цена/sq.ft.
- ROI (gross и net)
- Service charge
- Возраст здания
- Golden Visa eligibility

**Для семей обязательно:**
- Количество спален
- Школы рядом
- Детская инфраструктура
- Безопасность

### 2. Объективность

- Указывай реальные плюсы и минусы каждого объекта
- Не скрывай недостатки
- Давай честную рекомендацию

### 3. Визуальная структура

- Используй одинаковый формат для всех объектов
- Выравнивай колонки с помощью │
- Выделяй итоговую рекомендацию

### 4. Рекомендация

Всегда завершай сравнение чёткой рекомендацией:
- Для кого какой объект лучше
- Почему именно этот выбор
- Компромиссы каждого варианта

## Частые вопросы

**Q: Сколько объектов максимум?**
A: Оптимально 2-3. Больше 3 — сложно воспринять.

**Q: Нужно ли указывать все параметры?**
A: Нет, только релевантные для ситуации клиента.

**Q: Как быть с неполными данными?**
A: Ставь прочерк (—) или "уточняется".

**Q: Нужен ли перевод на английский?**
A: Да, если клиент международный.
