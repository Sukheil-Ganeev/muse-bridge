# Быстрые команды для генерации объявлений

## Базовый синтаксис

```
/недвижимость [район] [тип] [операция] [цена] [опции]
```

Все параметры, кроме района, могут идти в любом порядке.

---

### Операция

| Параметр | Что означает |
|----------|--------------|
| `аренда`, `rent` | Аренда |
| `продажа`, `sale` | Продажа |

**По умолчанию:** Если не указано — спросит.

---

### Цена

| Формат | Пример | Описание |
|--------|--------|----------|
| `XXXXX` | `140000` | Цена в AED |
| `X.Xm`, `Xm` | `2.5m`, `3m` | Миллионы AED |
| `XXX/sqft` | `150/sqft` | Цена за sq.ft. (для офисов) |

**Примеры:**
- `120000` = 120,000 AED
- `2.5m` = 2,500,000 AED
- `150/sqft` = 150 AED/sq.ft./год

---

### Площадь

| Формат | Пример | Описание |
|--------|--------|----------|
| `XXXXsqft` | `1500sqft` | Площадь в sq.ft. |
| `XXXXm2` | `150m2` | Площадь в м² (конвертируется в sq.ft.) |

**Примеры:**
- `1500sqft` = 1,500 sq.ft.
- `150m2` = ~1,615 sq.ft.

## Алгоритм парсинга

### Шаг 1: Разбиение на токены

```
/недвижимость marina 2br аренда 140000 furnished wa
         ↓
Токены: [marina, 2br, аренда, 140000, furnished, wa]
```

### Шаг 2: Идентификация параметров

```
marina    → Район (первый токен)
2br       → Тип (паттерн \d+br)
аренда    → Операция (словарь)
140000    → Цена (число)
furnished → Меблировка (словарь)
wa        → Формат (словарь)
```

### Шаг 3: Применение defaults

```
Если не указан тип → apartment
Если не указан формат → WhatsApp
Если не указан язык → русский
```

### Шаг 4: Валидация

| Проверка | Действие |
|----------|----------|
| Район не распознан | Спросить уточнение |
| Цена вне диапазона | Предупреждение |
| Операция не указана | Спросить |

## Результат парсинга

После парсинга команда преобразуется в структурированный объект:

```json
{
  "район": "Dubai Marina",
  "район_код": "marina",
  "тип": "2BR Apartment",
  "операция": "Аренда",
  "цена": 140000,
  "цена_формат": "140,000 AED/год",
  "площадь": null,
  "меблировка": "Furnished",
  "вид": null,
  "чеки": null,
  "формат": "WhatsApp",
  "язык": "ru",
  "застройщик": null,
  "опции": []
}
```

Этот объект используется для генерации объявления по соответствующему шаблону.

## Советы по использованию

1. **Минимальная команда**: `/недвижимость marina 2br аренда 120000` — этого достаточно для генерации базового объявления.

2. **Уточнения**: Если чего-то не хватает, система спросит недостающие данные.

3. **Регистр**: Не важен — `MARINA`, `Marina`, `marina` работают одинаково.

4. **Порядок**: После района параметры могут идти в любом порядке.

5. **Сочетания**: Можно комбинировать любые опции: `wa tg` создаст обе версии.
