# VISA КАЛЬКУЛЯТОР

Справочник по визам при покупке недвижимости в ОАЭ.

---

## Типы виз для владельцев недвижимости

### Property Visa (2 года)

| Параметр | Значение |
|----------|----------|
| Минимальная стоимость | 750,000 AED |
| Срок действия | 2 года |
| Тип недвижимости | Жилая (Residential) |
| Статус объекта | Ready (сданный) |
| Продление | Возможно при сохранении владения |

**Требования:**
- Недвижимость должна быть жилой (не коммерческой)
- Объект должен быть полностью оплачен и сдан
- Один объект или несколько с общей стоимостью от 750,000 AED
- Недвижимость должна быть в freehold зоне

**Включает:**
- Владелец недвижимости
- Супруг/супруга
- Дети до 18 лет (сыновья до 25 при обучении)
- Родители (при определённых условиях)

---

### Golden Visa (10 лет)

| Параметр | Значение |
|----------|----------|
| Минимальная стоимость | 2,000,000 AED |
| Срок действия | 10 лет |
| Тип недвижимости | Жилая (Residential) |
| Статус объекта | Ready или Off-plan (50%+ оплачено) |
| Продление | Автоматическое при сохранении владения |

**Требования для Ready:**
- Стоимость от 2,000,000 AED
- Один объект или несколько с общей стоимостью
- Недвижимость жилая в freehold зоне
- Полная оплата

**Требования для Off-plan:**
- Стоимость от 2,000,000 AED
- Оплачено минимум 50% стоимости
- Застройщик должен быть одобрен DLD
- Недвижимость жилая

**Включает:**
- Владелец недвижимости
- Супруг/супруга
- Дети (без ограничения возраста)
- Домашний персонал (по количеству спален)

## Сравнение виз

| Критерий | Property Visa | Golden Visa |
|----------|---------------|-------------|
| Мин. стоимость | 750,000 AED | 2,000,000 AED |
| Срок | 2 года | 10 лет |
| Off-plan | Нет | Да (50%+) |
| Дети без ограничений | Нет | Да |
| Автопродление | Нет | Да |
| Можно жить вне ОАЭ | До 6 месяцев | Без ограничений |

| Стоимость объекта | Доступные визы |
|-------------------|----------------|
| до 750,000 AED | Нет визы |
| 750,000 - 1,999,999 AED | Property Visa (2 года) |
| от 2,000,000 AED | Property Visa (2 года) + Golden Visa (10 лет) |

## Процесс получения визы

### Шаг 1: Подготовка документов

**Для Property Visa:**
- Паспорт (действующий)
- Title Deed
- Фото 4x6
- Медицинский тест
- Emirates ID application

**Для Golden Visa:**
- Паспорт (действующий)
- Title Deed или договор купли-продажи с 50%+ оплатой
- Фото 4x6
- Медицинский тест
- Страховка
- Подтверждение финансовой состоятельности

### Шаг 2: Подача заявки

| Канал | Описание |
|-------|----------|
| ICP (Federal Authority) | Федеральный портал визовых услуг |
| GDRFA Dubai | Для недвижимости в Дубае |
| GDRFA Abu Dhabi | Для недвижимости в Абу-Даби |
| Amer Centre | Офлайн подача документов |

### Шаг 3: Сроки и стоимость

| Услуга | Property Visa | Golden Visa |
|--------|---------------|-------------|
| Госпошлина | ~1,000-1,500 AED | ~2,000-3,000 AED |
| Медтест | ~300-500 AED | ~300-500 AED |
| Emirates ID | ~370 AED | ~370 AED |
| Срок обработки | 2-4 недели | 2-4 недели |

## Важные нюансы

### Совместное владение

- Можно объединить несколько объектов для достижения минимума
- Совместное владение (joint ownership): каждый владелец должен иметь долю от 750,000 AED для Property Visa
- Для Golden Visa: доля каждого владельца от 2,000,000 AED

### Ипотека

- Объект с ипотекой подходит для визы
- Считается полная стоимость объекта, не выплаченная сумма
- Главное — объект зарегистрирован на ваше имя

### Коммерческая недвижимость

- **НЕ подходит** для Property Visa и Golden Visa
- Офисы, retail, склады — не дают право на визу
- Только жилая недвижимость (residential)

### Несколько объектов

- Можно суммировать стоимость
- Все объекты должны быть жилыми
- Все должны быть в freehold зонах

## Часто задаваемые вопросы

**Q: Можно ли получить визу на off-plan за 750,000 AED?**
A: Нет. Property Visa требует Ready объект. Golden Visa возможна для off-plan от 2,000,000 AED при оплате 50%+.

**Q: Что если я продам недвижимость?**
A: Виза аннулируется. Для сохранения визы нужно иметь недвижимость.

**Q: Можно ли работать с Property Visa?**
A: Да, но нужно получить разрешение на работу от работодателя.

**Q: Как включить родителей в Golden Visa?**
A: Родители включаются отдельной заявкой. Нужно подтверждение родства и финансовой зависимости.

**Q: Что если стоимость недвижимости упала ниже минимума?**
A: Учитывается цена покупки (из Title Deed), а не текущая рыночная стоимость.
