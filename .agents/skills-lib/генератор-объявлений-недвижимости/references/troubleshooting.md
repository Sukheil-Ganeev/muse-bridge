# Troubleshooting — Решение проблем

## Проблемы с форматированием

### Текст не становится жирным в WhatsApp

**Симптом:** Звёздочки видны, но текст обычный

**Решение:**
1. Убедитесь, что нет пробелов: `*ТЕКСТ*` не `* ТЕКСТ *`
2. Проверьте, что звёздочки с обеих сторон
3. Не используйте перенос строки внутри форматирования
4. Скопируйте текст заново (возможно, невидимые символы)

---

### Разделитель выглядит странно

**Симптом:** Линия прерывается или отображается неправильно

**Решение:**
- Используйте символ `─` (U+2500), не дефис `-`
- Для WhatsApp: 15 символов
- Для Telegram: 18 символов
- Скопируйте готовый: `───────────────`

---

### Эмодзи не отображаются

**Симптом:** Квадратики или пустые места вместо эмодзи

**Решение:**
1. Используйте стандартные эмодзи: 💰 ⚠️ ▫️
2. Проверьте шрифты устройства получателя
3. Замените на текстовые маркеры: - или •

---

## Проблемы с содержанием

### Объявление слишком длинное

**Симптом:** Текст обрезается в превью WhatsApp

**Решение:**
1. Сократите описание до 1 строки
2. Уберите необязательные детали
3. Используйте сокращения (BR, sq.ft.)
4. Оптимальная длина: 15-20 строк

**Пример сокращения:**
```
ДО:
Площадь квартиры: 1,450 квадратных футов
Количество спален: 2
Количество ванных комнат: 3

ПОСЛЕ:
▫️ 2 спальни | 3 ванные | 1,450 sq.ft.
```

---

### Не хватает данных для объявления

**Симптом:** Клиент дал мало информации

**Решение:**

Минимальный набор:
1. Тип (апартаменты/вилла)
2. Район
3. Цена
4. Контакт

Всё остальное — "детали по запросу" или опустить.

**Пример минимального объявления:**
```
*2BR АПАРТАМЕНТЫ | DUBAI MARINA*
───────────────
💰 *АРЕНДА: 140,000 AED/год*

Детали по запросу
*КОНТАКТ:* +971 50 XXX XXXX
```

---

### Неизвестный район

**Симптом:** Клиент указал незнакомую локацию

**Решение:**
1. Уточните у клиента полное название
2. Проверьте по Google Maps
3. Используйте общее название (Dubai вместо конкретного района)
4. Смотрите references/локации-оаэ.md

## Проблемы с ценами

### Не знаю курс USD

**Решение:**
Курс фиксированный: **1 USD = 3.67 AED**

```
AED → USD: разделить на 3.67
USD → AED: умножить на 3.67
```

---

### Путаница sq.ft. и m²

**Решение:**
В ОАЭ стандарт — **sq.ft.** (квадратные футы)

Конверсия:
```
sq.ft. × 0.093 = m²
m² × 10.76 = sq.ft.
```

Если дали в m², конвертируйте в sq.ft. для объявления.

---

### Не указан service charge

**Решение:**
- Для продажи: опустите или напишите "уточняйте"
- Типичные значения:
  - Стандартные здания: 12-18 AED/sq.ft.
  - Премиум: 20-30 AED/sq.ft.
  - Люкс: 30-50 AED/sq.ft.

## Проблемы с типами недвижимости

### Путаница BUA и Plot для вилл

**Симптом:** Указана только одна площадь

**Решение:**
- **BUA** = площадь ДОМА (Built-Up Area)
- **Plot** = площадь УЧАСТКА

Всегда указывайте ОБА значения для вилл и таунхаусов.

Если дали одно число — уточните, что это.

---

### Не понятно Fitted или Shell & Core

**Симптом:** Нет информации об отделке офиса

**Решение:**
Уточните у клиента или по фото:
- **Shell & Core** — бетонные стены, нет потолка
- **CAT A** — есть потолок, пол, освещение, но пусто
- **Fitted** — есть мебель, рабочие места

---

### Пентхаус без террасы?

**Симптом:** Площадь террасы не указана

**Решение:**
1. Уточните — терраса обязательна для пентхаусов
2. Если нет террасы — возможно, это не пентхаус, а апартаменты высокого этажа
3. Укажите "терраса: уточняйте"

## Прочие проблемы

### Клиент хочет объявление на английском

**Решение:**
Этот скилл для русского языка. Для английского:
1. Замените заголовки на английские
2. Сохраните структуру
3. Термины уже на английском (sq.ft., BR, etc.)

---

### Нужно много объявлений сразу

**Решение:**
1. Создавайте по одному
2. Используйте шаблоны из assets/templates/
3. Копируйте структуру, меняйте данные

---

### Объявление не работает (нет откликов)

**Возможные причины:**
1. Цена не рыночная — проверьте аналоги
2. Мало фотографий — добавьте качественные фото
3. Неправильная аудитория — проверьте группы рассылки
4. Текст слишком сухой — добавьте эмоциональное описание

---
