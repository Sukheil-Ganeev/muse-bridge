# Шпаргалка синтаксиса: WhatsApp / Telegram / Email

## Быстрая таблица форматирования

| Что | WhatsApp | Telegram | Email |
|-----|----------|----------|-------|
| **Жирный** | `*текст*` | `**текст**` | Нет |
| **Курсив** | `_текст_` | `__текст__` | Нет |
| **Зачёркнутый** | `~текст~` | `~~текст~~` | Нет |
| **Моно (инлайн)** | `` `текст` `` | `` `текст` `` | Нет |
| **Моно (блок)** | ` ```текст``` ` | ` ```текст``` ` | Нет |
| **Спойлер** | Нет | `\|\|текст\|\|` | Нет |
| **Ссылки** | Нет (вставлять URL) | `[текст](url)` | Plain URL |
| **Цитаты** | `> _курсивом_` | `> __курсивом__` | Кавычки |

## Разделители

| Тип | WhatsApp (15 символов) | Telegram (18 символов) |
|-----|------------------------|------------------------|
| Стандартный | `───────────────` | `──────────────────` |
| Двойной | `━━━━━━━━━━━━━━━` | `━━━━━━━━━━━━━━━━━━` |

**Email:** разделители НЕ используются.

## Списки (общие для WA и TG)

```
▫️ Основной маркер
• Альтернативный маркер
— Длинное тире (НЕ дефис -)
1️⃣ 2️⃣ 3️⃣ Нумерованные
✅ Сделано / ❌ Нет / ⬜ Ожидание
```

## Эмодзи-маркеры (WA и TG)

Позиция: **ПЕРЕД** текстом, НЕ после.

```
📌 Важное
📋 Список / документ
⚠️ Предупреждение
💡 Совет
📅 Дата / расписание
👤 Персона
📧 Контакт
⚡️ Итог / действие
🔑 Ключевое
```

## Лимиты

| Платформа | Лимит | Рекомендация |
|-----------|-------|--------------|
| WhatsApp | Превью ~1000 символов | 1 пост = 1 тема |
| Telegram | 4096 символов/сообщение | До 3000 символов |
| Email | Нет жёсткого | 300-800 слов (юрид. до 1000) |

## Запрещено

| Ошибка | WA | TG | Email |
|--------|----|----|-------|
| Дефисы `---` как разделители | X | X | — |
| Эмодзи ПОСЛЕ заголовка | X | X | — |
| Эмодзи вообще | — | — | X |
| Markdown-ссылки | X | — | — |
| `*жирный*` (одинарные) | — | X | X |
| `**жирный**` (двойные) | X | — | X |
| HTML-теги | X | — | — |
| Разделители `────` | — | — | X |
| Сленг / разговорный тон | — | — | X |

## Быстрый пример: одно и то же сообщение в 3 форматах

### WhatsApp
```
*СТАТУС БРОНИРОВАНИЯ*
📅 _17 февраля 2026_

━━━━━━━━━━━━━━━

✅ *Оплачено*
▫️ Desert Safari — 4 билета

───────────────

📅 *Дата экскурсии:* 20 февраля

_Подробности уточняйте_
```

### Telegram
```
**СТАТУС БРОНИРОВАНИЯ**
```
