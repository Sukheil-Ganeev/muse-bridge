# Experience Index — Vercel Deployment

## 🎯 Критические уроки (топ-5)

> **ВАЖНО:** Читай эту секцию КАЖДЫЙ РАЗ при активации скилла!

### 1. CLI workflow: `vercel` (preview) vs `vercel --prod` (production)
**Проблема:** Непонятно, какую команду использовать для деплоя
**Решение:**
- `vercel` — preview деплой (тестовая версия, уникальный URL)
- `vercel --prod` — production деплой (на основной домен)
**Когда важно:** Первый деплой, понимание workflow

### 2. Vercel CLI должен быть установлен глобально
**Проблема:** Попытка использовать `vercel` без установки → command not found
**Решение:** `npm install -g vercel` или `pnpm add -g vercel`
**Когда важно:** Первая попытка деплоя через CLI

### 3. Environment Variables НЕ работают локально без `vercel env pull`
**Проблема:** Переменные окружения не видны при локальной разработке
**Решение:**
1. Добавить переменные в Vercel Dashboard
2. Запустить `vercel env pull` для загрузки в локальный `.env`
**Когда важно:** Использование API ключей, секретов

### 4. Vercel оптимизирован для Next.js, но работает со всем
**Проблема:** Непонятно, можно ли использовать без Next.js
**Решение:** Да, Vercel поддерживает любые статичные сайты, но оптимизирован для Next.js
**Когда важно:** Выбор платформы для деплоя
**Подробно:** references/vercel-vs-netlify.md

### 5. Preview Deployments создаются автоматически для каждого PR
**Проблема:** Как протестировать изменения перед мерджем в main
**Решение:** Vercel автоматически создаёт preview URL для каждого pull request
**Когда важно:** Командная работа, code review
**Подробно:** SKILL.md → секция "Preview Deployments"
