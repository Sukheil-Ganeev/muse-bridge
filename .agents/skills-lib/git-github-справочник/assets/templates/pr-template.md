## Как протестировать

<!-- Пошаговая инструкция для ревьюера -->

1. Склонируй ветку:
   ```bash
   git fetch origin
   git checkout <branch-name>
   ```

2. Установи зависимости (если нужно):
   ```bash
   npm install
   # или
   pip install -r requirements.txt
   ```

3. Запусти приложение:
   ```bash
   npm start

   python app.py
   ```
