# Шаблон хорошего commit message
# Используй этот формат для понятных и информативных коммитов

<type>(<scope>): <subject>

<body>

<footer>

# ──────────────────────────────────────────────────────────────
# СТРУКТУРА:
# ──────────────────────────────────────────────────────────────

# 1. ЗАГОЛОВОК (обязательно):
# <type>(<scope>): <subject>
#
# - type: тип изменения (обязательно)
# - scope: область изменения (опционально)
# - subject: краткое описание (обязательно, до 50 символов)

# 2. ТЕЛО (опционально):
# Детальное описание изменения
# - Что изменено
# - Почему изменено
# - Как это работает

# 3. ПОДВАЛ (опционально):
# Ссылки на issues, breaking changes

# ──────────────────────────────────────────────────────────────
# ТИПЫ (type):
# ──────────────────────────────────────────────────────────────

# feat:     Новая функциональность
# fix:      Исправление бага
# docs:     Изменения в документации
# style:    Форматирование кода (пробелы, отступы, не меняет логику)
# refactor: Рефакторинг кода (не добавляет фичи, не исправляет баги)
# perf:     Улучшение производительности
# test:     Добавление или изменение тестов
# build:    Изменения в системе сборки или зависимостях
# ci:       Изменения в CI/CD конфигурации
# chore:    Рутинные задачи, обновления зависимостей
# revert:   Откат предыдущего коммита

# ──────────────────────────────────────────────────────────────
# ПРИМЕРЫ:
# ──────────────────────────────────────────────────────────────

# Пример 1: Простой коммит
# feat: add user authentication
#
# Пример 2: С областью (scope)
# fix(auth): resolve token expiration issue
#
# Пример 3: С телом
# feat(api): add endpoint for user profile
#
# Implement GET /api/user/profile endpoint that returns
# user information including name, email, and avatar.
# Requires authentication token.
#
# Пример 4: С breaking change
# feat(api): change authentication flow
#
# BREAKING CHANGE: Authentication now requires OAuth2 instead
# of basic auth. Update all API clients accordingly.
#
# Closes #123
#
# Пример 5: Исправление с issue reference
# fix(ui): button alignment on mobile
#
# Fixes #456

# ──────────────────────────────────────────────────────────────
# ПРАВИЛА:
# ──────────────────────────────────────────────────────────────

# ✓ Заголовок не более 50 символов
# ✓ Заголовок начинается с маленькой буквы
# ✓ Заголовок без точки в конце
# ✓ Используй повелительное наклонение (add, not added)
# ✓ Тело коммита до 72 символов на строку
# ✓ Отделяй заголовок от тела пустой строкой
# ✓ Используй тело для объяснения "что" и "почему", не "как"
# ✓ Один коммит = одно логическое изменение

# ──────────────────────────────────────────────────────────────
# ИСПОЛЬЗОВАНИЕ ШАБЛОНА:
# ──────────────────────────────────────────────────────────────

# Установить как глобальный шаблон:
# git config --global commit.template ~/.gitmessage

# Использовать для одного коммита:
# git commit --template commit-message-template.txt
