# Протокол работы с опытом скиллов

## Обзор

Система experience/ позволяет скиллам накапливать и применять опыт:
- **Статичные инструкции** (SKILL.md) — базовые правила
- **Динамический опыт** (experience/) — уроки из практики

---

## Структура experience/

```
experience/
├── _index.md             # Индекс + топ-5 критических уроков
├── fixes/                # Исправленные ошибки
├── improvements/         # Найденные улучшения
├── patterns/             # Повторяющиеся паттерны
└── warnings/             # Что НЕ делать
```

---

## Когда записывать опыт

### Триггеры для записи

| Событие | Тип записи | Папка |
|---------|------------|-------|
| Исправлена ошибка | fix | fixes/ |
| Найден лучший способ | improvement | improvements/ |
| Обнаружен повторяющийся паттерн | pattern | patterns/ |
| Нашли что НЕ работает | warning | warnings/ |

### Уровни severity

- **critical** — влияет на работоспособность, нужно помнить ВСЕГДА
- **high** — значительно ускоряет работу
- **medium** — полезно знать
- **low** — мелкое улучшение

---

## Как записывать опыт

### Шаг 1: Определи тип и severity

```
Исправил ошибку? → fixes/ (severity по влиянию)
Нашёл лучший способ? → improvements/
Заметил паттерн? → patterns/
Нашёл что не работает? → warnings/
```

### Шаг 2: Создай файл

Формат имени: `EXP-XXX-краткое-описание.md`

Пример: `EXP-001-body-height-100.md`

### Шаг 3: Заполни по шаблону

Используй шаблон: `_experience-system/templates/experience-entry.md`

### Шаг 4: Обнови _index.md

Добавь ссылку в соответствующую секцию и обнови топ-5 если нужно.

---

## Как читать опыт

### При активации скилла

1. Проверь наличие `experience/_index.md`
2. Прочитай секцию "Критические уроки (топ-5)"
3. Держи в уме при выполнении задачи

### При проблемах

1. Загляни в соответствующую папку (fixes/, warnings/)
2. Поищи по тегам или ключевым словам

---

## Команды пользователя

| Команда | Действие |
|---------|----------|
| "запиши в опыт" / "запиши это в опыт" | Создать новую запись опыта |
| "покажи опыт [скилла]" | Показать _index.md скилла |
| "что знаешь про [проблему]" | Поиск в experience/ по ключевым словам |

---

## Нумерация записей

Формат ID: `EXP-XXX` где XXX — порядковый номер в рамках скилла.

Следующий номер определяется по последнему файлу в experience/

---

## Миграция из troubleshooting.md

Если скилл имеет `references/troubleshooting.md`:

1. Каждая ошибка → отдельный файл в `experience/fixes/`
2. Сохрани оригинал для истории
3. Добавь все в `_index.md`

---

## Автоматическая инициализация

Скрипт `init_experience.py` создаёт базовую структуру для скиллов.

```bash
python init_experience.py                    # Все скиллы
python init_experience.py имя-скилла         # Конкретный скилл
```
