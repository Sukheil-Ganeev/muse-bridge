# FAQ — Max Bot API

## Общие вопросы

### Где зарегистрировать бота?
Через **@MasterBot** в мессенджере Max. Отправьте `/start`, затем `/create`. Придумайте никнейм (мин. 11 символов, суффикс `_bot` или `bot`).

### Какой Base URL у API?
```
https://platform-api.max.ru
```
Старый домен `botapi.max.ru` больше не поддерживается.

### Как передавать токен?
Только через заголовок `Authorization`:
```
Authorization: YOUR_TOKEN
```
Query parameter `access_token` больше не работает.

### Max Bot API — это VK Bot API?
**Нет.** Max Bot API базируется на TamTam Bot API — это отдельный REST API со своим форматом. НЕ используйте методы VK API (`messages.send`, `vk_api` и т.д.) — они не работают.

### Какой лимит запросов?
30 запросов в секунду (RPS). При превышении — ошибка 429.

### Какой максимальный размер сообщения?
4000 символов текста.

## Регистрация и токен

### Минимальная длина никнейма бота?
11 символов, включая суффикс `_bot` или `bot`. Примеры: `dubaitours_bot`, `safariuae_bot`.

### Как восстановить токен?
Через @MasterBot — команда для управления вашими ботами. Можно сгенерировать новый токен (старый перестанет работать).

### Нужна ли верификация юрлица для бота?
С 2026 года для **публикации** ботов и Mini Apps требуется верифицированное юрлицо РФ. Для разработки и тестирования — нет.

## Сообщения и медиа

### Какие форматы текста поддерживаются?
Поле `format` в POST /messages: `markdown` или `html`.

### Как отправить фото?
Трёхшаговый процесс:
1. `POST /uploads?type=photo` — получить upload URL
2. Загрузить файл на upload URL
3. Отправить сообщение с `token` из шага 2

### Максимальный размер фото/видео?
- Фото: до 50 MB
- Видео: до 2 GB
- Аудио/файлы: до 100 MB

### Можно ли отправлять стикеры?
Да, тип attachment — `sticker`. Используйте `sticker_id` из стикерпака.

## Клавиатуры и кнопки

### Сколько кнопок можно в клавиатуре?
До 210 кнопок: 30 рядов по 7 кнопок. Для типов `link`, `open_app`, `request_contact`, `request_geo_location` — максимум 3 кнопки в ряду.

### Как обработать нажатие кнопки?
1. Пользователь нажимает callback-кнопку
2. Бот получает событие `message_callback` с `callback_id` и `payload`
3. Бот отвечает через `POST /answers` с `callback_id`

### Что такое intent у кнопки?
Визуальный стиль: `default` (стандартный), `positive` (зелёный), `negative` (красный).

## Webhooks и Long Polling

### Что лучше — Webhook или Long Polling?
- **Long Polling** — для разработки, тестов, простых ботов
- **Webhook** — для продакшена, высоких нагрузок
- Одновременно может быть активен только один режим

### Webhook поддерживает HTTP?
**Нет**, только HTTPS. Самоподписанные сертификаты допускаются.

### Как переключиться с Long Polling на Webhook?
`POST /subscriptions` с URL вашего webhook. Long Polling автоматически отключится.

## Для туризма ОАЭ

### Можно ли использовать Max Bot API из ОАЭ?
Да, API доступен глобально. Но для **публикации** бота с 2026 года нужно верифицированное юрлицо РФ.

### Какой процент аудитории из Max — туристы из РФ?
Max ориентирован на российский рынок. Для туристов из РФ, прилетающих в Дубай, Max может быть удобным каналом коммуникации наряду с Telegram и WhatsApp.

### Можно ли принимать оплату через Max бот?
Напрямую — нет (встроенные платежи только для юрлиц РФ). Но можно отправлять ссылку на оплату (кнопка `link`) на вашу платёжную страницу.
