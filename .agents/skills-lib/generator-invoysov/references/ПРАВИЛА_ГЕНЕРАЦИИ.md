## 1. КОНСТАНТЫ (неизменяемые элементы)

### 1.1 Размер документа

```
Формат: A4 (210mm x 297mm)
Размер слайда: 8.26" x 11.68"
```

### 1.2 Заголовок документа

```
Текст: "INVOICE"
Формат: Жирный, чёрный (#1F1F1F)
```

### 1.3 Структура таблицы услуг

| Колонка | Обязательная | Описание |
|---------|--------------|----------|
| # | Да | Порядковый номер строки (1, 2, 3...) |
| DESCRIPTION | Да | Описание услуги (CAPS) |
| Price (Excl. VAT) | Да | Цена без НДС |
| Amount (Excl. VAT) | Да | Сумма без НДС |
| VAT 5%, Amount | Да | Сумма НДС (5%) |
| Amount (Incl. VAT) | Да | Итого с НДС |

**Опциональные колонки:**
- `hours` - для почасовой аренды
- `Quantity` - для количества единиц

### 1.4 VAT (НДС)

```
Ставка: 5%
Формула: VAT = Amount (Excl. VAT) * 0.05
Округление: до сотых (2 знака после запятой)
```

### 1.5 Шрифты

```
Основной текст: Arial
Дополнительный: Segoe UI, Microsoft Sans Serif
```

### 1.6 Цвета

| Элемент | HEX-код |
|---------|---------|
| Основной текст | #3B3B3B |
| Заголовки | #1F1F1F |
| Фон таблиц | #FFFFFF |
| Шапка таблицы | Красный (фон), белый (текст) |

### 1.7 Фиксированные тексты

```
"Bill To:" - перед именем клиента
"Contact number:" - перед телефоном клиента
"Address:" - перед адресом клиента
"Issued By:" - перед реквизитами компании
"Invoice Date:" - перед датой инвойса
"COMPANY BANK ACCOUNT" - заголовок банковских реквизитов
"Total:" - перед итоговой суммой
```

## 2. ПЕРЕМЕННЫЕ (всегда меняются)

### 2.1 Номер инвойса

```
Формат: #YY-XXX или #YY-XXXX
Где:
  YY = последние 2 цифры года
  XXX/XXXX = порядковый номер (3-4 цифры)

Примеры:
  #26-398 (год 2026, номер 398)
  #22-0121 (год 2022, номер 121)
```

### 2.2 Дата инвойса

```
ЭТАЛОННЫЙ формат: Mon DD, YYYY (Jan 22, 2026)
Альтернативный: Month DD, YYYY (January 22, 2026)
```

### 2.3 Данные клиента

| Поле | Формат |
|------|--------|
| Bill To | CAPS для физ. лиц: `ФАМИЛИЯ ИМЯ [ОТЧЕСТВО]` |
| Bill To (компания) | `НАЗВАНИЕ КОМПАНИИ L.L.C/LLC` |
| Contact number | Международный формат с кодом страны |
| Address | Краткий (UAE) или полный адрес |

### 2.4 Услуги и цены

- Описание услуги (DESCRIPTION)
- Цена без НДС
- Количество/часы (если применимо)
- Даты оказания услуги
- Время начала/окончания

## 3. ОПЦИОНАЛЬНЫЕ ЭЛЕМЕНТЫ

### 3.1 POS Terminal

```
ЕСЛИ оплата картой через терминал:
  → Добавить строку: "PAYMENT VIA POS TERMINAL + X%"
  → X = 3.5% или 4%
  → Рассчитать: комиссия = Total * X / 100
  → Добавить комиссию к Total

ИНАЧЕ:
  → Не добавлять строку POS Terminal
```

**Когда использовать:**
- B2C клиенты (физические лица)
- Оплата на месте картой

**Когда НЕ использовать:**
- B2B клиенты (юридические лица)
- Оплата банковским переводом

### 3.2 Адрес клиента

```
ЕСЛИ физическое лицо без полного адреса:
  → Address: UAE (или страна клиента)

ЕСЛИ физическое лицо без информации об адресе:
  → Address: -

ЕСЛИ юридическое лицо (компания):
  → Address: [Полный юридический адрес]
```

### 3.3 TRN (Tax Registration Number)

```
ЕСЛИ клиент - юридическое лицо ОАЭ:
  → Добавить поле: TRN: XXXXXXXXXXXXXXX (15 цифр)

ИНАЧЕ:
  → Не добавлять TRN
```

### 3.4 Конвертация USD/AED

```
ЕСЛИ цены указаны в USD:
  → Добавить строку: "Total in USD: XXXX,XX USD"
  → Добавить строку: "Total in AED (1 USD=3,65 AED): XXXX,XX AED"

ЕСЛИ цены указаны только в AED:
  → Показать только: "Total: XXXX AED"
```

**Курс конвертации:** 1 USD = 3.65 AED (КОНСТАНТА)

### 3.5 Customer Details

```
ЕСЛИ имя контактного лица отличается от Bill To:
  → Добавить поле: Customer Details: [Имя контакта]

ЕСЛИ компания и нужно указать контактное лицо:
  → Добавить поле: Customer Details: [Имя менеджера]
```

## 4. КАТЕГОРИИ УСЛУГ (справочник)

### 4.1 ТУРЫ И ЭКСКУРСИИ

**Паттерн описания:**
```
PRIVATE [ТИП] TOUR [МЕСТО] (for [N] persons) [ДАТА], START AT [ВРЕМЯ]
```

**Примеры:**
```
PRIVATE TOUR IN DUBAI (for 2 persons) 28 JANUARY, START AT 10:00 AM
PRIVATE JEEP SAFARI TOUR (for 2 persons) 30 JANUARY
PRIVATE TOUR IN ABU DHABI (for 2 persons) 1 FEBRUARY, START AT 9:00 AM
PRIVATE DUBAI MODERN TOUR FROM 09:00 TO 16:00
```

**Элементы:**
- Тип тура: TOUR, JEEP SAFARI TOUR, MODERN TOUR
- Место: IN DUBAI, IN ABU DHABI
- Персоны: `(for N persons)`
- Дата: DD MONTH или D MONTH
- Время: START AT HH:MM AM/PM или FROM HH:MM TO HH:MM

### 4.2 ТРАНСФЕРЫ

**Паттерн описания:**
```
[ТИП ТРАНСФЕРА] BY [МАРКА АВТО]
```

**Типы трансферов:**
```
MEETING AT THE AIRPORT AND TRANSFER TO THE HOTEL BY [АВТО]
PICK UP FROM THE HOTEL AND TRANSFER TO THE AIRPORT BY [АВТО]
TRANSFER FROM [ТОЧКА A] TO [ТОЧКА B] BY [АВТО]
TRANSFER ON [АВТО] WITH DRIVER
```

**Расширенный паттерн (с деталями):**
```
TRANSFER RT FROM [ОТЕЛЬ] (ADDRESS: [АДРЕС]) TO THE PORT (ADDRESS [ПОРТ]) DATE [ДД.ММ.ГГ] TIME [ЧЧ:ММ] BY [АВТО] AND BACK TRANSFER AT [ЧЧ:ММ] - [N] CARS.
```

**Марки авто:**
- LEXUS ES350
- MERCEDES V CLASS
- MERCEDES S-CLASS
- TOYOTA HIACE

### 4.3 ЯХТЫ И КАТАМАРАНЫ

**Паттерн описания:**
```
[YACHT/RENT] [НАЗВАНИЕ] [РАЗМЕР] [FT/FEET] [FROM HH:MM TO HH:MM]
```

**Примеры:**
```
YACHT HEIGAN 90 FEET
YACHT RENTING IN DUBAI: MAJESTY 48 FT NEW (5 HOURS)
RENT AN INFINITY CATAMARAN 60 FEET FROM 17:00 TO 22:00
```

**Элементы:**
- Тип: YACHT, CATAMARAN
- Название: HEIGAN, MAJESTY, INFINITY
- Размер: XX FEET / XX FT
- Время: FROM HH:MM TO HH:MM или (N HOURS)

### 4.4 БИЛЕТЫ И ШОУ

**Паттерн описания:**
```
[НАЗВАНИЕ ШОУ] [КАТЕГОРИЯ] FOR [N] [ADULT/CHILD]
```

**Примеры:**
```
LA PERLE SHOW BY DRAGON SILVER CATEGORY FOR 2 ADULT
LA PERLE SHOW BY DRAGON SILVER CATEGORY FOR 2 CHILD
БИЛЕТЫ В АКВАРИУМ ДУБАЙ МОЛЛ С ПОДВОДНЫМ ЗООПАРКОМ И БУХТОЙ ПИНГВИНОВ
```

**Элементы:**
- Название: LA PERLE SHOW, АКВАРИУМ ДУБАЙ МОЛЛ
- Категория: SILVER CATEGORY, VIP, GOLD
- Персоны: FOR N ADULT, FOR N CHILD

### 4.5 АРЕНДА АВТО

**Паттерн описания:**
```
[ТАРИФ] FOR [МАРКА МОДЕЛЬ ГОД]
```

**Примеры:**
```
CAR WITH DRIVER FOR 10 HOURS IN A LEXUS ES350
EXTENSION OF THE RENTAL PERIOD FOR ROLLS-ROYCE CULLINAN VIP BLACK BADGE 2023
```

**Элементы (Sokol специфика):**
- Rental charges (DD MMM YYYY - DD MMM YYYY), N days x XXX AED/day
- Outstanding vehicle value
- Non-refundable insurance premium
- GPS equipment cost
- PPF protective film cost

### 4.6 КЕЙТЕРИНГ

**Паттерн описания:**
```
[CATERING/LEVEL UP CATERING] ON THE [ЯХТА]. DATE [ДД.ММ.ГГ] TIME - FROM [ЧЧ:ММ] till [ЧЧ:ММ], NUMBER OF PEOPLE - [N] PERSON.
```

**Примеры:**
```
LEVEL UP CATERING
CATERING ON THE YACHT MAJESTY 48 FT NEW. DATE 16.02.23 TIME - FROM 15:30 till 20:30, NUMBER OF PEOPLE - 7 PERSON.
```

**Дополнительно:** Может включать детальное MENU с ценами

### 4.7 ПРОЧИЕ УСЛУГИ

**Примеры:**
```
PROFESSIONAL DJ
JET SKI ( Water ATV 1800CC )
DUBAI PRIVATE HORSE RIDING ON THE BEACH FOR 2 HOURS
```

## 5. ФОРМАТЫ ДАННЫХ

### 5.1 Дата инвойса

| Тип | Формат | Пример |
|-----|--------|--------|
| ЭТАЛОН | Mon DD, YYYY | Jan 22, 2026 |
| Стандарт | Month DD, YYYY | January 22, 2026 |

### 5.2 Дата услуги (в описании)

| Формат | Пример | Использование |
|--------|--------|---------------|
| DD MONTH | 28 JANUARY | Туры, экскурсии |
| D MONTH | 1 FEBRUARY | Туры (однозначное число) |
| DD.MM.YY | 16.02.23 | Трансферы, кейтеринг |
| DD.MM.YYYY | 04.10.2023 | Трансферы (полный год) |
| DATE: DD.MM.YYYY | DATE: 04.10.2023 | С префиксом DATE |
| DD MMM YYYY | 03 May 2025 | Периоды аренды (Sokol) |
| START: D MONTH | START: 14 OCTOBER | Трансферы с водителем |

### 5.3 Время

| Формат | Пример | Использование |
|--------|--------|---------------|
| START AT HH:MM AM/PM | START AT 10:00 AM | Туры |
| FROM HH:MM TO HH:MM | FROM 17:00 TO 22:00 | Яхты, туры |
| HH:MM-HH:MM | 15:30-20:30 | Яхты (краткий) |
| TIME HH:MM | TIME 15:00 | Трансферы |
| DEPARTURE AT H:MM AM/PM | DEPARTURE AT 5:30 AM | Трансферы |

### 5.4 Цены

**Десятичный разделитель:** запятая (,)
**Тысячный разделитель:** пробел или точка

## 7. УСЛОВНАЯ ЛОГИКА

### 7.1 Выбор бренда

```
ЕСЛИ услуга связана с арендой авто долгосрочной:
  → Бренд: Sokol Car Rental L.L.C
  → Licence: 1442819
  → Офис: 2106

ИНАЧЕ (туры, трансферы, яхты, билеты, краткосрочная аренда):
  → Бренд: Marsel Luxury Car Rental
  → Licence: 1024110
  → Офис: 2109
```

### 7.2 Формат имени клиента

```
ЕСЛИ клиент = физическое лицо:
  → Формат: CAPS (ФАМИЛИЯ ИМЯ ОТЧЕСТВО)
  → Пример: MIRZAYEVA NILUFAR

ЕСЛИ клиент = юридическое лицо:
  → Формат: CAPS или Mixed Case (как в документах компании)
  → Добавить: L.L.C / LLC если применимо
  → Добавить: TRN если есть
  → Пример: RMCOS TRADING L.L.C, TRN: 104042090100003
```

### 7.3 Валюта ценообразования

```
ЕСЛИ клиент из СНГ (Россия, Казахстан, Украина и др.):
  → Валюта: USD
  → Показать: Total in USD + Total in AED (с конвертацией)

ЕСЛИ клиент из ОАЭ (юр. лицо):
  → Валюта: AED
  → Показать: только Total в AED

ЕСЛИ оплата POS Terminal:
  → Валюта: USD или AED (по договорённости)
  → Добавить: строку комиссии
```

### 7.4 POS Terminal процент

```
ЕСЛИ стандартный клиент:
  → Комиссия: 4%

ЕСЛИ VIP/корпоративный клиент:
  → Комиссия: 3.5%
```

### 7.5 Адрес компании

```
ЕСЛИ инвойс создаётся в 2024-2026 году:
  → Адрес: DAMAC SMART HEIGHTS BUILDING, OFFICE NUMBER 2106/2109

ЕСЛИ старый инвойс (до 2024):
  → Адрес: AL FALAHI BUILDING, 312-931, Al Suq Al Kabeer Plot 184-0, Dubai, UAE
```

### 7.6 Period (период)

```
ЕСЛИ услуга многодневная (аренда, тур):
  → Добавить поле: Period: from DD-MM-YY to DD-MM-YY

ЕСЛИ услуга однодневная:
  → Не добавлять поле Period
```

### 7.7 Sokol специфика (аренда авто с инцидентами)

```
ЕСЛИ есть страховой случай (Total Loss, Damage):
  → Добавить: Outstanding vehicle value

ЕСЛИ есть штрафы:
  → Добавить: Traffic fines (see Annex A for breakdown)

ЕСЛИ есть дорожные сборы:
```
