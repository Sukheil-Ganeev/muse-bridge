## После генерации

### Шапка
- [ ] Номер инвойса в формате #YY-XXX
- [ ] Дата в формате Mon DD, YYYY
- [ ] Логотип соответствует бренду
- [ ] Licence Number правильный (Marsel: 1024110, Sokol: 1442819)

### Данные клиента
- [ ] Имя в правильном регистре (CAPS для физ.лиц)
- [ ] Телефон в международном формате (+971, +7, +90...)
- [ ] Адрес заполнен (минимум страна или "-")
- [ ] TRN указан для B2B в ОАЭ (15 цифр)
- [ ] Customer Details добавлен если контакт отличается от Bill To

### Таблица услуг
- [ ] Все 6 колонок заполнены (#, DESCRIPTION, Price, Amount, VAT, Total)
- [ ] VAT = 5% от суммы без налога (Amount Excl. VAT * 0.05)
- [ ] Итоги сходятся (Excl. VAT + VAT = Incl. VAT)
- [ ] POS Terminal добавлен если нужно (4% или 3.5%)
- [ ] Колонки hours/Quantity добавлены если применимо

### Описания услуг

#### Туры
- [ ] Формат: PRIVATE [ТИП] TOUR [МЕСТО] (for N persons) [ДАТА], START AT [ВРЕМЯ]
- [ ] Указано количество персон
- [ ] Указано время начала

#### Трансферы
- [ ] Указан тип авто (LEXUS ES350, MERCEDES V CLASS и т.д.)
- [ ] Указаны точки А и Б
- [ ] Указаны дата и время

#### Яхты
- [ ] Указано название и размер (XX FEET / XX FT)
- [ ] Указано время (FROM HH:MM TO HH:MM)

#### Билеты/шоу
- [ ] Указана категория (SILVER, GOLD, VIP)
- [ ] Указано количество (FOR N ADULT/CHILD)

## Контрольные вопросы

1. **Бренд определён верно?**
   - Туры, трансферы, яхты, билеты → Marsel
   - Долгосрочная аренда авто → Sokol

2. **POS Terminal нужен?**
   - Физ.лицо + оплата картой → Да (4% или 3.5%)
   - Юр.лицо + банковский перевод → Нет

3. **TRN нужен?**
   - Юр.лицо ОАЭ → Да (15 цифр)
   - Физ.лицо или иностранная компания → Нет

4. **Конвертация нужна?**
   - Клиент из СНГ + цены в USD → Да
   - Клиент из ОАЭ + цены в AED → Нет
