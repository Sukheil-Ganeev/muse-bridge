## Проблема

VAT рассчитан неправильно — использована неверная ставка, неправильная база или ошибка округления.

## Контекст

VAT в ОАЭ = 5%. Часто путают формулу или допускают ошибки в арифметике.

**Неправильно:**
```
Amount (Excl. VAT): 1000 AED
VAT 5%, Amount: 52.50 AED       ← Неверный расчёт
Amount (Incl. VAT): 1052.50 AED
```

## Решение

Формула: `Amount (Excl. VAT) × 0.05`

**Правильно:**
```
Amount (Excl. VAT): 1000 AED
VAT 5%, Amount: 50.00 AED       ← 1000 × 0.05 = 50
Amount (Incl. VAT): 1050.00 AED ← 1000 + 50 = 1050
```

## Урок

Всегда проверяй: `Excl. VAT + VAT = Incl. VAT`. Округляй до 2 знаков.
