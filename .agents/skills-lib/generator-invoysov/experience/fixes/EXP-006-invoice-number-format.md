## Проблема

Номер инвойса не соответствует стандартному формату #YY-XXX.

## Контекст

**Неправильно:**
```
Invoice #: 398
Invoice: 2026-398
Invoice #: INV-26-398
Invoice #: 26398
```

## Решение

Формат: **#YY-XXX** или **#YY-XXXX**

**Правильно:**
```
Invoice #: #26-398
Invoice #: #26-0121
Invoice #: #22-1234
```

## Урок

Структура:
- `#` — обязательный символ в начале
- `YY` — последние 2 цифры года (26 для 2026)
- `XXX/XXXX` — порядковый номер (3-4 цифры)
