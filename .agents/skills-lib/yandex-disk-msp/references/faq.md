# FAQ — Яндекс Диск MCP

## Общие вопросы

### Как найти фотографии для презентаций?

1. Определи категорию: билеты, экскурсии, яхты, машины
2. Перейди в нужную корневую папку (см. таблицу ниже)
3. Навигируй вглубь через `get_metadata`
4. Скачай через `get_download_url` + `curl`
5. Подробный алгоритм: `experience/patterns/photo-search-algorithm.md`

| Категория | Корневой путь |
|-----------|--------------|
| Билеты/аттракционы | `CRM системы стран/CRM система (ОАЭ)/БИЛЕТЫ/` |
| Групповые экскурсии | `CRM системы стран/CRM система (ОАЭ)/ГРУППОВЫЕ ЭКСКУРСИИ/` |
| Индивидуальные экскурсии | `CRM системы стран/CRM система (ОАЭ)/ИНДИВИДУАЛЬНЫЕ ЭКСКУРСИИ/` |
| Яхты | `Яхты для PDF/` |
| Машины | `Машины PDF/` |
| Брендинг/логотипы | `фирменный стиль Дубаи/` |

### Где фотографии яхт?

**Папка:** `disk:/Яхты для PDF/`
- Содержит ~250 подпапок, каждая = одна яхта
- Файлы именованы: `"Astra Exterior 1.JPG"`, `"Astra Deck 2.JPG"`, `"Astra Interior 1.JPG"`
- **Для каталогов/карточек** используй файлы с "Exterior" в названии
- **Deck** — фото палубы и зон отдыха
- **Interior** — салон и каюты
- Лучший пример структуры: папка `ASTRA 80 FEET`

**Важно:** НЕ путай с `МОРСКОЙ КРУИЗ/` (это групповая экскурсия на dhow boat, не яхта).

### Где фотографии экскурсий?

**Путь:** `CRM системы стран/CRM система (ОАЭ)/`

| Тип экскурсии | Папка | Примечание |
|--------------|-------|-----------|
| Сафари (обычное) | `ИНДИВИДУАЛЬНЫЕ ЭКСКУРСИИ/НА САФАРИ/` | 1 фото: Desert-Safari.jpg |
| VIP сафари | `ИНДИВИДУАЛЬНЫЕ ЭКСКУРСИИ/НА VIP САФАРИ/` | CARAVANSERAI, ROYAL SAHARA, SONARA |
| Платиновое сафари | `ГРУППОВЫЕ ЭКСКУРСИИ/НА ПЛАТИНОВОЕ САФАРИ/` | 6 фото, Platinum Heritage |
| Тур по Дубаю | `ГРУППОВЫЕ ЭКСКУРСИИ/ПО ДУБАЮ/` | Burj Al Arab, Dubai Mall |
| Морской круиз | `ГРУППОВЫЕ ЭКСКУРСИИ/МОРСКОЙ КРУИЗ/` | Dhow boats, каяки |

**Внимание:** Папка `ГРУППОВЫЕ ЭКСКУРСИИ/НА САФАРИ/` — ПУСТАЯ!

### Где фотографии машин?

**Папка:** `disk:/Машины PDF/`
- Содержит фотографии автомобилей для PDF-каталогов
- Используется для презентаций по аренде авто (бизнес брата Марселя)

### Как скачать файл на локальный диск?

```
1. Получи URL:   yandex_disk_get_download_url(path="disk:/путь/к/файлу.jpg")
2. Скачай:       curl -L -o "D:/Downloads/filename.jpg" "полученный_URL"
```

**Важно:**
- URL временный (~30 минут), скачивай сразу
- Используй `-L` для следования редиректам
- Сохраняй в `D:/Downloads/` (НЕ в C:/Users/londo/Downloads/)

### Как загрузить файл на Яндекс Диск?

```
1. Получи URL для загрузки:  yandex_disk_get_upload_url(path="disk:/путь/новый_файл.jpg")
2. Загрузи:                  curl -T "локальный_файл.jpg" "полученный_URL"
```

### Как узнать сколько места на диске?

Используй `yandex_disk_info` — покажет общий объём, использованное и свободное место.

## Продвинутые вопросы

### Как работать с большими папками (>20 файлов)?

1. Вызови `get_metadata` с `limit` и `offset` параметрами
2. Если результат слишком большой (>30K символов), он сохранится в temp-файл
3. Парси файл через Python:
   ```python
   import json, sys
   sys.stdout.reconfigure(encoding='utf-8')
   with open('temp_file.json', 'r', encoding='utf-8') as f:
       data = json.load(f)
   text = data[0]['text']
   items = json.loads(text)['_embedded']['items']
   for item in items:
       print(f"{item['type']}: {item['name']}")
   ```

### Как найти конкретный файл, если не знаешь путь?

1. Используй `yandex_disk_list_files` с `limit=100` и `offset=0`
2. Этот инструмент возвращает плоский список ВСЕХ файлов
3. Ищи по имени через `offset` и `limit` (пагинация)
4. Когда нашёл — путь будет в поле `path`

### Поддерживается ли поиск по имени файла?

Прямого поиска нет. Варианты:
- `list_files` — перебор всех файлов (медленно)
- `get_metadata` — навигация по папкам, если знаешь примерное расположение
- Лучше использовать карту диска из `experience/patterns/disk-structure.md`
