# Паттерн: Пошаговый алгоритм поиска продуктовых фотографий

**Дата:** 2026-02-06
**Контекст:** Выработан после нескольких итераций поиска фото для PDF-презентаций

## Алгоритм

### Шаг 1. Определи категорию продукта

| Категория | Корневая папка |
|-----------|---------------|
| Яхты | `disk:/Яхты для PDF/` |
| Билеты/аттракционы | `disk:/CRM системы стран/CRM система (ОАЭ)/БИЛЕТЫ/` |
| Групповые экскурсии | `disk:/CRM системы стран/CRM система (ОАЭ)/ГРУППОВЫЕ ЭКСКУРСИИ/` |
| Индивидуальные экскурсии | `disk:/CRM системы стран/CRM система (ОАЭ)/ИНДИВИДУАЛЬНЫЕ ЭКСКУРСИИ/` |
| Машины | `disk:/Машины PDF/` |
| Отели | `disk:/CRM системы стран/CRM система (ОАЭ)/ОТЕЛИ/` |

### Шаг 2. Навигируй к нужной подпапке

```
get_metadata("disk:/корневая_папка/")
```

- Если папка большая (>20 items) — используй `limit` и `offset`
- Ищи подпапку по названию продукта

### Шаг 3. Просмотри содержимое подпапки

```
get_metadata("disk:/корневая_папка/подпапка/")
```

Оцени файлы:
- **Приоритет 1:** Файлы с понятными именами (`Desert-Safari.jpg`, `Astra Exterior 1.JPG`)
- **Приоритет 2:** Файлы `*-topaz-sharpen.jpeg` (улучшенное качество)
- **Приоритет 3:** Обычные фото (`IMG_*.jpg`)
- **Избегай:** `photo_YYYY-MM-DD_*.jpg` (могут быть личными)
- **Избегай:** `*-topaz-face-upscale-2x.png` (содержат лица)

### Шаг 4. Скачай выбранные фото

```
1. get_download_url("disk:/полный/путь/к/файлу.jpg")
2. curl -L -o "D:/Downloads/Skill_Presentations/{проект}/images/filename.jpg" "URL"
```

- Скачивай СРАЗУ после получения URL (срок жизни ~30 мин)
- Сохраняй в `images/` рядом с `presentation.html`

### Шаг 5. Проверь пригодность

- Фото достаточного размера? (для презентации 1920x1080 нужно минимум ~800px по ширине)
- Нет личных данных / лиц клиентов?
- Фото соответствует продукту? (не перепутаны dhow boat и яхта)

## Специальные случаи

### Яхты — ищи "Exterior"
```
get_metadata("disk:/Яхты для PDF/{НАЗВАНИЕ} {ДЛИНА} FEET/")
```
- Бери файлы с "Exterior" в имени — это внешний вид для каталогов
- "Deck" — палуба, "Interior" — салон
- Лучший пример: `ASTRA 80 FEET` (все файлы подписаны)

### Сафари — проверь ОБЕ папки
- `ГРУППОВЫЕ ЭКСКУРСИИ/НА САФАРИ/` — **ПУСТАЯ!**
- `ИНДИВИДУАЛЬНЫЕ ЭКСКУРСИИ/НА САФАРИ/` — 1 фото (Desert-Safari.jpg)
- `ГРУППОВЫЕ ЭКСКУРСИИ/НА ПЛАТИНОВОЕ САФАРИ/` — 6 фото
- `ИНДИВИДУАЛЬНЫЕ ЭКСКУРСИИ/НА VIP САФАРИ/` — подпапки CARAVANSERAI, ROYAL SAHARA, SONARA

### Морской круиз vs Яхта
- `МОРСКОЙ КРУИЗ/` = dhow boats (арабские лодки), групповая экскурсия (150-300 AED)
- `Яхты для PDF/` = приватная аренда яхт (от 450 AED/час)
- **НЕ ПУТАЙ!** Для карточки "Yacht Rental" используй ТОЛЬКО `Яхты для PDF/`

### Instagram — НЕ фото
- `фирменный стиль Дубаи/Instagram/` = иконки highlights
- Файл `13 яхта.jpg` — это иконка парусника, НЕ фото яхты

## Чек-лист перед использованием

- [ ] Фото из правильной папки (не Instagram, не МОРСКОЙ КРУИЗ для яхт)
- [ ] Имя файла не начинается с `photo_YYYY-MM-DD` (не личное)
- [ ] Нет суффикса `face-upscale` (нет лиц)
- [ ] Формат подходит (JPG/PNG, не слишком маленький)
- [ ] Скачан в `D:/Downloads/`, не в `C:/Users/londo/Downloads/`
