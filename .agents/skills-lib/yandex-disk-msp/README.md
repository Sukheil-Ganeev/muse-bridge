# Yandex Disk MCP — Скилл навигации и работы с файлами

## Назначение

Скилл для работы с Яндекс Диском Сухейля через MCP-инструменты. Поиск фотографий для презентаций, навигация по CRM-структуре, скачивание файлов и управление контентом.

## Структура скилла

```
yandex-disk-мсп/
├── SKILL.md                  # Основной файл скилла (триггеры, инструменты, карта диска)
├── README.md                 # Этот файл — описание структуры
├── references/
│   ├── faq.md                # Частые вопросы: где искать фото, как скачивать
│   ├── troubleshooting.md    # Решение проблем: overflow, encoding, expired URL
│   └── cheatsheet.md         # Шпаргалка: команды MCP, шаблоны путей, Python-сниппеты
└── experience/
    ├── _index.md             # Критические уроки (читать при активации!)
    ├── fixes/
    │   └── instagram-icons-not-photos.md   # Instagram-файлы = иконки, не фото
    ├── patterns/
    │   ├── disk-structure.md               # Полная карта Яндекс Диска Сухейля
    │   └── photo-search-algorithm.md       # Алгоритм поиска продуктовых фото
    └── warnings/
        └── personal-photos.md              # Круизные фото могут быть личными
```

## Когда использовать

- Поиск фотографий для PDF-презентаций (экскурсии, яхты, авто)
- Навигация по CRM-структуре (билеты, экскурсии, отели)
- Скачивание файлов с Яндекс Диска на локальную машину
- Загрузка новых файлов на диск
- Любые операции с файлами через Yandex Disk MCP

## Ключевые MCP-инструменты

| Инструмент | Частота использования | Назначение |
|-----------|----------------------|-----------|
| `yandex_disk_get_metadata` | Часто | Навигация по папкам, просмотр содержимого |
| `yandex_disk_get_download_url` | Часто | Получение ссылки для скачивания |
| `yandex_disk_list_files` | Средне | Плоский список всех файлов (с пагинацией) |
| `yandex_disk_info` | Редко | Общая информация о диске |
| `yandex_disk_create_folder` | Редко | Создание новых папок |
| `yandex_disk_copy` / `move` / `delete` | Редко | Управление файлами |

## Связанные скиллы

- **Skill_Presentations** — PDF-презентации из справочников (использует фото с диска)
- **MARSEL_BUSINESS** — CRM-система лимузинов (данные о клиентах и заказах)

## Протокол активации

1. Прочитать `experience/_index.md` — критические уроки
2. Определить задачу (поиск фото / скачивание / навигация)
3. Использовать алгоритм из `experience/patterns/photo-search-algorithm.md`
4. При проблемах — см. `references/troubleshooting.md`
