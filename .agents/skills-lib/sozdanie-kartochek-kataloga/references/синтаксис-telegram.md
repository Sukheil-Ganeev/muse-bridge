# Синтаксис форматирования Telegram

## Базовое форматирование

| Элемент | Синтаксис | Пример |
|---------|-----------|--------|
| Жирный | `**текст**` | **жирный текст** |
| Курсив | `__текст__` | __курсивный текст__ |
| Зачёркнутый | `~~текст~~` | ~~зачёркнутый~~ |
| Моноширинный | ``` `текст` ``` | `код` |
| Подчёркнутый | `--текст--` | --подчёркнутый-- |

## Разделитель

**18 символов тире:**
```
──────────────────
```

## Эмодзи (только 3)

| Эмодзи | Использование | Пример |
|--------|---------------|--------|
| 💰 | Перед ценами | 💰 **Цены** |
| ➕ | Перед опциями | ➕ **Опции** |
| ⚠️ | Перед важным | ⚠️ **Важно** |

**Позиция:** ПЕРЕД двойными звёздочками!
```
💰 **Цены**  ← ПРАВИЛЬНО
**Цены** 💰  ← НЕПРАВИЛЬНО
```

## Списки

Используйте длинное тире `—` (не дефис `-`):
```
— пункт 1
— пункт 2
— пункт 3
```

## Категории билетов

**Два пробела** после категории:
```
**Standard**  **$91 взр / $77 дет**
            ↑↑
        ДВА ПРОБЕЛА
```

## Стандартные блоки

### Заголовок раздела
```
**Название раздела**
```

### Цены
```
💰 **Билеты (USD)**

**Категория**  **$XX взр / $XX дет**
__пояснение__
```

### Оплата
```
**Оплата**
USD • рубли по СБП • AED по курсу 3.65 • тенге • USDT __(другие — по согласованию)__
```

### Отмена
```
**Отмена**
за 48 ч — 100% • за 24 ч — 50% • менее 24 ч — без возврата • билеты **невозвратные**
```

### Для бронирования
```
**Для бронирования:** дата • формат • кол-во взрослых/детей (возраст) • эмират и отель • нужен ли трансфер
```

## Частые ошибки

| Неправильно | Правильно |
|-------------|-----------|
| `рубли по СПБ` | `рубли по СБП` |
| `**Цены** 💰` | `💰 **Цены**` |
| `-` (дефис) | `—` (длинное тире) |
| 1 пробел после категории | 2 пробела после категории |
| 15 тире в разделителе | 18 тире в разделителе |
| `*жирный*` (WhatsApp) | `**жирный**` (Telegram) |
| `_курсив_` (WhatsApp) | `__курсив__` (Telegram) |
