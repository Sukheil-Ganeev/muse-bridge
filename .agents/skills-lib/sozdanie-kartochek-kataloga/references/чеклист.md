# Чеклист перед публикацией карточки

## Критические проверки

- [ ] **СБП** написано правильно (НЕ СПБ!)
- [ ] Все **7 эмиратов** указаны в трансфере:
  - Дубай
  - Шарджа
  - Аджман
  - Рас-Аль-Хайма (РАК)
  - Умм-Аль-Кувейн (УАК)
  - Фуджейра
  - Абу-Даби
- [ ] Билеты — **невозвратные** (выделено жирным)
- [ ] **Мессенджер определён** (WhatsApp или Telegram)
- [ ] Используется **правильный синтаксис** для мессенджера

## Форматирование

### Общее
- [ ] **Два пробела** после категории билетов
- [ ] **Длинное тире** `—` для списков (не дефис `-`)
- [ ] **Средняя точка** `•` для разделения элементов в строке

### Эмодзи
- [ ] Эмодзи **ПЕРЕД** заголовком (💰 *Цены*, не *Цены* 💰)
- [ ] Используются только **3 эмодзи**: 💰 ➕ ⚠️

### Разделители
- [ ] **WhatsApp:** 15 тире `───────────────`
- [ ] **Telegram:** 18 тире `──────────────────`

### Синтаксис WhatsApp
- [ ] Жирный: `*текст*`
- [ ] Курсив: `_текст_`
- [ ] Категории: ``` ```текст``` ```

### Синтаксис Telegram
- [ ] Жирный: `**текст**`
- [ ] Курсив: `__текст__`
- [ ] Категории: `**текст**`

## Структура

- [ ] Только **10 базовых блоков** (не больше)
- [ ] **Нет запрещённых блоков**:
  - "Почему стоит посетить"
  - "Для Instagram"
  - "Для семей с детьми"
  - Таблицы сравнения
  - Модули в основном файле
- [ ] Для продуктов с питанием — **2 файла** (основное + меню)

## Стандартные блоки (проверить наличие)

### Обязательные
1. [ ] Заголовок
2. [ ] График/Время
3. [ ] Что включено
4. [ ] Цены/Билеты
5. [ ] Трансфер
6. [ ] Оплата
7. [ ] Отмена
8. [ ] Для бронирования

### Опциональные
- [ ] Якорь (описание) — если нужен
- [ ] Примечания — если есть важное

## Финальная проверка

- [ ] Скопировать в мессенджер и проверить отображение
- [ ] Проверить все ссылки (если есть)
- [ ] Проверить актуальность цен
- [ ] Проверить график работы
