# Создание карточек каталога WhatsApp/Telegram

## Описание

Скилл для создания компактных карточек туристических продуктов ОАЭ для каталога товаров в мессенджерах WhatsApp и Telegram.

## Когда использовать

- Нужно найти информацию по **новому продукту** (парк, аттракцион, ресторан)
- Создать **компактную карточку** для каталога товаров
- Формат: минимализм, быстрое сканирование

## Отличие от форматирование-турпродуктов

| Этот скилл | форматирование-турпродуктов |
|------------|----------------------------|
| Для каталога товаров | Для личных сообщений |
| Компактный формат | Развёрнутый формат |
| Минимум деталей | Полное описание |
| Новые продукты | Существующие продукты |

## Структура папки

```
создание-карточек-каталога/
├── SKILL.md                      # Основной файл скилла
├── README.md                     # Это описание
├── marketplace.json              # Метаданные для маркетплейса
├── assets/
│   ├── templates/                # Шаблоны для разных типов продуктов
│   │   ├── билеты-whatsapp.txt
│   │   ├── билеты-telegram.txt
│   │   ├── тур-whatsapp.txt
│   │   ├── тур-telegram.txt
│   │   ├── питание-whatsapp.txt
│   │   └── питание-telegram.txt
│   └── examples/                 # Готовые примеры
│       ├── аквапарк-whatsapp.txt
│       └── аквапарк-telegram.txt
└── references/
    ├── синтаксис-whatsapp.md     # Справочник синтаксиса WhatsApp
    ├── синтаксис-telegram.md     # Справочник синтаксиса Telegram
    └── чеклист.md                # Чеклист перед публикацией
```

## Быстрый старт

1. Определить мессенджер (WhatsApp или Telegram)
2. Определить тип продукта (билеты, тур, питание)
3. Использовать соответствующий шаблон из `assets/templates/`
4. Проверить по чеклисту из `references/чеклист.md`

## Критические правила

- **СБП** (не СПБ!)
- Все **7 эмиратов** в трансфере
- Билеты — **невозвратные** (жирным)
- **2 пробела** после категории
- Эмодзи **ПЕРЕД** заголовком (💰 ➕ ⚠️)
