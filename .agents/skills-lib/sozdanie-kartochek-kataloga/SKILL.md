# Создание карточек для каталога WhatsApp/Telegram

## НАЗНАЧЕНИЕ

Этот скилл используется когда:
- Нужно найти информацию по НОВОМУ продукту (парк, аттракцион, ресторан)
- Создать КОМПАКТНУЮ карточку для каталога товаров WhatsApp/Telegram
- Формат: минимализм, быстрое сканирование

**НЕ путать с форматированием-турпродуктов** (для личных сообщений клиентам).

## 4 ТИПА ПРОДУКТОВ

### ТИП 1: Билеты без трансфера
- Цены за человека
- Трансфер = опция

### ТИП 2: Пакеты с групповым трансфером
- Билеты + групповой трансфер
- Указывать дни: (Чт, Вс)

### ТИП 3: Индивидуальные туры
- Цена за МАШИНУ, не за человека
- Программа/маршрут

### ТИП 4: Продукты с питанием
- **2 ФАЙЛА**: основное + меню
- В основном НЕ перечислять блюда

Всегда жирным!

### 4. ДВА ПРОБЕЛА после категории
```
```Базовая```  50$ взр / 35$ реб  ← ДВА ПРОБЕЛА!
```

- 💰 перед *Цены*
- ➕ перед *Опции*
- ⚠️ перед *Важно*
