# Создание профессионального CV

## Философия эффективного CV

CV — это маркетинговый документ, а не автобиография. Его единственная цель — получить приглашение на собеседование. Каждое слово должно работать на эту цель.

**Три ключевых принципа:**
1. **Релевантность** — CV адаптируется под конкретную вакансию
2. **Измеримость** — достижения выражены в числах
3. **Читаемость** — информация считывается за 7.4 секунды

## Правило 7.4 секунд (Eye-Tracking данные)

Рекрутеры тратят в среднем **7.4 секунды** на первичный просмотр CV (TheLadders 2018, обновлено с 6 сек в 2012). За это время они:
- Сканируют по F-паттерну (сверху вниз по левому краю, затем горизонтально)
- Ищут ключевые слова из вакансии
- Оценивают визуальную структуру
- Принимают решение: читать дальше или отклонить

**80% времени** уходит на 6 ключевых элементов:
1. Имя кандидата
2. Текущая должность и компания
3. Даты начала/окончания текущей позиции
4. Предыдущая должность и компания
5. Даты предыдущей позиции
6. Образование

**Дополнительные данные (ResumeGo 2024, 418 рекрутеров):**
- 81% рекрутеров тратят менее 1 минуты на первичный скрининг
- 47% тратят 30 сек - 1 минуту
- 78% считают "skim-ability" высоко важной
- 88% тратят больше времени на особо интересных кандидатов

### Опциональные секции (по релевантности)

- **Языки** — если требуются или дают преимущество
- **Волонтёрство** — если демонстрирует нужные навыки

## Формулы достижений

### CAR (Context-Action-Result)

**Контекст** → **Действие** → **Результат**

```
[Ситуация/проблема] + [Что сделал] + [Измеримый результат]
```

**Примеры:**

❌ Плохо: "Занимался продажами"

✅ Хорошо: "При падении продаж на 20% (Context) внедрил систему холодных звонков с персонализированными скриптами (Action), увеличив конверсию на 35% за 3 месяца (Result)"

### XYZ (Google Formula)

**Accomplished [X] by doing [Y], resulting in [Z]**

```
Достиг [X] посредством [Y], что привело к [Z]
```

**Примеры:**

❌ Плохо: "Управлял командой"

✅ Хорошо: "Увеличил производительность команды на 40% (X) через внедрение Scrum и ежедневных стендапов (Y), сократив time-to-market с 6 до 3 недель (Z)"

### STAR для достижений

**Situation → Task → Action → Result**

Используется когда нужно подробное описание:

```
[Ситуация]: Компания теряла 15% клиентов ежемесячно
[Задача]: Снизить отток до 5%
[Действие]: Создал систему раннего предупреждения оттока + программу лояльности
[Результат]: Отток снизился до 3%, LTV вырос на 25%
```

## F-паттерн сканирования

Рекрутеры читают CV по паттерну буквы F:

```
████████████████████████████  ← Первая горизонтальная линия (заголовок)
██████████████                ← Вторая горизонтальная линия (резюме)
████
████                          ← Вертикальное сканирование по левому краю
████
████
████
```

**Оптимизация под F-паттерн:**
1. Самая важная информация — в первых 2-3 строках
2. Ключевые слова и достижения — в начале пунктов
3. Левое выравнивание для заголовков секций
4. Не прячьте важное в правой части документа

## ATS-оптимизация

### Что такое ATS

ATS (Applicant Tracking System) — программа, которая фильтрует CV до просмотра рекрутером.

**Реальность 2025 (по данным Enhancv):**
- Миф о 75% отсеве — преувеличение
- **Только 8%** рекрутеров включают автоматическое отклонение контента
- **92%** полагаются на человеческий обзор
- ATS **организует и сортирует**, а не автоматически отклоняет

**Статистика ATS:**
- 99% Fortune 500 используют ATS
- 98% крупных организаций используют ATS
- Рекомендуемый match rate: **75%+**
- AI Score >= 70 = **100% вероятность найма** (Kaggle данные)

### Правила прохождения ATS

**Форматирование:**
- Формат: .docx (безопаснее) или text-based .pdf
- Шрифты: стандартные (Arial, Calibri, Times New Roman, Garamond, Georgia, Helvetica)
- Размер: 10-12pt для текста, 14-16pt для заголовков
- Без таблиц, колонок, текстовых боксов
- Без картинок, графиков, иконок
- Без шапок и подвалов (headers/footers)

**Ключевые слова (критично важно):**
- 99.7% рекрутеров используют keyword-фильтры
- Включение job title увеличивает шанс интервью **в 10.6 раз**
- Оптимальное количество keywords: **15-25**
- Оптимальная плотность: **2-3%**
- Копируйте формулировки из вакансии дословно
- Используйте и аббревиатуры, и полные названия: "SEO (Search Engine Optimization)"
- Современные ATS понимают контекст (семантический анализ)

**Структура:**
- Стандартные названия секций: "Опыт работы", "Образование", "Навыки"
- Хронологический порядок (от новых к старым)
- Даты в формате: "Янв 2022 — Дек 2024" или "01/2022 — 12/2024"

## Профессиональное резюме (Summary)

> **Статистика:** Summary даёт **+340% к callback rate**. Это самая важная секция CV после контактной информации.

### Структура идеального Summary

```
[Должность] с [X лет] опыта в [отрасль/специализация].
[Главное достижение с цифрами].
[Ключевая экспертиза или уникальное преимущество].
```

**Объём:** 50-100 слов, 3-5 предложений

### Примеры

**Marketing Manager:**
> Маркетинг-менеджер с 7-летним опытом в B2B SaaS. Увеличил MRR с $100K до $1.5M за 3 года через построение команды и запуск performance-маркетинга. Эксперт в growth hacking и product-led growth стратегиях.

**Software Engineer:**
> Full-stack разработчик с 5-летним опытом в финтех-стартапах. Спроектировал и реализовал платёжную систему, обрабатывающую $50M транзакций ежемесячно. Специализация: высоконагруженные системы на Go и PostgreSQL.

**Sales Manager:**
> Руководитель отдела продаж с опытом построения команд с нуля. За 2 года вывел стартап с $0 до $5M ARR. Эксперт в Enterprise-продажах с циклом сделки 6-12 месяцев.

## Описание опыта работы

### Формат записи

```
НАЗВАНИЕ КОМПАНИИ | Город                         Мес ГГГГ — Мес ГГГГ
Должность

• [Глагол действия] + [что сделал] + [результат с цифрами]
• [Глагол действия] + [что сделал] + [результат с цифрами]
• [Глагол действия] + [что сделал] + [результат с цифрами]
```

### Количество пунктов

- Текущая/последняя позиция: 4-6 пунктов
- Предыдущие позиции: 2-4 пунктов
- Старые позиции (5+ лет): 1-2 пункта или объединить

### Что включать

✅ Включайте:
- Достижения с измеримыми результатами
- Масштаб ответственности (бюджеты, команды, проекты)
- Релевантные навыки и инструменты
- Продвижение внутри компании

❌ Не включайте:
- Должностные обязанности без результатов
- Очевидные вещи ("отвечал на звонки")
- Нерелевантный опыт
- Причины ухода

- "Python (pandas, numpy, sklearn)"
- "Английский — свободное ведение переговоров"

## Адаптация под вакансию

### Алгоритм адаптации

1. **Выделите ключевые слова** из описания вакансии
2. **Сопоставьте** со своим опытом
3. **Переформулируйте** пункты, используя лексику вакансии
4. **Переставьте** релевантный опыт выше
5. **Добавьте** недостающие ключевые слова в навыки

### Пример адаптации

**Вакансия требует:** "опыт управления cross-functional командами"

**Было:** "Руководил отделом маркетинга"

**Стало:** "Руководил cross-functional командой из 8 человек (маркетинг, дизайн, аналитика)"

## Частые ошибки

### Содержание

| Ошибка | Решение |
|--------|---------|
| Обязанности вместо достижений | Начинайте с глагола действия + результат |
| Нет цифр | Добавьте хотя бы одну метрику в каждый пункт |
| Слишком много информации | 1-2 страницы максимум |
| Нерелевантный опыт | Удалите или сократите |
| Устаревшие навыки | Уберите Windows XP, Flash, IE |

### Форматирование

| Ошибка | Решение |
|--------|---------|
| Разные шрифты/размеры | Один шрифт, 2-3 размера |
| Стена текста | Буллеты, отступы, пустое пространство |
| Креативный дизайн | Чистый профессиональный макет |
| Фото (для международных) | Убрать, если не требуется. **Исключение:** для UAE/GCC — фото обязательно |
| Личная информация | Только имя, контакты, LinkedIn |

## Шаблон промпта для создания CV

При создании CV для пользователя используй следующую структуру вопросов:

```
1. На какую позицию/вакансию?
2. Текущий опыт работы (компании, должности, период)?
3. Главные достижения на каждой позиции?
4. Образование и сертификаты?
5. Ключевые навыки?
6. Есть ли описание вакансии для адаптации?
```

После сбора информации:
1. Структурируй по шаблону выше
2. Переформулируй обязанности в достижения
3. Добавь количественные метрики
4. Оптимизируй под ключевые слова вакансии
5. Проверь по чеклисту

### Визовый статус — правильные формулировки

**Если есть резидентская виза:**
```
Visa Status: UAE Resident (valid until MM/YYYY)
Available: Immediately
```

**Если виза через семью:**
```
Visa Status: UAE Resident (family sponsorship)
Work Permit: Eligible with employer NOC
```

**Если нужна рабочая виза:**
```
Visa Status: Requires employer sponsorship
Available: Upon visa processing (typically 2-3 weeks)
```

**Чего избегать:** "I have my own visa", "Free visa holder", "I don't need sponsorship", не указывать вообще.
