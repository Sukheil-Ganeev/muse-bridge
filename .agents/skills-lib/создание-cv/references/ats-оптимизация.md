## Как работает ATS

### Процесс обработки

```
CV загружается → Парсинг текста → Извлечение данных → Сопоставление
с вакансией → Скоринг → Ранжирование → Топ-кандидаты рекрутеру
```

### Что оценивает ATS

1. **Ключевые слова** — Совпадение с требованиями вакансии
2. **Навыки** — Технические и soft skills
3. **Опыт работы** — Релевантность, продолжительность (корреляция 0.777!)
4. **Образование** — Степень, специализация
5. **Сертификаты** — Профессиональные квалификации (+6% к Hire Rate)

## Форматирование для ATS

### Файловый формат

| Формат | ATS-совместимость | Рекомендация |
|--------|-------------------|--------------|
| .docx | Отличная | Предпочтительно для большинства ATS |
| .pdf | Хорошая | Проверить, что текст извлекается |
| .txt | Отличная | Теряется форматирование |
| .doc (старый) | Средняя | Избегать |
| Картинка | Не читается | Никогда не использовать |

**Проверка PDF:** Откройте PDF, попробуйте выделить и скопировать текст. Если не получается — ATS не прочитает.

### Структура документа

**Используйте:**
```
✅ Стандартные секции с понятными заголовками
✅ Простой одноколоночный макет
✅ Стандартные шрифты (Arial, Calibri, Times New Roman)
✅ Размер шрифта 10-12pt
✅ Простые буллеты (•, -, *)
✅ Выравнивание по левому краю
```

**Избегайте:**
```
❌ Таблицы (текст внутри может не распознаться)
❌ Многоколоночный макет
❌ Текстовые боксы
❌ Графики, диаграммы
❌ Изображения, иконки
❌ Headers и Footers
❌ Водяные знаки
❌ Нестандартные шрифты
❌ Креативные символы (★, ➤, ●)
```

### Названия секций

Используйте стандартные названия, которые ATS точно распознает:

| Стандартно | Нестандартно (избегать) |
|------------|-------------------------|
| Опыт работы | Карьерный путь, Профессиональная история |
| Образование | Академическая подготовка |
| Навыки | Компетенции, Умения |
| Контакты | Личная информация |
| Резюме | Обо мне, Профиль |
| Сертификаты | Дополнительное образование |

## Работа с ключевыми словами

### Статистика ключевых слов 2025

| Факт | Данные | Источник |
|------|--------|----------|
| Рекрутеры используют keyword фильтры | **99.7%** | Jobscan |
| Включение job title увеличивает шанс интервью | **в 10.6 раз** | Jobscan |
| Оптимальное количество keywords | **15-25** | uppl.ai |
| Оптимальная плотность keywords | **2-3%** | uppl.ai |

### Тренды 2025

- **Семантический анализ**: ATS понимает контекст ("led cross-functional teams" = лидерство)
- **Контекст важнее списков**: keywords в достижениях весомее изолированных навыков
- **NLP и AI**: современные ATS используют Natural Language Processing

### Извлечение ключевых слов из вакансии

**Шаг 1:** Скопируйте текст вакансии

**Шаг 2:** Выделите:
- Названия должностей
- Технические навыки
- Soft skills
- Инструменты и технологии
- Требования к опыту
- Отраслевые термины

**Шаг 3:** Посчитайте частоту упоминания — чем чаще, тем важнее

### Чего избегать

- Keyword stuffing (перенасыщение)
- Общие buzzwords: "hardworking", "team player", "go-getter"
- Несоответствие keywords job description

### Пример анализа вакансии

**Текст вакансии:**
> "Ищем Product Manager с опытом работы в B2B SaaS. Требуется: управление продуктом, работа с метриками, Agile/Scrum, взаимодействие со стейкхолдерами, roadmap планирование. Опыт с Jira, Confluence обязателен."

**Извлечённые ключевые слова:**
```
Должность: Product Manager
Отрасль: B2B SaaS
Навыки: управление продуктом, метрики, Agile, Scrum,
        стейкхолдеры, roadmap, планирование
Инструменты: Jira, Confluence
```

### Размещение ключевых слов

| Секция | Приоритет | Как использовать |
|--------|-----------|------------------|
| Заголовок/Должность | Высший | Точное название из вакансии |
| Резюме (Summary) | Высокий | 3-5 ключевых слов |
| Навыки | Высокий | Все релевантные ключевые слова |
| Опыт работы | Средний | Естественно в контексте достижений |
| Образование | Низкий | Специализация, если релевантна |

### Правила использования

**Точное совпадение:**
```
Вакансия: "Agile/Scrum"
CV: "Agile/Scrum" ✅
CV: "Гибкие методологии" ❌
```

**Аббревиатуры + полные названия:**
```
SEO (Search Engine Optimization)
CRM (Customer Relationship Management)
BI (Business Intelligence)
```

**Синонимы:**
```
"Управление проектами" И "Project Management"
"Машинное обучение" И "Machine Learning" И "ML"
"Руководство командой" И "Team Lead" И "Team Management"
```

## Проверка ATS-совместимости

### Онлайн-инструменты

1. **Jobscan** (jobscan.co) — Сравнение CV с вакансией
2. **Resume Worded** (resumeworded.com) — Аудит и скоринг
3. **TopResume** (topresume.com) — Бесплатный анализ

### Ручная проверка

1. **Копирование текста:**
   - Откройте CV в PDF
   - Выделите весь текст (Ctrl+A)
   - Скопируйте и вставьте в Notepad
   - Проверьте, что весь текст читается корректно

2. **Проверка структуры:**
   - Порядок секций сохранился?
   - Даты на своих местах?
   - Буллеты не превратились в мусор?

3. **Ключевые слова:**
   - Используйте Ctrl+F для поиска ключевых слов из вакансии
   - Все критичные слова должны присутствовать

## Типичные ошибки ATS

### Проблемы форматирования

| Ошибка | Последствие | Решение |
|--------|-------------|---------|
| Таблицы | Текст читается в неправильном порядке | Убрать таблицы |
| Колонки | Перемешивание текста | Одна колонка |
| Картинки с текстом | Текст не распознаётся | Только настоящий текст |
| Headers/Footers | Контакты не извлекаются | Контакты в основном теле |
| Fancy bullets (➜●★) | Заменяются на мусор | Простые буллеты (•-*) |

### Проблемы с контентом

| Ошибка | Последствие | Решение |
|--------|-------------|---------|
| Нет ключевых слов | Низкий скоринг | Добавить из вакансии |
| Креативные названия секций | Не распознаются | Стандартные названия |
| Только аббревиатуры | Частичное совпадение | Аббревиатура + расшифровка |
| Нестандартные даты | Парсинг сбоит | "Янв 2022" или "01/2022" |

## Адаптация CV под вакансию

### Алгоритм адаптации

```
1. Сохраните вакансию в текстовый файл
2. Выделите все ключевые слова и требования
3. Сопоставьте со своим опытом
4. Добавьте недостающие ключевые слова в:
   - Summary
   - Навыки
   - Описание опыта
5. Убедитесь, что топ-3 требования видны в первых строках
6. Проверьте через ATS-сканер
7. Сохраните версию с названием вакансии
```

### Именование файлов

```
Правильно:
Ivan_Petrov_Product_Manager_CV.pdf
Petrov_CV_Company_Name.docx

Неправильно:
resume_final_v3.pdf
CV.docx
```

## Чеклист ATS-оптимизации

### Формат
- [ ] Файл в .docx (безопаснее) или text-based .pdf
- [ ] Одноколоночный макет
- [ ] Нет таблиц, текстовых боксов, графиков
- [ ] Стандартный шрифт (Arial, Calibri, Times New Roman, Garamond, Georgia, Helvetica)
- [ ] Размер 10-12pt
- [ ] Контакты в основном теле (не в header)

### Структура
- [ ] Стандартные названия секций ("Work Experience", "Education", "Skills")
- [ ] Чёткая иерархия (заголовки, подзаголовки)
- [ ] Даты в едином формате
- [ ] Простые буллеты

### Ключевые слова
- [ ] Название должности из вакансии в заголовке (+10.6x к callback)
- [ ] 15-25 релевантных keywords
- [ ] Плотность keywords 2-3%
- [ ] Все обязательные навыки упомянуты
- [ ] Аббревиатуры расшифрованы (SEO + Search Engine Optimization)
- [ ] Синонимы для важных терминов
- [ ] Инструменты указаны по названиям

### Проверка
- [ ] Текст копируется корректно
- [ ] Проверено через ATS-сканер
- [ ] Target match rate: 75%+
- [ ] Версия сохранена для конкретной вакансии

## AI Bias в найме (предупреждение)

### Исследования University of Washington (2024-2025)

- AI-инструменты показывают расовую и гендерную предвзятость
- "Белые" имена предпочитаются в 85.1% случаев
- При коротких резюме bias усиливается

### Причины AI-bias

1. **Обучающие данные** — содержат исторические неравенства
2. **Недостаток информации** — при коротких резюме демографические сигналы весомее
3. **Зеркальный эффект** — люди копируют паттерны AI-рекомендаций

### Правовые риски 2025

- Июль 2024: Суд отклонил ходатайство Workday — компания может нести ответственность
- Сентябрь 2024: Калифорния признала intersectionality как защищенную идентичность
- Май 2025: Коллективный иск против Workday (ADEA)
