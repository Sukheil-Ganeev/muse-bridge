# Сбор визуальных примеров CV

## ❌ Способы которые НЕ работают

### Chrome DevTools MCP (скриншоты сайтов)

**Проблема:** Скриншоты захватывают шапки сайтов, popups, cookie-баннеры, а не сами CV.

**Результат:** 90% скриншотов бесполезны — видно интерфейс сайта, а не резюме.

**Причины:**
- fullPage скриншоты слишком длинные, CV мелкое
- viewport скриншоты обрезают CV
- Popups и cookie-баннеры закрывают контент
- Нужно вручную прокручивать и закрывать popups
- Многие страницы дают 404

**Вывод:** НЕ использовать для массового сбора примеров CV.

---

## ✅ Способы которые РАБОТАЮТ

### 1. Ручной сбор пользователем

**Процесс:**
1. Дать пользователю список ссылок на качественные примеры
2. Пользователь открывает в браузере
3. Пользователь делает скриншоты вручную или скачивает PDF
4. Сохраняет в указанную папку

**Преимущества:** Контроль качества, точный выбор.

### 2. Прямые ссылки на изображения/PDF

**Источники с прямыми файлами:**
- Canva — экспорт в PNG/PDF
- Google Docs templates — скачивание
- Microsoft Office templates — .docx файлы

**Процесс:**
1. Найти прямые URL на файлы (не страницы)
2. Скачать через curl/wget
3. Конвертировать если нужно

### 3. API сервисов резюме

Некоторые сервисы предоставляют API:
- Indeed API
- LinkedIn API (ограниченно)

### 4. Готовые датасеты

**Kaggle:**
- Resume Dataset
- CV Images Dataset

**GitHub:**
- Репозитории с примерами CV
- Open source resume templates

### 5. Генерация собственных примеров

**Процесс:**
1. Создать CV в Canva/Figma/Word
2. Экспортировать как изображение
3. Использовать как референс

## Вывод

**Лучший подход:** Дать пользователю курированный список ссылок + инструкцию как сохранить примеры вручную. Автоматический сбор скриншотов через браузер неэффективен.
