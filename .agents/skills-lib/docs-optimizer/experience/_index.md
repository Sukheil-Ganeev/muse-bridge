# docs-optimizer — Experience Log

## Топ уроков (читать при активации скилла)

### Урок 1 — Emoji grep на Windows не работает (2026-03-12)
**Проблема:** `grep -c "🔴"` возвращает 0 даже если файл содержит 🔴 символы.
**Причина:** Bash на Windows (MINGW64) некорректно обрабатывает Unicode emoji в grep.
**Решение:** Использовать `grep -c "ОТКРЫТ"` без emoji, или подсчёт через `wc -l` после фильтрации.

### Урок 2 — Research папки создают ложные orphan docs (2026-03-12)
**Проблема:** AP-03 (Orphan Docs) выдаёт 70+ файлов без ссылок.
**Причина:** docs/research/competitors/ содержит 265 файлов — это архив конкурентного анализа, не активная документация.
**Решение:** При проверке AP-03 исключать docs/research/competitors/, docs/research/references/, docs/archive/.

### Урок 3 — .claude/rules/ файлы untracked (2026-03-12)
**Проблема:** После создания .claude/rules/ файлы не попадают в git.
**Причина:** .claude/ может быть в .gitignore или просто untracked.
**Решение:** Проверить `git status .claude/rules/` — если untracked, добавить `git add .claude/rules/`.

### Урок 4 — MEMORY.md score vs системный prompt (2026-03-12)
**Проблема:** `wc -l MEMORY.md` показывает 28 строк, но в system-reminder видно 170+ строк.
**Причина:** Claude Code инжектирует расширенный MEMORY.md контекст (включая системные поля).
**Решение:** Для AP-17 проверять физический файл через `wc -l`, не system-reminder.

### Урок 5 — Verification score 2→4 за одну сессию (2026-03-12)
