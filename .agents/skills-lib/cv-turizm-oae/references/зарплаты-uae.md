## Бонусы и льготы (Tax-Free!)

### Финансовые преимущества

| Бонус | Описание |
|-------|----------|
| **Налоги** | 0% (полностью tax-free) |
| **Проживание** | Бесплатно (большинство отелей) |
| **Питание** | Бесплатно (staff meals) |
| **Транспорт** | Часто бесплатно |
| **Медстраховка** | Включена (обязательна по закону) |
| **Service charges** | Дополнительно к базовой зарплате |

### Стандартные бенефиты

| Бенефит | Детали |
|---------|--------|
| Annual leave | Минимум 30 дней (по закону) |
| Авиабилеты | 1 раз в год домой |
| Испытательный срок | 3-6 месяцев |
| End of service | Gratuity после 1 года |

## Что влияет на зарплату

### Повышающие факторы

| Фактор | Влияние |
|--------|---------|
| **Языки** | +10-20% за каждый дополнительный язык |
| **Опыт в ОАЭ** | Ценится выше, чем опыт за рубежом |
| **Сертификации** | IATA, CTA, GDS — значительный плюс |
| **Luxury опыт** | 5-star hotels = выше зарплата |
| **GCC опыт** | Знание региона = преимущество |

### Понижающие факторы

| Фактор | Влияние |
|--------|---------|
| Нужна рабочая виза | Иногда влияет на стартовую зарплату |
| Нет опыта в ОАЭ | Может потребоваться "entry" позиция |
| Только один язык | Ограничивает возможности |

## Рекомендации по переговорам о зарплате

### Для entry-level
- Не соглашайтесь ниже рыночной цены
- Уточняйте про benefits (они могут стоить 3,000-5,000 AED)
- Спрашивайте про review period (когда пересмотр)

### Для mid-level
- Подготовьте цифры достижений
- Знайте свою рыночную стоимость (эта таблица)
- Negotiable: базовая + комиссия + бонусы

### Для senior
- Всё negotiable
- Обсуждайте полный пакет: зарплата + жильё + авто + билеты
- Срок контракта влияет на условия
