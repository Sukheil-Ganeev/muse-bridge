# Специфика рынка труда в туризме ОАЭ

## Визовые вопросы

### Типы виз для работы

| Тип визы | Описание | Для CV |
|----------|----------|--------|
| **Employment Visa** | Через работодателя | "Requires employer sponsorship" |
| **Family/Spouse Visa** | Через родственника-резидента | "UAE Resident (family sponsorship)" |
| **Golden Visa** | 10-летняя виза | "UAE Golden Visa holder" |
| **Freelance Visa** | Для самозанятых | "UAE Freelance Permit holder" |

### Как указывать в CV

**Резидент через семью (оптимальный вариант для работодателя):**
```
Visa Status: UAE Resident
Work Authorization: Valid, no sponsorship required from employer
```

**Нужна виза от работодателя:**
```
Visa Status: Available for employment visa sponsorship
Notice Period: Immediately available upon visa processing
```

### Преимущества семейной визы для работодателя
- Нет расходов на оформление визы (3,000-5,000 AED экономии)
- Быстрый старт работы (не нужно ждать 2-4 недели)
- Меньше бюрократии
- Кандидат более "привязан" к ОАЭ

- **Размер компании** — корпорации платят больше
- **Комиссионная структура** — в продажах может удвоить доход

## Формат CV для ОАЭ

### Что включать

```
✓ Полное имя
✓ UAE номер телефона (+971)
✓ Email (профессиональный)
✓ LinkedIn (если есть)
✓ Локация (Dubai, UAE)
✓ Визовый статус
✓ Языки с уровнями
```

### Что НЕ включать

```
✗ Дата рождения / возраст
✗ Семейное положение
✗ Количество детей
✗ Национальность / гражданство
✗ Религия
✗ Номер паспорта
```

### Про фото в CV

> **ВАЖНО: В UAE фото ОБЯЗАТЕЛЬНО!**

В отличие от западных стандартов, в ОАЭ фото в CV — стандартная практика и часто обязательное требование.

**Требования к фото:**
- Профессиональное качество
- Нейтральный фон (белый или светло-серый)
- Деловой стиль одежды
- Размер: паспортное или чуть больше
- Актуальное (не старше 1-2 лет)

**Где разместить:**
- Верхний правый угол CV
- Рядом с контактной информацией

## Особенности рабочей культуры

### График работы
- **Стандарт:** Воскресенье-Четверг, 9:00-18:00
- **Туризм:** часто 6 дней, включая выходные
- **Сезон:** переработки в октябре-марте

### Испытательный срок
- Обычно 3-6 месяцев
- Можно уволить/уволиться с 1-дневным уведомлением
- Без компенсации при увольнении

### Бенефиты (что спрашивать)
- Медицинская страховка (обязательна по закону)
- Annual leave (минимум 30 дней по закону)
- Авиабилеты домой (раз в год)
- Комиссия/бонусы
- Транспорт (редко)

## Сезонность в туризме ОАЭ

### Высокий сезон (больше работы, больше найма)
- **Октябрь - Апрель**
- Пик: Новый год, зимние каникулы
- Много туристов из Европы и России

### Низкий сезон
- **Май - Сентябрь**
- Жара 45°C+
- Меньше туристов
- Время для тренингов и подготовки

### Рамадан
- Плавающие даты (лунный календарь)
- Сокращённый рабочий день
- Особые правила (еда, напитки)
- После Рамадана — Eid, много локальных туристов

## Культурные нюансы

### На интервью
- Одежда: smart casual или business (закрытые плечи/колени)
- Приходить вовремя (но интервьюер может опоздать)
- Small talk в начале — норма
- Не критиковать прошлых работодателей

### В CV
- Быть уверенным, но не хвастаться
- Цифры и достижения — да
- "I am the best" — нет
- Скромность ценится, но компетентность важнее

### Коммуникация
- WhatsApp — основной рабочий инструмент
- Email — для формальных вопросов
- Телефонные звонки — норма (даже без предупреждения)
