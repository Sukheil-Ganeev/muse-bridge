## 1. Специфика рынка туризма ОАЭ

### Статистика рынка GCC 2024-2025

| Показатель | Значение | Изменение |
|------------|----------|-----------|
| Вклад туризма в экономику GCC | **$247.1 млрд** | +32% vs 2019 |
| Международные туристы | **72.2 млн** | +51.5% vs 2019 |
| Занятость в туризме | **1.7 млн человек** | +33% vs 2020 |

### Общая картина
- **Туризм** — второй по значимости сектор экономики ОАЭ после нефти
- **Дубай** принимает 16+ млн туристов в год
- **Абу-Даби** активно развивает культурный туризм (Лувр, Warner Bros World)
- **Рас-эль-Хайма** — adventure tourism, горы, пустыня
- **Прогноз 2030:** ВВП от туризма GCC достигнет $340+ млрд (>10% ВВП региона)

### Рынок труда
- **Дефицит кадров:** 67% компаний сообщают о нехватке персонала
- **Новые рабочие места:** 178,000+ к 2030 (Abu Dhabi Tourism Strategy)
- **Remote-friendly:** 57% вакансий поддерживают гибридный формат
- **AI-автоматизация:** CAGR AI в hospitality — 45% (2024-2030)

## 2. Требования целевых компаний

### Ticket Combo
**Профиль:** Агрегатор билетов на аттракционы и экскурсии в ОАЭ

**Что ценят:**
- Опыт B2C продаж
- Знание достопримечательностей ОАЭ
- Мультиязычность (приоритет: русский, арабский, английский)

**Типичные позиции:**
- Sales Agent (русскоязычный рынок)
- Customer Support Representative
- B2B Partnership Manager

**Ключевые фразы для CV:**
- "Managed customer inquiries for attraction tickets"
- "Achieved X% conversion rate in ticket sales"
- "Processed X bookings per day using reservation systems"

## 6. Визовый статус — как подать нейтрально

### Правильные формулировки

**Если есть резидентская виза:**
```
Visa Status: UAE Resident (valid until MM/YYYY)
Available: Immediately
```

**Если виза через мужа/семью:**
```
Visa Status: UAE Resident (family sponsorship)
Work Permit: Eligible with employer NOC
```

**Если нужна рабочая виза:**
```
Visa Status: Requires employer sponsorship
Available: Upon visa processing (typically 2-3 weeks)
```

### Чего избегать
- "I have my own visa" — звучит высокомерно
- "Free visa holder" — устаревший термин
- "I don't need sponsorship" — может быть неточно
- Не указывать вообще — вызывает вопросы

### Оптимальный подход
Указать статус кратко в CV, детали обсудить на интервью. Если виза через мужа — это **преимущество** (employer не несёт расходов на визу).

• Достижение с цифрами

## 8. Чеклист перед отправкой CV

- [ ] Файл назван: `FirstName_LastName_CV.pdf`
- [ ] Формат PDF (не Word)
- [ ] **Фото включено** (обязательно для UAE!)
- [ ] Нет лишних личных данных (возраст, семейное положение, национальность)
- [ ] Визовый статус указан
- [ ] Языки указаны с уровнями
- [ ] Ключевые слова из вакансии включены
- [ ] Достижения с цифрами
- [ ] Контакты актуальные (UAE номер!)
- [ ] Нет грамматических ошибок

> **Важно:** В UAE фото в CV — стандартная практика и часто обязательное требование. Используйте профессиональное фото на нейтральном фоне.
