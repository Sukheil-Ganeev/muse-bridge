# PDF-мастер: Индекс опыта

## Топ-5 критических уроков

1. **НИКОГДА replace all в CSS** — массовая замена font-weight/letter-spacing ломает @font-face и layout. Только точечные правки конкретных классов.
2. **Всегда метрики из PDF** — page.get_text("dict") для текста, page.get_image_rects() для фото, page.get_drawings() для фигур. НИКОГДА "на глаз".
3. **PyMuPDF flags=20 ≠ faux bold** — это интерпретация названия шрифта, не PDF-инструкция. Проверять через FontDescriptor.
4. **Не компенсировать разницу рендеринга** — letter-spacing, text-stroke ломают layout. Разница PDF vs браузер нормальна.
5. **Один раз решить → больше не трогать** — шрифтовые метания (7 итераций 600→700→500→550→600) = потеря времени и баги.
