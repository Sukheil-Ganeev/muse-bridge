# postgresql-table-design

## Описание
Проектирование схем PostgreSQL: best practices, типы данных, индексирование, ограничения, паттерны производительности и продвинутые фичи. Используется при создании таблиц, оптимизации запросов и проектировании схем БД.

```
    └── cheatsheet.md     # Шпаргалка
```
