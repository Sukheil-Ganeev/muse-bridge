## 1. Обзор платформы

### Что такое Max

**Max** — российский мессенджер от VK (ВКонтакте), позиционируемый как суперапп по модели WeChat. Эволюционная цепочка: ICQ -> TamTam -> VK Messenger -> **Max** (март 2025).

**Ключевые факты (февраль 2026):**
- Зарегистрированных пользователей: **89+ млн**
- Среднесуточная аудитория: **22,5 млн**
- С 1 сентября 2025 — обязательная предустановка на все устройства, продаваемые в РФ
- Третье место по охвату населения РФ (после WhatsApp и Telegram)
- Регистрация по номеру телефона: Россия (+7), Беларусь (+375), страны СНГ

### Экосистема VK

Max не изолированный мессенджер — он часть экосистемы VK:
- **VK ID** — единая авторизация (вход через VK, Госуслуги, Alfa ID)
- **VK Pay / СБП** — встроенные платежи и переводы
- **Mini Apps** — мини-приложения (аналог WeChat/Telegram Web Apps)
- **GigaChat** — встроенный AI-ассистент (расшифровка голосовых, генерация текста/изображений)
- **Госуслуги** — интеграция с государственными сервисами РФ

### Аудитория и значение для туризма ОАЭ

**Целевая аудитория:** пользователи из России — основной поток русскоязычных туристов в ОАЭ.

**Позиция в стратегии:**
1. WhatsApp Business — приоритет 1 (глобально)
2. Telegram — приоритет 2 (русскоязычные + международные)
3. Instagram — приоритет 3 (визуальный маркетинг)
4. **Max — приоритет 4** (нишевая, только РФ, но быстрорастущая)

**Когда Max критичен:** если >30% клиентов из России и активно пользуются Max.

## 2. Типы чатов

### Личные чаты

Переписка 1-на-1 между пользователями.

**Возможности:**
- Текстовые сообщения (без ограничения длины)
- Голосовые сообщения с расшифровкой через GigaChat
- Фото, видео, документы (до 4 ГБ на файл)
- Стикеры, эмодзи, GIF-анимации
- Геолокация (поделиться местоположением)
- Закрепление важных сообщений
- Пересылка сообщений
- Ответ на конкретное сообщение (reply)
- Реакции на сообщения

**Для туризма:** основной канал общения с клиентом — переписка, голосовые, отправка ваучеров/билетов как файлов.

### Групповые чаты

Многопользовательские чаты до **1 000 участников**.

**Возможности:**
- Назначение администраторов
- Настройка прав участников (кто может писать, добавлять людей)
- Закрепление сообщений
- Ссылки-приглашения для вступления
- Опросы
- Модерация (удаление сообщений, бан участников)

### Каналы

Публикация контента для подписчиков (подробнее в разделе 3).

## 3. Каналы

### Что такое каналы в Max

Каналы — инструмент для публикации контента широкой аудитории подписчиков. Аналог каналов Telegram.

**Статус (февраль 2026):** с 9 февраля 2026 создание приватных каналов доступно **всем пользователям**. Публичные каналы — пока по заявке.

### Создание канала

1. Открыть раздел "Чаты"
2. Нажать "+" в верхней части экрана
3. Выбрать "Создать приватный канал"
4. Установить фото, название и описание
5. Настроить параметры (одобрение заявок, права)

**Занимает меньше минуты.**

### Типы каналов

| Тип | Доступность | Описание |
|-----|-------------|----------|
| Приватный | Всем пользователям | Вступление по ссылке или заявке |
| Публичный | По заявке / верифицированным | Доступен в поиске, открытая подписка |

### Управление каналом

**Роли:**
- **Владелец** — полный контроль, передача прав
- **Администратор** — публикация, модерация, управление подписчиками

**Настройки:**
- Контроль заявок на вступление (ручное одобрение / автоматическое)
- Ограничение комментариев
- Закрытый канал — отлично для приватных клубов, VIP-клиентов, курсов

### Типы публикаций

- Текстовые посты (форматирование: жирный, курсив, ссылки)
- Фото и видео (до 4 ГБ)
- Документы и файлы
- Опросы
- Голосовые сообщения
- Репосты из других каналов

### Аналитика

На данный момент встроенная аналитика каналов ограничена:
- Счётчики просмотров (планируется)
- Статистика активности (планируется)
- Аналитика через рекламные кабинеты (доступна)

**Для туризма:** канал — площадка для публикации акций, фотоотчётов экскурсий, анонсов новых туров, отзывов клиентов.

## 4. Групповые чаты — подробно

### Создание группового чата

1. Нажать "+" в разделе "Чаты"
2. Выбрать "Создать групповой чат"
3. Добавить участников из контактов
4. Задать название и аватар группы

### Права и роли

| Роль | Возможности |
|------|-------------|
| Создатель | Полный контроль, удаление группы, назначение админов |
| Администратор | Модерация, удаление сообщений, бан участников, закрепление |
| Участник | Отправка сообщений (если разрешено), реакции |

### Ссылки-приглашения

- Генерация уникальной ссылки для вступления
- Возможность сброса ссылки (старая перестаёт работать)
- Ограничение по количеству вступлений (если настроено)

### Модерация

- Удаление отдельных сообщений
- Бан/разбан участников
- Запрет отправки определённого типа контента
- Медленный режим (slow mode) — ограничение частоты сообщений

### Применение для туризма

- **VIP-чат для клиентов** — закрытая группа с эксклюзивными предложениями
- **Рабочий чат команды** — координация гидов, водителей, менеджеров
- **Чат конкретного тура** — группа участников экскурсии (маршрут, время, контакты)

## 5. Звонки

### Аудио и видеозвонки

**Характеристики:**
- Без ограничений по длительности
- Без ограничений по количеству участников (групповые)
- Возможность отключения микрофона и камеры
- Демонстрация экрана (screen sharing)
- Звонок работает в фоне — можно одновременно писать в чатах

### Типы звонков

| Тип | Описание |
|-----|----------|
| Аудиозвонок 1-на-1 | Голосовой вызов между двумя пользователями |
| Видеозвонок 1-на-1 | С видео, переключение камер |
| Групповой аудио | Несколько участников, голос |
| Групповой видео | Несколько участников, видео + экран |
| Конференция | Запланированный звонок с ссылкой для подключения |

### Применение для туризма

- **Консультация клиента** — видеозвонок для обсуждения деталей тура
- **Демонстрация** — показ экрана с маршрутом, отелем, каталогом
- **Координация команды** — утренний созвон с гидами и водителями
- **Конференция** — групповой звонок с корпоративным клиентом

## 7. VK Pay и платежи

### Система быстрых платежей (СБП)

Max интегрирован с СБП — системой мгновенных переводов между банками РФ.

**Как перевести деньги:**
1. Открыть чат с получателем
2. Нажать на "скрепку" (вложения)
3. Выбрать "Деньги"
4. Указать сумму и подтвердить

**Требования:**
- Номер получателя должен быть в контактах
- Оба пользователя подключены к СБП
- Поддерживаемые банки (февраль 2026): Альфа-Банк, ВТБ (список расширяется)

### VK Pay

VK Pay — платёжная система экосистемы VK. Планируется полная интеграция с Max:
- Оплата товаров и услуг
- Переводы между пользователями
- Оплата в Mini Apps
- Приём платежей от клиентов (для бизнеса)

### Применение для туризма

**Текущее:** клиенты из РФ могут переводить рубли через СБП прямо в чате (если у вас или партнёра есть счёт в поддерживаемом банке РФ).

**Перспективное:** оплата туров через Mini App с VK Pay.

**Ограничение:** система работает только в рублях и между банками РФ. Для AED/USD клиент переводит в рублях, вы конвертируете.

## 8. Стикеры

### Магазин стикеров

Max имеет встроенный каталог стикерпаков. Пользователи могут:
- Просматривать и добавлять бесплатные стикерпаки
- Использовать стикеры в любых чатах
- Отправлять анимированные стикеры

### Создание собственных стикеров

Создание через бота **@stickers**:

**Процесс:**
1. Найти бота @stickers в поиске
2. Начать диалог, следовать инструкциям
3. Загрузить изображения как **файлы** (не как фото!)
4. Выбрать эмодзи-ассоциации для каждого стикера

**Требования к изображениям:**
- Формат: PNG или WEBP
- Размер: максимум 512x512 пикселей
- Прозрачный фон

**Для туризма:** брендированные стикеры — инструмент маркетинга:
- Стикерпак "Дубай" с достопримечательностями
- Эмоции путешественника
- Логотип и фирменные элементы компании
- Распространение через канал или чат — вирусный эффект

### Планы развития

- Магазин платных стикеров (авторы получают процент от продаж)
- Расширенные анимированные стикеры

## 9. Mini Apps

### Что такое Mini Apps

Веб-приложения, которые открываются внутри Max без выхода из мессенджера. Аналог Telegram Web Apps и WeChat Mini Programs.

**Технологии:** HTML, CSS, JavaScript + Max Bridge SDK для интеграции.

### Текущий статус (февраль 2026)

- SDK в стадии развития, документация расширяется
- Разработчики могут подать заявку на размещение Mini App
- Хостинг — на собственном сервере (HTTPS обязателен)
- Планируется маркетплейс Mini Apps

### Возможности для бизнеса

- Каталог товаров/услуг с фильтрами
- Форма бронирования (выбор даты, времени, количества)
- Оплата через VK Pay
- Электронные билеты и ваучеры (QR-коды)
- Фотогалерея с геолокацией
- Отзывы и рейтинги

### Применение для туризма ОАЭ

**Идеальный Mini App для туристического бизнеса:**
- Каталог экскурсий по Дубаю и Абу-Даби
- Бронирование с выбором даты и количества человек
- Встроенная оплата (VK Pay / СБП)
- Электронный ваучер после оплаты
- Push-напоминание перед экскурсией

**Важно:** Mini Apps пока не массовая функция. Для большинства бизнесов достаточно бота + канала.

## 10. Настройки приватности и безопасности

### Двухфакторная аутентификация (2FA)

Доступна с сентября 2025 года.

**Как включить:**
1. Профиль -> Приватность
2. Двухфакторная аутентификация
3. Задать дополнительный пароль (буквы + цифры, не повторяет пароль устройства)

**Второй фактор — пароль** (не SMS-код), что надёжнее.

### Безопасный режим

Активация "Безопасного режима" ограничивает нежелательные контакты:
- Скрывает профиль из общего поиска
- Ограничивает звонки и сообщения — "только контакты"
- Блокирует приглашения от незнакомых

### Настройки приватности

| Настройка | Варианты |
|-----------|----------|
| Поиск по номеру телефона | Вкл / Выкл |
| Статус "в сети" | Все / Контакты / Никто |
| Приглашения в чаты | Все / Только контакты |
| Звонки от незнакомых | Разрешить / Запретить |
| Последний визит | Виден всем / Контактам / Скрыт |

### Блокировка пользователей

- Заблокированный не может писать, звонить, видеть статус
- Список заблокированных в настройках приватности
- Разблокировка в любой момент

### Рекомендации для бизнес-аккаунта

- Включить 2FA обязательно
- Не включать "Безопасный режим" — клиенты должны находить вас
- Поиск по номеру — оставить включённым (чтобы клиенты находили)
- Приглашения — разрешить от всех

## 11. Интеграция с VK экосистемой

### VK ID

Единая система авторизации:
- Вход через VK аккаунт
- Вход через Госуслуги
- Вход через Alfa ID (Альфа-Банк)
- Одна учётная запись для всех сервисов VK

С сентября 2025 — пользователи VK могут авторизоваться через Max и наоборот.

### Связь с ВКонтакте

- Общий VK ID
- Синхронизация контактов
- Переход из VK в Max и обратно
- Общие Mini Apps

### Госуслуги

Планируется (в разработке):
- Электронная подпись через Госключ
- Цифровой ID
- Получение госуслуг прямо в мессенджере

### GigaChat

AI-ассистент от Сбера, встроенный в Max:
- Доступен как чат-бот
- Расшифровка голосовых
- Генерация контента
- Суммаризация

## 12. Бизнес-возможности

### Бизнес-аккаунт

**Что даёт:**
- Верифицированный профиль (синяя галочка)
- Доступ к созданию ботов через dev.max.ru
- Создание каналов (публичных)
- Доступ к API и Mini Apps
- Аналитика

**Стоимость:** бесплатно (по состоянию на февраль 2026). Платные тарифы планируются на 2026-2027.

### Верификация бизнеса

**Способы верификации:**
1. **Через Госуслуги** — владелец организации подтверждает через учётную запись
2. **Через Alfa ID** — мгновенная верификация для клиентов Альфа-Банка
3. **Через аккредитованные банки** — подтверждение связи владельца с юрлицом

**Требования:**
- ИНН организации (10 или 12 цифр)
- Верификацию проходит владелец (единоличный исполнительный орган) или лицо с правом первой подписи
- Платформа для верификации: dev.max.ru

### Требования к юрлицу

**Поддерживаются:**
- Юридические лица РФ (ООО, АО и др.)
- ИП (с ограничениями)

**Не поддерживаются:**
- Иностранные компании (в т.ч. ОАЭ) — напрямую
- Физические лица — для бизнес-функций

### Решение для бизнеса из ОАЭ

**Вариант 1: Партнёрство с компанией в РФ**
- Российский партнёр регистрирует бизнес-аккаунт
- Вы предоставляете контент и обрабатываете заявки
- Партнёр получает запросы, передаёт вам

**Вариант 2: Собственное юрлицо в РФ**
- Регистрация ООО/представительства в России
- Полный доступ ко всем бизнес-функциям Max
- Интеграция с основным бизнесом в ОАЭ

## 13. Примеры для туризма ОАЭ

### Сценарий 1: Канал "Экскурсии в Дубае"

**Контент-план:**
- Понедельник: анонс тура недели с ценой и фото
- Среда: фотоотчёт с прошедшей экскурсии
- Пятница: акция/скидка выходного дня
- Ежедневно: сторис-формат (короткие посты с фото)

**Результат:** подписчики видят актуальные предложения, обращаются в личку для бронирования.

### Сценарий 2: Рабочий чат команды

```
Группа: "Dubai Tours Team" (15 человек)
- Менеджер по бронированию
- 5 гидов
- 3 водителя
- 2 менеджера по продажам
- Бухгалтер
- Руководитель

Утро: маршруты дня, время подачи, контакты клиентов
День: отчёты гидов, фото
Вечер: итоги дня, финансы
```

### Сценарий 3: VIP-группа для постоянных клиентов

```
Группа: "Dubai VIP Club" (до 200 человек)
- Эксклюзивные цены (на 10-15% ниже)
- Ранний доступ к новым турам
- Персональные рекомендации
- Фото и видео от команды
```

### Сценарий 4: Переводы через СБП

```
Клиент из Москвы -> Max чат -> "Хочу сафари на завтра"
Менеджер: "Пустынное сафари, 290 AED = 7 500 руб."
Клиент: нажимает "скрепка" -> "Деньги" -> 7 500 руб.
Менеджер: получает перевод -> отправляет ваучер -> бронирует
```

## Стратегия для туристического бизнеса ОАЭ

### Краткосрочная (2026)

1. Создать канал "Экскурсии Дубай" — публикация акций, фото, анонсов
2. Использовать личные чаты для консультаций русскоязычных клиентов
3. Настроить переводы через СБП (партнёр в РФ)
4. Создать VIP-группу для постоянных клиентов

### Среднесрочная (2026-2027)

1. Рассмотреть бизнес-аккаунт (через партнёра или юрлицо РФ)
2. Подключить бота для автоответов и каталога (см. `max-bot-справочник`)
3. Протестировать Mini App для каталога туров (когда SDK стабилизируется)
4. Отслеживать Numbered Mailings (если запустят)

### Долгосрочная (2027+)

1. Полная интеграция Max в омниканальную стратегию
2. Mini App с бронированием и оплатой через VK Pay
3. Аналитика и оптимизация конверсий
4. Автоматизация через CRM-интеграции
