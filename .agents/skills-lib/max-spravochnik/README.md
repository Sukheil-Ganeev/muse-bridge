# Max — Справочник платформы

Справочник по мессенджеру Max (VK Messenger) как платформе для туристического бизнеса ОАЭ. Охватывает чаты, каналы, звонки, платежи, стикеры, Mini Apps, приватность и бизнес-возможности.

**Боты вынесены в отдельный справочник:** `max-bot-справочник`

## Структура

```
max-справочник/
├── SKILL.md              # Основной файл (~3500 слов, 14 разделов)
├── README.md             # Этот файл
├── references/
│   ├── faq.md            # 15 частых вопросов
│   ├── troubleshooting.md # 15 типичных проблем и решений
│   └── cheatsheet.md     # Шпаргалка по всем функциям
└── experience/
    └── _index.md         # Накопленный опыт
```

## Разделы SKILL.md

1. **Обзор платформы** — Max (ex-TamTam/ICQ), экосистема VK, аудитория 89+ млн
2. **Типы чатов** — личные, групповые, каналы
3. **Каналы** — создание, управление, публикация, аналитика
4. **Групповые чаты** — создание, модерация, права, ссылки-приглашения
5. **Звонки** — аудио/видео, групповые, конференции, демонстрация экрана
6. **Медиа и контент** — файлы до 4 ГБ, фото, видео, голосовые, GigaChat
7. **VK Pay и платежи** — СБП, переводы в рублях
8. **Стикеры** — магазин, создание через @stickers, брендированные паки
9. **Mini Apps** — мини-приложения, SDK, перспективы
10. **Приватность и безопасность** — 2FA, безопасный режим, настройки
11. **Интеграция с VK** — VK ID, Госуслуги, GigaChat
12. **Бизнес-возможности** — верификация, бизнес-аккаунт, решения для ОАЭ
13. **Примеры для туризма** — 4 практических сценария
14. **Лимиты и ограничения** — таблицы, сравнение с конкурентами

## Ключевые факты

| Параметр | Значение |
|----------|----------|
| Пользователей | 89+ млн (февраль 2026) |
| Суточная аудитория | 22,5 млн |
| Файлы | До 4 ГБ |
| Группа | До 1 000 участников |
| Регистрация | РФ, Беларусь, СНГ |
| Платежи | СБП (рубли, банки РФ) |
| Бизнес-аккаунт | Юрлицо РФ, бесплатно |
| Предустановка | Обязательна с 01.09.2025 |

## Для туризма ОАЭ

- Приоритет 4 после WhatsApp, Telegram, Instagram
- Критичен при >30% клиентов из РФ
- Бизнес-функции требуют юрлицо РФ (или партнёра)
- Канал + личные чаты + СБП = рабочая связка
