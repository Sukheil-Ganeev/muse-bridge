# Опыт работы с Max (платформа)

Критические уроки и best practices из реальной практики.

---

## Критические уроки (топ-5)

### 1. Max != VK Bot API

**Урок:** Max имеет СОБСТВЕННЫЙ Bot API (platform-api.max.ru), отличный от VK Bot API. Не путать платформы. Бот-контент вынесен в `max-bot-справочник`.

---

### 2. Бизнес-функции требуют юрлицо РФ

**Урок:** без российского юрлица доступ к бизнес-инструментам (верификация, публичные каналы, API) закрыт.

**Решения:**
- Партнёрство с компанией в РФ
- Регистрация ООО в России (если значительная аудитория)
- Использование Max как дополнительного канала (личные чаты, приватные каналы)

---

### 3. Каналы — приватные доступны всем с февраля 2026

**Статус:** с 9 февраля 2026 любой пользователь может создать приватный канал. Публичные — по заявке.

---

### 4. СБП — ограниченный список банков

**Проблема:** переводы через СБП работают только с поддерживаемыми банками (Альфа-Банк, ВТБ).

**Решение:** уточнять у клиента банк перед предложением оплаты через Max.

---

### 5. Max — нишевая платформа для РФ

**Реальность 2026:** 89+ млн зарег., но основная аудитория — Россия.

**Для туризма ОАЭ:**
- Приоритет: WhatsApp, Telegram, Instagram
- Max: опционально, если >30% клиентов из РФ

---

## Предупреждения

### НЕ путать Max Bot API с VK Bot API

**Ошибка:** в старой версии справочника использовались VK API эндпоинты (api.vk.com) и библиотека vk_api. Это НЕПРАВИЛЬНО для Max.

**Правильно:** Max Bot API — platform-api.max.ru, свои методы, своя документация.

---

### НЕ фетчить dev.tamtam.chat и botapi.tamtam.chat

**Проблема:** старые TamTam домены мёртвые или медленные.

**Правильно:** использовать WebSearch, dev.max.ru, help.max.ru.

---

## Рекомендации для туризма ОАЭ

### Когда использовать Max

**Критерии:**
1. >30% клиентов из России
2. Есть партнёр/юрлицо в РФ
3. Telegram/WhatsApp уже используются (Max как дополнение)

**Иначе:** сфокусироваться на WhatsApp/Telegram.
