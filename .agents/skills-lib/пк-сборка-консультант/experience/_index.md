# Опыт скилла: пк-сборка-консультант

> Читать при каждой активации скилла!

## Критические уроки (топ-5)

1. **ВСЕГДА проверять совместимость** -- даже если пользователь не просит. Несовместимые компоненты = деньги на ветер
2. **RTX 5090 требует 1000-1200W БП** -- не 850W как иногда пишут в интернете
3. **Ryzen с суффиксом F не имеет встроенной графики** -- нельзя рекомендовать для офисных сборок без дискретной GPU
4. **DDR5-6000 оптимальна для AMD AM5** -- выше может быть МЕДЛЕННЕЕ из-за рассинхрона с Infinity Fabric
5. **NH-D15 G2 высота 168мм, не 165мм** -- критично для компактных корпусов

## Частые ошибки

- Рекомендовать EVGA -- компания закрылась в 2022
- Ссылаться на UserBenchmark -- дискредитированный ресурс
- Не предупреждать о SOCD/Snap Tap бане в CS2
- Забывать про вентиляторы корпуса при расчёте бюджета
- Не учитывать высоту RAM при выборе башенного кулера
