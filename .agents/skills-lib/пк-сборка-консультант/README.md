# пк-сборка-консультант

Мега-скилл -- экспертный консультант по сборке и выбору компонентов ПК.

## Структура

```
пк-сборка-консультант/
├── SKILL.md                    # Основной файл скилла (маршрутизация и алгоритмы)
├── README.md                   # Этот файл
├── references/
│   ├── scenarios.md            # Подробные workflow 7 сценариев
│   ├── builds-2026.md          # 3 готовые конфигурации ($800/$1500/$3000)
│   ├── faq.md                  # 30+ частых вопросов
│   ├── cheatsheet.md           # Быстрая шпаргалка
│   └── troubleshooting.md      # Решение проблем
├── assets/
│   └── templates/
│       ├── build-request.md    # Шаблон конфигурации
│       └── comparison.md       # Шаблон сравнения
└── experience/
    └── _index.md               # Накопленный опыт (обновляется)
```

## Источник данных

23 справочника по компонентам ПК + 3 бонусных файла:
`D:/Downloads/PC_GUIDES/`

Скилл НЕ дублирует данные -- читает справочники динамически через Read tool.

## Сценарии использования

1. Полная сборка ПК под бюджет и задачи
2. Выбор конкретного компонента
3. Проверка совместимости
4. Сравнение компонентов
5. Консультация для новичка
6. Бюджетная сборка
7. Ревью готовой конфигурации
