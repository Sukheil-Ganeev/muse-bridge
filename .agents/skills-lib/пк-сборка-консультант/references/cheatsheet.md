# Шпаргалка — Быстрый справочник

> Компактный справочник для быстрых ответов без погружения в полные справочники.

---

## 1. Компоненты: ключевые параметры

| Компонент | Ключевые параметры | На что смотреть в первую очередь | Справочник |
|-----------|-------------------|----------------------------------|------------|
| **CPU** | Сокет, ядра/потоки, частота, TDP, кэш | Сокет (совместимость с MB!), TDP (нужен кулер), поколение | `01_CPU.md` |
| **GPU** | VRAM, TDP, длина, архитектура | VRAM (8/12/16GB), TDP (хватит ли БП?), длина (влезет ли?) | `02_GPU.md` |
| **RAM** | Тип (DDR4/5), частота, CL, объём, кол-во планок | Тип (совместимость!), 2 планки обязательно, частота | `03_RAM.md` |
| **MB** | Сокет, чипсет, форм-фактор, слоты, VRM | Сокет (совместимость!), форм-фактор, кол-во M.2 слотов | `04_MOTHERBOARD.md` |
| **PSU** | Мощность (W), сертификат (80+), модульность, кабели | Мощность с запасом 20-30%, бренд (!), наличие 12VHPWR | `05_PSU.md` |
| **Case** | Форм-фактор, макс. длина GPU, макс. высота кулера, airflow | Совместимость с MB, вместимость GPU и кулера | `06_CASE.md` |
| **SSD** | Интерфейс (NVMe/SATA), Gen (3/4/5), объём, TBW | Gen4 — оптимум, 1TB минимум, бренд | `07_STORAGE.md` |
| **Cooler** | Тип (башня/AIO), TDP рассеивания, высота, сокеты | Совместимость с сокетом, достаточность для TDP CPU | `08_COOLING.md` |
| **Monitor** | Разрешение, частота (Hz), матрица, время отклика | Разрешение (под GPU!), частота (144Hz+ для игр) | `11_MONITOR.md` |

## 2. Таблица совместимости (краткая)

### Критичная совместимость (не будет работать)

| Что | С чем | Что должно совпадать | Пример |
|-----|-------|---------------------|--------|
| CPU | MB | Сокет | AM5 = AM5, LGA1851 = LGA1851 |
| CPU | RAM | Тип памяти | AM5 → DDR5, AM4 → DDR4 |
| MB | RAM | Тип памяти + макс. частота | DDR5 слоты ≠ DDR4 планки |
| MB | Case | Форм-фактор | ATX плата → ATX+ корпус |

### Физическая совместимость (не влезет)

| Что | Куда | Что проверять |
|-----|------|--------------|
| GPU | Case | Длина GPU <= макс. длина в корпусе |
| Cooler | Case | Высота кулера <= макс. высота в корпусе |
| Cooler | RAM | Клиренс под кулером >= высота планки RAM |
| AIO радиатор | Case | Есть ли место для 240/280/360mm |

### Электрическая совместимость (не хватит питания)

| Что | С чем | Правило |
|-----|-------|---------|
| Вся система | PSU | Суммарное TDP × 1.25 <= мощность БП |
| GPU | PSU | Есть нужные кабели (12VHPWR / 8pin×2) |
| CPU | PSU | Есть EPS кабель (8pin или 8+4pin) |

## 4. Топ ошибок новичков: "Не делай так!"

| # | Ошибка | Почему плохо | Как правильно |
|---|--------|-------------|---------------|
| 1 | **Одна планка RAM** | Нет двухканального режима, минус 10-15% FPS | Всегда 2 планки (2x8, 2x16, 2x32) |
| 2 | **Дешёвый noname БП** | Нестабильное питание, может сгореть и спалить всё | Seasonic, Corsair, be quiet!, EVGA — минимум 80+ Bronze |
| 3 | **Забыли кулер** | CPU перегревается, троттлит, может выключаться | Если нет боксового — докупить башню ($25-35) |
| 4 | **Несовместимый сокет** | CPU физически не встанет в MB | Проверить сокет: AM5=AM5, LGA1851=LGA1851 |
| 5 | **GPU не влезает в корпус** | Карта длиннее свободного места | Сравнить длину GPU и макс. длину в спеках корпуса |
| 6 | **БП без запаса** | Работает на пределе, шумит, может отключаться | Запас 20-30% сверх расчётного потребления |
| 7 | **DDR4 в DDR5 слоты** | Физически разные разъёмы, не вставится | Проверить тип RAM на MB |
| 8 | **RAM в неправильных слотах** | Нет двухканала, работает медленнее | Слоты A2+B2 (2-й и 4-й) — читать мануал MB |
| 9 | **Забыли подключить питание GPU** | Видеокарта не запустится | Подключить все кабели питания от БП к GPU |
| 10 | **Игнорируют airflow** | Всё перегревается в закрытом корпусе | Минимум 2-3 вентилятора, перед = вдув, зад = выдув |
| 11 | **Экономят на всём ради GPU** | Система несбалансирована, GPU простаивает | Баланс компонентов важнее одного мощного |
| 12 | **Не включают XMP/EXPO** | RAM работает на DDR5-4800 вместо DDR5-6000 | Зайти в BIOS → включить XMP/EXPO |

## 5. Словарь терминов для новичков

| Термин | Расшифровка | Простое объяснение |
|--------|-------------|-------------------|
| **CPU** | Central Processing Unit | Процессор — мозг компьютера |
| **GPU** | Graphics Processing Unit | Видеокарта — рисует картинку на экране |
| **RAM** | Random Access Memory | Оперативная память — рабочий стол, очищается при выключении |
| **SSD** | Solid State Drive | Твердотельный накопитель — быстрое хранилище файлов |
| **NVMe** | Non-Volatile Memory Express | Очень быстрый интерфейс для SSD (через M.2 разъём) |
| **HDD** | Hard Disk Drive | Жёсткий диск — медленное хранилище с вращающимся диском |
| **MB / Mobo** | Motherboard | Материнская плата — соединяет все компоненты |
| **PSU** | Power Supply Unit | Блок питания — подаёт электричество |
| **AIO** | All-In-One (cooler) | Жидкостное охлаждение "всё-в-одном" с радиатором и помпой |
| **TDP** | Thermal Design Power | Тепловыделение в ваттах — сколько тепла нужно отводить |
| **Сокет** | Socket | Разъём на MB для установки CPU (AM5, LGA1851) |
| **Чипсет** | Chipset | Набор микросхем на MB, определяет возможности (B650, X870, Z890) |
| **Форм-фактор** | Form Factor | Размер платы/корпуса (ATX, mATX, ITX) |
| **PCIe** | PCI Express | Высокоскоростная шина для GPU и SSD (Gen3, Gen4, Gen5) |
| **VRAM** | Video RAM | Видеопамять — своя память у видеокарты |
| **Двухканал** | Dual Channel | Режим работы RAM в 2 планках — вдвое шире шина данных |
| **XMP / EXPO** | Extreme Memory Profile | Профиль разгона RAM — включить для заявленной скорости |
| **BIOS** | Basic I/O System | Базовая прошивка MB — настройка перед загрузкой ОС |
| **Bottleneck** | — | Узкое место — слабый компонент ограничивает мощный |
| **Airflow** | — | Воздушный поток в корпусе — охлаждение компонентов |
| **OC / Разгон** | Overclocking | Повышение частоты компонента выше стандартной |
| **Модульный БП** | Modular PSU | БП, где кабели отключаются — удобнее, чище укладка |
| **80+ Bronze/Gold** | — | Сертификат эффективности БП (Gold > Bronze > White) |
| **QVL** | Qualified Vendor List | Список RAM, протестированных с данной MB |
| **M.2** | — | Компактный разъём для SSD на материнской плате |
| **ATX 3.0/3.1** | — | Стандарт БП с 12VHPWR разъёмом для новых GPU |
| **12VHPWR** | — | Новый разъём питания GPU (RTX 4000/5000, RX 9000) |
| **Ray Tracing (RT)** | — | Технология реалистичного освещения в играх |
| **DLSS / FSR** | — | Технологии апскейлинга: ИИ повышает FPS с минимальной потерей качества |
| **CL / Тайминги** | CAS Latency | Задержка RAM — чем меньше число, тем быстрее (CL30 > CL36) |

## 6. Быстрые формулы

### Мощность БП
```
Минимум = (CPU TDP + GPU TDP + 100W) × 1.25
Рекомендуется = (CPU TDP + GPU TDP + 100W) × 1.3
```

### Примеры расчёта БП

| Конфигурация | Расчёт | Рекомендация |
|-------------|--------|--------------|
| R5 9600X (65W) + RTX 5060 (150W) | (65+150+100)×1.25 = 394W | 550-650W |
| R7 9700X (65W) + RTX 5070 Ti (250W) | (65+250+100)×1.25 = 519W | 650-750W |
| R7 9800X3D (120W) + RTX 5080 (300W) | (120+300+100)×1.25 = 650W | 850-1000W |
| i7 265K (125W) + RTX 5090 (450W) | (125+450+100)×1.25 = 844W | 1000-1200W |

### Баланс CPU↔GPU (нет bottleneck)

| Уровень GPU | Минимальный CPU |
|-------------|----------------|
| RTX 5060 / RX 9070 | Ryzen 5 9600X / i5 245K |
| RTX 5070 | Ryzen 5 9600X / i5 245K |
| RTX 5070 Ti | Ryzen 7 9700X / i7 265K |
| RTX 5080 | Ryzen 7 9800X3D / i7 265K |
| RTX 5090 | Ryzen 7 9800X3D / i9 285K |

## 7. Чеклист перед покупкой (финальный)

```
[ ] Сокет CPU = сокет MB
[ ] Тип RAM = тип MB (DDR4/DDR5)
[ ] Форм-фактор MB <= форм-фактор Case
[ ] Длина GPU <= макс. длина в Case
[ ] Высота кулера <= макс. высота в Case
[ ] Мощность БП >= расчётная с запасом 25%
[ ] БП имеет нужные кабели (12VHPWR, EPS)
[ ] RAM — 2 планки (двухканал!)
[ ] Кулер поддерживает сокет CPU
[ ] Кулер справится с TDP CPU
[ ] Wi-Fi на MB или адаптер
[ ] Достаточно USB портов
[ ] Не забыты: термопаста, ОС, монитор, периферия
```
