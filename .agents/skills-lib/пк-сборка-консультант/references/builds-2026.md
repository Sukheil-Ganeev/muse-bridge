### Почему 9800X3D?
- Абсолютный лидер в играх благодаря 3D V-Cache (96MB L3)
- В среднем на 10-15% быстрее обычных CPU в играх
- 120W TDP — умеренное тепловыделение для топа
- AM5 — возможность будущего апгрейда на Zen 6

### Почему RTX 5080, а не RTX 5090?
- RTX 5090 стоит ~$2000 — почти вдвое дороже
- RTX 5080 даёт 70-80% производительности 5090
- Для 1440p — RTX 5080 более чем достаточно
- Для 4K — тоже отлично справляется

| CPU | Ryzen 7 9700X (~$300, -10-15% в играх) | Ryzen 9 9900X (~$450, лучше многопоток) |
| GPU | RTX 5070 Ti (~$750, -20% произв.) | RTX 5090 (~$2000, +25% произв.) |
| RAM | DDR5-6000 CL32 (~$80) | 2x32GB DDR5-6000 (~$200, 64GB для проф. задач) |
| MB | B650E Tomahawk (~$180) | X870E Godlike (~$600+, излишне для большинства) |
| Кулер | AIO 240mm (~$60) | Custom WC loop (~$500+, для энтузиастов) |

### Заметки
- 1000W БП — запас для RTX 5080 с пиковыми нагрузками + будущий апгрейд
- ATX 3.1 / 12VHPWR кабель — нативная поддержка, без переходников
- X870E — максимум разъёмов, USB, PCIe 5.0, Wi-Fi 7
- 9800X3D — лучший игровой CPU, но если задачи больше рабочие, рассмотреть 9900X/9950X
