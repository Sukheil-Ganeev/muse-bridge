# EXP-CMD-001: Максимум 8 скиллов на агента при чтении SKILL.md

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Severity:** critical
**Категория:** fix

## Проблема

При анализе 90 скиллов в Волне 0, агенты получили по 15-16 скиллов для чтения SKILL.md файлов. 3 из 6 агентов упали с ошибкой "Prompt is too long":
- Агент 1: 15 скиллов -- FAIL
- Агент 2: 16 скиллов -- FAIL
- Агент 3: 15 скиллов -- FAIL

SKILL.md файлы в среднем 3-5 KB каждый, но при 15 файлах суммарный объём превышал лимит контекста агента.

## Решение

Разбить группы на 7-8 скиллов максимум на агента. После split:
- 9 агентов по 7-10 скиллов -- 100% успех (0 падений)

## Правило

```
max_skills_per_agent = 8  # для задач чтения/анализа SKILL.md
```

При планировании: `ceil(total_skills / 8)` = количество агентов.
Для 90 скиллов: `ceil(90 / 8)` = 12 агентов (мы использовали 11, один получил 10).

## Подтверждение

- До split: 3/6 агентов (50%) упали
- После split: 0/9 агентов (0%) упали
- Правило подтверждено с запасом
