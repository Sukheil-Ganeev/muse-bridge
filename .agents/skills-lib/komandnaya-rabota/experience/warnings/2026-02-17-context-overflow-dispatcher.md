# EXP-CMD-011: Context overflow диспетчера при параллельном рефакторинге

**Дата:** 2026-02-17
**Проект:** Волна 5 рефакторинга скиллов
**Категория:** warning

## Проблема
Диспетчер (главное окно) запустил 6 параллельных агентов для рефакторинга 14 скиллов.
Когда 2 агента провалились, диспетчер начал:
1. Запускать bash-проверки (wc -w) для диагностики
2. Перезапускать агентов (agent-1b, agent-4b)
3. Получать и обрабатывать отчёты завершившихся агентов

Результат: контекст главного окна переполнился РАНЬШЕ, чем завершились 5 из 8 агентов.
- Результаты 5 агентов не проверены
- netlify-deployment вообще не получил перезапуска
- Gate G1, Волна 2, Gate G2 — НЕ выполнены
- Из 15 FAIL подтверждено исправлено только 4

## Решение
1. Диспетчер НЕ запускает wc/grep/проверки — делегирует агенту-верификатору
2. При провале агента — перезапуск через ОТДЕЛЬНОГО агента-диспетчера (субагент), а не в главном окне
3. Все промежуточные проверки — через фоновые субагенты (run_in_background=true)
4. Главное окно: только TaskCreate, TaskUpdate, SendMessage

## Правило
Главное окно при параллельной работе 6+ агентов:
- НЕ запускать bash-команды (даже простые wc -w)
- НЕ читать файлы (даже маленькие)
- Только управлять задачами и агентами
- Все проверки — через субагентов
