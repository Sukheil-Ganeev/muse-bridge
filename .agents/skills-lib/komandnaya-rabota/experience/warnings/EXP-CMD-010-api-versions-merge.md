# EXP-CMD-010: API версии при merge -- обновлять до актуальной

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Severity:** high
**Категория:** warning

## Проблема

При merge двух скиллов, использующих разные версии одного API, агент может скопировать устаревшую версию из одного из источников.

## Конкретный пример

**Merge #2:** instagram-bot + facebook-messenger-bot -> meta-messenger-bot

| Источник | API версия |
|----------|-----------|
| instagram-bot-справочник | Meta Graph API v21.0 |
| facebook-messenger-bot-справочник | Meta Graph API v22.0 |

При merge агент мог использовать v21.0 (устаревшую) в некоторых секциях, если не получил явную инструкцию.

## Решение

В MERGE_MAPPING.md для каждого merge с API:

```markdown
### API версии
- Источник A: v21.0
- Источник B: v22.0
- **ЦЕЛЕВАЯ:** v22.0 (максимальная)
- ПРАВИЛО: Все ссылки на API обновить до v22.0
```

Merge-агент ОБЯЗАН:
1. Использовать НОВЕЙШУЮ версию API из всех источников
2. Обновить ВСЕ URL и ссылки до актуальной версии
3. Проверить, что нет смешения версий в результате

## Когда применять

- При merge любых скиллов с API интеграциями
- При merge справочников по платформам (Meta, VK, Telegram и т.д.)
- При merge любых технических скиллов с версионированием
