# EXP-CMD-009: Лимит 5000 слов при merge -- следить!

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Severity:** high
**Категория:** warning

## Проблема

При объединении 2+ скиллов легко превысить стандартный лимит SKILL.md (5000 слов). Если не контролировать размер -- результат выходит за рамки стандарта, файл становится слишком длинным для эффективного использования.

## Конкретный пример

**Merge #4:** создание-карточек-каталога -> форматирование-турпродуктов

- Исходный размер форматирование-турпродуктов: ~3800 слов
- Добавленный контент из создание-карточек-каталога: ~1200 слов
- Результат после merge: 4893 слова (в рамках лимита, но впритык)
- Модульная система вынесена в `references/modules.md` для экономии места

Если бы контент не был вынесен -- файл превысил бы 5500 слов.

## Решение

Mapper должен на этапе планирования:

1. Оценить текущий размер целевого SKILL.md (в словах)
2. Оценить объём добавляемого контента
3. Если сумма > 4500 слов -- спланировать вынос в references/:
   - Таблицы -> `references/cheatsheet.md`
   - FAQ -> `references/faq.md`
   - Модули/детали -> `references/modules.md`
   - Примеры -> `references/examples.md`

## Формула

```
estimated_total = current_words + added_words - duplicates_removed
if estimated_total > 4500:
    plan_references_extraction()
```
