# EXP-CMD-012: Pipeline рефакторинга скиллов (T-003 word count)

**Дата:** 2026-02-17
**Проект:** Волна 5 рефакторинга скиллов
**Категория:** pattern

## Описание
Проверенный pipeline для снижения word count SKILL.md с сохранением 100% контента.

### Шаг 0: Бэкап
```bash
cp -r skill_folder backup_folder
```
ОБЯЗАТЕЛЬНО до любых изменений.

### Шаг 1: Рефакторинг (параллельные агенты)
Распределение по весу:
- >7000 слов: 1 скилл/агент
- 5500-7000: 2 скилла/агент
- <5500: до 4/агент

Паттерн: "Summarize + Delegate to References"
- SKILL.md: 3500-5000 слов (ядро)
- references/: детали (код, JSON, примеры)
- В SKILL.md ссылки: → references/файл.md

### Шаг 2: Верификация (параллельные аудит-агенты)
1 агент на 1 скилл:
1. Карта секций (бэкап → текущий, по каждому заголовку)
2. Grep ключевых сущностей (функции, API, числа, термины)
3. Сравнение total word count (SKILL + refs, до vs после)

### Шаг 3: Исправление (если найдены потери)
Из бэкапа восстановить потерянный контент в references/ или SKILL.md.

## Результаты
- 3 скилла рефакторены: 100% контент сохранён
- Аудит подтвердил: 314+ сущностей проверено, 0 потерь
- Целевой word count: 3,498-3,706 слов (идеально)

## Антипаттерны
- НЕ давать агенту инструкцию "сократи" без указания "перенеси в references"
- НЕ назначать 2+ тяжёлых скилла одному агенту
- НЕ пропускать бэкап и верификацию
- Агент может УВЕЛИЧИТЬ файл вместо сокращения (фото-редактор: 11,551→11,981)
