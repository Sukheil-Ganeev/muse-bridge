# Паттерн: Анализ экспортированных сессий

**Дата:** 2026-02-19
**Контекст:** Анализ exported Claude Code conversation

## Workflow
1. Экспорт: `/export` в Claude Code → файл .txt в рабочей директории
2. Поиск: файл сохраняется в CWD сессии (обычно C:/Users/londo/)
3. Анализ: субагент sonnet читает и пишет отчёт
4. Обновления: параллельные субагенты обновляют MEMORY.md, скиллы, changelog

## Уроки
- Файл экспорта = CWD сессии, НЕ D:/Downloads/
- Имя файла = случайные цифры .txt
- Для больших файлов: только субагент (не главное окно)
- Параллельные обновления экономят время

## Антипаттерны
- НЕ искать файл через find / (слишком долго на Windows)
- НЕ читать экспорт в главном окне (забивает контекст)
- НЕ обновлять всё последовательно (параллелить!)
