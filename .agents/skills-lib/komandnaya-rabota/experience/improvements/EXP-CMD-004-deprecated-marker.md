# EXP-CMD-004: DEPRECATED маркер лучше немедленного удаления

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Severity:** high
**Категория:** improvement

## Описание

После merge операции вместо немедленного удаления исходных скиллов -- добавить DEPRECATED маркер. Удаление выполняется отдельной задачей ПОСЛЕ полной верификации.

## Реализация

### 1. YAML frontmatter
```yaml
---
name: создание-карточек-каталога
description: "DEPRECATED - контент перенесён в форматирование-турпродуктов. Используй форматирование-турпродуктов вместо этого скилла."
---
```

### 2. Blockquote в начале SKILL.md
```markdown
> **DEPRECATED:** Этот скилл объединён в [форматирование-турпродуктов].
> Используй форматирование-турпродуктов для всех задач форматирования.
> Дата: 2026-02-17
```

## Преимущества

1. **Страховка:** Если merge оказался неполным -- оригинальный контент доступен
2. **Плавная миграция:** Пользователи видят куда перенаправиться
3. **Верифицируемость:** Можно сравнить deprecated скилл с merge-результатом
4. **Откат:** В случае проблемы -- просто убрать маркер

## Workflow

```
Merge -> DEPRECATED маркер -> Верификация (Волна 3) -> USER подтверждение -> Удаление (Волна 4)
```
