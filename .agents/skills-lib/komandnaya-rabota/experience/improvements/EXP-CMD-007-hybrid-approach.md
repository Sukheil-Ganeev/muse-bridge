# EXP-CMD-007: Тиммейт vs субагент -- гибридный подход работает

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Severity:** high
**Категория:** improvement

## Описание

В проекте Skills Merge подтверждён гибридный подход: тиммейты для координационных задач, обычные субагенты для исполнения.

## Сравнение в проекте

| Роль | Тип | Результат |
|------|-----|-----------|
| Mapper (координация) | Тиммейт (mailbox) | Успех -- создал MERGE_MAPPING.md |
| 6 merge-агентов (исполнение) | Субагенты (без team_name) | 6/6 успех (100%) |

## Когда тиммейт

- Агент должен **общаться** с другими агентами через SendMessage
- Агент выполняет **координационную** роль (mapper, orchestrator)
- Результат агента нужен **другим агентам** в реальном времени

## Когда субагент

- Агент выполняет **самостоятельную** задачу (merge, write, convert)
- Результат -- **файл**, который проверяется через Gate
- Агент **не зависит** от других агентов в процессе работы
