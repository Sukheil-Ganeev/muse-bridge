# Командная работа -- скилл координации многоагентных команд

## Описание

Скилл для координации многоагентных команд в Claude Code. Охватывает полный цикл: от планирования волн и создания задач до shutdown агентов и пост-мортема. Подходит для проектов любого масштаба (от 3 до 18+ агентов).

## Быстрый старт

1. **TeamCreate** -- создай команду с именем проекта
2. **mkdir** -- создай папки `_research/`, `_qa/`
3. **TaskCreate x N** -- создай все задачи сразу (Волна 1 подробно, Волны 2-5 каркас)
4. **TaskUpdate addBlockedBy** -- настрой зависимости между волнами
5. **Task x N** -- запусти Волну 1 (параллельно, run_in_background: true)
6. **Quality Gate G1** -- проверь файлы через Explore-агента
7. **Волна 2** -- critic + advocate
8. **Quality Gate G2** -- 0 критических ошибок
9. **Волна 3** -- technical-writer
10. **Quality Gate G3** -- все файлы на месте
11. **Волна 4-5** -- презентация + улучшения (параллельно)
12. **Shutdown всех + TeamDelete**

## Связь со скиллом 2

Этот скилл содержит БАЗОВЫЕ принципы координации команд. Для конкретного сценария создания справочников используй дополнительный скилл **командная-работа-справочники**, который расширяет этот скилл:

- **командная-работа** -- HOW (как координировать команду)
- **командная-работа-справочники** -- WHAT (что конкретно делать для справочника: 18 ролей, 14 разделов, шаблоны промптов)

Скилл **командная-работа-справочники** REQUIRES этот скилл и ссылается на него для базовых принципов.

## Ключевые концепции

- **Волны** -- группы параллельных задач с зависимостями между волнами
- **Quality Gates** -- точки контроля между волнами (G1, G2, G3)
- **Handoff-протокол** -- стандарт передачи контекста между волнами
- **Retry Budget** -- максимальное количество перезапусков агента
- **Checkpoint Snapshots** -- снимки состояния после каждой волны
- **Промпт продолжения** -- файл для восстановления контекста в новой сессии
