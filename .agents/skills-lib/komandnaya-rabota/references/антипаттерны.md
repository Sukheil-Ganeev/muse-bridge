# Антипаттерны командной работы
> Актуально на: 2026-02-15

## 1. Голодание контекста
**Симптом:** Главное окно заполняется раньше чем тиммейты завершают
**Причина:** Чтение больших файлов / WebSearch в главном окне
**Решение:** Рекомендуется до 5KB за раз; допустимо до 10KB для одноразовой полной проверки. Систематическое чтение больших файлов — делегируй агенту

## 2. Зомби-агенты
**Симптом:** Idle агенты висят после завершения задач
**Причина:** Не отправлен shutdown_request
**Решение:** Shutdown после прохождения Quality Gate (не сразу после волны — агенты могут понадобиться для уточнений)

## 3. Ложные данные
**Симптом:** В финальном документе ошибки, противоречия
**Причина:** Пропущена Волна верификации
**Решение:** ВСЕГДА запускай critic + advocate. В первом проекте нашли 7 критических ошибок.

## 4. Задачи-сироты
**Симптом:** Задачи без зависимостей запускаются раньше времени
**Причина:** Забыли addBlockedBy
**Решение:** Создавай задачи Волны 1 + каркас Волн 2-5 с зависимостями ДО запуска агентов; уточни после architect [ОБНОВЛЕНО по Ревизии 7]

## 5. Агент-универсал
**Симптом:** Один агент делает всё → контекст переполняется
**Причина:** Слишком широкий промпт
**Решение:** Один агент = одна специализация. Разделяй.

## 6. Тихий провал
**Симптом:** Агент не нашёл данных но не сообщил
**Причина:** В промпте нет инструкции про ненайденные данные
**Решение:** В каждом промпте: "Если не найдёшь — пометь [НЕ НАЙДЕНО]"

## 7. Гонка за API
**Симптом:** Лимиты API исчерпаны на этапе исследования
**Причина:** Все исследователи дёргают API
**Решение:** Исследователи = WebSearch. API = только advocate в Волне 2.

## 8. Дублирование данных
**Симптом:** Одна информация в 3 файлах, при обновлении — конфликты
**Причина:** Нет чёткого ownership данных
**Решение:** Каждый факт живёт в ОДНОМ файле. Другие — ссылаются.

## 9. Слепой перезапуск
**Симптом:** Агент не работает, перезапуск — опять не работает, ещё раз...
**Причина:** Не выяснена корневая причина сбоя
**Решение:** После ПЕРВОГО сбоя — СТОП и диагностика. ls файлов, проверка ошибок. Смена подхода после анализа. НИКОГДА не повторять одно действие 3 раза.

## 10. Mailbox Miss
**Симптом:** Тиммейт стартует и сразу уходит в idle без работы
**Причина:** Задача через mailbox не доставлена / не обработана
**Решение:** Для файловых задач — обычные субагенты (Task без team_name). Тиммейты только для межагентной коммуникации.

## 11. Перегрузка контекста субагента
**Симптом:** Агент падает с "Prompt is too long"
**Причина:** Слишком много больших файлов в одном промпте
**Решение:** Максимум 3-4 больших файла на субагента. Для справочников >500KB — обязательно дробить.
