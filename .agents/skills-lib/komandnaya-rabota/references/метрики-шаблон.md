## Метрики эффективности команды

### Ключевые KPI

| Метрика | Формула | Хорошо | Плохо |
|---------|---------|--------|-------|
| Completion Rate | завершённых / запланированных * 100% | >= 90% | < 70% |
| Retry Rate | retries / total_tasks * 100% | < 15% | > 30% |
| False Positive Rate | ложных critic / всего critic * 100% | < 25% | > 40% |
| Gate Pass Rate | gates passed 1st try / total gates | >= 80% | < 50% |
| Context Utilization | используемый контекст / лимит | 60-80% | > 90% |
| Agent Efficiency | качество результата / retry count | > 7/10 при 0 retry | < 5/10 при 2+ retry |

### Данные проекта Битрикс24 (эталон)

| Параметр | Значение | Заметки |
|----------|----------|---------|
| Агентов запланировано | 18 | |
| Агентов запущено | 20+ | +pre-research, +fix-агенты |
| Тип агентов | Обычные субагенты | 0 тиммейтов, 100% успех |
| Параллельных в пике | 7 (исследователи) | Все завершились |
| Ошибок critic | 27 | |
| Подтверждено advocate | 13 | |
| Ложных срабатываний | 9 (33%) | Высокий % -- critic пере-осторожен |
| QA оценка | 8.5/10 | |
| Файлов создано | 94 | |
| Общий размер | ~1 MB | |
| Волн | 5/5 | |
| Пересессий | 0 | Весь проект в 1 сессию |
| Writer токенов | 198K | Самая тяжёлая задача |
| Слияние ролей | design+html, finalizer+interactive | Подтверждено |

### Ключевые выводы по профилированию

- **Critic** при 33% ложных срабатываний -- нормально, лучше пере-проверить
- **Writer** на 198K токенов -- предел, для более крупных проектов разделять на 2
- **Pre-research агенты** (5-10 мин) -- значительно улучшают quality планирования
- **TaskOutput timeout 300-600 сек** -- стандарт для тяжёлых задач (вместо 120)

## Формула оценки контекста

| Элемент | Токены |
|---------|--------|
| Каждый тиммейт при запуске | ~2-3K |
| Каждое сообщение от тиммейта | ~500-1000 |
| Каждый TaskCreate/TaskUpdate | ~200 |
| Бюджет главного окна | ~150K |
| Бюджет токенов за волну (5 агентов) | ~750K |

Максимум тиммейтов: базовый состав 18, +2-3 fix-агентов (до 21).
Если больше -- разделять на сессии.
