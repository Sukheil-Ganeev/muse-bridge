# Типы агентов
> Актуально на: 2026-02-15

| Тип | Инструменты | Когда использовать |
|-----|-------------|-------------------|
| general-purpose | ВСЕ (WebSearch, Edit, Write, Bash, Read...) | Исследование, создание файлов, любые задачи |
| Explore | Read, Grep, Glob, WebSearch, WebFetch | Быстрый анализ, чтение, поиск (НЕ может редактировать) |
| Plan | Read, Grep, Glob, WebSearch | Планирование (НЕ может редактировать) |
| Bash | Bash | Выполнение команд |

## Правила выбора

1. Для исследователей (WebSearch + запись файлов): general-purpose
2. Для чтения/анализа существующих файлов: Explore
3. Для создания контента (файлы, код): general-purpose
4. Для проверки/QA: general-purpose (нужен WebSearch для верификации)
5. Для презентаций (HTML/CSS): general-purpose

## Важно

- Explore и Plan НЕ МОГУТ создавать/редактировать файлы
- Для задач требующих Write/Edit — ТОЛЬКО general-purpose
- mode: "bypassPermissions" — тиммейты не спрашивают разрешение
- run_in_background: true — ВСЕГДА для тиммейтов

## Тиммейты vs Обычные субагенты

| Параметр | Тиммейт (team_name) | Субагент (без team_name) |
|----------|---------------------|--------------------------|
| Доставка задачи | Mailbox (НЕНАДЁЖНО) | Прямой промпт (НАДЁЖНО) |
| Общение SendMessage | Да | Нет |
| Shutdown | Сложно, idle-спам | Чисто |
| Лучше для | Межагентная координация | Чтение/запись файлов |
| Проверено | gaming-guides + puzzlebot: тиммейты = провал, субагенты = 100% |

## Правило по умолчанию
Используй обычные субагенты. Тиммейты — ТОЛЬКО если агенты ДОЛЖНЫ общаться.
