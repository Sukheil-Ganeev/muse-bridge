# Rutube Partner Program: Полное руководство

Российская платформа для монетизации видеоконтента (аналог YouTube).

---

## Что такое Rutube Partner Program

Rutube - российская видеоплатформа с возможностью монетизации через рекламу, подписки и донаты от зрителей.

**Как это работает:**
1. Вы создаёте канал и загружаете видео
2. Rutube показывает рекламу в начале/середине/конце видео
3. Вы получаете долю от рекламных доходов
4. Зрители могут оформить подписку или отправить донаты

**Официальный сайт:** [rutube.ru/partner](https://rutube.ru/partner)

---

## Регистрация и верификация

### Шаг 1: Создать канал

1. Перейти на [rutube.ru](https://rutube.ru)
2. Зарегистрироваться (email или соцсети)
3. Создать канал:
   - Название
   - Описание
   - Аватар и обложка

### Шаг 2: Проверка требований для монетизации

**Минимальные требования (2026):**
- 1000 подписчиков
- 4000 часов просмотров за последние 12 месяцев
- Оригинальный контент (не репосты с YouTube)
- Канал активен минимум 30 дней
- Контент не нарушает правила Rutube

**Как проверить:**
1. Канал → Аналитика
2. Проверить:
   - Подписчики (≥ 1000)
   - Часы просмотров за 12 месяцев (≥ 4000)

### Шаг 3: Подключить монетизацию

1. Канал → Настройки → Монетизация
2. Заполнить данные:
   - ФИО, паспорт, ИНН
   - Реквизиты для выплат
3. Пройти верификацию (3-7 дней)

### Шаг 4: Настроить выплаты

**Способы вывода:**
- Банковская карта РФ (минимум 1000₽)
- ЮMoney (минимум 500₽)
- Счёт ИП (минимум 3000₽)

## Монетизация видео

### 1. Реклама в видео

**Форматы:**
- **Pre-roll** (в начале): 5-30 секунд
- **Mid-roll** (в середине): только для видео 10+ минут
- **Post-roll** (в конце): редко используется

**Ставки CPM (2026):**

| Тематика | CPM за 1000 просмотров |
|----------|------------------------|
| Юмор, развлечения | 50-100₽ |
| Лайфстайл, путешествия | 100-200₽ |
| Новости | 80-150₽ |
| Бизнес, финансы | 150-300₽ |
| IT, технологии | 200-400₽ |

**Факторы влияния:**
- География (Москва/СПб: +30%)
- Досмотры (70%+ досмотров: +40%)
- Длительность (видео 10+ минут: mid-roll реклама)

### 2. Premium подписки

**Как работает:**
- Зрители платят за доступ к эксклюзивному контенту
- Ставки: 99-999₽/месяц

**Эксклюзивный контент:**
- Ранний доступ к видео
- Видео только для подписчиков
- Бонусы (прямые трансляции, закулисье)

### 3. Донаты

**Как работает:**
- Кнопка "Поддержать" под видео
- Зритель отправляет произвольную сумму
- Rutube берёт комиссию 15%

## Примеры туристических каналов

### Канал 1: "Дубай Insider" (5K подписчиков, 100 видео)

**Профиль:**
- Подписчики: 5,000
- Видео: 100 (за 12 месяцев)
- Просмотры: 300,000/месяц
- Средний досмотр: 55%

**Стратегия:**
- 2-3 видео в неделю (8-15 минут)
- Темы: обзоры отелей, туры, лайфстайл
- Формат: влоги + обзоры

**Доход:**

1. **Реклама:**
```
Просмотры: 300,000
CPM: 150₽ (туризм)
Доход: (300,000 / 1000) × 150₽ = 45,000₽
```

2. **Подписки:**
```
Подписчиков Premium: 50 (1% конверсия)
Ставка: 299₽/месяц
Доход: 50 × 299₽ = 14,950₽
```

**ИТОГО: 59,950₽/месяц**

### Канал 2: "Переезд в ОАЭ" (15K подписчиков, 200 видео)

**Профиль:**
- Подписчики: 15,000
- Видео: 200 (за 18 месяцев)
- Просмотры: 800,000/месяц
- Средний досмотр: 62%

**Стратегия:**
- 4-5 видео в неделю (10-20 минут)
- Mid-roll реклама (видео 10+ минут)
- Темы: переезд, виза, работа, жильё

**Доход:**

1. **Реклама:**
```
Просмотры: 800,000
CPM: 180₽ (высокий досмотр)
Доход: (800,000 / 1000) × 180₽ = 144,000₽
```

2. **Подписки:**
```
Подписчиков Premium: 150 (1% конверсия)
Ставка: 399₽/месяц
Доход: 150 × 399₽ = 59,850₽
```

3. **Донаты:**
```
Средний донат: 5,000₽/месяц
```

**ИТОГО: 208,850₽/месяц**
