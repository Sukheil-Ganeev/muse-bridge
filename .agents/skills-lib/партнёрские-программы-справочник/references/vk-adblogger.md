# VK AdBlogger: Полное руководство

Официальная платформа ВКонтакте для монетизации сообществ и личных страниц.

---

## Что такое VK AdBlogger

VK AdBlogger - это официальная платформа ВКонтакте, которая соединяет блогеров (владельцев сообществ и страниц) с рекламодателями.

**Как это работает:**
1. Вы регистрируете своё сообщество на платформе
2. Рекламодатели размещают заказы на рекламу
3. Вы выбираете подходящие заказы и публикуете рекламу
4. Получаете оплату после публикации

**Официальный сайт:** [dev.vk.com/adblogger](https://dev.vk.com/adblogger)

## Регистрация и верификация

### Шаг 1: Проверка требований

**Минимальные требования:**
- 1000+ подписчиков в сообществе или на странице
- Регулярная активность (минимум 2-3 поста в неделю)
- ERR (engagement rate) не ниже 2%
- Контент не нарушает правила ВКонтакте

**Как рассчитать ERR:**
```
ERR = (Лайки + Комментарии + Репосты) / Охват × 100%

Пример:
Пост получил 350 лайков, 45 комментариев, 20 репостов
Охват: 10000 просмотров
ERR = (350 + 45 + 20) / 10000 × 100% = 4.15%
```

### Шаг 2: Регистрация

1. Перейти на [dev.vk.com/adblogger](https://dev.vk.com/adblogger)
2. Войти через аккаунт VK
3. Нажать "Подключить сообщество"
4. Выбрать сообщество из списка
5. Согласиться с условиями

### Шаг 3: Верификация

**Для физических лиц:**
- Паспорт РФ (фото первых страниц)
- Селфи с паспортом
- ИНН (необязательно, но желательно)

**Для ИП:**
- Свидетельство о регистрации ИП
- ИНН
- Выписка из ЕГРИП (не старше 3 месяцев)

**Время проверки:** 1-3 рабочих дня

### Шаг 4: Настройка выплат

**Способы вывода:**
1. **Банковская карта РФ** (Visa, MasterCard, Мир)
   - Минимум для вывода: 500₽
   - Комиссия: 0%
   - Срок зачисления: 1-3 рабочих дня

2. **Счёт ИП**
   - Минимум для вывода: 3000₽
   - Комиссия: 0%
   - Срок зачисления: 3-5 рабочих дней

3. **ЮMoney (Яндекс.Деньги)**
   - Минимум для вывода: 500₽
   - Комиссия: 5%
   - Срок зачисления: моментально

**Рекомендация:** Использовать карту РФ (нет комиссии, быстрый вывод)

## Типы рекламы

### 1. Посты в ленте

**Описание:** Рекламный пост публикуется в ленте сообщества.

**Ставки 2026:**
- 1K-5K подписчиков: 300-500₽
- 5K-10K подписчиков: 500-800₽
- 10K-50K подписчиков: 800-2000₽
- 50K-100K подписчиков: 2000-5000₽
- 100K+ подписчиков: 5000-20000₽

**Требования:**
- Обязательная метка #реклама или #партнёрство
- Пост должен оставаться не менее 24 часов
- Нельзя удалять или редактировать после публикации

**Формат:**
```
🌴 [Заголовок рекламного поста]

[2-3 абзаца описания продукта/услуги с личным опытом]

💡 [Преимущества для аудитории]

🔗 [Ссылка или промокод]

#реклама #партнёрство
```

### 2. Stories (Истории)

**Описание:** Рекламная история в формате Stories.

**Ставки 2026:**
- 1K-5K подписчиков: 200-350₽
- 5K-10K подписчиков: 350-500₽
- 10K-50K подписчиков: 500-1200₽
- 50K+ подписчиков: 1200-3000₽

**Требования:**
- Длительность: 24 часа
- Метка "Реклама" обязательна
- Интерактивные элементы (опросы, стикеры) повышают ставку

**Особенности:**
- Высокий engagement (особенно с опросами)
- Подходит для быстрых промо-акций
- Можно добавить ссылку "Свайп вверх" (от 10K подписчиков)

### 3. Reels (Клипы)

**Описание:** Короткие вертикальные видео (15-90 секунд).

**Ставки 2026:**
- 1K-5K подписчиков: 500-800₽
- 5K-10K подписчиков: 800-1500₽
- 10K-50K подписчиков: 1500-5000₽
- 50K+ подписчиков: 5000-15000₽

**Почему дороже:**
- Требует больше времени на создание
- Выше вирусный потенциал
- Алгоритмы VK продвигают клипы активнее

**Требования:**
- Метка "Реклама" в описании
- Длительность: 15-90 секунд
- Вертикальный формат (9:16)
- Оригинальный контент (не репост)

### 4. Плашка в шапке сообщества

**Описание:** Баннер в шапке сообщества (над постами).

**Ставки 2026:**
- 10K-50K подписчиков: 1000-3000₽/месяц
- 50K-100K подписчиков: 3000-8000₽/месяц
- 100K+ подписчиков: 8000-20000₽/месяц

**Требования:**
- Размер баннера: 1590×400 пикселей
- Метка "Реклама" обязательна
- Можно добавить кликабельную ссылку

**Особенности:**
- Пассивная реклама (всегда видна)
- Не мешает основному контенту
- Подходит для долгосрочных партнёрств

## Ставки 2026: Факторы влияния

### 1. Engagement Rate (ERR)

| ERR | Множитель ставки |
|-----|------------------|
| Меньше 1% | -30% |
| 1-2% | базовая ставка |
| 2-5% | +20% |
| 5-10% | +50% |
| Больше 10% | +100% |

**Как повысить ERR:**
- Публиковать качественный, полезный контент
- Задавать вопросы в постах (стимулировать комментарии)
- Использовать опросы в Stories
- Отвечать на комментарии (стимулирует обсуждение)

### 2. Тематика сообщества

| Ниша | Ставка |
|------|--------|
| Юмор, мемы | Низкая (-20%) |
| Лайфстайл, путешествия | Средняя |
| Бизнес, финансы | Высокая (+30%) |
| IT, технологии | Высокая (+40%) |
| Люкс, премиум | Очень высокая (+60%) |

**Почему туризм - хорошая ниша:**
- Средние ставки (не низкие, как юмор)
- Платёжеспособная аудитория
- Высокая конверсия в продажи
- Много рекламодателей (отели, туры, авиабилеты)

### 3. География аудитории

| Регион | Множитель |
|--------|-----------|
| Москва, СПб | +30% |
| Крупные города (Казань, Екатеринбург) | +10% |
| Регионы РФ | базовая ставка |
| СНГ (не РФ) | -20% |

## Как выбирать заказы

### Dashboard VK AdBlogger

После регистрации вы увидите доступные заказы:

```
┌─────────────────────────────────────────────────────┐
│ Заказ #12345                                        │
│ Рекламодатель: "Отель в Дубае"                      │
│ Тип: Пост в ленте                                   │
│ Оплата: 1200₽                                       │
│ Дедлайн: 3 дня                                      │
│ Описание: Промо нового отеля в центре Дубая         │
│ Требования: Фото отеля + текст + ссылка             │
│                                                     │
│ [Принять заказ]  [Отклонить]                        │
└─────────────────────────────────────────────────────┘
```

### Критерии выбора

**✅ Брать заказ, если:**
- Релевантен вашей тематике (туризм → турпродукты)
- Вы сами пробовали продукт/услугу (или готовы попробовать)
- Ставка адекватная (не меньше базовой для вашей аудитории)
- Рекламодатель с хорошей репутацией

**❌ Отклонять заказ, если:**
- Нерелевантная тематика (туризм → финансовая пирамида)
- Сомнительный продукт (может навредить репутации)
- Низкая ставка (меньше вашего минимума)
- Слишком много требований за малую оплату

## Налоги и легализация

### Самозанятость (рекомендуется)

**Для кого:** Доход до 2.4M₽/год

**Ставки:**
- 4% с физлиц (прямая реклама)
- 6% с юрлиц (через VK AdBlogger)

**Как оформить:**
1. Скачать приложение "Мой налог" (iOS/Android)
2. Регистрация через госуслуги (5 минут)
3. После каждого вывода формировать чек в приложении
4. Налог списывается автоматически до 12 числа следующего месяца

**Пример:**
```
Январь: заработали 15000₽
Налог: 15000 × 6% = 900₽
Чистыми: 14100₽
```

### ИП на УСН (для больших оборотов)

**Для кого:** Доход больше 2.4M₽/год

**Ставка:** 6% с доходов

**Как оформить:**
1. Подать документы в налоговую (онлайн через госуслуги)
2. Получить свидетельство о регистрации ИП
3. Выбрать систему налогообложения УСН 6%
4. Платить налог ежеквартально

**Преимущества:**
- Нет лимита по доходу
- Можно работать с крупными рекламодателями
- Проще получать крупные выплаты

## Частые ошибки

### ❌ Ошибка 1: Забыть метку #реклама

**Последствия:**
- Штраф от ВКонтакте: блокировка функции AdBlogger
- Штраф по закону "О рекламе": до 500,000₽ (для юрлиц)

**Решение:**
Всегда добавляйте #реклама или #партнёрство в конец поста.

### ❌ Ошибка 2: Удалить пост раньше времени

**Последствия:**
- Рекламодатель не оплатит заказ
- Снижение рейтинга
- Возможная блокировка аккаунта

**Решение:**
Не удаляйте рекламные посты минимум 24 часа (или срок из договора).

### ❌ Ошибка 3: Публиковать слишком много рекламы

**Последствия:**
- Подписчики отписываются
- Падает engagement rate
- Снижаются ставки за рекламу

**Решение:**
Баланс 70% полезный контент / 30% реклама (максимум).

### ❌ Ошибка 4: Работать без самозанятости

**Последствия:**
- Штраф от налоговой: до 40% от незадекларированного дохода
- Блокировка вывода средств

**Решение:**
Оформить самозанятость в первый же день (10 минут в приложении).
