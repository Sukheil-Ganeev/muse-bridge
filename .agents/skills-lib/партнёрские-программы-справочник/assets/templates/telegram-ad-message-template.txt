
## Telegram-специфичные фишки

### 1. Использовать эмодзи

```
✅ ❌ 🔥 🎁 💡 📍 🏨 🐪 🇦🇪
```

### 2. Кнопки (Inline Keyboard)

```python
# Telegram Bot API
keyboard = [
    [{"text": "🔗 Забронировать", "url": "https://..."}],
    [{"text": "🎁 Получить промокод", "callback_data": "promo"}]
]
```

### 3. Короткие абзацы

```
❌ Длинный текст без переносов

✅ Короткие абзацы
Каждый по 1-2 строки
Легко читается с телефона
```

---

## Советы

1. **Краткость:** Telegram - быстрый мессенджер. Короткие сообщения работают лучше.
2. **Эмодзи:** Привлекают внимание, но не перебарщивайте (макс 5-7 на пост).
3. **Кнопки:** Используйте inline кнопки вместо текстовых ссылок (выше CTR).
4. **Срочность:** "Только сегодня", "Последние места" - стимулируют действие.
