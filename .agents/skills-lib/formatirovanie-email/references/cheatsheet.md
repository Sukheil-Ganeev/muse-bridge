# Шпаргалка — Email форматирование

## Структура
Subject -> To/Cc -> Dear -> Вступление -> Основная часть -> Заключение -> Подпись

## Обращения
EN: Dear Mr./Ms. [Surname],
RU: Уважаемый г-н [Фамилия],

## Шаблоны Subject
- "Re: [тема] — [номер дела]"
- "Urgent: [тема]"
- "Final Notice — [тема]"
- "Formal Complaint — [тема]"
- "Request: [тема]"

## Закрытие
EN: Best regards, / Kind regards, / Regards,
RU: С уважением,

## Правила
- Нет эмодзи
- Нет WhatsApp-форматирования
- Абзацы через пустую строку
- Нумерация пунктов
- Конкретный запрос в конце
