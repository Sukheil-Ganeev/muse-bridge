# База опыта: Telegram Bot API

## Критические уроки (топ-5)

1. **Rate Limits 2026:** Адаптивные лимиты зависят от репутации бота. Не спамьте, иначе лимиты понизятся.

2. **Webhook vs Polling:** Production всегда на webhook. Polling только для разработки.

3. **Обработка ошибок:** Всегда проверяйте error_code 429 (rate limit) и делайте retry_after паузу.

4. **Inline-кнопки:** callback_data ограничен 64 байтами. Для сложных данных используйте ID + база данных.

5. **Токены безопасности:** Никогда не коммитьте токены в git. Используйте переменные окружения.

## Секции опыта

- `fixes/` - Исправленные ошибки
- `improvements/` - Найденные улучшения
- `patterns/` - Повторяющиеся паттерны
- `warnings/` - Что НЕ делать
