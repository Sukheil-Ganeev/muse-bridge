# Синхронизация Notion AI агентов

Скилл для автоматической синхронизации локальных Markdown файлов агентов с их Notion страницами.

## Когда использовать

- После редактирования INSTRUCTIONS.md, CHEATSHEET.md и других файлов агента
- Когда нужно обновить версию агента в Notion
- Для массового обновления всех агентов

## Быстрый старт

```bash
# Синхронизировать одного агента
cd C:/Users/londo/.claude/skills/sync-notion-agents/scripts
python sync_agents.py formatting

# Все включённые агенты
python sync_agents.py all

# Тестовый режим (без изменений)
python sync_agents.py all --dry-run

# Принудительно (игнорировать версию)
python sync_agents.py formatting --force
```

## Доступные агенты

| Короткое имя | Описание | Статус |
|--------------|----------|--------|
| `formatting` | Форматирование текстов | ✅ Включён |
| `bank` | Банковские реквизиты | ✅ Включён |
| `bookings` | Подтверждения бронирований | ✅ Включён |
| `routes` | Оптимизация маршрутов | ❌ Нет Page ID |
| `calculator` | Калькулятор валют | ❌ Нет Page ID |
| `requests` | Обработка запросов | ❌ Нет Page ID |

## Структура файлов агента

Каждый агент находится в папке `D:/Downloads/NOTION_AI_AGENT_<NAME>/`:

```
NOTION_AI_AGENT_FORMATTING/
├── INSTRUCTIONS.md      → Основной контент страницы
├── CHEATSHEET.md        → Toggle "📋 Шпаргалка"
├── TEMPLATES.md         → Toggle "📝 Шаблоны"
├── REFERENCE_TABLES.md  → Toggle "📊 Справочники"
├── CHANGELOG.md         → Toggle "📜 История версий"
├── CLAUDE.md            → Только локально (не синхронизируется)
└── README.md            → Только локально
```

## Как это работает

### Алгоритм синхронизации

1. **Проверка версии** — сравнивает версию из CHANGELOG.md с версией на странице Notion
2. **Сохранение "Воспоминаний"** — находит и сохраняет секцию "Воспоминания" (не удаляется!)
3. **Очистка страницы** — удаляет все блоки кроме "Воспоминаний"
4. **Загрузка контента** — добавляет новые блоки из MD файлов
5. **Восстановление "Воспоминаний"** — секция остаётся в конце страницы

### Структура страницы Notion после синхронизации

```
[Страница агента]
│
├── [INSTRUCTIONS.md контент]     ← основной текст
│
├── ───────────────               ← разделитель
├── ▶ 📋 Шпаргалка                ← Toggle с CHEATSHEET.md
├── ▶ 📝 Шаблоны                  ← Toggle с TEMPLATES.md
├── ▶ 📊 Справочники              ← Toggle с REFERENCE_TABLES.md
├── ▶ 📜 История версий           ← Toggle с CHANGELOG.md
│
└── ▶ Воспоминания                ← НЕ ТРОГАЕТСЯ!
```

## Настройка

### 1. Установка зависимостей

```bash
pip install notion-client
```

### 2. API ключ Notion

Создайте интеграцию на https://www.notion.so/my-integrations и получите ключ.

```bash
# Windows PowerShell
$env:NOTION_API_KEY = "secret_xxx..."

# Windows CMD
set NOTION_API_KEY=secret_xxx...

# Linux/macOS
export NOTION_API_KEY="secret_xxx..."
```

### 3. Доступ к страницам

Каждая страница агента должна быть расшарена с вашей интеграцией:
1. Откройте страницу в Notion
2. Нажмите "Share" → "Invite"
3. Выберите вашу интеграцию

## Добавление нового агента

1. Создайте папку `D:/Downloads/NOTION_AI_AGENT_<NAME>/`
2. Создайте файлы: INSTRUCTIONS.md, CHEATSHEET.md, etc.
3. Создайте страницу в Notion и получите Page ID
4. Добавьте агента в `config.py`:

```python
AGENTS_CONFIG["myagent"] = {
    "folder": "NOTION_AI_AGENT_MYAGENT",
    "page_id": "abc123...",
    "display_name": "Мой агент",
    "enabled": True,
}
```

## Получение Page ID

Page ID можно найти в URL страницы Notion:
```
https://www.notion.so/workspace/My-Page-abc123def456...
                                        ^^^^^^^^^^^^^^^^
                                        Это Page ID (32 символа)
```

Или через "Copy link" → извлечь ID из URL.

## Опции командной строки

| Опция | Описание |
|-------|----------|
| `--dry-run` | Тестовый режим без изменений |
| `--force`, `-f` | Игнорировать проверку версий |
| `--verbose`, `-v` | Подробный вывод |
| `--list`, `-l` | Показать список агентов |

## Версионирование

Скрипт использует версии из CHANGELOG.md для определения необходимости обновления:

```markdown
## [1.2.0] - 2025-01-29

### Добавлено
- Новая функция...
```

Если локальная версия совпадает с версией в Notion — агент пропускается (если не указан `--force`).

## Секция "Воспоминания"

**ВАЖНО:** Секция "Воспоминания" НЕ УДАЛЯЕТСЯ при синхронизации!

Это позволяет Notion AI сохранять контекст между сессиями. Содержимое этой секции управляется самим агентом, а не синхронизацией.

## Troubleshooting

### "notion-client не установлен"
```bash
pip install notion-client
```

### "NOTION_API_KEY не установлен"
Установите переменную окружения с вашим API ключом.

### "Page ID не указан"
Добавьте Page ID в config.py или создайте страницу в Notion.

### Ошибка 401 Unauthorized
Проверьте что API ключ правильный и страница расшарена с интеграцией.

### Ошибка 400 Bad Request
Возможно превышен лимит блоков (100 за запрос) или некорректный Markdown.

## Ограничения

- Notion API: max 100 блоков за один запрос
- Rate limit: 3 запроса в секунду
- Rich text: max 2000 символов в одном блоке
- Вложенные блоки в Toggle: max 100
