# Codex Session LLM Review

## Назначение

Превратить сырой `promotion-candidates.md` в безопасный, понятный владельцу документ с тремя чистыми списками.

## Вход

```text
docs/codex-session-vault/knowledge/promotion-candidates.md
docs/codex-session-vault/knowledge/session-summaries/*
```

## Выход

```text
docs/codex-session-vault/knowledge/llm-review-clean-lists-YYYY-MM-DD.md
```

## Правила чистки

- Не копировать токены, cookies, логины, приватные пути к оригинальным JSONL и личные детали.
- Не переносить сырые цитаты из стенограмм.
- Одноразовые ситуации превращать в правила только если они реально повторяются.
- Разделять глобальные правила, проектные правила и личные предпочтения пользователя.
- Память пользователя не менять без прямой просьбы «запомни».
- `AGENTS.md` не редактировать автоматически, если пользователь не попросил применить правила.

## Структура результата

1. Кандидаты для `AGENTS.md`.
2. Кандидаты для памяти пользователя.
3. Идеи для новых или улучшенных навыков.
4. Что можно применить сразу.
5. Что требует осторожности.
6. Следующий шаг.
