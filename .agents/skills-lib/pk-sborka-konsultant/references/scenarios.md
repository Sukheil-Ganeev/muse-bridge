# Сценарии работы скилла — Пошаговые Workflow

> Этот файл описывает 7 основных сценариев консультирования.
> Для каждого сценария — чёткий алгоритм действий.

---

## Сценарий 1: Полная сборка ПК

### Когда использовать
Пользователь хочет собрать ПК с нуля и просит подобрать все компоненты.

### Пошаговый алгоритм

#### Шаг 1: Анкетирование (обязательно!)
Задать ВСЕ вопросы перед подбором. Не начинать подбор, пока нет ответов:

```
1. Бюджет? (конкретная сумма или диапазон, в какой валюте)
2. Основное назначение? (игры / работа / стримы / монтаж / программирование / всё понемногу)
3. Если игры — какие? (AAA новинки, киберспорт, казуальные)
4. Желаемое разрешение? (1080p / 1440p / 4K)
5. Нужен ли монитор, клавиатура, мышь? (или только системник)
6. Есть ли компоненты, которые можно переиспользовать?
7. Предпочтения по бренду? (AMD/Intel/NVIDIA — или без разницы)
8. Размер корпуса? (полная башня / средняя / компактный / без предпочтений)
9. Важна ли тишина?
10. Планируется ли апгрейд в будущем?
```

#### Шаг 2: Подбор CPU
- Справочник: `01_CPU.md`
- Определить платформу (AMD AM5 / Intel LGA1851)
- Выбрать модель по бюджету и задачам
- Записать: сокет, TDP, поддерживаемая RAM

#### Шаг 3: Подбор GPU
- Справочник: `02_GPU.md`
- Выбрать по назначению и бюджету (GPU = 35-40% от бюджета на системник)
- Записать: TDP, длину, требования к питанию (количество коннекторов)
- Проверить баланс с CPU (нет ли bottleneck)

#### Шаг 4: Подбор RAM
- Справочник: `03_RAM.md`
- Определить тип (DDR5 для новых платформ)
- Объём: 32 ГБ (2x16) — стандарт 2026 года
- Частота: DDR5-6000 — sweet spot для AMD AM5
- Записать: тип, частоту, количество планок

#### Шаг 5: Подбор материнской платы
- Справочник: `04_MOTHERBOARD.md`
- Совместимость с CPU (сокет!)
- Совместимость с RAM (тип, максимальная частота)
- Форм-фактор (ATX / mATX / ITX)
- Достаточно ли слотов и портов

#### Шаг 6: Подбор блока питания
- Справочник: `05_PSU.md`
- Рассчитать потребление: CPU TDP + GPU TDP + 100-150W на остальное
- Добавить запас 20-30%
- Проверить наличие нужных кабелей (ATX 3.1 / 12VHPWR для новых GPU)
- Минимум 80+ Bronze, рекомендуется 80+ Gold

#### Шаг 7: Подбор корпуса
- Справочник: `06_CASE.md`
- Совместимость с MB (форм-фактор)
- Вместимость GPU (длина!)
- Вместимость кулера (высота!)
- Качество airflow

#### Шаг 8: Подбор хранилища
- Справочник: `07_STORAGE.md`
- Основной SSD: NVMe Gen4 минимум 1 ТБ
- Дополнительное хранилище если нужно

#### Шаг 9: Подбор охлаждения
- Справочники: `08_COOLING.md`, `09_AIR_COOLING.md`, `10_AIO_COOLING.md`
- По TDP процессора
- Совместимость с сокетом
- Высота кулера vs клиренс корпуса
- Клиренс RAM (если башенный кулер)

#### Шаг 10: Периферия (если нужна)
- Справочники: `11_MONITOR.md`, `12_PERIPHERALS.md`
- Монитор: разрешение и частота под GPU
- Клавиатура, мышь, гарнитура

#### Шаг 11: Финальная проверка совместимости
Пройти ВЕСЬ чеклист из Сценария 3 (ниже). Каждую пару проверить.

#### Шаг 12: Итоговая таблица
Выдать результат в формате:

```
| # | Компонент        | Модель              | Цена     | Справочник    |
|---|------------------|---------------------|----------|---------------|
| 1 | Процессор        | AMD Ryzen 7 9700X   | $XXX     | 01_CPU.md     |
| 2 | Видеокарта       | NVIDIA RTX 5070 Ti  | $XXX     | 02_GPU.md     |
| 3 | Оперативная пам. | 2x16GB DDR5-6000    | $XXX     | 03_RAM.md     |
| 4 | Мат. плата       | MSI B650 Tomahawk   | $XXX     | 04_MB.md      |
| 5 | SSD              | Samsung 990 EVO 1TB | $XXX     | 07_STORAGE.md |
| 6 | Блок питания     | Corsair RM850x      | $XXX     | 05_PSU.md     |
| 7 | Корпус           | Fractal North       | $XXX     | 06_CASE.md    |
| 8 | Кулер            | Deepcool AK620      | $XXX     | 08_COOLING.md |
|   | **ИТОГО**        |                     | **$XXX** |               |
```

Под таблицей:
- Ожидаемая производительность (FPS в играх)
- Возможные альтернативы
- Рекомендации по сборке

## Сценарий 2: Выбор одного компонента

### Когда использовать
Пользователь уже имеет систему или частично подобрал — спрашивает про конкретный компонент.

### Алгоритм

#### Шаг 1: Уточняющие вопросы
```
1. Какой компонент выбираем?
2. Для какой системы? (новая сборка или апгрейд)
3. Если апгрейд — что уже есть? (сокет, MB, RAM тип)
4. Бюджет на этот компонент?
5. Приоритеты? (цена / производительность / тишина / размер)
```

#### Шаг 2: Определить ограничения совместимости
- Что уже выбрано/установлено?
- Какие ограничения это накладывает?
- Открыть соответствующий справочник из `D:/Downloads/PC_GUIDES/`

#### Шаг 3: Предложить 2-3 варианта
Для каждого варианта указать:
- Модель и цену
- Плюсы и минусы
- Почему именно этот вариант для данного случая

#### Шаг 4: Проверить совместимость
С уже имеющимися/выбранными компонентами.

### На что обращать внимание по типу компонента

| Компонент | Ключевые вопросы | Справочник |
|-----------|-------------------|------------|
| CPU | Сокет MB, задачи, бюджет | 01_CPU.md |
| GPU | Разрешение, игры, длина в корпусе, мощность БП | 02_GPU.md |
| RAM | Тип (DDR4/5), частота, кол-во слотов | 03_RAM.md |
| MB | Сокет CPU, форм-фактор, функции | 04_MOTHERBOARD.md |
| PSU | Суммарное TDP, коннекторы, запас | 05_PSU.md |
| Case | Форм-фактор MB, длина GPU, высота кулера | 06_CASE.md |
| SSD | Интерфейс (Gen3/4/5), объём, назначение | 07_STORAGE.md |
| Кулер | Сокет, TDP CPU, высота в корпусе | 08_COOLING.md |

## Сценарий 3: Проверка совместимости

### Когда использовать
Пользователь собрал конфигурацию и хочет проверить, что всё совместимо.

### Полный чеклист совместимости

#### Критические пары (несовместимость = не работает)

| # | Пара | Что проверять | Где смотреть |
|---|------|---------------|--------------|
| 1 | CPU ↔ MB | Сокет (AM5, LGA1851 и т.д.) | 01_CPU.md, 04_MOTHERBOARD.md |
| 2 | CPU ↔ RAM | Тип памяти (DDR4/DDR5), макс. частота контроллера | 01_CPU.md, 03_RAM.md |
| 3 | MB ↔ RAM | Тип памяти, макс. частота, кол-во слотов | 04_MOTHERBOARD.md, 03_RAM.md |
| 4 | MB ↔ Case | Форм-фактор (ATX в ATX/Full, mATX в mATX+, ITX в ITX+) | 04_MOTHERBOARD.md, 06_CASE.md |

#### Физические ограничения (не влезет)

| # | Пара | Что проверять | Где смотреть |
|---|------|---------------|--------------|
| 5 | GPU ↔ Case | Макс. длина GPU в корпусе vs длина видеокарты | 02_GPU.md, 06_CASE.md |
| 6 | Cooler ↔ Case | Макс. высота кулера в корпусе vs высота кулера | 08_COOLING.md, 06_CASE.md |
| 7 | Cooler ↔ RAM | Клиренс под кулером vs высота планок RAM | 08_COOLING.md, 03_RAM.md |
| 8 | AIO ↔ Case | Место для монтажа радиатора (240/280/360) | 10_AIO_COOLING.md, 06_CASE.md |

#### Электрические ограничения (не хватит питания)

| # | Пара | Что проверять | Где смотреть |
|---|------|---------------|--------------|
| 9 | GPU ↔ PSU | TDP GPU + пиковые нагрузки, наличие кабелей (12VHPWR) | 02_GPU.md, 05_PSU.md |
| 10 | Система ↔ PSU | Суммарное потребление + 20-30% запас | 05_PSU.md |
| 11 | CPU ↔ PSU | EPS кабель (8pin / 8+4pin / 8+8pin) | 01_CPU.md, 05_PSU.md |

#### Логическая совместимость (будет работать, но плохо)

| # | Пара | Что проверять | Где смотреть |
|---|------|---------------|--------------|
| 12 | CPU ↔ GPU | Нет ли bottleneck (слабый CPU с топовой GPU или наоборот) | 01_CPU.md, 02_GPU.md |
| 13 | Cooler ↔ CPU | Достаточно ли охлаждения для TDP процессора | 08_COOLING.md, 01_CPU.md |
| 14 | Monitor ↔ GPU | Разрешение и частота монитора vs мощность GPU | 11_MONITOR.md, 02_GPU.md |

## Сценарий 5: Консультация новичка

### Когда использовать
Пользователь явно не разбирается в ПК, использует бытовые термины, не знает технических характеристик.

### Признаки новичка
- "Хочу нормальный компьютер"
- "Чтобы не тормозил"
- "Для всего"
- Не знает, что такое сокет, чипсет, TDP
- Путает RAM и хранилище

### Словарь аналогий для объяснений

| Компонент | Аналогия | Пояснение |
|-----------|----------|-----------|
| **CPU** (Процессор) | **Мозг** | Думает и решает задачи. Чем мощнее — тем быстрее считает |
| **GPU** (Видеокарта) | **Художник** | Рисует картинку на экране. Для игр нужен крутой художник |
| **RAM** (Оперативная память) | **Рабочий стол** | Чем больше стол — тем больше можно разложить одновременно. Выключил ПК — стол очистился |
| **SSD** (Накопитель) | **Шкаф** | Хранит все файлы, игры, программы. Даже когда ПК выключен |
| **MB** (Материнская плата) | **Скелет / фундамент** | Соединяет все детали вместе. К ней подключается всё остальное |
| **PSU** (Блок питания) | **Сердце** | Качает электричество ко всем деталям. Слабое сердце — всё работает плохо |
| **Case** (Корпус) | **Дом** | Защищает все детали и обеспечивает вентиляцию |
| **Cooler** (Кулер) | **Кондиционер** | Охлаждает процессор, чтобы не перегрелся |
| **NVMe SSD** | **Скоростной лифт** | Быстрый доступ к данным, мгновенная загрузка |
| **HDD** | **Старый склад** | Медленный, но дешёвый. В 2026 почти не нужен |

### Принципы общения с новичком
1. **Никакого жаргона** без пояснения — каждый термин сопровождать аналогией
2. **Сначала объяснить зачем**, потом что выбрать
3. **Не перегружать вариантами** — давать 1 конкретную рекомендацию (не 5 на выбор)
4. **Использовать готовые сборки** из `builds-2026.md` как отправную точку
5. **Проводить за руку** — "Давайте начнём с главного: на что вы хотите тратить больше всего времени за ПК?"

### Упрощённая схема подбора для новичка

```
Что будете делать?
├── Играть в игры
│   ├── В простые (CS2, Valorant, Dota) → Бюджетная сборка
│   ├── В современные (AAA) на 1080p/1440p → Оптимальная сборка
│   └── На максималках в 4K → Топовая сборка
├── Работать (офис, интернет)
│   └── Бюджетная сборка (можно ещё дешевле)
├── Монтаж видео / 3D
│   └── Оптимальная или Топовая (больше RAM и SSD)
└── Стримить + играть
    └── Оптимальная сборка (CPU с запасом потоков)
```

## Сценарий 6: Бюджетная сборка

### Когда использовать
Пользователь ограничен в бюджете и хочет максимум за минимум денег.

### Алгоритм

#### Шаг 1: Определить точный бюджет
```
- Какой бюджет? (точная сумма)
- В какой валюте?
- Это только на системник или с периферией (монитор, клавиатура)?
- Бюджет жёсткий или можно немного превысить?
```

#### Шаг 2: Распределение бюджета (правило)

```
Только системник:
├── GPU: 35-40% ← Главный приоритет для игр
├── CPU: 20-25%
├── MB + RAM: 15-20%
├── SSD: 5-8%
├── PSU: 8-10%
├── Case + Cooler: 8-12%
```

```
Пример для $800:
├── GPU: $280-320
├── CPU: $160-200
├── MB: $110-140
├── RAM: $70-80
├── SSD: $60-70
├── PSU: $55-70
├── Case: $50-65
├── Cooler: $25-35
```

#### Шаг 3: Выбрать базовую конфигурацию
Взять сборку из `builds-2026.md` ближайшую по бюджету.

#### Шаг 4: Адаптировать под бюджет

**Где можно сэкономить (безопасно):**
- Корпус — взять попроще (но с нормальным airflow!)
- RAM — DDR5-5600 вместо 6000 (разница 1-3% в играх)
- SSD — менее известный бренд с хорошими отзывами
- Кулер — боксовый, если CPU с низким TDP (до 65W)
- MB — B-серия вместо X-серии

**Где НЕЛЬЗЯ экономить:**
- Блок питания — дешёвый noname БП = риск спалить всё
- Одна планка RAM вместо двух — теряется двухканал (минус 10-15% FPS)
- Видеокарта — лучше взять на ступень ниже, но новую, чем б/у "пока хватит"

#### Шаг 5: Проверить совместимость
Полный чеклист из Сценария 3.

#### Шаг 6: Предложить план экономии (если бюджет совсем мал)
- Что купить сейчас
- Что добавить/заменить через 3-6 месяцев
- На чём можно сэкономить временно (например, использовать встройку CPU вместо GPU)

## Сценарий 7: Ревью конфигурации

### Когда использовать
Пользователь уже собрал конфигурацию (сам или на форуме) и хочет проверить.

### Чеклист ревью

#### 1. Совместимость (критично)
Пройти все 15 пунктов из Сценария 3. Отметить каждый.

#### 2. Баланс системы (bottleneck)
```
Проверить:
[ ] CPU не является узким местом для GPU (и наоборот)
[ ] GPU соответствует разрешению монитора
[ ] RAM достаточно для задач (32 ГБ — норма для 2026)
[ ] SSD достаточного объёма
```

**Типичные перекосы:**
- Топовый CPU + бюджетная GPU → деньги на ветер
- Топовая GPU + слабый CPU → CPU не успевает за GPU
- DDR5-8000 с бюджетным CPU → переплата за RAM без выигрыша
- RTX 5080 + монитор 1080p 60Hz → GPU скучает

#### 3. Достаточность БП
```
Формула: (CPU TDP + GPU TDP + 100W) × 1.25 = минимальная мощность БП
Пример: (105 + 250 + 100) × 1.25 = 569W → нужен 650W минимум

Для топовых GPU (RTX 5080/5090):
Смотреть рекомендации производителя GPU! У них бывают пиковые нагрузки.
```

#### 4. Адекватность охлаждения
```
[ ] Кулер рассчитан на TDP процессора (с запасом!)
[ ] При разгоне — кулер на 30-50% мощнее TDP
[ ] Для CPU 125W+ TDP — башенный кулер или AIO 240mm+
[ ] Для CPU 170W+ TDP — AIO 280/360mm или топ-башня
[ ] Корпус имеет достаточно вентиляторов (минимум 2-3)
```

#### 5. Пропущенные компоненты
```
Чеклист "ничего не забыли?":
[ ] Термопаста (обычно в комплекте с кулером, но проверить)
[ ] Вентиляторы корпуса (иногда в комплекте 1-2, может нужно ещё)
[ ] Wi-Fi (есть ли на MB или нужен адаптер?)
[ ] Bluetooth (аналогично)
[ ] ОС (Windows лицензия или Linux?)
[ ] Кабели (SATA, доп. вентиляторы — обычно в комплекте с MB/Case)
[ ] Монитор, клавиатура, мышь (если нет)
```

#### 6. Цена-качество
```
[ ] Нет явной переплаты за ненужные функции
[ ] Нет подозрительно дешёвых компонентов (особенно БП!)
[ ] Бренды из проверенных (Tier A / Tier B)
```
