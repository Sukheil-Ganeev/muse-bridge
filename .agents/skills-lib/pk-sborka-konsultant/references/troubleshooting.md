## 1. Справочник не найден

### Проблема
При обращении к файлу из `D:/Downloads/PC_GUIDES/` он не найден или путь некорректен.

### Диагностика
```
1. Проверить существование папки: D:/Downloads/PC_GUIDES/
2. Проверить список файлов в папке
3. Проверить точное название файла (регистр, расширение)
```

### Решение

**Шаг 1:** Проверить базовый путь
```bash
ls "D:/Downloads/PC_GUIDES/"
```

**Шаг 2:** Если папка не существует — предложить пользователю:
- "Папка D:/Downloads/PC_GUIDES/ не найдена. Возможно, справочники были перемещены. Укажите актуальный путь к справочникам."

**Шаг 3:** Если папка есть, но конкретный файл нет:
- Проверить оглавление: `00_ОГЛАВЛЕНИЕ.md`
- Искать файл с похожим названием (опечатка?)
- Сообщить: "Справочник XX_NAME.md не найден в папке. Доступные справочники: [список]"

### Ожидаемая структура

## 2. Устаревшие цены

### Проблема
Цены в справочниках и builds-2026.md не соответствуют текущим рыночным ценам.

### Признаки устаревших цен
- Пользователь указывает, что цена в магазине существенно отличается (более 15%)
- Вышло новое поколение компонентов (цены на предыдущее снизились)
- Прошло более 3-6 месяцев с последнего обновления файлов

### Действия

**Шаг 1:** Предупредить пользователя
```
"Цены в моих справочниках актуальны на [дата последнего обновления].
Реальные цены могут отличаться. Рекомендую сверить с:
- PCPartPicker (pcpartpicker.com)
- Amazon / Newegg
- Местные магазины (DNS, Citilink, Regard — для России)"
```

**Шаг 2:** Адаптировать рекомендации
- Если компонент подорожал — предложить альтернативу
- Если подешевел — скорректировать бюджет (можно взять что-то лучше)
- Ценовые пропорции между компонентами обычно сохраняются

**Шаг 3:** Предложить обновить
```
"Хотите, я обновлю файл builds-2026.md с актуальными ценами?
Для этого мне нужно знать текущие цены — можете скинуть ссылки
на актуальные прайсы или назвать текущие цены."
```

### Как обновить цены
1. Открыть `references/builds-2026.md`
2. Обновить столбцы "Примерная цена"
3. Пересчитать итоговые суммы
4. Обновить заметку об актуальности в начале файла
5. При необходимости — заменить модели на актуальные

## 3. Компонент не описан в справочниках

### Проблема
Пользователь спрашивает о компоненте или модели, которой нет в справочниках.

### Варианты ситуаций

**А) Новая модель известного типа** (например, новая видеокарта)
- Найти ближайший аналог в справочнике
- Экстраполировать характеристики
- Предупредить: "Этой модели нет в моих справочниках. Ориентируюсь на [аналог] и общие характеристики."

**Б) Нишевый компонент** (например, capture card, звуковая карта, контроллер вентиляторов)
- Проверить, есть ли в смежных справочниках (12_PERIPHERALS.md, 13_NETWORKING.md)
- Если нет — ответить на основе общих знаний
- Предупредить: "Этот компонент не покрыт моими справочниками. Рекомендация на основе общих знаний — для подробностей лучше посмотреть обзоры."

**В) Совершенно новый компонент/технология**
- Честно сказать: "Эта технология появилась после обновления моих справочников. Рекомендую проверить актуальные обзоры на YouTube / Reddit / специализированных сайтах."
- Предложить добавить в справочники при следующем обновлении.

### Формат ответа
```
"[Компонент/модель] отсутствует в справочниках.

На основе общих знаний:
- [краткая информация]
- [рекомендации]

Для точной информации рекомендую:
- [ссылки/источники]

Хотите добавить эту информацию в справочники?"
```

## 4. Пользователь не знает свой бюджет

### Проблема
Пользователь говорит "не знаю" или "сколько нужно" или "подешевле" без конкретики.

### Алгоритм определения бюджета

**Шаг 1: Определить задачи**
```
"Давайте начнём с другой стороны. Расскажите:
1. Для чего вам ПК? (игры, работа, учёба, всё вместе)
2. Если игры — какие? (например: CS2, Cyberpunk, Fortnite)
3. Нужны ли монитор, клавиатура, мышь?"
```

**Шаг 2: Определить уровень по задачам**

| Задачи | Рекомендуемый уровень | Примерный бюджет |
|--------|----------------------|-----------------|
| Офис, интернет, учёба | Начальный | $400-500 |
| Простые игры (Valorant, CS2, Dota) | Бюджетный | $600-800 |
| Современные игры 1080p | Бюджетный+ | $800-1000 |
| Современные игры 1440p | Оптимальный | $1200-1600 |
| Игры 4K / стриминг / монтаж | Топовый | $2000-3000 |
| Профессиональная работа + 4K | Энтузиаст | $3000+ |

**Шаг 3: Предложить диапазон**
```
"Для ваших задач оптимально $[минимум]-$[максимум].
- За $[минимум] получите [описание]
- За $[максимум] получите [описание]
Какой диапазон вам комфортен?"
```

**Шаг 4: Если пользователь всё ещё не определился**
```
"Давайте так: скажите максимальную сумму, которую вы готовы потратить.
Я подберу лучшее в рамках этой суммы."
```

### Психологические приёмы
- Не давить на "нужно дорого" — уважать бюджет
- Показать, что даже за небольшие деньги можно собрать хороший ПК
- Использовать "инвестиция на X лет" — помогает принять решение
- Предлагать поэтапную покупку (сначала основное, потом апгрейд)

## 5. Конфликт рекомендаций

### Проблема
Разные справочники или источники дают противоречивые рекомендации.

### Типичные конфликты и их разрешение

**Конфликт 1: "Нужен мощный БП" vs "Достаточно слабого"**
- Приоритет: рекомендации производителя GPU
- При сомнениях — всегда выбирать БП помощнее (переплата $20-30 vs риск)

**Конфликт 2: "AIO лучше" vs "Воздух достаточно"**
- Зависит от TDP CPU
- До 65W TDP → воздушный кулер (если пользователь не хочет AIO)
- 95-125W TDP → качественная башня ИЛИ AIO 240mm (оба варианта ОК)
- 125W+ TDP → AIO 240mm+ рекомендуется (но топ-башня тоже справится)
- Итог: объяснить оба варианта, дать рекомендацию по ситуации

**Конфликт 3: "AMD лучше" vs "Intel лучше"**
- Нет универсального ответа
- Сравнивать конкретные модели в конкретном ценовом сегменте
- Для игр: проверить бенчмарки на момент консультации
- Для рабочих задач: зависит от конкретной нагрузки
- Итог: рекомендовать по критериям пользователя, не по личным предпочтениям

**Конфликт 4: "Gen5 SSD нужен" vs "Gen4 достаточно"**
- Для игр и общего использования: Gen4 — более чем достаточно
- Gen5 оправдан только для профессиональной работы с большими файлами
- Итог: Gen4 по умолчанию, Gen5 если бюджет позволяет и есть реальная потребность

### Иерархия приоритетов при конфликтах
1. **Безопасность** — не рекомендовать то, что может навредить (слабый БП → сгорят компоненты)
2. **Совместимость** — физически и электрически должно работать
3. **Потребности пользователя** — его задачи и бюджет
4. **Цена/качество** — оптимальное соотношение
5. **Будущий апгрейд** — если бюджет позволяет

### Формат ответа при конфликте
```
"Есть два подхода:

Вариант А: [описание]
+ Плюс: ...
- Минус: ...

Вариант Б: [описание]
+ Плюс: ...
- Минус: ...

Моя рекомендация для вашей ситуации: Вариант [X], потому что [причина]."
```

## 6. Пользователь хочет б/у компоненты

### Проблема
Пользователь рассматривает покупку б/у комплектующих для экономии.

### Классификация по риску

#### Безопасно покупать б/у (низкий риск)
| Компонент | Почему безопасно | На что смотреть |
|-----------|-----------------|-----------------|
| **Корпус** | Механика, почти не изнашивается | Царапины, погнутые стойки, сломанные защёлки |
| **Воздушный кулер** | Простая конструкция | Целостность рёбер, вентилятор крутится, крепёж в комплекте |
| **Периферия** (клавиатура, мышь) | Легко проверить | Работоспособность всех кнопок, состояние кабеля |
| **Монитор** | Можно визуально проверить | Битые пиксели, засветы, царапины, равномерность подсветки |

#### С осторожностью (средний риск)
| Компонент | Риски | Как минимизировать |
|-----------|-------|-------------------|
| **GPU** | Была в майнинге (износ вентиляторов, чипа) | Проверить в бенчмарке (FurMark 10 мин), послушать вентиляторы, посмотреть артефакты |
| **CPU** | Мог быть в разгоне (деградация) | Проверить бенчмарком, сравнить с эталонными результатами |
| **MB** | Могут быть скрытые дефекты | Проверить ВСЕ порты, слоты, BIOS |
| **AIO кулер** | Износ помпы (2-5 лет ресурса) | Послушать помпу (не гудит?), проверить утечки |

#### Не рекомендуется б/у (высокий риск)
| Компонент | Почему опасно | Альтернатива |
|-----------|--------------|-------------|
| **PSU** | Износ конденсаторов — может сгореть и спалить компоненты | Новый бюджетный от проверенного бренда ($50-70) |
| **SSD** | Ограниченный ресурс TBW, может отказать внезапно | Новый бюджетный NVMe ($50-70 за 1TB) |
| **RAM** | Скрытые ошибки, трудно диагностировать | Новая RAM стоит недорого ($35-40 за 16GB DDR5) |
| **HDD** | Механический износ, бэд-блоки | Если нужен HDD — только новый |

### Предупреждения для пользователя
```
"При покупке б/у компонентов учтите:
1. Нет гарантии (или ограниченная)
2. Невозможно узнать полную историю (майнинг, разгон, условия хранения)
3. Ресурс частично исчерпан
4. Могут быть скрытые дефекты

Рекомендация: экономьте на корпусе, кулере, периферии.
НЕ экономьте на БП, SSD, RAM — разница с новым невелика, а риск высокий."
```

### Проверка б/у GPU (самый частый случай)
```
Алгоритм проверки:
1. Визуальный осмотр (следы ремонта, пыль, состояние вентиляторов)
2. Запустить FurMark на 10-15 минут — следить за температурой и артефактами
3. Проверить в играх 15-20 минут — нет ли вылетов и артефактов
4. Послушать вентиляторы — нет ли треска, гула
5. Проверить серийный номер (не в розыске/не краденая)
6. Спросить продавца: для чего использовалась, сколько по времени
```

## 7. Апгрейд существующего ПК vs сборка нового

### Проблема
Пользователь не уверен, стоит ли модернизировать текущий ПК или собрать новый.

### Алгоритм определения

#### Шаг 1: Узнать текущую конфигурацию
```
"Расскажите, что сейчас стоит в ПК:
1. Процессор (CPU)
2. Видеокарта (GPU)
3. Оперативная память (RAM) — объём и тип (DDR3/DDR4/DDR5)
4. Материнская плата (MB) — если знаете
5. Блок питания (PSU) — мощность
6. SSD или HDD?
7. Сколько лет системе?

Если не знаете — скачайте CPU-Z или HWiNFO, они покажут всё."
```

#### Шаг 2: Оценить платформу

| Платформа | Год | Оценка | Рекомендация |
|-----------|-----|--------|-------------|
| AM5 (DDR5) | 2022+ | Актуальная | Апгрейд компонентов |
| LGA1700 (DDR4/DDR5) | 2021-2024 | Актуальная | Апгрейд компонентов |
| AM4 (DDR4) | 2017-2022 | Устаревающая | Апгрейд GPU/RAM или новая сборка |
| LGA1200 (DDR4) | 2020-2021 | Устаревшая | Скорее новая сборка |
| LGA1151 (DDR4) | 2017-2019 | Устаревшая | Новая сборка |
| AM3+ / LGA1150 и старше | До 2017 | Мёртвая | Только новая сборка |
| DDR3 (любая) | До 2016 | Мёртвая | Только новая сборка |

#### Шаг 3: Калькулятор "апгрейд vs новая"

```
Стоимость апгрейда:
+ Новый GPU: $XXX
+ Новая RAM: $XXX (если нужна)
+ Новый SSD: $XXX (если нужен)
+ Доп. компоненты: $XXX
= ИТОГО апгрейд: $XXX

Стоимость новой сборки:
= ИТОГО новая: $XXX

Прирост от апгрейда: ~XX%
Прирост от новой: ~XX%

Рекомендация: если апгрейд стоит > 60% от новой сборки → собирать новый ПК
```

#### Шаг 4: Правило принятия решения

**Апгрейд имеет смысл, если:**
- Платформа актуальная (AM5, LGA1700+)
- Нужно заменить 1-2 компонента
- Стоимость апгрейда < 50-60% от новой сборки
- Прирост от апгрейда решает проблему пользователя

**Новая сборка, если:**
- Платформа устаревшая (DDR3, старые сокеты)
- Нужно менять 3+ компонентов (CPU + MB + RAM = уже полсистемы)
- Стоимость апгрейда > 60% от новой сборки
- Текущая система старше 5-6 лет

### Популярные сценарии апгрейда

| Сценарий | Что менять | Бюджет | Прирост |
|----------|-----------|--------|---------|
| "Мало FPS в играх" | GPU | $250-500 | 50-200% FPS |
| "Всё тормозит" | SSD (если HDD) + RAM (если 8GB) | $80-120 | Огромный для отзывчивости |
| "Не хватает RAM" | Добавить RAM | $40-80 | Меньше зависаний |
| "CPU не тянет" | CPU (если платформа позволяет) | $150-400 | 20-50% |
| "Система старая" | Новая сборка | $700-1500 | Кардинальный |

### Формат ответа

```
## Анализ: Апгрейд vs Новая сборка

### Ваша текущая система:
[компоненты]

### Узкое место:
[что именно тормозит и почему]

### Вариант 1: Апгрейд
- Заменить: [компоненты]
- Стоимость: ~$XXX
- Ожидаемый прирост: ~XX%
- Хватит на: X лет

### Вариант 2: Новая сборка
- Конфигурация: [ссылка на builds-2026.md]
- Стоимость: ~$XXX
- Ожидаемый прирост: ~XX%
- Хватит на: X лет

### Рекомендация:
[Вариант X], потому что [причина].
```

## Общие принципы обработки проблем

1. **Никогда не врать** — если не знаешь, скажи честно
2. **Предупреждать о рисках** — особенно финансовых (б/у, устаревшие данные)
3. **Предлагать альтернативы** — если основной вариант недоступен
4. **Давать чёткие инструкции** — пошаговые, а не общие фразы
5. **Ссылаться на справочники** — для подробной информации
6. **Записывать новый опыт** — если проблема повторяется, добавить в `experience/`
