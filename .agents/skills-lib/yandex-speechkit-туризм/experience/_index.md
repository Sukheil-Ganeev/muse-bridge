## Критические уроки (топ-5)

### 1. Лимит 30 секунд — критический для бизнеса

**Проблема:** Yandex SpeechKit Sync API отклоняет файлы >30 сек с ошибкой 400.

**Реальность:** В WhatsApp чатах **56% голосовых >30 сек** (данные из 27 файлов).

**Решение:** Автоматическое деление на части по 29 сек → обработка каждой → склеивание.

**Результат:** С 44% до 100% успешной обработки (+127% эффективности).

📄 **Подробно:** `fixes/30sec-limit-workaround.md`

---

### 2. Универсальность > специализация

**Было:** 2 скрипта (для коротких + для длинных)
**Стало:** 1 универсальный (автоматически адаптируется)

**Улучшения:**
- UX: 2 шага → 1 шаг
- Ошибки: риск забыть обработать длинные → нулевой
- Надёжность: 44% → 100%

📄 **Подробно:** `improvements/universal-audio-processing.md`

---

### 3. Порог 29 сек (не 30!)

**Ошибка:**
```python
if duration <= 30.0:  # ❌ Опасно!
```

**Правильно:**
```python
if duration <= 29.0:  # ✅ Запас на погрешности
```

**Причина:** Длительность может быть 30.1 сек → ошибка 400 от API.

---

### 4. `-c copy` для скорости

**Медленно (перекодирование):**
```bash
ffmpeg -i input.ogg -t 29 output.ogg  # ❌ 5-10 сек
```

**Быстро (без перекодирования):**
```bash
ffmpeg -i input.ogg -t 29 -c copy output.ogg  # ✅ 0.5 сек
```

**Разница:** В 10-50 раз быстрее! Для 27 файлов: 2 минуты vs 20 секунд.

📄 **Подробно:** `patterns/audio-splitting-pattern.md`

---

### 5. Всегда cleanup временных файлов

**Без cleanup:**
```
15 длинных файлов × 3-5 частей каждый = 45-75 временных файлов
Занято места: ~200-500 MB
```

**С cleanup:**
```python
try:
    chunks = split_audio(file)
    result = process(chunks)
finally:
    for chunk in chunks:
        os.remove(chunk)  # Всегда удаляем!
```
