**Дата:** 2026-02-04
**Тип:** Improvement
**Impact:** CRITICAL
**Теги:** `audio-processing`, `automation`, `whatsapp`, `robustness`

## Что улучшили

**Было:** Два отдельных скрипта для разных случаев
```
transcribe_all_audio.py          # Только короткие (<30 сек)
transcribe_skipped_only.py       # Только длинные (>30 сек)
```

**Стало:** Один универсальный скрипт
```
transcribe_all_audio_v2.py       # Любые аудио автоматически
```

---

## Зачем

### Проблема разделения скриптов

1. **Нужно помнить** какой скрипт для какого случая
2. **Двойная работа** — сначала v1 (короткие), потом отдельно длинные
3. **Ошибки** — легко забыть обработать длинные
4. **Плохой UX** для пользователя

### Решение: Автоматическая адаптация

```python
# Один универсальный метод
def transcribe_any_audio(file_path: str) -> str:
    """Обрабатывает аудио ЛЮБОЙ длины"""
    duration = get_duration(file_path)

    if duration <= 29:
        return transcribe_direct(file_path)
    else:
        return transcribe_with_splitting(file_path)
```

## Как реализовано

### Архитектура v2

```python
def process_all_audio_files(folders: list) -> dict:
    """Главная функция - обрабатывает всё"""
    results = {}

    for folder in folders:
        audio_files = find_audio_files(folder)  # .ogg, .opus

        for audio_file in audio_files:
            # Автоматический выбор стратегии
            result = transcribe_any_audio(audio_file)
            results[audio_file] = result

    return results

def transcribe_any_audio(file_path: str) -> dict:
    """Ключевая логика - адаптация к длине"""

    # 1. Определяем длительность
    duration = get_audio_duration(file_path)

    # 2. Выбираем стратегию автоматически
    if duration <= 29.0:
        strategy = "direct"
        text = transcribe_direct(file_path)
    else:
        strategy = "split_and_merge"
        chunks = split_audio(file_path, chunk_duration=29)
        texts = [transcribe_direct(chunk) for chunk in chunks]
        text = " ".join(texts)
        cleanup_chunks(chunks)  # Удаляем временные файлы

    return {
        "file": file_path,
        "status": "success",
        "duration": duration,
        "strategy": strategy,
        "text": text
    }
```

### Ключевые принципы

1. **Автоматическое определение** — скрипт сам решает как обрабатывать
2. **Прозрачность** — логируем какая стратегия использовалась
3. **Очистка** — удаляем временные chunks после обработки
4. **Единый формат** — результат одинаковый независимо от стратегии

## Применение

### Когда использовать универсальный подход

**Всегда применяй для:**
- ✅ Пользовательский контент (WhatsApp, Telegram)
- ✅ Неизвестная длина файлов
- ✅ Batch-обработка множества файлов
- ✅ Автоматизация без участия человека

**Можно не применять если:**
- ❌ Гарантированно все файлы <20 сек
- ❌ Разовая обработка 1-2 файлов (проще вручную)

### Интеграция в рабочий процесс

```bash
# 1. Клод получает ZIP с WhatsApp чатом
# 2. Распаковывает
# 3. Запускает один универсальный скрипт
python transcribe_all_audio_v2.py

# 4. Получает 100% обработанных файлов
# 5. Создаёт досье клиента
```

**Нет ручных действий. Нет потери данных. 100% автоматизация.**

## Уроки

1. **Универсальность > специализация** для пользовательского контента

3. **Один инструмент** проще чем набор специализированных
4. **Прозрачность стратегии** помогает отладке
