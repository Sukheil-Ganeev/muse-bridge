# Batch Audio Processor

CLI инструмент для массовой обработки аудио файлов с прогресс-баром и статистикой.

## Использование

```bash
python main.py --input audio_folder/ --output results.csv --format csv
```

## Возможности

- Progress bar (tqdm)
- CSV/JSON экспорт
- Параллельная обработка
- Статистика (время, стоимость)
- Фильтрация по keywords

## Установка

```bash
pip install -r requirements.txt
```
