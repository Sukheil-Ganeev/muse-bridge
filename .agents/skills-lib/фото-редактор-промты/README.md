# Скилл: Экспертная система фото-редактирования

**Версия:** 4.2 Complete Edition
**Обновлено:** 30 января 2026

## Что делает этот скилл

Генерирует оптимальные промты для AI-редактирования фото с защитой от нежелательных изменений. Основан на глубокой базе знаний (145+ документов, 500+ промтов).

**Проблема:** AI меняет больше чем нужно → форма лица шире, кожа пластиковая, результат мультяшный.

**Решение:** Промты с защитой идентичности: ACTION + PROTECTION + STYLE + FALLBACK.

## Золотые правила

1. Сначала защити — потом улучшай
2. Один промт = одно изменение
3. Negatives с конкретикой
4. Всегда fallback
5. Сохраняй асимметрии (они = идентичность)
