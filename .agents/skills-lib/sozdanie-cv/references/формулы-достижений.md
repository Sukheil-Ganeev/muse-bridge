# Формулы достижений

Структурированные формулы для превращения обязанностей в убедительные достижения с измеримыми результатами.

---

## CAR (Context-Action-Result)

### Структура

```
CONTEXT (Контекст)     → Ситуация, проблема, вызов
ACTION (Действие)      → Что конкретно сделали
RESULT (Результат)     → Измеримый итог
```

### Формула написания

```
При/В условиях [контекст] + [глагол действия] + [что сделал] + [результат с числами]
```

### Примеры по сферам

**Продажи:**
```
❌ Плохо: Занимался продажами B2B клиентам

✅ Хорошо:
Context: При стагнации продаж в регионе
Action:  Разработал стратегию входа в enterprise-сегмент и обучил команду из 5 менеджеров
Result:  Увеличил выручку региона на 85% ($2M → $3.7M) за 12 месяцев
```

**Маркетинг:**
```
❌ Плохо: Вёл социальные сети компании

✅ Хорошо:
Context: При нулевом присутствии бренда в соцсетях
Action:  Создал контент-стратегию и запустил регулярные публикации на 4 платформах
Result:  Набрал 50K подписчиков за 6 месяцев, генерируя 200+ лидов ежемесячно
```

**IT:**
```
❌ Плохо: Разрабатывал backend систему

✅ Хорошо:
Context: При 15-секундном времени ответа API под нагрузкой
Action:  Спроектировал и реализовал кэширующий слой на Redis с оптимизацией запросов
Result:  Сократил время ответа до 200ms при нагрузке 10K RPS
```

**HR:**
```
❌ Плохо: Занимался подбором персонала

✅ Хорошо:
Context: При срочной потребности масштабировать разработку
Action:  Выстроил процесс найма с автоматизированным скринингом и структурированными интервью
Result:  Закрыл 35 позиций за 3 месяца, сократив time-to-hire с 60 до 25 дней
```

**Финансы:**
```
❌ Плохо: Контролировал бюджет подразделения

✅ Хорошо:
Context: При перерасходе операционного бюджета на 20%
Action:  Внедрил систему real-time мониторинга расходов и пересмотрел контракты с поставщиками
Result:  Сократил расходы на $400K (15%), сохранив качество сервиса
```

## XYZ (Google Formula)

### Структура

```
Accomplished [X] by doing [Y], resulting in [Z]

Достиг [X] посредством [Y], что привело к [Z]
```

### Формула написания

```
[Глагол достижения] + [что достиг X] + через/посредством [действие Y] + что привело к/в результате [измеримый эффект Z]
```

### Примеры

**Вариант 1: Фокус на метрике**
```
Увеличил конверсию на 40% (X)
через редизайн checkout-процесса и A/B тестирование (Y)
что привело к дополнительной выручке $500K/год (Z)
```

**Вариант 2: Фокус на процессе**
```
Автоматизировал процесс формирования отчётности (X)
через разработку Python-скриптов и дашбордов в Tableau (Y)
сократив время подготовки с 8 часов до 15 минут (Z)
```

**Вариант 3: Фокус на влиянии**
```
Вывел продукт на 5 новых рынков (X)
через локализацию, адаптацию ценообразования и партнёрства (Y)
увеличив международную выручку с $0 до $2M за год (Z)
```

### Шаблоны для разных ролей

**Руководитель:**
```
Построил команду из N человек через [процесс найма/обучения],
достигнув [метрика производительности/результата]
```

**Аналитик:**
```
Выявил [инсайт/проблему] через анализ [данных],
что позволило [бизнес-эффект с цифрами]
```

**Разработчик:**
```
Реализовал [функционал/систему] используя [технологии],
обеспечив [метрика производительности/надёжности]
```

**Маркетолог:**
```
Запустил [кампанию/канал] с бюджетом [сумма],
привлекнув [количество лидов/клиентов] при CAC [стоимость]
```

## STAR (Situation-Task-Action-Result)

### Структура

```
SITUATION (Ситуация)   → Контекст, обстоятельства
TASK (Задача)          → Ваша ответственность/цель
ACTION (Действие)      → Конкретные шаги
RESULT (Результат)     → Измеримый итог
```

### Когда использовать

- Сложные проекты, требующие детального описания
- Антикризисные ситуации
- Значительные достижения, требующие контекста
- Подготовка к поведенческим интервью

### Пример развёрнутого описания

```
SITUATION:
Компания теряла 25% крупных клиентов ежегодно из-за низкого качества
технической поддержки. NPS упал до -15.

TASK:
Как руководитель Customer Success, должен был снизить отток до 10%
и повысить удовлетворённость клиентов.

ACTION:
• Внедрил систему раннего предупреждения оттока на основе данных
• Создал программу proactive outreach для at-risk клиентов
• Реструктурировал команду поддержки, добавив tier для enterprise
• Запустил квартальные бизнес-ревью с топ-20 клиентами

RESULT:
Снизил отток до 8% за год, повысил NPS с -15 до +45.
Дополнительная retained revenue: $3.2M.
```

### Сокращённый формат для CV

```
Снизил отток крупных клиентов с 25% до 8%, повысив NPS с -15 до +45
через внедрение системы раннего предупреждения и программы proactive outreach.
Сохранил $3.2M выручки.
```

## PAR (Problem-Action-Result)

### Структура

```
PROBLEM (Проблема)     → Чёткая формулировка проблемы
ACTION (Действие)      → Ваше решение
RESULT (Результат)     → Измеримый итог
```

### Когда использовать

- Решение технических проблем
- Кризисные ситуации
- Troubleshooting

### Примеры

```
PROBLEM: Система падала при пиковых нагрузках (Black Friday), теряя $50K/час

ACTION: Провёл нагрузочное тестирование, выявил bottleneck в базе данных,
        реализовал шардинг и добавил кэширующий слой

RESULT: Система выдержала 10x нагрузку без простоев,
        обработав $5M транзакций за день
```

## Универсальные шаблоны

### Для любой роли

```
Шаблон 1: Оптимизация
[Сократил/Оптимизировал] [метрика] на [%/число]
через [действие],
[сэкономив/высвободив] [ресурс]

Пример: Сократил время onboarding новых сотрудников на 60%
через создание интерактивного обучающего портала,
высвободив 20 часов HR-команды ежемесячно
```

```
Шаблон 2: Рост
[Увеличил/Вырастил] [метрика] с [было] до [стало]
за [период]
посредством [действие]

Пример: Вырастил органический трафик с 10K до 150K посетителей/месяц
за 12 месяцев
посредством SEO-оптимизации и создания контентной стратегии
```

```
Шаблон 3: Запуск
[Запустил/Внедрил] [что именно]
[для кого / с каким охватом]
достигнув [результат]

Пример: Запустил программу лояльности
для 50K+ активных клиентов,
достигнув увеличения повторных покупок на 35%
```

```
Шаблон 4: Управление
[Руководил/Управлял] [чем]
с [масштаб: бюджет/команда/объём]
обеспечив [результат]

Пример: Руководил миграцией инфраструктуры в AWS
с бюджетом $2M и командой из 12 инженеров,
обеспечив zero-downtime и экономию $500K/год
```

## Чеклист качества достижения

- [ ] **Конкретное действие** — Что именно сделали?
- [ ] **Измеримый результат** — Есть числа/проценты/суммы?
- [ ] **Бизнес-влияние** — Понятен эффект для компании?
- [ ] **Ваш вклад** — Ясна ваша роль?
- [ ] **Временной контекст** — Понятны сроки?
