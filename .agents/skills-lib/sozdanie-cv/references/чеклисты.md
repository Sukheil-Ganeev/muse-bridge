# Чеклисты для CV

Систематические проверки перед отправкой резюме.

---

## Главный чеклист

### Перед каждой отправкой

```
□ CV адаптировано под конкретную вакансию
□ Использованы ключевые слова из описания вакансии
□ Нет орфографических и грамматических ошибок
□ Файл назван правильно: Имя_Фамилия_Должность_CV.pdf
□ Формат файла соответствует требованиям (PDF/DOCX)
□ Открывается корректно на разных устройствах
```

---

## Чеклист содержания

### Заголовок и контакты

```
□ Полное имя (как в документах)
□ Целевая должность указана
□ Телефон актуален и работает
□ Email профессиональный (не funny_bunny@mail.ru)
□ LinkedIn обновлён и соответствует CV
□ Город/локация указаны
□ Портфолио/GitHub (если релевантно)
□ Нет лишней информации (возраст, семейное положение — для международных)
```

### Профессиональное резюме (Summary)

```
□ 3-4 строки максимум
□ Указана специализация и опыт (в годах)
□ Есть главное достижение с цифрами
□ Понятно, какую роль ищете
□ Использованы ключевые слова вакансии
□ Нет общих фраз ("ответственный", "коммуникабельный")
```

### Опыт работы

```
□ Обратный хронологический порядок (новое сверху)
□ Для каждой позиции: компания, должность, даты, город
□ Даты в едином формате (Янв 2022 — Дек 2024)
□ Каждый пункт начинается с глагола действия
□ Каждый пункт содержит измеримый результат
□ Текущая позиция: 4-6 пунктов
□ Предыдущие: 2-4 пункта
□ Старые (5+ лет): 1-2 пункта
□ Нет нерелевантного опыта
□ Пробелы объяснены или заполнены
```

### Достижения

```
□ Каждое достижение имеет числовую метрику
□ Использованы формулы CAR или XYZ
□ Понятен ваш личный вклад
□ Показан бизнес-эффект
□ Достижения релевантны целевой вакансии
□ Самые впечатляющие — в начале
```

### Навыки

```
□ Навыки сгруппированы по категориям
□ Все навыки из вакансии присутствуют
□ Нет устаревших технологий
□ Указан уровень владения (где уместно)
□ Аббревиатуры расшифрованы
□ 8-15 навыков (не перегружено)
```

### Образование

```
□ Указан вуз, специальность, год окончания
□ Для junior: курсовые, дипломные проекты (если релевантны)
□ Для senior: достаточно одной строки
□ Дополнительное образование — только релевантное
```

### Сертификаты (если есть)

```
□ Только актуальные и релевантные
□ Указан год получения
□ Указана выдавшая организация
```

## Чеклист форматирования

### Общее

```
□ Длина: 1 страница (до 10 лет опыта) или 2 страницы
□ Поля: 1.5-2.5 см со всех сторон
□ Один шрифт для всего документа
□ 2-3 размера шрифта максимум
□ Достаточно "воздуха" (whitespace)
□ Единый стиль выделений (bold, italic)
```

### Шрифты

```
□ Профессиональный шрифт (Arial, Calibri, Helvetica, Garamond)
□ Размер основного текста: 10-12pt
□ Размер заголовков: 14-16pt
□ Размер имени: 18-24pt
□ Межстрочный интервал: 1.0-1.15
```

### Визуальная иерархия

```
□ Секции чётко разделены
□ Заголовки выделены
□ Буллеты единообразные
□ Даты выровнены
□ Левое выравнивание для основного текста
```

## Чеклист ATS

### Формат файла

```
□ .docx или text-based .pdf
□ Текст копируется корректно (проверить)
□ Нет защиты от копирования
```

### Структура

```
□ Одноколоночный макет
□ Нет таблиц
□ Нет текстовых боксов
□ Нет графиков и диаграмм
□ Нет изображений
□ Контакты НЕ в header/footer
□ Стандартные названия секций
```

### Ключевые слова

```
□ Название должности из вакансии есть в CV
□ Все обязательные навыки упомянуты
□ Технические термины точно соответствуют вакансии
□ Аббревиатуры + полные названия (SEO + Search Engine Optimization)
```

## Чеклист адаптации под вакансию

### Анализ вакансии

```
□ Выписаны все требования (must have)
□ Выписаны желательные требования (nice to have)
□ Выделены ключевые слова
□ Определены топ-3 приоритета работодателя
□ Понятна культура компании
```

### Адаптация CV

```
□ Заголовок соответствует названию вакансии
□ Summary отвечает на главные требования
□ Релевантные навыки на видном месте
□ Достижения переформулированы под требования
□ Нерелевантный опыт сокращён или убран
□ Добавлены все ключевые слова
```

## Чеклист финальной проверки

### Вычитка

```
□ Прочитано вслух (ловит ошибки)
□ Проверено через spell-checker
□ Проверено на грамматику (LanguageTool, Grammarly)
□ Нет повторяющихся слов в соседних пунктах
□ Нет двойных пробелов
□ Нет лишних точек/запятых
```

### Проверка фактов

```
□ Все даты корректны
□ Названия компаний написаны правильно
□ Должности соответствуют трудовой
□ Цифры достижений верны
□ Контакты актуальны
```

### Тест "чужими глазами"

```
□ Дал прочитать коллеге/другу
□ Понятно, чем занимаетесь?
□ Понятно, почему вы хороший кандидат?
□ Нет непонятных аббревиатур?
□ Не слишком ли длинно?
```

### Технические проверки

```
□ Открыть PDF на телефоне — читается?
□ Открыть в другом PDF-reader — не ломается?
□ Распечатать — выглядит хорошо?
□ Скопировать текст — копируется корректно?
```

## Чеклист по типам позиций

### Для IT-позиций

```
□ Технологический стек чётко указан
□ GitHub/Portfolio ссылка есть
□ Есть описание проектов с технологиями
□ Указаны масштабы систем (RPS, пользователи, данные)
□ Методологии разработки упомянуты
```

### Для менеджерских позиций

```
□ Указан размер команды
□ Указан бюджет (если управляли)
□ Есть примеры развития людей
□ Показаны бизнес-результаты (не только процессные)
□ Упомянуты кросс-функциональные проекты
```

### Для продающих позиций

```
□ Есть цифры продаж (выручка, план, рост)
□ Указан размер клиентской базы
□ Показана конверсия/воронка
□ Упомянуты крупные сделки
□ Есть примеры overachievement
```

### Для стартапов

```
□ Показана готовность работать в неопределённости
□ Упомянут опыт работы в разных ролях
□ Есть примеры быстрых результатов
□ Демонстрируется предпринимательский mindset
```

### Для корпораций

```
□ Соблюдён формальный стиль
□ Упомянут опыт работы в крупных структурах
□ Показано умение работать с процессами
□ Есть релевантные сертификаты
```

## Красные флаги — самопроверка

### Проверьте и исправьте

```
□ Нет пробелов в опыте без объяснения
□ Нет слишком частой смены работы без причины
□ Нет понижения в должности без объяснения
□ Нет завышенных/ложных данных
□ Нет негатива о предыдущих работодателях
□ Нет слишком личной информации
□ Нет устаревших навыков
□ Email не выглядит непрофессионально
```

## Быстрый чеклист (60 секунд)

Минимальная проверка перед отправкой:

```
□ Имя и контакты верны
□ Должность соответствует вакансии
□ Нет опечаток в первых 3 строках
□ Файл открывается
□ Файл назван правильно
□ Отправляю правильную версию (для этой вакансии)
```
