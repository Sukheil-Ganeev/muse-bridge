# Психология найма

Понимание того, как думают рекрутеры и hiring managers, позволяет создать CV, которое работает на вас.

---

## Eye-Tracking исследования CV

### Сводка исследований

| Исследование | Год | Участники | Среднее время | Метод |
|--------------|-----|-----------|---------------|-------|
| TheLadders (original) | 2012 | 30 | 6 сек | Eye-tracking |
| **TheLadders (updated)** | **2018** | **30** | **7.4 сек** | Eye-tracking |
| University of Michigan | 2023 | - | 6 сек (70% на верхнюю треть) | Eye-tracking |
| Texas A&M / MDPI | 2023 | 221 | - | Eye-tracking + ML |
| ResumeGo | 2024 | 418 | 30 сек - 1 мин (47%) | Survey |
| InterviewPal | 2025 | 312 | 11.2 сек (scan) / 1:34 (total) | Data analysis |

### Правило 7.4 секунд

Eye-tracking исследования (TheLadders, 2018) показывают:
- **7.4 секунды** — среднее время первичного скана CV (+1.4 сек vs 2012)
- **80% времени** уходит на 6 ключевых точек
- Решение "читать дальше или нет" принимается за эти секунды

### 6 точек фиксации внимания

Рекрутер смотрит в первую очередь на:

```
1. Имя кандидата
2. Текущая должность и компания
3. Даты начала/окончания текущей позиции
4. Предыдущая должность и компания
5. Даты предыдущей позиции
6. Образование
```

### Время просмотра секций

| Приоритет | Секция | Время/Внимание |
|-----------|--------|----------------|
| 1 | Имя и контакты | Первые 1-2 сек |
| 2 | Текущая должность | 1-2 сек |
| 3 | Summary/Headline | 1-2 сек |
| 4 | Experience (первые 2-3 пункта) | 2-3 сек |
| 5 | Skills (если видны) | < 1 сек |
| 6 | Education | < 1 сек |
| 7 | Остальное | Часто пропускается |

### Тепловые карты внимания

| Зона | Цвет | Элементы резюме | % внимания |
|------|------|-----------------|------------|
| Высокое внимание | Красный | Имя, текущая должность, контакты | ~30% |
| Среднее внимание | Оранжевый | Professional summary | ~20% |
| Умеренное внимание | Желтый | Ключевые навыки (Core competencies) | ~15% |
| Низкое внимание | Зеленый | Пункты опыта работы | ~20% |
| Минимальное внимание | Синий | Образование, дополнительная информация | ~15% |

### Что игнорируется

- Правая сторона страницы
- Нижняя часть резюме
- Плотные блоки текста (параграфы)
- Последние пункты в списках
- Позиции после первых 2-3

### Оптимизация под 7.4 секунд

**Заголовок должен содержать:**
```
ИМЯ ФАМИЛИЯ
Целевая должность | Ключевая экспертиза | Главное достижение
```

**Summary (если есть) — 3-4 строки (+340% к callback!):**
```
Кто вы + опыт + топ-достижение + ключевое преимущество
```

**Первый пункт опыта — самый сильный:**
```
Самое впечатляющее достижение с максимальными цифрами
```

## F-паттерн сканирования

### Научное обоснование (Nielsen Norman Group)

| Параметр | Значение |
|----------|----------|
| Автор исследования | Jakob Nielsen, NN/g |
| Год | Впервые опубликовано в 2006, обновлено |
| Участники | 232 пользователя |
| Объем данных | Тысячи веб-страниц |

### Как работает

Глаза сканируют страницу по траектории буквы F:

```
████████████████████████████████████████  ← Горизонтально сверху (имя, заголовок)
█                                      █
████████████████████████               █  ← Горизонтально чуть ниже (summary)
█                                      █
█                                      █
█                                      █  ← Вертикально вниз по левому краю
█                                      █
█                                      █
```

### Дополнительные паттерны сканирования

| Паттерн | Описание |
|---------|----------|
| **F-паттерн** | Две горизонтальные линии + вертикальная слева |
| **E-паттерн** | Вариация F с дополнительными горизонтальными сканами |
| **Layer-cake** | Глаза сканируют заголовки, пропуская основной текст |
| **Spotted** | Точечное сканирование ключевых элементов |
| **Z-паттерн** | Слева направо, вниз по диагонали, снова слева направо |

### Практическое применение

| Позиция | Что размещать | Пример |
|---------|---------------|--------|
| Верх страницы | Имя, должность, контакты | Чётко и крупно |
| Первая горизонталь | Summary + ключевые навыки | Топ-3 преимущества |
| Вторая горизонталь | Последнее место работы | Компания + должность |
| Левый край | Заголовки секций, названия компаний | Выделить визуально |
| Начало пунктов | Глаголы действия, ключевые слова | Сильные формулировки |

### Что НЕ видит рекрутер

- Правую часть страницы (особенно длинные строки)
- Нижнюю треть первой страницы
- Вторую страницу (изначально)
- Текст внутри плотных абзацев
- Последние пункты в списках
- Позиции после первых 2-3

## Когнитивные искажения рекрутеров

### Эффект ореола (Halo Effect)

**Что это:** Одна положительная характеристика влияет на восприятие всего остального.

**Как использовать:**
- Поставьте самое сильное достижение первым
- Упомяните известные компании/бренды в начале
- Престижное образование — в видное место

```
✅ "Бывший менеджер Google, увеличил выручку на $5M"
❌ "Увеличил выручку на $5M, работал в Google"
```

### Эффект якоря (Anchoring)

**Что это:** Первая информация становится "якорем" для оценки остального.

**Как использовать:**
- Начинайте с самых больших цифр
- Первый пункт — самое впечатляющее достижение
- Summary задаёт тон всему CV

```
✅ "Управлял бюджетом $10M" (в начале)
❌ "Управлял бюджетом $10M" (в конце списка)
```

### Предвзятость подтверждения (Confirmation Bias)

**Что это:** Рекрутер ищет подтверждение своего первого впечатления.

**Как использовать:**
- Создайте сильное первое впечатление
- Повторяйте ключевые темы на протяжении CV
- Если первое впечатление положительное, рекрутер будет искать плюсы

### Эффект контраста

**Что это:** CV оценивается в сравнении с предыдущим.

**Как использовать:**
- Выделяйтесь визуально (в рамках профессионализма)
- Используйте конкретные числа (большинство пишут без них)
- Демонстрируйте результаты, а не обязанности

## Что ищут рекрутеры

### Красные флаги (негатив)

| Флаг | Что думает рекрутер | Как избежать |
|------|---------------------|--------------|
| Пробелы в опыте | "Что скрывает?" | Объясните или заполните (учёба, фриланс) |
| Частая смена работы | "Уйдёт через полгода" | Покажите причины роста, объедините схожие роли |
| Понижение в должности | "Не справился?" | Подайте как осознанный выбор |
| Орфографические ошибки | "Невнимателен к деталям" | Вычитайте несколько раз |
| Слишком длинное CV | "Не умеет приоритизировать" | Максимум 2 страницы |
| Отсутствие результатов | "Просто исполнитель" | Добавьте метрики |

### Зелёные флаги (позитив)

| Флаг | Что думает рекрутер |
|------|---------------------|
| Прогресс в карьере | "Растёт, амбициозен" |
| Измеримые достижения | "Понимает бизнес-ценность" |
| Релевантный опыт | "Быстро встроится" |
| Известные компании | "Уже прошёл отбор" |
| Рекомендации внутри | "Проверенный человек" |
| Чистое форматирование | "Профессионал" |

## Позиционирование

### Для разных аудиторий

**HR/Рекрутер (первый фильтр):**
- Ищет ключевые слова из вакансии
- Проверяет формальные требования
- Оценивает "общее впечатление"

*Оптимизация:* Ключевые слова, чёткая структура, ATS-совместимость

**Hiring Manager (второй фильтр):**
- Оценивает релевантность опыта
- Ищет конкретные достижения
- Представляет вас в команде

*Оптимизация:* Специфичные достижения, технические детали, культурный fit

**C-level (финальное решение):**
- Смотрит на бизнес-влияние
- Оценивает потенциал роста
- Думает о долгосрочной ценности

*Оптимизация:* Стратегические инициативы, ROI, масштаб влияния

### Позиционирование по уровню

**Junior:**
- Потенциал > опыт
- Обучаемость, энтузиазм
- Проекты, стажировки, образование

**Middle:**
- Конкретные результаты
- Самостоятельность
- Глубина экспертизы

**Senior:**
- Масштаб влияния
- Менторство, лидерство
- Стратегические инициативы

**Lead/Manager:**
- Результаты команды
- Развитие людей
- Бизнес-метрики

## Storytelling в CV

### Нарратив карьеры

CV должно рассказывать историю профессионального роста:

```
Начало (образование)
    ↓
Первые роли (фундамент)
    ↓
Рост ответственности (развитие)
    ↓
Текущая позиция (кульминация)
    ↓
Целевая роль (куда иду)
```

### Как создать связную историю

1. **Определите тему:** Что объединяет ваш опыт?
   - "От инженера к техническому лидеру"
   - "Рост в e-commerce от стартапа до enterprise"
   - "Специалист по масштабированию команд"

2. **Покажите прогрессию:** Каждая роль — ступень вверх
   - Больше ответственности
   - Больше масштаб
   - Новые компетенции

3. **Свяжите с вакансией:** Почему эта роль — логичный следующий шаг?

### Пример нарратива

```
SUMMARY:
Product Lead с траекторией от разработчика до руководителя продукта.
За 8 лет прошёл путь от написания кода до управления P&L в $10M.
Ищу роль Head of Product, чтобы масштабировать продуктовую функцию.

ОПЫТ:
2022-н.в.: Product Lead — управление продуктом с выручкой $10M
2019-2022: Senior PM — запуск 0→1 продукта до $2M ARR
2017-2019: PM — управление бэклогом и командой из 5 человек
2015-2017: Developer — создание технического фундамента
```

## Эмоциональное воздействие

### Слова, которые работают

| Категория | Сильные слова |
|-----------|---------------|
| Результат | Достиг, Превысил, Перевыполнил |
| Инновация | Первый, Пионер, Трансформировал |
| Лидерство | Возглавил, Построил, Вдохновил |
| Эффективность | Оптимизировал, Автоматизировал, Ускорил |
| Рост | Вырастил, Масштабировал, Расширил |

### Слова, которые НЕ работают

| Избегать | Почему | Замена |
|----------|--------|--------|
| Ответственный за | Пассивно | Руководил, Обеспечил |
| Помогал | Размыто | Содействовал достижению X |
| Участвовал | Неопределённо | Внёс вклад в Y, приведший к Z |
| Работал над | Нет результата | Разработал, Создал |
| Различные | Неконкретно | Указать конкретно |
| Успешно | Избыточно | Убрать (успех — в метриках) |

## Чеклист психологической оптимизации

### Первое впечатление (6 секунд)
- [ ] Имя и должность видны сразу
- [ ] Главное достижение в первых строках
- [ ] Ключевые навыки легко найти
- [ ] Визуально чистый, профессиональный вид

### F-паттерн
- [ ] Важная информация слева
- [ ] Заголовки выделены
- [ ] Начало пунктов — сильные глаголы
- [ ] Нет "стен текста"

### Когнитивные триггеры
- [ ] Самое сильное — первым (эффект якоря)
- [ ] Узнаваемые имена компаний на видном месте (эффект ореола)
- [ ] Конкретные числа (контраст с обычными CV)
- [ ] История роста прослеживается

### Эмоциональное воздействие
- [ ] Активные глаголы
- [ ] Нет слабых формулировок
- [ ] Позитивный тон
- [ ] Демонстрация ценности, а не обязанностей
