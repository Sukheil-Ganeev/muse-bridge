# Скилл: Создание CV

## Описание

Универсальный скилл для создания профессиональных резюме (CV). Помогает составить, улучшить или оценить резюме с учётом современных требований рекрутинга и ATS-систем. Включает специализированный раздел для туристической индустрии ОАЭ (Ticket Combo, ETHARA, Platinumlist, DMC, OTA).

## Когда использовать

- Создание CV с нуля
- Улучшение существующего резюме
- Адаптация CV под конкретную вакансию
- Аудит и оценка качества резюме
- Перевод обязанностей в достижения
- CV для туристической индустрии ОАЭ (Ticket Combo, ETHARA, Platinumlist)
- Переквалификация опыта (Fashion/Retail -> Tourism)
- Подготовка CV с трилингвизмом (AR/EN/RU)

## Структура скилла

```
создание-cv/
├── SKILL.md                    # Основной файл с методологией
├── README.md                   # Этот файл
└── references/
    ├── глаголы-действия.md     # 200+ сильных глаголов по категориям
    ├── формулы-достижений.md   # CAR, XYZ, STAR методы с примерами
    ├── ats-оптимизация.md      # Прохождение автоматических фильтров
    ├── психология-найма.md     # Как думают рекрутеры
    └── чеклисты.md             # Проверки перед отправкой
```

## Основные концепции

### Формулы достижений

| Формула | Структура | Пример |
|---------|-----------|--------|
| **CAR** | Context → Action → Result | "При падении продаж внедрил CRM, увеличив конверсию на 40%" |
| **XYZ** | Accomplished X by Y, resulting in Z | "Сократил расходы на 30% через автоматизацию отчётности" |
| **STAR** | Situation → Task → Action → Result | Для сложных кейсов |

### Правило 6 секунд

Рекрутеры тратят 6 секунд на первичный скан CV. За это время должно быть видно:
- Имя и целевая должность
- Последняя компания и позиция
- Ключевые навыки
- Главное достижение

### F-паттерн

Глаза сканируют документ по F-паттерну:
1. Горизонтально сверху (заголовок)
2. Горизонтально чуть ниже (summary)
3. Вертикально вниз по левому краю

## Ключевые принципы

1. **Достижения, не обязанности** — "Увеличил продажи на 50%", а не "Занимался продажами"
2. **Всегда цифры** — Конкретные метрики в каждом пункте
3. **Адаптация** — Одно CV не подходит для всех вакансий
4. **ATS-совместимость** — Простое форматирование, ключевые слова
5. **Краткость** — 1-2 страницы максимум

## Использование референсов

При создании CV обращайтесь к референсам:

- **[[глаголы-действия]]** — Когда нужен сильный глагол для начала пункта
- **[[формулы-достижений]]** — Для структурирования достижений
- **[[ats-оптимизация]]** — При оптимизации под автоматические системы
- **[[психология-найма]]** — Для понимания приоритетов рекрутера
- **[[чеклисты]]** — Финальная проверка перед отправкой

## Типичный workflow

```
1. Собрать информацию о кандидате
   ↓
2. Получить описание целевой вакансии
   ↓
3. Выделить ключевые слова из вакансии
   ↓
4. Структурировать опыт по шаблону
   ↓
5. Переформулировать в достижения (CAR/XYZ)
   ↓
6. Добавить метрики
   ↓
7. Оптимизировать под ATS
   ↓
8. Проверить по чеклисту
```

## Примечания

- Для международных вакансий: CV без фото, без возраста, без семейного положения
- **Для UAE/GCC: фото обязательно** (стандартная практика региона)
- Для российского рынка: фото часто ожидается
- Формат файла: предпочтительно PDF, иногда DOCX (уточнять в вакансии)
- Имя файла: `Имя_Фамилия_Должность_CV.pdf` (для UAE: `FirstName_LastName_CV.pdf`)
