# Реестр операционных правил

> **Легенда уверенности:** A — прямая инструкция Марселя; B — повторено/подтверждено в нескольких чатах; C — операционный вывод из кейсов и поправок.

> **Важно:** event prices, availability, contacts, bank limits and platform policies are volatile. Их нельзя переносить в новый заказ без актуальной проверки.

## R001 — Перед любым новым ответом по мероприятию сначала восстановить его историю: что запрашивали, кому, сколько билетов, какие категории/места и цены уже назывались, какая формула прибыли применялась и что уже было отправлено.
- **Приоритет:** CRITICAL
- **Область:** Global
- **Статус:** Active
- **Уверенность:** A — прямая инструкция
- **Как применять:** Не повторять работу и не создавать противоречия с ранее отправленным предложением.
- **Источники:** Chat 4: 513–535; Chat 8: 4577–4603; Chat 10: 1–76
