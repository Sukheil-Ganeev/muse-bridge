# Playbook — Large Groups

## Questions
- exact number, adults/children;
- must everyone be in one row/block?;
- acceptable split: 15+15, 10+10+10, adjacent rows?;
- max order limit;
- named guests required now or later?;
- group invoice and payment deadline;
- hold/allocation available?;
- can supplier guarantee same category and proximity?;

## Rule
Do not say “30 tickets available” merely because the page lets you select a category. Availability and a contiguous group block are separate facts.
