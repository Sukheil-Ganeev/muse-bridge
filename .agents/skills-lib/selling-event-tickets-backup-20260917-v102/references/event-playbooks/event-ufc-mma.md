# Event Playbook — UFC / MMA

## Partner offer
Include event/date/venue/start, current verified card, category/section/row/seats/together, price, age and “card subject to change”.

## View logic
Floor/ringside is closer but can have flatter sightlines and cage/people obstruction. Lower bowl may give a better overall view. Describe trade-offs honestly.

## Special controls
- UFC weigh-in is a separate product from fight-night seating.
- Asian UFC can be real-name, one ID per ticket, original passport and face verification.
- Per-account quantity limits can break group seating.
- Full card must be refreshed immediately before sending.
