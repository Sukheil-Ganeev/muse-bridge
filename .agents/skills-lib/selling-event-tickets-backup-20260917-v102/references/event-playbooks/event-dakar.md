# Event Playbook — Dakar / Expedition Programs

Dakar is not a normal seat ticket. Build a day-by-day product:

- route and stage dates;
- meeting/departure points;
- viewing points;
- daily transfer distance and duration;
- accommodation each night;
- hotel/camp/guesthouse standard;
- included nights vs program days;
- room configuration and luggage transfer;
- meals/drinks;
- bivouac/prologue/opening/finish access;
- airport transfers;
- VAT and invoice entity;
- cancellation and route-change rules.

Never promise one hotel for the week without supplier confirmation. Explain that it is closer to an expedition than a resort holiday.
