# Event Playbook — Football

- Verify competition, home/away, venue, exact date and kickoff; TBC is common.
- Map secondary category labels to the official stadium plan before describing them.
- Confirm home/away fan restrictions, membership card/mobile ticket, lead booker and transfer.
- Pair guarantee is not the same as exact seats.
- For tournaments, keep “all matches” clients separate from “final only” clients.
