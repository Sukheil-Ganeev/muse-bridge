# Agent Talk

Скилл для естественного общения между AI-агентами через tmux-bridge.

## Что это

Ты пишешь в Claude Code обычным языком — Claude сам отправляет сообщение нужному агенту через tmux.

## Как пользоваться

Просто пиши в Claude Code:

```
codex: проверь auth.ts
```

```
спроси кодекс что с тестами
```

```
напиши кодексу сделай ревью
```

```
что делает codex?
```

```
стоп кодекс
```

Claude автоматически переведёт это в команды tmux-bridge и отправит сообщение.

## Требования

- WSL с Ubuntu
- tmux 3.2+
- smux установлен (`~/.smux/bin/tmux-bridge`)
- Агенты запущены в tmux-панелях (через `bash ~/start-agents.sh`)

## Поддерживаемые агенты

- **Codex** — codex, кодекс, кодексу
- **Gemini** — gemini, джемини, джемину
- **Claude** — claude, клод, клоду (для меж-агентного общения)
- Любой агент с именем панели из `tmux-bridge list`
