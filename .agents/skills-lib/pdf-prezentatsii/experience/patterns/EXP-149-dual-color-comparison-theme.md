# EXP-149: Семантическая двойная палитра для сравнительных презентаций

**Дата:** 2026-03-04
**Проект:** GPU Buyer's Guide Dubai 2026 (RTX 3090 vs RTX 5090)
**Категория:** pattern

## Паттерн

Назначь один акцентный цвет каждой "стороне" сравнения. Применяй его к КАЖДОМУ визуальному элементу, связанному с этой стороной.

**GPU Guide пример:**
```
RTX 5090 (новый/флагман)  → Cyan    #22D3EE
RTX 3090 (зрелый/ценность) → Amber   #F59E0B
Общий бренд (NVIDIA)       → Green   #76B900
```

## Где применять

| Элемент | RTX 5090 | RTX 3090 |
|---------|----------|----------|
| `border-left` карточки | `3px solid #22D3EE` | `3px solid #F59E0B` |
| Glow blob | `background: #22D3EE; opacity:0.08` | `background: #F59E0B; opacity:0.08` |
| Заголовок раздела | `color: #22D3EE` | `color: #F59E0B` |
| Section label | `color: rgba(34,211,238,0.7)` | `color: rgba(245,158,11,0.7)` |
| Spec pills | `.pill-cyan` | `.pill-amber` |
| Comparison row | cyan bg tint | amber bg tint |

## CSS классы

```css
.card-5090 { border-left: 3px solid #22D3EE; }
.card-3090 { border-left: 3px solid #F59E0B; }

.pill-cyan  { border-color: rgba(34,211,238,0.4); color: #22D3EE; background: rgba(34,211,238,0.08); }
.pill-amber { border-color: rgba(245,158,11,0.4); color: #F59E0B; background: rgba(245,158,11,0.08); }
```

## Психология

- Зритель считывает "к какому лагерю относится элемент" **без чтения текста**
- Единый бренд-цвет (green) объединяет обе стороны → нет ощущения "vs до смерти"
- Работает на split-слайдах, таблицах сравнения и одиночных карточках

## Общие паттерны цветовых пар

| Контекст | Цвет 1 | Цвет 2 | Объединитель |
|---------|--------|--------|-------------|
| Старое vs Новое | Amber (зрелость) | Cyan (будущее) | Brand color |
| Бюджет vs Премиум | Amber (ценность) | Purple (премиум) | Neutral white |
| Два конкурента | Brand A цвет | Brand B цвет | — |
| До / После | Red (проблема) | Green (решение) | — |
| Dev / Prod | Orange (осторожно) | Blue (стабильно) | — |

## Правило

Двойная палитра работает если:
1. Оба цвета достаточно **разные** (не два оттенка синего)
2. Оба цвета достаточно **различимы** на тёмном фоне (проверить contrast ratio)
3. Применяется **ПОСЛЕДОВАТЕЛЬНО** на всех слайдах — не только на слайде сравнения
