# EXP-105: Text-shadow glow -- не переусердствовать

## Проблема

Агрессивный text-shadow glow создаёт "неоновый" эффект, который режет глаза и ухудшает читаемость. Особенно заметно на числах, процентах и данных в metric-карточках.

## Примеры

```css
/* СЛИШКОМ АГРЕССИВНО */
.metric-value {
    text-shadow: 0 0 30px rgba(96, 165, 250, 0.5);  /* alpha 0.5 + blur 30px */
}

h2 {
    text-shadow: 0 0 20px rgba(139, 92, 246, 0.6);  /* Неон на заголовке */
}

/* ПРАВИЛЬНО -- subtle glow */
.metric-value {
    text-shadow: 0 0 8px rgba(96, 165, 250, 0.15);  /* Едва заметное свечение */
}

h2 {
    text-shadow: 0 0 6px rgba(139, 92, 246, 0.12);
}
```

## Параметры

| Элемент | blur-radius | alpha | Заметки |
|---------|-------------|-------|---------|
| Заголовки слайдов | 6-8px | 0.12-0.15 | Мягкий акцент |
| Числа/данные | 0 (none) | -- | Числа должны быть чёткими |
| Accent text | 4-6px | 0.10-0.12 | Едва заметный ореол |
| Декоративные | 10-15px | 0.20-0.25 | Допустимо для фоновых элементов |

## Правило

- **alpha 0.12-0.15** -- для контентного текста
- **blur 6-8px** -- для заголовков
- **text-shadow: none** -- для чисел, процентов, данных в таблицах
- **Никогда alpha > 0.3** для читаемого текста

## Урок

**Glow = приправа, не основное блюдо.** Если glow заметен с первого взгляда -- он слишком сильный. Правильный glow создаёт ощущение глубины, но не конкурирует с контентом за внимание.
