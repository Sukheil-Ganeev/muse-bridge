# EXP-142: Анимированные PDF — честная документация ограничений

**Тип:** WARNING
**Дата:** 2026-02-28
**Контекст:** Вопрос пользователя "умеешь ли делать анимированные PDF?"

## Факт: Анимированные PDF НЕ существуют

PDF (ISO 32000) — статичный формат. НЕ поддерживаются:
- CSS animations / @keyframes
- CSS transitions
- Animated GIF / APNG / WebP (рендерятся как 1 кадр)
- SVG SMIL анимации
- HTML5 Canvas
- JavaScript анимации (кроме Acrobat JS, только в Adobe Reader)

## "Анимации" которые формально существуют но бесполезны

| Фича | Работает ТОЛЬКО в | Реальность |
|------|-------------------|-----------|
| Page transitions | Adobe Acrobat | Chrome, Preview, др. — игнорируют |
| Embedded video (MP4) | Adobe Acrobat Pro | Rich Media Annotations, фрагментация |
| Acrobat JavaScript | Adobe Reader | НЕ браузерный JS, ограниченный API |
| 3D models (U3D/PRC) | Adobe Acrobat | Устаревшая технология |

## Правильная стратегия: двойной формат

```
HTML (интерактивный) → для показа на экране/проекторе
        ↓ (Playwright)
PDF (статичный)     → для отправки/печати/архива
```

## При запросе "анимированная презентация"

1. Создать HTML5 презентацию с полными анимациями
2. Предложить PDF как дополнительный статичный вариант
3. НЕ обещать "анимации в PDF" — это невозможно
4. Альтернативы: HTML файл, MP4 видео, PPTX

## Урок
Честность > обещания. PDF = статика. HTML = анимации. Это разные форматы для разных целей.
