## Как использовать этот файл

При активации справочника **yandex-cloud-справочник** Claude должен:

1. Прочитать этот файл
2. Ознакомиться с критическими уроками (если есть)
3. Применять найденные паттерны и избегать предупреждений

При завершении работы, если был получен ценный урок, Claude предложит:

```
"Хотите записать это в опыт справочника?"
```

## Категории опыта

### fixes/
Исправленные ошибки и баги в примерах кода или конфигурациях.

**Примеры:**
- Неправильные connection strings
- Ошибки в Terraform конфигурациях
- Проблемы с IAM permissions
- Troubleshooting deploy

### improvements/
Найденные улучшения и оптимизации.

**Примеры:**
- Лучшие подходы к архитектуре
- Оптимизация costs
- Performance tuning
- Security improvements

### patterns/
Повторяющиеся паттерны и best practices.

**Примеры:**
- Стандартные архитектуры для туризма
- Naming conventions
- Error handling patterns
- Monitoring setups

### warnings/
Что НЕ делать (антипаттерны).

**Примеры:**
- Распространенные ошибки новичков
- Security риски
- Performance bottlenecks
- Cost traps
