# 04-Inventory Management Schema

Управление всеми физическими активами, запасами, техническим обслуживанием, страховками и лицензиями.

**Таблицы:**
- `inventory_items` - SKU каталог всех предметов
- `stock_movements` - История всех движений запасов
- `yacht_maintenance` - ТО яхт
- `vehicle_maintenance` - ТО автомобилей
- `insurance_policies` - Полисы страховки
- `licenses_and_certifications` - Лицензии и сертификаты
- `asset_depreciation` - Амортизация активов

**Ключевые Запросы:**
1. Низкий уровень запасов
2. История движения запасов
3. Требуемое техническое обслуживание
4. Истекающие страховки и лицензии
5. Стоимость активов
