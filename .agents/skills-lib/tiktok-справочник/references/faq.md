# TikTok FAQ — Часто задаваемые вопросы

## Общие вопросы

### Есть ли у TikTok Bot API?
Нет. TikTok не предоставляет Bot API для автоматизации сообщений (как Telegram или WhatsApp). TikTok — контент-платформа, API ориентированы на публикацию контента, аналитику и рекламу.

### Какие API доступны в TikTok?
- **Content Posting API** — публикация видео/фото
- **Login Kit** — авторизация пользователей (OAuth 2.0)
- **Embed API / oEmbed** — встраивание видео на сайт
- **Research API** — поиск и аналитика (требует отдельной заявки)
- **Business API** — управление рекламой (Ads Manager)
- **TikTok Shop API** — управление магазином и каталогом

### Как зарегистрировать приложение?
1. Перейти на https://developers.tiktok.com/
2. Зарегистрироваться или войти
3. Создать приложение (App)
4. Получить `client_key` и `client_secret`
5. Настроить Redirect URI и выбрать Scopes

### Нужна ли верификация приложения?
Да. Неаудированные приложения ограничены:
- 5 пользователей в 24 часа
- Весь контент публикуется в приватном режиме
- После тестирования нужно пройти аудит TikTok

## Content Posting API

### Сколько видео можно публиковать в день?
До 15 публикаций на пользователя в день через API.

### Какой максимальный размер видео?
- iOS: 287.6 МБ
- Android: 72 МБ
- Web/Desktop: 500 МБ
- Через API: поддерживает chunk-загрузку для больших файлов

### Можно ли публиковать фото?
Да, Content Posting API поддерживает Photo Mode (до 35 фото в одном посте).

### Что такое Direct Post vs Upload?
- **Direct Post** — публикует видео напрямую в аккаунт пользователя
- **Upload (Inbox)** — загружает как черновик, пользователь получает уведомление и публикует вручную

## Авторизация

### Как работает OAuth 2.0 в TikTok?
TikTok использует стандартный OAuth 2.0 + PKCE:
1. Редирект на TikTok для авторизации
2. Пользователь даёт согласие
3. TikTok возвращает `code`
4. Обмен `code` на `access_token` + `refresh_token`

### Сколько живёт access_token?
- access_token: 24 часа
- refresh_token: 365 дней
- Обновление через refresh_token автоматическое

### Что такое Server-to-Server Auth?
Авторизация без участия пользователя (через `client_credentials`). Используется для серверных интеграций (Ads API и др.).

## TikTok Shop

### Доступен ли TikTok Shop в ОАЭ?
Доступность TikTok Shop зависит от региона. Проверяйте актуальный статус на https://seller.tiktok.com/. Даже если Shop недоступен как полноценный магазин, можно использовать Product Links в видео.

### Что можно продавать для туризма?
- Билеты на достопримечательности
- Экскурсионные пакеты
- Ваучеры на яхты и автомобили
- Подарочные сертификаты

### Как работает Affiliate Program?
Создатели контента могут продвигать товары продавцов и получать комиссию за продажи через свои видео.

## Реклама

### В чём разница между Promote и Ads Manager?
- **Promote** — простой буст видео из приложения (от $3/день, до 7 дней)
- **Ads Manager** — полноценная рекламная платформа с детальным таргетингом (от $20/день на ad group, от $50/день на campaign)

### Какой формат рекламы лучше для туризма?
- **Spark Ads** — продвижение лучших органических видео (самый естественный)
- **In-Feed Ads** — видео в ленте FYP (основной формат)
- **TopView** — максимальный охват при открытии приложения (дорого)

### Как таргетировать СНГ аудиторию?
В Ads Manager: Geography > Russia, Kazakhstan, Uzbekistan и др. Интересы: Travel, Tourism, Luxury. Можно использовать Custom Audiences и Lookalike.

## Аналитика

### Где смотреть аналитику TikTok?
- **TikTok Studio** — встроенная аналитика (бизнес/creator-аккаунт)
- **Video Insights** — детали по каждому видео (просмотры, watch time, источники)
- **API** — `video.list` endpoint с метриками
- **Сторонние инструменты** — Sprout Social, Exolyt, Brandwatch

### Какой engagement rate считается хорошим?
- 5-10% — хороший
- 10%+ — отличный
- Формула: (Лайки + Комментарии + Шеры) / Просмотры x 100

### Что важнее: просмотры или watch time?
Watch time (среднее время просмотра) — ключевая метрика алгоритма. Видео с высоким watch time получают больше показов в FYP. Хороший показатель: 15-20 секунд средний watch time.

## Хэштеги и тренды

### Сколько хэштегов использовать?
Рекомендация 2025-2026: 3-5 специфических хэштегов. Алгоритм приоритизирует микро-нишевые хэштеги над массовыми.

### Где искать тренды?
- **TikTok Creative Center** — https://ads.tiktok.com/business/creativecenter/
- **Discover Page** — вкладка "Discover" в приложении
- **For You Page** — наблюдение за трендами в ленте
- **tokchart.com** — трендовые звуки в реальном времени

### Использовать ли #fyp и #foryou?
Эффективность этих хэштегов не подтверждена. Лучше использовать нишевые хэштеги, релевантные контенту.
