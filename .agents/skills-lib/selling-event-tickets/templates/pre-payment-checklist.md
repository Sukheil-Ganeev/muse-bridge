# Pre-Payment Checklist

- [ ] Event, city, date and session match the client request.
- [ ] Quantity is correct.
- [ ] Together guarantee/exact seats are confirmed.
- [ ] Product unit is correct (ticket vs suite/table/package).
- [ ] Listing still active.
- [ ] Checkout Total/Payable captured.
- [ ] No fee is double-counted.
- [ ] Currency and working rate confirmed.
- [ ] Bank/FX reserve applied only when appropriate.
- [ ] Transfer/delivery method usable by the final guest.
- [ ] Real-name/passport/lead-booker requirements satisfied.
- [ ] Age rules checked.
- [ ] Refund/cancellation explained.
- [ ] Selling price and actual profit recalculated.
- [ ] Partner/client payment received or agreed.
- [ ] Screenshot/confirmation/order ID stored.
