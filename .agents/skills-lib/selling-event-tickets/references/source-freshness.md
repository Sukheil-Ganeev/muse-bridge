# Матрица актуальности знаний

| Тип знания | Можно использовать без веб-проверки? | Что делать |
|---|---|---|
| Рабочий процесс, разделение внешнего/внутреннего блока | Да | Использовать как постоянное правило. |
| WhatsApp TXT и одна звёздочка | Да | Использовать постоянно. |
| Формула полной себестоимости | Да | Подставлять актуальные числа. |
| Последняя локальная маржа старого заказа | Только как история | Проверить, что речь о том же событии/клиенте/category. |
| Наличие и цена | Нет | Проверить live listing/checkout. |
| Дата, время, venue, кард, lineup | Нет | Проверить организатора и актуальные источники. |
| Platform fee/policy/transfer | Нет | Проверить правила конкретного события и последний checkout. |
| Email и контакты | Нет | Проверить действительность адреса. |
| Банковские лимиты/FX/cashback | Нет | Проверить официальный банк на текущую дату. |
| Возраст и правила входа | Нет | Проверить event-specific policy. |
| Вывод из отсутствующего скриншота | Нет | Запросить новый скрин или открыть страницу заново. |
