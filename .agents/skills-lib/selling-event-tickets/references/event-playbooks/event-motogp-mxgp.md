# Event Playbook — MotoGP / MXGP / Motorsport

- Separate weekend access days from hospitality service days.
- GA can be standing/free seating; do not invent rows.
- Check paddock, pit lane, grid, garage, rider appearance and age restrictions.
- “First come first served” experience is not guaranteed access.
- Child age bands may differ for GA and VIP.
- Confirm processing fee at package checkout.
