# Event Playbook — Concerts & Festivals

## Verify
Exact city/date/venue, doors/show time, support act, standing/seated, stage map, age/height, ticket format, QR activation, transfer, resale warning and refund.

## Category ladder
GA/standing → reserved seating → Golden Circle/front standing → premium/platinum → VIP package → lounge/table/box/suite.

## Setlist
Do not promise exact songs. A likely setlist can be provided only as an explicitly labelled estimate based on recent shows, separate from guaranteed event facts.

## Advertising
Use clean map without face-value prices. Avoid fixed public price if inventory is volatile; quote live on request.
