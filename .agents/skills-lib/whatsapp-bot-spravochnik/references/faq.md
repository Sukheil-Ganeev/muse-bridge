# WhatsApp Bot / Business API — FAQ

## 1. Чем отличается WhatsApp Business App от WhatsApp Business API?

**WhatsApp Business App** — бесплатное мобильное приложение для малого бизнеса (1 устройство, ручные ответы, базовый каталог). **WhatsApp Business API (Cloud API)** — программный интерфейс для интеграции в системы: боты, автоматизация, массовые рассылки, CRM-интеграция, множество операторов.

## 2. Сколько стоит WhatsApp Cloud API?

Сам API бесплатный. Вы платите только за отправленные template-сообщения (per-message с июля 2025). Service-сообщения (ответы в 24ч окне) бесплатны. Цены зависят от страны получателя и категории (Marketing ~$0.15-0.18, Utility ~$0.08-0.12, Authentication ~$0.04-0.06 для UAE).

## 3. Нужен ли отдельный номер телефона?

Да. Номер для API **не должен** быть привязан к обычному WhatsApp или WhatsApp Business App. Если номер уже используется — нужно сначала удалить WhatsApp с этого номера. Meta также предоставляет тестовый номер для разработки.

## 4. Как получить Permanent Token (не истекающий)?

Создайте System User в Business Settings → Users → System Users. Назначьте ему права на приложение WhatsApp (`whatsapp_business_messaging`, `whatsapp_business_management`). Сгенерируйте токен — он не истекает, но показывается только один раз. Сохраните в `.env`.

## 5. Что такое Template Message и когда он нужен?

Template (HSM) — предварительно одобренный Meta шаблон сообщения. Нужен когда: 1) вы пишете клиенту первым, 2) прошло >24ч с последнего сообщения клиента, 3) массовые рассылки. В активном 24ч окне Templates не нужны — можно отправлять произвольные сообщения.

## 6. Сколько времени занимает одобрение Template?

Обычно от нескольких минут до 24 часов. Частые причины отказа: промо-контент в Utility-категории, отсутствие opt-out в Marketing-шаблонах, спам-слова (FREE!!!, BUY NOW!!!), слишком общий текст.

## 7. Что такое 24-часовое окно (Customer Service Window)?

Когда клиент пишет вам первым, открывается 24-часовое окно. В этом окне все ваши ответы **бесплатны** (категория Service). Каждое новое сообщение клиента обновляет окно ещё на 24 часа. После закрытия окна — нужен Template.

## 8. Что такое 72-часовое окно?

Если клиент пришёл через Click-to-WhatsApp рекламу (Facebook/Instagram), окно расширяется до 72 часов. Все сообщения бесплатны, включая Templates.

## 9. Можно ли использовать один номер для нескольких операторов?

Да. Cloud API позволяет подключить один номер к нескольким системам/операторам одновременно через webhook. Все сообщения приходят на один endpoint, маршрутизация — на вашей стороне.

## 10. Чем отличаются Reply Buttons от List Message?

**Reply Buttons** — до 3 кнопок, видны сразу, идеальны для да/нет/может быть. **List Message** — раскрывающийся список до 10 секций по 10 элементов, идеален для каталогов и больших меню. Оба типа бесплатны в 24ч окне.

## 11. Что такое WhatsApp Flows?

Многоэкранные интерактивные формы внутри WhatsApp. Клиент заполняет данные (TextInput, DatePicker, Dropdown и др.), не покидая чат. Используются для бронирования, регистрации, опросов, оформления заказов.

## 12. Нужна ли верификация бизнеса в Meta?

Для начала работы — нет (250 сообщений/день). Для повышения лимитов до 100K/день — да. Верификация требует: свидетельство о регистрации бизнеса, подтверждение адреса. Срок проверки: 1-5 рабочих дней.

## 13. Какие лимиты на количество сообщений?

С 2026: новый аккаунт — 250 уникальных получателей/24ч. После верификации бизнеса — сразу 100K/24ч (промежуточные уровни 1K и 10K убираются). Пропускная способность: 80 msg/sec (до 1000 msg/sec).

## 14. Можно ли отправлять сообщения на любой номер?

Нет. Для первого сообщения (business-initiated) нужен Template. Номер должен быть в WhatsApp. Клиент может заблокировать вас или пожаловаться на спам — это снижает Quality Rating.

## 15. Какие неофициальные библиотеки существуют и стоит ли их использовать?

Есть whatsapp-web.js, Baileys, venom-bot — все работают через WhatsApp Web API. **Категорически не рекомендуются для production:** нарушают Terms of Service Meta, риск перманентного бана номера, нестабильны, нет гарантий. Для production — только официальный Cloud API.
