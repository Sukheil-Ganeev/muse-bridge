# WhatsApp Bot / Business API — Troubleshooting

## 1. Webhook не проходит верификацию

**Симптом:** Meta возвращает ошибку при сохранении Callback URL.

**Причины и решения:**
- Verify Token в коде не совпадает с тем, что в App Dashboard → проверить точное совпадение строки
- Сервер не отвечает 200 OK с `hub.challenge` → убедиться, что GET `/webhook` возвращает `req.query['hub.challenge']` как plain text
- URL не HTTPS → Meta требует валидный SSL (Let's Encrypt подходит)
- Для локальной разработки: `npx ngrok http 3000` и использовать ngrok URL
- Firewall блокирует Meta IP → разрешить входящие от Meta (документация: developers.facebook.com)

## 2. Сообщения не доставляются (Error 131026)

**Симптом:** API возвращает 200 OK, но сообщение не приходит.

**Причины:**
- Номер получателя не зарегистрирован в WhatsApp → проверить номер
- Получатель заблокировал ваш номер → ничего не поделать
- Неверный формат номера → использовать международный формат без +, пробелов, дефисов (например: `971501234567`)
- Номер на тестовом аккаунте → тестовый номер может отправлять только на номера из whitelist

## 3. Template отклонён (Rejected)

**Симптом:** Шаблон в статусе Rejected после review.

**Частые причины:**
- Промо-контент в категории Utility → переместить в Marketing
- Нет opt-out возможности в Marketing → добавить "Reply STOP to unsubscribe" в footer
- Спам-слова: "FREE!!!", "BUY NOW!!!", "LIMITED TIME!!!" → переформулировать спокойнее
- Слишком общий текст ("You have a notification") → быть конкретнее
- Нарушение Commerce Policy → убрать запрещённый контент

**Решение:** Исправить текст и создать новый шаблон (редактировать отклонённый нельзя).

## 4. Quality Rating упал до Yellow/Red

**Симптом:** В WhatsApp Manager рейтинг качества снизился.

**Причины:**
- Много жалоб на спам (block/report) от получателей
- Низкий процент доставки
- Рассылка без контекста (cold outreach)

**Решения:**
- Прекратить массовые рассылки на время
- Отправлять только релевантный контент
- Использовать opt-in перед добавлением в рассылку
- Стимулировать ответы (Service-сообщения не влияют на рейтинг)
- Мониторить метрики в WhatsApp Manager → Analytics

## 5. Error 131047: Re-engagement message

**Симптом:** "This message was not delivered because the 24-hour window has expired."

**Решение:** 24ч окно закрыто. Отправить Template Message вместо обычного сообщения. Нельзя отправлять произвольные сообщения вне 24ч окна.

## 6. Error 130429: Rate limit hit

**Симптом:** Too many requests.

**Решения:**
- Реализовать exponential backoff: 1s → 2s → 4s → 8s
- Не превышать 80 msg/sec (default throughput)
- Для больших объёмов: дождаться автоматического апгрейда до 1000 msg/sec
- Проверить tier-лимит: не превышен ли лимит уникальных получателей за 24ч

## 7. Error 132000: Template parameter count mismatch

**Симптом:** Количество переданных параметров не совпадает с шаблоном.

**Решение:**
- Проверить количество `{{1}}`, `{{2}}` и т.д. в теле шаблона
- Убедиться, что `components.parameters` содержит точное число элементов
- Header может иметь свой параметр (media или text) — передавать в отдельном компоненте `type: "header"`

## 8. Webhook получает дубликаты сообщений

**Симптом:** Одно сообщение клиента обрабатывается несколько раз.

**Причины:**
- Сервер не отвечает 200 OK вовремя (<20 секунд) → Meta повторяет доставку
- Обработка блокирует ответ

**Решение:**
```javascript
app.post('/webhook', (req, res) => {
  res.sendStatus(200); // СРАЗУ ответить 200
  // Потом обработать асинхронно
  processAsync(req.body);
});
```
- Дедупликация по `message.id` — хранить ID обработанных сообщений в Redis/Map

## 9. Media (изображения/документы) не отправляются

**Симптом:** Error при отправке media-сообщений.

**Причины:**
- URL файла недоступен публично → Meta должен скачать файл по ссылке
- Размер превышает лимит (16 MB для видео/документов, 5 MB для изображений)
- Неподдерживаемый формат → изображения: JPEG/PNG, видео: MP4, аудио: OGG/Opus, документы: PDF/DOC
- HTTPS обязателен для URL media

**Альтернатива:** Загрузить media через Media API (`POST /PHONE_ID/media`) и использовать media_id вместо link.

## 10. Номер телефона не регистрируется (Error 133010)

**Симптом:** Phone number is not registered with WhatsApp Cloud API.

**Решения:**
- Убедиться, что номер добавлен в WhatsApp Manager
- Номер не должен быть в обычном WhatsApp → удалить WA с телефона перед регистрацией
- Верифицировать номер через SMS или звонок в App Dashboard
- Подождать 5-10 минут после регистрации

## 11. Webhook не получает сообщения

**Симптом:** Verification прошёл, но POST-запросы не приходят.

**Проверить:**
- Подписка на events: App Dashboard → WhatsApp → Configuration → Webhook Fields → включить `messages`
- Сервер доступен извне (проверить через curl с другого хоста)
- SSL сертификат валидный (не self-signed в production)
- Логировать ВСЕ входящие запросы для диагностики
- App не в Development Mode (для production нужен Live Mode)

## 12. Interactive Message не отображается у клиента

**Симптом:** Вместо кнопок/списка клиент видит обычный текст.

**Причины:**
- Старая версия WhatsApp у клиента → минимум WhatsApp 2.21.x
- Неверная структура JSON → проверить `interactive.type` ("button", "list", "product_list")
- Reply Buttons: максимум 3 кнопки, title до 20 символов
- List: button text обязателен, sections обязательны

## 13. Flow не запускается

**Симптом:** CTA кнопка отправлена, но Flow не открывается.

**Причины:**
- Flow не в статусе Published → опубликовать в WhatsApp Manager
- flow_id неверный → скопировать из WhatsApp Manager → Flows
- flow_message_version не совпадает → использовать "3"
- Клиент на старой версии WhatsApp → Flows требуют WA 2.23.x+

## 14. Error 368: Temporarily blocked for policies violation

**Симптом:** Аккаунт временно заблокирован.

**Причины:**
- Массовый спам
- Отправка запрещённого контента
- Много жалоб от пользователей

**Решение:**
- Прекратить все рассылки
- Проверить Quality Rating в WhatsApp Manager
- Подождать 24-72 часа (обычно разблокируется автоматически)
- Если повторяется — обратиться в Meta Support
- Пересмотреть стратегию рассылок

## 15. Utility Template классифицирован как Marketing

**Симптом:** Meta меняет категорию шаблона при review.

**Причины:**
- Текст содержит элементы промо (скидки, призыв к покупке)
- Кнопка ведёт на промо-страницу

**Решение:**
- Utility только для транзакционной информации: подтверждения, напоминания, статусы
- Убрать любые промо-элементы из текста
- Создать отдельный Marketing-шаблон для промо
