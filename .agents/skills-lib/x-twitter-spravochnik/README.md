# x-twitter-справочник

Production-ready руководство по X (Twitter) как платформе для туристического бизнеса ОАЭ.

## Структура

```
x-twitter-справочник/
├── SKILL.md              # Основной справочник (~4500 слов)
├── README.md             # Этот файл
└── references/
    ├── faq.md            # 15 частых вопросов
    ├── troubleshooting.md # 15 типичных проблем и решений
    └── cheatsheet.md     # Шпаргалка по API v2
```

## Что покрывает

- API v2 — все основные эндпоинты (посты, медиа, пользователи, поиск)
- Аутентификация — OAuth 2.0 PKCE, Bearer, OAuth 1.0a
- Тарифы API — Free/Basic/Pro/Enterprise + pay-per-use (2026)
- X Premium — Basic ($3) / Premium ($8) / Premium+ ($16-40)
- X Ads — форматы, таргетинг, бюджеты, средние CPC/CPM
- X Spaces — аудиокомнаты, API
- Аналитика — метрики постов, пользователей, engagement rate
- Embed/oEmbed — встраивание на сайты
- Контент-стратегия — хэштеги Дубая/ОАЭ, расписание, примеры постов
- Rate Limits — лимиты по тарифам и эндпоинтам

## Что НЕ покрывает

- Боты и автоматизация (Filtered Stream, DM automation) — см. `x-twitter-bot-справочник`
- Webhook-подписки на события
- Compliance endpoints

## Актуальность

Февраль 2026. Включает информацию о новой pay-per-use модели API.
