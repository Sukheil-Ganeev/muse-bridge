# X (Twitter) — FAQ (Часто задаваемые вопросы)

## 1. Чем X отличается от Twitter?

X — это ребрендинг Twitter, проведённый в июле 2023 Илоном Маском. Домен `twitter.com` редиректит на `x.com`. API по-прежнему работает на `api.x.com` (и `api.twitter.com` для legacy). Функционально — та же платформа с расширениями (Grok AI, длинные посты, Premium).

## 2. Какой тариф API выбрать для малого туристического бизнеса?

**Basic ($200/мес)** — оптимальный выбор. Позволяет читать 10 000 постов/мес и публиковать до 50 000. Если нужна только публикация без чтения — Free (1 500 постов/мес, write-only). С февраля 2026 доступна **pay-per-use** модель — платите только за фактические вызовы.

## 3. Нужен ли Premium для бизнес-аккаунта?

Да, рекомендуется минимум **Premium ($8/мес)**:
- Синяя галочка повышает доверие клиентов
- Охват постов в 6 раз выше (600 vs 100 показов)
- Возможность редактирования постов
- Доступ к расширенной аналитике

Для бренда с бюджетом — **Verified Organizations** ($200/мес) с золотой галочкой.

## 4. Как получить API ключи?

1. Зайти на https://developer.x.com/
2. Зарегистрировать Developer Account
3. Создать Project → App
4. Получить: API Key, API Secret, Bearer Token
5. Для OAuth 2.0 — настроить redirect URI и scopes

## 5. Можно ли публиковать на русском языке?

Да, X поддерживает все языки, включая русский. Для таргетинга русскоязычной аудитории используйте оператор `lang:ru` в поиске и геотаргетинг (Россия, Казахстан, Узбекистан) в рекламе. Хэштеги можно использовать на кириллице (#Дубай, #ОАЭ).

## 6. Сколько фото/видео можно прикрепить к посту?

- До 4 фото в одном посте
- 1 видео ИЛИ 1 GIF (но не вместе с фото)
- Видео: до 2 мин 20 сек (free), до 60 мин (Premium+)
- Фото: до 5 МБ (JPEG, PNG, WebP)
- Видео: до 512 МБ (MP4, H.264)

## 7. Как работает поиск по геолокации?

Используйте оператор `place:"Dubai"` или `place_country:AE` для фильтрации по стране. Также доступен `point_radius:[lon lat radius]` для поиска по координатам. Но учтите: геотегов мало, большинство пользователей не отмечают локацию.

## 8. Что такое X Spaces и зачем это туристическому бизнесу?

X Spaces — живые аудиокомнаты (аналог Clubhouse). Полезно для:
- Q&A сессий «Спроси о Дубае»
- Анонсов сезонных предложений
- Коллабораций с travel-блогерами
- Нетворкинга с агентами и партнёрами

Доступно с Premium+ или при 600+ подписчиках.

## 9. Как работает система верификации?

С 2023 года верификация (синяя галочка) доступна ТОЛЬКО через подписку Premium/Premium+. Бесплатных галочек больше нет. Организации получают золотую галочку через Verified Organizations ($200+/мес). Государственные аккаунты — серую галочку (бесплатно).

## 10. Какие хэштеги лучше использовать для туризма в ОАЭ?

**Обязательные:** #Dubai, #UAE, #VisitDubai, #MyDubai
**Тематические:** #DesertSafari, #BurjKhalifa, #DubaiTravel, #ExploreUAE
**Русскоязычные:** #Дубай, #ОАЭ, #ОтдыхвДубае
**Правило:** 2-3 хэштега на пост оптимально. Больше 5 — снижает вовлечение.

## 11. Чем X Ads отличается от рекламы в Instagram/Facebook?

- **Дешевле:** CPC $0.18-0.74 vs $1.41 (Meta)
- **Реальное время:** хорошо для событий, новостей, акций
- **Текстовый фокус:** лучше для информационного контента
- **Меньше визуала:** слабее для чисто визуальных продуктов
- **Аудитория:** больше B2B, tech-savvy, международная

## 12. Как измерить эффективность постов?

**Основные метрики:**
- Impressions (показы) — через non_public_metrics API
- Engagement Rate = (лайки + ретвиты + ответы) / показы * 100%
- Link clicks — через UTM-метки и non_public_metrics
- Conversions — через X Pixel на сайте

**Инструменты:** X Analytics (бесплатно), API metrics, сторонние (Hootsuite, Buffer).

## 13. Как отличается pay-per-use от фиксированных тарифов?

**Фиксированные:** платите $200 или $5000/мес вне зависимости от использования.
**Pay-per-use:** покупаете кредиты заранее, списываются за каждый вызов API. Разные эндпоинты стоят разное количество кредитов. Выгодно при нерегулярном использовании. Новичкам дают $10 ваучер.

## 14. Можно ли встроить посты X на свой сайт?

Да, через oEmbed API:
```
GET https://publish.x.com/oembed?url=https://x.com/user/status/123
```
Также доступен визуальный генератор на https://publish.x.com/. Поддерживает тёмную/светлую тему, настройку ширины, скрытие тредов.

## 15. Как бороться с ограничениями Rate Limit?

1. **Кэширование** — сохраняйте ответы API локально
2. **Batch-запросы** — GET /2/tweets принимает до 100 ID за раз
3. **Проверяйте заголовки** — `x-rate-limit-remaining` показывает остаток
4. **Exponential backoff** — при 429 ошибке ждите и повторяйте
5. **Повышайте тариф** — Basic → Pro при масштабировании
6. **Pay-per-use** — гибче при нерегулярных нагрузках
