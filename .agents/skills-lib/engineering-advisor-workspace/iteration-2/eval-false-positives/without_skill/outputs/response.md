## ЗАПРОС В — Объяснение функции

```python
def calculate_price(base, nights, pax, discount=0):
    return base * nights * pax * (1 - discount/100)
```

Функция считает итоговую стоимость для группы туристов с учётом скидки.

**Параметры:**
- `base` — базовая цена за одну ночь на одного человека
- `nights` — количество ночей
- `pax` — количество человек (passengers/participants)
- `discount` — скидка в процентах (по умолчанию 0, то есть без скидки)

**Что происходит внутри:**
1. `base * nights` — считает стоимость за весь период для одного человека
2. `* pax` — умножает на количество людей в группе
3. `* (1 - discount/100)` — применяет скидку. Например, при скидке 10% умножает на 0.9, что уменьшает сумму на 10%

**Пример:**
```python
calculate_price(base=100, nights=3, pax=2, discount=10)
# 100 * 3 * 2 * (1 - 10/100)
# = 600 * 0.9
# = 540.0
```

Итого: 2 человека на 3 ночи по 100 AED со скидкой 10% = **540 AED**.
