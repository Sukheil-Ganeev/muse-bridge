## Запрос В — Объяснение кода

**Запрос:** Объясни что делает эта функция:
```python
def calculate_price(base, nights, pax, discount=0):
    return base * nights * pax * (1 - discount/100)
```

### Решение: СКИЛЛ НЕ АКТИВИРОВАН

**Причина:** Прямое исключение из SKILL.md:
> "Поиск информации, объяснение кода, обучение — нет изменений в коде"

Запрос не предполагает Write/Edit операций. Никакие файлы не создаются и не редактируются. Это учебный запрос — объяснение существующего кода.

**Важно:** Триггер #3 ("Функция с бизнес-логикой — price, total, calculate") мог бы сработать при НАПИСАНИИ этой функции. Но при объяснении — исключение имеет приоритет.

### Выполнение запроса

Функция `calculate_price` вычисляет итоговую стоимость туристической услуги.

**Параметры:**
- `base` — базовая цена за одну ночь на одного человека (например, в AED)
- `nights` — количество ночей
- `pax` — количество человек (passengers/participants)
- `discount` — скидка в процентах (по умолчанию 0, то есть без скидки)

**Что делает:**
1. Умножает базовую цену на количество ночей и количество гостей — получает полную стоимость без скидки
2. Умножает результат на `(1 - discount/100)` — применяет процентную скидку

**Пример:**
```python
calculate_price(base=500, nights=3, pax=2, discount=10)
# 500 * 3 * 2 * (1 - 10/100)
# 3000 * 0.9
# = 2700 AED
```

**Потенциальные улучшения** (не критично, но стоит учитывать):
- Нет проверки на отрицательные значения (`nights < 0`, `pax < 0`, `discount > 100`)
- Нет округления — результат может быть дробным (2700.0 вместо 2700)
- Нет типизации — не понятно в какой валюте результат

Если эта функция будет использоваться в продакшн-коде для расчёта реальных цен — при НАПИСАНИИ тестов для неё сработает триггер #3 (Recommended: бизнес-логика с деньгами).
