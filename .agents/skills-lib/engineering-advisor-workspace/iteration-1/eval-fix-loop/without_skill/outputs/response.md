# Ответ на запрос пользователя

## Проблема

Ошибка `AttributeError: 'PipelineResult' object has no attribute 'text'` появляется снова потому, что ты правишь симптом, а не причину.

## Почему так происходит

Скорее всего одна из трёх ситуаций:

**1. Правка не сохраняется туда, где нужно**

Ты правишь `handlers.py`, но в проекте может быть несколько файлов с похожим кодом, или бот запускается из другой директории и берёт старую версию файла. Изменения применяются, но к другому файлу.

**2. `PipelineResult` не имеет атрибута `.text` — это правда**

Объект возвращает данные не через `.text`, а через что-то другое. Например:
- `.result`
- `.output`
- `.transcript`
- `.data`
- через словарь: `result["text"]`

Каждый раз когда ты "правишь" — ты, возможно, пишешь другое неправильное имя атрибута, и снова получаешь ту же ошибку.

**3. Конфликт версий или кэш**

Старый `.pyc` файл или неперезапущенный процесс бота продолжает работать со старым кодом.

## Как найти правильное имя атрибута

Добавь одну строку **перед** проблемной строкой:

```python
result = await pipeline.process(audio_file)
print(dir(result))        # покажет все доступные атрибуты
print(type(result))       # покажет тип объекта
response_text = result.text  # вот тут падает
```

Запусти бот, посмотри в логи — увидишь список атрибутов которые реально есть у объекта.

Либо так:

```python
result = await pipeline.process(audio_file)
print(result.__dict__)    # покажет все поля со значениями
```

## Быстрое решение

После того как найдёшь правильный атрибут — зафикси это в коде и добавь комментарий:

```python
result = await pipeline.process(audio_file)
# PipelineResult возвращает текст через .transcript (не .text!)
response_text = result.transcript
await bot.send_message(user_id, response_text)
```

Это не даст снова забыть почему именно такое название.

## Чтобы это не повторялось в четвёртый раз

Найди класс `PipelineResult` в коде (поиском по проекту) или в документации библиотеки и посмотри что он реально содержит. Правка "наугад" будет повторяться бесконечно.
