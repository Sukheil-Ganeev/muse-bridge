# Как переписать Telegram-бот с нуля: пошаговый подход

Хороший вопрос — и правильное желание. Когда handlers.py разрастается до 800 строк и функции вызывают друг друга хаотично, это классический признак того, что код "вырос из штанишек". Переписать с чистого листа — это не трусость, это инженерное решение.

Вот как это сделать без боли.

---

## Шаг 1: Не удаляй старый код сразу

Создай новую папку рядом — например `bot_v2/`. Старый бот продолжает работать, новый ты строишь параллельно. Когда новый готов — переключаешь токен и выключаешь старый.

Это страховка. Без неё ты окажешься в ситуации "ни то, ни другое не работает".

---

## Шаг 2: Определи, что вообще делает твой бот

Перед тем как писать код — напиши список команд и действий, которые бот поддерживает. Например:

- /start — приветствие
- /help — справка
- Кнопка "Купить" — показывает товары
- Кнопка "Назад" — возвращает в меню
- Получил текст — пересылает менеджеру

Это займёт 15 минут. Зато ты будешь знать, что именно писать заново — без лишнего.

---

## Шаг 3: Нормальная структура папок

Вот структура, которая масштабируется и не запутывает:

```
bot/
├── main.py              # Точка входа, запуск бота
├── config.py            # Токены, настройки из .env
├── handlers/
│   ├── __init__.py
│   ├── start.py         # /start, /help
│   ├── menu.py          # Главное меню и навигация
│   ├── orders.py        # Всё про заказы
│   └── admin.py         # Команды для администратора
├── keyboards/
│   ├── __init__.py
│   ├── main_menu.py     # Клавиатуры для главного меню
│   └── order.py         # Клавиатуры для заказов
├── services/
│   ├── __init__.py
│   └── database.py      # Работа с БД (если есть)
└── middlewares/
    └── auth.py          # Проверка прав (если нужна)
```

**Главное правило:** один файл = одна тема. handlers/orders.py знает только про заказы. Он не знает про клавиатуры — он их импортирует. Он не знает про БД — он вызывает services/.

---

## Шаг 4: Как регистрировать хендлеры

Вместо того чтобы всё регистрировать в одном месте, каждый модуль регистрирует сам себя:

```python
# handlers/start.py
from aiogram import Router

router = Router()

@router.message(Command("start"))
async def cmd_start(message: Message):
    await message.answer("Привет!")
```

```python
# main.py
from handlers import start, menu, orders

dp.include_router(start.router)
dp.include_router(menu.router)
dp.include_router(orders.router)
```

Всё. В main.py нет никакой логики — только подключение роутеров. Добавляешь новый раздел — создаёшь новый файл и одну строку в main.py.

---

## Шаг 5: Разделяй данные и отображение

Частая ошибка — смешивать логику и текст кнопок в одном месте:

```python
# Плохо — всё в одной куче
async def show_menu(message):
    kb = InlineKeyboardMarkup(inline_keyboard=[[
        InlineKeyboardButton(text="Купить", callback_data="buy")
    ]])
    await message.answer("Выбери действие:", reply_markup=kb)
```

```python
# Хорошо — клавиатура отдельно
# keyboards/main_menu.py
def get_main_menu():
    return InlineKeyboardMarkup(inline_keyboard=[[
        InlineKeyboardButton(text="Купить", callback_data="buy")
    ]])

# handlers/menu.py
from keyboards.main_menu import get_main_menu

async def show_menu(message):
    await message.answer("Выбери действие:", reply_markup=get_main_menu())
```

Теперь если нужно поменять текст кнопки — ты идёшь в keyboards/, а не ищешь по всему проекту.

---

## Шаг 6: Порядок переписывания

Не пиши всё сразу. Иди маленькими шагами:

1. Создай структуру папок и пустые файлы
2. Перенеси /start и /help — они простые, хороший старт
3. Убедись что бот запускается и эти команды работают
4. Перенеси следующий логический блок (меню)
5. Проверь
6. Следующий блок (заказы)
7. И так далее

Каждый шаг — рабочий бот. Никогда не ломай всё сразу.

---

## Что выбросить при переписывании

- Функции, которые никто не вызывает (проверь поиском по коду)
- Закомментированный код "на всякий случай" — у тебя будет git
- Дублирующиеся обработчики одного и того же события
- Глобальные переменные для хранения состояния — используй FSMContext из aiogram

---

## Итого: с чего начать прямо сейчас

1. Создай папку `bot_v2/`
2. Напиши список всего что делает бот (10-20 пунктов)
3. Создай структуру папок как выше
4. Напиши `main.py` и `config.py` — пустой каркас
5. Перенеси /start
6. Запусти — убедись что работает
7. Дальше по одному блоку

Это займёт не один день, но через неделю у тебя будет чистый бот, который ты сам понимаешь и можешь развивать.
