# Limo Order Manager

Скилл для управления лимузинными заказами MARSEL LUXURY CAR RENTAL.

## Структура
```
limo-order-manager/
├── SKILL.md           # Основной файл (прайсы, матрица, команды)
├── README.md          # Это файл
└── references/
    ├── faq.md         # FAQ
    └── cheatsheet.md  # Шпаргалка
```

## Данные
Все данные в `D:/MARSEL_BUSINESS/`:
- 2 партнёра (Раджа + TJ)
- 55 клиентов CRM
- 113 заказов
- B2B прайс-листы
- SOP и чек-листы

## Команды
- `/limo-order` — создать заказ
- `/limo-price` — калькулятор цены
- `/limo-partner` — подбор партнёра
- `/limo-client` — поиск клиента
- `/limo-report` — отчёт
