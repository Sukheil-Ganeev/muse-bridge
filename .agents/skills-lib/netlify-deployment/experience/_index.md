# Experience Index — Netlify Deployment

## 🎯 Критические уроки (топ-5)

> **ВАЖНО:** Читай эту секцию КАЖДЫЙ РАЗ при активации скилла!

### 1. Netlify Drop временный деплой имеет password protection
**Проблема:** После drag-and-drop деплоя сайт защищён паролем
**Решение:** Используй **GitHub Integration** для автоматического деплоя без пароля, или оплати Netlify Pro
**Когда важно:** При попытке поделиться ссылкой с клиентом

### 2. CORS ошибки при локальном просмотре HTML файлов
**Проблема:** `file://` протокол не поддерживает fetch() к внешним API
**Решение:** Используй `netlify dev` для локальной разработки или любой локальный сервер
**Когда важно:** При разработке с Google Sheets API

### 3. Redirects не работают для SPA без `_redirects` файла
**Проблема:** React/Vue роутинг возвращает 404 на прямых ссылках
**Решение:** Создай `public/_redirects` с правилом `/*    /index.html   200`
**Когда важно:** Любой SPA проект

### 4. Environment Variables не видны в браузере без префикса
**Проблема:** Переменные вроде `API_KEY` undefined в коде
**Решение:** Для клиентских переменных используй **Build Environment Variables** и включи их в билд
**Когда важно:** Использование API ключей в frontend коде

### 5. Serverless Functions требуют структуру `netlify/functions/`
**Проблема:** Functions не деплоятся если лежат в другой папке
**Решение:** Всегда используй `netlify/functions/` или настрой `functionsDirectory` в `netlify.toml`
**Когда важно:** Webhook обработка, API endpoints
