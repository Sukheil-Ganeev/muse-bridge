# Netlify Deployment — Справочник

Полный справочник по деплою на Netlify для туристического бизнеса и автоматизации.

## Структура

```
netlify-deployment/
├── SKILL.md                     # 📘 Основное руководство (1000-1500 строк)
├── README.md                    # 📍 Этот файл — навигация
├── marketplace.json             # ⚙️ Метаданные скилла
├── assets/
│   ├── templates/               # 📝 Готовые шаблоны для копирования
│   └── examples/                # 💡 Примеры проектов
├── references/                  # 📚 Справочники
│   ├── faq.md                   # ❓ Часто задаваемые вопросы
│   ├── troubleshooting.md       # 🔧 Решение проблем
│   ├── cheatsheet.md            # ⚡ Шпаргалка команд
│   ├── deployment-comparison.md # 📊 Drop vs GitHub vs CLI
│   ├── advanced-features.md     # 🚀 Продвинутые возможности
│   └── security-guide.md        # 🔒 Безопасность
├── scripts/                     # 🤖 Скрипты автоматизации
└── experience/                  # 📖 Накопленный опыт
    └── _index.md                # 🎯 Критические уроки (читать при активации!)
```

## Quick Start

### Для новичков
1. Читай **SKILL.md** → секция "Quick Start Guide"
2. Выбери метод деплоя (Drop / GitHub / CLI)
3. Следуй пошаговым инструкциям

### При проблемах
1. **references/troubleshooting.md** — 20+ типичных ошибок
2. **references/faq.md** — ответы на частые вопросы
3. **experience/_index.md** — уроки из реального опыта

### Для копирования
- **assets/templates/** — готовые файлы (netlify.toml, _redirects, functions)
- **assets/examples/** — полные примеры проектов
