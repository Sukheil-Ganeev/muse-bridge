## Формула приблизительного расчёта

```
Для CBR:
Размер (МБ) = битрейт (kbps) × длительность (сек) / 8 / 1024

Пример: 6000 kbps × 3600 сек (1 час) / 8 / 1024 = 2636 МБ ≈ 2.6 ГБ

Для CRF/CQP:
Размер зависит от контента. Статичный экран с текстом — меньше.
Быстрое движение, яркие цвета — больше.
Ориентируйся на таблицы выше.
```
