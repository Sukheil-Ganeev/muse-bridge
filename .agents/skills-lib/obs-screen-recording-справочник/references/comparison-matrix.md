## Профили программ

### OBS Studio

**Тип:** Профессиональная система записи и стриминга с открытым исходным кодом.

Самый мощный бесплатный инструмент. Поддерживает любые сценарии: от простого захвата экрана до многокамерных стримов. Огромная экосистема плагинов. Требует начальной настройки, но даёт полный контроль. Мощные аудиофильтры (Noise Gate, Compressor, RNNoise). Кроссплатформенный. Формат MKV защищает от потери данных при сбое.

**Сильные стороны:** полный контроль, плагины, бесплатность, сообщество, стабильность.
**Слабые стороны:** нет встроенного редактора, требует настройки, интерфейс может пугать новичков.

---

### Streamlabs

**Тип:** Стриминг-платформа на базе OBS с упрощённым интерфейсом.

Форк OBS с добавленными виджетами, темами и интеграцией с донатами. Проще в настройке для стримеров. Ultra-подписка даёт доступ к облаку, мультистримингу и расширенным функциям. Больше потребляет ресурсов чем OBS из-за встроенных виджетов.

**Сильные стороны:** готовые темы, виджеты донатов, проще для стримеров-новичков.
**Слабые стороны:** тяжелее OBS, меньше плагинов, Ultra подписка дорогая, нет Linux.

---

### Bandicam

**Тип:** Лёгкий рекордер с минимальной нагрузкой на систему.

Один из самых лёгких рекордеров. Отлично подходит для записи игр и приложений с DirectX/OpenGL. Простой интерфейс. Поддерживает запись в 4K при 480 FPS (для замедленного видео). Бесплатная версия ограничена 10 минутами и ставит водяной знак.

**Сильные стороны:** минимальная нагрузка, простота, высокий FPS для замедленной съёмки.
**Слабые стороны:** только Windows, водяной знак в бесплатной версии, нет стриминга, ограниченные форматы.

---

### Camtasia

**Тип:** Комбайн для записи экрана и редактирования видео.

Профессиональный инструмент «два в одном»: запись + полноценный видеоредактор. Идеален для создания обучающих видео и курсов. Включает библиотеку эффектов, переходов, аннотаций и шаблонов. Дорогой, но заменяет связку OBS + видеоредактор.

**Сильные стороны:** встроенный редактор, шаблоны, аннотации, идеален для обучающего контента.
**Слабые стороны:** дорогой ($313), тяжёлый, не для стриминга, ограниченные кодеки.

---

### ShareX

**Тип:** Универсальный инструмент захвата с автоматизацией.

Больше, чем просто запись экрана — это комбайн для скриншотов, GIF, записи видео, OCR, загрузки в облако. Мощные workflow и автоматизация. Запись видео — не основная функция, но работает достойно. Полностью бесплатный и с открытым кодом.

**Сильные стороны:** автоматизация, скриншоты, GIF, OCR, загрузка в облако, бесплатный.
**Слабые стороны:** только Windows, запись видео — не основной фокус, сложный интерфейс, нет аудиофильтров.

---

### Xbox Game Bar

**Тип:** Встроенный в Windows рекордер для игр.

Самый простой способ записать экран на Windows 10/11. Нажал Win+G — записываешь. Не требует установки. Работает через аппаратное ускорение. Ограничен по настройкам: нет выбора кодека, нет аудиофильтров, нет захвата рабочего стола (только приложения/игры).

**Сильные стороны:** уже установлен, элементарно прост, минимальная нагрузка.
**Слабые стороны:** нельзя записать рабочий стол, минимум настроек, только MP4, нет стриминга, только Windows.

---

### NVIDIA ShadowPlay (GeForce Experience)

**Тип:** Аппаратный рекордер от NVIDIA с мгновенным повтором.

Использует выделенный блок NVENC на видеокарте — практически нулевая нагрузка на систему. Уникальная функция Instant Replay: постоянно записывает последние N минут, можно сохранить интересный момент задним числом. Поддержка AV1 на RTX 40-серии.

**Сильные стороны:** нулевое влияние на FPS, Instant Replay, простота, поддержка 8K.
**Слабые стороны:** только NVIDIA GPU, минимум настроек, нет сцен/источников, базовые возможности.

---

### ScreenPal (ранее Screencast-O-Matic)

**Тип:** Простой онлайн-рекордер для обучения и бизнеса.

Ориентирован на быструю запись экрана для обучения и корпоративных нужд. Встроенный редактор достаточно функционален. Облачное хранение для простого шаринга. Работает через браузер или десктопное приложение.

**Сильные стороны:** простота, облако, встроенный редактор, кроссплатформенный.
**Слабые стороны:** ограничения в бесплатной версии, нет GPU-ускорения, не для геймеров.

---

### Loom

**Тип:** Облачный рекордер для быстрых видеосообщений.

Создан для бизнес-коммуникации: записал экран + камеру, получил ссылку, отправил коллегам. Мгновенная обработка в облаке. Интеграции с Slack, Notion, Gmail. Не подходит для длинных записей или высокого качества. Бесплатный план ограничен 25 видео по 5 минут.

**Сильные стороны:** мгновенный шаринг, интеграции, транскрипция, простота.
**Слабые стороны:** зависимость от интернета, ограничения бесплатного плана, низкое качество записи, нет оффлайн-режима.

---

### FFmpeg

**Тип:** Командная утилита для обработки мультимедиа.

Не программа с интерфейсом, а мощнейший CLI-инструмент. Может записывать экран, но основное применение — конвертация, обработка и стриминг. Поддерживает абсолютно все кодеки и форматы. Используется как бэкенд во многих других программах (включая OBS).

**Сильные стороны:** абсолютная гибкость, все кодеки и форматы, скриптуемость, бесплатный.
**Слабые стороны:** только командная строка, крутая кривая обучения, нет GUI, не для обычных пользователей.
