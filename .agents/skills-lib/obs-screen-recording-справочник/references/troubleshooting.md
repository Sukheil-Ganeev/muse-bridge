# Troubleshooting — Решение проблем OBS

## 1. Чёрный экран при записи (Display Capture не работает)

**Симптом:** При добавлении источника Display Capture в OBS виден только чёрный экран, хотя рабочий стол отображается нормально.

**Причина:** На компьютерах с двумя видеокартами (встроенная Intel + дискретная NVIDIA/AMD) OBS может запускаться на одном GPU, а рабочий стол рендерится на другом. Windows также может блокировать захват экрана из-за настроек графики. В Windows 11 метод захвата по умолчанию может быть несовместим с вашей конфигурацией.

**Решение:**
1. Правый клик по ярлыку OBS → **Запустить с графическим процессором** → выберите тот же GPU, на котором работает монитор (обычно NVIDIA).
2. Или: Windows Параметры → Система → Дисплей → Графика → найдите OBS Studio → Настройки → выберите **Высокая производительность** (дискретная GPU).
3. В OBS: Источники → Display Capture → Свойства → **Метод захвата**: попробуйте переключить между «Автоматический», «DXGI», «Windows 10 (1903+)».
4. Если используете ноутбук с NVIDIA Optimus — откройте **NVIDIA Control Panel** → Manage 3D Settings → Program Settings → добавьте obs64.exe → выберите «High-performance NVIDIA processor».
5. Попробуйте запустить OBS **от имени администратора** (правый клик → Запуск от имени администратора).
6. Если ничего не помогло — используйте **Window Capture** или **Game Capture** вместо Display Capture. Window Capture обычно не имеет проблемы с чёрным экраном.

## 2. Рассинхрон аудио и видео

**Симптом:** Звук отстаёт от видео или опережает его. Губы не совпадают с речью, звук клика мыши приходит раньше или позже визуального нажатия.

**Причина:** Разные устройства аудио и видео захватываются с разной задержкой. USB-микрофоны и аудиоинтерфейсы могут добавлять латентность. Также проблему может вызвать перегруженный CPU, который не успевает обрабатывать оба потока синхронно.

**Решение:**
1. Откройте **Расширенные свойства аудио**: в микшере нажмите на шестерёнку → Расширенные свойства аудио.
2. Для проблемного аудиоисточника (микрофон или desktop audio) добавьте **смещение синхронизации** (Sync Offset). Начните с 50-100 мс и подбирайте экспериментально.
3. Запишите тестовый клип с хлопком в ладоши перед камерой или щелчком по экрану — так легко увидеть рассинхрон.
4. Настройки → Вывод → Расширенный → проверьте, что **аудио-семплрейт** (Частота дискретизации) одинаков в OBS (Настройки → Аудио → Частота дискретизации) и в системных настройках звука Windows (обычно 48 kHz).
5. Правый клик по динамику в трее Windows → Звуки → Свойства устройства → Дополнительно → частота должна совпадать с OBS (48000 Hz).
6. Если проблема появляется только на длинных записях (2+ часа) — обновите OBS до последней версии, в старых версиях был баг с дрифтом аудио на длинных сессиях.

## 3. Высокая нагрузка CPU (100%) во время записи

**Симптом:** Процессор загружен на 90-100% при записи, система тормозит, курсор дёргается, приложения не отвечают.

**Причина:** Использование программного кодировщика x264 с тяжёлым пресетом (slow, medium) при недостаточно мощном процессоре. Также высокое разрешение (4K) или FPS (60) на слабом CPU.

**Решение:**
1. **Переключитесь на аппаратный энкодер:** Настройки → Вывод → Расширенный → Энкодер: выберите **NVENC H.264** (NVIDIA) или **H264/AVC Encoder (AMD)** вместо x264. Это перенесёт нагрузку с CPU на GPU.
2. Если аппаратный энкодер недоступен — в настройках x264 измените **Preset** на **veryfast** или **ultrafast**. Качество немного снизится, но нагрузка упадёт в 3-5 раз.
3. Понизьте **разрешение записи**: Настройки → Видео → Выходное разрешение → 1920x1080 (если было выше). Масштабирование уменьшит нагрузку.
4. Снизьте **FPS** с 60 до 30 — нагрузка уменьшится почти вдвое.
5. Закройте ненужные программы и вкладки браузера (Chrome с 30 вкладками потребляет гигабайты RAM и загружает CPU).
6. Проверьте **Приоритет процесса** OBS: Настройки → Расширенные → Приоритет процесса → **Выше нормального** (но не Высокий, чтобы не мешать другим процессам).
7. Если записываете игру — используйте **Game Capture** вместо Display Capture. Game Capture потребляет меньше ресурсов.

## 4. Запись прерывается или зависает

**Симптом:** Запись неожиданно останавливается через какое-то время. OBS показывает ошибку или просто перестаёт писать. Индикатор записи может зависнуть.

**Причина:** Недостаточно места на диске, запись на медленный HDD (не успевает записывать данные), перегрев компонентов, конфликт с антивирусом или другим ПО, ошибка драйвера GPU.

**Решение:**
1. **Проверьте свободное место на диске:** убедитесь, что на диске, куда пишется запись, есть минимум 20-50 ГБ свободного места. OBS может прервать запись, когда место заканчивается.
2. **Записывайте на SSD**, а не HDD. HDD может не успевать записывать поток данных, особенно при высоком битрейте (20+ Mbps). SSD справляется без проблем.
3. Добавьте OBS в **исключения антивируса** (Windows Defender, Kaspersky, ESET и т.д.). Антивирус может блокировать запись файла.
4. **Обновите драйверы GPU** до последней версии с официального сайта NVIDIA/AMD (не через Windows Update).
5. Проверьте **температуру** CPU и GPU во время записи (HWMonitor, MSI Afterburner). Перегрев (CPU > 95°C, GPU > 90°C) может вызывать троттлинг и зависания.
6. Откройте логи OBS: **Справка → Файлы журналов → Показать последний** — там будет указана причина остановки.
7. Попробуйте **понизить битрейт** или переключиться на CQP с более высоким значением (22-25) — это уменьшит объём данных, записываемых на диск.

## 5. Нет звука в записи (desktop audio)

**Симптом:** Запись видео работает, но в итоговом файле нет звука с рабочего стола (музыка, звуки системы, звук из браузера). Микрофон при этом может записываться нормально.

**Причина:** Неверно выбрано устройство Desktop Audio в настройках OBS, аудиодрайвер не поддерживает захват, конфликт с внешними аудиоустройствами (наушники с USB-DAC, HDMI-аудио).

**Решение:**
1. Настройки → **Аудио** → Устройство аудио рабочего стола (Desktop Audio) → убедитесь, что выбрано **По умолчанию** или конкретное устройство, через которое воспроизводится звук.
2. Проверьте в **микшере OBS** (нижняя панель): столбик «Desktop Audio» должен двигаться, когда играет музыка или звук с рабочего стола. Если нет — устройство выбрано неверно.
3. Правый клик по значку динамика в трее Windows → **Параметры звука** → проверьте, какое устройство вывода используется по умолчанию. Оно должно совпадать с настройкой Desktop Audio в OBS.
4. Если используете **аудиоинтерфейс или внешний DAC** — некоторые устройства не поддерживают loopback-захват. Решение: выберите конкретное устройство вместо «По умолчанию» или добавьте **источник «Захват выходного аудиопотока (WASAPI)»** вручную.
5. Перезапустите OBS после смены аудиоустройства.
6. Убедитесь, что Desktop Audio **не замучен** (не нажата кнопка динамика в микшере OBS) и громкость не на нуле.

## 6. Микрофон не записывается

**Симптом:** В записи нет звука с микрофона, хотя в Windows микрофон работает (Skype, Discord слышат). В микшере OBS столбик Mic/Aux не двигается.

**Причина:** Микрофон не выбран в настройках OBS, Windows заблокировал доступ к микрофону для OBS, микрофон замучен в микшере, неверный аудиоканал.

**Решение:**
1. Настройки → **Аудио** → Микрофон/Дополнительное аудио (Mic/Auxiliary Audio) → выберите ваш микрофон из списка (не «По умолчанию», а конкретное устройство).
2. Проверьте **доступ к микрофону** в Windows: Параметры → Конфиденциальность → Микрофон → включите «Разрешить приложениям доступ к микрофону» → убедитесь, что OBS Studio разрешён доступ (или включите для всех десктопных приложений).
3. В **микшере OBS** (нижняя панель) проверьте: столбик Mic/Aux — не замучен ли (кликните на значок динамика, если перечёркнут), громкость не на нуле.
4. Правый клик на Mic/Aux в микшере → **Расширенные свойства аудио** → проверьте, что аудиодорожки активированы (галочки на нужных треках).
5. Если микрофон USB — попробуйте переключить в другой USB-порт. Избегайте USB-хабов, подключайте напрямую к материнской плате.
6. Откройте **Windows Звуки** (правый клик по динамику в трее → Звуки → Запись) → проверьте, что ваш микрофон активен и установлен как устройство по умолчанию. Говорите в микрофон — полоска уровня должна двигаться.
7. Перезапустите OBS (полностью закройте и откройте заново) после всех изменений.

## 7. Файл MP4 повреждён после краша OBS

**Симптом:** OBS неожиданно закрылся (краш, BSOD, отключение питания), файл записи в формате MP4 не воспроизводится. Плеер показывает ошибку или чёрный экран с нулевой длительностью.

**Причина:** MP4 записывает метаданные и индексную таблицу (moov atom) в конец файла при финализации. Если запись прервалась аварийно, эта таблица не была записана, и файл считается повреждённым.

**Решение:**
1. **Попробуйте утилиту untrunc:**
   - Скачайте untrunc (https://github.com/anthwlock/untrunc).
   - Вам нужен «рабочий» MP4-файл, записанный с теми же настройками OBS (тот же кодек, разрешение, FPS). Запишите короткий тестовый файл.
   - Выполните команду: `untrunc reference_good.mp4 broken_file.mp4`
   - Утилита восстановит индексную таблицу на основе рабочего файла.

2. **FFmpeg (альтернативный метод):**
   ```bash
   ffmpeg -i broken.mp4 -c copy recovered.mkv
   ```
   Иногда FFmpeg может прочитать данные без полного индекса и сохранить в MKV.

3. **VLC Media Player:**
   - Откройте VLC → Медиа → Конвертировать/Сохранить → выберите повреждённый файл.
   - VLC попытается восстановить индекс и сконвертировать файл. Результат не гарантирован.

4. **Recover MP4 (онлайн-сервис):**
   - Сайт restore.media или mp4repair.org — загрузите повреждённый файл и рабочий образец.

**Предотвращение на будущее:**
- Переключитесь на формат **MKV** или **Fragmented MP4** (fMP4) — они устойчивы к крашам.
- Настройки → Вывод → Формат записи → **MKV**. После записи ремуксируйте в MP4: Файл → Ремультиплексирование записей.

## 8. Низкое качество записи (размытость, артефакты)

**Симптом:** Записанное видео выглядит размытым, текст плохо читается, видны блочные артефакты (особенно при движении), пиксели «рассыпаются» на границах объектов.

**Причина:** Слишком низкий битрейт или высокое значение CRF/CQP, неверное выходное разрешение, масштабирование с использованием некачественного фильтра, энкодер настроен в режиме CBR с недостаточным битрейтом.

**Решение:**
1. **Увеличьте качество кодирования:**
   - Для NVENC: Настройки → Вывод → Расширенный → Управление битрейтом: **CQP** → Значение: **18-20** (ниже число = выше качество).
   - Для x264: CRF **18-20**.
   - Если используете CBR — увеличьте битрейт до **15000-25000 Kbps** для 1080p.

2. **Проверьте разрешение:** Настройки → Видео:
   - Базовое разрешение: должно совпадать с разрешением вашего монитора (например, 1920x1080).
   - Выходное разрешение: **не уменьшайте** для записи (оставьте 1920x1080). Уменьшение = потеря чёткости текста.

3. **Фильтр масштабирования:** если выходное разрешение отличается от базового, выберите фильтр **Lanczos** (лучшее качество) вместо Bilinear.

4. **Пресет энкодера:** для NVENC используйте **P5 (Slow)** или **Max Quality** — улучшает качество при том же битрейте. Для x264: preset **slow** или **medium**.

5. **Профиль:** установите **High** (не Baseline или Main) — это разрешает энкодеру использовать продвинутые методы сжатия.

6. Убедитесь, что OBS записывает в **полном разрешении** — иногда окно предпросмотра OBS показывает уменьшенное изображение, но запись идёт в полном качестве. Проверьте итоговый файл.

## 9. Лаги/фризы в записанном видео

**Симптом:** Записанное видео воспроизводится рывками — изображение периодически застывает на доли секунды, затем «догоняет». В реальном времени экран работал плавно.

**Причина:** OBS пропускает кадры (dropped frames) из-за перегрузки системы — CPU или GPU не успевают кодировать в реальном времени, либо диск не успевает записывать данные.

**Решение:**
1. Проверьте **статистику OBS** во время записи: Вид → Статистика. Обратите внимание на:
   - **Пропущенные кадры (рендеринг)** — проблема GPU. Уменьшите нагрузку на видеокарту.
   - **Пропущенные кадры (кодирование)** — проблема CPU/энкодера. Переключитесь на более лёгкий энкодер или preset.
   - **Пропущенные кадры (вывод)** — проблема диска. Записывайте на SSD.

2. **Переключитесь на NVENC** с x264 — аппаратный энкодер пропускает кадры значительно реже.

3. **Понизьте FPS** с 60 до 30 — вдвое меньше кадров для кодирования.

4. **Записывайте на SSD.** Если запись идёт на HDD, при битрейте выше 15 Mbps диск может не успевать. SSD решает эту проблему полностью.

5. Закройте **фоновые процессы:** Chrome, Discord overlay, другие программы записи/стриминга, торренты — всё, что потребляет ресурсы.

6. В **NVIDIA Control Panel** → Manage 3D Settings → Power management mode → **Prefer maximum performance** (для obs64.exe).

7. Если лаги только в конкретном приложении (игра) — используйте **Game Capture** вместо Display Capture. Game Capture работает эффективнее с DirectX/Vulkan.

## 10. OBS не видит GPU (NVENC недоступен)

**Симптом:** В настройках энкодера нет варианта NVENC (или AMD AMF). Доступен только x264 (программный кодировщик).

**Причина:** Устаревшие или неустановленные драйверы видеокарты, видеокарта не поддерживает аппаратное кодирование, OBS запускается на встроенной графике вместо дискретной, несовместимая версия OBS.

**Решение:**
1. **Обновите драйверы GPU** до последней версии:
   - NVIDIA: https://www.nvidia.com/drivers → скачайте Game Ready или Studio Driver.
   - AMD: https://www.amd.com/en/support → AMD Software: Adrenalin Edition.
   - Важно: используйте чистую установку (Custom → Clean Install).

2. **Проверьте совместимость видеокарты:**
   - NVENC требует NVIDIA GTX 600-й серии или новее (Kepler+). Для полной поддержки OBS рекомендуется GTX 1650+.
   - AMF требует AMD GCN-архитектуру или новее.
   - Встроенная графика Intel поддерживает **QuickSync** (не NVENC) — это тоже аппаратный энкодер.

3. **Назначьте OBS на дискретную GPU:**
   - Windows: Параметры → Система → Дисплей → Графика → OBS Studio → Высокая производительность.
   - NVIDIA Control Panel → Manage 3D Settings → Program Settings → obs64.exe → High-performance NVIDIA processor.

4. **Переустановите OBS** — иногда помогает при повреждении конфигурации.

5. Проверьте, что в системе установлен **Visual C++ Redistributable** 2019/2022 — OBS и NVENC требуют эту библиотеку.

6. Если всё ещё не работает — откройте OBS → Справка → Файлы журналов → Загрузить последний → проанализируйте лог (или выложите на форум OBS для помощи).

## 11. Запись занимает слишком много места

**Симптом:** Файлы записи получаются огромными — час записи занимает 20-50 ГБ или более, диск быстро заполняется.

**Причина:** Слишком высокий битрейт, режим Lossless или Near-Lossless (CQP 0-10), запись в несжатом формате, неоправданно высокое разрешение или FPS.

**Решение:**
1. **Переключитесь на CQP/CRF режим** вместо CBR с высоким битрейтом:
   - NVENC: Управление битрейтом → CQP → Значение: **20-22** (для экрана этого достаточно).
   - x264: CRF → Значение: **20-23**.
   - Это даст динамический битрейт: на статичных сценах файл будет маленьким.

2. **Проверьте, не установлен ли Lossless:** если CQP = 0 или включён режим Lossless — файлы будут огромными. Поставьте CQP 18-22.

3. **Используйте HEVC (H.265)** вместо H.264 — экономия 30-50% места при том же визуальном качестве:
   - Энкодер: NVIDIA NVENC HEVC (или AMD HEVC).
   - Примечание: HEVC может быть несовместим с некоторыми старыми плеерами и редакторами.

4. **Понизьте FPS до 30** (если было 60) — размер файла уменьшится почти вдвое.

5. **Не записывайте в 4K**, если публикуете в 1080p. Установите выходное разрешение 1920x1080.

6. **Аудио:** проверьте настройки аудио-битрейта. Для записи речи достаточно 128-160 Kbps AAC. Если стоит 320 Kbps на 6 аудиодорожках — это лишние мегабайты.

7. Если нужны маленькие файлы для быстрой отправки — после записи пережмите через **HandBrake** в H.265 RF 22. Файл уменьшится в 3-5 раз с минимальными потерями.

## 12. Game Capture не захватывает игру

**Симптом:** Добавлен источник Game Capture, но вместо игры чёрный экран. Игра работает, но OBS её не видит.

**Причина:** Игра использует несовместимый API рендеринга, античит блокирует захват, OBS и игра запущены с разными правами (admin/user), игра в оконном режиме без рамки не перехватывается стандартным методом.

**Решение:**
1. **Запустите OBS от имени администратора** (правый клик → Запуск от имени администратора). Если игра запущена от имени администратора, OBS тоже должен быть.

2. В свойствах Game Capture:
   - Режим: попробуйте **«Захват определённого окна»** вместо «Захват любого полноэкранного приложения».
   - Выберите процесс игры из списка.
   - Поставьте галочку **«Режим захвата SLI/Crossfire»** (иногда помогает даже без SLI).

3. **Проверьте совместимость античита:**
   - Игры с EAC (Easy Anti-Cheat) и BattlEye могут блокировать Game Capture.
   - Решение: используйте **Display Capture** или **Window Capture** вместо Game Capture.

4. **Отключите оверлеи:** Discord Overlay, Steam Overlay, GeForce Experience Overlay — они конфликтуют с Game Capture. Отключите все оверлеи и попробуйте снова.

5. Для игр на **Vulkan** (DOOM, CS2): в свойствах Game Capture поставьте галочку **«Разрешить прозрачность»** и убедитесь, что OBS обновлён до последней версии (поддержка Vulkan улучшается с каждым обновлением).

6. **Запустите игру после OBS** — Game Capture лучше подключается, если OBS уже запущен к моменту запуска игры.

7. Если ничего не помогает — используйте **Display Capture** как fallback. Качество аналогичное, но чуть выше нагрузка.

## 13. Звук микрофона с эхом или фоном

**Симптом:** В записи слышен фоновый шум (гул вентилятора, шум улицы), эхо от динамиков, гулкость помещения, или микрофон ловит звук из наушников/колонок.

**Причина:** Отсутствие аудиофильтров в OBS, микрофон подхватывает звук из динамиков (если нет наушников), плохая акустика помещения, высокая чувствительность микрофона.

**Решение:**
1. **Используйте наушники** во время записи — это полностью устранит эхо от динамиков.

2. **Добавьте фильтры на микрофон** (правый клик на микрофон в микшере → Фильтры):
   - **Шумоподавление (RNNoise):** нейросетевой фильтр, отлично убирает постоянный фоновый шум (вентилятор, кондиционер, шум электроники). Добавьте первым в цепочке.
   - **Noise Gate:** установите порог закрытия -35 дБ, порог открытия -30 дБ. Когда вы не говорите, микрофон будет полностью заглушён.
   - **Компрессор:** Ratio 4:1, Threshold -20 дБ — выровняет громкость и уменьшит «пики».

3. **Уменьшите чувствительность микрофона:**
   - В микшере OBS — ползунком понизьте громкость Mic/Aux.
   - В Windows: Параметры звука → Свойства микрофона → Уровни → понизьте до 60-80%.

4. **Расположение микрофона:** расстояние 15-25 см от рта. Слишком далеко = больше фонового шума. Слишком близко = «бубнение» и plosives (взрывные согласные «п», «б»).

5. **Улучшите акустику:** повесьте за микрофоном мягкую ткань или поставьте акустический экран. Даже обычное полотенце, сложенное за микрофоном, уменьшает отражения.

6. Если фон всё равно сильный — попробуйте внешний VST-плагин **ReaFir** (бесплатный от Reaper): OBS поддерживает VST через фильтры.

## 14. OBS потребляет много оперативной памяти

**Симптом:** OBS использует 2-4 ГБ оперативной памяти или более. Система начинает свопить, другие приложения тормозят. Потребление RAM растёт со временем записи.

**Причина:** Большое количество источников (особенно изображения высокого разрешения и браузерные источники), утечки памяти в плагинах, множество сцен с уникальными источниками, буферизация при записи.

**Решение:**
1. **Удалите или отключите неиспользуемые источники и сцены.** Каждый источник потребляет память, даже если сцена не активна. Правый клик на источник → «Скрыть» или удалить.

2. **Оптимизируйте изображения-оверлеи:**
   - Если у вас изображения 4000x4000 пикселей, а отображаются они как 200x200 — уменьшите исходный файл до нужного размера.
   - Используйте PNG только если нужна прозрачность, иначе JPEG меньше по памяти.

3. **Браузерные источники (Browser Source):**
   - Каждый Browser Source — это отдельный процесс Chromium, потребляющий 100-300 МБ.
   - Уменьшите количество Browser Source до минимума.
   - Поставьте галочку «Завершать, когда не видим» — браузер выгрузится из памяти, когда сцена неактивна.

4. **Проверьте плагины:** отключите сторонние плагины по одному, чтобы найти тот, который утекает по памяти. Частые виновники: старые версии StreamFX, Move Transition, устаревшие плагины.

5. **Обновите OBS** до последней версии — разработчики регулярно исправляют утечки памяти.

6. **Периодически перезапускайте OBS** при длинных сессиях записи (4+ часов). Сохраните запись, перезапустите OBS, начните новую запись.

7. Если RAM всего 8 ГБ — рассмотрите увеличение до 16 ГБ. OBS + браузер + записываемое приложение легко потребляют 10-12 ГБ вместе.

## 15. Запись не начинается (ошибка при старте)

**Симптом:** При нажатии «Начать запись» OBS выдаёт ошибку (например, «Не удалось начать запись», «Failed to start recording», «Error opening output»). Индикатор записи не загорается.

**Причина:** Невалидный путь сохранения, недостаточно прав для записи в указанную папку, конфликт формата и кодека, файл с таким именем уже открыт другой программой, ошибка инициализации энкодера.

**Решение:**
1. **Проверьте путь сохранения:** Настройки → Вывод → Путь записи. Убедитесь, что папка существует и доступна для записи. Попробуйте простой путь: `D:\OBS_Recordings` (без пробелов, кириллицы и спецсимволов).

2. **Создайте папку вручную:** если указанная папка не существует, OBS может не создать её автоматически. Создайте папку через проводник.

3. **Проверьте права доступа:**
   - Запустите OBS от имени администратора.
   - Убедитесь, что ваш пользователь имеет права записи в целевую папку (правый клик на папку → Свойства → Безопасность).

4. **Проверьте формат и кодек:**
   - Некоторые комбинации формата и кодека несовместимы. Например, AV1 в контейнере FLV не поддерживается.
   - Сбросьте на проверенную конфигурацию: формат MKV, кодек NVENC H.264, CQP 20.

5. **Проверьте свободное место на диске:** если на целевом диске менее 1 ГБ свободного места, запись не начнётся.

6. **Переустановите энкодер:**
   - Если ошибка связана с NVENC — переустановите драйверы NVIDIA (чистая установка).
   - Если ошибка с x264 — переустановите OBS.

7. **Посмотрите лог:** Справка → Файлы журналов → Показать последний. Найдите строку с «Error» или «Failed» — там будет конкретная причина. Частые ошибки:
   - `Output path does not exist` — путь не найден.
   - `Encoder initialization failed` — проблема с энкодером (драйвер или настройки).
   - `Could not open output file` — файл заблокирован или папка недоступна.

8. **Сбросьте настройки OBS:** если ничего не помогает — Файл → Показать папку настроек → закройте OBS → переименуйте папку (для бэкапа) → запустите OBS — настройки сбросятся на заводские.
