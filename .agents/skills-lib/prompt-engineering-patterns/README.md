# prompt-engineering-patterns

## Описание
Продвинутые техники промпт-инжиниринга для максимизации производительности, надёжности и управляемости LLM в продакшене. Используется при оптимизации промптов, улучшении выходных данных LLM или создании production-ready шаблонов.

## Структура
```
prompt-engineering-patterns/
├── SKILL.md              # Основной файл
├── README.md             # Этот файл
└── references/
    ├── faq.md            # Часто задаваемые вопросы
    ├── troubleshooting.md # Решение проблем
    └── cheatsheet.md     # Шпаргалка
```

## Использование
Скилл активируется автоматически по триггерам в description.
