# PuzzleBot -- FAQ (Часто задаваемые вопросы)

---

### 1. Как создать бота с нуля?

1. Зарегистрируйтесь на https://puzzlebot.top (через Telegram или email).
2. Создайте бота в @BotFather: отправьте `/newbot`, задайте имя и username (должен заканчиваться на `bot`).
3. Скопируйте токен бота (формат: `1234567890:ABCdefGHI...`).
4. В PuzzleBot: Dashboard -> "+ Добавить бота" -> вставьте токен -> "Подключить".
5. Создайте команду `/start`: Конструктор -> "+ Создать сценарий" -> Триггер "Команда" -> `start`.
6. Добавьте текстовый блок, кнопки и протестируйте бота в Telegram.

Весь процесс занимает около 10 минут.

### 3. Как подключить оплату (ЮKassa, Robokassa, крипто)?

**ЮKassa:**
1. Зарегистрируйтесь на yookassa.ru, получите Shop ID и Секретный ключ.
2. В PuzzleBot: Настройки -> Платежные системы -> ЮKassa -> ввести ключи.
3. Укажите webhook URL: `https://api.puzzlebot.top/webhook/payment/yookassa/{bot_id}`.
4. Протестируйте тестовой картой: `5555 5555 5555 4444`.

**Telegram Payments:**
1. В @BotFather: `/mybots` -> ваш бот -> Payments -> выберите провайдера.
2. Получите платежный токен.
3. Подходит ТОЛЬКО для цифровых товаров и услуг (правило Telegram).

**Криптовалюта (CryptoPay):**
1. Создайте приложение в @CryptoBot: `/pay` -> Create App.
2. Получите токен и настройте в PuzzleBot.
3. Поддерживаемые валюты: BTC, ETH, USDT, TON, LTC, BNB.

### 4. Как настроить автоворонку?

1. Определите триггер (подписка, команда, покупка, ключевое слово).
2. Создайте цепочку сообщений с задержками (сразу, через часы, через дни).
3. Добавьте условия продолжения/остановки (клик по кнопке, покупка, переменная).
4. Настройте "умные" задержки (окно 09:00-21:00 -- не отправлять ночью).

**Пример Welcome-серии:** День 0 -- приветствие + подарок, День 1 -- ценность, День 2 -- кейс, День 3 -- соцдоказательства, День 4 -- предложение со скидкой 24ч, День 5 -- последний шанс.

Лимиты: до 50 воронок, до 100 сообщений в воронке, до 20 условий/веток.

### 5. Как сделать магазин в боте?

1. Меню -> Магазин -> Активировать.
2. Пройдите мастер: данные, валюта, оплата, доставка, уведомления.
3. Создайте категории товаров (до 3 уровней вложенности, до 100 категорий).
4. Добавьте товары: название, цена, описание, фото (до 10), варианты (размеры/цвета).
5. Подключите платежную систему.
6. Настройте уведомления о заказах.

Типы товаров: физический, цифровой (файл/ссылка), услуга, подписка. Лимиты: до 10,000 товаров.

### 6. Как подключить Google Sheets?

**Простой способ (встроенная интеграция):**
Компонент "Google Sheets -> Добавить строку" -> укажите ID таблицы и маппинг колонок.

**Гибкий способ (Google Apps Script -- рекомендуется):**
1. Создайте таблицу, задайте заголовки в строке 1.
2. Расширения -> Apps Script -> вставьте функцию `doPost(e)`.
3. Разверните как веб-приложение (доступ "Все").
4. В PuzzleBot: HTTP-запрос POST на URL скрипта с JSON-данными.

ID таблицы берется из URL: `https://docs.google.com/spreadsheets/d/[ВОТ_ЭТОТ_ID]/edit`

### 7. Как настроить мультивалютность (AED/USD/RUB)?

1. Настройки магазина -> Валюты -> добавить нужные (до 20).
2. Выберите основную валюту (например, USD).
3. Настройте автоконвертацию (источник курса: Forex/ЦБ РФ/ручной).
4. Добавьте наценку к курсу: 3-5% рекомендуется.
5. Для ключевых товаров можно указать фиксированные цены в каждой валюте.

Определение валюты покупателя: настройки пользователя -> Telegram Premium -> IP -> язык -> по умолчанию. Пользователь может сменить валюту кнопкой в каталоге.

### 8. Как создать Mini App?

1. Mini Apps -> "Создать Mini App".
2. Выберите шаблон (Визитка, Магазин, Бронирование, Форма) или создайте с нуля.
3. Настройте страницы и элементы (заголовок, текст, изображение, кнопка, форма, список, карусель).
4. Опубликуйте.
5. Открытие: через Inline-кнопку (тип "Web App"), через меню бота, через команду.

Данные из Mini App отправляются через `Telegram.WebApp.sendData(JSON)`, обрабатываются триггером "Web App Data".

### 9. Как работают переменные и формулы?

**Вставка в текст:** `{переменная}` -- одинарные фигурные скобки. Fallback: `{first_name|друг}`.

**Системные (автоматические):** `{user_id}`, `{first_name}`, `{username}`, `{current_date}`, `{current_time}`.

**Формулы:** `{result} = {a} + {b}`, `round({total}, 2)`, `min({balance}, {order_sum} * 0.3)`.

**Условия в тексте:** `{if:is_vip}Скидка 20%{/if}`, `{if bonus_points > 0}У вас {bonus_points}!{endif}`.

**Форматирование:** `{name|lower}`, `{name|upper}`, `{name|capitalize}`, `{amount|number}`, `{date|date}`.

### 10. Как сегментировать аудиторию для рассылок?

Создайте категории пользователей (VIP, Покупатели, Новички, по городам, по UTM-источникам).

**Автоматическое назначение:** при `/start`, по условию переменных, по UTM, по реферальной ссылке.

**Рассылка по сегментам:** выберите категории получателей + условия фильтра (`{Город} = "Дубай" И {Активность} < 7 дней`). Исключите ненужные категории.

Комбинированный фильтр: до 20 условий, AND/OR логика.

### 11. Как настроить операторскую панель (Live Chat)?

1. Бот -> Настройки -> Операторы -> Добавить (по Telegram ID, @username или ссылке-приглашению).
2. Назначьте роли: Администратор, Старший оператор, Оператор, Наблюдатель.
3. Настройте автораспределение: по нагрузке (рекомендуется), равномерное, round-robin, по категориям.
4. Создайте шаблоны ответов (папки: Общие, Доставка, Оплата).
5. Настройте триггеры переключения: ключевые слова ("оператор", "помощь"), VIP-категория.

Метрики: время ответа, кол-во диалогов, рейтинг оператора (1-5 звезд).

### 12. Как подключить AI (ChatGPT) к боту?

**Способ 1 -- Встроенный плагин:** Настройки -> Плагины -> AI/ChatGPT -> API-ключ -> модель -> параметры.

**Способ 2 -- HTTP-запрос:**
```
POST https://api.openai.com/v1/chat/completions
Authorization: Bearer {openai_api_key}
{"model": "gpt-4o", "messages": [{"role": "system", "content": "..."}, {"role": "user", "content": "{user_message}"}], "max_tokens": 500}
```
Парсинг ответа: `$.choices[0].message.content` -> `{ai_response}`.

API-ключ: platform.openai.com -> API Keys. Мин. баланс: $5. Рекомендуемый лимит: 50-200 запросов/день.

### 13. Как экспортировать данные подписчиков?

Модерация -> Пользователи -> Экспорт. Форматы: CSV, XLSX, JSON.

Поля: Telegram ID, Username, Имя, Дата регистрации, Категории, Значения переменных.

Через API: `GET /api/v1/users/export?format=csv` (до 50,000 записей за раз).

### 14. Как настроить капчу и антиспам?

Настройки -> Модерация -> Антиспам:
- Мин. интервал между сообщениями: 2 сек.
- Макс. сообщений/мин: 20.
- Макс. нажатий кнопок/мин: 30.
- Фильтр запрещенных слов (список).
- Фильтр ссылок (блокировать все/разрешенные).
- Капча для новых/подозрительных пользователей.

Система предупреждений: 1 -> инфо, 3 -> блок 24ч, 5 -> постоянная блокировка.

### 15. Как создать квиз/викторину?

1. Инициализация: `{quiz_score} = 0`.
2. Серия вопросов с кнопками вариантов ответов.
3. Обработка: правильный ответ -> `{quiz_score} = {quiz_score} + 1`.
4. Условие результата: `{quiz_score} <= 3` -> Начинающий, `<= 7` -> Средний, `> 7` -> Эксперт.
5. Персональный оффер для каждого сегмента.
6. Генерация промокода: `"QUIZ" + random(1000, 9999)`.

Показывать прогресс ("Вопрос 3 из 7"), первый вопрос -- самый простой, ограничение оффера по времени (24-48ч).

### 16. Как настроить проверку подписки на канал?

1. Сделайте бота администратором канала.
2. Привяжите канал: Настройки -> Ресурсы -> + Добавить -> @username.
3. Добавьте условие в сценарий: "Пользователь подписан на @channel" -> Да/Нет.
4. Если не подписан -> сообщение "Подпишитесь на канал" + кнопка со ссылкой + кнопка "Проверить".

Бот проверяет подписку через Telegram API `getChatMember`.

### 17. Как настроить Webhook для внешних сервисов?

**Исходящий (PuzzleBot -> сервис):** добавьте блок "HTTP-запрос" -> URL, метод POST, Content-Type: application/json, тело запроса с переменными.

**Входящий (сервис -> PuzzleBot):**
1. Настройки -> Интеграции -> Входящие вебхуки -> Создать.
2. Получите URL: `https://puzzlebot.top/webhook/bot{ID}/{name}`.
3. Укажите сценарий для запуска.
4. Настройте маппинг JSON-полей в переменные (JSONPath: `$.user.email`).

Безопасность: секретный токен в URL (`?token=secret123`), проверка подписи.

### 18. Как настроить Bitrix24 CRM?

1. В Bitrix24: Приложения -> Разработчикам -> Входящий вебхук.
2. Дайте права: CRM, Пользователи, Задачи.
3. Получите URL: `https://домен.bitrix24.ru/rest/1/TOKEN/`.
4. В PuzzleBot: сохраните URL в переменную `{bitrix_webhook}`.
5. Используйте HTTP-запрос для вызова методов: `crm.contact.add`, `crm.lead.add`, `crm.deal.add`.

Рекомендуется создать поле `UF_CRM_TELEGRAM_ID` для связки контактов.

### 19. Как работает реферальная/партнерская программа?

**Реферальная ссылка бота:** `https://t.me/bot_name?start=ref_{user_id}`. При переходе параметр доступен как `{user.ref}`.

**Партнерка PuzzleBot:** 7 дней тарифа за каждого реферала + 20% комиссия с оплат реферала в течение 3 месяцев. Ссылка: `https://puzzlebot.top/ref/YOUR_ID`. Вывод: от 500 руб, до 5 рабочих дней.

### 20. Как создать бота для бронирования экскурсий (туризм)?

1. Каталог: эмираты -> категории -> экскурсии (фото + описание + цена + кнопки).
2. Бронирование: дата (календарь) -> количество гостей -> контакты (имя, телефон, отель) -> подтверждение.
3. Мультивалютность: USD, AED, RUB.
4. Программа лояльности: баллы за заказы, 4 уровня (Bronze/Silver/Gold/VIP).
5. Интеграции: Google Sheets / NocoDB (база экскурсий), Notion (CRM), Webhook (статусы).
6. Напоминания: за 24ч и 2ч до экскурсии.
7. После экскурсии: запрос отзыва + предложение следующей.

### 21. Как правильно именовать переменные?

Хорошо: `{user_phone}`, `{order_total}`, `{last_visit_date}`, `{cart_count}`, `{vip_until}`.

Плохо: `{x}`, `{data}`, `{temp}`, `{var1}`.

Правила: латиница + подчеркивание, осмысленное название, инициализировать числовые нулем, всегда использовать fallback в текстах.

### 22. Как настроить расписание (cron) для регулярных действий?

Используйте блок "Расписание": ежедневно (09:00), по дням недели (Пн, Ср, Пт), по cron-выражению (`0 9 * * 1-5` -- Пн-Пт в 09:00).

Примеры: ежедневный дайджест, напоминание об истечении подписки, сброс счетчика AI-запросов, проверка неактивных пользователей (>7 дней).

### 24. Как использовать PuzzleBot API программно?

**Базовый URL:** `https://api.puzzlebot.top/v1/`
**Токен:** Настройки -> API -> Получить токен (формат `pb_abc123...`).
**Заголовок:** `Authorization: Bearer pb_abc123...`

Ключевые эндпоинты:
- `GET /bot/info` -- информация о боте
- `POST /messages/send` -- отправка сообщения
- `GET /users/{telegram_id}` -- данные пользователя
- `POST /scenarios/run` -- запуск сценария
- `POST /broadcast/send` -- массовая рассылка

Rate Limits: 1000 запросов/мин, 30 сообщений/сек.

### 25. Как организовать A/B тестирование рассылок?

1. Создайте 2+ варианта сообщения (текст, кнопки, медиа).
2. Укажите % аудитории для теста (обычно 10-20%).
3. Запустите тест -- варианты отправляются тестовой группе.
4. Дождитесь результатов (CTR, переходы, конверсии).
5. Система автоматически выберет лучший вариант и отправит остальным.

Рекомендуется тестировать: заголовок, кнопки (текст и расположение), наличие/отсутствие медиа, время отправки.
