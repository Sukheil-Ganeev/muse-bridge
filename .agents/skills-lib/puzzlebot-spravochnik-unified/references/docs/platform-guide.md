## 2. Быстрый старт (10 минут)

1. Зарегистрироваться на puzzlebot.top (через Telegram или email)
2. Создать бота: `/newbot` в @BotFather -> имя -> username (на `bot`) -> получить токен
3. Подключить: Dashboard -> "+ Добавить бота" -> вставить токен -> "Подключить"
4. Создать `/start`: Конструктор -> "+ Создать сценарий" -> Триггер "Команда" -> `start`
5. Добавить текст: `Привет, {first_name}!` + кнопки (inline или reply)
6. Протестировать бота в Telegram

**Токен** -- пароль от бота (формат: `1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ`). Хранить в безопасности, не передавать третьим лицам.

### Интерфейс: 5 разделов

Dashboard, Конструктор, Модерация, Статистика, Настройки.

**Конструктор** -- три панели: левая (блоки), центр (canvas -- drag & drop), правая (свойства блока).

## 3. Конструктор сценариев

### 3.1 Блоки

**Команда** -- точка входа. Начинается с `/`, до 32 символов, латиница. Стандартные: `/start`, `/help`, `/settings`, `/menu`.

| Тип блока | Назначение |
|-----------|-----------|
| Текстовый | Текст с переменными `{переменная}`, HTML/Markdown |
| Медиа | Фото, видео, документ, аудио, голосовое, стикер |
| Кнопки | Reply-кнопки (клавиатура) или Inline-кнопки (под сообщением) |
| Условие | ЕСЛИ-ИНАЧЕ, ветвление логики |
| Действие | Запись в переменную, математика, HTTP-запросы |
| Форма | Сбор данных от пользователя с валидацией |
| Задержка | Пауза от 1 сек до 30 дней, имитация "печатания" |

### 3.2 Кнопки и клавиатуры

**Reply Keyboard** -- под полем ввода, заменяет стандартную клавиатуру, при нажатии отправляет текст. Специальные: запрос контакта, геолокации, создание опроса.

**Inline Keyboard** -- под сообщением, не засоряет чат. Три типа:

1. **Callback** -- отправляет callback_data: переход к блоку, изменение сообщения, показ alert/toast
2. **URL** -- открывает ссылку: поддерживает переменные `https://shop.com/order/{order_id}`
3. **Web App** -- открывает Mini App

**Лимиты:** Inline -- 8 кнопок в ряду, 100 рядов; Reply -- 12 кнопок в ряду. Текст кнопки -- до 64 символов.

**Динамические клавиатуры:** генерация из массива, условные кнопки (показать если `{cart_count} > 0`).

### 3.3 Медиа-контент

| Тип | Макс. размер |
|-----|-------------|
| Фото | 10 МБ (JPG, PNG, WebP) |
| Видео | 50 МБ |
| Документ | 50 МБ |
| Аудио / Голосовое | 50 МБ |
| Видеосообщение (круглое) | 50 МБ, до 60 сек |
| GIF | 50 МБ |

3 способа отправки: загрузка файла, по URL, по File ID (мгновенная, файл уже на серверах). Медиа-группа (альбом): до 10 фото/видео.

Параметры: Parse mode (HTML/Markdown), Disable notification, Protect content (запрет пересылки), Spoiler.

### 3.4 Условия и логика

**Структура:** ЕСЛИ [условие] -> Действие A, ИНАЧЕ -> Действие B

**Операторы сравнения:**
- Числа: `>`, `<`, `>=`, `<=`, `==`, `!=`
- Строки: `==`, `!=`, `contains`, `startswith`
- Null: `exists`, `== null`, `!= null`

**Логические операторы:** `AND`, `OR`, `NOT`. Комбинирование:
```
({user.balance} >= 1000 OR {user.premium} == true) AND {user.verified} == true
```

**Типы ветвлений:** простое if-else, множественное (цепочка), Switch (по значению переменной с default).

**Специальные условия:** проверка подписки на канал, проверка времени (`{current_hour}`, `{current_day}`), проверка источника (`{user.ref}`).

**Правило:** располагать условия от частного к общему, всегда предусматривать ветку ИНАЧЕ.

### 3.5 Формы и ввод данных

**Типы полей:** текст, число, email, телефон, дата (ДД.ММ.ГГГГ), время (ЧЧ:ММ), фото, документ, геолокация, выбор из списка.

**Валидация:** встроенная (email, телефон, число, дата), regex (`^[A-Z]{2}\d{4}$`), диапазон (мин/макс), длина строки, кастомные сообщения об ошибках, макс. попыток.

**Многошаговые формы:** прогресс ("Шаг 2 из 5"), навигация [Назад] [Пропустить] [Отмена], подтверждение перед сохранением.

**Преобразования данных:**
- `{user.email | lowercase}` -- нижний регистр
- `{user.name | trim}` -- обрезка пробелов
- `{user.name | capitalize}` -- первая заглавная

### 3.6 Таймауты и задержки

| Тип | Описание |
|-----|----------|
| Задержка | Пауза между блоками (1 сек -- 30 дней) |
| Отложенное сообщение | Отправка в будущем |
| Таймаут | Действие при отсутствии ответа |
| Расписание | Регулярные запуски (cron, напр. `0 9 * * 1-5`) |

**Каскадные напоминания (пример):** 30 мин -> 3 часа -> 24 часа -> 72 часа.

**Управление таймерами:** теги для группировки (`cart_reminder`), отмена по тегу, ID таймера (`cart_reminder_{user.id}`).

**Имитация "печатания":** Typing indicator, автоматический расчет (~50 символов/сек), мин. 1 сек, макс. 5 сек.

### 3.7 Telegram Mini Apps

Веб-приложение внутри Telegram. Встроенные шаблоны PuzzleBot: Визитка, Магазин, Бронирование, Форма заявки, Мини-игра, Личный кабинет.

**Открытие:** через Inline-кнопку (тип "Web App"), через меню бота, через команду.

**Отправка данных из Mini App:**
```javascript
Telegram.WebApp.sendData(JSON.stringify({action: "add_to_cart", product_id: 123}));
```

**Обработка в боте:** Триггер "Web App Data" -> `{web_app_data}` -> парсинг JSON.

## 4. Переменные и формулы

### 4.1 Системные переменные

| Переменная | Описание | Всегда есть? |
|------------|----------|--------------|
| `{user_id}` | Telegram ID | Да |
| `{first_name}` | Имя | Да |
| `{last_name}` | Фамилия | Нет |
| `{username}` | Username (без @) | Нет |
| `{full_name}` | Полное имя | Да |
| `{language_code}` | Язык (ru, en) | Да |
| `{bot_username}` | Username бота | Да |
| `{current_date}` | Текущая дата | Да |
| `{current_time}` | Текущее время | Да |
| `{current_hour}` | Текущий час | Да |
| `{current_day}` | День недели | Да |
| `{current_month}` | Месяц | Да |

### 4.2 Синтаксис переменных

**Вставка:** `{переменная}` (одинарные фигурные скобки).

**Fallback (значение по умолчанию):** `{first_name|друг}` -- если пустое, подставится "друг".

**Условный текст:**
```
{if:is_vip}Вы VIP-клиент! Скидка 20%{/if}
{if:is_vip}VIP{else}Обычный{/if}
{if:category:vip}Персональная скидка{/if}
{if bonus_points > 0}У вас {bonus_points} бонусов!{endif}
```

**Форматирование:**
- `{name|lower}` -- нижний регистр
- `{name|upper}` -- ВЕРХНИЙ
- `{name|capitalize}` -- Первая заглавная
- `{amount|number}` -- 1 234 567
- `{date|date}` -- 15 января 2026

### 4.3 Пользовательские переменные

**Типы:** строка, число, дата, логический (true/false).

**Области видимости:** пользовательские (уникальны для каждого), глобальные (общие для бота: `{exchange_rate}`, `{promo_active}`), временные (сессия).

**Запись:** через "Ввод данных", через действие "Установить переменную", через кнопку.

### 4.4 Формулы и вычисления

**Базовые:** `+`, `-`, `*`, `/`, `%` (остаток). Порядок: скобки -> умножение/деление -> сложение/вычитание.

**Функции:**
```
round({total})           -- округление до целого
round({total}, 2)        -- до 2 знаков
min({a}, {b})            -- минимум
max({a}, {b})            -- максимум
```

**Практические формулы:**

```
-- Процентная скидка
{final_price} = {original_price} - ({original_price} * {discount_percent} / 100)

-- Кэшбэк
{cashback} = {order_sum} * {cashback_percent} / 100
{balance} = {balance} + {cashback}

-- Списание бонусов (лимит 30%)
{bonus_used} = min({balance}, {order_sum} * 0.3)
{final_sum} = {order_sum} - {bonus_used}

-- Счетчик
{visit_count} = {visit_count} + 1
```

### 4.5 Категории пользователей

Сегментация аудитории. Системные: Все пользователи, Администраторы, Заблокированные.

**Автоматическое назначение:** при `/start`, по условию (`{total_purchases} >= 10000` -> VIP), по UTM (`?start=utm_source_instagram`), по реферальной ссылке.

**Проверка:** `{if:category:vip}VIP-меню{/if}`. Пользователь может быть в нескольких категориях одновременно.

**Перемещение:** Действие 1: Удалить из "Лиды", Действие 2: Добавить в "Клиенты".

### 4.6 Хранение и экспорт данных

Данные хранятся на серверах PuzzleBot (ЕС, GDPR). Экспорт: CSV, XLSX, JSON.

**Глобальные переменные:** `{exchange_rate} = 92.5`, `{promo_active} = true`.

**API PuzzleBot:**
```
GET  /api/v1/users/{user_id}                -- данные пользователя
POST /api/v1/users/{user_id}/variables       -- обновить переменную
GET  /api/v1/users/export?format=csv         -- экспорт (до 50,000 записей)
```
Лимиты: 60 запросов/мин, 10,000/день.

## 5. Магазин и платежи

### 5.1 Настройка магазина

Активация: Меню -> Магазин -> Активировать. Мастер настройки: данные, валюта, оплата, доставка, уведомления.

**Каталог:** отображение (Список/Плитка/Карусель), сортировка (по умолчанию/цене/популярности).

**Типы товаров:** физический (требует доставки), цифровой (файл/ссылка после оплаты), услуга (без доставки), подписка (регулярный платеж).

**Карточка товара:** название (до 256 символов), цена, описание, старая цена (зачеркнутая), артикул, категория, фото (до 10), остаток, варианты (размеры, цвета).

Лимиты: до 10,000 товаров, 100 категорий (3 уровня вложенности), 100 вариантов на товар.

### 5.2 Платежные системы

| Система | Комиссия | Регион |
|---------|----------|--------|
| ЮKassa | 2.8-3.5% | Россия |
| Robokassa | 3-5% | Россия, СНГ |
| Telegram Payments | 0-2% | Весь мир |
| CloudPayments | 2.7-3% | Россия |
| СБП | 0.4-0.7% | Россия |
| Stripe | 2.9% + $0.30 | Весь мир |
| CryptoPay | 0.5-1% | Весь мир (BTC, ETH, USDT, TON) |

**ЮKassa:** карты (Visa, MC, МИР), SberPay, мобильный баланс. Подключение: yookassa.ru -> Shop ID + Secret Key. Webhook: `https://api.puzzlebot.top/webhook/payment/yookassa/{bot_id}`.

**Telegram Payments:** нативный интерфейс, ТОЛЬКО для цифровых товаров. Токен от @BotFather: `/mybots` -> Payments.

**Криптовалюта:** CryptoCloud, CryptoPay (@CryptoBot), NOWPayments. Валюты: BTC, ETH, USDT, TON, LTC, BNB.

**Тестовые карты ЮKassa:** `5555 5555 5555 4444` (успех), `5555 5555 5555 4002` (отклонение).

### 5.3 Заказы и доставка

**Статусы:** Новый -> Ожидает оплаты -> Оплачен -> В обработке -> Отправлен -> Доставлен -> (Отменен/Возврат).

**Переменные уведомлений:** `{order_id}`, `{order_total}`, `{order_items}`, `{order_status}`, `{tracking_number}`, `{tracking_url}`.

**Типы доставки:** самовывоз, курьер, почта, ТК (СДЭК, Boxberry), цифровая. Расчет: фиксированная, по весу, по сумме, по региону.

### 5.4 Мультивалютность

Поддержка до 20 валют: RUB, USD, EUR, AED, KZT, UAH и др.

**Автоконвертация:** источники курсов (ЦБ РФ, Forex, ручной). Рекомендуемая наценка к курсу: 3-5%.

**Фиксированные цены:** можно указать отдельно для каждой валюты (приоритет над автоконвертацией).

**Промокоды:** процентные работают для всех валют; фиксированные нужно указать для каждой валюты отдельно.

**Определение валюты покупателя:** настройки пользователя -> Telegram Premium -> IP -> язык -> валюта по умолчанию.

## 6. Постинг и рассылки

### 6.1 Постинг

**Форматирование:**

| Стиль | Синтаксис |
|-------|-----------|
| **Жирный** | `*текст*` или `**текст**` |
| *Курсив* | `_текст_` |
| ~~Зачеркнутый~~ | `~текст~` |
| `Моноширинный` | `` `текст` `` |
| Спойлер | `||текст||` |
| Ссылка | `[Текст](https://url)` |

**Кнопки под постами:** URL `[Текст](https://link.com)`, несколько в ряд -- разделитель `|`.

**Мультипостинг:** публикация в несколько каналов одновременно (до 50 каналов). Кросс-постинг: автокопирование из канала-источника (до 10 источников).

**Отложенный постинг:** планирование по дате/времени, очередь слотов (до 24/день), повторяющиеся публикации. До 500 запланированных, до 1 года вперед.

### 6.2 Автоворонки

Цепочки сообщений с интервалами после триггера. До 50 воронок, 100 сообщений, 20 условий/веток.

**Триггеры:** подписка, команда, кнопка, ключевое слово, покупка, категория, дата, webhook.

**Задержки:** сразу, минуты, часы, дни, умная (окно 09:00-21:00).

**Пример Welcome-серии:**
```
День 0: Приветствие + подарок
День 1: Знакомство + ценность
День 2: Контент + кейс
День 3: Соцдоказательства
День 4: Предложение (скидка 24ч)
День 5: Последний шанс + FOMO
```

### 6.3 Рассылки и сегментация

**Сегментация:** по категории, по поведению, по переменным, по времени, комбинированная.

**Расширенный фильтр:**
```
(Категория = "Покупатели" ИЛИ "VIP")
И (Город = "Москва" ИЛИ "СПб")
И (Активность < 7 дней)
И НЕ (Категория = "Отписались")
```

**A/B тестирование:** 2+ варианта -> % для теста -> автовыбор лучшего -> отправка остальным.

**Скорость:** быстрый 25-30/сек (срочные), нормальный 15-20/сек, медленный 5-10/сек, безопасный 1-3/сек.

**Лучшее время:** будни 10-12, 18-21; выходные 11-14, 17-20. Информационные: 1-2 раза/неделю; промо: не чаще 1/неделю.

## 7. События и триггеры

### 7.1 Типы событий

**Системные:** подписка, отписка, повторный запуск, первое сообщение.

**Пользовательские:** получение сообщения (текст, фото, видео, документ, голосовое, стикер, контакт, геолокация), нажатие inline-кнопки, переход по deep link.

**Платежные:** инициация платежа, успешная оплата, неудачная оплата, возврат.

**Формы:** начало/завершение/отмена/таймаут заполнения.

**Группы/каналы:** вступление/выход, новый пост, реакция на пост.

### 7.2 Текстовые триггеры (ключевые слова)

| Тип | Пример | Срабатывает на |
|-----|--------|----------------|
| Точное совпадение | "прайс" | Только "прайс" |
| Содержит | "доставка" | "как доставка", "доставка?" |
| Начинается с | "заказ" | "заказ N123", "заказать" |
| Несколько (ИЛИ) | "цена" ИЛИ "стоимость" | Любое из слов |
| Regex | `^\d{10,11}$` | Номер телефона |

**Приоритет проверки:** точное совпадение > начинается с > содержит > regex > любое сообщение.

### 7.3 Автоматизация

**Структура:** СОБЫТИЕ/ТРИГГЕР -> УСЛОВИЕ (опц.) -> ДЕЙСТВИЕ(Я) -> СЛЕДУЮЩИЙ ШАГ.

**Цепочки:** последовательные, параллельные, ветвящиеся.

**Пример системы лояльности:** при оплате -> `{points} + ({order_sum} / 10)` -> пороги: 5 покупок = Серебро, 10 = Золото, 25 = Платина.

## 8. Диалоги и операторская панель

**Просмотр диалогов:** Бот -> Диалоги. Три колонки: список | история | карточка пользователя.

**Статусы:** Новый -> На операторе -> Ожидает ответа -> Закрыт.

**Переключение на оператора:** автоматическое (ключевые слова "оператор", "помощь", "человек"; N вопросов без ответа; VIP) или ручное.

**Операторская панель:** добавление оператора (по Telegram ID, username, ссылке-приглашению). Автораспределение: равномерное, по нагрузке, round-robin, по категориям.

**Роли:** Администратор (полный доступ), Старший оператор (все диалоги + управление), Оператор (назначенные диалоги), Наблюдатель (только чтение).

**Шаблоны ответов:** папки (Общие/Доставка/Оплата), поддержка переменных, быстрый вызов `Ctrl+1` или `/доставка`.

**Рекомендации:** первый ответ -- до 5 мин, VIP -- до 2 мин.

## 9. Интеграции

### 9.1 HTTP-запросы и Webhooks

**Исходящие (PuzzleBot -> внешний сервис):** компонент "HTTP-запрос". POST/GET/PUT/DELETE + JSON body + заголовки.

**Входящие (внешний сервис -> PuzzleBot):** создать в Настройки -> Интеграции -> Входящие вебхуки. URL: `https://puzzlebot.top/webhook/bot{ID}/{name}`. Парсинг JSON через JSONPath (`$.user.email`, `$.items[0].name`).

**Безопасность:** проверка подписи (X-Signature), секретный токен в URL, IP-фильтрация.

### 9.2 Google Sheets

**3 метода:**

1. **Встроенная интеграция** -- самый простой: компонент "Google Sheets -> Добавить строку"
2. **Google Sheets API** -- средний: `POST .../values/Лист1!A:F:append` с Bearer token
3. **Google Apps Script** -- максимальная гибкость (рекомендуется для сложной логики):
   ```javascript
   function doPost(e) {
     var data = JSON.parse(e.postData.contents);
     var sheet = SpreadsheetApp.getActiveSheet();
     sheet.appendRow([data.user_id, new Date(), data.name, data.phone]);
     return ContentService.createTextOutput(JSON.stringify({status: "success"}));
   }
   ```

Лимиты Google Sheets: 10 млн ячеек, 300 запросов/мин, Apps Script -- до 6 мин выполнения.

### 9.3 Bitrix24

Подключение через входящий вебхук Bitrix24. URL: `https://домен.bitrix24.ru/rest/1/TOKEN/`.

Ключевые методы: `crm.contact.add`, `crm.lead.add`, `crm.deal.add`, `crm.deal.update`, `tasks.task.add`.

Хранить URL в переменной `{bitrix_webhook}`, проверять дубликаты перед созданием контактов.

### 9.4 PuzzleBot API

**Базовый URL:** `https://api.puzzlebot.top/v1/`
**Авторизация:** `Authorization: Bearer pb_abc123xyz...`

Ключевые эндпоинты: `/bot/info`, `/bot/stats`, `/messages/send`, `/broadcast/send`, `/users/{id}`, `/scenarios/run`.

Rate Limits: 1000/мин общий, 30/сек на отправку, 100/мин на получение данных.

### 9.5 AI-плагины

**Подключение ChatGPT:** встроенный плагин (Настройки -> Плагины -> AI) или HTTP-запрос:
```
POST https://api.openai.com/v1/chat/completions
Authorization: Bearer {openai_api_key}
{"model": "gpt-4o", "messages": [...], "max_tokens": 500, "temperature": 0.7}
Парсинг: $.choices[0].message.content -> {ai_response}
```

**Альтернативы:** Claude (Anthropic), YandexGPT, GigaChat.

**Оптимизация расходов:** gpt-3.5-turbo для простых задач, ограничение max_tokens, кэширование FAQ, лимит запросов/день.

**Лимит в боте:** `{ai_requests_today} >= 10` -> "Лимит исчерпан". Ежедневный сброс через планировщик.

## 10. Модерация и управление

**Карточка пользователя:** Telegram ID, username, имя, язык, дата регистрации, категории, значения переменных.

**Фильтры:** по категориям, по активности, по дате, по переменным (`{balance} >= 1000`).

**Массовые действия:** добавить/удалить из категории, установить переменную, отправить сообщение, экспорт, блокировка.

**Антиспам:** мин. интервал 2 сек, макс. 20 сообщений/мин, 30 нажатий/мин, фильтр слов, фильтр ссылок, капча.

**Система предупреждений:** 1 warn -> инфо, 2 -> строгое, 3 -> блок 24ч, 4 -> блок 7 дней, 5 -> постоянная блокировка. Снятие: автоматически через 30 дней.

**Статистика:** DAU/WAU/MAU, Retention (D1/3/7/30), стикинесс, источники, воронки конверсии.

## 13. Аудит и отладка

### 5-этапный процесс аудита

1. **Подготовка:** снапшот бота, сохранение документации
2. **Анализ структуры:** подсчет блоков, кнопок, переходов, переменных
3. **Проверка переходов (критично):** каждая кнопка имеет goto -> существующий блок -> контент есть -> выход ("Назад") есть
4. **Проверка категорий:** все упомянутые категории созданы и используются
5. **Подсчет и сравнение:** план vs факт

### Метрики скорости

| Метрика | Хорошо | Приемлемо | Плохо |
|---------|--------|-----------|-------|
| Ответ на /start | < 1 сек | 1-3 сек | > 3 сек |
| Переход по кнопке | < 0.5 сек | 0.5-2 сек | > 2 сек |
| Отправка формы | < 2 сек | 2-5 сек | > 5 сек |

### Типичные ошибки

1. Поверхностный анализ (85% видимой готовности, 60% реальной)
2. Кнопка существует, но не работает (нет goto / ведет на пустой блок)
3. Блоки-сироты (без входящих переходов)
4. Placeholder-тексты ("Здесь будет описание")

**Формула проверки карточки:**
```
Работает = Название + Описание + Кнопка действия (goto настроен)
           + Целевой блок (существует, с контентом) + Кнопка "Назад"
```
