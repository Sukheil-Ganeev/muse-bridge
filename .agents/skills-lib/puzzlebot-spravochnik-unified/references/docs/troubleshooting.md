# PuzzleBot -- Troubleshooting (Решение проблем)

---

## 1. Бот не отвечает на команды

**Симптомы:** отправляете `/start` или другую команду -- бот молчит.

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| Неверный токен | Скопируйте токен заново из @BotFather, переподключите бота |
| Бот используется другим сервисом | Отвяжите от старого сервиса или создайте нового бота |
| Нет сценария для команды | Создайте сценарий с триггером "Команда" -> `start` |
| Сценарий отключен | Проверьте статус сценария (должен быть "Активен") |
| Превышен лимит подписчиков | Проверьте тариф -- новые пользователи не смогут подписаться |
| Пользователь в черном списке | Проверьте: Модерация -> Пользователи -> поиск по ID |

**Диагностика:** Настройки -> Токен -> "Проверить подключение". Если ошибка -- переподключите бота.

## 2. Кнопки не работают / не отображаются

**Симптомы:** кнопки не появляются, нажатие не вызывает реакции, кнопки "зависают".

**Причины и решения:**

- **Кнопка без перехода (goto):** откройте свойства кнопки -> убедитесь, что назначен целевой блок.
- **Целевой блок удален:** кнопка ведет на несуществующий блок -> создайте блок заново или переназначьте.
- **Целевой блок пуст:** блок существует, но не содержит контента -> добавьте текст/медиа.
- **Превышен лимит:** Inline -- макс. 8 в ряду, 100 рядов. Reply -- макс. 12 в ряду.
- **Слишком длинный текст кнопки:** макс. ~64 символа.
- **Старая клавиатура осталась:** отправьте `remove_keyboard: true` или обновите Reply-клавиатуру.

**Проверка:** пройдите каждую кнопку вручную. Используйте формулу: `Кнопка работает = goto назначен + блок существует + контент есть + есть выход ("Назад")`.

## 3. Сценарий зацикливается

**Симптомы:** бот повторяет одно и то же сообщение, бесконечный цикл, пользователь не может выйти.

**Причины и решения:**

- **Циклическая ссылка:** блок A -> блок B -> блок A. Решение: добавьте условие выхода или кнопку "Главное меню".
- **Триггер срабатывает на ответ бота:** текстовый триггер "содержит" перехватывает собственное сообщение. Решение: используйте точное совпадение или добавьте условие `{is_waiting_input} != true`.
- **Отсутствие условия остановки в воронке:** добавьте проверку `{purchased} != 1` или `{funnel_completed} != 1`.
- **Конфликт триггеров:** два триггера срабатывают поочередно. Решение: проверьте приоритеты, используйте более точные условия.

**Экстренно:** заблокируйте бота для себя и разблокируйте -- это сбросит текущий сценарий.

## 4. Оплата не проходит

**Симптомы:** ошибка при оплате, платеж не подтверждается, деньги списаны но статус не изменился.

**Решения по системам:**

**ЮKassa:**
- Проверьте Shop ID и Secret Key (Настройки -> Платежи).
- Проверьте webhook URL: `https://api.puzzlebot.top/webhook/payment/yookassa/{bot_id}`.
- Убедитесь, что webhook включен в личном кабинете ЮKassa.
- Тестируйте через тестовый режим: карта `5555 5555 5555 4444`.
- Фискализация 54-ФЗ: проверьте настройки чеков.

**Telegram Payments:**
- Только цифровые товары и услуги (правило Telegram).
- Проверьте платежный токен в @BotFather.
- Мин. сумма: $1, макс: $10,000.

**Крипто:**
- Проверьте API-токен CryptoPay.
- Убедитесь, что валюта поддерживается (BTC, ETH, USDT, TON).

**Если деньги списаны, статус не изменился:** проблема с webhook -- проверьте URL, убедитесь что PuzzleBot получает уведомление от платежной системы.

## 5. Рассылка не доходит до всех подписчиков

**Симптомы:** часть пользователей не получает рассылку.

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| Пользователь заблокировал бота | Статус "bot blocked" в отчете -- нормально, удалите из базы |
| Аккаунт удален/деактивирован | Статус "user deactivated" -- автоматически |
| Неправильный сегмент | Проверьте фильтры рассылки, условия категорий |
| Rate Limit Telegram | Макс. 30 сообщений/сек для всех, 1/сек одному. Используйте медленный режим |
| Большой объем | 10,000 получателей / 20 сообщ./сек = ~8.5 минут. Подождите завершения |

**Проверка:** после рассылки смотрите статистику: отправлено, доставлено, не доставлено (с причинами).

## 6. Webhook не получает данные

**Симптомы:** внешний сервис отправляет данные, но PuzzleBot не реагирует.

**Диагностика:**

1. **Проверьте URL:** `https://puzzlebot.top/webhook/bot{ID}/{name}` -- правильный ли ID бота и имя webhook?
2. **Проверьте формат:** Content-Type должен быть `application/json`.
3. **Проверьте JSON:** валидный ли JSON? Используйте jsonlint.com.
4. **Проверьте маппинг:** JSONPath корректен? `$.user.email` vs `$.data.user.email`.
5. **Проверьте идентификацию пользователя:** webhook должен передавать Telegram ID для привязки к пользователю.

**Отладка:**
- webhook.site -- тестируйте получение данных.
- Postman -- отправьте тестовый POST-запрос вручную.
- Логирование -- запишите входящие данные в Google Sheets для анализа.

## 7. Google Sheets не синхронизируется

**Симптомы:** данные не записываются в таблицу, чтение возвращает пустоту, ошибка авторизации.

**Решения:**

| Проблема | Решение |
|----------|---------|
| Ошибка доступа | Убедитесь, что таблица доступна: "Все у кого есть ссылка -> Редактор" |
| Неверный ID таблицы | Скопируйте ID из URL: `.../spreadsheets/d/[ВОТ_ID]/edit` |
| Неверное имя листа | Название листа чувствительно к регистру и пробелам |
| Apps Script ошибка | Проверьте логи: Расширения -> Apps Script -> Выполнения |
| Лимит API | Макс. 300 запросов/мин на проект, 60 на пользователя |
| Apps Script таймаут | Макс. 6 минут выполнения -- оптимизируйте код |

**Тестирование Apps Script:** добавьте `Logger.log(e.postData.contents)` в начало функции и проверьте логи.

## 8. Переменная не сохраняет значение

**Симптомы:** переменная остается пустой, сбрасывается, содержит неверное значение.

**Причины и решения:**

- **Не назначено действие "Установить переменную":** проверьте, что в блоке есть действие записи.
- **Ошибка типа данных:** записываете строку в числовую переменную или наоборот.
- **Пустое значение из Telegram:** `{username}` и `{last_name}` могут быть пустыми -- используйте fallback: `{username|нет}`.
- **Перезапись другим блоком:** другой сценарий или триггер перезаписывает переменную.
- **Глобальная vs пользовательская:** глобальная одна на всех, пользовательская -- своя для каждого.
- **Область видимости temp:** временные переменные сбрасываются после завершения сессии.

**Диагностика:** Модерация -> Пользователи -> найдите пользователя -> проверьте значения переменных в карточке.

## 9. Медиа-файлы не отправляются

**Симптомы:** фото/видео/документ не загружается, ошибка отправки.

**Ограничения Telegram:**

| Тип | Макс. размер |
|-----|-------------|
| Фото | 10 МБ |
| Видео/Документ/Аудио | 50 МБ |
| GIF | 50 МБ |
| Видеосообщение (круглое) | 50 МБ, до 60 сек |

**Решения:**
- Уменьшите размер файла (сжатие, конвертация).
- Фото: используйте JPG вместо PNG, рекомендуемое качество 80%.
- Видео: конвертируйте в MP4 с H.264.
- Если отправляете по URL: убедитесь, что ссылка доступна (не требует авторизации).
- File ID уникален для каждого бота -- нельзя использовать между ботами.
- Медиа-группа (альбом): макс. 10 фото/видео, подпись только к первому.

## 10. Формула возвращает ошибку

**Симптомы:** вычисление не работает, результат NaN или 0, неверный ответ.

**Типичные ошибки:**

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Деление на ноль | `{divisor}` = 0 | Добавьте условие: `{if divisor > 0}...{endif}` |
| NaN | Пустая переменная в формуле | Инициализируйте: `{counter} = 0` при /start |
| Неверный порядок | `{a} + {b} * {c}` (умножение первое) | Используйте скобки: `({a} + {b}) * {c}` |
| Строка вместо числа | Текстовое значение в математике | Конвертируйте или проверяйте тип |
| Переполнение округления | Много знаков после точки | Используйте `round({result}, 2)` |

**Отладка:** записывайте промежуточные результаты в отдельные переменные и проверяйте каждый шаг.

## 11. Mini App не открывается

**Симптомы:** кнопка Mini App не работает, белый экран, ошибка загрузки.

**Решения:**

- **Кнопка не настроена:** проверьте, что тип кнопки -- "Web App", а не "URL" или "Callback".
- **URL Mini App неверный:** должен быть HTTPS, доступен публично.
- **Ошибка в коде:** откройте в браузере URL Mini App, проверьте консоль на ошибки.
- **Старая версия Telegram:** Mini Apps требуют актуальную версию приложения.
- **Кэш:** попросите пользователя очистить кэш Telegram или перезапустить приложение.
- **CORS-проблема:** сервер Mini App должен разрешать запросы от Telegram.

## 12. Бот заблокирован Telegram

**Симптомы:** бот полностью перестал работать, ошибка "bot was blocked".

**Причины:**
- Рассылка спама (жалобы пользователей).
- Нарушение правил Telegram (запрещенный контент).
- Слишком высокая частота запросов без контроля.
- Фишинг или мошенничество.

**Решения:**
- Обратитесь в поддержку Telegram: https://telegram.org/support.
- Проверьте, не отправлял ли бот нежелательный контент.
- Используйте безопасный режим рассылки (1-3 сообщ./сек).
- Добавьте кнопку отписки в каждую рассылку.
- Не рассылайте чаще 1 раза/неделю промо-контент.

**Профилактика:** сегментируйте аудиторию, не рассылайте всем одно и то же, следите за процентом жалоб.

## 13. Таймаут срабатывает раньше/позже

**Симптомы:** напоминание приходит не вовремя, задержка не соответствует настройке.

**Причины:**

- **Часовой пояс:** PuzzleBot работает в UTC, а не в локальном времени. Убедитесь, что переменная `{user.timezone}` задана.
- **Загрузка системы:** при большом количестве одновременных таймеров (макс. 10,000) возможна задержка в секунды.
- **Конфликт таймеров:** несколько таймеров с одинаковым тегом. Используйте уникальные теги: `cart_reminder_{user.id}`.
- **Пересоздание таймера:** старый не отменен -- отменяйте по тегу при создании нового.

**Лимиты таймеров:** мин. 1 секунда, макс. 30 дней, до 100 отложенных на пользователя.

## 14. Условие не срабатывает

**Симптомы:** ветвление работает не так, как ожидается, всегда идет в "ИНАЧЕ".

**Типичные ошибки:**

- **Тип данных:** `{status}` = строка "5", а вы сравниваете как число `> 3`. Убедитесь в типах.
- **Регистр:** `"VIP" != "vip"`. Используйте `{status|lower}` перед сравнением.
- **Пробелы:** `" VIP" != "VIP"`. Используйте `{status|trim}`.
- **Пустая переменная:** `{phone}` не задана -- используйте проверку `exists` или `!= null`.
- **Порядок условий:** располагайте от частного к общему (> 100, потом > 50, потом > 0).
- **Отсутствие ветки ИНАЧЕ:** если ни одно условие не подошло, бот молчит. Всегда добавляйте fallback.

**Отладка:** перед условием отправьте диагностическое сообщение: `DEBUG: status={status}, type={typeof status}`.

## 15. Импорт/экспорт данных дает ошибку

**Симптомы:** не удается импортировать CSV, экспорт зависает, данные повреждены.

**Импорт:**
- Формат CSV: разделитель -- запятая (,), кодировка UTF-8.
- Обязательное поле: `user_id` (Telegram ID).
- Пользователь должен хотя бы раз написать боту (иначе бот не сможет ему отправить).
- Проверьте размер файла: очень большие файлы (>50,000 строк) нужно разбивать.

**Экспорт:**
- Лимит: до 50,000 записей за раз.
- Большие экспорты могут занимать время -- дождитесь завершения.
- Форматы: CSV, XLSX, JSON.

## 16. Кросс-постинг / мультипостинг не работает

**Симптомы:** пост публикуется не во все каналы, ошибка публикации.

**Решения:**
- Убедитесь, что бот -- администратор в каждом канале с правами публикации.
- Проверьте: Настройки -> Ресурсы -- все каналы привязаны.
- Лимит: макс. 50 каналов в мультипосте, 10 источников кросс-постинга.
- Telegram Rate Limit: при публикации в много каналов одновременно возможна задержка.
- Проверьте, что @username или ID канала указан правильно.

## 17. AI-модуль (ChatGPT) не отвечает или отвечает ошибкой

**Симптомы:** бот не возвращает AI-ответ, ошибка 401/429/500.

| Ошибка | Причина | Решение |
|--------|---------|---------|
| 401 Unauthorized | Неверный API-ключ | Проверьте ключ на platform.openai.com |
| 429 Too Many Requests | Превышен лимит запросов | Ожидайте или увеличьте лимит аккаунта |
| 500 Internal Error | Ошибка OpenAI | Повторите через несколько минут |
| Пустой ответ | `max_tokens` слишком мал | Увеличьте (рекомендуется 300-500) |
| Неадекватный ответ | Плохой системный промпт | Уточните роль, правила и ограничения |
| Баланс 0 | Закончились средства | Пополните на platform.openai.com -> Billing |

**Оптимизация расходов:** gpt-3.5-turbo для простых задач, кэширование FAQ, ограничение 50-200 запросов/день.

## 18. Интеграция Bitrix24 не работает

**Симптомы:** контакт/лид/сделка не создается, ошибка HTTP-запроса.

**Решения:**
- Проверьте webhook URL: `https://домен.bitrix24.ru/rest/1/TOKEN/` -- должен быть актуальным.
- Проверьте права: CRM, Пользователи, Задачи должны быть включены.
- Проверьте формат JSON в теле запроса.
- Если ошибка "Access denied" -- переиздайте webhook.
- Проверьте дубликаты: перед созданием контакта ищите по телефону (`crm.contact.list`).
- Лимиты Bitrix24 API: до 2 запросов/сек.

## 19. Пользователь не может пройти форму

**Симптомы:** форма зависает, валидация не принимает ответ, данные не сохраняются.

**Решения:**
- Проверьте тип поля: если ожидается число, а пользователь вводит текст -- выдайте понятную ошибку.
- Regex-валидация: протестируйте регулярное выражение на regex101.com.
- Макс. попыток: если установлено N попыток -- добавьте блок "Ошибка" для превышения.
- Кнопка "Пропустить": для необязательных полей.
- Кнопка "Отмена": для выхода из формы.
- Проверьте, что переменная для сохранения создана и имеет правильный тип.

## 20. Статистика показывает неверные данные

**Симптомы:** счетчики не совпадают, метрики не обновляются.

**Причины:**
- **Задержка обновления:** статистика может обновляться с задержкой (до 15 минут).
- **Тестовые данные:** ваши собственные действия включаются в статистику. Используйте тестовый аккаунт.
- **Заблокированные пользователи:** все еще считаются в "Всего", но не в "Активные".
- **Дублирование счетчиков:** один пользователь может запускать сценарий несколько раз. Добавьте условие: `{already_counted} != true`.
- **Часовой пояс:** статистика в UTC, а не в локальном времени.

**Точная аналитика:** экспортируйте данные в Google Sheets и анализируйте самостоятельно.
