# 06. Оплата и Магазин -- Глубокий справочник

## Video 34: 34_Multivaljutnyj_Magazin_Korzina
**Тема:** Создание мультивалютного Telegram-магазина с корзиной, продажа физических (MacBook) и электронных товаров (подарочный сертификат), промокоды, варианты доставки и оплаты
**PuzzleBot-элементы:** Магазин (вкладка), платежная система, варианты доставки, способы оплаты, категории товаров, группы товаров, акции/промокоды, электронные товары (список), блок "Товар" (конструктор), форма ввода (в доставке), изменение стоимости чека, команда после покупки
**Категория:** Магазин
**Ключевые техники:**
- Мультивалютность: указание цен в рублях и долларах одновременно
- Настройка древовидных вариантов доставки с подвариантами (курьер / самовывоз с выбором адреса / без доставки для электронных товаров)
- Настройка способов оплаты с подвариантами (наличный/безналичный, нужна сдача/без сдачи)
- Галочка "завершить оформление заказа без оплаты" для оплаты вне бота
- Генерация уникальных промокодов через акции
- Продажа электронных товаров со списком промокодов (каждый покупатель получает уникальный код)
- Переменная для вывода одного элемента из списка
- Скидка на доставку через изменение стоимости чека (понизить на сумму)
**Шаги реализации:**
1. Подключить платежную систему
2. Открыть вкладку "Магазин", включить, выбрать валюты (рубли + доллары), сохранить
3. Настроить варианты доставки: курьер (с формой ввода адреса), самовывоз (два подварианта с адресами, один со скидкой), без доставки (для электронных товаров)
4. Настроить способы оплаты: наличный / безналичный расчет с подвариантами, галочка "завершить без оплаты"
5. Создать категории товаров (MacBook Pro, MacBook Air)
6. Добавить товары с ценой в двух валютах, привязать к категориям
7. Объединить товары в группы для отображения в одном блоке
8. Создать акцию типа "промокод" (уникальный, с генерацией), настроить снижение стоимости
9. Создать электронный товар, вставить список промокодов
10. Скопировать переменную для вывода элемента из списка, добавить в команду после покупки
11. В конструкторе добавить блок "Товар" с выбранными товарами
12. Опубликовать и протестировать
**Полезные детали:** Акция типа "промокод" применяется к сумме товаров, но не к доставке. При создании электронного товара промокоды вставляются в "список", и каждый покупатель получает уникальный код. Группы товаров позволяют отобразить несколько товаров в одном блоке-карусели.

## Video 53: 53_Sdelat_Platnyj_Telegram_Kanal
**Тема:** Создание платного доступа в группу/канал Telegram через бота с оплатой
**PuzzleBot-элементы:** Платежные системы (вкладка "Настройки"), стартовая команда, текстовый блок, инлайн-клавиатура (действие "Платеж"), действие в ресурсах ("Принять заявку на вступление"), события ресурса ("Заявка на вступление"), дополнительные настройки ("Выполнение только из клавиатуры")
**Категория:** Оплата
**Ключевые техники:**
- Подключение платежной системы через Настройки > Платежные системы (номер кошелька + секретный ключ)
- Создание кнопки с действием "Платеж" в инлайн-клавиатуре (название, стоимость, команда при успехе)
- Автоматическое принятие заявки на вступление через действие в ресурсах
- Настройка событий ресурса для обработки заявок на вступление
- Создание пригласительной ссылки с функцией "Заявки на вступление" в Telegram
**Шаги реализации:**
1. Подключить платежную систему: Настройки > Платежные системы > выбрать систему > указать кошелёк и ключ > сохранить
2. В конструкторе открыть команду "Старт", добавить текст приветствия
3. Добавить инлайн-клавиатуру с действием "Платеж": название кнопки, наименование платежа, стоимость, команда при успешной оплате
4. В созданной команде (при успешной оплате) добавить действие в ресурсах: выбрать ресурс > "Принять заявку на вступление" + текстовый блок
5. В дополнительных настройках поставить "Выполнение только из клавиатуры"
6. Настроить событие ресурса "Заявка на вступление": тип действия "Команда/Условия" > команда "Старт"
7. В Telegram создать пригласительную ссылку с включённой функцией "Заявки на вступление"
**Полезные детали:** Опция "Открывать веб-приложение" в настройках платёжной системы улучшает UX. Галочка "Выполнение только из клавиатуры" предотвращает случайный вызов команды. Пользователь переходит по ссылке > подаёт заявку > переходит в бота > оплачивает > заявка одобряется автоматически.

## Video 60: 60_Nastraivaem_Platnuju_Podpisku_Kanal
**Тема:** Создание ежемесячной платной подписки на канал с напоминаниями и автоматическим управлением доступом
**PuzzleBot-элементы:** Персональная переменная (число, дни подписки), категории (активная/неактивная подписка), инлайн-клавиатура (действие "Платеж"), действие "Изменить переменную" (прибавить дни), действие "Изменить категории", действие в ресурсах ("Удалить пользователя"), условия (проверка значения переменной), сценарии (ежедневное вычитание, повторение поста), события ресурса (заявка на вступление: принять/отклонить по категории), действие "Изменить сценарий" (активация/деактивация), пригласительная ссылка с заявками
**Категория:** Оплата
**Ключевые техники:**
- Ежедневное вычитание дней подписки через сценарий с повторением
- Условия проверки оставшихся дней: 2 дня -- напоминание, 0 -- удаление из канала
- Автоматическое принятие/отклонение заявок по категории (активная/неактивная подписка)
- Активация сценария при оплате и деактивация при истечении подписки
- Использование пригласительной ссылки с функцией "Заявки на вступление"
**Шаги реализации:**
1. Создать числовую персональную переменную "Дни подписки"
2. Создать категории "Активная подписка" и "Неактивная подписка"
3. В стартовой команде: текст + инлайн-кнопка с действием "Платеж" (валюта, стоимость, команда при успехе)
4. В команде успешной оплаты: текст + ссылка на канал (пригласительная с заявками) + прибавить дни + изменить категории (активная ON, неактивная OFF) + активировать сценарий
5. Создать команду "Напоминание" (за 2 дня): текст + кнопка оплаты для продления
6. Создать команду "Подписка истекла": текст + кнопка оплаты + изменить категории (активная OFF, неактивная ON) + удалить пользователя из ресурса + деактивировать сценарий
7. Создать условие: проверка переменной = 2 > напоминание; проверка переменной = 0 > подписка истекла
8. Создать сценарий: перезапуск ON, не завершать после выполнения; пост "через 1 день" с повторением каждый день; действие "вычесть 1" из переменной (последовательность "До") + отправить условие
9. В событиях ресурса: "Заявка на вступление" > принять (если категория "Активная") / отклонить (если нет категории)
**Полезные детали:** В сценарии порядок важен: сначала вычесть день из переменной (последовательность "До"), потом отправить условие для проверки. Убрать галочку "Завершить после выполнения всех постов" чтобы сценарий работал бесконечно. Пригласительная ссылка с заявками обязательна -- без неё бот не сможет управлять доступом. При продлении подписки дни прибавляются к текущему остатку.

## Video 72: 72_Obzor_Vkladki_Magazin_Servise
**Тема:** Обзор вкладки «Магазин» -- часть 2: страница товаров (CSV импорт/экспорт, электронные товары), страница заказов (4 состояния), настройка акций (скидки, промокоды, условия, приоритеты).
**PuzzleBot-элементы:** Магазин > Товары (обычный / электронный, группа товаров, превью, цена по валютам, остаток, артикул, категория), Заказы (завершённый, в процессе, ожидают оплаты, отменённые), Акции (скидка / промокод, условия: категория, сумма, количество, конкретный товар, категория товара; изменение стоимости, добавление товара, отключение по дате/количеству, суммирование/замена с приоритетом)
**Категория:** Магазин
**Ключевые техники:**
- Экспорт/импорт товаров в CSV формате через меню с тремя точками
- Электронный товар: загрузка элементов (ссылки, промокоды), отправка команды после покупки с переменной элемента
- Акция-промокод: генерация общих или уникальных фраз
- 5 типов условий акций: категория пользователя, сумма товаров, количество позиций, конкретный товар, товар из категории
- Суммирование или замена акций с приоритетами
- Изменение стоимости отдельно для товаров, доставки или оплаты
**Шаги реализации:**
1. Страница товаров: добавить товар > заполнить название, описание
2. Тип товара: обычный или электронный; для электронного -- загрузить элементы + команда после покупки
3. Настроить превью (фото/видео/аудио), цену по валютам, остаток, артикул, категорию
4. Доп. настройки: команда после покупки, изменение сценария
5. Страница заказов: управление 4 состояниями (завершённый, в процессе, ожидают оплаты, отменённые)
6. Вкладка «Акции»: создать акцию > название, описание > тип (скидка / промокод)
7. Для промокода: общая фраза или генерация уникальных
8. Настроить условия (все / одно из): категория, сумма, количество, товар, категория товаров
9. Изменение стоимости (товары / доставка / оплата), добавление бесплатного товара, дата отключения
10. Суммирование / замена с приоритетом > сохранить и включить акцию
**Полезные детали:** Акция создаётся выключенной -- не забудьте включить. Элементы электронного товара можно отправлять в случайном порядке и задавать цикличность. В заказах со статусом «В процессе» администратор может вносить изменения (добавить/убрать товары, изменить доставку/оплату). Приоритет замены: если новая акция имеет более низкий приоритет, действующая не будет заменена.
