## Video 96: Sozdaem_Platnyj_Dostup_Ssylke
**Тема:** Платный доступ по пригласительной ссылке в группу/канал с автоматическим удалением при остановке бота
**PuzzleBot-элементы:** Модерация (категории «Доступ» и «Запрет»), условия с проверкой категорий, inline-клавиатура с платежом, действие «Изменить категорию», действие в ресурсах «Принять заявку на вступление» и «Удалить пользователя», события ресурса (заявка на вступление), события бота (пользователь остановил бота), исключающее правило
**Категория:** Оплата
**Ключевые техники:**
- Две категории модерации: «Доступ» (разрешает вступление) и «Запрет» (запрещает)
- Условие проверяет наличие категории «Доступ»: есть → ссылка в группу; нет → предложение оплатить
- Автоматическое одобрение заявки в ресурсе по наличию категории
- Удаление пользователя из группы при остановке бота
**Шаги реализации:**
1. В «Модерации» создать две категории: «Доступ» и «Запрет»
2. Создать команду оплаты: текстовый блок + inline-кнопка «Платёж» (валюта, стоимость, команда успеха)
3. В команде успеха: действие «Изменить категорию» (добавить «Доступ», убрать «Запрет») + действие в ресурсах «Принять заявку» + текстовый блок со ссылкой на группу
4. Создать условие: правило 1 — проверка наличия категории «Доступ» → отправить команду со ссылкой; исключающее правило — добавить категорию «Запрет» + отправить команду оплаты
5. Создать команду удаления: действие в ресурсах → «Удалить пользователя»
6. В стартовой команде: действие «Отправить условие»
7. В ресурсе → События → «Заявка на вступление»: принять заявку (допнастройки: категория «Доступ»)
8. В боте → События → «Пользователь остановил бота»: отправить команду удаления (допнастройки: категория одобрения)
9. Опубликовать и проверить: оплата → ссылка → заявка → автоматическое одобрение; остановка бота → удаление из группы
**Полезные детали:** Категория «Запрет» назначается в исключающем правиле условия, когда у пользователя нет «Доступа» — это дополнительная маркировка неоплативших. При остановке бота (событие) проверяется наличие категории одобрения, чтобы удалять только тех, кто ранее получил доступ. В событии «Заявка на вступление» допнастройки с категорией определяют, для каких пользователей срабатывает автоматическое принятие.

## Video 97: Sozdaem_Chat_Bota_Magazina
**Тема:** Создание и настройка полноценного магазина одежды в Telegram-боте через PuzzleBot
**PuzzleBot-элементы:** Вкладка «Магазин», варианты доставки, варианты оплаты, блок «Товар», категории товаров, группы товаров, формы ввода, текстовый блок, обычная клавиатура, кнопка «Переход к команде», изменение стоимости чека (скидка), чек, корзина
**Категория:** Магазин
**Ключевые техники:**
- Активация магазина с выбором валюты (рубли)
- Настройка нескольких вариантов доставки (курьер, самовывоз, почта) с разной стоимостью
- Скидка для самовывоза через «Изменить стоимость чека» -> «Понизить»
- Настройка вариантов оплаты с подвариантами (наличный/безналичный расчет)
- Завершение оформления заказа без оплаты в боте (для наличного/безналичного расчета)
- Создание категорий и групп товаров для отображения в одном блоке
**Шаги реализации:**
1. Создать бота и подключить к PuzzleBot, подключить платежную систему
2. Перейти во вкладку «Магазин», активировать, выбрать валюту
3. Активировать доставку, настроить варианты (курьер, самовывоз, почта) с ценами и формами ввода для адреса
4. Настроить скидку для самовывоза через «Изменить стоимость чека» -> «Понизить»
5. Настроить варианты оплаты: наличный (с подвариантами «Нужна сдача»/«Без сдачи») и безналичный расчет
6. Для наличного/безналичного расчета поставить галочку «Завершить оформление заказа без оплаты»
7. Добавить товары: заполнить информацию, загрузить изображения, указать цену и остаток, выбрать категорию
8. Создать группы товаров для объединения в одном отображении
9. В конструкторе: стартовая команда -> приветствие -> блок «Товар» с выбором способа отображения
10. Опубликовать и протестировать полную цепочку: товар -> корзина -> оформление -> доставка -> оплата -> чек
**Полезные детали:** Варианты доставки создаются с автоматическими шаблонами, которые можно удалять или дополнять. В шаблоне курьера автоматически есть текстовый блок с формой ввода для адреса. Ответы на вопросы в формах доставки автоматически отображаются в чеке. Для варианта «Нужна сдача» добавляется форма ввода с маской «Число». Группы товаров позволяют отображать несколько товаров в одном блоке с превью.

## Video 102: Sozdajom_Platnuju_Podpisku_Telegram
**Тема:** Настройка платной подписки для получения права писать в чат Telegram с автоматическим истечением срока
**PuzzleBot-элементы:** Платежная система, вкладка «Модерация», категории пользователей, настройки прав (запрет/разрешение отправки сообщений), вкладка «Сценарии» (бывший «Автопостинг»), тип отправки «Сразу»/«Через», добавление в категорию чата, конструктор, кнопка «Платеж», функция «Выполнение только из клавиатуры», запуск сценария
**Категория:** Оплата
**Ключевые техники:**
- Создание категорий модерации с разными правами доступа к чату
- Запрет отправки сообщений для категории «Без» (по умолчанию)
- Разрешение отправки сообщений для платной категории
- Автоматическое переключение категорий через сценарий с таймером
- Использование сценария для автоматического истечения подписки
- Защита команды от обхода оплаты через «Выполнение только из клавиатуры»
**Шаги реализации:**
1. Подключить платежную систему (номер кошелька + токен)
2. В модерации чата: категория «Без» — запретить отправку сообщений
3. Создать вторую категорию (платную) — разрешить отправку сообщений
4. Создать сценарий: пост 1 (тип «Сразу») — добавить в платную категорию + текст; пост 2 (тип «Через», например, 1 минута) — вернуть в категорию «Без» + текст
5. В конструкторе: стартовая команда с приветствием и кнопкой «Платеж» (цена 2 рубля, переход при успехе)
6. Команда «Успех»: текст + включить «Выполнение только из клавиатуры» + запуск сценария
7. Опубликовать и проверить: без оплаты нет права писать, после оплаты — есть, через заданное время — снова нет
**Полезные детали:** Вкладка «Сценарии» ранее называлась «Автопостинг». Функция «Выполнение только из клавиатуры» защищает от вызова команды напрямую (в обход оплаты). Сценарий используется как таймер для автоматического снятия подписки. При входе по ссылке-приглашению без оплаты пользователь не может отправлять сообщения.

- Удаление категории «У бота» и добавление категории «Канала» в реферальной системе
**Шаги реализации:**
