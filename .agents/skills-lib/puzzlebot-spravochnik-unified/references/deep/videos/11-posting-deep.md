# 11. Постинг -- Глубокий справочник

## Video 29: 29_Vkladka_Posting
**Тема:** Обзор вкладки "Постинг": создание, планирование и редактирование постов с мультипостингом
**PuzzleBot-элементы:** Вкладка Постинг, фильтр постов, миниатюры постов (дата, статус, места отправки, текст, иконки блоков), статусы (черновик, в очереди, отправлен), дата и время отправки, мультипостинг (бот + ресурсы), автомат (переход к команде после отправки), дублирование поста, отключение уведомлений, редактирование отправленного поста, кнопка "Опубликовать изменения"
**Категория:** Posting
**Ключевые техники:**
- Мультипостинг: отправка поста одновременно в бота и все подключённые ресурсы (группы/каналы)
- Три статуса поста: черновик, в очереди, отправлен
- Редактирование отправленного поста: можно менять текст/медиа, но нельзя добавлять новые блоки
- Автомат: автоматический переход к команде после отправки (работает только при отправке в бота)
- Отключение уведомлений: пользователь получит пост без звука
- Отличие от Конструктора: нет возможности прикрепить обычную клавиатуру
- Фильтрация постов и группировка по датам
**Шаги реализации:**
1. Перейти на вкладку "Постинг"
2. Нажать кнопку создания поста
3. Настроить дату и время отправки
4. Выбрать места отправки: "Изменить список" -> указать ресурсы
5. Добавить блоки контента (текст, медиа, инлайн-клавиатура)
6. При необходимости настроить автомат (переход к команде)
7. Сменить статус поста или отправить сразу
8. Для редактирования: открыть отправленный пост, внести изменения, нажать "Опубликовать изменения"
**Полезные детали:** Количество подписчиков бота влияет на скорость отправки постов (большие базы -- медленнее). Время можно изменить прямо из миниатюры поста. Для отмены изменений отправленного поста есть кнопка "Отменить". Модальное окно схоже с конструктором -- рекомендуется сначала изучить конструктор.

## Video 74: 74_Obzor_Vkladki_Posting_Servise
**Тема:** Обзор вкладки «Постинг» -- создание, планирование и редактирование публикаций в боте и ресурсах, фильтры, действия, опросы и викторины.
**PuzzleBot-элементы:** Вкладка «Постинг» (фильтры: отправленные, в очереди, черновики), модальное окно поста (блоки как в конструкторе), дополнительные настройки (защита от пересылки/сохранения, повторение), действия (отправка команды, смена категории, закрепление, удаление), категории и аудитории, спойлер, блоки опрос и викторина, inline-кнопки, редактирование отправленных постов
**Категория:** Posting
**Ключевые техники:**
- Фильтрация постов: по статусу (отправленные / очередь / черновики) и дате
- Отправка поста одновременно в бота и ресурсы
- Категории vs аудитории: категория -- группа пользователей (вручную/автоматически), аудитория -- подписчики ресурса, являющиеся пользователями бота
- Редактирование уже отправленного поста (без добавления новых блоков)
- Уникальные блоки постинга: опросы и викторины (недоступны в конструкторе)
- Дублирование поста и отправка без уведомления
**Шаги реализации:**
1. Вкладка «Постинг» > кнопка «Создать новый пост»
2. Модальное окно: добавить блоки (текст, медиа, inline-кнопки, опрос/викторина)
3. Настройки поста: дата/время публикации, место отправки (бот + ресурсы)
4. Выбрать категории/аудитории для таргетирования (отправка по категориям -- только внутри бота)
5. Дополнительные настройки: защита от пересылки, повторение поста
6. Действия: отправка команды, смена категории, закрепление, удаление
7. Статус: «Запланировать» / «Черновик» > кнопки «Отправить сейчас», «Предпросмотр», «Удалить»
8. Для спойлера: скрыть часть текста
9. Редактирование отправленного поста: кликнуть на миниатюру, изменить текст, нажать «Опубликовать»
10. Проверить в Telegram (бот + ресурс)
**Полезные детали:** Отправка по категориям работает только внутри бота -- при отправке в ресурсы пост получат все подписчики ресурса. В постинге нет возможности прикрепить обычную клавиатуру. Отправленный пост можно редактировать, но нельзя добавлять новые блоки. Рядом с датой в левой панели отображается количество запланированных/черновых/отправленных постов. Для отправки в ресурс его нужно сначала подключить.

## Video 81: Otpravljaem_Post_Reakcijami_Neskolko
**Тема:** Публикация постов с реакциями одновременно в несколько ресурсов, редактирование опубликованных постов
**PuzzleBot-элементы:** Постинг, текстовый блок, inline-клавиатура, действие «Реакция», выбор мест отправки, редактирование поста
**Категория:** Posting
**Ключевые техники:**
- Создание поста с кнопками-реакциями через раздел «Постинг» ресурса
- Одновременная отправка в несколько ресурсов (чатов и каналов)
- Редактирование уже отправленного поста с применением изменений ко всем ресурсам
**Шаги реализации:**
1. Открыть бота, к которому подключены чаты и каналы; перейти в любой ресурс, вкладка «Постинг»
2. Создать новый пост: добавить текстовый блок с текстом сообщения
3. Добавить inline-клавиатуру; в типе действия выбрать «Реакция» и вписать эмодзи реакции для каждой кнопки
4. Указать места для отправки (выбрать несколько ресурсов)
5. Сохранить и нажать «Отправить сейчас»
6. Для редактирования: открыть пост, изменить текст, нажать «Опубликовать изменения» — текст обновится во всех ресурсах
**Полезные детали:** Изменения в тексте поста автоматически применяются ко всем ресурсам, куда пост был отправлен. Тип действия кнопки «Реакция» позволяет добавлять интерактивные кнопки-реакции под постом.
