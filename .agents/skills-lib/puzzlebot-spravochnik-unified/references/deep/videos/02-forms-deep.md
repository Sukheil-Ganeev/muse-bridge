# 02. Формы ввода -- Глубокий справочник

## Video 05: 05_Quiz_Test_Formy_Vvoda_3
**Тема:** Создание квиз-теста с вариативной системой, где каждый вариант ответа открывает свои подварианты. Третья часть серии по формам ввода.
**PuzzleBot-элементы:** Формы ввода (тип: тестирование), Переход к команде из формы ввода, Инлайн-клавиатура, Настройки форм ввода (объединение уведомлений в "Сложный" тип), Галочка "Не записывать ответ".
**Категория:** Формы ввода
**Ключевые техники:**
- Создание вариативного квиза: каждый вариант ответа ведет к отдельной команде с новыми подвариантами
- Использование действия "Переход к команде" в вариантах формы ввода для ветвления
- Галочка "Не записывать ответ" на кнопке выхода, чтобы не получать уведомление при отказе от ответа
- Объединение уведомлений: Настройки бота > Формы ввода > Создать правило типа "Сложный"
- Указание завершающих форм ввода в правиле -- после ответа на любую из них квиз считается завершенным
**Шаги реализации:**
1. Создать в меню кнопку перехода к команде начала квиза
2. Открыть новую команду, добавить форму ввода с вопросом (выбор типа автомобиля)
3. Указать название для статистики, тип ввода, варианты ответа
4. Для каждого варианта настроить действие "Переход к команде" к соответствующей ветке
5. Добавить кнопку "Выход" с галочкой "Не записывать ответ"
6. Заполнить дочерние команды аналогичными формами ввода с подвариантами
7. Для конечных форм ввода задать переход к общей завершающей команде
8. В завершающей команде добавить текстовый блок и инлайн-кнопку перехода в меню
9. Настроить объединение уведомлений: Настройки > Формы ввода > Создать правило > Тип "Сложный"
10. Указать команды с завершающими формами и остальные участвующие формы
11. Опубликовать и проверить
**Полезные детали:**
- Тип правила "Сложный" нужен, когда пользователь может ответить не на все формы ввода (вариативная система)
- После настройки правила приходит одно общее уведомление вместо отдельных на каждую форму
- Серия из трех частей: 1 -- регистрация, 2 -- тест с подсчетом, 3 -- вариативный квиз

## Video 07: 07_Registracija_Formy_Vvoda_1
**Тема:** Создание простой регистрации в боте через формы ввода (имя, телефон) с тайм-аутами и защитой от повторного прохождения. Первая часть серии.
**PuzzleBot-элементы:** Формы ввода (текст, запрос контакта), Переменные из формы ввода, Маска ввода, Реакция на ответ, Текст ошибки, Тайм-ауты, Дополнительные настройки (переход к команде, отключение повторного прохождения), Статистика форм ввода.
**Категория:** Формы ввода
**Ключевые техники:**
- Форма ввода с типом "Отправка сообщения" для текстовых данных (имя)
- Форма ввода с типом "Запрос контакта" для получения телефона (кнопка "Поделиться контактом")
- Добавление реакции на ответ с использованием переменной из формы ввода
- Текст ошибки при несоответствии маске ввода
- Тайм-ауты между сообщениями, чтобы не сыпались мгновенно
- Отключение повторного прохождения: в дополнительных настройках формы указать команду, куда перенаправить при повторном входе
**Шаги реализации:**
1. Удалить шаблонные команды (выделить через Shift, удалить, опубликовать)
2. Открыть команду Start, добавить текстовый блок с приветствием
3. Добавить форму ввода имени: текст вопроса, название для статистики, тип "Отправка сообщения"
4. Добавить реакцию на ответ с переменной из формы ввода, текст ошибки
5. Добавить вторую форму ввода телефона: тип "Запрос контакта", изменить текст кнопки
6. Добавить завершающий текстовый блок
7. Создать вторую команду (меню), указать переход к ней в дополнительных настройках Start
8. Добавить тайм-ауты для комфортного UX
9. В первой форме ввода отключить повторное прохождение, указать команду-перенаправление (меню)
10. Опубликовать, проверить, удалить ответы в статистике при необходимости
**Полезные детали:**
- Название для статистики формы не видно пользователю -- это внутреннее имя
- При повторном запуске бота пользователь автоматически перенаправляется в меню (не проходит регистрацию заново)
- Для удаления тестовых ответов: вкладка Статистика -> удалить ответы на формы ввода

## Video 09: 09_Test_Formy_Vvoda_2
**Тема:** Создание теста с подсчетом правильных ответов и переходом на разные команды в зависимости от результата. Вторая часть серии.
**PuzzleBot-элементы:** Формы ввода (тип: тестирование), Блок "Результат" (подсчет правильных ответов), Условия в результате (сумма ответов >= N), Переменная из блока "Результат", Переход к команде по результату, Удаление формы после ответа.
**Категория:** Формы ввода
**Ключевые техники:**
- Использование типа ввода "Тестирование" для форм с вариантами ответов
- Блок "Результат" для автоматического подсчета правильных ответов по выбранным формам
- Настройка условий: при сумме от 0 (хотя бы одна ошибка) -- одна команда; при сумме от 3 (все правильно) -- другая
- Переменная из блока "Результат" для вывода количества правильных ответов пользователю
- Удаление формы после ответа для чистоты чата
- Тип блока "Телеграмм" для разнообразия вопросов
**Шаги реализации:**
1. Создать кнопку в меню с переходом к команде теста
2. Открыть команду, добавить первую форму ввода с типом "Тестирование"
3. Задать вопрос, название для статистики, варианты ответа (правильный/неправильный)
4. По аналогии создать второй и третий вопрос (можно использовать тип блока "Телеграмм")
5. Добавить блок "Результат", выбрать нужные формы
6. Настроить первое условие: сумма от 0 -- переход к команде "Ошибка"
7. Настроить второе условие: сумма от 3 -- переход к команде "Все правильно"
8. Вставить переменную из блока "Результат" в текст команд для отображения числа правильных ответов
9. Включить удаление формы после ответа в каждой форме
10. Опубликовать и проверить
**Полезные детали:**
- Порядок условий в блоке "Результат" важен: условие с большим значением (все правильно) должно быть ниже
- Удаление формы после ответа улучшает пользовательский опыт
- Переменная из блока "Результат" отображает число правильных ответов в тексте

## Video 19: 19_Uvedomlenie_Otvety_Forma
**Тема:** Запись заявки через форму ввода и отправка уведомлений о ней в группу/канал (два способа: простой и сложный)
**PuzzleBot-элементы:** Вкладка Настройки -> Уведомления, Конструктор, форма ввода, текстовый блок, переменные (имя пользователя, переменная формы ввода), действие "Отправить команду или условия", параметр "Изменить места отправки", ресурс (группа)
**Категория:** Формы ввода
**Ключевые техники:**
- Простой способ: вкладка Настройки -> Уведомления -> правило дублирования (шаблонное, нередактируемое)
- Сложный способ: форма ввода + отдельная команда-уведомление + отправка в ресурс
- Использование переменных в шаблоне уведомления: имя пользователя + текст заявки из формы ввода
- Отправка команды в ресурс (группу): действие "Отправить команду" с галочкой "Изменить места отправки"
**Шаги реализации:**
1. (Простой способ) Перейти в Настройки -> Уведомления, создать правило дублирования, выбрать ресурс
2. (Сложный способ) В команде "Старт" добавить блок "Форма ввода"
3. Добавить вопрос в виде текстового блока, указать название для статистики, тип ввода "Отправка сообщения"
4. Добавить реакцию на ответ
5. Создать отдельную команду для уведомления
6. В команде уведомления добавить текстовый блок с переменными: имя пользователя + переменная формы ввода
7. Вернуться в команду "Старт", в разделе "Действия" добавить "Отправить команду или условия"
8. Указать команду уведомления, поставить галочку "Изменить места отправки"
9. В параметре "Ресурс" выбрать нужную группу, нажать "Добавить"
10. Опубликовать изменения
**Полезные детали:** Сложный способ позволяет полностью настроить внешний вид уведомления (форматирование, переменные, кнопки). Работает как для групп, так и для каналов. Требуется предварительное подключение чата/канала к PuzzleBot.

## Video 62: 62_Nastraivaem_Proverku_Dannyh_Reguljarnye
**Тема:** Использование регулярных выражений для валидации данных в формах ввода (ФИО, дата, телефон, email, ИНН, ссылка VK, паспорт, номер карты)
**PuzzleBot-элементы:** Мини-приложение, блок "Форма ввода" (маска ввода: регулярное выражение), поле "Регулярные выражения", поле "Плейсхолдер", поле "Ошибка", кнопка отправки с переходом к мини-приложению, текстовый блок, инлайн-клавиатура (переход к мини-приложению), стартовая команда
**Категория:** Формы ввода
**Ключевые техники:**
- Регулярные выражения в форме ввода для валидации: ФИО (заглавные буквы + пробелы), дата (ДД.ММ.ГГГГ), телефон (+7...), email (только Gmail), ИНН (10 или 12 цифр), ссылка VK, паспорт (4 + 6 цифр), номер карты (16 цифр через дефис)
- Плейсхолдер как подсказка формата внутри поля ввода
- Сообщение об ошибке при несоответствии формату
- Переход между мини-приложениями после успешной отправки формы
**Шаги реализации:**
1. Создать мини-приложение для регистрации
2. Добавить текстовый блок оформления
3. Для каждого поля добавить блок "Форма ввода":
   - Заголовок (вопрос)
   - Маска ввода > "Регулярное выражение"
   - Само выражение (regex)
   - Плейсхолдер (подсказка формата)
   - Сообщение об ошибке
4. Примеры regex:
   - ФИО: `^[А-ЯЁ][а-яё]+\s[А-ЯЁ][а-яё]+\s[А-ЯЁ][а-яё]+$`
   - Дата: `^(0[1-9]|[12][0-9]|3[01])\.(0[1-9]|1[0-2])\.(19|20)\d{2}$`
   - Телефон: `^+7\s?\(?\d{3}\)?[\s-]?\d{3}[\s-]?\d{2}[\s-]?\d{2}$`
   - Email Gmail: `^[a-zA-Z0-9._%+-]+@gmail\.com$`
   - ИНН: `^\d{10}$|^\d{12}$`
   - VK: `^(https?://)?(www\.)?vk\.com/[a-zA-Z0-9_.]+$`
   - Паспорт: `^\d{4}\s\d{6}$`
   - Карта: `^\d{4}-\d{4}-\d{4}-\d{4}$`
5. Настроить кнопку отправки с переходом к следующему мини-приложению
6. В стартовой команде добавить кнопку перехода к мини-приложению регистрации
**Полезные детали:** Регулярные выражения позволяют сразу отсеивать ошибки ввода. Каждое поле может иметь своё сообщение об ошибке и подсказку. Символы regex: `^` -- начало строки, `$` -- конец строки, `\s` -- пробел, `\d` -- цифра, `|` -- "или", `[]` -- набор символов, `+` -- одно или более повторений. Ошибки отображаются под каждым полем отдельно.
