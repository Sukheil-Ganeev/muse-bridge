# 08. Мини-приложения -- Глубокий справочник

## Video 70: 70_Novye_Funkcii_Mini_Prilozhenija
**Тема:** Новые функции мини-приложений (продолжение): блок «Меню» (фиксированное нижнее меню, SVG/PNG иконки, активные страницы), блок «Вкладки» (обычные до 5 / расширенные до 24), обновлённая «Подстановка» (сворачиваемый контент), цвета кнопок клавиатуры.
**PuzzleBot-элементы:** Блок «Меню» (до 5 кнопок, стили: только изображение / изображение + название, SVG/PNG, активные страницы), блок «Вкладки» (обычные до 5 / расширенные до 24, связь с мини-приложениями), блок «Подстановка» (скрыть подзаголовок, сворачиваемый контент, расположение и стиль заголовка), клавиатура (цвета кнопок для типов «Обычная» / «Фиксированная»)
**Категория:** Мини-приложения
**Ключевые техники:**
- Блок «Меню»: фиксированное нижнее меню с SVG-иконками (меняют цвет при активности) или PNG (цвет меняется только у надписи)
- Настройка активных страниц для кнопок меню -- подсветка при переходе во вложенные разделы
- Использование блока «Подстановка» для отображения меню на всех страницах без дублирования
- Расширенные вкладки (до 24) с иконками -- работают по принципу подстановки контента из мини-приложений
- Сворачиваемая подстановка: контент по умолчанию свёрнут, разворачивается по клику на заголовок
**Шаги реализации:**
1. Создать мини-приложение для меню > блок «Меню» > выбрать стиль > загрузить иконки (рекомендуется SVG)
2. Для каждой кнопки: задать действие (переход в мини-приложение), указать активные страницы (включая подразделы)
3. На всех страницах добавить блок «Подстановка» с меню-приложением
4. Блок «Вкладки»: выбрать тип (обычные / расширенные), связать каждую вкладку с мини-приложением
5. Расширенные вкладки: загрузить иконки, задать порядок, в доп. настройках -- вкладка по умолчанию
6. Подстановка со сворачиванием: включить «Скрыть подзаголовок», выбрать расположение и стиль заголовка
7. Кнопки клавиатуры: задать произвольный цвет для типов «Обычная» / «Фиксированная»
8. В стартовой команде: текст + inline-кнопка перехода к основному мини-приложению
9. Настроить отображение меню на всех вкладках через «Подстановку» + отметить активные страницы
10. Опубликовать и проверить
**Полезные детали:** SVG-иконки меняют цвет автоматически при активации кнопки (предустановленный -- синий, можно изменить в кастомизации). PNG-иконки остаются статичными, меняется только цвет надписи. Активные страницы нужно указывать явно для всех подразделов, иначе кнопка меню не будет подсвечиваться. Блок «Подстановка» -- ключевой инструмент для единообразного меню на всех страницах.

## Video 77: 77_Obzor_Obnovlenija_PuzzleBot_Modalnoe
**Тема:** Обзор обновлений: StartPayload для мини-приложений, открытие мини-приложения из условия, заметки в конструкторе, модальное окно, кнопки подстановки, скрытие карточек, якоря, оптимизация конструктора, кнопка настройки, фуллскрин, новые формулы.
**PuzzleBot-элементы:** Переменная WebPageStartPayload, условие с проверкой переменной, подстановка условия, модальное окно (открытие мини-приложения поверх страницы), действие «Подстановка» в кнопках, заметки (комментарии на рабочей области), скрытие карточек (крестик), якоря (ссылка на блок), настройки конструктора (облегчённый вид), кнопка настройки мини-приложения (три точки), фуллскрин (через BotFather), новые формулы текста
**Категория:** Мини-приложения
**Ключевые техники:**
- WebPageStartPayload: значение после `_` в StartApp записывается в переменную (UTM-метки, маркеры)
- Условие открывает мини-приложение напрямую по результатам проверок (например, промокод по метке)
- Подстановка условий в блоке «Подстановка» -- динамическое отображение контента
- Модальное окно: открытие мини-приложения поверх текущей страницы с заголовком
- Кнопки с действием «Подстановка» -- контент подставляется/скрывается при нажатии
- Якоря: скопировать ссылку на блок через троеточие, использовать для навигации внутри приложения
- Фуллскрин настраивается через BotFather > мини-приложения > «Основное» > «Фуллскрин»
**Шаги реализации:**
1. StartPayload: скопировать ссылку на бота, добавить `_метка` (до 512 символов)
2. Создать условие: проверка WebPageStartPayload > «сообщение содержит» > фраза метки > переход к мини-приложению
3. Второе правило условия для другой метки с другим приложением
4. В основном мини-приложении: блок «Подстановка» > ввести название условия (вместо приложения)
5. Модальное окно: блок «Клавиатура» > кнопка > действие «Открыть в модальном окне» > название приложения + заголовок
6. Кнопки подстановки: действие «Подстановка» > выбрать мини-приложение (переключается по нажатию)
7. Заметки: создать на рабочей области для пояснений
8. Якоря: троеточие рядом с блоком > «Скопировать ссылку» > использовать в кнопке (действие «Ссылка, браузер по умолчанию»)
9. Настройки > Конструктор: включить облегчённый вид (блоки скрываются при масштабировании)
10. BotFather: настроить фуллскрин и кнопку настройки мини-приложения
**Полезные детали:** StartApp в Telegram позволяет до 512 символов после `_`. Подстановка условий позволяет динамически показывать разный контент в зависимости от параметров. Модальное окно открывается поверх страницы -- удобно для деталей, настроек, подтверждений. Якоря позволяют создавать глубокие ссылки на конкретные блоки внутри мини-приложения. Новые формулы текста: изменение регистра, обрезка, усечение, очистка, фильтрация, проверка содержимого, удаление эмодзи, валидация, маскировка, извлечение, замена.

## Video 79: 79_Obrabatyvaem_Zajavki_Mini_Prilozhenii
**Тема:** Обработка заявок в мини-приложениях Telegram с помощью NoCode-таблиц: создание интерфейса просмотра заявок, одобрение/отклонение, уведомление пользователей, навигация по заявкам.
**PuzzleBot-элементы:** Мини-приложение (просмотр заявок, пустое состояние), клавиатура «Фиксированная» (кнопки принять/отклонить с цветами), условие (проверка наличия переменной), условие (без проверки -- для выполнения действий), действие «Отправить команду другому пользователю» (по переменной с ID), действие «Удалить строку» из NoCode, переменные из NoCode, команды уведомлений (одобрение/отказ), inline-клавиатура
**Категория:** Мини-приложения
**Ключевые техники:**
- Мини-приложение для просмотра заявок с переменными из NoCode (отображение данных заявки)
- Фиксированная клавиатура с цветными кнопками «Принять» / «Отклонить»
- Условие проверки наличия переменной для навигации: есть заявка > показать / нет > экран «Заявок нет»
- Отправка команды другому пользователю по ID из переменной (уведомление о решении)
- Удаление строки из NoCode после обработки заявки
- Цепочка: обработать заявку > удалить строку > перейти к следующей заявке
**Шаги реализации:**
1. Создать мини-приложение для просмотра заявок: заголовок, описание, текстовый блок с переменными из NoCode
2. Добавить фиксированную клавиатуру с кнопками «Принять» (зелёный) и «Отклонить» (красный)
3. Создать команды уведомлений: одобрение и отказ (текстовые блоки с сообщениями для пользователя)
4. Создать мини-приложение для пустого состояния (заявок нет)
5. Условие «Следующая заявка»: проверка наличия переменной > переход к приложению с заявкой / к пустому
6. Условие «Одобрить»: без проверки > отправить команду одобрения другому пользователю (по ID из переменной) > удалить строку из NoCode > перейти к условию «Следующая заявка»
7. Аналогичное условие «Отклонить» с командой отказа
8. Привязать кнопки мини-приложения к условиям одобрения/отклонения
9. Создать команду уведомления администратора о новой заявке (текст + inline-кнопка перехода к просмотру)
10. В мини-приложении отправки заявки: добавить действие «Отправить команду администратору» (выполнить другому пользователю по юзернейму)
**Полезные детали:** Заявки обрабатываются последовательно: после обработки текущей строка удаляется из NoCode и автоматически загружается следующая. Условие «без проверки» используется как контейнер для выполнения нескольких действий подряд. Уведомление администратора при поступлении новой заявки содержит inline-кнопку для быстрого перехода к просмотру. Является продолжением видео о создании заявок.

**Категория:** Мини-приложения
**Ключевые техники:**
- Мини-истории (stories) — загрузка изображений с кнопками (например, «Начать диалог» с закрытием приложения)
- Блок «Карточки» для визуальной навигации к мини-историям
