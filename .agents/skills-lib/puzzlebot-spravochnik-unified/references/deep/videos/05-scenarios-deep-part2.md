## Video 55: 55_Sozdat_Telegram_Bot_Taksi
**Тема:** Практическое руководство по созданию Telegram-бота для такси (часть 1: пассажирская часть)
**PuzzleBot-элементы:** Обычная команда (главное меню, личный кабинет), инлайн-клавиатура, форма ввода (отправка сообщения, запрос контакта), персональные переменные (точка А, точка Б, фон/телефон, количество заказов), глобальная переменная (глобал номер), действие "Изменить переменную" (прибавить +1), условия (проверка регистрации по наличию переменной), действие "Создать строку" (Google Sheets), действие "Отправить команду или условия" с изменением места отправки (канал), дублирование команд
**Категория:** Сценарии
**Ключевые техники:**
- Создание формы ввода с запросом контакта (кнопка "Поделиться контактом") для получения номера телефона
- Использование глобальной числовой переменной для автоинкремента номера заявки (+1)
- Условие проверки регистрации через наличие переменной "фон" (телефон)
- Пересылка заказа в Telegram-канал водителей через изменение места отправки
- Запись данных в Google Таблицу с несколькими листами (заявки, пассажиры)
- Структура: регистрация > личный кабинет > создание заказа > итог > пересылка водителям
**Шаги реализации:**
1. Создать бота в BotFather, подключить к PuzzleBot
2. Подключить Google Таблицу (3 листа: заявки, пассажиры, водители)
3. Создать персональные переменные: точка А (текст), точка Б (текст), фон (текст), количество заказов (число)
4. Создать глобальную переменную "глобал номер" (число!) для нумерации заявок
5. Создать команду "Главное меню" с картинкой и кнопками "Стать пассажиром" / "Стать водителем"
6. Создать условие "Проверка регистрации" (проверка наличия переменной "фон")
7. Создать форму "Регистрация номера" с запросом контакта и записью в Google Sheets (лист "Пассажир")
8. Создать формы ввода: точка А > точка Б (с кнопкой "Назад")
9. Создать команду "Итог" с отображением точек А и Б, кнопки "Отправить заказ" и "Ввести заново"
10. Создать команду "Пересылка": инкремент глобал номер +1, создать строку в Google Sheets, отправить в канал водителей
11. Создать Telegram-канал для водителей, добавить бота администратором
**Полезные детали:** Глобальная переменная для номера заявки ОБЯЗАТЕЛЬНО должна быть числового типа (не текст). Рекомендуется использовать канал, а не чат для заявок водителям (есть подводные камни с чатами). В дополнительных настройках формы ввода рекомендуется: удалить сообщение с ответом, удалить блок вопроса после ответа, удалить текущую команду после вызова следующей -- чтобы не засорять историю. Это первая часть, вторая -- взаимодействие водителей и пассажиров.

## Video 95: Sozdaem_Mini_Prilozhenie_Napominanie
**Тема:** Создание мини-приложения для продажи курсов с системой напоминаний через сценарии
**PuzzleBot-элементы:** Сценарии (с постами и повторениями), действие «Изменить сценарий» (активация/деактивация), мини-приложения (с видео), inline-клавиатура, обычная команда, блок «Видео», перезапуск сценария при повторном вызове, последовательность выполнения «До»
**Категория:** Сценарии
**Ключевые техники:**
- Сценарии с запланированными постами-напоминаниями (через указанное время)
- Перезапуск сценария при повторном вызове (в настройках сценария)
- Цепочка сценариев: один напоминает о просмотре видео, другой — о бонусе
- Деактивация одного сценария при активации другого
- Последовательность выполнения действия «Изменить сценарий» — «До» (сначала управление сценарием, потом контент)
**Шаги реализации:**
1. Создать обычную команду и два мини-приложения (видеоурок и бонус)
2. Перейти в «Сценарии»: создать сценарий 1 (напоминание о видео) → включить «Перезапуск при повторном вызове»
3. Добавить 3 поста-напоминания с разным временем отправки (тип «Через»), каждый с кнопкой → переход к мини-приложению с видео
4. Продублировать сценарий 1, переименовать в сценарий 2 (напоминание о бонусе), изменить кнопки на переход к мини-приложению с бонусом
5. В обычной команде: действие «Изменить сценарий» → активировать сценарий 1, последовательность «До» + текстовый блок + кнопка → мини-приложение видео
6. В мини-приложении видео: действие «Изменить сценарий» → активировать сценарий 2 + деактивировать сценарий 1, последовательность «До» + заголовок + блок «Видео»
7. В мини-приложении бонус: действие «Изменить сценарий» → деактивировать сценарий 2, последовательность «До» + заголовок + блок «Видео»
8. В стартовой команде: действие «Отправить команду» → первая обычная команда
9. Опубликовать и проверить цепочку напоминаний
**Полезные детали:** Перезапуск при повторном вызове сценария обнуляет таймеры и начинает цепочку заново. Последовательность выполнения «До» гарантирует, что сценарий управляется ДО показа контента пользователю. Сценарии работают как автоворонки — каждый пост отправляется по расписанию. Деактивация одного сценария при активации другого предотвращает дублирование напоминаний.

## Video 99: Sozdanie_Reakcii_Vo_Vkladke
**Тема:** Создание реакции на события во вкладке «События» в PuzzleBot
**PuzzleBot-элементы:** Вкладка «События», оповещения, реакция на событие, текстовое сообщение, событие «Пользователь был заблокирован в боте», дополнительные настройки, добавить действие
**Категория:** Сценарии
**Ключевые техники:**
- Настройка реакций на системные события бота (блокировка, запрет доступа к команде, остановка бота, неизвестная команда, начало/завершение диалога)
- Включение/выключение оповещений для различных событий
- Добавление пользовательских реакций с текстовыми сообщениями
**Шаги реализации:**
1. Перейти к боту, выбрать подключенный ресурс
2. Открыть вкладку «События»
3. Нажать «Добавить реакцию» для создания новой реакции на событие
4. Выбрать событие (например, «Пользователь был заблокирован в боте»)
5. Настроить тип действия (текстовое сообщение), ввести текст
6. Включить реакцию на событие (переключатель)
7. Сохранить изменения
**Полезные детали:** Видео очень короткое (38 секунд), без голосовой транскрипции. На скриншотах видно: левая панель с оповещениями (сообщения для заблокированных пользователей, сообщение о запрете доступа к команде, сообщение при добавлении бота в ресурс, сообщение при остановленном боте, сообщение на неизвестную команду, сообщение о начале/завершении диалога). Справа настраивается конкретная реакция на событие с типом действия «Текстовое сообщение».

## Video 107: Stavim_Parol_Chat_Bota
**Тема:** Создание системы парольного доступа к секретным разделам бота
**PuzzleBot-элементы:** Вкладка «Модерация», категории, конструктор, инлайн-команда (название = пароль), текстовый блок, действие «Изменить категории», группа команд, настройки доступа группы (по категории), инлайн-клавиатура, действие «Ссылка», действие «Отправить команду или условия», таймаут
**Категория:** Сценарии
**Ключевые техники:**
- Использование названия инлайн-команды как пароля (пользователь вводит текст = вызывает команду)
- Присвоение категории при вводе правильного пароля
- Ограничение доступа к группе команд по категории
- Таймаут для автоматического перехода к секретной команде после ввода пароля
**Шаги реализации:**
1. В модерации создать категорию (например, «Авторизованный»)
2. В конструкторе: стартовая команда с приветствием (приглашение ввести пароль)
3. Создать инлайн-команду, название которой = пароль
4. В этой команде: текстовый блок + действие «Изменить категории» -> активировать категорию
5. Создать новую группу команд, в настройках добавить доступ для созданной категории
6. В этой группе создать секретную команду с контентом (текст, ссылка и т.д.)
7. В команде-пароле добавить действие «Отправить команду или условия» -> секретная команда, установить таймаут (например, 2 секунды)
8. Опубликовать и проверить: без пароля — «Доступ ограничен», с паролем — доступ открыт
**Полезные детали:** Пароль = название инлайн-команды. Когда пользователь вводит текст, совпадающий с названием команды, она срабатывает. Группа команд с ограничением по категории показывает «Доступ ограничен» для пользователей без нужной категории. Таймаут в 2 секунды создает небольшую паузу перед показом секретного контента.
