# 12. Баллы и геймификация -- Глубокий справочник

## Video 106: Spisyvaem_Bally_Vydajom_Dostup
**Тема:** Списание баллов внутреннего баланса за продукт и предоставление постоянного доступа к контенту
**PuzzleBot-элементы:** Вкладка «Модерация», категории доступа, конструктор, инлайн-команды, кнопка «Условия», проверка наличия категории, проверка значения переменной (баланс >= N), действие «Изменить переменную» (вычитание баллов), действие «Изменить категорию», действие «Скрыть кнопку», действие «Отправить команду или условия»
**Категория:** Баллы и геймификация
**Ключевые техники:**
- Проверка наличия категории для определения «уже оплачено»
- Проверка баланса перед покупкой (переменная >= нужное количество)
- Трехуровневая логика кнопки-условия: (1) уже куплено -> переход к контенту, (2) достаточно баллов -> списание + доступ, (3) недостаточно -> скрытие кнопки
- Автоматическое изменение названия кнопки после покупки
- Постоянный доступ через категории
**Шаги реализации:**
1. В модерации создать категории доступа (например, «Доступ к гайду», «Доступ к уроку»)
2. В конструкторе создать инлайн-команды для каждого продукта (гайд, урок)
3. Создать кнопку «Условия» для каждого продукта с тремя правилами:
   - Правило 1: проверка наличия категории -> если есть, сменить название кнопки и перейти к контенту
   - Правило 2: проверка баланса >= цена -> списать баллы, активировать категорию, перейти к контенту
   - Исключающее правило: скрыть кнопку (недостаточно баллов)
4. Добавить кнопки «Условия» в личный кабинет (инлайн-команду)
5. Опубликовать и проверить: покупка списывает баллы и дает постоянный доступ
**Полезные детали:** Это продолжение серии про внутренний баланс. Категории дают постоянный доступ — после покупки кнопка меняет название и сразу ведет к контенту. Если баллов недостаточно, кнопка полностью скрывается в личном кабинете. Требуется предварительное подключение ресурса и настройка системы баллов.
