# 06. Оплата и Магазин -- Глубокий справочник

## Video 110: Sdelat_Telegram_Bot_Priema
**Тема:** Создание бота для приема оплат с подключением двух платежных систем (Telegram Stars и Prodamus)
**PuzzleBot-элементы:** BotFather, API-ключ, платежные системы (Telegram Stars, Prodamus), настройки платежных систем, конструктор, текстовый блок, переменная first_name, кнопка «Платеж» (Stars и рубли), команда при успешной оплате
**Категория:** Оплата
**Ключевые техники:**
- Подключение двух платежных систем одновременно: Telegram Stars (без настроек) и Prodamus (URL магазина + секретный ключ + адрес уведомления)
- Создание двух кнопок оплаты с разными платежными системами на одном экране
- Personalization через переменную first_name в приветствии
- Различие валют: Stars (звезды) и рубли (Prodamus)
**Шаги реализации:**
1. Создать бота в BotFather, скопировать токен
2. Добавить бота в PuzzleBot через API-ключ
3. В настройках бота: «Платежные системы» -> добавить Telegram Stars (просто сохранить)
4. Добавить Prodamus: ввести URL магазина, секретный ключ, скопировать адрес уведомления и вставить его в настройки Prodamus
5. В конструкторе: стартовая команда -> приветствие с переменной first_name -> две кнопки
6. Кнопка 1 «Telegram Stars»: действие «Платеж», валюта Stars, цена 2 звезды, переход к команде «Оплатил»
7. Кнопка 2 «Оплатить картой»: действие «Платеж», валюта рубли (Prodamus), цена 1000 руб, переход к «Оплатил»
8. Команда «Оплатил»: текст благодарности + ссылка на продукт/курс/документ
9. Опубликовать и протестировать обе кнопки
**Полезные детали:** Telegram Stars подключается одним нажатием без настроек. Prodamus требует: URL магазина, секретный ключ, адрес уведомления (копируется из PuzzleBot и вставляется в настройки Prodamus). Другие платежные системы (ЮMoney, ЮКасса) подключаются аналогично Prodamus. В команде «Оплатил» можно добавить: ссылку на курс, доступ к приватному чату, чек-лист, документ и т.д. Обязательно указывать команду перехода при успешной оплате.
