## Video 56: 56_Sozdat_Telegram_Bot_Proverki
**Тема:** Создание Telegram-бота для проверки подписки на несколько каналов/чатов одновременно
**PuzzleBot-элементы:** Обычная команда, текстовый блок, инлайн-клавиатура (ссылка браузер по умолчанию, переход к команде), условия (проверка наличия подписки на несколько ресурсов), исключающее правило, ресурсы (добавление каналов/чатов), стартовая команда, блок документов
**Категория:** Группы и каналы
**Ключевые техники:**
- Проверка подписки сразу на несколько ресурсов (каналов/чатов) в одном условии
- Добавление нескольких ресурсов: для каждого канала -- добавить бота администратором > выдать все права > отправить сообщение > добавить ресурс в PuzzleBot
- Зацикливание пользователя в логике до выполнения всех условий подписки
- Выдача подарка (документ PDF, чек-лист) после успешной проверки
**Шаги реализации:**
1. Создать бота в BotFather, подключить к PuzzleBot
2. Подготовить каналы/чаты: в каждом добавить бота администратором со всеми правами, отправить сообщение
3. Добавить все ресурсы в PuzzleBot (кнопка "Добавить ресурс")
4. Создать команду "Приветствие" с текстом и инлайн-кнопками со ссылками на каналы + кнопка "Подписался"
5. Создать условие "Проверка": добавить проверку "Наличие подписки" > отметить все нужные ресурсы
6. В действии условия (подписан) -- переход к команде "Готово" (спасибо за подписку + подарок)
7. В исключающем правиле (не подписан) -- переход к команде "Не подписался" (повторное предложение)
8. Кнопку "Подписался" в приветствии направить на условие "Проверка"
9. В стартовой команде добавить переход к "Приветствие"
**Полезные детали:** Можно проверять подписку на 2, 5, 10 и более ресурсов одновременно. Если зелёный индикатор горит у ресурса -- всё подключено верно, красный -- проблема с правами администратора. Средний пользователь может настроить такого бота за 5 минут. Если пользователь подписался только на один из двух каналов, проверка не пройдёт.

## Video 80: Ogranichivaem_Dostup_Mini_Prilozheniju
**Тема:** Ограничение доступа к мини-приложению по подписке на канал
**PuzzleBot-элементы:** Группы команд, проверка подписки на ресурс, мини-приложение, inline-клавиатура, текстовый блок, поп-ап, кнопка «Ссылка мини-приложения», кнопка «Переход к мини-приложению»
**Категория:** Мини-приложения
**Ключевые техники:**
- Создание группы команд с проверкой подписки на ресурс (в настройках группы)
- Показ поп-апа при попытке доступа без подписки
- Размещение защищённого мини-приложения в отдельной группе с проверкой подписки
**Шаги реализации:**
1. Добавить бота в ресурс (канал/группу) как администратора с полными правами, включая последний переключатель (для приглашения юзер-бота)
2. Написать любое сообщение в ресурс (можно сразу удалить), затем добавить ресурс в личном кабинете
3. Создать группу команд, в настройках группы выбрать «Проверка подписки на ресурс» и указать подключённый канал
4. Внутри этой группы создать мини-приложение с основным функционалом (доступ только подписанным)
5. В основной группе создать второе мини-приложение — навигационное: кнопка «Подписаться» (ссылка на ресурс) + кнопка «Перейти к приложению» (переход к мини-приложению из защищённой группы)
6. В кнопке перехода к защищённому приложению добавить поп-ап с сообщением «Необходимо подписаться» (в допнастройках — «Показать поп-ап»)
7. В стартовой команде добавить inline-кнопку для перехода к основному мини-приложению
8. Сохранить и опубликовать
**Полезные детали:** Бот должен получить ВСЕ права администратора (включая последний переключатель) — это необходимо для приглашения юзер-бота. Поп-ап при отсутствии подписки настраивается через дополнительные настройки кнопки. Мини-приложение из другой группы вызывается по названию.

## Video 88: Podkljuchaem_Chat_Bota_Biznes
**Тема:** Подключение чат-бота к бизнес-аккаунту Telegram для автоматической обработки сообщений (на примере продажи рекламы)
**PuzzleBot-элементы:** Бизнес-аккаунт (ресурс), форма ввода (выбор варианта, календарь), триггеры, вкладка «Диалоги», события (команда Start для бизнес-аккаунта)
**Категория:** Группы и каналы
**Ключевые техники:**
- Активация бизнес-мода бота через BotFather (MyBots → Settings → Business Mode)
- Подключение бота к Telegram Business аккаунту (настройки → Telegram для бизнеса → Чат-боты)
- Бот отвечает от имени владельца аккаунта
- Ограничение 24 часа: бот может отвечать только в течение 24 часов с последнего сообщения
- Триггеры для автоматических ответов (например, на слово «прайс»)
**Шаги реализации:**
1. В BotFather: MyBots → выбрать бота → Settings → Business Mode → активировать
2. В настройках Telegram аккаунта → «Telegram для бизнеса» → «Чат-боты» → вставить ссылку/username бота
3. Обязательно активировать «Ответы на сообщения» (чтобы бот мог отвечать от имени)
4. В личном кабинете PuzzleBot: добавить появившийся бизнес-аккаунт как ресурс
5. В конструкторе ресурса: настроить команду Start (отправляется при первом контакте) — приветствие + форма ввода (выбор канала для рекламы + календарь для даты)
6. Настроить триггеры: тип условия «Сообщение содержит» → добавить фразы → действие (отправить прайс)
7. Администратор может отвечать через вкладку «Диалоги»
**Полезные детали:** Подписка Telegram Business (на момент записи входит в Telegram Premium) обязательна. Бот может отвечать только 24 часа с последнего сообщения/контакта — после этого нужно новое сообщение через Telegram. Команда Start в бизнес-аккаунте отправляется при ПЕРВОМ контакте (можно изменить через вкладку «События»). Бота можно отключить в конкретном диалоге через настройки. Исключённых пользователей можно убрать через настройки аккаунта. Форма ввода с типом «Календарь» позволяет запретить выбор прошлых дат.

## Video 89: Podkljuchenie_Chata_Kanala_Resursa
**Тема:** Подключение чата или канала (ресурса) к сервису PuzzleBot
**PuzzleBot-элементы:** Добавление бота как администратора ресурса, добавление ресурса в личный кабинет, юзер-бот
**Категория:** Группы и каналы
**Ключевые техники:**
- Выдача боту ВСЕХ прав администратора, включая последний переключатель (для юзер-бота)
- Обязательная отправка сообщения в ресурс после добавления бота
**Шаги реализации:**
1. Открыть Telegram → настройки ресурса (канала/группы) → Администраторы → Добавить администратора
2. Найти привязанного бота, выдать ему полные права (все переключатели, включая последний) — для приглашения юзер-бота
3. Сохранить изменения
4. Написать любое сообщение в ресурс (можно сразу удалить)
5. В личном кабинете PuzzleBot: выбрать бота → «Добавить ресурс» → выбрать ресурс
**Полезные детали:** Последний переключатель прав администратора критически важен — без него бот не сможет пригласить юзер-бота, который выполняет действия, недоступные обычному боту. Обязательно нужно отправить хотя бы одно сообщение в ресурс после добавления бота, иначе ресурс не появится в списке для подключения. Процедура одинакова для чатов и каналов.
