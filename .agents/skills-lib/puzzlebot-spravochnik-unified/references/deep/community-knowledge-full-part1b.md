**Q:** Как "пушить" человека, если он бросил бота (не навязчивое напоминание)?
**A:** Создаете сценарий с постом, тип отправки "через" 7 дней. В настройках сценария включаете "перезапуск при повторном вызове". Указываете запуск сценария в ключевых командах бота. Если юзер активный -- сценарий перезапускается. Если нет -- через 7 дней придет пост.

---

**Q:** Как загрузить список юзеров (по ID) для рассылки?
**A:** Пришлите на почту support@puzzlebot.top юзернейм бота и файл (.csv или Excel) с Telegram ID пользователей. Бот должен быть привязан.

---

**Q:** Как равномерно распределять пользователей на группы (A/B тест)?
**A:** Создайте условия: если пользователь не в группах, присвоить категорию X + переменная X+1. Условие: если X > Y, проверить Y > Z, присвоить Z. Если Y < Z -- присвоить Y. Логика равномерного распределения.

### Переменные

**Q:** Как записать фото в переменную, если его просто отправляют боту?
**A:** Фото без контекста -- это "неизвестная команда". Можно из неизвестной команды сделать прокладку: "фото не определилось, попробуйте ещё раз" -- а здесь форма ввода. На неизвестную команду нельзя сразу форму. Или в /start поставить действие "отправить команду" с блоком формы.

---

**Q:** Как работать с балансом/валютой в боте с внешней таблицей?
**A:** Нужны персональные числовые переменные для хранения баллов + числовые для зачисления/снятия. БД для общего хранения -- рекомендуется NocoDB. Админ-панель через проверку `{{USER_ID_TEXT}}`. В ней кнопки для зачисления/снятия и команды для уведомления.

---

**Q:** Как отправлять запрос к n8n с долгой обработкой (15-30 сек)?
**A:** Интегрированные переменные не подходят -- ожидают быстрый ответ. Обратно отправляете через ноду Telegram send message, указывая userid и бота. User ID передавайте с самого начала на webhook n8n. Не забывайте про ограничение 4096 символов -- если превышает, делаете скриптом разбивку.

---

**Q:** Как сделать чтобы каждый час пользователю приходило +5 энергии?
**A:** Создать в сценарии пост. Тип отправки: через 1 час. В действиях: Изменить переменную +5; запустить этот же сценарий. Настройки: "Перезапуск при повторном вызове", снять "Завершить после выполнения всех постов".

---

**Q:** Как фильтровать пользователей по дате присоединения?
**A:** Системная переменная `{{JOIN_DATE}}`. Установите дату отсечения. Условие со сравнением `{{JOIN_DATE}}` и датой отсечения. Отправляйте только тем, у кого `{{JOIN_DATE}}` больше даты.

**Q:** Операции с датами в PuzzleBot?
**A:** Доступные функции:
- `ADD_DAYS("03.09.2023 15:34:12", 4)` -- прибавить дни
- `ADD_MONTHS(...)`, `ADD_YEARS(...)`, `ADD_HOURS(...)`, `ADD_MINUTES(...)`, `ADD_SECONDS(...)`
- `DAYS_BETWEEN("15.09.2023", "11.09.2023")` -- разница в днях
- `DATE_FORMAT("15.09.2023 15:34:12", "d F Y")` -- форматирование
- Для вычитания -- отрицательное значение: `ADD_HOURS("03.09.2023 15:34:12", -2)`
- Формат даты может быть любым общепринятым (dd.mm.yyyy, dd/mm/yyyy, yyyy-mm-dd), год всегда 4 цифры

**Q:** Как преобразовать все буквы переменной в верхний регистр?
**A:** Без внешних интеграций -- цепочка replace:
```
replace(replace(replace({{Ваша переменная}}, "а", "А"), "б", "Б"), "в", "В") ...
```
(для всех 33 букв русского алфавита)

**Q:** Как вывести все записи из NocoDB в мини-приложении?
**A:** В интегрированной переменной вывести все значения 1 столбца через формат "наличие", в доп настройках вариант поиска "все". Ниже "разделить при нескольких значениях" -- тег `<br>` для разделения строки. Вывести всю таблицу со всеми столбцами -- задание со звездочкой.

---

**Q:** Как разбить ответ из формы ввода на несколько переменных?
**A:** Через regex-функции:
```
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 0) = Line1
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 1) = Line2
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 2) = Line3
```
Регулярное выражение подбирается под конкретный случай.

**Q:** Как достать случайную строку из Google Таблицы?
**A:** Создаете переменную тип "текст" (RandomX) и переменную тип "формула" с выражением `random(1, 100000)` (Random). В команде действие: изменить переменную RandomX=Random, выполнить "До". В интегрированной переменной из таблицы -- фильтр по RandomX.

---

**Q:** Как определить номер недели пользователя в боте?
**A:** Категория или переменная + сценарий. Сценарий через 7, 14, 21 дней меняет переменную (номер недели: 1, 2, 3). Далее Условием проверяете значение и выдаете актуальное расписание.

### Настройка бота

**Q:** Как редактировать данные в форме ввода (пользователь ошибся)?
**A:** Два пути:
1. Показывать результат после каждого ответа + кнопка "Редактировать" (каждая форма в отдельной команде)
2. По окончанию всего опроса выводить все ответы для проверки. Кнопки "Редактировать" и "Отправить". По "Редактировать" -- спрашиваем что исправить, каждая кнопка ведет на свою форму

---

**Q:** Как перенести бота на другой аккаунт / дублировать?
**A:** Настройки бота -> Дублировать. Можно:
- Дублировать весь бот между аккаунтами
- Копировать отдельные разделы (вкладки для дублирования)
- Для переноса подписчиков: support@puzzlebot.top
- Для переноса аккаунта: письмо от обеих сторон на support@puzzlebot.top с юзернеймами

---

**Q:** Как загрузить файл больше лимита ЛК (видео, документ)?
**A:** Через ID файла:
1. Открыть бота, отправить команду `/cp`
2. Выбрать "Загрузить файл" и отправить файл
3. Скопировать ID вида `AgACAgIAAxkBA...`
4. Вставить в блок в личном кабинете
Лимит через ID -- до 2 ГБ (как у Telegram). Важно: ID уникальны для каждого бота!

---

**Q:** Как подключить канал к боту (ресурс)?
**A:** 1. Добавить бота в канал
2. Назначить полные права администратора
3. Написать любое сообщение в канал (обязательно для каналов!)
4. В ЛК -> страница бота -> "Добавить ресурс"
5. Выбрать ресурс в появившемся окне
Бот автоматически выйдет из неподтвержденных ресурсов через 20 минут.

---

**Q:** Как создать админ-панель внутри бота?
**A:** Можно создать админ-панель внутри бота или через админку конструктора. Нужны: команды-условия для проверки, сценарии для уведомлений. Доступ настраивается через `{{USER_ID_TEXT}}` с проверкой ID админа.

---

**Q:** Как сделать форму ввода со списком из NocoDB (мини-апп)?
**A:** При настройке формы ввода "список" выбираете: какой столбец отображается (1) и какой записывается (2). При выборе строки из 1 в переменную записывается значение из 2. Потом новая интегрированная переменная тянет нужное значение, фильтруя по записанной переменной.

---

**Q:** Бот не реагирует на триггеры в группе -- "не удалось найти пользователя"
**A:** Проверьте настройку "действие выполнять пользователю, получившему ответ". Если отправляете сообщение просто в чат (не ответом) -- эта настройка не сработает. Либо уберите настройку, либо отвечайте через кнопку "Ответить".

---

**Q:** Работает ли зацикливание сценария?
**A:** Да, если в типе отправки у сценария будет не "Сразу", а "Через" (минимум 1 минута). Сценарий отправляет условие, которое снова запускает сценарий.

---

**Q:** Как правильно использовать команду /start?
**A:** Лучше всегда оставлять /start пустой и переадресующей. Скопируйте содержимое в другую команду, а со старта перенаправляйте через условие с проверкой категорий.

---

**Q:** Как реализовать партнерскую (реферальную) систему?
**A:** 1. Создать реферальную ссылку в разделе "Вход"
2. Создать команду для подсчета бонусов реферала
3. Создать переменные: баланс без рефералов + баланс за рефералов
4. Условие: проверка набрал ли реферал 500 бонусов
5. Если набрал: команда -> действие "отправить другому юзеру" (через глобальную переменную "Юзернейм создателя последней активированной реферальной ссылки")
6. В новой команде: изменить переменную бонусов

---

**Q:** Как сделать внутренний баланс пользователя?
**A:** Создать персональную переменную типа "число" со значением 0. Подключить платежную систему. В команде успешного платежа через Действие добавлять значение в переменную. При "трате" -- вычитать из переменной.

2. Форма ввода в боте -> сохранение в таблицу через интеграцию
