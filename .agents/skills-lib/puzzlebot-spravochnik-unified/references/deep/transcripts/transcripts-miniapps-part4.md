# Транскрипции: Мини-приложения

## Video 100: Создание мини-приложения (полный обзор)

В данном видео мы рассмотрим, как создать и настроить мини-приложение в Telegram-боте. Но для начала нам необходимо создать Telegram-бот и подключить его к сервису PuzzleBot. С подробной инструкцией вы можете ознакомиться по ссылке в описании. Для того, чтобы создать мини-приложение, нам необходимо выбрать нужного бота и перейти во вкладку «Конструктор». Нажмем на значок с плюсом и выберем мини-приложение. Рассмотрим последовательно параметры мини-приложения. Введем название мини-приложения. Оно должно быть уникальным. Разберем ссылки на мини-приложения. Прямая и техническая ссылка создаются после публикации изменений. Для открытия страницы мини-приложения необходимо использовать прямую ссылку. Ее можно вставлять в текст или переходить по ней с других социальных сетей. Важно! Для работы прямых ссылок необходимо выбрать в меню Botfather включить режим «Мини-эп». Техническая ссылка используется только для настроек Botfather. Прямой переход работать не будет. Подробнее о настройке Botfather, а также об основной и короткой ссылке рассказали в базе знаний. Ссылка на статью в описании. Рассмотрим дополнительные настройки. Отправить один случайный блок отправляет случайный блок. Защита контента. Эта функция запрещает копирование и вызов меню, по клику правой кнопки мыши. Отобразить кнопку назад показывает кнопку назад вместо кнопки закрыть. Для нее можно выбрать следующие действия. Предыдущие мини-приложения, переход к конкретному мини-приложению и переход к команде или условию. Показать поп-ап перед закрытием мини-приложения. Данная функция будет защищать пользователя от случайного закрытия окна. Закрывать окно по жесту свайпу вниз позволяет свернуть мини-приложение, при движении палеца сверху вниз. Рекомендуем использовать для мини-приложений с небольшим количеством контента. Перейдем к части блоков и рассмотрим их особенности. Выберем текстовый блок и заполним его. Для текста можем применить форматирование или вставить переменную. Для текстового и остальных блоков можно задавать заголовок и описание. Заполним их. Перейдем к блоку изображения. При загрузке одной картинки, она будет заполнена. Она автоматически будет растянута по ширине с сохранением пропорций. При добавлении двух и более картинок, блок работает по принципу карусели с ограниченной высотой. Блок «Видео» отображает видео, загруженное на следующие платформы. YouTube, Vimeo, VK, Zen, RuTube, OK. В данном блоке необходимо указать ссылку на видео из адресной строки, за исключением платформы Zen. Для этой платформы необходимо скопировать особую ссылку. Подробнее о том, как ее найти, вы можете прочитать в базе знаний по ссылке в описании. В блоке «Стикер» мы можем отображать анимацию в формате TGS или JSON. В блоке «Заголовок» можно расположить текст слева, либо по центру. То же самое можно сделать для блока «Описание». Блок «Строки» позволяет расположить текст с левой стороны и с правой. Он подходит для личных кабинетов или профилей пользователя. Блок «Документ» позволяет скачать отдельные документы. И все разом. Документы отправляются в личные сообщения с бота. В отличие от клавиатуры в боте, в мини-приложении клавиатура может существовать как самостоятельный блок. Клавиатур может быть любое количество, кроме клавиатуры с типом «Фиксированная». Также для каждой кнопки можно настроить выполнение вибрации. Добавим каждый вид клавиатуры для демонстрации. И создадим в них кнопки. Теперь рассмотрим особенности форм ввода в мини-приложении. Формы ввода могут быть следующих типов. Ввод текста позволяет принять текст от пользователя. Маска ввода определяет, какой текст сможет вести пользователь. Однострочный или многострочный тип определяет высоту поля ввода. Placeholder позволяет задать текст, который указан в поле ввода, когда пользователь в него еще ничего не ввел. Раскроем дополнительные настройки. Дублировать ответ в переменную позволяет указать запись ответа не только в переменную форму ввода, но и в любую другую. Обязательная форма требует ответа на форму. Повторное прохождение разрешает или запрещает повторный ответ на форму. В случае с запретом форма все равно будет отображаться, но в отключенном состоянии, и без возможности выбрать вариант или отправить ответ. Подставить ответ из переменной отображает форму ввода с заранее введенным ответом. Который пользователь может стереть. Рассмотрим другие типы форм ввода. Выбор даты дает пользователю указать день, месяц и год. В настройках можно ограничить период, запретить даты из прошлого и будущего, или дни недели. Выбор времени позволяет указать пользователю часы и минуты. В настройках можно выбрать интервал доступного времени. Выбор варианта предоставляет пользователю выбор среди заданных вариантов. В настройках можно выбрать количество вариантов для выбора, и вид переключателей. В настройках вариантов можно задать варианты, которые будут выбраны по умолчанию. Отключить запись названия варианта в переменную, а также включить вибрацию при клике. Ещё можно изменять переменную при выборе нужного варианта. Загрузка файла принимает файлы от пользователя. В настройках можно выбрать количество файлов и ограничить маской ввода тип принимания. файлов. Отлично мы рассмотрели особенности блока мини-приложения. Для примера создадим в команде Start кнопку с переходом к мини-приложению. Сохраним и опубликуем изменения. Таким образом мы рассмотрели возможности мини-приложения и смогли настроить связь с командой.
