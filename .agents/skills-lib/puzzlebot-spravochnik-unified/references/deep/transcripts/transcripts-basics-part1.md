## Video 23: Конструктор (часть 2)

В этом видео мы продолжим разбирать возможности вкладки «Конструктор». А именно, рассмотрим дополнительные настройки команды. Выберем команду и откроем список дополнительных настроек. Синонимы. Данная функция позволяет добавить альтернативные фразы, по которым можно будет вызвать команду. Для начала мы можем выбрать тип условия. Должен ли наш синоним совпадать полностью, содержать частично, начинаться, заканчиваться определенной фразой или иметь регулярное выражение. Также в данной настройке можно выбрать тип условия на количество символов. У каждого синонима также можно выбрать шанс срабатывания. А для тех типов условия, где необходим ввод фразы, можно поставить галочку рядом с чувствительностью к регистру. Для примера выберем полное совпадение и добавим текущую. В текущей команде несколько синонимов. Далее мы можем выбрать дополнительные условия. Выполнение только из клавиатуры. При выборе данной функции команду нельзя будет выполнить, просто отправив ее название боту. Выполнение из текущей группы. Команда будет выполнена только если пользователь находится в текущей группе команд. Отправить один случайный блок. Отправляет случайный блок команды. Также можно удалить текущую команду после вызова следующей. Защита контента от пересылки защищает содержимое отправленного сообщения от пересылки и сохранения. При выборе «Отображать в меню» команда будет отображаться при вводе символа слэш и в кнопке «Меню». Далее перейдем к вкладке «Действия». Мы можем добавить действия с командами в категории «Конструктор». В модерации появляется возможность изменить категорию, совершить определенное действие в ресурсах, например, удалить, заблокировать или принять заявку о пересылке. Также вкладка «Действия» позволяет изменить сценарий. Очистить корзину в магазине, совершить действие с диалогом, например, завершить или начать его. Мы также можем изменить и очистить переменную, отправить триггеры, очистить статистику. В работе со Spreadsheets можно работать со строками. Bitrix24 совершает действия с лидом, сделками и контактами. А также вкладка «Действия» позволяет удалять через время, удалять обычную клавиатуру, отправлять уведомления, удалять сообщения пользователя, закреплять первый блок, отправлять все сообщения и отправлять запрос. Для примера работы данной вкладки изменим категорию пользователю. Для этого необходимо ее создать. Перейдем в наш бот. Выберем вкладку «Модерация», нажмем на «плюс» и введем название для категории. Нажмем на кнопку «Создать категорию». Вернемся во вкладку «Конструктор». Откроем команду и добавим действие «Изменить категорию». Нажмем на кнопку «Изменить». Выберем вкладку «Замена». Затем необходимый ресурс. И нужную категорию. Также добавим текстовый блок и напишем текст. Заодно попробуем добавить группу команд с особым доступом. Только для тех, кто вызвал тестовую команду. Для этого в онлайн-клавиатуре текущей команды создадим дополнительную кнопку перехода к еще не существующей. Закроем окно. Команда автоматически создалась. Также для сравнения добавим кнопку в начальной команде с переходом к новой команде. Закроем окно. Теперь создадим новую группу команд. Для этого в навигации наведем на фразу «Основная группа». И в окне выберем «Создать группу». Введем название и сохраним. Перейдем в нее. Настройкой группы выберем доступ для категорий. Также можно задать параметр «Проверка подписки на ресурс». ## Video 24: Конструктор (часть 1)

В данном видео мы рассмотрим возможности вкладки «Конструктор». Перейдем в «Бота» и откроем саму вкладку. Сразу после привязки бота сервис автоматически добавляет тестовый шаблон, который можно опробовать в нашем боте. Для удаления шаблона зажмем «Shift». Выделим все команды. После чего нажмем на кнопку «Удаление». Для применения изменений опубликуем их. Отлично. Разберем интерфейс вкладки. Появляется кнопка для перехода в режим выделения команд. При наведении на название бота можно выбрать нужному бота и перейти в него. При выборе строки навигации появляется список созданных групп команд. Также при выделении команды слева по центру появляются кнопки для удаления команды и для перемещения ее в другую группу. Создадим обычную команду, где разберем ее настройки. Входим в модальное окно, которое можно поделить на две составляющие. В верхней часть настройки команды и в нижней часть список блоков. Впишем название и сохраним изменения, закрыв окно. У нас появилась миниатюра команды, которую можно свободно перемещать. Снова откроем команду. Разберем интерфейс модального окна. Справа вверху находится кнопка включения уведомления о приходе сообщения с командой. а также кнопка дублирования команды. Далее идет название и список дополнительных настроек, которые мы разберем позже. И панель управления, в которой на данный момент есть кнопка копирования ссылки на команду и удаления команды. Рассмотрим блоки. Текст, изображение, видео и аудио – блоки вполне понятные. Документы отправляют пользователю файл. Геолокация отправляет пользователю карту с выбранной вами точкой. Таймаут задает время, через которое будет отправлен следующий блок. Товар отправляет пользователю карточку товара. Блок список позволяет создать переменную, которая будет подставлять один элемент из списка. Например, вы можете сдать список из десяти промокодов, и после вызова команды, содержащую переменную, бот автоматически отправит один промокод из списка. Блок результат позволяет подсчитать количество правильных ответов на форму ввода с типом тестирования. И, исходя из условий, перевести пользователя к нужной команде. Если выделить текст, его можно форматировать. Под текстом можно увидеть количество введенных и допустимых символов. Также можно скрыть изображение под спойлер, поставив галочку. И в самом низу кнопки для создания обычной и инлайн клавиатуры. Рассмотрим подробнее клавиатуры. Обычная клавиатура отображается в Telegram в отдельном блоке вместо ввода текста.
