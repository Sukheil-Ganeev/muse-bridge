# Транскрипции: Мини-приложения

## Video 69: Новые функции (часть 1)

В данном видео мы разберем новые функции, которые были добавлены на платформу. Рассмотрим блок карточек. Создадим мини-приложение и дадим ему название. Добавим блок карточек. Данный блок позволяет создавать кнопки в виде карточек, которые можно листать, а также добавлять действия для этих карточек. Карточка может быть круглой или прямоугольной. Мы можем настроить размеры карточек по высоте и ширине. И изначально выставлен автоматический размер. В таком случае картинка будет отображаться в исходных размерах. Также можно изменить на пиксели или проценты. Если задать один параметр в точном значении, а другой — авто, то размер изображения изменится по заданному параметру, не испортив пропорции. В дополнительных настройках мы можем выбрать помечать новые карточки. Таким образом, непросмотренные карточки будут иметь специальную обводку. Также есть пункт, который, перемещает просмотренные карточки в конец. Нажмем на кнопку «Добавить карточку» и загрузим необходимые файлы. Рассмотрим попапы. Для мини-приложений появилась возможность вызывать попапы. Они имеют два вида — обычный с кнопкой и без кнопки, который будет показывать текст внизу экрана. Вызывать попапы можно через действия и в настройках кнопки. Добавим действие «Показать попап». Выберем вариант с кнопкой. Выберем fractionой по Jessica Bell. Рассмотрим блок «Подстановка». Создадим ещё одно мини-приложение. Дадим ему название. У нас появился новый блок «Подстановка». Добавим его. Данный блок позволяет подставить контент из другого мини-приложения. Введем название мини-приложения, которые надо подставить. Данный блок подходит для управления повторяющимися элементами в разных миний приложениях. Например, блок контактов, меню и подобного. Теперь рассмотрим форму ввода с типом список. Добавим блок форма ввода. В типе ввода выберем новый тип – список. Он позволяет вывести список элементов, в котором можно выбрать один или несколько вариантов. Добавить варианты можно четырьмя разными способами. Вручную, загрузив в тексте файл, подключив Google Sheets или NoCode. Заполним его. Поле значения будет записывать данные в переменную. В него можно подставить числовое значение для дальнейших математических операций или оставить пустое. Тогда в него автоматически будет записано название варианта. Рассмотрим подстановку в формах ввода с типом выбор варианта. Добавим еще одну форму ввода. В типе ввода выберем выбор варианта. Раскроем один из вариантов. И нажмем на дополнительные настройки. Теперь в данном типе можно сделать подстановку. Контент другого мини-приложения будет подставляться, когда пользователь выбирает данный вариант. Это будет удобно в случае, когда необходимо задать уточняющие вопросы для пользователя. Рассмотрим блок HTML. Также нововведением является блок HTML. Давайте добавим его и заполним. Помимо этого, в дополнительных настройках можно добавить HTML-код в TagHat. До конкретной страницы. На странице настроек бота, во вкладке «Мини-приложения» можно добавить HTML-код для всех mini-приложений. Чаще всего это необходимо для сервисов по сбору статистики. Рассмотрим настройки кастомизации. Также была добавлена расширенная кастомизация. Нажмем на заголовок «Стиль» и выберем вариант «Кастомизировать». Настройка позволяет задать свои цвета, размеры и шрифты для мини-приложения. Важно отметить, что изначально не ношу его только для текстов. выбрать дизайн, какой операционной системы будет взят за изначальный вариант. Для нашего примера поменяем цвет. Сохраним изменения. Рассмотрим формулы в тексте. Раскроем стартовую команду и добавим текстовый блок. Теперь прямо в тексте можно делать расчеты без необходимости создания новых переменных. Чтобы произвести расчет, необходимо его записать следующим образом. Двойные фигурные скобки равно ваш расчет равно двойные фигурные скобки. Добавим inline клавиатуру и добавим переход к основному мини-приложению. Сохраним и опубликуем изменения. Проверим работу бота в Telegram. Отправим стартовую команду и запустим мини-приложение. Отлично, все работает корректно.

## Video 70: Новые функции (часть 2)

В данном видео мы разберем новые функции, которые были добавлены на платформу. В их числе блок меню, обновленный блок подстановка, цвета для кнопок в блоке клавиатура, а также новый блок вкладки. Добавим мини-приложение и рассмотрим блок меню. Данный блок позволяет разместить до пяти кнопок, которые фиксированно будут отображаться внизу мини-приложения. Мы можем выбрать стиль, только изображение или изображение с названием. Загрузим изображение и дадим название для кнопки. Обратите внимание, что в качестве формата изображения можно выбрать SVG. В таком случае она будет менять цвет, когда активна. Предустановленный цвет синий, но в настройках кастомизации вы можете его изменить. Если загрузить PNG изображение, то цвет меняется только у надписи, а иконка остается в исходном виде. Кнопки в меню работают по принципу обычных кнопок. Для каждой из них мы можем задать действия. Добавим переход в нужное мини-приложение для каждой из кнопок. Также у нас появилась возможность задать активные страницы для кнопок в меню. Это перечень страниц, на которых кнопка будет считаться активной. Например, у нас есть кнопка настройки. Мы переходим на страницу настройки и кнопка подсвечивается. Но если мы перейдем в подраздел и откроем, например, настройки уведомлений, кнопка настройки уже не будет задаваться. Она будет активна, т.к. это отдельные страницы. Чтобы избежать данной ситуации, в настройках кнопки укажем список всех вложенных страниц, на которых кнопка должна оставаться активной. Это позволяет подсвечивать нужную секцию, даже если пользователь находится внутри подраздела. Блок меню по умолчанию не отображается на всех страницах. Чтобы не создавать меню вручную для каждого мини-приложения, мы можем воспользоваться блоком подстановка. Добавим блок подстановка. И выберем мини-приложение с меню. Таким образом, меню будет отображаться на всех страницах, где мы добавили данный блок. И любые изменения в меню будут автоматически применяться везде, где имеется данный блок. Оформим данное мини-приложение для демонстрации. Рассмотрим блок вкладки. Они представлены в двух вариантах. Обычные вкладки до 5 штук. Они максимально похожи на стандартные системные вкладки Android и iOS. В них нет возможности добавить изображения, только текст. В расширенных вкладках можно добавить до 24 элементов. Для них есть возможность загрузить иконку, изменить порядок и задать название. Каждая вкладка связана с отдельным мини-приложением. Работают они по принципу блока подстановки. При нажатии на вкладку будет отображаться контент под названием. Подставленный из указанного мини-приложения. В дополнительных настройках можно выбрать, какая вкладка будет активна по умолчанию. Теперь рассмотрим нововведение в блоке «Подстановка». Для этого добавим данный блок и укажем название мини-приложения, которое надо подставить. В новых настройках появился пункт «Скрыть подзаголовок». Если данная функция активна, подстановка будет отображаться в виде заголовка со стрелкой. По умолчанию контент будет свернут. При клике на заголовок блок разворачивается и показывает подставленное содержимое. Помимо этого, можно выбрать расположение и стиль для заголовка. Теперь мы можем выбрать любой цвет для кнопок в клавиатуре с типом «Обычная» и «Фиксированная». Добавим блок «Клавиатура» и настроим кнопку. Раскроем команду «Старт». Добавим текстовый блок и заполним его. Также добавим инлайн-клавиатуру и выберем переход к мини-приложению. Введем название нашего основного приложения. Теперь необходимо настроить отображение меню на всех вкладках с помощью блока «Подстановка», как мы делали ранее. А также отметить активные страницы. Сохраним и опубликуем изменения. Проверим работу бота в Telegram. Отправим стартовую команду. Перейдем в мини-приложение. И проверим работу новых функций. Отлично, все работает корректно.

## Video 77: StartPayload, модальное окно

В данном видео мы разберем новые функции, которые были добавлены на платформу. Среди них Start Payload для мини-приложений, открытие мини-приложения из условия, заметки, модельное окно и многое другое. Перед началом хотелось бы отметить, что в первую очередь была сильно оптимизирована вкладка конструктора. Теперь прокрутка и перенос блоков работают плавнее. В мобильной версии улучшена возможность приближать и отдалять рабочую область с помощью движения пальцев. А также появилась возможность закрывать приложение свайпом. Помимо этого, во вкладке настройки появился раздел «Конструктор». Здесь можно настроить облегченный вид конструктора, чтобы при масштабировании блоки автоматически скрывались с рабочей области. Во вкладке мини-приложения теперь можно добавить кнопку настройки. Вызывается она при нажатии на трек. Это проиточие в правом верхнем углу мини-приложения. Также добавили поддержку открытия мини-приложения на полный экран. Настроить данную функцию можно в Botfather. Для этого откроем мини-приложение Botfather, раскроем вкладку с мини-приложениями, выберем «Основное», затем выберем «Фуллскрин». Помимо этого была добавлена функция «Заметка». Это новая сущность во вкладке «Конструктор», которая позволяет оставлять... комментарии или пояснения прямо на рабочей области. Для мини-приложений появилась переменная StartPayload. Теперь при открытии мини-приложения в боте значение после нижнего подчеркивания в параметре StartApp записывается в переменную WebPageStartPayload. Это удобно использовать как UTM-метку или любой маркер источника. Для демонстрации нам необходимо скопировать прямую ссылку на бота, а также добавить к ссылке нижнее подчеркивание. И написать название для метки. Общая длина StartApp может быть до 512 символов. Перейдем к функции «Открытие мини-приложения из условия». Условие теперь может напрямую открыть нужное мини-приложение по результатам своих проверок. Например, мы хотим, чтобы при наличии метки со скидкой, которую мы получили до этого, открывалось мини-приложение с промокодом. Для этого добавим условие и дадим ему название. Теперь нам необходимо добавить проверку значения переменной. Выберем переменную веб-пейджа StartPayload. В типе условия сообщение содержит. И во фразах добавим текст нашей метки. В действиях выберем переход к мини-приложению. И введем приложение с промокодом. Повторим те же действия для второго правила. Но изменим фразу. А также выполним переход ко второму приложению. Вернемся в основное мини-приложение и добавим блок «Подстановка». Теперь в данном блоке мы можем не только подставлять нужное приложение, но также подставлять и условия. Введем название нашего условия. Таким образом, если пользователь запустил мини-приложение по ссылке с промокодом, ему будет доступен промокод. Если нет, то промокод ему не отобразится. Перейдем к новой функции «Модальное окно». Работает оно по принципу подстановки и позволяет открывать мини-приложение поверх текущей страницы в модальном окне. Добавим блок «Клавиатура». Дадим название кнопке. В действиях выберем «Открыть в модальном окне». Введем название мини-приложения, которое будет открываться в модальном окне. А также заполним заголовок. Таким образом, при нажатии на кнопку пользователю раскроется модальное окно, в котором будет отображаться нужное мини-приложение. Помимо этого, теперь кнопкам доступны новые действия подстановки. Добавим еще одну кнопку и выберем действие «Подстановка». Повторим те же действия для второго варианта. Таким образом, при нажатии на кнопку ниже подставляется мини-приложение. При повторном нажатии подстановка скрывается. Также появилась возможность скрывать карточки. Для демонстрации добавим блок «Карточки» и оформим его. Нажмем на крестик. Отлично, карточка скрыта. Помимо этого, теперь можно добавлять якоря. Для этого необходимо в любом мини-приложении напротив нужного блока нажать на троеточие и выбрать вариант «Скопировать ссылку». Для примера, давайте разместим данную ссылку в кнопке с помощью действия ссылка «Браузер по умолчанию». Таким образом, при нажатии на кнопку нам открывается мини-приложение на нужном блоке. Сохраним и опубликуем изменения. Перейдем в Telegram и проверим, как данные нововведения будут выглядеть с десктопного приложения. Также были добавлены новые функции для формул. Изменение регистра, обрезка и усечение, очистка и фильтрация, проверка содержимого, удаление эмодзи, валидация, маскировка, извлечение и замена.
