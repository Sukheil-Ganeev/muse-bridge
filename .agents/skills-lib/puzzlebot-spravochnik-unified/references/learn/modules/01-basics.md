# 01 -- Основы PuzzleBot

Справочный модуль: создание бота, подключение, интерфейс конструктора, первые команды, форматирование, настройки аккаунта.

---

## 1. Создание бота через BotFather

### Пошаговая инструкция

1. Откройте Telegram, найдите **@BotFather** (обязательно с галочкой верификации -- существуют фейки)
2. Нажмите **"Начать"**, отправьте команду `/newbot`
3. Введите **название бота** (отображаемое имя, любые символы)
4. Введите **username** бота:
   - Уникальный во всём Telegram
   - Только латинские буквы и цифры
   - Обязательно заканчивается на `bot` (например: `MyShopBot`, `city_guide_bot`)
5. Скопируйте **API-ключ (токен)** из ответа BotFather

> **Важно:** API-ключ -- конфиденциальная информация. Не публикуйте его в открытых чатах.

### Дополнительные настройки в BotFather

- `/setdescription` -- описание бота (видно до нажатия "Начать")
- `/setabouttext` -- текст в разделе "О боте"
- `/setuserpic` -- аватар бота
- `/mybots` -- список ваших ботов и управление ими

## 2. Авторизация в PuzzleBot

### С компьютера (Telegram установлен)

1. Перейдите на **puzzlebot.top**
2. Нажмите **"Личный кабинет"**
3. Нажмите **"Войти через Telegram"**
4. Подтвердите открытие Telegram в браузере
5. В Telegram нажмите **"Начать"** у бота PuzzleBot
6. Перейдите по ссылке из сообщения -- страница перезагрузится

### С мобильного (Telegram на другом устройстве)

1. Перейдите на puzzlebot.top -> "Личный кабинет" -> "Войти через Telegram"
2. Появится **QR-код**
3. Отсканируйте QR-код камерой устройства с Telegram
4. Откройте Telegram -> нажмите **"Начать"** -> перейдите по ссылке
5. Страница автоматически перезагрузится и откроется ЛК

---

## 3. Подключение бота к PuzzleBot

1. Войдите в личный кабинет PuzzleBot
2. Нажмите **"Добавить бота"**
3. Вставьте **API-ключ** (токен), скопированный из BotFather
4. Подтвердите привязку
5. Бот сразу доступен для настройки в личном кабинете

> После привязки автоматически создаётся тестовый шаблон с примерами команд. Его можно удалить: **Shift + выделить все команды -> Удалить -> Опубликовать**.

## 4. Интерфейс конструктора -- все вкладки

| Вкладка | Назначение |
|---------|-----------|
| **Конструктор** | Создание команд, блоков, клавиатур -- основная рабочая область |
| **Переменные** | Персональные и глобальные переменные, формулы |
| **Автопостинг (Сценарии)** | Автоматические цепочки сообщений по расписанию пользователя |
| **Постинг** | Создание и отправка постов (рассылки, мультипостинг) |
| **Модерация** | Управление пользователями, категориями, экспорт |
| **Статистика** | Просмотр ответов на формы ввода, аналитика |
| **Вход** | Ссылки (многоразовые, промо, реферальные) |
| **Диалоги** | Управление активными диалогами с пользователями |
| **Настройки** | Интеграции, платежи, уведомления, подписки на события, дублирование |

### Навигация в конструкторе

- **Миниатюры команд** -- перетаскиваются мышкой для удобной организации
- **Группы команд** -- навигация в верхней панели, переключение между группами
- **Режим выделения** -- Shift + клик для массового выбора команд
- **Обычные команды** -- синие блоки, отправляют новое сообщение
- **Инлайн-команды** -- розовые блоки, заменяют текущее сообщение

### URL-адреса панели управления

| URL | Страница |
|-----|----------|
| `cp.puzzlebot.top/home` | Личный кабинет (главная) |
| `cp.puzzlebot.top/constructor?b=BotName` | Конструктор бота |
| `cp.puzzlebot.top/variables?b=BotName` | Переменные бота |
| `cp.puzzlebot.top/bot?b=BotName` | Страница бота (dashboard) |

### Навигация по левому меню (точные названия)

```
PuzzleBot :// Личный кабинет
  Подключенные боты
    [Имя бота]
    @username_bot
    Тариф «Креативный» / «Профессиональный» / «Премиум»
    Осталось: X д. Y ч.
    [Управление тарифом] [Улучшить]
  + Добавить бота
  Задать вопрос в поддержку
```

### Элементы управления в конструкторе

| Элемент | Расположение | Назначение |
|---------|-------------|------------|
| **Опубликовать изменения** | Верхний правый угол | Применение изменений к боту |
| **"+"** | Панель конструктора | Добавление команды / условия / мини-приложения |
| **Shift + выделение** | Рабочая область | Массовый выбор команд для удаления |
| **Настройки команды** | Внутри команды | Название, синонимы, дополнительные настройки |
| **Добавить новый блок** | Внутри команды | Текст, Изображение, Видео, Аудио, Документ и др. |

## 5. Создание первой команды /start

### Базовый /start

1. Перейдите во вкладку **"Конструктор"**
2. Откройте команду **Start** (создана по умолчанию)
3. Добавьте **текстовый блок** с приветствием
4. Вставьте переменную имени: `{{FIRST_NAME_TEXT}}` для персонализации
5. Создайте **обычную клавиатуру** с кнопками навигации
6. Нажмите **"Опубликовать"**

### Рекомендация от сообщества

Лучше оставлять `/start` пустой и переадресующей:
1. Скопируйте содержимое Start в отдельную команду (например, "Главное меню")
2. В Start добавьте только условие, которое проверяет категорию пользователя
3. Условие перенаправляет: новый пользователь -> регистрация, старый -> меню

Это даёт гибкость для приветственных бонусов, проверки подписки и A/B-тестов.

## 6. Блоки контента

### Стандартные блоки

| Блок | Описание |
|------|----------|
| **Текст** | Текстовое сообщение (с форматированием, переменными, формулами) |
| **Изображение** | Загрузка файла или вставка ID файла |
| **Видео** | Видеофайл |
| **Аудио** | Аудиофайл |
| **Документ** | Любой файл как документ |
| **Геолокация** | Точка на карте |
| **Контакт** | Контактная карточка |
| **Медиагруппа** | Несколько медиафайлов в одном сообщении |

### Специальные блоки

| Блок | Описание |
|------|----------|
| **Форма ввода** | Запрос данных у пользователя |
| **Таймаут** | Задержка между блоками (для комфортного UX) |
| **Товар** | Карточка товара с ценой и кнопкой оплаты |
| **Список** | Подстановка одного элемента из списка (промокоды, токены) |
| **Результат** | Подсчёт правильных ответов формы "Тестирование" |
| **Слайдер** | Автоматическая карусель |

### Управление блоками

- **Стрелки** вверх/вниз -- изменение порядка блоков
- **Меню блока** -- копировать, вставить, дублировать, удалить
- Для **ID изображения**: можно вставить ID файла вместо загрузки (полезно при переносе)
- **Спойлер** -- скрытие контента до нажатия

## 7. Форматирование текста

### Как форматировать (НЕ Markdown!)

PuzzleBot использует **визуальный тулбар**, а НЕ Markdown-разметку.

1. Напишите текст в блоке
2. **Выделите** нужный фрагмент мышкой
3. Появится **всплывающая панель форматирования**
4. Выберите стиль:

| Кнопка тулбара | Результат |
|----------------|----------|
| **B** | Жирный текст |
| *I* | Курсив |
| ~~S~~ | Зачёркнутый |
| `</>` | Моноширинный (код) |
| Ссылка | Текст-гиперссылка |
| Спойлер | Скрытый текст |

### Вставка ссылки в текст

1. Выделите слова, которые станут ссылкой
2. Во всплывающем окне нажмите **"Ссылка"**
3. Вставьте URL и нажмите **Enter**
4. Текст станет синим с подчёркиванием

> **Важно:** Не вставляйте голые URL в текст -- выглядит неопрятно. Всегда оформляйте ссылки через тулбар.

### Переменные в тексте

Вставляются через кнопку **{x}** в редакторе или вручную: `{{ИМЯ_ПЕРЕМЕННОЙ}}`

### Формулы прямо в тексте

Мощный инструмент -- вычисления и условия прямо внутри текстового блока:
```
{{=if {{Balance}} > 100 ; Ваш баланс: {{Balance}} ; Пополните баланс}}
```

### Лимит символов

Под текстовым блоком отображается счётчик символов. Лимит Telegram для текстового сообщения -- 4096 символов. Описание к медиа -- 1024 символа.

## 8. Дублирование и перенос бота

### Дублирование бота

**Настройки бота -> Дублировать**

Возможности:
- **Дублировать весь бот** между аккаунтами PuzzleBot
- **Копировать отдельные разделы** (вкладки для дублирования)
- Дублирование создаёт копию без подписчиков

### Перенос на другой аккаунт

1. Перенос самого бота: **Настройки -> Дублировать / Перенести**
2. Перенос подписчиков: написать на **support@puzzlebot.top**
3. Перенос аккаунта целиком: письмо **от обеих сторон** на support@puzzlebot.top с юзернеймами

### Передача бота заказчику

1. Передайте право владения токеном в **@BotFather**
2. Перенесите бота на аккаунт заказчика в PuzzleBot

### Дублирование группы команд

Прямой возможности нет. Хитрый способ:
1. Дублировать бота в другой аккаунт
2. Из другого аккаунта дублировать обратно
3. Дублируйте **без замены** (чтобы не перезаписать оригинал)

## 9. Настройки аккаунта и бота

### Важные разделы настроек

| Раздел | Что настраивается |
|--------|-------------------|
| **Интеграции** | Google Sheets, API-токен, Bitrix24 |
| **Платежные системы** | Telegram Stars, Робокасса и др. |
| **Уведомления** | Правила дублирования уведомлений в группы/каналы |
| **Подписки на события** | Вебхуки для внешних сервисов (Make, n8n) |
| **Формы ввода** | Правила объединения уведомлений |
| **Дублирование** | Копирование бота между аккаунтами |

### API-токен PuzzleBot

Для внутренних запросов (удаление сообщений, управление):
**Настройки -> Интеграции -> Сгенерировать API-токен**

### Подключение ресурсов (каналы и группы)

1. Добавьте бота в канал/группу
2. Назначьте **полные права администратора** (обязательно все галочки, включая "Выбор администратора")
3. **Напишите любое сообщение** в канал (обязательный шаг для каналов, можно удалить после)
4. В ЛК -> страница бота -> **"Добавить ресурс"**
5. Выберите ресурс в появившемся списке

> Бот автоматически покинет неподтверждённые ресурсы через 20 минут.

## 10. Загрузка файлов через /cp

Если файл превышает лимит загрузки через ЛК:

1. Откройте **вашего бота** в Telegram
2. Отправьте команду `/cp`
3. Выберите **"Загрузить файл"**
4. Отправьте файл боту
5. Скопируйте **ID файла** (вида `AgACAgIAAxkBA...`)
6. Вставьте ID в соответствующий блок в личном кабинете

Лимит загрузки через ID -- **до 2 ГБ** (ограничение Telegram).

> **Важно:** ID файлов уникальны для каждого бота. Нельзя использовать ID файла из одного бота в другом.

---

## 11. Команда /cp -- панель управления

Команда `/cp` в боте открывает быстрый доступ к:
- **Загрузке файлов** (получение ID)
- **Управлению диалогами** (активные диалоги с пользователями)
- **Быстрым действиям** прямо из Telegram

Также доступна вкладка **"Диалоги"** в панели ЛК.

---

## 12. Публикация изменений

После любых изменений в конструкторе необходимо нажать кнопку **"Опубликовать"**. Без публикации изменения не применяются к боту.

- Публикация работает **на уровне группы команд** -- публикуйте каждую группу отдельно
- После удаления команд также нужна публикация
- Тестируйте бота **после каждой публикации**
