# 04 -- Переменные и формулы

Справочный модуль: персональные, глобальные, кастомные переменные, все формулы и функции, условия, регулярные выражения, inline-вычисления.

---

## 1. Типы переменных

### Персональные переменные

**Индивидуальные значения для каждого пользователя.** Каждый пользователь бота имеет свой набор значений.

Примеры: баланс, имя, количество заказов, статус регистрации.

### Глобальные переменные

**Общие значения для всех пользователей.** Одно значение, доступное всему боту.

Примеры: название бота, ссылка на сайт, курс валюты, счётчик заявок.

### Синтаксис

```
{{имя_переменной}}
```

Правила именования:
- Латинские буквы **A-Z** (регистр не важен)
- Цифры **0-9**
- Нижнее подчёркивание `_`
- Никаких пробелов, кириллицы, спецсимволов

---

## 2. Стандартные (системные) персональные переменные

| Переменная | Описание |
|-----------|----------|
| `{{FIRST_NAME_TEXT}}` | Имя пользователя из Telegram |
| `{{LAST_NAME_TEXT}}` | Фамилия пользователя из Telegram |
| `{{USER_NAME_TEXT}}` | Username (@username) |
| `{{USER_ID_TEXT}}` | Числовой Telegram ID пользователя |
| `{{JOIN_DATE}}` | Дата первого входа пользователя в бота |
| `{{START_PAYLOAD}}` | Параметр deep link (из ссылки `t.me/bot?start=параметр`) |
| `{{HAS_PREMIUM}}` | Есть ли Telegram Premium (true/false) |
| `{{USER_AVATAR_URL}}` | URL аватара пользователя (для мини-приложений) |

> Системные переменные редактируются только в тех местах, где были созданы (формы ввода, реферальная система и т.д.). Нельзя изменить `{{FIRST_NAME_TEXT}}` вручную.

## 3. Создание кастомных переменных

### Пошаговая инструкция

1. Перейдите на вкладку **"Переменные"**
2. Выберите тип: **Персональные** или **Глобальные**
3. Нажмите **"Добавить переменную"**
4. Заполните:
   - **Имя** (латиница, цифры, подчёркивание)
   - **Формат значения** (текст / число / формула / ссылка / документ)
   - **Тип значения** (обычное или интегрированное)
   - **Значение по умолчанию**
   - **Описание** (для удобства)
   - **Группа** (для организации)
5. Сохраните

> **Важно:** После создания переменной перезапустите конструктор, чтобы она появилась в списке доступных.

### Форматы значений

| Формат | Описание | Операторы изменения |
|--------|----------|-------------------|
| **Текст** | Строка текста | Только "заменить" (значение в кавычках) |
| **Число** | Целое или дробное число | Заменить, прибавить, вычесть |
| **Формула** | Вычисляемое значение из других переменных | Автоматически пересчитывается |
| **Ссылка** | URL-адрес | Заменить |
| **Документ** | ID файла | Заменить |

### Типы значений

| Тип | Описание |
|-----|----------|
| **Обычное** | Значение хранится внутри бота |
| **Интегрированное (HTTP)** | GET-запрос к внешнему API, JSON-формат |
| **Интегрированное (Google Sheets)** | Значение из ячейки Google Таблицы |

## 4. Группировка переменных

При большом количестве переменных группировка критична для навигации.

1. При создании переменной укажите **группу**
2. Используйте иерархию: `Категория > Подкатегория > Название`
3. Пример: `Водители > Регистрация > Имя`

Рекомендуемые группы:
- Пользовательские данные
- Баланс и платежи
- Настройки
- Временные (для вычислений)

## 5. Изменение переменных

### Через действие в команде

1. В команде откройте раздел **"Действия"**
2. Добавьте **"Изменить переменную"**
3. Выберите переменную
4. Выберите оператор и запишите значение

### Операторы для числовых переменных

| Оператор | Пример | Результат |
|----------|--------|----------|
| **Заменить** | `Balance` = `100` | Balance станет 100 |
| **Прибавить** | `Balance` + `50` | Balance увеличится на 50 |
| **Вычесть** | `Balance` - `30` | Balance уменьшится на 30 |

### Операторы для текстовых переменных

| Оператор | Пример | Результат |
|----------|--------|----------|
| **Заменить** | `Status` = `"VIP"` | Status станет "VIP" |

### Очистка переменной

Действие **"Очистить переменную"** сбрасывает значение до **значения по умолчанию**.

### Настройка "Выполнить до"

При добавлении действия "Изменить переменную" настройка **"Выполнить до"** означает:
- **Включено:** сначала выполняется действие (начисление), потом выводится блок (сообщение)
- **Выключено:** сначала блок, потом действие

> **Важно:** Последовательность действий критична! Команды с вычислениями и работой с числами должны быть **СВЕРХУ**, отправка в другую команду -- **СНИЗУ**.

## 6. Интегрированные переменные

### HTTP (JSON API)

Получение данных с внешнего API:

1. Создайте переменную -> тип **"Интегрированный"**
2. Вставьте URL JSON-запроса
3. Нажмите **"Проверить запрос"**
4. Выберите нужное поле из ответа
5. Сохраните

**Пример -- курс криптовалюты TON:**
```
URL: https://api.coingecko.com/api/v3/simple/price?ids=the-open-network&vs_currencies=usd
Ответ: the-open-network.usd -> значение курса
```

Глобальная интегрированная переменная обновляется автоматически при каждом обращении.

### Google Sheets

Получение данных из ячейки таблицы:

1. Подключите Google Sheets: **Настройки -> Интеграция -> Google Sheets** (все галочки!)
2. Создайте переменную -> тип "Интегрированный" -> Google Sheets
3. Выберите таблицу, лист, настройте фильтры поиска
4. Укажите целевой столбец для получения значения

**Варианты поиска:**
- **По адресу строки** -- конкретная ячейка
- **По поиску** -- фильтр по значению в столбце (например, User ID)
- **Все значения** -- вернуть все совпадения (разделитель настраивается)

### Кэширование

> **Критично для массовых рассылок!** Google Sheets допускает только 60 запросов/минуту. При рассылке ставьте **большое кэширование** в условии и в интегрированной переменной. Рассмотрите переход на **NocoDB** (10 запросов/сек).

## 7. Формулы и выражения

### Переменная-формула

При создании переменной с форматом **"Формула"** -- значение автоматически пересчитывается при каждом обращении.

```
Пример: {{result}} = {{usd_value}} * {{price_ton}}
```

### Inline-вычисления в тексте

Формулы можно писать **прямо в текстовом блоке** через синтаксис `{{=выражение}}`:

```
{{=if {{Balance}} > 0 ; У вас {{Balance}} бонусов ; Баланс пуст}}
```

## 8. Функции для работы с датами

### ADD_DAYS / ADD_HOURS / ADD_MINUTES и др.

Прибавление (или вычитание) к дате:

```
ADD_DAYS("03.09.2023 15:34:12", 4)        -- +4 дня
ADD_MONTHS("03.09.2023 15:34:12", 2)       -- +2 месяца
ADD_YEARS("03.09.2023 15:34:12", 1)        -- +1 год
ADD_HOURS("03.09.2023 15:34:12", 3)        -- +3 часа
ADD_MINUTES("03.09.2023 15:34:12", 30)     -- +30 минут
ADD_SECONDS("03.09.2023 15:34:12", 120)    -- +120 секунд
```

Для **вычитания** -- отрицательное число:
```
ADD_HOURS("03.09.2023 15:34:12", -2)       -- минус 2 часа
```

Вместо строки даты можно подставить переменную:
```
ADD_DAYS({{JOIN_DATE}}, 30)                -- дата через 30 дней после входа
```

### DAYS_BETWEEN

Разница в днях между двумя датами:

```
DAYS_BETWEEN("15.09.2023", "11.09.2023")   -- результат: 4
DAYS_BETWEEN({{end_date}}, {{start_date}}) -- разница между переменными
```

### DATE_FORMAT

Форматирование даты в нужный вид:

```
DATE_FORMAT("15.09.2023 15:34:12", "d F Y")
```

**Ключи форматирования:**
| Ключ | Значение | Пример |
|------|---------|--------|
| `d` | День (01-31) | 15 |
| `F` | Месяц словом | Сентябрь |
| `m` | Месяц (01-12) | 09 |
| `Y` | Год (4 цифры) | 2023 |
| `H` | Часы (00-23) | 15 |
| `i` | Минуты (00-59) | 34 |
| `s` | Секунды (00-59) | 12 |

**Формат даты на входе:** любой общепринятый формат (`dd.mm.yyyy`, `dd/mm/yyyy`, `yyyy-mm-dd`). Год всегда 4 цифры.

## 9. Математические функции

### round, ceil, floor

```
round(3.7)    -- 4 (округление к ближайшему)
ceil(3.2)     -- 4 (округление вверх)
floor(3.9)    -- 3 (округление вниз)
```

Пример -- конвертация секунд в ЧЧ:ММ:СС:
```
(floor({{SEC}}/3600))+":"+(floor(({{SEC}}-floor({{SEC}}/3600)*3600)/60))+":"+({{SEC}}-floor({{SEC}}/3600)*3600-floor(({{SEC}}-floor({{SEC}}/3600)*3600)/60)*60)
```

### numberFormat

Форматирование числа с разделителями:
```
numberFormat({{price}}, 2, ".", " ")
-- 1234567.89 -> 1 234 567.89
```

Параметры: `numberFormat(число, знаков_после_запятой, десятичный_разделитель, разделитель_тысяч)`

## 10. Функция random

Генерация случайного числа:

```
random(1, 100)      -- случайное от 1 до 100
random(1, 100000)   -- для уникальных ID
```

**Применение -- случайная строка из Google Таблицы:**
1. Создайте текстовую переменную `RandomX`
2. Создайте переменную-формулу `Random` = `random(1, 100000)`
3. В команде: действие "Изменить переменную" `RandomX` = `Random`, выполнить "До"
4. Интегрированная переменная из таблицы -- фильтр по `RandomX`

## 11. Функция plure (склонение)

Склонение слов по числу:

```
plure({{count}}, "бонус", "бонуса", "бонусов")
```

| Число | Результат |
|-------|----------|
| 1 | бонус |
| 2 | бонуса |
| 5 | бонусов |
| 21 | бонус |
| 0 | бонусов |

Использование в тексте:
```
У вас {{count}} {{=plure({{count}}, "бонус", "бонуса", "бонусов")}}
-- "У вас 5 бонусов"
-- "У вас 21 бонус"
```

## 12. Функции match и match_all (regex)

### match -- первое совпадение

```
match({{text}}, "/regex/флаги")
```

### match_all -- все совпадения по индексу

```
match_all({{text}}, "/regex/флаги", индекс)
```

**Пример -- разбить ответ на строки:**
```
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 0)  -- первое совпадение
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 1)  -- второе совпадение
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 2)  -- третье совпадение
```

**Пример -- извлечь число из текста:**
```
match({{user_input}}, "/(\d+)/")
```

**Пример -- извлечь email:**
```
match({{text}}, "/([\w.-]+@[\w.-]+\.\w+)/")
```

## 13. Условное выражение if/else

### Синтаксис

```
{{=if условие ; значение_true ; значение_false}}
```

### Примеры

**Простое условие:**
```
{{=if {{Balance}} > 100 ; VIP-клиент ; Обычный клиент}}
```

**С переменными в значениях:**
```
{{=if {{Balance}} > 0 ; Ваш баланс: {{Balance}} руб. ; Пополните баланс}}
```

**Сравнение текста:**
```
{{=if {{Status}} = "VIP" ; Добро пожаловать! ; Станьте VIP для доступа}}
```

**Вложенные условия:**
```
{{=if {{score}} > 90 ; Отлично ; {{=if {{score}} > 60 ; Хорошо ; Нужно подтянуть}}}}
```

### Операторы сравнения

| Оператор | Описание |
|----------|----------|
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |
| `=` | Равно |
| `!=` | Не равно |

## 14. Функция replace

Замена подстроки:

replace({{text}}, "старое", "новое")

replace(replace(replace({{var}}, "а", "А"), "б", "Б"), "в", "В")

## 15. Условия в кнопках условия

Подробно описано в модуле 03 (Кнопки и меню). Ключевые моменты для переменных:

### Проверка значения переменной

В условии (обычном или кнопке условия):
1. Добавьте проверку **"Значение переменной"**
2. Выберите переменную
3. Выберите оператор (=, >, <, содержит, не пустая)
4. Укажите значение для сравнения

### Проверка вызова команды

- **"Вызов команды или условия"** -- была ли команда вызвана хотя бы раз
- С **количеством** -- вызвана ровно N раз
- С **периодом** -- вызвана за последние N дней

### Комбинированные проверки

```
Правило: "Все проверки" (AND)
  - Balance > 0
  - Status = "VIP"
  - Подписан на канал @mychannel
-> Действие: отправить команду "VIP-меню"

Исключающее правило:
-> Действие: отправить команду "Обычное меню"
```

## 16. Регулярные выражения в условиях

### Синонимы команд с regex

В дополнительных настройках команды:
1. Добавьте **синоним**
2. Тип совпадения: **"Регулярное выражение"**
3. Введите regex-паттерн

Пример -- команда срабатывает на любое число:
```
/^\d+$/
```

### Проверка значения переменной через regex

В условии проверки переменной можно использовать оператор **"совпадает с regex"**:
```
/^[A-Z]{2}\d{3}[A-Z]{2}$/    -- формат госномера
```

## 17. Inline-вычисления в тексте -- сводка

Всё, что можно писать прямо в текстовом блоке:

```
# Подстановка переменной
Привет, {{FIRST_NAME_TEXT}}!

# Условие
{{=if {{Balance}} > 0 ; Баланс: {{Balance}} ; Пополните баланс}}

# Склонение
{{=plure({{days_left}}, "день", "дня", "дней")}} до конца подписки

# Дата
Ваша подписка до: {{=ADD_DAYS({{pay_date}}, 30)}}

# Разница дат
Осталось {{=DAYS_BETWEEN({{end_date}}, {{today}})}} дней

# Форматирование даты
Дата входа: {{=DATE_FORMAT({{JOIN_DATE}}, "d F Y")}}

# Случайное число
Ваш код: {{=random(1000, 9999)}}

# Округление
Итого: {{=round({{total}} * 1.2)}} руб.

# Математика
Скидка: {{=floor({{price}} * 0.15)}} руб.
```

## 18. Практические паттерны

### Приветственный бонус с защитой от повторного начисления

1. Создайте числовую переменную `Balance` (по умолчанию 0)
2. Создайте команду "Начисление бонуса": действие "Изменить переменную" Balance + 7, настройка "Выполнить до"
3. Создайте условие: проверка "Вызов команды Начисление бонуса"
   - Если вызвана -> отправить в меню (бонус уже получен)
   - Если не вызвана -> отправить на начисление
4. Все кнопки из Start замкните на это условие

### Калькулятор с внешним API

1. Глобальная интегрированная переменная `Price_TON` (URL: CoinGecko API)
2. Форма ввода: маска "Число" -> переменная `USD_Value`
3. Персональная переменная-формула: `{{USD_Value}} * {{Price_TON}}`
4. Команда вывода с переменной-формулой в текстовом блоке

### Ограничение доступа по дате (подписка на 30 дней)

1. При оплате: создайте переменную `end_date` = `ADD_DAYS(текущая_дата, 30)`
2. Запустите сценарий: каждый день проверяет `DAYS_BETWEEN({{end_date}}, текущая_дата)`
3. Если разница <= 0 -- смена категории, отключение доступа

### Еженедельный трекер

1. Сценарий: через 7, 14, 21 день меняет переменную `week_number` (1, 2, 3)
2. Условие проверяет значение `week_number`
3. Выдаёт актуальное расписание для текущей недели

### Уникальный ID для записей

1. Числовая переменная `counter` (по умолчанию 0)
2. При создании записи: `counter` + 1 (выполнить "До")
3. Использовать `{{counter}}` как уникальный ID

### Генерация энергии каждый час

1. Создайте сценарий с постом, тип отправки "Через 1 час"
2. В действиях: изменить переменную `energy` + 5
3. В действиях: запустить этот же сценарий
4. В настройках сценария: "Перезапуск при повторном вызове", снять "Завершить после выполнения всех постов"

## 19. Типичные ошибки

1. **Переменная не появляется в списке** -- перезапустите конструктор после создания
2. **Текстовая переменная не меняется** -- значение должно быть в кавычках, оператор только "заменить"
3. **Глобальная переменная global_number не совпадает** -- при удалении сообщений в канале синхронизация сбивается
4. **Интегрированная переменная тормозит при рассылке** -- увеличьте кэширование, Google Sheets допускает только 60 запросов/мин
5. **Формула не вычисляется** -- проверьте синтаксис: `{{=выражение}}` для inline-вычислений, без `=` для переменных-формул
6. **Сценарий с зацикливанием не работает** -- тип отправки должен быть "Через" (не "Сразу"), минимум 1 минута
7. **Действия выполняются не в том порядке** -- вычисления и изменения переменных должны быть СВЕРХУ, отправка в другую команду -- СНИЗУ
