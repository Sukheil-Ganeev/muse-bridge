# 08. Мини-приложения

## Обзор

Мини-приложения PuzzleBot -- встроенные веб-страницы внутри Telegram, позволяющие создавать полноценные интерфейсы без программирования. Поддерживают карточки, stories, баннеры, формы, меню, вкладки, HTML-код и многое другое.

---

## Блоки мини-приложений

### Основные блоки контента

| Блок | Описание |
|------|----------|
| **Заголовок** | Текст заголовка (стили: Экстра, H3). Поддерживает переменные для персонализации. Можно добавить кликабельный текст или изображение с действием |
| **Описание** | Текст описания (стили: B1, B3). Информационные блоки |
| **Текст** | Основной текстовый блок. Стили: обычный, предупреждение (с изображением), раздел (с изображением/стикером). Поддерживает спойлер |
| **Изображение** | Фото с описанием. Описание попадает в поиск |
| **Видео** | Видеоблок с действиями: при запуске и после просмотра 95%. Активация фиксированной кнопки после просмотра |
| **Стикер** | Визуальное оформление |
| **Разделитель** | Визуальное разделение между смысловыми блоками |

### Блок "Карточки"

Визуальная навигация с изображениями:

**Настройки:**
- Форма: круглые / прямоугольные
- Размеры: авто / пиксели / проценты (один точный + другой авто = сохранение пропорций)
- Бейдж: статический текст или динамический из переменной (скрывается если значение пустое)
- Прозрачность: для недоступных элементов
- Показ определённой карточки: по номеру или переменной
- Помечание новых: отметка непросмотренных карточек
- Перемещение просмотренных: в конец списка

**Действия карточки:**
- Переход к мини-приложению
- Переход к мини-истории (stories)
- Ссылка
- Любое стандартное действие

**Скрытие:** Крестик на карточке позволяет пользователю скрыть её.

### Блок "Баннер"

Крупный визуальный блок с макетами:

- **Макеты** -- предустановленные шаблоны оформления
- **Изображение** -- загрузка фона
- **Заголовок и текст** -- поверх изображения
- **Бейдж** -- с переменной (автоскрытие при пустом значении)
- **Тёмная/светлая тема** -- адаптация под тему Telegram
- **Кликабельность:** весь баннер или только кнопка
- **Кнопка скрытия** -- пользователь может закрыть
- **Выделение** -- убирает отступы на iOS, добавляет на Android

### Блок "Клавиатура"

Кнопки внутри мини-приложения:

**Типы:**
- **Обычная** -- стандартная кнопка
- **Фиксированная** -- закреплена внизу экрана (для кнопок "Принять"/"Отклонить")
- **Полупрозрачная** -- стилизованная кнопка

**Цвета:** Произвольный цвет для типов "Обычная" и "Фиксированная".

**Действия кнопок:**
- Переход к мини-приложению
- Переход к команде
- Ссылка
- Платёж
- Открыть в модальном окне
- Подстановка (переключение контента)
- Начать диалог
- Закрыть мини-приложение
- Ссылка мини-приложения (открытие URL внутри мини-аппа)

## Мини-истории (Stories)

### Создание

1. Нажать **"+"** в разделе мини-историй
2. Дать название
3. Загрузить изображение/видео (до **50 МБ**)
4. Добавить несколько историй для слайдшоу-эффекта
5. Опционально: добавить клавиатуру с одной кнопкой (действие -- ссылка, начать диалог и др.)

### Интеграция в мини-приложение

1. Блок **"Карточки"** -> добавить карточку -> загрузить обложку
2. Действие карточки: **"Переход к мини-истории"**
3. Истории работают как Telegram-истории: можно переключать, останавливать

### Stories с прогрессом

- Каждая история автоматически показывает **прогресс-бар** вверху
- Переключение свайпом или тапом
- Пауза при удержании
- Кнопка внутри истории (например, "Начать диалог" с закрытием мини-приложения)

## Меню (до 5 кнопок)

### Блок "Меню"

Фиксированное нижнее меню навигации:

1. Создать отдельное мини-приложение для меню
2. Добавить блок **"Меню"**
3. Выбрать стиль: **только изображение** / **изображение + название**
4. Загрузить иконки (рекомендуется **SVG** -- меняют цвет при активности; **PNG** -- цвет меняется только у надписи)
5. Для каждой кнопки: действие (переход к мини-приложению) + **активные страницы**

### Активные страницы

- Указать все мини-приложения, при просмотре которых кнопка меню будет **подсвечена**
- Включать подразделы явно -- иначе кнопка не подсветится
- Предустановленный цвет активности -- синий (изменяется в кастомизации)

### Меню на всех страницах

Используется блок **"Подстановка"**:

1. На каждой странице добавить блок "Подстановка"
2. Указать мини-приложение с меню
3. Меню отобразится единообразно на всех страницах **без дублирования кода**

## Вкладки (до 24 штук)

### Блок "Вкладки"

Два типа:

**Обычные вкладки (до 5):**
- Текстовые названия
- Каждая связана с мини-приложением
- Переключение по клику

**Расширенные вкладки (до 24):**
- С иконками
- Работают по принципу подстановки контента из мини-приложений
- В дополнительных настройках: вкладка по умолчанию

### Настройка

1. Добавить блок **"Вкладки"**
2. Выбрать тип: обычные / расширенные
3. Для каждой вкладки: связать с мини-приложением
4. Расширенные: загрузить иконки, задать порядок
5. Допнастройки: вкладка по умолчанию

## HTML-блок

### Использование

1. Добавить блок **"HTML"** в мини-приложение
2. Заполнить HTML-код

### HTML в TagHead

В дополнительных настройках -- код, который вставляется в `<head>` страницы:
- Обычно используется для **сервисов аналитики** (Яндекс.Метрика, Google Analytics)
- Подключение внешних стилей и скриптов

### Общий HTML для всех мини-приложений

Настройки бота -> Мини-приложения: добавить **общий HTML-код** для всех приложений (статистика, общие стили).

### Навигация из HTML

Три способа перехода между страницами:

#### 1. Атрибут `goto_web_page`

```html
<a goto_web_page="bb0ad173446c99b1">Перейти на вторую страницу</a>
```
- Значение: ID мини-приложения (например, `bb0ad173446c99b1`)
- После загрузки страницы атрибут заменяется на `href`

#### 2. Функция `gotoWebPage()`

```html
<button onclick="gotoWebPage('bb0ad173446c99b1')">Перейти</button>
```
- Первый аргумент: ID мини-приложения
- Второй аргумент: `false` (по умолчанию) = переход внутри аппа; `true` = открытие в стороннем браузере

#### 3. Функция `getWebPageUrl()`

```html
<script>
  var url = getWebPageUrl("bb0ad173446c99b1");
  // Возвращает ссылку текстом, не переходя
</script>
```

### Вывод аватара пользователя

```html
<div style="display: flex; align-items: center; gap: 10px;">
  <img src="{{USER_AVATAR_URL}}" alt="Аватар"
       style="width: 60px; height: 60px; border-radius: 60%;
              border: 2px solid #1590b7;">
  <div>
    <span style="font-size: 20px; color: #333;">
      <strong>{{FIRST_NAME_TEXT}}, приветствуем</strong>
    </span>
  </div>
</div>
```

### HTML-карточки (flexbox)

```html
<div style="display: flex; align-items: center; gap: 10px;">
  <div style="display: block; margin-left: 2%; margin-right: 2%;">
    <a goto_web_page="ID_СТРАНИЦЫ_1">
      <img src="URL_КАРТИНКИ" style="width: 100%; border-radius: 5px;">
    </a>
  </div>
  <div style="margin-right: 2%;">
    <a goto_web_page="ID_СТРАНИЦЫ_2">
      <img src="URL_КАРТИНКИ_2" style="width: 100%; border-radius: 5px;">
    </a>
  </div>
</div>
```

### Ограничения

- Сложный код может не работать на страницах PuzzleBot
- Решение: разместить код на GitHub и открывать мини-приложение по **внешней ссылке**

## Блок "Подстановка" (Substitution)

### Принцип

Вставка контента одного мини-приложения внутрь другого **без дублирования**.

### Использование

1. Добавить блок **"Подстановка"**
2. Указать название мини-приложения для подстановки
3. Контент отобразится как часть текущей страницы

### Подстановка условий

Вместо мини-приложения можно указать **название условия** -- динамическое отображение контента в зависимости от проверок.

### Сворачиваемый контент

- Включить **"Скрыть подзаголовок"**
- Контент по умолчанию свёрнут
- Разворачивается по клику на заголовок
- Настройка расположения и стиля заголовка

### Обёртка

Подстановка поддерживает **обёртку** -- отдельный визуальный блок вокруг подставленного контента.

### Кнопки с действием "Подстановка"

Кнопка клавиатуры с действием **"Подстановка"**: контент подставляется/скрывается при нажатии (переключение).

### Ограничения подстановки на странице товара

Навигационные элементы (формы ввода, меню, клавиатуры, блоки товаров) **не отображаются** при подстановке на страницу товара.

## Popup / Модальные окна

### Попапы (два вида)

**С кнопкой:**
- Добавить действие **"Показать попап"**
- Содержит текст и кнопку действия
- Используется для подтверждений, предупреждений

**Без кнопки:**
- Текст внизу экрана
- Автоматически исчезает
- Используется для коротких уведомлений

### Модальное окно

Открытие мини-приложения **поверх текущей страницы**:

1. Кнопка клавиатуры -> действие **"Открыть в модальном окне"**
2. Указать: название мини-приложения + заголовок окна
3. Удобно для деталей, настроек, подтверждений

### Поп-ап при отсутствии подписки

В дополнительных настройках кнопки перехода к защищённому приложению:
- **"Показать поп-ап"** -> текст "Необходимо подписаться"
- Срабатывает только если пользователь не подписан на ресурс

## Поиск внутри мини-приложения

### Блок "Поиск"

1. Добавить блок **"Поиск"** в мини-приложение
2. Настроить область поиска:
   - По отдельным мини-приложениям
   - По целым группам команд
3. Настроить отображение результатов:
   - Название мини-аппа
   - Название группы
   - Иконка блоков

### Что индексируется

- Текстовые блоки
- Кнопки
- Изображения и видео -- **только если есть описание**

### Поисковые настройки страницы

Для каждого мини-приложения:
- **Заголовок** -- отображается вместо названия
- **Описание** -- дополнительная информация
- **Ключевые фразы** -- для нечёткого поиска

### Исключение из поиска

Опция **"Игнорировать в поиске по группе команд"** -- исключает страницу из результатов поиска.

### Навигация по результатам

- Клик по миниатюре блока -> перемещение к нужному месту
- Клик по кнопке -> выполнение действия кнопки
- Если блок на текущей странице -- описание в поиске не отображается
- Если на другой странице -- может выводиться название мини-аппа и/или группы

## Полноэкранный режим (Fullscreen)

1. Открыть **BotFather** -> /mybots -> выбрать бота
2. **Bot Settings** -> **Configure Mini App** -> активировать

1. BotFather -> /mybots -> выбрать бота
2. **Bot Settings** -> **Menu Button** -> **Configure Menu Button**
3. Вставить техническую ссылку мини-приложения
4. Указать название кнопки

### Кнопка в профиле бота

1. BotFather -> /mybots -> выбрать бота
2. **Bot Settings** -> **Configure Mini App** -> активировать
3. Вставить техническую ссылку мини-приложения

## StartPayload / UTM

### WebPageStartPayload

Переменная `{{WebPageStartPayload}}` содержит значение после `_` в ссылке StartApp.

### Формат ссылки

```
https://t.me/UserNameBot?startapp=параметр
```

- До **512 символов** после `_`
- Примеры: UTM-метки, маркеры, промокоды

### Реализация

1. Скопировать ссылку на бота, добавить `_метка` (до 512 символов)
2. Создать условие: проверка `WebPageStartPayload` -> "сообщение содержит" -> фраза метки
3. Если совпадает -> переход к нужному мини-приложению
4. Разные метки -> разные приложения

### Подстановка условий по метке

В основном мини-приложении: блок "Подстановка" -> указать название **условия** (вместо приложения). Условие проверяет метку и подставляет нужный контент.

## Якоря и навигация

### Создание якоря

1. Рядом с нужным блоком нажать **троеточие**
2. Выбрать **"Скопировать ссылку"**
3. Ссылка содержит якорь на конкретный блок

### Использование

- В кнопке: действие **"Ссылка, браузер по умолчанию"** -> вставить якорную ссылку
- Глубокие ссылки на конкретные блоки внутри мини-приложения

### Короткая ссылка на мини-приложение

Через BotFather:
1. Команда `/newapp` -> выбрать бота
2. Указать: название, описание, фото **640x360**, техническую ссылку, окончание URL
3. Формат прямой ссылки: `https://t.me/UserNameBot/short_name?startapp=параметр`

### Баг с прямой ссылкой (актуально на сентябрь 2024)

При переходе по прямой ссылке может открываться основное мини-приложение вместо указанного. Исправление: добавить `/short_name` после юзернейма бота перед `?`.

## Ограничение доступа по подписке

### Через группу команд

1. Создать **отдельную группу команд**
2. В настройках группы -> **"Проверка подписки на ресурс"** -> выбрать канал
3. Мини-приложения в этой группе доступны **только подписчикам**
4. В основной группе: кнопка перехода к мини-приложению из защищённой группы
5. В допнастройках кнопки: **"Показать поп-ап"** при отсутствии подписки

### Кнопка "Подписаться"

Действие: **"Ссылка мини-приложения"** -> URL канала. Открывает канал для подписки прямо из мини-аппа.

### Важно

- Бот должен иметь **ВСЕ** права администратора (включая последний переключатель -- для юзер-бота)
- Обязательно написать сообщение в ресурс после добавления бота
- Проверка подписки настраивается на уровне **группы команд**, а не отдельного мини-приложения

## Формы в мини-приложениях

### Типы форм

| Тип | Описание |
|-----|----------|
| **Текст** | Свободный ввод текста |
| **Число** | Ввод числа (с маской) |
| **Телефон** | Автоматическая валидация формата |
| **Регулярное выражение** | Кастомная валидация (ФИО, дата, email, ИНН, паспорт, карта) |
| **Список** | Выбор из вариантов (вручную / файл / Google Sheets / NocoDB) |
| **Выбор варианта** | Кнопки выбора с подстановкой контента |
| **Тестирование** | Варианты с отметкой правильных (для квизов) |
| **Опрос** | Варианты без правильных ответов |
| **Календарь** | Выбор даты (можно запретить прошлые даты) |
| **Выбор адреса** | Системная в командах доставки магазина |

### Регулярные выражения

Примеры regex для валидации:

```
ФИО:      ^[А-ЯЁ][а-яё]+\s[А-ЯЁ][а-яё]+\s[А-ЯЁ][а-яё]+$
Дата:     ^(0[1-9]|[12][0-9]|3[01])\.(0[1-9]|1[0-2])\.(19|20)\d{2}$
Телефон:  ^+7\s?\(?\d{3}\)?[\s-]?\d{3}[\s-]?\d{2}[\s-]?\d{2}$
Email:    ^[a-zA-Z0-9._%+-]+@gmail\.com$
ИНН:      ^\d{10}$|^\d{12}$
VK:       ^(https?://)?(www\.)?vk\.com/[a-zA-Z0-9_.]+$
Паспорт:  ^\d{4}\s\d{6}$
Карта:    ^\d{4}-\d{4}-\d{4}-\d{4}$
```

Для каждого поля:
- **Плейсхолдер** -- подсказка формата внутри поля
- **Сообщение об ошибке** -- отображается под полем при несоответствии

### Форма "Список" из NocoDB

1. Форма ввода -> тип **"Список"** -> источник **NocoDB**
2. Настроить: столбец **отображения** и столбец **записи**
3. При выборе: в переменную записывается значение из столбца записи
4. Новая интегрированная переменная тянет остальные данные, фильтруя по записанной переменной

### Дублирование ответа в переменную

В допнастройках формы: **"Дублировать ответ в переменную"** -> указать переменную для сохранения ответа.

## Мини-приложение для админа

### Просмотр заявок

1. Создать мини-приложение с переменными из NocoDB (данные заявки)
2. Добавить **фиксированную клавиатуру**: кнопки "Принять" (зелёный) и "Отклонить" (красный)
3. Условие проверки наличия переменной: есть заявка -> показать; нет -> экран "Заявок нет"
4. Обработка: отправить команду-уведомление другому пользователю (по ID из переменной) + удалить строку из NocoDB + перейти к следующей заявке

### Уведомление админа о новой заявке

В мини-приложении отправки заявки:
- Действие **"Отправить команду администратору"** (выполнить другому пользователю по юзернейму)
- Команда содержит текст + инлайн-кнопку для быстрого перехода к просмотру

## Кастомизация

### Настройка стилей

Заголовок **"Стиль"** -> **"Кастомизировать"**:
- Цвета (основной, фон, акцент)
- Шрифты
- Размеры элементов
- Базовая ОС (iOS / Android) -- дизайн какой ОС будет базовым

**Элемент интерфейса (из OCR):** Кнопка `визуальные настройки` (32 упоминания в видео) -- открывает панель кастомизации стилей мини-приложения.

### Блоки мини-приложений -- точные названия (из OCR)

| Блок | Название в интерфейсе |
|------|----------------------|
| Карточки | `Карточка` |
| Строки | `Строки` |
| Вкладки | `Вкладки` |
| Клавиатура | `Клавиатура` (тип: Обычная / Инлайн / Фиксированная) |
| Стикер | `TGS` (формат файла стикеров) |
| Товар | `Товар` |

### Формулы в тексте

Расчёты прямо в тексте без создания переменных:

```
{{= выражение =}}
```

Примеры:
- `{{= price * quantity =}}` -- стоимость
- `{{= if {{otvet}} > 5 ; {{sfera1}} ; {{sfera2}} =}}` -- условный вывод
- `{{= round({{balance}}, 2) =}}` -- округление

## Настройки Конструктора для мини-приложений

### Техническая ссылка

Скопировать из Конструктора (мини-приложение должно быть **опубликовано**).

### Облегчённый вид

Настройки -> Конструктор -> **облегчённый вид**: блоки скрываются при масштабировании для удобства навигации.

### Заметки

Создание заметок-комментариев на рабочей области Конструктора для пояснений к блокам.

### Кнопка настройки мини-приложения

Три точки в правом верхнем углу мини-приложения (настраивается через BotFather).
