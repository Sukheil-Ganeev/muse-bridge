## Кнопки и навигация

### 1. Как сделать бесшовный переход в мини-приложении через HTML?

Три способа:

**Способ 1 -- атрибут `goto_web_page`:**
```html
<a goto_web_page="bb0ad173446c99b1">Перейти на вторую страницу</a>
```
После загрузки страницы атрибут автоматически заменяется на href.

**Способ 2 -- функция `gotoWebPage()`:**
```html
<button onclick="gotoWebPage('bb0ad173446c99b1')">Перейти</button>
```
Второй аргумент: `false` (по умолчанию) -- переход, `true` -- открыть в браузере.

**Способ 3 -- функция `getWebPageUrl()`:**
Просто возвращает ссылку текстом, без перехода.

### 2. Чем отличаются инлайн-команды от обычных?

**Инлайн-команды (розовые):**
- Содержат только 1 блок и 1 инлайн-клавиатуру
- Заменяют предыдущее сообщение (не отправляют новое)
- Идеальны для слайдеров, галерей, переключаемых меню

**Обычные команды (синие):**
- Содержат неограниченное количество блоков
- Поддерживают обычную и инлайн клавиатуру
- Отправляют новое сообщение

**Правило:** При переходе от обычной к инлайн -- текст заменяется. При переходе от инлайн к обычной -- новое сообщение.

---

### 3. Как удалить уже отправленную команду с кнопками у всех пользователей?

Удалить ранее отправленное сообщение у всех нельзя. На будущее:
- Ставить действие «Удалить через время»
- Включать галочку «Удалить после вызова следующей команды»
- Для кнопок «Платеж» -- можно отредактировать в конструкторе и при сохранении дать согласие на изменение суммы для тех, кто уже получил кнопку

---

### 4. Как сделать таймер с кнопкой (если не нажал -- следующий блок)?

Через сценарий:
1. В команде с кнопкой запустить сценарий с постом через заданное время
2. По нажатию кнопки -- перевести пользователя на следующую команду и **отключить сценарий**
3. Если кнопка не нажата -- сценарий сработает и отправит следующий блок

## Переменные и формулы

### 5. Как записать фото в переменную, если пользователь просто отправляет его боту?

Фото без контекста воспринимается как «неизвестная команда». Решения:
1. На событие «Неизвестная команда» отправить промежуточную команду с формой ввода (маска «Изображение»)
2. В `/start` поставить действие «Отправить команду» с блоком формы ввода

Напрямую поставить форму на «неизвестную команду» нельзя.

### 6. Какие операции с датами есть в PuzzleBot?

| Функция | Описание |
|---------|----------|
| `ADD_DAYS(date, n)` | Прибавить/вычесть дни |
| `ADD_HOURS(date, n)` | Прибавить/вычесть часы |
| `ADD_MONTHS(date, n)` | Прибавить/вычесть месяцы |
| `ADD_YEARS(date, n)` | Прибавить/вычесть годы |
| `ADD_MINUTES(date, n)` | Прибавить/вычесть минуты |
| `ADD_SECONDS(date, n)` | Прибавить/вычесть секунды |
| `DAYS_BETWEEN(d1, d2)` | Разница в днях |
| `DATE_FORMAT(date, fmt)` | Форматирование |

Для вычитания используй отрицательное значение: `ADD_HOURS(date, -2)`.

Формат даты: любой общепринятый (dd.mm.yyyy, dd/mm/yyyy, yyyy-mm-dd), год всегда 4 цифры.

### 7. Как вывести все записи из NocoDB в мини-приложении?

В интегрированной переменной:
- Вывести все значения одного столбца через формат «наличие»
- В доп. настройках вариант поиска «все»
- В поле «разделить при нескольких значениях» указать тег `<br>` для переноса строки

Вывод всей таблицы со всеми столбцами -- сложная задача, требует кастомного решения.

### 8. Как разбить ответ формы на несколько переменных?

Через regex-функцию `match_all`:
```
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 0)  -- первая строка
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 1)  -- вторая строка
match_all({{var}}, "/([a-zA-Z0-9]+)/m", 2)  -- третья строка
```
Регулярное выражение подбирается под конкретный формат данных.

## Оплата и платежи

### 9. Как ограничить доступ к контенту через 30 дней после оплаты?

1. При оплате создать переменную с датой = текущая + 30 дней: `AddDate(CurrentDate, 30)`
2. Запустить сценарий, который каждый день сравнивает текущую дату с переменной
3. Если даты равны -- выполнить действия по запрету: смена категории, отключение сценария

---

### 10. Что за ошибка 80 при оплате через Робокассу?

Превышен лимит дохода за месяц или сумма товаров больше допустимого лимита. Лимиты указаны на странице Тарифов PuzzleBot. Лимит сбрасывается 1-го числа каждого месяца. Решение -- перейти на более высокий тариф.

---

### 11. Как оплатить тариф PuzzleBot по безналичному счету (юр. лицо)?

Отправить на email **weare@puzzlebot.top**:
- Карточку компании (реквизиты)
- Юзернейм бота или аккаунта
- Предпочитаемый тариф
- Период тарифа (минимум 3 месяца по счету)

Криптовалютой можно оплатить через бот **@paypuzzlebot**.

## Рассылки

### 12. Как настроить «пуш-напоминание» неактивному пользователю?

1. Создать сценарий с постом, тип отправки «Через 7 дней»
2. В настройках: «Перезапуск при повторном вызове»
3. Запуск сценария привязать к ключевым командам бота
4. Если пользователь активен -- сценарий перезапускается, таймер обнуляется
5. Если неактивен -- через 7 дней получает пост-напоминание

---

### 13. Как сделать рассылку из Google Таблиц с персонализированным текстом?

1. Рассылка ведет на условие
2. Условие проверяет наличие User ID в таблице
3. Если найден -- отправить команду с интегрированной переменной (текст из таблицы)

**Критически важно:** Ставить большое кэширование и в условии, и в интегрированной переменной. Google Sheets допускает только **60 запросов в минуту**.

---

### 14. Как загрузить список пользователей для рассылки?

Отправить на **support@puzzlebot.top**:
- Юзернейм бота
- Файл (.csv или Excel) с Telegram ID пользователей

Бот должен быть привязан к PuzzleBot.

## Настройка бота

### 15. Как загрузить файл больше лимита личного кабинета?

Через File ID:
1. Открыть бота, отправить команду `/cp`
2. Выбрать «Загрузить файл» и отправить файл
3. Скопировать ID вида `AgACAgIAAxkBA...`
4. Вставить в блок в личном кабинете

Лимит через ID -- до **2 ГБ** (как у Telegram). Важно: File ID уникальны для каждого бота.

---

### 16. Как дублировать группу команд внутри одного бота?

Прямой возможности нет. Хитрый способ:
1. Дублировать нужную группу в **другой бот** (Настройки -> Дублировать)
2. Из другого бота дублировать обратно в исходный
3. Обязательно дублировать **БЕЗ замены** (иначе потеряете данные)

---

### 17. Как принимать одновременно кнопки и произвольный текст?

Прямого решения нет, но через «костыль»:
1. Создать переменную-флаг `ожидает_текст`
2. В команде с кнопками установить флаг
3. Переопределить событие «Неизвестная команда» -> условие проверки флага
4. Если ожидается текст -- записать в переменную
5. Если нет -- стандартный ответ «Я не знаю, как ответить»

## Интеграции

### 18. NocoDB или Google Таблицы -- что выбрать?

| Критерий | Google Sheets | NocoDB |
|----------|--------------|--------|
| Скорость | 60 запросов/мин | 10 запросов/сек |
| Хранение данных | Серверы Google | Серверы PuzzleBot |
| Настройка | Авторизация Google | API-токен |
| Рекомендация | Простые проекты | Большие проекты, приватность |

**NocoDB** рекомендуется сообществом как более быстрый и безопасный вариант. Работает на собственных серверах PuzzleBot: `nocodb.puzzlebot.top`.

---

### 19. Интегрированная переменная не загружается с первого раза в мини-приложении. Что делать?

Действия «До» в мини-приложениях выполняются не совсем «До», а «Между». Решения:
1. **Промежуточное приложение:** переход через промежуточное мини-приложение для изменения переменной и переадресации
2. **Скрипт:** получать данные из таблицы скриптом напрямую, без интегрированной переменной

## Общие вопросы

### 20. Может ли бот первым написать пользователю?

**Нет**, если пользователь не взаимодействовал с ботом ранее. Единственное исключение:
- Закрытый ресурс (канал/группа) с функцией «Заявка на вступление»
- При подаче заявки бот может отправить сообщение пользователю (через событие ресурса)

Это ограничение Telegram, а не PuzzleBot.
