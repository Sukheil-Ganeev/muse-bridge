# Troubleshooting — Telegram Platform

> Боты: проблемы с Bot API см. в `telegram-bot-справочник`

---

### 1. FLOOD_WAIT_X — слишком частые запросы

**Симптом:** Ошибка `FloodWaitError` с указанием секунд ожидания.

**Решение:**
```python
from telethon.errors import FloodWaitError
import asyncio

try:
    await client.send_message(channel, text)
except FloodWaitError as e:
    await asyncio.sleep(e.seconds)
    await client.send_message(channel, text)
```
- Добавьте задержки 1-3 сек между запросами
- Используйте exponential backoff при повторных ошибках
- Premium-аккаунт снимает часть лимитов (FLOOD_PREMIUM_WAIT)

---

### 2. Сессия невалидна / AUTH_KEY_UNREGISTERED

**Симптом:** Ошибка авторизации после перезапуска.

**Решение:**
- Удалите файл `.session` и авторизуйтесь заново
- Проверьте, не была ли сессия завершена в настройках Telegram
- Не переносите `.session` между устройствами без понимания привязки
- Убедитесь, что api_id и api_hash корректны

---

### 3. PHONE_NUMBER_BANNED — аккаунт заблокирован

**Симптом:** Невозможно авторизоваться, ошибка бана.

**Причины:**
- Массовый спам или парсинг
- Жалобы от пользователей
- Использование в нескольких автоматизациях одновременно

**Решение:**
- Подать апелляцию: https://telegram.org/support (с номера через приложение)
- Для нового аккаунта: "прогрев" 1-2 недели обычного использования перед автоматизацией
- Использовать отдельный номер для автоматизации

---

### 4. Не могу получить участников канала — CHAT_ADMIN_REQUIRED

**Симптом:** Ошибка при `GetParticipantsRequest` для канала.

**Решение:**
- Для каналов (не супергрупп) нужны права админа
- Для публичных каналов: можно получить только count, но не список
- Для своего канала: убедитесь, что аккаунт — владелец или админ

---

### 5. Сообщение не публикуется в канал

**Симптом:** Нет ошибки, но пост не появляется.

**Проверить:**
- Аккаунт — админ канала с правом `post_messages`
- Правильный username/ID канала (с `-100` для ID)
- Канал не заблокирован/ограничен
- Файл не превышает лимит (2 GB / 4 GB Premium)

```python
# Проверка прав
full = await client(GetFullChannelRequest("channel"))
print(full.full_chat.about)  # Если работает — доступ есть
```

### 6. Stories не публикуются — STORIES_NOT_AVAILABLE

**Симптом:** Ошибка при `SendStoryRequest`.

**Решение:**
- Stories доступны только для Premium-аккаунтов (более 3 в день)
- Для каналов: Stories поддерживаются с определённого размера
- Проверьте формат медиа: фото (JPEG/PNG) или видео (MP4, до 60 сек)

---

### 7. Медиафайл не загружается — FILE_REFERENCE_EXPIRED

**Симптом:** Ошибка при пересылке или повторной отправке файла.

**Решение:**
```python
# Telethon — обновление file_reference
message = await client.get_messages("channel", ids=message_id)
# Теперь message.media содержит свежий file_reference
await client.send_file("target_channel", message.media)
```
- file_reference устаревает через несколько часов
- Всегда получайте свежее сообщение перед пересылкой медиа

### 8. Не могу создать супергруппу — CHANNELS_TOO_MUCH

**Симптом:** Превышен лимит созданных каналов/групп.

**Решение:**
- Лимит: ~500 каналов/супергрупп (1000 для Premium)
- Удалите или покиньте неиспользуемые каналы/группы
- Подключите Premium для увеличения лимита

---

### 9. Topik-режим (форум) не включается

**Симптом:** Опция "Топики" недоступна в группе.

**Решение:**
- Группа должна быть супергруппой (не базовой)
- Минимум ~200 участников (ограничение Telegram)
- Через API: `channels.toggleForum(channel, enabled=True)`
- Нужны права owner или admin с `manage_topics`

---

### 10. Telegram Ads — реклама отклонена модерацией

**Симптом:** Объявление не проходит модерацию.

**Причины:**
- Текст >160 символов
- Запрещённая тематика (азартные игры, фарма без лицензии)
- Некорректная ссылка в кнопке
- Обманчивый текст (clickbait)

**Решение:**
- Чётко укажите продукт/услугу в тексте
- Используйте прямую ссылку на канал или бот
- Избегайте капса и восклицательных знаков
- Для туризма: укажите конкретные цены и услуги

---

### 11. Slow mode конфликтует с ботом

**Симптом:** Бот не может отвечать быстро в группе с slow mode.

**Решение:**
- Боты не подпадают под slow mode (только обычные участники)
- Если бот = userbot (через MTProto), slow mode действует
- Решение для userbot: назначить admin-права (админы не ограничены slow mode)

---

### 12. API возвращает устаревшую статистику

**Симптом:** `GetBroadcastStatsRequest` показывает данные с задержкой.

**Решение:**
- Встроенная статистика обновляется с задержкой 1-6 часов
- Для постов старше 7 дней — приблизительные данные
- Для точных данных в реальном времени: используйте TGStat API
- Графики хранятся 90 дней, экспорт — до 1 года

---

### 13. UserBot забанили за "спам" — UserIsBlockedError

**Симптом:** Аккаунт ограничен после массовой рассылки или добавления в группы.

**Решение:**
- Не добавляйте более 20 пользователей за раз
- Не отправляйте одинаковые сообщения многим пользователям
- "Прогрейте" аккаунт: 1-2 недели обычного использования
- Используйте Premium-аккаунт
- Апелляция: Настройки > Конфиденциальность > Обратиться в поддержку

---

### 14. Telethon: `Database is locked` при нескольких процессах

**Симптом:** Ошибка SQLite при запуске двух скриптов с одной сессией.

**Решение:**
- Один файл `.session` = один процесс
- Для нескольких процессов: создайте разные сессии (`TelegramClient('session_1', ...)`)
- Альтернатива: один процесс с несколькими обработчиками

---

### 15. Premium-функции не работают через API

**Симптом:** Stories, кастомные эмодзи, бизнес-функции недоступны.

**Решение:**
- Убедитесь, что аккаунт имеет активную Premium-подписку
- Некоторые функции доступны только через клиентское приложение
- TDLib обычно получает поддержку новых функций быстрее Telethon/Pyrogram
- Обновите библиотеку до последней версии
