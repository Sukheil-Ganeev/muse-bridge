# FAQ — Telegram Platform

> Боты: вопросы про Bot API см. в `telegram-bot-справочник`

---

### 1. Чем отличается MTProto API от Bot API?

**Bot API** — REST-обёртка для ботов (токен от BotFather, ограниченные возможности). **MTProto** — полный протокол Telegram, даёт доступ к каналам, группам, Stories, контактам и всем функциям клиента. Для управления каналами и контентом используйте MTProto через Telethon/Pyrogram.

---

### 2. Как получить API ID и API Hash?

Перейти на https://my.telegram.org, авторизоваться по номеру телефона, выбрать "API development tools", заполнить форму. Получите `api_id` (число) и `api_hash` (строка). Один номер = один api_id.

---

### 3. Telethon или Pyrogram — что выбрать?

Обе библиотеки на Python, асинхронные, с полным доступом к MTProto. **Telethon** — лучшая документация, огромное сообщество, больше примеров. **Pyrogram** — более "Pythonic" API, встроенный TgCrypto для скорости. Для туристического бизнеса оба подходят одинаково. Рекомендуем начать с Telethon.

---

### 4. Можно ли публиковать в канал без бота?

Да. Через Telethon/Pyrogram авторизуйтесь как пользователь (owner/admin канала) и используйте `client.send_message("channel_username", "текст")`. Бот не нужен — вы публикуете от своего аккаунта.

---

### 5. Как автоматизировать постинг в канал?

1. Получите api_id и api_hash на my.telegram.org
2. Установите Telethon: `pip install telethon`
3. Авторизуйтесь (код придёт в Telegram)
4. Используйте `client.send_message()` или `client.send_file()` с таймерами
5. Для расписания: `schedule=datetime(...)` в send_message

---

### 6. Сколько стоит Telegram Premium и зачем он для бизнеса?

$4.99/мес. Для бизнеса: файлы до 4 GB (каталоги, ваучеры), 1000 каналов (мониторинг конкурентов), 100 Stories в день, транскрипция голосовых, Business-функции (часы работы, автоответы, Quick Replies).

---

### 7. Как работает Telegram Ads?

Рекламная платформа на https://ads.telegram.org. Спонсированные сообщения (до 160 символов + кнопка) показываются в каналах с 1000+ подписчиков. Оплата по CPM (от 0.1 TON за 1000 показов). Таргетинг: по каналам, языку, тематике. Для туризма — таргетинг на RU-каналы про путешествия и ОАЭ.

---

### 8. Что такое Telegram Business и как его включить?

Набор инструментов для бизнес-аккаунтов. Включается при подписке на Premium: Настройки > Telegram Business. Функции: часы работы, местоположение, приветственные/away сообщения, быстрые ответы, подключение чат-бота, теги для чатов.

---

### 9. Как создать топики (форум) в группе?

Нужна супергруппа. Настройки группы > Топики > Включить. Через API: `channels.toggleForum(channel, enabled=True)`. После включения можно создавать темы: "Отзывы", "Бронирование", "Вопросы" — каждая тема как отдельный чат.

---

### 10. Как получить статистику канала через API?

Через Telethon: `GetBroadcastStatsRequest(channel)`. Доступно для каналов от 50 подписчиков. Метрики: рост, охват, просмотры, реакции, источники подписчиков. Для внешней аналитики: TGStat API (платный, 2.5M+ каналов).

---

### 11. Что такое Telegram Stars?

Внутренняя валюта Telegram для Mini Apps и цифрового контента. Покупается через App Store/Google Play (~$0.013/Star). Используется для подписок, покупок внутри Mini Apps, оплаты медиа. Разработчики выводят через Fragment в TON.

---

### 12. Можно ли парсить участников группы/канала?

Технически — да, через `GetParticipantsRequest`. Но: массовый парсинг нарушает ToS Telegram, аккаунт может быть забанен. Рекомендация: получайте только данные своих групп, не массово, с задержками между запросами.

---

### 13. Как публиковать Stories через API?

Через Telethon: `SendStoryRequest(peer, media, caption, period)`. Premium позволяет до 100 Stories в день. Доступно и для каналов. Для бизнеса: ежедневные анонсы экскурсий, акции, закулисье.

---

### 14. Что такое FloodWait и как его избежать?

FloodWait — ограничение Telegram при слишком частых запросах. Ошибка `FLOOD_WAIT_X` требует паузы X секунд. Избежать: задержки 1-3 сек между сообщениями, exponential backoff, Premium-аккаунт (повышенные лимиты), постепенный "прогрев" нового аккаунта.

---

### 15. Безопасно ли использовать Telethon/Pyrogram для бизнеса?

Да, если соблюдать правила: не спамить, не массово парсить, использовать отдельный аккаунт для автоматизации, включить 2FA, соблюдать rate limits. Библиотеки официально используют MTProto — это легитимный способ работы с Telegram API.
