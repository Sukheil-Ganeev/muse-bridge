# МОДУЛЬ: ПОЛИТИКИ ОТМЕНЫ И ВОЗВРАТА

---

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

### Когда отправлять:
- Когда клиент спрашивает "а если я не смогу прийти?"
- При вопросах о возврате денег
- При вопросах о переносе даты
- Когда клиент сомневается в бронировании

### Отличие от основной карточки:
- Основная карточка: краткая строка об отмене
- Модуль ПОЛИТИКИ: полные условия, сроки, исключения

---

```
Болезнь: возврат при наличии справки
Форс-мажор: рассматривается индивидуально
```

## 3. СЕКЦИЯ: ОТМЕНА И ВОЗВРАТ

### Стандартный формат:
```
*ОТМЕНА И ВОЗВРАТ*
За 48+ часов: 100% возврат
За 24–48 часов: 50% возврат
Менее 24 часов: без возврата
_Возврат на карту: 7–14 рабочих дней_
```

### Варианты:

**Гибкая политика:**
```
*ОТМЕНА И ВОЗВРАТ*
За 72+ часов: 100% возврат
За 24–72 часа: 75% возврат
Менее 24 часов: 50% возврат
День в день: без возврата
```

**Строгая политика (экстрим):**
```
*ОТМЕНА И ВОЗВРАТ*
За 7+ дней: 100% возврат
За 3–7 дней: 50% возврат
Менее 3 дней: без возврата
_Прыжки требуют заблаговременного планирования_
```

**Невозвратные билеты:**
```
*ОТМЕНА И ВОЗВРАТ*
Билеты невозвратные
_Перенос возможен за 24+ часов (один раз)_
```

**С разделением по типам:**
```
*ОТМЕНА И ВОЗВРАТ*

_Билеты через нас:_
За 48+ часов: 100% возврат
За 24–48 часов: 50% возврат
Менее 24 часов: без возврата

_Билеты напрямую у поставщика:_
По политике компании-поставщика
_Уточняйте условия при бронировании_
```

## 4. СЕКЦИЯ: ПЕРЕНОС ДАТЫ

### Формат:
```
*ПЕРЕНОС ДАТЫ*
[Условия переноса]
[Сроки]
_Ограничения_
```

### Варианты:

**Стандартный:**
```
*ПЕРЕНОС ДАТЫ*
Возможен за 24+ часов до визита
Бесплатно, один раз
_Новая дата: в течение 30 дней_
_Повторный перенос: по согласованию, возможна доплата_
```

**Гибкий:**
```
*ПЕРЕНОС ДАТЫ*
Бесплатно в любое время до начала
Неограниченное количество раз
_Новая дата: в течение 90 дней_
```

**Строгий:**
```
*ПЕРЕНОС ДАТЫ*
Возможен за 72+ часов
Комиссия 10% от стоимости
_Перенос возможен только один раз_
```

---

## 5. СЕКЦИЯ: НЕЯВКА

### Формат:
```
*НЕЯВКА (NO-SHOW)*
[Последствия]
_Что считается неявкой_
```

### Вариант:

```
*НЕЯВКА (NO-SHOW)*
Полная потеря стоимости билета
Возврат и перенос невозможны

_Что считается неявкой:_
Опоздание более 30 минут
Отсутствие документов (паспорт)
Несоответствие требованиям (вес, здоровье)
```

---

## 6. СЕКЦИЯ: ОСОБЫЕ СЛУЧАИ

### Формат:
```
*ОСОБЫЕ СЛУЧАИ*
[Ситуация]: [решение]
[Ситуация]: [решение]
```

### Вариант:

```
*ОСОБЫЕ СЛУЧАИ*

_Погодные условия:_
Отмена по погоде (ветер, дождь) — перенос бесплатно или 100% возврат

_Болезнь:_
Возврат при наличии медицинской справки
_Справка должна быть датирована до даты визита_

_Технические причины:_
100% возврат или бесплатный перенос

_Форс-мажор:_
Рассматривается индивидуально
```

---

## 7. СЕКЦИЯ: ГРУППОВЫЕ БРОНИРОВАНИЯ

### Когда добавлять:
- Для групп 10+ человек
- Когда условия отличаются от индивидуальных

```
*ГРУППОВЫЕ БРОНИРОВАНИЯ (10+)*
Предоплата: 30% при бронировании
Остаток: за 7 дней до визита

_Отмена группы:_
За 14+ дней: возврат предоплаты
За 7–14 дней: 50% предоплаты
Менее 7 дней: без возврата

_Уменьшение группы:_
До 20% от заявленного — бесплатно
Более 20% — перерасчёт по индивидуальным ценам
```

## 8. ПОЛНЫЙ ПРИМЕР МОДУЛЯ

### Пример: Стандартная политика

```
📋 *ПОЛИТИКИ*
───────────────
*ОТМЕНА И ВОЗВРАТ*
За 48+ часов: 100% возврат
За 24–48 часов: 50% возврат
Менее 24 часов: без возврата
_Возврат на карту: 7–14 рабочих дней_

*ПЕРЕНОС ДАТЫ*
Возможен за 24+ часов до визита
Бесплатно, один раз
_Новая дата: в течение 30 дней_
_Повторный перенос: возможна комиссия_

*НЕЯВКА (NO-SHOW)*
Полная потеря стоимости билета
_Опоздание более 30 минут = неявка_
───────────────
*ОСОБЫЕ СЛУЧАИ*
Погода (отмена со стороны парка): 100% возврат или перенос
Болезнь: возврат при наличии справки
Технические причины: 100% возврат

*ВАЖНО*
Билеты именные, передача третьим лицам невозможна
При возврате комиссия платёжной системы не возвращается
```

### Пример: Skydive (строгая)

```
📋 *ПОЛИТИКИ*
───────────────
*ОТМЕНА И ВОЗВРАТ*
За 7+ дней: 100% возврат
За 3–7 дней: 50% возврат
Менее 3 дней: без возврата
_Экстремальные активности требуют планирования_

*ПЕРЕНОС ДАТЫ*
Возможен за 48+ часов
Бесплатно, один раз
_Повторный перенос: 10% комиссия_

*НЕЯВКА*
Полная потеря стоимости
_Неявка также при: несоответствии требованиям (вес, здоровье), алкогольном опьянении_
───────────────
*ОСОБЫЕ СЛУЧАИ*

_Погода:_
Отмена по ветру/облачности — бесплатный перенос или 100% возврат
_Решение принимается утром в день прыжка_

_Медицинские причины:_
Отказ на медосмотре — 100% возврат
Собственное решение после брифинга — без возврата

*ВАЖНО*
Подписание отказа от претензий (waiver) обязательно
Видеосъёмка: невозвратна после оплаты
```

### Пример: Аквапарк (гибкая)

```
📋 *ПОЛИТИКИ*
───────────────
*ОТМЕНА И ВОЗВРАТ*
До начала рабочего дня: 100% возврат
В день посещения: без возврата
_Открытая дата: действует 90 дней, перенос не требуется_

*ПЕРЕНОС ДАТЫ*
Для билетов с фиксированной датой: бесплатно за 24ч+
Для open-date билетов: не требуется
_Билет действителен в любой день в течение срока_

*НЕЯВКА*
Для билетов с датой: потеря стоимости
Для open-date: использовать в течение срока действия
───────────────
*ОСОБЫЕ СЛУЧАИ*
Закрытие по погоде: 100% возврат или перенос
Частичное закрытие (некоторые горки): без компенсации
```

## 9. ПРАВИЛА ФОРМАТИРОВАНИЯ

### Заголовок модуля:
- `📋 *ПОЛИТИКИ*` (с эмодзи)
- Или без эмодзи: `*ПОЛИТИКИ*`

### Сроки:
- `За 48+ часов` (с плюсом)
- `За 24–48 часов` (диапазон с коротким тире)
- `Менее 24 часов`

### Символы:
- **`|`** можно использовать для сроков в компактной записи
- В развёрнутом формате — без `|`
- Подкатегории через `_курсив_`

### Структура:
- Разделители `───────────────` между блоками
- Внутри секций — без разделителей
