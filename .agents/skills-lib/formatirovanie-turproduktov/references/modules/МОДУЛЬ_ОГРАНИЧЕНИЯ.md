# МОДУЛЬ: ОГРАНИЧЕНИЯ И ТРЕБОВАНИЯ

---

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

### Когда отправлять:
- При бронировании ЛЮБОЙ активности
- ОБЯЗАТЕЛЬНО для экстремальных активностей (прыжки, дайвинг, сафари, зиплайн)
- Когда клиент спрашивает "можно ли мне/ребёнку/беременной"
- При наличии хронических заболеваний у клиента

### Важно:
- Модуль отправляется КАК ОТДЕЛЬНОЕ СООБЩЕНИЕ
- После основной карточки
- Самодостаточен — не требует контекста

## 3. СЕКЦИЯ: ВОЗРАСТ И РОСТ

### Формат:
```
*ВОЗРАСТ И РОСТ*
Минимум: 18 лет, рост от 150 см
_Участники 18–20 лет — согласие родителей_
```

### Варианты записи:

**Только минимум:**
```
Минимум: 12 лет, рост от 120 см
```

**Диапазон:**
```
Возраст: 8–65 лет, рост 120–200 см
```

**С сопровождением:**
```
Минимум: 5 лет
_Дети 5–12 лет — в сопровождении взрослого_
_Дети до 5 лет — не допускаются_
```

**Без ограничений:**
```
Возраст: без ограничений
_Дети до 13 лет — в сопровождении взрослого_
```

## 4. СЕКЦИЯ: ВЕС И ФИЗИЧЕСКИЕ ТРЕБОВАНИЯ

### Формат:
```
*ВЕС И ФИЗИЧЕСКИЕ ТРЕБОВАНИЯ*
Мин. вес: 40 кг, макс. вес: 120 кг
_Уметь плавать (для водных активностей)_
_Хорошая физическая форма_
```

### Варианты:

**Только максимум:**
```
Макс. вес: 120 кг
```

**Тандем (для прыжков):**
```
Тандем: макс. 100 кг
Соло: 50–100 кг
```

**С дополнительными требованиями:**
```
Макс. вес: 100 кг
_Уметь плавать_
_Хорошее зрение или контактные линзы_
```

## 5. СЕКЦИЯ: МЕДИЦИНСКИЕ ПРОТИВОПОКАЗАНИЯ

### Формат:
```
*МЕДИЦИНСКИЕ ПРОТИВОПОКАЗАНИЯ*

_Категорически запрещено:_
Беременность, эпилепсия, серьёзные проблемы с сердцем, недавние операции (менее 6 мес), психические расстройства

_Требуется справка от врача:_
Астма (контролируемая), диабет, высокое давление, проблемы со спиной/шеей, нарушения слуха
```

### Важные правила:
1. **Запятые** для перечисления (НЕ вертикальные черты!)
2. Две подгруппы: запрещено / требуется справка
3. В скобках уточнения при необходимости

### Типичные противопоказания по категориям:

**Для экстремальных активностей (прыжки, дайвинг):**
```
_Категорически запрещено:_
Беременность, эпилепсия, проблемы с сердцем, астма (неконтролируемая), психические расстройства, алкогольное/наркотическое опьянение, недавние операции, вывихи/переломы

_Требуется справка от врача:_
Диабет, высокое давление, проблемы со спиной/шеей, нарушения слуха, астма (контролируемая)
```

**Для водных парков:**
```
_Не рекомендуется:_
Беременность, эпилепсия, проблемы с сердцем, недавние операции

_Некоторые горки запрещены при:_
Проблемы со спиной/шеей, высокое давление
```

**Для смотровых площадок (минимум):**
```
_Особых медицинских ограничений нет_
_При боязни высоты — на усмотрение посетителя_
```

## 6. СЕКЦИЯ: ДРЕСС-КОД

### Формат:
```
*ДРЕСС-КОД*

_Разрешено:_
Спортивная одежда, шорты, футболка, кроссовки, купальник (для водных)

_Запрещено:_
Юбки, платья, сланцы, каблуки, свободная одежда, украшения
```

### Варианты по типу активности:

**Экстремальные активности:**
```
_Разрешено:_
Облегающая спортивная одежда, кроссовки на шнурках

_Запрещено:_
Юбки, платья, сланцы, свободная одежда, шарфы, украшения
```

**Аквапарки:**
```
_Разрешено:_
Купальники, плавки, рашгарды, буркини, пляжные шорты

_Запрещено:_
Хлопковая одежда, джинсы, нижнее бельё, абайи
```

**Смотровые площадки:**
```
_Дресс-код:_
Свободный, рекомендуется удобная обувь
```

**Рестораны/ужины:**
```
_Дресс-код:_
Smart casual, закрытая обувь
_Пляжная одежда и шорты не допускаются_
```

## 7. СЕКЦИЯ: ПЕРЕД ПОСЕЩЕНИЕМ

### Формат:
```
*ПЕРЕД ПОСЕЩЕНИЕМ*
Снять: украшения, часы, очки, пирсинг
Не употреблять: алкоголь за 24ч, тяжёлую пищу за 2ч
Взять: паспорт, удобную сменную одежду
```

### Варианты:

**Для прыжков/экстрима:**
```
*ПЕРЕД ПОСЕЩЕНИЕМ*
Снять: все украшения, часы, очки, пирсинг
Не употреблять: алкоголь за 24ч, тяжёлую пищу за 2ч
Закрепить: длинные волосы
Взять: паспорт, сменную одежду, воду
_Оборудование предоставляется_
```

**Для дайвинга:**
```
*ПЕРЕД ПОСЕЩЕНИЕМ*
Не нырять: за 24ч до полёта
Не употреблять: алкоголь за 24ч
Взять: купальник, полотенце
_Всё оборудование включено_
```

**Для аквапарков:**
```
*ПЕРЕД ПОСЕЩЕНИЕМ*
Взять: купальник, сменную одежду, солнцезащитный крем
_Полотенца и шкафчики — в аренду_
_Еда и напитки — запрещены (кроме воды и детского питания)_
```
