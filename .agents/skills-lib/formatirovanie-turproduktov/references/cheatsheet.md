## Шпаргалка WhatsApp

### Форматирование текста

| Что нужно | Как писать | Пример |
|-----------|------------|--------|
| Заголовок | `*ТЕКСТ*` | `*САФАРИ В ПУСТЫНЕ*` |
| Описание | `_текст_` | `_Незабываемое приключение_` |
| Категория | ` ```текст``` ` | ` ```Взрослый``` ` |
| Старая цена | `~текст~` | `~250$~` |

### Структурные элементы

| Что нужно | Как писать |
|-----------|------------|
| Разделитель | `───────────────` (15 штук) |
| Пробелов после категории | **2 пробела** |
| Маркер списка | `•` |
| Пустая строка | Обязательно между блоками |

### Эмодзи (только 3!)

| Эмодзи | Где |
|--------|-----|
| 💰 | Перед "СТОИМОСТЬ" |
| ➕ | Перед "ЧТО ВКЛЮЧЕНО" |
| ⚠️ | Перед "ВАЖНО" |

### Шаблон цены

```
```Категория```  ЦЕНА$
```

**Примеры:**
```
```Взрослый```  185$
```Ребёнок 3-11```  155$
```Ребёнок 0-2```  бесплатно
```VIP```  ~300$~ 250$
```

## Быстрая памятка

### Ключевые правила

| Вопрос | Ответ |
|--------|-------|
| Сколько файлов? | Туры = 1, Питание = 2 |
| Группировка цен? | Туры = по эмиратам, Питание = по пакетам |
| Пробелов после ` ``` `? | ВСЕГДА 2 |
| Какие эмодзи? | Только 💰 ➕ ⚠️ |
| Нужна валюта? | ДА, всегда |
| Пустые строки? | ДА, между блоками |

### Различия WA vs TG

| Элемент | WhatsApp | Telegram |
|---------|----------|----------|
| Жирный | `*текст*` | `**текст**` |
| Курсив | `_текст_` | `__текст__` |
| Категория | ` ```текст``` ` | `**текст**` |
| Разделитель | 15 символов | 18 символов |
| После категории | 2 пробела | ` — ` |

## Чек-лист перед отправкой

### WhatsApp
- [ ] Заголовки в `*звёздочках*`
- [ ] Описание в `_подчёркиваниях_`
- [ ] Категории в ` ```тройных кавычках``` `
- [ ] 2 пробела после категории
- [ ] Разделитель 15 символов `─`
- [ ] Эмодзи только 💰 ➕ ⚠️
- [ ] Пустые строки между блоками
- [ ] Валюта указана

### Telegram
- [ ] Заголовки в `**двойных звёздочках**`
- [ ] Описание в `__двойных подчёркиваниях__`
- [ ] Категории в `**двойных звёздочках**`
- [ ] Тире ` — ` после категории
- [ ] Разделитель 18 символов `─`
- [ ] Эмодзи только 💰 ➕ ⚠️
- [ ] Пустые строки между блоками
- [ ] Валюта указана

## Частые замены

| Неправильно | Правильно |
|-------------|-----------|
| `-----` | `─────` |
| `-` (дефис) | `─` (черта) |
| `'текст'` | ` ```текст``` ` |
| `"текст"` | `*текст*` |
| `185` | `185$` |
| `ребенок` | `Ребёнок` |
| `взр` | `Взрослый` |
| `3-11 лет` | `3-11` |
