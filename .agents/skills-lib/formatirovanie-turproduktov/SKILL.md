## ВВЕДЕНИЕ И ФИЛОСОФИЯ

### Ключевые принципы форматирования

Форматирование текста должно обеспечивать:
- **Читаемость** — информация воспринимается легко и быстро
- **Структурность** — чёткая иерархия и группировка
- **Единообразие** — одинаковые элементы оформляются одинаково
- **Компактность** — максимум информации при минимуме текста

## РАЗДЕЛ 1: СИНТАКСИС ФОРМАТИРОВАНИЯ

### 1.1. WhatsApp (одинарные символы)

| Элемент | Синтаксис | Результат |
|---------|-----------|-----------|
| Жирный | `*текст*` | **текст** |
| Курсив | `_текст_` | _текст_ |
| Моноширинный | ` ```текст``` ` | `текст` |
| Зачёркнутый | `~текст~` | ~~текст~~ |
| Цитата | `> текст` | блок цитаты |

**Особенности WhatsApp:**
- НЕ поддерживает: заголовки (H1, H2), таблицы, ссылки в markdown
- Моноширинный отменяет другое форматирование
- Нет пробелов между символами и текстом: `*текст*`, не `* текст *`
- Можно комбинировать: `*_жирный курсив_*`

**Источники:** WhatsApp Help Center, официальная документация 2025

### 1.2. Telegram (двойные символы)

| Элемент | Синтаксис | Результат | Применение |
|---------|-----------|-----------|------------|
| Жирный | `**текст**` | **текст** | Заголовки, категории, акценты |
| Курсив | `__текст__` | _текст_ | Описания, пояснения |
| Зачёркнутый | `~~текст~~` | ~~текст~~ | Старые цены |
| Цитата | `> текст` | блок цитаты | Важная информация |
| Спойлер | `\|\|текст\|\|` | скрытый | Спойлеры |

**Источники:** Telegram Core API, официальная документация 2025

**❌ НЕ ИСПОЛЬЗОВАТЬ В TELEGRAM:**
- Моноширинный для категорий — создаёт уродливые блоки кода с кнопкой «копировать»

### 1.2.1. Telegram для ботов/CRM (техническая справка)

Bot API использует `parse_mode: "MarkdownV2"` или `"HTML"`.

**MarkdownV2 требует экранирования спецсимволов**

Символы для экранирования: _ * [ ] ( ) ~ ` > # + - = | { } . и восклицательный знак

См. официальную документацию Telegram Bot API.

### 1.3. СРАВНИТЕЛЬНАЯ ТАБЛИЦА

| Элемент | WhatsApp | Telegram |
|---------|----------|----------|
| Жирный | `*текст*` | `**текст**` |
| Курсив | `_текст_` | `__текст__` |
| **Категории цен** | ` ```текст``` ` | `**текст**` |
| Зачёркнутый | `~текст~` | `~~текст~~` |

**КРИТИЧНО:**
- WhatsApp: одинарные символы (`*`, `_`)
- Telegram: двойные символы (`**`, `__`)
- **Telegram: категории ЖИРНЫМ, не моноширинным!**

### 1.4. Краткая шпаргалка Telegram

## РАЗДЕЛ 2: БАЗОВЫЕ ЭЛЕМЕНТЫ ФОРМАТИРОВАНИЯ

### 2.1. Применение стилей

| Стиль | Применение | WhatsApp | Telegram |
|-------|------------|----------|----------|
| **Жирный** | Заголовки, группировки, категории (Telegram) | `*ЦЕНЫ*` | `**ЦЕНЫ**` |
| _Курсив_ | Описания, пояснения | `_текст_` | `__текст__` |
| `Моно` | Категории (ТОЛЬКО WhatsApp!) | ` ```Базовая``` ` | ❌ не использовать |

### 2.1.1. Формат категорий цен

**Для WhatsApp:**
```
```Базовая```  50$ взр / 35$ реб
```

**Для Telegram:**
```
**Базовая** — 50$ взр / 35$ реб
```

> **ВАЖНО:** В Telegram моноширинный создаёт блоки кода — используй жирный!

### 2.2. Разделители и символы

| Символ | Название | Правило | Пример |
|--------|----------|---------|--------|
| `\|` | Вертикальная черта | ВСЕГДА с пробелами | `пн \| ср \| пт` |
| `/` | Слэш | С ПРОБЕЛАМИ для перечисления | `50$ взр / 30$ реб` |
| `→` | Стрелка | ВСЕГДА с пробелами | `Дубай → Абу-Даби` |
| `—` | Длинное тире | ВСЕГДА с пробелами | `5ч — с обедом` |
| Крупный разделитель | см. ниже | ТОЛЬКО между крупными блоками | см. правила |

#### Крупный разделитель (РАЗНЫЙ ДЛЯ ПЛАТФОРМ!)

| Платформа | Количество | Разделитель |
|-----------|------------|-------------|
| **WhatsApp** | 15 тире | `───────────────` |
| **Telegram** | 18 тире | `──────────────────` |

Используется ТОЛЬКО для разделения крупных блоков информации:
1. После описания продукта
2. Перед блоком 💰 *ЦЕНЫ*
3. Перед блоком ➕ *ОПЦИИ* (если есть)
4. Перед блоком ⚠️ *ВАЖНО*

**НЕ использовать внутри блоков между подсекциями!**

### 2.3. Эмодзи (ТОЛЬКО 3!)

| Эмодзи | Назначение | Правило размещения |
|--------|------------|-------------------|
| 💰 | Перед секцией ЦЕНЫ | Эмодзи ПЕРЕД звёздочкой |
| ➕ | Перед секцией ОПЦИИ | Эмодзи ПЕРЕД звёздочкой |
| ⚠️ | Перед секцией ВАЖНО | Эмодзи ПЕРЕД звёздочкой |

**Правильно:** `💰 *ЦЕНЫ*`
**Неправильно:** `*💰 ЦЕНЫ*` или `*ЦЕНЫ* 💰`

**Другие эмодзи ЗАПРЕЩЕНЫ!** Они создают визуальный шум и нарушают профессиональность.

### 2.4. Форматы цен

| Формат | Пример | Комментарий |
|--------|--------|-------------|
| Базовый | `50$` | Доллар ПОСЛЕ числа, БЕЗ пробела |
| С категориями | `50$ взр / 30$ реб` | Используйте сокращения |
| Диапазон | `50–80$` | Короткое тире БЕЗ пробелов |

### 2.5. Сокращения

| Полная форма | Сокращение |
|--------------|------------|
| взрослый | взр |
| ребёнок | реб |
| человек | чел |
| часов | ч |

### 2.6. Возраст и время

**Возраст:**
- От возраста: `(3+)`
- До возраста: `(8+)`
- Диапазон: `(3–11,99)`

**Время:**
- Продолжительность: `5ч`, `8ч` (БЕЗ точки)
- Временной интервал: `14:00–15:00` (короткое тире БЕЗ пробелов)

### 3.2. Правила пробелов для разделителей

| Разделитель | Правило | Правильно | Неправильно |
|-------------|---------|-----------|-------------|
| `\|` | Пробелы с обеих сторон | `A \| B` | `A\|B` |
| `/` | Пробелы с обеих сторон | `A / B` | `A/B` |
| `→` | Пробелы с обеих сторон | `A → B` | `A→B` |
| `—` | Пробелы с обеих сторон | `A — B` | `A—B` |

## РАЗДЕЛ 5: СТРУКТУРА ДЛЯ ТУРОВ

### 5.1. Базовая структура тура

```
*НАЗВАНИЕ ТУРА В КАПСЛОКЕ*
_Краткое описание маршрута, достопримечательностей, программы_
───────────────
*ДНИ И СБОР*
[дни через /]
_Детали сбора и возврата_

*МАРШРУТ* (опционально)
[Точка 1 → Точка 2 → Точка 3]

*ФОРМАТ*
[Элементы через |]

*ВКЛЮЧЕНО*
[Что входит через |]
───────────────
💰 *ЦЕНЫ* ```(дети 3–11,99)```

*Из Дубая, Шарджи, Аджмана:*
```Базовая```  50$ взр / 35$ реб
_пояснение что включено_

```Стандарт```  90$ взр / 60$ реб
_пояснение_

*Из Абу-Даби:*
```Групповая```  85$ взр / 60$ реб
_пояснение_
───────────────
➕ *ОПЦИИ* ```(по желанию)``` [ЕСЛИ ЕСТЬ]

*Объект:*
Опция 1: цена$ (возраст)
Опция 2: цена$ (возраст)
───────────────
⚠️ *ВАЖНО*
[Важные пункты]

*ОПЛАТА*
USD | Рубли СБП | AED (курс 3.65) | USDT

*ОТМЕНА*
За 48ч — 100% возврат | За 24ч — 50% | Менее 24ч — без возврата
_Билеты — возврат по политике компании-поставщика_

*ДЛЯ ОФОРМЛЕНИЯ*
Дата, кол-во взр/детей (с возрастом), эмират и отель размещения
```

### 5.2. Блок ЦЕНЫ для туров

> **КРИТИЧНО:** Группировка по ЭМИРАТАМ!

```
💰 *ЦЕНЫ* ```(дети 3–11,99)```

*Из [Эмират 1]:*
```Категория 1```  цена$ взр / цена$ реб
_что включено/не включено_

```Категория 2```  цена$ взр / цена$ реб
_описание_

*Из [Эмират 2]:*
```Категория```  цена$ взр / цена$ реб
```

**Правила:**
1. Группировка: `*Из [место]:*` в жирном
2. Категории: ` ```Категория``` ` (ДВА ПРОБЕЛА перед ценой!)
3. Формат цен: `50$ взр / 35$ реб`
4. Описание: `_курсивом_` под ценой
5. Пустая строка между категориями

### 5.3. Блок ОПЦИИ для туров

```
➕ *ОПЦИИ* ```(по желанию)```

*Объект/Локация:*
Название опции: цена$ (возраст)
Другая опция: цена$ (возраст)

*Другой объект:*
Опция: цена$ (возраст)

_Стоимость за билет_
```

**Правила:**
1. Группировка по объектам: `*Объект:*` в жирном
2. Каждая опция на ОТДЕЛЬНОЙ строке (НЕ через |)
3. Формат: `Название: цена$ (возраст)`

### 5.3.1. Примеры отдельных блоков

**Пример: Расписание**
```
*РАСПИСАНИЕ*
пн | ср | пт — 09:00–14:00
вт | чт — 10:00–15:00
```

**Пример: Маршрут**
```
*МАРШРУТ*
Дубай → Шарджа → Аджман → Дубай
_длительность 5ч — включён обед_
```

**Пример: Опции**
```
➕ *ОПЦИИ*
Трансфер из отеля — 15$ / чел
Обед — 25$ / чел
```

**Пример: Важная информация**
```
⚠️ *ВАЖНО*
_Бронирование за 24ч | паспорт обязателен_
```

## РАЗДЕЛ 7: ТИПИЧНЫЕ ОШИБКИ

### Ошибка 1: Один пробел после категории

```
❌ ```Базовая``` 50$
✅ ```Базовая```  50$
```

### Ошибка 2: Опции через |

```
❌ 124 этаж: 70$ | 148 этаж: 155$
✅ 124 этаж: 70$ (8+)
   148 этаж: 155$ (3+)
```

### Ошибка 3: Эмодзи после заголовка

```
❌ *ЦЕНЫ* 💰
✅ 💰 *ЦЕНЫ*
```

### Ошибка 4: Без группировки по эмиратам (для туров)

```
❌ ```Базовая``` 50$ взр / 35$ реб
   ```Групповая``` 85$ взр / 60$ реб

✅ *Из Дубая, Шарджи, Аджмана:*
   ```Базовая``` 50$ взр / 35$ реб

   *Из Абу-Даби:*
   ```Групповая``` 85$ взр / 60$ реб
```

### Ошибка 5: Отсутствие пробелов вокруг символов

```
❌ пн/ср/пт
✅ пн / ср / пт

❌ Точка1→Точка2
✅ Точка1 → Точка2
```

### Ошибка 6: Группировка цен питания по эмиратам

```
❌ *Из Дубая:*
   ```Трансфер + ужин```  250$

✅ ```Трансфер + ужин```  250$ взр / 225$ реб
   _стандартный трансфер из Дубая, Шарджи_
```

### Ошибка 7: Детальное меню в основном описании

```
❌ *ВКЛЮЧЕНО*
   Хумус, мутабле, мухаммара, бамие биль зейт... [50+ блюд]

✅ *ВКЛЮЧЕНО*
   Ужин-буфет (50+ блюд) | Вода | Шоу
```

### Ошибка 8: Разделители внутри блоков

Разделители `───────────────` ставятся ТОЛЬКО между крупными блоками, НЕ внутри блока *ВАЖНО*!

```
❌ НЕПРАВИЛЬНО:
⚠️ *ВАЖНО*
Минимум от 2 человек
───────────────
*ОПЛАТА*
USD | AED
───────────────
*ОТМЕНА*
За 24ч — 100%

✅ ПРАВИЛЬНО:
⚠️ *ВАЖНО*
Минимум от 2 человек

*ОПЛАТА*
USD | Рубли СБП | AED (курс 3.65) | USDT

*ОТМЕНА*
За 48ч — 100% возврат | За 24ч — 50% | Менее 24ч — без возврата
_Билеты — возврат по политике компании-поставщика_
```

**Правило:** Внутри блока ВАЖНО между подсекциями (*ОПЛАТА*, *ОТМЕНА*, *ДЛЯ ОФОРМЛЕНИЯ*) — только пустые строки, БЕЗ разделителей!

**КАК ИСПРАВИТЬ:**
1. Убрать все разделители внутри блока *ВАЖНО*
2. Оставить только пустые строки между подсекциями
3. Разделители — ТОЛЬКО между крупными блоками (перед 💰, ➕, ⚠️)

## РАЗДЕЛ 9: ПРАВИЛО ВЫДАЧИ ГОТОВОГО ТЕКСТА

### Цель

Чтобы можно было сразу копировать/отправлять клиенту без "лишних слов".

### Общее правило (ВСЕГДА)

Итоговый текст (готовый к отправке клиенту) должен выдаваться ОТДЕЛЬНО от пояснений и без каких-либо вставок/комментариев внутри него.

### Формат по умолчанию

По умолчанию итог выдаётся как **TXT файл** (НЕ в формате кода!):

→ Создать и отправить `.txt` файл с готовым текстом

### Если пользователь просит явно

- "Сделай в MD" / "дай md" / "в формате md" → выдать итог как `.md` файл

### Важно

- **НЕ использовать формат кода (code block)** — всегда отправлять файлом
- По умолчанию — `.txt` файл
- По запросу — `.md` файл
- Внутри файла — ТОЛЬКО финальный текст, без служебных пояснений
- Любые пояснения (если нужны) — только СНАРУЖИ файла и максимально коротко

### Краткая памятка формата выдачи

| Запрос | Формат выдачи |
|--------|---------------|
| Без уточнения | `.txt` файл |
| "дай в md" | `.md` файл |
| Формат кода | ❌ НЕ использовать |

### Пример правильной выдачи

Пояснение перед файлом (если нужно):
"Вот готовый текст для отправки клиенту:"

→ [Отправить файл: название_продукта.txt]

Пояснение после (если нужно):
"Текст готов к копированию."

### Пример неправильной выдачи

```text
*НАЗВАНИЕ ЭКСКУРСИИ*
_Описание_
<!-- Здесь я добавил описание -->
───────────────
*ДНИ И СБОР*
(Примечание: это блок с информацией о днях)
...
```

❌ НЕ использовать code block!
❌ Внутри текста НЕ должно быть комментариев!

## РАЗДЕЛ 13: ПРОДВИНУТОЕ TELEGRAM-ФОРМАТИРОВАНИЕ (VoiceTranscriptionBot)

> **Источник:** Проверенные практики из проекта VoiceTranscriptionBot (v5.2.0), применяемые в Telegram-ботах для туристического бизнеса.

### 13.1. HTML-режим (parse_mode="HTML")

Telegram-боты используют HTML, а НЕ Markdown. При отправке сообщений через Bot API с `parse_mode="HTML"` доступны следующие теги:

| Тег | Результат | Применение в туризме |
|-----|-----------|---------------------|
| `<b>жирный</b>` | **жирный** | Заголовки секций, названия туров, важное |
| `<i>курсив</i>` | _курсив_ | Подсказки, второстепенная информация |
| `<code>моно</code>` | `моно` | Цены, даты, суммы, телефоны, ID бронирований |
| `<blockquote>цитата</blockquote>` | блок цитаты | Описания продуктов, текст туров, отзывы |
| `<pre>блок кода</pre>` | блок кода | Таблицы, прайсы, расписания |
| `<tg-spoiler>спойлер</tg-spoiler>` | скрытый текст | Промокоды, спецпредложения |

**ВАЖНО:** HTML-режим и MarkdownV2-режим из раздела 1.2 — это РАЗНЫЕ вещи:
- **Раздел 1.2** (MarkdownV2) — для ручной отправки текста через Telegram-клиент или `parse_mode="MarkdownV2"`
- **Раздел 13** (HTML) — для отправки через бота с `parse_mode="HTML"` (рекомендуется для ботов)

### 13.2. Паттерн секции (Section Pattern)

Стандартный шаблон оформления любого блока информации в Telegram-боте:

```html
📊 <b>Заголовок секции</b>
──────────────────
▫️ Пункт 1 — описание
▫️ Пункт 2 — описание
──────────────────
```

**Правила:**
- Каждая секция начинается с эмодзи + `<b>заголовок</b>`
- После заголовка — тонкий разделитель (18 символов `─`)
- Пункты списка маркируются `▫️`
- Секция закрывается разделителем или переходит в следующую

### 13.3. Константы форматирования

| Константа | Значение | Применение |
|-----------|----------|------------|
| Тонкий разделитель | `──────────────────` (18 символов `─`) | Между подсекциями |
| Жирный разделитель | `━━━━━━━━━━━━━━━━━━` (18 символов `━`) | Между крупными блоками, итоги |
| Маркер списка | `▫️` | Пункты в списках |

**Совместимость с разделом 2.2:**
- WhatsApp по-прежнему использует 15 тире `───────────────`
- Telegram (включая ботов) использует 18 тире `──────────────────`
- Жирный разделитель `━━━━━━━━━━━━━━━━━━` — новый элемент, используется для финальных итогов и крупных разделов

### 13.4. Blockquote для описаний продуктов

В Telegram-ботах описание тура или билета оборачивается в `<blockquote>` для визуального выделения:

```html
🏛️ <b>Городской тур по Дубаю</b>
──────────────────
<blockquote>Обзорная экскурсия по главным достопримечательностям Дубая: Бурдж-Халифа, Dubai Mall, Gold Souk, Jumeirah Mosque</blockquote>
```

**Когда использовать:**
- Описание продукта (тур, билет, ресторан)
- Текст транскрипции (голосовые сообщения)
- Резюме (краткое содержание голосовых)
- Отзывы клиентов

### 13.5. Цены, даты, телефоны в `<code>`

Все числовые данные и контактная информация оборачиваются в `<code>` для удобства копирования:

```html
💰 Цена: <code>150 AED</code>
📅 Дата: <code>21.02.2026</code>
📞 Телефон: <code>+971 55 309 6985</code>
🔖 Бронь: <code>#BR-2026-0221</code>
⏰ Время: <code>09:00–14:00</code>
```

**Почему `<code>`:**
- Выделяется моноширинным шрифтом — бросается в глаза
- Telegram позволяет копировать содержимое одним нажатием
- Клиент быстро находит цену или телефон в длинном тексте

### 13.6. Расширенная эмодзи-система для туризма

> **Совместимость с разделом 2.3:** Правило "только 3 эмодзи (💰 ➕ ⚠️)" действует для КАТАЛОЖНЫХ КАРТОЧЕК и ОПИСАНИЙ ПРОДУКТОВ, отправляемых вручную. В Telegram-ботах используется расширенная система ниже.

| Категория | Эмодзи | Применение |
|-----------|--------|------------|
| Экскурсии | 🏛️ | Городские туры, обзорные |
| Билеты | 🎫 | Входные билеты, аттракционы |
| Парки | 🎢 | Аквапарки, тематические парки |
| Авто | 🚗 | Аренда автомобилей |
| Трансферы | 🚐 | Групповые и индивидуальные |
| МВУ | 🪪 | Международные водительские |
| Яхты | ⛵ | Яхт-круизы, водные прогулки |
| Водные | 🌊 | Водные развлечения, дайвинг |
| Абаи | 👗 | Традиционная одежда |
| Цена | 💰 | Стоимость, суммы |
| Дата | 📅 | Даты, расписание |
| Место | 📍 | Локации, адреса |
| Время | ⏰ | Время работы, длительность |
| Статистика | 📊 | Дашборд, отчёты |
| Поиск | 🔍 | Поиск, фильтры |
| Настройки | ⚙️ | Параметры, настройки |
| Успех | ✅ | Подтверждение, завершено |
| Ошибка | ❌ | Отмена, отказ |
| Предупреждение | ⚠️ | Важная информация |
| Срочность | 🚨 | Срочные сообщения |

### 13.7. Кнопки с эмодзи (inline-кнопки)

Каждая inline-кнопка в Telegram-боте ОБЯЗАТЕЛЬНО начинается с эмодзи:

**Кнопки действий:**
- `⭐ Сохранить` / `📌 Закрепить`
- `✅ Подтвердить` / `❌ Отмена`
- `📎 Объединить` / `📊 Дайджест`
- `🌐 Перевести` / `📜 История`

**Кнопки навигации:**
- `⬅ Назад` / `➡️ Далее`
- `◀️ Предыдущая` / `▶️ Следующая`

**Кнопки платформ (после форматирования):**
- `📱 Формат WA` — отформатировать для WhatsApp
- `💬 Формат TG` — отформатировать для Telegram

**Кнопки для туристических продуктов:**
- `➡️ Переслать {Имя}` — переслать ответственному члену команды
- `💰 Прайс` — показать прайс-лист
- `📋 Шаблон` — быстрый ответ из шаблона

### 13.8. Экранирование (XSS-защита)

При `parse_mode="HTML"` пользовательский ввод ОБЯЗАТЕЛЬНО экранировать через `html.escape()`:

```python
import html
safe_text = html.escape(user_input)
message = f"<b>Клиент:</b> {safe_text}"
```

**Что экранируется:**
- `<` → `&lt;`
- `>` → `&gt;`
- `&` → `&amp;`
- `"` → `&quot;`

**Зачем:** Если клиент отправит текст с `<`, `>` или `&`, сообщение сломается или Telegram отклонит его.

▫️ ⏰ Длительность: <code>4 часа</code>
▫️ 👥 Группа: <code>до 12 чел</code>
▫️ 🚐 Трансфер: включён

──────────────────

▫️ Взрослый: <code>150 AED</code>
▫️ Ребёнок (3-11): <code>100 AED</code>

## РАЗДЕЛ 14: АВТОМАТИЧЕСКОЕ ФОРМАТИРОВАНИЕ ЧЕРЕЗ БОТА

> **Источник:** Функциональность VoiceTranscriptionBot — AI-форматирование текстов через Gemini.

### 14.1. Что это

VoiceTranscriptionBot умеет автоматически форматировать текст для нужной платформы через AI (Gemini). Бот знает все правила из этого скилла и применяет их автоматически.

### 14.2. Триггеры команды

| Триггер (русский) | Платформа |
|--------------------|-----------|
| форматируй для тг / телеграм / телеги | Telegram |
| форматируй для ва / ватсап / whatsapp | WhatsApp |
| форматирование тг / ва | По указанию |
| оформи для тг / ва | По указанию |
| формат тг / ва | По указанию |
| форматируй (без платформы) | Бот спросит |

| Триггер (английский) | Платформа |
|-----------------------|-----------|
| format for tg / telegram | Telegram |
| format for wa / whatsapp | WhatsApp |

### 14.3. Как использовать

**Способ 1: Текст + триггер**
Отправь текст описания продукта и добавь "форматируй для тг" — бот автоматически оформит для Telegram с HTML-тегами, разделителями и эмодзи.

**Способ 2: Реплай + триггер**
Ответь на любое сообщение (транскрипцию, текст клиента, черновик) командой "форматируй для ва" — бот возьмёт текст из реплая и оформит для WhatsApp.

**Способ 3: Кнопки после перевода**
После перевода текста через бот появляются кнопки:
- `📱 Формат WA` — отформатировать результат для WhatsApp
- `💬 Формат TG` — отформатировать результат для Telegram

### 14.4. Что бот делает автоматически

При форматировании бот:
1. Определяет тип продукта (тур, питание, билет, каталожная карточка)
2. Применяет правильную структуру (раздел 5, 6, 11 или 4)
3. Расставляет разделители нужной длины (15 для WA, 18 для TG)
4. Добавляет эмодзи по правилам (💰 ➕ ⚠️ для WA, расширенная система для TG-бота)
5. Форматирует цены, даты, телефоны
6. Группирует цены правильно (по эмиратам / пакетам / категориям)
7. Экранирует спецсимволы

VoiceTranscriptionBot также предоставляет:
