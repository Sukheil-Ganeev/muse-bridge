# Форматирование для WhatsApp

## ВАЖНО ПРО ИМЯ НАВЫКА
- Основной универсальный навык в Codex: `форматирование-мессенджеры`.
- Этот файл (`форматирование-whatsapp`) — узкоспециализированный профиль для WhatsApp.
- Для WhatsApp использовать только разделитель: `───────────────` (без жирных линий).

## СИНТАКСИС WhatsApp

### Базовое форматирование
| Элемент | Синтаксис | Пример |
|---------|-----------|--------|
| Жирный | *текст* | *Заголовок* |
| Курсив | _текст_ | _примечание_ |
| Зачёркнутый | ~текст~ | ~устарело~ |
| Моноширинный (инлайн) | `текст` | `код` |
| Моноширинный (блок) | ```текст``` | ```категория``` |

### Разделители
- Стандартный: `───────────────` (15 символов тире ─)
- Использовать только один тип разделителя: `───────────────`
- НИКОГДА не использовать обычные дефисы `---` — они выглядят дёшево

### Списки
- Основной маркер: `▫️` (для пунктов)
- Альтернативы: `•`, `—` (длинное тире)
- Нумерованные: `1️⃣ 2️⃣ 3️⃣` или `1. 2. 3.`
- Чекбоксы: `✅` (сделано) / `❌` (нет) / `⬜` (ожидание)

### Цитаты
> _Текст цитаты курсивом_
Используется для выдержек из документов, законов, переписки.

### Эмодзи-маркеры для заголовков
- Позиция: ПЕРЕД текстом, НЕ после
- Использовать уместные, не декоративные
- Примеры: 📌 📋 ⚠️ 💡 📅 👤 📧 📱 ⚡️ 🔑

## СТРУКТУРА СООБЩЕНИЙ

### Короткое сообщение (до 500 символов)
```

Текст сообщения в 2-3 предложения.

▫️ Пункт 1
▫️ Пункт 2

_Примечание курсивом_
```

## ПРАВИЛА

### Обязательные:
1. Разделители `───────────────` (15 тире) между секциями
2. Использовать только `───────────────` во всех секциях и блоках
3. Заголовки всегда *жирные*
4. Эмодзи ПЕРЕД заголовком, не после
5. Длинное тире `—` для списков (не дефис `-`)
6. Цитаты: > _курсивом_

### Запрещено:
- Обычные дефисы `---` как разделители
- Эмодзи после заголовка (*Текст* 📌 — НЕПРАВИЛЬНО)
- Больше 3-4 эмодзи на пост (не карнавал)
- Стены текста без разделителей
- Markdown-ссылки [text](url) — WhatsApp их не поддерживает
- HTML-теги

### Длина сообщений:
- WhatsApp обрезает превью после ~1000 символов
- Оптимально: 1 пост = 1 тема
- Если длинно — разбить на серию постов + пост-оглавление

## СОХРАНЕНИЕ ФАЙЛОВ

При сохранении WhatsApp-постов в файлы:
- Формат: `.txt`
- Кодировка: UTF-8
- Имена файлов: `POST_N_Название.txt`
- Папка: `WhatsApp_Posts/` или по контексту
