# AI SMM Дизайн-Автоматизация

## 1. Обзор

Скилл основан на комплексном исследовании **38 AI-инструментов** по **7 категориям** для автоматизации SMM-дизайна. Исследование проведено в феврале 2026 года с фокусом на туристический бизнес в ОАЭ (экскурсии, яхты, аренда авто, билеты в парки).

**Для кого:** малый/средний бизнес, предприниматели, SMM-менеджеры, фрилансеры. Особенно актуально для мультиязычного контента (RU/EN/AR) и русскоязычных платформ (Telegram, VK).

## 4. Контент-стратегия по платформам

### Instagram (приоритет: высший)

| Формат | Частота | Контент | Инструменты |
|--------|---------|---------|-------------|
| Reels | 3-5/нед | POV экскурсий, яхт, авто; "Top-5 мест" | CapCut + InVideo AI |
| Carousel | 3/нед | Гиды, прайсы, сравнения | Canva + ChatGPT |
| Stories | Ежедневно | Опросы, behind-the-scenes, отзывы | Canva + CapCut |
| Feed Posts | 2-3/нед | Карточки экскурсий, прайсы, промо | Canva (Bulk Create) |

**Правила:** Reels 9:16 (1080x1920), 15-30 сек. Feed 3:4 (1080x1440). Хештеги 3-5 штук. Субтитры обязательны. Публикация 7-9 и 17-19 по GMT+4.

### TikTok (приоритет: высокий)

| Формат | Частота | Контент | Инструменты |
|--------|---------|---------|-------------|
| Видео | 5-7/нед | POV-экскурсии, нативная съёмка, тренды | CapCut |
| Photo Carousel | 2/нед | Listicles, мемы с локациями | Canva |

**Правила:** 21-34 секунды оптимально. Hook в первые 1-3 сек. Нативный стиль > профессиональный монтаж. Трендовые звуки дают +3-5x к охвату.

### Telegram (приоритет: высший для RU-аудитории)

| Формат | Частота | Контент | Инструменты |
|--------|---------|---------|-------------|
| Текст + фото | Ежедневно | Акции, экскурсии, отзывы | YandexGPT + Canva |
| Видеосообщения (кружочки) | 3/нед | Личные обращения, BTS | Телефон |
| Альбомы | 2/нед | Фотоотчёты | Реальные фото |
| Inline-кнопки | В каждом посте | "Забронировать", "Подробнее" | Telegram Bot API |

**Правила:** Оптимально 500-1000 символов. Markdown-разметка. Фото как документ для качества. Публикация 10-12 и 18-20 по MSK.

### VK (приоритет: средний)

| Формат | Частота | Контент | Инструменты |
|--------|---------|---------|-------------|
| Посты + фото | 3-5/нед | Экскурсии, прайсы, отзывы | YandexGPT + Canva |
| Клипы | 2-3/нед | Адаптированные Reels | CapCut |
| Статьи | 1/мес | Гиды, длинные тексты | Claude Pro |

**Правила:** Длинные тексты работают лучше чем на Instagram. Автопостинг через Make.com (VK API). YandexGPT для идеального русского.

### YouTube Shorts (приоритет: дополнительный)

- Те же Reels, адаптированные под YouTube
- Формат 9:16, до 60 секунд
- SEO: заголовок + описание + теги (ChatGPT)
- Долгосрочный reach (в отличие от Instagram/TikTok)

## 5. Пайплайн автоматизации

### Полный цикл: от идеи до аналитики

```
ИДЕЯ -> ДИЗАЙН -> ТЕКСТ -> ПЛАНИРОВАНИЕ -> ПУБЛИКАЦИЯ -> АНАЛИТИКА
  |        |        |          |               |              |
  v        v        v          v               v              v
ChatGPT  Canva   Claude/    Buffer/         Make.com      SocialBee/
контент- Magic   ChatGPT   SocialBee       VK API        Buffer
план     Studio  YandexGPT  расписание     Telegram API   метрики
```

### Этап 1: Генерация идей
- ChatGPT/Claude генерируют контент-план на неделю/месяц
- Указать платформу, аудиторию, сезон, продукт

### Этап 2: Дизайн
- Canva Pro: шаблоны + Brand Kit + Magic Resize
- Bulk Create: CSV/Sheets -> автогенерация серии карточек
- Magic Switch: один дизайн -> 10 форматов за секунды

### Этап 3: Текст
- Claude/ChatGPT: основной текст, хештеги, CTA
- YandexGPT: финальная полировка русского текста
- Адаптация под каждую платформу (тон, длина, формат)

### Этап 4: Планирование
- Buffer/SocialBee: расписание публикаций
- Оптимальное время по платформе и часовому поясу
- Content Recycling для evergreen-контента (SocialBee)

### Этап 5: Публикация
- Instagram, TikTok, YouTube -- через планировщик (Buffer/SocialBee)
- VK, Telegram -- через Make.com (API интеграция)
- Автоматический ресайз и адаптация

### Этап 6: Аналитика
- SocialBee/Buffer: встроенные дашборды
- Метрики: reach, engagement, клики, конверсии
- AI-рекомендации по времени и типу контента

### Make.com: ключевой сценарий для VK + Telegram

```
Google Sheets (идея)
  -> ChatGPT модуль (генерация текста)
  -> Canva модуль (дизайн по шаблону)
  -> VK API модуль (публикация)
  -> Telegram Bot API (публикация)
  -> Google Sheets (лог статуса)
```

## 6. ROI-калькулятор

### Формулы

**ROI (%) = ((Доход от SMM - Затраты на AI-стек) / Затраты на AI-стек) x 100**

**Стоимость привлечения клиента (CAC) = Затраты на AI-стек / Количество клиентов из SMM**

**Стоимость единицы контента = Затраты на AI-стек / Количество единиц контента**

| Writesonic API ($399+/мес) | Непропорционально дорогой | ChatGPT API ($0.15-2.50/1M) |
| Brandfolder ($1,600+/мес) | Enterprise DAM для корпораций | Canva Brand Kit ($13) |
| Frontify ($29+/мес) | Нет дизайн-редактора | Canva Pro ($13) -- всё в одном |
| Synthesia (на старте) | AI-аватары -- Premium-фича | Начните без аватаров |

### Главные ошибки

1. **Одинаковый контент на все платформы** -- каждая требует адаптации (размеры, тон, хештеги)
2. **Видео без субтитров** -- 80% смотрят без звука
3. **Только AI-изображения** -- реальные фото конвертируют лучше, AI для дополнения
4. **Игнорирование сезонности** -- пик ноябрь-март, лето -- мёртвый сезон
5. **Старт с Premium-тира** -- начните с $0, освойте, потом масштабируйте
6. **Все инструменты сразу** -- добавляйте по 1-2 в месяц
7. **Игнорирование Telegram** -- ключевой канал для RU-аудитории в ОАЭ
8. **Горизонтальное видео** на вертикальных платформах
9. **Реже 3 постов/нед** -- алгоритмы "забывают"
10. **Неофициальные API Midjourney** -- бан аккаунта
