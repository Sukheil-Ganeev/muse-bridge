# Troubleshooting -- AI SMM Дизайн-Автоматизация

## Canva

### Canva credits / Magic Studio не работает
**Проблема:** Закончились AI-кредиты Magic Studio.
**Решение:**
- Canva Free: ~50 AI-генераций/мес, потом ждать следующий месяц
- Canva Pro: 500 AI-генераций/мес (лимит сбрасывается 1 числа)
- Альтернатива: использовать ChatGPT для генерации изображений (DALL-E 3), затем импортировать в Canva
- Для массовой генерации: Leonardo AI Free (150 кредитов/день)

### Magic Resize обрезает важные элементы
**Проблема:** При ресайзе текст или объекты обрезаются.
**Решение:**
- Размещать ключевые элементы в центральной "безопасной зоне" (60% площади)
- После ресайза всегда проверять каждый формат вручную
- Использовать Magic Switch вместо Resize -- он умнее адаптирует layout

### Bulk Create не подтягивает данные
**Проблема:** CSV/Google Sheets не корректно импортируется.
**Решение:**
- Проверить кодировку CSV: UTF-8 с BOM
- Проверить заголовки колонок: без спецсимволов, без пробелов в начале/конце
- Фото: использовать прямые URL (не Google Drive shared links)
- Максимум ~200 строк за раз

## CapCut

### Автосубтитры неточные на русском
**Проблема:** CapCut распознаёт русский на 90-95%, ошибки в именах и терминах.
**Решение:**
- После автогенерации всегда проверять текст вручную
- Добавить Custom Vocabulary (Pro): имена, названия экскурсий, локации
- Для идеальных субтитров: сначала транскрибировать в ChatGPT/Claude, затем вставить как SRT в CapCut

### Водяной знак на Free тире
**Проблема:** Экспорт с водяным знаком "CapCut".
**Решение:**
- CapCut Pro ($20/мес) убирает водяной знак
- Альтернатива: экспортировать через CapCut Web (иногда без водяного знака на бесплатном тире)
- Workaround: обрезать видео так, чтобы водяной знак был незаметен (не рекомендуется для профессионального контента)

### CapCut тормозит / вылетает
**Проблема:** Приложение медленно работает при монтаже.
**Решение:**
- Уменьшить разрешение preview (Settings -> Preview Quality -> 720p)
- Закрыть другие приложения
- 4K экспорт требует Pro + достаточно мощное устройство
- Для длинных видео (>5 мин) -- работать на ПК-версии, не мобильной

## Make.com

### Сценарий не запускается / ошибка 403
**Проблема:** Make.com сценарий выдаёт ошибку при публикации.
**Решение:**
- Проверить токены API (VK/Telegram): не истекли ли
- VK: access_token действует ~24ч (implicit flow) -- использовать server-side авторизацию для долгосрочного токена
- Telegram: токен бота бессрочный, но проверить что бот -- администратор канала
- Make.com Free: max 2 сценария, 1000 операций -- проверить лимиты

### Make.com сценарий VK не публикует фото
**Проблема:** Текст публикуется, но фото не прикрепляется.
**Решение:**
- VK API требует двухшаговый процесс: (1) загрузить фото через photos.getWallUploadServer + upload + photos.saveWallPhoto, (2) использовать полученный attachment ID в wall.post
- В Make.com: использовать модуль HTTP -> Upload File, затем VK API модуль
- Альтернатива: публиковать с прямой ссылкой на изображение (менее надёжно)

### Make.com: превышен лимит операций
**Проблема:** Free/Core тир -- закончились операции.
**Решение:**
- Free: 1,000 операций/мес -- хватает на ~30-50 публикаций
- Core ($9/мес): 10,000 операций -- хватает на ~300+ публикаций
- Оптимизация: объединять шаги в Router, использовать фильтры, минимизировать ненужные модули
- Каждый модуль в сценарии = 1 операция

## AI-генерация изображений

### AI генерирует некачественные / нереалистичные изображения
**Проблема:** Результат не похож на реальные фото ОАЭ.
**Решение:**
- Использовать Flux Pro для фотореализма (10/10)
- Промпт: указывать конкретные локации ("Burj Khalifa at golden hour, shot on Sony A7III")
- Добавлять "photorealistic, 8K, professional photography" в промпт
- Negative prompt: "cartoon, illustration, painting, artificial, CGI"
- Лучше всего: реальные фото + AI-стилизация, а не полная генерация

### Текст на изображении нечитаем / с ошибками
**Проблема:** AI генерирует некорректный текст на изображениях.
**Решение:**
- Использовать **Ideogram v3** -- единственный надёжный инструмент для текста (10/10)
- Для русского/арабского текста: генерировать изображение без текста -> добавить текст в Canva
- DALL-E 3 и Midjourney слабы в генерации текста (6-8/10)
- Для прайсов и баннеров: всегда шаблон Canva + AI-фон

### Midjourney: как использовать без Discord?
**Проблема:** Midjourney работает только через Discord (неудобно).
**Решение:**
- Midjourney Web Editor (https://www.midjourney.com/editor) -- работает с версии v6+
- Мобильное приложение Midjourney (2025+)
- НЕ использовать неофициальные API (PiAPI, APIframe) -- бан аккаунта, нарушение ToS

## Планировщики (Buffer / SocialBee)

### Buffer/SocialBee не поддерживает VK/Telegram
**Проблема:** Невозможно добавить VK или Telegram каналы.
**Решение:**
- Это ограничение всех западных планировщиков
- Единственный путь: **Make.com** (или n8n) через VK API и Telegram Bot API
- Схема: Buffer публикует в Instagram/TikTok/Facebook -> Make.com по расписанию публикует тот же контент в VK + Telegram
- Можно синхронизировать: Buffer webhook -> Make.com -> VK + Telegram

### Планировщик публикует в неправильное время
**Проблема:** Посты выходят не в то время, что запланировано.
**Решение:**
- Проверить часовой пояс в настройках Buffer/SocialBee
- Для ОАЭ: GMT+4 (Dubai). Для RU-аудитории: GMT+3 (Москва)
- Instagram лучшее время: 7-9 и 17-19 по GMT+4
- Telegram лучшее время: 10-12 и 18-20 по GMT+3
- SocialBee: AI подскажет оптимальное время на основе аналитики

### Content Recycling публикует устаревший контент
**Проблема:** SocialBee переиспользует пост с неактуальной ценой/акцией.
**Решение:**
- Помечать временный контент (акции, сезонные) категорией "Non-Evergreen" -- не будет переиспользоваться
- Evergreen категории: гиды, FAQ, tips, достопримечательности
- Регулярно (1 раз/мес) проверять и обновлять evergreen-контент

## Копирайтинг

### AI генерирует слишком "роботизированный" текст
**Проблема:** Тексты звучат неестественно.
**Решение:**
- Claude: использовать Projects с примерами своего стиля
- ChatGPT: создать Custom GPT с примерами текстов, тоном бренда
- В промпте: "пиши как живой человек, без клише, как в переписке с другом"
- Финальная полировка: YandexGPT для русского текста
- Добавлять emoji и разговорные фразы вручную

### ChatGPT/Claude дают разные рекомендации
**Проблема:** Два AI-инструмента противоречат друг другу.
**Решение:**
- ChatGPT лучше для: коротких текстов, мультиязычности, трендов (Browse)
- Claude лучше для: длинных текстов, стратегии, структурированных планов
- Использовать ChatGPT для черновика -> Claude для стратегической доработки -> YandexGPT для полировки русского

### AI не знает актуальные цены / услуги
**Проблема:** AI выдумывает цены и детали экскурсий.
**Решение:**
- Всегда предоставлять AI актуальные данные (прайс-лист, описания экскурсий)
- Claude: загрузить в Project все актуальные прайсы
- ChatGPT: создать Custom GPT с базой знаний (файлы прайсов, FAQ)
- Никогда не публиковать AI-тексты с ценами без ручной проверки

## Общие проблемы

### Контент не получает охват
**Проблема:** Посты есть, но reach низкий.
**Решение:**
- Проверить частоту: минимум 3 раза/нед, лучше ежедневно
- Видео > Фото > Текст по охвату -- увеличить долю видео
- Hook в первые 1-3 секунды видео
- Субтитры обязательны
- Хештеги: 3-5 релевантных (не 30 случайных)
- Время публикации: проверить аналитику, тестировать разное время
- Reels и Stories увеличивают reach основного аккаунта

### Нет конверсий из SMM в продажи
**Проблема:** Есть охват, но нет клиентов.
**Решение:**
- Добавить CTA в каждый пост ("Напишите в WhatsApp", "Ссылка в био")
- Telegram: inline-кнопки "Забронировать" в каждом посте
- Instagram: Linkin.bio (Later) или Link Sticker в Stories
- UTM-метки для отслеживания источника
- Промокоды уникальные для каждой платформы
- Отзывы клиентов (social proof) -- лучший конвертер

### Не хватает времени на SMM
**Проблема:** Нет времени создавать контент ежедневно.
**Решение:**
- Batch-создание: 1 день/нед -> контент на всю неделю
- Canva Bulk Create: серия карточек из таблицы за минуты
- Content Recycling (SocialBee): переиспользование лучших постов
- Make.com: автоматизация публикации
- Принцип "1 -> 5": одно видео -> 5 платформ (CapCut -> Magic Resize)
- Делегировать AI: контент-план (ChatGPT) -> тексты (Claude) -> дизайн (Canva) -> публикация (Buffer)
