## Быстрый workflow: 5 шагов создания поста

```
ШАГ 1: ИДЕЯ (2 мин)
  ChatGPT: "Предложи 5 тем для поста [продукт] для [платформа]"

ШАГ 2: ТЕКСТ (3 мин)
  Claude/ChatGPT: "Напиши пост для [платформа] о [тема].
  Тон: [дружеский/профессиональный]. Язык: [RU/EN].
  Включи CTA и 3-5 хештегов."

ШАГ 3: ДИЗАЙН (3 мин)
  Canva: выбрать шаблон -> вставить текст + фото -> Brand Kit

ШАГ 4: РЕСАЙЗ (1 мин)
  Canva Magic Resize: Instagram -> VK -> Telegram -> TikTok

ШАГ 5: ПУБЛИКАЦИЯ (1 мин)
  Buffer/SocialBee: запланировать
  Make.com: автопубликация в VK + Telegram
```

**Итого: 10 минут -> пост на 5 платформах.**

## Формулы ROI

### Базовый ROI
```
ROI (%) = ((Доход от SMM - Затраты на AI-стек) / Затраты на AI-стек) x 100
```

### Стоимость привлечения клиента (CAC)
```
CAC = Затраты на AI-стек в месяц / Количество клиентов из SMM в месяц
```

### Стоимость единицы контента
```
CPC = Затраты на AI-стек / Количество единиц контента
```

### Пример: Growth тир ($77/мес), 3 клиента/мес, средний чек $150
```
Доход: 3 x $150 = $450/мес
ROI: (($450 - $77) / $77) x 100 = 484%
CAC: $77 / 3 = $25.67
CPC: $77 / 60 постов = $1.28
```

## Промпты для AI-генерации (туризм ОАЭ)

### Копирайтинг: промпт для контент-плана
```
Создай контент-план на неделю для Instagram-аккаунта
туристической компании в Дубае.

Услуги: экскурсии, яхты, аренда авто, билеты в парки.
Аудитория: русскоязычные туристы из СНГ.
Язык: русский.
Тон: дружеский, экспертный, без воды.

Для каждого дня укажи:
- Формат (Reels / Carousel / Story / Feed Post)
- Тему
- Краткое описание
- Хештеги (3-5)
- Лучшее время публикации (GMT+4)
```

### Копирайтинг: промпт для поста
```
Напиши пост для Instagram о [экскурсия в Абу-Даби].

Стиль: дружеский, как рекомендация от местного.
Длина: 150-200 слов.
Включи:
- Яркий хук (первая строка)
- 3 ключевых преимущества
- Цену или "от ХХХ AED"
- CTA (написать в Direct / WhatsApp)
- 3-5 релевантных хештегов
- Emoji (умеренно)

Язык: русский.
```

### Копирайтинг: промпт для адаптации под платформу
```
Адаптируй этот пост для [Telegram / VK / TikTok]:

[вставить оригинальный пост]

Правила адаптации:
- Telegram: до 1000 символов, Markdown-разметка, inline-кнопки
```

## Хештег-стратегия

### Правила
- 3-5 хештегов на пост (Instagram)
- Микс: 1 широкий + 2 средних + 1-2 нишевых
- Не использовать 30 случайных хештегов (снижает reach)
- Для VK: 3-5 тегов в конце поста
- Для TikTok: 2-4 хештега + 1 трендовый

## Быстрые команды Make.com

### Telegram публикация
```
Модуль: Telegram Bot -> Send Message
Chat ID: @your_channel_name (или числовой ID)
Parse Mode: MarkdownV2
Text: Форматированный текст из предыдущего модуля
```

### VK публикация
```
Модуль: HTTP -> Make a Request
URL: https://api.vk.com/method/wall.post
Method: POST
Body:
  owner_id: -GROUP_ID
  message: Текст поста
  attachments: photo{owner_id}_{photo_id}
  access_token: YOUR_TOKEN
  v: 5.199
```

### Расписание (Scheduler)
```
Модуль: Scheduler -> Run at specific times
Cron: 0 9,17 * * 1-5  (9:00 и 17:00, пн-пт)
Timezone: Asia/Dubai (GMT+4)
```
