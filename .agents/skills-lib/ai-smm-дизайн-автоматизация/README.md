Скилл для автоматизации дизайна и публикации контента в соцсетях с помощью AI-инструментов.

## Когда использовать

- Подбор AI-инструментов для SMM
- Расчёт бюджета на AI-стек
- Создание контент-стратегии по платформам
- Настройка пайплайна автоматизации (Make.com, Zapier)
- Выбор стека для Instagram, TikTok, Telegram, VK
- Расчёт ROI от AI-автоматизации
- Сравнение инструментов (Canva vs Adobe Express, Claude vs ChatGPT и т.д.)
