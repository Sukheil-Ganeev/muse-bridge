# error-handling-patterns

## Описание
Паттерны обработки ошибок на разных языках: исключения, Result-типы, propagation и graceful degradation для создания устойчивых приложений. Используется при реализации обработки ошибок, проектировании API или повышении надёжности приложений.

## Структура
```
error-handling-patterns/
├── SKILL.md              # Основной файл
├── README.md             # Этот файл
└── references/
    ├── faq.md            # Часто задаваемые вопросы
    ├── troubleshooting.md # Решение проблем
    └── cheatsheet.md     # Шпаргалка
```

Скилл активируется автоматически по триггерам в description.
