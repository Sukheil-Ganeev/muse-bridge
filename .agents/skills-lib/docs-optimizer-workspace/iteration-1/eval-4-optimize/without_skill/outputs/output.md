## Что можно убрать / перенести

### 1. Дерево файловой структуры (строки 37–352) — 315 строк → УДАЛИТЬ

Это самый большой блок (57% всего файла). Он перечисляет каждый файл в проекте с однострочным комментарием. Проблемы:
- Дерево устаревает при каждом рефакторинге.
- Claude и так может найти файлы через поиск (`Glob`, `Grep`).
- Реальная ценность — только ключевые модули и что они делают на уровне подсистем, не отдельных файлов.

**Решение:** заменить на таблицу подсистем (14 строк) вместо 315.

### 2. Детальный список тестовых файлов (строки 285–323) — ~40 строк → УДАЛИТЬ

Перечень `test_*.py` файлов с количеством тестов в каждом. Это дублирует статистику из раздела "Статистика" и устаревает после каждого PR.

**Решение:** оставить только итоговые цифры в таблице статистики.

### 3. Раздел "Зависимости" (строки 425–451) — 28 строк → УДАЛИТЬ

Полный список `requirements.txt` со всеми версиями. Это дублирует сам файл `requirements.txt`.

**Решение:** удалить. При необходимости — `cat requirements.txt`.

### 4. Раздел "Cloudflare Tunnel" (строки 498–544) — 47 строк → ПЕРЕНЕСТИ

Подробная инструкция по настройке туннеля: 4 шага с bash-командами, альтернативный способ через браузер, примечание о старом туннеле. Туннель **уже настроен** (статус ✅). Инструкция больше не нужна в оперативном контексте.

**Решение:** перенести в `docs/DEPLOY_NOTES.md` или оставить только статус одной строкой.

### 5. Детальные описания `bots/` в дереве (строки 213–274) — ~60 строк → СОКРАТИТЬ

Каждый файл каждого бота расписан с однострочным комментарием. Для Claude достаточно знать какие боты существуют и их точку входа.

**Решение:** таблица ботов (5 строк).

### 6. Раздел "Статус проекта" — описания Batch (строки 9–16) — 8 строк → СОКРАТИТЬ

Батчи 1–5 все ✅ DONE. Описания содержат детали типа "S1: formatting. S2: COMMAND_AUDIT.md. S3: CA-01..05" — это архивная история, не оперативная информация.

**Решение:** оставить только таблицу статусов без деталей внутри ячейки.

6. Заменить детальный список файлов ботов на таблицу (~10 строк).

- `D:/Downloads/TouristBotEcosystem/CLAUDE.md` — основное сокращение
