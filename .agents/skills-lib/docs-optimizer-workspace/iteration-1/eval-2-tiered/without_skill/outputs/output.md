# Анализ токенов: что загружается при работе с TouristBotEcosystem

## Итог одной строкой

Каждая сессия стартует с ~31 600 автозагружаемыми токенами. Это примерно 25% от 128K окна Claude — ещё до того, как написана хоть одна строка кода.

---

## Что загружается автоматически при каждой сессии

Claude автоматически читает все файлы с именем `CLAUDE.md` — от корня диска вверх по дереву. Для этого проекта это:

| Файл | Размер | ~Токены | Загрузка |
|------|--------|---------|----------|
| `~/.claude/CLAUDE.md` (глобальный) | 7 965 байт | **~2 000** | авто, каждая сессия |
| `TouristBotEcosystem/CLAUDE.md` | 39 824 байт | **~9 960** | авто, каждая сессия |
| `TouristBotEcosystem/CHANGELOG.md` | 68 345 байт | **~17 090** | авто, каждая сессия |
| `TouristBotEcosystem/ISSUES.md` | 10 317 байт | **~2 580** | авто, каждая сессия |
| **ИТОГО авто** | **126 451 байт** | **~31 630** | |

> **Почему CHANGELOG и ISSUES загружаются автоматически?**
> Потому что в проектном `CLAUDE.md` есть явные указания: _"Читать ISSUES.md"_ и _"Обновить CHANGELOG.md"_. Claude выполняет эти инструкции при каждом старте сессии, даже если задача никак не связана с историей изменений.

---

## Разбивка по крупнейшим элементам CLAUDE.md

Файл `CLAUDE.md` весит ~10 000 токенов. Из них:

| Секция | ~Токены | Нужна каждый раз? |
|--------|---------|-------------------|
| `## Архитектура` (дерево файлов) | **~5 000** | Нет — нужна при навигации по коду |
| `## Cloudflare Tunnel` (инструкция настройки) | **~600** | Нет — разовая операция, уже выполнена |
| `## Деплой (GCP)` (таблица с деплоем) | **~390** | Нет — справочник, не меняется |
| `## Зависимости (requirements.txt)` | **~270** | Редко — только при добавлении пакетов |
| `## Статус проекта` | **~530** | Да — статус батчей |
| `## Команды` | **~460** | Да — часто нужны |
| `## Статистика`, `## AI Backends`, `## Источники` | **~450** | Да — краткая справка |

Итого "ненужный балласт" в CLAUDE.md: **~5 000–6 000 токенов** из 10 000.

## Главная проблема: CHANGELOG.md раздут

`CHANGELOG.md` — 1 088 строк, 36 версий, **~17 000 токенов**. При типичной задаче ("добавь новый handler") нужны только последние 1–2 версии (~640 токенов). Остальные 16 400 токенов — чистый балласт.

| Часть CHANGELOG | Токены | Нужна при старте? |
|-----------------|--------|-------------------|
| Последние 2 версии (v5.9.0, v5.8.0) | ~640 | Да |
| Версии v5.7.x–v5.0.x (8 версий) | ~5 000 | Редко |
| Версии v4.x и старше (26 версий) | ~11 400 | Практически никогда |

## Конкретные рекомендации по экономии

### 1. Разделить CHANGELOG.md на "горячий" и "архив" (экономия: ~16 000 токенов)

Создать `CHANGELOG_ARCHIVE.md` для версий v5.7.x и старше.
В `CHANGELOG.md` оставить только последние 3–5 версий.

```
Текущий CHANGELOG.md:   ~17 000 токенов (загружается каждый раз)
После разделения:        ~2 000 токенов (только свежие версии)
Экономия:               ~15 000 токенов
```

### 2. Убрать дерево файлов из CLAUDE.md в отдельный файл (экономия: ~4 500 токенов)

Секция `## Архитектура` с деревом файлов занимает ~5 000 токенов и нужна только когда Claude ищет конкретный файл. Вынести в `docs/ARCHITECTURE_TREE.md`, в CLAUDE.md оставить ссылку.

```
## Архитектура
Полное дерево файлов: docs/ARCHITECTURE_TREE.md
Ключевые точки входа:
- core/services.py — DI, ~38 сервисов
- bots/telegram_main/main.py — точка запуска
- config/settings.py — ~43 env переменные
```

### 3. Убрать инструкцию Cloudflare Tunnel из CLAUDE.md (экономия: ~600 токенов)

Туннель уже настроен (статус: ✅ НАСТРОЕН). Инструкцию по настройке перенести в `docs/DEPLOY_GCP.md` или `docs/SERVER_RUNBOOK.md`. В CLAUDE.md оставить только статус.

### 4. Требования (`requirements.txt`) вынести из CLAUDE.md (экономия: ~270 токенов)

Список зависимостей продублирован в реальном `requirements.txt`. В CLAUDE.md достаточно одной строки: _"22 зависимости, см. requirements.txt"_.

### 5. Убрать CHANGELOG.md из автоматической загрузки (экономия: ~17 000 токенов)

Если инструкция "обновить CHANGELOG" нужна только при завершении работы — можно изменить формулировку в CLAUDE.md так, чтобы Claude не читал его в начале каждой сессии:

```markdown
## После завершения задачи
Обновить CHANGELOG.md (читать только при финальном коммите, не в начале сессии).
```

### 6. ISSUES.md — переформулировать ссылку (экономия: ~1 500 токенов)

Сейчас ISSUES.md весит ~2 500 токенов, большинство — закрытые задачи. Архивные разделы (Phase 8, Phase 9 — все ✅) вынести в `docs/ISSUES_ARCHIVE.md`. Активный `ISSUES.md` оставить только с открытыми задачами (~200 токенов).

## Итог по возможной экономии

| Мера | Экономия токенов |
|------|-----------------|
| 1. Разделить CHANGELOG на горячий + архив | ~15 000 |
| 2. Дерево файлов в отдельный файл | ~4 500 |
| 3. Убрать инструкцию Cloudflare (уже выполнена) | ~600 |
| 4. requirements.txt — одна строка | ~270 |
| 5. Отложенная загрузка CHANGELOG | до ~17 000 |

Это позволит сократить стартовую нагрузку с ~31 600 до **~9 000–15 000 токенов**, то есть освободить **дополнительные 15–22K токенов** для рабочего кода в каждой сессии.
