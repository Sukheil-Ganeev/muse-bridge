## Наиболее критичные случаи

### Критично: ARCHITECTURE.md vs ARCHITECTURE_v1.md
Два файла описывают одно и то же — архитектуру v4.0 на дату 2026-03-03. Один из них лишний. ARCHITECTURE.md немного полнее и является "финальной" версией. ARCHITECTURE_v1.md можно удалить или перенести в `docs/archive/`.

### Критично: DEPLOY.md (Oracle Cloud) vs DEPLOY_GCP.md (Google Cloud)
Оба файла описывают деплой одного и того же проекта, но на разные облака. DEPLOY.md устарел — реально используется GCP (34.107.127.155). Oracle Cloud упоминается только в DEPLOY.md. Вводит путаницу.

### Критично: статистика проекта не синхронизирована
Тесты: 970 (ARCHITECTURE.md) vs 1042+ (README.md) vs 1050+ (PROJECT_ACCOMPLISHMENTS.md) vs 1263 (CLAUDE.md). Единственный достоверный источник — CLAUDE.md (1263), остальные устарели.

### Критично: SSH-команда в 3 файлах
`ssh -i ~/.ssh/google_compute_engine londo@34.107.127.155` — если IP изменится, нужно обновить 3 файла одновременно.
