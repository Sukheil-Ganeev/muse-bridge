# FAQ — Facebook для туристического бизнеса

## Общие вопросы

### Какая версия Graph API актуальна?
**v22.0** (2025). С сентября 2025 запросы к версиям ниже v22.0 отклоняются. Новые версии выходят каждые ~4 месяца.

### Чем отличается Page Token от User Token?
- **User Token** — действия от имени пользователя (лайки, RSVP, группы). Живёт ~1 час (short-lived) или ~60 дней (long-lived)
- **Page Token** — действия от имени страницы (публикации, модерация, аналитика). Бессрочный, если получен из long-lived user token

### Можно ли публиковать на личный профиль через API?
Нет. API позволяет публиковать только на Pages. Это ограничение Meta с 2018 года.

### Нужен ли App Review для моего бота/приложения?
- **Development Mode** — работает без App Review, но только для админов и тестеров приложения (до 5 человек)
- **Live Mode** — требует App Review для каждого permission, который вы запрашиваете
- Для маленькой команды Development Mode достаточно

### Чем Facebook Shops отличается от Marketplace?
| | Shops | Marketplace |
|--|-------|-------------|
| Где | На вашей Page | Отдельная секция FB |
| API | Product Catalog API | Нет открытого API |
| Для кого | Бизнесы с Page | Любой пользователь |
| Checkout | On-FB или external | Личные сообщения |
| Каталог | Управляемый, с коллекциями | Отдельные листинги |

## Публикации

### Можно ли комбинировать фото и видео в одном посте?
Нет. Один пост — либо фото (до 10 штук), либо видео (одно). Это ограничение API.

### Как запланировать пост на конкретное время?
Используйте `scheduled_publish_time` (Unix timestamp) + `published=false`:
```http
POST /{page_id}/feed
  ?message=Текст
  &published=false
  &scheduled_publish_time=1710500400
```
Ограничение: от 10 минут до 75 дней в будущем.

### Максимальный размер видео?
- Обычное видео: до 10 GB, длительность до 240 минут
- Reels: 4-90 секунд, 9:16, мин. 540p
- Stories: до 60 секунд, 9:16

### Сколько постов можно публиковать в день?
Рекомендуемый лимит — 25 постов в сутки на страницу. Превышение может привести к снижению reach.

## Reels

### Какие форматы видео поддерживаются для Reels?
MP4, MOV, MKV, WMV. Рекомендуется MP4 (H.264).

### Можно ли добавить музыку к Reels через API?
Нет. Музыка из библиотеки Facebook добавляется только через мобильное приложение. Через API можно загрузить видео с уже встроенным аудио.

### Минимальная длительность Reels?
4 секунды. Максимальная — 90 секунд.

## События

### Можно ли создавать платные события через API?
API позволяет создать событие, но интеграция с билетами/оплатой — только через партнёрские платформы (Eventbrite и т.д.) или внешнюю ссылку в описании.

### Как часто стоит создавать события для турбизнеса?
- Регулярные (еженедельные): групповые экскурсии, sunset safari
- Разовые: праздничные туры, NYE yacht party
- Оптимально: 2-4 события в месяц

## Аналитика

### Метрика Impressions deprecated — что использовать?
С ноября 2025 `page_impressions` заменена на **Views**. Views считает количество показов на экране, включая повторные просмотры. Аналогичное изменение уже произошло в Instagram.

### Какие метрики самые важные для туристической страницы?
1. **page_engaged_users** — уникальные пользователи с взаимодействием
2. **post_clicks** — клики на контент (показывает интерес к бронированию)
3. **page_fan_adds** — рост аудитории
4. **post_video_views** — эффективность видеоконтента
5. **page_fans_country** — география аудитории (ключевая для таргетинга)

## Реклама

### Минимальный бюджет для рекламы в ОАЭ?
- Минимальный дневной бюджет: ~$1 (3.67 AED)
- Рекомендуемый для тестов: 50-100 AED/день
- Для стабильных результатов: 200-500 AED/день

### Какой формат рекламы лучше для экскурсий?
- **Carousel** — для каталога (5-10 экскурсий в одном объявлении)
- **Video/Reels Ad** — для атмосферы (пустыня, яхты, город)
- **Lead Ad** — для сбора заявок (форма прямо в Facebook)
- **Collection** — для интеграции с Shops

## Модерация

### Как автоматически скрывать спам-комментарии?
1. Meta Business Suite → Page Settings → Moderation
2. Добавить ключевые слова в Keyword Blocklist
3. Включить Profanity Filter (Medium/Strong)
4. Или использовать Webhooks + свой сервер для real-time фильтрации

### Можно ли забанить пользователя навсегда?
Да. `POST /{page_id}/blocked?user[]={user_id}` блокирует пользователя на уровне страницы. Он не сможет комментировать, писать сообщения или видеть контент страницы в ленте.

## Интеграции

### Как связать Facebook Page с Instagram?
1. Meta Business Suite → Settings → Accounts → Instagram
2. Или: Facebook Page Settings → Instagram → Connect Account
3. После привязки: единый инбокс, cross-posting, общая аналитика

### Как связать WhatsApp с Facebook Page?
1. Meta Business Suite → Settings → WhatsApp
2. Привязать номер WhatsApp Business
3. CTA кнопка "Send WhatsApp Message" появится на странице
4. Или вручную: CTA → WhatsApp link (wa.me/номер)
