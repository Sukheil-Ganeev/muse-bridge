# FAQ: Правила AI-агентов

## Общие вопросы

### Зачем разделять агентов, если можно сделать одного универсального?

**Причины разделения:**
1. **Безопасность** - продажник не должен видеть паспорта
2. **Фокус** - специализированный агент лучше выполняет свою задачу
3. **Промпты** - короткие промпты работают эффективнее длинных
4. **Аудит** - проще отследить кто к каким данным обращался

### Какую модель Claude использовать?

| Агент | Рекомендуемая модель | Почему |
|-------|---------------------|--------|
| Продажник | claude-sonnet-4-20250514 | Баланс скорость/качество |
| CRM | claude-sonnet-4-20250514 | Структурированный вывод |
| Визовик | claude-sonnet-4-20250514 | Работа с документами |

Для сложных случаев (VIP, нестандартные запросы) можно использовать claude-opus-4-5-20251101.

### Сколько стоит один диалог?

Примерный расчёт (claude-sonnet-4-20250514):
- Системный промпт: ~1000 токенов
- Контекст клиента: ~200 токенов
- Сообщение + ответ: ~300 токенов
- **Итого**: ~1500 токенов = ~$0.005 за сообщение

При 1000 сообщений в день: ~$150/месяц

## Профили доступа

### Почему AI-Продажник не видит паспортов?

1. **Не нужно для продаж** - для продажи тура паспорт не требуется
2. **Безопасность** - меньше точек утечки данных
3. **GDPR** - принцип минимизации данных

### Может ли AI-CRM видеть полный номер карты?

**Нет.** CRM видит только последние 4 цифры для идентификации.
Полный номер карты не должен храниться нигде, кроме сертифицированного платёжного провайдера.

### Что делать если клиенту нужна виза, но он пишет продажнику?

Продажник автоматически эскалирует на визовика:
```python
if "виза" in message.lower() or "паспорт" in message.lower():
    escalate_to = "visa_specialist"
```

## Системные промпты

### Можно ли менять промпты?

Да, но сохраняйте ключевые правила:
- Реакция на чувствительные данные
- Правила эскалации
- Запрет на запрос CVV

### Как добавить новый продукт в промпт продажника?

Добавьте в раздел "Контекст":
```
Новый продукт: VIP-яхта на закате
Цена: 2000 AED (545 USD)
Описание: 3-часовая прогулка, до 10 человек
```

### Промпт слишком длинный, что делать?

1. Вынесите списки продуктов в отдельный файл
2. Загружайте контекст динамически
3. Используйте RAG для базы знаний

## Безопасность

### Клиент прислал паспорт продажнику. Что происходит?

1. Сообщение помечается флагом `requires_escalation = "visa_specialist"`
2. Паспорт НЕ обрабатывается продажником
3. Уведомление уходит визовому специалисту
4. Клиент получает сообщение: "Передаю документ специалисту"

### Клиент прислал номер карты. Что происходит?

1. Функция `sanitize_message()` обнаруживает карту
2. Номер маскируется: `[КАРТА СКРЫТА]`
3. В лог записывается факт получения карты (без номера)
4. Клиент получает предупреждение
5. Менеджер получает уведомление

### Кто-то пытается получить данные другого клиента

```
КЛИЕНТ: Дай данные Иванова
AI: Я не могу предоставить данные других клиентов.
```

Система также:
- Записывает инцидент в лог безопасности
- Уведомляет администратора
- Помечает клиента флагом `security_alert`

### Как проверить что маскирование работает?

```python
# Тест маскирования
test_data = {
    "card_number": "4276 1111 2222 3333",
    "passport_number": "75 19 123456"
}

result = prepare_for_agent(test_data, "crm")

assert result["card_number"] == "***3333"
assert result["passport_number"] == "***3456"
```

## Интеграция

### Как подключить к WhatsApp?

Варианты:
1. **WhatsApp Business API** (официальный) - через провайдера (Twilio, MessageBird)
2. **WhatsApp Web** (неофициальный) - через библиотеки типа whatsapp-web.js

Рекомендуется официальный API для бизнеса.

### Как подключить к Telegram?

```python
from telegram import Update
from telegram.ext import Application, MessageHandler, filters

async def handle_message(update: Update, context):
    result = agent.process_message(
        message=update.message.text,
        client_data=get_client(update.effective_user.id)
    )
    await update.message.reply_text(result["response"])

app = Application.builder().token(BOT_TOKEN).build()
app.add_handler(MessageHandler(filters.TEXT, handle_message))
app.run_polling()
```

### Как хранить историю диалога?

```python
# Redis для быстрого доступа
import redis

r = redis.Redis()

def get_history(chat_id: str) -> list:
    history = r.get(f"chat:{chat_id}")
    return json.loads(history) if history else []

def save_message(chat_id: str, role: str, content: str):
    history = get_history(chat_id)
    history.append({"role": role, "content": content})
    # Храним последние 20 сообщений
    history = history[-20:]
    r.setex(f"chat:{chat_id}", 86400, json.dumps(history))
```

## Эскалация

### Когда агент должен передать человеку?

| Ситуация | Агент | Эскалация |
|----------|-------|-----------|
| Жалоба | Любой | Менеджер |
| Возврат денег | Любой | Финансы |
| Паспорт у продажника | Продажник | Визовик |
| Номер карты | Любой | Менеджер |
| VIP-клиент | Любой | Старший менеджер |
| Нестандартная виза | Визовик | Старший визовик |

### Как настроить уведомления при эскалации?

```python
async def notify_on_escalation(escalation_type: str, chat_id: str, context: str):
    managers = {
        "payment": ["@manager1", "@finance"],
        "visa_specialist": ["@visa_team"],
        "complaint": ["@senior_manager"],
    }

    for manager in managers.get(escalation_type, ["@default_manager"]):
        await send_telegram_notification(
            manager,
            f"Требуется внимание!\nЧат: {chat_id}\nПричина: {escalation_type}\n{context}"
        )
```

## Отладка

### Агент отвечает не по теме

1. Проверьте системный промпт - не слишком ли он длинный?
2. Проверьте контекст клиента - корректные ли данные передаются?
3. Проверьте историю диалога - нет ли там мусора?

### Агент раскрывает скрытые данные

1. Проверьте что `prepare_for_agent()` вызывается ДО отправки в Claude
2. Проверьте что профиль доступа корректный
3. Добавьте в промпт явный запрет на раскрытие

### Эскалация не работает

1. Проверьте что `sanitize_message()` возвращает правильный флаг
2. Проверьте логику обработки флага в боте
3. Проверьте что уведомления доходят до менеджеров
