# Experience Index — скачивание-видео

> Последнее обновление: 2026-02-12

## Критические уроки (топ-5)

1. **Всегда обновлять yt-dlp перед диагностикой** — 90% ошибок скачивания решаются через `yt-dlp -U`. Сайты постоянно меняют API.
2. **FFmpeg обязателен для 1080p+** — без FFmpeg максимум 720p. YouTube хранит HD+ как раздельные потоки video + audio.
3. **Конфиг уже настроен** — файл `%APPDATA%\yt-dlp\config` содержит путь `D:/Downloads/YouTube/` и deno runtime. Не нужно каждый раз указывать `-P`.
4. **deno для YouTube JS challenges** — без deno runtime некоторые YouTube видео не скачиваются. Настроен в конфиге.
5. **Cookies для возрастного/приватного контента** — `--cookies-from-browser chrome` решает большинство проблем с доступом.

## Как добавить запись

Пользователь говорит "запиши в опыт" -> создать файл в соответствующей подпапке:
- `fixes/` — исправленные ошибки (формат: `FIX-001_описание.md`)
- `improvements/` — найденные улучшения (формат: `IMP-001_описание.md`)
- `patterns/` — повторяющиеся паттерны (формат: `PAT-001_описание.md`)
- `warnings/` — что НЕ делать (формат: `WARN-001_описание.md`)

После добавления записи — обновить этот файл (_index.md).
