# Скилл: скачивание-видео

## Описание

Скилл для скачивания видео, аудио, плейлистов и субтитров с YouTube и 1700+ сайтов через yt-dlp. Используется когда пользователь просит скачать видео, извлечь аудио, скачать плейлист, субтитры или отправляет ссылку на видеоплатформу.

## Структура скилла

```
скачивание-видео/
├── SKILL.md              # Основной файл скилла
│                          # Quick Start, команды, форматы, рецепты, настройки
├── README.md             # Этот файл — описание структуры

├── references/
│   ├── cheatsheet.md     # Шпаргалка — компактный справочник всех команд
```

## Когда активировать

- Пользователь просит скачать видео/аудио
- Пользователь делится ссылкой на YouTube, TikTok, Instagram и т.д.
- Нужно извлечь аудио из видео (MP3, FLAC, AAC и др.)
- Нужно скачать плейлист или субтитры
- Вопросы о yt-dlp, ffmpeg, форматах видео

## Ключевые настройки

| Параметр | Значение |
|----------|----------|
| **Путь сохранения** | `D:/Downloads/YouTube/` (ВСЕГДА) |
| **yt-dlp версия** | 2026.02.04 |
| **FFmpeg версия** | 8.0.1 |
| **deno** | Настроен для YouTube JS challenges |
| **Конфиг** | `%APPDATA%\yt-dlp\config` |

## Зависимости

| Компонент | Назначение | Обязательность |
|-----------|-----------|----------------|
| yt-dlp | Скачивание видео/аудио | Обязателен |
| FFmpeg | Слияние потоков, конвертация, постобработка | Обязателен для 1080p+ |
| deno | Runtime для YouTube JS challenges | Настроен в конфиге |
| aria2c | Параллельная загрузка (опционально) | Опционален |
| cookies | Приватный/возрастной контент | По необходимости |
