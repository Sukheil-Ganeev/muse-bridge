# FAQ - Часто задаваемые вопросы

## Какой формат входных данных?

Парсер работает с экспортированными чатами WhatsApp. Каждый чат — это папка с файлами:

```
Имя_контакта/
├── chat.txt          # Текст сообщений (обязательно)
└── media/            # Медиафайлы (опционально)
    ├── IMG_*.jpg
    ├── VID_*.mp4
    ├── AUD_*.opus
    └── ...
```

**Формат chat.txt:**
```
============================================================
ЧАТ: Марсель Ганеев
JID: 971507705321@s.whatsapp.net
Сообщений: 1547
Экспорт: 26.01.2026 15:30:45
============================================================

[26.01.2026 10:30:45] Марсель Ганеев:
  Привет! Нужен трансфер из аэропорта
  [ФОТО] media/IMG_20260126_103045.jpg
```

## Куда сохраняются результаты?

Все результаты сохраняются в:

```
D:/Downloads/Туризм-ОАЭ-Проект/02-Данные/_парсинг/
├── жсонл/              # all_messages.jsonl (~887k строк)
├── контакты/           # contacts.json (3050 контактов)
├── метаданные/         # chat_metadata.json
└── логи/               # Логи парсинга с ошибками
```

Пути настраиваются в `scripts/utils/config.py`.

## Как работает классификация контактов?

Классификация происходит по нескольким признакам:

### По источнику (source)
- `whatsapp` — из личного WhatsApp
- `wa_business` — из WhatsApp Business
- `both` — присутствует в обоих

### По типу (type)
- `client` — клиент (заказывал услуги)
- `agent` — турагент (партнёр)
- `supplier` — поставщик (отели, рестораны)
- `personal` — личный контакт
- `spam` — спам/реклама
- `unknown` — не классифицирован

### По языку (language)
Определяется автоматически по содержимому сообщений:
- `ru` — русский
- `en` — английский
- `ar` — арабский
- `mixed` — смешанный

## Как парсить группы?

Групповые чаты определяются автоматически по JID:
- Личный чат: `971501234567@s.whatsapp.net`
- Группа: `120363012345678901@g.us`

В групповых чатах:
- `is_group: true`
- `participants` содержит список участников
- Каждое сообщение содержит реального отправителя в поле `sender`

**Фильтрация групп:**
```python
# Только группы
groups = [c for c in contacts if c['is_group']]

# Только личные чаты
personal = [c for c in contacts if not c['is_group']]
```

## Как искать сообщения?

Используйте встроенный поиск:

```python
from scripts.utils.search import search_messages

# Поиск по тексту
results = search_messages(query="Ferrari World")

# Поиск с фильтрами
results = search_messages(
    query="трансфер",
    date_from="2025-01-01",
    date_to="2026-01-26",
    sender="Марсель"
)
```

## Как обновить данные после нового экспорта?

1. Скопируйте новые папки в исходные директории
2. Запустите парсер заново:
```bash
python scripts/parsing/parse_all_chats.py --update
```

Флаг `--update` пропускает уже обработанные чаты и добавляет только новые.
