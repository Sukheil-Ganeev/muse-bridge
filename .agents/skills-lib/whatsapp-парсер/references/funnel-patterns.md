Документация по определению этапов воронки продаж из WhatsApp-переписки туристического бизнеса.

## 1. Этапы воронки

| Этап | Код | Описание | Ключевые маркеры |
|------|-----|----------|------------------|
| Запрос | `REQUEST` | Первое обращение клиента | Вопрос о продукте/услуге |
| Интерес | `INTEREST` | Клиент уточняет детали | Вопросы о цене, датах, условиях |
| Предложение | `PROPOSAL` | Отправлено коммерческое предложение | Цена, условия, варианты |
| Бронь | `BOOKING` | Клиент подтвердил намерение | Согласие, резерв, бронирование |
| Оплата | `PAYMENT` | Деньги получены | Подтверждение оплаты |
| Выполнено | `COMPLETED` | Услуга оказана | Благодарность, отзыв |
| Потерян | `LOST` | Клиент отказался | Отказ, ушел к конкуренту |
| Молчание | `GHOSTED` | Нет ответа >7 дней | Таймаут без ответа |

## 2. Regex-паттерны этапов

### REQUEST (Запрос)

```python
REQUEST_PATTERNS = [
    r"(?i)(хотел|хочу|хотим|интересует|нужен|нужна|ищу|подскажите)",
    r"(?i)(сколько стоит|какая цена|прайс|тариф)",
    r"(?i)(есть ли|можно ли|доступн)",
    r"(?i)(добрый день|здравствуйте|привет).*\?",
    r"(?i)(на какие даты|когда можно|свободн)",
]
```

**Примеры сообщений:**
- "Здравствуйте! Сколько стоит сафари?"
- "Добрый день, интересует экскурсия в Абу-Даби"
- "Привет, есть ли свободные яхты на выходные?"
- "Подскажите цену на трансфер из аэропорта"

**Вес этапа:** 1.0

---

### INTEREST (Интерес)

```python
INTEREST_PATTERNS = [
    r"(?i)(а если|а можно|а как насчет|а что если)",
    r"(?i)(подробнее|детальнее|расскажите больше)",
    r"(?i)(какие варианты|что предложите|альтернатив)",
    r"(?i)(входит ли|включено ли|есть ли в комплекте)",
    r"(?i)(на \d+ (человек|персон|взрослых|детей))",
    r"(?i)(групп\w+ скидк|оптов\w+ цен)",
]
```

**Примеры сообщений:**
- "А если на 6 человек, какая цена будет?"
- "Расскажите подробнее, что входит в тур"
- "Какие варианты яхт есть на 4 часа?"
- "А питание включено в стоимость?"

**Вес этапа:** 1.2

---

### PROPOSAL (Предложение)

```python
PROPOSAL_PATTERNS = [
    r"(?i)(предлагаю|предлагаем|могу предложить)",
    r"(?i)(стоимость составит|цена будет|итого)",
    r"(?i)(вот варианты|на выбор|опции)",
    r"(?i)(\d+\s*(AED|USD|EUR|руб|₽|\$|€|дирхам))",
    r"(?i)(включает в себя|в стоимость входит)",
    r"(?i)(отправляю (счет|инвойс|предложение))",
]
```

**Примеры сообщений (менеджер):**
- "Предлагаю вам Desert Safari за 250 AED с человека"
- "Стоимость составит 1500 дирхам за группу"
- "Вот варианты яхт на выбор: 50ft - 800 AED/час, 65ft - 1200 AED/час"
- "В стоимость входит: пикап от отеля, BBQ ужин, шоу-программа"

**Вес этапа:** 1.5

---

### BOOKING (Бронь)

```python
BOOKING_PATTERNS = [
    r"(?i)(бронирую|забронируйте|резервирую|подтверждаю)",
    r"(?i)(давайте|договорились|согласен|согласна|берем|беру)",
    r"(?i)(оформляйте|оформите|оформляем)",
    r"(?i)(фиксируем|закрепляем|держите)",
    r"(?i)(подтверждение брони|бронь подтверждена)",
    r"(?i)(номер брони|код бронирования)",
]
```

**Примеры сообщений:**
- "Бронирую! На 4 человек на завтра"
- "Давайте, берем этот вариант"
- "Согласен, оформляйте"
- "Договорились, фиксируем на 15 января"

**Вес этапа:** 2.0

---

### PAYMENT (Оплата)

```python
PAYMENT_PATTERNS = [
    r"(?i)(оплатил|оплачено|перевел|перевела|отправил деньги)",
    r"(?i)(чек|квитанция|подтверждение оплаты)",
    r"(?i)(деньги поступили|платеж получен|оплата прошла)",
    r"(?i)(скрин (оплаты|перевода|платежа))",
    r"(?i)(transaction|payment confirmed)",
    r"(?i)(реквизиты для оплаты|куда переводить)",
]
```

**Примеры сообщений:**
- "Оплатил 500 AED, скрин прилагаю"
- "Перевела на карту, чек отправляю"
- "Деньги отправил, проверьте пожалуйста"
- "Payment confirmed, transaction ID: ABC123"

**Вес этапа:** 2.5

---

### COMPLETED (Выполнено)

```python
COMPLETED_PATTERNS = [
    r"(?i)(спасибо за|благодарю|было здорово|понравилось)",
    r"(?i)(все прошло|все было|отлично провели)",
    r"(?i)(рекомендую|посоветую|обратимся еще)",
    r"(?i)(оставлю отзыв|напишу отзыв)",
    r"(?i)(услуга оказана|заказ выполнен|тур завершен)",
    r"(?i)(до свидания|до встречи|всего доброго).*(!|спасибо)",
]
```

**Примеры сообщений:**
- "Спасибо за отличный тур! Всё очень понравилось"
- "Благодарим, обязательно обратимся ещё"
- "Рекомендую друзьям, сервис на высоте!"
- "Всё прошло замечательно, отзыв оставим"

**Вес этапа:** 3.0

## 3. Причины выхода из воронки

### REJECTION (Отказ)

```python
REJECTION_PATTERNS = [
    r"(?i)(дорого|не подходит|не устраивает|отказываюсь)",
    r"(?i)(передумал|передумали|отменяем|отмена)",
    r"(?i)(не актуально|планы изменились|не в этот раз)",
    r"(?i)(нашли другое|выбрали других|уже забронировали)",
    r"(?i)(спасибо,?\s*(не надо|не нужно|откажусь))",
]
```

### Детализация причин отказа

| Причина | Regex | Типичный этап |
|---------|-------|---------------|
| Высокая цена | `(?i)(дорого\|дороговато\|не потянем\|выше бюджета)` | INTEREST, PROPOSAL |
| Даты не подходят | `(?i)(на эти даты.*нет\|не подходят даты\|заняты)` | INTEREST, BOOKING |
| Выбрали конкурента | `(?i)(уже забронировали\|выбрали друг\|нашли друг)` | PROPOSAL, BOOKING |
| Отмена поездки | `(?i)(отмен\w+ (поездк\|тур)\|не едем\|не летим)` | BOOKING, PAYMENT |
| Нет ответа | Таймаут 168 часов (7 дней) | REQUEST, INTEREST |

### Детальные паттерны причин

```python
LOSS_REASONS = {
    "price_too_high": {
        "patterns": [
            r"(?i)(дорого|дороговато|не потянем|выше бюджета)",
            r"(?i)(нашли дешевле|есть дешевле|у других дешевле)",
        ],
        "stage_typical": ["PROPOSAL", "INTEREST"]
    },
    "dates_unavailable": {
        "patterns": [
            r"(?i)(на эти даты.*нет|не подходят даты|заняты)",
            r"(?i)(планы изменились|перенесли|сдвинулись даты)",
        ],
        "stage_typical": ["INTEREST", "BOOKING"]
    },
    "competitor_chosen": {
        "patterns": [
            r"(?i)(уже забронировали|выбрали друг|нашли друг)",
            r"(?i)(у других|в другом месте|альтернатив)",
        ],
        "stage_typical": ["PROPOSAL", "BOOKING"]
    },
    "trip_cancelled": {
        "patterns": [
            r"(?i)(отмен\w+ (поездк|тур|путешеств))",
            r"(?i)(не едем|не летим|не поедем)",
            r"(?i)(визу.*отказ|не дали визу)",
        ],
        "stage_typical": ["BOOKING", "PAYMENT"]
    },
    "no_response": {
        "patterns": [],
        "timeout_hours": 168,
        "stage_typical": ["REQUEST", "INTEREST", "PROPOSAL"]
    }
}
```


```
Клиент: "А что включено в эту цену?"
Клиент: "Есть ли скидка на группу?"

           дюны, завтрак в пустыне, фото. На 4 чел итого 800 AED."

[BOOKING]
Клиент: "Хорошо, бронируем на завтра на 4 человек!"
```

## 6. Формулы конверсии

### Базовые формулы

```
Конверсия этапа = (Перешедшие на следующий этап / На текущем этапе) x 100%

Общая конверсия = (Завершенные / Запросы) x 100%

Конверсия по цепочке = CR1 x CR2 x CR3 x CR4 x CR5
```

### Веса этапов для Pipeline

```
Stage Weights:
  REQUEST:    0.10
  INTEREST:   0.20
  PROPOSAL:   0.40
  BOOKING:    0.70
  PAYMENT:    0.90
  COMPLETED:  1.00
```

### Ожидаемая выручка

```
Expected Value = Deal_Value x P(conversion) x Stage_Weight
```

## 7. Бенчмарки конверсии

| Переход | Отлично | Хорошо | Норма | Плохо |
|---------|---------|--------|-------|-------|
| REQUEST -> INTEREST | >80% | 70-80% | 60-70% | <60% |
| INTEREST -> PROPOSAL | >75% | 65-75% | 55-65% | <55% |
| PROPOSAL -> BOOKING | >60% | 50-60% | 40-50% | <40% |
| BOOKING -> PAYMENT | >90% | 85-90% | 75-85% | <75% |
| PAYMENT -> COMPLETED | >95% | 90-95% | 85-90% | <85% |
