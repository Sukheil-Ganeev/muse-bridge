# P003: Стандартный формат экспорта WhatsApp (ZIP)

**Дата:** 2026-02-05
**Severity:** HIGH
**Проект:** MARSEL_BUSINESS (лимузинные партнёры)

## Контекст

При экспорте чата через меню WhatsApp "Экспортировать чат" -> ZIP, формат отличается от кастомного массового экспорта.

## Формат

```
[DD/MM/YYYY, HH:MM:SS] Sender: Message text
[DD/MM/YYYY, HH:MM:SS] Sender: <прикреплено: filename.jpg>
```

### Regex

```python
MSG_PATTERN = re.compile(
    r'^\[(\d{2}/\d{2}/\d{4}),\s(\d{2}:\d{2}:\d{2})\]\s(.+?):\s(.+)$'
)
ATTACHMENT = re.compile(r'^<прикреплено:\s(.+?)>$')
```

## Отличия от кастомного формата

| Параметр | Стандартный (ZIP) | Кастомный (массовый) |
|----------|-------------------|----------------------|
| Дата | `[DD/MM/YYYY, HH:MM:SS]` | `[DD.MM.YYYY HH:MM:SS]` |
| Отправитель | На той же строке после `]` | Отдельная строка |
| Вложения | `<прикреплено: file>` | `[ФОТО] media/file` |
| Заголовок | Нет | `ЧАТ:`, `JID:` |
