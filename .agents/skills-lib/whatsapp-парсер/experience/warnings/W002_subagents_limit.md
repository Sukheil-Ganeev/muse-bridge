# W002: Не запускать 50+ субагентов одновременно

**Severity:** CRITICAL
**Дата:** 2026-02-05
**Источник:** Проект Туризм-ОАЭ

---

## Проблема

При запуске 50-67 субагентов:
- API лимиты ("You're out of extra usage")
- Массовые падения ("classifyHandoffIfNeeded is not defined")
- Неполные результаты

## Оптимальное количество

| Субагентов | Риск | Рекомендация |
|------------|------|--------------|
| 5-10 | Низкий | Для простых задач |
| **10-15** | Средний | **ОПТИМАЛЬНО** |
| 15-30 | Высокий | С мониторингом |
| 50+ | КРИТИЧЕСКИЙ | НЕ ИСПОЛЬЗОВАТЬ |

## Альтернатива

Для массовой обработки — Python-скрипт с API:
- Контролируемый rate limiting
- Checkpoint/resume
- Гарантированное сохранение
