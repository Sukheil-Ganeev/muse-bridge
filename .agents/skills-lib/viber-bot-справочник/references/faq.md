# Viber Bot API — FAQ

## Общие вопросы

### Можно ли создать бота в Viber бесплатно?
Нет. С 5 февраля 2024 года боты создаются **только на коммерческих условиях**. Нужно подать заявку через Viber for Business или через верифицированного партнёра Rakuten Viber. Публикация бота бесплатна, но bot-initiated сообщения сверх 10,000/месяц — платные.

### Чем Viber Bot API отличается от Telegram Bot API?
| Параметр | Viber | Telegram |
|----------|-------|----------|
| Получение обновлений | Только webhook | Webhook или Long Polling |
| Состояния диалога | Встроенный tracking_data | Нет (нужна БД или FSM-библиотека) |
| Карусели | Нативный Rich Media | Нет (только Inline Keyboard) |
| SSL | Обязательный CA-signed | Допускается self-signed |
| Коммерческая модель | Платная (10K бесплатных) | Полностью бесплатный API |
| HTML в кнопках | Да (font, b, i, br) | Нет |
| Создание бота | Через заявку + контракт | @BotFather за секунды |

### Поддерживает ли Viber long polling?
**Нет.** Viber работает **исключительно** через webhook. Для разработки нужен HTTPS-сервер с доверенным сертификатом. Для локальной разработки используйте ngrok или Cloudflare Tunnel.

### Какой максимальный размер tracking_data?
**4000 символов.** Рекомендуется использовать JSON-строку. Для сложных состояний с большим объёмом данных — комбинируйте с внешней БД (Redis, PostgreSQL).

### Сбрасывается ли tracking_data при переподписке?
**Да.** Событие `subscribed` (после unsubscribe + subscribe) удаляет все tracking_data и context. Новый диалог начинается с чистого листа.

## Webhook

### Какой SSL-сертификат нужен для webhook?
Доверенный CA-signed сертификат. **Self-signed НЕ принимается.** Бесплатные варианты: Let's Encrypt, Cloudflare. Для локальной разработки — ngrok (предоставляет HTTPS).

### Как проверить, что webhook работает?
Отправьте `get_account_info` запрос. В ответе будет поле `webhook` с вашим URL. Если пустое — webhook не установлен.

### Можно ли фильтровать события webhook?
Да. В `set_webhook` укажите массив `event_types` с нужными типами. Если не указать — будут приходить все события.

### Что делать, если webhook не получает callbacks?
1. Проверьте SSL-сертификат (не self-signed)
2. Сервер должен отвечать HTTP 200 на каждый callback
3. URL должен быть доступен извне
4. Проверьте через `get_account_info`

## Сообщения

### Какой максимальный размер текстового сообщения?
**7000 символов** для type: text.

### Можно ли отправить сообщение неподписанному пользователю?
Только в ответ на `conversation_started` (welcome message). Инициативные сообщения — только подписчикам.

### Как отправить сообщение с клавиатурой?
Добавьте объект `keyboard` к любому типу сообщения. Клавиатура — это не отдельное сообщение, а дополнение к основному.

### Поддерживает ли Rich Media кнопку share-phone?
**Нет.** В Rich Media не работают `location-picker` и `share-phone`. Используйте обычную keyboard для этих действий.

### Какой максимальный размер видео/файла?
- Видео: **26 МБ** (только .mp4)
- Файл: **50 МБ**

## Broadcast

### Сколько получателей в одной рассылке?
Максимум **300 подписчиков** на один запрос `broadcast_message`.

### Есть ли API для получения списка всех подписчиков?
**Нет.** Viber не предоставляет такой API. Вы должны самостоятельно сохранять ID подписчиков из callbacks `subscribed` и `message`.

### Какой rate limit у broadcast?
**500 запросов за 10 секунд.** При 300 получателях на запрос это 150,000 сообщений за 10 секунд.

## Разработка

### Можно ли тестировать бота локально?
Да, через туннель:
- **ngrok:** `ngrok http 8080` — получаете HTTPS URL
- **Cloudflare Tunnel:** `cloudflared tunnel --url http://localhost:8080`
- Затем set_webhook с полученным HTTPS URL

### Какие SDK официальные?
- **Node.js:** `viber-bot` (npm)
- **Python:** `viberbot` (pip)
- **Java:** Viber Java Bot API (Maven)

### Можно ли задеплоить на Vercel/Netlify Functions?
Да, serverless подходит для Viber ботов (webhook-based). AWS Lambda + API Gateway, Vercel Serverless Functions, Google Cloud Functions — все работают.

### Как получить user ID для тестирования?
Откройте чат с вашим ботом в Viber и отправьте любое сообщение. В webhook callback придёт `sender.id` — это ваш user ID.

## Туризм ОАЭ

### Как определить язык пользователя?
В callback `sender.language` содержит код языка (ru, en, ar и т.д.), а `sender.country` — код страны (RU, KZ, AE). Используйте для автоматического выбора языка welcome message.

### Нужна ли отдельная Rich Media карусель для каждой категории экскурсий?
Рекомендуется. Создайте отдельные карусели для экскурсий, билетов, яхт, автомобилей — так пользователю удобнее листать. Максимум 6 карточек в одной карусели (оптимально для мобильного экрана).

### Как отслеживать источник трафика (Instagram, сайт, QR)?
Через deep links с параметром `context`:
```
viber://pa?chatURI=dubaitours&context=instagram_ad
viber://pa?chatURI=dubaitours&context=website
viber://pa?chatURI=dubaitours&context=qr_flyer
```
Контекст приходит в `conversation_started` callback.
