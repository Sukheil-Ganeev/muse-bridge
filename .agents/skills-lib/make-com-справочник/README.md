# make-com-справочник

## Назначение

Production-ready справочник по платформе автоматизации Make.com (ex-Integromat) для быстрого поиска информации при построении сценариев автоматизации бизнес-процессов.

**Контекст:** Владелец -- Сухейль, предприниматель в сфере туризма в ОАЭ (Дубай). Экскурсии, билеты в парки, яхты (Paramount Yachts, брат Муфамад), аренда автомобилей (брат Марсель), трансферы.

## Структура скилла

```
make-com-справочник/
  SKILL.md                          # Основной справочник (~5000 слов)
  README.md                         # Этот файл
  references/
    faq.md                          # 20+ часто задаваемых вопросов
    troubleshooting.md              # 15+ типичных проблем с решениями
    cheatsheet.md                   # Шпаргалка: функции, лимиты, формулы
```

## Содержание SKILL.md

1. **Обзор платформы** -- тарифы, лимиты, ключевые концепции
2. **Сценарии** -- создание, триггеры, модули, connections, routers, filters, blueprints
3. **Данные и маппинг** -- типы данных, переменные, Data Stores, Data Structures
4. **Функции** -- все категории с синтаксисом: Math, Text, Date, Array, Object, General, Crypto
5. **Обработка ошибок** -- типы ошибок, Error Handlers (Resume, Rollback, Commit, Break, Ignore)
6. **Webhooks и HTTP** -- Custom Webhooks, HTTP Module, JSON/XML, Make API
7. **Топ модули** -- Telegram, Google Sheets, WhatsApp, OpenAI, Flow Control, Tools
8. **Advanced** -- Custom Apps, AI Agents, MCP Server, Make Bridge
9. **Best Practices** -- именование, организация, оптимизация операций, безопасность, отладка, мониторинг
10. **Применение в туризме ОАЭ** -- типичные сценарии для бизнеса Сухейля
11. **Rate Limits** -- сводная таблица лимитов всех ключевых сервисов
