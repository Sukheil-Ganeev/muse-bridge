## Платежные системы

### ЮKassa (YooKassa)

| Параметр | Значение |
|----------|----------|
| Комиссия | от 2.8% |
| Страна | Россия |
| Особенности | Популярная, встроенная касса |

**Подключение:**
```
1. Зарегистрироваться на yookassa.ru
2. Пройти модерацию (1-3 дня)
3. Получить shopId и секретный ключ
4. Настроить webhook в ЮKassa
5. Вставить данные в SaleBot
```

**Webhook URL:** `https://salebot.site/webhook/yookassa/ВАШ_ID`

**Создание платежа в боте:**
```
Блок "Создать платеж":
- Сумма: #{price}
- Описание: Заказ #{order_id}
- Email: #{email}
- НДС: none / vat20 / vat10
```

## CRM-системы

### amoCRM

**Возможности интеграции:**
- Создание контактов
- Создание сделок
- Изменение этапов воронки
- Двусторонняя синхронизация

**Подключение:**
```
1. amoCRM -> Настройки -> Интеграции
2. Создать интеграцию
3. Права: Контакты, Сделки, Задачи
4. Redirect URI: https://salebot.site/oauth/amocrm
5. Авторизовать в SaleBot
```

**Сопоставление полей:**
```
SaleBot          amoCRM
#{name}      →   Имя контакта
#{phone}     →   Телефон
#{email}     →   Email
#{source}    →   Источник
```

**Блоки в сценарии:**
- Создать контакт
- Создать сделку
- Изменить этап
- Добавить примечание
- Создать задачу

## Онлайн-школы

### GetCourse

| Функция | Описание |
|---------|----------|
| Регистрация на вебинар | Добавление в группу/тренинг |
| Проверка статуса | Является ли учеником |
| Прогресс обучения | % прохождения курса |

**Подключение:**
```
1. GetCourse -> Настройки -> Интеграции -> API
2. Создать ключ "SaleBot"
3. Домен школы: myschool.getcourse.ru
4. Настроить webhook из GetCourse
```

**Webhook URL:** `https://salebot.site/webhook/getcourse/ВАШ_ID`

**Типичные сценарии:**
1. Регистрация на вебинар через бота
2. Напоминания до/после вебинара
3. Дожим после вебинара
4. Поддержка учеников
5. Сбор отзывов

**Блоки:**
- Добавить на вебинар/тренинг
- Получить данные пользователя
- Проверить статус ученика
- Получить прогресс обучения

## API и Webhooks

### Входящие вебхуки

Внешние системы отправляют данные в SaleBot.

**Создание:**
```
Настройки -> Вебхуки -> Входящие -> Создать
URL: https://salebot.site/webhook/incoming/abc123xyz
```

**Использование:**
```
Триггер: Входящий вебхук
Доступные переменные:
- #{webhook_order_id}
- #{webhook_status}
- #{webhook_*} (любое поле из JSON)
```

---

### Исходящие вебхуки

SaleBot отправляет данные на ваш сервер.

**Блок "HTTP-запрос":**
```
URL: https://yourserver.com/api/endpoint
Метод: POST
Headers:
  Content-Type: application/json
  Authorization: Bearer #{api_key}
Body:
{
  "name": "#{name}",
  "phone": "#{phone}",
  "source": "salebot"
}
```

---

### SaleBot API

**Базовый URL:** `https://chatter.salebot.pro/api/`

**Авторизация:** `Authorization: Bearer ВАШ_API_КЛЮЧ`

**Методы:**

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/api/message/send` | Отправить сообщение |
| GET | `/api/client/{id}` | Получить клиента |
| POST | `/api/client/{id}/update` | Обновить клиента |
| POST | `/api/scenario/run` | Запустить сценарий |

**Пример отправки сообщения:**
```json
POST /api/message/send
{
  "client_id": "123456",
  "message": "Привет!",
  "platform": "telegram"
}
```

## Универсальная интеграция

Для любого сервиса с API можно использовать блок "HTTP-запрос":

```
URL: https://api.сервис.com/endpoint
Метод: GET / POST / PUT / DELETE
Headers: {...}
Body: {...}
Сохранить ответ в: #{response}
```
