## Проблема

`innerHTML` injection и Quill API корректно вставляют форматированный контент, но после перезагрузки изменения могут пропасть.

## Корневая причина

Проблема не во вставке, а в сохранении: PuzzleBot не автосохраняет изменения конструктора.

## Решение

После вставки ОБЯЗАТЕЛЬНО выполнить Save workflow:
1. Клик вне блока на canvas
2. Клик по оранжевой кнопке `SAVE`
3. Подтвердить изменения зелёной галочкой в диалоге
4. Дождаться тоста: `Отличная работа. Изменения применены!`

## Урок

`innerHTML` остаётся базовым быстрым методом. Критично соблюдать полный Save workflow.
