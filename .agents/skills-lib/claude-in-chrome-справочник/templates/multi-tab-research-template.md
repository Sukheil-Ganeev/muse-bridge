# Multi-Tab Research Template

## Назначение

Шаблон для исследования и сравнительного анализа информации с нескольких сайтов одновременно. Claude открывает вкладки, собирает данные с каждой, сравнивает и формирует сводный отчет.

**Когда использовать:**
- Сравнение цен конкурентов (туризм, e-commerce)
- Исследование рынка по нескольким источникам
- Сбор информации из разных порталов для единого отчета
- Мониторинг акций, скидок, наличия на нескольких сайтах

## Шаги

### Шаг 1. Инициализация и определение источников

```
tabs_context_mcp(createIfEmpty=true)
```

Определить список сайтов для исследования:
```
Сайт 1: https://www.getyourguide.com
Сайт 2: https://www.viator.com
Сайт 3: https://www.klook.com
```

### Шаг 2. Открытие вкладок

```
tabs_create_mcp(url="https://www.getyourguide.com")
tabs_create_mcp(url="https://www.viator.com")
tabs_create_mcp(url="https://www.klook.com")
```

### Шаг 3. Сбор данных с каждой вкладки

Для КАЖДОЙ вкладки повторяем цикл поиска и извлечения:

```
# --- Вкладка 1: GetYourGuide ---
# 3a. Поиск
find(text="Search", tabId=TAB_1)
computer(action="left_click", ref=REF, tabId=TAB_1)
computer(action="type", text="Desert Safari Dubai", tabId=TAB_1)
computer(action="key", text="Enter", tabId=TAB_1)
computer(action="wait", duration=3, tabId=TAB_1)

# 3b. Извлечение данных
# Вариант A — JS (быстрый, экономит контекст):
javascript_tool(action="javascript_exec", text="
  JSON.stringify(
    Array.from(document.querySelectorAll('.activity-card')).slice(0, 10).map(el => ({
      name: el.querySelector('.activity-card__title')?.textContent.trim(),
      price: el.querySelector('.price')?.textContent.trim(),
      rating: el.querySelector('.rating')?.textContent.trim(),
      reviews: el.querySelector('.reviews-count')?.textContent.trim()
    }))
  )
", tabId=TAB_1)

# Вариант B — get_page_text (универсальный):
get_page_text(tabId=TAB_1)
```

```

# (повторить 3a-3b для TAB_2)

# --- Вкладка 3: Klook ---
# (повторить 3a-3b для TAB_3)
```

### Шаг 4. Сравнительный анализ

## Пример промпта

```
Проведи сравнительный анализ цен на "Desert Safari Dubai":

Открой в отдельных вкладках:
1. GetYourGuide
2. Viator
3. Klook

На каждом сайте найди "Desert Safari Dubai" и собери для первых 10 результатов:
- Название
- Цену (в USD)
- Рейтинг
- Количество отзывов
- Длительность

Затем:
- Сравни цены: кто дешевле, кто дороже
- Найди самый рейтинговый тур на каждой площадке
- Покажи нашу цену (180 AED = $49) vs конкуренты
- Сохрани результат в D:/Downloads/competitor_analysis.csv
- Сделай скриншот результатов на каждом сайте
```

## Параметры для настройки

| Параметр | По умолчанию | Описание |
|----------|-------------|---------|
| `Количество сайтов` | 3 | Сколько сайтов исследовать (рекомендация: не более 5) |
| `URL сайтов` | — | Список URL для открытия |
| `Поисковый запрос` | — | Что искать на каждом сайте |
| `Поля для сбора` | name, price, rating | Какие данные извлекать |
| `Количество результатов` | 10 | Сколько результатов с каждого сайта |
| `Формат отчета` | CSV | CSV, Excel, Markdown, PowerPoint |
| `Скриншоты` | нет | Делать ли скриншоты каждой вкладки |
| `Путь сохранения` | `D:/Downloads/` | Куда сохранить отчет |

## Частые ошибки

- **Вкладки теряют tab ID после переключения** -- Решение: всегда использовать `tabs_context_mcp()` для обновления ID перед работой с вкладками, если прошло время.

- **Сайт загрузился не полностью** -- Динамический контент не подгрузился. Решение: `computer(action="wait", duration=3)` после навигации. Или `computer(action="scroll", scroll_direction="down", scroll_amount=3)` для триггера lazy-loading.

- **Разные CSS-селекторы на разных сайтах** -- Решение: использовать `get_page_text` (универсальный) вместо `javascript_tool` (сайт-специфичный). Или настроить отдельные селекторы для каждого сайта.

- **Anti-bot / CAPTCHA на одном из сайтов** -- Claude паузится. Решение: пользователь решает CAPTCHA, затем Claude продолжает с остальных вкладок.

- **Слишком много данных засоряют контекст** -- Решение: использовать `javascript_tool` с `.slice(0, 10)` для ограничения результатов. Не применять `get_page_text` на тяжелых страницах без необходимости.

- **Цены в разных валютах** -- Решение: указать Claude конвертировать все в одну валюту (USD или AED) для корректного сравнения.

## Автоматизация (Scheduled Task)

Для регулярного мониторинга конвертируйте этот workflow в шорткат:

```
1. Создать шорткат /competitor-scan
2. Протестировать 2-3 раза
3. Настроить Schedule:
   - Частота: ежедневно
   - Время: 08:00
   - Модель: Haiku 4.5 (для экономии)
4. Результат: CSV-файл обновляется каждое утро
```

**Требование:** Chrome должен быть открыт в назначенное время.

## Оптимизация контекста

| Метод извлечения | Объем контекста | Когда использовать |
|-----------------|----------------|-------------------|
| `javascript_tool` (CSS-селекторы) | Минимальный | Известная структура DOM |
| `get_page_text` | Средний | Неизвестная структура |
| `read_page(accessibility_tree)` | Большой | Нужна интерактивность (клики по ref) |
| `read_page(html)` | Очень большой | Нужен полный HTML (редко) |

Рекомендация: начинайте с `javascript_tool`, переходите на `get_page_text` только если CSS-селекторы неизвестны.
