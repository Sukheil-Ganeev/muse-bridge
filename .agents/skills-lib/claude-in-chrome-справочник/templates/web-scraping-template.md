# Web Scraping Template

## Назначение

Шаблон для извлечения структурированных данных с веб-страницы: таблиц, списков товаров, каталогов, цен, отзывов. Подходит для одностраничного и многостраничного скрапинга.

**Когда использовать:**
- Сбор цен конкурентов с сайтов (GetYourGuide, Viator, Klook и др.)
- Парсинг каталогов товаров/услуг
- Извлечение таблиц и списков в CSV/JSON
- Мониторинг изменений на странице

## Шаги

### Шаг 1. Инициализация и навигация

```
tabs_context_mcp(createIfEmpty=true)
navigate(url="https://ЦЕЛЕВОЙ_САЙТ.com/страница")
```

### Шаг 2. Оценка структуры страницы

Выберите один из двух подходов:

**Подход A** — Быстрый (JS injection, экономит контекст):
```
javascript_tool(action="javascript_exec", text="
  JSON.stringify(
    Array.from(document.querySelectorAll('CSS_СЕЛЕКТОР_КАРТОЧКИ')).map(el => ({
      name: el.querySelector('.СЕЛЕКТОР_НАЗВАНИЯ').textContent.trim(),
      price: el.querySelector('.СЕЛЕКТОР_ЦЕНЫ').textContent.trim(),
      rating: el.querySelector('.СЕЛЕКТОР_РЕЙТИНГА')?.textContent.trim() || 'N/A',
      url: el.querySelector('a')?.href || ''
    }))
  )
", tabId=TAB_ID)
```

**Подход B** — Универсальный (чтение DOM + анализ Claude):
```
get_page_text(tabId=TAB_ID)
# Claude анализирует текст и извлекает нужные данные
```

### Шаг 3. Пагинация (если нужно)

```

find(text="Next", tabId=TAB_ID)

# Подождать загрузку
computer(action="wait", duration=2, tabId=TAB_ID)

```

## Пример промпта

```
Открой сайт https://www.getyourguide.com и найди "Desert Safari Dubai".
Для каждого результата на первых 3 страницах собери:
- Название экскурсии
- Цену (в AED или USD)
- Рейтинг (звезды)
- Количество отзывов
- URL страницы

Сохрани результат в CSV файл desert_safari_prices.csv в D:/Downloads/
```

## Параметры для настройки

| Параметр | По умолчанию | Описание |
|----------|-------------|---------|
| `URL` | — | Адрес целевой страницы |
| `CSS_СЕЛЕКТОР_КАРТОЧКИ` | `.product-card` | CSS-селектор элемента-контейнера одной записи |
| `Поля для извлечения` | name, price | Список полей и их CSS-селекторов |
| `Количество страниц` | 1 | Сколько страниц пагинации обработать |
| `Формат вывода` | CSV | CSV, JSON или таблица в консоли |
| `Путь сохранения` | `D:/Downloads/` | Куда сохранить файл |

## Частые ошибки

- **Пустой результат JS-запроса** -- Неверный CSS-селектор. Решение: сначала `read_page(format="html")` или `computer(screenshot)` чтобы изучить структуру DOM.

- **Данные загружаются динамически (SPA)** -- Контент подгружается через API после рендера. Решение: `computer(action="wait", duration=3)` перед парсингом, или `read_network_requests(urlPattern="api")` для перехвата API-ответов.

- **Anti-bot защита / CAPTCHA** -- Claude паузится. Решение: пользователь решает CAPTCHA вручную, затем Claude продолжает.

- **Дублирование данных при пагинации** -- Решение: проверять уникальность (по URL или названию) перед добавлением в массив.

- **`get_page_text` возвращает слишком много текста** -- Засоряет контекст. Решение: использовать `javascript_tool` с точечными CSS-селекторами вместо полного текста страницы.
