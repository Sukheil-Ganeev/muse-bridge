# Shopify-справочник

Production-ready руководство по Shopify e-commerce для туристического бизнеса ОАЭ.
Магазин туров, билетов, яхт, трансферов -- от быстрого старта до headless Hydrogen.

## Структура

```
shopify-справочник/
├── SKILL.md                    # Основной файл (~5000 слов)
├── README.md                   # Этот файл
└── references/
    ├── faq.md                  # 12 частых вопросов
    ├── troubleshooting.md      # 12 типичных проблем
    └── cheatsheet.md           # CLI, API, Liquid, Webhooks, тарифы
```

## Быстрый старт

1. Прочитайте `SKILL.md` -- полный обзор платформы
2. Раздел 2 "Быстрый старт" -- магазин за 1 день
3. Раздел 3 "Архитектура продуктов" -- как создавать экскурсии
4. Раздел 7 "Платёжные системы" -- подключение Stripe/Telr

## Что покрывает справочник

| Раздел | Описание |
|--------|---------|
| Обзор платформы | Тарифы, услуги vs товары, бизнес-модель |
| Быстрый старт | Магазин за 1 день: регистрация, продукты, тема |
| Архитектура продуктов | Variants, metafields, collections, tags для туризма |
| Shopify Liquid | Layout, templates, sections, snippets, Online Store 2.0 |
| Admin API | REST (legacy) + GraphQL, аутентификация, CRUD, webhooks |
| Storefront API | Headless, Hydrogen, виджет бронирования |
| Платежи ОАЭ | Stripe, Telr, PayTabs, crypto, manual (Kaspi/Сбер), VAT 5% |
| Мультиязычность | Markets, Translate & Adapt, RTL (арабский), hreflang |
| SEO | URL structure, Schema.org TouristTrip, блог, скорость |
| Apps для туризма | Бронирование, отзывы, upsell, WhatsApp, loyalty |
| Аналитика | Shopify Analytics, GA4, Meta Pixel, Яндекс.Метрика |
| Автоматизация | Shopify Flow, Zapier/Make, CLI |
| Примеры ОАЭ | Desert Safari, Burj Khalifa, яхта, webhook->Telegram |
| Безопасность | PCI DSS, GDPR, DTCM, защита API |

## Требования

- Аккаунт Shopify (от $39/мес, Basic план)
- Trade License ОАЭ (для легальной торговли)
- Аккаунт в платёжном шлюзе (Stripe/Telr/PayTabs)
- Домен (через Shopify или свой)
