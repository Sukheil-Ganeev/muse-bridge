# X (Twitter) — Troubleshooting (Решение проблем)

## 1. Ошибка 401 Unauthorized

**Симптом:** API возвращает `401 Unauthorized` на любой запрос.

**Причины и решения:**
- **Истёкший access token** — обновите через refresh token (POST `/2/oauth2/token` с `grant_type=refresh_token`)
- **Неверный Bearer Token** — проверьте в Developer Portal, перегенерируйте при необходимости
- **Неверные API Keys** — проверьте consumer_key/consumer_secret
- **Revoked app** — проверьте статус приложения в Developer Portal
- **Неправильный заголовок** — формат: `Authorization: Bearer YOUR_TOKEN` (с пробелом после Bearer)

## 2. Ошибка 403 Forbidden

**Симптом:** Запрос синтаксически верный, но API отказывает.

**Причины:**
- **Недостаточный тариф** — Free не даёт читать посты (write-only)
- **Отсутствует scope** — при OAuth 2.0 не запросили нужный scope (например, `tweet.write`)
- **Suspended account** — аккаунт заблокирован X
- **Country restriction** — контент недоступен в вашем регионе

**Решение:** проверьте тариф API, scopes в OAuth, статус аккаунта.

## 3. Ошибка 429 Too Many Requests (Rate Limit)

**Симптом:** API возвращает 429 с текстом "Rate limit exceeded".

**Решение:**
1. Проверьте заголовок `x-rate-limit-reset` (Unix timestamp сброса)
2. Дождитесь сброса окна (15 минут или 24 часа в зависимости от тарифа)
3. Реализуйте exponential backoff: wait 1s, 2s, 4s, 8s...
4. Кэшируйте ответы, используйте batch-запросы
5. При систематическом превышении — повысьте тариф

## 4. Медиа не загружается

**Симптом:** Ошибка при загрузке фото или видео.

**Проверьте:**
- **Размер файла:** фото до 5 МБ, видео до 512 МБ, GIF до 15 МБ
- **Формат:** фото JPEG/PNG/WebP, видео MP4 (H.264), GIF
- **Для видео/GIF:** используйте chunked upload (INIT → APPEND → FINALIZE)
- **Аудио видео:** только AAC LC (Low Complexity)
- **Разрешение:** не больше 4096x4096 (фото), 1920x1200 (видео)
- **v2 Media Upload** — с 2025 года новый эндпоинт, v1.1 sunset

## 5. Пост не публикуется (duplicate content)

**Симптом:** Ошибка "You are not allowed to create a Tweet with duplicate content".

**Причина:** X блокирует идентичные посты в течение определённого периода.

**Решение:**
- Добавьте timestamp или уникальный элемент в текст
- Используйте вариации текста
- Подождите некоторое время между одинаковыми постами

## 6. OAuth 2.0 PKCE — токен не выдаётся

**Симптом:** POST на `/2/oauth2/token` возвращает ошибку.

**Проверьте:**
- `code_verifier` совпадает с исходным (SHA256 → base64url = code_challenge)
- `redirect_uri` совпадает с зарегистрированным в Developer Portal
- `client_id` указан верно
- Код авторизации не истёк (используйте в течение 30 секунд)
- `grant_type` = `authorization_code` (не `client_credentials`)

## 7. Поиск возвращает 0 результатов

**Симптом:** Search API возвращает пустой ответ.

**Проверьте:**
- **Тариф:** Free не имеет доступа к Search
- **recent vs all:** `/2/tweets/search/recent` только последние 7 дней
- **Сложность запроса:** слишком много фильтров → начните с базового
- **Оператор place:** мало постов с геотегами, попробуйте текстовый поиск
- **Кавычки:** `"точная фраза"` значительно сужает результаты
- **Синтаксис:** нет пробела между оператором и значением (`from:user`, не `from: user`)

## 8. Не видны non_public_metrics

**Симптом:** API возвращает метрики без impressions, clicks и т.д.

**Причина:** `non_public_metrics` доступны ТОЛЬКО:
- Автору поста
- Через OAuth 2.0 User Context (не App-only)
- С scope `tweet.read`

**Решение:** используйте OAuth 2.0 с User Context, не Bearer Token.

## 9. Webhook/Filtered Stream не работает

**Важно:** Filtered Stream и Webhooks — функционал для ботов. См. **x-twitter-bot-справочник** для детальной информации.

Общие проверки:
- Тариф Basic или выше (Free не поддерживает)
- Правила (rules) корректно добавлены
- Соединение не разорвано (keep-alive)

## 10. Embed-код не отображается на сайте

**Симптом:** Встроенный твит показывает пустое место или ссылку.

**Решение:**
- Подключите `widgets.js`: `<script async src="https://platform.x.com/widgets.js"></script>`
- Проверьте CSP (Content Security Policy) — разрешите `platform.x.com`
- Замените `twitter.com` на `x.com` в URL
- Для SPA-фреймворков: вызовите `twttr.widgets.load()` после рендера

## 11. X Premium не даёт длинные посты через API

**Симптом:** Пост обрезается на 280 символах через API, хотя Premium активен.

**Причина:** Расширенный лимит символов (4K/25K) через API требует:
- OAuth 2.0 User Context от Premium-аккаунта
- Корректный scope `tweet.write`
- API v2 (не v1.1)

**Проверьте:** токен принадлежит именно Premium-аккаунту.

## 12. Spaces API возвращает пустые данные

**Симптом:** Spaces endpoints возвращают пустой массив.

**Причины:**
- Space завершён (state: ended) — данные хранятся ограниченное время
- Нет активных/запланированных Spaces у запрошенных пользователей
- Тариф Free не поддерживает Spaces API

**Решение:** проверяйте `state` поле, используйте `/2/spaces/search` для поиска live Spaces.

## 13. Ошибка при создании List

**Симптом:** POST `/2/lists` возвращает ошибку.

**Проверьте:**
- OAuth 2.0 User Context (не App-only)
- Scope `list.write`
- Имя списка не пустое и до 25 символов
- Не превышен лимит списков (1 000 на аккаунт)
- Не более 5 000 участников в списке

## 14. Реклама не откручивается

**Симптом:** Рекламная кампания создана, но показов 0.

**Проверьте:**
- Статус кампании: ACTIVE (не PAUSED/DRAFT)
- Бюджет установлен и не исчерпан
- Таргетинг не слишком узкий (расширьте гео/интересы)
- Платёжный метод действителен
- Аккаунт прошёл модерацию рекламодателей
- Креатив соответствует политикам X Ads

## 15. Пост отображается как "Age-restricted"

**Симптом:** Пост виден только авторизованным пользователям, помечен как sensitive.

**Причина:** X автоматически или вручную пометил контент как sensitive.

**Решение:**
- Проверьте настройки аккаунта: Settings → Privacy → Mark media as containing sensitive
- Избегайте контента, нарушающего правила (насилие, adult)
- Обжалуйте через Settings → Help Center, если ошибочная маркировка
