# PuzzleBot — Опыт и критические уроки

> Читать при каждой активации скилла!

## Критические уроки (топ-7)

### 1. Ctrl+Shift+M НЕ работает для моноширинного
- **Проблема:** Вводит символ "m" и стирает выделенный текст
- **Решение:** Кнопка `</>` на всплывающей панели (3-я слева после B и I)
- **Подтверждено:** 2x (2026-02-15)

### 2. {{Переменные}} ломаются при обычном вводе
- **Проблема:** PuzzleBot превращает `{{...}}` в `<span class="my-variable">` элементы. При наборе текста переменная может "улететь" в другое место или разбиться (часть текста отрывается)
- **Решение:** Вставлять HTML напрямую через JS с правильной разметкой:
```javascript
editor.innerHTML = '...<span class="my-variable" type="user" contenteditable="false">{{user_id}}</span>...'
```
- **Дата:** 2026-02-15

### 3. JavaScript Selection API — лучший способ выделения
- **Проблема:** Клики по координатам ненадёжны — зависят от масштаба, скролла, размера окна
- **Решение:** `TreeWalker` + `Range API` для программного выделения
- **Пример:**
```javascript
const walker = document.createTreeWalker(editor, NodeFilter.SHOW_TEXT);
while (walker.nextNode()) {
  const idx = walker.currentNode.textContent.indexOf('искомый текст');
  if (idx !== -1) {
    const range = document.createRange();
    range.setStart(walker.currentNode, idx);
    range.setEnd(walker.currentNode, idx + 'искомый текст'.length);
    window.getSelection().removeAllRanges();
    window.getSelection().addRange(range);
    break;
  }
}
```
- **Дата:** 2026-02-15

### 4. Оптимальный паттерн работы (проверен 2x)
```
editor.innerHTML = весь текст с <p> и <br>
              ↓
for each фрагмент:
    JS createRange → выделить текст
    Ctrl+B / Ctrl+I
              ↓
JS проверка всех тегов разом (innerHTML.includes)
              ↓
Один финальный скриншот
```
**Детально:**
1. Вставить весь HTML через JS (`editor.innerHTML = ...`) — сразу с переменными, `<p>`, `<br>`, структурой. Никакого посимвольного ввода!
2. Выделять фрагменты через JS Selection API — конвейером, без пауз между шагами
3. Применять Ctrl+B / Ctrl+I через клавиатуру
4. Для `<code>` — выделить через JS → скриншот → клик по кнопке `</>`
5. Проверка — один вызов JS: `innerHTML.includes('<strong>')` и т.д.
6. Один финальный скриншот для визуала

**Метрики на типичный блок (6 форматирований):**
- 1 вызов JS для вставки текста
- 6 пар (JS-выделение + горячая клавиша)
- 1 вызов JS для проверки
- 1 скриншот
- = ~10 действий вместо 30+

- **Подтверждено:** кейс «Оставьте отзыв» — всё с первого раза (2026-02-15)

### 5. Кнопка </> на панели — координаты плавают
- **Проблема:** Панель форматирования появляется рядом с выделением, координаты каждый раз разные
- **Решение:** Делать скриншот перед кликом по `</>`, не полагаться на фиксированные координаты
- **Дата:** 2026-02-15

### 6. Эмодзи не включать в выделение при форматировании
- **Проблема:** Эмодзи в конце строк (♾, 🕐, 🎉, 🔥) не должны быть в курсиве/жирном
- **Решение:** В JS контролировать через `indexOf` + `.length` нужной подстроки (без эмодзи)
- **Дата:** 2026-02-15

### 7. Пустые строки и структура DOM
- Каждый Enter в редакторе создаёт `<p><br></p>`
- Для 3 пустых строк нужно 3 Enter'а
- PuzzleBot использует `<strong>`/`<em>`/`<code>` (а не `<b>`/`<i>`), Telegram отображает одинаково
- **Дата:** 2026-02-15

## Кейсы

### Кейс 1: «Карточка скидок» (2026-02-15)
- Первый прогон, медленный — пошагово с проверками после каждого шага
- Обнаружен баг Ctrl+Shift+M (стирает текст, вводит "m")
- 11 форматирований, включая `<code>`
- **Урок:** не проверять скриншотом каждый шаг

### Кейс 2: «Оставьте отзыв» (2026-02-15)
- Быстрый прогон по оптимальному паттерну
- `innerHTML` → 6 пар (JS + Ctrl+B/I) → JS-проверка → 1 скриншот
- Без `<code>`, без переменных `{{}}`, без откатов Ctrl+Z
- **Результат:** всё сработало с первого раза, ~10 действий

## Мини-приложения (формы) в PuzzleBot

### Ключевое: форма = мини-приложение, НЕ блок!
- Формы в PuzzleBot реализованы как **Mini App** (мини-приложения)
- Inline-кнопка → действие **«Переход к Мини-приложению»** (НЕ «Переход к блоку»!)
- PuzzleBot **сам генерирует** прямую ссылку (`https://t.me/BOT?startapp=HASH`) — BotFather НЕ нужен
- **Дата:** 2026-02-15

### Структура мини-приложения (формы)
Состоит из последовательности блоков:
1. **Заголовок** — название формы (стиль: extra/H1/H2/H3, расположение: слева/по центру)
2. **Форма ввода** (N штук) — каждое поле отдельный блок
3. **Клавиатура** — кнопка отправки внизу

### Настройки каждого поля «Форма ввода»

| Параметр | Описание | Пример |
|----------|----------|--------|
| **Вопрос** | Текст для пользователя (макс 320 символов) | "Введите свое ФИО" |
| **Название для статистики** | Метка в аналитике | "ФИО Пользователя" |
| **Переменная** | Куда сохраняется ответ → `{{переменная}}` | `tkt_client_name` |
| **Тип ввода** | Ввод текста / Выбор даты / Выбор времени / Выбор варианта / Тестирование / Опрос / **Загрузка файла** / Список / Выбор валюты / Выбор адреса | Ввод текста |
| **Маска ввода** | Валидация: Текст / Телефон / Почта / Регулярное выражение / Число / Ссылка / Криптокошелек | Телефон |
| **Тип поля** | Однострочный / Многострочный | Однострочный |
| **Плейсхолдер** | Подсказка в пустом поле | "Фамилия Имя Отчество" |
| **Ошибка** | Текст при невалидном вводе | "Неправильный формат текста" |

### Доступные типы блоков в конструкторе
Текст, Изображение, Видео, Стикер, Заголовок, Описание, Строки, Документ, Вкладки, **Форма ввода**, Карточки, HTML код, Подстановка, Разделитель, Баннер, Меню, Клавиатура, Товар, Поиск

### Привязка формы к кнопке
1. Создать кнопку в блоке → «Выберите действие»
2. Выбрать **«Переход к Мини-приложению»**
3. Ввести название мини-приложения → выбрать из списка
4. НЕ «Переход к блоку» — формы это Mini App!

### Настройки мини-приложения (правая панель)
- **Название** — текстовое имя
- **Прямая ссылка** — `https://t.me/BOT?startapp=HASH` (генерируется автоматически)
- **Техническая ссылка** — для интеграций
- Поисковые настройки
- Дополнительные настройки
- **Действия** — что происходит после отправки формы

### Пример: форма «Покупка билетов в парки»
```
Заголовок (H1): "Получить билеты"
Поле 2: ФИО          → tkt_client_name     (Текст, однострочный)
Поле 3: Телефон       → tkt_client_phone    (Маска: Телефон)
Поле 4: Email         → tkt_client_email    (Маска: Почта)
Поле 5: Дата          → tkt_visit_date      (Текст, однострочный)
Поле 6: Взрослые      → tkt_count_adults    (Маска: Число)
Поле 7: Дети          → tkt_count_children  (Маска: Число)
Поле 8: Младенцы      → tkt_count_infants   (Маска: Число)
Клавиатура: кнопка отправки
```

## Чего НЕ делать

| Действие | Почему плохо |
|----------|-------------|
| Ctrl+Shift+M для моноширинного | Стирает текст, вводит "m" |
| Вводить `{{переменные}}` вручную | Ломаются, улетают, разбиваются |
| Кликать по координатам для выделения | Координаты плывут от масштаба/скролла |
| Скриншот после каждого шага | Замедляет работу в 3-4 раза |
| Включать эмодзи в выделение | Эмодзи не должны форматироваться |
