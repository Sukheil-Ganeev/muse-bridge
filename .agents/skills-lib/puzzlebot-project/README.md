# PuzzleBot Project Skill

Единый скилл проекта PuzzleBot -- анализ Telegram-сообщества и конвертация видео-туториалов в базу знаний.

## Структура

```
skill/
  SKILL.md              # Основной файл скилла (полное описание проекта)
  README.md             # Этот файл
  references/
    faq.md              # FAQ по обоим pipeline (15 вопросов)
    troubleshooting.md  # Типичные проблемы и решения (10 штук)
    cheatsheet.md       # Команды, параметры, формулы, структуры
```

## Когда использовать

- Анализ экспорта Telegram-группы (messages.json)
- Извлечение Q&A-пар из чата сообщества
- Определение экспертов и активных помощников
- Генерация FAQ для бота или документации
- Транскрипция видео-туториалов (faster-whisper)
- Извлечение ключевых кадров из скринкастов (SSIM)
- OCR текста с экрана (Tesseract)
- Создание Obsidian-статей из видео

## Связь с проектом

Этот скилл заменяет предыдущий `docs/skill/` (покрывал только chat-analysis). Новый скилл охватывает весь проект: оба pipeline, экспортеры и вспомогательные инструменты.
