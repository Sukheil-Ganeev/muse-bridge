# Опыт работы с Instagram Graph API

## Критические уроки (топ-5)

### 1. Access Token истекает!
**Проблема:** Long-lived token действует 60 дней без использования, потом API возвращает ошибку.

**Решение:** Настройте автоматическое обновление токенов каждые 50-55 дней.

```javascript
// Автообновление токена
const refreshToken = async () => {
  const response = await fetch(
    `https://graph.facebook.com/v18.0/oauth/access_token?` +
    `grant_type=fb_exchange_token&` +
    `client_id=${APP_ID}&` +
    `client_secret=${APP_SECRET}&` +
    `fb_exchange_token=${OLD_TOKEN}`
  );
  const data = await response.json();
  return data.access_token;
};
```

### 2. Двухэтапная публикация обязательна
**Проблема:** Нельзя опубликовать пост одним запросом.

**Решение:** Всегда используйте 2 шага:
1. Создайте медиа-контейнер (`/media`)
2. Опубликуйте (`/media_publish`)

### 3. Rate Limits — скользящее окно
**Проблема:** Лимит 200 запросов/час обновляется **не в начале часа**, а скользящим окном.

**Решение:** Отслеживайте время каждого запроса, а не просто count/час.

### 4. App Review обязателен для production
**Проблема:** Без App Review можно тестировать только с тестовыми пользователями.

**Решение:** Подайте на App Review заранее (3-7 дней на рассмотрение).

### 5. Reels требуют вертикальный формат
**Проблема:** Горизонтальное видео не будет распознано как Reels.

**Решение:** Используйте aspect ratio 9:16 (например, 1080x1920).

## Формат записей

При создании нового опыта используйте структуру:

```
fixes/         — исправленные ошибки
improvements/  — найденные улучшения
patterns/      — повторяющиеся паттерны
warnings/      — что НЕ делать
```

Файл: `YYYY-MM-DD-краткое-описание.md`

Пример:
```markdown
# 2026-02-05 — Решение ошибки #190 (permissions)

## Проблема
API возвращал ошибку (#190) Application does not have permission

## Причина
Не пройден App Review для `instagram_content_publish`

## Решение
1. Подал на App Review
2. Прикрепил скриншоты использования API
3. Одобрено за 4 дня

## Урок
Подавайте на App Review заранее, не в последний момент!
```
