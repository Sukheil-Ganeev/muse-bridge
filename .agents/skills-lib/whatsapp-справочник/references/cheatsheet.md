# WhatsApp — Шпаргалка (Cheatsheet)

## Количественные лимиты

| Параметр | Лимит |
|----------|-------|
| Участников в группе | 1 024 |
| Контактов в broadcast-рассылке | 256 |
| Групп в сообществе (Community) | 50 |
| Участников в Announcement Group | 5 000 |
| Товаров в каталоге | 500 |
| Фото на 1 товар | 10 |
| Пользовательских меток (labels) | 20 |
| Стандартных меток | 5 |
| Привязанных устройств (multi-device) | 4 + телефон |
| Быстрых ответов (quick replies) | 50 |
| Подписчиков канала | Без лимита |
| Broadcast-списков | Без лимита |

## Размеры файлов

| Тип | Как медиа | Как документ |

| Аудио/голосовое | 16 МБ | 2 ГБ |
| Документ (PDF, DOC и др.) | — | 2 ГБ |
| Стикер (статичный) | 100 КБ | — |
| Стикер (анимированный) | 500 КБ | — |

## Длина текстов

| Поле | Лимит |
|------|-------|
| Сообщение в чате | 65 536 символов |
| Текстовый статус | 700 символов |
| Описание бизнес-профиля | 512 символов |

| Имя группы | 100 символов |
| Описание группы | 2 048 символов |

## Форматирование текста

| Формат | Синтаксис | Результат |
|--------|-----------|----------|
| Жирный | `*текст*` | **текст** |
| Курсив | `_текст_` | _текст_ |
| Зачёркнутый | `~текст~` | ~~текст~~ |
| Моноширинный | `` ```текст``` `` | `текст` |
| Маркированный список | `- элемент` или `* элемент` | - элемент |
| Нумерованный список | `1. элемент` | 1. элемент |
| Цитата | `> текст` | > текст |
| Код в строке | `` `код` `` | `код` |

## Стандартные метки (Labels)

| Метка | Назначение |
|-------|-----------|
| New customer | Новый клиент |
| New order | Новый заказ |
| Pending payment | Ожидание оплаты |
| Paid | Оплачено |
| Complete | Завершено |

## Автосообщения

| Тип | Когда отправляется | Настройка |
|-----|-------------------|-----------|
| Greeting Message | Первое сообщение или после 14 дней неактивности | Инструменты > Приветствие |
| Away Message | Вне рабочих часов / по расписанию / всегда | Инструменты > Нет на месте |
| Quick Reply | Вручную по ключевому слову (напр. /price) | Инструменты > Быстрые ответы |

## Статус (Status)

| Параметр | Значение |
|----------|---------|
| Время жизни | 24 часа |
| Форматы | Текст, фото, видео, GIF |
| Видео | До 30 секунд |
| Кто видит | Только контакты (настраивается) |
| Аналитика | Список просмотревших |

## Каналы (Channels)

| Параметр | Значение |
|----------|---------|
| Создание | Вкладка Обновления > Меню > Создать канал |
| Подписчики | Без лимита |
| Контент | Текст, фото, видео, ссылки, стикеры, опросы |
| Аналитика | Охват, рост, подписки за 30 дней |
| Стоимость | Бесплатно |
| Комментарии | Нет (ожидаются в 2026) |

## Сообщества (Communities)

| Параметр | Значение |
|----------|---------|
| Создание | Чаты > Новый > Новое сообщество |
| Групп в сообществе | До 50 |
| Announcement Group | До 5 000 участников, только админы |
| Обычная группа | До 1 024 участников |
| Конфиденциальность | Участники не видят полный список |

## Безопасность — чек-лист

- [ ] Включить 2FA (двухфакторную аутентификацию)
- [ ] Указать email для восстановления 2FA PIN
- [ ] Настроить бэкап чатов (Google Drive / iCloud)
- [ ] Проверить связанные устройства
- [ ] Не использовать неофициальные приложения (GB WhatsApp)
- [ ] Не передавать OTP-коды в чатах
