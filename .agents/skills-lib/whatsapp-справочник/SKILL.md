## 1. Экосистема WhatsApp — три продукта

### WhatsApp (личный мессенджер)

Бесплатное приложение для личного общения. 2+ млрд пользователей. End-to-end шифрование всех сообщений, звонков и медиа.

### WhatsApp Business App (бесплатное бизнес-приложение)

Бесплатное приложение для малого и среднего бизнеса. Все функции личного WhatsApp плюс:
- Бизнес-профиль (адрес, описание, часы работы, email, сайт)
- Каталог товаров/услуг (до 500 позиций)
- Метки (labels) для организации чатов
- Быстрые ответы (quick replies)
- Приветственные и автоответы (greeting / away messages)
- Рассылки (broadcast lists, до 256 контактов)
- Короткая ссылка и QR-код
- Встроенная статистика сообщений

**Когда использовать:** 1-5 сотрудников, до ~1000 клиентов, ручная обработка заказов.

### WhatsApp Business Platform (API)

Платная платформа для среднего и крупного бизнеса. Многоканальность, автоматизация, CRM-интеграция, чат-боты, массовые рассылки без лимитов.

**Когда использовать:** 5+ операторов, автоматизация, интеграция с CRM, массовые рассылки.

> Подробно про API: см. `whatsapp-bot-справочник`

### Таблица сравнения

| Возможность | Personal | Business App | Business API |
|-------------|----------|-------------|-------------|
| Стоимость | Бесплатно | Бесплатно | Платно (за сообщение) |
| Бизнес-профиль | Нет | Да | Да |
| Каталог | Нет | Да (500 товаров) | Да |
| Метки | Нет | Да (до 20) | Через CRM |
| Автоответы | Нет | Greeting + Away | Полная автоматизация |
| Рассылки | 256 контактов | 256 контактов | Без лимитов |
| Каналы | Да | Да | Да |
| Сообщества | Да | Да | Нет |
| Чат-боты | Нет | Нет | Да |
| Multi-agent | Нет | 1 телефон + 4 устройства | Без лимитов |
| Верификация (галочка) | Нет | Нет | Да (зелёная) |

### Coexistence (2025+)

Новая модель от Meta: можно одновременно использовать Business App и Cloud API на одном номере. Менеджеры работают в приложении на телефоне, а CRM/боты подключены через API. Сообщения синхронизируются между обоими каналами.

## 2. Бизнес-профиль WhatsApp Business

### Настройка профиля

Откройте WhatsApp Business > Настройки > Инструменты для бизнеса > Профиль компании.

**Поля профиля:**

| Поле | Описание | Пример для туризма |
|------|----------|-------------------|
| Название | Имя компании | Dubai Tours by Suheil |
| Категория | Тип бизнеса | Travel & Tourism |
| Описание | О компании (до 512 символов) | Экскурсии, билеты, яхты, авто в ОАЭ. Цены ниже кассы! |
| Адрес | Физический адрес | Tecom, Barsha Heights, Dubai |
| Часы работы | Расписание | Пн-Сб 09:00-21:00 |
| Email | Контактная почта | info@dubaitours.ae |
| Сайт | URL | https://dubaitours.ae |

### Верификация бизнеса

- **Зелёная галочка** (Official Business Account) — только через Business API, требует верификацию Meta
- **Бизнес-аккаунт без галочки** — доступен в Business App, подтверждает что это бизнес

### Рекомендации для туризма

- Используйте фото логотипа или узнаваемую достопримечательность на аватарке
- В описании укажите ключевые услуги и преимущества (цены ниже, все эмираты, RU/EN)
- Обязательно укажите часы работы (клиенты из разных часовых поясов)
- Добавьте адрес офиса — повышает доверие

## 3. Каталог товаров и услуг

### Создание каталога

WhatsApp Business > Настройки > Инструменты для бизнеса > Каталог > Добавить товар/услугу.

**Поля товара:**

| Поле | Лимит | Обязательное |
|------|-------|-------------|
| Название | 100 символов | Да |
| Изображения | До 10 фото или 1 видео | Да (мин. 1) |
| Цена | Числовое значение + валюта | Нет |
| Описание | До 5000 символов | Нет |
| Ссылка на сайт | URL | Нет |
| Код товара | Артикул/SKU | Нет |

**Лимиты каталога:**
- Максимум 500 товаров/услуг
- Формат фото: JPEG/PNG, рекомендуется 600x600 px
- Размер фото: до 5 МБ каждое

### Collections (Коллекции)

Коллекции — папки для группировки товаров внутри каталога. Клиент видит категории вместо бесконечного списка.

**Создание:** Каталог > Коллекции > Создать коллекцию > Выбрать товары.

**Пример коллекций для туризма:**

| Коллекция | Товары |
|-----------|--------|
| Экскурсии Дубай | City Tour, Desert Safari, Dhow Cruise, Miracle Garden |
| Экскурсии Абу-Даби | Grand Mosque, Ferrari World, Louvre, Royal Palace |
| Билеты в парки | Burj Khalifa, Aquaventure, IMG Worlds, Dubai Frame |
| Яхты и водные | Yacht Tour, Jet Ski, Parasailing, Deep Sea Fishing |
| Аренда авто | Luxury, Sport, Business, Economy |
| Трансферы | Airport Transfer, City Transfer, Abu Dhabi Transfer |

### Корзина (Cart)

Клиенты могут добавлять товары из каталога в корзину и отправлять заказ одним сообщением. Вы получаете сообщение со списком выбранных товаров, количеством и общей суммой.

### Ссылки на каталог

- **Ссылка на весь каталог:** `https://wa.me/c/971XXXXXXXXX`
- **Ссылка на товар:** Каждый товар имеет уникальную ссылку для вставки в соцсети и рекламу
- Можно делиться каталогом прямо из чата

## 4. WhatsApp Channels (Каналы)

### Что это

Каналы — инструмент одностороннего вещания (аналог каналов в Telegram). Админ публикует обновления, подписчики читают. Каналы находятся в отдельной вкладке "Обновления" (Updates), не смешиваясь с личными чатами.

### Создание канала

1. Откройте вкладку "Обновления" (Updates)
2. Нажмите меню (три точки) > "Создать канал"
3. Введите название, описание и иконку
4. Нажмите "Создать канал"

### Возможности каналов

| Функция | Описание |
|---------|----------|
| Публикации | Текст, фото, видео, ссылки, стикеры |
| Опросы (Polls) | Голосования среди подписчиков |
| Аналитика | Охват, рост, подписки/отписки за 30 дней |
| Неограниченная аудитория | Нет лимита на количество подписчиков |
| Конфиденциальность | Подписчики не видят друг друга |
| Бесплатно | Никаких платежей за публикации |

### Что ожидается в 2026

- Комментарии и threaded replies (обратная связь от подписчиков)
- Расширенная аналитика с AI-рекомендациями по контенту
- Монетизация: платные подписки, премиум-контент, спонсорство

### Стратегия для туризма

**Контент-план канала:**
- Понедельник: горячие предложения недели с ценами
- Среда: фотоотчёт/видео с прошедших экскурсий
- Пятница: анонс выходных (Desert Safari, яхты)
- По ситуации: flash-акции, новые направления, праздники ОАЭ

**Продвижение канала:**
- Ссылку на канал — в бизнес-профиль, Instagram bio, сайт
- QR-код — в офисе, на визитках, буклетах
- Делиться ссылкой в чатах с клиентами
- Упоминать в статусах WhatsApp

## 5. WhatsApp Communities (Сообщества)

### Что это

Сообщество — суперструктура, объединяющая несколько групп под одним зонтиком. Есть общая "Группа объявлений" (Announcement Group) для массовых уведомлений от админов.

### Лимиты

| Параметр | Лимит |
|----------|-------|
| Групп в сообществе | До 50 |
| Участников в Announcement Group | До 5 000 |
| Участников в обычной группе | До 1 024 |
| Кто пишет в Announcement Group | Только админы |
| Конфиденциальность | Участники не видят полный список и номера |

### Создание сообщества

1. Вкладка Чаты > Новый чат > Новое сообщество
2. Введите название и описание
3. Добавьте существующие группы или создайте новые
4. Настройте Announcement Group

### Пример для туризма

**Сообщество:** "Dubai Tours Network"

| Группа | Назначение |
|--------|-----------|
| Объявления (Announcement) | Новые продукты, цены, важные новости |
| Агенты — Дубай | Вопросы и бронирования по Дубаю |
| Агенты — Абу-Даби | Вопросы и бронирования по Абу-Даби |
| Яхты и водные | Яхт-туры, джет-ски, рыбалка |
| Аренда авто | Машины, трансферы, МВУ |
| Отзывы и фото | Фотоотчёты клиентов |

**Преимущества:**
- Агенты видят только нужные группы
- Важные объявления не теряются в потоке сообщений
- Модерация на уровне всего сообщества

## 7. WhatsApp Status (Статусы)

### Что это

Статусы — публикации (текст, фото, видео), которые видят ваши контакты в течение 24 часов. Аналог Instagram Stories. 780+ млн пользователей просматривают статусы ежедневно (2025). 62% брендов используют статусы в маркетинге.

### Форматы

| Формат | Лимит |
|--------|-------|
| Текст | 700 символов, выбор фона и шрифта |
| Фото | JPEG/PNG, до 16 МБ |
| Видео | До 30 секунд, до 16 МБ |
| GIF | Анимированные изображения |

### Аналитика статусов

В WhatsApp Business доступна базовая статистика:
- Кто просмотрел ваш статус (список контактов)
- Количество просмотров
- Время просмотра

### Стратегия для туризма

**Что публиковать:**
- Фото/видео с текущих экскурсий (social proof)
- Flash-акции с ограниченным сроком (24 часа = естественный дедлайн)
- "За кулисами": подготовка к туру, встреча гостей
- Отзывы клиентов (скриншоты с разрешения)
- Прайс-листы на неделю

**Best practices:**
- Публикуйте 3-5 статусов в день (не спамьте)
- Лучшее время: 9-11 утра и 18-20 вечера (аудитория СНГ: +1ч к Dubai)
- Первый статус дня — самый важный (виден первым)
- Используйте текстовые статусы для цен, фото — для эмоций

## 8. Broadcast Lists (Рассылки)

### Что это

Рассылка — отправка одного сообщения нескольким контактам одновременно. Каждый получатель видит сообщение как личное (не групповое). Ответы приходят в личный чат.

### Лимиты

| Параметр | Лимит |
|----------|-------|
| Контактов в списке | До 256 |
| Количество списков | Без лимита |
| Условие доставки | Получатель должен сохранить ваш номер в контактах |

### Создание рассылки

Чаты > Меню > Новая рассылка > Выбрать контакты > Создать.

### Важное ограничение

Сообщение дойдёт только до тех, кто **сохранил ваш номер** в своих контактах. Если контакт не сохранил — сообщение не доставится без уведомления об ошибке.

**Решение:** Просите клиентов сохранить ваш номер. Добавляйте в подпись: "Сохраните наш номер, чтобы получать лучшие предложения!"

### Стратегия для туризма

**Сегментация списков:**

| Список | Кто | Контент |
|--------|-----|---------|
| Агенты Москва | Турагенты из Москвы | Прайсы, наличие, спецпредложения |
| Агенты Казахстан | Турагенты из КЗ | То же + Kaspi оплата |
| VIP-клиенты | Повторные клиенты | Эксклюзивные цены, новые продукты |
| Яхт-клиенты | Интересовались яхтами | Яхт-предложения, праздники на борту |

## 9. Click-to-Chat и QR-коды

### Ссылка wa.me

**Формат:** `https://wa.me/НОМЕР`

**Правила:**
- Номер с кодом страны, без `+`, пробелов, дефисов и скобок
- Пример: `https://wa.me/971501234567`

### Предзаполненный текст

**Формат:** `https://wa.me/971501234567?text=ТЕКСТ`

**Примеры:**
```
https://wa.me/971501234567?text=Здравствуйте!%20Интересует%20Desert%20Safari
https://wa.me/971501234567?text=Хочу%20забронировать%20яхту%20на%20выходные
https://wa.me/971501234567?text=Прайс%20на%20экскурсии%20Дубай
```

**Пробелы** кодируются как `%20`.

### Короткая ссылка в Business App

WhatsApp Business > Настройки > Инструменты для бизнеса > Короткая ссылка.

Здесь же можно:
- Скопировать ссылку
- Получить QR-код
- Настроить приветственное сообщение

### QR-код

Способы создания:
1. Встроенный в WhatsApp Business (Настройки > QR-код)
2. Любой генератор QR (вставив ссылку wa.me)

**Где размещать QR-код:**
- Стойка ресепшн / офис
- Визитные карточки
- Буклеты и флаеры
- Меню на яхте / в автомобиле
- Instagram Stories и посты
- Сайт (лендинг)
- Email-подпись

### Universal Link (Deep Link)

**Для мобильных приложений и сайтов:**
```
https://wa.me/971501234567  — откроет WhatsApp (мобильный/десктоп)
https://api.whatsapp.com/send?phone=971501234567  — альтернативный формат
```

Оба формата работают на iOS, Android и WhatsApp Web.

## 12. Метки, быстрые ответы и автосообщения

### Метки (Labels)

Организация чатов по категориям. До 20 пользовательских меток + 5 стандартных.

**Стандартные метки:**
- New customer (Новый клиент)
- New order (Новый заказ)
- Pending payment (Ожидание оплаты)
- Paid (Оплачено)
- Complete (Завершено)

**Дополнительные для туризма:**

| Метка | Цвет | Назначение |
|-------|------|-----------|
| Hot Lead | Красный | Горячий клиент, нужен быстрый ответ |
| Агент | Синий | Турагент-партнёр |
| VIP | Золотой | Повторный / крупный клиент |
| Яхта | Бирюзовый | Запрос на яхту (передать Муфамаду) |
| Авто | Серый | Запрос на авто (передать Марселю) |
| Экскурсия завтра | Оранжевый | Тур завтра, нужна координация |

### Быстрые ответы (Quick Replies)

Сохранённые шаблоны ответов с коротким ключевым словом.

**Настройка:** Инструменты для бизнеса > Быстрые ответы > Добавить.

**Примеры:**

| Ключ | Сообщение |
|------|----------|
| /price | Прайс-лист на экскурсии Дубай: Desert Safari $65, City Tour $50, Dhow Cruise $45... |
| /address | Наш офис: Tecom, Barsha Heights. Метро Dubai Internet City. Карта: [ссылка] |

## 14. Безопасность и конфиденциальность

### End-to-End шифрование

Все сообщения, звонки, фото, видео и документы зашифрованы протоколом Signal. Даже WhatsApp/Meta не могут прочитать содержимое. Шифрование включено по умолчанию и не может быть отключено.

### Двухфакторная аутентификация (2FA)

Настройки > Аккаунт > Двухшаговая проверка > Включить.
- 6-значный PIN при входе с нового устройства
- Опциональный email для восстановления
- **Обязательно включите для бизнес-аккаунта!**

### Исчезающие сообщения (Disappearing Messages)

Автоматическое удаление сообщений через выбранный срок:
- 24 часа
- 7 дней
- 90 дней

**Для бизнеса:** полезно для временных прайсов, промокодов, конфиденциальных данных.

### Блокировка и жалобы

- Заблокированный контакт не может писать, звонить, видеть статусы и "Был в сети"
- Жалобы (Report) отправляют последние 5 сообщений в Meta для проверки
- Массовые жалобы могут привести к бану аккаунта

### Рекомендации для бизнеса

1. **Включите 2FA** на всех устройствах с бизнес-аккаунтом
2. **Не спамьте** — массовые жалобы = бан
3. **Бэкап чатов** — настройте резервное копирование в Google Drive / iCloud
4. **Не передавайте** OTP-коды и пароли в чатах
5. **Регулярно проверяйте** привязанные устройства (Настройки > Связанные устройства)

## 15. Юзернеймы WhatsApp (2026)

### Что это

Новая функция, анонсированная Meta для запуска в 2026 году. Пользователи смогут выбрать уникальный юзернейм и общаться/звонить без обмена номерами телефонов.

### Что известно

- Запуск запланирован на июнь 2026
- Сначала бета-тестеры, затем глобальный rollout
- Юзернейм будет отображаться вместо номера в чатах и группах
- Можно звонить по юзернейму (voice + video)
- Для бизнеса: "business-scoped user ID" в API

### Значение для бизнеса

- Клиенты смогут найти вас по юзернейму (например, `@dubaitours`)
- Не нужно делиться личным номером
- Проще запомнить и передать контакт
- Брендирование через уникальный юзернейм
