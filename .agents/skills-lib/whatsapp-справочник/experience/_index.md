# База опыта: WhatsApp Business API

## Критические уроки (топ-5)

1. **Ценовая модель 2026:** Оплата за сообщение, не за беседу. Используйте бесплатные окна максимально.

2. **Категории важны:** Utility на 40% дешевле Marketing. Не используйте Marketing там, где подходит Utility.

3. **72ч окно:** Click-to-WhatsApp реклама дает 72 часа бесплатной переписки. Самый выгодный способ привлечения.

4. **Template approval:** Meta проверяет шаблоны 2-24 часа. Создавайте заранее, не перед рассылкой.

5. **Webhook 200 OK:** Всегда отвечайте 200 OK сразу, обрабатывайте асинхронно. Иначе Meta будет считать webhook неработающим.

## Секции опыта

- `fixes/` - Исправленные ошибки
- `improvements/` - Найденные улучшения
- `patterns/` - Повторяющиеся паттерны
- `warnings/` - Что НЕ делать
