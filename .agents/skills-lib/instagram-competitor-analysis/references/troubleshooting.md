# Troubleshooting -- Instagram Competitor Analysis

## Проблема 1: Instaloader выдает "Login required" или "Challenge required"

### Симптомы
```
instaloader.exceptions.ConnectionException: 401 Unauthorized
instaloader.exceptions.TwoFactorAuthRequiredException
QueryReturnedBadRequestException: 400 Bad Request
```

### Причины
- Слишком агрессивный скрейпинг (>50 постов/час без задержек)
- Использование основного бизнес-аккаунта
- Запуск с нового IP без предварительного логина в браузере
- Instagram обнаружил автоматическую активность

### Решение
1. **Немедленно:** Прекратить скрейпинг на 24-48 часов.
2. **Залогиниться вручную** через браузер в тот же аккаунт, пройти challenge (капча/SMS).
3. **Настроить задержки** в скрипте:
   ```python
   import time
   import random

   # Между запросами постов
   time.sleep(random.uniform(60, 120))

   # Между профилями конкурентов
   time.sleep(random.uniform(300, 600))
   ```
4. **Использовать throwaway-аккаунт** -- никогда основной бизнес-аккаунт.
5. **Ограничить объём:** максимум 20-30 постов за сессию, не чаще 1 раза в день.

## Проблема 2: Данные собираются, но анализ не дает полезных инсайтов

### Симптомы
- Огромные CSV-файлы с постами, но непонятно что с ними делать
- Ручной просмотр занимает часы
- Нет конкретных actionable выводов

### Причины
- Не определены KPI до начала сбора данных
- Слишком много конкурентов -- нет фокуса
- Данные собираются, но не структурируются

### Решение
1. **Определить 3-5 конкретных вопросов** до начала:
   - "Какие цены на desert safari у конкурентов?"
   - "Как часто конкурент X публикует акции?"
   - "Какие хештеги приносят больше engagement?"
2. **Сузить список** до 3-5 ключевых конкурентов (не 20+).
3. **Создать шаблон отчёта** с конкретными метриками:
   ```
   Конкурент | Ср. цена тура | Кол-во постов/нед | Топ-хештеги | Акции
   ```
4. **Перейти на Approach 3** (AI-powered) для автоматического извлечения цен и инсайтов через Claude API.

## Проблема 3: Облачный сервис (Apify/Phantom Buster) перестал собирать данные

### Симптомы
- Задачи в облаке завершаются с ошибкой
- Пустые результаты после успешного запуска
- Сообщения "Rate limited" или "Proxy error"

### Причины
- Instagram обновил защиту (происходит каждые 2-3 месяца)
- Исчерпана квота плана (проверить dashboard сервиса)
- Целевой аккаунт сменил настройки приватности
- Прокси-серверы сервиса попали в бан Instagram

### Решение
1. **Проверить статус сервиса:**
   - Apify: https://status.apify.com
   - Phantom Buster: проверить changelog на обновления фантомов
2. **Проверить квоту:** Dashboard -> Usage -> оставшиеся compute units / execution time.
3. **Обновить актор/фантом** до последней версии (сервисы адаптируются к изменениям Instagram).
4. **Подождать 24-48 часов** -- часто проблема решается на стороне сервиса.
5. **Альтернатива:** Временно переключиться на ручной сбор или Instaloader (Approach 1) пока облачный сервис починится.
6. **Связаться с поддержкой** сервиса -- они часто предоставляют workaround быстрее, чем публичный фикс.
