# FAQ -- Instagram Competitor Analysis

## 1. Какой подход выбрать, если бюджет $0 и нужно отслеживать 5 конкурентов?

**Ответ:** Approach 1 (Python + Instaloader). Это бесплатный вариант, подходит для 1-10 конкурентов. Требуется базовое знание Python. Установите Instaloader (`pip install instaloader`), настройте скрипт с задержками 60-120 секунд между запросами и запускайте через Windows Task Scheduler раз в неделю. Используйте отдельный (не основной) Instagram-аккаунт для скрейпинга.

## 2. Законно ли скрейпить посты конкурентов из Instagram?

**Ответ:** Instagram явно запрещает автоматический сбор данных в своих Terms of Service. Однако миллионы компаний используют эти инструменты для бизнес-аналитики. Риски:
- **Минимальный:** Временная блокировка аккаунта (challenge required).
- **Средний:** Перманентная блокировка аккаунта-скрейпера.
- **Максимальный:** Юридические претензии (крайне редко для малого бизнеса).

Рекомендация: используйте throwaway-аккаунт, соблюдайте задержки, не скрейпьте приватные аккаунты.

## 3. Чем отличаются Apify и Phantom Buster?

**Ответ:**
| Критерий | Apify ($49/мес) | Phantom Buster ($59/мес) |
|----------|-----------------|--------------------------|
| Интерфейс | API-first, для разработчиков | Визуальный, no-code |
| Гибкость | Высокая (свои акторы) | Средняя (готовые фантомы) |
| Ротация IP | Встроенная | Встроенная |
| Интеграции | Webhooks, API | Google Sheets, CRM |
| Лучше для | Технических пользователей | Маркетологов без кода |

Для туристического бизнеса без разработчика в штате -- Phantom Buster проще в освоении.

## 4. Как часто нужно проверять конкурентов?

**Ответ:** Зависит от целей:
- **Ценовой мониторинг** (туры, билеты): ежедневно или через день -- цены меняются часто.
- **Контент-стратегия** (какие посты публикуют): еженедельно -- достаточно для выявления трендов.
- **Сезонный анализ** (акции, спецпредложения): ежедневно в высокий сезон (октябрь-март для ОАЭ), еженедельно в низкий.

Approach 1 оптимален для еженедельных проверок. Для ежедневного мониторинга рекомендуется Approach 2 (облачные сервисы).

## 5. Можно ли отслеживать Stories и Reels конкурентов?

**Ответ:**
- **Stories:** Instaloader умеет скачивать Stories, но они исчезают через 24 часа -- нужен ежедневный запуск. Облачные сервисы (Apify) справляются лучше с автоматическим 24/7 мониторингом.
- **Reels:** Instaloader скачивает Reels как обычные посты. Apify и Phantom Buster также поддерживают Reels.
- **Highlights:** Доступны через Instaloader (`--highlights`).

Ограничение: приватные аккаунты недоступны ни одним инструментом без подписки на аккаунт.
