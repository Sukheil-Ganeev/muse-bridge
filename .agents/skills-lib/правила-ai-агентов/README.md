# Правила AI-агентов для туристического бизнеса ОАЭ

Скилл для настройки и интеграции AI-агентов (продажник, CRM, визовик) с разграничением доступа к данным клиентов.

## Когда использовать

- Настройка нового AI-агента для туристического бизнеса
- Интеграция Claude API с WhatsApp/Telegram ботами
- Обработка чувствительных данных (паспорта, карты)
- Разграничение доступа между агентами

## Структура скилла

```
правила-ai-агентов/
├── SKILL.md                      # Основной файл (полное руководство)
├── README.md                     # Этот файл
└── references/
    ├── faq.md                    # Частые вопросы
    ├── troubleshooting.md        # Решение проблем
    └── cheatsheet.md             # Шпаргалка для быстрого доступа
```

## Содержание SKILL.md

1. **Профили доступа агентов** - таблица кто что видит
2. **Системные промпты** - готовые промпты для Claude API
3. **Функция prepare_for_agent()** - Python код фильтрации
4. **Правила безопасности** - что запрещено, как логировать
5. **Примеры диалогов** - реакции на паспорт, карту, запрос чужих данных
6. **Интеграция с ботом** - FastAPI код, архитектура

## Быстрый старт

### 1. Скопируй системный промпт

Из `SKILL.md` раздел "Системные промпты для Claude API":
- `SYSTEM_PROMPT_SALES` - для продажника
- `SYSTEM_PROMPT_CRM` - для CRM
- `SYSTEM_PROMPT_VISA` - для визовика

### 2. Используй функцию фильтрации

```python
from skill import prepare_for_agent

# Фильтруем данные клиента для продажника
safe_data = prepare_for_agent(client_data, "sales")
```

### 3. Проверяй входящие сообщения

```python
from skill import sanitize_message

result = sanitize_message(user_message, "sales")
if result["requires_escalation"]:
    notify_manager(result["requires_escalation"])
```

## Типы агентов

| Агент | Назначение | Доступ |
|-------|------------|--------|
| AI-Продажник | Продажа туров, экскурсий | Контакты, история, предпочтения |
| AI-CRM | Заполнение карточек | Всё, но карты маскированы |
| AI-Визовик | Сбор документов для виз | Паспорта, визовая история |
