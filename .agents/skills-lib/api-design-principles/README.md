# api-design-principles

## Описание
Принципы проектирования REST и GraphQL API для создания интуитивных, масштабируемых и поддерживаемых интерфейсов. Используется при проектировании новых API, ревью спецификаций или установлении стандартов дизайна API.

## Структура
```
api-design-principles/
├── SKILL.md              # Основной файл
├── README.md             # Этот файл
└── references/
    ├── faq.md            # Часто задаваемые вопросы
    ├── troubleshooting.md # Решение проблем
    └── cheatsheet.md     # Шпаргалка
```

## Использование
Скилл активируется автоматически по триггерам в description.
