# Templates (Шаблоны)

## Список шаблонов

### 1. media-kit-template.pptx
**Назначение:** Медиакит для рекламодателей (PDF презентация канала)

**Содержание:**
- Слайд 1: Обложка (название канала, логотип, контакты)
- Слайд 2-3: О канале (тематика, миссия, уникальность)
- Слайд 4-6: Статистика (подписчики, охват, ERR, графики роста)
- Слайд 7-8: Демография аудитории (география, возраст, пол, интересы)
- Слайд 9-11: Примеры постов (5-7 лучших с статистикой)
- Слайд 12: Прайс-лист (пакеты: Bronze, Silver, Gold, Platinum)
- Слайд 13: Кейсы (успешные сотрудничества)
- Слайд 14: Отзывы (3-5 отзывов довольных брендов)
- Слайд 15: Контакты (email, Telegram, WhatsApp)

**Как использовать:**
1. Скачать шаблон (или создать свой в PowerPoint/Canva)
2. Заменить placeholder данные на свои
3. Экспортировать в PDF
4. Отправлять потенциальным рекламодателям

**Инструменты для создания:**
- PowerPoint / Keynote / Google Slides
- Canva Pro (готовые шаблоны медиакитов)
- Figma (профессиональный дизайн)

### 2. invoice-template.docx
**Назначение:** Инвойс для оплаты рекламы

**Содержание:**
- Заголовок: INVOICE
- Номер инвойса и дата
- Клиент (название компании, ИНН, адрес)
- Исполнитель (ваше ИП/самозанятость, ИНН, адрес)
- Услуга (описание, количество, цена)
- Итого к оплате
- Реквизиты для оплаты (банк, карта, ЮMoney)
- Подписи сторон

**Как использовать:**
1. Открыть шаблон в Word/Google Docs
2. Заполнить данные клиента и услуги
3. Экспортировать в PDF
4. Отправить клиенту для оплаты

**Автоматизация:**
См. `scripts/generate-invoice.js` для автоматической генерации инвойсов

### 3. sponsorship-proposal.pdf
**Назначение:** Коммерческое предложение для брендов

**Содержание (5-7 страниц):**
- Страница 1: Обложка (название канала, "Спонсорские пакеты 2026")
- Страница 2: О канале (тематика, миссия, уникальность)
- Страница 3: Аудитория (демография, интересы, платежеспособность)
- Страница 4: Пакеты (Bronze, Silver, Gold, Platinum с ценами)
- Страница 5: Кейсы (2-3 успешных сотрудничества с результатами)
- Страница 6: Отзывы (3-5 отзывов довольных брендов)
- Страница 7: Контакты (email, Telegram, WhatsApp)

**Как использовать:**
1. Создать в PowerPoint или Canva
2. Экспортировать в PDF
3. Отправлять потенциальным спонсорам вместе с медиакитом

**Шаблон письма для отправки:**

- Bronze (7,000₽): 1 пост

Готов обсудить индивидуальные условия.

## Как создать собственные шаблоны

### Для медиакита:
1. Собрать статистику (подписчики, охват, ERR)
2. Сделать скриншоты лучших постов
3. Получить демографию аудитории (из аналитики платформы)
4. Создать презентацию (10-15 слайдов)
5. Добавить прайс-лист (ваши цены)

### Для инвойса:
1. Зарегистрироваться как самозанятый или ИП
2. Получить реквизиты (ИНН, банковский счёт)
3. Создать шаблон в Word (структура выше)
4. Сохранить как .docx для повторного использования

### Для спонсорского предложения:
1. Выбрать 3-5 лучших кейсов
2. Получить отзывы от довольных клиентов
3. Создать красивую презентацию (Canva Pro или Figma)
4. Экспортировать в PDF
