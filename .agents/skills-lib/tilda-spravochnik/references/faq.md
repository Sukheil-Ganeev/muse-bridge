# Tilda -- FAQ (12 вопросов)

---

## 1. Какой тариф Tilda нужен для туристического бизнеса?

**Personal ($15/мес)** -- если один сайт/лендинг со своим доменом, формы, магазин, аналитика. Покрывает 90% потребностей.

**Business ($25/мес)** -- если нужно несколько сайтов (экскурсии + яхты + авто), экспорт кода, API-доступ, или HTML-код в шапке всех страниц.

**Free** -- только для тестирования. Нет своего домена (только .tilda.ws), ограничен 50 страниц и 50 МБ.

## 2. Можно ли сделать полноценный магазин экскурсий с оплатой?

Да. Tilda Store поддерживает до 5000 товаров, корзину, промокоды, варианты товаров (до 30). Каждая экскурсия = товар с ценой в AED. Подключите Stripe или PayPal в Site Settings -> Payment Systems. Клиент добавляет экскурсию в корзину -> вводит данные -> оплачивает. Для сложных бронирований (яхты, VIP-программы) лучше использовать форму заявки + ручное подтверждение.

## 3. Как настроить отправку заявок в Telegram бот?

1. Напишите @TildaFormsBot в Telegram -> нажмите "Start" -> получите API Key и Secret Key
2. В Tilda: Site Settings -> Forms -> Telegram -> вставьте API Key и Secret Key
3. Подтвердите или пропустите "Assign service to all forms"
4. Откройте блок формы на странице -> Content -> выберите Telegram как приёмник
5. Опубликуйте страницу

Для группы: добавьте @TildaFormsBot -> напишите /start -> следуйте инструкциям. Каждая заявка придёт в Telegram мгновенно с полями формы.

## 4. Как сделать мультиязычный сайт (RU/EN/AR)?

**Два подхода:**

1. **Отдельные проекты** (рекомендуется, Business план): создайте 3 проекта, настройте субдомены (en.site.com, ru.site.com, ar.site.com). Полный контроль над каждой версией.

2. **Папки в одном проекте** (Personal план): страницы `/en/desert-safari`, `/ru/desert-safari`, `/ar/desert-safari`. Добавьте языковой переключатель через меню ME204 или кастомный T123 блок.

Для арабского (RTL) добавьте CSS: `body { direction: rtl; }` через T123 блок. Не забудьте hreflang-теги для SEO.

**Автоперевод:** Weglot ($15+/мес) автоматически переводит и добавляет переключатель.

## 5. Какие платёжные системы работают в ОАЭ?

**Работают в ОАЭ из списка Tilda:**
- **Stripe** -- основная рекомендация. ОАЭ поддерживается, 135+ валют, AED
- **PayPal** -- работает, но требует UAE PayPal account
- **2Checkout (Verifone)** -- международный, работает

**Не работают в ОАЭ напрямую:**
- CloudPayments -- ориентирован на РФ/СНГ
- ЮKassa, Robokassa -- только для РФ

**Для криптоплатежей:** CryptoCloud, NOWPayments через T123 блок (кастомная интеграция).

## 6. Как добавить выбор даты тура в форму?

В блоке формы (BF400/BF200) добавьте поле:
- Тип: **Date** (выпадающий календарь)
- Название: "Дата тура"
- Обязательное: Да

Если нужен выбор диапазона дат или недоступных дат -- используйте T123 блок с JavaScript-датапикером (например, flatpickr) и кастомное поле.

## 7. Можно ли подключить WhatsApp с автотекстом?

Да, через CTA-кнопку с WhatsApp API ссылкой:

```
https://wa.me/971XXXXXXXXX?text=Здравствуйте!%20Хочу%20забронировать%20Desert%20Safari
```

Вставьте эту ссылку в кнопку блока (любой блок с CTA -> Link -> вставить URL). При клике у клиента откроется WhatsApp с готовым текстом.

Для динамического текста (название тура, дата) используйте JavaScript в T123 блоке, который формирует ссылку на лету.

## 8. Как оптимизировать скорость загрузки?

1. **Изображения:** сжимайте через TinyPNG/Squoosh до загрузки. Используйте WebP. Не загружайте фото больше 1 МБ
2. **Видео:** не загружайте напрямую -- используйте YouTube/Vimeo embed
3. **Блоки:** не используйте больше 15-20 блоков на странице
4. **JavaScript:** минимизируйте кастомные скрипты в T123
5. **Шрифты:** используйте 1-2 шрифта, не больше
6. **Lazy Loading:** включено в Tilda по умолчанию

Tilda CDN (5,500 серверов) обеспечивает быструю доставку. Проверяйте через PageSpeed Insights -- целевой балл > 80.

## 9. Как настроить Schema.org для экскурсий?

Через Page Settings -> Advanced -> HTML Code for HEAD добавьте JSON-LD:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "TouristTrip",
  "name": "Desert Safari Dubai",
  "description": "6-hour desert adventure with BBQ dinner",
  "offers": {
    "@type": "Offer",
    "price": "180",
    "priceCurrency": "AED"
  },
  "provider": {
    "@type": "TravelAgency",
    "name": "Your Company",
    "addressCountry": "AE"
  }
}
</script>
```

Проверяйте через Google Rich Results Test. Для каждой страницы-экскурсии -- свой JSON-LD.

## 10. Можно ли интегрировать с Notion как CRM?

Да, через Make.com (рекомендуется) или Zapier:

1. Tilda форма -> Webhook -> Make.com
2. Make.com -> Notion: Create a Database Item
3. Маппинг полей: Name -> Имя, Phone -> Телефон, tour -> Экскурсия

Notion Database работает как простая CRM: статус лида (Новый/В работе/Оплачен/Завершён), фильтры, Kanban-вид.

Нативной интеграции Tilda-Notion нет -- только через автоматизаторы.

## 11. Как сделать калькулятор стоимости тура?

Через T123 блок с JavaScript. Создайте HTML-форму с полями (количество гостей, тип тура, трансфер) и JavaScript-функцию расчёта. Пример:

```javascript
function calculate() {
  var guests = document.getElementById('guests').value;
  var price = document.getElementById('tourType').value;
  var total = guests * price;
  document.getElementById('result').textContent = 'Итого: ' + total + ' AED';
}
```

Полный пример с select, checkbox и стилями -- в SKILL.md, раздел 9 "Кастомизация".

## 12. Tilda vs Shopify -- когда что использовать?

| Задача | Tilda | Shopify |
|--------|-------|---------|
| Лендинг экскурсии | Отлично | Избыточно |
| Каталог 10-50 туров | Хорошо | Хорошо |
| Полноценный магазин 500+ товаров | Ограниченно | Отлично |
| Инвентарь, складской учёт | Базовый | Полный |
| Подписки, recurring payments | Нет | Да |
| Скидки, купоны, распродажи | Базовые | Продвинутые |
| Мультивалютность | Ограниченная | Полная |
| SEO для лендингов | Хорошо | Средне |
| Стоимость | $15-25/мес | $29-299/мес |

**Tilda:** лендинги, каталоги, визитки, портфолио, сайты-каталоги до 50 товаров.
**Shopify:** полноценный e-commerce с инвентарём, скидками, доставкой, аналитикой продаж.
