### Шаг 2: ОЦЕНКА РИСКОВ

**Перед генерацией промта проверить:**

```
КРАСНЫЕ ФЛАГИ (предупредить пользователя):
- "Сделай моложе на 10 лет" → Риск: несоответствие реальности
- "Измени форму носа/лица" → Риск: потеря идентичности
- "Для паспорта" + ретушь → Риск: отказ в документе
- "Сделай худее/стройнее" → Риск: обман, дисморфия
- "Осветли кожу" → Риск: культурная нечувствительность

ЖЁЛТЫЕ ФЛАГИ (уточнить):
- Высокая интенсивность (>5/10) → Уточнить: для чего?
- Множественные изменения → Предложить: по одному
- Нет указания платформы → Рекомендовать: Gemini
- Детские фото → Использовать Children Safe (1/10 максимум!)
```

### Шаг 3: ГЕНЕРАЦИЯ ПРОМТА

**Структура каждого промта:**

```
=== AI PHOTO ENHANCEMENT REQUEST ===

[ACTION] — что делать
{Конкретное действие с параметрами}

[PROTECTION] — что НЕ менять (CRITICAL)
DO NOT MODIFY:
- Face shape and width - preserve exactly
- All facial proportions - nose, lips, eyes, jaw
- Skin texture - keep all natural pores visible
- Natural asymmetry - this is identity
- {Специфичные защиты для задачи}

[STYLE] — желаемый результат
Style: {описание}
NOT: {анти-референсы}

[FALLBACK] — если не получается
IF IN DOUBT: Preserve over enhance
WHEN UNCERTAIN: Do less, not more
If any change would alter recognition - skip that change entirely

=== END REQUEST ===
```

## 20 ЗОЛОТЫХ ПРАВИЛ

### Защита идентичности (1-5)

1. **Сначала защити - потом улучшай** — промт без защитных инструкций = риск потери идентичности
2. **Явный список неприкосновенного** — перечислить конкретно что НЕ менять
3. **Зеркальный тест** — "это я, только лучше", а не "красиво, но это не я"
4. **Сохраняй асимметрии** — асимметрия = часть идентичности
5. **Выражение лица священно** — микро-выражения не трогать

### Естественность (6-10)

6. **Кожа - не фарфор** — видимые поры = реалистичность
7. **Шкала 1-10, выбирай 3-4** — AI стремится к максимуму, указывай `intensity 3/10`
8. **Возрастная честность** — "хорошо для своего возраста", не "моложе"
9. **Соответствие контексту** — уровень обработки должен соответствовать окружению
10. **Правило одного взгляда** — если видно что "отфотошоплено" - провал

### Структура промта (11-15)

11. **ACTION -> PROTECTION -> STYLE** — правильный порядок определяет приоритеты
12. **Негативы с конкретикой** — `DO NOT: poreless skin, uniform tone, enlarged eyes`
13. **Измеримые цели** — `Fill shadows 30%, brighten eyes 15%`
14. **Fallback инструкции** — `IF IN DOUBT: preserve over enhance`
15. **Референсные точки** — "Like LinkedIn photo but warmer" понятнее чем "professional"

### Итеративность (16-20)

16. **Один промт = одно изменение** — множественные = потеря контроля
17. **От глобального к детальному** — свет -> цвет -> детали
18. **Знай когда остановиться** — если "исправляешь исправления" - стоп
19. **Сравнение с оригиналом** — после каждых 2-3 итераций A/B сравнение
20. **Документация изменений** — запись каждого шага позволяет откатить

### Формула безопасного промта

```
[Конкретное действие] + [параметр N%] +
[что сохранить] + [что НЕ делать] + [fallback]
```

**Пример:**
```

       preserve all skin texture and facial proportions,
       DO NOT smooth skin or change eye size,
       if any change affects face shape - skip it"
```

## TROUBLESHOOTING

> Полное руководство по решению проблем: см. `references/troubleshooting.md`

| Проблема | Решение в промте |
|----------|------------------|
| Лицо стало шире/уже | `maintain EXACT face width and proportions` |
| Пластиковая кожа | `preserve natural skin texture with ALL visible pores` |
| Глаза увеличились | `eye SIZE must remain 100% UNCHANGED` |
| Нос изменился | `nose shape, width, bridge - NO changes` |
| Мультяшный вид | Один change за промт, снизить интенсивность |
| Кожа осветлилась (bias) | Использовать Dark Skin Pro протокол |
| AI изменил что не просили | `ONLY modify: [X]. DO NOT touch: [всё остальное]` |

### Универсальный фикс

Добавь в конец любого проблемного промта:
```
CRITICAL REQUIREMENTS:
- Forensic-level preservation of facial structure
- No morphing, reshaping, or proportion changes
- Natural texture retention throughout
- Result indistinguishable from professional photo edit
- Zero tolerance for identity drift

If any requirement cannot be met - make NO changes.
```

### Когда отказаться от AI-редактирования

- Клиент хочет изменить костную структуру лица
- Каждая попытка меняет пропорции
- Задача требует изменения идентичности
- Для документов (паспорт/виза) нужна ретушь внешности

**Альтернативы:** Photoshop (больше контроля), работа только со светом/цветом, профессиональная пересъёмка.

## CHEATSHEET: БЫСТРАЯ ШПАРГАЛКА

> Полная шпаргалка: см. `references/cheatsheet.md`

### Универсальные защиты (копировать в каждый промт)
```
PRESERVE:
- Face shape and proportions - exactly
- Skin texture - all natural pores visible
- Eye size and shape - unchanged
- Natural asymmetry - this is identity

DO NOT:
- Reshape any facial features
- Smooth skin to poreless
- Enlarge or reshape eyes
- "Improve" bone structure
```

### Интенсивность по целям
| Цель | Интенсивность |
|------|---------------|
| Документы | 1/10 (только техническое) |
| Детские фото | 1/10 (минимум!) |
| CV/LinkedIn | 2-3/10 |
| Dating | 3/10 |
| Соцсети | 3-4/10 |
| Портфолио | 4-5/10 |
| Creative | 5+/10 |

### Красные флаги результата (немедленно отклонить)
- Кожа выглядит пластиковой
- Глаза неестественно яркие/большие
- Зубы ярче белка глаз
- Лицо симметричнее оригинала
- Выражение лица изменилось
- При первом взгляде видна обработка
- Кожа стала светлее (bias alert!)

### Зелёный свет (безопасно)
- Конкретные параметры: `by 10%`, `+0.5 stops`
- Световые методы: `add shadow`, `enhance highlight`
- Защитные слова: `preserve`, `maintain`, `keep`
- Ограничения: `subtle`, `gentle`, `maximum 5%`
- Негативные промты: `no morphing`, `no reshaping`
