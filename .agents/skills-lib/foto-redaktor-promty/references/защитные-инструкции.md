# Защитные инструкции для AI-редактирования фото

> Полная библиотека защитных блоков для предотвращения нежелательных изменений
> Включает базовые, усиленные и платформо-специфичные защиты

---

## Универсальный защитный блок (Master Protection)

Используй этот блок для максимальной защиты:

```
=== MASTER IDENTITY PROTECTION ===

FACIAL STRUCTURE (LOCKED - NO CHANGES):
- Face width and proportions
- Jawline shape and angle
- Cheekbone position
- Forehead shape
- All bone structure indicators

FEATURES (LOCKED - NO CHANGES):
- Eye size, shape, position, color
- Nose size, shape, width
- Lip size, shape, fullness
- Ear position and shape
- Hairline pattern

TEXTURE (MUST PRESERVE):
- Natural skin pores visible at 200% zoom
- Fine lines appropriate for age
- Natural skin variation
- Peach fuzz where naturally present

IDENTITY VERIFICATION:
- Person must be instantly recognizable
- Would pass family recognition test
- Identical to original except for requested change

IF ANY PROTECTION WOULD BE VIOLATED:
Do NOT make the change. Return original unchanged.

=== END MASTER PROTECTION ===
```

## 1. ЗАЩИТА ФОРМЫ ЛИЦА

### 1.1 Базовая защита формы лица

```
DO NOT CHANGE:
- Face shape or width
- Cheekbone structure
- Jaw line
- Chin shape
- Forehead size
```

### 1.2 Усиленная защита формы лица

```
CRITICAL - FACE STRUCTURE MUST REMAIN IDENTICAL:
- Face width and proportions: do not make narrower or wider
- Cheekbones: do not lift, lower, or reshape
- Jaw line: keep exact same shape and angle
- Chin: no reshaping, resizing, or projection changes
- Forehead: do not change size, shape, or proportions
- Distance between features: must stay exactly the same

Measure and verify: all proportions must match original
within pixel-level accuracy.
```

### 1.3 Защита для DALL-E (максимальная)

```
ABSOLUTE RESTRICTIONS - DALL-E SPECIFIC:
The face structure is LOCKED and cannot be modified in any way.

PIXEL-PERFECT REQUIREMENTS:
- Same face width (do not slim or widen by even 1%)
- Same cheekbone position and prominence
- Same jaw shape, angle, and definition
- Same chin projection and shape
- Same forehead proportions

WARNING: DALL-E tends to "beautify" by changing proportions.
This is EXPLICITLY FORBIDDEN for this image.

Measure these proportions before and after.
They MUST match EXACTLY.

If you cannot make the requested edit without altering
face structure, make NO changes at all.
```

### 1.4 Защита для специфических типов лица

**Круглое лицо:**
```
ROUND FACE PROTECTION:
This person has a naturally round face shape.
Round face is the CORRECT and DESIRED shape.

DO NOT:
- Slim or elongate face
- Narrow jawline
- Add V-line effect
- Apply any slimming

This is NOT a flaw to fix. This is identity.
```

**Квадратная челюсть:**
```
SQUARE JAW PROTECTION:
Preserve strong square jawline completely.
DO NOT soften, narrow, or round the jaw angles.
Square jaw is a feature, not a flaw.
```

**Широкий нос:**
```
WIDE NOSE PROTECTION:
Preserve original nose width exactly.
DO NOT narrow or refine nose shape.
This is the person's natural and real nose.
```

## 2. ЗАЩИТА ТЕКСТУРЫ КОЖИ

### 2.1 Базовая защита текстуры

```
DO NOT CHANGE:
- Skin texture: keep all natural pores visible
- Do NOT smooth or blur skin
- Do NOT apply beauty/softening filter
- Keep skin looking real, not plastic or CGI
```

### 2.2 Усиленная защита текстуры

```
SKIN TEXTURE PROTECTION (CRITICAL):
- ALL natural pores must remain visible at 200% zoom
- No smoothing algorithm of any kind
- No blur filter application
- No beauty mode effects
- No airbrushing simulation
- Skin should have natural variation and texture
- Must NOT look like beauty app filter
- Micro-texture must be preserved throughout

VERIFICATION: Zoom to 200%. If pores not visible, texture is lost.
```

### 2.3 Защита возрастных особенностей

```
PRESERVE AGE-APPROPRIATE FEATURES:
- Keep all wrinkles and expression lines
- Keep natural skin texture appropriate for age
- Keep any age spots or natural marks
- Do NOT make the person look younger

The goal is to look REFRESHED at current age,
not to reverse aging.

Wisdom lines are credibility, not flaws.
Expression lines show life and character.
```

### 2.4 Защита уникальных особенностей

```
UNIQUE FEATURES PROTECTION:
These are identity markers, NOT imperfections:
- Freckles: KEEP all of them
- Moles/beauty marks: KEEP every single one
- Birthmarks: KEEP
- Scars: KEEP (unless explicitly asked to remove)
- Dimples: KEEP
- Natural skin variations: KEEP

These make this person recognizable and unique.
```

## 3. ЗАЩИТА ГЛАЗ

### 3.1 Базовая защита глаз

```
DO NOT CHANGE:
- Eye size or shape
- Eye position or depth
- Pupil size
- Distance between eyes
- Iris color or pattern
```

### 3.2 Усиленная защита глаз

```
EYE STRUCTURE PROTECTION (CRITICAL):
- Eye SIZE: must remain EXACTLY the same (measure!)
- Eye SHAPE: no rounding, elongating, or any modification
- Eye POSITION: no moving up, down, or closer together
- Lid shape: keep natural eyelid crease exactly as is
- Pupil and iris size: unchanged from original
- Iris COLOR: exact same hue, do not shift
- Iris PATTERN: preserve all details and texture
- Sclera (whites): keep natural color, don't over-whiten
- Natural blood vessels: keep at least 30% visible

VERIFICATION: Overlay original and result at 50% opacity.
Eye contours must match exactly.
```

### 3.3 Защита от "кукольных глаз"

```
ANTI-DOLL EYE PROTECTION:
Result must NOT have:
- Unnaturally large eyes
- Perfectly white sclera (looks dead)
- Over-bright or glowing iris
- Uniform iris color without texture
- Multiple artificial catchlights
- "Alien" or "anime" appearance

Eyes should look HUMAN:
- Some blood vessels in whites
- Natural color variation in iris
- Appropriate brightness for lighting
- Single realistic catchlight
```

## 7. FALLBACK ИНСТРУКЦИИ

### 7.1 Fallback для глаз
```
If you cannot brighten the eyes without changing face shape,
only adjust overall image brightness.
```

### 7.2 Fallback для кожи
```
If you cannot even out skin tone without smoothing texture,
only adjust color balance globally.
```

### 7.3 Fallback для освещения
```
If lighting adjustment would change facial features,
only adjust global exposure without local changes.
```

### 7.4 Универсальный fallback
```
If any requested change would alter protected features
(face shape, skin texture, facial proportions, identity),
make NO changes to those areas.

Only proceed with changes that don't affect protected features.
```

### 7.5 Строгий fallback (когда критично)
```
If you cannot complete this edit while preserving all
protected features exactly, return the original image
unchanged and explain what couldn't be done safely.
```

### 7.6 Каскадный fallback
```
FALLBACK CASCADE:
1. Try full requested edit with all protections
2. If fails → reduce intensity by 50%
3. If still fails → only do safest part of request
4. If still fails → only adjust exposure/brightness
5. If still fails → return original unchanged

At each step, verify identity is preserved.
```
