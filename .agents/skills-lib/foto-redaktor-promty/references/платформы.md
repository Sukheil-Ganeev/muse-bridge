# Платформы AI: Специализация для портретной ретуши

> Подробные руководства по каждой из 10 платформ.
> Краткая таблица выбора — в SKILL.md.

---

## Gemini (Google)

**Лучше всего для:** CV, профессиональные фото, деликатная ретушь
**Сильные стороны:** Сохранение идентичности, понимание нюансов, естественность
**Слабые стороны:** Иногда делает больше чем просили, варьируется между сессиями

**Ключевые слова:** subtle, gentle, natural, precisely, maintain, preserve

**Специфичные tips:**
```
Добавлять в промт:
"Please follow these instructions precisely without
adding any additional changes or improvements."

"Make ONLY this single change: [request].
Do not make any other improvements, even if beneficial."
```

**Избегать:** perfect, beautiful, fix, enhance (без конкретики)

## DALL-E (OpenAI)

**Лучше всего для:** Замена фона, креативные задачи
**Сильные стороны:** Качество генерации, понимание инструкций
**ГЛАВНАЯ ПРОБЛЕМА:** Склонен изменять черты лица, особенно глаза!

**Обязательная защита для DALL-E:**
```
MANDATORY IDENTITY PRESERVATION:
- Eye SIZE must remain 100% UNCHANGED
- Eye SHAPE must remain 100% UNCHANGED
- Face proportions: PIXEL-PERFECT to original
- NO "improvements" to facial features

WARNING: Do not enlarge eyes under any circumstances.
Even 5% enlargement is unacceptable.
```

**Правило:** Занижайте интенсивность на 30-50% от желаемой!

## Midjourney

**Лучше всего для:** Художественные портреты, стилизация (когда изменения допустимы)
**НЕ подходит для:** Точная ретушь, сохранение идентичности

**Обязательные параметры:**
```
--style raw    (убирает художественную стилизацию)
--s 0          (минимум стилизации)
или --s 50     (приемлемо для ретуши)
```

**Ключевые фразы:**
```
same person, identical features, photorealistic,
no modification to face structure
```

**Главное правило:** Midjourney - это художник, не ретушёр. Используйте когда художественный результат важнее идентичности.

## Stable Diffusion

**Лучше всего для:** Приватность (локально), максимальный контроль, batch-обработка
**Требования:** GPU (минимум RTX 3060 12GB), техническая настройка

**Ключевые параметры для ретуши:**
```
Denoising Strength: 0.3-0.5 (не выше для сохранения идентичности)
CFG Scale: 5-7
Steps: 25-35
Model: Realistic Vision V6 или epiCRealism XL
```

**ControlNet для защиты структуры:**
- Canny - сохранение контуров
- OpenPose - сохранение позы
- IP-Adapter Face - сохранение идентичности (weight 0.7+)

**Негативный промт:**
```
(altered face:1.5), (changed proportions:1.4),
(modified bone structure:1.4), (different jawline:1.4),
(slimmed face:1.3), (morphed features:1.4),
plastic skin, smooth skin, airbrushed
```

## Flux (Black Forest Labs)

**Лучше всего для:** Кинематографическое качество, фотореализм высшего уровня
**Сильные стороны:** Превосходная детализация, реалистичная кожа, точный контроль
**Особенности:** Отличная работа с текстурами, естественные тени

**Ключевые параметры:**
```
- Flux.1 [pro] для максимального качества
- Flux.1 [dev] для баланса скорость/качество
- Guidance scale: 3.5-7 для ретуши
```

**Сильные стороны для портретов:**
- Превосходная работа со светом и тенью
- Естественные skin tones
- Сохранение мелких деталей (поры, волоски)

**Когда выбирать Flux:**
- Нужно кинематографическое качество
- Работа с освещением критична
- Требуется высокая детализация

## Leonardo AI

**Лучше всего для:** Быстрая генерация, стилизованные портреты
**Сильные стороны:** PhotoReal режим, Alchemy для улучшения
**Особенности:** Хороший баланс скорости и качества

**Ключевые режимы:**
```
- PhotoReal: максимальный реализм
- Alchemy: улучшенная обработка
- Image Guidance: контроль над результатом
```

**Для портретной ретуши:**
- Использовать PhotoReal с высоким fidelity
- Alchemy для постобработки
- Image-to-image для сохранения основы

**Ограничения:** Меньше контроля чем у SD, облачный сервис

---

## Ideogram

**Лучше всего для:** Типографика в изображениях, логотипы с текстом
**Сильные стороны:** ЛУЧШАЯ работа с текстом среди всех AI
**Для портретов:** Ограниченно, но хорошо для баннеров с текстом

**Когда использовать:**
- Нужен текст на изображении (имя, титул)
- Создание баннеров и обложек
- Промо-материалы с надписями

**Ограничения для портретов:** Не специализируется на ретуши

---

## Adobe Firefly

**Лучше всего для:** Коммерческое использование, этичный AI
**Сильные стороны:** Юридически чистый, интеграция с Adobe CC
**Особенности:** Обучен только на лицензированном контенте

**Преимущества:**
- Безопасно для коммерческого использования
- Интеграция с Photoshop, Lightroom
- Компенсация авторам исходных изображений

**Generative Fill:**
- Отличен для ретуши в контексте
- Хорошее сохранение стиля
- Встроен в Photoshop

**Когда выбирать:**
- Коммерческие проекты
- Корпоративное использование
- Нужна юридическая защита

---

## Runway ML

**Лучше всего для:** Видео из фото, анимация портретов
**Сильные стороны:** Gen-2, image-to-video, motion brush
**Особенности:** Лидер в видео генерации

**Для портретов:**
- Оживление статичных портретов
- Создание видео из headshot
- Talking head generation

**Gen-2 возможности:**
- Text-to-video
- Image-to-video (ваш портрет)
- Motion transfer

**Ограничения:** Не для статичной ретуши, фокус на видео

---

## GPT-4o Image (OpenAI)

**Лучше всего для:** Multi-turn редактирование, итеративная ретушь
**Сильные стороны:** Понимание контекста, диалоговое редактирование
**Особенности:** Встроен в ChatGPT

**Уникальные возможности:**
- Итеративные правки через диалог
- "Сделай немного меньше", "Верни как было"
- Понимание сложных инструкций на естественном языке

**Workflow:**
```
1. Загрузить фото
2. Описать что нужно
3. Увидеть результат
4. Корректировать через диалог
5. Повторять до идеала
```

**Преимущества:**
- Не нужно переписывать весь промт
- Можно уточнять постепенно
- Хорошо для обучения и экспериментов

**Ограничения:**
- Зависит от политик OpenAI
- Может отказать в некоторых редактированиях
