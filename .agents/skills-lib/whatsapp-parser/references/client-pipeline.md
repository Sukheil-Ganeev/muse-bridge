# Полный пайплайн обработки клиентского чата

**Источник:** SKILL.md, перенесено для экономии места

---

## Обзор

Когда требуется углубленная обработка отдельного клиента (как в кейсе "Фарход-Досье"), используется 8-этапный пайплайн: парсинг, транскрибация, исправление ошибок, пунктуация, объединение, анализ медиа, досье, экспорт.

---

## Этап 1: Парсинг чата

```python
# Извлечение сообщений из chat.txt
python parse_client_chat.py --jid 971XXXXXXXXX

# Результат: client_messages.json
```

## Этап 2: Транскрибация голосовых

**Основной инструмент: faster-whisper** (локальный, бесплатный, мультиязычный)

```python
from faster_whisper import WhisperModel

# GPU (если есть CUDA)
model = WhisperModel("large-v3", device="cuda", compute_type="float16")
# CPU fallback
model = WhisperModel("medium", device="cpu", compute_type="int8")

# Транскрипция с автодетектом языка
segments, info = model.transcribe(
    "voice.opus",
    beam_size=5,
    language=None,  # автодетект
    vad_filter=True,
    vad_parameters=dict(min_silence_duration_ms=500),
)
```

**Сервисы по языкам:**

| Язык | Сервис | Качество | Пунктуация |
|------|--------|----------|------------|
| Русский/Английский/Арабский | **faster-whisper** (large-v3) | Отлично (95%+) | Да, встроенная |
| Русский | Yandex SpeechKit | Отлично (95%+) | Нет (нужен DeepPavlov) |
| Английский/Арабский | Whisper (OpenAI) | Отлично | Да |

**Преимущество faster-whisper:** Работает локально, бесплатно, поддерживает все языки, возвращает текст С пунктуацией (в отличие от SpeechKit), checkpoint/resume при прерывании.

**Модели:**
- `large-v3` — максимальное качество (нужно ~6GB VRAM для GPU)
- `medium` — баланс качество/скорость (рекомендуется для CPU)
- `small` — быстрый, для массовых прогонов

**Скорость:** ~5-10x realtime на CPU (medium), ~30x на GPU (large-v3)

**Формат результата (JSONL):**
```json
{
  "filename": "101760_a387fa75.opus",
  "text": "Привет, Марсель! Как дела?",
  "text_original": null,
  "language": "ru",
  "language_probability": 0.98,
  "duration_seconds": 12.5,
  "segments": [{"start": 0.0, "end": 2.5, "text": "Привет, Марсель!"}],
  "model": "medium",
  "device": "cpu"
}
```

См. также: `/yandex-speechkit-туризм` (альтернатива для русскоязычных)

## Этап 3: Исправление ошибок распознавания

Yandex SpeechKit может некорректно распознавать:
- Имена собственные ("сухеля" -> "Сухейль")
- Топонимы ("дубай" -> "Дубай", "шарджа" -> "Шарджа")
- Специфические термины ("дихам" -> "дирхам", "сафар" -> "сафари")

```python
# Создание словаря исправлений
correction_dict = {
    "names": ["Сухейль", "Фарход", "Марсель"],
    "places": ["Дубай", "Абу-Даби", "Шарджа", "Фуджейра"],
    "business_terms": ["дирхам", "сафари", "трансфер", "экскурсия"]
}

# Применение исправлений
python apply_corrections.py \
    --input client_transcriptions.json \
    --dict correction_dictionary.json \
    --output client_transcriptions_corrected.json

# Результат: улучшенные транскрипции с сохранением оригиналов для аудита
```

**Статистика по кейсу "Фарход":**
- Исправлено: 657 из 2,105 транскрипций (31.2%)
- Категории: имена (11 вариантов), топонимы (8), термины (6)

## Этап 4: Добавление пунктуации

Yandex SpeechKit возвращает текст БЕЗ знаков препинания.

```python
# Восстановление пунктуации через DeepPavlov RuBERT
python add_punctuation.py --input client_transcriptions_corrected.json

# До:  привет сухейль как дела жду твоего ответа
# После: Привет, Сухейль! Как дела? Жду твоего ответа.

# Добавляется:
# - Запятые (перечисления, придаточные)
# - Точки (конец предложений)
# - Вопросительные/восклицательные знаки
# - Заглавные буквы (начало предложений, имена)
```

## Этап 5: Объединение данных

```python
# Слияние текстовых + транскрипций + пунктуация
python merge_chat_with_transcriptions.py \
    --messages client_messages.json \
    --transcriptions client_transcriptions_corrected.json \
    --output client_complete_chat.json

# Результат: полный чат с улучшенными транскрипциями
```

## Этап 6: Анализ медиафайлов

```python
# Статистика и классификация медиа
python analyze_media.py --chat-folder /path/to/client/chat/

# Результат:
# - Фото: количество, типы (скриншоты, паспорта, чеки)
# - Видео: количество, длительность
# - Документы: PDF, DOCX, XLSX
# - Локации: координаты из [ЛОКАЦИЯ]
```

**Опционально: OCR для медиа**

```python
# Распознавание текста на изображениях
python ocr_media.py --chat-folder /path/to/client/chat/

# Извлекает:
# - Чеки и скриншоты оплат (суммы, даты)
# - Паспортные данные (для виз)
# - Тексты бронирований
```

См. скилл: `/ocr-туризм`
