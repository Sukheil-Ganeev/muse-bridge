# P004: faster-whisper для коротких аудио

**Дата:** 2026-02-05
**Severity:** MEDIUM
**Проект:** MARSEL_BUSINESS (лимузинные партнёры)

## Характеристики

| Параметр | Значение |
|----------|----------|
| Библиотека | faster-whisper 1.2.1 |
| Модель | medium |
| Устройство | CPU |
| Скорость | ~90 сек на 10 сек аудио |

## Типичные ошибки

| Распознано | Правильно | Тип |
|-----------|-----------|-----|
| Сухие | Сухейль | Имя |
| TG | TJ | Аббревиатура |
| биктимеров | биг-таймеров | Сленг |

## Решение

Словарь исправлений + `text.replace()` после транскрипции.

```python
corrections = {"Сухие": "Сухейль", "TG": "TJ", "биктимеров": "биг-таймеров"}
for wrong, correct in corrections.items():
    text = text.replace(wrong, correct)
```

## Когда использовать

- **faster-whisper**: 1-5 коротких файлов, не критична точность имён
- **Yandex SpeechKit**: массовая транскрибация (100+), русский язык
