# W003: Большие чаты ломают general-purpose агентов

**Дата:** 2026-02-05
**Severity:** CRITICAL
**Проект:** MARSEL_BUSINESS (лимузинные партнёры)

## Проблема

general-purpose субагенты (Task tool) при чтении файлов >6000 строк падают с ошибкой "Prompt is too long". Контент чата загружается в контекст агента и превышает лимит.

## Когда возникает

| Чат | Строк | Сообщений | Результат |
|-----|-------|-----------|-----------|
| Raja personal | 6,790 | 3,001 | FAIL |
| Raja group | 3,713 | 1,829 | OK |
| TJ group | 11,109 | 6,186 | FAIL |

**Порог:** ~5,000 строк = зона риска, >6,000 = гарантированный FAIL.

## Решение

Использовать **Bash агент** с Python-скриптом вместо general-purpose:

```python
# Bash-агент запускает Python скрипт, который:
# 1. Читает файл порциями (не загружает в контекст)
# 2. Извлекает данные через regex
# 3. Сохраняет JSON результат
# 4. Возвращает только саммари

python extract_data.py --input chat.txt --output result.json
```

## Преимущества Bash-агента

- Python обрабатывает файл вне контекста агента
- Нет ограничения по размеру файла
- Результат — компактный JSON
- Агенту возвращается только саммари

## Ошибка при повторных запусках

Длительные агенты (>15 мин) могут упасть с "OAuth token revoked". Решение: включать полный скрипт в промпт, минимизировать количество итераций.
