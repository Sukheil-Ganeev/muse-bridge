# F001: Дубликаты в исходных данных (63%)

**Severity:** HIGH
**Дата:** 2026-02-05
**Источник:** Проект Туризм-ОАЭ

---

## Проблема

В исходном файле transcriptions_turbo.jsonl:
- Всего строк: 32,846
- Уникальных media_path: 12,068
- **Дубликатов: 20,778 (63%!)**

Причина: скрипт парсинга запускался несколько раз, результаты добавлялись вместо перезаписи.

## Симптомы

- Файл результатов в 3 раза больше ожидаемого
- Повторная обработка тех же данных
- Неверная статистика

## Решение

Перед обработкой загружать уже обработанные записи:

```python
# Загрузка уже обработанных
processed = set()
if os.path.exists(output_file):
    with open(output_file, 'r', encoding='utf-8') as f:
        for line in f:
            data = json.loads(line)
            key = (data['chat_folder'], data['media_path'])
            processed.add(key)

print(f"Уже обработано: {len(processed)} уникальных записей")

# При обработке
for record in records:
    key = (record['chat_folder'], record['media_path'])
    if key in processed:
        continue  # ПРОПУСТИТЬ дубликат
```

## Распределение дубликатов

| Количество повторов | Файлов | Процент |
|---------------------|--------|---------|
| 1 (уникальные) | 1,089 | 9% |
| 2 раза | 1,183 | 10% |
| 3 раза | 9,796 | **81%** |

> 81% аудиофайлов были записаны по 3 раза!
