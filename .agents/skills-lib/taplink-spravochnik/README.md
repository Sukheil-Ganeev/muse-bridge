# Taplink -- Справочник для туристического бизнеса ОАЭ

## Назначение

Production-ready справочник по платформе **Taplink** -- конструктору мультиссылок и мини-сайтов для Instagram Bio. Ориентирован на туристический бизнес в Дубае: экскурсии, билеты в парки, аренда яхт и автомобилей, трансферы.

## Когда активируется

- Создание или настройка Taplink-страницы
- Подключение форм, платежей, мессенджеров
- Настройка Webhooks и интеграций (Make.com, Zapier, Albato)
- Кастомизация HTML/CSS/JS
- Аналитика (GA4, Метрика, Facebook Pixel)
- Вопросы по тарифам и возможностям Taplink

## Быстрый старт

1. Определите тариф: **Business** для полного функционала (формы + платежи + домен)
2. Создайте страницу: аватар + описание + WhatsApp + услуги + форма
3. Подключите Stripe (AED) или ручную оплату (Сбер/Kaspi/USDT)
4. Настройте Webhook -> Make.com для уведомлений в Telegram
5. Добавьте GA4 + Facebook Pixel для аналитики
6. Опубликуйте и вставьте ссылку в Instagram Bio

## Ключевые ограничения Taplink

- **Нет REST API** -- только Webhooks (send-only, 2 события)
- **Нет мобильного приложения** -- управление через веб
- **11 языков** интерфейса, арабский НЕ поддерживается
- **Формы и платежи** -- только на тарифе Business
- **Webhook** требует HTTPS и валидный SSL
