## Ключевые факты и предупреждения

### Критические

- **Taplink НЕ имеет публичного REST API** -- только Webhooks (send-only, 2 события)
- **Timer, Forms, CRM** -- доступны только на тарифе **Business** (не Pro!)
- **Нет мобильного приложения** -- управление только через веб-интерфейс
- **11 языков** интерфейса -- арабский **НЕ поддерживается**
- **Webhook** требует HTTPS и валидный SSL-сертификат
- **60+ платёжных провайдеров**, комиссия Taplink -- **0%** (платишь только провайдеру)

### Тарифы (февраль 2026)

| Тариф | Квартальная | Эффективно/мес (год) |
|-------|:-----------:|:--------------------:|
| Basic | Бесплатно | $0 |
| Pro | ~$12/3мес | ~$2/мес |
| Business | $27/3мес | ~$4.50/мес |

Минимальный период оплаты -- 3 месяца. Скидки: 30% за 6 мес., 50% за 12 мес.

### Платежи в ОАЭ

- **Stripe** (2.9% + $0.30) -- рекомендуется для AED
- **PayPal** (3.4%) -- для международных клиентов
- **Ручные платежи** -- Сбер, Kaspi, USDT (через Custom Block с инструкциями)
- **Криптовалюта** -- через NOWPayments / CryptoCloud
