# Настройка Stripe для ОАЭ в Taplink -- Пошаговая инструкция

> **Для кого:** Владельцы Taplink-страниц на тарифе **Business**, принимающие оплату от международных клиентов в AED, USD и других валютах.

---

## Шаг 1: Создание Stripe-аккаунта

### 1.1 Регистрация

1. Перейдите на [stripe.com](https://stripe.com)
2. Нажмите **Start now**
3. Введите email и создайте пароль
4. Подтвердите email по ссылке из письма

### 1.2 Заполнение профиля компании (ОАЭ)

При первом входе Stripe попросит верификацию:

| Поле | Что указать |
|------|-------------|
| **Country** | United Arab Emirates |
| **Business type** | Individual / Sole proprietorship (если нет Trade License) или Company (если есть) |
| **Legal business name** | Название по Trade License (или ваше имя) |
| **Business address** | Адрес офиса: Tecom, Barsha Heights, Dubai, UAE |
| **Industry** | Travel & Tourism |
| **Business website** | URL вашего Taplink (taplink.cc/username или кастомный домен) |
| **Product description** | Tourism services: excursions, tickets, yacht rentals in Dubai and UAE |

### 1.3 Документы для верификации (ОАЭ)

Stripe в ОАЭ требует:

- **Emirates ID** (лицевая и обратная сторона)
- **Trade License** (если есть юрлицо)
- **Банковские реквизиты** (IBAN банковского счёта в ОАЭ)

> **Без Trade License:** Можно зарегистрироваться как Individual, но лимиты на оборот могут быть ниже. Рекомендуется получить freelance лицензию (например, через Tecom Free Zone).

### 1.4 Подключение банковского счёта

1. В Stripe Dashboard: **Settings** -> **Bank accounts and scheduling**
2. Добавьте счёт в ОАЭ:
   - **Bank name:** Emirates NBD / ADCB / Mashreq / RAKBank / другой
   - **IBAN:** AE07 0260 0010 XXXX XXXX XXX
   - **SWIFT/BIC:** EBILAEAD (для Emirates NBD)
   - **Currency:** AED
3. Stripe будет делать тестовый микроперевод (0.01 AED) для подтверждения

## Шаг 2: Настройка валюты AED

### 2.1 Основная валюта

1. В Stripe Dashboard: **Settings** -> **Business settings** -> **Currency**
2. Установите **AED** (United Arab Emirates Dirham) как основную валюту
3. Это определяет валюту отображения в дашборде

### 2.2 Мультивалютность

Stripe автоматически поддерживает приём платежей в 135+ валютах. Клиент может платить в:
- **AED** -- для локальных клиентов
- **USD** -- для международных
- **EUR, GBP, RUB** -- конвертация автоматическая

Stripe конвертирует все платежи в вашу основную валюту (AED) при выводе на банковский счёт.

### 2.3 Комиссии Stripe для ОАЭ

| Тип карты | Комиссия |
|-----------|----------|
| Карты ОАЭ | 2.75% + 1.00 AED |
| Международные карты | 3.25% + 1.00 AED |
| Конвертация валют | +2% |

> **Пример:** Экскурсия 250 AED, оплата международной картой:
> Комиссия = 250 * 3.25% + 1.00 = 9.13 AED
> Вы получите: ~240.87 AED

## Шаг 3: Подключение Stripe к Taplink

### 3.1 Получение API-ключей

1. В Stripe Dashboard: **Developers** -> **API keys**
2. Скопируйте:
   - **Publishable key:** `pk_live_XXXX...` (публичный)
   - **Secret key:** `sk_live_XXXX...` (секретный, НЕ показывайте никому!)

### 3.2 Настройка в Taplink

1. Войдите в Taplink
2. Перейдите в **Настройки** -> **Приём платежей** -> **Подключить платёжную систему**
3. Выберите **Stripe**
4. Вставьте:
   - **Publishable key:** pk_live_XXXX...
   - **Secret key:** sk_live_XXXX...
5. Нажмите **Сохранить**
6. Статус должен стать **Подключено** (зелёный индикатор)

### 3.3 Настройка цены на товаре/услуге

1. Откройте блок **Form and Payments** (или товар в магазине)
2. Укажите цену: `150` (без валюты)
3. Валюта определяется настройками Stripe (AED)
4. Включите переключатель "Принимать оплату"

## Шаг 4: Тестовый платёж

### 4.1 Переключение в тестовый режим

1. В Stripe Dashboard: переключите тумблер **Test mode** (справа вверху)
2. Скопируйте **тестовые** ключи:
   - `pk_test_XXXX...`
   - `sk_test_XXXX...`
3. Временно вставьте тестовые ключи в Taplink (вместо боевых)

### 4.2 Тестовые карты Stripe

| Номер карты | Описание |
|-------------|----------|
| `4242 4242 4242 4242` | Успешный платёж (Visa) |
| `5555 5555 5555 4444` | Успешный платёж (Mastercard) |
| `4000 0000 0000 0002` | Отклонённый платёж |
| `4000 0000 0000 3220` | Требуется 3D Secure |

- **Срок действия:** любая будущая дата (например, 12/30)
- **CVC:** любые 3 цифры (например, 123)

### 4.3 Проведение тестового платежа

1. Откройте вашу Taplink-страницу
2. Выберите товар/услугу с ценой
3. Заполните форму
4. На этапе оплаты введите тестовую карту `4242 4242 4242 4242`
5. Нажмите "Оплатить"
6. Проверьте:
   - В Stripe Dashboard (Test mode): появился платёж
   - В Taplink CRM: заявка со статусом "Оплачено"
   - В Telegram (если настроен webhook): уведомление о платеже

### 4.4 Возврат к боевому режиму

1. В Taplink замените тестовые ключи обратно на боевые (`pk_live_...`, `sk_live_...`)
2. В Stripe Dashboard отключите Test mode
3. Готово к приёму реальных платежей

## Шаг 5: Дополнительные настройки

### 5.1 Автоматические чеки (receipts)

1. Stripe Dashboard: **Settings** -> **Customer emails**
2. Включите **Successful payments** -- клиент получит email-чек автоматически
3. Настройте логотип и название компании в **Branding**

### 5.2 Настройка брендинга оплаты

1. Stripe Dashboard: **Settings** -> **Branding**
2. Загрузите:
   - **Logo:** логотип компании (для страницы оплаты и чеков)
   - **Icon:** маленькая иконка (для вкладки браузера)
   - **Brand color:** #D4A056 (или ваш фирменный цвет)
3. Это отобразится на странице оплаты Stripe Checkout

### 5.3 Выплаты на банковский счёт

1. Stripe Dashboard: **Settings** -> **Bank accounts and scheduling**
2. Настройте расписание выплат:
   - **Daily (Ежедневно):** деньги приходят каждый день (T+2 рабочих дня)
   - **Weekly (Еженедельно):** раз в неделю
   - **Monthly (Ежемесячно):** раз в месяц
3. Рекомендация для туризма: **Daily** -- деньги нужны для операционных расходов

### 5.4 Уведомления о платежах

Через Taplink Webhook (если настроен):
- Событие `payments.created` срабатывает при каждом платеже
- Данные включают: сумму, валюту, данные клиента

## Частые проблемы

### Stripe не принимает регистрацию из ОАЭ

Stripe полностью доступен в ОАЭ. Убедитесь, что:
- Выбрана страна **United Arab Emirates** при регистрации
- Указан корректный Emirates ID
- Банковский счёт в ОАЭ (не в другой стране)

### Платёж проходит в Stripe, но Taplink не видит

- Проверьте, что используете **боевые** ключи (не тестовые)
- Убедитесь, что Publishable и Secret key от одного аккаунта
- Проверьте статус подключения в Taplink: Настройки -> Приём платежей

### Клиент видит цену в USD, а не в AED

- Валюта определяется настройками Stripe, не Taplink
- Проверьте основную валюту в Stripe Dashboard
- Если товар создан до смены валюты — пересоздайте его

### Выплаты не приходят на банковский счёт

- Первая выплата может занять 7-14 дней (верификация)
- Проверьте статус верификации в Stripe Dashboard
- Убедитесь, что IBAN введён корректно
