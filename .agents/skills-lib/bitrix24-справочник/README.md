# Битрикс24 -- Справочник (Скилл)

## Описание

Production-ready справочник по платформе Битрикс24 для туристического бизнеса в ОАЭ. Содержит 14 разделов: от обзора платформы и тарифов до конкретных сценариев автоматизации бронирований.

## Структура

```
bitrix24-справочник/
├── SKILL.md                  # Главный файл (~5000 слов), все 14 разделов
├── README.md                 # Этот файл
├── references/
│   ├── faq.md                # 25+ частых вопросов с ответами
│   ├── troubleshooting.md    # Типичные проблемы и решения
│   ├── cheatsheet.md         # Шпаргалка: API, лимиты, горячие клавиши
│   ├── crm-guide.md          # Детальный гайд по CRM
│   ├── automation-guide.md   # Роботы, триггеры, бизнес-процессы
│   ├── api-reference.md      # REST API, примеры вызовов
│   ├── contact-center.md     # Подключение мессенджеров, телефония
│   └── tourism-scenarios.md  # Сценарии для туризма ОАЭ
└── experience/
    ├── _index.md             # Критические уроки проекта
    ├── fixes/
    ├── improvements/
    ├── patterns/
    └── warnings/
```

## Как использовать

1. **SKILL.md** -- основной файл, содержит ключевую информацию по всем 14 разделам
2. **references/** -- детальные справочники по отдельным темам
3. **experience/** -- накопленный опыт работы со скиллом

## Проектная папка

Полная версия справочника с подробными файлами по каждому разделу:
`D:/Downloads/BITRIX24_СПРАВОЧНИК/`
