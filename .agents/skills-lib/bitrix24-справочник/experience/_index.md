# Битрикс24 Справочник — Критические уроки

## Топ-5 критических уроков

### 1. Тарифы меняются часто
Битрикс24 регулярно обновляет тарифную сетку. При каждом использовании справочника проверяй актуальность через bitrix24.ru/prices/

### 2. Open Channels — ключевой модуль для туризма
Подключение Telegram и WhatsApp через Open Channels — основной канал коммуникации с туристами из СНГ. Настройка требует внимания к маршрутизации.

### 3. CoPilot AI развивается быстро
Функции CoPilot расширяются каждый квартал. Проверяй helpdesk.bitrix24.ru для актуальных возможностей.

### 4. REST API имеет rate limits
Лимиты зависят от тарифа. При интеграции через вебхуки учитывай ограничения.

### 5. Облако vs Коробка — разные функции
Не все модули доступны в обеих версиях. Конструктор сайтов, маркетинг, некоторые интеграции отличаются.
