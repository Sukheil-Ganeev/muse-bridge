# Шаблон: Подключение мессенджеров через Open Channels

ДАННЫЕ АКТУАЛЬНЫ НА: 2026-02-16

## Назначение

Пошаговое подключение Telegram, WhatsApp и других мессенджеров к Битрикс24 через Open Channels (Открытые линии). Настройка маршрутизации обращений, автоответов и рабочего времени.

**Лимиты Open Channels:** Бесплатный -- 1 линия, Базовый -- 2, Стандартный и выше -- без ограничений.

---

## Пошаговая инструкция

### Часть 1. Подключение Telegram

**Стоимость:** Бесплатно.
**Что нужно:** аккаунт Telegram.

#### Шаг 1. Создание бота в Telegram

1. Откройте Telegram, найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Укажите **имя бота** (отображаемое): например, `Dubai Tours - Сухейль`
4. Укажите **username бота**: например, `dubai_tours_suheyl_bot` (должен заканчиваться на `_bot`)
5. **Скопируйте токен** бота (строка вида `7123456789:AAF...`)

**Дополнительные настройки бота (через @BotFather):**
```
/setdescription - описание бота (видно при первом открытии)
/setabouttext - "О боте" (короткий текст)
/setuserpic - фото бота (логотип компании)
```

#### Шаг 2. Подключение бота к Битрикс24

1. В Битрикс24 перейдите: **Контакт-центр > Telegram**
2. Нажмите **"Подключить"**
3. Вставьте **токен бота** из BotFather
4. Выберите **Открытую линию** (или создайте новую)
5. Нажмите **"Подключить"**
6. Проверьте: отправьте тестовое сообщение боту в Telegram -- оно должно появиться в Битрикс24

#### Шаг 3. Настройка Открытой линии для Telegram

Путь: **Контакт-центр > Открытые линии > [ваша линия] > Настройки**

| Параметр | Рекомендуемое значение |
|----------|----------------------|
| Название линии | "Экскурсии Telegram" |
| Очередь операторов | Сухейль, Менеджер 1, Менеджер 2 |
| Распределение | Строго по очереди (или равномерно) |
| Рабочее время | 08:00 - 22:00 (Dubai, GMT+4) |
| Создавать лид | Да, при первом обращении |
| Источник лида | TELEGRAM |

### Часть 2. Подключение WhatsApp

**Стоимость:** от 800 руб./мес (через Wazzup).
**Что нужно:** номер WhatsApp, аккаунт Wazzup.

#### Почему через провайдера

Битрикс24 не имеет встроенной интеграции с WhatsApp. Нужен провайдер-посредник.

#### Основные провайдеры

| Провайдер | Стоимость | Особенности |
|-----------|-----------|-------------|
| **Wazzup** | от 800 руб./мес (Start) | Самый популярный в РФ/СНГ, простой |
| Edna | Индивидуально | Официальный WhatsApp Business API |
| ChatApp | от 990 руб./мес | Простая настройка |
| Umnico | от 1 500 руб./мес | Мультиканальная платформа |
| Twilio | $0.005/сообщение | Международный |
| Cloud API (Meta) | Бесплатно (первые 1000 сообщений) | Требует верификации бизнеса |

#### Подключение через Wazzup (рекомендуемый способ)

**Шаг 1. Регистрация в Wazzup**
1. Перейдите на **wazzup24.ru**
2. Зарегистрируйтесь (email + пароль)
3. Выберите тариф **Start** (от 800 руб./мес)

**Шаг 2. Подключение WhatsApp-номера**
1. В личном кабинете Wazzup нажмите **"Добавить канал" > WhatsApp**
2. Выберите тип: **WhatsApp Web** (сканирование QR)
3. Откройте WhatsApp на телефоне > Настройки > Связанные устройства
4. **Отсканируйте QR-код** с экрана Wazzup
5. Дождитесь синхронизации (1-2 минуты)

**Шаг 3. Установка приложения Wazzup в Битрикс24**
1. В Битрикс24 перейдите: **Маркетплейс > Поиск > "Wazzup"**
2. Установите приложение **Wazzup24**
3. Авторизуйтесь в Wazzup из Битрикс24

**Шаг 4. Настройка канала**
1. В настройках Wazzup привяжите WhatsApp-канал к **Открытой линии** Битрикс24
2. Выберите линию (или создайте новую: "WhatsApp")
3. Настройте очередь операторов
4. Проверьте: отправьте тестовое сообщение на подключенный номер WhatsApp

### Часть 3. Подключение Instagram Direct

**Стоимость:** Бесплатно.
**Что нужно:** бизнес-аккаунт Instagram + привязка к Facebook Page.

#### Шаги

1. Убедитесь, что у вас **бизнес-аккаунт** Instagram (не личный)
2. Instagram привязан к **публичной Facebook-странице**
3. В Битрикс24: **Контакт-центр > Instagram > Подключить**
4. Авторизуйтесь через Facebook
5. Выберите Instagram-аккаунт и Facebook-страницу
6. Привяжите к Открытой линии
7. Проверьте: отправьте Direct-сообщение на Instagram -- оно должно появиться в Битрикс24

---

### Часть 4. Настройка маршрутизации

#### Кто отвечает за какой канал

| Канал | Открытая линия | Очередь операторов | Приоритет |
|-------|---------------|-------------------|-----------|
| Telegram (экскурсии) | "Экскурсии TG" | Сухейль, Менеджер 1 | 1 |
| WhatsApp (общий) | "WhatsApp" | Сухейль, Марсель, Муфамад | По очереди |
| Instagram | "Instagram" | Менеджер SMM, Сухейль | 2 |

#### Способы распределения

Путь: **Контакт-центр > Открытые линии > [линия] > Очередь**

| Способ | Описание | Когда использовать |
|--------|----------|--------------------|
| **Равномерно** | Каждому оператору одинаковое количество | Несколько менеджеров одного направления |
| **Строго по очереди** | Первый свободный оператор | Общий канал (WhatsApp) |
| **Одновременно всем** | Уведомление всем, кто первый ответил | Срочные обращения |

#### Проверка доступности оператора

| Параметр | Настройка |
|----------|-----------|
| Рабочее время | 08:00 - 22:00 (Dubai, GMT+4) |
| Проверять онлайн-статус | Да |
| Если нет свободных | Перенаправить следующему в очереди |
| Если никто не ответил за N мин | Уведомить руководителя |
| Время ожидания (мин) | 5 минут |

### Часть 5. Настройка автоответов

Путь: **Контакт-центр > Открытые линии > [линия] > Автоматические действия**

#### Приветственное сообщение

| Параметр | Значение |
|----------|----------|
| Включено | Да |
| Когда | При первом обращении клиента |
| Текст (RU) | "Здравствуйте! Спасибо за обращение. Чем могу помочь? Менеджер ответит в течение нескольких минут." |
| Текст (EN) | "Hello! Thank you for contacting us. How can I help you? A manager will respond shortly." |

#### Сообщение при отсутствии операторов

| Параметр | Значение |
|----------|----------|
| Включено | Да |
| Когда | Нерабочее время или все операторы офлайн |
| Текст (RU) | "Спасибо за обращение! Сейчас нерабочее время (мы работаем с 08:00 до 22:00, Dubai). Мы ответим вам утром. Если срочно -- позвоните: +971 XX XXX XXXX" |
| Текст (EN) | "Thank you for reaching out! Our working hours are 8 AM to 10 PM (Dubai time). We'll get back to you soon." |

#### Быстрые ответы (шаблоны для менеджеров)

Путь: **Контакт-центр > Открытые линии > [линия] > Быстрые ответы**

| Название шаблона | Текст |
|-----------------|-------|
| Приветствие | "Здравствуйте, {Имя}! Спасибо за обращение. Чем могу помочь?" |
| Прайс экскурсий | "Отправляю наш актуальный прайс на экскурсии: [ссылка]" |
| Подтверждение | "Ваше бронирование подтверждено! Детали:\n- Дата: {дата}\n- Время: {время}\n- Место сбора: {место}" |
| Напоминание 24ч | "Напоминаем: завтра ваша экскурсия '{название}'. Сбор в {время} у {место}." |
| Реквизиты AED | "Реквизиты для оплаты в AED:\n[банковские реквизиты]" |
| Реквизиты Kaspi | "Для оплаты через Kaspi:\n[номер Kaspi]" |
| Реквизиты Сбер | "Для перевода на Сбер:\n[номер карты]" |
| Благодарность | "Спасибо за выбор наших услуг! Будем рады видеть вас снова в Дубае!" |
| Запрос отзыва | "Как прошла экскурсия? Будем благодарны за отзыв: [ссылка]" |

### Часть 6. Настройка рабочего времени

Путь: **Контакт-центр > Открытые линии > [линия] > Рабочее время**

| Параметр | Значение |
|----------|----------|
| Часовой пояс | Asia/Dubai (GMT+4) |
| Рабочие дни | Понедельник -- Воскресенье (без выходных, туризм!) |
| Рабочие часы | 08:00 - 22:00 |
| Праздники | Нет (работаем в праздники) |
| Поведение в нерабочее время | Показать сообщение "Нерабочее время" + принять обращение в очередь |

---

### Часть 7. Создание лидов из обращений

Путь: **Контакт-центр > Открытые линии > [линия] > CRM**

| Параметр | Значение |
|----------|----------|
| Создавать лид | Да |
| Когда | При первом обращении (если клиент не найден в CRM) |
| Источник | По каналу (TELEGRAM / WHATSAPP / INSTAGRAM) |
| Ответственный по умолчанию | По очереди операторов |
| Привязка к существующему | Автоматическая (по номеру телефона / username) |

## Примеры

### Пример: путь обращения через Telegram

```
1. Клиент находит бота @dubai_tours_suheyl_bot в Telegram
2. Отправляет: "Привет, хочу на desert safari"
3. Битрикс24 получает сообщение через Open Channel
4. Автоответ: "Здравствуйте! Спасибо за обращение..."
5. Создается лид (источник: TELEGRAM)
6. Сообщение появляется у Сухейля в чате Битрикс24
7. Сухейль отвечает прямо из Битрикс24 -- клиент получает ответ в Telegram
8. Вся переписка сохраняется в карточке CRM
```

### Пример: настройка нескольких ботов для разных направлений

```
Бот 1: @dubai_tours_bot     -> Линия "Экскурсии"  -> Сухейль
Бот 2: @dubai_cars_bot      -> Линия "Авто"       -> Марсель
Бот 3: @paramount_yachts_bot -> Линия "Яхты"       -> Муфамад
```

Каждый бот привязан к своей Открытой линии с отдельной очередью операторов.
