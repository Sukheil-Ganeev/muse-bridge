# Шаблон: Настройка CRM для турагентства

ДАННЫЕ АКТУАЛЬНЫ НА: 2026-02-16

## Назначение

Пошаговая настройка CRM Битрикс24 для туристического агентства в ОАЭ. Включает структуру воронок продаж, пользовательские поля, настройку карточек лида и сделки, режим работы CRM.

---

## Пошаговая инструкция

### Шаг 1. Выбор режима CRM

Путь: **CRM > Еще > Настройки > Режим работы CRM**

| Режим | Когда выбирать |
|-------|----------------|
| **Классический (с лидами)** | Более 20 обращений в день, нужна фильтрация (рекомендуется) |
| **Простой (без лидов)** | Менее 10 обращений, каждый контакт = клиент |

**Рекомендация для турагентства:** Классический режим. Много обращений из WhatsApp и Telegram -- не все конвертируются в продажу.

---

### Шаг 2. Создание воронок продаж

Путь: **CRM > Сделки > Еще > Настройки > Настройки CRM > Воронки продаж**

#### Воронка 1: Экскурсии

| # | Стадия | Цвет | Роботы |
|---|--------|------|--------|
| 1 | Новая заявка | Голубой | Автоответ клиенту + уведомление менеджеру |
| 2 | Консультация | Синий | Задача менеджеру "Связаться" (15 мин) |
| 3 | Подтверждение | Оранжевый | Задача гиду + задача водителю (если трансфер) |
| 4 | Оплата | Желтый | Отправка реквизитов клиенту |
| 5 | Проведена | Зеленый | Закрытие задач |
| 6 | Отзыв | Светло-зеленый | Follow-up через 2 дня |
| OK | Успешная сделка | Зеленый (финал) | -- |
| FAIL | Провалена | Красный (финал) | -- |

#### Воронка 2: Билеты в парки

| # | Стадия | Описание |
|---|--------|----------|
| 1 | Запрос | Клиент интересуется билетом |
| 2 | Подбор | Менеджер подбирает билеты и цену |
| 3 | Оплата | Ожидание оплаты |
| 4 | Отправка билета | Отправить e-ticket в WhatsApp/Telegram |
| 5 | Завершено | Билет доставлен |
| OK | Успешная сделка | -- |
| FAIL | Провалена | -- |

#### Воронка 3: Аренда яхт

| # | Стадия | Описание |
|---|--------|----------|
| 1 | Запрос | Клиент описывает пожелания |
| 2 | Подбор яхты | Подбор из каталога (300+ яхт) |
| 3 | Согласование | Согласование стоимости, маршрута, кейтеринга |

| 6 | Закрыто | Follow-up и отзыв |
| OK | Успешная сделка | -- |

| # | Стадия | Описание |

| Язык обслуживания | UF_CRM_LANGUAGE | Список | Да | Русский, English, Arabic |
| Трансфер нужен | UF_CRM_TRANSFER | Да/Нет | Нет | Да |

| Статус оплаты | UF_CRM_PAYMENT_STATUS | Список | Нет | Не оплачено, Частично, Полностью |

### Шаг 4. Настройка карточки сделки

1. Откройте любую сделку в нужной воронке
2. Нажмите **"Настроить карточку"** (значок шестеренки вверху)
3. Создайте секции и перетащите поля:

**Секция "Клиент":**
- Контакт, Телефон, Email, Мессенджер, Отель

**Секция "Детали заказа":**
- Дата тура, Количество гостей, Язык, Тип экскурсии, Трансфер, Особые пожелания

**Секция "Оплата":**
- Сумма, Валюта, Тип оплаты, Статус оплаты

**Секция "Исполнение":**
- Ответственный, Гид, Место сбора, Время сбора, Номер бронирования

---

### Шаг 5. Настройка валют

Путь: **CRM > Еще > Настройки > Валюта**

| Валюта | Код | Базовая |
|--------|-----|---------|
| Дирхам ОАЭ | AED | Да (основная) |
| Доллар США | USD | Нет |
| Российский рубль | RUB | Нет |
| Казахский тенге | KZT | Нет |

**Курс AED к USD:** фиксированный -- 1 USD = 3.6725 AED.

---
