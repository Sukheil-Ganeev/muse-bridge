# Шаблон: Роботы Битрикс24 для турагентства

ДАННЫЕ АКТУАЛЬНЫ НА: 2026-02-16

## Назначение

Готовые шаблоны роботов для автоматизации CRM в туристическом бизнесе. Каждый робот описан с пошаговой настройкой: привязка к стадии, условия, действия.

**Доступность:** Бесплатный тариф -- до 5 роботов/триггеров. Базовый и выше -- без ограничений.

---

## Пошаговая инструкция

### Общий порядок создания робота

1. Перейдите: **CRM > Сделки > (выберите воронку)**
2. Нажмите **"Роботы"** (кнопка вверху справа)
3. Выберите **стадию**, на которую хотите добавить робота
4. Нажмите **"+"** > выберите тип робота
5. Настройте параметры
6. Нажмите **"Сохранить"**

---

## Робот 1: Авто-ответ при новом лиде

**Воронка:** Любая
**Стадия:** Новая заявка
**Цель:** Клиент моментально получает подтверждение, что его заявка принята.

### Настройка

**Робот 1.1 -- Уведомление менеджеру:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Коммуникация > Уведомить в чат |
| Стадия | Новая заявка |
| Время | Немедленно |
| Получатель | Ответственный менеджер |
| Текст | "Новая заявка! {Название сделки}, клиент: {Имя контакта}, тел: {Телефон}" |

**Робот 1.2 -- Автоответ клиенту:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Коммуникация > Отправить сообщение клиенту |
| Стадия | Новая заявка |
| Время | Немедленно |
| Канал | Через Open Channel (WhatsApp/Telegram) |
| Текст | "Здравствуйте, {Имя}! Спасибо за обращение. Менеджер свяжется с вами в течение 15 минут." |

**Робот 1.3 -- Задача менеджеру:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Задачи > Создать задачу |
| Стадия | Новая заявка |
| Время | Немедленно |
| Название задачи | "Связаться с клиентом: {Имя контакта}" |
| Ответственный | Ответственный за сделку |
| Крайний срок | Через 15 минут |
| Описание | "Клиент: {Имя контакта}\nТелефон: {Телефон}\nМессенджер: {Мессенджер}\nОтель: {Отель}\nЗапрос: {Комментарий}" |

## Робот 2: Напоминание менеджеру через 24 часа

**Воронка:** Любая
**Стадия:** Новая заявка
**Цель:** Если менеджер не перевел сделку на следующую стадию за 24 часа -- эскалация.

### Настройка

**Робот 2.1 -- Ожидание:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Контроль > Ожидание |
| Стадия | Новая заявка |
| Время | 24 часа |

**Робот 2.2 -- Уведомление менеджеру:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Коммуникация > Уведомить в чат |
| Стадия | Новая заявка |
| Время | После робота 2.1 |
| Получатель | Ответственный менеджер |
| Текст | "ВНИМАНИЕ! Сделка '{Название сделки}' без реакции более 24 часов. Свяжитесь с клиентом!" |

**Робот 2.3 -- Уведомление руководителю (через 48ч):**
| Параметр | Значение |
|----------|----------|
| Тип робота | Контроль > Ожидание (ещё 24 часа) + Уведомить в чат |
| Стадия | Новая заявка |
| Время | После робота 2.2, ещё 24 часа |
| Получатель | Руководитель отдела |
| Текст | "Сделка '{Название сделки}' без реакции более 48 часов! Менеджер: {Ответственный}" |

## Робот 3: Перевод сделки на следующую стадию

**Воронка:** Экскурсии / Билеты
**Стадия:** Оплата
**Цель:** Автоматически переместить сделку на стадию "Проведена" / "Отправка билета" после оплаты.

### Настройка (через триггер + робот)

**Триггер:**
| Параметр | Значение |
|----------|----------|
| Тип | Триггер > Изменение поля |
| Отслеживаемое поле | Статус оплаты (UF_CRM_PAYMENT_STATUS) |
| Значение | "Полностью" |
| Перевести на стадию | Проведена (или "Отправка билета") |

**Робот на стадии "Проведена":**
| Параметр | Значение |
|----------|----------|
| Тип робота | Управление элементом > Изменить элемент |
| Стадия | Проведена |
| Время | Немедленно |
| Действие | Изменить поле "Комментарий" -> "Оплата подтверждена, тур/билет активирован" |

**Робот -- Задача на подготовку:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Задачи > Создать задачу |
| Стадия | Проведена |
| Время | Немедленно |
| Название задачи | "Подготовить тур: {Название сделки}" |
| Ответственный | Гид (из поля UF_CRM_GUIDE) |
| Описание | "Дата: {Дата тура}\nГости: {Количество}\nОтель: {Отель}\nЯзык: {Язык}\nТрансфер: {Трансфер}" |

**Стадия:** Оплата (после срабатывания триггера)

|----------|----------|
| Тип робота | Коммуникация > Уведомить в чат |
| Стадия | Оплата (после перехода сюда) |
| Время | Немедленно |
| Получатель | Групповой чат "Оплаты" (или конкретные сотрудники) |
| Текст | "Оплата получена! Сделка: {Название}\nСумма: {Сумма} {Валюта}\nКлиент: {Имя контакта}\nТип оплаты: {Тип оплаты}" |

**Робот 4.2 -- Уведомление клиенту:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Коммуникация > Отправить сообщение клиенту |
| Стадия | Оплата |
| Время | Немедленно |
| Текст | "Оплата получена! Спасибо. Ваше бронирование {Номер бронирования} подтверждено. Детали экскурсии пришлем за 24 часа до даты." |

## Робот 5: Напоминание клиенту за 24 часа до тура

**Воронка:** Экскурсии
**Стадия:** Подтверждение / Подготовка
**Цель:** Клиент получает напоминание с деталями за сутки до экскурсии.

### Настройка

**Робот 5.1 -- Ожидание до даты тура:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Контроль > Ожидание |
| Стадия | Подтверждение |
| Время | До значения поля "Дата тура" минус 1 день |

**Робот 5.2 -- Сообщение клиенту:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Коммуникация > Отправить сообщение клиенту |
| Стадия | Подтверждение |
| Время | После робота 5.1 |
| Текст | "Здравствуйте, {Имя}! Напоминаем: завтра ваша экскурсия '{Тип экскурсии}'.\n\nДата: {Дата тура}\nВремя сбора: {Время сбора}\nМесто: {Место сбора}\nГостей: {Количество}\n\nДо встречи!" |

**Воронка:** Любая
**Стадия:** Успешная сделка (финальная)
**Цель:** Через 30 дней предложить повторный тур.

### Настройка

| Параметр | Значение |
|----------|----------|
| Тип робота | Контроль > Ожидание |
| Стадия | Успешная сделка |
| Время | 30 дней |

**Робот 7.2 -- Создать повторную сделку:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Управление элементом > Создать элемент CRM > Сделка |
| Стадия | Успешная сделка |
| Время | После робота 7.1 |
| Название | "Повторное предложение: {Имя контакта}" |
| Контакт | {Контакт из текущей сделки} |
| Ответственный | {Ответственный из текущей сделки} |

**Робот 7.3 -- Уведомить менеджера:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Коммуникация > Уведомить в чат |
| Время | После робота 7.2 |

## Робот 8: VIP-обработка (сумма > $500)

**Воронка:** Любая
**Стадия:** Новая заявка
**Цель:** Автоматический приоритет и уведомление руководителя для крупных сделок.

### Настройка

**Условие:** Сумма сделки > 500 (в поле OPPORTUNITY)

**Робот 8.1 -- Изменить приоритет:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Управление элементом > Изменить элемент |
| Условие | Сумма > 500 |
| Действие | Изменить поле "Комментарий" -> "VIP-КЛИЕНТ" |

**Робот 8.2 -- Уведомить руководителя:**
| Параметр | Значение |
|----------|----------|
| Тип робота | Коммуникация > Уведомить в чат |
| Условие | Сумма > 500 |
| Получатель | Руководитель |
| Текст | "VIP-СДЕЛКА! {Название}: {Сумма} {Валюта}. Клиент: {Имя контакта}. Требуется персональное сопровождение." |
