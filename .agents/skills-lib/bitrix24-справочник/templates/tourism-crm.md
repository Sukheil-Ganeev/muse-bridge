# Шаблон: CRM для туризма ОАЭ -- Полный гайд

ДАННЫЕ АКТУАЛЬНЫ НА: 2026-02-16

## Назначение

Полная настройка Битрикс24 CRM для семейного туристического бизнеса в Дубае с тремя направлениями: экскурсии (Сухейль), аренда авто и трансферы (Марсель), яхты (Муфамад). Три отдельные воронки, автоматизация, отчетность.

---

## Пошаговая инструкция

### Шаг 1. Выбор тарифа

| Параметр | Базовый ($49/мес) | Стандартный ($99/мес) |
|----------|-------------------|----------------------|
| Пользователей | до 5 | до 50 |
| Воронки | до 5 | Без лимита |
| Открытые линии | 2 | Все каналы |
| CRM-маркетинг | Нет | Да |
| Бизнес-процессы | Нет | Базовые |
| Диск | 24 ГБ | 100 ГБ |

**Рекомендация:** Для семейного бизнеса (3 человека + помощники) -- **Базовый** на старте, переход на **Стандартный** при необходимости рассылок и маркетинга.

В AED: Базовый ~180 AED/мес (годовая), Стандартный ~364 AED/мес (годовая).

### Шаг 5. Автоматизация: авто-назначение по типу запроса

#### Сценарий: автоматическое назначение ответственного

Когда клиент обращается через Open Channel (мессенджер), нужно определить тип запроса и назначить правильного менеджера.

**Способ 1: Через маршрутизацию Open Channels (рекомендуется)**

1. Создайте 3 отдельные Открытые линии:
   - "Экскурсии" -> очередь: Сухейль + менеджеры экскурсий
   - "Авто и трансферы" -> очередь: Марсель + менеджеры авто
   - "Яхты" -> очередь: Муфамад + менеджеры яхт
2. Каждая линия привязана к своему каналу (разные Telegram-боты или разные номера WhatsApp)

**Способ 2: Через робота с условием (если один канал)**

Робот на стадии "Новая заявка" с условием по полю "Тип услуги":

| Значение поля "Тип услуги" | Назначить ответственным |
|-----------------------------|------------------------|
| Экскурсия / Билет / Сафари | Сухейль (ID: 1) |
| Аренда авто / Трансфер / МВУ | Марсель (ID: 2) |
| Яхта / Катер / Водные | Муфамад (ID: 3) |

**Настройка робота:**

```
Стадия: Новая заявка
Робот: Управление элементом > Изменить ответственного
Условие 1: Если "Тип услуги" содержит "экскурс" ИЛИ "билет" ИЛИ "сафари"
    -> Ответственный = Сухейль
Условие 2: Если "Тип услуги" содержит "авто" ИЛИ "трансфер" ИЛИ "МВУ"
    -> Ответственный = Марсель
Условие 3: Если "Тип услуги" содержит "яхт" ИЛИ "катер" ИЛИ "водн"
    -> Ответственный = Муфамад
```

**Способ 3: Через CRM-форму с выбором направления**

На сайте / в лендинге -- CRM-форма с полем "Что вас интересует?":
- Экскурсии и билеты -> воронка "Экскурсии", ответственный Сухейль
- Аренда авто / Трансфер -> воронка "Авто", ответственный Марсель
- Аренда яхты -> воронка "Яхты", ответственный Муфамад

### Шаг 6. Настройка валют и оплат

Путь: **CRM > Еще > Настройки > Валюта**

| Валюта | Код | Курс к AED | Применение |
|--------|-----|-----------|-----------|
| Дирхам ОАЭ | AED | 1.0000 (базовая) | Наличные, местные переводы |
| Доллар США | USD | 3.6725 | Иностранные клиенты |
| Российский рубль | RUB | 0.0370 (примерно) | Переводы Сбер |
| Казахский тенге | KZT | 0.0072 (примерно) | Переводы Kaspi |

**Отслеживание оплат через поля:**
- "Статус оплаты": Не оплачено / Частично / Полностью
- "Тип оплаты": Cash AED, Cash USD, Kaspi, Сбер, Карта, Крипто
- Триггер: при "Статус оплаты" = "Полностью" -> стадия "Оплата" / "Проведена"

## Примеры

### Пример: полный путь клиента (экскурсия)

```
1. Клиент Алексей пишет в WhatsApp: "Хочу desert safari на 4 человека"
2. Автоматически создается лид в Битрикс24
3. Робот: автоответ "Спасибо за обращение!" + уведомление Сухейлю
4. Сухейль конвертирует лид в сделку (воронка "Экскурсии")
5. Заполняет поля: Safari, 15.03.2026, 4 гостя, JBR Hilton, русский
6. Отправляет цену: 120 USD x 4 = 480 USD
7. Клиент подтверждает -> стадия "Подтверждение"
8. Робот: задача гиду Ахмеду + задача водителю (трансфер из JBR Hilton)
9. Клиент оплачивает Cash USD -> стадия "Оплата", статус "Полностью"
10. За 24ч: робот отправляет напоминание с деталями
11. Экскурсия проведена -> стадия "Проведена"
12. Через 2 дня: робот отправляет запрос отзыва
13. Через 30 дней: генератор продаж создает повторную сделку
```
