# Сценарии Битрикс24 для туристического бизнеса ОАЭ

---

## Сценарий 1: Обработка заявки на экскурсию (полный цикл)

### Путь клиента

```
Клиент пишет в WhatsApp
    -> Автоматически создается лид в CRM
    -> Менеджер квалифицирует (классический режим)
    -> Конвертация в Сделку + Контакт
    -> Стадия "Консультация" (робот: задача менеджеру)
    -> Стадия "Подтверждение" (робот: задача гиду)
    -> Стадия "Оплата" (робот: отправка реквизитов)
    -> Стадия "Подготовка" (робот: напоминание за 24ч)
    -> Стадия "Проведена" (робот: задача водителю)
    -> Стадия "Отзыв" (робот: follow-up через 2 дня)
```

### Настройка

1. **Воронка:** "Экскурсии"
2. **Стадии:** Новая заявка > Консультация > Подтверждение > Оплата > Подготовка > Проведена > Отзыв
3. **Поля карточки:** Дата тура, Количество гостей, Отель, Язык, Трансфер, Тип оплаты
4. **Роботы:**
   - На "Новая заявка": уведомление менеджеру + автоответ клиенту
   - На "Подтверждение": задача гиду + задача водителю (если трансфер = Да)
   - На "Оплата": отправка реквизитов клиенту
   - На "Подготовка": напоминание клиенту за 24ч (робот с задержкой)
   - На "Проведена": закрытие задач
   - На "Отзыв": follow-up через 2 дня

## Сценарий 2: Повторный клиент

### Логика

```
Успешная сделка завершена
    -> Генератор продаж (через 30 дней)
    -> Автоматически создается повторная сделка
    -> Менеджер получает уведомление
    -> Предложение нового тура / скидки
    -> Клиент соглашается -> обычный цикл
```

### Настройка

1. **Генератор продаж:** CRM > Еще > Генератор продаж
2. **Сегмент:** клиенты с успешными сделками за последние 90 дней
3. **Действие:** создать повторную сделку в воронке "Повторные продажи"
4. **Робот на стадии "Новая":** задача менеджеру "Связаться с повторным клиентом"

## Сценарий 3: VIP-клиент

### Логика

```
Сделка с суммой > $500
    -> Робот с условием: сумма > 500 USD
    -> Автоматический приоритет "Высокий"
    -> Уведомление старшему менеджеру
    -> Персональное сопровождение
    -> Бонус / скидка на следующий тур
```

### Настройка

1. **Робот на стадии "Новая заявка":**
   - Условие: Сумма сделки > $500
   - Действие 1: Изменить поле "Приоритет" = "Высокий"
   - Действие 2: Уведомить старшего менеджера в чат
   - Действие 3: Создать задачу "VIP-сопровождение"

## Сценарий 4: Групповой тур

### Логика

```
Запрос на групповой тур (>10 гостей)
    -> Смарт-процесс "Групповой тур"
    -> Привязка к нескольким сделкам
    -> Общий маршрут и расписание
    -> Распределение по транспорту
    -> Контроль общей суммы и оплат
```

### Настройка

1. **Смарт-процесс** "Групповые туры" с полями:
   - Название группы, Дата, Маршрут, Кол-во участников
   - Список транспорта, Гиды, Бюджет
2. **Связь:** привязка к сделкам каждого участника
3. **Воронка смарт-процесса:** Планирование > Сбор группы > Подготовка > Проведение > Закрыто

## Сценарий 5: Аренда яхты (от заявки до отзыва)

### Путь клиента

```
Запрос в Instagram/WhatsApp
    -> Лид/сделка в воронке "Аренда яхт"
    -> Менеджер уточняет: дата, время, кол-во гостей, кейтеринг, оформление
    -> Подбор яхты из каталога (смарт-процесс "Яхты")
    -> Согласование стоимости
    -> Оплата (частичная/полная)
    -> Подготовка (задачи капитану, кейтерингу, оформителю)
    -> Мероприятие
    -> Follow-up и отзыв
```

### Специфика

- Поля: тип яхты, длина, вместимость, маршрут, кейтеринг, оформление, DJ
- Смарт-процесс "Каталог яхт": 300+ яхт с характеристиками
- Мультизадачность: одновременно задачи капитану, кейтерингу, декоратору

## Сценарий 6: Аренда автомобиля

### Воронка

```
Запрос > Выбор авто > Документы (МВУ/паспорт) > Оплата > Выдача > Возврат
```

### Поля карточки

| Поле | Тип | Примеры |
|------|-----|---------|
| Класс авто | Список | Эконом, Бизнес, Спорт, Люкс |
| Марка/модель | Строка | BMW X5, Rolls Royce Ghost |
| Дата выдачи | Дата | 2026-03-15 |
| Дата возврата | Дата | 2026-03-20 |
| МВУ наличие | Да/Нет | Да |
| Депозит | Число | 5000 AED |
| Страховка | Список | Базовая, Полная |

## Сценарий 7: Трансфер

### Воронка

```
Заявка > Подтверждение > Назначение водителя > Выполнено
```

### Автоматизация

1. **Робот на "Подтверждение":** Создать задачу водителю с данными:
   - Имя клиента, телефон
   - Откуда (аэропорт/отель)
   - Куда (отель/достопримечательность)
   - Дата и время
   - Рейс (если трансфер из аэропорта)
   - Тип авто
2. **Робот за 2 часа до:** Напоминание водителю
3. **Робот после выполнения:** Уведомление менеджеру

## Сценарий 8: Билеты в парки и достопримечательности

### Воронка

```
Запрос > Подбор > Оплата > Отправка билета > Завершено
```

### Специфика

- Быстрый цикл (часто в тот же день)
- Поля: парк/место, дата, кол-во взрослых, кол-во детей, тип билета
- Робот на "Оплата": отправить ссылку на оплату
- Робот на "Отправка билета": отправить e-ticket в WhatsApp/Telegram
- Триггер: оплата получена -> автоматически на стадию "Отправка билета"

## Сценарий 9: Мультивалютная оплата

### Настройка валют

Путь: CRM > Настройки > Валюта.

| Валюта | Код | Применение |
|--------|-----|-----------|
| AED | AED | Наличные, местные переводы |
| USD | USD | Иностранные клиенты, карты |
| RUB | RUB | Переводы Сбер |
| KZT | KZT | Переводы Kaspi |

### Отслеживание оплат

1. Создать поле "Статус оплаты" (список): Не оплачено, Частично, Полностью
2. Создать поле "Способ оплаты" (список): Cash AED, Cash USD, Kaspi, Сбер, Карта, Крипто
3. Триггер на изменение поля "Статус оплаты" = "Полностью" -> стадия "Оплачено"

## Сценарий 10: Сезонная кампания

### Логика

```
Приближение высокого сезона (октябрь-апрель)
    -> CRM-маркетинг: сегментация по прошлым клиентам
    -> Email-рассылка: "Новый сезон в Дубае!"
    -> Персональные предложения (по истории покупок)
    -> Генератор продаж: автоматические сделки
    -> Менеджеры связываются с клиентами
```

### Настройка (тариф Стандартный и выше)

1. **Сегмент:** CRM-маркетинг > Сегменты > клиенты с успешными сделками
2. **Рассылка:** CRM-маркетинг > Рассылки > Email
3. **Генератор:** CRM > Генератор продаж > создать повторные сделки для сегмента
