# Автоматизация Битрикс24 -- Роботы, триггеры, бизнес-процессы

---

## Три уровня автоматизации

| Уровень | Инструмент | Сложность | Для кого |
|---------|-----------|-----------|----------|
| 1 | Роботы | Простая | Любой сотрудник |
| 2 | Триггеры | Простая | Любой сотрудник |
| 3 | Бизнес-процессы (БП) | Средняя-высокая | Администратор / интегратор |
| Доп. | RPA | Средняя | Любой сотрудник (no-code) |

---

## Роботы

Автоматические действия при переходе элемента CRM на определенную стадию воронки.

### Категории роботов

| Категория | Описание | Примеры |
|-----------|----------|---------|
| Коммуникация с клиентом | Автоматическая связь | Email, SMS, сообщение в мессенджер, звонок |
| Информирование сотрудников | Уведомления внутри команды | Push, чат, email уведомление |
| Управление элементом | Изменение данных | Изменить поле, сменить ответственного, сменить стадию |
| Оформление документов | Генерация документов | Счет, договор, акт с автоподстановкой |
| Работа с товарами | Действия с товарами | Изменение цен, количества |
| Данные о клиентах | Работа с контактами | Получить/обновить данные клиента |
| Контроль сотрудников | Мониторинг | Отслеживание просроченных задач, напоминания |
| Ожидание | Паузы | Ожидание времени, ожидание активности клиента |

### Настройки робота

| Параметр | Описание |
|----------|----------|
| Очередь | Порядок выполнения роботов на одной стадии |
| Время | Задержка (немедленно, через N мин/час/дней) |
| Условия | Фильтры по значениям полей |
| Логика | Операторы "И" / "ИЛИ" для сложных фильтров |

### Ограничения

- Бесплатный тариф: до 5 роботов/триггеров на весь портал
- Базовый и выше: без ограничений по количеству

## Триггеры

Отслеживают события и автоматически перемещают элемент на нужную стадию.

### Типы триггеров

| Триггер | Что отслеживает | Пример использования |
|---------|-----------------|---------------------|
| Входящее письмо | Клиент прислал email | Сделка -> "Ответ клиента" |
| Входящий звонок | Клиент позвонил | Сделка -> "Повторный контакт" |
| Переход по ссылке | Клик по ссылке из письма | Сделка -> "Заинтересован" |
| Заполнение CRM-формы | Клиент заполнил форму | Лид -> "Новая заявка" |
| Оплата счета | Счет оплачен | Сделка -> "Оплачено" |
| Посещение сайта | Клиент зашел на сайт | Сделка -> "Активный интерес" |
| Изменение поля | Изменилось значение | Сделка -> "Обновление данных" |
| Вебхук | HTTP-запрос от внешней системы | Сделка -> любая стадия |

### Механизм работы

1. Триггер привязывается к конкретной стадии воронки
2. Когда событие происходит, элемент CRM перемещается на эту стадию
3. Срабатывают роботы, привязанные к этой стадии

## Бизнес-процессы (БП)

Визуальный конструктор сложных многоэтапных сценариев.

### Два типа БП

| Тип | Описание | Пример |
|-----|----------|--------|
| Последовательный | Действия строго по порядку | Согласование договора |
| Со статусами | Несколько связанных процессов | Управление проектом |

### Ключевые конструкции

| Конструкция | Описание | Лимиты |
|-------------|----------|--------|
| Условие (if/else) | Ветвление логики | -- |
| Параллельные ветки | Одновременное выполнение | БП ждет завершения всех |
| Цикл | Повторение действий | 1 000 итераций (облако) |
| Переменные | Временные значения | Меняются в процессе |
| Константы | Постоянные значения | Название компании и т.д. |
| Глобальные | Доступны из любого БП | -- |

### Действия в БП

- Создать задачу
- Отправить уведомление (чат, email, push)
- Изменить поле документа
- Запустить согласование
- Отправить email/SMS
- Математические операции
- Задержки и ожидания
- Вызов REST API (вебхук)
- Создать элемент CRM

### Доступность по тарифам

| Тариф | Бизнес-процессы |
|-------|----------------|
| Бесплатный | Нет |
| Базовый | Нет |
| Стандартный | Базовые |
| Профессиональный | Полные |
| Энтерпрайз | Полные |

## RPA (Robotic Process Automation)

No-code конструктор для автоматизации рутинных операций.

| Параметр | Значение |
|----------|----------|
| Отличие от БП | Проще настройка, не нужен программист |
| Интерфейс | Визуальный, drag-and-drop |
| Ускорение | До 80% быстрее согласования документов |
| Области | CRM, задачи, маркетинг, кадровый документооборот |

## Шаблоны автоматизации для турагентства

### 1. Автораспределение лидов

**Когда:** Новый лид из любого канала (WhatsApp, Telegram, форма, звонок).
**Робот:** "Изменить ответственного" с условием "Распределение по очереди".
**Результат:** Каждый новый лид назначается свободному менеджеру.

### 2. Автоподтверждение заявки

**Когда:** Сделка на стадии "Новая заявка".
**Роботы:**
1. Отправить сообщение клиенту: "Спасибо за заявку! Менеджер свяжется с вами в течение 15 минут."
2. Уведомить менеджера в чат.
3. Создать задачу менеджеру "Связаться с клиентом" (дедлайн: 15 мин).

### 3. Напоминание за 24 часа до тура

**Когда:** Сделка на стадии "Подтверждено".
**Робот:** "Ожидание" (до значения поля "Дата тура" минус 1 день) > Отправить сообщение клиенту с деталями экскурсии.

### 4. Уведомление гиду/водителю

**Когда:** Сделка переходит на "Подтверждено".
**Робот:** Создать задачу гиду с данными: дата, место сбора, количество гостей, язык, контакт клиента.

### 5. Follow-up после тура

**Когда:** Сделка переходит на "Проведена".
**Робот:** "Ожидание" (2 дня) > Отправить сообщение: "Как прошла экскурсия? Будем рады вашему отзыву!" с ссылкой на форму отзыва.

### 6. Эскалация при отсутствии реакции

**Когда:** Сделка на стадии "Новая заявка" более 48 часов.
**Робот:** "Ожидание" (48 часов) > Уведомить руководителя: "Сделка без реакции более 48ч".

### 7. Автосмена стадии после оплаты

**Триггер:** Оплата счета.
**Действие:** Переместить сделку на стадию "Оплачено".
**Робот на стадии "Оплачено":** Создать задачу на подготовку.

### 8. Генератор повторных продаж

**Когда:** Сделка завершена успешно.
**Робот:** "Ожидание" (30 дней) > Создать новую сделку "Повторное предложение" > Уведомить менеджера.

## Вебхуки

### Входящий вебхук

Позволяет вызывать REST API без OAuth.

**URL формат:** `https://домен.bitrix24.ru/rest/{user_id}/{token}/{метод}.json`

**Создание:** Настройки > Интеграция > REST API > Входящий вебхук > выбрать права.

### Исходящий вебхук

Битрикс24 отправляет POST-запрос на ваш сервер при наступлении события.

**Настройка:** указать URL обработчика и выбрать события для отслеживания.

### Интеграция с Zapier / Make

| Параметр | Zapier | Make.com |
|----------|--------|----------|
| Сервисов | 6 000+ | 1 000+ |
| Сложность | Средняя | Средняя-высокая |
| Стоимость | Отдельная подписка | Отдельная подписка |
| Когда использовать | Связь с внешними сервисами (Gmail, Sheets, Slack) | Сложные сценарии с ветвлениями |

Встроенные роботы Битрикс24 бесплатны и покрывают 90% типовых сценариев. Zapier/Make нужны для интеграции с внешними сервисами, не имеющими прямого коннектора в Маркетплейсе.
