## REST API -- Формат запроса

### Через входящий вебхук

```
GET/POST https://домен.bitrix24.ru/rest/{user_id}/{token}/{метод}.json

Пример:
GET https://mycompany.bitrix24.ru/rest/1/abc123def456/crm.deal.list.json?filter[STAGE_ID]=WON
```

### Пример: создать лид (curl)

```bash
curl -X POST "https://домен.bitrix24.ru/rest/1/TOKEN/crm.lead.add.json" \
  -d "fields[TITLE]=Новая заявка на экскурсию" \
  -d "fields[NAME]=Иван" \
  -d "fields[LAST_NAME]=Петров" \
  -d "fields[PHONE][0][VALUE]=+79001234567" \
  -d "fields[SOURCE_ID]=WEB"
```

### Пример: создать сделку (JSON)

```json
{
  "fields": {
    "TITLE": "Desert Safari 15.03.2026",
    "CATEGORY_ID": 2,
    "STAGE_ID": "C2:NEW",
    "CONTACT_ID": 123,
    "OPPORTUNITY": 120,
    "CURRENCY_ID": "USD",
    "UF_CRM_TOUR_DATE": "2026-03-15",
    "UF_CRM_GUESTS": 4,
    "UF_CRM_HOTEL": "JBR Hilton",
    "ASSIGNED_BY_ID": 1
  }
}
```

### Пример: batch (пакетный вызов)

```json
{
  "halt": 0,
  "cmd": {
    "deals": "crm.deal.list?filter[STAGE_ID]=NEW&select[]=ID&select[]=TITLE",
    "contacts": "crm.contact.list?select[]=ID&select[]=NAME&select[]=LAST_NAME"
  }
}
```

## Коды ошибок API

| Код | Описание |
|-----|----------|
| 200 | Успех |
| 400 | Неверный запрос (ошибка в параметрах) |
| 401 | Не авторизован (неверный токен) |
| 403 | Нет прав доступа |
| 404 | Метод не найден |
| 429 | Слишком много запросов (лимит 2 req/sec) |
| 500 | Внутренняя ошибка сервера |
