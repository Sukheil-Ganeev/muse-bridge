# Контакт-центр Битрикс24 -- Подключение мессенджеров и телефония

---

## Open Channels (Открытые линии)

Единое окно для обработки обращений из всех каналов. Все сообщения поступают в единый интерфейс оператора.

### Лимиты по тарифам

| Тариф | Открытые линии |
|-------|---------------|
| Бесплатный | 1 |
| Базовый | 2 |
| Стандартный и выше | Неограниченно |

Лимит открытых чатов на оператора: до 1 000.

### Ключевые функции

- Автоматическое создание лида/сделки при первом обращении
- Маршрутизация на свободного менеджера или по очередям
- Быстрые ответы (шаблоны сообщений)
- Чат-боты для автоматических ответов
- Оценка качества обслуживания (CSI)
- История переписки сохраняется в карточке CRM
- Перенаправление диалога другому оператору
- Бесшовный переход между каналами

## Подключение мессенджеров

### Telegram

**Способ:** Встроенная интеграция через бота.

**Пошаговая инструкция:**
1. Открыть @BotFather в Telegram
2. Команда `/newbot`, задать имя и username
3. Скопировать токен бота
4. В Битрикс24: Контакт-центр > Telegram > Подключить
5. Вставить токен
6. Выбрать Открытую линию
7. Настроить очередь ответственных

**Стоимость:** Бесплатно.

**Возможности:**
- Получение сообщений от клиентов
- Отправка ответов из Битрикс24
- Передача файлов
- Автоответчик и чат-боты
- Создание лидов/сделок из обращений

### WhatsApp

**Способ:** Через провайдера (нет встроенной интеграции).

**Основные провайдеры:**

| Провайдер | Стоимость | Особенности |
|-----------|-----------|-------------|
| Wazzup | от 800 руб./мес (Start) | Самый популярный в РФ/СНГ, простая настройка |
| Edna | Индивидуально | Официальный WhatsApp Business API |
| Twilio | $0.005/сообщение | Международный, нет номеров РФ/СНГ |
| 360dialog | Индивидуально | WABA |
| Umnico | от 1 500 руб./мес | Мультиканальная платформа |
| ChatApp | от 990 руб./мес | Простая настройка |
| Cloud API (Meta) | Бесплатно (первые 1000) | Требует верификации бизнеса |

**Подключение через Wazzup (рекомендуемый):**
1. Зарегистрироваться на wazzup24.ru
2. Подключить WhatsApp-номер (сканировать QR-код)
3. В Маркетплейсе Битрикс24 установить приложение Wazzup
4. В настройках Wazzup привязать канал к Открытой линии
5. Настроить очередь операторов

### Instagram Direct

**Способ:** Встроенный коннектор.

**Требования:**
- Бизнес-аккаунт Instagram
- Привязка к публичной Facebook-странице

**Подключение:**
1. Контакт-центр > Instagram > Подключить
2. Авторизоваться через Facebook
3. Выбрать Instagram-аккаунт и Facebook-страницу
4. Привязать к Открытой линии

**Стоимость:** Бесплатно.

### Facebook Messenger

**Способ:** Встроенный коннектор.

**Подключение:**
1. Контакт-центр > Facebook > Подключить
2. Авторизоваться через Facebook
3. Выбрать страницу
4. Привязать к Открытой линии

**Стоимость:** Бесплатно.

### VK (ВКонтакте)

**Способ:** Встроенный коннектор через сообщество VK.

**Подключение:**
1. Контакт-центр > ВКонтакте > Подключить
2. Авторизоваться через VK
3. Выбрать сообщество
4. Привязать к Открытой линии

### Viber

**Способ:** Через бизнес-бот Viber.

**Важно:** С 05.02.2024 создание нового бизнес-бота Viber -- только платное.

### Avito

Встроенная интеграция + приложения на Маркетплейсе. С 20.11.2025: категория "Услуги" доступна от подписки "Расширенная".

## Телефония

### Способы подключения

| Способ | Описание | Для кого |
|--------|----------|----------|
| Аренда номера | Виртуальный номер от Битрикс24 | Быстрый старт |
| SIP-коннектор | Подключение своей АТС | Свой оператор, номера +971 |
| REST-приложение | Кастомная интеграция | Разработчики |

### Стоимость аренды номеров (РФ)

| Тип номера | Стоимость |
|-----------|-----------|
| Москва / СПб | 255 руб./мес |
| Другие города | 500 руб./мес |
| 8-800 | 2 000 руб./мес |
| Мобильные | 350 руб./мес |

Поставщик: ООО "Фастком" / Voximplant.

### Для бизнеса в ОАЭ

Рекомендуется SIP-подключение через местного VoIP-провайдера:
- Аренда номера +971 через VoIP-оператора (du, Etisalat, или международный SIP-провайдер)
- Подключение через SIP-коннектор в Битрикс24
- Стоимость зависит от оператора и тарифа

### Функции телефонии

| Функция | Описание |
|---------|----------|
| Запись звонков | Автоматическая запись всех разговоров |
| IVR (голосовое меню) | Многоуровневое меню; формат mp3, до 2 Мб, моно |
| Очереди | Распределение звонков по операторам |
| Маршрутизация | По номеру, времени, SLA |
| Статистика | Отчеты по звонкам, пропущенным, длительности |
| CRM-привязка | Автоматическая привязка звонков к карточке клиента |

IVR доступен на коммерческих тарифах (Базовый и выше).

## Виджет на сайт

Единый виджет объединяет три инструмента:
1. **Онлайн-чат** -- мгновенное общение с посетителем сайта
2. **Callback** -- обратный звонок (посетитель оставляет номер)
3. **CRM-форма** -- заполнение формы заявки

### Установка

Код виджета вставляется перед `</body>` на любом сайте. Настраивается: цвет, позиция, приветствие, рабочее время.

## Маршрутизация обращений

### Способы распределения

| Способ | Описание |
|--------|----------|
| Равномерно | Каждому оператору одинаковое количество |
| Строго по очереди | Первый свободный оператор |
| Одновременно всем | Уведомление всем -- кто первый ответил |

### Проверка доступности

- По рабочему времени (расписание)
- По онлайн-статусу (оператор в сети)
- Автоматическое перенаправление при отсутствии

## Оценка качества (CSI)

Встроенная система оценки обслуживания. После закрытия диалога клиенту отправляется запрос на оценку. Результаты доступны в отчетах.
