# Troubleshooting -- Битрикс24: Типичные проблемы и решения

---

## CRM

### Проблема: Не создаются лиды из мессенджеров
**Симптом:** Клиент пишет в WhatsApp/Telegram, но лид не появляется в CRM.
**Решения:**
1. Проверить настройки Открытой линии: CRM > Контакт-центр > Открытые линии > выбрать линию > "В CRM" > должно быть включено создание лидов
2. Проверить, подключен ли канал к Открытой линии
3. Убедиться, что у менеджера есть права на создание лидов
4. Если используется Wazzup -- проверить подписку и баланс

### Проблема: Дубликаты контактов
**Симптом:** Один клиент отображается несколько раз.
**Решения:**
1. CRM > Контакты > Еще > Найти дубликаты
2. Включить автоматическое обнаружение: CRM > Настройки > Прочее > Обнаружение дубликатов
3. Настроить контроль дубликатов при импорте (доступно от Стандартного тарифа)

### Проблема: Воронка не отображает все стадии
**Симптом:** В канбане видны не все стадии.
**Решения:**
1. Проверить права доступа (менеджер может не видеть чужие стадии)
2. Сбросить фильтры в канбане
3. Убедиться, что стадии не скрыты в настройках воронки

### Проблема: Не удается создать больше воронок
**Симптом:** Кнопка создания новой воронки недоступна.
**Причина:** Ограничение тарифа (Бесплатный -- 1, Базовый -- до 5, Профессиональный -- до 20).
**Решение:** Обновить тариф или объединить воронки.

## Автоматизация

### Проблема: Робот не срабатывает
**Симптом:** Сделка переходит на стадию, но робот не выполняется.
**Решения:**
1. Проверить условия робота (фильтры по полям)
2. Убедиться, что робот не приостановлен
3. Проверить лимит роботов на тарифе (бесплатный -- 5)
4. Для роботов с задержкой -- проверить, не завершилась ли сделка до срабатывания
5. Убедиться, что элемент CRM перемещен на стадию (а не создан сразу на ней)

### Проблема: Бизнес-процесс зависает
**Симптом:** БП запущен, но не продвигается.
**Решения:**
1. Проверить журнал БП: открыть элемент > Бизнес-процесс > Журнал
2. Ищите блок "Ожидание" или "Задание" -- возможно, БП ждет действия пользователя
3. Если цикл -- проверить, не превышен ли лимит итераций (1 000 в облаке)
4. Перезапустить БП: удалить и запустить заново

### Проблема: Триггер не перемещает сделку
**Симптом:** Событие произошло (звонок, письмо), но сделка не сменила стадию.
**Решения:**
1. Проверить, привязан ли триггер к правильной стадии
2. Убедиться, что событие соответствует типу триггера
3. Для триггера "Входящий звонок" -- проверить, подключена ли телефония
4. Для триггера "Email" -- проверить, подключена ли почта к CRM

## Контакт-центр

### Проблема: WhatsApp не подключается
**Симптом:** Ошибка при подключении WhatsApp через Wazzup/Edna.
**Решения:**
1. Проверить подписку провайдера (Wazzup -- от 800 руб./мес)
2. Убедиться, что номер WhatsApp не заблокирован
3. Переподключить QR-код в личном кабинете провайдера
4. Проверить, установлено ли приложение провайдера в Маркетплейсе Битрикс24

### Проблема: Telegram-бот не отвечает
**Симптом:** Сообщения от клиентов не приходят в Битрикс24.
**Решения:**
1. Проверить токен бота (может истечь)
2. Убедиться, что бот подключен к Открытой линии
3. Проверить, что менеджеры добавлены в очередь ответственных
4. Пересоздать подключение: Контакт-центр > Telegram > Отключить > Подключить заново

### Проблема: Звонки не записываются
**Симптом:** Запись звонков не сохраняется.
**Решения:**
1. Проверить настройки телефонии: включена ли запись
2. Убедиться, что хватает места на диске
3. На бесплатном тарифе запись звонков недоступна
4. При SIP-подключении -- проверить настройки SIP-коннектора

## Почта

### Проблема: Письма не привязываются к CRM
**Симптом:** Email клиента не отображается в карточке сделки.
**Решения:**
1. Проверить, включена ли интеграция: Почта > Настройки > CRM-интеграция
2. Убедиться, что email клиента указан в его карточке контакта
3. Проверить настройку Send&Save
4. Если используется внешний почтовый клиент -- убедиться, что настроен IMAP

### Проблема: Почта не синхронизируется
**Симптом:** Новые письма не появляются в Битрикс24.
**Решения:**
1. Проверить настройки подключения (логин, пароль, IMAP/SMTP)
2. Для Gmail -- использовать пароль приложения (не основной пароль)
3. Переподключить ящик: Почта > Настройки > Отключить > Подключить заново
4. Проверить лимиты синхронизации по тарифу

## API

### Проблема: Ошибка 429 Too Many Requests
**Симптом:** API возвращает ошибку при частых запросах.
**Причина:** Превышен лимит 2 запроса/секунду.
**Решения:**
1. Использовать метод `batch` для пакетных вызовов (до 50 команд)
2. Добавить задержку между запросами (минимум 500 мс)
3. Кэшировать данные на стороне клиента

### Проблема: Вебхук возвращает пустой ответ
**Симптом:** Вызов входящего вебхука не возвращает данных.
**Решения:**
1. Проверить URL вебхука (формат: `https://домен.bitrix24.ru/rest/{user_id}/{token}/метод`)
2. Убедиться, что вебхуку назначены нужные права (CRM, задачи и т.д.)
3. Проверить, не истек ли токен (при смене пароля пользователя токен обновляется)
4. Проверить параметры запроса (формат JSON или URL-encoded)

### Проблема: Исходящий вебхук не отправляется
**Симптом:** Битрикс24 не отправляет POST-запрос при событии.
**Решения:**
1. Проверить URL обработчика (должен быть доступен из интернета, HTTPS)
2. Убедиться, что указано правильное событие
3. Проверить логи на стороне обработчика (Битрикс24 ожидает HTTP 200)
4. Тайм-аут ответа: обработчик должен ответить в течение нескольких секунд

## Общее

### Проблема: Портал работает медленно
**Решения:**
1. Очистить кэш браузера
2. Проверить интернет-соединение
3. Проверить, не превышены ли лимиты хранилища
4. Для большого количества данных -- рассмотреть переход на Энтерпрайз

### Проблема: Уведомления не приходят
**Решения:**
1. Проверить настройки уведомлений: Профиль > Уведомления
2. На мобильном -- проверить разрешения push-уведомлений
3. Проверить, не отключены ли уведомления для конкретного чата/задачи
4. Убедиться, что статус "Онлайн" активен (в оффлайне часть уведомлений задерживается)

### Проблема: Не удается войти в мобильное приложение
**Решения:**
1. Обновить приложение до последней версии
2. Проверить URL портала (формат: название.bitrix24.ru)
3. Если включена 2FA -- использовать одноразовый код
4. Переустановить приложение
