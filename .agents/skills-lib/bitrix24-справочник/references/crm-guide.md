## Режимы работы CRM

| Режим | Описание | Когда использовать |
|-------|----------|--------------------|
| Классический (с лидами) | Лид -> Квалификация -> Сделка + Контакт + Компания | Большой поток входящих (>20/день), нужна фильтрация |
| Простой (без лидов) | Сразу Сделка + Контакт/Компания | Малый бизнес, каждый контакт -- потенциальный клиент |

Переключение: CRM > Еще > Настройки > Режим работы CRM.

По умолчанию установлен Простой режим.

## Сущности CRM

### Лиды

Потенциальный клиент или входящая заявка. Стадии обработки настраиваются.

**Жизненный цикл лида:**
1. Новый лид (из формы, звонка, мессенджера, email)
2. В обработке (менеджер работает)
3. Квалификация (определение потребности)
4. Качественный -> Конвертация в Сделку + Контакт + Компанию
5. Некачественный -> Закрытие с указанием причины

**Повторные лиды:** при повторном обращении ранее закрытого клиента автоматически создается повторный лид, привязанный к существующему контакту.

### Сделки

Основной элемент для ведения продаж. Содержит: данные клиента, историю взаимодействия, товары, сумму, текущий этап.

**Ключевые поля сделки:**
- Название, Сумма, Валюта
- Контакт, Компания
- Стадия, Воронка
- Ответственный менеджер
- Источник, UTM-метки
- Пользовательские поля (до 1 016 на тип)

### Контакты

Физические лица (клиенты, представители). Хранят: ФИО, телефоны, email, историю обращений и покупок.

### Компании

Юридические лица. К компании могут быть привязаны несколько контактов и сделок. Хранят: реквизиты, адрес, банковские данные.

## Воронки продаж

### Настройка воронки

Путь: CRM > Сделки > Еще > Настройки > Настройки CRM > Воронки продаж.

Каждая воронка имеет:
- Собственные стадии (название, цвет)
- Обязательные финальные стадии: "Успешная сделка" и "Провалена"
- Роботов и триггеров на каждой стадии
- Индивидуальную настройку карточки

### Лимиты воронок по тарифам

| Тариф | Количество воронок |
|-------|--------------------|
| Бесплатный | 1 |
| Базовый | до 5 |
| Стандартный | [ТРЕБУЕТ ПРОВЕРКИ] |
| Профессиональный | до 20 |
| Энтерпрайз | [ТРЕБУЕТ ПРОВЕРКИ] |

### Туннели продаж

Связь между воронками. При достижении определенной стадии в одной воронке сделка автоматически перемещается или копируется в другую.

**Два режима:**
- **Копирование** -- создается копия, оригинал остается
- **Перемещение** -- сделка переносится, исчезает из исходной

**Пример для турагентства:**
Воронка "Продажи" > стадия "Оплачено" -> туннель -> Воронка "Проведение" > стадия "Подготовка"

### Рекомендуемые воронки для турагентства

| Воронка | Стадии |
|---------|--------|
| Экскурсии | Новая заявка > Консультация > Подтверждение > Оплата > Проведена > Отзыв |
| Билеты в парки | Запрос > Подбор > Оплата > Отправка билета > Завершено |
| Аренда яхт | Запрос > Подбор яхты > Согласование > Оплата > Мероприятие > Закрыто |
| Аренда авто | Запрос > Выбор авто > Документы > Оплата > Выдача > Возврат |
| Трансферы | Заявка > Подтверждение > Назначение водителя > Выполнено |

## Смарт-процессы

Конструктор новых типов элементов CRM. "CRM внутри CRM".

**Что можно настроить:**
- Собственные поля
- Воронки и стадии в канбане
- Роботов и триггеров
- Права доступа
- Связь с задачами, календарем, другими элементами CRM

**Путь создания:** CRM > Еще > Настройки > Список смарт-процессов > Создать.

**Отличие от бизнес-процессов:**
- Бизнес-процессы автоматизируют действия внутри существующих элементов CRM
- Смарт-процессы создают совершенно новые типы элементов

**Примеры для туризма:**
- Реестр экскурсий (название, дата, маршрут, гид, транспорт, макс. участников)
- Бронирования яхт (яхта, дата, время, кейтеринг, оформление)
- Маршруты (точки маршрута, транспорт, время, стоимость)

## Настройка карточки CRM

### Пользовательские поля

Максимум: 1 016 полей на каждый тип элемента.

**Типы полей:**

| Тип | Описание | Пример |
|-----|----------|--------|
| Строка | Текст | Комментарий, название отеля |
| Целое число | Только целые | Количество гостей |
| Число | Дробные | Сумма, процент |
| Дата / Дата+Время | Выбор даты | Дата экскурсии |
| Да/Нет | Флажок | Трансфер нужен |
| Список | Набор значений | Язык обслуживания, тип оплаты |
| Сотрудник | Привязка к пользователю | Ответственный гид |
| Привязка к элементу CRM | Ссылка на другой элемент | Связанная компания |
| Файл | Загрузка документа | Скан паспорта, ваучер |
| Ссылка | URL | Ссылка на маршрут в Google Maps |

**Настройка карточки:**
- Поля перетаскиваются, группируются в секции
- Можно скрывать ненужные системные поля
- Отдельные настройки для каждой воронки
- Обязательные поля задаются для конкретных стадий
- Тип поля после создания изменить нельзя (нужно создать новое)

### Рекомендуемые поля для турагентства

| Поле | Тип | Пример значений |
|------|-----|-----------------|
| Дата тура/экскурсии | Дата | 2026-03-15 |
| Количество гостей | Целое число | 4 |
| Отель клиента | Строка | JBR Hilton |
| Язык обслуживания | Список | Русский, English, Arabic |
| Трансфер нужен | Да/Нет | Да |
| Тип оплаты | Список | Cash AED, Cash USD, Kaspi, Сбер, Крипто |
| Номер бронирования | Строка | EXC-2026-0315-001 |
| Особые пожелания | Строка | Вегетарианское питание |
| Гид | Сотрудник | Ахмед |

## Аналитика CRM

### Встроенные отчеты

Путь: CRM > Аналитика.

**Группы отчетов:**
1. Анализ лидов (первичные, повторные)
2. Продажи (воронка продаж, конверсия)

**Типы воронки:**
- Классическая -- показывает только фактически пройденные этапы
- Конверсионная -- рассчитывает теоретическую конверсию между всеми этапами

### BI-конструктор

Продвинутая аналитика с интерактивными дашбордами. Виджеты: конверсия, динамика продаж, эффективность менеджеров. Типы диаграмм: линейная, столбчатая, круговая.

## Счета и коммерческие предложения

### Коммерческие предложения (КП)

Создаются из карточки сделки. Содержат список товаров/услуг с ценами.

**Стадии:** Новое > Отправлено клиенту > Принято / Отклонено > Анализ причины.

### Счета

Генерируются по шаблону из карточки сделки или КП. Содержат: реквизиты, товары/услуги, итоговую сумму. Отслеживание статуса оплаты.

### Шаблоны документов

Стандартные шаблоны включены в каждый портал. Можно создавать собственные. Автоматическая подстановка данных из CRM: реквизиты, товары, суммы, контакты.

## Импорт / Экспорт

### Импорт

- Форматы: CSV, XLS
- Поддерживаемые сущности: лиды, контакты, компании, сделки, товары
- Путь: CRM > (раздел) > шестеренка > Импорт
- Доступен импорт с реквизитами и без

### Экспорт

- Форматы: CSV, XLS (Excel)
- Поддерживаемые сущности: лиды, сделки, счета, предложения, контакты, компании, товары
- Путь: CRM > (раздел) > шестеренка > Экспорт

### Перенос между порталами

Экспорт с одного портала > Импорт на другой. Формат CSV. Переносятся: лиды, сделки, контакты, компании.

## Дубликаты

### Автоматическое обнаружение

- По умолчанию: раз в день
- Поддерживаемые сущности: лиды, контакты, компании
- Автообъединение: если все поля совпадают, один ответственный, одна стадия

### Ручное объединение

Для дубликатов с различиями. При объединении данные из обоих элементов сохраняются в одном.

### Контроль дубликатов

Доступен от тарифа Стандартный. Предупреждение при создании элемента с совпадающими данными.

## Мультивалютность

### Настройка

Путь: CRM > Еще > Настройки > Валюта.

### Рекомендуемые валюты для бизнеса в ОАЭ

| Валюта | Код | Применение |
|--------|-----|-----------|
| Дирхам ОАЭ | AED | Основная рабочая (наличные, местные переводы) |
| Доллар США | USD | Для иностранных клиентов |
| Российский рубль | RUB | Переводы Сбер для клиентов из РФ |
| Казахский тенге | KZT | Kaspi-переводы для клиентов из Казахстана |

Курсы обновляются вручную или через интеграцию. Каждая сделка может быть в своей валюте.

## CRM для сервисного бизнеса

### Онлайн-запись

Встроенный сервис записи клиентов на услуги:
- Клиент выбирает услугу, специалиста, дату и время
- Форма размещается на сайте
- Данные автоматически попадают в CRM
- Автоматические напоминания о визите

Подходит для: экскурсий, записи на консультации, аренды.
