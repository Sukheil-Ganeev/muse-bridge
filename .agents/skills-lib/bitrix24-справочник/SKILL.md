## 01. Обзор платформы

Битрикс24 -- комплексный сервис для управления бизнесом от компании "1С-Битрикс" (СП "1С" и "Битрикс", основано в 2007 году). Платформа запущена 12 апреля 2012 года. На 2026 год зарегистрировано более 15 миллионов организаций в ~195 странах мира.

### Ключевые модули

| Модуль | Назначение |
|--------|-----------|
| CRM | Управление клиентами, сделками, воронками продаж |
| Задачи и проекты | Kanban, Gantt, Scrum, учет времени |
| Коммуникации | Внутренний мессенджер, видеозвонки, календарь |
| Контакт-центр | Телефония, мессенджеры (Telegram, WhatsApp, Instagram) |
| Автоматизация | Роботы, триггеры, бизнес-процессы |
| Сайты | Конструктор сайтов и лендингов без кода |
| Маркетинг | Email/SMS-рассылки, сегментация, аналитика |
| BitrixGPT | AI-помощник (генерация текстов, расшифровка звонков) |
| API | REST API, вебхуки, Маркетплейс приложений |

### Облако vs Коробка

| Параметр | Облако (Cloud) | Коробка (On-Premise) |
|----------|---------------|---------------------|
| Установка | Не требуется | На своём сервере |
| Оплата | Подписка (мес./год) | Лицензия + 25%/год за обновления |
| Кастомизация | Ограниченная | Полная (код, макеты, модули) |
| Для кого | МСБ, стартапы, агентства | Крупный бизнес, банки, госструктуры |
| Для турагентства | Оптимально | Избыточно |

Языки интерфейса: 17 (русский, английский, немецкий, испанский, португальский, французский, итальянский, польский, украинский, турецкий, китайский, японский, вьетнамский, индонезийский, малайский, тайский, хинди). Арабский язык -- только неофициальная локализация через community-пакет на GitHub.

## 03. CRM -- ядро системы

CRM Битрикс24 охватывает весь цикл работы с клиентом: от первого обращения до повторных продаж.

### Режимы работы

| Режим | Описание | Для кого |
|-------|----------|----------|
| Классический (с лидами) | Лид -> Квалификация -> Сделка + Контакт + Компания | Бизнес с большим потоком входящих обращений |
| Простой (без лидов) | Сразу Сделка + Контакт/Компания | Малый бизнес, короткий цикл продаж |

### Четыре основные сущности

| Сущность | Назначение | Пример в туризме |
|----------|-----------|------------------|
| Лид | Потенциальный клиент, входящая заявка | Запрос на экскурсию из WhatsApp |
| Сделка | Процесс продажи с суммой и стадиями | Бронирование desert safari на $120 |
| Контакт | Физическое лицо | Турист Иван Петров |
| Компания | Юридическое лицо | ТОО "Казахстан Трэвел" |

### Воронки продаж

- Множественные воронки (количество зависит от тарифа: Бесплатный -- 1, Базовый -- до 5, Профессиональный -- до 20)
- Каждая воронка имеет свои стадии, настройки карточки, роботов
- Туннели продаж -- связь между воронками (копирование или перемещение сделок)
- Финальные стадии обязательны: "Успешная сделка" и "Провалена"

### Смарт-процессы

"CRM внутри CRM" -- конструктор для создания произвольных бизнес-сценариев. Позволяют создать новые типы элементов с собственными полями, воронками, стадиями, роботами и правами доступа.

Примеры для туризма: процесс "Бронирования", "Реестр экскурсий", "Маршруты".

### Карточки CRM

- До 1 016 пользовательских полей на каждый тип элемента
- Типы полей: строка, число, дата, список, файл, привязка к элементу CRM, сотрудник и др.
- Обязательные поля можно задать для конкретных стадий
- Настройка карточки индивидуальна для каждой воронки

### Аналитика CRM

Встроенные отчеты: воронка продаж (классическая и конверсионная), анализ лидов, план и прогноз продаж, рейтинг менеджеров. BI-конструктор для продвинутых дашбордов.

### Счета и коммерческие предложения

Генерация документов по шаблонам из карточки сделки. Стадии: Новое -> Отправлено -> Принято/Отклонено. Подстановка данных из CRM автоматически.

### Дубликаты

Автоматическое обнаружение (по умолчанию раз в день) для лидов, контактов, компаний. Автообъединение при полном совпадении полей. Ручное объединение для остальных случаев.

Подробнее: `references/crm-guide.md`

## 04. Задачи и проекты

### Основные возможности

| Возможность | Описание |
|-------------|----------|
| Создание задач | Короткая и полная форма; роли: постановщик, исполнитель, соисполнители, наблюдатели |
| Чек-листы | Неограниченное количество; подпункты с ответственными |
| Шаблоны | Для повторяющихся задач; группировка по направлениям |
| Приоритеты | Обычный и срочный |
| Файлы | Вложения, комментарии прямо в карточке задачи |

### Представления

| Представление | Назначение |
|---------------|-----------|
| Kanban | Колонки по стадиям, перетаскивание карточек |
| Диаграмма Ганта | Временная шкала, зависимости между задачами (FS, SS, FF, SF) |
| Календарь | Задачи по дням/неделям/месяцам |
| Список | Табличный вид с настраиваемыми колонками |
| Сроки | Фокус на дедлайнах |
| Мой план | Персональное планирование |

### Scrum

Полноценная реализация: бэклог, спринты, 4 типа встреч (планирование, daily, демонстрация, ретроспектива), аналитика (Burndown, Burnup, Velocity, Cumulative Flow).

### Проекты и группы

Проект = группа с установленными сроками. Три уровня конфиденциальности: открытый, закрытый, секретный. Роли: ответственный, модератор, участники.

### Учет времени

Встроенный таймер в карточке задачи. Ручной ввод для офлайн-работы. Доступен на тарифах Стандартный и выше.

### Эффективность сотрудников

Формула: Эффективность = 100 - (Замечания / Всего в работе) * 100. Защита от накруток: задачи "сам себе" не учитываются. Доступно на тарифах Стандартный, Профессиональный, Энтерпрайз.

Облачное хранилище (от 5 ГБ до 3 ТБ в зависимости от тарифа). Версионность файлов, совместное редактирование через Google Docs / MS365, настройка прав доступа.

## 06. Контакт-центр

Единое окно для обработки обращений из всех каналов: Telegram, WhatsApp (через Wazzup, Edna и др.), Instagram Direct, Facebook Messenger, VK, Viber, онлайн-чат на сайте.

Ключевые возможности:
- Автоматическое создание лида/сделки из обращения
- Маршрутизация на свободного менеджера или по очередям
- Быстрые ответы (шаблоны)
- Чат-боты для автоматических ответов
- Оценка качества обслуживания (CSI)
- История переписки сохраняется в карточке CRM

### Подключение мессенджеров

| Канал | Способ подключения | Стоимость |
|-------|-------------------|-----------|
| Telegram | Через бота (@BotFather), встроенная интеграция | Бесплатно |

### Телефония

Встроенная IP-телефония: аренда виртуальных номеров, SIP-коннектор для подключения своего оператора, запись звонков, IVR (голосовое меню), очереди, маршрутизация, статистика.

Для бизнеса в ОАЭ: рекомендуется SIP-подключение через местного провайдера VoIP (номера +971). Аренда российских номеров возможна от ~200 руб./мес.

### Виджет на сайт

Единый виджет объединяет: онлайн-чат, callback (обратный звонок), CRM-форму. Устанавливается на любой внешний сайт.

Подробнее: `references/contact-center.md`

## 07. Автоматизация

### Роботы

Автоматические действия, срабатывающие при перемещении элемента CRM (сделки, лида) на определенную стадию воронки.

| Категория роботов | Примеры |
|-------------------|---------|
| Коммуникация | Отправить email, SMS, уведомление в чат |
| Работа с CRM | Изменить поле, создать сделку/лид/контакт, создать счет |
| Задачи | Создать задачу, добавить участника |
| Планирование | Создать событие в календаре, поставить напоминание |
| Контроль | Ожидание (пауза), условие (if/else), вебхук |

Ограничение на Бесплатном тарифе: 5 роботов/триггеров.

### Триггеры

Отслеживают события и автоматически перемещают элемент на нужную стадию: входящее письмо, звонок, заполнение CRM-формы, оплата счета, входящий вебхук.

### Бизнес-процессы (БП)

Визуальный конструктор сложных сценариев. Элементы: условия (if/else), циклы (до 1 000 итераций), параллельные ветки, согласования, задания, уведомления, REST-действия (вызов внешних API).

Доступность: Стандартный -- базовые, Профессиональный и Энтерпрайз -- полные.

### Шаблоны автоматизации

- Автораспределение лидов между менеджерами
- Уведомление о просроченных сделках
- Follow-up после тура (через N дней)
- Эскалация при отсутствии реакции
- Автосмена стадии после оплаты

Подробнее: `references/automation-guide.md`

### Конструктор сайтов (Битрикс24.Сайты)

Конструктор лендингов с интеграцией CRM-форм. Каждое заполнение формы автоматически создает лид/сделку. Встроенного автоматизированного A/B-тестирования нет, но можно создать несколько версий вручную.

### CRM-формы

Конструктор форм обратной связи. Типы: стандартная, обратный звонок, запись на услугу. Условные поля, автозаполнение. Встраиваются на любой сайт или используются в лендингах Битрикс24.

### Интернет-магазин (CRM-магазин)

Каталог товаров, заказы, интеграция с CRM-сделками. Платежные системы: российские (ЮKassa, Robokassa, Тинькофф), международные (Stripe -- через Маркетплейс, поддерживает Visa, Mastercard, iDeal, WeChat Pay, SEPA, Alipay).

## 11. API и интеграции

### REST API

Все облачные порталы имеют REST API. Авторизация: OAuth 2.0 (для приложений) или входящие вебхуки (для скриптов).

Базовый URL: `https://ваш_домен.bitrix24.ru/rest/`

Лимиты: 2 запроса/секунду на портал (возможны пакетные вызовы через `batch`).

### Вебхуки

| Тип | Описание |
|-----|----------|
| Входящий | Позволяет вызывать API без OAuth. URL: `/rest/{user_id}/{token}/` |
| Исходящий | Битрикс24 отправляет HTTP-запрос на ваш сервер при наступлении события |

### Основные методы API

| Метод | Описание |
|-------|----------|
| `crm.lead.list` / `crm.lead.add` | Работа с лидами |
| `crm.deal.list` / `crm.deal.add` / `crm.deal.update` | Работа со сделками |
| `crm.contact.list` / `crm.contact.add` | Работа с контактами |
| `crm.company.list` / `crm.company.add` | Работа с компаниями |
| `tasks.task.list` / `tasks.task.add` | Работа с задачами |
| `user.get` / `user.current` | Информация о пользователях |
| `crm.status.list` | Справочники стадий и статусов |
| `batch` | Пакетные вызовы (до 50 команд за раз) |

### Маркетплейс

Каталог приложений для расширения функционала. Установка в 1 клик. Категории: CRM, маркетинг, телефония, аналитика, склад и др. Подписка "Маркет Плюс" для расширенного доступа. Можно создавать собственные приложения.

### Интеграции

| Сервис | Тип интеграции |
|--------|---------------|
| 1С:Предприятие | Двусторонняя синхронизация (контакты, счета, каталог) |
| Zapier / Make | Коннекторы для связи с 1000+ сервисами |
| Google Workspace | Календарь, Диск, Docs |
| Microsoft 365 | Outlook, OneDrive |
| Telegram / WhatsApp | Через Open Channels (контакт-центр) |

Подробнее: `references/api-reference.md`

## 12. Мобильное приложение

Приложение для iOS и Android. Основные функции: CRM (просмотр/создание сделок, лидов), задачи (Kanban, создание, учет времени), мессенджер и видеозвонки, push-уведомления, QR-визитки, геолокация.

Ограничения по сравнению с десктопом: нет полноценного конструктора бизнес-процессов, ограниченная настройка роботов, нет конструктора сайтов, нет некоторых отчетов аналитики.

Офлайн-режим: просмотр ранее загруженных данных, создание задач и заметок (синхронизация при восстановлении связи).

Дизайн обновлен ("Зефир", ноябрь 2025) -- новые значки, цвета, навигация.

## 13. Администрирование

### Структура и права доступа

Оргструктура компании: отделы, подразделения, руководители. Роли в CRM: администратор, директор, начальник отдела, менеджер. Права настраиваются по ролям для каждого модуля.

### Безопасность

Двухфакторная аутентификация (2FA), IP-ограничения, управление сессиями, история входов, шифрование (Энтерпрайз). Экстранет заменен на "Коллабы" -- для работы с внешними пользователями.

### Импорт/экспорт

Форматы: CSV, XLS (Excel). Импорт: лиды, контакты, компании, сделки, товары. Экспорт: все элементы CRM. Приложения Маркетплейса для расширенного импорта.

### Бэкапы

Облако: автоматические бэкапы выполняются на стороне 1С-Битрикс. Коробка: ответственность владельца сервера.

### Миграция облако-коробка

Официальный сервис миграции недоступен с осени 2023 года. Альтернативы: приложение "Мигратор" от Эм Си Арт, "Миграция порталов" от Техдиректор, профильные разработчики.

## 14. Битрикс24 для туризма ОАЭ

### Рекомендуемые воронки

| Воронка | Стадии |
|---------|--------|
| Экскурсии | Новая заявка -> Консультация -> Подтверждение -> Оплата -> Проведена -> Отзыв |
| Билеты в парки | Запрос -> Подбор -> Оплата -> Отправка билета -> Завершено |
| Аренда яхт | Запрос -> Подбор яхты -> Согласование -> Оплата -> Мероприятие -> Закрыто |
| Аренда авто | Запрос -> Выбор авто -> Документы -> Оплата -> Выдача -> Возврат |
| Трансферы | Заявка -> Подтверждение -> Назначение водителя -> Выполнено |

### Пользовательские поля карточки сделки

| Поле | Тип | Примеры значений |
|------|-----|-----------------|
| Дата тура/экскурсии | Дата | 2026-03-15 |
| Количество гостей | Целое число | 4 |
| Отель клиента | Строка | JBR Hilton |
| Язык обслуживания | Список | Русский, English, Arabic |
| Трансфер нужен | Да/Нет | Да |
| Тип оплаты | Список | Cash AED, Cash USD, Kaspi, Сбер, Крипто |

### Автоматизация бронирований (роботы)

| Событие | Робот |
|---------|-------|
| Новая заявка | Уведомление менеджеру в чат + автоответ клиенту в WhatsApp/Telegram |
| Переход на "Подтверждение" | Задача гиду/водителю на подготовку |
| Переход на "Оплата" | Отправка ссылки на оплату или реквизитов |
| За 24ч до тура | Напоминание клиенту с деталями (робот с задержкой) |
| Тур проведен | Follow-up через 2 дня: запрос отзыва |
| Нет ответа 48ч | Эскалация -- уведомление руководителю |

### Мессенджеры для туризма

WhatsApp и Telegram -- основные каналы работы с туристами из СНГ.

Рекомендуемый стек:
1. Telegram -- бесплатное подключение через @BotFather
2. WhatsApp -- через Wazzup (от 800 руб./мес тариф Start)
3. Instagram Direct -- бесплатный коннектор (для маркетинга и входящих)

Шаблоны быстрых ответов: приветствие, прайс экскурсий, подтверждение бронирования, напоминание за 24ч, благодарность после тура.

### Мультивалютность

Битрикс24 поддерживает работу с несколькими валютами в CRM. Актуальные валюты для бизнеса в ОАЭ:

| Валюта | Применение |
|--------|-----------|
| AED | Основная рабочая валюта (наличные, переводы) |
| USD | Для иностранных клиентов |
| RUB | Переводы Сбер для клиентов из РФ |
| KZT | Kaspi-переводы для клиентов из Казахстана |

Настройка: CRM > Настройки > Валюта. Курсы обновляются вручную или через интеграцию.

### Готовые сценарии

1. **Обработка заявки на экскурсию** (полный цикл):
   - Клиент пишет в WhatsApp -> создается лид -> менеджер квалифицирует -> создается сделка -> подтверждение -> оплата -> задача гиду -> проведение -> follow-up -> отзыв

2. **Повторный клиент**:
   - Генератор продаж создает повторную сделку через 30 дней -> менеджер предлагает новый тур

3. **VIP-клиент**:
   - Сделка с суммой >$500 -> автоматический приоритет -> уведомление старшему менеджеру -> персональное сопровождение

4. **Групповой тур**:
   - Смарт-процесс "Групповой тур" -> связь с несколькими сделками -> общий маршрут -> распределение по транспорту

Подробнее: `references/tourism-scenarios.md`
