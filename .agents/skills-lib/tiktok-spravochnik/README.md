# tiktok-справочник

Production-ready руководство по TikTok для туристического бизнеса ОАЭ.

## Структура

```
tiktok-справочник/
├── SKILL.md              # Основной справочник (Content Posting API, Ads, Shop, тренды)
├── README.md             # Этот файл
└── references/
    ├── faq.md            # Часто задаваемые вопросы
    ├── troubleshooting.md # Решение проблем
    └── cheatsheet.md     # Шпаргалка
```

## Что покрывает

- **Content Posting API** — публикация видео и фото через API
- **Login Kit / OAuth 2.0** — авторизация пользователей
- **TikTok Embed** — встраивание видео на сайт (oEmbed)
- **Research API** — поиск видео, хэштеги, тренды
- **TikTok Shop** — e-commerce, каталог товаров, заказы
- **TikTok Promote** — продвижение видео из приложения
- **TikTok Ads Manager** — полноценная рекламная платформа
- **Creative Center** — тренды, звуки, шаблоны, AI-инструменты
- **Аналитика** — метрики, TikTok Studio, сторонние инструменты
- **Примеры для туризма ОАЭ** — контент-стратегия, хэштеги, сезонность

## Важно

TikTok **НЕ имеет Bot API** в классическом смысле. Бот-справочник отсутствует.
Платформа ориентирована на контент-маркетинг, а не на автоматизацию сообщений.

## Бизнес-контекст

Туризм в ОАЭ (Дубай). Аудитория: СНГ + международная.
Dubai — самый просматриваемый город в TikTok (29.7M+ постов с #Dubai).
