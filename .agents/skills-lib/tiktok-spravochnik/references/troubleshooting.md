# TikTok Troubleshooting — Решение проблем

## Аутентификация

### access_token expired (Error 10008)
**Проблема:** access_token истёк (срок жизни 24 часа).
**Решение:**
```
POST https://open.tiktokapis.com/v2/oauth/token/
Content-Type: application/x-www-form-urlencoded

client_key={client_key}
&client_secret={client_secret}
&grant_type=refresh_token
&refresh_token={refresh_token}
```

### Invalid redirect_uri (Error 10003)
**Проблема:** Redirect URI не совпадает с зарегистрированным.
**Решение:** Проверить Redirect URI в Developer Portal. Должен совпадать ТОЧНО (включая trailing slash).

### State mismatch (CSRF)
**Проблема:** Параметр `state` в callback не совпадает с отправленным.
**Решение:** Генерировать уникальный `state` для каждого запроса и хранить в сессии. Сравнивать при получении callback.

### Scope not authorized
**Проблема:** Запрос scope, который не был одобрен для приложения.
**Решение:** Проверить список одобренных scopes в Developer Portal. Запросить дополнительные scopes через аудит.

## Content Posting API

### Контент публикуется только в приватном режиме
**Проблема:** Все видео, опубликованные через API, видны только автору.
**Причина:** Приложение не прошло аудит TikTok.
**Решение:**
1. Протестировать приложение с 5 пользователями
2. Подать заявку на аудит в Developer Portal
3. После одобрения ограничение снимается

### Превышен лимит публикаций (Error 10006)
**Проблема:** Превышен дневной лимит публикаций (15/день на пользователя).
**Решение:** Подождать до сброса лимита (00:00 UTC). Планировать публикации заранее.

### Upload failed — chunk error
**Проблема:** Ошибка при загрузке видео по частям (chunks).
**Решение:**
1. Проверить `chunk_size` — должен быть кратен размеру видео
2. Убедиться что `total_chunk_count` корректен
3. Каждый chunk загружать с правильным `chunk_number`
4. Повторить неудавшийся chunk (не всю загрузку)

### Video processing failed (FAILED status)
**Проблема:** Видео не прошло обработку на стороне TikTok.
**Решение:**
- Проверить формат: MP4 или MOV (H.264 + AAC)
- Проверить размер: не более 500 МБ
- Проверить длительность: не менее 3 сек
- Проверить разрешение: минимум 540x960

## Research API

### Доступ запрещён (403 Forbidden)
**Проблема:** Нет доступа к Research API.
**Решение:** Research API требует отдельной заявки. Подать на https://developers.tiktok.com/ с описанием целей использования.

### Превышена дневная квота (Error 10010)
**Проблема:** Превышен лимит 1000 запросов/день или 100 000 записей/день.
**Решение:** Оптимизировать запросы, кэшировать результаты. Для увеличения лимитов — заявка в TikTok Support.

## TikTok Ads Manager

### Campaign rejected
**Проблема:** Рекламная кампания отклонена модерацией.
**Частые причины:**
- Нарушение рекламных политик TikTok
- Запрещённый контент или продукты
- Некорректные Landing Pages
- Обманчивые заголовки
**Решение:** Ознакомиться с TikTok Advertising Policies, исправить креативы, подать на повторную модерацию.

### Низкий охват при хорошем бюджете
**Проблема:** Кампания тратит мало при достаточном бюджете.
**Решение:**
1. Расширить аудиторию (меньше фильтров)
2. Увеличить ставку (bid)
3. Проверить качество креатива (engagement rate)
4. Убедиться что нет пересечения аудиторий между ad groups

### Высокий CPM
**Проблема:** Стоимость за 1000 показов слишком высокая.
**Решение:**
- Использовать Spark Ads (более низкий CPM)
- Таргетировать менее конкурентные аудитории
- Улучшить engagement rate креатива (лучший контент = ниже CPM)
- Тестировать разные форматы и аудитории

## Promote

### Promote недоступен для видео
**Проблема:** Кнопка Promote неактивна.
**Возможные причины:**
- Аккаунт не бизнес/creator
- Видео нарушает Community Guidelines
- Видео использует защищённую музыку
- Региональные ограничения
**Решение:** Переключиться на Business/Creator аккаунт. Заменить музыку на Commercial Sound.

## Embed API

### oEmbed возвращает ошибку
**Проблема:** `GET /oembed?url=...` возвращает 404 или ошибку.
**Решение:**
- Проверить что URL видео корректен и публично доступен
- Формат URL: `https://www.tiktok.com/@username/video/{video_id}`
- Приватные видео не поддерживают oEmbed

### Embed не отображается на сайте
**Проблема:** Встроенное видео не загружается.
**Решение:**
1. Убедиться что `embed.js` загружен: `<script async src="https://www.tiktok.com/embed.js"></script>`
2. Проверить CSP (Content Security Policy) — разрешить `*.tiktok.com`
3. Проверить что блокировщик рекламы не блокирует TikTok-скрипты

## TikTok Shop

### Товар не прошёл модерацию
**Проблема:** Товар отклонён при добавлении в каталог.
**Решение:**
- Проверить категорию товара (некоторые категории запрещены)
- Улучшить описание и изображения
- Убедиться что цена адекватная
- Проверить соответствие локальным законам (для ОАЭ — лицензирование туристических услуг)

### Заказы не синхронизируются
**Проблема:** Заказы из TikTok Shop не появляются в вашей системе.
**Решение:**
1. Проверить Webhook URL (должен быть доступен из интернета)
2. Проверить SSL-сертификат (HTTPS обязателен)
3. Проверить формат ответа (200 OK в течение 5 сек)
4. Проверить логи на стороне TikTok Shop Seller Center

## Общие проблемы

### Rate limit exceeded (Error 10005)
**Проблема:** Слишком много запросов к API.
**Решение:**
- Реализовать exponential backoff
- Кэшировать ответы API
- Оптимизировать количество запросов
- Для повышения лимитов — заявка через TikTok Support

### SSL/TLS errors
**Проблема:** Ошибки SSL при обращении к API.
**Решение:** Обновить корневые сертификаты. TikTok API требует TLS 1.2+.

### Неожиданный формат ответа
**Проблема:** API возвращает данные в неожиданном формате.
**Решение:** Проверить версию API (v2 vs v1). TikTok мигрировал на API v2 — убедиться что используются актуальные эндпоинты `open.tiktokapis.com/v2/`.
