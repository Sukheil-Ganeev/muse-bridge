# FIX-002: Точность триггеров — контекст важнее глаголов

- **ID:** FIX-002
- **Дата:** 2026-02-17
- **Источник:** reviewer-report.md (MEDIUM #2), tester-report.md (MEDIUM #5)

## Контекст

Триггеры скилла содержали широкие глаголы: "сделай", "напиши", "создай", "исправь". Эти слова встречаются в 70%+ запросов пользователя, что приводило к ложным активациям. Пример: "сделай мне красивый текст поздравления" — не про код, но триггер срабатывал.

## Проблема

1. Глаголы слишком общие — совпадают с бытовыми запросами
2. Отсутствовали технические глаголы: optimize, deploy, улучши, обнови
3. Отсутствовали английские варианты: generate code, write function, fix bug

## Решение

Добавил контекстный квалификатор после глаголов: `— В КОНТЕКСТЕ КОДА (функцию, скрипт, API, бота, модуль, сайт)`. Это фильтрует нетехнические запросы. Также добавил недостающие глаголы на русском и английском.

## Урок

**Триггеры скилла = глагол + контекст, не просто глагол.** "Сделай" может означать что угодно. "Сделай функцию" — однозначно код. Контекстные квалификаторы снижают false positive без потери true positive.
