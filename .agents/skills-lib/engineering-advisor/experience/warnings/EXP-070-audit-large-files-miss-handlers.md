# EXP-070: Аудит больших файлов (>1000 строк) может пропустить существующий код

- **Дата:** 2026-02-28
- **Severity:** medium
- **Тип:** warning
- **Проект:** rassilka-bot

## Проблема
Первичный аудит файла admin.py (~1500 строк) показал 11 "мёртвых кнопок" без handlers.
При детальном анализе оказалось что ВСЕ 11 handlers уже существовали — просто Explore-агент
не прочитал файл до конца из-за его размера.

## Урок
Для файлов >1000 строк:
1. НЕ доверять результату одного Explore — перепроверять
2. Grep по конкретным callback_data строкам: `F.data == "manage_groups"`
3. Или grep по `startswith("cancel_broadcast")` для динамических callbacks
4. Читать файл частями (offset+limit) если он слишком большой

## Правило
Перед заявлением "handler не существует" — обязательно grep:
```
grep -n "callback_data_string" handlers/*.py
```
