# WARN-006: Субагенты НЕ наследуют контекст скиллов — передавай вручную

**Дата:** 2026-02-22
**Проект:** VoiceTranscriptionBot v5.5.0
**Severity:** critical
**Категория:** warning

## Инцидент

При работе через субагентов (волновая стратегия, параллельные агенты) ключевые правила из активного скилла engineering-advisor НЕ были переданы субагентам. В результате:

- Бэкапы не делались (правило #9 из CLAUDE.md)
- MagicMock(spec=...) не был указан во всех промптах (правило из EXP-041)
- Формат бэкапов не соблюдался (backups/файл_ДАТА_ВРЕМЯ.py)

Субагенты работают в изолированном контексте — они НЕ видят:
- Активные скиллы главного окна
- Содержимое CLAUDE.md (если не передать явно)
- Уроки из experience/
- Правила форматирования и стайл-гайды

## Правило (ОБЯЗАТЕЛЬНО)

**В КАЖДЫЙ промпт для субагента включать блок "Правила проекта":**

```
## Правила проекта (ОБЯЗАТЕЛЬНО)
1. ПЕРЕД редактированием файла — бэкап в backups/: cp файл backups/файл_YYYY-MM-DD.py
2. Тесты: MagicMock(spec=RealClass), НЕ голый MagicMock()
3. Проверить ВСЕ обращения к полям dataclass — сверить с определением класса
4. Форматирование: эмодзи в заголовках, разделители "─" * 18, код в <code>
5. Не хардкодить строки — использовать i18n/константы
6. html.escape() для пользовательского ввода в Telegram
```

**Минимальный набор для ЛЮБОГО субагента:**
- Бэкап перед правкой
- MagicMock(spec=...)
- Стиль проекта (из CLAUDE.md или STYLE_GUIDE.md)

**Расширенный набор (для сложных задач):**
- Все уроки из experience/_index.md топ-5
- Конкретные правила скилла, релевантные задаче
- Ссылки на docs/STYLE_GUIDE.md

## Шаблон промпта для субагента

```
ЗАДАЧА: [описание]

## Правила проекта (ОБЯЗАТЕЛЬНО)
- Бэкап: cp оригинал → backups/имя_ДАТА.расширение
- Тесты: MagicMock(spec=RealClass)
- Dataclass: сверяй .field с @dataclass определением
- Формат: эмодзи + разделители + <code> для чисел/дат

## Контекст
[что нужно прочитать, какие файлы связаны]

## Шаги
[конкретные действия]
```

## Почему это важно

Субагент — это чистый лист. Он не знает ни о каких скиллах, правилах, уроках. Если не передать — он сделает по-своему. Это как отправить нового сотрудника на объект без инструктажа: он сделает работу, но нарушит 5 правил безопасности, потому что никто не сказал.
