# WARN-005: Бэкапы ПЕРЕД редактированием — не после

**Дата:** 2026-02-22
**Проект:** VoiceTranscriptionBot v5.5.0
**Severity:** critical
**Категория:** warning

## Инцидент

При реализации v5.5.0 (30 фич, 15+ файлов изменено) бэкапы НЕ были сделаны перед редактированием. Правило из CLAUDE.md было нарушено:

> "ОБЯЗАТЕЛЬНО: Бэкапы ПЕРЕД любыми изменениями. Перед редактированием любого файла — сохрани копию в backups/ с датой и временем. Это железное правило, без исключений."

Бэкапы были сделаны post-factum после того, как пользователь указал на нарушение.

## Причина

При работе через субагентов (волновая стратегия, параллельные агенты) шаг "сделай бэкап" не был включён в промпты для субагентов. Диспетчер (главное окно) сфокусировался на скорости выполнения и пропустил этот шаг.

## Правило (ОБЯЗАТЕЛЬНО при каждой сессии)

**В КАЖДЫЙ промпт для субагента, который РЕДАКТИРУЕТ файлы, добавлять:**

```
ПЕРЕД любым редактированием: скопируй оригинал файла в backups/ с датой.
Пример: cp admin/main.py backups/admin_main_YYYY-MM-DD_HH-MM.py
```

**Или делать бэкап-волну ПЕРЕД основными волнами:**
- Волна -1 (бэкап): скопировать все файлы, которые будут изменены
- Волна 0+: основная работа

## Чек-лист для диспетчера

- [ ] Перед запуском волны: определить список файлов для изменения
- [ ] Запустить бэкап-агента ПЕРВЫМ (до любых правок)
- [ ] В промптах субагентов: напомнить про бэкап если файл ещё не скопирован
- [ ] После завершения: проверить что все изменённые файлы имеют бэкап
