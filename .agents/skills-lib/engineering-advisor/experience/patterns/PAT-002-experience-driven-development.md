## Контекст

Engineering Advisor накопил 39+ уроков из 9 реальных проектов. Но уроки НЕ ПРЕДОТВРАТИЛИ повторения старых ошибок в новом проекте (VoiceTranscriptionBot), потому что:
1. Уроки не загружались при старте сессии
2. Не было обязательного протокола "проверь experience/ перед работой"
3. Не было механизма записи новых уроков по завершении

## Паттерн: Experience-Driven Development

```
СТАРТ СЕССИИ:
  → Загрузить experience/_index.md
  → Прочитать топ-5 критических уроков
  → Объявить команде: "Загружено N уроков"

ВО ВРЕМЯ РАБОТЫ:
  → При каждом code review — сверять с уроками
  → При обнаружении бага — проверить: есть ли похожий урок?
  → Если да → times_applied++
  → Если нет → пометить для записи

КОНЕЦ СЕССИИ:
  → Есть новые уроки? → Записать в experience/
  → Обновить _index.md
  → Предложить интеграцию в SKILL.md если >= 10 новых записей
```

## Урок

**Опыт без системы загрузки — мёртвый опыт.** 39 уроков бесполезны если их не читать при старте. Теперь загрузка experience/ — MANDATORY при каждой активации скилла.

## Метрика успеха

- До: 0 уроков предотвратили баги в VoiceTranscriptionBot
- После: каждый урок должен предотвращать >=1 баг за 5 сессий
