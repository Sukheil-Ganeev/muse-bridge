### Триггер #7 (верификация) — тесты = доказательство для кодовых проектов
Первый запуск бота (Волна 1) показал TypeError. Без реального запуска — баг бы остался. Но начиная с 338 тестов (Волна 3), тест-агент запускает pytest и это само по себе является "фактическим результатом". Для кодовых проектов с хорошим покрытием тестами отдельный verification step не нужен — тесты достаточны.

### Триггер #3 (бизнес-логика) — формулы покрыты тестами
ai_adapter.py управляет AI-генерацией (деньги за API-вызовы), publisher.py публикует контент (репутационные риски). Тесты для обоих модулей нашли:
- Fallback chain работает (Gemini → Groq → original text)
- Publisher корректно обрабатывает partial failure (2/3 OK, 1/3 FAIL)

Волна 3 добавила:
- MetricsService: `(likes + comments + shares) / views * 100` — engagement_rate
- ScoringService: weighted average 5 критериев
- ABTestService: confidence formula, determine_winner
- Все формулы покрыты тестами (test_calculate_engagement_rate, test_weighted_average, test_determine_winner)

### Триггер #4 (безопасность) — API ключи в .env
Все 56 файлов используют ENV переменные через config.py. Ни один API ключ не хардкожен в коде. Паттерн: graceful degradation если ключ пуст (AI adapter возвращает original text, интеграции отключаются).
