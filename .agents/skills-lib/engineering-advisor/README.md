# Engineering Advisor v4.0

Автоматический советник по инженерным практикам для вайб-кодера. Определяет 22 сценария риска в коде и рекомендует действия с тремя уровнями серьёзности (Advisory / Recommended / MANDATORY).

## Как работает

Engineering Advisor — **маршрутизатор**: обнаруживает ситуацию, объясняет понятным языком и направляет к нужному инструменту (superpowers или другому скиллу). Сам он код не пишет и не тестирует.

1. При работе с кодом автоматически сканирует на 22 триггера
2. При срабатывании — объясняет ситуацию простыми словами (аналогии из туристического бизнеса)
3. Предлагает готовый промпт и делегирует нужному superpowers-скиллу
4. Выводит результат в формате Severity: 🔴 BLOCK / 🟡 WARN / 🟢 INFO

## Три уровня рекомендаций

- **Advisory** (🟢) — совет друга. Можно проигнорировать.
- **Recommended** (🟡) — совет врача. Пропуск создаёт реальный риск.
- **MANDATORY** (🔴) — техника безопасности. Обязательно. Оплата, безопасность, деплой, блокирующие вызовы в async.

## Система опыта

Скилл накапливает опыт в `experience/`. При активации читает `_index.md` (топ-5 критических уроков). При завершении предлагает записать новые уроки. 54+ записей из 9 реальных проектов.
