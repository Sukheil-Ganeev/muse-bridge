# VK-СПРАВОЧНИК

Production-ready руководство по VK как платформе для туристического бизнеса в ОАЭ.

## Структура справочника

```
vk-справочник/
├── SKILL.md              # Основной файл (~4500 слов)
├── README.md             # Этот файл - описание структуры
├── references/           # Подробные руководства
│   ├── faq.md            # 15 частых вопросов
│   ├── troubleshooting.md # 15 типичных проблем
│   └── cheatsheet.md     # Шпаргалка по методам API
└── experience/           # Накопленный опыт
    └── _index.md
```

## Быстрый старт

1. **Читать:** `SKILL.md` — обзор всех возможностей VK-платформы
2. **Шпаргалка:** `references/cheatsheet.md` — быстрый доступ к методам
3. **Проблемы:** `references/troubleshooting.md` — решения типичных ошибок

## Основные возможности (платформа)

- Управление сообществами (создание, настройки, участники)
- Стена и контент (посты, отложенные записи, медиа)
- VK Clips (короткие видео)
- VK Stories (истории с ссылками)
- VK Market (товары и услуги)
- VK Donut (платные подписки)
- VK Articles (лонгриды)
- VK Live (прямые трансляции)
- VK Реклама (таргетинг, Stories Ads, Carousel)
- Аналитика (stats.get, stats.getPostReach)
- VK Mini Apps (мини-приложения)
- Модерация (фильтры, чёрный список)

## Что НЕ входит в этот справочник

- Боты сообществ (Long Poll, Callback API, messages.send) -> см. `vk-bot-справочник`
- VK Video API (подробности) -> см. `vk-video-справочник`

## Кейсы для туризма ОАЭ

1. **Автопостинг экскурсий** — ежедневное расписание туров
2. **VK Market** — каталог экскурсий как товаров
3. **VK Clips** — короткие видео достопримечательностей
4. **VK Donut** — VIP-контент и эксклюзивные скидки
5. **Stories со ссылками** — промо с прямым бронированием

## Технические детали

**Версия API:** v5.199 (2026)

**Rate Limits:**
- Community Token: 3 req/sec
- User Token: 5 req/sec
- Standalone App: 20 req/sec

**Языки примеров:** Python, JavaScript, Bash (curl)
