## Советы по адаптации примеров

### Для вашей ситуации замените:

| В примере | На ваши данные |
|-----------|----------------|
| [Field] | Ваша специальность |
| [University Name] | Ваш университет |
| [Year] | Год окончания |
| 500+ clients | Ваше реальное число |
| AED 2,500 | Ваш средний чек |
| 5+ years | Ваш реальный опыт |

### Цифры, которые нужно подготовить:
- Количество клиентов (всего / в месяц)
- Средний чек заказа
- Количество обработанных запросов в день
- Время ответа клиентам
- % повторных покупок
- Количество поставщиков
- Результаты выставок (контакты, заказы)

### Если чего-то не знаете точно:
- Используйте приблизительные числа с "approximately" или "~"
- Или уберите конкретную цифру, оставив качественное описание
- Никогда не придумывайте цифры — их могут проверить
