# CV для туристической индустрии ОАЭ

Специализированный скилл для создания CV в сфере туризма ОАЭ.

## Структура скилла

```
cv-туризм-оаэ/
├── SKILL.md                    # Основной файл (полное руководство)
├── README.md                   # Этот файл
└── references/
    ├── специфика-оаэ.md        # Визы, зарплаты, формат CV
    ├── целевые-компании.md     # Ticket Combo, ETHARA, Platinumlist
    ├── ключевые-слова.md       # ATS для туризма
    ├── примеры-cv.md           # Образцы для туризма
    └── вопросы-кандидату.md    # 22 вопроса для сбора информации
```

## Целевые компании

| Компания | Тип | Сайт |
|----------|-----|------|
| Ticket Combo | Тикетинг | ticketcombo.ae |
| ETHARA | DMC | ethara.com |
| Platinumlist | Events | platinumlist.net |

## Когда использовать

- Создание CV для туристической индустрии ОАЭ
- Переквалификация из fashion/retail в туризм
- Подготовка к интервью в туркомпаниях
- Адаптация опыта под ATS

## Ключевые преимущества кандидата

1. **Трилингвизм** — арабский, английский, русский
2. **Опыт с международной клиентурой** — GCC, Европа, СНГ
3. **Знание ОАЭ** — локации, культура, специфика
4. **Визовый статус** — резидент ОАЭ

## Как использовать

1. Прочитай `SKILL.md` для понимания контекста
2. Используй `вопросы-кандидату.md` для сбора информации
3. Подбери ключевые слова из `ключевые-слова.md`
4. Адаптируй опыт по примерам из `примеры-cv.md`
5. Учитывай специфику из `специфика-оаэ.md` и `целевые-компании.md`
