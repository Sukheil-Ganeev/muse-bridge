## 4. КОМИССИИ ПЛАТЁЖНЫХ СИСТЕМ

### 4.1 Visa / Mastercard конвертация

| Компонент | Процент |
|-----------|---------|
| Базовый курс конвертации | Рыночный курс |
| Markup Visa/MC | 1.0–1.5% |
| Foreign transaction fee | 0.5–1.0% |
| **ИТОГО потери на курсе** | **1.5–2.5%** |

### 4.2 Как это работает

```
Рыночный курс:     1 AED = 120.00 KZT
Курс Visa/MC:      1 AED = 117.00–118.00 KZT (хуже на 1.5-2.5%)

Снимаешь 1,000 AED:
- По рыночному: должен списаться 120,000 KZT
- По курсу Visa: списывается 122,000–123,000 KZT
- Потеря: 2,000–3,000 KZT (~2%)
```

### 4.3 Важно

- Курс Visa/MC ВСЕГДА хуже рыночного
- Это скрытая комиссия, которую не показывают отдельно
- При снятии в банкомате всегда выбирай **AED** (не соглашайся на конвертацию в KZT)

## 6. НАША ШКАЛА НАЦЕНОК

### 6.1 Прогрессивная шкала

| Сумма (AED) | Наценка | Наши расходы | Чистая маржа |
|-------------|---------|--------------|--------------|
| до 200 | 20% | ~14% | ~6% |
| 200–500 | 12% | ~8% | ~4% |
| 500–1,500 | 10% | ~5% | ~5% |
| 1,500–3,000 | 8% | ~4% | ~4% |
| от 3,000 | 7% | ~3.5% | ~3.5% |

### 6.2 Формула расчёта курса

```
КУРС ДЛЯ КЛИЕНТА = API_КУРС × (1 + НАЦЕНКА%)

Где:
- API_КУРС = актуальный курс AED/KZT из ExchangeRate-API
- НАЦЕНКА% = зависит от суммы (см. таблицу выше)
```

### 6.3 Примеры расчётов

**Пример 1: Мелкая сумма 150 AED (наценка 20%)**
```
API курс:           1 AED = 120 KZT
Наш курс:           1 AED = 120 × 1.20 = 144 KZT
Клиент платит:      150 × 144 = 21,600 KZT
Наша выручка:       150 × 0.20 = 30 AED
Наши расходы:       ~21 AED (14%)
Чистая прибыль:     ~9 AED (6%)
```

**Пример 2: Средняя сумма 900 AED (наценка 10%)**
```
API курс:           1 AED = 120 KZT
Наш курс:           1 AED = 120 × 1.10 = 132 KZT
Клиент платит:      900 × 132 = 118,800 KZT
Наша выручка:       900 × 0.10 = 90 AED
Наши расходы:       ~45 AED (5%)
Чистая прибыль:     ~45 AED (5%)
```

**Пример 3: Крупная сумма 3,500 AED (наценка 7%)**
```
API курс:           1 AED = 120 KZT
Наш курс:           1 AED = 120 × 1.07 = 128.4 KZT
Клиент платит:      3,500 × 128.4 = 449,400 KZT
Наша выручка:       3,500 × 0.07 = 245 AED
Наши расходы:       ~122 AED (3.5%)
Чистая прибыль:     ~123 AED (3.5%)
```

## 8. ВАЖНЫЕ НЮАНСЫ

### 8.1 Лимит Kaspi 300K KZT

- Это ~2,500 AED по текущему курсу
- После исчерпания комиссия 0.95%
- Лимит обновляется 1-го числа каждого месяца

### 8.2 Несколько снятий

При суммах > 3,000 AED нужно несколько снятий:
- Каждое снятие = +20 AED комиссия банкомата
- Учитывай это в расчётах

### 8.3 Выбор валюты в банкомате

**ВСЕГДА выбирай:**
- "Withdraw in AED" ✅
- "Without conversion" ✅

**НИКОГДА не выбирай:**
- "Convert to KZT" ❌ (DCC — невыгодный курс)
