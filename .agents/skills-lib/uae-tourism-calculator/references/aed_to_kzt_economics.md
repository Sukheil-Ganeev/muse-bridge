## 6. НАША ШКАЛА НАЦЕНОК

### 6.1 Прогрессивная шкала

| Сумма (AED) | Наценка | Наши расходы | Чистая маржа |
|-------------|---------|--------------|--------------|
| до 500 | 7% | ~3% | ~4% |
| 500–1,500 | 5% | ~2.5% | ~2.5% |
| 1,500–3,000 | 4% | ~2% | ~2% |
| от 3,000 | 3% | ~2% | ~1% |

### 6.2 Формула расчёта курса

```
СУММА KZT = AED × КУРС_AED_KZT × (1 - КОМИССИЯ%)

Где:
- КУРС_AED_KZT = актуальный курс из ExchangeRate-API
- КОМИССИЯ% = наша наценка (см. таблицу выше)

Альтернативная формула:
КУРС_ДЛЯ_КЛИЕНТА = API_КУРС × (1 - НАЦЕНКА%)
```

### 6.3 Примеры расчётов

**Пример 1: Мелкая сумма 300 AED (наценка 7%)**
```
API курс:           1 AED = 135 KZT (примерный)
Сумма без комиссии: 300 × 135 = 40,500 KZT
Наша комиссия:      40,500 × 7% = 2,835 KZT (~21 AED)
Клиент получает:    40,500 - 2,835 = 37,665 KZT
Эффективный курс:   37,665 / 300 = 125.55 KZT/AED

Наши расходы:       300 × 3% = 9 AED
Чистая прибыль:     21 - 9 = 12 AED (4%)
```

**Пример 2: Средняя сумма 1,000 AED (наценка 5%)**
```
API курс:           1 AED = 135 KZT
Сумма без комиссии: 1,000 × 135 = 135,000 KZT
Наша комиссия:      135,000 × 5% = 6,750 KZT (~50 AED)
Клиент получает:    135,000 - 6,750 = 128,250 KZT
Эффективный курс:   128,250 / 1,000 = 128.25 KZT/AED

Наши расходы:       1,000 × 2.5% = 25 AED
Чистая прибыль:     50 - 25 = 25 AED (2.5%)
```

**Пример 3: Крупная сумма 2,500 AED (наценка 4%)**
```
API курс:           1 AED = 135 KZT
Сумма без комиссии: 2,500 × 135 = 337,500 KZT
Наша комиссия:      337,500 × 4% = 13,500 KZT (~100 AED)
Клиент получает:    337,500 - 13,500 = 324,000 KZT
Эффективный курс:   324,000 / 2,500 = 129.6 KZT/AED

Наши расходы:       2,500 × 2% = 50 AED
Чистая прибыль:     100 - 50 = 50 AED (2%)
```

**Пример 4: Крупная сумма 5,000 AED (наценка 3%)**

## 7. СРАВНЕНИЕ СО SWIFT

### 7.1 SWIFT перевод — детали

**Процесс:**
```
AED счёт в ОАЭ → SWIFT → Корреспондент (USD) → Банк в КЗ → KZT счёт
```

**Комиссии SWIFT:**

| Этап | Комиссия |
|------|----------|
| Банк-отправитель (ОАЭ) | $25-35 или 0.1-0.25% |
| Банк-корреспондент | $15-25 (списывается из суммы) |
| Банк-получатель (КЗ) | $0-15 или 0.1% |
| Конвертация AED → USD | ~0.5% |
| Конвертация USD → KZT | ~0.5-1% |
| **ИТОГО** | **$55-75 + 1-2%** |

### 7.2 Когда SWIFT выгоднее

| Сумма | Криптомост (3%) | SWIFT ($60 + 1.5%) | Лучший вариант |
|-------|-----------------|---------------------|----------------|
| 500 AED | 15 AED | ~77 AED (15%) | Криптомост |
| 1,000 AED | 30 AED | ~75 AED (7.5%) | Криптомост |
| 2,000 AED | 60 AED | ~90 AED (4.5%) | Криптомост |
| 5,000 AED | 150 AED | ~135 AED (2.7%) | SWIFT (едва) |
| 10,000 AED | 300 AED | ~210 AED (2.1%) | SWIFT |

**Вывод:** SWIFT становится выгоднее только от ~5,000 AED, но криптомост всё равно быстрее (30 мин vs 3-5 дней).

### 7.3 Недостатки SWIFT

- **Срок:** 3-5 рабочих дней (выходные не считаются)
- **Нужен счёт в банке ОАЭ** (не все туристы имеют)
- **Могут запросить документы** о происхождении средств
- **Непредсказуемые комиссии** корреспондентов

## 9. ВАЖНЫЕ НЮАНСЫ

### 9.1 Лимиты P2P Binance

- Без верификации: $300/день
- С KYC: практически без лимита
- Рекомендуем иметь верифицированный аккаунт

### 9.2 Время работы

**Лучшее время для P2P сделок:**
- Рабочие дни: 10:00-20:00 (время Астаны)
- Больше мерчантов онлайн
- Лучшие курсы

**Избегать:**
- Ночь и раннее утро (мало мерчантов)
- Праздничные дни (плохие курсы)

### 9.3 Безопасность операций

**Для обменника AED → USDT:**
- Работай только с проверенными обменниками
- Проверяй адрес кошелька перед отправкой
- Храни чеки и подтверждения

**Для P2P:**
- Используй только эскроу Binance
- Не отпускай крипту до реального зачисления
- Сохраняй переписку в чате сделки

### 9.4 Налоговые аспекты

- В ОАЭ нет налога на криптоoperации
- В Казахстане криптодоход облагается 10%
- При регулярных операциях рекомендуется консультация с налоговым специалистом
