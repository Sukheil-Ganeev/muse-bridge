## 4. РАСЧЁТ РЕАЛЬНЫХ РАСХОДОВ

### 4.1 Формула расходов

```
РАСХОДЫ = Комиссия_сети + Потеря_на_курсе + Время_поездки

Где:
- Комиссия сети TRC20: ~$1 (фикс)
- Потеря на курсе: ~1% (обменник даёт хуже чем официальный)
- Время поездки: твоя оценка (бензин, время, парковка)
```

### 4.2 Примеры расчёта расходов

**Пример 1: Мелкая сумма 100 USDT (~367 AED)**

```
Комиссия сети:        $1 = 3.67 AED
────────────────────────────────────────
Получишь:             365 - 3.67 = 361.33 AED
Потеря:               367.25 - 361.33 = 5.92 AED (~1.6%)
```

## 6. НАША ШКАЛА НАЦЕНОК ДЛЯ USDT

### 6.1 Логика наценки

Мы предоставляем сервис:
- Принимаем крипту на свой кошелёк (риски)
- Едем в обменник (время, бензин)
- Обмениваем по неофициальному курсу
- Клиенту не нужно самому разбираться

**За это мы берём комиссию!**

### 6.2 Прогрессивная шкала

| Сумма (USDT) | Наши расходы | Наценка | Чистая маржа |
|--------------|--------------|---------|--------------|
| до 100 | ~2% | **12%** | ~10% |
| 100–500 | ~1.5% | **10%** | ~8.5% |
| 500–1,500 | ~1% | **7%** | ~6% |
| 1,500–3,000 | ~0.8% | **5%** | ~4.2% |
| от 3,000 | ~0.5% | **4%** | ~3.5% |

### 6.3 Формула расчёта курса для клиента

```
КУРС_ДЛЯ_КЛИЕНТА = ОФИЦИАЛЬНЫЙ_КУРС × (1 - НАЦЕНКА%)

Или проще:
КЛИЕНТ_ПЛАТИТ_USDT = СУММА_AED / КУРС_ДЛЯ_КЛИЕНТА

Пример (500 AED, наценка 10%):
Официальный курс: 3.6725 AED за 1 USDT
Наш курс: 3.6725 × 0.90 = 3.305 AED за 1 USDT
Клиент платит: 500 / 3.305 = 151.3 USDT
Мы получаем: 151.3 × 3.65 = 552.2 AED
Наша прибыль: 552.2 - 500 = 52.2 AED (~10%)
```
