# Шаблоны сообщений для WhatsApp и Telegram

Шаблоны форматирования для туристических сообщений в ОАЭ.

---

## РАЗДЕЛ 1: ПРАВИЛА ФОРМАТИРОВАНИЯ

### 1.1. Синтаксис по платформам

| Элемент | WhatsApp | Telegram |
|---------|----------|----------|
| Жирный | `*текст*` | `**текст**` |
| Курсив | `_текст_` | `__текст__` |
| Категория | ` ```текст``` ` | `**текст**` |
| Зачёркнутый | `~текст~` | `~~текст~~` |

### 1.2. Разделители

| Платформа | Количество тире | Пример |
|-----------|-----------------|--------|
| WhatsApp | 15 тире | `───────────────` |
| Telegram | 18 тире | `──────────────────` |

### 1.3. Разрешённые эмодзи

Используются ТОЛЬКО два эмодзи:
- 💰 перед секцией *ЦЕНЫ* / **ЦЕНЫ**
- ⚠️ перед секцией *ВАЖНО* / **ВАЖНО**

Другие эмодзи ЗАПРЕЩЕНЫ для профессионального вида.

### 1.4. Формат цен

| Тип | Формат | Пример |
|-----|--------|--------|
| Базовый | `число$` | `50$` |
| С категориями | `цена$ взр / цена$ реб` | `50$ взр / 35$ реб` |
| Диапазон | `число-число$` | `50-80$` |

### 1.5. Правило ДВУХ пробелов (WhatsApp)

После ` ```категории``` ` перед ценой ВСЕГДА два пробела:
```
```Базовая```  50$ взр / 35$ реб
```

## РАЗДЕЛ 4: СТАНДАРТНЫЕ ФРАЗЫ

### На русском

- "Уточните, пожалуйста, *количество взрослых и детей* (с возрастом)"
- "Для бронирования нужны: дата, количество гостей, отель размещения"
- "Курс актуален в течение часа"

### Для оформления

```
*ДЛЯ ОФОРМЛЕНИЯ*
Дата, кол-во взр/детей (с возрастом), эмират и отель размещения
```

### Политика отмены

```
*ОТМЕНА*
За 48ч — 100% возврат | За 24ч — 50% | Менее 24ч — без возврата
```
