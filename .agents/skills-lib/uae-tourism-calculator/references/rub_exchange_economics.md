# Экономика обмена валют: RUB → AED

Полная документация по приёму российских рублей и конвертации в дирхамы.

---

## 1. ВАЖНО: ОГРАНИЧЕНИЯ ДЛЯ РОССИЙСКИХ КАРТ

### 1.1 Карты МИР НЕ работают в ОАЭ

| Статус | Описание |
|--------|----------|
| **МИР** | Не работает в ОАЭ из-за санкций |
| **Visa/MC российских банков** | Заблокированы международно |
| **UnionPay** | Работает с ограничениями |

**Причина:** Санкции США и ЕС против российских банков. Платёжная система МИР отключена от международных расчётов.

### 1.2 Доступные варианты для россиян

| Вариант | Работает? | Комиссии | Рекомендация |
|---------|-----------|----------|--------------|
| Карты МИР | Нет | — | Не использовать |
| Visa/MC (рос. банки) | Нет | — | Не использовать |
| **UnionPay** | Да | 1-2% | Резервный вариант |
| **Криптомост RUB→USDT→AED** | Да | 3-4% | Основной вариант |

## 3. РАСХОДЫ НА КАЖДОМ ЭТАПЕ

### 3.1 Этап 1: RUB → USDT (P2P биржа)

| Параметр | Значение |
|----------|----------|
| Способ | P2P на Binance/Bybit |
| Оплата | СБП (Сбер, Тинькофф, Альфа) |
| Курс ЦБ | ~95-100 RUB за $1 (варьируется) |
| Курс P2P | ~97-103 RUB за 1 USDT |
| **Спред** | **~2-3%** |
| Комиссия биржи | 0% |

**Пример:**
```
Курс ЦБ РФ:           1 USD = 98 RUB
Курс P2P Binance:     1 USDT = 100.5 RUB
Спред:                (100.5 - 98) / 98 = 2.5%
```

### 3.2 Этап 2: Перевод USDT

| Сеть | Комиссия | Время |
|------|----------|-------|
| TRC20 (Tron) | ~$1 (~3.7 AED) | 1-3 мин |
| BEP20 (BSC) | ~$0.3 | 1-3 мин |
| ERC20 | $5-30 | 5-15 мин |

**Рекомендация:** Используй TRC20

### 3.3 Этап 3: USDT → AED (обменник)

| Параметр | Значение |
|----------|----------|
| Официальный курс | 3.6725 AED за $1 |
| Курс обменника | 3.63-3.66 AED за 1 USDT |
| **Потеря на курсе** | **~0.5-1%** |

### 3.4 ИТОГО расходы криптомоста

| Этап | Расход |
|------|--------|
| RUB → USDT (спред P2P) | ~2-3% |
| Перевод USDT (комиссия сети) | ~$1 (фикс) |
| USDT → AED (обменник) | ~0.5-1% |
| **ИТОГО** | **~3-4%** |

## 4. АЛЬТЕРНАТИВА: UnionPay

### 4.1 Какие банки выпускают UnionPay

| Банк | Выпуск UnionPay | Примечание |
|------|-----------------|------------|
| Газпромбанк | Да | Основной вариант |
| Россельхозбанк | Да | Есть ограничения |
| Почта Банк | Да | Виртуальная карта |
| Солидарность | Да | Региональный |

### 4.2 Комиссии UnionPay в ОАЭ

| Параметр | Значение |
|----------|----------|
| Конвертация RUB→AED | Через USD (двойная) |
| Комиссия банка-эмитента | 1-2% |
| Комиссия банкомата ОАЭ | 15-25 AED |
| Невыгодный курс конвертации | ~1-2% |
| **ИТОГО потерь** | **~4-6%** |

### 4.3 Сравнение: Криптомост vs UnionPay

| Параметр | Криптомост | UnionPay |
|----------|------------|----------|
| **Расходы** | ~3-4% | ~4-6% |
| Скорость | 30-60 мин | Сразу в банкомате |
| Сложность | Нужен крипто-кошелёк | Просто карта |
| Лимиты | Без ограничений | Лимиты банка |
| Риски | P2P мошенники | Отказ банкомата |

**Вывод:** Криптомост выгоднее на 1-2%, но требует навыков работы с криптой.

## 6. НАША ШКАЛА НАЦЕНОК ДЛЯ RUB

### 6.1 Прогрессивная шкала (фиксированная наценка к курсу)

| Сумма (AED) | Наценка к курсу | Наши расходы | Чистая маржа |
|-------------|-----------------|--------------|--------------|
| до 200 | **+5 руб** | ~3-4% | ~15-18% |
| 200–500 | **+4 руб** | ~3-4% | ~12-15% |
| 500–1,500 | **+3.5 руб** | ~3-4% | ~10-13% |
| 1,500–3,000 | **+3 руб** | ~3-4% | ~8-11% |
| от 3,000 | **+2.5 руб** | ~3-4% | ~6-9% |

### 6.2 Формула расчёта курса

```
КУРС ДЛЯ КЛИЕНТА = API_КУРС + НАЦЕНКА

Где:
- API_КУРС = актуальный курс RUB/AED из ExchangeRate-API
- НАЦЕНКА = фиксированная (см. таблицу выше)

Пример (при API курсе 27 RUB/AED):
- до 200 AED:     27 + 5 = 32 RUB/AED
- 200-500 AED:    27 + 4 = 31 RUB/AED
- 500-1,500 AED:  27 + 3.5 = 30.5 RUB/AED
- 1,500-3,000:    27 + 3 = 30 RUB/AED
- от 3,000 AED:   27 + 2.5 = 29.5 RUB/AED
```
