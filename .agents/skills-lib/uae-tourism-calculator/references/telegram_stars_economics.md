# Экономика оплаты: Telegram Stars → AED (Дубай)

Полная документация по приёму оплаты через Telegram Stars и конвертации в дирхамы.

---

## 1. ЧТО ТАКОЕ TELEGRAM STARS

```
Telegram Stars — внутренняя валюта Telegram для оплаты
цифровых товаров и услуг через ботов и мини-приложения.

Код валюты: XTR
Тип:        Виртуальная валюта (не крипто)
Платформа:  Telegram Bot API
Вывод:      Fragment → TON → USDT → AED
```

### 1.1 Ключевые характеристики

| Параметр | Значение |
|----------|----------|
| Код валюты | `XTR` |
| Цена покупки (клиент) | ~$0.015-0.02 за 1 Star |
| Цена вывода (бизнес) | ~$0.013 за 1 Star |
| Комиссия Apple/Google | 30% (15% если доход <$1M/год) |
| Комиссия Telegram | ~5% |
| Бизнес получает | ~65% от оплаты клиента |
| Минимум вывода | 1,000 Stars |
| Холд перед выводом | 21 день |
| Вывод через | Fragment → TON |

### 1.2 Ограничение: только цифровые товары!

```
⚠️ КРИТИЧЕСКИ ВАЖНО:
Telegram Stars официально только для ЦИФРОВЫХ товаров и услуг.

✅ МОЖНО продавать через Stars:
- Электронные ваучеры / e-tickets
- Цифровые путеводители
- Онлайн-консультации
- Доступ к каналам/ботам
- Цифровой контент

❌ НЕЛЬЗЯ напрямую:
- Физические экскурсии
- Физические билеты
- Трансферы
- Аренду автомобилей

💡 ОБХОД: Продавать "цифровой ваучер на экскурсию" —
   по сути e-ticket, который обменивается на услугу.
   Юридически серая зона — на свой риск.
```

## 3. РАСХОДЫ НА КАЖДОМ ЭТАПЕ

### 3.1 Этап 1: Оплата клиентом (Stars)

| Параметр | Значение |
|----------|----------|
| Способ | Inline-кнопка "Оплатить" в Telegram-боте |
| Валюта | XTR (Telegram Stars) |
| Комиссия для бизнеса | 0% |
| Время зачисления | Мгновенно |
| **Холд** | **21 день до вывода!** |

**Откуда клиент берёт Stars:**

| Способ покупки | Цена за 1 Star | Комиссия | Рекомендация |
|----------------|----------------|----------|--------------|
| App Store (iOS) | ~$0.020 | 30% Apple | Дорого |
| Google Play (Android) | ~$0.018 | 30% Google | Дорого |
| @PremiumBot | ~$0.015 | ~5% Telegram | Выгоднее на 10-20% |
| TON Wallet (внутри TG) | ~$0.014 | ~3-5% | Самый дешёвый |
| P2P перепродавцы | ~$0.012-0.015 | Разная | Риск мошенничества |

### 3.2 Этап 2: Вывод через Fragment

| Параметр | Значение |
|----------|----------|
| Платформа | [fragment.com](https://fragment.com) |
| Курс вывода | ~$0.013 за 1 Star (фиксируется на момент вывода) |
| Комиссия Fragment | 0% |
| Минимум | 1,000 Stars |
| Нужен | TON-кошелёк |
| Время | 5-15 минут |

**Пошаговый процесс вывода:**
```
1. Открой настройки канала/бота → раздел "Stars"
2. Проверь баланс (минимум 1,000 Stars, старше 21 дня)
3. Нажми "Withdraw" → откроется Fragment
4. Залогинься через Telegram аккаунт
5. Подключи TON-кошелёк (Tonkeeper или TON Space)
6. Выбери сумму Stars для вывода
7. Проверь курс (фиксируется в момент вывода!)
8. Подтверди → TON придут на кошелёк за 1-5 мин
```

**Кошельки для TON:**

| Кошелёк | Платформа | Особенности |
|---------|-----------|-------------|
| **Tonkeeper** | iOS, Android, Desktop | Рекомендуется. Поддержка всех DEX |
| **TON Space** | Внутри Telegram | Удобно, но ограниченный функционал |
| **MyTonWallet** | Браузер | Для продвинутых |

### 3.3 Этап 3: TON → USDT (биржа)

| Параметр | Значение |
|----------|----------|
| Биржи | Bybit, OKX, Gate.io, MEXC |
| Пара | TON/USDT |
| Спред | ~1-2% |
| Комиссия трейда | ~0.1% (мейкер) / 0.15% (тейкер) |
| Комиссия вывода USDT (TRC20) | ~$1 |
| Время | 5-15 мин (трейд) + 1-3 мин (вывод) |

**Рекомендация:** Bybit — лучшая ликвидность TON/USDT, низкие комиссии.

**Пример:**
```
Получил: 500 TON (~$3,000 при TON=$6)
Продал на Bybit: 500 TON → 2,960 USDT (спред ~1.3%)
Комиссия трейда: ~4.4 USDT (0.15%)
Вывод TRC20: ~1 USDT
────────────────────────────────────────
Получил USDT: 2,954.6 USDT
Потеря: ~$45.4 (~1.5%)
```

## 4. ПОЛНАЯ СТОИМОСТЬ (КЛИЕНТ → БИЗНЕС)

### 4.1 Цепочка распределения стоимости

```
Клиент платит:    $0.02 за 1 Star   (100%)
├── Apple/Google:  ~$0.006            (30%)
├── Telegram:      ~$0.001            (5%)
└── Бизнес получает: $0.013 за 1 Star (65%)
    ├── TON→USDT:  ~$0.0002           (1.5%)
    ├── USDT→AED:  ~$0.0001           (1%)
    └── NET:       ~$0.0127 за 1 Star (~63.5%)

Эффективная комиссия: ~36.5% от оплаты клиента
```

### 4.2 Влияние фиксированных комиссий на малые суммы

| Сумма Stars | $1 TRC20 = | % от суммы |
|-------------|-----------|------------|
| 1,000 Stars ($13) | 7.7% | Дорого! |
| 2,500 Stars ($32.5) | 3.1% | Ощутимо |
| 5,000 Stars ($65) | 1.5% | Нормально |
| 10,000 Stars ($130) | 0.8% | Мало |
| 50,000 Stars ($650) | 0.15% | Незаметно |

**Вывод:** На мелких суммах фикс $1 TRC20 съедает маржу! Выводить Stars стоит накопительно, крупными пачками.

## 5. НАША ШКАЛА НАЦЕНОК ДЛЯ STARS

### 5.1 Логика наценки

Мы предоставляем сервис:
- Принимаем Stars через бота (настройка, поддержка)
- Ждём 21 день холд-период (замораживание денег!)
- Выводим через Fragment → TON → USDT → AED (4 этапа!)
- Берём на себя риск колебания курса TON
- Оплачиваем комиссии бирж и обменников

**За это мы берём наценку!**

### 5.2 Прогрессивная шкала

| Сумма (AED) | Наши расходы | Наценка | Чистая маржа |
|-------------|--------------|---------|--------------|
| до 200 | ~3.5% | **15%** | ~11.5% |
| 200–500 | ~3% | **12%** | ~9% |
| 500–1,500 | ~2.5% | **10%** | ~7.5% |
| 1,500–3,000 | ~2.5% | **8%** | ~5.5% |
| от 3,000 | ~2% | **6%** | ~4% |

> Наценка выше чем для USDT (4-12%) и RUB (+2.5-5 руб), потому что:
> 1. Холд 21 день (деньги заморожены!)
> 2. Двойная конвертация (TON→USDT→AED vs прямая USDT→AED)
> 3. Риск волатильности TON (может упасть за 21 день)
> 4. Сложность процесса (4 шага vs 2 для USDT)

### 5.3 Формула расчёта Stars для клиента

```
STARS = ceil(СУММА_AED / 3.6725 / 0.013 × (1 + НАЦЕНКА%))

Или поэтапно:
1. AED → USD:    сумма / 3.6725
2. USD → Stars:  USD / 0.013
3. + Наценка:    Stars × (1 + наценка)
4. Округлить:    до целых Stars (вверх)

Пример (500 AED, наценка 12%):
1. 500 / 3.6725 = $136.15
2. 136.15 / 0.013 = 10,473 Stars
3. 10,473 × 1.12 = 11,730 Stars
4. Округляем → 11,730 Stars
```

## 13. ВАЖНЫЕ НЮАНСЫ

### 13.1 Холд-период 21 день

```
⚠️ Stars нельзя вывести сразу!

Получил Stars 1 февраля → вывести можно с 22 февраля.
Это значит: 3 недели деньги заморожены.

Для туризма это проблема:
- Экскурсия завтра, а деньги через 3 недели
- Поставщику платить нужно сейчас
- Нужен оборотный капитал для покрытия

Решение: иметь оборотный капитал минимум на 1 месяц расходов
```

### 13.2 Волатильность TON

```
⚠️ Курс TON может измениться за 21 день!

Пример риска:
Получил 10,000 Stars → при выводе TON стоит $6 → получишь $130
Через неделю TON падает на 20% → получишь $104
Потеря: $26 (20%)

Как минимизировать:
- Выводить Stars → TON → USDT как можно быстрее
- Не держать TON на кошельке — сразу продавать за USDT
- Курс Stars фиксируется при выводе — это защищает
```

### 13.3 Безопасность

**При выводе через Fragment:**
- Проверяй адрес TON-кошелька перед отправкой
- Транзакции необратимы!
- Используй только свой кошелёк (не чужой)

**При продаже TON на бирже:**
- Работай только на проверенных биржах (Bybit, OKX)
- Включи 2FA на бирже
- Не используй P2P для продажи TON (лучше ордербук)

**При обмене USDT → AED:**
- Только проверенные обменники (см. usdt_exchange_economics.md)
- Проверяй отзывы на BestChange
- Крупные суммы — лучше в офисе

### 13.4 Рефанды

```
Клиент может запросить рефанд.
Бот должен обработать через API: refundStarPayment

Важно:
- Хранить telegram_payment_charge_id ВСЕХ платежей
- Срок рефанда определяется ботом (ты решаешь)
- Stars возвращаются клиенту, списываются с баланса бота
- Если Stars уже выведены — рефанд из своего баланса!
```

### 13.5 Время операций

| Этап | Время |
|------|-------|
| Оплата клиентом | Мгновенно (2 клика) |
| Холд-период | 21 день (!) |
| Вывод Fragment → TON | 5-15 мин |
| Продажа TON → USDT | 5-15 мин |
| Вывод USDT (TRC20) | 1-3 мин |
| Обмен USDT → AED | 15-30 мин |

**Лучшее время для продажи TON:**
- Рабочие дни: 10:00-20:00 (UTC)
- Больше ликвидности на биржах
- Не продавать в выходные (спреды шире)

### 13.6 Налоги и легальность

```
ОАЭ:
- Нет налога на криптооперации
- Telegram Stars не регулируются (виртуальная валюта, не крипто)

РФ:
- Stars: пока не регулируются

Казахстан:
- Криптодоход: 10% подоходный
```
