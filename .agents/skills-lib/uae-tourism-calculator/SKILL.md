| Шаг | Действие |
|-----|----------|

```

Мы переводим вам X,XXX₽

*② Клиент → вам:*
Клиент платит вам XX,XXX₽
Вы переводите нам XX,XXX₽

### Расчёт "К отправке нам"

```
К отправке = Полная сумма − Комиссия агента

Пример:
Полная сумма: 39,120₽
Комиссия агента: 3,050₽
К отправке нам: 39,120 - 3,050 = 36,070₽

## Алгоритм расчёта

```
1. Получить курс API (AED/RUB)
2. Определить наценку по шкале
3. Наш курс = API + наценка

ИТОГО (AED) = кол-во × цена
ПРИБЫЛЬ АГЕНТА (AED) = кол-во × прибыль/ед
К ОТПРАВКЕ (AED) = ИТОГО − ПРИБЫЛЬ

Всё в RUB = AED × наш курс, округл. до 10

ЗАРАБОТОК НА КУРСЕ = ИТОГО × наценка
(показывать только в режиме сотрудник)
```

### Если исходная сумма в USD

Марсель часто считает в долларах. Если сумма приходит в USD:

```
1. USD → AED:    сумма × 3.6725 (фикс курс)
   Пример: 1,500$ × 3.65 = 5,475 AED
2. Далее стандартный алгоритм AED → RUB
3. В карточке клиенту ПОКАЗЫВАТЬ разбивку:
   💵 *X,XXX$ × 3.65 = X,XXX AED*
```

Клиент должен видеть откуда взялась сумма в дирхамах.

## РАСЧЁТ ДЛЯ СОТРУДНИКА (в чате Claude)

**После выдачи карточки ВСЕГДА показывать отдельно:**

### Логика расчёта прибыли

**ЧЕРЕЗ АГЕНТА (50/50):**
- Агент не знает про схему 50/50
- Прибыль агента = Наша прибыль с продукта
- Заработок на курсе считаем от суммы К ОТПРАВКЕ

**НАПРЯМУЮ КЛИЕНТУ (100%):**
- Вся указанная прибыль = наша
- Заработок на курсе считаем от полной суммы

### Формулы

**Через агента:**
```
Прибыль с продукта = Прибыль агента (50/50)
База для курса = Итого − Прибыль агента
Заработок на курсе = База × наценка
```

**Напрямую клиенту:**
```
Прибыль с продукта = Указанная прибыль (100%)
База для курса = Итого (полная сумма)
Заработок на курсе = База × наценка
```

### Пример: через агента

```
4 билета × 260 AED, прибыль агента 25 AED/шт

ПРИБЫЛЬ С ПРОДУКТА:
4 × 25 = 100 AED (50/50)

ЗАРАБОТОК НА КУРСЕ:
База: 1,040 − 100 = 940 AED
940 × 3.50 = 3,290₽ = 156 AED

ИТОГО: 100 + 156 = 256 AED (6,305₽)
```

### Пример: напрямую клиенту

```
4 билета × 260 AED, прибыль 50 AED/шт

ПРИБЫЛЬ С ПРОДУКТА:
4 × 50 = 200 AED (100% наша)

ЗАРАБОТОК НА КУРСЕ:
База: 1,040 AED (полная сумма)
1,040 × 3.50 = 3,640₽ = 172 AED

ИТОГО: 200 + 172 = 372 AED (9,162₽)
```

## ИНТЕГРАЦИЯ С NOTION

### Когда записывать

```
✅ ЗАПИСЫВАТЬ:
- Клиент/агент подтвердил заказ
- Оплата получена или ожидается
- Реальная сделка

❌ НЕ ЗАПИСЫВАТЬ:
- Просто расчёт "посмотреть цену"
- Клиент ещё думает
- Тестовый расчёт
```

### Порядок записи

```
1️⃣ Сначала → 📦 Заказы (фиксируем сделку)
2️⃣ Потом  → 💱 Операции обмена (фиксируем валютную операцию)
3️⃣ В комментарии Операции → ссылка на Заказ
```

### Чеклист перед записью

```
□ Тип продажи определён (через агента / напрямую клиенту)
□ Себестоимость известна или вычислена
□ Курс получен из API
□ Суммы проверены (сходятся)
□ Карточка отправлена клиенту/агенту
```

### Как вычислить себестоимость

```
Себестоимость = Цена продажи − Общая прибыль

Пример:
Цена = 260 AED, прибыль = 50 AED/шт
Себестоимость = 260 - 50 = 210 AED
```

## РАСЧЁТ В TELEGRAM STARS ⭐

### Когда использовать

Клиент хочет оплатить через Telegram Stars (XTR) в боте.

### Ключевые параметры

```
Курс вывода Stars:     $0.013 за 1 Star
Курс USD/AED:          3.6725 (фикс)
Холд-период:           21 день
Минимум вывода:        1,000 Stars
Тип товара:            только цифровые (ваучеры, e-tickets)
```

### Шкала наценок Stars

| Сумма AED | Наценка |
|-----------|---------|
| до 200 | +15% |
| 200–500 | +12% |
| 500–1,500 | +10% |
| 1,500–3,000 | +8% |
| от 3,000 | +6% |

> Наценка выше чем RUB/USDT из-за: холд 21 день, двойная конвертация TON→USDT→AED, риск волатильности TON

### Алгоритм расчёта Stars

```
1. AED → USD:    сумма / 3.6725
2. USD → Stars:  USD / 0.013
3. + Наценка:    Stars × (1 + наценка по шкале)
4. Округлить:    до целых Stars (вверх)

ИТОГО Stars = ceil(AED / 3.6725 / 0.013 × (1 + наценка))
```

### Расчёт прибыли (для сотрудника)

```
Получено Stars → Fragment: Stars × $0.013 = USD
USD → TON → USDT (−1.5%): USD × 0.985
USDT → AED (курс ~3.65): USDT × 3.65
Минус комиссия TRC20: −3.67 AED
= Чистый приход AED
Прибыль = Чистый приход − Стоимость услуги
```
