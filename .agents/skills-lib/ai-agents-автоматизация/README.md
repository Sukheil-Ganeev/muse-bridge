# Скилл: AI Agents Автоматизация

## Описание

Скилл для создания AI-агентов и автоматизаций с использованием Make.com, Notion API и внешних API.

## Возможности

### Основной функционал

- **Автоматический workflow** — Claude самостоятельно создаёт документацию, тесты, мониторинг
- **11 интеллектуальных триггеров** — реагирует на ключевые фразы: "создай", "работает", "сломалось", "медленно", "агент", "интеграция" и др.
- **Проактивные подсказки** — предлагает клонирование проектов, добавление в каталог компонентов, оптимизацию
- **Автоверсионирование** — отслеживает и обновляет версии при изменениях в агентах
- **Чеклист здоровья** — проверяет целостность проекта, зависимости и конфигурации

### Интеграции

- Make.com API и сценарии
- Notion Database API
- REST API конфигурации
- Webhook триггеры
- Custom интеграции
