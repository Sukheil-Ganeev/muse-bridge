# Troubleshooting: Решение проблем

## Make.com

### Проблема: Модуль не выполняется
**Симптомы:** Серый значок, нет данных
**Решения:**
1. Проверь подключение (Connections в левом меню)
2. Проверь URL/токены
3. Запусти "Run this module only"

### Проблема: Router не создаёт ветки
**Симптомы:** Только одна линия от Router
**Решение:** Наведи на Router → нажми "+" для добавления ветки

### Проблема: Данные из предыдущего модуля не видны
**Симптомы:** Пустой список переменных
**Решения:**
1. Запусти предыдущий модуль "Run this module only"
2. Введи переменную вручную: `{{1.data.field}}`

## Notion

### Проблема: Invalid request URL (400)
**Причины:**
1. Database ID без дефисов
2. Интеграция не подключена

**Решения:**
1. Добавь дефисы: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`
2. В Notion: база → ⋯ → Connections → добавь интеграцию

### Проблема: Body failed validation (400)
**Причина:** Неправильный Value Type
**Решение:** Измени Value Type с "Text" на "Rich Text"

### Проблема: Missing parameter 'page'
**Причина:** Выбран Parent: Page ID
**Решение:** Выбери просто "Page ID" из Search Objects

### Проблема: Данные не обновляются в Notion
**Причины:**
1. Неправильный Page ID
2. Неправильное имя поля (Key)

**Решения:**
1. Проверь Page ID — должен быть из Search Objects той же ветки
2. Проверь Key — должен точно совпадать с названием колонки в Notion

## API

### Проблема: Authentication required
**Причина:** API не требует авторизации, но выбран тип с ключом
**Решение:** Выбери Authentication type = "No Auth"

### Проблема: Timeout / No response
**Причины:**
1. API недоступен
2. Неправильный URL

**Решения:**
1. Проверь API в браузере
2. Проверь URL на опечатки
3. Увеличь таймаут в настройках модуля

## Общие проблемы

### Проблема: Сценарий работал, теперь не работает
**Возможные причины:**
1. API изменил структуру ответа
2. Токен Notion истёк
3. База данных удалена/перемещена

**Диагностика:**
1. Запусти каждый модуль отдельно
2. Проверь логи ошибок
3. Проверь токены и подключения

### Проблема: Расход операций больше ожидаемого
**Причина:** Незапланированные запуски или ошибки
**Решение:**
1. Проверь расписание (Schedule)
2. Проверь что нет петель (loops)
3. Отключи сценарий если не нужен

### Дополнительные сценарии отладки

#### Проблема: JSON parsing error
**Причина:** Неправильный формат JSON в ответе API
**Решение:**
1. Проверь ответ API в браузере
2. Используй JSON модуль для парсинга
3. См. `03_ДАННЫЕ_И_МАППИНГ/JSON_ПАРСИНГ.md`

#### Проблема: Rate limit exceeded
**Причина:** Превышен лимит запросов к API
**Решение:**
1. Добавь модуль Sleep между запросами
2. Используй Iterator с задержкой
3. См. `08_ADVANCED/RATE_LIMITING.md`

#### Проблема: Webhook не получает данные
**Причина:** Неправильная настройка или URL
**Решение:**
1. Проверь что Webhook активен (зелёный)
2. Проверь URL в отправляющей системе
3. См. `06_WEBHOOKS_API/WEBHOOKS.md`
