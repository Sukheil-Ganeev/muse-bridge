# FAQ: Создание автоматизаций

## Make.com

### Что такое операция в Make.com?
Одна операция = один запуск одного модуля. Например, HTTP запрос = 1 операция, Search в Notion = 1 операция.

### Сколько операций в бесплатном плане?
1000 операций в месяц.

### Как посчитать расход операций?
Посчитай все модули в сценарии (кроме Router — он бесплатный). Например:
- HTTP (1) + Router (0) + 6×Search (6) + 6×Update (6) = 13 операций/запуск
- 13 × 30 дней = 390/месяц

### Как запустить один модуль для теста?
Правой кнопкой на модуль → "Run this module only"

### Как выровнять модули?
Правой кнопкой на пустом месте → "Auto-align"

## Notion API

### Где создать интеграцию?
notion.so/my-integrations → New integration

### Как подключить интеграцию к базе?
Открыть базу → ⋯ (три точки) → Connections → выбрать интеграцию

### Как получить Database ID?
Из URL базы данных: `notion.so/[DATABASE_ID]?v=...`
Добавить дефисы в формат UUID: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

### Почему Value Type = Rich Text, а не Text?
Notion API требует rich_text формат для текстовых полей. Text в Make.com — это упрощённый тип.

## AlAdhan API

### Какой метод расчёта для ОАЭ?
method=8 (Gulf Region)

### Нужен ли API ключ?
Нет, API бесплатный и открытый.

### Как получить время для другого города?
Изменить параметр city: `?city=Abu%20Dhabi&country=UAE&method=8`

## Общие вопросы

### Данные не отображаются в списке переменных
HTTP модуль ещё не запускался. Запусти его отдельно: "Run this module only"

### Ошибка 400 Invalid request URL
1. Проверь Database ID (должен быть с дефисами)
2. Проверь что интеграция подключена к базе (Connections)

### Ошибка Missing parameter 'page'
Выбран Parent: Page ID вместо Page ID. Нужен просто Page ID из Search Objects.
