## Каналы — быстрый старт

```
1. Чаты -> "+" -> Создать приватный канал
2. Фото + название + описание
3. Настроить одобрение заявок
4. Пригласить подписчиков (ссылка)
5. Публиковать контент
```

---

## Группа — быстрый старт

```
1. Чаты -> "+" -> Создать групповой чат
2. Добавить участников
3. Название + аватар
4. Назначить админов
5. Сгенерировать ссылку-приглашение
```
