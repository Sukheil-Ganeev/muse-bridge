# Примеры форматирования каждого типа контента

Подробные примеры оформления различных типов медиа-вложений в итоговом MD-документе.

---

## Голосовое сообщение

```markdown
**14:25 Клиент:**
🎤 *Голосовое сообщение (1:23):*
> Добрый день! Хотел уточнить по поводу завтрашней экскурсии.
> Во сколько нас заберут из отеля? И нужно ли брать с собой
> какие-то документы? Паспорт, например?
```

## Изображение

```markdown
**14:30 Клиент:**
📷 *Изображение: Скриншот бронирования*
> Скриншот из приложения Booking.com. Отель: JW Marriott Marquis Dubai.
> Даты: 20-25 января 2025. Номер бронирования: 123456789.
```

## PDF документ

```markdown
**14:35 Клиент:**
📄 *PDF: Авиабилеты*
> Электронные билеты Emirates EK123.
> Маршрут: Москва (SVO) → Дубай (DXB)
> Дата: 20.01.2025, вылет 10:30
> Пассажиры: Иванов Иван, Иванова Мария
```

## Контакт VCF

```markdown
**14:40 Клиент:**
📇 *Контакт: Водитель Ахмед*
> Телефон: +971 50 123 4567
> Заметка: Водитель для трансферов
```

## Геолокация

```markdown
**14:45 Клиент:**
📍 *Локация: JW Marriott Marquis Dubai*
> Координаты: 25.1866, 55.2576
> Адрес: Sheikh Zayed Rd, Business Bay, Dubai
```

## Видео

```markdown
**14:50 Клиент:**
🎥 *Видео (1:30):*
> Видеозапись из Desert Safari. Показывает дюны и джипы.
```

## Автоопределение типа контакта по паттернам

| Паттерны | Тип |
|----------|-----|
| турагент, комиссия, партнёр | агенты |
| обменник, курс, водитель, гид | поставщики |
| коллега, офис, зарплата | сотрудники |
| бронирование, экскурсия, тур | клиенты |
