# Промты для запуска в новом чате

Готовые промты для быстрого старта работы со скиллом.

---

## Промт: Массовый экспорт из iTunes бэкапа

```
Мне нужно экспортировать ВСЕ чаты WhatsApp из резервной копии iTunes iPhone.

**Бэкап находится:**
C:\Users\londo\AppData\Roaming\Apple Computer\MobileSync\Backup\

**Что нужно:**
1. Найти последний бэкап iPhone
2. Извлечь ChatStorage.sqlite (WhatsApp и WA Business)
3. Экспортировать ВСЕ чаты с медиафайлами
4. Использовать имена из адресной книги
5. Для групповых чатов показывать имена участников
6. Сохранить в D:/Downloads/

**GPU:** RTX 3060 (для Whisper если нужно)

Начни с поиска бэкапа и анализа структуры.
```

## Промт: Обработка одного ZIP-чата

```
Обработай экспорт WhatsApp чата из ZIP-архива.

**Архив:** [путь к файлу]
**Контакт:** [имя]
**Тип:** [клиент/агент/поставщик/сотрудник]
**Тематика:** [тема переписки]

Расшифруй голосовые через Whisper, проанализируй медиа, собери итоговый MD.
```

## Промт: Пакетная обработка нескольких чатов

```
Нужно обработать несколько ZIP-архивов WhatsApp чатов:

1. [имя_файла_1.zip] — [имя контакта], [тип], [тематика]
2. [имя_файла_2.zip] — [имя контакта], [тип], [тематика]
3. [имя_файла_3.zip] — [имя контакта], [тип], [тематика]

Обработай по порядку, расшифруй голосовые, собери MD в D:/Downloads/Chats/
```
