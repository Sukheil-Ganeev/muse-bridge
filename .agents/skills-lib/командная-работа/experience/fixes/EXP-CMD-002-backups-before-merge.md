# EXP-CMD-002: Бэкапы ПЕРЕД merge операциями, не после

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Severity:** critical
**Категория:** fix

## Проблема

Merge-агенты модифицировали целевые SKILL.md файлы без предварительного бэкапа. В проекте Skills Merge данные не потерялись (агенты только ДОБАВЛЯЛИ контент), но это было везение. Если бы агент неправильно перезаписал файл -- откат невозможен.

## Решение

Добавить шаг в Pre-flight Check перед каждым merge:

1. Создать папку `_backups/` в корне проекта (если не существует)
2. Скопировать все целевые файлы перед модификацией
3. Формат имени: `_backups/{skill-name}_SKILL_{YYYY-MM-DD}.md`

Пример:
```
_backups/
├── создание-cv_SKILL_2026-02-17.md
├── форматирование-турпродуктов_SKILL_2026-02-17.md
├── uae-tourism-calculator_SKILL_2026-02-17.md
└── yandex-cloud-справочник_SKILL_2026-02-17.md
```

## Когда применять

- ВСЕГДА перед merge операциями
- ВСЕГДА перед масштабным редактированием SKILL.md
- Перед любой операцией, которая модифицирует >3 файлов одновременно
