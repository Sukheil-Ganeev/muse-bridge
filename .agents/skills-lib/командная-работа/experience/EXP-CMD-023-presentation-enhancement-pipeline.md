### Критические уроки

#### 1. transform: scale() ломает position: fixed -> ИСПОЛЬЗУЙ zoom
- `document.body.style.transform = 'scale(x)'` создаёт новый containing block
- `position: fixed` элементы (TOC overlay, nav bar) перестают быть fixed
- TOC overlay получал height: 15120px вместо viewport, контент уезжал на 5689px
- **РЕШЕНИЕ:** `document.body.style.zoom = x` -- НЕ ломает fixed positioning
- Это было в EXP-094 (декоры), но повторилось -- ВСЕГДА проверять!

#### 2. e.key НЕ работает с русской раскладкой
- `e.key === 'T'` -> в русской раскладке T производит 'Е' (кириллица)
- `e.key === 'F'` -> в русской раскладке F производит 'А'
- **РЕШЕНИЕ:** `e.code === 'KeyT'` -- физическая клавиша, работает в ЛЮБОЙ раскладке
- Стрелки, Escape, Home, End -- можно оставить через e.key (они одинаковые)

#### 3. Агенты неконсистентны -- нужен эталон + QA
- UAE агент сделал правильно (window.toggleTOC, window.tocVisible)
- Russia и Comparison -- оба сделали одну и ту же ошибку (локальный tocVisible)
- QA нашёл 3 проблемы в 2 файлах
- **ПАТТЕРН:** первый агент = эталон, QA сравнивает остальных с эталоном

#### 4. Фикс-агент эффективнее отдельных
- 1 фикс-агент на 2 файла (Russia + Comparison) = быстрее чем 2 отдельных
- Используй Edit tool для точечных правок, НЕ Write для перезаписи
- Для однотипных багов в N файлах -- 1 агент с Edit

#### 5. Premium CSS -- добавляй ПЕРЕД </style>, не перезаписывай
- Все анимации и hover -- одним блоком перед </style>
- Edit tool с точной вставкой перед закрывающим тегом
- НЕ удалять существующие стили -- только дополнять (каскад CSS)
