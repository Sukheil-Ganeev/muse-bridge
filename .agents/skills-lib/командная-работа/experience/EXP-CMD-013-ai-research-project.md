## Уроки

### 1. Исследовательские проекты НЕ требуют верификации (critic/advocate)
Для информационных исследований (не фактологических справочников) можно пропустить Волну 2 (верификация). Данные собираются из публичных источников, противоречия некритичны, цель — обзор, а не точный справочник.

### 2. Ограничение TeamCreate: один лидер = одна команда
Нельзя создать вторую команду, пока активна первая. Решение: добавить задачи презентации в ту же команду. Или завершить первую команду (TeamDelete) перед созданием второй.

### 3. Синтезатор как отдельный агент — эффективно
Один агент читает все 5 файлов и создаёт единый отчёт. Работает хорошо если файлы < 700 строк каждый. Для более крупных файлов нужно разделять.

### 4. HTML-билдер получает CSS-систему в промпте
Передача полной CSS дизайн-системы (тема, компоненты, метрики) прямо в промпт агента — работает. Не нужен отдельный architect для простых презентаций. Для сложных (20+ слайдов) — всё равно разделять.

### 5. Финализатор — лёгкая задача
Добавление slideshow mode + PDF конвертация = 28K токенов, 88 секунд. Самый лёгкий агент в проекте. Можно объединить с билдером, но разделение даёт гибкость.
