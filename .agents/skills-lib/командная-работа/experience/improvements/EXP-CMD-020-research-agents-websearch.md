# EXP-CMD-020: Исследовательские агенты = general-purpose с WebSearch

**Дата:** 2026-02-18
**Проект:** Credit Cards Research (ОАЭ vs Россия)
**Контекст:** 2 параллельных исследователя: один по кредитным картам ОАЭ, другой по России. Каждый создаёт MD-документ ~3000 слов.

## Проблема / Ситуация

При выборе типа агента для исследовательских задач нужно правильно указать subagent_type и передать достаточно деталей в промпте. Без детальной структуры агент пишет "обзорную статью" вместо структурированного справочного документа.

## Решение / Паттерн

### Тип агента

- **subagent_type: general-purpose** (нужен WebSearch + Write)
- НЕ read-only (Explore, Plan) -- они не могут создавать файлы
- НЕ специализированные -- нужен полный набор инструментов

### Обязательные параметры в промпте

1. **Детальная структура документа** -- ВСЕ разделы и подразделы
   ```
   ## 1. Введение
   ## 2. Типы карт (кредитные, дебетовые, предоплаченные)
   ## 3. Требования к получению
   ### 3.1. Для резидентов
   ### 3.2. Для нерезидентов
   ...
   ```

2. **Язык и объём:** русский, ~3000 слов, формат MD с таблицами

3. **Специфика аудитории:** резидент ОАЭ, новичок в финансовой системе, связи с РФ (для данного проекта)

4. **Формат данных:** таблицы для сравнения карт, выделение ключевых чисел, маркировка [ТРЕБУЕТ ПРОВЕРКИ] для неподтверждённых фактов

## Результат

- Оба исследователя создали структурированные MD-документы
- Документы следовали заданной структуре (не "обзорная статья")
- Таблицы сравнения карт присутствуют
- Аудитория учтена (практические советы для резидентов)

## Правило на будущее

Для исследовательских агентов:
- Тип: general-purpose (WebSearch + Write обязательны)
- Промпт: детальная структура (все разделы), язык, объём, формат
- Аудитория: указывать конкретно (кто читатель, какой контекст)
- 1 агент = 1 тема (НЕ больше!)
- Агенту сравнения/аналитики: указать пути к ОБОИМ исходным документам
