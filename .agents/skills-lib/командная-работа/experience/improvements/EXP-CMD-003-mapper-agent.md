# EXP-CMD-003: Mapper-агент в Волне 0 обязателен для merge-проектов

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Severity:** critical
**Категория:** improvement

## Описание

Mapper -- специализированный агент, который создаёт детальный план (MERGE_MAPPING.md) для каждой merge-операции ДО начала фактических merges. Без mapper'а merge-агенты работают вслепую.

## Что создаёт Mapper

Файл `MERGE_MAPPING.md` с разделами для каждого merge:

### 1. Описание операции
- Тип: поглощение / создание нового / реструктуризация
- Источники: какие скиллы участвуют
- Цель: какой скилл будет результатом

### 2. Секции для сохранения
- Из источника A: секции X, Y, Z
- Из источника B: секции M, N

### 3. Дубли для устранения
- Секция X в A == секция M в B (выбрать: A, потому что актуальнее)

### 4. Чеклист "НЕЛЬЗЯ потерять"
- Конкретные факты, числа, таблицы
- Каждый пункт -- верифицируемый

## Результат в проекте Skills Merge

| Параметр | Без mapper | С mapper |
|----------|-----------|---------|
| Успешность merges | неизвестно | 6/6 (100%) |
| Retry | вероятно высокий | 0 |
| Потеря контента | вероятно | 0% |
| Время на merge-агента | больше (разбирается сам) | меньше (план готов) |

## Рекомендация

Mapper ВСЕГДА запускать как первый агент в Волне merge. Тип: тиммейт (через mailbox) или обычный субагент. В проекте Skills Merge использовался как тиммейт -- работал успешно.
