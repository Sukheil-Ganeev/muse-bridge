# EXP-SG-001: SingaporeToursBot -- 4 параллельных агента (2026-02-18)

**Проект:** Telegram-бот для туризма в Сингапуре (D:/Downloads/SingaporeToursBot/)
**Категория:** pattern | **Severity:** high
**Теги:** параллельные-агенты, контракт-импортов, brainstorming, i18n, волновая-реализация

## Что работало
- 4 агента параллельно (Infrastructure+DB, Core+Locales, Keyboards+Handlers, Cart+Orders+AI+Admin)
- Единый контракт импортов: имена файлов, callback-префиксы, сигнатуры функций
- Каждый агент получил полную спецификацию с точными именами и путями
- Результат: 28 файлов за 1 сессию, 0 конфликтов между агентами

## Ключевые уроки
1. **Контракт > Code Review**: когда все агенты знают точные имена (callback prefixes: `cat_`, `cart_`, `ord_`, `adm_`, `agt_`), код стыкуется без правок
2. **Brainstorming перед кодом**: 7 вопросов -> 9 секций дизайна -> утверждение -> только потом код. Экономит 50% переделок
3. **Главное окно = диспетчер**: ни одного большого файла не читалось в главном окне. Всё через субагентов
4. **Волновая реализация**: MVP (каталог+заказы) -> кабинет агентов -> бонусные фичи. Каждая волна самодостаточна
5. **i18n с первого дня**: 3 JSON файла (ru/en/zh) по 68 ключей -- проще добавить сразу чем рефакторить потом

- Navigation Stack для кнопок "Назад" -- переиспользуется из VoiceBot
