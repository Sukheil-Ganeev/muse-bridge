# EXP-CMD-006: Чеклист из mapping = 100% сохранение контента

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Категория:** pattern

## Описание

При merge операциях mapper создаёт чеклист конкретных фактов, чисел и таблиц, которые НЕЛЬЗЯ потерять. Каждый merge-агент получает свой чеклист и верифицирует каждый пункт после завершения.

## Примеры чеклистов

### Merge #3 (создание-cv + cv-туризм-оаэ):
- [ ] 18 пунктов: шаблоны резюме для ОАЭ, арабский формат, фото требования
- Результат: 18/18 сохранено

### Merge #5 (банковские-реквизиты -> uae-tourism-calculator):
- [ ] 6 AED счетов: NBD Gulnaz, Mashreq Gulnaz, ...
- [ ] Криптокошельки: USDT TRC-20, BTC, ETH
- [ ] Формулы расчёта маржи
- Результат: 14/14 сохранено

### Merge #6 (yandex-disk-мсп -> yandex-cloud-справочник):
- [ ] MCP интеграция: yandex-disk-msp сервер
- [ ] 7 experience записей
- [ ] REST API endpoints
- Результат: 14/14 сохранено

### Merge #1 (3 форматирования -> форматирование-мессенджеры):
- [ ] WhatsApp синтаксис: *bold*, _italic_, 15 тире
- [ ] Telegram синтаксис: **bold**, __italic__, 18 тире
- [ ] Email HTML шаблоны
- Результат: 100% сохранено

### Merge #2 (instagram-bot + fb-messenger-bot -> meta-messenger-bot):
- [ ] API v22.0 (не v21.0!)
- [ ] Webhook верификация: hub.verify_token
- [ ] 24-часовое окно
- Результат: 100% сохранено

## Правило

Для каждого merge в MERGE_MAPPING.md обязателен раздел:

```markdown
### Чеклист "НЕЛЬЗЯ потерять"
- [ ] Факт 1 (конкретное число/значение)
- [ ] Факт 2 (конкретная таблица/формула)
- [ ] ...
```

Merge-агент ОБЯЗАН проверить каждый пункт после завершения работы.
