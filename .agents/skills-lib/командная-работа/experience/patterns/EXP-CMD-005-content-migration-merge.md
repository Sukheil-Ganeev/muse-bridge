# EXP-CMD-005: Content-Migration паттерн для merge скиллов

**Дата:** 2026-02-17
**Проект:** Skills Merge -- Анализ и объединение 90 скиллов
**Категория:** pattern

## Описание

Проверенный паттерн для проектов объединения/реорганизации коллекции скиллов. 5 волн с чёткими gate-проверками между ними.

## Архитектура

### Волна 0: Mapper (1 агент)
- Создаёт MERGE_MAPPING.md
- Для каждого merge: секции для сохранения, дубли, чеклист "НЕЛЬЗЯ потерять"
- Gate G0: файл существует и содержит все merge-операции

### Волна 1: Лёгкие merges (параллельно, 2-4 агента)
- Поглощения: один скилл поглощает другой (контент добавляется)
- Каждый агент работает по чеклисту из маппинга
- Gate G1: все целевые файлы обновлены, чеклисты выполнены

### Волна 2: Средние merges (параллельно, 1-2 агента)
- Создание новых скиллов из 2-3 источников
- Больше работы: структурирование, устранение дублей, обновление API версий
- Gate G2: новые файлы созданы, чеклисты выполнены

### Волна 3: Верификация (2 агента)
- Автотесты: YAML frontmatter, размер, ссылки, дубли
- Critic review: проверка на потерю контента по чеклистам маппинга
- Gate G3: 0 критических проблем

### Волна 4: Cleanup (1 агент + USER)
- Удаление deprecated скиллов
- Удаление бэкапов
- Только после подтверждения USER

## Метрики подтверждения

| Параметр | Значение |
|----------|----------|
| Скиллов | 90 |
| Merge-операций | 7 (6 выполнено, 1 pending) |
| Успешность merges | 6/6 (100%) |
| Чеклист compliance | 100% |
| Retry | 0 (после mapper'а) |
| Агентов всего | ~21 |

## Ключевые правила

1. **max_skills_per_agent = 8** для задач анализа
2. **Бэкапы ПЕРЕД merge** (формат: `_backups/{name}_SKILL_{date}.md`)
3. **DEPRECATED > немедленное удаление** (маркер + удаление после верификации)
4. **Чеклист из маппинга** = гарантия 100% сохранения контента
