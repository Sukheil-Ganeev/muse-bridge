# EXP-CMD-021: Оптимальный размер команды для исследовательских проектов

**Дата:** 2026-02-18
**Проект:** Credit Cards Research (ОАЭ vs Россия)
**Контекст:** 7 агентов: 2 исследователя, 1 аналитик-сравнение, 3 дизайнера презентаций + lead. 3 MD + 3 HTML→PDF.

## Проблема / Ситуация

Нужно определить оптимальное количество агентов для исследовательского проекта с презентациями. Слишком мало -- последовательное выполнение, потеря времени. Слишком много -- расход API лимитов и сложность координации.

## Решение / Паттерн

### Формула размера команды

| Роль | Правило | Пример |
|------|---------|--------|
| Исследователи | 1 агент = 1 тема (НЕ больше!) | 2 темы = 2 агента |
| Сравнение/анализ | Отдельный агент (читает N документов, пишет 1) | 1 агент |
| Презентации | 1 агент = 1 презентация | 3 презентации = 3 агента |
| Lead (главное окно) | ТОЛЬКО диспетчер, НЕ читает большие файлы | 1 |

### Итого для типичного исследовательского проекта

```
Агенты = N_тем (исследование) + N_перекрёстных (аналитика) + N_презентаций + 1 (lead)
```

Для Credit Cards: 2 + 1 + 3 + 1 = 7 агентов

### Когда добавлять дополнительных

- **Critic + Advocate** (Волна 2): если данные из интернета и нужна верификация (+2 агента)
- **Fixer**: если верификация нашла ошибки (+1 агент)
- **QA**: для больших проектов (>5 документов) (+1 агент)

### Когда НЕ добавлять

- НЕ давать одному исследователю 2 темы -- контекст переполнится
- НЕ давать одному презентационному агенту 2 презентации -- разные палитры/темы
- НЕ делать lead "рабочим" агентом -- контекст заполнится, потеряется контроль

## Результат

- 7 агентов = оптимум для 2 темы + сравнение + 3 презентации
- 0 перезагрузки агентов
- Lead контекст не переполнился
- Все агенты завершили работу в рамках своего контекста

## Правило на будущее

- 1 агент = 1 тема исследования (строго!)
- 1 агент = 1 презентация (строго!)
- Сравнение/аналитика = отдельный агент
- Lead = ТОЛЬКО диспетчер
- Формула: N_тем + N_перекрёстных + N_презентаций + 1 lead
- Верификация: +2-3 агента если данные из интернета
