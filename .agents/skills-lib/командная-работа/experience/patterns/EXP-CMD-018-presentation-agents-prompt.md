# EXP-CMD-018: Презентационные агенты -- детальный промпт критичен

**Дата:** 2026-02-18
**Проект:** Credit Cards Research (ОАЭ vs Россия)
**Контекст:** 3 HTML→PDF презентации с уникальными палитрами (Gold Vault, Frost Finance, Dual Bridge), конвертация через Playwright.

## Проблема / Ситуация

Презентационный агент получает задачу "создай презентацию по документу X". Без детального промпта результат непредсказуем: агент выбирает случайные цвета, использует неподдерживаемые CSS-свойства (animation, backdrop-filter, conic-gradient, vh/vw), создаёт зависимости от внешних ресурсов. PDF конвертация падает или выдаёт битый результат.

## Решение / Паттерн

### Обязательные компоненты промпта для презентационного агента

1. **Тема-палитра: полный CSS :root с переменными**
```css
:root {
  --bg-primary: #0a0a14;
  --accent-gold: #d4a854;
  --card-bg: rgba(212,168,84,0.08);
  /* ... все переменные */
}
```

2. **Структура КАЖДОГО слайда**: заголовок, компоненты (карточки, таблицы, highlight-box), данные

3. **Технические ограничения PDF -- жёсткий запрет:**
   - НЕТ animation / transition
   - НЕТ backdrop-filter
   - НЕТ conic-gradient
   - НЕТ vh / vw единиц
   - НЕТ внешних зависимостей

4. **Zero-dependency подход:**
   - Системные шрифты (font-family: system-ui, -apple-system, sans-serif)
   - Inline SVG для иконок
   - CSS linear-gradient / radial-gradient для фонов

5. **Конвертация:** Playwright скрипт прямо в промпте агента
   ```js
   const browser = await chromium.launch();
   const page = await browser.newPage();
   await page.setViewportSize({ width: 1280, height: 720 });
   // ...
   ```

6. **Пути сохранения:** HTML файл + output/PDF

### Серия презентаций с единой дизайн-системой

- **Общие компоненты:** .slide, .card, .styled-table, .highlight-box, .stat-block
- **Уникальная палитра для каждой:** Gold Vault (золото, ОАЭ), Frost Finance (синий лёд, РФ), Dual Bridge (фиолетовый, сравнение)
- **VS-layout** особенно эффективен для сравнительной презентации
- **Ambient glow** (2 блоба на слайд) = визуальный код темы (золотой glow для ОАЭ, ледяной для РФ)

## Результат

- 3 презентации с единой дизайн-системой, но уникальными палитрами
- 0 ошибок конвертации HTML→PDF
- Каждый агент создал HTML + Playwright скрипт + PDF за один прогон
- Визуальная консистентность серии

## Правило на будущее

Промпт презентационного агента ВСЕГДА должен содержать:
1. Полную CSS палитру (:root переменные)
2. Структуру каждого слайда (заголовки, компоненты, данные)
3. Список ЗАПРЕЩЁННЫХ CSS-свойств для PDF
4. Zero-dependency требование (системные шрифты, inline SVG)
5. Готовый Playwright скрипт конвертации
6. Пути сохранения HTML + PDF

Для серий презентаций: общие компоненты + уникальные палитры.
