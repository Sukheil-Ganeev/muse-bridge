# Требования к презентации справочника
> Актуально на: 2026-02-14

## Обязательные требования

| Требование | Детали | Почему критично |
|-----------|--------|-----------------|
| Overlay fade | 150ms in + 150ms out для переключения тем | CSS transition = "лоскутный" эффект |
| Кастомный scrollbar | 6px, thin, styled под тему | Стандартный 17px = "чужеродно" |
| Fullscreen | Hotkey F, requestFullscreen() | Обязательная фича |
| Dark mode | WCAG AA 4.5:1, #22223a base | Каждый элемент отдельно |
| Inline HTML | CSS + JS в одном файле | Переносимость |
| < 250KB | Без внешних зависимостей | Быстрая загрузка |
| 50-60 слайдов | По всем разделам | Полнота |

## В промпт html-css-developer

"ОБЯЗАТЕЛЬНО реализуй:
- Overlay fade для переключения тем (НЕ CSS transitions на элементах!)
- Кастомный scrollbar (6px, thin, border-radius: 3px)
- Fullscreen режим (F)
- initTheme() БЕЗ transition при загрузке
- Dark mode: проверь контраст КАЖДОГО элемента"

## Технические детали

### Overlay fade (правильная реализация)

- Создать overlay div с position: fixed
- При смене темы: overlay opacity 0 → 1 (150ms) → меняем тему → opacity 1 → 0 (150ms)
- НЕ использовать CSS transition на элементах — они мигают по отдельности

### Dark mode

- Base: #22223a
- Контраст: WCAG AA minimum 4.5:1
- Проверить КАЖДЫЙ элемент: текст, заголовки, таблицы, код, ссылки, границы
- rgba < 20% = невидимо на тёмном фоне

### Scrollbar

- width: 6px
- scrollbar-width: thin
- border-radius: 3px
- Styled под обе темы (light и dark)

### initTheme()

- При загрузке: определить тему из localStorage
- Применить БЕЗ transition (disable transitions → set theme → enable transitions)
- Это предотвращает "вспышку" при загрузке
