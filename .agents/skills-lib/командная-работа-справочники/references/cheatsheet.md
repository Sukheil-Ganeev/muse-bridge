# Шпаргалка справочников
> Актуально на: 2026-02-14

## 10 шагов создания справочника

1. Определи тему → выбери пресет из адаптация-разделов.md
2. TeamCreate → team_name
3. mkdir: _research/, _qa/, presentation/
4. TaskCreate x 18 (из шаблоны-промптов.md)
5. TaskUpdate addBlockedBy (из SKILL.md → Зависимости)
6. Волна 1: 7 исследователей параллельно
7. Волна 2: critic → advocate (последовательно)
8. Волна 3: technical-writer
9. Волна 4+5: презентация + улучшения (параллельно)
10. TeamDelete

## Обязательные фичи презентации

- Overlay fade (150ms)
- Scrollbar 6px
- Dark mode WCAG AA
- Hotkeys: <- -> D T H F
- Inline HTML < 250KB
- Fullscreen

## Ранжирование источников

```
Tier 1: Официальные сайты       -> ДОВЕРЯЙ
Tier 2: Крупные СМИ             -> ПРОВЕРЯЙ
Tier 3: Блоги, Reddit           -> [ТРЕБУЕТ ПРОВЕРКИ]
Tier 4: AI-статьи               -> БАН
Tier 4: Данные >2 лет           -> [ПРОВЕРИТЬ АКТУАЛЬНОСТЬ]
```

## Слияние ролей (малые команды)

```
critic + advocate         = verifier (< 6 файлов)
qa + templates            = qa-templates
diagrams + templates      = assets-creator
4 presentation agents     = 1 presentation-full
```

## Версионирование

```
v1.0 = полная команда 18 агентов
v1.x = 2-3 агента (researcher + writer)
v2.0 = 10-12 агентов (новые разделы)
Next review: +3 месяца
```

## Золотые правила

1. WebSearch в каждого исследователя
2. Помечай [ТРЕБУЕТ ПРОВЕРКИ]
3. До 15KB на файл; больше → разбить, НЕ обрезать
4. Не дублируй данные
5. "ДАННЫЕ АКТУАЛЬНЫ НА: [дата]" в начале каждого файла
6. 63/63 проверок QA → 100% pass rate
7. Если не найдено → [НЕ НАЙДЕНО], не выдумывай
8. Один стиль во всех файлах
