# Скоринг-рубрика для Critic
> Актуально на: 2026-02-14

## Рубрика оценки файла исследования

| Критерий | 0 (плохо) | 1 (норма) | 2 (отлично) |
|----------|-----------|-----------|-------------|
| Полнота | Пропущены ключевые данные | Основное есть, мелочи пропущены | Исчерпывающе, всё на месте |
| Точность | Фактические ошибки | Мелкие неточности | Всё верифицируемо верно |
| Источники | Нет ссылок на источники | Блоги, форумы (Tier 3) | Официальные сайты (Tier 1-2) |
| Формат | Нечитаемо, нет таблиц | Читаемо, базовые таблицы | Идеальные таблицы, единый стиль |
| Актуальность | Данные >2 лет | В целом актуально (1-2 года) | Свежие данные 2025-2026 |

## Оценка

- Максимум: **10 баллов** на файл
- **ПОРОГ:** если ЛЮБОЙ файл < 5 баллов → вернуть на **ДОРАБОТКУ** (НЕ переписывание!)
- Critic указывает КОНКРЕТНО что исправить
- Fix-агент **ДОПОЛНЯЕТ** исходный файл, а не перезаписывает
- Уникальные данные из исходного файла **СОХРАНИТЬ**
- Если критерий "Точность" = 0 → перепроверить факты, но структуру файла сохранить

## Как critic использует рубрику

1. Оценить каждый из 7 файлов по рубрике
2. Записать балл в таблицу
3. Для файлов < 5 баллов — описать что именно не так
4. Для файлов с Точность = 0 — перечислить конкретные ошибки

## Формат в critic-report.md

| Файл | Полнота | Точность | Источники | Формат | Актуальность | ИТОГО | Статус |
|------|---------|----------|-----------|--------|-------------|-------|--------|
| research-1.md | 2 | 1 | 2 | 2 | 2 | 9/10 | OK |
| research-2.md | 1 | 0 | 1 | 1 | 1 | 4/10 | ДОРАБОТКА |

## Важные правила доработки

- **< 5 баллов = ДОРАБОТКА**, не переписывание с нуля
- Critic указывает конкретные пункты для исправления
- Fix-агент читает исходный файл + замечания critic → дополняет/исправляет
- Уникальные данные, найденные исследователем, ОБЯЗАТЕЛЬНО сохранить
- Структура файла (секции, заголовки) сохраняется — меняется только содержание
