# EXP-099: Скилл >7000 слов = 1 агент на 1 скилл при рефакторинге

**Дата:** 2026-02-17
**Проект:** Волна 5 рефакторинга скиллов (T-003 word count)
**Категория:** warning

## Проблема
При рефакторинге 14 скиллов для снижения word count, агенту-1 были назначены 2 тяжёлых скилла:
- фото-редактор-промты (11,551 слов)
- netlify-deployment (9,227 слов)
Суммарно: 20,778 слов входного контента + промпт с инструкциями.

Результат: агент провалился. Фото-редактор ВЫРОС до 11,981 слов (+430), netlify остался без изменений.

Агент-4 (git-github 6,492 + туризм 6,111 = 12,603 слов) упал с "Prompt is too long". Успел только первый скилл.

## Решение
- Скилл >7000 слов: ТОЛЬКО 1 скилл на агента
- Скилл 5500-7000 слов: максимум 2 на агента
- Скилл <5500 слов: до 4 на агента (лёгкие задачи)

## Правило
```
max_skills_per_refactor_agent:
  >7000 слов: 1 скилл/агент
  5500-7000: 2 скилла/агент
  <5500: до 4 скиллов/агент
```
