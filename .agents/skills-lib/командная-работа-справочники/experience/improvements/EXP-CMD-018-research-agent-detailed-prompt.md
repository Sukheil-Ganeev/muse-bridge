# EXP-CMD-018: Детальная структура документа в промпте исследователя

**Дата:** 2026-02-18
**Проект:** Credit Cards Research (ОАЭ vs Россия)
**Контекст:** 2 исследователя создают MD-справочники по кредитным картам, 1 аналитик -- сравнительный документ.

## Проблема / Ситуация

Исследовательский агент без детальной структуры пишет "обзорную статью" -- поверхностный текст без таблиц, без конкретных чисел, без учёта аудитории. Для справочника это неприемлемо: нужна чёткая структура, таблицы сравнения, практические рекомендации.

## Решение / Паттерн

### Обязательные элементы промпта исследователя

1. **Тип агента:** general-purpose (нужен WebSearch + Write)
2. **Детальная структура документа** (все разделы и подразделы):
   ```
   ## 1. Введение и контекст рынка
   ## 2. Типы кредитных карт
   ### 2.1. Классические
   ### 2.2. Премиальные
   ### 2.3. Кэшбэк
   ## 3. Требования к получению
   ### 3.1. Для резидентов
   ### 3.2. Для нерезидентов
   ## 4. Сравнительная таблица ТОП-10 карт
   ...
   ```
3. **Язык, объём, формат:** русский, ~3000 слов, MD с таблицами
4. **Специфика аудитории:** кто читатель, какой у него контекст
5. **Маркировка неподтверждённого:** [ТРЕБУЕТ ПРОВЕРКИ]

### Аналитик-сравнение -- отдельный агент

- Получает пути к ОБОИМ справочникам: "Прочитай файл A и файл B"
- Создаёт 3-й документ: сравнительную таблицу, плюсы/минусы, рекомендации
- addBlockedBy: оба исследования

### 1 агент = 1 тема

- Исследователь ОАЭ не должен писать про РФ (и наоборот)
- Контекст одной темы: 3000 слов MD + WebSearch = ~150K токенов
- 2 темы на агента: переполнение контекста, потеря качества

## Результат

- Оба справочника получились структурированными (не "обзорные статьи")
- Таблицы сравнения карт присутствуют
- Аудитория учтена (практические советы для целевого читателя)
- Сравнительный документ синтезировал данные из обоих источников

## Правило на будущее

Промпт исследователя справочника:
1. Тип: general-purpose
2. Структура: ВСЕ разделы и подразделы прописаны
3. Формат: язык + объём + MD с таблицами
4. Аудитория: конкретное описание читателя
5. Правило: 1 агент = 1 тема, строго
6. Аналитик перекрёстных сравнений: отдельный агент с путями ко ВСЕМ источникам
