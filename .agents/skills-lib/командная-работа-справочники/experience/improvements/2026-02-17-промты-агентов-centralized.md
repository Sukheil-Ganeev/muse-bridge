# EXP-105: ПРОМТЫ_АГЕНТОВ.md -- централизованный файл промптов

**Дата:** 2026-02-17
**Проект:** Оптимизация Docker-справочника (20% -> 100%)
**Категория:** improvement

## Проблема

При делегировании задач тиммейтам длинные промты в каждой задаче засоряют контекст главного окна (диспетчера). Особенно критично при >5 агентах с детальными инструкциями.

## Решение

Создать один файл `ПРОМТЫ_АГЕНТОВ.md` в корне рабочей директории проекта:

```markdown
# Промты агентов

## Агент-1: SKILL.md writer
[детальный промпт для агента 1...]

## Агент-2: References writer
[детальный промпт для агента 2...]

## Агент-3: Templates creator
[детальный промпт для агента 3...]
```

### Как использовать

1. Главное окно создает файл ОДИН раз
2. В задаче тиммейту указывает: "Прочитай секцию ## Агент-N в ПРОМТЫ_АГЕНТОВ.md"
3. Агент читает ТОЛЬКО свою секцию
4. Главное окно остается чистым

## Преимущества

- Контекст диспетчера не засоряется
- Промпты можно редактировать без пересоздания задач
- Повторное использование при следующей оптимизации
- Единый source of truth для инструкций

## Влияние

Экономия ~30% контекста главного окна при работе с 5+ агентами. Подтверждено на проекте Docker-справочника.
