# EXP-CMD-019: Зеркальные проекты — шаблонизация и межсессионная передача

**Дата:** 2026-02-18
**Проект:** Debit Cards Research (ОАЭ vs Россия)
**Контекст:** Второй проект сессии — дебетовые карты. Зеркальная копия первого (кредитные карты), но с новыми темами (СБП, Jaywan, овердрафт) и новыми палитрами (Emerald Banking, Arctic Steel, Twin Streams).

---

## Урок 1: Контекстный документ для межсессионной передачи

### Проблема / Ситуация
При завершении большого проекта (6 презентаций, 6 справочников, 12 файлов) вся информация о структуре, палитрах и решениях остаётся в контексте сессии. Если новая сессия начнётся без этой информации — придётся заново исследовать файлы, восстанавливать палитры, вспоминать принятые решения.

### Решение / Паттерн
При завершении большого проекта создавать **КОНТЕКСТ-*.md** с обязательными секциями:
1. **Структура файлов** — полные пути ко всем созданным файлам (HTML, PDF, MD)
2. **Палитры** — CSS переменные каждой темы (`:root` для каждой палитры)
3. **Ключевые находки** — важные факты и цифры из исследований
4. **Архитектурные решения** — DAG-структура, количество агентов, зависимости
5. **TODO для следующей сессии** — что нужно доделать, проверить, улучшить

### Результат
Контекстный документ позволяет новой сессии начать с полной информацией вместо исследования файлов с нуля. Экономия: ~15-20 минут на каждый проект при продолжении в новой сессии.

### Правило на будущее
**ПРАВИЛО:** При завершении проекта с 5+ файлами — ВСЕГДА создавать КОНТЕКСТ-{project-name}.md в корне проекта. Без контекстного документа новая сессия начнёт с нуля, что потребует повторного исследования и рискует потерей принятых решений.

## Урок 2: Зеркальные проекты — шаблонизация промптов ускоряет в 3x

### Проблема / Ситуация
Первый проект (кредитные карты) потребовал полное проектирование промптов для всех 7 агентов с нуля: структура справочника, палитры, запреты CSS, Playwright скрипт, формат документа.

### Решение / Паттерн
Для второго проекта (дебетовые карты) промпты скопированы и изменены только 3 элемента:
1. **Тема** (содержание: дебетовые вместо кредитных, СБП вместо грейс-период)
2. **Палитра** (CSS :root — Emerald Banking / Arctic Steel / Twin Streams)
3. **Специфичные разделы** (овердрафт, Jaywan, СБП — уникальные для дебетовых карт)

Всё остальное — **без изменений**:
- Структура слайдов
- Запреты CSS (animation, backdrop-filter, vh/vw)
- Playwright скрипт конвертации
- Формат справочника (MD с таблицами)
- DAG-зависимости (addBlockedBy)
- Формула команды (2+1+3+1=7)

### Результат
- Второй проект запустился в **3x быстрее** первого
- Время на проектирование промптов: ~15 мин -> ~5 мин
- 0 retry в обоих проектах
- Качество второго проекта не уступает первому

### Правило на будущее
**ПРАВИЛО:** При серии похожих справочников:
1. Скопировать промпт предыдущего агента
2. Заменить ТОЛЬКО: тему, палитру, специфичные разделы
3. НЕ переписывать: структуру, запреты CSS, Playwright, формат, DAG, формулу команды
4. Хранить "эталонный промпт" — первый проект серии = шаблон для всех последующих

## Бонус: Серия из 6 тема-палитр для справочников

За одну сессию создано 6 уникальных тема-палитр для презентаций справочников:

| Проект | ОАЭ (тёплые тона) | Россия (холодные тона) | Сравнение (градиент) |
|--------|-------------------|----------------------|---------------------|
| Credit Cards | Gold Vault (золото) | Frost Finance (синий) | Dual Bridge (золото→синий) |
| Debit Cards | Emerald Banking (изумруд) | Arctic Steel (стальной) | Twin Streams (изумруд→стальной) |

**Принцип дизайна палитр для парных справочников:**
- Для ОАЭ — тёплые тона (золото, изумруд) — ассоциация с богатством региона
- Для России — холодные тона (синий, стальной) — ассоциация с климатом/надёжностью
- Для сравнения — градиент обоих — визуальный мост между темами
- Все zero-dependency, одна CSS `:root` на тему
