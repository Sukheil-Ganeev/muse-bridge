# VK Реклама (VK Ads API)

**Полное руководство по настройке рекламных кампаний VKontakte для туризма ОАЭ**

---

## Обзор VK Реклама

**VK Ads** (ads.vk.com) - официальная рекламная платформа ВКонтакте с аудиторией 90+ миллионов пользователей из России и СНГ.

### Почему VK для туристического бизнеса?

1. **Массовая аудитория РФ** - 70+ миллионов активных пользователей ежедневно
2. **Детальный таргетинг** - география, демография, интересы, поведение
3. **Мощный ретаргетинг** - пиксель VK для показа рекламы посетителям вашего сайта
4. **Look-alike аудитории** - найти пользователей, похожих на ваших клиентов
5. **Доступные цены** - CPC от 5₽, CPM от 50₽

## Регистрация и настройка

### Шаг 1: Создание рекламного кабинета

1. Перейдите на **ads.vk.com**
2. Войдите через аккаунт VK
3. Нажмите "Создать кабинет"
4. Выберите тип:
   - **Физическое лицо** - для самозанятых
   - **Юридическое лицо** - для компаний (нужны реквизиты)
   - **Агентство** - для рекламных агентств

### Шаг 2: Пополнение баланса

**Способы оплаты:**
- Банковская карта (РФ): Visa, MasterCard, Мир
- ЮMoney (Яндекс.Деньги)
- Безналичный расчёт (для юрлиц)

**Минимальное пополнение:** 300₽

**Важно:** Для клиентов из ОАЭ - используйте карты РФ (друзей/родственников) или платёжного агента.

### Шаг 3: Установка пикселя VK на сайт

Пиксель VK - код, который отслеживает действия посетителей на вашем сайте (просмотры страниц, заявки, покупки).

**Установка:**

1. В кабинете VK Ads → "Пиксели" → "Создать пиксель"
2. Скопируйте код:

```html
<!-- VK Pixel Code -->
<script type="text/javascript">
!function(){var t=document.createElement("script");
t.type="text/javascript",t.async=!0,t.src='https://vk.com/js/api/openapi.js?169',
t.onload=function(){VK.Retargeting.Init("VK-RTRG-XXXXXX-XXXXX"),
VK.Retargeting.Hit()},document.head.appendChild(t)}();
</script>
<!-- End VK Pixel Code -->
```

3. Вставьте код перед закрывающим тегом `</head>` на всех страницах сайта

**Отслеживание событий (конверсий):**

```javascript
// Заявка оформлена
VK.Retargeting.Event('lead');

// Покупка завершена
VK.Retargeting.Event('purchase', {
  products: [{ id: 'tour-desert-safari', price: 4000 }],
  total_price: 4000
});
```

## Создание рекламной кампании

### Структура VK Ads

```
Рекламный кабинет
└── Кампания (Desert Safari Promotion)
    ├── Группа объявлений 1 (Москва, 25-35 лет)
    │   ├── Объявление 1 (Видео)
    │   ├── Объявление 2 (Карусель)
    │   └── Объявление 3 (Фото)
    └── Группа объявлений 2 (СПб, 35-45 лет)
        ├── Объявление 1 (Видео)
        └── Объявление 2 (Карусель)
```

### Шаг 1: Создание кампании

1. Нажмите "Создать кампанию"
2. Выберите цель:
   - **Трафик на сайт** - для привлечения посетителей
   - **Конверсии** - для оптимизации по целевым действиям (заявки)
   - **Сообщения** - для общения в мессенджере VK

3. **Рекомендация для туризма:** "Конверсии" (если установлен пиксель)

### Шаг 2: Настройка таргетинга

#### География (где показывать рекламу)

**Для туров в ОАЭ - выбирайте:**

1. **Москва** (40% клиентов)
2. **Санкт-Петербург** (15%)
3. **Крупные города:**
   - Екатеринбург
   - Новосибирск
   - Казань
   - Нижний Новгород
   - Челябинск
   - Краснодар
   - Самара

**Настройка:** "География" → Выбрать города → Радиус (по умолчанию границы города)

#### Демография

**Возраст:** 25-55 лет (основная платежеспособная аудитория для туров)

**Пол:**
- Женщины (55%) - чаще инициируют бронирование туров
- Мужчины (45%) - для бизнес-туров, yacht tours

**Семейное положение:**
- В активном поиске / Влюблён(а) / Помолвлен(а) / Женат (замужем) - для семейных туров
- Всё влюбленные - для романтических туров, honeymoon

**Дети:**
- Есть дети - для семейных туров (парки, аквапарки)
- Нет детей - для экстремальных туров (desert safari, skydiving)

#### Интересы и поведение

**Интересы (выбирайте 5-10):**
- Путешествия и туризм
- Авиаперелёты
- Отели и гостиницы
- Пляжный отдых
- Экзотические страны
- Роскошь и премиум товары
- Шопинг
- Яхты и катера
- Экстремальный спорт (для desert safari)

**Поведение:**
- Искали "Дубай", "ОАЭ", "туры в эмираты"
- Посещали сайты туроператоров
- Смотрели видео про Дубай на VK Видео

**Настройка:** "Интересы и поведение" → Введите ключевые слова → Выберите категории

#### Доход (если доступно)

- **Средний и выше** - для стандартных туров (100-200K₽)
- **Высокий** - для премиум туров (яхты, luxury hotels)

### Шаг 3: Ретаргетинг

**Ретаргетинг = показ рекламы тем, кто уже посетил ваш сайт.**

#### Создание аудитории ретаргетинга

1. В кабинете VK Ads → "Аудитории" → "Создать аудиторию"
2. Выберите источник:
   - **Пиксель VK** - посетители сайта
   - **База данных** - загрузить email/phone клиентов

**Примеры аудиторий:**

1. **Все посетители сайта (30 дней)**
   - Пиксель VK → Все посетители → Последние 30 дней
   - Размер: зависит от трафика (например, 5,000 человек)

2. **Просмотрели страницу туров, но не оформили заявку**
   - Пиксель VK → URL содержит "/tours/" → Исключить URL "/thank-you"

3. **Добавили в корзину, но не купили**
   - Пиксель VK → Событие "add_to_cart" → Исключить событие "purchase"

#### Настройка ретаргетинга в кампании

1. Создайте отдельную группу объявлений для ретаргетинга
2. Таргетинг → "Аудитории" → Выберите созданную аудиторию
3. Креатив: "Вернитесь и получите скидку 15%!"

**Почему ретаргетинг эффективен?**
- Тёплая аудитория (уже знают ваш бренд)
- Конверсия в 3-10 раз выше холодного трафика
- Стоимость лида в 2-5 раз ниже

### Шаг 4: Look-alike аудитории

**Look-alike = VK находит пользователей, похожих на ваших клиентов.**

#### Создание look-alike аудитории

1. В кабинете VK Ads → "Аудитории" → "Создать look-alike"
2. Выберите исходную аудиторию:
   - **База клиентов** (минимум 100 человек) - загрузите email/phone
   - **Пиксель VK** - те, кто совершил конверсию (купил тур)

3. Настройте параметры:
   - **Размер аудитории:** 1% (самые похожие) до 10% (менее похожие)
   - **География:** Москва, СПб, регионы

4. VK создаст аудиторию (обычно 100K-1M человек)

**Пример:**
- Загрузили 200 email клиентов, которые купили yacht tours
- VK создал look-alike 500,000 человек с похожим поведением
- Показываем им рекламу яхт-туров → высокая конверсия

**Лучше для:** вовлечения и эмоционального воздействия

**Спецификации:**
- Длительность: 15 сек - 10 мин (оптимально 30-60 сек)
- Формат: MP4, MOV
- Размер: до 1 ГБ
- Разрешение: минимум 1080×1080px (квадрат) или 1080×1920px (вертикаль)
- Текст: добавьте субтитры (многие смотрят без звука)

**Структура видео для туров:**
- 0-5 сек: Hook (захватывающий кадр - например, джипы в пустыне)
- 5-20 сек: Показать эмоции (счастливые туристы)
- 20-40 сек: Детали тура (что включено)
- 40-60 сек: Цена и призыв к действию ("Забронируйте со скидкой 20%!")

**Пример сценария:**
```

Текст: "Забронируйте со скидкой 20% до конца месяца!"
Кнопка: "Забронировать"
```

## Ставки и бюджет

### Модели ставок VK Ads

#### 1. CPC (Cost Per Click) - цена за клик

**Когда использовать:** для трафика на сайт

**Средние ставки 2026:**
- Минимум: 5₽/клик
- Средний: 15-30₽/клик
- Конкурентные ниши (туризм): 20-50₽/клик

**Расчёт бюджета:**
- Бюджет 10,000₽ / Ставка 25₽ = 400 кликов
- CTR (click-through rate) 2% → нужно 20,000 показов
- Конверсия клик → лид: 5% → 20 лидов
- Стоимость лида: 10,000₽ / 20 = 500₽

#### 2. CPM (Cost Per Mille) - цена за 1000 показов

**Когда использовать:** для охвата и брендинга

**Средние ставки 2026:**
- Минимум: 50₽/1000 показов
- Средний: 100-200₽/1000 показов
- Конкурентные ниши: 150-300₽/1000 показов

**Расчёт бюджета:**
- Бюджет 10,000₽ / CPM 150₽ = 66,666 показов
- CTR 2% → 1,333 клика
- Конверсия клик → лид: 5% → 67 лидов
- Стоимость лида: 10,000₽ / 67 = 149₽

**Вывод:** CPM дешевле для привлечения лидов (если CTR хороший)

#### 3. oCPM (Optimized CPM) - оптимизация по конверсиям

**Когда использовать:** если установлен пиксель VK и есть минимум 25 конверсий/неделю

**Как работает:**
- Вы задаёте целевую стоимость конверсии (например, 500₽/лид)
- VK автоматически оптимизирует показы для достижения этой цены
- Алгоритм машинного обучения находит лучшую аудиторию

**Настройка:**
1. Цель кампании: "Конверсии"
2. Выберите событие пикселя: "lead" или "purchase"
3. Укажите целевую цену конверсии: 500₽
4. VK будет стремиться к этой цене

**Рекомендация:** используйте oCPM после тестирования (когда собрали данные о конверсиях)

### Дневной бюджет

**Минимальный:** 300₽/день (для тестирования)

**Рекомендуемый для туризма:**
- **Начало (тестирование):** 500-1,000₽/день (15-30K₽/месяц)
- **Масштабирование:** 2,000-5,000₽/день (60-150K₽/месяц)
- **Сезонные кампании:** 10,000₽+/день (300K₽+/месяц)

**Пример распределения 100,000₽/месяц:**
- VK Реклама: 40,000₽ (40%)
- Яндекс.Директ: 30,000₽ (30%)
- Telegram Ads: 20,000₽ (20%)
- myTarget: 10,000₽ (10%)

## Оптимизация кампаний

### A/B тестирование креативов

**Что тестировать:**
1. **Изображения:** пустыня vs небоскрёбы vs пляж
2. **Заголовки:** "Дубай от 50,000₽" vs "Незабываемый Дубай"
3. **Призыв к действию:** "Забронировать" vs "Узнать больше"
4. **Формат:** видео vs карусель vs фото

**Методология:**
1. Создайте 3-5 вариантов объявлений
2. Запустите с одинаковым бюджетом (по 1,000₽ на каждое)
3. Через 3-7 дней проанализируйте:
   - CTR (клики/показы) - целевой: 1-3%
   - CPC (цена за клик) - целевой: 15-30₽
   - Конверсия (заявки/клики) - целевой: 3-10%

4. **Отключите** объявления с CTR < 0.5% (неэффективны)
5. **Масштабируйте** лучшие (увеличьте бюджет на 50-100%)

### Анализ аудиторий

**Где смотреть статистику:**
VK Ads → Кампания → Группа объявлений → "Статистика" → "Разрезы"

**Анализируйте:**
1. **География:** какие города дают больше лидов?
   - Если Москва конвертит лучше → увеличьте бюджет на Москву
   - Если регионы дорогие → исключите их

2. **Возраст:** какая возрастная группа лучше?
   - Например: 30-40 лет конвертит в 2 раза лучше → сфокусируйтесь на них

3. **Пол:** мужчины или женщины?
   - Для семейных туров: женщины чаще инициируют покупку
   - Для yacht tours: мужчины (50-60% аудитории)

4. **Время показа:** когда люди кликают?
   - Вечер (18:00-23:00) обычно лучше
   - Выходные (суббота, воскресенье) активнее

### Правила автоматической оптимизации

**Настройка правил:**
VK Ads → Кампания → "Автоматические правила"

**Примеры правил:**

1. **Отключить неэффективные объявления:**
   - Условие: CTR < 0.5% за последние 7 дней
   - Действие: Остановить объявление

2. **Увеличить бюджет на лучшие:**
   - Условие: CPA (стоимость лида) < 400₽ за последние 7 дней
   - Действие: Увеличить дневной бюджет на 50%

3. **Снизить ставку, если дорого:**
   - Условие: CPC > 50₽ за последние 3 дня
   - Действие: Снизить ставку на 20%

## API автоматизация (для разработчиков)

### VK Ads API

**Документация:** https://dev.vk.com/ru/api/ads

**Для чего использовать:**
- Автоматическое создание кампаний
- Массовое редактирование объявлений
- Получение статистики
- Автоматическая оптимизация ставок

### Python пример: Создание кампании

```python
import requests

# Получите access_token на dev.vk.com
ACCESS_TOKEN = 'your_access_token'
ACCOUNT_ID = 'your_account_id'  # Из кабинета VK Ads

def create_campaign(name, budget):
    """Создать рекламную кампанию"""

    params = {
        'access_token': ACCESS_TOKEN,
        'account_id': ACCOUNT_ID,
        'data': [{
            'client_id': ACCOUNT_ID,
            'type': 'normal',  # Обычная кампания
            'name': name,
            'day_limit': budget,  # Дневной бюджет в рублях
            'all_limit': budget * 30,  # Общий бюджет (месяц)
            'start_time': 0,  # Старт немедленно
            'stop_time': 0,  # Без даты окончания
        }]
    }

    response = requests.post(
        'https://api.vk.com/method/ads.createCampaigns',
        params=params
    )

    return response.json()

# Создать кампанию "Desert Safari Promo" с бюджетом 1000₽/день
result = create_campaign('Desert Safari Promo', 1000)
print(f"Campaign ID: {result['response'][0]['id']}")
```

    date_to: dateTo,
  };

  const response = await axios.get(
    'https://api.vk.com/method/ads.getStatistics',
    { params }
  );

  const stats = response.data.response[0].stats;

  // Рассчитать метрики
  const totalClicks = stats.reduce((sum, day) => sum + day.clicks, 0);
  const totalSpent = stats.reduce((sum, day) => sum + day.spent, 0);
  const avgCPC = totalSpent / totalClicks;

  return {
    clicks: totalClicks,
    spent: totalSpent,
    cpc: avgCPC.toFixed(2),
  };
}

// Получить статистику за последние 7 дней
const today = new Date().toISOString().split('T')[0];
const weekAgo = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000)
  .toISOString()
  .split('T')[0];

getCampaignStats(CAMPAIGN_ID, weekAgo, today).then(stats => {
  console.log('Campaign Stats (Last 7 days):');
  console.log(`Clicks: ${stats.clicks}`);
  console.log(`Spent: ${stats.spent}₽`);
  console.log(`Avg CPC: ${stats.cpc}₽`);
});

## Частые ошибки и как их избежать

### Ошибка 1: Слишком широкий таргетинг

**Проблема:** Таргетинг "Вся Россия, 18-65 лет, любые интересы"

**Почему плохо:**
- Показываем рекламу нецелевой аудитории
- Низкий CTR (менее 0.5%)
- Высокая стоимость лида (1000₽+)

**Решение:**
- Сузьте географию (топ-10 городов РФ)
- Возраст 25-55 лет (платежеспособная аудитория)
- Интересы: только travel-related

### Ошибка 2: Нет ретаргетинга

**Проблема:** Привлекаете только холодный трафик

**Почему плохо:**
- Стоимость лида в 3-10 раз выше
- Низкая конверсия (1-3% вместо 10-20%)

**Решение:**
- Установите пиксель VK на сайт
- Создайте аудиторию посетителей
- Запустите отдельную кампанию для ретаргетинга с другим креативом (скидка, спецпредложение)

### Ошибка 3: Один креатив на всю кампанию

**Проблема:** Показываете одно и то же объявление всем

**Почему плохо:**
- "Баннерная слепота" - люди перестают замечать рекламу
- Не знаете, какой креатив работает лучше

**Решение:**
- Создайте 3-5 вариантов креативов
- A/B тестируйте
- Обновляйте креативы каждые 2-3 недели

### Ошибка 4: Игнорирование статистики

**Проблема:** Запустили кампанию и не смотрите результаты

**Почему плохо:**
- Тратите бюджет на неэффективные объявления
- Не оптимизируете под лучшую аудиторию

**Решение:**
- Проверяйте статистику ежедневно (первая неделя) или еженедельно
- Анализируйте: CTR, CPC, конверсии
- Отключайте неэффективное, масштабируйте лучшее
