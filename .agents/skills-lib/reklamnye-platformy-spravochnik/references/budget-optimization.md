## Стоимость привлечения клиента

### Воронка продаж

```
Показы (Impressions)
    ↓ CTR 1-3%
Клики (Clicks)
    ↓ Конверсия 3-10%
Лиды (Leads)
    ↓ Конверсия 10-30%
Продажи (Sales)
```

### Средняя стоимость лида по платформам (2026)

| Платформа | CPC | Конверсия клик→лид | Стоимость лида |
|-----------|-----|---------------------|----------------|
| **VK Реклама** | 15-30₽ | 3-8% | 200-800₽ |
| **Telegram Ads** | 5-20₽ | 3-10% | 300-1000₽ |
| **Яндекс.Директ (Поиск)** | 30-100₽ | 5-15% | 500-2000₽ |
| **Яндекс.Директ (РСЯ)** | 10-30₽ | 2-5% | 600-1500₽ |
| **myTarget** | 8-20₽ | 3-6% | 300-1200₽ |
| **Авито** | - | - | 500-1500₽ (за Premium) |

**Ретаргетинг** (всех платформ): 100-500₽ (в 2-5 раз дешевле!)

### Конверсия лид → продажа

**По типу продукта:**
- **Экскурсии (Desert Safari, City Tour):** 15-30%
- **Билеты в парки:** 20-40% (низкий порог входа)
- **Трансферы:** 40-60% (простое решение)
- **Yacht Tours:** 10-20% (премиум, долгое принятие решения)
- **Многодневные туры:** 5-15% (высокий чек, долгое принятие решения)

**Факторы конверсии:**
- Скорость ответа (5 минут vs 2 часа): +300% конверсии
- Наличие WhatsApp (мгновенная связь): +50%
- Отзывы на сайте: +30%
- Гибкая оплата (частями, в рублях): +20%

### Расчёт CAC (Customer Acquisition Cost)

**Формула:**
```
CAC = Стоимость лида / Конверсия лид→продажа
```

**Пример для Desert Safari:**
- Стоимость лида: 500₽ (VK Реклама)
- Конверсия лид→продажа: 20%
- CAC = 500₽ / 20% = **2,500₽**

**Средний чек:** 4,000₽ (Desert Safari)
**Маржа:** 30% = 1,200₽
**Прибыль:** 1,200₽ - 2,500₽ = **-1,300₽** (убыток!)

**Проблема:** CAC выше маржи = убыточно.

**Решения:**
1. Снизить CAC (оптимизировать рекламу)
2. Увеличить конверсию лид→продажа (улучшить sales)
3. Увеличить LTV (продавать дополнительные услуги)

## ROI расчёты

### Формула ROI

```
ROI = (Выручка - Затраты) / Затраты × 100%
```

### Пример 1: Кампания VK Реклама (Desert Safari)

**Исходные данные:**
- Бюджет: 30,000₽ на месяц
- Показы: 500,000
- Клики: 10,000 (CTR 2%)
- CPC: 3₽
- Лиды: 400 (конверсия 4%)
- Продажи: 80 (конверсия 20%)
- Средний чек: 4,000₽

**Расчёт:**
- Выручка: 80 × 4,000₽ = 320,000₽
- Затраты: 30,000₽
- **ROI: (320,000₽ - 30,000₽) / 30,000₽ × 100% = 967%**

**Вывод:** Отличная кампания! Масштабируем.

### Пример 2: Ретаргетинг в РСЯ (Yacht Tours)

**Исходные данные:**
- Бюджет: 10,000₽ на неделю
- Аудитория: 500 посетителей страницы yacht tours
- Показы: 50,000
- Клики: 1,500 (CTR 3%)
- CPC: 6.67₽
- Лиды: 60 (конверсия 4%)
- Продажи: 8 (конверсия 13%)
- Средний чек: 200,000₽

**Расчёт:**
- Выручка: 8 × 200,000₽ = 1,600,000₽
- Затраты: 10,000₽
- **ROI: (1,600,000₽ - 10,000₽) / 10,000₽ × 100% = 15,900%**

**Вывод:** Ретаргетинг невероятно эффективен для премиум продуктов!

## Автоматические стратегии оптимизации

### VK Реклама: oCPM (Optimized CPM)

**Что это:** VK автоматически оптимизирует ставки для достижения заданной цены конверсии.

**Настройка:**
1. Установите пиксель VK
2. Соберите минимум 25 конверсий/неделю
3. Создайте кампанию с целью "Конверсии"
4. Укажите целевую цену конверсии: 500₽

**VK будет:**
- Повышать ставки на аудитории, которые конвертят дешевле
- Снижать/отключать показы дорогим аудиториям

**Результат:** Стабильная цена лида 400-600₽.

### Яндекс.Директ: "Целевая доля рекламных расходов"

**Что это:** Яндекс оптимизирует ставки для достижения заданного CPA (cost per acquisition).

**Настройка:**
1. Интегрируйте Яндекс.Метрику с Директом
2. Настройте цели (заявка, покупка)
3. Соберите минимум 50 конверсий
4. Создайте кампанию с стратегией "Целевая доля рекламных расходов"
5. Укажите целевую цену конверсии: 1,000₽

**Результат:** Яндекс старается привести лиды по цене 1,000₽ (может колебаться ±30%).

### myTarget: "Максимум конверсий"

**Что это:** myTarget оптимизирует ставки CPM для максимального количества конверсий.

**Настройка:**
1. Установите пиксель myTarget
2. Соберите минимум 50 конверсий
3. Создайте кампанию с целью "Конверсии"
4. Укажите недельный бюджет: 20,000₽

**Результат:** myTarget сам распределит бюджет на самые конверсионные аудитории.

## A/B тестирование

### Что тестировать

#### 1. Креативы (изображения/видео)

**Гипотеза:** Какое изображение привлекает больше кликов?

**Вариант A:** Пустыня на закате
**Вариант B:** Джипы в движении
**Вариант C:** Туристы в восторге

**Методология:**
1. Создайте 3 объявления с одинаковым текстом, разными изображениями
2. Бюджет: по 3,000₽ на каждое (итого 9,000₽)
3. Запустите на 5-7 дней
4. Проанализируйте CTR, CPC, конверсию
5. Выберите лучшее, отключите худшие

**Результат:** CTR может отличаться в 2-3 раза!

#### 2. Заголовки

**Вариант A (цена):** "Desert Safari от 150 AED"
**Вариант B (эмоция):** "Незабываемое приключение в пустыне!"
**Вариант C (скидка):** "Desert Safari -20% при раннем бронировании"

#### 3. Призыв к действию (CTA)

**Вариант A:** "Забронировать"
**Вариант B:** "Узнать больше"
**Вариант C:** "Получить скидку"

#### 4. Аудитории

**Вариант A:** Широкий таргетинг (интересы: путешествия)
**Вариант B:** Ретаргетинг (посетители сайта)
**Вариант C:** Look-alike (похожие на клиентов)

### Статистическая значимость

**Минимальные требования для валидного теста:**
- Минимум 100 кликов на каждый вариант
- Минимум 10 конверсий на каждый вариант
- Разница в CTR/конверсии минимум 20%

**Пример:**
- Вариант A: CTR 1.5%
- Вариант B: CTR 2.0%
- Разница: 33% → **статистически значима**

## Правила оптимизации

### Ежедневная оптимизация (первая неделя)

**Проверяйте каждый день:**
1. **CTR:** < 0.5% = плохой креатив → замените
2. **CPC:** в 2 раза выше среднего → снизьте ставку или отключите
3. **Конверсии:** 0 за 3 дня → проблема с landing page или офферомуникации

### Еженедельная оптимизация

**Каждую неделю:**
1. Отключите объявления с CTR < 0.5%
2. Увеличьте бюджет на объявления с ROI > 300% (+50%)
3. Добавьте новые креативы (A/B тесты)
4. Проверьте ретаргетинг (работает ли пиксель?)

### Ежемесячная оптимизация

**Каждый месяц:**
1. Пересмотрите распределение бюджета по платформам
2. Масштабируйте лучшие платформы (+50-100%)
3. Снизьте/отключите худшие платформы
4. Запустите look-alike кампании (если есть 100+ клиентов)
5. Обновите креативы (новые фото/видео)

## Масштабирование прибыльных кампаний

### Когда масштабировать?

**Критерии:**
- ROI > 200% (стабильно 2+ недели)
- Стоимость лида предсказуема (колебания < 30%)
- Достаточно операционных ресурсов (менеджеры обрабатывают лиды за 5 минут)

### Как масштабировать?

**Вариант 1: Увеличение бюджета (постепенно)**

**Правило:** Увеличивайте бюджет на 20-50% каждые 3-7 дней.

**Пример:**
- Неделя 1: 10,000₽ → ROI 300%
- Неделя 2: 15,000₽ (+50%)
- Неделя 3: 22,000₽ (+50%)
- Неделя 4: 33,000₽ (+50%)

**Почему постепенно:** Резкое увеличение бюджета (×10) может снизить ROI (алгоритмам нужно время на обучение).

**Вариант 2: Расширение аудитории**

**Шаги:**
1. Добавьте новые города (Москва работает? → добавьте СПб)
2. Расширьте возраст (30-40 работает? → добавьте 40-50)
3. Создайте look-alike аудиторию (на базе конвертеров)

**Вариант 3: Дублирование на другие платформы**

**Если VK работает отлично:**
- Запустите те же креативы на myTarget (VK + OK)
- Запустите на Telegram Ads (travel каналы)
- Запустите на Яндекс.Директ РСЯ (баннеры)

## Частые ошибки оптимизации

### Ошибка 1: Слишком быстрое отключение кампаний

**Проблема:** Отключили кампанию через 2 дня ("не работает").

**Почему плохо:** Алгоритмам нужно 5-7 дней на обучение (особенно автоматическим стратегиям).

**Решение:** Дайте минимум 7 дней, 50+ кликов перед оценкой.

### Ошибка 2: Резкое масштабирование

**Проблема:** Бюджет 10K → 100K за день.

**Почему плохо:**
- Алгоритмы не успевают адаптироваться
- ROI падает в 2-3 раза
- Тратите деньги впустую

**Решение:** Масштабируйте постепенно (+20-50% каждую неделю).

### Ошибка 3: Игнорирование сезонности

**Проблема:** Одинаковый бюджет круглый год.

**Почему плохо:**
- Летом (май-сентябрь) спрос на туры в ОАЭ падает на 50%
- Зимой (декабрь-январь) спрос удваивается

**Решение:**
- Декабрь-январь: +100% бюджет
- Май-сентябрь: -30-50% бюджет

## Заключение

Оптимизация бюджета = непрерывный процесс тестирования и улучшения.

**Ключевые принципы:**
1. Начните с малого (50K₽/месяц), протестируйте
2. Инвестируйте в ретаргетинг (80% ROI идёт отсюда)
3. Масштабируйте постепенно (+20-50% каждую неделю)
4. A/B тестируйте всё (креативы, аудитории, платформы)
5. Используйте автоматические стратегии (после 50+ конверсий)

**Целевые метрики:**
- ROI: 200-500% (хорошо), 500%+ (отлично)
- Стоимость лида: 300-1,000₽ (стандартные туры), 100-500₽ (ретаргетинг)
- Конверсия лид→продажа: 15-30%

Удачи в оптимизации!
