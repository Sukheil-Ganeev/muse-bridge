Конфиг yt-dlp на Windows лежит здесь:

  %APPDATA%\yt-dlp\config

В реальном пути это обычно что-то вроде:
  C:\Users\лондо\AppData\Roaming\yt-dlp\config

Хорошая новость — конфиг уже настроен. В нём прописан путь -P D:/Downloads/YouTube/, поэтому указывать его каждый раз при запуске не нужно. Просто пишешь:

  yt-dlp "URL"

И видео само сохранится в D:/Downloads/YouTube/.

Также в конфиге уже включены:
- deno runtime — для обработки YouTube JS challenges (решает проблему "sign in required")
- --sleep-interval 3 — пауза между скачиваниями, защита от бана

Если захочешь посмотреть или изменить конфиг вручную — открой файл %APPDATA%\yt-dlp\config любым текстовым редактором. Каждый параметр пишется с новой строки, например:

  -P D:/Downloads/YouTube/
  --merge-output-format mp4
  --embed-metadata
  --sleep-interval 3

Всё что написано в конфиге применяется автоматически к каждой команде, без необходимости вводить вручную.
