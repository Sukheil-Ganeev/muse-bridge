## Конфиг yt-dlp на Windows

### Где находится файл конфига

На Windows yt-dlp ищет конфигурационный файл в нескольких местах (по приоритету):

1. `%APPDATA%\yt-dlp\config` (рекомендуется)
   Обычно это: `C:\Users\ВашеИмя\AppData\Roaming\yt-dlp\config`

2. `%APPDATA%\yt-dlp\config.txt`

3. Рядом с исполняемым файлом: `yt-dlp.conf` или `yt-dlp.txt`

4. `C:\Users\ВашеИмя\yt-dlp.conf`

Самый простой способ найти нужную папку — открыть Проводник и вставить в адресную строку:
```
%APPDATA%\yt-dlp\
```

Если папки нет — создайте её вручную.

---

### Как создать конфиг

1. Откройте папку `%APPDATA%\yt-dlp\`
2. Создайте файл с именем `config` (без расширения) или `config.txt`
3. Откройте его в Блокноте или любом текстовом редакторе

---

### Пример содержимого конфига

Чтобы не указывать путь сохранения каждый раз, добавьте в конфиг:

```
# Папка для сохранения видео
-o D:/Downloads/%(title)s.%(ext)s

# Лучшее качество видео
-f bestvideo+bestaudio/best

# Встраивать субтитры если есть
--embed-subs

# Скачивать миниатюру
--embed-thumbnail

# Прогресс-бар
--progress
```

---

### Объяснение шаблона пути

В строке `-o D:/Downloads/%(title)s.%(ext)s`:
- `%(title)s` — название видео
- `%(ext)s` — расширение файла (mp4, webm и т.д.)
- `%(uploader)s` — имя канала/автора
- `%(id)s` — ID видео
- `%(upload_date)s` — дата загрузки

Пример с папкой по каналам:
```
-o D:/Downloads/%(uploader)s/%(title)s.%(ext)s
```

---

### Проверка что конфиг работает

Запустите команду:
```
yt-dlp --ignore-config --print-json <url>
```

Или просто запустите yt-dlp с каким-нибудь видео — если путь не указан в команде, он должен взяться из конфига.

Чтобы посмотреть какие настройки применяются:
```
yt-dlp --verbose <url>
```
В начале вывода будет указано, какой конфиг-файл был загружен.

---

### Совет

Если хотите отключить конфиг для одного запуска — используйте флаг `--no-config` или `--ignore-config`.
