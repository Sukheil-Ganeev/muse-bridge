Это классическая проблема — YouTube периодически обновляет защиту, и старая версия yt-dlp перестаёт справляться. Решается в два шага.

**Шаг 1 — обновить yt-dlp (решает 90% случаев):**

```bash
yt-dlp -U
```

После обновления просто запустить скачивание заново. Скорее всего, этого достаточно.

**Шаг 2 — если обновление не помогло:**

На этой машине в конфиге уже настроен deno runtime — он специально обрабатывает YouTube JS challenges (именно те, что вызывают ошибку "Sign in to confirm you're not a bot"). Просто запусти команду заново после обновления — deno подключится автоматически.

Если всё ещё не работает — явно указать player_client:

```bash
yt-dlp --extractor-args "youtube:player_client=web,ios" -P "D:/Downloads/YouTube/" "URL"
```

Флаг `web,ios` заставляет yt-dlp использовать клиент iOS вместо веб-клиента — YouTube реже блокирует мобильные запросы.

**Дополнительно:** если видео с возрастным ограничением или требует аккаунта:

```bash
yt-dlp --cookies-from-browser chrome "URL"
```

Это передаёт куки из Chrome, и YouTube видит авторизованный запрос.

**Краткий порядок действий:**
1. `yt-dlp -U` — обновить
2. Попробовать ещё раз — deno подхватит JS challenge автоматически
3. Если нет — добавить `--extractor-args "youtube:player_client=web,ios"`
4. Если видео требует авторизации — `--cookies-from-browser chrome`
