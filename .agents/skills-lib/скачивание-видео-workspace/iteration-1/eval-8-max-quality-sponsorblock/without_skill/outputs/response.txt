Задача: скачать видео youtube.com/watch?v=dQw4w9WgXcQ в максимальном качестве, вырезать рекламные вставки (SponsorBlock), встроить субтитры и обложку.

Готовая команда:

yt-dlp \
  -f "bestvideo+bestaudio/best" \
  --merge-output-format mkv \
  --sponsorblock-remove all \
  --embed-subs \
  --sub-langs "ru,en" \
  --embed-thumbnail \
  --embed-metadata \
  --remux-video mkv \
  -o "%(title)s.%(ext)s" \
  "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

---

Пояснения по каждому флагу:

-f "bestvideo+bestaudio/best"
  Скачивает отдельно лучшее видео и лучший звук, затем объединяет.
  Это даёт максимальное качество (например, VP9 4K + Opus 160k).
  Fallback "/best" — если раздельные потоки недоступны.

--merge-output-format mkv
  Итоговый контейнер — MKV. Он поддерживает любые кодеки без перекодирования,
  а также встроенные субтитры и обложку.

--sponsorblock-remove all
  Вырезает все рекламные вставки по базе SponsorBlock:
  спонсорские интеграции, заставки, призывы к подписке, музыкальные превью и т.д.
  Используется метка "all" — убирает всё что помечено сообществом.

--embed-subs
  Встраивает субтитры прямо в файл (не отдельной дорожкой снаружи).

--sub-langs "ru,en"
  Скачивает субтитры на русском и английском. Если нужны другие языки —
  замените коды или укажите "all" для всех доступных.

--embed-thumbnail
  Встраивает обложку (превью видео) в метаданные файла.
  В большинстве плееров будет отображаться как иконка файла.

--embed-metadata
  Встраивает название, автора, дату и другие метаданные в файл.

--remux-video mkv
  Принудительно переупаковывает в MKV без перекодирования (быстро, без потери качества).

-o "%(title)s.%(ext)s"
  Имя файла = название видео + расширение. Файл сохранится в текущую папку.

---

Если нужно сохранить в конкретную папку — добавьте путь в -o:

  -o "D:/Downloads/%(title)s.%(ext)s"

Если субтитры автоматически сгенерированы (а не ручные) — добавьте флаг:

  --write-auto-subs

Для проверки доступных форматов перед скачиванием:

  yt-dlp -F "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
