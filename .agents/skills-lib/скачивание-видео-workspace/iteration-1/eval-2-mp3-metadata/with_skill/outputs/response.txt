Вот команда для скачивания MP3 с встроенной обложкой:

yt-dlp -x --audio-format mp3 --audio-quality 0 --embed-thumbnail --embed-metadata -P "D:/Downloads/YouTube/" "https://youtube.com/watch?v=dQw4w9WgXcQ"

Что делает каждый флаг:
- -x — извлечь только аудио (не скачивать видео)
- --audio-format mp3 — конвертировать в MP3
- --audio-quality 0 — максимальное качество (~320kbps)
- --embed-thumbnail — встроить обложку прямо в MP3-файл (видно в плеере, файловом менеджере)
- --embed-metadata — встроить название, исполнителя, дату и прочее
- -P "D:/Downloads/YouTube/" — сохранить в эту папку

Файл появится в D:/Downloads/YouTube/ с именем видео и расширением .mp3.

Важно: для встраивания обложки нужен FFmpeg. Если он установлен — всё сработает автоматически. Если нет, команда выдаст предупреждение и обложка не встроится. Проверить: ffmpeg -version
