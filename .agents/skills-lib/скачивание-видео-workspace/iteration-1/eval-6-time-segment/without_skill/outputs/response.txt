Для скачивания только первых 3 минут видео с YouTube используй yt-dlp с параметрами обрезки через FFmpeg.

Команда:

yt-dlp -x --audio-format mp3 --download-sections "*0:00-3:00" "https://youtube.com/watch?v=dQw4w9WgXcQ"

Если нужно видео (не только аудио):

yt-dlp --download-sections "*0:00-3:00" "https://youtube.com/watch?v=dQw4w9WgXcQ"

Пояснения:

--download-sections "*0:00-3:00" — ключевой параметр. Звёздочка (*) означает "применить к видео", затем указывается временной диапазон в формате начало-конец.

-x — извлечь только аудио (убери если нужно видео)

--audio-format mp3 — конвертировать в MP3 (работает только вместе с -x)

Требования:
- yt-dlp актуальной версии (параметр --download-sections появился в 2022)
- FFmpeg установлен и доступен в PATH — без него обрезка не работает

Проверить версию yt-dlp:
yt-dlp --version

Обновить до последней версии:
yt-dlp -U

Если FFmpeg не установлен, команда скачает видео целиком без обрезки. На Windows FFmpeg можно поставить через winget:
winget install ffmpeg
