Ошибка "ERROR: Requested format not available" означает, что yt-dlp пытается скачать формат, которого нет у этого конкретного видео. Например, ты просишь 1080p, а видео загружено только в 720p — или просишь MP4, а доступен только WebM.

Решение в три шага:

**Шаг 1 — посмотри, что реально доступно:**

yt-dlp -F "youtube.com/watch?v=xxx"

Команда выведет таблицу всех доступных форматов с их ID, разрешением, кодеком и размером. Это главный инструмент диагностики.

**Шаг 2 — скачай с fallback (рекомендую):**

yt-dlp -f "bv*[height=1080]+ba/bv*[height=720]+ba/best" -P "D:/Downloads/YouTube/" "youtube.com/watch?v=xxx"

Эта команда пробует 1080p → если нет, берёт 720p → если нет, берёт лучшее из доступного. Ошибки "format not available" не будет.

**Шаг 3 — или просто лучшее качество без условий:**

yt-dlp -f best -P "D:/Downloads/YouTube/" "youtube.com/watch?v=xxx"

---

**Если хочешь конкретно MP4:**

yt-dlp -f "bv*[ext=mp4]+ba[ext=m4a]/b[ext=mp4]" --merge-output-format mp4 -P "D:/Downloads/YouTube/" "youtube.com/watch?v=xxx"

Эта команда сначала ищет MP4+M4A потоки, если нет — берёт любой MP4. FFmpeg должен быть установлен (проверить: ffmpeg -version).

---

**Частые причины этой ошибки:**

1. Видео залито в низком качестве — 1080p просто нет, доступно только 360p/480p/720p
2. Ты указал конкретный формат по ID (-f 137+140), а этот ID не существует для данного видео
3. Указал расширение [ext=mp4], а YouTube отдаёт только WebM
4. Старая версия yt-dlp — попробуй: yt-dlp -U

---

**Итог — рабочая команда на все случаи:**

yt-dlp -f "bv*[ext=mp4][height<=1080]+ba[ext=m4a]/bv*+ba/best" --merge-output-format mp4 -P "D:/Downloads/YouTube/" "youtube.com/watch?v=xxx"

Эта строка сначала пробует MP4 1080p, затем любое видео+аудио, затем просто лучшее — и никогда не выдаст "format not available".
