Ошибка "ERROR: Requested format not available" означает, что yt-dlp пытается скачать конкретный формат видео (например, mp4 720p), которого нет на серверах YouTube для данного видео. Это частая ситуация — не все видео доступны во всех форматах.

## Причины

1. Видео не имеет запрошенного разрешения (например, нет 1080p или 4K)
2. Формат был указан явно через -f и именно он недоступен
3. Некоторые форматы доступны только для определённых регионов
4. Видео могло быть загружено в нестандартном формате

## Решение

### Шаг 1 — Посмотреть доступные форматы

Сначала узнайте, какие форматы вообще есть для этого видео:

    yt-dlp -F "youtube.com/watch?v=xxx"

Это выведет таблицу со всеми доступными форматами. Пример вывода:
    ID  EXT   RESOLUTION  ...
    18  mp4   640x360
    22  mp4   1280x720
    137 mp4   1920x1080   (только видео, без звука)
    140 m4a   audio only

### Шаг 2 — Выбрать нужный формат

После просмотра списка скачайте нужный по ID:

    yt-dlp -f 22 "youtube.com/watch?v=xxx"

Или укажите конкретное разрешение:

    yt-dlp -f "bestvideo[height<=720]+bestaudio/best[height<=720]" "youtube.com/watch?v=xxx"

### Шаг 3 — Универсальная команда (рекомендуется)

Если не нужен конкретный формат, используйте автоматический выбор лучшего доступного:

    yt-dlp -f "bestvideo+bestaudio/best" "youtube.com/watch?v=xxx"

Или просто без флага -f — yt-dlp сам выберет лучшее:

    yt-dlp "youtube.com/watch?v=xxx"

### Шаг 4 — Если нужен именно mp4

    yt-dlp -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best" --merge-output-format mp4 "youtube.com/watch?v=xxx"

## Итог

Самый простой способ решить проблему — сначала запустить yt-dlp -F чтобы увидеть доступные форматы, затем выбрать подходящий. Если просто нужно скачать видео без специфичного формата — уберите флаг -f и yt-dlp справится сам.
