Чтобы посмотреть доступные форматы без скачивания, используй флаг -F:

```bash
yt-dlp -F "https://youtube.com/watch?v=dQw4w9WgXcQ"
```

Это только запрашивает информацию с сервера — ничего не скачивается.

## Расшифровка колонок

| Колонка | Что означает |
|---------|-------------|
| **ID** | Номер формата — используется при скачивании конкретного варианта |
| **EXT** | Контейнер файла: mp4, webm, m4a, webm |
| **RESOLUTION** | Разрешение видео (ширина x высота) или "audio only" для аудиодорожек |
| **FPS** | Кадров в секунду (24, 30, 60) |
| **FILESIZE** | Приблизительный размер файла |
| **TBR** | Total Bitrate — общий битрейт в kbps |
| **PROTO** | Протокол загрузки: https (прямой), m3u8 (HLS-стрим), dash |
| **VCODEC** | Видеокодек: avc1/H.264, vp9, av01/AV1 |
| **VBR** | Video Bitrate в kbps |
| **ACODEC** | Аудиокодек: aac, opus |
| **ABR** | Audio Bitrate в kbps |
| **ASR** | Audio Sample Rate в Hz (44100 = CD-качество) |
| **MORE INFO** | Метка качества (144p, 360p, 1080p и т.д.) и тип потока |

## Ключевые моменты для этого видео

**Важно:** YouTube хранит видео и аудио РАЗДЕЛЬНО для качества 360p и выше. Строки с `video only` — это только картинка без звука. Строки с `audio only` — только звук.

Поэтому для скачивания в хорошем качестве потребуется FFmpeg, который склеивает два потока в один файл.

**Кодеки в порядке предпочтения:**
- `av01` (AV1) — современный, лучшее сжатие, меньший размер при том же качестве
- `vp9` — хорошее качество, широкая поддержка
- `avc1` / H.264 — самый совместимый, работает везде (TV, телефоны, старые плееры)

**Аудио:**
- `opus` — лучший кодек для потокового вещания, меньше размер
- `aac` — универсальный, работает в MP4/M4A

## Как читать ID форматов

Если захочешь скачать конкретную комбинацию — используешь `-f ID_видео+ID_аудио`. Например:
- `137+140` — 1080p H.264 + AAC 129kbps (самый совместимый вариант)
- `248+251` — 1080p VP9 + Opus (меньший размер файла)
- `399+251` — 1080p AV1 + Opus (самое современное, наименьший размер)

Но это уже для скачивания — ты пока только смотришь что доступно.
