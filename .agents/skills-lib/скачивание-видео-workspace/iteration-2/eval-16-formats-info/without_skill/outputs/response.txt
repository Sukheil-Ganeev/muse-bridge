## Просмотр доступных форматов видео без скачивания

Чтобы посмотреть все доступные форматы для видео, используй флаг `-F` (или `--list-formats`):

```bash
yt-dlp -F "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
```

## Расшифровка колонок

| Колонка | Что означает |
|---------|-------------|
| **ID** | Номер формата — используется при скачивании конкретного формата |
| **EXT** | Контейнер файла: mp4, webm, m4a |
| **RESOLUTION** | Разрешение видео (ширина x высота) или "audio only" для аудио |
| **FPS** | Частота кадров в секунду |
| **FILESIZE** | Примерный размер файла |
| **TBR** | Общий битрейт (total bitrate) в kbps |
| **VCODEC** | Видеокодек: avc1 (H.264), vp9, av01 (AV1) |
| **ACODEC** | Аудиокодек: aac, opus |
| **ABR** | Аудио битрейт в kbps |

---

## Важный момент: видео и аудио отдельно

YouTube хранит видео и аудио как отдельные потоки (DASH). В списке видишь:
- Строки с `video only` — только картинка, без звука
- Строки с `audio only` — только звук, без картинки
- Иногда есть "объединённые" форматы (обычно только для 360p и ниже)

По умолчанию yt-dlp автоматически скачает лучшее видео + лучшее аудио и объединит их в один файл — это поведение по умолчанию и оно правильное.

## Если хочешь скачать конкретный формат

После просмотра списка можно скачать конкретный формат по ID:

```bash
# Скачать видео 1080p (ID 137) + лучшее аудио
yt-dlp -f 137+140 "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# Скачать лучшее качество (поведение по умолчанию)
yt-dlp "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# Скачать максимум 720p
yt-dlp -f "bestvideo[height<=720]+bestaudio" "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
```

Но для просмотра форматов без скачивания — достаточно флага `-F`.
