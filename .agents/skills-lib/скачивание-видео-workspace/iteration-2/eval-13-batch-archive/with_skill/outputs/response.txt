Для пакетного скачивания 100 ссылок из файла с пропуском уже скачанных используй эту команду:

yt-dlp -a urls.txt --download-archive "D:/Downloads/YouTube/archive.txt" -P "D:/Downloads/YouTube/" --no-overwrites -i

Разбор флагов:

-a urls.txt
  Читает ссылки из файла urls.txt (одна ссылка на строку).

--download-archive "D:/Downloads/YouTube/archive.txt"
  Ключевой флаг. yt-dlp ведёт файл archive.txt, в котором хранятся ID всех скачанных видео.
  При повторном запуске — если видео уже есть в архиве, оно пропускается без скачивания.
  Файл создаётся автоматически при первом запуске.

-P "D:/Downloads/YouTube/"
  Папка сохранения. Все видео скачаются в D:/Downloads/YouTube/

--no-overwrites
  Не перезаписывать файл если он уже существует на диске (дополнительная защита помимо архива).

-i (--ignore-errors)
  Если одна из 100 ссылок недоступна или удалена — пропустить её и продолжить со следующей.
  Без этого флага yt-dlp остановится на первой же ошибке.

---

Как это работает на практике:

Первый запуск:
  - скачивает все 100 видео
  - записывает их ID в archive.txt

Повторный запуск той же команды:
  - читает archive.txt
  - все 100 видео уже там → все пропускаются
  - скачиваться ничего не будет

Если добавил новые ссылки в urls.txt:
  - старые пропускаются (есть в архиве)
  - новые скачиваются

---

Если хочешь скачивать в MP4 1080p (а не в формате по умолчанию), расширь команду:

yt-dlp -a urls.txt --download-archive "D:/Downloads/YouTube/archive.txt" -P "D:/Downloads/YouTube/" --no-overwrites -i -f "bv*[ext=mp4][height<=1080]+ba[ext=m4a]/b[ext=mp4]" --merge-output-format mp4

Для этого нужен FFmpeg (без него YouTube отдаёт максимум 720p).

---

Формат файла urls.txt — просто одна ссылка на строку:

https://youtube.com/watch?v=aaa111
https://youtube.com/watch?v=bbb222
https://youtube.com/watch?v=ccc333
...
