Для скачивания видео с ВКонтакте через yt-dlp используй следующую команду:

yt-dlp "https://vk.com/video-123456_789"

Если видео требует авторизации (приватное или доступно только авторизованным пользователям), нужно передать куки из браузера:

yt-dlp --cookies-from-browser chrome "https://vk.com/video-123456_789"

Или экспортировать куки вручную и указать файл:

yt-dlp --cookies cookies.txt "https://vk.com/video-123456_789"

Дополнительные полезные опции:

# Выбрать лучшее качество (по умолчанию):
yt-dlp "https://vk.com/video-123456_789"

# Скачать в конкретном качестве (например 720p):
yt-dlp -f "bestvideo[height<=720]+bestaudio/best[height<=720]" "https://vk.com/video-123456_789"

# Сохранить в определённую папку с именем из заголовка:
yt-dlp -o "D:/Downloads/%(title)s.%(ext)s" "https://vk.com/video-123456_789"

# Посмотреть доступные форматы без скачивания:
yt-dlp -F "https://vk.com/video-123456_789"

Примечания:
- Убедись, что yt-dlp обновлён до последней версии: yt-dlp -U
- ВКонтакте периодически меняет защиту, и старые версии yt-dlp могут не работать
- Для публичных видео авторизация обычно не нужна
- Полный URL должен включать https://, иначе yt-dlp может не распознать ссылку
