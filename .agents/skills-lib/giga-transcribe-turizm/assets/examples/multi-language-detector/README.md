# Multi-Language Audio Detector

Автоопределение языка аудио для туристического бизнеса ОАЭ (русский, английский, арабский, турецкий).

## Описание

Транскрибирует аудио на всех поддерживаемых языках параллельно и выбирает лучший результат на основе confidence scoring.

## Использование

```bash
python main.py --input client_voice.ogg
```

Вывод:
```
Detected languages:
  Russian: 0.95 "Привет, хотел узнать про экскурсии"
  English: 0.45 "Привет wanted excursions"
  Arabic: 0.20 "..."

Best result: Russian (0.95)
```

## Поддерживаемые языки

- Русский (ru-RU) - основной для СНГ клиентов
- Английский (en-US) - международные клиенты
- Арабский (ar-AE) - местные клиенты
- Турецкий (tr-TR) - турецкие туристы

## Конфигурация

```env
YANDEX_API_KEY=xxx
YANDEX_FOLDER_ID=xxx
```

## Алгоритм

1. Параллельная транскрипция на 4 языках
2. Расчет confidence для каждого результата
3. Анализ качества текста (словарь, структура)
4. Выбор лучшего варианта
5. Возврат с метаданными
