### Когда Metro лучше такси

| Ситуация | Рекомендация |
|----------|-------------|
| 1-2 чел, вдоль Red/Green Line | Metro (в 7-10 раз дешевле) |
| DXB → Downtown | Metro 3 AED vs такси 70 AED |
| Бюджетный день | Daily Cap 14 AED = безлимит |
| Dubai → Abu Dhabi (1-2 чел) | E100/E101 25 AED vs такси 250 AED |

### Когда такси лучше Metro

| Ситуация | Почему |
|----------|--------|
| Группа 3+ | Делить стоимость выгоднее |
| Safari Zoo, Miracle Garden, Global Village | Нет прямого Metro |
| Ночь 00:00-05:00 | Metro закрыто |
| Воскресенье до 08:00 | Metro закрыто |
| Atlantis (Palm) | Monorail ПРИОСТАНОВЛЕН |

## 10. Формат вывода маршрута

```
=======================================================
  МАРШРУТ НА [ДАТУ]
  Старт: [Отель], [Город]
=======================================================

  #   Время        Локация              На месте   До след.
  1   09:00        Выезд из отеля          -        25 мин
  2   09:25-12:25  Dubai Safari Zoo       3ч        35 мин
  ...

=======================================================
  ИТОГИ: ~XX км | ~Xч в пути | Salik ~XX AED
=======================================================
```

## 11. Форматирование для мессенджеров

### WhatsApp / Telegram

**Заголовки:** Используй эмодзи в начале
```
=== МАРШРУТ НА 15.01 ===
```

**Списки:**
```
1. Dubai Safari Zoo
2. Dubai Frame
3. Burj Khalifa
```

**Время:**
```
09:00 - Выезд
09:30 - Safari Zoo (3ч)
12:30 - Обед
```

**Итоги:**
```
ИТОГО:
- Расстояние: ~75 км
- Время в пути: ~2ч
- Salik: ~20 AED
```

## 12. Чеклист перед отправкой

- [ ] Маршрут линейный (не циклический)
- [ ] Пробки учтены (7-9, 17-19)
- [ ] <= 6 локаций
- [ ] Есть обед (1 час)
- [ ] Буферы добавлены (+15%)
- [ ] Часы работы OK
- [ ] Сезонность OK
- [ ] <= 150 км
- [ ] <= 12 часов
- [ ] Транспорт уточнен (авто/такси/Metro)
- [ ] Transit-данные корректны (E100/E101, расписание)
