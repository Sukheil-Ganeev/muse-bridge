## 6. Контекстные подсказки

Если пользователь упоминает:
- "закат" + "башня" = Burj Khalifa
- "аквапарк" = Atlantis Aquaventure
- "самолет из цветов" = Miracle Garden
- "самая быстрая горка" = Ferrari World
- "павильоны стран" = Global Village
- "золото" + "рынок" = Old Dubai (Gold Souk)
- "абра" / "водное такси" = Old Dubai (Creek)
- "крытый парк" = Warner Bros World
- "250 метров колесо" = Ain Dubai

## 7. Алгоритм нормализации

```
1. Привести к нижнему регистру
2. Удалить лишние пробелы
3. Проверить точное совпадение
4. Проверить частичное совпадение (contains)
5. Проверить транслитерацию
6. Проверить сокращения
7. Если не найдено - запросить уточнение
```

**Пример:**
```
Вход: "хочу на бурдж халифу и в сафари"
После нормализации:
- "бурдж халифу" -> "Burj Khalifa"
- "сафари" -> "Dubai Safari Zoo"
```
