# Критические правила маршрутов ОАЭ

Обязательные правила и ограничения при построении туристических маршрутов.

---

## 1. Категорически запрещено

| Нарушение | Почему критично | Последствия |
|-----------|-----------------|-------------|
| Циклический маршрут (A - C - A - B) | Потеря времени на повторный путь | +1-2 часа впустую, усталость |
| Игнорировать пробки в час пик | 7-9 и 17-19 - дороги встают | Опоздание на 30-60 мин |
| Пропускать обед (8+ часов без еды) | Падение энергии, раздражение | Испорченное впечатление |
| Включать закрытые локации | Miracle Garden летом ЗАКРЫТ | Сорванные планы, разочарование |
| Перегружать день (8+ локаций) | Физическая усталость | Бегом везде, ничего не запомнят |
| Недостаточно времени на локацию | Не успеют осмотреть | Ощущение "галопом по европам" |

## 2. Обязательные правила

| Правило | Как применять | Пример |
|---------|---------------|--------|
| Уточнить транспорт перед расчетом | Спросить: авто/такси/метро? | "На чем планируете передвигаться?" |
| Добавить буфер 15% на непредвиденности | К каждому отрезку пути | 40 мин дорога - закладывай 46 мин |
| Проверить часы работы (особенно пт) | Пятница: многое открыто с 14:00 | Мечеть Шейха Зайда: пт с 16:30 |
| Учесть лучшее время посещения | Safari утром, Burj на закат | Сафари 9:00, Burj Khalifa 17:30 |
| Предусмотреть перерыв на еду | Минимум 1 час на обед | 12:00-13:00 или 13:00-14:00 |

## 4. Буферы времени

| Ситуация | Буфер | Когда добавлять |
|----------|-------|-----------------|
| Парковка | +15 мин | Всегда (моллы, достопримечательности) |
| Очередь на вход | +10 мин | Популярные места без брони |
| Туалет/вода | +5 мин | Каждые 2-3 часа |
| Час пик (7-9, 17-19) | +50% | Все поездки в это время |
| Пятничная молитва | +30 мин | Около мечетей 12:00-14:00 |
| Фотосессия | +10-15 мин | Инстаграмные локации |

**Пример расчета с буферами:**
```
Базовое время в пути: 40 мин
+ Час пик (+50%): +20 мин
+ Парковка: +15 мин
= ИТОГО: 75 мин (1 час 15 мин)
```

## 5. Лимиты на день

| Параметр | Лимит | Комфортно | Перебор |
|----------|-------|-----------|---------|
| Локации в день | 5-6 | 4-5 | 7+ |
| Километраж | 150 км | 100-120 км | 200+ км |
| Часов программы | 10-12 ч | 8-10 ч | 14+ ч |
| Время на ногах | 6-7 ч | 4-5 ч | 8+ ч |
| Пеших переходов | 5-6 км | 3-4 км | 8+ км |

**Формула оптимального дня:**
```
4-5 локаций + 1 обед + 2-3 перерыва = идеальный день
```

## 7. Чеклист перед отправкой маршрута

- [ ] Маршрут НЕ циклический (линейный или кольцевой)
- [ ] Учтены пробки (7-9, 17-19)
- [ ] Локаций <= 6
- [ ] Есть перерыв на обед (1 час)
- [ ] Буферы добавлены (+15%)
- [ ] Часы работы проверены
- [ ] Сезонность учтена
- [ ] Лучшее время посещения соблюдено
- [ ] Общий километраж <= 150 км
- [ ] Программа <= 12 часов

## 8. Памятка (быстрый справочник)

### ЗАПРЕЩЕНО:
- Циклические маршруты (A-C-A)
- Игнорировать пробки (7-9, 17-19)
- 8+ локаций в день
- Пропускать обед

### ОБЯЗАТЕЛЬНО:
- Уточнить транспорт
- Буфер +15% к времени
- Проверить часы работы (пятница!)
- Перерыв на еду

### ЛУЧШЕЕ ВРЕМЯ:
- Safari Zoo - 9:00-11:00 (утро)
- Burj Khalifa - 17:30-19:30 (закат)
- Global Village - после 16:00
- Desert Safari - после 15:00

### ЗАКРЫТО ЛЕТОМ:
- Miracle Garden (июнь-сентябрь)
- Global Village (июнь-октябрь)

### ЛИМИТЫ:
- 5-6 локаций/день
- 150 км максимум
- 10-12 часов программа
