## 1. Локации Дубая

### 1.1. Burj Khalifa

| Параметр | Значение |
|----------|----------|
| Координаты | 25.1972, 55.2744 |
| Район | Downtown Dubai |
| Часы работы | 08:00 - 00:00 |
| Время посещения | 1.5 - 2.5 ч |
| Лучшее время | Закат (17:30-18:30 зимой, 19:00-19:30 летом) |
| Стоимость | 149-399 AED |
| Ближайшая станция | Burj Khalifa/Dubai Mall (R25), Red Line |
| Пешком от станции | 10 мин (через Dubai Mall) |

**Советы:**
- Бронировать билеты заранее онлайн (дешевле на 20-30%)
- Слоты на закат разбирают первыми
- Уровень 124-125 достаточен для большинства
- Рядом Dubai Fountain - бесплатное шоу каждые 30 мин вечером

**Близкие локации:** Dubai Mall, Dubai Aquarium (5 мин пешком)
