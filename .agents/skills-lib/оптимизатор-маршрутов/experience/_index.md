## Критические уроки (топ-5)

1. **ВСЕГДА активируй скилл форматирования** (`форматирование-whatsapp` или `форматирование-telegram`) через Skill tool перед созданием файла. НЕ форматируй вручную по памяти!
2. **Transit между северными эмиратами — слабый.** Google Maps часто возвращает ZERO_RESULTS для transit Аджман↔Шарджа. Ищи маршруты вручную через веб-поиск + справочники.
3. **Всегда считай пешую дистанцию при пересадках.** Al Jubail → Al Zahia = 9.4 км пешком — нереально! Проверяй через `maps_directions` mode=walking.
4. **Честно сравнивай transit vs такси.** Если автобус + такси на пересадке стоит ~42-52 AED, а такси напрямую ~50-70 AED — разница мизерная, а время в 3 раза больше. Говори прямо.
5. **Указывай конкретные приложения для карт оплаты.** Не просто "ta.gov.ae", а конкретно: Ajman ONE (для Masaar), S'hail (для nol), Darbi (для Hafilat).

## Интеграции

### EXP-NEW: Интеграция в VoiceTranscriptionBot v5.4.0 (2026-02-22)
**Контекст:** Маршрутизатор интегрирован как модуль core/router.py в VoiceTranscriptionBot
**Что реализовано:**
- Класс RouteBuilder с маршрутами, оптимизацией дня, транзитом и Саликом
- AI-маршрут через Gemini (естественный язык → тип маршрута)
- TSP оптимизация: Nearest Neighbor + 2-opt + якорные точки (Safari Zoo утро, Burj Khalifa закат, Global Village после 16:00)
- Telegram команды: /route + inline кнопки (между точками, план дня, метро, на машине)
- WhatsApp команды: текстовые триггеры для маршрутов
- Google Maps API: Directions, Distance Matrix, Geocoding
- Haversine формула для оценки Салика (8 ворот, радиус 500м)
- 35 тестов (pytest)
**Урок:** Использование httpx вместо aiohttp. Якорные точки — ключевая фича для туристических маршрутов по ОАЭ.
