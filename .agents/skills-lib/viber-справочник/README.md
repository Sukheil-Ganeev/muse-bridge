# viber-справочник

Production-ready руководство по Viber как платформе для туристического бизнеса ОАЭ.

## Структура

```
viber-справочник/
├── SKILL.md              # Основной справочник (~4500 слов)
├── README.md             # Этот файл
└── references/
    ├── faq.md            # Часто задаваемые вопросы
    ├── troubleshooting.md # Решение проблем
    └── cheatsheet.md     # Шпаргалка
```

## Что покрывает

- Обзор платформы (Rakuten Viber, 1.2B+ пользователей, фокус СНГ)
- Communities — создание, управление, модерация, суперадмины
- Channels — broadcast-формат, отличие от Communities
- Business Messages — верифицированные аккаунты, типы сообщений, цены
- Viber Ads — CPM-реклама, форматы, таргетинг
- Медиа — лимиты файлов, стикеры, GIF
- Sticker Market — создание паков, брендированные стикеры
- Viber Lenses — AR-линзы (партнерство со Snap)
- Viber Pay — платежи (ограниченная география)
- Приватность — E2E шифрование, секретные чаты
- Интеграция с CRM — Infobip, API, webhooks
- Примеры для туризма ОАЭ — сообщества, каналы, рассылки, реклама
- Лимиты и ограничения

## Что НЕ покрывает

- Bot API (см. `viber-bot-справочник`)
- Chatbot-разработка
- Webhook API для ботов

## Ключевые факты для бизнеса

| Факт | Значение |
|------|----------|
| Проникновение в Беларуси | ~90% |
| Проникновение в Украине | 70%+ (29.4% трафика) |
| E2E шифрование | По умолчанию с 2016 |
| Мин. платеж Business Messages | 150 EUR/мес (ОАЭ/СНГ) |
| Viber Pay в ОАЭ | Не доступен |
| Макс. участников Community | 1 млрд |
