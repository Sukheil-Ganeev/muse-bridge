## 1. Обзор платформы

### Что такое Viber

Viber (полное название — Rakuten Viber) — мессенджер, принадлежащий японскому холдингу Rakuten Group с 2014 года. Основан в 2010 году израильскими предпринимателями Талмоном Марко и Игорем Магазинником. Штаб-квартира разработки — Минск (Беларусь) и Люксембург.

### Ключевые цифры

| Метрика | Значение |
|---------|----------|
| Зарегистрированные пользователи | 1.2+ млрд |
| Активные пользователи (MAU) | ~260 млн |
| Доля мобильного трафика | 77.3% |
| Платформы | iOS, Android, Windows, macOS, Linux |
| Шифрование | E2E по умолчанию (с 2016) |
| Протокол | На базе Signal Double Ratchet |

### География и аудитория

Viber занимает уникальную нишу — это мессенджер #1 или #2 в странах СНГ и Восточной Европы:

| Страна / Регион | Доля трафика | Проникновение |
|----------------|-------------|---------------|
| Украина | 29.4% | 70%+ |
| Россия | 12.4% | 70%+ |
| Беларусь | 6.5% | ~90% |
| Греция | 5.6% | ~90% |
| Сербия | — | ~90% |
| Болгария | — | ~90% |
| Грузия, Молдова | — | Высокое |
| СНГ/ЦВЕ в целом | ~55% | 70%+ |

**Для туристического бизнеса ОАЭ это ключевой канал:** основная клиентская база (туристы из Беларуси, Украины, Грузии, Молдовы) активно использует Viber как основной мессенджер.

### Основные продукты платформы

- **Личные чаты** — 1-на-1, E2E шифрование
- **Групповые чаты** — до 250 участников
- **Communities (Сообщества)** — до 1 млрд участников, модерация
- **Channels (Каналы)** — broadcast-формат, подписчики
- **Viber Business Messages** — официальные бизнес-аккаунты
- **Viber Ads** — рекламная платформа (CPM)
- **Viber Pay** — платежи (ограниченная география)
- **Viber Lenses** — AR-фильтры (партнерство со Snap)
- **Sticker Market** — стикеры, в т.ч. брендированные

## 2. Viber Communities (Сообщества)

### Что это

Communities — расширенные групповые чаты без ограничения на количество участников (технически до 1 млрд). Запущены в 2018 году. Подходят для создания клиентских сообществ, профессиональных групп, локальных коммьюнити.

### Отличие от группового чата

| Параметр | Группа | Сообщество |
|----------|--------|------------|
| Макс. участников | 250 | 1 млрд |
| Роли | Админ, участник | Суперадмин, админ, участник |
| Видимость номеров | Да | Нет (приватность) |
| Публичная ссылка | Нет | Да |
| Статистика | Нет | Да (insights) |
| Модерация | Базовая | Полная (бан, мут, удаление) |
| Закрепленные сообщения | Нет | Да |
| Discover (поиск) | Нет | Да |

### Роли управления

**Суперадмин** (создатель):
- Полный контроль над сообществом
- Назначение/снятие админов
- Изменение описания, фото, настроек
- Удаление любых сообщений
- Бан участников
- Передача роли суперадмина

**Админ** (назначается суперадмином):
- Модерация контента
- Удаление сообщений
- Бан и мут участников
- Закрепление сообщений
- Публикация от имени сообщества

**Участник:**
- Чтение и отправка сообщений
- Реакции на сообщения
- Пересылка контента

### Приватность в сообществах

Viber защищает приватность участников: ни суперадмин, ни админы **не видят номера телефонов** участников. Это важное отличие от Telegram и WhatsApp.

### Статистика сообщества (Community Insights)

С октября 2020 доступна аналитика:
- Количество участников и динамика роста
- Активность (сообщения, реакции)
- Вовлеченность по постам
- Лучшее время для публикаций

### Создание сообщества

1. Открыть Viber → "Создать" → "Сообщество"
2. Задать название (до 250 символов)
3. Загрузить аватар (рекомендуется 500x500 px)
4. Добавить описание
5. Настроить: кто может писать, правила вступления
6. Пригласить участников (ссылка, контакты, QR)

### Советы по модерации

- Закрепите правила сообщества первым сообщением
- Назначьте 2-3 админов для разных часовых поясов
- Используйте функцию "только админы могут писать" для анонсов
- Регулярно проверяйте insights для оптимизации контента

## 3. Viber Channels (Каналы)

### Что это

Channels — формат одностороннего вещания (broadcast). Только админы публикуют контент, подписчики читают и реагируют. Аналог каналов в Telegram.

### Отличие от Communities

| Параметр | Community | Channel |
|----------|-----------|---------|
| Кто пишет | Все участники | Только админы |
| Формат | Дискуссия | Broadcast |
| Комментарии | В общий чат | Реакции |
| Применение | Обсуждение | Новости, контент |
| Макс. подписчиков | 1 млрд | 1 млрд |

### Создание канала

1. Viber → "Создать" → "Канал"
2. Название, аватар, описание
3. Категория (путешествия, бизнес, развлечения и т.д.)
4. Настройка возрастных ограничений (если нужно)
5. Публичная ссылка для подписки

### Функции админа канала

- Публикация текста, фото, видео, файлов, стикеров
- Закрепление постов
- Просмотр статистики подписчиков
- Управление соадминами
- Настройка уведомлений для подписчиков

### Продвижение канала

- Публичная ссылка (viber://pa?chatURI=...)
- QR-код для оффлайн-материалов
- Viber Discover — внутренний каталог каналов
- Кросс-промо с другими каналами
- Ссылка на сайте и в соцсетях

## 4. Viber Business Messages

### Что это

Viber Business Messages — официальный инструмент бизнес-коммуникации. Компании получают верифицированный аккаунт с синей галочкой и могут отправлять клиентам транзакционные, сервисные и промо-сообщения.

### Типы сообщений

| Тип | Назначение | Контент |
|-----|-----------|---------|
| Transactional | Подтверждения, уведомления | Текст, кнопки |
| Promotional | Маркетинг, акции | Текст, изображения, кнопки, карусели |
| Conversational (Session) | Диалог с клиентом | Любой контент |

### Верификация (синяя галочка)

Для получения верифицированного бизнес-аккаунта:
1. Зарегистрироваться через официального партнера Viber (Infobip, MessageBird, Vonage и др.)
2. Предоставить документы компании
3. Viber проводит ручную проверку
4. После одобрения — синяя галочка рядом с названием

### Стоимость

| Компонент | Цена |
|-----------|------|
| Минимальный месячный платеж (ОАЭ, СНГ) | 150 EUR/мес за Sender ID |
| Минимальный платеж (другие регионы) | 100 EUR/мес |
| Цена за сообщение (Европа) | от 0.0025 EUR |
| Сессионное сообщение | 0.0037-0.0229 EUR |
| Оплата | Только за доставленные |

Первый календарный месяц — без минимального платежа.

### Формат Rich Business Messages

- Текст до 1000 символов
- Изображение (до 500 KB, рекомендуется)
- До 3 кнопок (URL, reply, call)
- Карусель из карточек
- Видео-превью

### Официальные партнеры (CPaaS)

| Партнер | Уровень | Особенности |
|---------|---------|-------------|
| Infobip | Platinum | Полная интеграция, API, аналитика |
| Vonage (Nexmo) | Gold | API, простая интеграция |
| MessageBird | Gold | Omnichannel |
| Sinch | Gold | SMS fallback |
| GMS | Gold | Фокус на СНГ |
| Messaggio | — | Бюджетный, фокус на СНГ |

## 5. Viber for Business — бизнес-аккаунты

### Типы бизнес-присутствия

1. **Viber Business Account** — верифицированный аккаунт для сообщений (через CPaaS-партнера)
2. **Community** — бесплатное сообщество бренда
3. **Channel** — бесплатный канал бренда
4. **Viber Chatbot** — автоматизированный бот (см. viber-bot-справочник)

### Viber Business Calls

Бесплатные звонки клиентам через Viber (аналог callback):
- Клиент нажимает кнопку в бизнес-сообщении
- Звонок через Viber (бесплатно для обеих сторон)
- Интеграция с call-центром
- E2E шифрование (с 2025)

### Что выбрать для туризма

| Задача | Инструмент |
|--------|-----------|
| Массовые рассылки акций | Business Messages (Promotional) |
| Подтверждение бронирований | Business Messages (Transactional) |
| Клиентское сообщество | Community |
| Новостной канал | Channel |
| Автоматические ответы | Chatbot (см. viber-bot-справочник) |
| Звонки клиентам | Business Calls |

## 6. Viber Ads — рекламная платформа

### Модель оплаты

CPM (Cost Per Mille) — оплата за 1000 показов. Цена зависит от страны показа.

### Рекламные форматы

| Формат | Описание | Где показывается |
|--------|----------|-----------------|
| Banner Ads | Статичный/анимированный баннер | Чаты, Explore, More |
| Post-Call Ads | После завершения звонка | Экран после звонка |
| Desktop Ads | Баннеры для десктопа | Viber Desktop |
| Video Ads | Видеоролики (только десктоп) | Viber Desktop |
| Promoted Stickers | Брендированные стикерпаки | Sticker Market |
| Native Ads | Нативные размещения | Viber Explore |

### Таргетинг

- **Демография:** пол, возраст
- **География:** страна, регион
- **Интересы:** категории контента
- **Устройство:** iOS / Android / Desktop
- **Международные звонки:** пользователи, звонящие из страны A в страну B (+25% к CPM)

Таргетинг на международные звонки особенно ценен для туризма: можно показать рекламу пользователям из Беларуси/Украины, которые звонят в ОАЭ.

### Ориентировочная стоимость

| Регион | CPM (за 1000 показов) |
|--------|-----------------------|
| Россия | ~3 EUR |
| Украина | ~1.5-2 EUR |
| Беларусь | ~2-3 EUR |
| Грузия | ~1-2 EUR |
| ОАЭ | ~5-8 EUR |

Точные цены — через рекламный кабинет Viber или агентства-партнеры.

### Как запустить рекламу

1. Обратиться в Viber Ads через forbusiness.viber.com
2. Или через рекламное агентство-партнера
3. Минимальный бюджет и условия — по запросу
4. Креативы: статика, анимация, видео

## 7. Медиа и контент

### Лимиты файлов

| Тип контента | Лимит |
|-------------|-------|
| Любой файл | 200 MB |
| Видео (из галереи) | 200 MB, до 10 мин |
| Видео (запись в приложении) | 20 сек |
| Изображение (Business Messages) | до 500 KB рекомендуемо |
| Стикер | 490x490 px |
| Поддерживаемые форматы | PDF, MP4, JPEG, PNG, GIF, ZIP, DOC и др. |

### Особенности медиа в Viber

- **Автосжатие изображений** — Viber сжимает фото при отправке (можно отправить как файл для сохранения качества)
- **GIF** — встроенная библиотека GIF (интеграция с GIPHY)
- **Стикеры** — собственный Sticker Market с тысячами паков
- **Голосовые сообщения** — без ограничения длительности
- **Местоположение** — отправка геолокации в чате
- **Контакты** — пересылка контактной карточки

### Форматирование текста

В обычных чатах Viber **не поддерживает** markdown-разметку (жирный, курсив). Форматирование доступно только в Business Messages через Rich Media шаблоны.

## 8. Sticker Market

### Обзор

Viber Sticker Market — встроенный магазин стикеров. Стикеры — один из ключевых элементов UX Viber и важный инструмент монетизации платформы.

### Создание собственного стикерпака

1. Открыть Sticker Market → "Создать"
2. Загрузить изображения (490x490 px, PNG с прозрачностью)
3. Каждый пак — до 24 стикеров
4. Выбрать видимость: приватный или публичный
5. Публичные паки доступны всем через ссылку или в каталоге

### Брендированные стикеры (Promoted Stickers)

Один из рекламных форматов Viber для бизнеса:
- Компания создает стикерпак со своим брендом
- Пак размещается в Sticker Market как бесплатный
- Пользователи скачивают и используют стикеры
- Бренд получает органическое распространение

Для туризма: стикерпак с достопримечательностями ОАЭ (Burj Khalifa, пустыня, яхты) — эффективный инструмент бренд-осведомленности.

### Монетизация стикеров

Viber продает премиум-стикерпаки (от $0.99 до $1.99). Создатели контента могут сотрудничать с Viber для размещения платных паков, но программа открыта не для всех — требуется договоренность с платформой.

## 9. Viber Lenses (AR-линзы)

### Что это

AR-линзы в Viber, реализованные в партнерстве со Snap Inc. (Snapchat). Запущены в 2021 году. Позволяют применять AR-эффекты к лицу во время видеозвонков и при создании фото/видео.

### Возможности

- **AR-маски** — маски животных, персонажей
- **Фильтры** — цветокоррекция, стилизация
- **Beautification** — ретушь, помада, румяна, цвет волос
- **Bitmoji** — интеграция с персонализированными Bitmoji-аватарами
- **Брендированные линзы** — создание компанией собственных AR-линз

### Для бизнеса

Компании могут создать спонсорские/брендированные линзы:
- Заказ через Viber for Business
- Линза появляется в каталоге для всех пользователей
- Дополнительный формат рекламного взаимодействия
- Пример: AR-линза "Примерь дубайский образ" для продвижения туров

## 11. Приватность и безопасность

### End-to-End шифрование

Viber был одним из первых мессенджеров, внедривших E2E шифрование по умолчанию (с 2016):
- Все 1-на-1 чаты — зашифрованы
- Групповые чаты — зашифрованы (с 2018)
- Бизнес-чаты — зашифрованы (с 2025)
- Протокол: на базе Signal Double Ratchet (собственная реализация)
- Ключи хранятся только на устройствах
- Сообщения не хранятся на серверах после доставки

### Секретные чаты (Secret Chats)

- Таймер самоуничтожения: 10 сек, 1 мин, 1 час, 1 день
- Уведомление о скриншоте
- Не отображаются в общем списке чатов

### Скрытые чаты (Hidden Chats)

- Доступ только по PIN-коду
- Не видны в основном списке
- Для конфиденциальных переписок

### Исчезающие сообщения (Disappearing Messages)

- Можно включить для любого чата
- Таймеры: 10 сек, 1 мин, 1 час, 1 день
- Уведомление о скриншоте
- После истечения таймера — удаляются без следа

### Дополнительные настройки приватности

- Контроль статуса "онлайн"
- Управление статусом доставки/прочтения
- Блокировка контактов
- Запрет на добавление в группы

## 12. Интеграция с CRM

### Через CPaaS-партнеров

Viber Business Messages интегрируется с CRM-системами через API партнеров:

| Платформа | Интеграция | Особенности |
|-----------|-----------|-------------|
| Infobip | API + Web UI | Moments, Conversations, People CDP |
| Salesforce | Через Infobip/Vonage | Marketing Cloud |
| HubSpot | Через партнеров | Workflows, контакты |
| Bitrix24 | Нативная | Открытые линии |
| amoCRM | Через виджеты | Сделки, воронки |
| Notion | Нет прямой | Через Zapier/Make |

### Сценарии интеграции

1. **Подтверждение бронирования** — CRM триггер → Viber Business Message клиенту
2. **Напоминание о туре** — автоматическое за 24ч до экскурсии
3. **Сбор отзывов** — после завершения тура → сообщение с кнопкой
4. **Промо-рассылки** — сегментация в CRM → персонализированные сообщения

### Webhook и API

Для получения входящих сообщений от клиентов используется Webhook. API позволяет:
- Отправлять сообщения по номеру телефона
- Получать уведомления о доставке/прочтении
- Управлять подписчиками
- Отправлять Rich Media (изображения, кнопки, карусели)

## 13. Примеры для туристического бизнеса ОАЭ

### Стратегия присутствия в Viber

Для туристического бизнеса в Дубае с аудиторией из СНГ рекомендуется многоуровневое присутствие:

#### Уровень 1: Community (бесплатно)

**"Дубай для туристов из СНГ"** — сообщество:
- Полезная информация о Дубае
- Ответы на вопросы
- Клиенты общаются между собой
- Фото/видео с экскурсий
- Отзывы от реальных клиентов

Преимущества: бесплатно, органический рост, доверие через сообщество.

#### Уровень 2: Channel (бесплатно)

**"Экскурсии Дубай | Спецпредложения"** — канал:
- Еженедельные акции
- Новые экскурсии/маршруты
- Фото/видео контент
- Цены ниже чем на сайтах

Преимущества: broadcast без обсуждений, чистая подача информации.

#### Уровень 3: Business Messages (платно)

Верифицированный аккаунт для:
- Подтверждение бронирований
- Напоминания о турах
- Промо-рассылки по базе клиентов
- Персонализированные предложения

#### Уровень 4: Ads (платно)

Рекламные кампании с таргетингом:
- Аудитория: Беларусь, Украина, Грузия, Молдова
- Интересы: путешествия
- Международные звонки: пользователи, звонящие в ОАЭ
- Формат: баннеры с акциями на экскурсии

### Контент-план для канала/сообщества

| День | Контент |
|------|---------|
| Пн | Акция недели (экскурсия со скидкой) |
| Ср | Полезная информация (виза, погода, лайфхаки) |
| Пт | Фото/видео с экскурсии |
| Вс | Отзыв клиента + спецпредложение |

## 14. Лимиты и ограничения

### Общие лимиты

| Параметр | Лимит |
|----------|-------|
| Участники группы | 250 |
| Участники Community/Channel | 1 млрд |
| Размер файла | 200 MB |
| Видео (из галереи) | 200 MB / 10 мин |
| Видео (запись) | 20 сек |
| Стикеров в паке | 24 |
| Размер стикера | 490x490 px |
| Символов в названии группы | 250 |
| Изображение в Business Message | до 500 KB |
| Текст в Business Message | 1000 символов |
| Кнопок в Business Message | до 3 |

### Ограничения Business Messages

- Минимальный месячный платеж (ОАЭ, СНГ): 150 EUR
- Нужен CPaaS-партнер (нельзя подключиться напрямую)
- Промо-сообщения: требуется opt-in от пользователя
- Транзакционные: можно без opt-in, но только для уведомлений

### Ограничения по странам

- Viber Pay: только 7 стран Европы (не ОАЭ, не СНГ)
- Viber Ads: доступны для таргетинга на большинство стран
- Некоторые функции могут быть недоступны в отдельных регионах

### Политика 2025

- Business-чаты получили E2E шифрование
- Упрощена терминология Communities и Channels
- Обновлены условия использования
