# Viber — Cheatsheet (Шпаргалка)

## Быстрые факты

| Факт | Значение |
|------|----------|
| Владелец | Rakuten Group (Япония) |
| Пользователи | 1.2+ млрд зарег., ~260 млн MAU |
| E2E шифрование | По умолчанию (Signal Double Ratchet) |
| Макс. участников Community | 1 млрд |
| Макс. участников группы | 250 |
| Макс. размер файла | 200 MB |
| Макс. видео | 200 MB / 10 мин |
| Макс. стикеров в паке | 24 шт (490x490 px) |
| Бизнес-сообщение текст | до 1000 символов |
| Кнопок в бизнес-сообщении | до 3 |
| Форматирование текста | Нет (только в Business Messages Rich Media) |

## Продукты платформы

| Продукт | Бесплатно | Для бизнеса |
|---------|-----------|-------------|
| Чаты (1-на-1, группы) | Да | — |
| Communities | Да | Создание бренд-сообщества |
| Channels | Да | Broadcast новостей/акций |
| Business Messages | Нет (от 150 EUR/мес) | Верифицированные рассылки |
| Viber Ads | Нет (CPM) | Баннеры, post-call, стикеры |
| Viber Bot | Бесплатно (API) | Автоматизация |
| Viber Pay | Да (только 7 стран EU) | НЕ доступен ОАЭ/СНГ |
| Viber Lenses | Да | Брендированные AR-линзы |

## Business Messages — типы

| Тип | Opt-in | Стоимость | Применение |
|-----|--------|-----------|-----------|
| Transactional | Нет | Дешевле | Подтверждения, уведомления |
| Promotional | Да | Дороже | Акции, маркетинг |
| Session | Нет (инициирован клиентом) | Средняя | Диалог (24ч окно) |

## Viber Ads — форматы

|--------|-----|--------|

## Стратегия для туризма ОАЭ

### Уровень 1 (бесплатно)
- Community: "Дубай для туристов из СНГ"
- Channel: "Экскурсии Дубай | Спецпредложения"

### Уровень 2 (платно, от 150 EUR/мес)
- Business Messages: подтверждения, напоминания, промо

### Уровень 3 (рекламный бюджет)
- Viber Ads: таргетинг на Беларусь/Украину/Грузию

### Приоритет стран для таргетинга
1. Беларусь (90% на Viber — must have)
2. Украина (70%+ — основной рынок)
3. Грузия, Молдова (высокое проникновение)
4. Россия (70%+, но WhatsApp/Telegram сильнее)
