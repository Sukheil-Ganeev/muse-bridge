## Quick Start

### Шаг 1: Выбрать платформу

**Если у вас есть:**
- VK сообщество (1000+ подписчиков) → `references/vk-adblogger.md`
- Telegram канал (1000+ подписчиков) → `references/telegram-ads.md`
- Дзен блог (7000+ просмотров/неделю) → `references/yandex-dzen-partner.md`
- Rutube канал (1000+ подписчиков) → `references/rutube-partner.md`
- Любой контент → `references/affiliate-tourism.md` (без требований)

### Шаг 2: Прочитать детальное руководство

Открыть соответствующий файл в `references/` и следовать инструкциям.

### Шаг 3: Оформить самозанятость

**До первого дохода:**
1. Скачать приложение "Мой налог"
2. Регистрация через госуслуги (5 минут)
3. Готово - можно зарабатывать легально

**Детали:** `references/tax-legal.md`

### Шаг 4: Начать монетизацию

Использовать шаблоны из `assets/templates/` для создания рекламного контента.

### Шаг 5: Отслеживать результаты

- Использовать `scripts/calculate-earnings.py` для прогнозирования дохода
- Использовать `scripts/track-affiliate-clicks.js` для tracking affiliate ссылок
- Анализировать в Google Analytics (инструкции в `references/analytics-optimization.md`)
