# Критические уроки партнёрских программ (топ-5)

Эти уроки помогут избежать распространённых ошибок при работе с партнёрскими программами.

---

## 1. Disclosure обязателен (2026)

**Урок:** Всегда указывайте #реклама или #партнёрство в каждом монетизированном посте.

**Почему критично:**
- Закон "О рекламе" РФ требует обязательной маркировки
- VK/Telegram могут заблокировать канал за скрытую рекламу
- Штраф для блогеров: до 100,000₽
- Штраф для юрлиц: до 500,000₽

**Что делать:**
- Добавлять #реклама или #партнёрство в КАЖДЫЙ рекламный пост
- Даже если это affiliate ссылка (тоже реклама!)
- Даже если платформа автоматически добавляет метку (добавьте свою тоже)

**Пример:**
```
❌ Плохо:
"Забронируйте отель здесь: [ссылка]"

✅ Хорошо:
"Забронируйте отель здесь: [ссылка]

#реклама #партнёрство"
```

**Исключение:**
TON Ads в Telegram автоматически добавляет метку "Sponsored" - дополнительная не нужна.

## 2. Не спамить рекламой

**Урок:** Максимум 20-30% контента = реклама. Остальное = полезный контент.

**Почему критично:**
- Подписчики массово отписываются от спам-каналов
- Падает engagement rate → падают ставки за рекламу
- Алгоритмы платформ понижают охват спам-каналов

**Что делать:**
- Баланс: 70% полезный контент / 30% реклама (максимум!)
- Лучше: 80% полезный / 20% реклама
- Между рекламными постами минимум 2-3 обычных поста

**Пример:**
```
❌ Плохо:
Пн: Реклама
Вт: Реклама
Ср: Реклама
Чт: Реклама
Пт: Реклама

(Подписчики отпишутся)

✅ Хорошо:
Пн: Полезный пост
Вт: Полезный пост
Ср: Реклама
Чт: Полезный пост
Пт: Полезный пост
Сб: Полезный пост
Вс: Реклама
```

## 3. Релевантность важнее денег

**Урок:** Рекламируйте только то, что релевантно вашей аудитории и что вы сами пробовали.

**Почему критично:**
- Нерелевантная реклама = потеря доверия аудитории
- Потеря доверия = отписки + низкая конверсия
- Низкая конверсия = меньше affiliate дохода

**Что делать:**
- Туристический блог → туристические продукты (отели, туры, билеты)
- НЕ рекламировать: крипто, финансовые пирамиды, сомнительные продукты
- Лучше отказаться от высокооплачиваемого заказа, если он не релевантен

**Пример:**
```
❌ Плохо:
Канал "Дубай туризм" → реклама крипто-кошелька

(Аудитория не заинтересована, потеря доверия)

✅ Хорошо:
Канал "Дубай туризм" → реклама отелей, туров, билетов

(Высокая конверсия, доверие аудитории)
```

**Золотое правило:**
Если сами не пользуетесь продуктом - не рекламируйте.

## 4. Диверсификация доходов

**Урок:** Не зависеть от одной платформы. Диверсифицировать источники дохода.

**Почему критично:**
- Платформы могут изменить условия (снизить ставки, повысить требования)
- Платформы могут заблокировать аккаунт (алгоритмы, ошибки модерации)
- Одна платформа падёт = потеря всего дохода

**Что делать:**
- Минимум 3 источника дохода:
  1. Платформенная монетизация (VK AdBlogger, Telegram Ads)
  2. Affiliate программы (Booking, Aviasales)
  3. Собственные продукты (курсы, консультации)
- Не больше 50% дохода от одного источника

**Пример:**
```
❌ Плохо:
100% дохода = VK AdBlogger

(VK заблокирует аккаунт → 0 дохода)

✅ Хорошо:
40% = Telegram Ads
30% = Affiliate (Booking, Aviasales)
20% = Собственный курс
10% = VK AdBlogger

(Одна платформа упадёт → 60-90% дохода останется)
```

**Золотое правило:**
Если зарабатываете больше 50% от одного источника - диверсифицируйте!

## 5. Налоги с первого рубля

**Урок:** Оформить самозанятость/ИП ДО первого дохода. Платить налоги с первого рубля.

**Почему критично:**
- Штраф за незадекларированный доход: до 40% от суммы
- Блокировка банковских карт при крупных поступлениях
- Налоговая проверит все поступления за последние 3 года

**Что делать:**
- Зарегистрировать самозанятость в день запуска монетизации
- После каждого дохода формировать чек в приложении "Мой налог"
- Налог 6% списывается автоматически (до 12 числа следующего месяца)

**Пример:**
```
❌ Плохо:
Январь: заработали 50,000₽, не заплатили налог
Февраль: заработали 80,000₽, не заплатили налог
Март: налоговая проверка → штраф 52,000₽ (40%)

✅ Хорошо:
Январь: заработали 50,000₽, заплатили налог 3,000₽ (6%)
Февраль: заработали 80,000₽, заплатили налог 4,800₽ (6%)
Март: всё легально, никаких проблем
```

**Как оформить:**
1. Скачать приложение "Мой налог" (iOS/Android)
2. Регистрация через госуслуги (5 минут)
3. После каждого дохода → Новый чек → Указать сумму
4. Налог списывается автоматически

**Важно:**
Даже если доход 1000₽/месяц - всё равно платите налог!

## Бонус: Урок 6 - UTM метки для tracking

**Урок:** Добавляйте UTM метки ко всем affiliate ссылкам для отслеживания эффективности.

**Почему важно:**
- Без tracking не знаете, какие посты/каналы приносят доход
- Не можете оптимизировать стратегию

**Что делать:**
```
https://booking.com/hotel.html?
  aid=12345&
  utm_source=telegram&
  utm_medium=post&
  utm_campaign=dubai_march&
  utm_content=atlantis_review
```

**Анализировать в:**
- Google Analytics
- Яндекс.Метрика
- Notion/Airtable (ручной tracking)

## Как использовать этот файл

1. **При активации скилла:** Прочитать все 5 критических уроков
2. **Перед размещением рекламы:** Проверить чек-лист:
   - ✅ Добавлена метка #реклама
   - ✅ Не больше 30% рекламы
   - ✅ Реклама релевантна аудитории
   - ✅ Не зависим от одной платформы
   - ✅ Самозанятость оформлена
   - ✅ UTM метки добавлены (для affiliate)

3. **После ошибки:** Записать урок в `experience/fixes/` или `experience/warnings/`
