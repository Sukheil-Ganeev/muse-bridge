## 1. Tracking партнёрских ссылок

### UTM метки

**Что это:**
Дополнительные параметры в URL для отслеживания источников трафика.

**Формат:**
```
https://booking.com/hotel.html?
  aid=12345&
  utm_source=telegram&
  utm_medium=post&
  utm_campaign=dubai_march&
  utm_content=atlantis_review
```

**Параметры:**
- `utm_source`: откуда (telegram, vk, dzen, rutube)
- `utm_medium`: тип контента (post, story, video, article)
- `utm_campaign`: кампания (dubai_march, desert_safari)
- `utm_content`: конкретный контент (atlantis_review, burj_khalifa)

**Генератор UTM:**
```
https://ga-dev-tools.google/campaign-url-builder/
```

### Короткие ссылки

**Зачем:**
- Красивые ссылки (вместо длинных)
- Отслеживание кликов
- Можно менять destination URL

**Сервисы:**
- Bitly: [bitly.com](https://bitly.com)
- Clck.ru: [clck.ru](https://clck.ru) (российский)
- Rebrandly: [rebrandly.com](https://rebrandly.com) (кастомные домены)

**Пример:**
```
Было: https://booking.com/hotel/atlantis-the-palm.html?aid=12345&utm_source=telegram
Стало: https://bit.ly/dubai-atlantis

Tracking:
- Сколько кликов
- Откуда кликнули (страна, устройство)
- Когда кликнули
```

## 2. Google Analytics 4

### Настройка

**Шаг 1: Создать аккаунт GA4**
1. Перейти на [analytics.google.com](https://analytics.google.com)
2. Создать свойство (Property)
3. Получить Measurement ID (G-XXXXXXXXXX)

**Шаг 2: Добавить код на сайт**
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

**Шаг 3: Настроить события (Events)**

**Событие: Клик по партнёрской ссылке**
```javascript
// При клике на партнёрскую ссылку
document.querySelectorAll('a[data-affiliate]').forEach(link => {
  link.addEventListener('click', function() {
    gtag('event', 'affiliate_click', {
      'affiliate_name': this.dataset.affiliate,
      'link_url': this.href,
      'content_type': this.dataset.contentType
    });
  });
});
```

## 4. Конверсия: клик → продажа

### Формула конверсии

```
Конверсия = (Продажи / Клики) × 100%

Пример:
Клики по ссылке Booking: 1000
Продажи (бронирования): 30

Конверсия = (30 / 1000) × 100% = 3%
```

### Средние конверсии (2026)

| Ниша | Средняя конверсия |
|------|-------------------|
| Отели (Booking) | 2-5% |
| Туры (GetYourGuide) | 3-6% |
| Авиабилеты (Aviasales) | 1-3% |
| Курсы (инфопродукты) | 1-2% |

### Как улучшить конверсию

**1. Релевантность:**
```
❌ Статья про еду в Дубае → ссылка на отели
✅ Статья про отели в Дубае → ссылка на отели

Результат: конверсия +50-100%
```

**2. Качество трафика:**
```
❌ Случайный трафик из поиска
✅ Целевая аудитория (подписчики, которые доверяют)

Результат: конверсия +100-200%
```

**3. CTA (Call-to-Action):**
```
❌ "Ссылка: https://..."
✅ "Забронировать со скидкой 20% (только сегодня!)"

Результат: конверсия +30-50%
```

**4. Срочность:**
```
❌ "Посмотрите отели здесь"
✅ "Акция заканчивается через 24 часа!"

Результат: конверсия +20-40%
```

## 5. ROI (Return on Investment)

### Формула ROI

```
ROI = (Прибыль - Затраты) / Затраты × 100%

Пример:
Затраты:
- Создание статьи: 3,000₽
- Продвижение VK реклама: 5,000₽
ИТОГО: 8,000₽

Прибыль:
- Affiliate комиссии: 25,000₽

ROI = (25,000₽ - 8,000₽) / 8,000₽ × 100% = 212.5%
```

**Что это значит:**
С каждого вложенного рубля получили 3.12₽ (включая вложенный рубль).

### Расчёт для разных каналов

**VK:**
```
Затраты: пост 2,000₽ (время) + реклама 3,000₽ = 5,000₽
Доход: affiliate 15,000₽

ROI = (15,000₽ - 5,000₽) / 5,000₽ × 100% = 200%
```

**Telegram:**
```
Затраты: пост 1,000₽ (время, бесплатно публиковать)
Доход: affiliate 8,000₽

ROI = (8,000₽ - 1,000₽) / 1,000₽ × 100% = 700%
```

**Дзен:**
```
Затраты: статья 5,000₽ (время + дизайн)
Доход: реклама 10,000₽ + affiliate 12,000₽ = 22,000₽

ROI = (22,000₽ - 5,000₽) / 5,000₽ × 100% = 340%
```

## 6. A/B тестирование

### Что тестировать

**Заголовки:**
```
Вариант A: "10 лучших отелей в Дубае"
Вариант B: "10 отелей в Дубае, которые вы ещё не знаете"

Метрика: CTR (клики / показы)
```

**CTA (призыв к действию):**
```
Вариант A: "Забронировать"
Вариант B: "Забронировать со скидкой 20%"

Метрика: Конверсия (клики / просмотры)
```

**Размещение ссылок:**
```
Вариант A: В конце статьи
Вариант B: В середине статьи (после 2-го абзаца)

Метрика: Клики по ссылке
```

### Как проводить A/B тест

**Шаг 1: Гипотеза**
```
"Если добавить срочность в CTA ('Акция до завтра!'),
то конверсия увеличится на 20%"
```

**Шаг 2: Создать 2 варианта**
- Вариант A (контроль): без срочности
- Вариант B (тест): со срочностью

**Шаг 3: Запустить тест**
- 50% аудитории видят A
- 50% аудитории видят B
- Минимум 1000 просмотров на вариант

**Шаг 4: Анализ**
```
Вариант A:
Просмотры: 1000
Клики: 30
Конверсия: 3%

Вариант B:
Просмотры: 1000
Клики: 42
Конверсия: 4.2%

Результат: B выигрывает (+40% к конверсии)
```

## 7. Best Performing платформы

### По туристической нише (2026)

**Топ-3 по ROI:**

1. **Telegram (700% ROI)**
   - Низкие затраты (бесплатные посты)
   - Высокое доверие аудитории
   - Хорошая конверсия (4-6%)

2. **Дзен (340% ROI)**
   - Долгосрочный трафик (SEO)
   - Двойной доход (реклама + affiliate)
   - Средняя конверсия (3-4%)

3. **VK (200% ROI)**
   - Большой охват
   - Средние затраты
   - Средняя конверсия (2-3%)

### По типу контента

**Топ-3 форматы:**

1. **Глубокие гайды (2000+ слов)**
   - Высокая дочитываемость (60-70%)
   - Много места для affiliate ссылок
   - Долгосрочный трафик из поиска

2. **Видео-обзоры (10-15 минут)**
   - Высокое вовлечение
   - Можно показать продукт
   - Хорошая конверсия (4-5%)

3. **Сравнения (A vs B)**
   - Помогают принять решение
   - Естественно вставить 2 affiliate ссылки
   - Высокая конверсия (5-7%)

## 8. Кейс: 100K подписчиков → 50-150K₽/месяц

### Исходные данные

**Канал:**
- Платформа: Telegram
- Подписчики: 100,000
- Тематика: Туризм ОАЭ
- Частота постов: 1 пост/день

### Стратегия

**Монетизация:**
1. Telegram Ads (CPM 400₽)
2. Booking Affiliate
3. GetYourGuide Affiliate
4. Собственный курс (19,990₽)

### Расчёт дохода

**1. Telegram Ads:**
```
Охват поста: 60,000 (60% от подписчиков)
Рекламный охват: 36,000 (60% от обычного)
CPM: 400₽

Доход за 1 рекламу:
(36,000 / 1000) × 400₽ = 14,400₽

Реклама: 1 раз/3 дня = 10 реклам/месяц

Доход: 10 × 14,400₽ = 144,000₽/месяц
```

**2. Booking Affiliate:**
```
Посты с отелями: 4/месяц
Клики: 100/пост = 400 кликов
Конверсия: 4% = 16 бронирований
Средняя комиссия: 1,000₽

Доход: 16 × 1,000₽ = 16,000₽/месяц
```

**3. GetYourGuide Affiliate:**
```
Посты с турами: 4/месяц
Клики: 80/пост = 320 кликов
Конверсия: 5% = 16 покупок
Средняя комиссия: 400₽

Доход: 16 × 400₽ = 6,400₽/месяц
```

**4. Собственный курс:**
```
Анонс курса: 1 раз/месяц
Охват: 60,000
Конверсия: 0.5% = 300 человек интересуются
Из них покупают: 10% = 30 покупок
Цена: 19,990₽

Доход: 30 × 19,990₽ = 599,700₽/месяц
(но это не каждый месяц, а 1-2 раза в год)

Среднемесячный: 599,700₽ / 6 = 99,950₽/месяц
```

### Итого

```
Telegram Ads: 144,000₽
Booking: 16,000₽
GetYourGuide: 6,400₽
Курс: 99,950₽ (среднемесячно)

ИТОГО: 266,350₽/месяц

Налоги (6% самозанятость): 15,981₽
Чистыми: 250,369₽/месяц
```

**Вывод:** 100K подписчиков = 250K₽/месяц пассивного дохода
