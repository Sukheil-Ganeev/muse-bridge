# Affiliate Tourism: Полное руководство

Партнёрские программы для монетизации туристического контента.

---

## Что такое Affiliate Marketing

Affiliate (партнёрский маркетинг) - это модель, где вы получаете комиссию за каждого клиента, которого привели на сервис через свою реферальную ссылку.

**Как это работает:**
1. Вы регистрируетесь в партнёрской программе (например, Booking.com)
2. Получаете уникальную партнёрскую ссылку
3. Размещаете ссылку в контенте (статья, пост, видео)
4. Когда кто-то кликает и покупает → вы получаете комиссию

## 6 основных партнёрских программ (туризм)

### 1. Booking.com Partner Program

**Что это:**
Крупнейшая платформа бронирования отелей в мире.

**Регистрация:**
[partners.booking.com](https://partners.booking.com)

**Комиссия:**
- 25% от комиссии Booking
- Реально: ~4-5% от стоимости бронирования

**Cookie:**
- 30 дней (если кликнули по ссылке, у них есть 30 дней на бронирование)

**Средний чек:**
- Отель в Дубае: 10,000-30,000₽ за ночь
- Комиссия: 400-1,500₽ за бронирование

**Как продвигать:**
- Статьи "Топ отелей в Дубае"
- Обзоры конкретных отелей
- Посты с рекомендациями
- Видео-туры по отелям

**Пример:**
```
Статья: "10 лучших отелов в Дубае с видом на море"

Каждый отель = ссылка Booking.com
10 бронирований/месяц × 800₽ комиссия = 8,000₽/месяц
```

**Преимущества:**
- Высокий бренд (доверие аудитории)
- Большой выбор отелей
- Хороший интерфейс партнёрской программы

**Недостатки:**
- Комиссия ниже, чем у некоторых конкурентов
- Отслеживание конверсий иногда глючит

## Интеграция партнёрских ссылок

### 1. Прямые ссылки (Basic)

**Как выглядит:**
```
https://booking.com/hotel/atlantis-the-palm.html?aid=12345
```

**Как получить:**
- Зайти в партнёрскую программу
- Найти нужный отель/тур
- Скопировать ссылку с вашим `aid` (affiliate ID)

**Где размещать:**
- В тексте статьи
- В описании видео
- В постах соцсетей

### 2. Deeplinks (продвинутые ссылки)

**Что это:**
Ссылка на конкретный отель/тур с параметрами (даты, город).

**Пример:**
```
https://booking.com/searchresults.html?
  aid=12345&
  ss=Dubai&
  checkin=2026-03-15&
  checkout=2026-03-20&
  group_adults=2
```

**Преимущества:**
- Более персонализированные
- Выше конверсия

### 3. API интеграция (для продвинутых)

**Что это:**
Автоматическое получение данных через API и создание ссылок.

**Пример (Booking API):**
```javascript
const bookingAPI = require('booking-api');

async function getHotels(city) {
  const hotels = await bookingAPI.search({
    city: city,
    checkin: '2026-03-15',
    checkout: '2026-03-20',
    adults: 2
  });

  // Добавить affiliate ID к каждому отелю
  hotels.forEach(hotel => {
    hotel.url += '?aid=YOUR_AFFILIATE_ID';
  });

  return hotels;
}
```

### 4. Виджеты

**Что это:**
Встраиваемые блоки (iframe) на сайт с формой поиска.

**Пример (Hotellook виджет):**
```html
<iframe
  src="https://search.hotellook.com/?
    marker=YOUR_MARKER&
    trs=250334&
    destination=Dubai"
  width="100%"
  height="400px">
</iframe>
```

**Преимущества:**
- Красиво выглядит
- Высокая конверсия
- Не нужно создавать ссылки вручную

## Tracking и аналитика

### 1. UTM метки

**Что это:**
Дополнительные параметры в ссылке для отслеживания источника.

**Формат:**
```
https://booking.com/hotel.html?
  aid=12345&
  utm_source=telegram&
  utm_medium=post&
  utm_campaign=dubai_hotels_march
```

**Параметры:**
- `utm_source`: откуда (telegram, vk, dzen)
- `utm_medium`: тип (post, story, video)
- `utm_campaign`: кампания (dubai_hotels_march)

**Как отслеживать:**
- Google Analytics
- Яндекс.Метрика
- Собственная таблица (Notion, Airtable)

### 2. Google Analytics

**Настройка:**
1. Создать аккаунт GA4
2. Добавить код на сайт/landing
3. Настроить события (клики по affiliate ссылкам)

**Что отслеживать:**
- Клики по партнёрским ссылкам
- Источники трафика (откуда пришли)
- Конверсия (клик → продажа)

**Пример отчёта:**
```
Источник: Telegram
Клики: 500
Конверсия: 3% (15 продаж)
Средняя комиссия: 800₽
Доход: 15 × 800₽ = 12,000₽
```

### 3. Расчёт ROI

**ROI (Return on Investment) - окупаемость инвестиций:**

**Формула:**
```
ROI = (Прибыль - Затраты) / Затраты × 100%
```

**Пример:**
```
Затраты:
- Создание контента: 5,000₽
- Реклама поста: 2,000₽
ИТОГО: 7,000₽

Прибыль:
- Affiliate комиссии: 15,000₽

ROI = (15,000₽ - 7,000₽) / 7,000₽ × 100% = 114%
```

**Вывод:** Контент окупился на 114% (с каждого вложенного рубля получили 2.14₽)

**Где размещать:**
- Дзен (статьи)
- VK (посты + статьи)
- Telegram (посты + статьи)
- Rutube (видео)

**Партнёрские ссылки:**
- В тексте статьи (естественно)
- В описании видео
- В кнопках CTA ("Забронировать со скидкой")

### 2. Обзоры и сравнения

**Форматы:**
- Обзор конкретного отеля/тура
- Сравнение (Отель A vs Отель B)
- "Топ-10" подборки

```

- Atlantis (Booking): https://...
```

**Как получить промокоды:**

```
Действует до 31 марта!
```

**Преимущества:**
- Стимулирует покупки
- Создаёт ощущение эксклюзивности

## Налоги

### Самозанятость

**Ставка:** 4% с физлиц, 6% с юрлиц

**Важно:**
Affiliate программы (Booking, Aviasales и др.) - это иностранные юрлица.

**Как легализовать:**
1. Оформить самозанятость
2. После каждой выплаты формировать чек
3. Налог списывается автоматически

**Пример:**
```
Январь: affiliate доход 30,000₽
Налог: 30,000₽ × 6% = 1,800₽
Чистыми: 28,200₽
```

## Резюме

**Affiliate туризм - пассивный доход для контент-криейторов:**

**Преимущества:**
- Нет требований к аудитории (можно начать с 0)
- Пассивный доход (ссылки работают годами)
- Диверсификация (несколько программ = стабильность)

**Недостатки:**
- Нужен трафик (без аудитории = без дохода)
- Конверсия низкая (1-5%)
- Зависимость от партнёрских программ (могут изменить условия)

**Потенциальный доход:**
- 1K подписчиков: 1-3K₽/месяц
- 10K подписчиков: 5-15K₽/месяц
- 50K подписчиков: 30-100K₽/месяц
- 100K+ подписчиков: 100-500K₽/месяц

**Следующий шаг:** Зарегистрироваться в 2-3 партнёрских программах и начать тестировать
