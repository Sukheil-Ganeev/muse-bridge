# Инфопродукты: Полное руководство

Создание и продажа собственных цифровых продуктов (курсы, гайды, консультации).

---

## Что такое инфопродукты

Инфопродукты - это цифровые продукты, содержащие ценную информацию или обучение.

**Типы:**
- Онлайн-курсы
- Видео-уроки
- PDF-гайды и чек-листы
- Консультации 1-на-1
- Членство (закрытое сообщество)
- Вебинары и марафоны

---

## Платформы для создания

### 1. GetCourse

**Что это:** Платформа для онлайн-школ (аналог Teachable).

**Функции:**
- Создание курсов (уроки, видео, тесты)
- Приём платежей (карты РФ, ЮMoney)
- Email рассылки
- Вебинары
- CRM для студентов

**Стоимость:** от 2500₽/месяц

**Для туризма ОАЭ:**
- Курс "Переезд в Дубай за 30 дней" (19,990₽)
- Курс "Открытие бизнеса в ОАЭ" (49,990₽)

### 2. iSpring

**Что это:** Платформа для корпоративного обучения.

**Функции:**
- Создание интерактивных курсов
- SCORM совместимость
- Мобильное приложение
- Отчёты и аналитика

**Стоимость:** от 27,000₽/год

### 3. Tilda + Платёжные системы

**Что это:** Конструктор лендингов + интеграция оплаты.

**Функции:**
- Создание лендинга для продажи гайда
- Интеграция Stripe/Telr (приём оплаты)
- Автоматическая доставка (email с PDF)

**Стоимость:**
- Tilda: 750₽/месяц
- Stripe/Telr: комиссия 2.5-3.5%

**Пример:**
```
Landing: "Гайд по переезду в Дубай"
Цена: 2990₽
Stripe оплата → Email с PDF
```

## Создание и продажа

### Шаг 1: Выбрать тему

**Критерии:**
- У вас есть экспертиза
- Есть спрос (люди спрашивают об этом)
- Можете создать уникальную ценность

### Шаг 2: Валидация идеи

**Тест перед созданием:**
1. Опрос аудитории (VK, Telegram)
2. Предпродажа (принять оплату до создания курса)
3. Бесплатный мини-курс (чтобы понять интерес)

### Шаг 3: Создание контента

**Для курса:**
- Структура (модули, уроки)
- Запись видео (камера + микрофон)
- Монтаж (DaVinci Resolve, Premiere Pro)
- Загрузка на GetCourse

**Для гайда:**
- Написать текст (Google Docs)
- Добавить изображения
- Дизайн (Canva, Figma)
- Экспорт в PDF

### Шаг 4: Создание лендинга

**Структура продающего лендинга:**
```
1. Заголовок (результат + для кого)
   "Переезд в Дубай за 30 дней без стресса"

2. Проблема (боли аудитории)
   "Переезд в новую страну - это стресс..."

3. Решение (ваш продукт)
   "Мой курс покажет пошаговый план..."

4. Что внутри (модули, уроки)
   - Модуль 1: ...
   - Модуль 2: ...

5. Для кого (целевая аудитория)
   "Для тех, кто планирует переезд..."

6. Результаты (что получат)
   "После курса вы сможете..."

7. Автор (почему вам доверять)
   "Меня зовут Сухейль, я живу в Дубае 5 лет..."

8. Отзывы (социальное доказательство)
   [Скриншоты отзывов]

9. Цена и оплата
   "19,990₽"
   [Кнопка "Купить"]

10. FAQ
    "Часто задаваемые вопросы"

11. Гарантия возврата
    "30 дней гарантия возврата денег"
```

### Шаг 5: Payment Processing

**Для РФ аудитории:**
- ЮMoney (без комиссии для покупателя)
- Карты РФ (через Tinkoff Acquiring)
- Robokassa (агрегатор платежей)

**Для международной аудитории:**
- Stripe (комиссия 2.9% + 30¢)
- Telr (для ОАЭ, комиссия 2.75%)
- USDT (криптовалюта, для тех кто хочет анонимность)

**Автоматизация доставки:**
```
Оплата → Webhook → Email с PDF
```

## Продвижение инфопродуктов

### 1. Контент-маркетинг

**Стратегия:**
- Публиковать полезный бесплатный контент
- Создавать доверие и экспертизу
- В конце контента - CTA на платный продукт

**Пример:**
```
Статья: "10 ошибок при переезде в Дубай"

В конце:
"Хотите узнать, как избежать ВСЕ ошибки?
Мой курс 'Переезд в Дубай' покажет пошаговый план.
[Узнать подробнее]"
```

### 2. Email рассылка

**Воронка:**
1. Бесплатный лид-магнит (чек-лист PDF)
2. 5-7 писем с пользой
3. Предложение платного продукта

**Пример последовательности:**
```
Письмо 1: Добро пожаловать + чек-лист
Письмо 2: Совет 1 (виза)
Письмо 3: Совет 2 (жильё)
Письмо 4: Совет 3 (работа)
Письмо 5: История успеха
Письмо 6: Предложение курса (скидка 20%)
Письмо 7: Последний шанс (скидка истекает)
```

### 3. Вебинары

**Формат:**
- Бесплатный вебинар (60-90 минут)
- Даёте много пользы
- В конце - предложение платного продукта

**Пример:**
```
Вебинар: "Как переехать в Дубай за 30 дней"

Структура:
- 60 минут: пошаговый план
- 15 минут: Q&A
- 15 минут: презентация платного курса

Конверсия: 5-10% покупают
```

### 4. Партнёрская программа

**Идея:**
Дать другим блогерам комиссию за продажи вашего курса.

**Условия:**
- 30% комиссия партнёру
- Уникальная партнёрская ссылка
- Отслеживание через UTM

**Пример:**
```
Ваш курс: 19,990₽
Комиссия партнёра: 30% = 5,997₽
Вы получаете: 13,993₽

Партнёр продаёт 10 курсов:
- Его доход: 59,970₽
- Ваш доход: 139,930₽
```

## Налоги

### Самозанятость

**Ставка:** 4% с физлиц, 6% с юрлиц

**Важно:**
Платёжные системы (Stripe, Telr) = иностранные юрлица (6%)

**Пример:**
```
Продажа курса: 19,990₽
Налог: 6% = 1,199₽
Чистыми: 18,791₽
```
