# Social Proof в недвижимости

## Типы социального доказательства

### 1. Статистика продаж
```
▫️ "5 из 10 юнитов уже проданы"
▫️ "Bestseller комплекса"
▫️ "90% заполняемость здания"
▫️ "[X] семей уже выбрали этот комплекс"
```

### 2. Отзывы клиентов
```
*ЧТО ГОВОРЯТ ЖИТЕЛИ*
"Переехали год назад — ни разу не пожалели.
Вид потрясающий, управление отличное."
— Анна, владелец 2BR
```

### 3. Экспертные оценки
```
▫️ "Рекомендация нашего аналитика"
▫️ "Выбор редакции [издание]"
▫️ "Топ-10 зданий района по [критерий]"
```

### 4. Медийные упоминания
```
▫️ "Комплекс упоминался в Forbes"
▫️ "Застройщик года по версии [награда]"
```

### 5. Известные резиденты (осторожно!)
```
▫️ "Район, который выбирают [категория]"
▫️ "Адрес успешных людей"
```

## Как собирать отзывы

### После сделки
```
[Имя], поздравляю с покупкой!

Через месяц хотел бы узнать ваши впечатления.
Если всё отлично — буду благодарен за короткий отзыв
для будущих клиентов.

Формат:
- Что понравилось в процессе?
- Что скажете о [объекте]?
- Рекомендуете ли меня?
```

### Структура отзыва
```
"[Ситуация до] → [Процесс работы] → [Результат]"

Пример:
"Искали квартиру 3 месяца безуспешно. [Агент] за неделю
нашёл идеальный вариант. Уже год живём — счастливы!"
— Сергей и Мария, 2BR Downtown
```

## Где использовать

### В объявлении
```
*3BR АПАРТАМЕНТЫ | MARINA*
───────────────
[Характеристики]
───────────────
*ЧТО ГОВОРЯТ*
"Лучший вид в здании!" — текущий арендатор
───────────────
[Цена и контакт]
```

### В follow-up
```
Кстати, вот что говорят жители этого комплекса:
"[Отзыв]"

Хотите познакомиться с кем-то из них перед решением?
```

### В презентации
```
*ПОЧЕМУ ВЫБИРАЮТ [КОМПЛЕКС]*

📊 [X] семей уже здесь
⭐ 4.8/5 рейтинг жителей
💬 "[Короткий отзыв]"
```

## Шаблоны блоков

### Компактный
```
⭐ *ОТЗЫВ:* "Идеальное место для семьи" — Мария К.
```

### Развёрнутый
```
*ПОЧЕМУ НАМ ДОВЕРЯЮТ*
───────────────
"Работа с [агент] — это профессионализм на каждом этапе.
Нашли квартиру мечты за 2 недели. Рекомендую!"
— Алексей, купил 3BR в Dubai Hills

"Продали виллу за месяц по хорошей цене.
Всё чётко, без стресса."
— Олег и Наталья, продавцы
```

## Правила

### DO
- Реальные отзывы реальных людей
- С разрешения клиента
- Конкретика (район, тип, результат)
- Разнообразие (покупатели, продавцы, арендаторы)

### DON'T
- Выдуманные отзывы
- Имена селебрити без разрешения
- Только положительные (подозрительно)
- Слишком длинные
