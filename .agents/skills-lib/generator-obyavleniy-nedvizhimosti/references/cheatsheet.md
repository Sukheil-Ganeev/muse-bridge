
---

## Структура объявления

```
ЗАГОЛОВОК — *[X]BR ТИП | РАЙОН*
ОПИСАНИЕ — _одна строка курсивом_
───────────────
ХАРАКТЕРИСТИКИ
▫️ спальни | ванные | площадь
▫️ этаж | вид
▫️ меблировка
▫️ паркинг
КОМПЛЕКС — название + удобства
───────────────
💰 ЦЕНА — операция + сумма AED
УСЛОВИЯ — чеки/Title Deed
⚠️ ВАЖНО — доступность
КОНТАКТ — имя + телефон
```

---

## Обязательные поля

| Тип | Поля |
|-----|------|
| Все | Тип, район, цена, контакт |
| Апартаменты | + спальни, площадь, этаж |
| Виллы | + BUA, Plot, бассейн |
| Офисы | + тип отделки, парковка |
| Аренда | + чеки, что включено |
| Продажа | + Title Deed |

## Цены

### Конверсия валют
```
1 USD = 3.67 AED

100K AED ≈ $27K
500K AED ≈ $136K
1M AED ≈ $272K
5M AED ≈ $1.36M
10M AED ≈ $2.72M
```

### Формат цен
```
Аренда: 140,000 AED/год
Продажа: 2,450,000 AED
Офис: 150 AED/sq.ft./год
```

---

## Площадь

### Конверсия
```
1 sq.ft. = 0.093 m²
1 m² = 10.76 sq.ft.

500 sq.ft. ≈ 46 m²
1,000 sq.ft. ≈ 93 m²
1,500 sq.ft. ≈ 139 m²
2,000 sq.ft. ≈ 186 m²
5,000 sq.ft. ≈ 465 m²
```

### Типичные размеры
```
Studio: 300-600 sq.ft.
1BR: 600-1,000 sq.ft.
2BR: 1,000-1,600 sq.ft.
3BR: 1,400-2,500 sq.ft.
```

## Типы недвижимости

### Жилая
- **Apartment** — апартаменты
- **Villa** — отдельный дом
- **Townhouse** — сблокированный дом
- **Penthouse** — верхний этаж

### Коммерческая
- **Shell & Core** — голые стены
- **CAT A** — базовая отделка
- **Fitted** — готов к работе

## Чеки (аренда)

```
2 чека = 2 раза в год
4 чека = ежеквартально
```
