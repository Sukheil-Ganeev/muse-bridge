## КАЛЬКУЛЯТОР ROI

### Когда использовать

При запросе расчёта доходности недвижимости (ROI, yield, окупаемость).

### Формулы

**Gross ROI (валовая доходность):**
```
Gross ROI = (Годовая аренда / Цена покупки) x 100
```

**Net ROI (чистая доходность):**
```
Расходы = Service charge + Maintenance + Agency + Vacancy
Net ROI = ((Годовая аренда - Расходы) / Цена покупки) x 100
```

**Типичные расходы:**
- Service charge: 15-25 AED/sq.ft./год
- Maintenance: ~1% от цены/год
- Agency fee: 5% от аренды
- Vacancy: ~5-10% от аренды

### Формат вывода

```
📊 *РАСЧЁТ ROI*
───────────────
*ОБЪЕКТ*
▫️ Тип: [X]BR Апартаменты
▫️ Район: [РАЙОН]
▫️ Площадь: [X,XXX] sq.ft.

*ФИНАНСЫ*
▫️ Цена покупки: [X,XXX,XXX] AED
▫️ Ожидаемая аренда: [XXX,XXX] AED/год
▫️ Service charge: [XX,XXX] AED/год
▫️ Прочие расходы: [XX,XXX] AED/год
───────────────
💰 *Gross ROI: [X.X]%*
💰 *Net ROI: [X.X]%*
💰 *Окупаемость: ~[XX] лет*

_При росте стоимости 5%/год:_
_Total Return: ~[XX]%/год_
```

| Район | Gross ROI | Net ROI | Appreciation |
|-------|-----------|---------|--------------|
| JVC | 8-10% | 6-8% | 5-8% |
| Dubai Marina | 5-7% | 3-5% | 7-10% |
| Downtown | 4-6% | 2-4% | 8-12% |
| Palm Jumeirah | 4-5% | 2-3% | 5-8% |
| Business Bay | 6-8% | 4-6% | 6-9% |
| Dubai Hills | 5-7% | 3-5% | 8-12% |

### Пример расчёта

**Вход:** 2BR в Dubai Marina, цена 2,000,000 AED, площадь 1,200 sq.ft., аренда 120,000 AED/год

**Расчёт:**
- Service charge: 1,200 x 20 = 24,000 AED
- Maintenance: 2,000,000 x 1% = 20,000 AED
- Agency: 120,000 x 5% = 6,000 AED
- Vacancy: 120,000 x 5% = 6,000 AED
- Итого расходы: 56,000 AED

**Результат:**
- Gross ROI: 120,000 / 2,000,000 x 100 = 6.0%
- Net ROI: (120,000 - 56,000) / 2,000,000 x 100 = 3.2%
- Окупаемость: 2,000,000 / 64,000 = ~31 год (без appreciation)

## КАЛЬКУЛЯТОР ИПОТЕКИ

### Когда использовать

При запросе расчёта ипотеки для недвижимости ОАЭ.

### Базовые параметры ОАЭ

**LTV (Loan-to-Value) лимиты:**
| Категория | Первая недвижимость | Вторая+ недвижимость |
|-----------|---------------------|----------------------|
| Резиденты ОАЭ | до 80% | до 70% |
| Нерезиденты | до 50-60% | до 50% |

**Типичные условия:**
- Ставки: 4.5-6.5% годовых
- Срок: 5-25 лет
- Минимальный первый взнос: 20-50%
- Возраст заёмщика: 21-65 лет (на момент погашения до 70)

### Формулы

**Ежемесячный платёж (аннуитет):**
```
M = P x [r(1+r)^n] / [(1+r)^n - 1]

Где:
P = сумма кредита (цена - первый взнос)
r = месячная ставка (годовая / 12 / 100)
n = количество месяцев (срок x 12)
```

**Общая переплата:**
```
Переплата = (M x n) - P
```

**Итого выплат:**
```
Итого = M x n = P + Переплата
```

### Пример расчёта

**Входные данные:**
```
Цена: 2,000,000 AED
Первый взнос: 400,000 AED (20%)
Кредит: 1,600,000 AED
Ставка: 5% годовых (0.417% в месяц)
Срок: 20 лет (240 месяцев)
```

**Расчёт:**
```
r = 5 / 12 / 100 = 0.00417
n = 20 x 12 = 240

M = 1,600,000 x [0.00417(1.00417)^240] / [(1.00417)^240 - 1]
M = 1,600,000 x [0.00417 x 2.714] / [2.714 - 1]
M = 1,600,000 x 0.01132 / 1.714
M = 10,559 AED
```

**Результат:**
```
Ежемесячный платёж: 10,559 AED
Общая переплата: (10,559 x 240) - 1,600,000 = 934,160 AED
Итого выплат: 2,534,160 AED
```

## NOTION ИНТЕГРАЦИЯ (опционально)

### Когда использовать

При наличии подключённого Notion MCP можно автоматизировать работу с объектами.

### Структура базы Properties

| Поле | Тип | Описание |
|------|-----|----------|
| ID | Title | Уникальный номер объекта |
| Type | Select | Apartment/Villa/Townhouse/Penthouse/Office |
| Operation | Select | Sale/Rent |
| Status | Select | Active/Reserved/Sold/Rented |
| Location | Select | Dubai Marina/Downtown/Palm/etc. |
| Building | Text | Название здания/комплекса |
| Bedrooms | Number | Количество спален |
| Bathrooms | Number | Количество ванных |
| Area (sq.ft.) | Number | Площадь |
| Price (AED) | Number | Цена |
| Floor | Text | Этаж (например "25/45") |
| View | Select | Sea/Marina/City/Garden |
| Furnished | Select | Yes/No/Semi |
| Parking | Number | Количество мест |
| Photos | Files | Фотографии объекта |
| Created | Date | Дата добавления |
| Agent | Person | Ответственный агент |
| Notes | Text | Заметки |
| Ad Generated | Checkbox | Объявление создано |

### Автоматизация

**Сохранение объекта в Notion:**
После генерации объявления можно сохранить данные в базу командой:
`/недвижимость сохранить в Notion`

**Генерация из Notion:**
Если объект уже есть в базе, можно сгенерировать объявление командой:
`/недвижимость из Notion [ID объекта]`

### Связанные базы

| База | Назначение |
|------|------------|
| Properties | Объекты недвижимости |
| Clients | Клиенты и их предпочтения |
| Transactions | Сделки |
| Agents | Агенты |
