# Справочник типов недвижимости ОАЭ

## Жилая недвижимость (Residential)

### Апартаменты (Apartments)

| Тип | Описание | Площадь (sq.ft.) |
|-----|----------|------------------|
| Studio | Одна комната без отдельной спальни | 300-600 |
| 1BR | 1 спальня + гостиная | 600-1,000 |
| 2BR | 2 спальни + гостиная | 1,000-1,600 |
| 3BR | 3 спальни + гостиная | 1,400-2,500 |
| 4BR | 4 спальни + гостиная | 2,200-4,000 |
| 5BR+ | 5+ спален | 3,500+ |
| Duplex | Двухуровневые | 2,000-5,000 |
| Loft | Высокие потолки, открытая планировка | 800-2,000 |

**Особенности объявления:**
- Указывать этаж / общее количество этажей
- Вид (Sea/Marina/City/Garden)
- Меблировка
- Паркинг

---

### Studio (Студии)

Компактные апартаменты без отдельной спальни — спальная зона совмещена с гостиной.

| Характеристика | Типичные значения |
|----------------|-------------------|
| Площадь | 300-600 sq.ft. |
| Планировка | Open-plan (одна комната) |
| Ванная | 1 |
| Балкон | Часто есть (маленький) |
| Паркинг | 1 место или нет |

**Целевая аудитория:**
- Молодые профессионалы
- Студенты
- Одиночки
- Инвесторы (высокий ROI)

**Особенности для объявления:**
- Подчеркнуть компактность и функциональность
- Указать близость к метро/транспорту
- Выделить низкую цену аренды
- Отметить, если DEWA включена (важно для бюджетных арендаторов)
- Указать минимальный срок (часто 6 месяцев)

**Популярные районы для Studio:**
- JVC (самые доступные)
- Dubai Marina (премиум)
- Business Bay (для работающих)
- Sports City (бюджетный)
- JLT (средний сегмент)

**Ценовой диапазон (аренда/год):**
- JVC: 25,000-40,000 AED
- Dubai Marina: 50,000-80,000 AED
- Business Bay: 40,000-65,000 AED
- Downtown: 60,000-90,000 AED

---

### Duplex (Двухуровневые апартаменты)

Апартаменты на двух этажах с внутренней лестницей — сочетание пространства квартиры и приватности виллы.

| Характеристика | Типичные значения |
|----------------|-------------------|
| Площадь | 2,000-5,000 sq.ft. |
| Уровни | 2 (иногда 3 — Triplex) |
| Спальни | 2-5 BR |
| Ванные | 2-6 |
| Высота потолков | 3.0-4.5м (на первом уровне) |
| Терраса | Часто большая |
| Паркинг | 2-3 места |

**Планировка типичного Duplex:**

*Нижний уровень:*
- Гостиная
- Столовая
- Кухня
- Гостевая ванная
- Иногда гостевая спальня

*Верхний уровень:*
- Мастер-спальня (en-suite)
- Дополнительные спальни
- Семейная ванная
- Иногда кабинет/study

**Целевая аудитория:**
- Семьи с детьми
- Те, кто хочет пространство виллы, но в апартаментах
- Покупатели премиум-сегмента
- Работающие из дома (разделение зон)

**Особенности для объявления:**
- Указать площадь КАЖДОГО уровня
- Описать расположение спален (какой уровень)
- Подчеркнуть высоту потолков
- Указать размер террасы
- Отметить приватность (меньше соседей на этаже)
- Выделить вид с верхнего уровня

**Популярные районы для Duplex:**
- Dubai Marina (высотки)
- Downtown Dubai
- Palm Jumeirah
- Dubai Hills Estate
- City Walk

**Ценовой диапазон (продажа):**
- JVC: 1.5-3M AED
- Dubai Marina: 3-8M AED
- Downtown: 5-15M AED
- Palm Jumeirah: 8-25M AED

**Отличия от Penthouse:**
| Параметр | Duplex | Penthouse |
|----------|--------|-----------|
| Расположение | Любой этаж | Верхние этажи |
| Терраса | Обычная | Большая, часто с бассейном |
| Приватный лифт | Редко | Часто |
| Эксклюзивность | Средняя | Высокая |
| Цена | $$$ | $$$$ |

## Коммерческая недвижимость (Commercial)

### Офисы (Offices)

| Тип | Описание |
|-----|----------|
| Shell & Core | Голые стены, только коммуникации |
| CAT A | Базовая отделка (потолок, пол, свет) |
| Fitted | Готов к работе (мебель, переговорные) |
| Plug & Play | Полностью готов (мебель, IT) |
| Serviced | С услугами (reception, уборка) |

**Особенности объявления:**
- Площадь (GLA/NLA)
- Тип отделки — ОБЯЗАТЕЛЬНО
- Цена за sq.ft. И общая
- Парковочные места
- Service charge и Chiller
- Free zone / Mainland

## Off-plan (Новостройки)

### Этапы строительства

| Этап | Описание | Риск | Скидка |
|------|----------|------|--------|
| Launch | Старт продаж | Высокий | 15-25% |
| Foundation | Фундамент | Средний | 10-15% |
| Structure | Каркас | Низкий | 5-10% |
| Finishing | Отделка | Минимальный | 0-5% |
| Ready | Готов | Нет | 0% |

### Типы Off-plan

| Тип | Описание |
|-----|----------|
| Apartment | Квартиры в новостройках |
| Villa | Виллы в новых комплексах |
| Townhouse | Таунхаусы в комьюнити |
| Commercial | Коммерческая недвижимость |

**Обязательные поля для объявления:**
- Название проекта
- Застройщик (Developer)
- Payment Plan (план оплаты)
- Дата сдачи (Completion Date)
- Статус строительства
- DLD регистрация
- Escrow номер

## Терминология по типам

### Для жилой недвижимости
- **BR** — Bedroom (спальня)
- **Bath** — Bathroom (ванная)
- **En-suite** — Ванная при спальне
- **Maid's room** — Комната прислуги
- **Driver's room** — Комната водителя
- **Majlis** — Гостевая комната (арабская)
- **Balcony** — Балкон
- **Terrace** — Терраса

### Для коммерческой недвижимости
- **GLA** — Gross Leasable Area
- **NLA** — Net Leasable Area
- **Fit-out** — Отделка
- **HVAC** — Климат-контроль
- **Raised floor** — Фальшпол
- **Grade A/B/C** — Класс здания
