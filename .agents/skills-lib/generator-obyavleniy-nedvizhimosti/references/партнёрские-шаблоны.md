# Партнёрские шаблоны (Co-Broke)

## Что такое Co-Broke

Совместная работа двух агентов:
- Один представляет объект (listing agent)
- Другой представляет клиента (buyer's agent)
- Комиссия делится (обычно 50/50)

## Шаблоны для агентов

### Предложение партнёрства

```
*Коллега, приветствую!*

Есть клиент на [тип] в [район].
Бюджет: [X-Y] AED
Срок: [когда нужно]

Есть подходящие объекты?
Co-broke 50/50.

[Ваше имя]
[Компания]
```

### Запрос на объект

```
*Здравствуйте!*

Увидел ваш [объект] на [портал/группа].
Есть клиент с подтверждённым бюджетом.

Вопросы:
1. Актуален ли объект?
2. Условия co-broke?
3. Когда возможен просмотр?

[Ваше имя]
[Контакт]
```

### Подтверждение условий

```
*Подтверждаю условия:*

Объект: [адрес]
Цена: [X] AED
Комиссия продавца: [X]%
Co-broke split: [X/X]%
Ваша часть: [X] AED
Моя часть: [X] AED

Просмотр: [дата, время]
Клиент: [имя/профиль]

Согласны? Подтвердите.
```

### После показа

```
*Отчёт о показе:*

Объект: [адрес]
Клиент: [профиль]
Результат: [понравилось/не подошло/думает]

▫️ [что понравилось]
▫️ [что не понравилось]
▫️ [вопросы клиента]

```

## Группы агентов

### Правила постинга
1. Указывать тип поста: [ЛИСТИНГ] / [ЗАПРОС] / [SOLD]
2. Полная информация сразу
3. Актуальность — удалять проданное
4. Не флудить — 1 пост на объект

### Формат для групп

```
[ЛИСТИНГ] 2BR Marina Gate | 1.8M | Co-broke 50/50

📍 Dubai Marina
🏠 2BR | 2Bath | 1,450 sqft
💰 1,800,000 AED
📊 ROI: 6.5%
🅿️ 1 parking

✅ Furnished
✅ Sea view
✅ Available now

Split: 50/50
Contact: [имя] [телефон]
```

## Соглашение о сотрудничестве

### Основные пункты
```
1. Объект: [адрес]
2. Цена: [X] AED
3. Комиссия от продавца: [X]%
4. Распределение: [X]% listing / [X]% buyer agent
5. Оплата: в течение [X] дней после закрытия
6. Эксклюзивность клиента: [да/нет]
7. Срок соглашения: [дата]
```
