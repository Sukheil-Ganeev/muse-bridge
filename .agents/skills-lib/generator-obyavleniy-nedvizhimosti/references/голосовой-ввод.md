# Голосовой ввод

Подробное руководство по парсингу голосового ввода для генерации объявлений о недвижимости.

---

## Обзор

Пользователь диктует параметры объекта голосом. Транскрипт приходит от:
- Yandex SpeechKit
- OpenAI Whisper
- Google Speech-to-Text
- Telegram Voice Message

Claude парсит транскрипт и генерирует структурированное объявление.

---

## Алгоритм обработки

### 1. Получить транскрипт
```
"двушка в марине аренда сто двадцать тысяч меблированная"
```

### 2. Привести к нижнему регистру
```
"двушка в марине аренда сто двадцать тысяч меблированная"
```

### 3. Найти тип недвижимости
```
"двушка" → 2BR Apartment
```

### 4. Найти район
```
"марине" → Dubai Marina
```

### 5. Найти операцию
```
"аренда" → Rent
```

### 6. Найти цену
```
"сто двадцать тысяч" → 120,000 AED
```

### 7. Найти доп. параметры
```
"меблированная" → Furnished
```

### 8. Сгенерировать объявление

## Примеры парсинга

### Пример 1: Базовый

**Вход:** "двушка в марине аренда сто двадцать"

**Парсинг:**
```
Тип: 2BR Apartment (из "двушка")
Район: Dubai Marina (из "марине")
Операция: Rent (из "аренда")
Цена: 120,000 AED (из "сто двадцать" + подразумевается "тысяч" для аренды)
```

**Результат:**
```
*2BR АПАРТАМЕНТЫ | DUBAI MARINA*
_Аренда в популярном районе_
───────────────
💰 *АРЕНДА: 120,000 AED/год*
```

### Пример 2: Расширенный

**Вход:** "вилла на пальме четыре спальни продажа двенадцать миллионов с бассейном"

**Парсинг:**
```
Тип: Villa 4BR (из "вилла" + "четыре спальни")
Район: Palm Jumeirah (из "пальме")
Операция: Sale (из "продажа")
Цена: 12,000,000 AED (из "двенадцать миллионов")
Особенности: Pool (из "с бассейном")
```

**Результат:**
```
*4BR ВИЛЛА | PALM JUMEIRAH*
_Роскошная вилла с приватным бассейном_
───────────────
💰 *ПРОДАЖА: 12,000,000 AED*
```

### Пример 3: С площадью

**Вход:** "офис в дифц тысяча пятьсот квадратных футов аренда двести пятьдесят за фут"

**Парсинг:**
```
Тип: Office (из "офис")
Район: DIFC (из "дифц")
Площадь: 1,500 sq.ft. (из "тысяча пятьсот квадратных футов")
Операция: Rent (из "аренда")
Цена: 250 AED/sq.ft./year (из "двести пятьдесят за фут")
Итого: 375,000 AED/year
```

### Пример 4: Сложное числительное

**Вход:** "трёшка в даунтауне продажа два с половиной миллиона меблированная высокий этаж вид на бурдж"

**Парсинг:**
```
Тип: 3BR Apartment (из "трёшка")
Район: Downtown Dubai (из "даунтауне")
Операция: Sale (из "продажа")
Цена: 2,500,000 AED (из "два с половиной миллиона")
Меблировка: Furnished (из "меблированная")
Этаж: High Floor (из "высокий этаж")
Вид: Burj Khalifa View (из "вид на бурдж")
```

### Пример 5: Краткосрочная аренда

**Вход:** "студия в марине аренда помесячно пятнадцать тысяч furnished"

**Парсинг:**
```
Тип: Studio (из "студия")
Район: Dubai Marina (из "марине")
Операция: Rent Monthly (из "аренда помесячно")
Цена: 15,000 AED/month (из "пятнадцать тысяч" + "помесячно")
Меблировка: Furnished
```

## Валидация

### Автоматические исправления

| Вход | Исправление | Причина |
|------|-------------|---------|
| "аренда пятьдесят" | 50,000 AED/год | Для аренды подразумеваются тысячи |
| "продажа полтора" | 1,500,000 AED | Для продажи подразумеваются миллионы |
| "офис сто" | 100 AED/sq.ft./год | Для офисов цена за фут |

### Проверка адекватности

Если распознанная цена кажется нереальной:

```
⚠️ *УТОЧНЕНИЕ*
Распознано: 2BR Marina, аренда 12,000 AED/год
Это выглядит слишком низко. Вы имели в виду:
▫️ 12,000 AED/месяц = 144,000 AED/год?
▫️ 120,000 AED/год?
```

## Неполные данные

### Что делать если не хватает данных

1. **Нет района:**
   ```
   Уточните район: Dubai Marina, Downtown, Palm или другой?
   ```

2. **Нет цены:**
   ```
   Укажите цену: сколько за аренду/продажу?
   ```

3. **Нет операции:**
   ```
   Это аренда или продажа?
   ```

4. **Нет типа:**
   ```
   Какой тип недвижимости: апартаменты, вилла, офис?
   ```

### Минимальный набор для генерации

- Тип недвижимости
- Район
- Операция
- Цена

## Обработка ошибок транскрипции

### Типичные ошибки и исправления

| Ошибка транскрипции | Правильно |
|---------------------|-----------|
| "до бай марина" | Dubai Marina |
| "дубай маріна" | Dubai Marina |
| "палм жумейра" | Palm Jumeirah |
| "бизнес бэй" | Business Bay |
| "жвс" | JVC |
| "жлт" | JLT |
| "дифси" | DIFC |
| "100 20" | 120 (сто двадцать) |
| "2 000 000" | 2,000,000 |

### Fuzzy matching для районов

Используй нечёткое сопоставление:
- "марин" → Dubai Marina
- "дауттаун" → Downtown
- "пальм" → Palm Jumeirah
- "арабиан ранч" → Arabian Ranches

## Особые случаи

### 1. Несколько объектов

**Вход:** "две квартиры двушка в марине аренда сто двадцать и трёшка в даунтауне продажа три миллиона"

**Обработка:** Генерировать два отдельных объявления

### 2. Сравнение

**Вход:** "что лучше взять двушку в марине за сто пятьдесят или трёшку в jvc за сто двадцать"

**Обработка:** Создать сравнительную таблицу

### 3. Уточняющие вопросы

**Вход:** "есть ли двушки в марине до ста тысяч"

**Обработка:** Это вопрос, а не данные для объявления. Ответить по существу.
