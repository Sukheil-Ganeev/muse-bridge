Подробный справочник по адаптации объявлений под разные целевые аудитории.

## 1. ИНВЕСТОРЫ

### Профиль

| Характеристика | Описание |
|----------------|----------|
| Возраст | 35-60 лет |
| Доход | Высокий (>$100K/год) |
| Цель | Пассивный доход, сохранение капитала |
| Локации | Россия, СНГ, Европа, Индия, Пакистан |
| Бюджет | От 1M AED (чаще 2-5M AED) |

### Что важно для инвесторов

1. **ROI (Return on Investment)**
   - Gross yield (валовая доходность)
   - Net yield (чистая доходность)
   - Сравнение с банковскими депозитами

2. **Capital Appreciation**
   - Историческая динамика цен
   - Перспективы роста района
   - Планы застройки и инфраструктуры

3. **Golden Visa**
   - Порог: от 2M AED недвижимости
   - 10-летняя резидентская виза
   - Возможность для всей семьи

4. **Payment Plans (для off-plan)**
   - Соотношение взносов
   - Post-handover планы
   - Возможность перепродажи до сдачи

5. **Управление**
   - Возможность сдачи в аренду
   - Property management услуги
   - Airbnb разрешения

### Ключевые фразы для инвесторов

```
▫️ "ROI: 7.2% годовых"
▫️ "Стабильный арендный доход"
▫️ "Golden Visa eligible"
▫️ "Payment plan 20/60/20"
▫️ "Высокий потенциал роста"
▫️ "Capital appreciation +15%"
```

## 2. СЕМЬИ

### Профиль

| Характеристика | Описание |
|----------------|----------|
| Состав | 2 взрослых + 1-3 ребёнка |
| Возраст детей | 0-18 лет |
| Цель | Комфортное проживание, школы |
| Бюджет | 2-5M AED (покупка), 150-400K AED (аренда) |
| Предпочтения | 3-4BR, вилла/таунхаус |

### Что важно для семей

1. **Образование**
   - Близость к школам (GEMS, Taleem, Nord Anglia)
   - Рейтинг школ в районе

   - 24/7 охрана
   - Низкий криминал

3. **Инфраструктура для детей**
   - Детские площадки
   - Бассейны для детей
   - Спортивные секции

4. **Зелень и парки**
   - Parks and gardens
   - Jogging tracks
   - Велодорожки

5. **Community lifestyle**
   - Семейные районы
   - Events для детей
   - Kids clubs

### Профиль

| Характеристика | Описание |
|----------------|----------|
| Срок | 2 недели — 3 месяца |
| Цель | Отпуск, зимовка, бизнес |
| Происхождение | Россия, СНГ, Европа |
| Бюджет | 200-500 AED/день |
| Сезон | Октябрь — Апрель |

### Что важно для туристов

1. **Локация**
   - Близость к достопримечательностям
   - Вид (море, Burj Khalifa)
   - Пляж рядом

2. **Включённые услуги**

   - Уборка
   - Трансфер

3. **Гибкость**
   - Минимальный срок
   - Условия отмены
   - Без депозита

4. **Удобства**
   - Fully furnished
   - Оборудованная кухня
   - TV, Netflix

5. **Атмосфера**
   - Вид
   - Pool access
   - Beach access

## 5. ОПРЕДЕЛЕНИЕ АУДИТОРИИ

### Автоматическое определение

| Триггер в запросе | Аудитория | Уверенность |
|-------------------|-----------|-------------|
| ROI, доходность, инвестиция, yield | Инвестор | Высокая |
| Golden Visa | Инвестор | Высокая |
| Дети, школа, семья | Семья | Высокая |
| 3BR+, вилла с садом | Семья | Средняя |
| Работа, офис, метро | Экспат | Высокая |
| Gym, furnished, ready | Экспат | Средняя |
| Отпуск, краткосрок, туристы | Турист | Высокая |
| На месяц, 2 недели | Турист | Высокая |

### Комбинированные триггеры

- **Инвестор + Семья**: "Хочу купить для семьи и сдавать когда не живём"
- **Экспат + Турист**: "Снять на 3 месяца пока ищу постоянное жильё"
- **Инвестор + Турист**: "Купить для Airbnb"

### Если аудитория неясна

Задай уточняющий вопрос:
```
Уточните, пожалуйста:
▫️ Для проживания или инвестиции?
▫️ С семьёй/детьми или для себя?
▫️ На какой срок?
```

## 6. АДАПТАЦИЯ ОБЪЯВЛЕНИЯ

### Где размещать блок ЦА

```
ЗАГОЛОВОК
_Подзаголовок_
───────────────
ХАРАКТЕРИСТИКИ
...
───────────────
[БЛОК ДЛЯ ЦА]     <-- ЗДЕСЬ
───────────────
ЦЕНА
УСЛОВИЯ
КОНТАКТ
```

### Когда добавлять блок

- Если ЦА определена по запросу
- Если объект явно подходит под ЦА
- Если нужно подчеркнуть преимущества

### Когда НЕ добавлять блок

- Стандартное объявление без контекста
- Клиент не указал цель
- Объект универсальный
