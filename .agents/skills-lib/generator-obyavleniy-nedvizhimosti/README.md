# Генератор объявлений о недвижимости ОАЭ

## Описание

Claude Code скилл для автоматической генерации объявлений о недвижимости, оптимизированных для рассылки через WhatsApp и Telegram. Поддерживает сохранение в файл и интеграцию с Notion.

## Возможности

- Генерация объявлений для WhatsApp и Telegram (RU/EN)
- Поддержка продажи и аренды
- Все типы недвижимости: жилая, коммерческая, off-plan, земля
- Автоматическое форматирование под мессенджер
- Валидация данных
- Сохранение в файл (4 версии)
- Интеграция с Notion
- Калькулятор ROI

## Использование

```
/генератор-объявлений-недвижимости
```

Или просто попросите создать объявление о недвижимости.

## Поддерживаемые типы недвижимости

### Жилая недвижимость (Residential)
- Апартаменты (Studio - 5BR)
- Виллы
- Таунхаусы (Townhouses)
- Пентхаусы
- Hotel Apartments

### Коммерческая недвижимость (Commercial)
- Офисы (Offices)
- Этажи зданий (Full Floor / Half Floor)
- Retail (магазины, торговые помещения)
- Warehouse (склады)

### Off-plan (Новостройки)
- Апартаменты на этапе строительства
- Виллы на этапе строительства
- Таунхаусы на этапе строительства

### Земельные участки (Land)
- Residential plots (под жилую застройку)
- Commercial plots (под коммерческую застройку)
- Mixed-use plots (смешанное использование)

## Мессенджеры и форматы

| Мессенджер | Жирный | Курсив | Разделитель |
|------------|--------|--------|-------------|
| WhatsApp | `*текст*` | `_текст_` | 15 символов |
| Telegram | `**текст**` | `__текст__` | 18 символов |

### Форматы сохранения
- **WA RU** — WhatsApp на русском
- **TG RU** — Telegram на русском
- **EN** — Английский (WhatsApp формат)
- **Plain** — Без форматирования

## Минимальные данные для объявления

1. Тип недвижимости
2. Операция (продажа/аренда)
3. Мессенджер (WhatsApp/Telegram)
4. Локация
5. Характеристики (площадь, спальни и т.д.)
6. Цена
7. Контакт

## Интеграции

### Notion
- Автоматическое создание записей в базе данных
- Сохранение всех версий объявления
- Теги по типу и локации

### Файловая система
- Сохранение в `D:/Downloads/`
- Автоматическое именование файлов
- Поддержка 4 форматов
