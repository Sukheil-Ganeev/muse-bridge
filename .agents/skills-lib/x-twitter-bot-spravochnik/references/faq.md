# FAQ — X (Twitter) Bot API v2

## 1. Можно ли создать бота на Free tier?

Частично. Free tier позволяет публиковать до 500 постов/месяц на App (1,500 на юзера), но **нет чтения**, нет поиска, нет стриминга, нет DM API. Для полноценного бота (мониторинг, ответы, DM) нужен минимум **Basic** ($200/мес).

## 2. Какой тариф выбрать для туристического бота?

**Basic ($200/мес)** — достаточен для: автопостинга, мониторинга упоминаний, DM-бота, Filtered Stream (25 правил), Recent Search. Для full-archive поиска и 1000 правил стриминга нужен **Pro ($5,000/мес)**.

## 3. Чем отличается OAuth 2.0 App-only от OAuth 2.0 PKCE?

**App-only** (Bearer Token) — только чтение от имени приложения. **PKCE** — полный доступ от имени пользователя (посты, DM, лайки). Для бота используйте PKCE.

## 4. Как обновлять токены автоматически?

Access Token живёт 2 часа, Refresh Token — 6 месяцев. Бот должен перехватывать 401 ошибку и вызывать `POST /2/oauth2/token` с `grant_type=refresh_token`. Сохраняйте оба токена в файл/БД при каждом обновлении.

## 5. Сколько постов в день можно публиковать?

Free: ~17 постов/день (500/мес). Basic: ~1,667/день (50,000/мес). Но есть дополнительный лимит: 100 постов на юзера за 24 часа. Для туристического бота 2-4 поста/день — оптимально.

## 6. Можно ли отправлять DM незнакомым пользователям?

Только если у пользователя открыты DM для всех. Массовая рассылка DM незнакомцам нарушает правила X и приведёт к бану. DM-бот должен **отвечать** на входящие сообщения, а не инициировать.

## 7. Как работает Filtered Stream?

Вы создаёте правила (набор операторов-фильтров), подключаетесь к стриму по SSE, и X отправляет вам посты, совпадающие с правилами, в реальном времени. Соединение должно быть постоянным — используйте VPS/контейнер, не serverless.

## 8. Можно ли публиковать посты с изображениями на Free tier?

Да. С января 2025 медиа загружается через `POST /2/media/upload` (v2 endpoint). Free tier поддерживает media upload + tweet write.

## 9. Как избежать бана за автоматизацию?

Соблюдайте X Automation Rules: не спамьте, не отправляйте дублирующийся контент, не делайте массовые лайки/ретвиты, добавляйте задержки между действиями (3-10 сек), не публикуйте идентичные тексты.

## 10. Какую библиотеку выбрать — tweepy или twitter-api-v2 (npm)?

**Python** — tweepy (самая популярная, полная поддержка v2, активная разработка). **Node.js** — twitter-api-v2 (TypeScript, полная обёртка, streaming). Выбирайте по языку вашего стека.

## 11. Что такое twikit и стоит ли его использовать?

twikit — неофициальная Python-библиотека, работающая через внутренний API X без ключей. Бесплатно, но: нестабильно (может сломаться), нарушает ToS, аккаунт могут забанить. Подходит только для прототипов и исследований.

## 12. Можно ли использовать webhooks на Basic тарифе?

Нет. Account Activity API (webhooks) доступен только на **Enterprise** тарифе. На Basic/Pro используйте **polling** — периодический опрос API (mentions, DM events каждые 15-60 секунд).

## 13. Как мониторить несколько ключевых слов одновременно?

Два подхода: (1) Filtered Stream — одно соединение, несколько правил (Basic: 25, Pro: 1000). (2) Search API с polling — один запрос с операторами `OR` каждые N секунд. Stream лучше для реалтайма, Search — для периодических проверок.

## 14. Какой формат видео поддерживается для постов?

MP4 (H264, AAC), до 512 MB, до 140 секунд, одно видео на пост. Минимальное разрешение 32x32, максимальное 1920x1200 (или 1200x1920). Рекомендуется 720p или 1080p.

## 15. Как тестировать бота без публикации реальных постов?

Создайте отдельный тестовый аккаунт X. Используйте отдельный App в Developer Portal привязанный к тестовому аккаунту. Все посты будут на тестовом аккаунте. Полноценного sandbox у X API нет.
