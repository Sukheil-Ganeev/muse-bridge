# Справка по синтаксису форматирования

Полный справочник по синтаксису форматирования для WhatsApp и Telegram.

---

## WhatsApp

### Базовое форматирование

| Элемент | Синтаксис | Результат | Применение |
|---------|-----------|-----------|------------|
| Жирный | `*текст*` | **текст** | Заголовки, важное |
| Курсив | `_текст_` | _текст_ | Описания |
| Моноширинный | ` ```текст``` ` | `текст` | Категории цен |
| Зачёркнутый | `~текст~` | ~~текст~~ | Старые цены |

### Примеры использования

**Заголовок раздела:**
```
💰 *СТОИМОСТЬ*
```

**Описание:**
```
_Незабываемое путешествие по пустыне
с ужином под звёздами_
```

**Категория с ценой:**
```
```Взрослый```  185$
```Ребёнок 3-11```  155$
```

**Скидка/старая цена:**
```
```VIP```  ~250$~ 199$
```

### Комбинирование форматов

| Комбинация | Синтаксис | Результат |
|------------|-----------|-----------|
| Жирный + курсив | `*_текст_*` | ***текст*** |
| Жирный в описании | `_текст *важно* текст_` | _текст **важно** текст_ |

### Особенности WhatsApp

**Поддерживается:**
- Жирный, курсив, моноширинный, зачёркнутый
- Эмодзи
- Переносы строк

**НЕ поддерживается:**
- Заголовки разных уровней (H1, H2...)
- Таблицы
- Ссылки с текстом `[текст](url)`
- Списки с маркерами (только вручную через •)
- Цитаты
- Код с подсветкой синтаксиса

### Структура документа WhatsApp

```
*НАЗВАНИЕ ПРОДУКТА*

_Краткое описание продукта на 2-3 строки.
Что увидит/получит клиент._

💰 *СТОИМОСТЬ*

*Из Дубая:*
```Взрослый```  185$
```Ребёнок 3-11```  155$
```Ребёнок 0-2```  бесплатно

*Из Абу-Даби:*
```Взрослый```  165$
```Ребёнок 3-11```  140$

───────────────

➕ *ЧТО ВКЛЮЧЕНО*

• Трансфер из отеля
• Входные билеты
• Услуги гида

───────────────

⚠️ *ВАЖНО*

• Минимальный возраст: 3 года
• Иметь при себе паспорт
```

## Telegram

### Базовое форматирование

| Элемент | Синтаксис | Результат | Применение |
|---------|-----------|-----------|------------|
| Жирный | `**текст**` | **текст** | Заголовки, категории |
| Курсив | `__текст__` | _текст_ | Описания |
| Зачёркнутый | `~~текст~~` | ~~текст~~ | Старые цены |
| Подчёркнутый | `++текст++` | <u>текст</u> | Редко |
| Спойлер | `\|\|текст\|\|` | [спойлер] | Не использовать |

### ВАЖНО: Моноширинный в Telegram

**НЕ ИСПОЛЬЗОВАТЬ моноширинный для категорий!**

В Telegram моноширинный шрифт (` ``` ` или `` ` ``) выглядит как код программы — серый фон, другой шрифт. Это неуместно для цен.

**Неправильно (Telegram):**
```
```Взрослый```  185$
```

**Правильно (Telegram):**
```
**Взрослый** — 185$
```

## Telegram Bot API (техническая справка)

Для разработчиков ботов — форматирование через API.

### Markdown V2 (parse_mode: MarkdownV2)

```
*жирный*
_курсив_
__подчёркнутый__
~зачёркнутый~
||спойлер||
`моноширинный`
```код```
[ссылка](URL)
```

**Экранирование символов:**
Следующие символы нужно экранировать через `\`:
```
_ * [ ] ( ) ~ ` > # + - = | { } . !
```

### HTML (parse_mode: HTML)

```html
<b>жирный</b>
<i>курсив</i>
<u>подчёркнутый</u>
<s>зачёркнутый</s>
<span class="tg-spoiler">спойлер</span>
<code>моноширинный</code>
<pre>блок кода</pre>
<a href="URL">ссылка</a>
```

### Пример отправки через API

```python
import requests

text = """
<b>САФАРИ В ПУСТЫНЕ</b>

<i>Незабываемое приключение!</i>

💰 <b>СТОИМОСТЬ</b>

<b>Взрослый</b> — 185$
<b>Ребёнок</b> — 155$
"""

requests.post(
    f"https://api.telegram.org/bot{TOKEN}/sendMessage",
    data={
        "chat_id": CHAT_ID,
        "text": text,
        "parse_mode": "HTML"
    }
)
```

## Специальные символы

### Разделитель

| Платформа | Символ | Количество | Результат |
|-----------|--------|------------|-----------|
| WhatsApp | `─` | 15 | `───────────────` |
| Telegram | `─` | 18 | `──────────────────` |

**Код символа:** U+2500 (Box Drawings Light Horizontal)

**Как ввести:**
- Скопировать из этого документа
- Windows: Alt+2500 (на нумпаде)
- Mac: удерживать Option, ввести 2500

### Маркеры списка

| Символ | Код | Название |
|--------|-----|----------|
| • | U+2022 | Bullet |
| ◦ | U+25E6 | White Bullet |
| ‣ | U+2023 | Triangle Bullet |

**Рекомендуется:** использовать `•` (U+2022)

### Тире

| Символ | Код | Использование |
|--------|-----|---------------|
| - | U+002D | НЕ использовать |
| – | U+2013 | En Dash (для диапазонов: 3–11) |
| — | U+2014 | Em Dash (после категории в TG) |
| ─ | U+2500 | Для разделителей |

## Валюта

### Форматы записи

| Валюта | Формат | Пример |
|--------|--------|--------|
| Доллар США | `N$` | `185$` |
| Дирхам ОАЭ | `N AED` | `500 AED` |
| Евро | `N€` | `150€` |
| Рубль | `N₽` | `5000₽` |

### Правила:
- Символ валюты БЕЗ пробела после числа: `185$`
- Код валюты С пробелом: `500 AED`
- Не использовать слова: ~~"долларов"~~, ~~"дирхам"~~

## Числа и диапазоны

### Возраст
```
3-11 лет     (дефис)
3–11 лет     (en dash, предпочтительно)
```

### Время
```
09:00        (с ведущим нулём)
~18:00       (приблизительно)
8-9 часов    (диапазон)
```

### Цены
```
185$         (без пробелов)
от 185$      (с "от")
185-250$     (диапазон)
~200$        (приблизительно)
```
