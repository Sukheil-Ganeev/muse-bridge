## АВТОМАТИЧЕСКОЕ ОПРЕДЕЛЕНИЕ МОДУЛЯ

> **КРИТИЧНО:** При получении RAW-файла определяй модуль по названию папки!

**МАППИНГ ПАПОК -> МОДУЛЕЙ:**

| Папка в пути | Ключевое слово | Модуль инструкции | Когда отправлять |
|--------------|----------------|-------------------|------------------|
| `_01_FAQ_RAW` | FAQ | МОДУЛЬ_FAQ | Типичные вопросы клиента |
| `_02_Ограничения_RAW` | Ограничения | МОДУЛЬ_ОГРАНИЧЕНИЯ | При бронировании, экстрим |
| `_03_Тарифы_RAW` | Тарифы | МОДУЛЬ_ТАРИФЫ | Детальные вопросы о ценах |
| `_04_Расписание_RAW` | Расписание | МОДУЛЬ_РАСПИСАНИЕ | "Когда лучше?" |
| `_05_Локация_RAW` | Локация | МОДУЛЬ_ЛОКАЦИЯ | "Как добраться?" |
| `_06_Практические_советы` | Практика | МОДУЛЬ_ПРАКТИКА | При бронировании, "Что взять?" |
| `_07_Инфраструктура_RAW` | Инфраструктура | МОДУЛЬ_ИНФРАСТРУКТУРА | "Где поесть?", "Есть ли шкафчики?" |
| `_08_Политики_RAW` | Политики | МОДУЛЬ_ПОЛИТИКИ | Вопросы об отмене/возврате |
| `_09_Контакты_RAW` | Контакты | МОДУЛЬ_КОНТАКТЫ | Нужна прямая связь |

**ЛОГИКА ОПРЕДЕЛЕНИЯ:**
1. Получаешь путь к файлу: `...\билеты\_04_Расписание_RAW\Fishing Trip Dubai`
2. Ищешь ключевое слово в пути: `_04_Расписание` -> РАСПИСАНИЕ
3. Применяешь соответствующий модуль: `МОДУЛЬ_РАСПИСАНИЕ`

**Пример:**
```
Путь: C:\...\билеты\_02_Ограничения_RAW\Skydive Dubai.txt
     └── Ключевое слово: "Ограничения"
         └── Применить: МОДУЛЬ_ОГРАНИЧЕНИЯ
```

## КРАТКОЕ ОПИСАНИЕ МОДУЛЕЙ

**⚠️ МОДУЛЬ_ОГРАНИЧЕНИЯ** — при бронировании, для экстремальных активностей
```

───────────────

*ФИЗИЧЕСКИЕ ТРЕБОВАНИЯ*
*МЕДИЦИНСКИЕ ПРОТИВОПОКАЗАНИЯ*
*ДРЕСС-КОД*
*ПЕРЕД ПОСЕЩЕНИЕМ*
```

*КОМБО-ПАКЕТЫ*
*ГОДОВЫЕ АБОНЕМЕНТЫ*

## ПРАВИЛА ФОРМАТИРОВАНИЯ ДЛЯ МОДУЛЕЙ

**Заголовки модулей:**
- С эмодзи: `⚠️ *ОГРАНИЧЕНИЯ*`, `📍 *КАК ДОБРАТЬСЯ*`
- Или без: `*ОГРАНИЧЕНИЯ*`, `*КАК ДОБРАТЬСЯ*`

**Разделители:**
- `───────────────` (15 тире для WhatsApp)
- Между крупными секциями внутри модуля

**Символ `|`:**
- ТОЛЬКО для служебных блоков: оплата, отмена, дни
- НЕ для перечислений — используй запятые

**Цены:**
- В AED (местная валюта) или $
- Диапазон: `60–200 AED` или `от 325 AED`
