# FAQ — Часто задаваемые вопросы

## Q1: Когда использовать один файл, а когда два?

| Тип продукта | Количество файлов | Пояснение |
|--------------|-------------------|-----------|
| **ТУРЫ и экскурсии** | 1 файл | Даже если есть питание как часть тура |
| **Продукты с питанием** | 2 файла | Рестораны, ужины с шоу, круизы с питанием |

### ПОЧЕМУ ТАК:

**Туры:**
- Основной продукт — это маршрут и активности
- Питание второстепенно (обед в туре — бонус, а не суть)
- Клиент выбирает тур ради экскурсии, не ради обеда

**Питание:**
- Основной продукт — это еда
- Меню критично для клиента (аллергии, предпочтения, вегетарианство)
- Клиент платит именно за гастрономический опыт

### Структура двух файлов для питания:

```
[Название]_основное_описание.txt
├── Цены по пакетам
├── Что включено/не включено
├── Условия бронирования
└── Формат мероприятия

[Название]_меню.txt
├── Закуски
├── Основные блюда
├── Десерты
├── Напитки
└── Особые диеты (веган, халяль и т.д.)
```

## Q2: Как группировать цены?

| Тип продукта | Принцип группировки | Пример |
|--------------|---------------------|--------|
| **Туры** | По эмиратам/локациям | Из Дубая, Из Абу-Даби |
| **Питание** | По пакетам/опциям | Silver, Gold, VIP |
| **Билеты** | По зонам/категориям | General, Premium, VIP |

### Примеры правильной группировки:

**Туры:**
```
💰 *СТОИМОСТЬ*

*Из Дубая:*
```Взрослый```  185$
```Ребёнок 3-11```  155$

*Из Абу-Даби:*
```Взрослый```  165$
```Ребёнок 3-11```  140$
```

**Питание:**
```
💰 *ПАКЕТЫ*

*Silver Package:*
```Взрослый```  89$
```Ребёнок```  59$

*Gold Package:*
```Взрослый```  129$
```Ребёнок```  89$
```

## Q3: Сколько пробелов после категории?

**ВСЕГДА ДВА ПРОБЕЛА** между категорией и ценой!

| Неправильно | Правильно |
|-------------|-----------|
| ` ```Взрослый``` 50$` | ` ```Взрослый```  50$` |
| ` ```VIP``` 200$` | ` ```VIP```  200$` |

### Почему это важно:
1. **Визуальное выравнивание** — цены образуют ровный столбец
2. **Единообразие** — все описания выглядят профессионально
3. **Читаемость** — глаз легче находит цену

## Q4: Какие эмодзи использовать?

### Разрешённые эмодзи (только 3):

| Эмодзи | Значение | Где использовать |
|--------|----------|------------------|
| 💰 | Цены | Заголовок блока цен |
| ➕ | Включено | Заголовок "Что включено" |
| ⚠️ | Важно | Критическая информация |

### Запрещены:
- ❌ Декоративные эмодзи (🌴 🏝️ 🎉)
- ❌ Эмодзи в тексте описания
- ❌ Избыточные эмодзи (💵💲🤑)

### Правильное использование:
```
💰 *СТОИМОСТЬ*
➕ *ЧТО ВКЛЮЧЕНО*
⚠️ *ВАЖНО*
```

## Q5: Как форматировать детей разных возрастов?

### Правило: Разные цены = разные строки

**Неправильно:**
```
```Ребёнок 3-11 / 0-2 бесплатно```  45$
```

**Правильно:**
```
```Ребёнок 3-11```  45$
```Ребёнок 0-2```  бесплатно
```

### Стандартные возрастные категории:
- `Взрослый` — без уточнения возраста
- `Ребёнок 3-11` — самая частая категория
- `Ребёнок 0-2` или `Инфант` — бесплатно или символическая цена
- `Пенсионер 60+` — если есть скидка

## Q6: Нужны ли пустые строки?

### Да, пустые строки ОБЯЗАТЕЛЬНЫ:

| Где | Сколько |
|-----|---------|
| После заголовка раздела | 1 строка |
| Между группами цен | 1 строка |
| Перед разделителем | 1 строка |
| После разделителя | 1 строка |

### Пример:
```
💰 *СТОИМОСТЬ*
                          ← пустая строка
*Из Дубая:*
```Взрослый```  185$
```Ребёнок```  155$
                          ← пустая строка
*Из Абу-Даби:*
```Взрослый```  165$
```Ребёнок```  140$
                          ← пустая строка
───────────────
                          ← пустая строка
➕ *ЧТО ВКЛЮЧЕНО*
```

## Q7: Как писать "включено/не включено"?

### Формат списка:
```
➕ *ЧТО ВКЛЮЧЕНО*

• Трансфер из отеля и обратно
• Входные билеты
• Услуги гида на русском языке
• Обед (для туров с питанием)

⚠️ *НЕ ВКЛЮЧЕНО*

• Личные расходы
• Чаевые (по желанию)
• Дополнительные напитки
```

### Правила:
- Каждый пункт с новой строки
- Маркер `•` (точка), не `-` и не `*`
- Краткие формулировки
- Самое важное — первым

## Q8: Как форматировать время и даты?

### Время:
```
*Начало:* 09:00
*Окончание:* ~18:00
*Длительность:* 8-9 часов
```

### Дни недели:
```
*Дни проведения:* ежедневно
*Дни проведения:* Пн, Ср, Пт
*Дни проведения:* кроме воскресенья
```

### НЕ использовать:
- ❌ `9:00` → ✅ `09:00`
- ❌ `понедельник, среда` → ✅ `Пн, Ср`

## Q9: Как обрабатывать опции/варианты?

### Каждая опция — отдельная строка:

**Неправильно:**
```
124 этаж: 70$ | 148 этаж: 155$
```

**Правильно:**
```
```124 этаж```  70$
```148 этаж```  155$
```

### Или с подзаголовком:
```
*Смотровая площадка:*
```124 этаж (At the Top)```  70$
```148 этаж (Sky)```  155$
```

## Q10: Нужно ли указывать валюту?

### Да, валюта указывается ВСЕГДА

| Правильно | Неправильно |
|-----------|-------------|
| `185$` | `185` |
| `500 AED` | `500` |
| `150€` | `150 евро` |

### Формат:
- Доллары: `185$` (знак после числа)
- Дирхамы: `500 AED` (пробел + код)
- Евро: `150€` (знак после числа)

## Q11: Как форматировать длинные описания?

### Правила:
1. Разбивать на абзацы (3-4 предложения)
2. Использовать курсив для описательного текста
3. Выделять ключевые слова жирным

### Пример:
```
_Незабываемое путешествие в сердце пустыни!
Вас ждёт захватывающий джип-сафари по золотым
дюнам, катание на сэндбордах и встреча заката._

_В традиционном лагере бедуинов вы насладитесь
*арабским ужином*, покатаетесь на верблюдах
и увидите *шоу танца живота*._
```

## Q12: Что делать с техническими деталями?

### Выносить в отдельный блок:

```
⚠️ *ВАЖНАЯ ИНФОРМАЦИЯ*

• Минимальный возраст: 3 года
• Дресс-код: закрытые плечи и колени
• При себе иметь: паспорт, удобную обувь
• Не рекомендуется: беременным, с проблемами спины
```

### Что относится к техническим деталям:
- Ограничения по возрасту/здоровью
- Дресс-код
- Что взять с собой
- Правила отмены/переноса
