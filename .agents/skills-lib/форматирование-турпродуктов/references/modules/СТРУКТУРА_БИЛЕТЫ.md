## 4. БЛОК ЦЕНЫ ДЛЯ БИЛЕТОВ

> **КРИТИЧНО:** Группировка по КАТЕГОРИЯМ БИЛЕТОВ (НЕ по эмиратам!)

### ОТЛИЧИЕ ОТ ТУРОВ:
- **ТУРЫ:** группировка по эмиратам (`*Из Дубая:*`)
- **БИЛЕТЫ:** группировка по категориям билетов (``` ```General Admission``` ```)

### Структура:
```
💰 *ЦЕНЫ*

```General Admission```  70$ взр / 45$ реб
_базовый вход, доступ ко всем зонам_

```VIP Experience```  155$ взр / 120$ реб
_без очереди, лаунж, напитки_

```Комбо 2 парка```  120$ взр / 85$ реб
_Аквапарк + Зоопарк, действует 14 дней_
```

### ПРАВИЛА:
1. Каждая категория = ``` ```название``` ``` + цена
2. **ДВА ПРОБЕЛА** после ``` ```категории``` ``` перед ценой
3. В курсиве под каждой категорией — что входит
4. Пустая строка между категориями
5. Цены: `70$` (доллар после числа, без пробела)
6. Формат: `70$ взр / 45$ реб`

## 5. БЛОК ВАЖНО ДЛЯ БИЛЕТОВ

> **КРИТИЧНО:** Только КЛЮЧЕВЫЕ ограничения! Детали — в модуле ОГРАНИЧЕНИЯ

### Что включать:
- Возраст/рост (минимальные требования)
- Сопровождение детей
- За сколько приехать
- Что обязательно взять

### Что НЕ включать (идёт в модуль ОГРАНИЧЕНИЯ):
- Полный список противопоказаний
- Детальный дресс-код
- Физические требования
- Медицинские ограничения

```
⚠️ *ВАЖНО*
Минимум: 12 лет, рост от 120 см
Дети до 16 лет — в сопровождении взрослого
Приехать за 30 минут до слота
Взять: паспорт, удобную обувь

*ОПЛАТА*
USD | Рубли СПБ | AED (курс 3.65) | USDT

*ОТМЕНА*
За 48ч — 100% возврат | За 24ч — 50% | Менее 24ч — без возврата

*ДЛЯ ОФОРМЛЕНИЯ*
```

## 6. ПРАВИЛА ФОРМАТИРОВАНИЯ

### Разделители (15 тире):
```
───────────────
```
Используются ТОЛЬКО между крупными блоками

### Символы:
| Символ | Использование | Пример |
|--------|---------------|--------|
| `\|` | ТОЛЬКО служебные блоки (оплата, отмена) | `USD \| AED` |
| `,` | Все остальные перечисления | `Вход, напитки, лаунж` |
| `/` | с пробелами в ценах | `70$ взр / 45$ реб` |
| `→` | с пробелами | ` → ` |
| `—` | с пробелами | ` — ` |

### Эмодзи (только 3):
- 💰 перед `*ЦЕНЫ*`
- ➕ перед `*ОПЦИИ*` (если есть)
- ⚠️ перед `*ВАЖНО*`

### Цены:
- `70$` (доллар после числа, без пробела)
- `70$ взр / 45$ реб`

## 9. ТИПИЧНЫЕ ОШИБКИ

### Ошибка 1: Один пробел после категории
```
❌ ```Prime``` 95$
✅ ```Prime```  95$
```

### Ошибка 2: Группировка по эмиратам (как в турах)
```
❌ *Из Дубая:*
   ```General```  70$

✅ ```General Admission```  70$ взр / 45$ реб
   _базовый вход_
```

### Ошибка 3: Все ограничения в основной карточке
```
❌ ⚠️ *ВАЖНО*
   Минимум 12 лет, рост 120 см, вес до 120 кг
   Запрещено: беременность, эпилепсия, астма, диабет...
   Дресс-код: спортивная обувь, никаких юбок...
   [50 строк ограничений]

✅ ⚠️ *ВАЖНО*
   Минимум: 12 лет, рост от 120 см
   Дети до 16 лет — в сопровождении взрослого
   _Полные требования — в модуле ОГРАНИЧЕНИЯ_
```

### Ошибка 4: Эмодзи после заголовка
```
❌ *ЦЕНЫ* 💰
✅ 💰 *ЦЕНЫ*
```
