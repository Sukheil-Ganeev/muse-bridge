# МОДУЛЬ: РАСПИСАНИЕ И ВРЕМЯ ПОСЕЩЕНИЯ

---

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

### Когда отправлять:
- Когда клиент спрашивает "когда лучше посетить?"
- При вопросах о времени работы по дням
- При вопросах о сезонности и погоде
- При планировании визита на конкретную дату
- Когда важны слоты времени (Prime/Non-Prime)

### Отличие от основной карточки:
- Основная карточка: краткое время работы
- Модуль РАСПИСАНИЕ: детали по дням, сезонам, рекомендации

## 3. СЕКЦИЯ: ЧАСЫ РАБОТЫ

### Формат:
```
*ЧАСЫ РАБОТЫ*
Пн — Пт: 09:00 — 18:00
Сб — Вс: 08:00 — 20:00
_Последний вход за 1 час до закрытия_
```

### Варианты записи:

**Одинаковое время:**
```
*ЧАСЫ РАБОТЫ*
Ежедневно: 09:00 — 22:00
_Последний вход: 21:00_
```

**Разное по дням:**
```
*ЧАСЫ РАБОТЫ*
Пн — Чт: 10:00 — 22:00
Пт: 14:00 — 23:00
Сб — Вс: 10:00 — 23:00
_Пт: открытие позже из-за молитвы_
```

**Сезонное:**
```
*ЧАСЫ РАБОТЫ*

_Зима (окт — апр):_
Ежедневно: 09:00 — 18:00

_Лето (май — сен):_
Ежедневно: 06:00 — 11:00, 16:00 — 20:00
_Закрыто в самое жаркое время_
```

**Несколько зон:**
```
*ЧАСЫ РАБОТЫ*

_Аквапарк:_
Ежедневно: 09:00 — 17:30

_Аквариум:_
Ежедневно: 10:00 — 21:00

_Пляж:_
Ежедневно: 09:00 — закат
```

### Важно указывать:
- Последний вход
- Исключения (пятница, праздники)
- Разницу между зонами

## 4. СЕКЦИЯ: СЛОТЫ ВРЕМЕНИ

### Когда нужна:
- Для аттракционов с тарифами Prime/Non-Prime
- Для мест с бронированием по слотам

### Формат:
```
*СЛОТЫ ВРЕМЕНИ*

_Non-Prime (стандартная цена):_
07:00–15:30, 20:00–00:00

_Prime (повышенная цена):_
16:00–19:00
```

### Варианты:

**Для смотровых площадок:**
```
*СЛОТЫ ВРЕМЕНИ (124-125 этаж)*

_Non-Prime:_
Утро: 07:00–15:30
Вечер: 20:00–00:00

_Prime:_
Закат: 16:00–19:00

*СЛОТЫ ВРЕМЕНИ (148 этаж)*

_Non-Prime:_
09:00–11:00, 21:00–23:00

_Prime:_
12:00–20:00
```

**Для шоу/представлений:**
```
*СЕАНСЫ*

_Будние дни:_
11:00, 14:00, 17:00, 20:00

_Выходные:_
10:00, 12:00, 14:00, 16:00, 18:00, 20:00

_Длительность:_ 45 минут
```

## 5. СЕКЦИЯ: ЛУЧШЕЕ ВРЕМЯ ДЛЯ ПОСЕЩЕНИЯ

### Формат:
```
*ЛУЧШЕЕ ВРЕМЯ ДЛЯ ПОСЕЩЕНИЯ*

_Меньше людей:_
Раннее утро, поздний вечер, будние дни

_Лучшие фото:_
Закат (золотой час)

_Избегать:_
Выходные днём, праздники
```

### Расширенный вариант:

```
*ЛУЧШЕЕ ВРЕМЯ ДЛЯ ПОСЕЩЕНИЯ*

_Для избежания толп:_
Раннее утро (до 10:00) — минимум людей
Поздний вечер (после 20:00) — ночные виды
Будние дни предпочтительнее выходных

_Для лучших фотографий:_
Закат (16:00–18:30) — золотой час, но много людей
Рассвет (выходные с 05:00) — эксклюзивный опыт
Ночь (после 20:00) — огни города

_Избегать:_
Сб — Вс днём (максимум посетителей)
Праздники ОАЭ
Школьные каникулы
```

### По типу активности:

**Для аквапарков:**
```
_Меньше людей:_
Будни, раннее утро (к открытию)

_Комфортнее всего:_
Зима (окт — апр) — не так жарко
Утренние часы летом

_Избегать:_
Выходные, праздники, летние каникулы
```

**Для пустынных активностей:**
```
_Лучшее время:_
Окт — апр (комфортная температура)
Закатные туры (красивые виды, не жарко)

_Избегать:_
Май — сен днём (слишком жарко, +45°C)
```

## 6. СЕКЦИЯ: СЕЗОННОСТЬ

### Формат:
```
*СЕЗОННОСТЬ*

_Высокий сезон (окт — апр):_
Больше посетителей, бронировать заранее, комфортная погода

_Низкий сезон (май — сен):_
Меньше людей, жарко, некоторые активности ограничены
```

### Расширенный вариант:

```
*СЕЗОННОСТЬ*

_Пик сезона (дек — фев):_
Максимум туристов, бронировать за неделю+
Погода идеальная (20–25°C)
Цены могут быть выше

_Средний сезон (окт — ноя, мар — апр):_
Комфортно, меньше людей чем в пик
Хорошее время для посещения

_Низкий сезон (май — сен):_
Минимум посетителей, нет очередей
Очень жарко (35–45°C)
Некоторые outdoor-активности закрыты или ограничены
```

## 9. ПРАВИЛА ФОРМАТИРОВАНИЯ

### Заголовок модуля:
- Используйте `🕐 *РАСПИСАНИЕ*` (эмодзи часов)
- Или без эмодзи: `*РАСПИСАНИЕ*`

### Время:
- Формат: `09:00 — 18:00` (с длинным тире и пробелами)
- Диапазон без пробелов: `07:00–15:30` (короткое тире)

### Символы:
- **Запятые** для перечислений
- **`|`** НЕ используется в этом модуле
- Подкатегории через `_курсив_`

### Структура:
- Разделители `───────────────` между крупными секциями
- Внутри секций — только пустые строки
