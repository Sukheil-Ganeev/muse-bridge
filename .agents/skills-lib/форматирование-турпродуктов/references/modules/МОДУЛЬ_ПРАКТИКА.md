# МОДУЛЬ: ПРАКТИЧЕСКИЕ СОВЕТЫ

---

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

### Когда отправлять:
- При бронировании (вместе с ОГРАНИЧЕНИЯМИ)
- Когда клиент спрашивает "что взять с собой?"
- При вопросах "как подготовиться?"
- Для активностей, требующих подготовки (дайвинг, прыжки, сафари)

### Отличие от ОГРАНИЧЕНИЙ:
- ОГРАНИЧЕНИЯ: что НЕЛЬЗЯ и ТРЕБУЕТСЯ
- ПРАКТИКА: что РЕКОМЕНДУЕТСЯ и ПОЛЕЗНО

## 3. СЕКЦИЯ: ЧТО ВЗЯТЬ

### Формат:
```
*ЧТО ВЗЯТЬ*
Обязательно: [список через запятую]
Рекомендуем: [список через запятую]
_Предоставляется: [что дадут на месте]_
```

### По типу активности:

**Аквапарки:**
```
*ЧТО ВЗЯТЬ*
Обязательно: купальник, сменную одежду
Рекомендуем: солнцезащитный крем (SPF 50+), солнцезащитные очки, головной убор
_Можно арендовать: полотенце (10$), шкафчик (15$)_
_Запрещено проносить: еду и напитки (кроме воды и детского питания)_
```

**Экстремальные активности:**
```
*ЧТО ВЗЯТЬ*
Обязательно: паспорт, подтверждение брони
Рекомендуем: сменную одежду, воду, лёгкий перекус (после)
_Предоставляется: всё оборудование, комбинезон, шлем_
_Оставить в шкафчике: украшения, часы, телефон_
```

**Смотровые площадки:**
```
*ЧТО ВЗЯТЬ*
Обязательно: подтверждение брони (QR-код), паспорт
Рекомендуем: камеру, удобную обувь
_Камеры хранения: есть у входа_
```

**Пустынные активности:**
```
*ЧТО ВЗЯТЬ*
Обязательно: паспорт
Рекомендуем: солнцезащитный крем, солнцезащитные очки, головной убор, шарф от песка
_Предоставляется: вода в машине, напитки в кемпе_
```

**Дайвинг/снорклинг:**
```
*ЧТО ВЗЯТЬ*
Обязательно: купальник, сертификат (для дайвинга)
Рекомендуем: полотенце, сменную одежду
_Предоставляется: всё оборудование, гидрокостюм, маска_
```

## 4. СЕКЦИЯ: ЧТО НАДЕТЬ

### Формат:
```
*ЧТО НАДЕТЬ*
Рекомендуем: [список через запятую]
_Для [особых условий]: [рекомендации]_
```

### Варианты:

**Для экстрима:**
```
*ЧТО НАДЕТЬ*
Рекомендуем: облегающая спортивная одежда, кроссовки на шнурках
_Длинные волосы: собрать в хвост/косу_
_Выдаётся: комбинезон поверх вашей одежды_
```

**Для аквапарков:**
```
*ЧТО НАДЕТЬ*
Рекомендуем: купальник, быстросохнущая футболка, аквашузы
_Для горок: плотно сидящий купальник (бикини может развязаться)_
_Рашгарды: рекомендуем для защиты от солнца_
```

**Для пустыни:**
```
*ЧТО НАДЕТЬ*
Рекомендуем: лёгкая закрытая одежда, удобная обувь
_Вечерние туры: может быть прохладно, возьмите кофту_
_Избегайте: открытую обувь (песок горячий)_
```

**Для ресторанов/ужинов:**
```
*ЧТО НАДЕТЬ*
Рекомендуем: smart casual, закрытая обувь
_Не допускается: пляжная одежда, шорты, сланцы_
```

## 5. СЕКЦИЯ: ПЕРЕД ВИЗИТОМ

### Формат:
```
*ПЕРЕД ВИЗИТОМ*
[Действие 1]
[Действие 2]
_Примечание_
```

### Варианты:

**Для экстремальных активностей:**
```
*ПЕРЕД ВИЗИТОМ*
Приехать за 1 час до времени прыжка
Не употреблять алкоголь за 24 часа
Не есть тяжёлую пищу за 2 часа
Выспаться накануне
_Брифинг и подготовка занимают 30–45 минут_
```

**Для парков:**
```
*ПЕРЕД ВИЗИТОМ*
Приехать к открытию (09:00) — меньше людей
Зарядить телефон (карты, фото)
Скачать приложение парка
_Позавтракать заранее — еда в парке дорогая_
```

**Для смотровых:**
```
*ПЕРЕД ВИЗИТОМ*
Приехать за 30 минут до забронированного слота
Подготовить QR-код брони
_Опоздание более 30 минут — билет сгорает_
```

**Для дайвинга:**
```
*ПЕРЕД ВИЗИТОМ*
Не летать за 24 часа ДО погружения
Не нырять за 24 часа ДО полёта
Выспаться, не употреблять алкоголь
_Медицинская анкета заполняется на месте_
```

## 6. СЕКЦИЯ: ЛАЙФХАКИ

### Формат:
```
*ЛАЙФХАКИ*
[Совет 1]
[Совет 2]
[Совет 3]
```

### По типу:

**Для парков:**
```
*ЛАЙФХАКИ*
Приезжайте к открытию — первые 2 часа минимум очередей
Берите шкафчик в центре парка (не у входа) — удобнее
Начинайте с дальних аттракционов — там меньше людей
Скачайте приложение для карты и времени ожидания
Waterproof чехол для телефона — must have
```

**Для экстрима:**
```
*ЛАЙФХАКИ*
Бронируйте утренние слоты — меньше ветра
Возьмите видео-пакет — своим телефоном снять не получится
Оденьтесь в яркое — лучше видно на видео
После прыжка останьтесь на территории — кафе с видом на дропзону
```

**Для смотровых:**
```
*ЛАЙФХАКИ*
Закат красивый, но много людей — выбирайте вечер (после 20:00)
Телескопы бесплатные — не стесняйтесь использовать
Фонтан Dubai Fountain виден сверху — расписание каждые 30 мин с 18:00
Выходные с 05:00 — эксклюзивный рассвет, почти никого
```

**Для аквапарков:**
```
*ЛАЙФХАКИ*
Водные носки (water socks) выдают бесплатно у Guest Services
Кабана окупается для компании 4+ человек
Горки Poseidon/Neptune — максимум адреналина, но очередь 30+ мин
Lazy River — идеально для отдыха между горками
Splashers (детская зона) — там меньше людей даже в пик
```

## 8. ПРАВИЛА ФОРМАТИРОВАНИЯ

### Заголовок модуля:
- `✅ *ПРАКТИЧЕСКИЕ СОВЕТЫ*` (с эмодзи галочки)
- Или без эмодзи: `*ПРАКТИЧЕСКИЕ СОВЕТЫ*`

### Символы:
- **Запятые** для перечислений
- **`|`** НЕ используется в этом модуле
- Подкатегории через `_курсив_`

### Структура:
- Разделитель `───────────────` перед ЛАЙФХАКИ
- Внутри секций — без разделителей

### Порядок секций:
1. Что взять
2. Что надеть
3. Перед визитом
4. Лайфхаки
