## 4. БЛОК ЦЕНЫ ДЛЯ ПИТАНИЯ

> **КРИТИЧНО:** Группировка по ПАКЕТАМ (НЕ по эмиратам!)

### ОТЛИЧИЕ ОТ ТУРОВ:
- **ТУРЫ:** группировка по эмиратам (`*Из Дубая:*`)
- **ПИТАНИЕ:** группировка по пакетам (` ```Трансфер + ужин``` `)

```
💰 *ЦЕНЫ*

```Пакет 1: Трансфер + ужин```  250$ взр / 225$ реб
_стандартный комфортный трансфер из Дубая, Шарджи, Аджмана_

```Пакет 2: VIP-трансфер + ужин```  350$ взр / 325$ реб
_премиум автомобили (S/V Class, Land Cruiser 300), до 6 пассажиров_

```Пакет 3: Сафари + ужин```  350$ взр / 325$ реб
_сафари по дюнам на Land Cruiser 300 + ужин_
```

### ПРАВИЛА:
1. Каждый пакет = ` ```категория``` ` + цена
2. ДВА ПРОБЕЛА после ` ```пакета``` ` перед ценой
3. В курсиве под каждым пакетом — что входит
4. Пустая строка между пакетами

## 6. ПРАВИЛА ФОРМАТИРОВАНИЯ

### Разделители (15 тире):
`───────────────` — ТОЛЬКО между крупными блоками

### Символы:
- `|` — ТОЛЬКО для служебных блоков (дни, оплата, отмена)
- `,` — для всех остальных перечислений
- `→` — с пробелами: ` → `
- `—` — с пробелами: ` — `

### Эмодзи (только 2 для питания):
- 💰 перед *ЦЕНЫ*
- ⚠️ перед *ВАЖНО*
- (➕ ОПЦИИ обычно не используется в питании)

### Цены:
- `250$` (доллар после числа, без пробела)
- `250$ взр / 225$ реб`
