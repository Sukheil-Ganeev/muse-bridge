# МОДУЛЬ: ЧАСТЫЕ ВОПРОСЫ (FAQ)

---

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

### Когда отправлять:
- Когда клиент задаёт типичный вопрос
- Для быстрых ответов без полного описания
- Как дополнение к основной карточке

### Особенность:
- FAQ можно отправлять ЧАСТИЧНО (только релевантные вопросы)
- Или ПОЛНОСТЬЮ как справочник

## 3. ФОРМАТ ВОПРОСОВ

### Правильный формат:
```
*Вопрос?*
Краткий ответ. Дополнение если нужно.
```

### Правила:
1. Вопрос в `*жирном*` с вопросительным знаком
2. Ответ на следующей строке, обычным текстом
3. Пустая строка между вопросами
4. Ответ — 1–2 предложения максимум

## 6. ПРАВИЛА ФОРМАТИРОВАНИЯ

### Заголовок модуля:
- `❓ *ЧАСТЫЕ ВОПРОСЫ*` (с эмодзи вопроса)
- Или: `*FAQ*`

### Вопросы:
- В `*жирном*` с `?`
- Короткие, разговорные
- Как спросил бы клиент

### Ответы:
- Без форматирования (обычный текст)
- 1–2 предложения
- Конкретно и по делу

### Структура:
- Один разделитель `───────────────` после заголовка
- Пустая строка между вопросами
- Без разделителей между вопросами
