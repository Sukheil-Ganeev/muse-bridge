## 1. ВВЕДЕНИЕ И ФИЛОСОФИЯ

### Ключевые принципы форматирования

Форматирование текста должно обеспечивать:
- **Читаемость** — информация воспринимается легко и быстро
- **Структурность** — чёткая иерархия и группировка
- **Единообразие** — одинаковые элементы оформляются одинаково
- **Компактность** — максимум информации при минимуме текста

## 4. БАЗОВЫЕ ЭЛЕМЕНТЫ ФОРМАТИРОВАНИЯ

### 4.1. ТИПОГРАФИКА

| Стиль | Синтаксис | Применение | Пример |
|-------|-----------|------------|--------|
| **Жирный** | `*текст*` | Заголовки секций, подзаголовки, группировки | *ЦЕНЫ* |
| _Курсив_ | `_текст_` | Описания, пояснения, уточнения | _включено питание_ |
| `Моно` | ` ```текст``` ` | Категории, возрастные группы | ```Базовая``` |

### 4.2. РАЗДЕЛИТЕЛИ И СИМВОЛЫ

| Символ | Название | Правило | Пример |
|--------|----------|---------|--------|
| `\|` | Вертикальная черта | ТОЛЬКО для служебных блоков: дни, оплата, отмена. С пробелами | `USD \| AED \| USDT` |
| `/` | Слэш | Дни недели и цены, С ПРОБЕЛАМИ | `50$ взр / 30$ реб` |
| `→` | Стрелка | Маршруты, ВСЕГДА с пробелами | `Дубай → Абу-Даби` |
| `—` | Длинное тире | Условия, ВСЕГДА с пробелами | `5ч — с обедом` |
| `───────────────` | Крупный разделитель | ТОЛЬКО между основными блоками (15 символов) | см. ниже |

#### ВАЖНО: Когда использовать `|`, а когда запятую

**`|` — ТОЛЬКО для служебных блоков:**
- Дни недели: `пн | ср | пт`
- Способы оплаты: `USD | Рубли СПБ | AED | USDT`
- Условия отмены: `За 48ч — 100% | За 24ч — 50%`

**Запятая — для всех остальных перечислений:**
- Что включено: `Ужин-буфет, вода, шоу`
- Требования: `Минимум 12 лет, рост от 120 см`
- Противопоказания: `Беременность, эпилепсия, астма`
- Предоставляется: `Гидрокостюм, шлем, полотенца`

#### Крупный разделитель (15 тире)
```
───────────────
```
Используется ТОЛЬКО для разделения крупных блоков информации.

### 4.3. ЭМОДЗИ

**Разрешены только 3 эмодзи:**

| Эмодзи | Назначение | Правило размещения |
|--------|------------|-------------------|
| 💰 | Перед секцией ЦЕНЫ | Эмодзи ПЕРЕД звёздочкой |
| ➕ | Перед секцией ОПЦИИ | Эмодзи ПЕРЕД звёздочкой |
| ⚠️ | Перед секцией ВАЖНО | Эмодзи ПЕРЕД звёздочкой |

**Правильно:** `💰 *ЦЕНЫ*`
**Неправильно:** `*💰 ЦЕНЫ*` или `*ЦЕНЫ* 💰`

### 4.4. ФОРМАТЫ ЦЕН И СОКРАЩЕНИЙ

#### Цены

| Формат | Пример | Комментарий |
|--------|--------|-------------|
| Базовый | `50$` | Доллар ПОСЛЕ числа, БЕЗ пробела |
| С категориями | `50$ взр / 30$ реб` | Используйте сокращения |
| Диапазон | `50–80$` | Короткое тире БЕЗ пробелов |

#### Сокращения

| Полная форма | Сокращение |
|--------------|------------|
| взрослый | взр |
| ребёнок | реб |
| человек | чел |
| часов | ч |

#### Возраст

| Формат | Пример |
|--------|--------|
| От возраста | `(3+)` |
| До возраста | `(8+)` |
| Диапазон | `(3–11,99)` |

#### Время

| Формат | Пример | Комментарий |
|--------|--------|-------------|
| Продолжительность | `5ч`, `8ч` | БЕЗ точки после "ч" |
| Временной интервал | `14:00–15:00` | Короткое тире БЕЗ пробелов |

## 5. КРИТИЧНЫЕ ПРАВИЛА

### Правило двух пробелов

**КРИТИЧНО:** После ` ```категории``` ` перед ценой — ДВА ПРОБЕЛА!

**Правильно:**
```
```Базовая```  50$ взр / 35$ реб
```

**Неправильно:**
```
```Базовая``` 50$ взр / 35$ реб
```

### Правила пробелов для разделителей

| Разделитель | Правило | Правильно | Неправильно |
|-------------|---------|-----------|-------------|
| `\|` | Пробелы с обеих сторон | `A \| B` | `A\|B` |
| `/` | Пробелы с обеих сторон | `A / B` | `A/B` |
| `→` | Пробелы с обеих сторон | `A → B` | `A→B` |
| `—` | Пробелы с обеих сторон | `A — B` | `A—B` |

## 6. ИТОГОВЫЕ ПРИНЦИПЫ

### ДЕЛАЙТЕ

- Используйте `|` ТОЛЬКО для служебных блоков (дни, оплата, отмена)
- Все остальные перечисления — через запятую
- Используйте сокращения (взр/реб, ч)
- Группируйте по смыслу
- Ставьте пустые строки между категориями
- Следуйте правилам пробелов СТРОГО

### НЕ ДЕЛАЙТЕ

- Не убирайте разделители между блоками
- Не объединяйте разные опции в одну строку
- Не жертвуйте иерархией заголовков
- Не добавляйте лишние эмодзи
- Не перечисляйте все блюда в основном описании
