# МОДУЛЬ: ЛОКАЦИЯ И КАК ДОБРАТЬСЯ

---

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

### Когда отправлять:
- Когда клиент спрашивает "как добраться?"
- При вопросах о парковке
- При вопросах о транспорте (метро, такси)
- Когда клиент едет самостоятельно (без трансфера)

### Отличие от основной карточки:
- Основная карточка: НЕ содержит локацию
- Модуль ЛОКАЦИЯ: полная информация о месте и транспорте

## 4. СЕКЦИЯ: КАК ДОБРАТЬСЯ

### На машине:

```
_На машине:_
Sheikh Zayed Road (E11) → Выезд 34 на Palm Jumeirah → Crescent Road до Atlantis
_Время в пути: 30–45 мин из центра Дубая_
```

**Расширенный вариант:**
```
_На машине:_

Из Dubai Marina:
Al Sufouh Road → Palm Jumeirah → Crescent Road
_15–20 минут_

Из Downtown:
Sheikh Zayed Road → Выезд 34 → Palm Jumeirah
_25–35 минут_

Из Дейры:
Al Maktoum Bridge → Sheikh Zayed Road → Выезд 34
_35–45 минут_
```

### На метро:

```
_На метро:_
Красная линия → станция Burj Khalifa/Dubai Mall
Выход: LG уровень к Dubai Mall
_5 минут пешком до входа At The Top_
```

**С пересадками:**
```
_На метро:_
Красная линия → станция DMCC
Зелёная линия → станция Dubai Marina

_Затем:_ монорейл Palm Gateway → Atlantis
_Или:_ такси 15 мин / 30–40 AED
```

### На такси:

```
_На такси:_
Из Dubai Marina: 15–25 мин, ~40–60 AED
Из Downtown: 25–35 мин, ~60–80 AED
Из Дейры: 35–45 мин, ~80–100 AED
_Рекомендуем: Uber, Careem, RTA Taxi_
```

### На монорейле:

```
_На монорейле Palm:_
Palm Gateway Station → Atlantis Aquaventure Station
_6 минут, каждые 15 минут_
_Цена: 30 AED в одну сторону_
```

### На автобусе:

```
_На автобусе:_
Маршрут 8 от Mall of the Emirates
_Остановка: Dubai Mall_
_Интервал: каждые 15 минут_
```

## 5. СЕКЦИЯ: ПАРКОВКА

### Формат:
```
*ПАРКОВКА*

_Бесплатная:_
Парковка Aquaventure, рядом с входом
_Бесплатный шаттл до аквапарка_

_Платная:_
10 AED/час в зоне AA/AB
Первые 3 часа бесплатно на Palm Beach West

_Valet:_
50 AED, у входа The Avenues
```

### Расширенный вариант:

```
*ПАРКОВКА*

_Бесплатная парковка Aquaventure:_
Поверните направо на первом круговом перекрестке после тоннеля
Бесплатный шаттл до Ticketing Plaza

_Альтернативные бесплатные:_
Nasimi Beach (мало мест в сезон)
Al Ittihad Park

_Платная в Atlantis Resort:_
Зона AA/AB: 10 AED/час
Palm Beach West: первые 3ч бесплатно, далее 10 AED/час

_Valet Parking:_
50 AED у входа The Avenues
_Валидация в ресторанах_
```

### Только платная:

```
*ПАРКОВКА*

_Dubai Mall Parking:_
Первые 4 часа бесплатно
Далее 20 AED/час
_Более 7000 мест, вход с Financial Centre Road_

_Valet:_
100 AED, у главного входа
```

## 7. ПРАВИЛА ФОРМАТИРОВАНИЯ

### Заголовок модуля:
- `📍 *ЛОКАЦИЯ*` (с эмодзи геолокации)
- Или без эмодзи: `*ЛОКАЦИЯ*`

### Адреса:
- Полный адрес на отдельных строках
- Ориентиры в `_курсиве_`

### Время и стоимость:
- Время: `15–20 минут`
- Стоимость такси: `~40–60 AED`
- Парковка: `10 AED/час`

### Символы:
- **Запятые** для перечислений
- **`|`** НЕ используется в этом модуле
- Подкатегории через `_курсив_`
