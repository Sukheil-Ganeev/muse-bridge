## 3. СЕКЦИЯ: БАЗОВЫЕ БИЛЕТЫ

### Формат:
```
*БАЗОВЫЕ БИЛЕТЫ*

```Категория```  цена$ взр / цена$ реб
_включено: что входит_
```

### Правила:
1. **ДВА ПРОБЕЛА** после ``` ```категории``` ```
2. Цена: `70$ взр / 45$ реб`
3. Описание в `_курсиве_` под ценой
4. Пустая строка между категориями

2. Комбо-пакеты
