## 3. БЛОК ЦЕНЫ ДЛЯ ТУРОВ

> **КРИТИЧНО:** Группировка по ЭМИРАТАМ!

### Структура:
```
💰 *ЦЕНЫ* ```(дети 3–11,99)```

*Из [Эмират 1]:*
```Категория 1```  цена$ взр / цена$ реб
_что включено/не включено_

```Категория 2```  цена$ взр / цена$ реб
_описание_

*Из [Эмират 2]:*
```Категория```  цена$ взр / цена$ реб
```

### ПРАВИЛА:
1. **Группировка:** `*Из [место]:*` в жирном
2. **Категории:** ``` ```Категория``` ``` (ДВА ПРОБЕЛА перед ценой!)
3. **Формат цен:** `50$ взр / 35$ реб`
4. **Описание:** `_курсивом_` под ценой
5. **Пустая строка** между категориями

## 4. БЛОК ОПЦИИ ДЛЯ ТУРОВ

```
➕ *ОПЦИИ* ```(по желанию)```

*Объект/Локация:*
Название опции: цена$ (возраст)
Другая опция: цена$ (возраст)

*Другой объект:*
Опция: цена$ (возраст)

_Стоимость за билет_
```

### ПРАВИЛА:
1. **Группировка по объектам:** `*Объект:*` в жирном
2. **Каждая опция на ОТДЕЛЬНОЙ строке** (НЕ через |)
3. **Формат:** `Название: цена$ (возраст)`

---

## 5. ПРАВИЛА ФОРМАТИРОВАНИЯ

### Разделители (15 тире):
```
───────────────
```
Используются ТОЛЬКО между крупными блоками

### Символы:
| Символ | Использование | Пример |
|--------|---------------|--------|
| `\|` | ТОЛЬКО служебные блоки (дни, оплата, отмена) | `USD \| AED` |
| `,` | Все остальные перечисления | `Гид, транспорт, обед` |
| `/` | с пробелами в днях и ценах | `пн / ср / пт` |
| `→` | с пробелами | ` → ` |
| `—` | с пробелами | ` — ` |

### Эмодзи (только 3):
- 💰 перед `*ЦЕНЫ*`
- ➕ перед `*ОПЦИИ*`
- ⚠️ перед `*ВАЖНО*`

### Цены:
- `50$` (доллар после числа, без пробела)
- `50$ взр / 30$ реб`

## 8. ТИПИЧНЫЕ ОШИБКИ

### Ошибка 1: Один пробел после категории
```
❌ ```Базовая``` 50$
✅ ```Базовая```  50$
```

### Ошибка 2: Опции через |
```
❌ 124 этаж: 70$ | 148 этаж: 155$
✅ 124 этаж: 70$ (8+)
   148 этаж: 155$ (3+)
```

### Ошибка 3: Эмодзи после заголовка
```
❌ *ЦЕНЫ* 💰
✅ 💰 *ЦЕНЫ*
```

### Ошибка 4: Без группировки по эмиратам
```
❌ ```Базовая``` 50$ взр / 35$ реб
   ```Групповая``` 85$ взр / 60$ реб

✅ *Из Дубая, Шарджи, Аджмана:*
   ```Базовая``` 50$ взр / 35$ реб

   *Из Абу-Даби:*
   ```Групповая``` 85$ взр / 60$ реб
```

### Ошибка 5: Отсутствие пробелов вокруг символов
```
❌ пн/ср/пт
✅ пн / ср / пт

❌ Точка1→Точка2
✅ Точка1 → Точка2
```

### Ошибка 6: Разделители внутри блоков

Разделители `───────────────` ставятся ТОЛЬКО между крупными блоками, НЕ внутри блока *ВАЖНО*!

```
❌ НЕПРАВИЛЬНО:
⚠️ *ВАЖНО*
Минимум от 2 человек
───────────────
*ОПЛАТА*
USD | AED
───────────────
*ОТМЕНА*
За 24ч — 100%

✅ ПРАВИЛЬНО:
⚠️ *ВАЖНО*
Минимум от 2 человек

*ОПЛАТА*
USD | Рубли СПБ | AED (курс 3.65) | USDT

*ОТМЕНА*
За 48ч — 100% возврат | За 24ч — 50% | Менее 24ч — без возврата
_Билеты — возврат по политике компании-поставщика_
```

**Правило:** Внутри блока ВАЖНО между подсекциями (*ОПЛАТА*, *ОТМЕНА*, *ДЛЯ ОФОРМЛЕНИЯ*) — только пустые строки, БЕЗ разделителей!
