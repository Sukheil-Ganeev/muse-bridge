# Типичные ошибки форматирования

Этот документ содержит список самых частых ошибок при форматировании турпродуктов и способы их исправления.

---

## Ошибка 1: Один пробел после категории

### Проблема:
```
```Базовая``` 50$
```Премиум``` 100$
```

### Решение:
```
```Базовая```  50$
```Премиум```  100$
```

### Почему критично:
- Визуальное выравнивание цен нарушается
- Описания выглядят неряшливо
- Нарушается единообразие всех документов

### Как запомнить:
> После закрывающих кавычек ` ``` ` ВСЕГДА ставь ДВА пробела перед ценой

## Ошибка 2: Опции через разделитель |

### Проблема:
```
124 этаж: 70$ | 148 этаж: 155$
Silver: 89$ | Gold: 129$ | VIP: 199$
```

### Решение:
```
```124 этаж```  70$
```148 этаж```  155$
```

или

```
*Silver Package:*  89$
*Gold Package:*  129$
*VIP Package:*  199$
```

### Почему критично:
- На мобильных устройствах строка переносится некрасиво
- Сложно быстро найти нужную цену
- Невозможно добавить детали к каждой опции

## Ошибка 3: Заголовки без звёздочек

### Проблема:
```
СТОИМОСТЬ

Из Дубая:
Взрослый  185$
```

### Решение:
```
💰 *СТОИМОСТЬ*

*Из Дубая:*
```Взрослый```  185$
```

### Почему критично:
- Заголовки не выделяются визуально
- Структура документа не читается
- В WhatsApp всё сливается в сплошной текст

---

## Ошибка 4: Разные возрасты в одной строке

### Проблема:
```
```Ребёнок 3-11 / инфант 0-2 бесплатно```  45$
```Дети от 3 до 11 лет, младше бесплатно```  45$
```

### Решение:
```
```Ребёнок 3-11```  45$
```Ребёнок 0-2```  бесплатно
```

### Почему критично:
- Неясно, какая цена к какому возрасту относится
- Длинные строки плохо читаются
- Невозможно быстро найти нужную категорию

---

## Ошибка 5: Использование неправильных кавычек

### Проблема:
```
'Взрослый'  50$
"Ребёнок"  35$
«VIP»  100$
```

### Решение:
```
```Взрослый```  50$
```Ребёнок```  35$
```VIP```  100$
```

### Почему критично:
- Обычные кавычки не создают моноширинный шрифт в WhatsApp
- Форматирование не применяется
- Документ выглядит непрофессионально

### Правильные символы:
- WhatsApp: ` ``` ` (обратные кавычки, 3 штуки с каждой стороны)
- Telegram: НЕ использовать моноширинный для категорий!

## Ошибка 6: Лишние эмодзи

### Проблема:
```
🌴 *САФАРИ В ПУСТЫНЕ* 🐪

🚗 Трансфер включён
🍽️ Ужин-барбекю
💃 Шоу танца живота
🐫 Катание на верблюдах

💵 *ЦЕНЫ* 💰
```

### Решение:
```
*САФАРИ В ПУСТЫНЕ*

_Трансфер, ужин-барбекю, шоу танца
живота, катание на верблюдах_

💰 *СТОИМОСТЬ*
```

### Почему критично:
- Избыток эмодзи отвлекает от информации
- Выглядит несерьёзно и непрофессионально
- Сложнее найти важную информацию

### Разрешённые эмодзи (только 3):
- 💰 — цены
- ➕ — включено
- ⚠️ — важно

## Ошибка 7: Отсутствие пустых строк

### Проблема:
```
💰 *СТОИМОСТЬ*
*Из Дубая:*
```Взрослый```  185$
```Ребёнок```  155$
*Из Абу-Даби:*
```Взрослый```  165$
───────────────
➕ *ЧТО ВКЛЮЧЕНО*
```

### Решение:
```
💰 *СТОИМОСТЬ*

*Из Дубая:*
```Взрослый```  185$
```Ребёнок```  155$

*Из Абу-Даби:*
```Взрослый```  165$

───────────────

➕ *ЧТО ВКЛЮЧЕНО*
```

### Почему критично:
- Текст сливается в нечитаемую массу
- Нет визуального разделения блоков
- Клиенту сложно найти нужную информацию

## Ошибка 8: Неправильный разделитель

### Проблема:
```
----------
==========
**********
___________
- - - - - -
```

### Решение:
```
───────────────     (WhatsApp: 15 символов)
──────────────────  (Telegram: 18 символов)
```

### Почему критично:
- Дефисы `-` выглядят как пунктир
- Другие символы не создают сплошную линию
- Нарушается визуальное единообразие

### Как получить правильный символ:
- Символ: `─` (горизонтальная черта, код U+2500)
- Или скопировать из этого документа

## Ошибка 9: Смешение форматов WhatsApp и Telegram

### Проблема (в WhatsApp):
```
**ЗАГОЛОВОК**
__описание__
```

### Проблема (в Telegram):
```
*ЗАГОЛОВОК*
```категория```  цена
```

### Решение:

**Для WhatsApp:**
```
*ЗАГОЛОВОК*
_описание_
```категория```  цена
```

**Для Telegram:**
```
**ЗАГОЛОВОК**
__описание__
**категория** — цена
```

### Почему критично:
- Форматирование просто не применится
- Клиент увидит звёздочки и подчёркивания как текст
- Описание выглядит сломанным

## Ошибка 10: Неконсистентные названия категорий

### Проблема:
```
```Взрослый```  185$
```ребенок 3-11```  155$
```Дети```  155$
```взр```  185$
```

### Решение:
```
```Взрослый```  185$
```Ребёнок 3-11```  155$
```

### Почему критично:
- Разные названия одной категории путают
- Клиент не понимает, это одно и то же или разное
- Документ выглядит непрофессионально

### Стандартные названия:
- `Взрослый` (не "взр", не "взрослые")
- `Ребёнок 3-11` (не "дети", не "ребенок")
- `Инфант 0-2` или `Ребёнок 0-2`

## Ошибка 11: Цена без валюты

### Проблема:
```
```Взрослый```  185
```Ребёнок```  155
```

### Решение:
```
```Взрослый```  185$
```Ребёнок```  155$
```

### Почему критично:
- Неясно, какая валюта
- Может быть путаница (доллары? дирхамы? евро?)
- Клиент вынужден уточнять

---

## Ошибка 12: Меню в основном файле (для питания)

### Проблема:
Один файл с ценами И детальным меню на 50+ блюд

### Решение:
Два отдельных файла:
1. `Ресторан_основное.txt` — цены, условия
2. `Ресторан_меню.txt` — детальное меню

### Почему критично:
- Основной файл становится слишком длинным
- Клиенту сложно найти цены среди меню
- Меню часто обновляется отдельно от цен

## Чек-лист перед отправкой

Проверь документ по этому списку:

- [ ] Заголовки выделены `*звёздочками*`
- [ ] После категорий ДВА пробела
- [ ] Каждая опция на отдельной строке
- [ ] Пустые строки между блоками
- [ ] Разделитель из символов `─` (не дефисы)
- [ ] Эмодзи только 💰 ➕ ⚠️
- [ ] Валюта указана везде
- [ ] Категории названы единообразно
- [ ] Формат соответствует платформе (WA/TG)
- [ ] Для питания — два файла
