# Предупреждение: синхронизация документации

## Дата: 2026-02-21

## Что НЕ делать
Не создавай README отдельно от CLAUDE.md и CHANGELOG.md. Они ДОЛЖНЫ быть синхронизированы.

## Что произошло
Создали README на v5.0.1. Потом за сессию добавили 30+ фич (v5.1, v5.2). README стал устаревшим через час после создания.

## Правильный подход
После добавления новых фич — запускай 3 субагента ПАРАЛЛЕЛЬНО:
1. Обновить README (новые команды, метрики, фичи)
2. Обновить CLAUDE.md (версии, структура, "что работает")
3. Обновить CHANGELOG.md (новые записи версий)

## Чеклист перед завершением сессии:
- [ ] README актуален? (количество команд, тестов, фич)
- [ ] CLAUDE.md актуален? (версии, структура файлов)
- [ ] CHANGELOG.md актуален? (все изменения записаны)
