# Скилл: README мирового уровня

## Описание
Создание профессиональных README.md файлов уровня Google, Meta, Anthropic для любого проекта.

## Структура
```
readme-проекты/
├── SKILL.md              # Основной скилл (процесс + шаблоны)
├── README.md             # Это описание
└── references/
    ├── cheatsheet.md     # Шпаргалка по badges и markdown
    └── examples.md       # Примеры из реальных проектов
```

## Использование
Скажи: "создай readme", "сделай ридми проекта", "обнови readme"

## Процесс
1. **Волна 1** — 2 субагента параллельно: исследование практик + сбор метрик
2. **Волна 2** — 1 субагент: создание README по шаблону 17 секций
3. **Результат** — ~500 строк, badges, mermaid, collapsible, roadmap
