# Definition of Done — VIP-DXB-CatalogBot

Фича или фикс считается завершёнными только когда ВСЕ применимые пункты отмечены.
Нельзя говорить "готово" пока этот чеклист не пройден.

---

## Тесты

- [ ] Тесты написаны ДО кода (или одновременно) — не после
- [ ] Есть тест на happy path (основной сценарий работает)
- [ ] Есть тест на not found / пустой результат
- [ ] Есть тест на invalid input / ошибку
- [ ] Есть тест на auth/permissions (если есть роли)
- [ ] Coverage >= 80% для новых файлов (`--cov-fail-under=80`)
- [ ] Нет пропущенных тестов для критичных DB-операций (unit мока недостаточно — нужен integration с TEST_DATABASE_URL)
- [ ] Общий тест-счёт не упал ниже baseline (`pytest --collect-only -q`)

## Качество кода

- [ ] 0 новых type errors (`mypy [module] --ignore-missing-imports`)
- [ ] 0 неиспользуемых импортов (`python -m pyflakes [module]`)
- [ ] Нет debug statements: `print("debug")`, `pdb.set_trace()`, `breakpoint()`
- [ ] Нет временных TODO/FIXME без тикета или обоснования
- [ ] `cleanup` прогнан по изменённым файлам

## Логирование

- [ ] Новый хэндлер/функция логирует входящее событие: `logger.info(f"[module] event: {details}")`
- [ ] Логирует результат или ошибку: `logger.info(f"[module] result: {result}")` / `logger.error(f"[module] error: {e}")`
- [ ] Формат: `[module] action: details` (как в CLAUDE.md)

## Безопасность

- [ ] Пользовательский ввод экранирован (`html.escape()` в Telegram/MiniApp)
- [ ] HMAC-SHA256 проверяется на входящих webhook (IG/WA/FB/Viber)
- [ ] Нет хардкоженных секретов в коде (всё через `.env`)
- [ ] DB-метод использует asyncpg `$1/$2` параметры (не `?` и не f-string с user input)

## База данных

- [ ] Новые миграции идемпотентны (`CREATE TABLE IF NOT EXISTS`, `IF NOT EXISTS` для колонок)
- [ ] Новые таблицы имеют `created_at TIMESTAMPTZ DEFAULT NOW()`
- [ ] Индексы добавлены для FK и часто фильтруемых полей
- [ ] Нет прямых `db._db.execute()` — только методы `CatalogDB` или asyncpg pool

## Документация

- [ ] `CLAUDE.md` обновлён (если изменилось поведение, архитектура, DB-схема, паттерн)
- [ ] Платформенный `*_bot/CLAUDE.md` обновлён (если затронута конкретная платформа)
- [ ] `AGENTS.md` проверен (нужно ли обновить правила для агентов)

## Деплой

- [ ] `git status --short` проверен (нет лишних файлов в коммите)
- [ ] `.env` и `*.db` файлы НЕ закоммичены
- [ ] `quality-loop: verify` выполнен → статус SAFE TO DEPLOY

---

**Правило:** если хотя бы один применимый пункт не отмечен → задача НЕ завершена.
Исключение только по явному решению с записанным обоснованием (технический долг с тикетом).
