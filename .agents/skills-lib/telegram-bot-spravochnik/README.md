# telegram-bot-справочник

Production-ready справочник по Telegram Bot API для создания, развёртывания и масштабирования ботов.

## Когда активировать

- Вопросы по разработке Telegram-ботов
- Работа с Bot API: сообщения, кнопки, медиа, платежи
- Настройка webhook/polling
- Mini Apps (Web Apps)
- Деплой ботов (Railway, Vercel, Docker, VPS)
- Выбор библиотеки (aiogram, grammY, Telegraf)
- FSM и управление состояниями
- Telegram Stars и платежи

## Отличие от telegram-справочник

| | telegram-справочник | telegram-bot-справочник |
|---|---|---|
| Фокус | Платформа (каналы, группы, маркетинг) | Bot API (разработка ботов) |
| Аудитория | Маркетологи, бизнес | Разработчики |
| Код | Минимум | Много примеров на Python/Node.js |
