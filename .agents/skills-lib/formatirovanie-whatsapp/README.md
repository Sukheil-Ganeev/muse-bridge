# Скилл: Форматирование WhatsApp

## Назначение
Универсальное форматирование любого текста для отправки в WhatsApp.

## Когда использовать
- Любой запрос с "для ватсап", "в ватсап", "whatsapp формат"
- Подготовка постов в группы WhatsApp
- Форматирование документов, отчётов, анализов для мессенджера
