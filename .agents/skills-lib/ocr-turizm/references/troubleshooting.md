# Troubleshooting — OCR туризм

## Yandex Vision: Ошибка 401
**Причина:** Неверный API ключ
**Решение:** Проверь YANDEX_VISION_API_KEY в .env

## Yandex Vision: Ошибка 403
**Причина:** Нет роли ai.vision.user
**Решение:** Добавь роль yc.ai.vision.execute при создании ключа

## Google Vision: Ошибка 403
**Причина:** API не включен или неверный ключ
**Решение:** Включи Cloud Vision API в Google Console

## Пустой результат
**Причина:** Изображение низкого качества или нет текста
**Решение:** Улучши качество изображения, проверь языки

## Неверная сумма из чека
**Причина:** Нестандартный формат чека
**Решение:** Добавь паттерн в extract_payment_info()

## Арабский текст не распознаётся
**Причина:** Используется Yandex вместо Google
**Решение:** Используй ocr_google() с languages=["ar"]
