# подтверждения-бронирований

## Описание
Преобразование табличных данных подтверждений бронирования (из изображений или текста) в красиво оформленные сообщения WhatsApp/Telegram для клиентов. Извлечение полей: номер брони, дата, тур, время пикапа, отель, имя гостя.

## Структура
```
подтверждения-бронирований/
├── SKILL.md              # Основной файл
├── README.md             # Этот файл
├── references/
│   └── excursion_types.md  # Типы экскурсий и контекстные напоминания
└── experience/           # Накопленный опыт
    ├── _index.md
    ├── fixes/
    ├── improvements/
    ├── patterns/
    └── warnings/
```

## Использование
Скилл активируется автоматически по триггерам в description.
