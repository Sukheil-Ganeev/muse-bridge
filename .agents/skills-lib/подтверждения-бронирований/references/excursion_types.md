# Типы экскурсий и контекстные напоминания

Этот файл содержит информацию о различных типах экскурсий, специфических напоминаниях для каждого типа и деталях того, что включено в экскурсию.

---

## Обзорные экскурсии по городу

### MODERN DUBAI / ОБЗОРНАЯ ЭКСКУРСИЯ ПО ДУБАЮ
- **Тип:** Автобусная групповая экскурсия
- **Длительность:** 8–9 часов
- **Основные локации:** Бурдж Халифа, Dubai Mall, Palm Jumeirah, Burj Al Arab
- **Что включено:**
  - Трансфер от/до отеля
  - Madinat Jumeirah
  - Фотостоп у Burj Al Arab
  - Palm Jumeirah (монорельс) → Atlantis
  - Bluewaters / Ain Dubai
  - 45-минутный круиз в Dubai Marina (без питания)
  - Dubai Mall и фонтаны у Burj Khalifa
  - Сопровождение на русском языке
- **Напоминания:**
  - Удобная обувь для ходьбы
  - Камера для фотографий
  - Круиз без питания (можно взять с собой воду/снеки)

### DUBAI CLASSIC / OLD DUBAI
- **Тип:** Автобусная групповая экскурсия
- **Длительность:** 4–5 часов
- **Основные локации:** Старый Дубай, Gold Souk, Spice Souk, Абра по Creek
- **Что включено:**
  - Трансфер от/до отеля
  - Старый Дубай (Al Fahidi Historical District)
  - Gold Souk
  - Spice Souk
  - Поездка на абре по Dubai Creek
  - Сопровождение на русском языке
- **Напоминания:**
  - Удобная обувь для ходьбы по рынкам
  - Наличные для покупок на рынках
  - Возьмите сумку для покупок

### DUBAI BY NIGHT / ВЕЧЕРНИЙ ДУБАЙ
- **Тип:** Вечерняя экскурсия
- **Длительность:** 4–5 часов
- **Основные локации:** Dubai Marina, Burj Khalifa, фонтаны
- **Что включено:**
  - Трансфер от/до отеля
  - Dubai Marina Walk
  - Вид на Burj Al Arab в ночной подсветке
  - Шоу фонтанов Dubai Fountain
  - Сопровождение на русском языке
- **Напоминания:**
  - Легкая теплая одежда (вечером прохладно)
  - Камера для ночных фотографий
  - Штатив для фото (по желанию)

### DUBAI FRAME / РАМКА ДУБАЯ
- **Тип:** Экскурсия с посещением смотровой площадки
- **Длительность:** 3–4 часа
- **Основные локации:** Dubai Frame, Zabeel Park
- **Что включено:**
  - Трансфер от/до отеля
  - Входной билет в Dubai Frame
  - Смотровая площадка на 150 м
  - Стеклянный пол Sky Deck
  - Сопровождение на русском языке
- **Напоминания:**
  - Удобная обувь
  - Камера для панорамных фото
  - Не рекомендуется людям с боязнью высоты

## Экскурсии в Абу-Даби

### ABU DHABI CITY TOUR / ЭКСКУРСИЯ В АБУ-ДАБИ
- **Тип:** Автобусная групповая экскурсия
- **Длительность:** 10–12 часов
- **Основные локации:** Sheikh Zayed Grand Mosque, Emirates Palace, Louvre Abu Dhabi
- **Что включено:**
  - Трансфер от/до отеля (Дубай-Абу Даби-Дубай)
  - Sheikh Zayed Grand Mosque
  - Emirates Palace (фотостоп)
  - Corniche
  - Louvre Abu Dhabi (опционально)
  - Сопровождение на русском языке
- **Напоминания:**
  - Закрытая одежда для мечети (длинные рукава, длинные брюки/юбка)
  - Платок для женщин (для мечети)
  - Носки (обувь снимается в мечети)

### ABU DHABI + LOUVRE
- **Тип:** Автобусная групповая экскурсия с музеем
- **Длительность:** 12–13 часов
- **Основные локации:** Мечеть, Louvre Abu Dhabi
- **Что включено:**
  - Всё из стандартной экскурсии
  - Входной билет в Louvre Abu Dhabi
  - 2–3 часа в музее
- **Напоминания:**
  - Те же, что для стандартной экскурсии
  - В музее прохладно — возьмите легкую кофту

### ABU DHABI + QASR AL WATAN
- **Тип:** Автобусная групповая экскурсия с дворцом
- **Длительность:** 11–12 часов
- **Основные локации:** Мечеть, Президентский дворец
- **Что включено:**
  - Всё из стандартной экскурсии
  - Входной билет в Qasr Al Watan
  - Экскурсия по дворцу
- **Напоминания:**
  - Те же, что для стандартной экскурсии
  - Дресс-код для дворца (опрятная одежда)

## Пустынные сафари

### DESERT SAFARI / САФАРИ В ПУСТЫНЕ (вечернее)
- **Тип:** Сафари на джипах
- **Длительность:** 6–7 часов
- **Время:** Выезд ~15:00, возврат ~21:00
- **Что включено:**
  - Трансфер от/до отеля
  - Dune Bashing (катание по дюнам)
  - Фотостоп на закате
  - Катание на верблюдах
  - Лагерь с программой: танец живота, танура
  - Ужин BBQ (буфет)
  - Хна, кальян
- **Напоминания:**
  - Легкая закрытая одежда (защита от солнца и песка)
  - Солнцезащитный крем
  - Солнечные очки
  - Камера (в защитном чехле от песка)
  - НЕ рекомендуется беременным и людям с проблемами спины
  - Паспорта

### MORNING DESERT SAFARI / УТРЕННЕЕ САФАРИ
- **Тип:** Утреннее сафари
- **Длительность:** 4–5 часов
- **Время:** Выезд ~08:00, возврат ~12:00
- **Что включено:**
  - Трансфер от/до отеля
  - Dune Bashing
  - Sandboarding
  - Катание на верблюдах
  - Напитки в лагере
- **Напоминания:**
  - Те же, что для вечернего сафари
  - Возьмите больше воды (утром быстро жарко)

### VIP DESERT SAFARI / VIP САФАРИ
- **Тип:** Индивидуальное сафари
- **Длительность:** 6–7 часов
- **Что включено:**
  - Частный транспорт (Land Cruiser)
  - Отдельная зона/палатка в лагере
  - Персональный водитель/гид
  - Премиум ужин
- **Напоминания:**
  - Те же, что для стандартного сафари

### OVERNIGHT SAFARI / НОЧНОЕ САФАРИ С НОЧЕВКОЙ
- **Тип:** Сафари с ночевкой в пустыне
- **Длительность:** ~20 часов (вечер до утра)
- **Что включено:**
  - Всё из вечернего сафари
  - Ночевка в палатках/под звёздами
  - Завтрак
- **Напоминания:**
  - Теплая одежда (в пустыне холодно ночью!)
  - Спальные принадлежности предоставляются
  - Фонарик (по желанию)

## Водные экскурсии

### YACHT TOUR / ПРОГУЛКА НА ЯХТЕ
- **Тип:** Прогулка на яхте
- **Длительность:** 2–3 часа
- **Основные локации:** Dubai Marina, Palm Jumeirah, Burj Al Arab
- **Что включено:**
  - Трансфер (опционально)
  - Прогулка на яхте
  - Напитки (вода, соки)
  - Плавание с яхты (если погода позволяет)
- **Напоминания:**
  - Купальник и полотенце
  - Солнцезащитный крем
  - Солнечные очки
  - Легкая одежда
  - Паспорта

### DHOW CRUISE MARINA / КРУИЗ НА ДОАУ (МАРИНА)
- **Тип:** Ужин на традиционной лодке
- **Длительность:** 2 часа
- **Основные локации:** Dubai Marina
- **Что включено:**
  - Трансфер от/до отеля
  - 2-часовой круиз
  - Ужин буфет
  - Развлекательная программа
- **Напоминания:**
  - Легкая вечерняя одежда
  - Камера для вечерних фотографий
  - Паспорта

### DHOW CRUISE CREEK / КРУИЗ НА ДОАУ (КРИК)
- **Тип:** Ужин на традиционной лодке
- **Длительность:** 2 часа
- **Основные локации:** Dubai Creek, Old Dubai
- **Что включено:**
  - Трансфер от/до отеля
  - 2-часовой круиз по историческому Creek
  - Ужин буфет
  - Программа с танцами
- **Напоминания:**
  - Те же, что для Marina Cruise

### SPEED BOAT TOUR / СКОРОСТНОЙ КАТЕР
- **Тип:** Экстремальная прогулка на катере
- **Длительность:** 1–1.5 часа
- **Основные локации:** Palm Jumeirah, Burj Al Arab, Atlantis
- **Что включено:**
  - 90-минутная прогулка на RIB-катере
  - Профессиональный капитан
  - Спасательные жилеты
- **Напоминания:**
  - Одежда, которую не жалко намочить
  - Крем от солнца (водостойкий)
  - Очки с резинкой
  - Не рекомендуется беременным

### JET SKI TOUR / ПРОГУЛКА НА ГИДРОЦИКЛАХ
- **Тип:** Активный отдых на воде
- **Длительность:** 30–60 минут
- **Что включено:**
  - Инструктаж
  - Гидроцикл
  - Спасательный жилет
  - Инструктор сопровождает
- **Напоминания:**
  - Купальник/шорты
  - Минимальный возраст 16+ лет
  - Водительские права не требуются
  - Не рекомендуется беременным

## Культурные экскурсии

### MOSQUE TOUR / ЭКСКУРСИЯ В МЕЧЕТЬ
- **Тип:** Экскурсия по мечети
- **Длительность:** 2–3 часа
- **Основные локации:** Sheikh Zayed Grand Mosque
- **Напоминания:**
  - Закрытая одежда ОБЯЗАТЕЛЬНО (длинные рукава, длинные брюки/юбка до щиколоток)
  - Платок для женщин (выдают на месте, но лучше свой)
  - Носки (обувь снимается)
  - Паспорта
  - Не приходить в пляжной/спортивной одежде

### MUSEUM TOURS / МУЗЕЙНЫЕ ЭКСКУРСИИ
- **Тип:** Экскурсия по музеям
- **Музеи:** Louvre Abu Dhabi, Dubai Museum, Etihad Museum, Museum of the Future
- **Напоминания:**
  - Удобная обувь
  - Камера (проверить правила фотосъемки)
  - Паспорта
  - В музеях прохладно — возьмите кофту

### MUSEUM OF THE FUTURE / МУЗЕЙ БУДУЩЕГО
- **Тип:** Интерактивный музей
- **Длительность:** 2–3 часа
- **Местоположение:** Sheikh Zayed Road, Дубай
- **Что включено:**
  - Входной билет
  - Доступ ко всем этажам/экспозициям
- **Напоминания:**
  - Удобная обувь
  - Билеты по времени — приходить вовремя!
  - Фото/видео разрешены

### HERITAGE VILLAGE / ДЕРЕВНЯ НАСЛЕДИЯ
- **Тип:** Культурная экскурсия
- **Длительность:** 1–2 часа
- **Местоположение:** Al Shindagha, Дубай
- **Что включено:**
  - Вход бесплатный
  - Экспозиция традиционного быта
- **Напоминания:**
  - Удобная обувь
  - Лучше посещать утром или вечером (жарко!)

## Вечерние экскурсии и развлечения

### DUBAI FOUNTAIN SHOW / ФОНТАНЫ ДУБАЯ
- **Тип:** Вечернее шоу
- **Длительность:** 1–2 часа
- **Время шоу:** Каждые 30 минут с 18:00 до 23:00
- **Местоположение:** Dubai Mall / Burj Khalifa Lake
- **Напоминания:**
  - Легкая теплая одежда (вечером прохладно)
  - Камера/штатив для фотографий
  - Приходите за 15–20 минут для хорошего места

### LA PERLE SHOW / ШОУ ЛА ПЕРЛЬ
- **Тип:** Театральное акробатическое шоу
- **Длительность:** ~90 минут
- **Местоположение:** Al Habtoor City
- **Что включено:**
  - Входной билет
  - Водное шоу с акробатикой
- **Напоминания:**
  - Опрятная одежда (smart casual)
  - Приходите за 30 минут
  - Фото/видео запрещены во время шоу

### DINNER IN THE SKY / УЖИН В НЕБЕ
- **Тип:** Экстремальный ужин
- **Длительность:** ~2 часа
- **Высота:** 50 метров
- **Что включено:**
  - Подъём на платформе
  - Ужин/обед из нескольких блюд
- **Напоминания:**
  - Закрытая обувь ОБЯЗАТЕЛЬНО
  - Не рекомендуется людям с боязнью высоты
  - Минимальный возраст: 10+ лет
  - Ремни безопасности

## Экстремальные активности

### SKYDIVE DUBAI / ПРЫЖОК С ПАРАШЮТОМ
- **Тип:** Экстремальный спорт
- **Длительность:** ~3–4 часа (с подготовкой)
- **Высота прыжка:** 4000 м
- **Что включено:**
  - Инструктаж
  - Тандем-прыжок с инструктором
  - Оборудование
  - Видео/фото (опционально)
- **Напоминания:**
  - Спортивная одежда
  - Закрытая обувь (кроссовки)
  - Паспорт ОБЯЗАТЕЛЕН
  - Минимальный вес: 40 кг, максимальный: 100 кг
  - Минимальный возраст: 18+ лет
  - НЕ рекомендуется беременным, людям с проблемами сердца/спины

### XLine DUBAI MARINA / ЗИПЛАЙН
- **Тип:** Экстремальный аттракцион
- **Длительность:** ~1 час
- **Длина линии:** 1 км
- **Скорость:** до 80 км/ч
- **Что включено:**
  - Оборудование
  - Инструктаж
  - Полёт над Marina
- **Напоминания:**
  - Удобная одежда (без развевающихся элементов)
  - Закрытая обувь
  - Минимальный вес: 50 кг, максимальный: 100 кг
  - Минимальный возраст: 12+ лет

### FLYBOARDING / ФЛАЙБОРДИНГ
- **Тип:** Водный экстрим
- **Длительность:** 30–60 минут
- **Что включено:**
  - Инструктаж
  - Оборудование
  - Инструктор
- **Напоминания:**
  - Купальник
  - Умение плавать ОБЯЗАТЕЛЬНО
  - Минимальный возраст: 16+ лет
  - Не рекомендуется беременным

## Специальные возрастные требования

### Экскурсии с ограничениями по возрасту:

| Экскурсия/активность | Минимальный возраст | Дополнительные требования |
|----------------------|---------------------|---------------------------|
| Desert Safari (Dune Bashing) | 3+ года | НЕ рекомендуется беременным |
| Skydive Dubai | 18+ лет | Вес 40–100 кг |
| XLine Zipline | 12+ лет | Вес 50–100 кг |
| Flyboarding | 16+ лет | Умение плавать |
| Jet Ski | 16+ лет | — |
| Ferrari World (Formula Rossa) | 5+ лет | Рост 140+ см |

### Требования для детей:
- **Паспорта ОБЯЗАТЕЛЬНЫ** для всех детей
- Для некоторых аттракционов требуется **сопровождение взрослого**
- Проверяйте **ограничения по росту** для горок и аттракционов

## Общие напоминания для всех экскурсий

1. **Всегда берите паспорта** (особенно для детей — ОБЯЗАТЕЛЬНО)
2. **Будьте готовы за 10 минут до начала окна подачи**
3. **Имейте номер бронирования при себе**

## Погодные условия и сезонность

### Летом (май–сентябрь):
- Очень жарко (+40–50 C)
- Легкая светлая одежда
- Больше воды
- Сильный солнцезащитный крем (SPF 50+)
- Головной убор ОБЯЗАТЕЛЕН
- Избегайте активностей на улице в середине дня

### Зимой (ноябрь–март):
- Комфортная температура (+20–30 C днем)
- Вечером прохладно (+15–20 C)
- Легкая кофта/куртка для вечерних экскурсий
- Идеальное время для пустынного сафари и уличных активностей

### Рамадан (даты меняются):
- Некоторые заведения работают по сокращённому графику
- Уважайте пост — не ешьте/не пейте на улице днём
- Вечерние экскурсии могут начинаться позже
