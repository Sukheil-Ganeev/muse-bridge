# Salebot-Конструктор Skill

Скилл для проектирования чат-ботов на платформе SaleBot.

## Описание

Этот скилл помогает создавать профессиональные чат-боты для бизнеса на платформе SaleBot - мультиплатформенном конструкторе с поддержкой 8 мессенджеров.

### Возможности скилла

- Проектирование архитектуры ботов
- Написание сценариев и блок-схем
- Настройка интеграций (CRM, платежи, онлайн-школы)
- Работа с переменными и условиями
- Создание воронок продаж
- Настройка мультиканальности

## Когда использовать SaleBot

### Идеально подходит для:

| Сценарий | Почему SaleBot |
|----------|----------------|
| Мультиканальные продажи | 8 мессенджеров в одном месте |
| Онлайн-школы | Конструктор курсов, интеграция с GetCourse |
| Услуги (салоны, клиники) | Онлайн-запись, напоминания |
| Бизнес с CRM | Встроенная CRM или интеграция с amoCRM/Bitrix24 |
| Туристический бизнес | WhatsApp + единое окно чатов |

### Когда выбрать PuzzleBot вместо SaleBot:

| Сценарий | Почему PuzzleBot |
|----------|------------------|
| Только Telegram | Дешевле в 2-3 раза |
| Нужен Mini App | SaleBot не поддерживает |
| Ограниченный бюджет | Экономия 15-20 тыс./год |
| Простой бот | Проще в освоении |

### Сравнение платформ

| Критерий | SaleBot | PuzzleBot |
|----------|---------|-----------|
| Платформы | 8 мессенджеров | Только Telegram |
| Цена (базовый) | ~30,590 руб/год | ~9,990 руб/год |
| Встроенная CRM | Да | Нет |
| Курсы/вебинары | Да | Нет |
| Онлайн-запись | Да | Нет |
| Mini App | Нет | Да |
| Порог входа | Средний | Низкий |

## Quick Start

### Шаг 1: Регистрация (2 мин)
1. Перейти на https://salebot.pro
2. Нажать "Попробовать бесплатно"
3. 3 дня бесплатного тестового периода

### Шаг 2: Создание проекта (1 мин)
1. Нажать "Создать проект"
2. Выбрать платформу (начните с Telegram)
3. Ввести название

### Шаг 3: Подключение Telegram (3 мин)
1. Открыть @BotFather в Telegram
2. Создать бота: `/newbot`
3. Скопировать токен
4. Вставить в SaleBot

### Шаг 4: Первый сценарий (5 мин)
1. Перейти в "Сценарии" -> "Новый сценарий"
2. Добавить блок "Текст" с приветствием
3. Добавить кнопки меню
4. Сохранить и протестировать

### Шаг 5: Тестирование (2 мин)
1. Найти бота в Telegram
2. Нажать Start
3. Проверить работу

**Итого: ~15 минут до первого работающего бота**
