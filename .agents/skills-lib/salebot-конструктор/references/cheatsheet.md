## Синтаксис переменных

```
#{имя_переменной}
```

### Системные переменные пользователя

| Переменная | Описание | Пример |
|------------|----------|--------|
| `#{user_id}` | ID пользователя | `123456789` |
| `#{username}` | Username | `john_doe` |
| `#{first_name}` | Имя | `Иван` |
| `#{last_name}` | Фамилия | `Петров` |
| `#{full_name}` | Полное имя | `Иван Петров` |
| `#{language_code}` | Язык | `ru` |
| `#{is_premium}` | Premium статус | `true/false` |

### Системные переменные чата

| Переменная | Описание |
|------------|----------|
| `#{chat_id}` | ID чата |
| `#{chat_type}` | Тип: private/group/supergroup |
| `#{message_id}` | ID сообщения |
| `#{message_text}` | Текст сообщения |

### Дата и время

| Переменная | Описание | Пример |
|------------|----------|--------|
| `#{current_date}` | Текущая дата | `2024-01-15` |
| `#{current_time}` | Текущее время | `10:30:45` |
| `#{timestamp}` | Unix timestamp | `1705312245` |
| `#{day}` | День месяца | `15` |
| `#{month}` | Месяц | `1` |
| `#{year}` | Год | `2024` |
| `#{hour}` | Час | `10` |
| `#{day_of_week}` | День недели (1=Пн) | `1` |
| `#{day_name}` | Название дня | `Понедельник` |

### Специальные

| Переменная | Описание |
|------------|----------|
| `#{random}` | Случайное число 0-100 |
| `#{uuid}` | Уникальный ID |
| `#{newline}` | Перенос строки |
| `#{platform}` | Платформа (telegram/whatsapp...) |
| `#{bot_username}` | Username бота |

## Основные блоки

### Сообщения

| Блок | Назначение |
|------|------------|
| **Текст** | Отправка текста (до 4096 символов) |
| **Изображение** | Фото с подписью |
| **Видео** | Видео (до 50 МБ) |
| **Документ** | Файлы любого типа |
| **Аудио** | Аудио и голосовые |
| **Локация** | Точка на карте |

### Кнопки

| Блок | Назначение |
|------|------------|
| **Клавиатура** | Reply-кнопки под полем ввода |
| **Inline-кнопки** | Кнопки под сообщением |
| **URL-кнопка** | Открывает ссылку |
| **Callback** | Переход к блоку |

### Действия

| Блок | Назначение |
|------|------------|
| **Задержка** | Пауза 1-300 сек |
| **Переход** | Безусловный переход к блоку |
| **Остановка** | Завершение сценария |
| **Ожидание ответа** | Ждать ввод пользователя |
| **Установить переменную** | Присвоить значение |

### Логика

| Блок | Назначение |
|------|------------|
| **Условие** | Ветвление если/иначе |
| **Случайный выбор** | Рандом с процентами |
| **A/B тест** | Тестирование вариантов |

### Интеграции

| Блок | Назначение |
|------|------------|
| **Webhook** | Отправка на внешний URL |
| **API запрос** | Получение данных |
| **Email** | Отправка письма |
| **CRM** | Создание контакта/сделки |
| **Платеж** | Ссылка на оплату |

## Частые паттерны

### Приветствие с персонализацией

```
Привет, #{first_name}!

Я бот компании X. Чем могу помочь?

[Каталог] [Контакты] [О нас]
```

### Сбор данных

```
[Вопрос] → [Ожидание → переменная] → [Следующий вопрос]

1. "Как вас зовут?" → #{name}
2. "Ваш телефон?" → #{phone}
3. "Спасибо, #{name}! Перезвоним на #{phone}"
```

### Проверка условия

```
[Условие: #{age} >= 18]
├── Да → [Каталог товаров]
└── Нет → [Извините, только для взрослых]
```

### Таймер персонализации

```
#{hour} < 12  → "Доброе утро, #{first_name}!"
#{hour} < 18  → "Добрый день, #{first_name}!"
#{hour} >= 18 → "Добрый вечер, #{first_name}!"
```

### Корзина покупок

```
[Выбор товара] → #{cart} += товар
[Корзина] → показать #{cart}
[Оформить] → Сбор данных → Создать заказ → Платеж
```

### Воронка вебинара

```
Регистрация → Напоминание -1д → Напоминание -1ч
→ Ссылка на вебинар → После: предложение курса
→ Дожим +24ч → Дожим +48ч
```

### Поддержка с FAQ

```
[Частые вопросы]
├── [Доставка] → Текст о доставке
├── [Оплата] → Текст об оплате
├── [Возврат] → Текст о возврате
└── [Другой вопрос] → Связь с оператором
```

## Операции с переменными

### Присваивание
```
#{counter} = 0
#{name} = "Иван"
```

### Конкатенация
```
#{address} = #{city} + ", " + #{street}
```

### Математика
```
#{total} = #{price} * #{quantity}
#{with_discount} = #{total} - (#{total} * #{discount} / 100)
```

### Инкремент
```
#{counter} = #{counter} + 1
```

### Значение по умолчанию
```
#{phone|default:"не указан"}
#{price|default:0}
```

### Форматирование
```
#{total|number}    → 1 234 567
#{discount|percent} → 15%
#{date|date}       → 15 января 2024
```

## Работа с JSON

### Доступ к полям
```
#{user.name}        → значение поля name
#{order.items[0]}   → первый элемент массива
#{data.customer.phone} → вложенное поле
```

### Пример
```
#{order} = {
  "id": 123,
  "customer": {"name": "Иван"},
  "items": [{"name": "Товар", "price": 100}]
}

#{order.id}              → 123
#{order.customer.name}   → Иван
#{order.items[0].name}   → Товар
```
