## 1. Telegram

### Особенности
- Самая функциональная платформа для ботов
- Богатый API без ограничений
- Бесплатное подключение через @BotFather

### Подключение
1. Открыть @BotFather в Telegram
2. Команда `/newbot`
3. Указать имя и username
4. Скопировать токен в SaleBot

### Возможности

| Функция | Поддержка |
|---------|:---------:|
| Inline-кнопки | До 8 в ряд, 100 всего |
| Reply-кнопки | До 12 в ряд |
| Медиа | Фото, видео, аудио, файлы |
| Группы/каналы | Полная поддержка |
| Платежи | Telegram Payments |
| Mini App | Нет в SaleBot |

### Лимиты

| Параметр | Значение |
|----------|----------|
| Текст сообщения | 4096 символов |
| Подпись к медиа | 1024 символа |
| Callback data | 64 байта |
| Фото | 10 МБ |
| Видео/файлы | 50 МБ |
| Сообщений/сек | 30 |
| Рассылка | 25-30 сообщ/сек |

### Рекомендации
- Лучшая платформа для старта
- Неограниченные рассылки
- Идеально для воронок и автоматизации

---

## 2. WhatsApp

### Особенности
- Требует верификации бизнеса в Meta
- Платное API через провайдеров
- Строгие политики модерации

### Подключение
1. Регистрация в Meta Business Manager
2. Верификация бизнеса (1-5 дней)
3. Подключение через Meta Cloud API или 360dialog
4. Привязка нового номера телефона

### Возможности

| Функция | Поддержка |
|---------|:---------:|
| Quick Reply | До 3 кнопок |
| CTA кнопки | До 2 (URL/телефон) |
| Шаблоны | Обязательны после 24ч |
| Медиа | Фото (5МБ), видео (16МБ) |
| Статусы доставки | Да |
| Рассылки | Только одобренные шаблоны |

### Лимиты

| Параметр | Значение |
|----------|----------|
| Текст сообщения | 4096 символов |
| Тело шаблона | 1024 символа |
| Текст кнопки | 20 символов |
| Изображение | 5 МБ |
| Видео/аудио | 16 МБ |
| Документ | 100 МБ |

### Уровни лимитов рассылок

| Уровень | Контактов/24ч | Требования |
|---------|---------------|------------|
| Unverified | 250 | Новый аккаунт |
| Tier 1 | 1,000 | Верификация |
| Tier 2 | 10,000 | Хорошее качество |
| Tier 3 | 100,000 | Высокое качество |
| Unlimited | Без лимита | Отличная репутация |

### Окно 24 часа
- После сообщения клиента открывается окно 24ч
- В окне можно отправлять любые сообщения
- После 24ч - только платные шаблоны

### Рекомендации
- Обязательный opt-in (согласие) от клиента
- Следить за качеством аккаунта
- Быстро отвечать клиентам
- Не спамить - риск блокировки

## 3. VKontakte

### Особенности
- Бесплатное подключение
- Требует сообщество (группа)
- Права администратора

### Подключение
1. Создать сообщество в VK
2. Включить сообщения сообщества
3. Авторизоваться в SaleBot через VK
4. Выбрать сообщество

### Возможности

| Функция | Поддержка |
|---------|:---------:|
| Inline-кнопки | Да |
| Клавиатура | Да |
| Медиа | Фото, видео, документы |
| Рассылки | Подписчикам сообщества |

### Лимиты

| Параметр | Значение |
|----------|----------|
| Текст | 4096 символов |
| Сообщений в группу/мин | 20 |
| Файлы | Без жестких лимитов |

### Рекомендации
- Отключить встроенного бота VK
- Настроить приветствие в сообществе
- Использовать кнопку "Написать"

## 4. Instagram Direct

### Особенности
- Требует бизнес-аккаунт Instagram
- Привязка к странице Facebook
- Ограниченный функционал

### Подключение
1. Переключить на бизнес-аккаунт
2. Привязать страницу Facebook
3. Настроить в Business Manager
4. Подключить в SaleBot через Facebook

### Возможности

| Функция | Получение | Отправка |
|---------|:---------:|:--------:|
| Текст | Да | Да |
| Изображение | Да | Да |
| Видео | Да | Нет |
| Голосовое | Да | Нет |
| Стикер | Да | Нет |
| Story mention | Да | Нет |
| Quick Replies | - | До 13 кнопок |

### Особенности окна

| Период | Возможности |
|--------|-------------|
| 24 часа | Любые сообщения |
| +7 дней | Human Agent Window |
| После | Нельзя писать |

### Ice Breakers
- Подсказки при первом открытии чата
- До 4 вариантов
- Помогают начать диалог

### Рекомендации
- Быстро отвечать (в течение часа)
- Использовать Quick Replies для FAQ
- Настроить Ice Breakers

## 5. Facebook Messenger

### Особенности
- Требует страницу Facebook
- Богатый функционал шаблонов
- Интеграция с рекламой

### Подключение
1. Создать страницу Facebook
2. Включить сообщения страницы
3. Авторизоваться через Facebook в SaleBot

### Возможности

| Функция | Поддержка |
|---------|:---------:|
| Quick Replies | До 13 кнопок |
| Постоянное меню | До 3 пунктов |
| Generic Template | Карточка с фото |
| Carousel | До 10 карточек |
| Button Template | Текст + 3 кнопки |

### Лимиты

| Параметр | Значение |
|----------|----------|
| Текст | 2000 символов |
| Quick Replies | 13 |
| Кнопок в шаблоне | 3 |
| Карточек в карусели | 10 |
| Размер файла | 25 МБ |

### Message Tags (после 24ч)

| Тег | Назначение |
|-----|------------|
| CONFIRMED_EVENT_UPDATE | Обновление о мероприятии |
| POST_PURCHASE_UPDATE | Статус заказа |
| ACCOUNT_UPDATE | Изменения в аккаунте |
| HUMAN_AGENT | Ответ оператора (7 дней) |

### Рекомендации
- Использовать шаблоны для каталогов
- Настроить постоянное меню
- Интегрировать с Click-to-Messenger рекламой

## 6. Viber

### Особенности
- Бесплатное создание бота
- Цветные кнопки с изображениями
- Статусы прочтения

### Подключение
1. Зарегистрироваться на partners.viber.com
2. Создать бота (Create Bot Account)
3. Скопировать Authentication Token
4. Вставить в SaleBot

### Возможности

| Функция | Поддержка |
|---------|:---------:|
| Reply кнопки | Да, с кастомизацией |
| URL кнопки | Да |
| Медиа | Текст, фото, видео, файлы |
| Rich Media | До 6 карточек |
| Статусы | sent, delivered, seen |

### Лимиты

| Параметр | Значение |
|----------|----------|
| Текст | 7000 символов |
| Размер файла | 50 МБ |
| Видео | 26 МБ |
| Кнопок в клавиатуре | 24 |

### Особенности кнопок
- Размер: от 1 до 6 колонок
- Высота: от 1 до 2 строк
- Можно добавить изображение на кнопку
- Настраиваемые цвета

### Рекомендации
- Использовать цвета бренда
- Rich Media для каталогов
- Следить за seen-статусами

## 7. Avito

### Особенности
- Привязка к объявлениям
- Минимальный функционал
- Строгая модерация

### Подключение
1. Авторизоваться через Avito в SaleBot
2. Разрешить доступ
3. Активные объявления будут подключены

### Возможности

| Функция | Получение | Отправка |
|---------|:---------:|:--------:|
| Текст | Да | Да |
| Изображение | Да | Да |
| Кнопки | Нет | Нет |
| Файлы | Нет | Нет |

### Доступные переменные

| Переменная | Описание |
|------------|----------|
| `#{avito_id}` | ID пользователя |
| `#{item_id}` | ID объявления |
| `#{item_title}` | Название товара |
| `#{item_price}` | Цена |
| `#{name}` | Имя покупателя |

### Ограничения
- Нельзя отправлять внешние ссылки
- Запрещены рассылки
- Модерация сообщений
- Нельзя выводить сделки с площадки

### Рекомендации
- Быстрые автоответы
- Персонализация по товару
- Сбор телефона в чате

## 8. Одноклассники (OK)

### Особенности
- Аудитория 35+ лет
- Работает через группу
- Полноценные кнопки

### Подключение
1. Создать группу в OK
2. Включить сообщения группы
3. Авторизоваться в SaleBot через OK
4. Выбрать группу

### Возможности

| Функция | Поддержка |
|---------|:---------:|
| Inline-кнопки | До 3-4 в ряд |
| Клавиатура | Да |
| Медиа | Текст, фото, видео, аудио |

### Лимиты

| Параметр | Значение |
|----------|----------|
| Текст | 4096 символов |
| Кнопок в ряду | 3-4 |
| Рядов кнопок | 10 |

### Доступные переменные

| Переменная | Описание |
|------------|----------|
| `#{ok_id}` | ID пользователя OK |
| `#{first_name}` | Имя |
| `#{last_name}` | Фамилия |
| `#{gender}` | Пол |
| `#{age}` | Возраст |
| `#{location}` | Местоположение |

### Рекомендации
- Простые понятные сообщения
- Крупные кнопки
- Уважительный тон
- Минимум сложных механик
