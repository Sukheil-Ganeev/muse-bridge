# SaleBot Конструктор

## When to Use (Триггеры активации)

**Используй этот скилл когда пользователь:**

### Прямые триггеры
- Упоминает SaleBot, Salebot, Сейлбот
- Спрашивает про "бот для WhatsApp"
- Нужен бот для нескольких мессенджеров одновременно
- Требуется встроенная CRM в боте
- Нужна онлайн-запись через бота
- Задача: объединить чаты из разных мессенджеров в одно окно
- Нужен конструктор курсов с ботом
- Спрашивает про интеграцию с GetCourse, Bizon365

### Контекстные триггеры
- Онлайн-школа, инфобизнес с мультиканальностью
- Салон красоты, клиника (нужна онлайн-запись)
- Туристический бизнес (WhatsApp + другие мессенджеры)
- Бизнес с операторами (единое окно)
- Нужны рассылки в WhatsApp
- Интеграция amoCRM/Bitrix24 с ботами

### Когда НЕ использовать
- Если нужен ТОЛЬКО Telegram без других мессенджеров -> рекомендуй PuzzleBot
- Если нужен Telegram Mini App -> рекомендуй PuzzleBot
- Если бюджет минимален и нужен только Telegram -> рекомендуй PuzzleBot
- Если нужен только простой бот без CRM/рассылок -> возможно PuzzleBot проще

## Сравнение SaleBot vs PuzzleBot

### Краткое решение

| Ваша ситуация | Рекомендация |
|---------------|--------------|
| Работаю только в Telegram | **PuzzleBot** |
| Нужен WhatsApp + Telegram | **SaleBot** |
| Нужен Telegram Mini App | **PuzzleBot** |
| Онлайн-школа с вебинарами | **SaleBot (Инфобиз)** |
| Хочу сэкономить | **PuzzleBot** |
| Масштабирование бизнеса | **SaleBot** |
| Салон красоты / услуги | **SaleBot** |
| Единое окно для операторов | **SaleBot** |

### Детальное сравнение

| Критерий | SaleBot | PuzzleBot |
|----------|---------|-----------|
| **Платформы** | 8 мессенджеров | Только Telegram |
| **WhatsApp** | Да | Нет |
| **Встроенная CRM** | Да | Нет |
| **Онлайн-запись** | Да | Нет |
| **Курсы/вебинары** | Да | Нет |
| **Единое окно** | Да | Нет |
| **AI-ассистенты** | Да | Нет |
| **Mini App** | Нет | Да |
| **Простота** | Средняя | Высокая |
| **Цена (базовая)** | 30,590 руб/год | 9,990 руб/год |

### Когда выбрать SaleBot

1. **Мультиканальность** - клиенты пишут из разных мессенджеров
2. **WhatsApp обязателен** - особенно для туризма, услуг
3. **Нужна CRM** - встроенная система управления клиентами
4. **Онлайн-школа** - курсы, вебинары, интеграция с GetCourse
5. **Команда операторов** - единое окно для всех чатов
6. **Онлайн-запись** - салоны, клиники, сервисы

### Когда выбрать PuzzleBot

1. **Только Telegram** - весь бизнес в одном мессенджере
2. **Mini App нужен** - интерактивные приложения
3. **Ограниченный бюджет** - в 3 раза дешевле
4. **Простые задачи** - лид-магниты, квизы
5. **Новичок** - проще в освоении

## 8 поддерживаемых платформ

### 1. Telegram

**Подключение:**
1. Создать бота через @BotFather (`/newbot`)
2. Получить токен
3. Вставить токен в SaleBot

**Возможности:**
- Боты, группы, каналы
- Inline и Reply клавиатуры
- Платежи (встроенные)
- Все типы медиа
- Команды меню

**Лимиты:**
- 4096 символов на сообщение
- До 100 кнопок
- До 8 inline-кнопок в ряду
- ~30 сообщений/сек

**Переменные:**
```
#{user_id}      - ID пользователя
#{username}     - @username
#{first_name}   - Имя
#{last_name}    - Фамилия
#{language_code} - Язык (ru, en)
#{is_premium}   - Premium статус
```

### 2. WhatsApp Business API

**Требования:**
- Business Solution Provider (360dialog, Twilio, WABA360)
- Верификация бизнеса в Meta
- Утвержденные шаблоны сообщений

**Типы сообщений:**

| Тип | Описание | Стоимость |
|-----|----------|-----------|
| Session | В течение 24ч после сообщения клиента | Бесплатно* |
| Template | Инициирование диалога | Платно |

*оплачивается только провайдер

**Категории шаблонов:**
- **Marketing** - промо, рассылки (дорого)
- **Utility** - статус заказа, напоминания (средне)
- **Authentication** - OTP коды (дешево)

**Интерактивные элементы:**
- Reply Buttons - до 3 кнопок
- List Messages - выпадающий список до 10 пунктов
- CTA Buttons - ссылки и звонки

**Окно 24 часа:**
```
Клиент написал -> 24 часа свободного общения -> Только шаблоны
```

**Верификация:**
- Unverified: 250 контактов/сутки
- Verified: 1000 -> 10000 -> 100000 -> безлимит

### 3. VKontakte

**Подключение:**
1. Создать сообщество VK
2. Настройки -> API -> Создать ключ
3. Включить сообщения сообщества
4. Вставить ключ в SaleBot

**Возможности:**
- Reply и Inline клавиатуры
- Карусели (до 10 карточек)
- VK Pay (платежи)
- VK Donut (подписки)

**Типы кнопок:**
- Text (цветные)
- Callback
- Link
- Location
- VK Pay
- Open App

**Переменные:**
```
#{vk_id}      - ID пользователя
#{first_name} - Имя
#{last_name}  - Фамилия
#{sex}        - Пол (1-жен, 2-муж)
#{city}       - Город
#{photo}      - Ссылка на аватар
```

**Лимиты:**
- 5 кнопок в ряду
- 10 рядов кнопок
- 5 сообщений/час одному пользователю

### 4. Instagram Direct

**Требования:**
- Бизнес-аккаунт или аккаунт автора
- Привязанная страница Facebook
- Facebook Business Manager

**Подключение:**
1. Переключить Instagram на бизнес-аккаунт
2. Привязать страницу Facebook
3. В SaleBot -> Подключить через Facebook

**Возможности:**
- Текст и изображения
- Quick Replies (до 13 кнопок)
- Ice Breakers (подсказки для начала диалога)
- Ответы на комментарии (Private Replies)
- Story Mentions

**Окно сообщений:**
- Стандартное: 24 часа
- Human Agent Window: +7 дней (через оператора)

**Ограничения:**
- Нельзя отправлять видео (только получать)
- Нельзя отправлять голосовые
- Нельзя удалять сообщения

### 5. Facebook Messenger

**Требования:**
- Страница Facebook (не профиль)
- Роль администратора

**Подключение:**
1. Создать страницу Facebook
2. Включить сообщения в настройках
3. В SaleBot -> Подключить через Facebook

**Возможности:**
- Generic Template (карточки)
- Button Template
- Carousel (до 10 карточек)
- Receipt Template (чеки)
- Quick Replies (до 13)
- Постоянное меню

**Окно 24 часа:**
- Стандартные сообщения: 24 часа
- Message Tags: для уведомлений
- One-Time Notification: разовое сообщение

**Интеграция с рекламой:**
- Click-to-Messenger Ads
- Параметр `ref` для отслеживания

### 6. Viber

**Подключение:**
1. Зарегистрироваться на partners.viber.com
2. Создать бота
3. Получить Authentication Token
4. Вставить в SaleBot

**Возможности:**
- Клавиатура с кастомными кнопками
- Rich Media (карусель до 6 карточек)
- Статусы: sent, delivered, seen
- До 7000 символов в сообщении

**Типы кнопок:**
- Reply
- Open URL
- Share Phone
- Share Location
- Open Map

**Лимиты:**
- 50 МБ файлы
- 26 МБ видео
- 24 кнопки в клавиатуре

### 7. Avito

**Подключение:**
1. В SaleBot -> Создать проект -> Avito
2. Авторизоваться через Avito API

**Особенности:**
- Каждый диалог привязан к объявлению
- Только текст и изображения
- Нет кнопок и клавиатур
- Модерация сообщений

**Переменные:**
```
#{avito_id}    - ID пользователя
#{item_id}     - ID объявления
#{item_title}  - Название товара
#{item_price}  - Цена
#{name}        - Имя покупателя
```

**Ограничения:**
- Нельзя ссылки на внешние сайты
- Нельзя массовые рассылки
- Нельзя выводить сделки за площадку

### 8. Одноклассники

**Подключение:**
1. Создать группу в ОК
2. Получить API-ключи
3. Настроить в SaleBot

**Возможности:**
- Сообщения группы
- Кнопки
- Медиа контент

## Условия и ветвление

### Операторы сравнения

| Оператор | Описание |
|----------|----------|
| `=` или `==` | Равно |
| `!=` или `<>` | Не равно |
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |
| `содержит` | Включает подстроку |
| `начинается с` | Starts with |
| `заканчивается на` | Ends with |
| `~` | Регулярное выражение |
| `существует` | Переменная определена |
| `пустое` | Переменная пустая |

### Логические операторы

```
AND (&&) - И (все условия истинны)
OR (||)  - ИЛИ (хотя бы одно истинно)
NOT      - НЕ (инверсия)
```

**Пример:**
```
#{age} >= 18 AND #{city} = Москва
#{status} = vip OR #{orders_count} >= 10
```

### Примеры условий

**Проверка возраста:**
```
ЕСЛИ #{age} >= 18
├── Да -> Показать каталог
└── Нет -> Отказ в доступе
```

**Рабочее время:**
```
ЕСЛИ #{hour} >= 9 AND #{hour} < 18 AND #{day_of_week} <= 5
├── Да -> Переключить на оператора
└── Нет -> Автоответчик
```

**Сегментация:**
```
ЕСЛИ #{total_orders} >= 10
├── Да -> VIP скидка 20%
└── Нет -> ЕСЛИ #{total_orders} >= 5
           ├── Да -> Скидка 10%
           └── Нет -> Скидка 5%
```

### Регулярные выражения

```
Телефон:  ^\+7\d{10}$
Email:    ^[\w.-]+@[\w.-]+\.\w+$
Число:    ^\d+$
Дата:     ^\d{2}\.\d{2}\.\d{4}$
```

## Рассылки и маркетинг

### Типы рассылок

| Тип | Описание |
|-----|----------|
| Мгновенная | Отправляется сразу |
| Отложенная | По расписанию |
| Периодическая | С заданным интервалом |
| Триггерная | По событию |

### Выбор аудитории

1. **Все подписчики** - все активные пользователи
2. **По переменным** - `#{paid} = 1`
3. **По тегам** - VIP, premium
4. **По сегментам** - заранее созданный сегмент
5. **Загрузка CSV** - список ID или телефонов

### Персонализация

```
Привет, #{name}!

Ваш баланс: #{balance} руб.
Статус: #{status}

{% if #{vip} == 1 %}
Спасибо за вашу лояльность!
Персональная скидка: 20%
{% else %}
Специально для вас скидка 10%!
{% endif %}
```

### Статистика

| Метрика | Описание |
|---------|----------|
| Отправлено | Всего в очереди |
| Доставлено | Успешно |
| Прочитано | Открыли (где поддерживается) |
| Клики | Нажали на кнопки |
| Ошибки | Не доставлено |
| Отписки | Заблокировали |

### Лимиты по платформам

| Платформа | Скорость | Ограничения |
|-----------|----------|-------------|
