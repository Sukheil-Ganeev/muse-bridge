# Viber — Troubleshooting (Решение проблем)

## Communities и Channels

### Не могу создать Community/Channel

**Причины:**
- Устаревшая версия Viber (обновите до последней)
- Ограничение по региону (редко)
- Бан аккаунта за нарушения

**Решение:**
1. Обновить Viber до последней версии
2. Перезайти в аккаунт
3. Попробовать с другого устройства

### Community не отображается в Viber Discover

**Причины:**
- Новое сообщество (нужно время для индексации)
- Мало участников
- Не подана заявка на размещение

**Решение:**
1. Набрать минимум 100-500 участников
2. Регулярно публиковать контент
3. Правильно заполнить описание и категорию
4. Подать заявку через настройки сообщества

### Участники не видят сообщения в Community

**Причины:**
- Уведомления отключены у участника
- Сообщение удалено модератором
- Технический сбой Viber

**Решение:**
1. Попросить участников проверить настройки уведомлений
2. Закрепить важные сообщения (pin)
3. Дублировать критичную информацию

## Business Messages

### Не могу получить верификацию (синюю галочку)

**Причины:**
- Неполный пакет документов
- Компания не соответствует требованиям Viber
- Ошибки в заявке

**Решение:**
1. Обратиться к CPaaS-партнеру (Infobip, Vonage)
2. Подготовить: регистрацию компании, лицензию, сайт, логотип
3. Убедиться, что сайт компании активен и содержит контактную информацию
4. Запросить помощь партнера в оформлении заявки

### Сообщения не доставляются

**Причины:**
- Пользователь не на Viber
- Номер заблокировал бизнес-аккаунт
- Неправильный формат номера
- Превышен лимит отправки
- Пользователь отписался (opt-out)

**Решение:**
1. Проверить, что номер зарегистрирован в Viber
2. Проверить формат номера (международный: +971XXXXXXXXX)
3. Проверить статус доставки через API партнера
4. Настроить SMS fallback для недоставленных

### Высокая стоимость сообщений

**Оптимизация:**
1. Сегментировать аудиторию — не рассылать всем подряд
2. Использовать транзакционные вместо промо (дешевле)
3. Использовать сессионные сообщения (ответы в окне 24ч)
4. Сравнить цены нескольких CPaaS-партнеров
5. Комбинировать с бесплатными каналами (Community, Channel)

### Минимальный платеж 150 EUR слишком высок

**Альтернативы:**
1. Начать с бесплатного Community/Channel
2. Использовать Viber Bot (другая ценовая модель, см. viber-bot-справочник)
3. Попробовать партнеров с более низким минимальным платежом (GMS, Messaggio)
4. Комбинировать каналы: Viber Community (бесплатно) + WhatsApp Business (бесплатно) + Telegram (бесплатно)

## Viber Ads

### Реклама не получает показы

**Причины:**
- Слишком узкий таргетинг
- Низкий CPM bid
- Креатив не одобрен модерацией
- Маленькая аудитория в выбранном регионе

**Решение:**
1. Расширить таргетинг (добавить страны, убрать ограничения)
2. Увеличить bid
3. Проверить креатив на соответствие правилам
4. Связаться с менеджером Viber Ads

### Низкий CTR рекламы

**Оптимизация:**
1. Тестировать разные креативы (A/B тест)
2. Использовать анимированные баннеры
3. Четкий CTA (call-to-action)
4. Релевантный оффер для аудитории
5. Локализация (текст на языке аудитории — русский для СНГ)

## Стикеры

### Стикерпак не отображается в Sticker Market

**Причины:**
- Пак приватный (не публичный)
- Нарушение правил контента
- Неправильный формат изображений

**Решение:**
1. Проверить настройку видимости — "Public"
2. Убедиться, что изображения 490x490 px, PNG
3. Не более 24 стикеров в паке
4. Контент не нарушает правила Viber

## Приватность и безопасность

### Аккаунт взломан

**Действия:**
1. Деактивировать Viber на всех устройствах
2. Переустановить Viber
3. Активировать с тем же номером
4. Включить двухфакторную аутентификацию
5. Проверить привязанные устройства в настройках

### Спам в Community

**Решение:**
1. Включить модерацию (одобрение сообщений)
2. Забанить спамеров (они не смогут вернуться)
3. Назначить дополнительных модераторов
4. Включить режим "только админы могут писать" временно
5. Настроить автоматические правила (если доступно)

## Интеграция

### Webhook не работает

**Причины:**
- Неправильный URL
- Сервер недоступен
- SSL-сертификат невалиден
- Firewall блокирует запросы

**Решение:**
1. Проверить URL (HTTPS обязателен)
2. Проверить доступность сервера извне
3. Проверить SSL-сертификат (валидный, не self-signed)
4. Открыть порты для IP-адресов Viber
5. Проверить логи сервера на ошибки

### API возвращает ошибки

**Частые ошибки:**
- `401 Unauthorized` — неверный токен
- `403 Forbidden` — нет прав на действие
- `429 Too Many Requests` — превышен лимит запросов
- `500 Internal Server Error` — ошибка на стороне Viber

**Решение:**
1. Проверить токен авторизации
2. Проверить права аккаунта
3. Добавить retry с exponential backoff
4. Связаться с поддержкой CPaaS-партнера
