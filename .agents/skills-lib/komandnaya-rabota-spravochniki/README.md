# Командная работа: Справочники -- скилл создания production-ready справочников

## Описание

Специализированный скилл для создания production-ready справочников по платформам,
сервисам, транспортным системам и другим темам. 18 тиммейтов, 5 волн, от исследования
до интерактивной презентации.

## Зависимость

Этот скилл РАСШИРЯЕТ скилл `командная-работа`. Сначала ознакомься с ним.
Все универсальные принципы (Quality Gates, Error Recovery, Retry Budget,
Handoff-протокол, защита контекста, управление командой, Pre-flight Check,
калькулятор команды, метрики, антипаттерны) находятся в скилле `командная-работа`.

## Как использовать

1. Убедись что знаком со скиллом `командная-работа` (prerequisite)
2. Определи тему справочника и выбери пресет из references/адаптация-разделов.md
3. Следуй Quick Start в SKILL.md (10 шагов)
4. Используй references/шаблоны-промптов.md для промптов каждого из 18 агентов
5. Проверяй Definition of Done из references/чеклисты.md
