# EXP-100: Паттерн "Summarize + Delegate to References" для T-003

**Дата:** 2026-02-17
**Проект:** Волна 5 рефакторинга скиллов
**Категория:** pattern

## Описание
Для снижения word count SKILL.md до ≤5000 слов без потери контента:

1. **Оставить в SKILL.md** (3500-5000 слов):
   - YAML frontmatter (без изменений!)
   - Введение, Quick Start
   - Ключевые таблицы и формулы
   - Сводные таблицы с командами/скриптами
   - Таблица ресурсов (ссылки на все reference-файлы)

2. **Вынести в references/**:
   - Полные блоки кода (>20 строк)
   - JSON-схемы, конфигурации
   - Детальные примеры и шаблоны
   - Пошаговые инструкции
   - Развёрнутые таблицы

3. **В месте выноса оставить ссылку:**
   ```
   → Подробнее: references/имя-файла.md
   ```

## Ключевое правило
НОЛЬ удалений. Каждое слово из оригинала должно быть либо в SKILL.md, либо в references/.
Допускается конденсация (переформулировка короче), но НЕ удаление сущностей.
