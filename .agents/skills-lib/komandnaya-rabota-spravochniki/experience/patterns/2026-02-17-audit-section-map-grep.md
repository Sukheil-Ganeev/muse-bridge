# EXP-101: Аудит рефакторинга: карта секций + grep ключевых сущностей

**Дата:** 2026-02-17
**Проект:** Волна 5 рефакторинга скиллов
**Категория:** pattern

## Описание
Двухэтапная верификация после рефакторинга скиллов:

### Этап 1: Карта секций
Для каждого заголовка (## / ###) из бэкапа определить:
| Секция | В SKILL.md | В references/ | Статус |
Статусы: полностью / сокращено / перенесено / потеряно

### Этап 2: Grep ключевых сущностей
Из бэкапа извлечь уникальные сущности:
- Функции, классы, скрипты
- API endpoints, URLs
- Числа, цены, пороги
- Переменные окружения
- Технические термины

Для каждой: `grep -rl "термин" skill_path/`

## Результаты
- генератор-объявлений: 60+ сущностей, 0 потерь
- экспорт-whatsapp: 160+ сущностей, 0 потерь
- туризм-оаэ: 94 сущности, 0 потерь

## Правило
После ЛЮБОГО рефакторинга скилла обязательно:
1. wc -w на SKILL.md (≤5000)
2. Карта секций бэкап vs текущий
3. Grep 20+ ключевых сущностей
4. Сравнение total word count (SKILL + refs, до vs после)

## Обязательное условие
Бэкап ДО рефакторинга — обязателен. Без бэкапа аудит невозможен.
