# EXP-CMD-017: DAG-оркестрация для исследовательских справочников с презентациями

**Дата:** 2026-02-18
**Проект:** Credit Cards Research (ОАЭ vs Россия)
**Контекст:** 3 MD-документа (ОАЭ, Россия, Сравнение) + 3 HTML→PDF презентации. Документы -- структурированные справочники по кредитным картам.

## Проблема / Ситуация

При создании справочников по нескольким связанным темам (например, "Кредитные карты ОАЭ" и "Кредитные карты России") нужен сравнительный документ. Наивный подход: сначала ВСЕ исследования, потом сравнение, потом ВСЕ презентации. Это теряет время, потому что презентация по ОАЭ не зависит от исследования России.

## Решение / Паттерн

### DAG-зависимости для справочников

```
Справочник ОАЭ ──┬──> Сравнительный документ ──> Презентация "Dual Bridge"
                  │
Справочник РФ  ──┘
       │
       ├──> Презентация "Gold Vault" (ОАЭ)    -- зависит ТОЛЬКО от справочника ОАЭ
       └──> Презентация "Frost Finance" (РФ)   -- зависит ТОЛЬКО от справочника РФ
```

### Применение к справочникам

1. **Исследование тем** запускать ПАРАЛЛЕЛЬНО (каждый исследователь -- отдельный агент)
2. **Сравнительный/обзорный документ** блокируется ВСЕМИ исследованиями
3. **Презентации по отдельным темам** блокируются ТОЛЬКО своим документом
4. **Brainstorm → AskUser → Plan → Team** -- правильная последовательность до создания команды

### Отличие от стандартного 4-волнового pipeline

Стандартный pipeline справочников (Волна 1 research → Волна 2 critic → Волна 3 writer → Волна 4 QA) работает ВНУТРИ каждого исследования. DAG добавляет параллелизм МЕЖДУ исследованиями + точечные зависимости для перекрёстных документов.

### Презентационные агенты для справочников

- Полный CSS :root с палитрой в промпте
- Структура КАЖДОГО слайда (заголовок, компоненты, данные из справочника)
- Запрет: animation, backdrop-filter, conic-gradient, vh/vw (ограничения PDF)
- Zero-dependency: системные шрифты, inline SVG, CSS gradients
- Playwright скрипт конвертации HTML→PDF прямо в промпте
- Серия: общие компоненты (.slide, .card, .styled-table) + уникальная палитра каждой

## Результат

- 2 справочника + 1 сравнительный документ + 3 презентации
- Презентации ОАЭ и РФ стартовали до завершения сравнительного документа
- Экономия ~30% времени vs полностью последовательное выполнение
- Единая дизайн-система серии: Gold Vault (золото), Frost Finance (синий лёд), Dual Bridge (фиолетовый)

## Правило на будущее

Для проектов справочников по N связанным темам:
- Исследования: N параллельных агентов
- Сравнение: 1 агент, addBlockedBy все исследования
- Презентации: N+1 агент (N по темам + 1 сравнительная), addBlockedBy ТОЛЬКО свой документ
- VS-layout для сравнительных презентаций
- Ambient glow (2 блоба/слайд) как визуальный код темы
