# Адаптация разделов для справочников
> Актуально на: 2026-02-14

## Общие правила

1. Architect ВСЕГДА определяет разделы в Волне 1
2. Рекомендуется 10-16 разделов, но architect определяет реальное количество исходя из объёма темы. 8 полных разделов лучше чем 14 с водой. 18 плотных — лучше чем 14 с объединёнными темами. Architect обосновывает выбор в structure-plan.md.
3. Каждый раздел = 3-5 файлов = 1 подпапка
4. Исследователи распределяются по 2-3 раздела каждый
5. Баланс: ни один раздел не должен быть "пустым"

## Инструкция по адаптации

### Использование пресета

1. Architect в Волне 1 ВЫБИРАЕТ подходящий пресет
2. Адаптирует названия разделов под конкретную тему
3. Распределяет исследователей (по 2-3 раздела на каждого)
4. Сохраняет в structure-plan.md

### Правила адаптации

- **Не копируй пресет один в один** — адаптируй названия под тему
- **Оцени объём** — если тема маленькая, сократи до 8-10 разделов
- **Оцени сложность** — если тема обширная, расширь до 16-18 разделов
- **Каждый раздел должен быть содержательным** — лучше меньше, но полных
- **Нет подходящего пресета?** — architect создаёт свою структуру с нуля, используя пресеты как ориентир

### Создание нового пресета

Если тема не подходит ни под один пресет:

1. Определи ключевые аспекты темы (8-18 штук)
2. Группируй по логическим блокам
3. Убедись в покрытии: обзор → детали → практика → ресурсы
4. Добавь пресет в этот файл для будущего использования
