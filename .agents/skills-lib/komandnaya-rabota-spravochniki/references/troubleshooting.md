# Troubleshooting: Решение проблем при создании справочников
> Актуально на: 2026-02-14

## Writer не вмещает все файлы

**Проблема:** Technical-writer пытается загрузить все 9 файлов (7 research + critic + advocate) одновременно и переполняет контекст.

**Решение:** Поэтапная обработка файлов:
1. Этап 1: Прочитай structure-plan.md + critic-report.md + advocate-verification.md
2. Этап 2: Для КАЖДОГО раздела читай один research-N.md → запиши раздел → перейди к следующему
3. Этап 3: Собери SKILL.md + README.md

В промпте writer'а указать: "НЕ читай все файлы сразу. Читай по одному research файлу на раздел."

## Critic переполняется

**Проблема:** Critic загружает все 7 файлов исследований и не может обработать.

**Решение:** Попарное чтение + запись сразу в файл:
1. Прочитай structure-plan.md
2. Читай файлы ПОПАРНО: research-1 + research-2 → запиши проблемы в critic-report.md
3. research-3 + research-4 → ДОПИСАТЬ (append) в critic-report.md
4. research-5 + research-6 → ДОПИСАТЬ в critic-report.md
5. Финализируй critic-report.md

В промпте critic'а: "НЕ читай все файлы сразу. Читай попарно, записывай проблемы сразу в critic-report.md."

## Презентация > 250KB

**Проблема:** HTML файл превышает лимит 250KB.

**Решение:**
- Убрать дублирующиеся CSS стили
- Сократить inline-данные (длинные таблицы → компактный формат)
- Убрать неиспользуемый JS код
- Проверить нет ли встроенных base64 изображений
- Если невозможно — разбить на 2 файла (основной + приложение)

## Dark mode: элементы невидимы

**Проблема:** На тёмном фоне не видны текст, границы таблиц, ссылки.

**Решение:**
- Проверить контраст КАЖДОГО элемента (WCAG AA >= 4.5:1)
- rgba < 20% = невидимо на тёмном → заменить на видимые цвета
- Протестировать: текст, заголовки, таблицы, код, ссылки, границы, кнопки
- Dark mode base: #22223a — проверять цвета относительно него

## Scrollbar стандартный

**Проблема:** Браузер показывает стандартный 17px scrollbar вместо кастомного.

**Решение:** CSS overrides для обоих движков:
```css
/* Firefox */
* { scrollbar-width: thin; }

/* Chrome/Safari */
::-webkit-scrollbar { width: 6px; }
::-webkit-scrollbar-thumb { border-radius: 3px; }
```
Styled под обе темы (light и dark).

## CSS transition вместо overlay

**Проблема:** При переключении темы элементы мигают по отдельности ("лоскутный" эффект).

**Решение:** Заменить CSS transitions на overlay fade:
1. Создать overlay div с position: fixed, покрывающий весь экран
2. При смене темы: overlay opacity 0 → 1 (150ms)
3. Пока overlay виден — сменить тему (data-theme attribute)
4. Overlay opacity 1 → 0 (150ms)
5. НЕ использовать CSS transition на отдельных элементах для смены цвета

## initTheme() вызывает вспышку

**Проблема:** При загрузке страницы видна вспышка смены темы.

**Решение:**
1. Disable all transitions перед установкой темы
2. Set theme из localStorage
3. Enable transitions обратно
4. Это предотвращает "вспышку" при загрузке

## Исследователь не находит данные

**Проблема:** WebSearch не возвращает результатов по теме.

**Решение:**
- Пометить [НЕ НАЙДЕНО] — не выдумывать данные
- Попробовать альтернативные запросы (другие ключевые слова)
- Поискать на другом языке (EN если RU не работает, и наоборот)
- Проверить официальный сайт напрямую
- Записать в секцию ОБНАРУЖЕНО если нашёл смежные данные

## Файл > 15KB

**Проблема:** Раздел справочника превышает рекомендуемый размер.

**Решение:**
- Разбить на логические подфайлы (обзор.md + детали-1.md + детали-2.md)
- НЕ обрезать контент — лучше больше файлов чем потерять информацию
- Каждый подфайл = одна логическая тема
