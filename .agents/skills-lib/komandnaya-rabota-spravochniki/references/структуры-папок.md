# Структуры папок для справочников
> Актуально на: 2026-02-14

## Скилл

```
~/.claude/skills/{name}/
├── SKILL.md (~5000 слов)
├── README.md
├── references/
│   ├── faq.md
│   ├── troubleshooting.md
│   ├── cheatsheet.md
│   └── {специфичные для скилла}.md
├── diagrams/
│   ├── architecture.mmd
│   ├── workflow.mmd
│   └── dependencies.mmd
├── templates/
│   ├── {шаблон-1}.md
│   └── {шаблон-N}.md
└── experience/
    ├── _index.md
    ├── fixes/
    ├── improvements/
    ├── patterns/
    └── warnings/
```
