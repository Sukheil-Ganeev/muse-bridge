**Полное руководство по myTarget для туристического бизнеса ОАЭ (2026)**

## Обзор myTarget

**myTarget** (target.my.com) - рекламная платформа Mail.ru Group с доступом к аудитории ВКонтакте, Одноклассников, Mail.ru, Юла, и других площадок.

### Почему myTarget для туризма?

1. **90+ миллионов пользователей РФ/СНГ** - огромная аудитория
2. **Look-alike аудитории** - найти похожих на ваших клиентов (лучший алгоритм на рынке РФ)
3. **Размещение на VK + OK** - два крупнейших соцсети одновременно
4. **Мощный ретаргетинг** - пиксель myTarget на сайте
5. **Multiformat ads** - автоматическая адаптация креативов для всех площадок

**Аудитория:** 70+ миллионов активных пользователей РФ

**Аудитория:** 40+ миллионов (возраст 35-65 лет, регионы РФ)

**Где показывается:**
- Лента

**Почему важно для туризма:**
- Более взрослая аудитория (35-65 лет) - имеют деньги на туры
- Популярно в регионах (не только Москва/СПб)

### 3. Mail.ru

**Аудитория:** 25+ миллионов (email пользователи)

**Где показывается:**
- Главная страница Mail.ru
- Почта (правый блок)

### 4. Юла (Classifieds)

**Аудитория:** 20+ миллионов (покупатели/продавцы товаров/услуг)

**Где показывается:**
- Между объявлениями
- Категории (может быть релевантно для локальных туруслуг)

### 5. Мобильные приложения

**Где показывается:**
- В приложениях партнёров (тысячи приложений)
- Форматы: баннеры, видео, native ads

### Шаг 3: Look-alike аудитории (КЛЮЧЕВАЯ ФИЧА!)

**Look-alike = myTarget находит пользователей, похожих на ваших клиентов.**

**Почему myTarget лучший для look-alike:**
- Доступ к данным VK + OK + Mail.ru (миллионы профилей)
- Алгоритм машинного обучения анализирует 100+ параметров (интересы, поведение, демография)
- Высокая точность (конверсия на 50-200% выше, чем холодный трафик)

#### Создание look-alike аудитории

**Вариант A: На основе базы клиентов**

1. В myTarget → "Аудитории" → "Создать аудиторию"
2. Выберите "Загрузить список"
3. Загрузите файл CSV/TXT с данными клиентов:
   - Email (обязательно)
   - Phone (опционально)
   - VK ID (если есть)

**Формат файла:**

```csv
email,phone
ivan@example.com,+79991234567
maria@mail.ru,+79161234567
```

**Минимальное количество:** 100 человек (рекомендуется 500+)

4. myTarget сопоставит данные с профилями пользователей (match rate 30-60%)
5. Создайте look-alike:
   - "Создать похожую аудиторию"
   - Размер: 1% (самые похожие, 500K-1M человек) до 10% (менее похожие, 5-10M человек)
   - География: Москва, СПб, регионы

**Результат:** Аудитория пользователей, похожих на ваших клиентов по интересам, поведению, демографии.

**Вариант B: На основе пикселя (конверсии)**

1. Установите пиксель myTarget на сайт
2. Соберите минимум 1,000 конверсий (заявок/покупок)
3. Создайте сегмент "Оформили заявку"
4. Создайте look-alike на основе этого сегмента

**Когда использовать:** Когда хотите масштабироваться (найти больше похожих клиентов).

### Шаг 4: Ретаргетинг

**Ретаргетинг = показ рекламы посетителям вашего сайта.**

#### Создание аудитории ретаргетинга

1. Установите пиксель myTarget (см. выше)
2. В myTarget → "Аудитории" → "Создать аудиторию на основе счётчика"
3. Выберите условия:

**Примеры аудиторий:**

**1. Все посетители сайта (30 дней)**
- Условие: посетили любую страницу за последние 30 дней
- Размер: зависит от трафика (например, 10,000 человек)

**2. Посетители страницы туров, но не оформили заявку**
- Условие 1: URL содержит `/tours/`
- Условие 2: НЕ посетили URL `/thank-you` (страница благодарности)
- Период: последние 30 дней

**3. Добавили в корзину, но не купили**
- Условие: событие `add_to_cart`
- Исключить: событие `purchase`

**4. Купили недавно (для up-sell)**
- Условие: событие `purchase`
- Период: последние 7-14 дней
- Креатив: "Понравился тур? Забронируйте yacht tour со скидкой!"

#### Настройка ретаргетинга в кампании

1. Создайте группу объявлений "Ретаргетинг"
2. Таргетинг → "Аудитории" → Выберите созданную аудиторию
3. Креатив: специальное предложение (скидка, бонус)

**Пример:**
- Аудитория: посетители страницы yacht tours
- Креатив: "Вернитесь и получите скидку 15% на аренду яхты!"
- Кнопка: "Забронировать со скидкой"

## Ставки и бюджет

### Модель ставок: CPM (Cost Per Mille)

**myTarget использует CPM** - цена за 1000 показов.

**Средние ставки 2026 (туризм):**
- Минимум: 50₽/1000 показов
- Средний: 100-250₽/1000 показов
- Конкурентные аудитории: 200-400₽/1000 показов

**Расчёт бюджета:**

**Пример:**
- Бюджет: 30,000₽
- CPM: 150₽
- Показы: 30,000₽ / 150₽ × 1000 = 200,000 показов
- CTR: 1.5% (средний для display)
- Клики: 200,000 × 1.5% = 3,000 кликов
- CPC: 30,000₽ / 3,000 = 10₽
- Конверсия клик → лид: 4%
- Лиды: 3,000 × 4% = 120 лидов
- Стоимость лида: 30,000₽ / 120 = **250₽**

### Дневной бюджет

**Рекомендации:**
- **Тестирование:** 500-1,000₽/день (15-30K₽/месяц)
- **Масштабирование:** 2,000-5,000₽/день (60-150K₽/месяц)
- **Агрессивный рост:** 10,000₽+/день (300K₽+/месяц)

### Стратегии оптимизации ставок

#### 1. Ручная (для начинающих)

Вы указываете фиксированную ставку CPM (например, 150₽).

#### 2. Автоматическая "Максимум кликов"

myTarget оптимизирует ставки для максимального количества кликов.

**Настройка:**
- Укажите дневной бюджет: 1,000₽
- myTarget сам выбирает оптимальные ставки

#### 3. Автоматическая "Максимум конверсий"

myTarget оптимизирует под конверсии (заявки, покупки).

**Настройка:**
- Установите пиксель myTarget
- Настройте отслеживание конверсий
- Укажите дневной бюджет
- myTarget повышает ставки на аудитории, которые конвертят лучше

**Когда использовать:** После 50+ конверсий (чтобы алгоритм понял, кто ваша аудитория).

## API интеграция (для разработчиков)

### myTarget API

**Документация:** https://target.my.com/api/

**Для чего использовать:**
- Автоматическое создание кампаний
- Массовое редактирование объявлений
- Получение статистики
- Автоматическая загрузка аудиторий (look-alike, ретаргетинг)

### Python пример: Создание look-alike аудитории

```python
import requests

API_TOKEN = 'your_api_token'  # Получите в кабинете myTarget
BASE_URL = 'https://target.my.com/api/v2'

def create_lookalike_audience(source_audience_id, size_percent):
    """Создать look-alike аудиторию"""

    headers = {
        'Authorization': f'Bearer {API_TOKEN}',
        'Content-Type': 'application/json'
    }

    data = {
        'name': f'Look-alike {size_percent}%',
        'source_audience_id': source_audience_id,
        'size_percent': size_percent,  # 1-10%
        'geo': ['1'],  # 1 = Россия
    }

    response = requests.post(
        f'{BASE_URL}/audiences/lookalike.json',
        headers=headers,
        json=data
    )

    return response.json()

# Создать look-alike 3% на основе базы клиентов
source_id = 123456  # ID загруженной базы клиентов
lookalike = create_lookalike_audience(source_id, 3)
print(f"Look-alike audience created: {lookalike['id']}")
```

### Node.js пример: Получение статистики

```javascript
const axios = require('axios');

const API_TOKEN = 'your_api_token';
const BASE_URL = 'https://target.my.com/api/v2';

async function getCampaignStats(campaignId, dateFrom, dateTo) {
  const response = await axios.get(
    `${BASE_URL}/statistics/campaigns.json`,
    {
      headers: { Authorization: `Bearer ${API_TOKEN}` },
      params: {
        id: campaignId,
        date_from: dateFrom,  // YYYY-MM-DD
        date_to: dateTo,
      }
    }
  );

  const stats = response.data.items[0];

  return {
    impressions: stats.impressions,
    clicks: stats.clicks,
    spent: stats.spent,
    cpm: (stats.spent / stats.impressions * 1000).toFixed(2),
    cpc: (stats.spent / stats.clicks).toFixed(2),
  };
}

// Получить статистику за последнюю неделю
getCampaignStats(123456, '2026-01-29', '2026-02-05').then(stats => {
  console.log('Campaign Stats:');
  console.log(`Impressions: ${stats.impressions}`);
  console.log(`Clicks: ${stats.clicks}`);
  console.log(`Spent: ${stats.spent}₽`);
  console.log(`CPM: ${stats.cpm}₽`);
  console.log(`CPC: ${stats.cpc}₽`);
});
```

## Частые ошибки

### Ошибка 1: Маленькая база для look-alike

**Проблема:** Загрузили 50 email для создания look-alike.

**Почему плохо:**
- Малая выборка (алгоритм не понимает, кто ваша аудитория)
- Низкий match rate (30-40%)
- Неточный look-alike

**Решение:**
- Минимум 100 контактов (рекомендуется 500+)
- Используйте лучших клиентов (купивших премиум продукты)

### Ошибка 2: Игнорирование Одноклассников

**Проблема:** Показываем рекламу только на VK.

**Почему плохо:**
- Упускаете 40+ млн аудитории
- OK - более взрослая, платежеспособная аудитория

**Решение:**
- Тестируйте OK (особенно для семейных туров, возраст 35-55)

### Ошибка 3: Нет сегментации ретаргетинга

**Проблема:** Показываете одинаковую рекламу всем посетителям сайта.

**Решение:**
- Сегментируйте:
  - Посетители главной → реклама общих туров
  - Посетители Desert Safari → реклама Desert Safari со скидкой
  - Посетители Yacht Tours → реклама luxury яхт
  - Оформили заявку → исключить из ретаргетинга
