**Полное руководство по аналитике рекламных кампаний для туризма ОАЭ (2026)**

## Сквозная аналитика

### Что такое сквозная аналитика?

**Сквозная аналитика = отслеживание всего пути клиента от первого клика до продажи.**

**Воронка:**
```
Клик в рекламе (VK/Яндекс/Telegram)
    ↓
Посещение сайта
    ↓
Заявка (заполнил форму)
    ↓
Звонок (менеджер связался)
    ↓
Оплата (купил тур)
```

**Зачем:** Понять, какая реклама привела к продаже (а не просто к кликам).

### Инструменты сквозной аналитики

#### 1. CallTouch (15,000₽/месяц)

**Что делает:**
- Отслеживает звонки (динамический номер телефона для каждого рекламного источника)
- Показывает, с какой рекламы пришёл звонок
- Записывает разговоры
- Интеграция с CRM

**Пример:**
- Клиент кликнул рекламу VK → на сайте видит номер +7-999-123-XXXX (динамический)
- Клиент позвонил → CallTouch записал: "Звонок из VK Реклама, кампания Desert Safari"
- Клиент купил → в CRM видно: "Источник: VK Реклама, ROI 400%"

**Цена:** 15,000₽/месяц (тариф "Стандарт", 1000 звонков)

#### 2. Roistat (25,000₽/месяц)

**Что делает:**
- Полная сквозная аналитика (звонки + заявки + продажи)
- Отслеживает весь путь клиента
- Рассчитывает ROI по каждой платформе
- Интеграция с CRM, 1С, Битрикс24

**Пример воронки в Roistat:**
```
01.02.2026 10:00 - Клик в VK Реклама (кампания Desert Safari)
01.02.2026 10:01 - Посещение сайта (страница /desert-safari)
01.02.2026 10:05 - Заявка (заполнил форму)
01.02.2026 10:10 - Звонок (менеджер Мария, 5 минут)
01.02.2026 10:30 - Оплата (4,000₽, Desert Safari)

ROI: (4,000₽ - 300₽ затраты на рекламу) / 300₽ = 1,233%
```

**Цена:** 25,000₽/месяц (тариф "Профессиональный")

#### 3. Google Analytics 4 (бесплатно) + CRM интеграция

**Что делает:**
- Отслеживает посещения сайта
- Показывает источники трафика (VK, Яндекс, Telegram)
- Воронка конверсий
- НО: не отслеживает звонки и оффлайн-продажи (нужна интеграция с CRM)

**Интеграция с CRM (Битрикс24, amoCRM):**
1. В Google Analytics настройте цель "Заявка"
2. В CRM настройте вебхук (webhook): когда клиент купил → отправить событие в GA4
3. GA4 покажет: "5 заявок из VK → 1 продажа (20% конверсия)"

**Цена:** Бесплатно (GA4) + 0₽ (если CRM поддерживает интеграцию)

## Attribution Models (модели атрибуции)

### Что такое атрибуция?

**Атрибуция = кому "присвоить" продажу, если клиент взаимодействовал с несколькими рекламными каналами.**

**Пример:**
```
День 1: Клиент увидел рекламу VK (Desert Safari)
День 3: Клиент погуглил "туры в дубай" → кликнул Яндекс.Директ
День 5: Клиент вернулся через Telegram Ads
День 7: Клиент купил тур

Вопрос: Какая реклама привела к продаже? VK? Яндекс? Telegram?
```

### Модель 1: Last Click (последний клик)

**Принцип:** 100% заслуга последнему источнику (перед покупкой).

**Пример:**
```
VK → Яндекс → Telegram (КУПИЛ)
Атрибуция: Telegram = 100%
```

**Плюсы:**
- Просто (используется по умолчанию в Google Analytics, Яндекс.Метрике)

**Минусы:**
- Игнорирует первые касания (VK познакомил клиента с брендом, но заслугу получил Telegram)

**Когда использовать:** Если бюджет маленький и нужна простота.

---

### Модель 2: First Touch (первое касание)

**Принцип:** 100% заслуга первому источнику.

**Пример:**
```
VK (ПЕРВЫЙ) → Яндекс → Telegram → КУПИЛ
Атрибуция: VK = 100%
```

**Плюсы:**
- Учитывает важность знакомства с брендом

**Минусы:**
- Игнорирует, что клиент мог забыть о вас, и Telegram напомнил

**Когда использовать:** Для оценки эффективности брендинговых кампаний (VK, Telegram Ads).

---

### Модель 3: Linear (равномерное распределение)

**Принцип:** Заслуга делится поровну между всеми источниками.

**Пример:**
```
VK → Яндекс → Telegram → КУПИЛ
Атрибуция: VK = 33%, Яндекс = 33%, Telegram = 33%
```

**Плюсы:**
- Учитывает вклад всех каналов

**Минусы:**
- Не учитывает, что последний канал (перед покупкой) важнее

**Когда использовать:** Для общего понимания вклада каждого канала.

---

### Модель 4: Time Decay (с учётом времени)

**Принцип:** Чем ближе касание к покупке, тем больше заслуга.

**Пример:**
```
VK (7 дней назад) → Яндекс (3 дня назад) → Telegram (1 день назад) → КУПИЛ
Атрибуция: VK = 20%, Яндекс = 30%, Telegram = 50%
```

**Плюсы:**
- Учитывает, что последние касания важнее (решающий фактор)

**Минусы:**
- Всё ещё недооценивает первое знакомство

**Когда использовать:** Для точной оценки вклада каждого канала (рекомендуется).

---

### Модель 5: Position-Based (U-образная)

**Принцип:** 40% первому источнику, 40% последнему, 20% остальным.

**Пример:**
```
VK → Яндекс → Telegram → КУПИЛ
Атрибуция: VK = 40%, Яндекс = 20%, Telegram = 40%
```

**Плюсы:**
- Учитывает важность как первого знакомства, так и последнего касания

**Минусы:**
- Сложнее настроить

**Когда использовать:** Для мультиканальных кампаний (идеально для туризма).

## Настройка аналитики

**Установка:**

1. Создайте аккаунт GA4 на analytics.google.com
2. Скопируйте тег (Measurement ID: G-XXXXXXXXXX)
3. Вставьте на сайт:

```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

**Настройка целей (событий):**

**Цель 1: Просмотр страницы туров**
```javascript
gtag('event', 'view_tours', {
  'tour_type': 'Desert Safari'
});
```

**Цель 2: Заявка оформлена**
```javascript
gtag('event', 'lead', {
  'tour_type': 'Desert Safari',
  'price': 4000
});
```

**Цель 3: Покупка**
```javascript
gtag('event', 'purchase', {
  'transaction_id': 'T12345',
  'value': 4000,
  'currency': 'RUB',
  'items': [{
    'item_name': 'Desert Safari',
    'price': 4000,
    'quantity': 1
  }]
});
```

## Воронка продаж

### Пример воронки для туров

```
100% - Клик в рекламе (10,000 кликов)
  ↓ 80%
 80% - Посещение сайта (8,000 посещений)
  ↓ 5%
  4% - Заявка (400 заявок)
  ↓ 50%
  2% - Звонок состоялся (200 звонков)
  ↓ 50%
  1% - Оплата (100 продаж)
```

**Где теряются клиенты:**
- 20% после клика → не дошли до сайта (долгая загрузка, нерелевантный лендинг)
- 76% на сайте → не оставили заявку (сложная форма, нет доверия)
- 50% после заявки → не дозвонились или менеджер не убедил
- 50% после звонка → не оплатили (долгое принятие решения)

**Как оптимизировать:**
- Ускорить загрузку сайта (< 2 секунды)
- Упростить форму (минимум полей: имя, телефон, WhatsApp кнопка)
- Отвечать на заявки за 5 минут (конверсия +300%)
- Дожимать клиентов (повторный звонок через день)

## LTV (Lifetime Value)

### Что такое LTV?

**LTV = сколько денег клиент принесёт за всё время (не только первая покупка).**

**Пример:**
```
Покупка 1 (февраль 2026): Desert Safari - 4,000₽
Покупка 2 (декабрь 2026): Yacht Tour - 200,000₽
Покупка 3 (апрель 2027): City Tour - 6,000₽

LTV = 4,000₽ + 200,000₽ + 6,000₽ = 210,000₽
```

**Средний LTV для туризма ОАЭ:**
- Клиенты возвращаются 1.5-2 раза за 3 года
- Средний чек растёт (первый раз - стандартный тур, потом - премиум)
- LTV = первая покупка × 2-3

**Зачем считать LTV:**
- Можно потратить больше на привлечение (CAC может быть выше маржи первой покупки)

**Пример:**
- Первая покупка: Desert Safari, 4,000₽, маржа 1,200₽
- CAC: 2,500₽ → убыток -1,300₽
- НО: LTV 210,000₽ (повторные покупки) → прибыль 207,500₽
- **Вывод:** Можно тратить до 50,000₽ на привлечение и всё равно быть в плюсе!

## Cohort анализ

### Что такое cohort анализ?

**Cohort анализ = анализ групп клиентов, пришедших в один период.**

**Пример:**
```
Cohort январь 2026: 100 клиентов пришло из VK Реклама
- Месяц 1 (январь): 20 покупок (20% конверсия)
- Месяц 2 (февраль): 5 повторных покупок (+5%)
- Месяц 3 (март): 3 повторных покупки (+3%)

Итого: 28% конверсия за 3 месяца (вместо 20% за первый месяц)
```

**Зачем:**
- Понять, какие месяцы лучше для привлечения (летом клиенты дешевле, но меньше покупают сразу)
- Рассчитать LTV точнее

**Инструменты:**
- Google Analytics 4 (отчёт "Cohort Analysis")
- Excel/Google Sheets (ручной расчёт)

## Дашборды (dashboard)

### Что такое дашборд?

**Дашборд = единая панель с ключевыми метриками в реальном времени.**

**Пример дашборда для туризма:**

│  ROI ПО ПЛАТФОРМАМ (последние 30 дней)         │

│  Яндекс.Директ: 200% (30K затрат → 60K выручка) │
│  Telegram Ads:  400% (20K затрат → 80K выручка) │
│  myTarget:      250% (10K затрат → 25K выручка) │

### Инструменты для дашбордов

**1. Google Data Studio (бесплатно)**
- Подключается к GA4, Яндекс.Метрике
- Автообновление данных
- Шаринг с командой

**2. Metabase (open-source, бесплатно)**
- Подключается к любым базам данных
- SQL запросы
- Self-hosted

**3. Roistat/CallTouch (встроенные дашборды)**
- Готовые отчёты по ROI
- Интеграция с CRM

## Заключение

Аналитика = основа оптимизации рекламных кампаний.

**Ключевые рекомендации:**

1. **Установите сквозную аналитику** (CallTouch/Roistat или GA4 + CRM интеграция)
2. **Используйте правильную модель атрибуции** (Time Decay или Position-Based для мультиканальных кампаний)
3. **Считайте LTV**, а не только ROI первой покупки
4. **Создайте дашборд** для ежедневного мониторинга
5. **Анализируйте воронку** - находите узкие места и оптимизируйте

**Целевые метрики:**
- ROI: 200-500% (хорошо)
- Конверсия сайт → заявка: 3-10%
- Конверсия заявка → продажа: 15-30%
- LTV: 2-3× от первой покупки

Удачи в аналитике!
