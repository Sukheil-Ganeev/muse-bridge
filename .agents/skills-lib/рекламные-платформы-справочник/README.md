## Experience (критические уроки)

### _index.md - Топ-10 уроков

**ОБЯЗАТЕЛЬНО ПРОЧИТАЙТЕ перед запуском первой кампании!**

**Что внутри:**
1. Тестируйте перед масштабированием (экономия 50,000₽)
2. Ретаргетинг = 80% результата
3. Креатив важнее таргетинга
4. Мобильный трафик = 70-80% (оптимизируйте сайт!)
5. ROI считайте с LTV, не с первой продажи
6. Скорость ответа = конверсия ×3
7. Минус-слова экономят 20-30% бюджета
8. Обновляйте креативы каждые 2-3 недели
9. Look-alike работает только на базе ≥100 клиентов
10. Сезонность: зима ×2 спрос, лето ÷2

**Чек-лист перед запуском:** 8 пунктов, которые нужно проверить.

### По платформам:

| Платформа | CTR | CPC | Стоимость лида | ROI |
|-----------|-----|-----|----------------|-----|
| **VK Реклама** | 1-3% | 15-30₽ | 200-800₽ | 200-500% |
| **Telegram Ads** | 3-10% | 5-20₽ | 300-1000₽ | 200-500% |
| **Яндекс.Директ (Поиск)** | 5-15% | 30-100₽ | 500-2000₽ | 150-400% |
| **Яндекс.Директ (РСЯ)** | 1-3% | 10-30₽ | 600-1500₽ | 150-300% |

| **Ретаргетинг (любая платформа)** | 2-5% | 5-15₽ | 100-500₽ | 500-1500% |

### Воронка продаж:

```
100% - Клик в рекламе
 80% - Посещение сайта (20% bounce)
  5% - Заявка (конверсия 5%)
 50% - Звонок состоялся
 50% - Оплата

Итого: 1-2% конверсия клик → продажа
```
