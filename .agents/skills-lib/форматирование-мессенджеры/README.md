# форматирование-мессенджеры

Объединённый скилл форматирования текстов для WhatsApp, Telegram и Email.

## Структура

```
форматирование-мессенджеры/
├── SKILL.md              # Основной файл — триггеры, синтаксис, шаблоны, правила
├── README.md             # Этот файл
└── references/
    ├── cheatsheet.md     # Шпаргалка синтаксиса всех 3 платформ
    └── faq.md            # Часто задаваемые вопросы
```

## Что внутри SKILL.md

1. **Триггеры** — объединённые из WhatsApp, Telegram и Email скиллов
2. **Сводная таблица синтаксиса** — WA vs TG vs Email в одной таблице
3. **Раздел 1: Мессенджеры (WA + TG)** — общие шаблоны с параметризацией синтаксиса, 6 типов контента, особенности каждой платформы, правила
4. **Раздел 2: Email** — структура делового письма, 5 типов писем, стилистические правила
5. **Сохранение файлов** — форматы и именование для каждой платформы

## Источники (объединены из)

- `форматирование-whatsapp` (DEPRECATED)
- `форматирование-telegram` (DEPRECATED)
- `форматирование-email` (DEPRECATED)

## Ключевые отличия платформ

| | WhatsApp | Telegram | Email |
|---|---|---|---|
| Жирный | `*текст*` | `**текст**` | Нет |
| Разделитель | 15 тире | 18 тире | Нет |
| Ссылки | Нет | `[текст](url)` | Plain URL |
| Макс. длина | ~1000 превью | 4096 символов | 300-1000 слов |
