## РАЗДЕЛ 1: МЕССЕНДЖЕРЫ (WhatsApp + Telegram)

### 1.1 Разделители

⚠️ **КРИТИЧЕСКОЕ ПРАВИЛО: использовать только тонкий разделитель `─`.**
- WhatsApp: 15 символов `─`
- Telegram: 15 символов `─`
- НИКОГДА не использовать жирные линии в сообщениях.

**WhatsApp (15 символов):**
- Тонкий: `───────────────` (15 × ─)

**Telegram (15 символов):**
- Тонкий: `───────────────` (15 × ─)

НИКОГДА не использовать обычные дефисы `---`.

### 1.2 Списки и эмодзи-маркеры (общие для WA и TG)

**Списки:**
- Основной маркер: `▫️` (для пунктов)
- Альтернативы: `•`, `—` (длинное тире)
- Нумерованные: `1️⃣ 2️⃣ 3️⃣` или `1. 2. 3.`
- Чекбоксы: `✅` (сделано) / `❌` (нет) / `⬜` (ожидание)

**Эмодзи-маркеры для заголовков:**
- Позиция: ПЕРЕД текстом, НЕ после
- Использовать уместные, не декоративные
- Примеры: 📌 📋 ⚠️ 💡 📅 👤 📧 📱 ⚡️ 🔑

### 1.3 Структура сообщений

Шаблоны ниже используют `{ж}` = жирный и `{к}` = курсив. Подставляй синтаксис платформы.

### 1.5 Особенности WhatsApp

- Максимум: превью обрезается после ~1000 символов
- Markdown-ссылки `[текст](url)` — НЕ поддерживаются (вставлять URL как есть)
- HTML-теги — НЕ поддерживаются
- Если длинно — разбить на серию постов + пост-оглавление
- Оптимально: 1 пост = 1 тема

### 1.6 Особенности Telegram

- Максимум: 4096 символов на сообщение
- Ссылки: поддерживает markdown `[текст](url)` — использовать где возможно
- Спойлеры: `||скрытый текст||`
- Подсветка кода с языком: ` ```python ` (с указанием языка)
- Редактирование после отправки
- Автоматический предпросмотр для ссылок
- В каналах нет цитирования через `>`
- Если длиннее 4096 — серия постов + пост-оглавление

#### 1.6.1 Продвинутое форматирование TG (из VoiceTranscriptionBot)

Практики проверены на боевом проекте (VoiceTranscriptionBot, 26 команд, 1419+ тестов). Используй при разработке Telegram-ботов или при оформлении сообщений, требующих HTML-разметки (parse_mode=HTML).

**Паттерн кроссплатформенных хелперов:**

При разработке ботов, работающих одновременно в Telegram и WhatsApp, используй хелпер-функции, которые принимают параметр `platform` и возвращают правильную разметку:

| Хелпер | TG результат (HTML) | WA результат | Когда использовать |
|--------|---------------------|--------------|-------------------|
| `_b(text, platform)` | `<b>text</b>` | `*text*` | Заголовки, важное |
| `_i(text, platform)` | `<i>text</i>` | `_text_` | Подсказки, второстепенное |
| `_code(text, platform)` | `<code>text</code>` | `` `text` `` | Числа, даты, суммы, телефоны |
| `_quote(text, platform)` | `<blockquote>text</blockquote>` | `> text` | Цитаты, контент, транскрипции |
| `_pre(text, platform)` | `<pre>text</pre>` | ` ```text``` ` | Таблицы, ASCII-графики |
| `_section(title, platform, icon)` | `icon <b>title</b>\n───────────────` | То же | Заголовок секции с разделителем |
| `_esc(text, platform)` | `html.escape()` | без изменений | Пользовательский ввод (XSS защита) |
| `_spoiler(text, platform)` | `<tg-spoiler>text</tg-spoiler>` | текст как есть | Скрытый текст (только TG) |

**Паттерн секции (Section Pattern):**

Каждая логическая секция сообщения оформляется единообразно — эмодзи + жирный заголовок + тонкий разделитель + список с маркерами:

```html
📊 <b>Заголовок секции</b>
───────────────
▫️ Пункт 1 — описание
▫️ Пункт 2 — описание
▫️ Пункт 3 — описание
───────────────
```

Хелпер `_section(title, platform, icon)` генерирует первые две строки автоматически.

**Константы разделителей:**

| Константа | Символ | Длина | Unicode | Использование |
|-----------|--------|-------|---------|--------------|
| Тонкий (DIVIDER) | `───────────────` | 15 | U+2500 | Между секциями внутри блока |
| Дополнительный DIVIDER | `───────────────` | 15 | U+2500 | Использовать тот же символ, что и DIVIDER |
| Маркер (MARKER) | `▫️` | — | — | Элемент списка |

Определяй как константы в коде, чтобы не считать символы вручную каждый раз.

**Blockquote для контента:**

Транскрипции, переводы, резюме, цитаты — ВСЕГДА оборачивай в `<blockquote>`. Это визуально отделяет контент от интерфейсных элементов:

```html
<blockquote>Текст транскрипции, перевода или резюме</blockquote>
```

В WhatsApp аналог — `> текст` (каждая строка с префиксом `>`).

**Экранирование (XSS защита):**

При использовании `parse_mode=HTML` в Telegram — обязательно экранируй ЛЮБОЙ пользовательский ввод через `html.escape()`:

| Тип данных | Обработка | Пример |
|-----------|-----------|--------|
| Числа, даты, суммы | Безопасны → оборачивай в `<code>` | `<code>4,500 AED</code>` |
| Телефоны | Безопасны → оборачивай в `<code>` | `<code>+971 55 309 6985</code>` |
| Текст от пользователя | ОПАСЕН → `html.escape(text)` | `html.escape(user_input)` |
| Имя клиента из БД | ОПАСЕН → `html.escape(name)` | `html.escape(client_name)` |

Без экранирования пользователь может вставить `<script>` или сломать HTML-разметку сообщения.

```html
😊 Настроение: нейтральное
```

### 1.7 Правила мессенджеров

**Обязательно:**
1. Разделители между секциями (WA: 15 символов, TG: 15 символов)
2. Использовать только тонкий разделитель `─` (WA: 15 символов, TG: 15 символов).
3. Заголовки всегда жирные
4. Эмодзи ПЕРЕД заголовком, не после
5. Длинное тире `—` для списков (не дефис `-`)
6. Цитаты: `>` + курсивом

**Запрещено:**
- Обычные дефисы `---` как разделители
- Эмодзи после заголовка (НЕПРАВИЛЬНО: `*Текст* 📌`)
- Больше 3-4 эмодзи на пост
- Стены текста без разделителей
- Путать синтаксис WA и TG (`*жирный*` в Telegram / `**жирный**` в WhatsApp)
- HTML-теги в WhatsApp
- Markdown-ссылки в WhatsApp

```
Best regards, / С уважением,
[Имя Фамилия]
[Должность / адрес / контакт]
```

### 2.2 Правила Email

**Тема письма (Subject):**
- Краткая, конкретная, до 70 символов
- Ключевые слова: номер дела, тема, срочность
- Примеры: `Re: Furniture Removal — RDSC Case No. 2026/03032/04`, `Urgent: Move-Out Permit Request, Unit 2905`
- Для ответов: `Re: [оригинальная тема]`
- Для срочных: начинать с `Urgent:`

**Обращение:**
- EN: `Dear Mr. [Surname],` / `Dear Ms. [Surname],`
- RU: `Уважаемый г-н [Фамилия],` / `Уважаемая г-жа [Фамилия],`
- Имя неизвестно: `Dear Sir/Madam,` / `To Whom It May Concern,`
- К организации: `Dear [Company] Management,`

**Вступление (1-2 предложения):**
- Ссылка: `I refer to your message dated...`
- Представление: `My name is [Name], I am the tenant of...`
- Продолжение: `Thank you for your response regarding...`

**Основная часть:**
- Нумерованные пункты
- Каждый пункт — отдельный абзац с заголовком
- Цитаты из законов в кавычках и курсивом
- Факты отделены от запросов

**Заключение:**
- Запрос: `I kindly request that you...`
- Дедлайн: `...within 48 hours of this email`
- Последствия: `Should [condition], I will be compelled to...`
- Открытость: `I look forward to your prompt response.`

**Подпись:**
```
Best regards,
[Имя Фамилия]
[Адрес / квартира / юнит]
[Телефон]
```

### 2.3 Шаблоны типов писем (5 типов)

**1. Юридическое уведомление / Legal Notice:**
```
Subject: [Legal Notice / Final Notice] — [тема] — [номер дела]
To: [email]
Cc: [копии]

Dear Mr./Ms. [Name],

I refer to [контекст — предыдущая переписка / судебное решение / дело].

I wish to bring the following to your attention:

1. [Факт]

2. [Правовая норма]
   "[Цитата из закона]"

3. [Последствия нарушения]

I formally request that you [действие] within [срок].

Should this request not be met, I will have no alternative but to:
— [Действие 1];
— [Действие 2];
— [Действие 3].

This email constitutes formal notice and may be submitted as evidence in legal proceedings.

Best regards,
[Подпись]
```

**2. Формальный запрос / Formal Request:**
```
Subject: [Request / Application] — [тема]
To: [email]

Dear [обращение],

My name is [Name], [контекст].

I am writing to request [что нужно].

Background:
[1-2 абзаца контекста]

My request:
1. [Пункт 1]
2. [Пункт 2]
3. [Пункт 3]

I am prepared to [что готов сделать].

I would greatly prefer to resolve this cooperatively and look forward to your earliest response.

Best regards,
[Подпись]
```

**3. Жалоба / Complaint:**
```
Subject: Formal Complaint — [тема] — [номер]
To: [email]

Dear [обращение],

I am writing to formally lodge a complaint regarding [тема].

Facts:
1. [Факт 1 с датой]
2. [Факт 2 с датой]

My position:
[Правовые основания]

Requested resolution:
[Что хочу получить]

If this matter is not resolved within [срок], I will escalate to [инстанция].

Best regards,
[Подпись]
```

**4. Ответ на письмо / Reply:**
```
Subject: Re: [оригинальная тема]
To: [email]
Cc: [копии]

Dear Mr./Ms. [Name],

Thank you for your response [dated / regarding].

I note your position. However, I must respectfully clarify the following:

1. [Контраргумент / уточнение]

2. [Контраргумент / уточнение]

Accordingly, I request that you [действие].

Best regards,
[Подпись]
```

**5. Координационное письмо / Coordination:**
```
Subject: Coordination — [тема]
To: [email]
Cc: [копии]

Dear [обращение],

Thank you for [контекст].

Regarding your questions:

1. [Ответ 1]

2. [Ответ 2]

In order to proceed, I need the following from your side:
— [Что нужно]
— [Что нужно]

I am available [когда] and happy to discuss by phone if that is more convenient.

Best regards,
[Подпись]
```

### 2.4 Стилистические правила Email

**Обязательно:**
1. Каждое письмо начинается с Subject, To, Cc
2. Обращение: Dear + титул + фамилия
3. Абзацы разделены пустой строкой
4. Нумерация пунктов для структуры
5. Конкретный запрос в конце
6. Подпись с контактами

**Запрещено:**
- Эмодзи в деловых письмах
- WhatsApp/Telegram-форматирование (`*bold*`, `**bold**`)
- Разделители из символов (`────`, `────`)
- Сленг, разговорный тон
- Длинные абзацы без структуры (максимум 4-5 строк)
- `Dear Friend`, `Hello there` и подобное

**Тон:**
- Профессиональный, но не холодный
- Уверенный, но не агрессивный
- Конкретный — без воды
- Формула: "Я уважаю вашу позицию, но факты говорят иначе"

**Длина:**
- Оптимально: 300-800 слов
- Юридическое: до 1000 слов
- Короткое координационное: 100-200 слов
