## Проверочный чеклист

### Перед генерацией инвойса

- [ ] Определён бренд (Marsel или Sokol)
- [ ] Выбраны корректные реквизиты для бренда
- [ ] Название компании соответствует бренду
- [ ] Account No. соответствует выбранным реквизитам

### Валидация IBAN

- [ ] **Marsel (ЭТАЛОН):** 110500000000028642584 (без AE, 21 символ)
- [ ] **Marsel (старый):** AE110500000000019064835 (с AE, 23 символа)
- [ ] **Sokol:** AE070500000000019346595 (с AE, 23 символа)

### Валидация SWIFT (если указывается)

- [ ] Формат: ABDIAEADXXX (11 символов)
- [ ] Только для старых реквизитов Marsel
- [ ] Не указывается для эталонных и Sokol реквизитов

### Финальная проверка

- [ ] Реквизиты соответствуют бренду инвойса
- [ ] Licence Number соответствует компании
- [ ] Адрес офиса соответствует компании
