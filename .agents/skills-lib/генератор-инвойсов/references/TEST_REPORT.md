## Тест 3: POS Terminal (pos-terminal.yaml)

**Статус:** FAIL (ошибки в расчётах)

**Входные данные:**
- Инвойс #26-099, дата Feb 01, 2026
- Бренд: marsel
- Клиент: PETROV SERGEY ALEXANDROVICH
- Услуга 1: JEEP SAFARI TOUR, price_excl_vat = 476.19
- Услуга 2: LA PERLE SHOW, quantity = 3, price_excl_vat = 95.24 (за 1)
- POS Terminal: 4%

**Ожидаемый результат (указан в файле):**
- Услуга 1: 476.19 + VAT 23.81 = 500.00
- Услуга 2: 95.24 * 3 = 285.72 + VAT 14.28 = 300.00
- Subtotal: 800.00
- POS Terminal 4%: 32.00
- GRAND TOTAL: 832.00

**Фактический результат (проверка расчётов):**

**Услуга 1 (Safari Tour):**
- price_excl_vat = 476.19
- VAT = 476.19 * 0.05 = 23.8095 -> 23.81
- Amount (Incl. VAT) = 476.19 + 23.81 = **500.00** (КОРРЕКТНО)

**Услуга 2 (La Perle):**
- price_excl_vat per unit = 95.24
- Amount (Excl. VAT) = 95.24 * 3 = 285.72
- VAT = 285.72 * 0.05 = 14.286 -> 14.29
- Amount (Incl. VAT) = 285.72 + 14.29 = **300.01**

**НЕСООТВЕТСТВИЕ:** В примере указано VAT = 14.28 и Total = 300.00, но математически:
- 285.72 * 0.05 = 14.286 округляется до 14.29 (не 14.28)
- 285.72 + 14.29 = 300.01 (не 300.00)

**Итоги при корректном расчёте:**
- Total (Excl. VAT) = 476.19 + 285.72 = 761.91
- Total VAT = 23.81 + 14.29 = 38.10
- Total (Incl. VAT) = 761.91 + 38.10 = 800.01
- POS Commission = 800.01 * 0.04 = 32.0004 -> 32.00
- Grand Total = 800.01 + 32.00 = 832.01

**Замечания:**
1. **ОШИБКА:** Цены подобраны для "красивых" итогов, но математически не сходятся
2. Если нужен Total = 800.00, то исходные цены должны быть скорректированы
3. Формат строки POS: "PAYMENT VIA POS TERMINAL + 4%" - соответствует документации
4. Структура инвойса корректна

**Рекомендации:**
- Либо принять математически корректные итоги (800.01)
- Либо скорректировать исходные цены для получения 800.00

## Найденные проблемы

### Критические (блокирующие)
Не обнаружено.

### Высокий приоритет

1. **[P-001] Несогласованность расчётов VAT в примерах**
   - Файл: `simple-tour.yaml`, `pos-terminal.yaml`
   - Проблема: Комментарии с ожидаемыми результатами не совпадают с математикой
   - Влияние: Пользователь может получить неверные ожидания

### Средний приоритет

2. **[P-002] Отсутствует раздел обработки ошибок**
   - Файл: `SKILL.md`
   - Проблема: Не описано поведение при невалидных данных
   - Влияние: Неопределённое поведение скилла

3. **[P-003] Неясность с VAT на депозит**
   - Файл: `sokol-car-rental.yaml`
   - Проблема: Депозит облагается VAT, хотя это залог
   - Влияние: Потенциально некорректный расчёт

### Низкий приоритет

4. **[P-004] Формат номера Sokol не документирован**
   - Файл: `SKILL.md`
   - Проблема: #26-SKL-001 отличается от #YY-XXX
   - Влияние: Несогласованность документации

5. **[P-005] Округление: нет чёткого правила**
   - Файл: `SKILL.md`
   - Проблема: Указано "до сотых", но не указано направление (вверх/вниз/математическое)
   - Влияние: Разночтения в расчётах
