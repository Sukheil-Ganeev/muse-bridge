## Принципы из документации

### Progressive Disclosure (уровни информации):

| Уровень | Что включать | Где |
|---------|--------------|-----|
| 1. Быстрый старт | Минимум для создания инвойса | SKILL.md (начало) |
| 2. Основные правила | Часто используемое | SKILL.md (середина) |
| 3. Детали и нюансы | Редко используемое | references/ |
| 4. Готовые решения | Копируй и используй | templates/, examples/ |

### Безопасность SKILL.md (bash-совместимость):

При написании SKILL.md избегать:
- Восклицательный знак в конце строк внутри кавычек
- Восклицательный знак рядом с обратными кавычками
- Сложных комбинаций спецсимволов в одной строке

## Структура входных данных (предварительная)

```yaml
# Пример входных данных для скилла
invoice:
  number: "#26-XXX"           # Обязательно
  date: "Jan 22, 2026"        # Обязательно

client:
  name: "ИМЯ КЛИЕНТА"         # Обязательно
  phone: "+7 XXX XXX XXXX"    # Обязательно
  address: ""                 # Опционально (для корпоративных)

services:                     # Минимум 1 услуга
  - type: "PRIVATE_TOUR_DUBAI"
    description: "PRIVATE TOUR IN DUBAI WITH GUIDE"
    date: "28 JANUARY"
    time: "10:00 AM"          # Опционально
    persons: 2
    price_incl_vat: 250

payment:
  pos_terminal: false         # true/false
  pos_commission: 3.5         # % если pos_terminal = true

bank_details:
  use_default: true           # Использовать реквизиты по умолчанию
```
