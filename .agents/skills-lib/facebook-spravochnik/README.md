# facebook-справочник

Production-ready руководство по Facebook как платформе для туристического бизнеса ОАЭ.

## Структура

```
facebook-справочник/
├── SKILL.md              # Основной справочник (~4800 слов)
├── README.md             # Этот файл
└── references/
    ├── faq.md            # Часто задаваемые вопросы
    ├── troubleshooting.md # Решение проблем
    └── cheatsheet.md     # Шпаргалка по API endpoints
```

## Что включено

- **Graph API v22.0** — версионирование, базовый URL, ключевые изменения
- **Аутентификация** — типы токенов, получение Page Access Token, permissions
- **Pages API** — управление страницей, CTA, роли
- **Groups API** — публикация, участники, модерация
- **Posts API** — текст, фото, видео, карусели, scheduling, geo-targeting
- **Reels Publishing API** — 3-шаговый процесс загрузки
- **Stories API** — фото/видео Stories, аналитика
- **Events API** — создание, RSVP, управление
- **Facebook Shops** — Commerce Manager, Product Catalog API
- **Marketplace** — обзор, ограничения API
- **Insights API** — метрики страниц, постов, аудитории (с учетом deprecation 2025)
- **Ads API** — обзор форматов, таргетинг, бустинг
- **Модерация** — комментарии, баны, автомодерация, webhooks
- **Примеры для туризма ОАЭ** — контент-план, каталог, стратегия

## Что НЕ включено

- **Messenger боты** → см. `facebook-messenger-bot-справочник`
- **Детали рекламных кампаний** → см. `рекламные-платформы-справочник`

## Контекст

- Бизнес: экскурсии, билеты, трансферы, яхты в ОАЭ
- Аудитория: СНГ (RU, KZ, UZ, BY) + европейские туристы
- Валюта: AED
- Facebook особенно релевантен для европейской и арабской аудитории
