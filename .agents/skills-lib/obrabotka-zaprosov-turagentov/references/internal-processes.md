# Внутренние процессы обработки запросов

## 1. CRM-интеграция

### Когда создавать лид
- **Любой новый запрос** = новый лид в системе
- Даже если клиент "просто спрашивает" — фиксируем
- Повторный запрос от существующего клиента — обновляем карточку

### Какие данные собирать
| Поле | Обязательно | Пример |
|------|-------------|--------|
| Имя | Да | Александр |
| Контакт | Да | +971 50 123 4567 / WhatsApp |
| Продукт | Да | Desert Safari Premium |
| Желаемая дата | Да | 15 февраля 2025 |
| Кол-во человек | Да | 4 взрослых, 2 детей |
| Источник | Да | Instagram DM / сайт / реферал |
| Бюджет | Желательно | ~500 AED на человека |
| Особые пожелания | Если есть | Вегетарианское меню |

### Статусы лида
```
НОВЫЙ → В РАБОТЕ → ЗАБРОНИРОВАНО → ЗАВЕРШЕНО
   ↓         ↓           ↓
ОТЛОЖЕН   ОТКАЗ    ОТМЕНЕНО
```

**Новый** — только поступил, не обработан
**В работе** — ведём переговоры, отправили предложение
**Забронировано** — оплачено/подтверждено
**Завершено** — услуга оказана
**Отложен** — клиент вернётся позже (указать дату)
**Отказ** — не заинтересован (указать причину)
**Отменено** — была бронь, но отменилась

### Интеграция с Notion
- **База клиентов:** [ссылка на Notion база]
- **Синхронизация:** автоматическая через Zapier / ручная
- **Ответственный за актуальность:** старший менеджер

## 2. История переписки / Контекст клиента

### Что помнить о клиенте
- Предыдущие заказы (даты, продукты, суммы)
- Предпочтения (трансфер, тип питания, язык гида)
- Особые условия (скидки, договорённости)
- Состав семьи / группы
- Проблемы в прошлом (если были)

### Как использовать контекст
```
❌ Плохо: "Хотите Desert Safari?"
✅ Хорошо: "Александр, вы были на Desert Safari в прошлом году.
           В этот раз рекомендуем Premium с ужином — там новое шоу!"
```

```
❌ Плохо: "Трансфер нужен?"
✅ Хорошо: "В прошлый раз вы брали трансфер из JBR —
           заберём оттуда же?"
```

### Шаблон карточки клиента

```markdown
## 👤 [Имя клиента]

**Контакт:** +971 XX XXX XXXX (WhatsApp)
**Язык:** русский / English
**Теги:** #VIP #семья

### История заказов
| Дата | Продукт | Сумма | Отзыв |
|------|---------|-------|-------|
| 10.01.2025 | Desert Safari Standard | 600 AED | ⭐⭐⭐⭐⭐ |

### Предпочтения
- Трансфер из: Dubai Marina
- Питание: без свинины
- Гид: русскоязычный

### Заметки
- Путешествует с детьми 5 и 8 лет
- Интересовался яхтой на день рождения (март)

- Постоянная скидка 10% (согласовано с [имя])
```

### Теги клиентов

| Тег | Описание | Особенности работы |
|-----|----------|-------------------|
| **#VIP** | Крупные заказы, постоянные клиенты | Приоритет, персональные условия |
| **#семья** | С детьми | Детские опции, безопасность |
| **#бизнес** | Корпоративные клиенты | Счета, документы, групповые скидки |
| **#молодожёны** | Honeymoon | Романтические опции, приватность |
| **#блогер** | Инфлюенсеры | Согласование контента, бартер |
| **#проблемный** | Были жалобы | Внимание к деталям, эскалация |

## 4. Эскалация проблем

### Уровни эскалации

| Уровень | Кто решает | Какие вопросы | Время реакции |
|---------|------------|---------------|---------------|
| **1** | Оператор | Стандартные вопросы, информация, бронирование | Сразу |
| **2** | Старший менеджер | Скидки >10%, особые условия, нестандартные запросы | 1 час |
| **3** | Руководитель | Жалобы, возвраты, VIP-клиенты, конфликты | 2 часа |

### Когда эскалировать на Уровень 2
- Клиент просит скидку больше стандартной
- Нестандартный запрос (групповой тур, корпоратив)
- Клиент недоволен, но без агрессии
- Нужно согласовать изменение условий
- Запрос от блогера/медиа

### Когда эскалировать на Уровень 3
- Клиент требует возврат
- Агрессия, угрозы отзывами
- Инцидент на экскурсии (травма, потеря имущества)
- VIP-клиент с любым вопросом
- Юридические вопросы
- Запрос от СМИ

### Контакты для эскалации

| Уровень | Имя | Телефон | Telegram | Время работы |
|---------|-----|---------|----------|--------------|
| **2** | [Имя старшего] | +971 XX XXX XXXX | @username | 9:00-21:00 |
| **3** | [Имя руководителя] | +971 XX XXX XXXX | @username | Круглосуточно (срочное) |

### Как эскалировать правильно

```markdown
## Запрос на эскалацию

**Клиент:** [Имя], [контакт]
**Суть проблемы:** [кратко]
**Что уже сделано:** [ваши действия]
**Чего хочет клиент:** [требование]
**Срочность:** [низкая/средняя/высокая]
**Рекомендация:** [ваше мнение по решению]
```

### Что делать до эскалации
1. Выслушать клиента полностью
2. Извиниться за неудобства
3. Записать все детали
4. Предложить стандартное решение
5. Если не устраивает — эскалировать

**Фраза для клиента:**
```
"Я понимаю вашу ситуацию. Чтобы решить это максимально
быстро, я передам вопрос старшему менеджеру.
Он свяжется с вами в течение [время]. Это устроит?"
```

## 5. Учёт рабочего времени

### Метрики оператора

| Метрика | Как считать | Целевой показатель |
|---------|-------------|-------------------|
| **Кол-во запросов** | Все входящие обращения | — |
| **Время первого ответа** | От запроса до первого сообщения | < 5 минут |
| **Время обработки** | От запроса до закрытия/бронирования | < 2 часов |
| **Конверсия** | Забронировано / Всего запросов | > 30% |
| **Средний чек** | Сумма / Кол-во заказов | Рост MoM |
| **NPS/Отзывы** | Средняя оценка от клиентов | > 4.5 |

### Шаблон дневного отчёта

```markdown
## Отчёт за [дата]

**Оператор:** [Имя]
**Смена:** [время начала] — [время окончания]

### Статистика
| Показатель | Значение |
|------------|----------|
| Входящих запросов | XX |
| Обработано | XX |
| Забронировано | XX |
| Конверсия | XX% |
| Сумма броней | XXXX AED |
| Средний чек | XXX AED |

### Эскалации
- [Клиент] — [причина] — [статус]

### Проблемы/Заметки
- [что пошло не так или важные наблюдения]

### На завтра
- [что передать следующей смене]
```

### KPI оператора

**Ежедневные:**
- Время первого ответа < 5 мин (95% запросов)
- Все запросы обработаны до конца смены
- Заполнены карточки всех клиентов

**Еженедельные:**
- Конверсия > 30%
- 0 обоснованных жалоб
- Все напоминания отправлены вовремя

**Ежемесячные:**
- Выполнение плана продаж
- Рост среднего чека
- Положительные отзывы от клиентов

### Бонусная система

| Показатель | Бонус |
|------------|-------|

| 0 жалоб за месяц | +XX AED |
| Лучший отзыв недели | +XX AED |
| Перевыполнение плана | % от суммы |

## Чек-лист внутренних процессов

### При получении запроса
- [ ] Создать/обновить лид в CRM
- [ ] Проверить историю клиента
- [ ] Применить персонализацию
- [ ] Ответить в течение 5 минут

### При бронировании
- [ ] Собрать все обязательные данные
- [ ] Обновить статус лида
- [ ] Запланировать напоминание за 24ч
- [ ] Запланировать follow-up после визита

### При проблеме
- [ ] Выслушать и записать
- [ ] Попробовать решить на своём уровне
- [ ] Эскалировать если нужно (с полной информацией)
- [ ] Отследить решение до конца

### В конце смены
- [ ] Заполнить дневной отчёт
- [ ] Обновить все лиды
- [ ] Передать срочное следующей смене
- [ ] Проверить напоминания на завтра
