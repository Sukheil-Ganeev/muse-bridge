# Интеграция с Notion для получения актуальных цен

## Источник данных

- **Notion Workspace:** https://www.notion.so/Workspace-2de78820479f81d4a170c37153c22726
- Здесь хранятся актуальные прайс-листы для работы с турагентами

## Как искать цены

### Инструмент
Используй **Notion MCP** через инструмент `mcp__plugin_Notion_notion__notion-search`

### Алгоритм поиска
1. Загрузи инструмент через ToolSearch: `select:mcp__plugin_Notion_notion__notion-search`
2. Выполни поиск по названию продукта/отеля/тура
3. Проверь дату актуальности найденного прайса
4. Если найдено несколько результатов — выбери самый актуальный

### Пример запроса
```
Поиск: "Hilton Antalya"
Результат: прайс-лист с B2B и рекомендованными ценами
```

## Структура прайса (ожидаемая)

| Поле | Описание |
|------|----------|
| **Название продукта** | Отель, тур, услуга |
| **B2B цена** | Цена для агентов (закупочная) |
| **Recommended цена** | Рекомендованная розничная цена |
| **Период действия** | Даты, на которые действует прайс |
| **Примечания** | Особые условия, минимальные ночи, акции |

## Правило актуальности

### Проверка даты
- Смотри поле "Дата обновления" или "Период действия"
- Считай возраст прайса от текущей даты

### Действия по результату

| Возраст прайса | Действие |
|----------------|----------|
| До 30 дней | Использовать цены |
| Старше 30 дней | Уточнить у менеджера перед отправкой |
| Цены нет в Notion | Запросить актуальную цену у поставщика |

### Формулировка при устаревшем прайсе
> "Найденный прайс датирован [дата]. Рекомендую уточнить актуальность цен у менеджера перед отправкой агенту."

## Как обновлять прайсы

### При получении нового прайса
1. Загрузи инструмент: `select:mcp__plugin_Notion_notion__notion-create-pages`
2. Создай новую запись в соответствующей базе данных
3. Заполни обязательные поля:
   - Название продукта
   - B2B цена
   - Recommended цена
   - Период действия
   - **Дата добавления** (текущая дата)
   - **Источник** (название поставщика)

### При обновлении существующего прайса
1. Найди существующую запись через поиск
2. Используй `mcp__plugin_Notion_notion__notion-update-page`
3. Обнови цены и дату обновления

### Важно
- Всегда указывай источник прайса (поставщик, менеджер)
- Сохраняй историю изменений через примечания
- При значительном изменении цен — добавь комментарий с причиной

## Полезные инструменты Notion MCP

| Инструмент | Назначение |
|------------|------------|
| `notion-search` | Поиск прайсов и продуктов |
| `notion-fetch` | Получение детальной информации о странице |
| `notion-create-pages` | Добавление нового прайса |
| `notion-update-page` | Обновление существующего прайса |
| `notion-query-database-view` | Запрос к базе данных с фильтрами |

## Типичные сценарии

### Сценарий 1: Агент запрашивает цену на отель
1. Поиск в Notion по названию отеля
2. Проверка актуальности (< 30 дней)
3. Формирование ответа с B2B и Recommended ценами

### Сценарий 2: Цена не найдена
1. Сообщить агенту: "Актуальный прайс на [продукт] отсутствует в базе"
2. Предложить запросить у менеджера
3. После получения — добавить в Notion

### Сценарий 3: Получен новый прайс от поставщика
1. Проверить, есть ли продукт в Notion
2. Если есть — обновить
3. Если нет — создать новую запись
4. Указать дату и источник
