## 2. Интеграция с WhatsApp Business

### Настройка быстрых ответов

**Где:** WhatsApp Business → Настройки → Бизнес-инструменты → Быстрые ответы

**Рекомендуемые шорткаты:**

| Шорткат | Ответ |
|---------|-------|
| `/price` | Шаблон уточнения цены |
| `/book` | Инструкция бронирования |
| `/cancel` | Политика отмены |
| `/location` | Запрос локации |
| `/thanks` | Благодарность за бронирование |
| `/review` | Просьба оставить отзыв |

### Кнопки действий (Call to Action)

В WhatsApp Business можно добавить до 2 кнопок:
- **Позвонить** — прямой звонок
- **Сайт** — ссылка на каталог/прайс

### Каталог продуктов

**Настройка:** Бизнес-инструменты → Каталог

Рекомендации:
- Фото 1:1 (квадрат) для лучшего отображения
- Краткое описание (до 100 символов)
- Цена "от X AED" для диапазонов
- Категоризация по типам (Туры, Билеты, Трансферы)

### Автоприветствие

**Настройка:** Бизнес-инструменты → Приветственное сообщение

```
Здравствуйте! 👋

Спасибо, что обратились к нам!
Мы организуем туры, экскурсии и развлечения в ОАЭ.

Напишите, что вас интересует — ответим в течение 15 минут!

Популярное:
• Ain Dubai
• Burj Khalifa
• Desert Safari
• Abu Dhabi Tour
```

### Away-сообщение (нерабочее время)

**Настройка:** Бизнес-инструменты → Сообщение об отсутствии

```
Спасибо за сообщение!

Сейчас нерабочее время (мы на связи 9:00-22:00 Dubai time).
Ответим вам первым делом утром!

Срочно? Позвоните: +971 XX XXX XXXX
```

**Расписание:** Установить автоматическое включение по часам

## 3. Telegram-бот для агентов

### Концепция

Внутренний бот для быстрого получения информации о продуктах.
Агент пишет название продукта → бот выдаёт готовую карточку.

### Команды бота

```
/start — Приветствие и список команд

/price [продукт]
Выдаёт карточку с ценами продукта
Пример: /price ain dubai

/profit [продукт] [клиентская цена]
Рассчитывает прибыль агента
Пример: /profit ain dubai 150

/book [продукт]
Инструкция по бронированию продукта
Пример: /book desert safari

/available [продукт] [дата]
Проверка доступности
Пример: /available burj khalifa 25.01

/help — Полный список команд
```

### Пример диалога

```
Агент: /price ain dubai

Бот:
🎡 AIN DUBAI

Rotation Experience:
• Adult: 130 AED (агент: 115 AED)
• Child: 130 AED (агент: 115 AED)

Dining Experience:
• Afternoon: 380 AED (агент: 330 AED)
• Sunset: 480 AED (агент: 420 AED)

💡 Длительность: 40 мин
📍 Bluewaters Island

/book ain dubai — инструкция бронирования
```

### Техническая реализация

**Стек:** Make.com + Notion + Telegram Bot API

**Архитектура:**

```
[Telegram Bot] → [Make.com Webhook] → [Notion Query] → [Ответ]
```

**Шаги создания:**

1. **Создать бота** через @BotFather
2. **Настроить Webhook** в Make.com (Telegram → Watch for Updates)
3. **Парсить команду** (HTTP/Text Parser модуль)
4. **Запрос в Notion** (Notion → Search Objects)
5. **Форматировать ответ** (Text Aggregator)
6. **Отправить** (Telegram → Send Message)

## 4. Автогенерация карточек из Notion

### Структура базы данных Notion

**Таблица: Products**

| Поле | Тип | Пример |
|------|-----|--------|
| Name | Title | Ain Dubai |
| Category | Select | Attraction |
| Client Price | Number | 130 |
| Agent Price | Number | 115 |
| Duration | Text | 40 min |
| Location | Text | Bluewaters Island |
| Description | Text | ... |
| Includes | Multi-select | Entry, Photo |
| Booking Link | URL | ... |

### Скрипт генерации (логика)

```
ФУНКЦИЯ generate_card(product_name, recipient_type):

    # 1. Получить данные из Notion
    product = notion.query(
        database="Products",
        filter={"Name": {"contains": product_name}}
    )

    IF product is empty:
        RETURN "Продукт не найден"

    # 2. Определить цену по типу получателя
    IF recipient_type == "agent":
        price = product.agent_price
        show_profit = TRUE
    ELSE:
        price = product.client_price
        show_profit = FALSE

    # 3. Применить шаблон
    card = TEMPLATE.format(
        name = product.name.upper(),
        price = price,
        duration = product.duration,
        location = product.location,
        includes = format_list(product.includes),
        profit_line = calculate_profit() IF show_profit
    )

    # 4. Вернуть готовую карточку
    RETURN card
```

### Интеграция через Make.com

**Сценарий: Notion → Card Generator**

```
[Trigger: Webhook/Bot]
    ↓
[Notion: Get Database Item]
    ↓
[Router: Client / Agent]
    ↓
[Text Aggregator: Format Card]
    ↓
[Output: Telegram/WhatsApp/Clipboard]
```

**Ключевые модули:**

1. **Notion → Get a Database Item**
   - Database ID: ваша база Products
   - Filter: Name contains {{input}}

2. **Router**
   - Route 1: IF type = "client"
   - Route 2: IF type = "agent"

3. **Text Aggregator**
   - Клиентский шаблон (без закупки)
   - Агентский шаблон (с закупкой и прибылью)

### Альтернатива: n8n (self-hosted)

Преимущества:
- Бесплатный self-hosted
- Более гибкие условия
- Полный контроль над данными

Архитектура та же, только вместо Make.com используется n8n.
