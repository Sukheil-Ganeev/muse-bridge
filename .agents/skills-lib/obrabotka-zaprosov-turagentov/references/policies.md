# Policies — Политики и правила работы

Внутренние политики для обработки цен, отмен, срочных заказов и изменений.

---

## 1. Правила округления прибыли

### Принцип
Прибыль агента всегда округляется до **0.50 AED** в большую сторону.

### Формула
```
Округлённая прибыль = ceil(Прибыль × 2) / 2
```

### Примеры округления

| Рассчитанная прибыль | Округлённая прибыль |
|---------------------|---------------------|
| 8.33 AED | 8.50 AED |
| 12.17 AED | 12.50 AED |
| 15.00 AED | 15.00 AED |
| 7.01 AED | 7.50 AED |
| 9.49 AED | 9.50 AED |
| 9.51 AED | 10.00 AED |
| 20.75 AED | 21.00 AED |

### Практический пример

**Исходные данные:**
- B2B (закупка): 128 AED
- Recommended (продажа): 145 AED

**Расчёт:**
```
Общая прибыль = 145 - 128 = 17 AED
Прибыль агента (50%) = 17 × 0.5 = 8.50 AED ✓ (уже кратно 0.50)
```

**Другой пример:**
- B2B: 95 AED
- Recommended: 112 AED

```
Общая прибыль = 112 - 95 = 17 AED
Прибыль агента (50%) = 17 × 0.5 = 8.50 AED ✓
```

**Пример с округлением:**
- B2B: 100 AED
- Recommended: 117 AED

```
Общая прибыль = 117 - 100 = 17 AED
Прибыль агента (50%) = 17 × 0.5 = 8.50 AED ✓

Но если:
- B2B: 100 AED
- Recommended: 115 AED

Общая прибыль = 115 - 100 = 15 AED
Прибыль агента (50%) = 15 × 0.5 = 7.50 AED ✓
```

## 2. Сезонность цен

### Когда оформлять блок сезонности
- Цены различаются по периодам (высокий/низкий сезон)
- Праздничные наценки (Новый год, Eid и т.д.)
- Летние/зимние тарифы
- Акционные периоды

### Правила оформления сезонности

1. **Формат даты:** ДД.ММ (без года)
2. **Подпись периода:** в скобках после дат
3. **Порядок:** хронологический (с 01.01) или по актуальности
4. **Разделители:** НЕ ставить между периодами одного продукта
5. **Отступы:** пустая строка между периодами

## 3. Политика отмен

### Стандартные условия

| Срок до начала | Возврат |
|----------------|---------|
| 48+ часов | 100% (бесплатная отмена) |
| 24-48 часов | 50% стоимости |
| Менее 24 часов | 0% (невозвратно) |

```

*ОТМЕНА*
• За 48+ часов — бесплатно

• Менее 24 часов — без возврата

```

## 4. Срочные заказы

### Определение срочного заказа
- Бронирование на **сегодня** или **завтра**
- Менее 24 часов до начала услуги

### Условия

| Параметр | Значение |
|----------|----------|
| Наценка | +10% к стоимости |
| Минимальное время | 4 часа до начала |
| Гарантия | Без гарантии (по наличию) |

### Расчёт наценки

**Пример:**
- Стандартная цена: 150 AED
- Срочная наценка: 150 × 10% = 15 AED
- Итого: 165 AED

### Шаблон ответа на срочный запрос (WhatsApp)

**Если бронирование возможно:**
```
Добрый день!

Да, бронирование на [сегодня/завтра] возможно!

⚠️ *Обратите внимание:*
Это срочный заказ (менее 24 часов до начала).
Применяется наценка +10% к стандартной стоимости.

💰 *Стоимость:*
Стандартная цена:  [XXX] AED
Срочная наценка (+10%):  +[XX] AED
───────────────
*Итого:  [XXX] AED*

Для подтверждения нужна полная предоплата в течение 1 часа.

Подтверждаете?
```

**Если бронирование невозможно (менее 4 часов):**
```
Добрый день!

К сожалению, бронирование невозможно.

Минимальное время для срочного заказа — 4 часа до начала.
На данный момент до начала осталось менее 4 часов.

Альтернатива: могу предложить ближайшую доступную дату — [дата].

Рассмотрите?
```

**Если нет мест:**
```
Добрый день!

К сожалению, на [дата] все места уже заняты.

Ближайшие доступные даты:
• [дата 1]
• [дата 2]
• [дата 3]

Какая дата удобна?
```

### Правила срочных заказов

1. **Проверить наличие** перед подтверждением
2. **Предупредить о наценке** ДО бронирования
3. **Требовать предоплату** в течение 1 часа
4. **Не гарантировать** — только по наличию
5. **Время отсчёта** — от момента начала услуги, не бронирования

## 5. Изменение цен

### Когда сообщать об изменении
- Цена изменилась ПОСЛЕ отправки предложения клиенту
- Клиент получил старую информацию
- Разница более 5 AED или 3%

### Как сообщить клиенту

**Правило:** сообщать сразу, честно, с извинением и объяснением.

### Шаблон извинения (WhatsApp)

**При повышении цены:**
```
Добрый день!

Приносим извинения — цены на [продукт] изменились.

Ранее указанная цена:  [старая] AED
Актуальная цена:  [новая] AED
Разница:  +[разница] AED

Причина: [обновление тарифов поставщика / сезонное изменение / праздничная наценка]

Варианты:
1. Подтвердить по новой цене
2. Выбрать альтернативный продукт
3. Перенести на другую дату (если цена снизится)

Ещё раз приносим извинения за неудобства.
Что выбираете?
```

**При понижении цены:**
```
Добрый день!

Хорошие новости! Цены на [продукт] снизились.

Ранее указанная цена:  [старая] AED
Актуальная цена:  [новая] AED
Ваша выгода:  -[разница] AED

Подтверждаете бронирование по новой цене?
```

### Компенсации

| Ситуация | Компенсация |
|----------|-------------|
| Повышение до 10% | Извинение + скидка 5% на следующий заказ |
| Повышение 10-20% | Извинение + бесплатная опция (шкафчик, трансфер и т.п.) |
| Повышение более 20% | Право отказаться + полный возврат предоплаты |
| Ошибка с нашей стороны | Фиксация старой цены (в убыток) |

### Шаблон с компенсацией (WhatsApp)

```
Добрый день!

Приносим извинения — произошла ошибка в расчёте.

Ранее указанная цена:  [старая] AED
Актуальная цена:  [новая] AED

Мы понимаем, что это неудобно.
В качестве компенсации предлагаем:
• [Бесплатный трансфер / шкафчик / фото-пакет и т.д.]

Или:
• Скидка 5% на следующий заказ

Варианты:
1. Продолжить с компенсацией
2. Отменить бронирование (полный возврат)

Что предпочтительнее?
```

### Профилактика ошибок

1. **Проверять дату прайса** перед отправкой предложения
2. **Указывать срок актуальности** в карточке
3. **Подтверждать цену** перед финальным бронированием
4. **Фиксировать цену** сразу после подтверждения клиента
