# Шаблон карточки для АГЕНТА

## Назначение
Карточка для отправки **турагенту**. Содержит рекомендованные цены для клиента + блок расчёта прибыли агента.

## Что показывать
- Рекомендованные цены (Recommended Rate) — для передачи клиенту
- Блок "Твоя прибыль" — расчёт заработка агента (50% от комиссии)

## Что НЕЛЬЗЯ показывать
- B2B цены (закупочные) — НИКОГДА!
- Общую комиссию (только долю агента)

## Правила форматирования (WhatsApp)
- Жирный: `*текст*`
- Разделитель: 15 тире `───────────────`
- 2 пробела после категории
- Эмодзи только: 💰 ➕ ⚠️

## Формула расчёта прибыли агента

```
Общая прибыль = Recommended Rate - B2B Rate
Прибыль агента = Общая прибыль × 50%
```

**Пример расчёта (Observation Cabin):**
- B2B: 31.5$ взр / 25$ реб
- Recommended: 40$ взр / 30$ реб
- Общая прибыль: 8.5$ взр / 5$ реб
- Агенту (50%): 4.25$ взр / 2.50$ реб
