# Шаблон для ВНУТРЕННЕГО расчёта

## Назначение
Внутренний документ для **собственного использования**. Содержит ВСЕ цены и полный расчёт прибыли.

## Что показывать
- B2B цены (закупочные)
- Recommended Rate (рекомендованные)
- Общую комиссию
- Прибыль агента (50%)
- Нашу долю (50%)

## Кому НЕ показывать
- Клиентам — НИКОГДА
- Агентам — НИКОГДА
- Только для внутреннего использования!
