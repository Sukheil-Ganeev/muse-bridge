# Опыт работы с YouTube Data API v3

## Критические уроки (топ-5)

### 1. Квоты сбрасываются в полночь Pacific Time!
**Проблема:** Квоты 10,000 units/день сбрасываются не в вашем часовом поясе.

**Решение:** Учитывайте PST/PDT при планировании загрузок.

**Пример:**
- Дубай (GST): UTC+4
- Pacific Time (PST): UTC-8 (зима) или UTC-7 (лето)
- Разница: 12-11 часов

Квоты сбрасываются в Дубае в **12:00 дня** (зима) или **11:00** (лето).

### 2. videos.insert = 1,600 units (очень дорого!)
**Проблема:** Загрузка 1 видео = 1,600 units из 10,000 (16% квоты).

**Решение:** Максимум 6 видео/день. Планируйте загрузки заранее.

```python
# Плохо: 10 видео подряд = превышение квоты на 6,000 units
for video in videos:
    upload(video)  # ОШИБКА на 7-м видео!

# Хорошо: проверка квоты
remaining_quota = 10000 - used_quota
if remaining_quota >= 1600:
    upload(video)
else:
    print("Недостаточно квоты, жду следующего дня")
```

### 3. Resumable upload обязателен для больших файлов
**Проблема:** Файлы >5 MB без resumable upload могут оборваться.

**Решение:** Всегда используйте resumable upload.

```python
# Правильно
media = MediaFileUpload('video.mp4', chunksize=-1, resumable=True)
```

### 4. YouTube Shorts — автоопределение (не API параметр)
**Проблема:** Нет специального API для Shorts, разработчики ищут `media_type=SHORT`.

**Решение:** YouTube **автоматически** определяет Shorts по:
- Длительность < 60 секунд
- Вертикальный формат (9:16 aspect ratio)

Просто загружайте короткое вертикальное видео через обычный `videos.insert`.

### 5. search.list стоит 100 units (очень дорого!)
**Проблема:** Поиск видео через `search.list` = 100 units.

**Решение:** Используйте альтернативы:
- `videos.list` (1 unit) — если знаете video ID
- Кешируйте результаты поиска
- Используйте YouTube RSS (бесплатно, без квот)

```python
# Плохо: 100 units
youtube.search().list(q='Dubai tourism', part='id').execute()

# Хорошо: 1 unit (если знаете ID)
youtube.videos().list(id='VIDEO_ID', part='snippet').execute()
```

API возвращал ошибку "quotaExceeded" при 7-й загрузке видео.

## Причина
videos.insert = 1,600 units × 7 = 11,200 units > 10,000 (лимит)

## Решение
1. Ограничил загрузку до 6 видео/день
2. Добавил проверку remaining quota перед загрузкой
3. Настроил отложенную загрузку на следующий день

## Урок
Всегда мониторьте квоты! 1 видео = 16% дневной квоты.
