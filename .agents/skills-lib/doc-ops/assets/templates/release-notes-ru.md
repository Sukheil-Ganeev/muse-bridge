## Примеры заполненных release notes

### Пример 1: Phase 22 Max Bot

---

**Что нового в Phase 22: Max Bot — Апрель 2026**

Бот теперь работает в мессенджере **Max** (бывший ВКонтакте мессенджер).
Клиенты из России, которые привыкли использовать Max, могут бронировать
экскурсии без перехода в Telegram или WhatsApp.

**Что нового:**
- Каталог всех экскурсий и парков ОАЭ — прямо в Max
- Бронирование за 8 шагов (имя, телефон, дата, количество человек)
- Карточки с фото, описанием и ценой
- Поиск по названию или эмирату

**Для менеджеров:**
- Уведомления о бронях из Max приходят в Telegram как обычно
- В уведомлении будет пометка `[Max]` чтобы отличить от других платформ
- Бронь добавляется в общую CRM — ничего отдельного вести не нужно

**Никаких действий не нужно** — бот уже работает в Max.

## Технические заметки для Claude

При заполнении этого шаблона:
1. Писать от лица пользователя, не разработчика
2. Избегать технических терминов (asyncpg, FSM, migration, webhook)
3. Объяснять что изменилось для человека, а не как это устроено внутри
4. Секции без изменений — удалять, не оставлять пустыми
5. Если изменений меньше трёх — не растягивать, пишем только что есть
