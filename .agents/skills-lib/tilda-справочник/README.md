# Tilda-справочник

Production-ready руководство по Tilda для создания лендингов и каталогов туристического бизнеса ОАЭ.
Zero Code блоки, кастомный код, API, интеграции с CRM и мессенджерами, SEO, мультиязычность.

## Структура

```
tilda-справочник/
├── SKILL.md                    # Основной файл (~5000 слов)
├── README.md                   # Этот файл
└── references/
    ├── faq.md                  # 12 частых вопросов
    ├── troubleshooting.md      # 12 типичных проблем
    └── cheatsheet.md           # Шпаргалка: блоки, API, CSS, JS, SEO
```

## Быстрый старт

1. Прочитайте `SKILL.md` -- полный обзор платформы
2. Раздел 2: "Быстрый старт: лендинг за 2 часа" -- пошаговый план
3. Раздел 5: Формы и сбор лидов -- настройка Telegram/Email приёмников
4. Раздел 11: SEO -- meta-теги, Schema.org, Open Graph
5. Раздел 13: Практические примеры ОАЭ -- готовые структуры лендингов
