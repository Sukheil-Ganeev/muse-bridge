**Источник:** `_ПРИМЕРЫ/10_Розыгрыши/Бесконечный розыгрыш подарков.md`

## Зачем розыгрыши туристическому боту

### Бизнес-цели

1. **Привлечение новых подписчиков** — вирусный эффект
2. **Вовлечение существующих** — активность между покупками
3. **Сбор данных** — при регистрации на розыгрыш
4. **Продажи** — "утешительные" скидки всем участникам
5. **PR** — контент для соцсетей

### Метрики из кейса "Студент года"

- Регистрация на мероприятие: **100%** автоматизация
- Время на выбор победителя: **< 1 минуты**
- Уведомление всех участников: **мгновенно**
- Многоразовое использование: **неограниченно**

## Типы розыгрышей для VIP-DXB-RUS

### 1. Ежемесячный розыгрыш "Бесплатный тур"

**Приз:** Экскурсия на 2 человека (стоимость ~500 AED)

**Условия участия:**
- Подписка на бота
- Подписка на канал @vipdxbrus
- Репост в сторис (опционально)

**Механика:**
```
Регистрация → Подтверждение условий → Ожидание → Розыгрыш → Уведомление
```

### 2. Флеш-розыгрыш (24 часа)

**Приз:** Скидка 30% на любой тур

**Условия:**
- Быстрая регистрация (имя + телефон)
- Ограниченное время

**Механика:**
```
Анонс → Счетчик времени → Розыгрыш → Всем участникам скидка 10%
```

### 3. Реферальный розыгрыш

**Приз:** VIP-тур на 4 человека (стоимость ~2000 AED)

**Условия:**
- Пригласить 3+ друзей через бота
- Каждый друг = +1 шанс

**Механика:**
```
Уникальная ссылка → Трекинг рефералов → Множитель шансов → Розыгрыш
```

### 4. Конкурс контента

**Приз:** Фотосессия в Дубае

**Условия:**
- Выложить фото/видео из ОАЭ
- Отметить @vipdxbrus
- Использовать хештег #VIPDubaiExperience

**Механика:**
```
Отправка контента в бота → Модерация → Голосование → Победитель
```

### 5. Викторина "Знаток ОАЭ"

**Приз:** Скидка 20% + сувенир

**Условия:**
- Ответить на 5 вопросов об ОАЭ
- Минимум 4 правильных ответа

**Механика:**
```
Вопрос 1 → ... → Вопрос 5 → Результат → Приз/Скидка
```
