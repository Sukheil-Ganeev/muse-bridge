**Источник кейсов:** `../../references/case-studies-full.md`

## Как использовать этот индекс

**Сценарий 1: Хочу увеличить продажи**
→ Читай: `sales-mechanics.md` (все 3 механики)
→ Начни с: Квиз (быстрая победа)

**Сценарий 2: Нужно быстро разобраться**
→ Читай: `QUICK-REFERENCE.md` (5 минут)
→ Потом: `README.md` (для презентации)

**Сценарий 3: Хочу улучшить лояльность**
→ Читай: `loyalty-extended.md`
→ Дополнительно: `marketing-segmentation.md`

**Сценарий 4: Проблемы с качеством услуг**
→ Читай: `service-quality.md` (полная концепция)
→ Быстро: `service-quality-summary.md` (краткая версия)
→ Разработка: `service-quality-implementation.md` (код + БД)

**Сценарий 5: Нужно обучить гидов**
→ Читай: `education-knowledge.md`

**Сценарий 6: Хочу калькулятор цен**
→ Читай: `calculator-pricing.md`
→ Быстрая выдача ориентировочной стоимости

**Сценарий 7: Нужно визуальное бронирование**
→ Читай: `mini-app-booking.md`
→ Telegram Mini App с каталогом и формами

**Сценарий 8: Хочу привлечь клиентов розыгрышами**
→ Читай: `giveaways-contests.md`
→ 5 типов розыгрышей + викторины
