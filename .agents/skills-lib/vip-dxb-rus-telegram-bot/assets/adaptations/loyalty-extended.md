## Обновление FORM-REVIEW (расширение v2.1)

**Новые поля:**

| # | Field | Variable | Type | Required | Notes |
|---|-------|----------|------|----------|-------|
| 1 | **Платформа** | `review_platform` | **CHOICE** | **Yes** | **Google/Yandex/2GIS/TripAdvisor** |
| 2 | Rating | `review_rating` | CHOICE | Yes | 1-5 stars |
| 3 | Feedback | `review_text` | TEXT | Yes | 10-500 chars |
| 4 | What did you like? | `review_liked` | TEXT | No | Positive aspects |
| 5 | What to improve? | `review_improve` | TEXT | No | Suggestions |
| 6 | Screenshot | `review_screenshot` | FILE | Yes if 5★ | Proof for discount |
| 7 | Name | `review_client_name` | TEXT | Yes | From booking |
| 8 | Phone | `review_client_phone` | PHONE | Yes | From booking |

**Choice Options for Platform (новое поле):**
```
- 🗺️ Google Maps (скидка 15%)
- 🟡 Yandex Maps (скидка 12%)
- 🟢 2GIS (скидка 12%)
- ✈️ TripAdvisor (скидка 20%)
```

**Логика верификации:**
```
1. Клиент заполняет FORM-REVIEW
2. Выбирает платформу (Google/Yandex/2GIS/TripAdvisor)
3. Если рейтинг 5 звезд → запрос скриншота
4. Скриншот отправляется админу на проверку
5. Админ проверяет:
   - Совпадает ли имя клиента
   - Есть ли отзыв на выбранной платформе
   - Нет ли дубликатов (1 клиент = 1 отзыв на платформу)
6. После одобрения:
   - Начисляется скидка (15%/12%/12%/20%)
   - Обновляется {{review_[platform]_status}} → ✅
   - Срок действия скидки: 90 дней (вместо 30 в v2.0)
   - Отзыв добавляется в базу данных
7. Лучшие отзывы публикуются в канале (Блок 965)
```
