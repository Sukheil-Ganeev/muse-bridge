# Mini App для бронирования VIP-DXB-RUS

**Источник:** `_ПРИМЕРЫ/09_Mini-App-Hotel/` + `_ПРИМЕРЫ/12_CRM-система/Недвижимость _ Резиденции.md`

**Концепция:** Telegram Mini App для визуального бронирования туров с CRM-функционалом.

---

## Что такое Mini App

Mini App — это веб-приложение внутри Telegram:
- Открывается прямо в боте (без перехода в браузер)
- Полноценный интерфейс с формами, галереями, картами
- Доступ к данным пользователя Telegram
- Мгновенные уведомления через бота

### Преимущества для VIP-DXB-RUS

| Стандартный бот | Mini App |
|-----------------|----------|
| Текст + кнопки | Визуальный интерфейс |
| Последовательный выбор | Фильтры и сортировка |
| Одно фото за раз | Галереи, карусели |
| Простые формы | Календари, слайдеры |
| Нет карт | Интерактивные карты |

## CRM-функционал (из кейса резиденций)

### Архитектура статусов бронирования

```
Новая → В обработке → Подтверждена → Оплачена → В процессе → Завершена
  │         │             │             │            │
  └─ Отменена (из любого статуса до "В процессе")
```

### Для администратора (веб-панель)

```
┌─────────────────────────────────────────────────────────────┐
│ VIP-DXB-RUS | Панель управления              👤 Admin       │
├─────────────────────────────────────────────────────────────┤
│ [Дашборд] [Бронирования] [Клиенты] [Туры] [Отчеты]         │
├─────────────────────────────────────────────────────────────┤
│ 📊 Сегодня: 5 бронирований | 12,450 AED | 3 в процессе     │
├─────────────────────────────────────────────────────────────┤
│ Фильтры: [Все▼] [Сегодня▼] [Любой тур▼]      🔍 Поиск     │
├─────────────────────────────────────────────────────────────┤
│ ID       │ Клиент      │ Тур          │ Дата    │ Статус   │
├──────────┼─────────────┼──────────────┼─────────┼──────────┤
│ VIP-2847 │ @ivan_demo  │ Safari       │ 8 фев   │ ⏳ Новая  │
│          │ +971...     │ 2 чел, 470$  │ 15:00   │ [▼]      │
├──────────┼─────────────┼──────────────┼─────────┼──────────┤
│ VIP-2846 │ @maria_test │ Abu Dhabi    │ 8 фев   │ ✅ Оплач │
│          │ +971...     │ 4 чел, 1120$ │ 08:00   │ [▼]      │
└─────────────────────────────────────────────────────────────┘
```

### Действия по статусам

| Статус | Действия админа | Уведомление клиенту |
|--------|-----------------|---------------------|
| Новая | Принять / Отклонить | "Заявка получена, ожидайте" |
| В обработке | Подтвердить / Запросить детали | "Уточняем детали..." |
| Подтверждена | Отправить счет | "Подтверждено! Оплатите..." |
| Оплачена | Назначить гида | "Оплата получена! Ваш гид..." |
| В процессе | Отметить завершение | "Наслаждайтесь туром!" |
| Завершена | Запросить отзыв | "Спасибо! Оставьте отзыв..." |

## Интеграция Mini App с ботом

### Запуск Mini App из бота

**Блок вызова Mini App:**
```
БЛОК 1200: MINI_APP_LAUNCHER
├── Текст: "🌟 Откройте каталог туров для удобного выбора!"
├── Inline-кнопка:
│   type: web_app
│   url: "https://app.vipdxbrus.com"
│   text: "📱 Открыть каталог"
└── Альтернатива: [Текстовый каталог] → 500
```

### Передача данных

**Из бота в Mini App:**
```json
{
  "user_id": "{{USER_ID}}",
  "name": "{{NAME}}",
  "phone": "{{PHONE}}",
  "loyalty_level": "{{LOYALTY_LEVEL}}",
  "bonus_points": "{{BONUS_POINTS}}",
  "language": "{{LANG}}",
  "utm_source": "{{UTM_SOURCE}}"
}
```

**Из Mini App в бота (после бронирования):**
```json
{
  "action": "booking_created",
  "booking_id": "VIP-2847",
  "tour_id": "safari_adventure",
  "date": "2026-02-08",
  "people": 2,
  "total": 470,
  "pickup_hotel": "Marriott JBR"
}
```

### Уведомления через бота

После бронирования в Mini App бот отправляет:

```

📍 Safari Adventure
📅 8 февраля 2026, 15:00
👥 2 человека
🏨 Заберем из: Marriott JBR
💰 470 AED

⏳ Ожидайте подтверждения в течение 1 часа.
```

## Технический стек

### Frontend Mini App

```
React / Vue.js
├── Telegram Web App SDK
├── UI-библиотека (Material UI / Ant Design)
├── Карты (Mapbox / Google Maps)
├── Календарь (react-datepicker)
└── Галерея (lightbox)
```

### Backend

```
Node.js / Python
├── REST API для Mini App
├── WebSocket для real-time статусов
├── PostgreSQL / MongoDB база данных
├── Redis для кэширования
└── Интеграция с ботом через Bot API
```

### Хостинг

```
Cloudflare Pages (frontend) — бесплатно
Railway / Render (backend) — от $5/мес
Supabase (база + auth) — бесплатно до 500MB
```

## Альтернатива: Упрощенная версия

Если нет ресурсов на полноценный Mini App, можно использовать:

### Telegra.ph + Inline-кнопки

1. Создать страницы туров на Telegra.ph с фото
2. Добавить inline-кнопки для бронирования
3. Форма бронирования — через бота

**Плюсы:** Бесплатно, быстро (1 неделя)
**Минусы:** Нет календаря, фильтров, личного кабинета

### Google Forms + Google Sheets

1. Каталог туров — PDF или Telegra.ph
2. Бронирование через Google Forms
3. CRM — Google Sheets + скрипты

**Плюсы:** Бесплатно, просто
**Минусы:** Не в Telegram, неудобный UX
