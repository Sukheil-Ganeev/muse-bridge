# Адаптации механик продаж для VIP-DXB-RUS

Эта директория содержит адаптированные механики продаж из успешных кейсов Telegram-ботов для туристического бота VIP-DXB-RUS.

## Файлы

### `sales-mechanics.md` (основной документ)

Полное описание 3 механик продаж с детальными блоками, формами, переменными и roadmap внедрения.

**Содержание:**
1. **Квиз "Какой тур вам подходит?"** (7 вопросов, конверсия 26%)
   - Источник: Кейс Автошкола
   - Блоки: 980-989
   - Новая форма: FORM-QUIZ
   - 9 новых переменных

2. **Автоматизация бронирования со статусами** (5 статусов, +50% конверсия)
   - Источник: Кейс Резиденции Villingston
   - Блоки: 990-997
   - Статусы: Новая → В обработке → Подтверждена → Оплачена → Завершена
   - 15 новых переменных
   - Интеграция с AmoCRM

3. **Воронка для B2B-партнеров** (конверсия 31%, новый канал продаж)
   - Источник: Кейс HR-рекрутинг
   - Блоки: 1000-1021
   - Новая форма: FORM-B2B + FORM-B2B-BOOKING
   - 30 новых переменных
   - Закрытый канал @vipdxbrus_partners

## Метрики для отслеживания

**Квиз:**
- Конверсия старт → завершение: целевой 70%+
- Конверсия завершение → заявка: целевой 20%+

**Статусы:**
- Время обработки заявки: целевой < 1 час
- Конверсия новая → оплачена: целевой 60%+
- Процент отмен: целевой < 10%

**B2B:**
- Количество партнеров: целевой 10+ в месяц 1
- Конверсия заявка → одобрение: целевой 50%+
- Доля B2B от общей выручки: целевой 15%+ к месяцу 3
