## Обзор системы

### Источники вдохновения

**Кейс #2: Компьютерный клуб** (HR, контроль персонала)
- Проверка работы сотрудников 12 раз в день
- Фото-отчеты о выполнении заданий
- Мотивация через бонусы

**Кейс #4: Женская фитнес-студия** (Опросы клиентов)
- Сбор обратной связи после тренировок
- Сценарии прогрева для недовольных клиентов

**Кейс #13: Продвижение в геосервисах** (NPS, отзывы)
- Механика оценки от 1 до 10
- Обработка негативных отзывов до публикации
- Рост рейтинга с 4.6 до 5.0 за месяц

**Кейс #24: Частный детский сад** (Централизация коммуникации)
- Система обратной связи родители-воспитатели
- Отслеживание статуса обращений
- Снижение нагрузки на персонал

## Контроль работы гидов и партнеров

### Концепция

Система контроля качества работы гидов, водителей и партнеров на каждом этапе тура. Позволяет:
- Отслеживать готовность к турам (транспорт, внешний вид, подтверждение маршрута)
- Собирать фото-отчеты после каждой экскурсии
- Мотивировать лучших исполнителей
- Выявлять проблемные зоны

#### GUIDE-RATING (Рейтинг гидов)

**Блок: 1042**

Автоматический расчет рейтинга на основе:

```
📊 КРИТЕРИИ РЕЙТИНГА ГИДА:

1. Средняя оценка клиентов (вес 40%)
   - Из FORM-SATISFACTION
   - Обновляется после каждого тура

2. Своевременность отчетов (вес 20%)
   - % отчетов, сданных вовремя
   - Штраф за опоздание с отчетом > 2 часов

3. Отсутствие жалоб (вес 25%)
   - 0 жалоб = 100 баллов
   - 1 жалоба = -20 баллов
   - 2+ жалобы = -50 баллов

4. Количество туров (вес 15%)
   - Активность в течение месяца

ФОРМУЛА:
{{guide_rating}} = (оценка_клиентов × 0.4) +
                    (своевременность × 0.2) +
                    (без_жалоб × 0.25) +
                    (активность × 0.15)

ГРАДАЦИЯ:
⭐⭐⭐⭐⭐ 90-100 — Platinum (бонус +30%)
⭐⭐⭐⭐ 80-89 — Gold (бонус +20%)
⭐⭐⭐ 70-79 — Silver (бонус +10%)
⭐⭐ 60-69 — Bronze (без бонуса)
⭐ <60 — Review (собеседование с HR)
```

**Мотивация лучших гидов:**
- ТОП-3 гида месяца → публикация в канале + денежный бонус
- Platinum-статус → эксклюзивные VIP-туры
- Рейтинг доступен гиду в реальном времени через бот

#### Расчет рейтинга гида (Блок 1042)

```javascript
// Сбор данных за последние 30 дней
function calculate_guide_rating(guide_id) {

    // 1. Средняя оценка клиентов (40%)
    client_ratings = get_client_ratings(guide_id, days: 30);
    avg_client_rating = average(client_ratings);  // 0-5
    normalized_client = (avg_client_rating / 5) * 100;
    score_clients = normalized_client * 0.4;

    // 2. Своевременность отчетов (20%)
    total_reports = count_reports(guide_id, days: 30);
    on_time_reports = count_on_time_reports(guide_id, days: 30);
    timeliness = (on_time_reports / total_reports) * 100;
    score_timeliness = timeliness * 0.2;

    // 3. Отсутствие жалоб (25%)
    complaints = count_complaints(guide_id, days: 30);
    if (complaints == 0) {
        score_complaints = 100 * 0.25;
    } else if (complaints == 1) {
        score_complaints = 80 * 0.25;
    } else {
        score_complaints = 50 * 0.25;
    }

    // 4. Активность (15%)
    tours_count = count_tours(guide_id, days: 30);
    max_possible_tours = 60;  // 2 тура в день
    activity = (tours_count / max_possible_tours) * 100;
    score_activity = activity * 0.15;

    // ИТОГОВЫЙ РЕЙТИНГ
    {{guide_rating}} = score_clients + score_timeliness +
                       score_complaints + score_activity;

    // Определение статуса
    if ({{guide_rating}} >= 90) {
        {{guide_status}} = "Platinum ⭐⭐⭐⭐⭐";
        bonus_percent = 30;
    } else if ({{guide_rating}} >= 80) {
        {{guide_status}} = "Gold ⭐⭐⭐⭐";
        bonus_percent = 20;
    } else if ({{guide_rating}} >= 70) {
        {{guide_status}} = "Silver ⭐⭐⭐";
        bonus_percent = 10;
    } else if ({{guide_rating}} >= 60) {
        {{guide_status}} = "Bronze ⭐⭐";
        bonus_percent = 0;
    } else {
        {{guide_status}} = "Review ⭐";
        bonus_percent = 0;
        schedule_hr_meeting(guide_id);
    }

    return {{guide_rating}};
}

**Разработка бота (расширение функционала):**
```

```

Поддержка/обновления:   800 AED
─────────────────────────────
ИТОГО/месяц:          1,600 AED
```

#### Доходы

**Экономия на операциях:**
```
Экономия времени менеджеров: 6,000 AED/мес
Снижение текучести кадров:   3,000 AED/мес
Предотвращение оттока:       5,000 AED/мес
─────────────────────────────────────────
ИТОГО экономия:             14,000 AED/мес
```

**Рост продаж:**
```
Повторные продажи (+25%):   10,000 AED/мес
Рефералы (+15%):             8,000 AED/мес
Допродажи VIP-услуг:         7,000 AED/мес
─────────────────────────────────────────
ИТОГО прирост:              25,000 AED/мес
```

**Общая выгода:**
```
Экономия + Прирост = 14,000 + 25,000 = 39,000 AED/мес
```

#### Расчет ROI

```
Инвестиции (разовые):       25,000 AED
Ежемесячные расходы:         1,600 AED
Ежемесячная выгода:         39,000 AED

Чистая прибыль/месяц: 39,000 - 1,600 = 37,400 AED

Окупаемость: 25,000 / 37,400 = 0.67 месяца
             = ~20 дней

ROI за 3 месяца: (37,400 × 3 - 25,000) / 25,000 × 100%
               = (112,200 - 25,000) / 25,000 × 100%
               = 348.8%

ROI за 12 месяцев: (37,400 × 12 - 25,000) / 25,000 × 100%
                  = (448,800 - 25,000) / 25,000 × 100%
                  = 1,695%
```
