Быстрая справка по 3 механикам продаж из `sales-mechanics.md`

## 1. КВИЗ (Блоки 980-989)

```
Старт → Q1 (Бюджет) → Q2 (Интересы) → Q3 (Дни) → Q4 (Группа) → Q5 (Темп) → Q6 (Время) → Q7 (Опыт) → Результат
 980       981            982            983         984          985          986          987           988-989
```

**Цель:** Увеличить конверсию с 10-15% до 20-26%

**7 вопросов:**
1. Бюджет: economy/standard/comfort/vip
2. Интересы: архитектура/культура/экстрим/природа/развлечения/роскошь
3. Дни: короткая/средняя/долгая/резидент
4. Группа: соло/пара/семья/друзья/корпоратив
5. Темп: расслабленный/средний/активный/интенсивный
6. Время: утро/день/вечер/ночь/любое
7. Опыт: первый раз/возвращаюсь/постоянный/резидент

**Результат:** 3 персональных рекомендации + промокод QUIZ10 (24 часа)

**Новые переменные:** `quiz_*` (9 штук)

**Новая форма:** FORM-QUIZ (бронирование пакета 1-3 туров)

## 2. СТАТУСЫ БРОНИРОВАНИЯ (Блоки 990-997)

```
Новая → В обработке → Подтверждена → Оплачена → Завершена
 990         991             992            993         994

                              ↓
                          Отменена
                            996-997
```

**Цель:** Увеличить конверсию заявка→оплата с 40% до 60%

**5 статусов:**

| Статус | Блок | Действие системы | Действие клиента |
|--------|------|------------------|------------------|
| Новая | 990 | Уведомление менеджеру | Ждет звонка (1 час) |
| В обработке | 991 | Назначение менеджера | Согласование деталей |
| Подтверждена | 992 | Выставление счета | Оплата (24 часа) |
| Оплачена | 993 | Генерация ваучера | Ждет тура |
| Завершена | 994 | Начисление баллов | Отзыв + след. тур |

**Автонапоминания:**
- Подтверждена: через 12ч + 23ч (перед автоотменой)
- Оплачена: за 24ч + 2ч до тура
- Завершена: сразу после тура (запрос отзыва)

**Новые переменные:** `booking_*` (15 штук)

**Интеграция:** AmoCRM (webhooks для синхронизации статусов)

## 3. B2B-ВОРОНКА (Блоки 1000-1021)

```
Landing → Заявка → Ожидание → Одобрение → Кабинет партнера → Бронирование
  1000      1001      1005        1006          1010              1020-1021

                                      ↓
                              Отклонение
                                  (нет блока)
```

**Цель:** Создать новый канал продаж (30% от выручки к месяцу 6)

**Типы партнеров:**
- Турагентства (комиссия 20-25%)
- Отели (комиссия 15-20%)
- Корпорации (комиссия 15%, оптовые пакеты)

**Условия:**
- Оптовая цена: -10-20% от розницы
- Комиссия партнеру: 15-25%
- Минимум: 5 туров/месяц

**Партнерский кабинет (1010):**
- Статистика (туры, оборот, комиссия)
- Создание бронирований (FORM-B2B-BOOKING)
- Каталог туров с оптовыми ценами
- История заказов
- Выплата комиссии
- Маркетинговые материалы

**Закрытый канал:** @vipdxbrus_partners
- Акции только для партнеров
- Новые туры (раннее тестирование)
- Маркетинговые материалы (фото, видео)
- Кейсы и best practices

**Новые переменные:** `b2b_*` (30 штук)

**Новые формы:** FORM-B2B (заявка) + FORM-B2B-BOOKING (оптовое бронирование)
