## 1. Сегментация аудитории

### Концепция (адаптировано из кейса "Преподаватель арабского языка")

**Проблема:** Разная аудитория с разными запросами и болями. Универсальные предложения не работают.

**Решение:** Разделить аудиторию на 4 чётких сегмента и для каждого создать персонализированную воронку.

**Результат в кейсе:** Прирост подписчиков +26% за месяц, конверсия в заявку выросла с 8% до 19%.

---

### 4 сегмента VIP-DXB-RUS

#### Сегмент 1: ТУРИСТЫ (первый раз в ОАЭ)
**Кто:** Люди, которые планируют первую поездку в Дубай/ОАЭ.

**Боли:**
- Не знают, что посмотреть и куда пойти
- Боятся переплатить за туры
- Нужна помощь с визой, маршрутами, правилами
- Хотят "все включено" без лишних забот

**Цели:**
- Получить готовый маршрут
- Забронировать проверенные экскурсии
- Узнать лайфхаки и секретные места
- Избежать ошибок новичков

**Что предлагать:**
- Топ-5 must-see мест Дубая
- Пакетные туры (3/5/7 дней)
- Инструкция по визе
- Лайфхаки: как сэкономить 30%
- "Первый тур со скидкой 15%"

**Примеры сообщений:**
```
🌴 Первый раз в Дубае?

Мы создали готовый маршрут, чтобы вы увидели все must-see места!

✅ Burj Khalifa (самое высокое здание мира)
✅ Dubai Mall (крупнейший ТЦ)
✅ Золотой рынок (восточный колорит)
✅ Пустыня (джип-сафари на закате)
✅ Старый город (аутентичный Дубай)

💰 Готовый пакет "Всё включено" (3 дня):
   Обычная цена: 1,500 AED
   Для новичков: 1,275 AED (-15%)

📍 Включено:
- Трансфер из аэропорта
- 3 экскурсии с русским гидом
- Билеты в Burj Khalifa

- Забронировать пакет
- Посмотреть программу
```

**Кто:** Русскоязычные резиденты ОАЭ (работают, живут с семьёй).

**Боли:**
- Нужны семейные активности (детям скучно в ТЦ)
- Хотят узнать ОАЭ глубже (не только Дубай)
- Ищут долгосрочные услуги (консьерж, визы для гостей, логистика)
- Нужны сезонные предложения (праздники, каникулы)

**Цели:**
- Организовать досуг для семьи
- Исследовать другие эмираты (Рас-аль-Хайма, Фуджейра, Абу-Даби)
- Получить консьерж-сервис
- Экономить на постоянных услугах

**Что предлагать:**
- Семейные туры (детские активности)
- Туры в другие эмираты
- Консьерж-пакет (встречи родственников, организация праздников)
- Сезонные предложения (летние лагеря, новогодние туры)
- VIP-карта со скидками (для резидентов)

**Примеры сообщений:**

- Предлагать клиентам качественный сервис

## 2. FORM-SEGMENTATION — Квалификация

### Цель
Определить сегмент пользователя за 5 вопросов и направить в соответствующую воронку.

### Источник
Кейс "Образовательный бизнес" — снижение CPL на 40% через сегментацию аудитории.

---

### 5 вопросов для определения сегмента

#### Вопрос 1: Основной (определяет сегмент на 70%)

```markdown
👋 Добро пожаловать в VIP-DXB-RUS!

Чтобы предложить вам идеальный вариант, ответьте на 1 вопрос:

❓ Вы уже были в ОАЭ?

Buttons:
- Нет, первый раз (→ Сегмент 1: Туристы)
- Да, 1 раз (→ Вопрос 2)
- Да, 2+ раза (→ Сегмент 4: Любители ОАЭ)
- Я живу в ОАЭ (→ Сегмент 2: Экспаты)
- Я турагентство/отель (→ Сегмент 3: Партнёры)
```

**Логика:**
- "Нет, первый раз" → Сегмент 1 (Туристы) ✅
- "Да, 1 раз" → Вопрос 2 (уточняем: турист или потенциальный экспат?)
- "Да, 2+ раза" → Сегмент 4 (Любители ОАЭ) ✅
- "Я живу в ОАЭ" → Сегмент 2 (Экспаты) ✅
- "Я турагентство/отель" → Сегмент 3 (Партнёры) ✅

---

#### Вопрос 2: Уточняющий (для тех, кто был 1 раз)

```markdown
❓ Когда вы планируете следующую поездку?

Buttons:
- Уже в ОАЭ сейчас! (→ Сегмент 1: Туристы)
- В ближайший месяц (→ Сегмент 1: Туристы)
- Через 2-6 месяцев (→ Сегмент 4: Любители ОАЭ)
- Не знаю, просто интересуюсь (→ Сегмент 4: Любители ОАЭ)
```

**Логика:**
- Срочные (сейчас/месяц) → Туристы (нужна помощь прямо сейчас)
- Планирующие (2-6 мес) → Любители ОАЭ (ищут эксклюзив, не спешат)
- Интересующиеся → Любители ОАЭ (контентная воронка)


### Автоматическое сохранение источника

#### Код (Python + aiogram)

```python
@dp.message_handler(commands=['start'])
async def start_handler(message: types.Message):
    user_id = message.from_user.id

    # Извлечь параметр после /start
    args = message.get_args()  # "instagram_oct2026_stories"

    if args:
        # Разбить на части
        parts = args.split('_')
        utm_source = parts[0] if len(parts) > 0 else 'direct'
        utm_campaign = parts[1] if len(parts) > 1 else 'unknown'
        utm_medium = parts[2] if len(parts) > 2 else 'unknown'
    else:
        utm_source = 'direct'
        utm_campaign = 'organic'
        utm_medium = 'typing'

    # Сохранить в базу данных
    save_user_source(
        user_id=user_id,
        utm_source=utm_source,
        utm_campaign=utm_campaign,
        utm_medium=utm_medium,
        timestamp=datetime.now()
    )

    # Продолжить обычный flow
    await send_welcome_message(message)
```

## 5. Викторина "Как хорошо вы знаете ОАЭ?"

### Концепция (адаптировано из кейса "Фитнес-клуб викторина")

**Цель:** Вовлечь аудиторию через геймификацию, собрать базу подписчиков канала, повысить лояльность.

**Результат в кейсе:** Рост подписчиков канала на 25%, конверсия в заявку 20%.

### Механика викторины

1. **Вход:** Пользователь нажимает кнопку "Пройти викторину"

   - 5-6 баллов: "Турист" → скидка 5%
