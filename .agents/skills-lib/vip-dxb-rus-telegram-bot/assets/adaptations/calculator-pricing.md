# Калькулятор цен туров для VIP-DXB-RUS

**Источник:** `_ПРИМЕРЫ/02_Калькулятор/Калькулятор услуг.md`

**Концепция:** Бот-калькулятор для расчета стоимости туров в ОАЭ с мгновенным результатом.

---

## Зачем нужен калькулятор

### Проблема без калькулятора
- Клиент пишет "сколько стоит тур?" → ждет ответа менеджера
- Если менеджер не отвечает сразу → клиент уходит к конкуренту
- 70% клиентов не оставляют заявку без понимания цены

### Решение с калькулятором
- Клиент получает ориентировочную стоимость **за 2 минуты**
- Уже "прогрет" и готов к разговору с менеджером
- Бот собирает предварительные данные автоматически

## Формулы расчета

### Базовые цены (переменные)

```javascript
// Экскурсии (цена за человека)
PRICE_EXCURSION_DUBAI = 180     // Дубай обзорный
PRICE_EXCURSION_ABUDHABI = 280  // Абу-Даби
PRICE_EXCURSION_SAFARI = 250    // Сафари
PRICE_EXCURSION_YACHT = 350     // Яхта

// Туры (цена за день/чел)
PRICE_TOUR_BASE = 400           // Базовая стоимость дня
PRICE_HOTEL_3STAR = 250         // Отель 3*
PRICE_HOTEL_4STAR = 450         // Отель 4*
PRICE_HOTEL_5STAR = 800         // Отель 5*

// Скидки за группу
DISCOUNT_3_4_PEOPLE = 0.10      // 10% на 3-4 чел
DISCOUNT_5_10_PEOPLE = 0.15     // 15% на 5-10 чел
DISCOUNT_10_PLUS = 0.20         // 20% на 10+ чел
```

### Формула для экскурсий

```
TOTAL = BASE_PRICE × PEOPLE × (1 - GROUP_DISCOUNT) + EXTRAS
```

**Пример:**
- Сафари (250 AED) × 4 человека × (1 - 0.10) + Фотосессия (150) = 1050 AED

### Формула для туров

```
TOTAL = (TOUR_BASE + HOTEL_PRICE) × DAYS × PEOPLE × (1 - GROUP_DISCOUNT) + TRANSPORT + EXTRAS
```

**Пример:**
- (400 + 450) × 5 дней × 2 чел × 1.0 + 200 + 300 = 9000 AED

## Аналитика

### Метрики для отслеживания

| Метрика | Целевое значение |
|---------|------------------|
| Конверсия старт → завершение калькулятора | 75%+ |
| Конверсия калькулятор → заявка | 25%+ |
| Среднее время прохождения | < 3 минут |
| Средний чек расчета | 2,500+ AED |
| Конверсия прогрева (1ч) → заявка | 10%+ |
| Конверсия прогрева (24ч) → заявка | 15%+ |

### События для трекинга

```
calc_started       — начал калькулятор
calc_type_selected — выбрал тип тура
calc_people_set    — указал кол-во людей
calc_hotel_set     — выбрал отель
calc_completed     — получил расчет
calc_to_booking    — перешел к бронированию
calc_abandoned     — бросил калькулятор
calc_restart       — начал заново
```

## Ошибки, которых нужно избежать

### НЕ делать

1. **Слишком много вопросов** — максимум 6-8 шагов
2. **Сложные формулировки** — "тип размещения DBL" → "двухместный номер"
3. **Фейковый расчет** — одна цена для всех = потеря доверия
4. **Нет результата** — "оставьте заявку для расчета" раздражает
5. **Свободный ввод везде** — кнопки > текстовые поля

### Обязательно делать

1. **Показывать прогресс** — "Шаг 3 из 6"
2. **Давать ориентир** — "от X до Y AED"
3. **Честная вилка** — "точную сумму скажу после деталей"
4. **Понятный финал** — четкий CTA после расчета
5. **Сохранять историю** — клиент может вернуться
