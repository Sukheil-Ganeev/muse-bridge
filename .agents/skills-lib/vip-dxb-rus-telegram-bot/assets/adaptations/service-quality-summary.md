# Краткая сводка: Система контроля качества VIP-DXB-RUS

## 🎯 Что создано

Полная система контроля качества туристических услуг, адаптированная из 4 лучших кейсов:
- **Кейс #2:** Компьютерный клуб (контроль персонала)
- **Кейс #4:** Фитнес-студия (опросы клиентов)
- **Кейс #13:** Продвижение в геосервисах (NPS, отзывы)
- **Кейс #24:** Детский сад (система обратной связи)

---

## 📦 Что включено

### 1️⃣ Контроль работы гидов (Блоки 1040-1045)

| Блок | Название | Для кого | Что делает |
|------|----------|----------|------------|
| **1040** | FORM-GUIDE-REPORT | Гиды | Отчет после тура (фото, оценка, инциденты) |
| **1041** | FORM-GUIDE-CHECKLIST | Гиды | Проверка готовности перед выездом |
| **1042** | GUIDE-RATING | Гиды, Менеджеры | Автоматический рейтинг (0-100 баллов) |
| **1043** | GUIDE-DASHBOARD | Гиды | Личный кабинет (статистика, место в рейтинге) |
| **1044** | MANAGER-ALERT | Менеджеры | Уведомления о проблемах (критические/ежедневные) |
| **1045** | PARTNER-CONTROL | Менеджеры | Контроль партнеров (рестораны, отели, яхты) |

**Ключевые механики:**
- Фото-отчеты обязательны (как в Компьютерном клубе)
- Чек-лист за 30/15 минут до выезда → напоминания
- Рейтинг по формуле: клиенты (40%) + дисциплина (20%) + без жалоб (25%) + активность (15%)
- ТОП-3 гида месяца → публикация + бонус до +30%

---

### 2️⃣ Опросы удовлетворенности (Блоки 1046-1048)

| Блок | Название | Триггер | Что делает |
|------|----------|---------|------------|
| **1046** | FORM-SATISFACTION | Через 2-4 часа после тура | Опрос 8 вопросов + NPS (0-10) |
| **1047** | NPS-PROMOTERS | Если NPS 9-10 | Запрос отзыва на Google + промокод 500 AED |
| **1048** | NPS-DETRACTORS | Если NPS 0-6 | Звонок менеджера в течение 2 часов + скидка 30% |

**Ключевые механики:**
- NPS-сегментация: Промоутеры (9-10) → отзыв, Критики (0-6) → звонок менеджера
- Автоматические действия без участия человека
- Оценка гида/транспорта/организации → влияет на рейтинг

---

### 3️⃣ Система жалоб (Блоки 1049-1050)

| Блок | Название | Для кого | Что делает |
|------|----------|----------|------------|
| **1049** | FORM-COMPLAINT | Все | Форма жалобы (анонимная/открытая) |
| **1050** | COMPLAINT-STATUS | Автор жалобы | Отслеживание статуса (таймлайн) |

**Ключевые механики:**
- Классификация по приоритету: Критический (1 час) → Высокий (2 часа) → Средний (12 часов)
- SLA-таймеры: автоэскалация при превышении
- Статусы: Получена → Назначена → В обработке → Решена → Закрыта
- Уведомления клиенту на каждом этапе

## 📊 Переменные

### Основные переменные

```javascript
// Гиды
{{guide_rating}}          // 0-100 (автоматический расчет)
{{guide_status}}          // Platinum/Gold/Silver/Bronze/Review
{{tours_completed}}       // Количество туров за месяц
{{avg_rating}}            // Средняя оценка от туристов

// Туристы
{{nps_score}}             // 0-10 (Net Promoter Score)
{{overall_rating}}        // 1-10 (общая оценка тура)
{{guide_rating_client}}   // 1-5 (оценка гида)

// Жалобы
{{complaint_id}}          // Уникальный ID обращения
{{complaint_status}}      // Получена/В обработке/Решена
{{sla_deadline}}          // Дедлайн для ответа
```
