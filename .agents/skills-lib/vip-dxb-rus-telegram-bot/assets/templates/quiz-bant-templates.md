# Шаблоны квизов и BANT-квалификации

## Шаблон 1: Квиз-бот для лидогенерации

### Результаты
- Конверсия с рекламы: +40%
- Стоимость лида: -30%
- Средний чек: +25%

### Структура

```
БЛОК 1: ПРИВЕТСТВИЕ
├─ Текст: "🎯 Пройди квиз за 2 минуты и узнай:
│          ✅ Какой тур подходит именно тебе
│          ✅ Получи персональную скидку до 30%"
└─ Кнопка: "🚀 Начать квиз"

БЛОК 2: ИНИЦИАЛИЗАЦИЯ
├─ quiz_score = 0
├─ category_adventure = 0
├─ category_relax = 0
└─ category_culture = 0

БЛОКИ 3-7: ВОПРОСЫ

Вопрос 1: "🏖️ Какой отдых предпочитаете?"
├─ Активный (сафари, спорт) → +3 adventure
├─ Спокойный (пляж, SPA) → +3 relax
└─ Познавательный (музеи, экскурсии) → +3 culture

Вопрос 2: "💰 Бюджет на человека?"
├─ До 500 AED → score +1
├─ 500-1500 AED → score +2
└─ От 1500 AED → score +3

Вопрос 3: "👥 Сколько человек?"
├─ 1-2 → score +1
├─ 3-5 → score +2
└─ 6+ → score +3

Вопрос 4: "⏰ Когда планируете?"
├─ Через неделю → score +3
├─ Через месяц → score +2
└─ Через 3+ месяца → score +1

Вопрос 5: "🌟 Что важнее?"
├─ Цена → category_budget
├─ Качество → category_premium
└─ Уникальность → category_exclusive

БЛОК 8: РАСЧЁТ РЕЗУЛЬТАТА
├─ Если adventure > relax AND adventure > culture → "Искатель приключений"
├─ Если relax > adventure AND relax > culture → "Любитель комфорта"
└─ Иначе → "Культурный путешественник"

БЛОКИ 9-11: РЕЗУЛЬТАТЫ (3 варианта)

Искатель приключений:
├─ Рекомендация: Сафари, багги, вертолёты
├─ Промокод: ADVENTURE25 (скидка 25%, 48 часов)
└─ Кнопка: "Смотреть подборку"

Любитель комфорта:
├─ Рекомендация: Пляжи, SPA, яхты
├─ Промокод: RELAX20 (скидка 20%, 48 часов)
└─ Кнопка: "Смотреть подборку"

Культурный путешественник:
├─ Рекомендация: Музеи, экскурсии, гастротуры
├─ Промокод: CULTURE15 (скидка 15%, 48 часов)
└─ Кнопка: "Смотреть подборку"

БЛОК 12: РЕТАРГЕТИНГ (не завершивших)
├─ Триггер: начал квиз И НЕ завершил
├─ Задержка: 1 день
└─ Текст: "👋 Осталось пару вопросов! А скидка ждёт 😉"
```

### Переменные квиза

```
quiz_score (number: 0-15)
quiz_category (text: adventure/relax/culture)
quiz_budget (choice: economy/medium/premium)
quiz_started (boolean)
quiz_completed (boolean)
quiz_promo_code (text)
quiz_promo_expires (datetime)
```

## Шаблон 2: BANT-квалификация (B2B)

### Результаты
- Конверсия в сделку: +55% (40% → 62%)
- Полных брифов: +325% (20% → 85%)
- Экономия времени: 15 часов/неделя

### Что такое BANT

**B**udget — Бюджет
**A**uthority — Полномочия
**N**eed — Потребность
**T**imeframe — Сроки

### Структура

```
БЛОК 1: ВХОДЯЩИЙ ЛИД
├─ Сохранить: utm_source, utm_medium
└─ Текст: "👋 Что вас интересует?"
    ├─ Экскурсии
    ├─ Трансфер
    ├─ Яхты
    └─ Всё вместе

БЛОКИ 2-5: BANT-ВОПРОСЫ

B (Budget): "💰 Какой бюджет на поездку?"
├─ До 500 AED/чел → 0 points
├─ 500-1500 AED/чел → 2 points
└─ От 1500 AED/чел → 3 points

A (Authority): "👤 Кто принимает решение?"
├─ Я сам решаю → 3 points
├─ Нужно согласовать → 1 point
└─ Собираю информацию → 0 points

N (Need): "🎯 Для чего поездка?"
├─ Отпуск с семьёй → 2 points
├─ Бизнес + отдых → 3 points
├─ Событие (свадьба, юбилей) → 3 points
└─ Просто интересуюсь → 1 point

T (Timeframe): "⏰ Когда планируете?"
├─ Через неделю → 3 points
├─ Через месяц → 2 points
├─ Через 3+ месяца → 0 points
└─ Не определился → 0 points

БЛОК 6: РАСЧЁТ LEAD SCORE
├─ bant_score = budget + authority + need + timeline
└─ MAX: 12 баллов

БЛОК 7: МАРШРУТИЗАЦИЯ
├─ Если score >= 9 → 🔥 ГОРЯЧИЙ ЛИД
├─ Если score >= 5 → 🌡️ ТЁПЛЫЙ ЛИД
└─ Если score < 5 → ❄️ ХОЛОДНЫЙ ЛИД

БЛОК 8 (ГОРЯЧИЙ): СБОР БРИФА
├─ Имя
├─ Телефон
├─ Даты поездки
├─ Количество человек
├─ Особые пожелания
└─ → Уведомление менеджеру: "🔥 ОТВЕТИТЬ ЗА 15 МИНУТ!"

БЛОК 9 (ТЁПЛЫЙ): АВТОВОРОНКА
├─ День 1: Полезный контент
├─ День 3: Кейс клиента
├─ День 5: Повторная квалификация
└─ → При ответе → перевести в горячий

БЛОК 10 (ХОЛОДНЫЙ): ПОДПИСКА
├─ Подписка на канал
├─ Email-рассылка раз в 2 недели
└─ → Периодическая реактивация
```

### Уведомление менеджеру (горячий лид)

```
🔥 ГОРЯЧАЯ ЗАЯВКА!

👤 Клиент: {{client_name}}
📞 Телефон: {{client_phone}}
🎯 Интерес: {{service_interest}}

📊 BANT:
├─ Бюджет: Премиум (3/3)
├─ Решение: Сам принимает (3/3)
├─ Цель: Событие (3/3)
├─ Сроки: Через неделю (3/3)
└─ ИТОГО: 12/12 баллов

⏰ Обработать в течение 15 минут!

[📞 Позвонить] [💬 Написать]
```

### Переменные BANT

```
bant_budget (choice: economy/medium/premium)
bant_authority (choice: self/consult/info)
bant_need (choice: vacation/business/event/curious)
bant_timeframe (choice: week/month/3months/undefined)
bant_score (number: 0-12)
bant_priority (text: hot/warm/cold)
bant_notes (text)
```

## Шаблон 3: Квиз + BANT (комбинированный)

### Для VIP-DXB-RUS

```
ЭТАП 1: БЫСТРЫЙ КВИЗ (3 вопроса)
├─ Какой отдых? (adventure/relax/culture)
├─ Сколько человек? (1-2/3-5/6+)
└─ Когда? (неделя/месяц/3+месяца)

ЭТАП 2: РЕЗУЛЬТАТ + РЕКОМЕНДАЦИЯ
├─ Показать подходящие туры
├─ Показать скидку
└─ Кнопка: "Хочу забронировать"

ЭТАП 3: BANT (если нажал "забронировать")
├─ Бюджет (для выбора тура)
├─ Кто решает (для приоритета)
└─ → Маршрутизация по приоритету

ЭТАП 4: БРИФ ИЛИ АВТОВОРОНКА
├─ Горячий → Бриф + менеджер
└─ Тёплый/холодный → Контент + напоминания
```

### Метрики для отслеживания

| Метрика | Формула | Цель |
|---------|---------|------|
| Quiz Start Rate | Начали / Увидели × 100% | >70% |
| Quiz Completion | Завершили / Начали × 100% | >60% |
| Lead Conversion | Оставили контакт / Завершили × 100% | >40% |
| Hot Lead % | Горячие / Все лиды × 100% | 25-35% |
| Hot → Sale | Продажи / Горячие × 100% | >50% |
