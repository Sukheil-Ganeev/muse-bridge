# Методология аудита Telegram-ботов

## 5-этапный процесс

### Этап 1: Подготовка
- Сохранить снапшот бота
- Зафиксировать версию
- Создать директорию для результатов

### Этап 2: Анализ структуры (grep)

```bash
# Блоки по типам
grep -o '"type":"[^"]*"' snapshot.json | sort | uniq -c

# Все кнопки
grep -oP '"buttons":\s*\[[^\]]*\]' snapshot.json

# Все переходы
grep -oP '"goto":\s*"[^"]*"' snapshot.json | sort | uniq -c

# Placeholder-ы
grep -oP '"text":\s*"(Здесь будет|TODO)[^"]*"' snapshot.json
```

### Этап 3: Проверка переходов (КРИТИЧЕСКИЙ)

> **ВАЖНО:** Наличие кнопки НЕ означает, что она работает!

**Формула проверки карточки:**
```
Карточка = Название + Описание + Кнопка действия + Кнопка "Назад"
```

Проверить для каждой кнопки:
- [ ] Кнопка имеет `goto`
- [ ] `goto` ведёт на существующий блок
- [ ] Целевой блок содержит контент
- [ ] Из блока есть выход

### Этап 4: Систематическая проверка

**Чеклист категории:**
- [ ] Блок существует
- [ ] Название корректное
- [ ] Описание заполнено (не placeholder)
- [ ] Кнопки имеют переходы
- [ ] Кнопка "Назад" работает

**Чеклист карточки услуги:**
- [ ] Название услуги
- [ ] Описание (не "Здесь будет...")
- [ ] Цена указана
- [ ] Кнопка действия
- [ ] Кнопка "Назад"

## Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Поверхностный анализ | Визуальный осмотр без проверки связей | Использовать grep -A для контекста |
| Элемент ≠ функция | Есть текст, нет перехода | Формула: Название + Описание + Кнопка |
| Не проверены связи | Блоки есть, связей нет | Проверять goto для каждой кнопки |
| Placeholder остался | Забыли заполнить | Искать "Здесь будет", "TODO" |

## Скрипт автопроверки

```bash
#!/bin/bash
echo "=== ПРОВЕРКА КНОПОК ==="

EXPECTED_GT=42
ACTUAL_GT=$(grep -c "Оплатить групповой тур" snapshot.txt)

echo "Групповые туры: $ACTUAL_GT / $EXPECTED_GT"

if [ $ACTUAL_GT -lt $EXPECTED_GT ]; then
  echo "❌ ОШИБКА: Отсутствуют кнопки!"
fi
```
