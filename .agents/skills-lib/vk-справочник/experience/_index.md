# Опыт работы с VK API

Накопленные знания, ошибки и best practices при работе с VK API для туристического бизнеса.

## Критические уроки (топ-5)

### 1. Rate Limits: Community Token = 3 req/sec

**Проблема:** При превышении 3 запросов/секунду (Community Token) API возвращает ошибку 6 (Too many requests).

**Решение:**
- Добавлять `time.sleep(0.5)` между запросами
- Использовать метод `execute` для групповых запросов (до 25 методов за раз)

### 2. Отрицательный owner_id для групп

**Проблема:** `owner_id=12345678` не работает для сообществ.

**Решение:** Всегда используйте **отрицательный** ID: `owner_id=-12345678`

### 3. Загрузка фото - 3 шага обязательны

**Проблема:** Нельзя загрузить фото напрямую через wall.post.

**Решение:**
1. `photos.getWallUploadServer`
2. POST на upload URL
3. `photos.saveWallPhoto`

**Библиотека vk_api.VkUpload** автоматизирует это!

### 4. Токены не истекают, но проверяйте права

**Проблема:** Community Token работает постоянно, но ошибка 214 (Access denied) при недостающих правах.

**Решение:** При создании токена выбирайте ВСЕ нужные права:
- Управление сообществом
- Управление постами
- Фотографии
- Видео

### 5. Видео обрабатывается 5-10 минут после загрузки

**Проблема:** Видео загружено, но ещё не доступно для публикации.

**Решение:** Ждать пока `processing = 0` в `video.get` перед публикацией.

## Как записать новый опыт

**Формат:**

```markdown
## [Дата] Название урока

**Контекст:** Что пытались сделать

**Проблема:** Что пошло не так

**Решение:** Как исправили

**Урок:** Главный вывод
```

**Пример:**

```markdown
## 2026-02-05 Ошибка rate limiting при массовой загрузке фото

**Контекст:** Загружали 10 фото для альбома Desert Safari

**Проблема:** После 3-го фото API вернул ошибку 6 (Too many requests)

**Решение:** Добавили `time.sleep(1)` между загрузками

**Урок:** Community Token ограничен 3 запросами/секунду. Всегда добавляйте паузы!
```
