## Заметки по заполнению

- **Executive Summary** — писать ПОСЛЕ заполнения всех секций, не до
- **Пробелы рынка** — самая ценная секция; искать то, чего не делает НИКТО
- **Рекомендации** — только конкретные действия, не общие фразы типа "улучшить маркетинг"
- Если конкурент не рекламируется на платформе — указать "не обнаружено", не пропускать
- Карту рынка адаптировать под реальные данные, пример выше — ориентировочный
