# Website Dev Navigator

GPS-навигатор разработки сайтов для предпринимателей.

## Что это

Скилл, который ведёт через 10 этапов создания сайта -- от идеи до запуска. Работает как GPS-навигатор: показывает где ты, что дальше, позволяет пропускать этапы и возвращаться.

Основан на 21 шаблоне (10 бизнес + 10 технических + мастер-гайд), созданных из опыта разработки vipdxbrus.com (34 сессии, 248 продуктов, 56 компонентов).

## Для кого

- **Предприниматели** -- простым языком, фокус на решениях
- **Разработчики** -- технические детали, код, конфиги

Режим определяется автоматически, можно переключать.

## Как использовать

### Начать новый сайт

    "Хочу сделать сайт для [бизнеса]"
    "Создать сайт с нуля"
    "Начать разработку сайта"

### Продолжить работу

    "Продолжить разработку сайта"
    "Что дальше?"
    "Где я остановился?"

### Конкретный этап

    "Помоги с дизайном сайта"
    "Анализ конкурентов для сайта"
    "Как задеплоить сайт"

### Быстрые маршруты

    "У меня 1 час на сайт"
    "У меня 1 день"
    "Нужен минимальный сайт"

| 06 | Контент | Подготовить тексты и фото |
| 07 | SEO | Настроить для Google |

| 09 | Аналитика | Подключить отслеживание |
| 10 | Чеклист | Финальная проверка |
