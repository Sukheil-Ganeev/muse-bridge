# Website Dev Navigator -- GPS-навигатор разработки сайтов

Пошаговый навигатор от идеи до работающего сайта. 10 этапов, 21 шаблон, два режима работы.

Источник шаблонов: опыт создания vipdxbrus.com (34 сессии, 248 продуктов, 56 компонентов, анализ 12 конкурентов + 8 luxury-референсов).

---

## Концепция: GPS-навигатор

Скилл работает как GPS-навигатор в машине:

- **Текущая позиция** -- на каком этапе ты сейчас
- **Маршрут** -- что дальше, сколько осталось
- **Пропуск участков** -- не всё обязательно для каждого проекта
- **Возврат** -- можно вернуться к пройденному этапу
- **Прогресс** -- что сделано, что осталось

Навигатор НЕ заставляет проходить все 10 этапов по порядку. Он подсказывает оптимальный маршрут для конкретного проекта.

---

## Два режима работы

### Режим "Предприниматель" (по умолчанию)

- Простой язык, без технического жаргона
- Фокус на бизнес-решениях: "что выбрать и почему"
- Использует шаблоны `_бизнес.md`
- Вопросы формата: "Сколько услуг у вас?", "Кто ваш клиент?"

### Режим "Разработчик"

- Технические детали, код, конфиги
- Фокус на реализации: "как сделать"
- Использует шаблоны `_технический.md`
- Инструкции формата: "Next.js App Router, Prisma schema, Docker compose"

**Автоопределение режима:**
- Если в контексте разговора есть технические термины (React, Docker, API) -- режим разработчика
- Если пользователь говорит простым языком -- режим предпринимателя
- Переключение: "покажи техническую версию" / "объясни простым языком"

## Точки входа

### 1. "Начать новый сайт"

Приветственное сообщение:

    Привет! Я -- твой навигатор по созданию сайта.

    Давай определимся с маршрутом. Ответь на 3 вопроса:

    1. Что за бизнес? (в двух словах)
    2. Какой сайт нужен? (лендинг / каталог / магазин / визитка / не знаю)
    3. Сколько времени есть? (час / день / неделя / не спешу)

    После этого я построю маршрут и мы начнём с первого этапа.

Затем -- начать с этапа 01 (или предложить quick-start flow по времени).

### 2. "Продолжить разработку"

Проверить наличие `PROGRESS.md` в корне проекта:
- Есть -- прочитать, показать текущий этап и прогресс
- Нет -- спросить на каком этапе пользователь, создать `PROGRESS.md`

### 3. "Помоги с [конкретный этап]"

Перейти сразу к нужному этапу. Показать краткий обзор и загрузить шаблон.

### 4. "Что дальше?"

Прочитать `PROGRESS.md`, показать следующий незавершённый этап.

## 10 этапов маршрута

### Этап 01: Анализ конкурентов

**Суть:** Изучить 8-12 конкурентов, понять что работает на рынке, найти свою нишу.
**Шаблон:** `01_Анализ_конкурентов_бизнес.md` / `01_Анализ_конкурентов_технический.md`
**Результат:** Таблица конкурентов, 3 референса, список "украсть у лучших"
**Зависимости:** нет (стартовый этап)
**Связанный скилл:** `web-automation` (автоматический сбор данных с сайтов конкурентов)

Ключевые вопросы:
1. Кто ваши 4-6 прямых конкурентов? (сайты)
2. Какие 2-3 сайта-лидера рынка вас вдохновляют?
3. Что вам нравится у конкурентов? Что раздражает?

Когда переходить дальше: составлена таблица минимум 5 конкурентов, выбраны 3 референса.

### Этап 02: Анализ целевой аудитории

**Суть:** Понять кто ваши клиенты, чего хотят и как принимают решение о покупке.
**Шаблон:** `02_Анализ_целевой_аудитории_бизнес.md` / `02_Анализ_целевой_аудитории_технический.md`
**Результат:** 2-3 портрета клиентов, воронка принятия решения
**Зависимости:** лучше после 01, но можно параллельно

Ключевые вопросы:
1. Кто ваш типичный клиент? (пол, возраст, откуда)
2. Как клиент вас находит? (Google, Instagram, друзья)
3. Что для клиента важно при выборе? (цена, отзывы, скорость)
4. Как клиент предпочитает связаться? (WhatsApp, форма, звонок)

Когда переходить дальше: описан хотя бы 1 портрет клиента, определён основной канал связи.

### Этап 03: Архитектура сайта

**Суть:** Спланировать какие страницы будут, как они связаны и как посетитель будет по ним ходить.
**Шаблон:** `03_Архитектура_сайта_бизнес.md` / `03_Архитектура_сайта_технический.md`
**Результат:** Тип сайта, карта страниц, план главной страницы
**Зависимости:** после 01 и 02 (нужны данные о конкурентах и аудитории)
**Связь:** Результаты этапа 01 влияют на выбор структуры (что сработало у конкурентов)

Ключевые вопросы:
1. Какой тип сайта? (лендинг / визитка / каталог / магазин)
2. Сколько у вас услуг/товаров? (5-15 / 15-50 / 50+)
3. Какие страницы обязательны? (каталог, блог, FAQ, отзывы...)
4. Сколько категорий? (экскурсии, яхты, трансферы...)

Когда переходить дальше: выбран тип сайта, нарисовано дерево страниц, спланирована главная.

### Этап 04: Планирование разработки

**Суть:** Разбить проект на волны (этапы), чтобы запустить сайт быстрее.
**Шаблон:** `04_Планирование_разработки_бизнес.md` / `04_Планирование_разработки_технический.md`
**Результат:** План из 3-4 волн, список сессий работы
**Зависимости:** после 03 (нужна карта страниц)

Ключевые вопросы:
1. Что обязательно для запуска? (Волна 0)
2. Что можно добавить потом? (Волна 1-2)
3. Сколько сессий работы готовы выделить?

Когда переходить дальше: распределены фичи по волнам, определён MVP.

### Этап 05: Дизайн и UX

**Суть:** Определить как будет выглядеть сайт: цвета, шрифты, стиль, настроение.
**Шаблон:** `05_Дизайн_и_UX_бизнес.md` / `05_Дизайн_и_UX_технический.md`
**Результат:** Палитра цветов, шрифты, стиль (luxury/modern/classic/friendly/eco)
**Зависимости:** после 01 и 02 (стиль зависит от аудитории и конкурентов)
**Связанный скилл:** `ui-ux-pro-max` (50+ стилей, 161 палитра, 57 шрифтов, UX guidelines)

Ключевые вопросы:
1. Какой стиль ближе? (luxury минимализм / яркий / классический / дружелюбный / эко)
2. Какой акцентный цвет? (медный, синий, зелёный, чёрный...)
3. Есть ли фирменный стиль / логотип?
4. Покажите 2-3 сайта "хочу чтобы было похоже на..."

**Подсказка после завершения:** результаты этого этапа формируют бриф для разработчика/Claude.

Когда переходить дальше: выбраны цвета (акцент + фон), шрифты (2-3), стиль.

### Этап 06: Контент-стратегия

**Суть:** Подготовить ВСЕ тексты, фото и данные для сайта ДО начала разработки.
**Шаблон:** `06_Контент_стратегия_бизнес.md` / `06_Контент_стратегия_технический.md`
**Результат:** Карточки услуг, фотографии, тексты для страниц
**Зависимости:** после 03 (нужно знать какие страницы будут)
**Параллельно:** можно делать одновременно с 05 (дизайн)

Ключевые вопросы:
1. Сколько услуг/товаров для запуска? (минимум 5-15)
2. Есть ли свои фотографии? Какого качества?
3. На каких языках нужен контент? (RU, EN, AR)
4. Кто будет писать тексты? (вы сами, копирайтер, Claude)

Когда переходить дальше: заполнены карточки минимум 5 услуг, есть фото, написаны тексты для главной.

### Этап 07: SEO и маркетинг

**Суть:** Настроить сайт чтобы его находили в Google и Яндексе.
**Шаблон:** `07_SEO_и_маркетинг_бизнес.md` / `07_SEO_и_маркетинг_технический.md`
**Результат:** Список ключевых слов, мета-теги, структурированные данные
**Зависимости:** после 03 и 06 (нужны страницы и контент)
**Связанный скилл:** `seo-веб-оптимизация-справочник` (ключевые слова, Core Web Vitals, meta tags)
**Параллельно:** можно начинать исследование ключевых слов параллельно с 06 (контент)

Ключевые вопросы:
1. Что вбивают ваши клиенты в Google? (20-30 фраз)
2. По каким запросам хотите быть первыми?
3. Нужен ли блог для SEO?

Когда переходить дальше: составлен список 20+ ключевых слов, прописаны title и description для основных страниц.

### Этап 08: Деплой и хостинг

**Суть:** Опубликовать сайт в интернете, выбрать домен и хостинг.
**Шаблон:** `08_Деплой_и_хостинг_бизнес.md` / `08_Деплой_и_хостинг_технический.md`
**Результат:** Домен куплен, сайт опубликован, SSL работает
**Зависимости:** после разработки (минимум волна 0 из этапа 04)
**Связанные скиллы:** `vercel-деплой`, `netlify-deployment`

Ключевые вопросы:
1. Есть ли уже домен? Какой хотите?
2. Бюджет на хостинг? (бесплатно / $5-20/мес / не важно)
3. Кто будет обновлять сайт? (вы / разработчик / Claude)

Когда переходить дальше: сайт доступен по домену, HTTPS работает.

### Этап 09: Аналитика и метрики

**Суть:** Подключить отслеживание чтобы понимать что происходит на сайте.
**Шаблон:** `09_Аналитика_и_метрики_бизнес.md` / `09_Аналитика_и_метрики_технический.md`
**Результат:** GA4 подключён, Яндекс.Метрика с Вебвизором, основные цели настроены
**Зависимости:** после 08 (сайт должен быть опубликован)

Ключевые вопросы:
1. Какие действия посетителей важны? (WhatsApp-клик, заявка, звонок)
2. Нужна ли Яндекс.Метрика? (да, если аудитория из СНГ)
3. Как часто будете смотреть статистику?

Когда переходить дальше: GA4 и Метрика подключены, данные поступают.

### Этап 10: Чеклист запуска

**Суть:** Финальная проверка перед тем как показать сайт клиентам. Как пилот перед взлётом.
**Шаблон:** `10_Чеклист_запуска_бизнес.md` / `10_Чеклист_запуска_технический.md`
**Результат:** Все пункты чеклиста пройдены, сайт готов к запуску
**Зависимости:** после всех предыдущих этапов

Категории проверки:
1. Контент (тексты, фото, цены)
2. Функциональность (ссылки, кнопки, формы)
3. Мобильная версия (самое важное!)
4. Техническое (домен, SSL, скорость)
5. SEO (заголовки, alt-тексты, sitemap)
6. Аналитика (GA4, Метрика)
7. Юридическое (политика, cookies)

Когда считать готовым: все обязательные пункты отмечены, 3 человека проверили сайт с телефона.

## Расположение шаблонов

Навигатор ищет шаблоны в следующем порядке:

1. **Папка templates/ в текущем проекте** -- если проект уже содержит шаблоны
2. **D:/Downloads/abaya-sister-website/templates/** -- мастер-копия шаблонов

### Копирование шаблонов в новый проект

Для нового проекта скопировать шаблоны:

    cp -r "D:/Downloads/abaya-sister-website/templates/" "/path/to/new-project/templates/"

Шаблоны универсальны -- подходят для любого бизнес-сайта, не только для туризма.

- При возврате к пройденному этапу -- пометить "В работе (ревизия)"

## Умные подсказки между этапами

### После этапа 01 (конкуренты) -- перед 03 (архитектура)

    На основе анализа конкурентов:
    - У [X из Y] конкурентов есть [блог/FAQ/отзывы] -- рекомендую добавить
    - Все конкуренты используют [WhatsApp/корзину] для связи -- вам тоже стоит
    - Никто не делает [X] -- это ваша возможность отличиться

### После этапа 05 (дизайн) -- бриф для разработчика

    Дизайн-бриф для Claude / разработчика:
    - Стиль: [luxury минимализм]
    - Акцентный цвет: [#B87333]
    - Шрифты: заголовки [Tenor Sans], текст [Montserrat]
    - Фон: [тёплый белый #FDFBF9]
    - Референсы: [сайт1.com, сайт2.com]

### Параллельные этапы

    Эти этапы можно делать одновременно:
    - 05 Дизайн + 06 Контент (дизайн не зависит от текстов)
    - 06 Контент + 07 SEO (ключевые слова помогают писать тексты)

## Протокол работы с этапом

При переходе к любому этапу навигатор выполняет:

1. **Показать обзор** -- 2-3 предложения, зачем нужен этот этап
2. **Загрузить шаблон** -- прочитать соответствующий файл из templates/
3. **Задать ключевые вопросы** -- из шаблона, в порядке приоритета
4. **Зафиксировать решения** -- записать в PROGRESS.md
5. **Предложить следующий шаг** -- показать что делать дальше

### Формат показа этапа

    === ЭТАП 03: Архитектура сайта ===
    Прогресс: [===>------] 3/10

    Суть: Спланировать какие страницы будут на сайте и как по ним будет
    ходить посетитель. Как план здания -- сначала чертёж, потом стройка.

    Давайте ответим на 4 ключевых вопроса:

    1. Какой тип сайта?
       - Лендинг (1 страница)
       - Визитка (3-7 страниц)
       - Каталог-витрина (10-50 страниц)
       - Интернет-магазин (50+ страниц)

    Ваш ответ: ___
