# Обзор 10 этапов разработки сайта

Краткий справочник по всем этапам навигатора. Для подробностей -- загрузить соответствующий шаблон из templates/.

---

## Карта зависимостей

    01 Конкуренты ---+
                     +---> 03 Архитектура ---> 04 Планирование ---> Разработка
    02 Аудитория ---+         |                                        |
                              |                                        |
                         05 Дизайн                                 07 SEO
                         06 Контент                                    |
                                                                       v
                                                     08 Деплой ---> 09 Аналитика
                                                                       |
                                                                  10 Чеклист

**Параллельные пары:**
- 01 + 02 (исследование)
- 05 + 06 (дизайн + контент)
- 06 + 07 (контент + SEO)

## Минимальный путь до запуска

Если нужно максимально быстро:

    03 Архитектура (30 мин) --> 05 Дизайн (30 мин) --> Разработка --> 08 Деплой (1 час) --> 10 Чеклист (30 мин)

Итого: ~3 часа на планирование + время на разработку.

## Полный путь

    01 + 02 (3-4 часа) --> 03 (1-2 часа) --> 04 (1 час) --> 05 + 06 (3-4 часа) --> 07 (1-2 часа) --> Разработка --> 08 (1-3 часа) --> 09 (1 час) --> 10 (1-2 часа)

Итого: ~15-20 часов планирования + время на разработку.
