# Quick-Start Flows -- быстрые маршруты

4 готовых маршрута в зависимости от того, сколько времени есть.

---

## Flow 1: "У меня 1 час"

**Цель:** Быстро понять рынок, набросать план сайта, узнать что нужно для запуска.
**Результат:** Общее понимание + карта страниц + знание чеклиста.

### Минута 0-20: Быстрый скан конкурентов (Этап 01)

Не полный анализ, а экспресс-версия:

1. Открыть Google, вбить то, что вбил бы ваш клиент
2. Открыть первые 5 сайтов из выдачи
3. Для каждого ответить за 2 минуты:
   - Нравится / не нравится (общее ощущение)
   - Что цепляет? (одна вещь)
   - Что раздражает? (одна вещь)
   - Как предлагают связаться? (WhatsApp / форма / корзина)
4. Записать 3 идеи которые хочется "украсть"

### Минута 20-45: Карта страниц (Этап 03)

1. Выбрать тип сайта:
   - Лендинг (1 страница) -- если одна услуга
   - Визитка (3-7 страниц) -- если мало услуг
   - Каталог (10-50 страниц) -- если много услуг
   - Магазин (50+ страниц) -- если онлайн-продажи

2. Записать дерево страниц:

       Главная
       +-- Категория 1
       |   +-- Услуга 1.1
       |   +-- Услуга 1.2
       +-- Категория 2
       +-- О нас
       +-- Контакты
       +-- FAQ

3. Набросать план главной страницы (какие секции сверху вниз):
   - Hero (фото + заголовок + кнопка)
   - Доверие (цифры)
   - Популярные услуги (4-6 карточек)
   - О компании
   - Отзывы
   - Контакты / WhatsApp

### Минута 45-60: Обзор чеклиста (Этап 10)

Пробежать чеклист запуска и отметить:
- Что уже есть (фото, тексты, домен)
- Что нужно подготовить
- Что можно пропустить на старте

**Итог за 1 час:** Вы понимаете рынок, знаете структуру будущего сайта и что нужно подготовить.

## Flow 2: "У меня 1 день"

**Цель:** Полное исследование + архитектура + фирменный стиль.
**Результат:** Готовый план с решениями по дизайну, можно начинать разработку.

### Утро (2-3 часа): Исследование

**Этап 01 -- Конкуренты (1.5 часа):**
1. Найти 8-12 конкурентов (4-6 прямых + 2-3 лидера + 2-3 вдохновение)
2. Оценить каждый по 7 критериям из шаблона
3. Заполнить сравнительную таблицу
4. Выбрать 3 референса
5. Записать список "что хочу взять" и "чего хочу избежать"

**Этап 02 -- Аудитория (1 час):**
1. Описать 2-3 типа клиентов (портрет)
2. Определить путь клиента (воронка)
3. Определить главный канал связи
4. Определить языки сайта

### День (2-3 часа): Архитектура + Дизайн

**Этап 03 -- Архитектура (1 час):**
1. Выбрать тип сайта
2. Нарисовать дерево страниц (все страницы)
3. Спланировать главную (секции)
4. Определить навигацию (меню)

**Этап 05 -- Дизайн (1.5 часа):**
1. Выбрать стиль (luxury / modern / classic / friendly / eco)
2. Выбрать акцентный цвет (отличный от конкурентов)
3. Заполнить палитру (6 цветов: акцент, 2 фона, 3 текста)
4. Выбрать 2-3 шрифта
5. Собрать мудборд (3-5 скриншотов "хочу как тут")

### Вечер (1 час): Чеклист

**Этап 10 -- Чеклист:**
1. Пройти весь чеклист
2. Составить список того, что нужно подготовить
3. Определить приоритеты (что для MVP, что потом)

**Итог за 1 день:** Полное исследование, план сайта, фирменный стиль. Можно передавать разработчику или начинать работу с Claude.

## Flow 3: "У меня 1 неделя"

**Цель:** Пройти все 10 этапов и получить работающий сайт.
**Результат:** Сайт в интернете с контентом и аналитикой.

### День 1: Исследование (Этапы 01-02)

- Утро: Анализ конкурентов (полный, 8-12 сайтов)
- День: Анализ аудитории (2-3 портрета, воронка)
- Вечер: Обсуждение выводов, фиксация решений

### День 2: Планирование (Этапы 03-04)

- Утро: Архитектура сайта (тип, страницы, навигация)
- День: Планирование разработки (волны, приоритеты, сессии)
- Вечер: Согласование MVP (что в первой волне)

### День 3: Дизайн + Контент (Этапы 05-06)

- Утро: Дизайн и UX (стиль, цвета, шрифты, мудборд)
- День: Контент-стратегия (карточки услуг, тексты)
- Вечер: Сбор и подготовка фотографий

### День 4-5: Разработка

- Работа с Claude по плану из этапа 04
- Волна 0: навигация + главная + каталог + контакты
- Волна 1: все страницы + реальный контент

### День 6: SEO + Деплой (Этапы 07-08)

- Утро: SEO (ключевые слова, мета-теги, sitemap)
- День: Деплой (домен, хостинг, SSL)
- Вечер: Аналитика (GA4, Яндекс.Метрика)

### День 7: Запуск (Этапы 09-10)

- Утро: Проверка аналитики (данные поступают?)
- День: Чеклист запуска (все пункты)
- Вечер: Финальные правки, показ 3 людям с телефона
- ЗАПУСК!

**Итог за 1 неделю:** Работающий сайт с реальным контентом, SEO, аналитикой и пройденным чеклистом.

## Flow 4: "Минимальный сайт"

**Цель:** Получить сайт в интернете максимально быстро, без глубокого исследования.
**Результат:** Простой рабочий сайт.
**Когда использовать:** Нужна "визитка" прямо сейчас, исследование можно сделать потом.

### Шаг 1: Архитектура за 20 минут (Этап 03)

1. Тип: визитка или лендинг
2. Страницы: Главная + О нас + Контакты (минимум)
3. Главная: Hero + услуги + контакты

### Шаг 2: Быстрый дизайн за 15 минут (Этап 05)

1. Стиль: выбрать один из пяти
2. Цвет: один акцентный
3. Шрифт: один (например, Inter или Montserrat)

### Шаг 3: Разработка

Работа с Claude: создать сайт по минимальному плану.

### Шаг 4: Деплой за 30 минут (Этап 08)

1. Vercel (бесплатно) или Netlify
2. Подключить домен (если есть)
3. Проверить HTTPS

### Шаг 5: Быстрый чеклист за 15 минут (Этап 10)

Только критические пункты:
- [ ] Контакты правильные
- [ ] WhatsApp-кнопка работает
- [ ] С телефона всё видно
- [ ] HTTPS работает
- [ ] Фото загружаются

**Итог:** Минимальный сайт за 1.5-2 часа + время на разработку. Исследование и SEO -- потом.

      "Вчера"   --> Flow 4 (минимальный сайт)
