# FAQ — Instagram Messenger API (DM-автоматизация)

## 1. Есть ли у Instagram Bot API как у Telegram?

**Нет.** Instagram не имеет отдельного Bot API. Вся DM-автоматизация работает через **Messenger API for Instagram** — часть Meta Platform (Graph API). Это тот же API, что используется для Facebook Messenger, но с ограничениями Instagram.

## 2. Может ли бот написать первым?

**Нет.** Бот может только **отвечать** на действия пользователя:
- Входящее DM-сообщение
- Нажатие на Ice Breaker
- Нажатие на Persistent Menu
- Комментарий к посту (через Private Reply)
- Упоминание в Stories
- Нажатие на Quick Reply / кнопку

Массовые рассылки (broadcast) в Instagram невозможны.

## 3. Какой тип аккаунта нужен?

Только **Business** или **Creator** аккаунт, привязанный к Facebook Page. Personal аккаунты не поддерживаются. Конвертация: Instagram Settings → Account → Switch to Professional Account.

## 4. Что такое 24-часовое окно?

После последнего сообщения пользователя у вас есть **24 часа** на отправку ответов. После этого отправка сообщений запрещена, пока пользователь не напишет снова. Исключение: тег `HUMAN_AGENT` продлевает окно до **7 дней**, но только для живого оператора.

## 5. Сколько стоит использование API?

**API бесплатен.** Meta не берёт плату за использование Messenger API for Instagram. Расходы:
- Хостинг для webhook: $5-10/мес (VPS)
- Опционально: ManyChat/Chatfuel ($15-65/мес) если не хотите кодить
- Опционально: AI для автоответов (Claude/GPT API)

## 6. Что такое Ice Breakers?

Приветственные вопросы (до 4 штук), которые видит пользователь при **первом** открытии DM с вашим аккаунтом. Например: "Какие экскурсии есть?", "Цены на трансферы". Настраиваются через `/me/messenger_profile` с параметром `platform: "instagram"`.

## 7. Что такое Private Reply?

Автоматический ответ в DM пользователю, который оставил комментарий к вашему посту. Например, пользователь пишет "Сколько?" под постом — бот отправляет ему DM с ценами. Ограничения: 1 Private Reply на комментарий, в течение 24 часов.

## 8. Можно ли отправлять карточки с картинками и кнопками?

**Да.** Используйте **Generic Template** — горизонтальный скролл карточек (до 10 штук). Каждая карточка: изображение + заголовок + подзаголовок + кнопки (web_url или postback). Идеально для каталога экскурсий.

## 9. Как получить Page Access Token?

1. Создайте Facebook App на developers.facebook.com
2. В Graph API Explorer выберите приложение и страницу
3. Добавьте permissions: `instagram_basic`, `instagram_manage_messages`
4. Сгенерируйте User Token → обменяйте на Long-Lived Token (60 дней) → получите Page Access Token

## 10. Нужен ли App Review?

**Да**, для production. Permission `instagram_manage_messages` требует прохождения App Review (3-7 рабочих дней). Для тестирования можно использовать токены из Graph API Explorer без review, но только на аккаунтах, добавленных как тестовые.

## 11. Как передать диалог живому оператору?

Используйте **Quick Reply с payload `HUMAN_AGENT`** — при нажатии бот прекращает автоответы и уведомляет менеджера (через Telegram, email или Meta Business Suite Inbox). Тег `HUMAN_AGENT` продлевает окно ответов до 7 дней.

## 12. Поддерживает ли Instagram Persistent Menu?

**Да**, но только **1 уровень** (в отличие от Facebook Messenger, где 3 уровня). Максимум 20 пунктов. Настраивается через `/me/messenger_profile`. Меню отображается по иконке внизу чата.

## 13. Какие вложения можно отправлять?

| Тип | Форматы | Макс. размер |
|-----|---------|-------------|
| Изображения | JPEG, PNG, GIF | 8 MB |
| Видео | MP4 | 25 MB |
| Аудио | AAC, MP4, WAV | 25 MB |
| Файлы | PDF и др. | 25 MB |

Стикеры: можно получать от пользователей, но нельзя отправлять через API.

## 14. Можно ли использовать без программирования?

**Да.** No-code платформы:
- **ManyChat** — самый популярный, от $15/мес
- **Chatfuel** — альтернатива ManyChat
- **Make.com** (Integromat) — для сложных интеграций
- **SaleBot** — русскоязычный конструктор

Все они работают через тот же Messenger API, но предоставляют визуальный интерфейс.

## 15. Чем отличается от бота в WhatsApp/Telegram?

| Аспект | Instagram | WhatsApp | Telegram |
|--------|-----------|----------|----------|
| Первое сообщение | Нельзя | Template Messages | Можно |
| Рассылки | Нет | Template Messages | Broadcast |
| Кнопки | Quick Reply, Template | Quick Reply, List, Button | Inline, Reply Keyboard |
| 24ч окно | Да | Да | Нет |
| Оплата в чате | Нет | Нет | Telegram Payments |
| Стоимость API | Бесплатно | Per-message pricing | Бесплатно |
| Медиа в DM | Да | Да | Да |
| Модерация комментариев | Да | N/A | N/A |
