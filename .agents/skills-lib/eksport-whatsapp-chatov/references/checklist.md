# Чеклист обработки WhatsApp чата

## Подготовка

- [ ] Python 3.8+ установлен
- [ ] FFmpeg установлен и в PATH
- [ ] openai-whisper установлен (`pip install openai-whisper`)
- [ ] PyTorch с CUDA установлен (для GPU)
- [ ] Зависимости установлены (`pip install requests`)

## Получение архива

- [ ] Пользователь прикрепил ZIP файл экспорта WhatsApp
- [ ] Определено имя контакта
- [ ] Определён тип контакта (клиент/агент/поставщик/сотрудник)
- [ ] Определена тематика переписки
- [ ] Получены заметки (опционально)

## Автоматическая обработка (НОВОЕ)

```bash
# Единый пайплайн с автоопределением
python scripts/process_all.py "Чат WhatsApp.zip"
```

- [ ] Запущен `process_all.py`
- [ ] Проверены автоопределённые параметры
- [ ] Получен результат обработки

## Ручная обработка (при необходимости)

### Распаковка
- [ ] Создана папка для распаковки: `D:/Downloads/[имя]_extracted/`
- [ ] Архив распакован: `unzip -o "архив.zip" -d "папка"`
- [ ] Проверено содержимое (чат, аудио, фото, PDF, VCF)

### Расшифровка голосовых
- [ ] Запущен скрипт `transcribe_whisper.py`
- [ ] Модель: medium (или small для слабых GPU)
- [ ] Язык: ru
- [ ] Результат сохранён в `transcripts.txt`
- [ ] Пост-обработка: `python scripts/whisper_postprocess.py transcripts.txt`
- [ ] Проверено качество расшифровки

### Анализ медиа
- [ ] Все JPG изображения проанализированы через Read tool
- [ ] Описания сохранены в `images_analysis.txt`
- [ ] Все PDF документы проанализированы через Read tool
- [ ] Данные сохранены в `pdf_analysis.txt`
- [ ] VCF контакты обработаны через `parse_vcf.py`
- [ ] Контакты сохранены в `vcf_analysis.txt`

### Сборка документа
- [ ] Запущен скрипт `build_document.py`
- [ ] Проверен формат вывода (иконки, разделители)
- [ ] Итоговый MD файл создан

### Каталогизация
- [ ] Файл переименован по формату: `[тип]_[Имя]_[тематика].md`
- [ ] Файл перемещён в `D:/Downloads/Chats/[тип]/`
