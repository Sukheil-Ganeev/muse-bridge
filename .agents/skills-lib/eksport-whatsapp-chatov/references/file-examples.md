## Пример организации медиа `_медиа/`

```
D:/Downloads/Chats/_медиа/
├── чеки/              # PDF чеки переводов
├── счета/             # Счета и инвойсы
├── документы/         # Прочие PDF
├── скриншоты/
│   ├── курсы/         # Скриншоты курсов валют
│   ├── переводы/      # Скриншоты банковских переводов
│   └── ошибки/        # Скриншоты ошибок
├── открытки/          # Поздравительные изображения
├── фото/              # Прочие фото
└── index.md           # Индекс медиафайлов
```

### Команды для работы с базами и медиа

```bash
# Обновить базу реквизитов
python scripts/extract_requisites.py --chats-dir "D:/Downloads/Chats"

# Обновить CSV операций
python scripts/extract_operations.py --chats-dir "D:/Downloads/Chats"

# Обновить паттерны (контакты, связи, события)
python scripts/extract_patterns.py --chats-dir "D:/Downloads/Chats"

# Обновить индекс
python scripts/build_index.py --chats-dir "D:/Downloads/Chats"

# Организовать медиа
python scripts/organize_media.py --chats-dir "D:/Downloads/Chats" --extracted-dir "D:/Downloads"

# Добавить статистику
python scripts/chat_statistics.py "path/to/chat.md"
python scripts/chat_statistics.py --all --chats-dir "D:/Downloads/Chats"
```
