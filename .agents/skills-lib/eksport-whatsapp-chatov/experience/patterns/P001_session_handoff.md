# P001: Передача сессии через CONTINUE_SESSION.md

**Дата:** 2026-02-05
**Источник:** Чаты 121212.txt, 12321212.txt

---

## Проблема

При достижении лимита контекста сессия прерывается:
- Потеря текущего состояния
- Непонятно что уже сделано
- Дублирование работы

## Решение

Создавать файл `CONTINUE_SESSION.md` с полным контекстом:

```markdown
# CONTINUE_SESSION.md

## Текущий статус
- Проект: Туризм-ОАЭ-Проект
- Задача: Исправление грамматики транскрипций
- Прогресс: 24,694 / 32,846 (75%)

## Что сделано
- batch_001 - batch_178 готовы
- Проблемные: batch_141 (неполный), batch_149 (отсутствует)

## Что осталось
1. Перезапустить проблемные батчи
2. Обработать batch_179-200
3. Создать итоговый объединённый файл

## Пути к файлам
- Входные: D:/Downloads/Туризм-ОАЭ-Проект/02-Обработанные-данные/_парсинг/метаданные/
- Выходные: D:/Downloads/Туризм-ОАЭ-Проект/02-Обработанные-данные/_парсинг/исправленные/

## Команда для проверки статуса
\`\`\`bash
ls -la исправленные/batch_*.jsonl | wc -l
\`\`\`

## Промт для нового чата
> Продолжить обработку транскрипций. Прочитать CONTINUE_SESSION.md
```

## Когда создавать

- При достижении ~70% контекста
- Перед запуском долгих операций
- При планировании перерыва в работе
