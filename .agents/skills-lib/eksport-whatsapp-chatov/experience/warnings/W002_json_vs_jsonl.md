# W002: Не использовать JSON для инкрементального сохранения

**Severity:** HIGH
**Дата:** 2026-02-05
**Источник:** Чат 12321212.txt

---

## Проблема

JSON формат требует полной перезаписи файла при каждом добавлении:

```python
# ПЛОХО: потеря данных при падении
data = load_json("results.json")  # Читаем всё
data.append(new_result)            # Добавляем
save_json("results.json", data)    # Записываем всё заново
# Если упадёт между load и save — потеря ВСЕХ данных!
```

## Симптомы

- Файл пустой после падения скрипта
- Частичная потеря данных
- Большое потребление памяти для больших файлов

## Решение

**Использовать JSONL (JSON Lines):**

```python
# ХОРОШО: атомарная запись
with open("results.jsonl", "a", encoding="utf-8") as f:
    f.write(json.dumps(result, ensure_ascii=False) + "\n")
# Каждая запись сразу на диске, падение не влияет на предыдущие
```

## Сравнение

| Формат | При падении | Память | Скорость чтения |
|--------|-------------|--------|-----------------|
| JSON | Потеря всего | O(n) | Быстро (один раз) |
| JSONL | Потеря 1 записи | O(1) | Медленнее (построчно) |

## Правило

> Для любой операции с >100 записями — только JSONL
