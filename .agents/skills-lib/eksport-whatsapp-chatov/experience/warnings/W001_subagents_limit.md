# W001: Ограничение платформы — 50+ субагентов нестабильно

**Severity:** CRITICAL
**Дата:** 2026-02-05
**Источник:** Чаты 12211221.txt, 121212.txt

---

## Проблема (БАГ ПЛАТФОРМЫ, не ошибка пользователя!)

Запуск 50-67 субагентов одновременно приводит к:
- Достижению API лимитов ("You're out of extra usage") — **недокументированное ограничение Claude Max**
- Массовым падениям с ошибкой "classifyHandoffIfNeeded is not defined" — **БАГ Claude Code**
- Неполным/пустым батчам — **следствие багов**
- Потере контекста сессии

> **ВАЖНО:** Это ограничения/баги платформы Anthropic, а не ошибка пользователя!

## Симптомы

- Сообщение: "You're out of extra usage · resets 4pm"
- Субагенты падают группами
- Батчи пустые или неполные (например batch_141: 22/200)

## Решение

**Оптимальное количество:** 10-15 субагентов одновременно

| Количество | Риск | Результат |
|------------|------|-----------|
| 5-10 | Низкий | Стабильно |
| 10-15 | Средний | Оптимально |
| 15-30 | Высокий | Возможны падения |
| 50+ | КРИТИЧЕСКИЙ | Массовые падения |

## Альтернатива

Для массовой обработки использовать Python-скрипт с Claude API вместо субагентов:
- Контролируемый rate limiting
- Checkpoint/resume
- Гарантированное сохранение данных
