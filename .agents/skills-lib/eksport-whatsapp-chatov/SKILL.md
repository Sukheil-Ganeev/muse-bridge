# Экспорт WhatsApp чатов

Скилл для автоматической обработки WhatsApp чатов. Поддерживает два режима:
1. **ZIP-экспорт** — один чат из функции "Экспорт чата" в WhatsApp
2. **iTunes бэкап** — массовый экспорт ВСЕХ чатов из резервной копии iPhone (протестировано: 3,050 чатов, 887k сообщений, 412k медиа)

---

## ГЛАВНЫЙ ПРИНЦИП: Никакие данные НЕ теряются!

> **Это КРИТИЧЕСКИ ВАЖНО для всей работы скилла.**

### Что это значит:

| НЕЛЬЗЯ | НУЖНО |
|---------|--------|
| Сокращать данные | Сохранять ВСЁ полностью |
| Удалять "лишние" поля | Структурировать, но сохранять все поля |
| Извлекать только часть | Извлекать блок целиком + парсить |
| Укорачивать тексты | Хранить исходный текст в `<details>` |
| Угадывать недостающее | Оставлять пустым если нет данных |

### Примеры правильного сохранения:

**Реквизиты** — сохранять ВСЕ поля:
```
BANK : *ADIB BANK*
ACCOUNT NUMBER : *28642584*
IBAN NUMBER : *AE720500000000028642584*
SWIFT: *ABDIAEADXXX*
NAME : *MARSEL GANEEV*
```
Сохраняется: Bank, Account Number, IBAN, SWIFT, Name + исходный блок целиком

**Операции из PDF** — сохранять ВСЕ поля чека:
- Дата, время, сумма, комиссия
- Отправитель (имя, счёт, банк)
- Получатель (имя, счёт, телефон, банк)
- Номер транзакции, ID СБП, код авторизации
- Статус, тип операции
- **+ исходный текст PDF блока целиком**

**Контакты из VCF** — сохранять ВСЕ данные:
- Все телефоны (может быть несколько)
- Все email
- Организация, адрес, заметки
- **+ исходный VCF блок**

**События и даты** — сохранять с контекстом:
- Дата/время + 2-3 строки вокруг
- Тип события
- **+ исходная строка**

### Структура хранения:

```
Структурированные поля     →  Для быстрого поиска и фильтрации
          +
Исходный текст (<details>) →  Полные данные без потерь
```

## ДВА РЕЖИМА РАБОТЫ

| Режим | Источник | Результат | Когда использовать |
|-------|----------|-----------|-------------------|
| **ZIP-экспорт** | Функция "Экспорт чата" в WhatsApp | 1 чат | Нужен конкретный чат |
| **iTunes бэкап** | Резервная копия iPhone | ВСЕ чаты сразу | Массовый экспорт |

### Сравнение режимов

| Параметр | ZIP-экспорт | iTunes бэкап |
|----------|-------------|--------------|
| Источник | Функция в WhatsApp | iTunes/Finder бэкап |
| Формат данных | ZIP с _chat.txt | SQLite + хэши файлов |
| Один чат за раз | Да | Нет |
| Все чаты сразу | Нет | Да (3000+ чатов) |
| Обработка | Whisper + сборка MD | SQL запросы + копирование |
| Сложность | Простая | Требует понимания структуры |

## ЭКСПОРТ ИЗ ITUNES БЭКАПА

### Реальный опыт (26.01.2026)

| Метрика | WhatsApp | WA Business | ИТОГО |
|---------|----------|-------------|-------|
| **Чатов** | 1,063 | 1,987 | **3,050** |
| **Сообщений** | 485,639 | 401,583 | **887,222** |
| **Медиа** | 233,129 | 179,632 | **412,761** |
| **Не найдено** | 20 | 15 | **35** (0.008%) |

### Ключевые моменты

- Бэкап: `C:\Users\[USER]\AppData\Roaming\Apple Computer\MobileSync\Backup\[DEVICE_ID]\`
- База: `ChatStorage.sqlite` (чаты, сообщения, медиа) + `ContactsV2.sqlite` (имена)
- Три источника имён: адресная книга > имя чата > профиль WhatsApp > номер
- Медиа: `ZMEDIALOCALPATH` -> добавить `Message/` -> найти `fileID` в `Manifest.db` -> скопировать
- Групповые чаты: `ZGROUPMEMBER` -> `ZWAGROUPMEMBER.ZMEMBERJID` для имён участников

-> Скрипт экспорта: `references/export-script.md`

## Quick Start (ZIP-экспорт)

### Минимальный флоу

1. Пользователь прикрепляет ZIP-архив экспорта WhatsApp
2. Спросить имя контакта и тип (клиент/агент/поставщик/сотрудник)
3. Распаковать архив в `D:/Downloads/[имя]_extracted/`
4. Обработать голосовые через Whisper
5. Проанализировать медиафайлы
6. Собрать итоговый MD в `D:/Downloads/Chats/[тип]/`

### Быстрый пример

```bash
# 1. Распаковка
unzip -o "Чат WhatsApp.zip" -d "D:/Downloads/Иван_extracted/"

# 2. Whisper транскрипция (все .opus файлы)
python scripts/transcribe_whisper.py "D:/Downloads/Иван_extracted/"

# 3. Сборка документа
# Результат: D:/Downloads/Chats/клиенты/клиент_Иван_туры.md
```

## Пайплайн обработки

### Шаг 1: Распаковка архива

```bash
unzip -o "Чат WhatsApp с Иван.zip" -d "D:/Downloads/Иван_extracted/"
```

Структура распакованного архива:
```
Иван_extracted/
├── _chat.txt              # Текст переписки
├── 00000001-AUDIO.opus    # Голосовые сообщения
├── 00000002-PHOTO.jpg     # Изображения
├── 00000003-DOC.pdf       # PDF документы
└── contact.vcf            # Контакт (опционально)
```

### Шаг 2: Расшифровка голосовых (Whisper)

```python
import whisper
import sys
sys.stdout.reconfigure(encoding='utf-8')

model = whisper.load_model("medium", device="cuda")
result = model.transcribe("audio.opus", language="ru", fp16=True)
print(result["text"])
```

**Параметры:** модель `medium`, RTX 3060 (~5GB VRAM), `cuda`, язык `ru`, `fp16=True`

### Шаг 3: Анализ изображений

Использовать Read tool для анализа каждого изображения:
- Описать содержимое
- Извлечь текст (если есть)
- Определить тип (скриншот, фото, документ)

### Шаг 4: Анализ PDF

Использовать Read tool для PDF:
- Извлечь текстовое содержимое
- Определить тип документа (инвойс, договор, билет)
- Выделить ключевые данные

### Шаг 5: Парсинг VCF контактов

```python
def parse_vcf(vcf_path):
    contacts = []
    with open(vcf_path, 'r', encoding='utf-8') as f:
        content = f.read()
    for card in content.split('BEGIN:VCARD'):
        if 'FN:' in card:
            name = card.split('FN:')[1].split('\n')[0].strip()
            phone = ""
            if 'TEL' in card:
                phone = card.split('TEL')[1].split(':')[-1].split('\n')[0].strip()
            contacts.append({'name': name, 'phone': phone})
    return contacts
```

### Шаг 6: Сборка MD документа

Объединить все компоненты в структурированный Markdown:

- Реквизиты (если есть банковские данные)

## Первичные vs Вторичные файлы

### Первичные файлы (полные расшифровки)

**Что это:** Полные, неискажённые документы каждого чата.

**Содержат:** полную историю переписки, расшифровки ВСЕХ голосовых, описания ВСЕХ изображений и PDF, контактную информацию, сводку операций, банковские реквизиты, статистику.

**Правила:**
- НЕ редактируются после создания (источник истины)
- НЕ удаляются данные
- Можно добавлять статистику
- Это первоисточник для всех вторичных файлов

### Вторичные файлы (агрегированные данные)

**Что это:** Данные, извлечённые и объединённые из ВСЕХ первичных файлов.

**Зачем:** Быстрый поиск реквизитов, анализ операций в Excel, навигация, поиск связей.

**Правила:**
- Пересоздаются автоматически скриптами
- Можно удалить и сгенерировать заново
- Зависят от первичных файлов (источник данных)

-> Подробнее (полные примеры первичных и вторичных файлов): `references/file-examples.md`

### Сценарий 1: Простой чат без медиа

1. Распаковать архив
2. Прочитать `_chat.txt`
3. Определить период переписки
4. Собрать MD с метаданными и историей
5. Сохранить в нужную папку

### Сценарий 2: Чат с голосовыми

1. Распаковать архив
2. Найти все `.opus` файлы
3. Запустить Whisper для каждого
4. Вставить расшифровки в соответствующие места чата
5. Собрать итоговый документ

### Сценарий 3: Чат с финансовыми операциями

1. Обработать стандартно
2. Извлечь все упоминания сумм и валют
3. Сформировать таблицу операций
4. Добавить раздел "Сводка операций"
5. Извлечь реквизиты если есть

### Сценарий 4: Групповой чат

1. Определить всех участников
2. Добавить список участников в метаданные
3. Форматировать с указанием автора каждого сообщения
4. Тип: обычно `сотрудники` или специальная категория

### Сценарий 5: Массовый экспорт из iTunes бэкапа

**Триггеры:** "экспорт из бэкапа", "все чаты WhatsApp", "резервная копия iPhone"

1. Найти бэкап: `C:\Users\[USER]\AppData\Roaming\Apple Computer\MobileSync\Backup\`
2. Открыть `Manifest.db` и найти `ChatStorage.sqlite` по domain
3. Загрузить три источника имён (адресная книга, имена чатов, профили)
4. Построить индекс медиафайлов из `Manifest.db`
5. Для каждого чата:
   - Создать папку `[Имя]_[JID]/`
   - Экспортировать сообщения в `chat.txt`
   - Скопировать медиа в `media/`
   - Для групп: использовать `ZGROUPMEMBER` -> `ZMEMBERJID` для имён
6. Создать `CLAUDE.md`, `changelog.md`, `_СТАТИСТИКА.txt`
7. Повторить для WhatsApp Business (другой domain)

**Ожидаемый результат:** 3000+ чатов, 400k+ медиафайлов, потери <0.01%

## AI-агент: Архитектура данных

### Что делает AI-агент

1. **Автоответы** — отвечает на типовые вопросы (цены, наличие, условия)
2. **Классификация** — определяет тип контакта и намерение
3. **CRM-обновление** — создаёт/обновляет записи в Airtable
4. **Рефералы** — отслеживает кто кого привёл
5. **Метрики** — считает конверсию, время ответа, выручку
6. **Профилирование** — строит профили клиентов из истории переписок

### 7 сущностей данных

| Сущность | Описание | Источник |
|----------|----------|----------|
| **Контакты** | Все контакты из чатов | chat.txt заголовки |
| **Профили** | Детальная информация о клиентах | Анализ переписок |
| **Взаимодействия** | Сессии общения | Группировка по времени |
| **Операции** | Заказы, бронирования | Извлечение из текста |
| **Рефералы** | Кто кого привёл | VCF + упоминания |
| **Реквизиты** | Банковские данные | Паттерны IBAN/карт |
| **Метрики** | Агрегированная статистика | Расчёт по периодам |

## Технические требования

### Whisper конфигурация

```python
import whisper
import torch
import sys

# Кодировка для Windows
sys.stdout.reconfigure(encoding='utf-8')

# Проверка GPU
print(f"CUDA available: {torch.cuda.is_available()}")
print(f"GPU: {torch.cuda.get_device_name(0)}")

# Загрузка модели
model = whisper.load_model("medium", device="cuda")

# Транскрипция
def transcribe_audio(audio_path):
    result = model.transcribe(
        audio_path,
        language="ru",
        fp16=True,
        verbose=False
    )
    return result["text"]
```

**Требования к GPU:**
- RTX 3060 или выше
- Минимум 6GB VRAM для модели `medium`
- CUDA 11.x или выше
