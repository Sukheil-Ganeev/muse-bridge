# Паттерн: 3 волны субагентов для README

## Дата: 2026-02-21

## Паттерн
Создание README мирового уровня требует 3 волн:

### Волна 1 (параллельно, ~3-5 мин):
- **Субагент A** (sonnet): WebSearch лучших README практик
- **Субагент B** (Explore): сбор метрик проекта (файлы, строки, тесты, фичи)

### Волна 2 (после волны 1, ~5 мин):
- **Субагент C** (general-purpose): создание README по шаблону 17 секций

### Волна 3 (опционально, ~3 мин):
- **Субагент D** (general-purpose): создание v2 с 8 улучшениями

### Общее время: ~15 минут

## Почему не 1 агент?
- Исследование практик (WebSearch) и сбор метрик (Explore) — независимые задачи
- Параллельный запуск экономит 3-5 минут
- Создание README требует данных от обоих — поэтому волна 2 ждёт волну 1
- v2 требует v1 как базу — поэтому волна 3 после волны 2

## Ключевые параметры субагентов:
- Волна 1A: model=sonnet (экономия), run_in_background=true
- Волна 1B: subagent_type=Explore, run_in_background=true
- Волна 2: mode=bypassPermissions (создаёт файл)
- Волна 3: mode=bypassPermissions (создаёт файл)
