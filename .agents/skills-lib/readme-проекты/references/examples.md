# Примеры README из реальных проектов

## 1. FastAPI (76k+ stars)
**Что делает хорошо:**
- Bold bullet-points для features
- Код прямо в README (не "see docs")
- Benchmark-таблица с конкурентами
- Sponsors секция

## 2. aiogram (5k+ stars)
**Что делает хорошо:**
- Collapsible секции для примеров кода
- Badges по центру
- Минималистичный подход

## 3. lobehub/lobe-chat (50k+ stars)
**Что делает хорошо:**
- Enterprise-level визуализация
- Встроенные видео
- Feature-блоки со скриншотами
- Мультиязычность (EN/ZH/JA)

## 4. Best-README-Template (14k+ stars)
**Что делает хорошо:**
- Back to top навигация
- Table of Contents
- Roadmap с чекбоксами
- Contributing guidelines

## 5. VoiceTranscriptionBot (наш проект!)
**Что мы сделали:**
- 530 строк, 17 секций
- 8 badges с логотипами
- Mermaid архитектура
- 3 collapsible блока команд (87+)
- Key Metrics таблица
- Features в 5 категориях
- Quick Start в 4 шага
- 5 таблиц конфигурации
- Roadmap 13 пунктов
- Back to top после каждой секции

## Антипаттерны (что НЕ делать)
1. Пустые секции
2. Только текст, 0 визуала
3. "See docs" без кода
4. 15+ badges
5. Жаргон без пояснений
6. Устаревшие данные
7. Стена текста
