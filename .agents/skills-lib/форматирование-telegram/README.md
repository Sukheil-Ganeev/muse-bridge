# Скилл: Форматирование Telegram

## Назначение
Универсальное форматирование любого текста для отправки в Telegram.

## Когда использовать
- Любой запрос с "для телеграм", "для тг", "telegram формат"
- Подготовка постов в каналы и группы Telegram
- Форматирование документов, отчётов, анализов для мессенджера

## Структура
- `SKILL.md` — основное руководство + шаблоны
- `references/cheatsheet.md` — быстрая шпаргалка
- `references/faq.md` — частые вопросы
- `references/troubleshooting.md` — решение проблем

## Отличия от WhatsApp
| Элемент | WhatsApp | Telegram |
|---------|----------|----------|
| Жирный | *текст* | **текст** |
| Курсив | _текст_ | __текст__ |
| Разделитель | 15 тире | 18 тире |
| Ссылки | нет | [текст](url) |
| Макс. длина | 65536 | 4096 |
