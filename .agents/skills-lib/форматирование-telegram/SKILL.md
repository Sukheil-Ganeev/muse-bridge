## СИНТАКСИС Telegram

### Базовое форматирование
| Элемент | Синтаксис | Пример |
|---------|-----------|--------|
| Жирный | **текст** | **Заголовок** |
| Курсив | __текст__ | __примечание__ |
| Зачёркнутый | ~~текст~~ | ~~устарело~~ |
| Подчёркнутый | нет в markdown | — |
| Моноширинный (инлайн) | `текст` | `код` |
| Моноширинный (блок) | ```текст``` | ```блок кода``` |
| Спойлер | ||текст|| | ||спойлер|| |

### ВАЖНО: Отличия от WhatsApp!
| Элемент | WhatsApp | Telegram |
|---------|----------|----------|
| Жирный | *текст* | **текст** |
| Курсив | _текст_ | __текст__ |
| Зачёркнутый | ~текст~ | ~~текст~~ |
| Разделитель | 15 тире | 15 тире |

### Разделители
- Стандартный: `───────────────` (15 символов тире ─)
- Использовать только один тип разделителя: `───────────────` (15 символов ─)
- НИКОГДА не использовать обычные дефисы `---`

### Списки
- Основной маркер: `▫️` (для пунктов)
- Альтернативы: `•`, `—` (длинное тире)
- Нумерованные: `1️⃣ 2️⃣ 3️⃣` или `1. 2. 3.`
- Чекбоксы: `✅` (сделано) / `❌` (нет) / `⬜` (ожидание)

### Цитаты
> __Текст цитаты курсивом__
Telegram нативно поддерживает блоки цитат.

### Эмодзи-маркеры для заголовков
- Позиция: ПЕРЕД текстом, НЕ после
- Использовать уместные, не декоративные
- Примеры: 📌 📋 ⚠️ 💡 📅 👤 📧 📱 ⚡️ 🔑

### Ссылки
- Telegram поддерживает markdown-ссылки: [текст](url)
- Это преимущество перед WhatsApp!

## ОСОБЕННОСТИ TELEGRAM

### Преимущества перед WhatsApp:
1. **Ссылки** — поддерживает markdown [текст](url)
2. **Длина** — до 4096 символов в одном сообщении
3. **Предпросмотр** — автоматический для ссылок
4. **Редактирование** — можно править после отправки
5. **Спойлеры** — ||скрытый текст||
6. **Форматирование кода** — с подсветкой языка ```python```

### Ограничения:
- Максимум 4096 символов на сообщение (не 65536 как в WhatsApp)
- Если длиннее — разбить на серию с оглавлением
- В каналах нет цитирования через >

## ПРАВИЛА

### Обязательные:
1. Разделители `───────────────` (15 тире) между секциями
2. Использовать только `───────────────` во всех секциях и блоках
3. Заголовки всегда **жирные**
4. Эмодзи ПЕРЕД заголовком, не после
5. Длинное тире `—` для списков (не дефис `-`)
6. Цитаты: > __курсивом__
7. Ссылки: [текст](url) — использовать где возможно

### Запрещено:
- Обычные дефисы `---` как разделители
- Эмодзи после заголовка (**Текст** 📌 — НЕПРАВИЛЬНО)
- Больше 3-4 эмодзи на пост
- Стены текста без разделителей
- WhatsApp-синтаксис (*жирный* вместо **жирный**)

### Длина сообщений:
- Telegram: максимум 4096 символов
- Оптимально: 1 пост = 1 тема, до 3000 символов
- Если длинно — серия постов + пост-оглавление

## СОХРАНЕНИЕ ФАЙЛОВ

При сохранении Telegram-постов в файлы:
- Формат: `.txt`
- Кодировка: UTF-8
- Имена файлов: `POST_N_Название.txt`
- Папка: `Telegram_Posts/` или по контексту
