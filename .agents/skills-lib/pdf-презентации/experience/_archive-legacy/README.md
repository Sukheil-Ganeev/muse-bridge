# _archive-legacy

Этот архив содержит legacy-файлы без префикса `EXP-`, которые дублировали canonical-файлы формата `EXP-*` в `experience`.

Назначение:
- сохранить историю без безвозвратного удаления;
- держать рабочие каталоги (`fixes`, `improvements`, `patterns`, `warnings`) в canonical-формате.

Структура подпапок в архиве повторяет исходную.
