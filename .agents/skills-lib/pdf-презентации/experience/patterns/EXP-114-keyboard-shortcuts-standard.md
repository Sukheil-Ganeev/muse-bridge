# EXP-114: Стандарт keyboard shortcuts для презентаций

## Рекомендуемый набор
- `Left/Up` — предыдущий слайд
- `Right/Down` и `Space` — следующий слайд
- `Home/End` — первый/последний
- `T` — toggle TOC
- `F` — fullscreen
- `Esc` — закрыть TOC

## Важно
При открытом TOC блокировать фон: `body { overflow: hidden; }`.
