## Контекст

На canvas 1920x1080 стандартные веб-размеры шрифтов (14-16px текст, 38px заголовки) выглядят мелко и разреженно. Это САМАЯ частая проблема при создании первой версии презентации (EXP-025). Данный паттерн фиксирует проверенные размеры и пары шрифтов.

## Описание

### Таблица размеров для 1920x1080

| Элемент | Веб (1200-1440px) | 1920x1080 (презентация) | Примечание |
|---------|-------------------|-------------------------|------------|
| Hero h1 (титульный) | 48-56px | 64-76px | Самый крупный на всей презентации |
| Section h2 | 28-32px | 38-48px | Заголовок слайда |
| Card h3 | 20-24px | 22-28px | Заголовок карточки |
| Body text / feature-list | 14-16px | 17-19px | Основной текст |
| Table th/td | 14-15px | 15-19px | Таблицы в карточках |
| Code-block | 13-14px | 13-15px | Моноширинный, можно чуть мельче |
| Code-block (плотный) | 12px | 12-12.5px | Шпаргалки, длинные блоки |
| Section label | 11-12px | 13px | uppercase, letter-spacing: 3px |
| Slide number | 12px | 15px | bottom-right |
| Highlight-box text | 14-15px | 15-17px | Акцентная плашка внизу |
| Caption / muted | 12px | 13-14px | Подписи, сноски |
| Числа-акценты | 28-36px | 42-48px | Метрики, KPI, проценты |
| Tag / badge | 11-12px | 12-14px | Теги внутри карточек |

### Правило масштабирования

Систематическое увеличение на +15% от типичных веб-размеров:

```
Веб-размер * 1.15 = Размер для 1920x1080
14px * 1.15 = ~17px
38px * 1.15 = ~44px
64px * 1.15 = ~76px
```

### Метрики композиции (эталон из 23 справочников)

```
Slide padding:        70px top/bottom, 100px left/right
Card padding:         32px (стандарт), 28px (плотный), 22px (очень плотный)
Card gap:             32px (стандарт), 16-20px (плотный)
Card border-radius:   16px
Top gradient:         4px height
Highlight-box padding: 20px 28px
```

### Пары шрифтов

| Пара | Заголовки | Тело | Применение |
|------|-----------|------|------------|
| Системная (по умолчанию) | 'Segoe UI', Arial, sans-serif | То же | Zero-dependency, 90% справочников |
| Sora + Plus Jakarta Sans | Sora (700) | Plus Jakarta Sans (400, 600) | Премиум-презентации (Vault Command Center) |
| Inter | Inter (700) | Inter (400) | Минималистичные, современные |
| Nunito + Merriweather | Merriweather (700, 900) | Nunito (400, 700) | С serif-заголовками |

### Когда serif vs sans-serif

- **Sans-serif** (по умолчанию) -- технические справочники, IT, код, modern UI
- **Serif** -- академические, литературные, "классические" темы
- **Monospace** -- ТОЛЬКО для code-block и terminal mockup, никогда для body text

### Line-height

```css
/* Стандарт */
h1, h2 { line-height: 1.2; }
h3 { line-height: 1.3; }
body, p, li { line-height: 1.6; }

/* Компактный (плотные слайды) */
body, p, li { line-height: 1.45; }

/* Code-block */
.code-block { line-height: 1.5; }  /* 1.4 для шпаргалок */
```

### font-weight

```css
h1, h2 { font-weight: 700; }       /* Bold для заголовков */
h3 { font-weight: 600; }            /* Semi-bold для подзаголовков */
body { font-weight: 400; }          /* Regular для текста */
.highlight, strong { font-weight: 600; }  /* Semi-bold для акцентов */
.section-label { font-weight: 600; text-transform: uppercase; letter-spacing: 3px; }
```

### Контент обрезается -- что уменьшать

Приоритет уменьшения (от первого к последнему):
1. `font-size` кода: 13px -> 12.5px
2. `padding` карточек: 32px -> 28px -> 22px
3. `line-height`: 1.6 -> 1.45
4. `gap` между карточками: 32px -> 20px -> 16px
5. Объединять строки в таблицах/списках
6. **НЕ удалять контент** -- только уменьшать визуальные параметры (EXP из MEMORY.md)

## Когда применять

- **ВСЕГДА** при создании презентации 1920x1080 -- начинать с увеличенных размеров
- При жалобе "мелко" / "плохо читается" -- систематически увеличить все размеры на 15%
- При жалобе "обрезается" / "не помещается" -- уменьшать по приоритету (см. выше)
- CSS классы -- одна правка меняет всё. Inline стили -- `replace_all` по паттернам
