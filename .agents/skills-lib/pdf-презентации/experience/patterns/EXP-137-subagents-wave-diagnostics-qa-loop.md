# EXP-137: Wave-процесс с субагентами для сложных презентаций

## Контекст

Для большой презентации с множеством UX-косяков и плотной инфографикой одиночный проход даёт много повторных правок.
Стабильный результат получился только после волнового процесса с субагентами.

## Рабочая схема (волны по 6)

1. Волна 1: диагностика layout/viewport/geometry.
2. Волна 2: проверка инфографики (подписи, читабельность, контекстность).
3. Волна 3: motion/hover/palette/контраст.
4. Волна 4: интеграция фиксов и регресс-проверка.

После каждой волны:

- собрать findings в короткий список;
- закрыть субагентов;
- запустить следующую волну с уточнённым брифом.

## Gate-критерии для перехода между волнами

- Нет clipping/overlap на контрольных разрешениях.
- Инфографика подписана и соответствует контенту слайда.
- Счётчик, прогресс и safe-зоны синхронизированы.
- Нет пустых/дублированных слайдов в slideshow-режиме.

## Практический шаблон брифа

```text
Зона ответственности: только [X].
Не трогать чужие правки вне зоны.
Вернуть: 1) список дефектов, 2) точечные правки, 3) риск регрессий.
```

## Правило

Для deck 20+ слайдов использовать wave-подход по умолчанию: меньше хаоса, быстрее convergence, выше стабильность финального PDF/HTML.
