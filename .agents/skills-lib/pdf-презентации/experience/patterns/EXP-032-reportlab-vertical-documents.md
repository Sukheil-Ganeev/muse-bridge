# Reportlab: Вертикальные PDF-документы (A4)

**Дата:** 2026-02-05
**Контекст:** Создание минималистичного руководства "Как стать сафаристом в Дубае" — 6 страниц, reportlab

## Проблемы и решения

### 1. Таблицы разрываются на границе страниц (КРИТИЧНО!)

**Проблема:** Reportlab автоматически разрывает таблицы между страницами — шапка и первые строки на одной странице, остальные на следующей.

**Решение:** Комбинация подходов:
- **Уменьшить cell padding** с 6 до 4 — экономит ~2mm на каждой строке
- **Уменьшить spacing** между секциями (sp(10) → sp(8), sp(6) → sp(4))
- **PageBreak перед тяжёлым блоком** — если таблица гарантированно не влезет, лучше начать с новой страницы
- **НЕ полагаться на KeepTogether** для таблиц — он может создать пустое пространство

```python
# Компактная таблица — padding 4 вместо 6
cmds = [
    ('TOPPADDING', (0, 0), (-1, -1), 4),
    ('BOTTOMPADDING', (0, 0), (-1, -1), 4),
]
```

**Диагностика:** Если таблица разрывается — считаем: (количество строк × высота строки) + заголовки секций + spacing. Сравниваем с оставшимся местом на странице (~257mm для A4 с margins 22/18mm).

### 2. Custom Flowable внутри вложенных таблиц — overflow

**Проблема:** `LeftBorderBlock` с `self.width = W` вылезает за рамки, когда вложен в step-блок (который уже сужен на ~22mm из-за номера + линии).

**Решение:** Добавить параметр `max_width`:
```python
class LeftBorderBlock(Flowable):
    def __init__(self, text, color=SAND, bg=None, max_width=None):
        self.width = max_width or W  # <-- ключевой момент
        inner_w = self.width - 14*mm
        ...

# Использование внутри step:
LeftBorderBlock("текст", bg=SAND_LIGHT, max_width=W - 26*mm)
```

### 3. Минималистичные таблицы — одна линия

**Проблема:** Таблицы с полными рамками (GRID) и цветными шапками выглядят тяжело.

**Решение:** Только одна линия под заголовком:
```python
cmds = [
    ('LINEBELOW', (0, 0), (-1, 0), 0.75, SAND),  # единственная линия
    ('LEFTPADDING', (0, 0), (-1, -1), 0),  # без левого отступа
]
```
Без чередования строк (alternating rows), без GRID, без цветных шапок.

### 4. Нумерованные шаги — big number | line | content

**Паттерн:** Крупный номер (28pt, песочный) слева, тонкая вертикальная линия, контент справа.
```python
main = Table([[num_p, inner_t]], colWidths=[20*mm, W - 22*mm])
main.setStyle(TableStyle([
    ('LINEAFTER', (0, 0), (0, 0), 0.75, GREY_LINE),  # вертикальная линия
    ('LEFTPADDING', (1, 0), (1, 0), 5*mm),  # отступ контента от линии
]))
```

### 5. Итеративная подгонка spacing — методология

**Порядок действий:**
1. Собрать весь контент с большими отступами (sp(10-12))
2. Сгенерировать PDF, посмотреть разрывы страниц
3. Определить "тяжёлые" страницы и уменьшить spacing
4. Повторять пока все таблицы не перестанут разрываться
5. **Финальный шаг:** проверить последнюю страницу — часто footer/accent line выезжают на пустую страницу

**Типичные значения spacing для плотного документа:**
- Между секциями: sp(6-8)
- Перед таблицей: sp(3-4)
- Между элементами step: sp(1-3)
- Между советами/tips: sp(3)
- Перед footer: sp(3-6)

## Дизайн-система "Desert Minimal"

**Палитра:** всего 2 акцентных цвета
```python
SAND = HexColor("#C4956A")      # акцент
CHARCOAL = HexColor("#2D2D2D")  # текст
GREY_TEXT = HexColor("#888888")  # вторичный текст
GREY_LINE = HexColor("#E2E2E2") # линии
```

**Элементы:**
- `AccentLine` — короткая центрированная песочная линия (на титуле и перед footer)
- `LeftBorderBlock` — левая акцентная граница + опциональный фон
- `clean_table` — минималистичная таблица с одной линией
- `step()` — нумерованный шаг с вертикальной линией

**Шрифты:** Arial (системный, Windows) — `arial.ttf`, `arialbd.ttf`, `ariali.ttf`
