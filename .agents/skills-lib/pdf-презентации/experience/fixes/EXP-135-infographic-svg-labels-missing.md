# EXP-135: Пустые подписи в SVG-инфографике

## Проблема

На части слайдов инфографика рендерилась без текстовых подписей:

- блоки и линии были видны;
- подписи узлов/осей отсутствовали или сливались с фоном.

Для презентации это критично: инфографика без подписей теряет смысл.

## Корневая причина

Сошлись сразу несколько факторов:

1. Шаблон SVG вставлял визуальные формы, но не всегда подставлял label-тексты.
2. На отдельных темах цвет текста совпадал с фоном.
3. Часть `<text>` попадала вне видимого `viewBox` после масштабирования.

## Решение

1. Ввести обязательный слой подписей для каждого шаблона (`labels layer`).
2. Добавить fallback-словарь названий, если данные неполные.
3. Нормализовать стиль текста для SVG в одном месте.

```css
.infographic-svg text {
  fill: rgba(228, 238, 255, 0.92);
  font-size: 12px;
  font-weight: 600;
  letter-spacing: 0.2px;
}
```

```js
const FALLBACK_LABELS = ["Input", "Queue", "Process", "Store", "Output"];
const labels = (data.labels && data.labels.length ? data.labels : FALLBACK_LABELS).slice(0, 5);
```

## QA-чеклист (блокер)

- На каждом слайде с инфографикой есть минимум 3 осмысленные подписи.
- Подписи читаемы на текущей теме (контраст не ниже целевого).
- Подписи не выходят за `viewBox`.

## Правило

Любая инфографика без подписей или с нечитаемыми подписями считается regression и не проходит финальный QA.
