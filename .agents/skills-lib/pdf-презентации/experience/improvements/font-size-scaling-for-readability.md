# Масштабирование шрифтов для читаемости на 1920x1080

**ID:** EXP-025
**Дата:** 2026-02-05
**Контекст:** Telegram Stars Presentation — 14 слайдов, пользователь жалуется "всё мелко и далеко"

---

## Проблема

При создании презентации 1920x1080 с "типичными" font-size (14-16px для текста, 38px для заголовков, 28px для акцентов) — всё выглядит **мелко и разреженно** при просмотре PDF.

**Причина:** 1920x1080 — это большое разрешение. Размеры, привычные для веб-страниц (где viewport обычно 1200-1440px), на canvas 1920px смотрятся непропорционально мелко.

---

## Решение: Систематическое масштабирование ~15%

### Эталонные размеры для 1920x1080 слайдов

| Элемент | МЕЛКО (не делать) | ОПТИМАЛЬНО |
|---------|-------------------|------------|
| Заголовок h2 | 36-38px | **44-46px** |
| Подзаголовок | 16-18px | **20-22px** |
| Титульный h1 | 60-64px | **72-78px** |
| Описание титульного | 20-22px | **24-26px** |
| Текст карточек | 14-16px | **17-19px** |
| Таблицы (th/td) | 15-17px | **18-20px** |
| Числа-акценты (big) | 36-42px | **42-48px** |
| Результаты расчётов | 24-28px | **28-34px** |
| Теги/бейджи | 12-13px | **14-16px** |
| Подписи/footnotes | 12-13px | **14-16px** |
| Slide number | 12-14px | **15-17px** |
| Highlight box текст | 14-15px | **17-18px** |
| Flow step заголовки | 16-17px | **19-20px** |
| Flow step описания | 13-14px | **15-17px** |
| Иконки заголовков | 44-48px | **52-56px** |
| Bar chart высота | 32-36px | **40-46px** |
| Quote card текст | 14-16px | **17-19px** |

### Padding слайдов

| Элемент | РАЗРЕЖЕННО | ОПТИМАЛЬНО |
|---------|------------|------------|
| Slide padding | 60px 80px | **50px 70px** |
| Card padding | 24-28px | **30-34px** |
| Highlight box padding | 18-20px | **22-26px** |

**Логика:** Уменьшить padding слайда → больше пространства для контента → контент укрупняется → ощущение "ближе".

### Титульный слайд — особый случай

Титульный слайд часто выглядит "пустым" из-за:
- Слишком маленького h1 на огромном canvas
- Слишком больших отступов
- Мелкого мокапа справа

**Решение:**
```css
/* Заголовок */
h1 { font-size: 76px; }  /* не 64px */
p.desc { font-size: 26px; }  /* не 22px */

/* Мокап бота */
.mockup { width: 440px; }  /* не 380px */
.mockup-header font { 19px; }  /* не 16px */
.mockup-body font { 17-19px; }  /* не 14-16px */
```

## Метод исправления

### Быстрый путь: CSS variables → replace_all

Если размеры заданы через CSS классы/переменные → менять в одном месте.

### Inline стили: replace_all по паттернам

Когда размеры заданы inline, использовать replace_all по повторяющимся паттернам:
```
font-size:14px;color:var(--star-gold);font-weight:600;margin-bottom:12px → 16px
font-size:14px;color:var(--text-secondary);line-height:1.5 → 16px
font-size:18px;font-weight:600 → 20px
font-size:28px;font-weight:800 → 32px
```

**Порядок:**
1. Глобальный CSS (slide, slide-header, table, tag, bar, quote)
2. Повторяющиеся inline-паттерны через replace_all
3. Уникальные элементы через точечные Edit

---

## Когда применять

- **Всегда при первом создании** — начинать с увеличенных размеров (таблица выше)
- **При жалобе "мелко"** — систематическое масштабирование +15% по всей презентации
- **При жалобе "далеко/разреженно"** — уменьшить slide padding + увеличить элементы
