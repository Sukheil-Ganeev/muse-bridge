## Назначение скилла

Создание качественных README.md для HTML-презентаций с обязательным циклом: **Анализ → Планирование → Генерация → QA**.

**Когда активировать:**
- Нужно создать README.md для HTML-презентации (одной или нескольких)
- Нужно обновить существующий README презентации
- Пользователь спрашивает о структуре README для презентации
- Batch-генерация README для множества презентаций

## Детекция технологий

Скилл автоматически определяет технологию презентации:

| Технология | Маркеры | Навигация |
|-----------|---------|-----------|
| Custom HTML/CSS | `<div class="slide">`, нет библиотек | scroll-based |
| Reveal.js | `<div class="reveal">`, `<section>` | стрелки, пробел |
| Impress.js | `<div id="impress">`, `data-x/y` | стрелки |
| Deck.js | `class="deck-container"` | стрелки |
| Shower | `<div class="shower">` | стрелки |

## Batch-режим

**Формула:** `ceil(N / 3)` workers + `1` QA-агент

| Презентаций | Workers | QA | Итого агентов |
|------------|---------|-----|---------------|
| 1-3 | 1 | 0-1 | 1-2 |
| 4-6 | 2 | 1 | 3 |
| 7-9 | 3 | 1 | 4 |
| 10-15 | 4-5 | 1 | 5-6 |
| 16-30 | 6-10 | 1 | 7-11 |

## Инструкции по использованию

### При активации скилла

1. Прочитай `experience/_index.md` — применяй накопленные уроки
2. Определи режим: одиночный (1 презентация) или batch (несколько)
3. Следуй 4 фазам из SKILL.md строго по порядку
4. Используй `references/cheatsheet.md` как шаблон
5. Сверяйся с `references/example-readme.md` как эталоном
6. Проверяй по `references/qa-checklist.md`

### Типичные сценарии

| Запрос | Действие |
|--------|---------|
| "Создай README для презентации" | Фаза 1-4, одиночный режим |
| "Создай README для всех презентаций в папке" | Фаза 1-4, batch-режим |
| "Обнови README" | Прочитай текущий + HTML, обнови изменённые секции |
| "Проверь README" | Используй qa-checklist.md |

### При обновлении скилла

1. Обнови SKILL.md
2. Добавь запись в CHANGELOG.md
3. Если был полезный урок — добавь в experience/_index.md
