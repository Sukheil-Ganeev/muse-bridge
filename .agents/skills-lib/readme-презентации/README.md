# Скилл: README для презентаций

Создание качественных README.md для HTML-презентаций. Анализирует файлы, определяет технологию, генерирует по 14-секционному шаблону.

## Структура скилла

```
readme-презентации/
├── SKILL.md                    # Основной файл (триггеры, 4 фазы, batch-режим)
├── README.md                   # Этот файл
├── references/
│   ├── cheatsheet.md           # 14-секционный шаблон README
│   ├── example-readme.md       # Эталонный пример (реальный README)
│   ├── qa-checklist.md         # Чеклист проверки качества
│   ├── faq.md                  # Часто задаваемые вопросы
│   └── troubleshooting.md      # Решение проблем
└── experience/
    └── _index.md               # Накопленный опыт
```

## Когда использовать

- Создание README для одной HTML-презентации
- Массовая генерация README для множества презентаций (batch)
- Обновление существующего README

## Ключевые особенности

- **4 обязательных фазы:** анализ → планирование → генерация → QA
- **Адаптивность:** автоопределение технологии (Custom HTML, Reveal.js и др.)
- **14 секций:** метаданные, оглавление, бренды, бюджеты, теги, связи и т.д.
- **Batch-режим:** формула распределения по агентам, 2-волновая архитектура
- **QA-чеклист:** проверка консистентности, перекрёстных ссылок, форматирования

## Проверено

Скилл протестирован на batch-генерации 15 README для PC-hardware справочников:
- 14 индивидуальных + 1 combined
- 6 агентов, 2 волны, ~6 минут
- QA результат: 0 проблем
