## Технические инструкции

### Как открыть
Открыть `presentation.html` в любом современном браузере (Chrome/Edge/Firefox). Локальный сервер не нужен -- все стили и шрифты inline.

### Как конвертировать HTML -> PDF
Используется Playwright:
```bash
python -m playwright pdf presentation.html output/dac_amp_справочник.pdf --width=1920 --height=1080
```
Параметры: `print_background=True`, ждать `networkidle` для загрузки шрифтов.

### Как редактировать
- Файл self-contained: CSS inline в `<style>`, контент в `<div class="slide">`
- CSS variables в `:root` для смены цветовой палитры (тема «Warm Frequency» -- медный + янтарный)
- Каждый слайд: `<div class="slide">...</div>`
- Компоненты: `.card`, `.two-columns`, `.three-columns`, `.four-grid`, `.styled-table`, `.code-block`, `.flow-container`, `.myth-card`, `.scenario-card`, `.redflag-card`, `.freq-bars`, `.vu-meter`

## Краткое саммари

Справочник охватывает все аспекты выбора DAC (ЦАП) и усилителя для наушников. Центральная идея -- встроенного звука (Realtek ALC1220/ALC4080) достаточно для 80% пользователей, а внешний DAC/AMP нужен при наушниках с импедансом от 80 Ом, наличии помех или потребности в балансном выходе.

Подробно разобраны 5 типов устройств (USB-донгл, комбо, стек, PCIe, аудиоинтерфейс), ключевые характеристики (SNR, мощность, THD+N, выходной импеданс) и конкретные модели с ценами. Золотое правило бюджета -- 70% на наушники, 30% на DAC/AMP, при этом диапазон $80-200 закрывает 90% потребностей.

Отдельные слайды посвящены развенчанию 7 мифов аудиоиндустрии (USB-кабели, прогрев, 24/192 битрейт), типичным ошибкам новичков и красным флагам при покупке. Справочник завершается практическим чек-листом из 8 пунктов и компактной шпаргалкой для печати.

## Сценарии использования

1. **Консультация по выбору DAC/AMP:** Пользователь спрашивает, нужен ли ему внешний DAC -- агент проверяет импеданс наушников (слайд 5), определяет бюджет (слайд 6) и рекомендует конкретную модель (слайд 7) с учётом сценария (слайд 8).

2. **Разбор помех и шумов:** Пользователь жалуется на шипение/помехи в наушниках -- агент объясняет разницу встроенного и внешнего звука (слайд 5), рекомендует USB-донгл (FiiO KA11) или комбо, предупреждает о мифах (слайд 10).

3. **Выбор аудиоинтерфейса для стрима:** Пользователь-стример выбирает между DAC/AMP и аудиоинтерфейсом -- агент объясняет разницу (слайд 3, ошибка #5 на слайде 11), рекомендует Focusrite Scarlett Solo или MOTU M2.

## Проблемы и ограничения

- Не покрыты портативные DAC/AMP для смартфонов (только ПК/ноутбук)
- Нет детального сравнения конкретных моделей наушников (только импедансы)
- Цены актуальны на Q1 2026 -- могут измениться
- Не описаны многоканальные решения (7.1 surround)
- Отсутствуют рекомендации по акустической обработке помещения
- Субъективные характеристики звука (теплота, детальность) не покрыты -- фокус на объективных измерениях
