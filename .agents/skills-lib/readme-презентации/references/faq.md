# FAQ — README для презентаций

## Q: Сколько времени занимает создание одного README?
**A:** Одному агенту: 2-3 минуты (чтение HTML + заполнение шаблона). В batch-режиме с 5 агентами: 15 README за ~6 минут.

## Q: Обязательно ли заполнять все 14 секций?
**A:** Да, все 14 секций обязательны. Если данных нет (например, нет цен), напиши "Не указано в презентации" — но секцию не пропускай.

## Q: Как определить технологию презентации?
**A:** Смотри маркеры в HTML:
- `<div class="slide">` → Custom HTML/CSS
- `<div class="reveal">` + `<section>` → Reveal.js
- `<div id="impress">` → Impress.js
- Если непонятно — укажи "Custom HTML" и опиши найденную структуру

## Q: Что делать если HTML файл >500KB?
**A:** НЕ читай его для создания README напрямую. Варианты:
1. Если это combined/сводный файл — создай README через агрегацию из отдельных README
2. Если это единичная презентация — читай по частям (offset/limit)

## Q: Как считать токены?
**A:** Формула: размер_файла_KB × 300 = примерное количество токенов. Например, 150KB HTML ≈ 45,000 токенов.

## Q: Нужен ли QA для одного README?
**A:** Рекомендуется, но не обязательно. Для batch (3+ файлов) — QA-агент обязателен.

## Q: Как обновить существующий README?
**A:** Прочитай текущий README и HTML. Обнови только изменившиеся секции. Добавь запись в "Историю изменений".

## Q: Что если в папке нет backup файла?
**A:** Укажи в таблице "Файлы" что backup отсутствует. Это нормально для combined/сводных файлов.

## Q: Как определить целевую аудиторию?
**A:** По контенту презентации:
- Базовые термины, объяснения "что такое" → Начальный
- Сравнения, рекомендации, выбор → Средний
- Технические детали, разгон, конфигурация → Продвинутый
- Если всё сразу → "Все уровни"

## Q: Как заполнять "Связи и зависимости"?
**A:** Определи по тематике:
1. Посмотри соседние папки — есть ли смежные темы
2. Определи тематическую группу (аудио, гейминг, система, инфраструктура)
3. Укажи тип связи: "дополняет" (разные аспекты одной темы), "пересекается" (частичное совпадение), "prerequisite" (нужно знать перед этим)

## Q: Сколько агентов нужно для batch-режима?
**A:** Формула: ceil(количество_презентаций / 3) workers + 1 QA-агент. Например:
- 5 презентаций → 2 workers + 1 QA = 3 агента
- 15 презентаций → 5 workers + 1 QA = 6 агентов
- 30 презентаций → 10 workers + 1 QA = 11 агентов
