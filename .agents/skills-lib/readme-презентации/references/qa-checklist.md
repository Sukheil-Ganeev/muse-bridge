# QA-чеклист для README презентаций

## Проверка одного README

### Структура (14 секций)
- [ ] Заголовок + описание (> и 1-2 предложения)
- [ ] Метаданные (таблица с 8+ параметрами)
- [ ] Целевая аудитория (таблица)
- [ ] Файлы (таблица с реальными размерами)
- [ ] Технические инструкции (открытие, конвертация, редактирование, CSS-селекторы, токены)
- [ ] Содержание по слайдам (таблица с номерами и описаниями)
- [ ] Краткое саммари (3-5 абзацев)
- [ ] Бренды и модели (список или "не упоминаются")
- [ ] Бюджетные диапазоны (таблица или "не указаны")
- [ ] Ключевые слова и теги (бэктики)
- [ ] Связи и зависимости (таблица + тематические группы)
- [ ] Сценарии использования (2-3 сценария)
- [ ] Проблемы и ограничения (список)
- [ ] История изменений (таблица)

### Точность данных
- [ ] Количество слайдов соответствует реальному (div.slide / section)
- [ ] Размеры файлов — реальные (через ls -la, не приблизительные)
- [ ] Бренды/модели — только те, что реально есть в презентации
- [ ] Цены — только если явно указаны
- [ ] Технология определена корректно

### Форматирование
- [ ] Markdown-таблицы корректны (заголовок + разделитель + строки)
- [ ] Заголовки ## используются для секций
- [ ] Бэктики для тегов и файлов
- [ ] Нет битых ссылок

## Проверка batch (несколько README)

### Консистентность
- [ ] Все 14 секций присутствуют в КАЖДОМ README
- [ ] Единый формат таблиц во всех файлах
- [ ] Единый стиль описаний
- [ ] Тематические группы одинаковые во всех файлах

### Перекрёстные ссылки
- [ ] Ссылки двусторонние (если A → B, то B → A)
- [ ] Типы связей корректны (дополняет / пересекается / prerequisite)
- [ ] Группировка по темам одинакова во всех README

### Combined/сводные файлы
- [ ] README создан через агрегацию (НЕ чтение оригинала >500KB)
- [ ] Содержит ссылки на все индивидуальные README
- [ ] Предупреждение для AI-агентов о размере файла
- [ ] Сводная таблица брендов/бюджетов

## Критерии прохождения

- **PASS:** все чекбоксы отмечены
- **WARN:** 1-3 мелких проблемы (исправить на месте)
- **FAIL:** пропущены секции, неверные данные, битое форматирование (перегенерировать)
