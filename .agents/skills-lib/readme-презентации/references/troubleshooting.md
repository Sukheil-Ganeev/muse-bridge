# Troubleshooting — README для презентаций

## Проблема: HTML файл слишком большой для чтения

**Симптом:** Агент не может прочитать файл целиком, контекст переполняется.

**Решение:**
1. Если файл <200KB — читай целиком (это нормальный размер)
2. Если 200-500KB — читай по частям (offset/limit), сначала CSS/head для метаданных, потом слайды по очереди
3. Если >500KB — это скорее всего combined файл. Создавай README через агрегацию из отдельных README

## Проблема: Не могу определить технологию презентации

**Симптом:** В HTML нет стандартных маркеров (reveal, slide, impress).

**Решение:**
1. Посмотри `<head>`: есть ли подключения библиотек (JS, CSS)?
2. Посмотри структуру `<body>`: как организованы "страницы"?
3. Есть ли `@page` правило в CSS?
4. Укажи "Custom HTML" и опиши структуру в README

## Проблема: Перекрёстные ссылки не двусторонние

**Симптом:** QA находит что справочник A ссылается на B, но B не ссылается на A.

**Решение:**
1. Добавь обратную ссылку в README справочника B
2. Убедись что тип связи корректен в обе стороны
3. В batch-режиме: передай QA-агенту полномочия исправлять ссылки на месте

## Проблема: В презентации нет явных заголовков слайдов

**Симптом:** Нет `.slide-title`, `h1` или другого очевидного заголовка.

**Решение:**
1. Ищи первый текстовый элемент в каждом `.slide`/`section`
2. Ищи CSS-классы с "title", "header", "heading"
3. Если заголовков нет — опиши содержание слайда в 3-5 словах

## Проблема: Размеры файлов не совпадают

**Симптом:** Указанные в README размеры отличаются от реальных.

**Решение:**
1. ВСЕГДА используй `ls -la` для получения размеров
2. Не округляй — указывай точно (133 KB, а не ~130 KB)
3. Размер PDF может меняться при перегенерации — это нормально

## Проблема: Worker-агент упал посреди batch

**Симптом:** Агент завершился не создав все README.

**Решение:**
1. Проверь какие README созданы: `ls */README.md`
2. Создай нового worker для оставшихся файлов
3. Не пересоздавай уже готовые README

## Проблема: Markdown-таблицы битые

**Симптом:** Таблицы не рендерятся правильно.

**Решение:**
Проверь формат:
```
| Заголовок 1 | Заголовок 2 |
|-------------|-------------|
| Данные 1    | Данные 2    |
```
- Обязательна строка-разделитель с `|---|---|`
- Количество колонок одинаковое во всех строках
- Нет пустых строк внутри таблицы
