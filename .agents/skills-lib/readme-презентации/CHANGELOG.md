### Процесс создания

**Методология:** Brainstorming → Plan Mode → Team Execution

**Предшествующий проект:** Batch-генерация 15 README для PC-hardware справочников
- Папка: `D:/Downloads/Skill_Presentations/06_pc_hardware/`
- 14 индивидуальных справочников + 1 combined (218 слайдов)
- Архитектура: 6 агентов, 2 волны
- Результат QA: 0 критических проблем

**Brainstorming (6 раундов вопросов):**
1. Аудитория → AI-агенты (основная), пользователь (вторичная)
2. Задачи → конвертация, навигация, консультации (все равноважны)
3. Детализация → максимальная (14 секций)
4. Формат → гибкий (общая структура, адаптируется под содержание)
5. Анализ → файлы + контент + контекст
6. Адаптивность → автоопределение технологии

**Команда создания скилла:**

| Агент | Роль | Результат |
|-------|------|----------|
| team-lead | Brainstorming, планирование, координация | План, архитектура |
| explore-1 | Чтение опыта командной работы | Саммари 18-агентной архитектуры |
| explore-2 | Чтение опыта презентаций | Саммари 68 записей опыта |
| explore-3 | Анализ существующих презентаций | Структура HTML, CSS, размеры |

| agent-1 | Написание SKILL.md + README.md | 2 файла |
| agent-2 | Написание references/ + experience/ | 6 файлов |

### Ключевые решения

1. **14 секций обязательны** — проверено на 15 README, ни одна секция не оказалась лишней
2. **4 фазы (анализ → план → генерация → QA)** — обязательный протокол, без анализа README получаются неполными
3. **Адаптивная детекция** — поддержка Custom HTML, Reveal.js, Impress.js и других
4. **Batch-формула** — `ceil(N/3) workers + 1 QA` оптимальна для 5-30 презентаций
5. **Агрегация для >500KB** — combined-файлы не читаются напрямую, README создаётся из данных индивидуальных README
