# Шаблоны отзывов для карточек

## Когда добавлять отзыв

Отзыв добавляется в карточку продукта:
- **Премиум продукты** — подчёркивает ценность
- **При сомнениях клиента** — социальное доказательство
- **Дорогие экскурсии** — обоснование цены
- **Новые продукты** — формирование доверия

## Формат отзыва

```
_"Текст отзыва короткий"_
— Имя, месяц 2025
```

**Пример в карточке:**
```
_"Виды с колеса просто захватывающие! Особенно на закате"_
— Анна, январь 2025
```

## Правила составления отзывов

1. **Реалистичность** — используйте настоящие русские имена
2. **Краткость** — 1-2 предложения максимум
3. **Эмоциональность** — передавайте впечатления, а не факты
4. **Конкретика** — упоминайте детали (закат, дети, VIP-кабина)
5. **Актуальность** — даты в пределах последних 2-3 месяцев

### Чего избегать

- Слишком восторженные отзывы ("ЛУЧШЕЕ В МИРЕ!!!")
- Длинные описания
- Нереалистичные имена
- Старые даты (более 6 месяцев)
- Повторяющиеся формулировки
