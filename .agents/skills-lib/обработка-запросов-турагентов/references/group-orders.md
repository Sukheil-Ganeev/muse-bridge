# Групповые и корпоративные заказы

## 1. Групповые скидки

### Система скидок по количеству человек

| Количество | Скидка | Примечание |
|------------|--------|------------|
| 1-9 человек | 0% | Стандартная цена |
| 10-19 человек | -5% | Малая группа |
| 20-49 человек | -10% | Средняя группа |
| 50+ человек | Индивидуально | Запросить расчёт |

> **Важно:** Скидка применяется к рекомендованным ценам (Recommended Rate), не к B2B!

### Правила применения

- Скидка рассчитывается от общей суммы заказа
- Детские и взрослые билеты суммируются для определения размера группы
- Сопровождающие (гиды, водители) НЕ учитываются в подсчёте
- Скидки НЕ суммируются с промокодами

### Шаблон группового расчёта (WhatsApp)

```

[Название продукта]
───────────────

Взрослых:  [кол-во]
Детей (3-11):  [кол-во]
*Итого участников:*  [общее кол-во]
───────────────
💰 *Стоимость:*

Взрослые ([кол-во] × [цена]):  [сумма] AED
Дети ([кол-во] × [цена]):  [сумма] AED

*Итого до скидки:*  [сумма] AED
*Групповая скидка ([X]%):*  -[сумма] AED
───────────────
*ИТОГО К ОПЛАТЕ:*  [финальная сумма] AED
───────────────
⚠️ *Условия:*
• Цены действительны на дату [дата]
• Требуется 50% предоплата
• Финальный расчёт за 7 дней до даты
```

## 2. Корпоративные заказы

### Типы корпоративных мероприятий

| Тип | Описание | Особенности |
|-----|----------|-------------|
| **Тимбилдинг** | Командообразование | Активности, квесты, соревнования |
| **Корпоратив** | Праздничное мероприятие | Банкет, шоу, развлечения |
| **Инсентив-тур** | Поощрительная поездка | VIP-сервис, эксклюзивы |
| **Конференция** | Деловое мероприятие | Залы, оборудование, кейтеринг |

### Что нужно для расчёта корпоратива

**Обязательная информация:**
- [ ] Количество участников (взрослые/дети)
- [ ] Даты проведения (+ резервные)
- [ ] Бюджет на человека или общий
- [ ] Тип мероприятия (тимбилдинг/корпоратив/инсентив)
- [ ] Пожелания по локации (Дубай/Абу-Даби/другой эмират)

**Желательная информация:**
- Предпочтения по активностям
- Наличие VIP-гостей
- Требования к питанию (халяль, вегетарианское, аллергии)
- Брендирование (логотипы, сувениры)
- Трансфер (из отеля, аэропорта)

### Вопросы для уточнения у клиента

```
Для подготовки КП мне нужна информация:

1. Сколько участников? (взрослые/дети отдельно)
2. Какие даты рассматриваете?
3. Какой бюджет? (на человека или общий)
4. Какой формат — тимбилдинг, корпоратив, инсентив?
5. Есть пожелания по активностям или локациям?
6. Нужен ли трансфер?
7. Требования к питанию? (халяль, аллергии)
```

## 3. Мультивалютность

### Когда показывать цены в AED (по умолчанию)

- Все стандартные карточки
- Расчёты для турагентов
- Групповые расчёты
- Корпоративные КП

> **AED — базовая валюта для всех расчётов**

### Когда конвертировать в RUB/KZT

**Конвертация только по явному запросу клиента:**
- "Сколько это в рублях?"
- "Можно цену в тенге?"
- Клиент из РФ/Казахстана и просит в местной валюте

### Формат указания цен с конвертацией

```
💰 *Стоимость:*
Взрослый:  500 AED (~12,500 RUB*)
Ребёнок:  350 AED (~8,750 RUB*)

_*Курс ориентировочный. Финальный расчёт по курсу на день оплаты._
```

### Примечание о курсе

**Всегда добавлять при конвертации:**

```
⚠️ _Цены в RUB/KZT указаны справочно.
Финальная сумма рассчитывается по курсу ЦБ на день оплаты._
```

### Актуальные способы оплаты

```
*ОПЛАТА*
• AED — наличные/карта в ОАЭ
• USD — наличные/перевод
• RUB — перевод (СБП/карта РФ)
• KZT — перевод
• USDT — криптовалюта

_Курс фиксируется на день оплаты_
```
