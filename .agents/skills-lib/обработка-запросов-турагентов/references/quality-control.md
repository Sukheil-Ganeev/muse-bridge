# Качество и контроль карточек

Руководство по обеспечению качества карточек туров и процессам контроля.

---

## 1. A/B тестирование карточек

### Что тестировать

| Элемент | Варианты для теста | Метрика |
|---------|-------------------|---------|
| Длина карточки | Короткая (5 строк) vs Полная (15 строк) | Конверсия в заказ |
| Порядок блоков | Цена первая vs Описание первое | Время ответа клиента |
| Формулировки цен | "от 45 000 ₽" vs "45 000 - 65 000 ₽" | Количество уточняющих вопросов |
| Фото | С фото vs Без фото | Вовлечённость |
| Эмодзи | С эмодзи vs Без эмодзи | Конверсия |
| CTA (призыв к действию) | "Забронировать" vs "Узнать подробности" | Клики |

### Как измерять

**Основные метрики:**
- **Конверсия в заказ** — % клиентов, оформивших бронь после получения карточки
- **Время ответа клиента** — сколько минут/часов до реакции
- **Количество уточняющих вопросов** — меньше = карточка информативнее
- **Отказы** — % клиентов, ушедших после карточки

**Методология:**
1. Выбрать ОДИН элемент для теста
2. Разделить аудиторию 50/50
3. Минимальная выборка: 50 отправок на вариант
4. Срок теста: 2-4 недели
5. Фиксировать ВСЕ результаты

### Журнал тестов (шаблон)

```markdown
## Тест #001

**Дата:** 2025.01.15 - 2025.01.31
**Гипотеза:** Цена в начале карточки увеличит конверсию
**Элемент:** Позиция блока с ценой

### Вариант A (контроль)
Описание → Включено → Цена → CTA

### Вариант B (тест)
Цена → Описание → Включено → CTA

### Результаты

| Метрика | Вариант A | Вариант B |
|---------|-----------|-----------|
| Отправлено | 50 | 50 |
| Ответили | 35 (70%) | 42 (84%) |
| Забронировали | 8 (16%) | 12 (24%) |
| Среднее время ответа | 4.2 часа | 2.1 часа |

### Вывод
Вариант B победил. Цена в начале увеличивает конверсию на 50%.

### Действие
Внедрить вариант B как стандарт.
```

### Примеры тестов

**Тест "Цена в начале vs в конце":**

Вариант A (цена в конце):
```
🏝 Турция, Анталья
Отель Rixos Premium 5*
7 ночей, всё включено
Вылет: 15 марта из Москвы
✈️ Перелёт включён

💰 от 89 000 ₽/чел
```

Вариант B (цена в начале):
```
💰 от 89 000 ₽/чел

🏝 Турция, Анталья
Отель Rixos Premium 5*
7 ночей, всё включено
Вылет: 15 марта из Москвы
✈️ Перелёт включён
```

## 2. Фидбек от агентов

### Шаблон формы обратной связи

```markdown
# Обратная связь по карточкам туров

**Агент:** _______________
**Дата:** _______________
**Период использования:** с ___ по ___

## Общая оценка (1-10): ___

## Вопросы

### 1. Удобство использования
- Легко ли находить нужную карточку? (да/нет/частично)
- Комментарий: _______________

### 2. Полнота информации
- Достаточно ли информации в карточках? (да/нет)
- Чего не хватает: _______________

### 3. Что добавить?
- [ ] Больше фото
- [ ] Видео
- [ ] Отзывы туристов
- [ ] Сравнение отелей
- [ ] Карту расположения
- Другое: _______________

### 4. Что убрать/сократить?
_______________

### 5. Частые вопросы клиентов
После отправки карточки клиенты обычно спрашивают:
1. _______________
2. _______________
3. _______________

### 6. Проблемные карточки
Какие карточки вызывают сложности:
- Направление: _______________
- Проблема: _______________

### 7. Лучшие карточки
Какие карточки работают отлично:
- Направление: _______________
- Почему: _______________

### 8. Свободные комментарии
_______________
```

### Вопросы для устного интервью

1. **Про процесс:**
   - Сколько времени уходит на подбор карточки?
   - Редактируете ли карточки перед отправкой?

2. **Про клиентов:**
   - Как клиенты реагируют на карточки?
   - Что чаще всего уточняют?
   - После каких карточек быстрее бронируют?

3. **Про улучшения:**
   - Если бы могли изменить одну вещь — что?
   - Какой карточки не хватает?

### Периодичность сбора

| Тип фидбека | Частота | Ответственный |
|-------------|---------|---------------|
| Форма обратной связи | 1 раз в месяц | Руководитель отдела |
| Устное интервью | 1 раз в квартал | Руководитель/Маркетолог |
| Экспресс-опрос в чате | Еженедельно | Старший агент |
| Разбор сложных случаев | По мере возникновения | Команда |

### Как обрабатывать фидбек

**Шаг 1: Сбор**
- Собрать все формы до 5 числа месяца
- Выгрузить в единую таблицу

**Шаг 2: Категоризация**
```
Критично (исправить за неделю):
- Ошибки в ценах
- Неработающие ссылки
- Устаревшая информация

Важно (исправить за месяц):
- Недостающая информация
- Неудобный формат

Желательно (в план развития):
- Новые функции
- Улучшения дизайна
```

**Шаг 3: Приоритизация**
- Частота упоминания (много агентов = высокий приоритет)
- Влияние на продажи
- Сложность реализации

**Шаг 4: Действие**
- Создать задачи в Notion
- Назначить ответственных
- Установить дедлайны
- Сообщить агентам о плане

**Шаг 5: Отчёт**
- Ежемесячно публиковать "Что изменилось по вашим отзывам"

## 3. Аудит карточек

### Чеклист ежемесячной проверки

```markdown
# Аудит карточек — [Месяц] [Год]

**Аудитор:** _______________
**Дата проверки:** _______________

## Направление: _______________

### Цены
- [ ] Цены актуальны (проверено с туроператором)
- [ ] Формат цен единообразный
- [ ] Указаны условия цены (за человека, за номер)
- [ ] Есть информация о доплатах

### Условия
- [ ] Даты вылетов корректны
- [ ] Программа питания актуальна
- [ ] Категории номеров соответствуют отелю
- [ ] Условия отмены указаны верно

### Ссылки и медиа
- [ ] Все ссылки работают
- [ ] Фото загружаются
- [ ] Ссылки ведут на правильные страницы

### Контент
- [ ] Нет орфографических ошибок
- [ ] Информация не устарела
- [ ] Описание соответствует реальности

### Техническое
- [ ] Карточка корректно отображается в мессенджерах
- [ ] Форматирование сохраняется при копировании
- [ ] Размер файла оптимален

## Найденные проблемы

| # | Проблема | Критичность | Статус |
|---|----------|-------------|--------|
| 1 | | Высокая/Средняя/Низкая | |
| 2 | | | |

## Итого
- Проверено карточек: ___
- С проблемами: ___
- Критичных: ___
```

### Расписание аудита

| Неделя месяца | Направления | Ответственный |
|---------------|-------------|---------------|
| 1-я | Турция, Египет | Агент 1 |
| 2-я | ОАЭ, Мальдивы | Агент 2 |
| 3-я | Европа, экскурсии | Агент 3 |
| 4-я | Россия, СНГ | Агент 4 |

### Кто проводит аудит

**Роли:**
- **Аудитор** — проверяет карточки по чеклисту
- **Контролёр** — проверяет работу аудитора (выборочно, 10%)
- **Ответственный за исправления** — вносит правки

**Правило ротации:** аудитор не проверяет свои карточки

### Шаблон отчёта аудита

```markdown
# Отчёт аудита карточек

**Период:** [Месяц Год]
**Подготовил:** [ФИО]
**Дата отчёта:** [Дата]

## Сводка

| Показатель | Значение |
|------------|----------|
| Всего карточек | 150 |
| Проверено | 150 (100%) |
| Без замечаний | 128 (85%) |
| С замечаниями | 22 (15%) |
| Критичные проблемы | 3 (2%) |

## Критичные проблемы (исправлены)

1. **Турция, Rixos** — неверная цена (было 45 000, стало 52 000)
2. **Египет, Coral Sea** — отель закрыт на реновацию
3. **ОАЭ, Atlantis** — битая ссылка на бронирование

## Типичные ошибки

| Тип ошибки | Количество | % |
|------------|------------|---|
| Устаревшие цены | 8 | 36% |
| Неработающие ссылки | 6 | 27% |
| Опечатки | 5 | 23% |
| Неактуальные даты | 3 | 14% |

## Рекомендации

1. Настроить автоматическую проверку ссылок
2. Обновлять цены сразу после рассылки ТО
3. Добавить второй уровень проверки для топ-10 направлений

## Динамика качества

| Месяц | % без замечаний |
|-------|-----------------|
| Ноябрь 2024 | 78% |
| Декабрь 2024 | 82% |
| Январь 2025 | 85% |

**Тренд:** положительный (+7% за квартал)

## Следующие шаги

- [ ] Исправить все найденные ошибки до [дата]
- [ ] Провести обучение по частым ошибкам
- [ ] Обновить шаблоны карточек
```

## 4. Версионирование прайсов

### Формат версий

**Стандарт:** `vГГГГ.ММ.ДД`

Примеры:
- `v2025.01.31` — версия от 31 января 2025
- `v2025.02.15` — версия от 15 февраля 2025

**Для нескольких версий в день:** `vГГГГ.ММ.ДД.N`
- `v2025.01.31.1` — первое обновление
- `v2025.01.31.2` — второе обновление

### Что фиксировать

При каждом изменении обязательно записывать:

| Поле | Описание | Пример |
|------|----------|--------|
| Версия | Номер версии | v2025.01.31 |
| Дата | Дата и время изменения | 31.01.2025 14:30 |
| Автор | Кто внёс изменения | Иванов А.А. |
| Тип изменения | Категория | Цены / Условия / Новое |
| Описание | Что изменилось | Обновлены цены на март |
| Причина | Почему изменилось | Рассылка ТО от 30.01 |
| Затронутые карточки | Список | Турция: 5 карточек |

### Шаблон changelog для прайса

```markdown
# Changelog: [Название прайса/направления]

## v2025.01.31

**Дата:** 31 января 2025, 14:30
**Автор:** Иванов А.А.
**Тип:** Обновление цен

### Изменения

#### Добавлено
- Новый отель: Rixos Premium Belek

#### Изменено
- Цены на март +5% (все отели)
- Voyage Belek: изменена категория номеров

#### Удалено
- Crystal Sunrise Queen: закрыт на реновацию

### Причина
Рассылка туроператора Anex Tour от 30.01.2025

### Затронутые карточки
- Турция_Анталья_Rixos_март.md
- Турция_Анталья_Voyage_март.md
- Турция_Анталья_Crystal_март.md (удалена)

---

## v2025.01.15

**Дата:** 15 января 2025, 10:00
**Автор:** Петрова М.С.
**Тип:** Сезонное обновление

### Изменения

#### Добавлено
- Летний сезон 2025: 45 новых карточек
- Раннее бронирование: скидки до 35%

#### Изменено
- Обновлены все описания отелей

### Причина
Старт продаж летнего сезона

## v2024.12.01

[История продолжается...]
```

### Где хранить историю

**Основное хранилище: Notion**

Структура в Notion:
```
📁 Турагентство
  └── 📁 Прайсы и карточки
        ├── 📄 Текущие версии
        ├── 📁 Архив версий
        │     ├── 📁 2025
        │     │     ├── 📁 Январь
        │     │     └── 📁 Февраль
        │     └── 📁 2024
        └── 📄 Changelog (общий)
```

**База данных Notion для версий:**

| Свойство | Тип | Описание |
|----------|-----|----------|
| Версия | Title | Номер версии |
| Дата | Date | Дата изменения |
| Направление | Select | Турция/Египет/ОАЭ/... |
| Тип | Multi-select | Цены/Условия/Новое/Удаление |
| Автор | Person | Кто изменил |
| Описание | Text | Краткое описание |
| Файлы | Files | Прикреплённые карточки |
| Статус | Status | Актуально/Архив |

### Процесс версионирования

```
1. Получили обновление от ТО
         ↓
2. Создать новую версию в Notion
         ↓
3. Заполнить changelog
         ↓
4. Внести изменения в карточки
         ↓
5. Проверить изменения (чеклист)
         ↓
6. Опубликовать
         ↓
7. Уведомить команду
```

### Правила хранения

- **Текущая версия:** всегда доступна в основной папке
- **Предыдущие 3 версии:** быстрый доступ для отката
- **Старше 3 месяцев:** архив (сжатый)
- **Старше 1 года:** удаление или долгосрочный архив

### Быстрый откат

Если нужно вернуть предыдущую версию:

```markdown
## Процедура отката

1. Открыть Notion → Архив версий
2. Найти нужную версию по дате
3. Скопировать файлы карточек
4. Заменить текущие версии
5. Создать запись в changelog:
   "Откат до версии vXXXX.XX.XX, причина: [описание]"
6. Уведомить команду об откате
```
