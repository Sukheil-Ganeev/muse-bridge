## Ошибка #1: Разделители внутри ВАЖНО

### Проблема

Использование разделителей `───────────────` внутри блока ВАЖНО между подсекциями.

**Пример ошибки:**
```
⚠️ *ВАЖНО*

*ОПЛАТА*
Полная предоплата
Принимаются карты Visa/MC

───────────────

*ОТМЕНА*
Бесплатно за 24 часа
Позже — 50% стоимости

───────────────

*ДЛЯ ОФОРМЛЕНИЯ*
Копия паспорта
Номер телефона
```

### Решение

Убрать все разделители внутри блока ВАЖНО. Подсекции разделяются пустой строкой.

**Правильно:**
```
⚠️ *ВАЖНО*

*ОПЛАТА*
Полная предоплата
Принимаются карты Visa/MC

*ОТМЕНА*
Бесплатно за 24 часа
Позже — 50% стоимости

*ДЛЯ ОФОРМЛЕНИЯ*
Копия паспорта
Номер телефона
```

### Почему критично

- Разделители визуально разбивают единый блок на отдельные секции
- Клиент может подумать, что ВАЖНО — только первая часть
- Нарушается иерархия документа

### Как запомнить

**Правило:** Разделитель `───` ставится только МЕЖДУ основными блоками (💰, ➕, ⚠️), никогда ВНУТРИ них.

## Ошибка #2: Неправильное количество тире

### Проблема

Использование произвольного количества тире в разделителе.

**Примеры ошибок:**
```
──────────  (10 тире — слишком мало)
───────────────────────────────  (30 тире — слишком много)
---------------  (дефисы вместо тире)
═══════════════  (другой символ)
```

### Решение

Строго соблюдать количество:
- **WhatsApp:** 15 тире `───────────────`
- **Telegram:** 18 тире `──────────────────`

**Правильно для WhatsApp:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED

───────────────

⚠️ *ВАЖНО*
```

**Правильно для Telegram:**
```
💰 **ЦЕНЫ**

`Базовая`  2 100 AED

──────────────────

⚠️ **ВАЖНО**
```

### Почему критично

- Слишком мало — не воспринимается как разделитель
- Слишком много — переносится на новую строку, ломая вёрстку
- Дефисы — выглядят непрофессионально

### Как запомнить

**WhatsApp = 15** (как номер телефона в ОАЭ: +971-xx-xxx-xxxx = 15 символов)
**Telegram = 18** (слово "восемнадцать" длиннее)

## Ошибка #3: Один пробел после категории

### Проблема

Использование одного пробела между моноширинной категорией и ценой.

**Пример ошибки:**
```
```Базовая``` 2 100 AED
```Стандарт``` 2 800 AED
```Премиум``` 3 500 AED
```

### Решение

Всегда ставить **2 пробела** после закрывающих кавычек.

**Правильно:**
```
```Базовая```  2 100 AED
```Стандарт```  2 800 AED
```Премиум```  3 500 AED
```

### Почему критично

- Один пробел "слипает" категорию с ценой
- Ухудшается читаемость
- Неконсистентность с другими материалами

### Как запомнить

**Правило двух пробелов:** После ```` ``` ```` всегда `[ПРОБЕЛ][ПРОБЕЛ]` перед ценой.

**Визуально:** Представьте, что между категорией и ценой должна поместиться ещё одна буква.

## Ошибка #4: Эмодзи внутри звёздочек

### Проблема

Размещение эмодзи внутри форматирования жирного текста.

**Примеры ошибок:**
```
*💰 ЦЕНЫ*
*⚠️ ВАЖНО*
*➕ ОПЦИИ*
```

### Решение

Эмодзи всегда ставится ПЕРЕД звёздочками, снаружи форматирования.

**Правильно:**
```
💰 *ЦЕНЫ*
⚠️ *ВАЖНО*
➕ *ОПЦИИ*
```

### Почему критично

- В некоторых версиях мессенджеров жирный шрифт не применится
- Эмодзи может отобразиться некорректно
- Визуально заголовок выглядит "сжатым"

### Как запомнить

**Порядок:** ЭМОДЗИ → ПРОБЕЛ → *ТЕКСТ*

Эмодзи — это иконка-индикатор блока, она не часть заголовка.

## Ошибка #5: Лишние эмодзи

### Проблема

Использование нестандартных эмодзи для блоков.

**Примеры ошибок:**
```
🎫 *БИЛЕТЫ*
🍽️ *ПИТАНИЕ*
🚗 *ТРАНСФЕР*
✨ *ДОПОЛНИТЕЛЬНО*
📋 *ИНФОРМАЦИЯ*
💵 *СТОИМОСТЬ*
```

### Решение

Использовать только 3 разрешённых эмодзи:

| Эмодзи | Блок |
|--------|------|
| 💰 | ЦЕНЫ (все ценовые блоки) |
| ➕ | ОПЦИИ |
| ⚠️ | ВАЖНО |

**Правильно:**
```
💰 *ЦЕНЫ*
➕ *ОПЦИИ*
⚠️ *ВАЖНО*
```

### Почему критично

- Нарушается унификация всех материалов
- Клиенты не могут быстро ориентироваться
- Выглядит непрофессионально и "пёстро"

### Как запомнить

**Три кита:** 💰 (деньги) → ➕ (плюс) → ⚠️ (внимание)

Больше ничего не нужно!

## Ошибка #6: Расчёт без возраста

### Проблема

Указание детских цен без знания точного возраста ребёнка.

**Пример ошибки:**
```
💰 *ЦЕНЫ*

*ВЗРОСЛЫЕ*
```Базовая```  2 100 AED

*ДЕТИ*
```Базовая```  1 200 AED  ← Какой возраст?
```

### Решение

Если возраст не указан — запросить уточнение или показать все возрастные категории.

**Вариант 1 — Запрос:**
```
Для точного расчёта детских цен уточните:
• Возраст ребёнка (полных лет на дату поездки)
```

**Вариант 2 — Все категории:**
```
💰 *ЦЕНЫ*

*ВЗРОСЛЫЕ (12+)*
```Базовая```  2 100 AED

*ДЕТИ*
• 0-2 года: бесплатно
• 3-5 лет: 800 AED
• 6-11 лет: 1 200 AED
```

### Почему критично

- Возрастные категории различаются у операторов
- Неправильная цена → недоплата или переплата
- Потеря доверия турагента

### Как запомнить

**Нет возраста = Нет детской цены**

Всегда уточняйте!

## Ошибка #7: Округление цен

### Проблема

Самостоятельное округление цен из источника.

**Пример ошибки:**
```
Источник: 2 095 AED
Указано:  2 100 AED  ← Округлено!

Источник: 3 487 AED
Указано:  3 500 AED  ← Округлено!
```

### Решение

Указывать цены **точно** как в источнике.

**Правильно:**
```
```Базовая```  2 095 AED
```Премиум```  3 487 AED
```

### Почему критично

- Турагент может проверить цену у оператора
- Разница накапливается при групповых заказах
- Юридические риски при несовпадении цен

### Как запомнить

**Цена = копия из источника**

Никаких математических операций!

## Ошибка #8: Неправильная группировка (туры по пакетам)

### Проблема

Группировка туров по типу пакета вместо эмиратов.

**Пример ошибки:**
```
💰 *ЦЕНЫ*

*БАЗОВЫЙ ПАКЕТ*
Дубай: 1 500 AED
Абу-Даби: 1 800 AED
Шарджа: 1 200 AED

*ПРЕМИУМ ПАКЕТ*
Дубай: 2 200 AED
Абу-Даби: 2 500 AED
Шарджа: 1 800 AED
```

### Решение

Туры группируются **по эмиратам**, внутри — по пакетам.

**Правильно:**
```
💰 *ЦЕНЫ*

*ДУБАЙ*
```Базовая```  1 500 AED
```Премиум```  2 200 AED

*АБУ-ДАБИ*
```Базовая```  1 800 AED
```Премиум```  2 500 AED

*ШАРДЖА*
```Базовая```  1 200 AED
```Премиум```  1 800 AED
```

### Почему критично

- Турагент выбирает сначала направление, потом пакет
- Неудобно сравнивать цены одного направления
- Нарушается логика выбора клиента

### Как запомнить

**Туры = по эмиратам** (географическая логика)
**Питание = по пакетам** (логика "что включено")

## Ошибка #9: Слово "аттракции"

### Проблема

Использование слова "аттракции" вместо "аттракционы".

**Пример ошибки:**
```
🎢 *АТТРАКЦИИ ДУБАЯ*

💰 *ЦЕНЫ НА АТТРАКЦИИ*
```

### Решение

Использовать правильное слово: **аттракционы**.

**Правильно:**
```
🎢 *АТТРАКЦИОНЫ ДУБАЯ*

💰 *ЦЕНЫ НА АТТРАКЦИОНЫ*
```

### Почему критично

- "Аттракции" — неправильное словообразование
- Выглядит непрофессионально
- Может вызвать недоверие к материалу

### Как запомнить

**Аттракцион** → **Аттракционы** (как "стадион → стадионы")

НЕ "аттракция → аттракции"!

## Ошибка #10: Моноширинный в Telegram

### Проблема

Использование синтаксиса WhatsApp для моноширинного текста в Telegram.

**Пример ошибки (для Telegram):**
```
💰 **ЦЕНЫ**

```Базовая```  2 100 AED  ← Не сработает!
```Премиум```  2 800 AED
```

Отобразится как:
```
```Базовая```  2 100 AED
```
(кавычки будут видны как текст)

### Решение

В Telegram использовать **одинарные** обратные кавычки.

**Правильно для Telegram:**
```
💰 **ЦЕНЫ**

`Базовая`  2 100 AED
`Премиум`  2 800 AED
```

### Почему критично

- Текст отображается с лишними символами
- Выглядит как техническая ошибка
- Непрофессиональное впечатление

### Как запомнить

**WhatsApp = 3 кавычки** (` ``` `)
**Telegram = 1 кавычка** (` ` `)

## Ошибка #11: Один файл для питания

### Проблема

Создание одного файла для ресторанов/ужинов вместо двух.

**Пример ошибки:**
```
Создан: dinner_show.txt

(один файл для всех мессенджеров)
```

### Решение

Для питания всегда создавать **2 файла**: WhatsApp и Telegram.

**Правильно:**
```
Файл 1: dinner_show_whatsapp.txt
Файл 2: dinner_show_telegram.txt
```

### Почему критично

- Питание требует много визуального контента
- Разный синтаксис мессенджеров
- Один файл не работает для обоих платформ

### Как запомнить

**Питание = 2 файла**
**Всё остальное = 1 файл**

## Ошибка #12: Code block вместо файла

### Проблема

Вывод форматированного текста в code block вместо создания файла.

**Пример ошибки:**
```
Вот ваш расчёт:

```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED
```

(текст в code block, а не в файле)
```

### Решение

Всегда создавать **отдельный текстовый файл** с результатом.

**Правильно:**
```
Расчёт сохранён в файл: desert_safari_whatsapp.txt

[Содержимое файла]
```

### Почему критично

- Турагент не может скопировать из code block для отправки
- Форматирование может сломаться при копировании
- Неудобно для дальнейшей работы

### Как запомнить

**Результат = Файл**

Code block — только для примеров в документации!
