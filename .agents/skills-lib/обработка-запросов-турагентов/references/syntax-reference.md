# Syntax Reference — Полная справка по синтаксису

Подробное описание всех элементов форматирования для WhatsApp и Telegram.

---

## WHATSAPP

---

### Жирный текст

**Синтаксис:** `*текст*`

**Правила:**
- Звёздочки должны примыкать к тексту без пробелов
- Работает для слов и фраз
- Не работает через несколько строк

**Примеры:**
```
*ЦЕНЫ*                    ✓ Правильно
*Полная предоплата*       ✓ Правильно
* ЦЕНЫ *                  ✗ Не сработает (пробелы)
*Строка 1
Строка 2*                 ✗ Не сработает (перенос)
```

**Использование:**
- Заголовки блоков: `💰 *ЦЕНЫ*`
- Подзаголовки: `*ОПЛАТА*`
- Важные термины: `*Полная предоплата*`

---

### Курсив

**Синтаксис:** `_текст_`

**Правила:**
- Нижние подчёркивания должны примыкать к тексту
- Используется редко в турпродуктах

**Примеры:**
```
_примечание_              ✓ Правильно
_Цены на момент запроса_  ✓ Правильно
_ примечание _            ✗ Не сработает
```

**Использование:**
- Примечания: `_цены могут измениться_`
- Дополнительная информация

---

### Зачёркнутый текст

**Синтаксис:** `~текст~`

**Правила:**
- Тильды должны примыкать к тексту
- Используется для старых цен

**Примеры:**
```
~2 500 AED~               ✓ Правильно (старая цена)
~ 2 500 AED ~             ✗ Не сработает
```

**Использование:**
- Перечёркнутая старая цена: `~2 500 AED~ 2 100 AED`
- Отменённые услуги

---

### Моноширинный текст

**Синтаксис:** ` ```текст``` `

**Правила:**
- Три обратных кавычки с каждой стороны
- Используется для категорий цен
- После закрывающих кавычек — 2 пробела перед ценой

**Примеры:**
```
```Базовая```  2 100 AED   ✓ Правильно
```Стандарт```  2 800 AED  ✓ Правильно
```Премиум```  3 500 AED   ✓ Правильно
`Базовая`  2 100 AED      ✗ Неправильно (1 кавычка)
```Базовая``` 2 100 AED   ✗ Неправильно (1 пробел)
```

**Использование:**
- Категории цен: ` ```Базовая``` `, ` ```VIP``` `
- Названия пакетов: ` ```All Inclusive``` `

---

### Разделитель

**Синтаксис:** `───────────────` (15 тире)

**Правила:**
- Ровно 15 символов `─` (длинное тире, не дефис!)
- Пустая строка до и после
- Только между основными блоками

**Пример:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED

───────────────

⚠️ *ВАЖНО*

*ОПЛАТА*
Полная предоплата
```

**Код символа:** U+2500 (Box Drawings Light Horizontal)

**Как набрать:**
- Копировать из этого документа
- Alt+2500 на NumPad (Windows)
- Символьная таблица

## TELEGRAM

---

### Жирный текст

**Синтаксис:** `**текст**`

**Правила:**
- Две звёздочки с каждой стороны
- Должны примыкать к тексту

**Примеры:**
```
**ЦЕНЫ**                  ✓ Правильно
**Полная предоплата**     ✓ Правильно
*ЦЕНЫ*                    ✗ Неправильно (одна звёздочка)
** ЦЕНЫ **                ✗ Не сработает (пробелы)
```

**Использование:**
- Заголовки блоков: `💰 **ЦЕНЫ**`
- Подзаголовки: `**ОПЛАТА**`

---

### Курсив

**Синтаксис:** `__текст__` или `_текст_`

**Правила:**
- Два нижних подчёркивания (предпочтительно)
- Одно подчёркивание тоже работает

**Примеры:**
```
__примечание__            ✓ Правильно
_примечание_              ✓ Правильно
```

**Использование:**
- Примечания
- Дополнительная информация

---

### Зачёркнутый текст

**Синтаксис:** `~~текст~~`

**Правила:**
- Две тильды с каждой стороны

**Примеры:**
```
~~2 500 AED~~             ✓ Правильно
~2 500 AED~               ✗ Неправильно (одна тильда)
```

**Использование:**
- Старые цены: `~~2 500 AED~~ 2 100 AED`

---

`Базовая` 2 100 AED       ✗ Неправильно (1 пробел)

**Использование:**
- Категории цен: `` `Базовая` ``, `` `VIP` ``

## ОБЩИЕ ПРАВИЛА

---

### Разрешённые эмодзи

| Эмодзи | Код | Название | Блок |
|--------|-----|----------|------|
| 💰 | U+1F4B0 | Money Bag | ЦЕНЫ |
| ➕ | U+2795 | Plus Sign | ОПЦИИ |
| ⚠️ | U+26A0 | Warning | ВАЖНО |

**Правило использования:**
```
ЭМОДЗИ + ПРОБЕЛ + *ЗАГОЛОВОК*

💰 *ЦЕНЫ*     ← WhatsApp
💰 **ЦЕНЫ**   ← Telegram
```

**Запрещённые эмодзи для основных блоков:**
- 🎫 🎟️ (билеты)
- 🍽️ 🍴 (питание)
- 🚗 🚐 (транспорт)
- ✨ ⭐ (украшения)
- 📋 📝 (документы)

---

### Правило двух пробелов

После категории (моноширинного текста) всегда **2 пробела** перед ценой.

**Визуализация:**
```
```Базовая```[ПРОБЕЛ][ПРОБЕЛ]2 100 AED
            ↑↑
            Два пробела
```

**Почему?**
- Улучшает читаемость
- Визуально отделяет категорию от цены
- Стандарт форматирования

---

### Заголовки блоков

Все заголовки основных блоков пишутся **КАПСЛОКОМ**.

**Основные блоки:**
```
💰 *ЦЕНЫ*
➕ *ОПЦИИ*
⚠️ *ВАЖНО*
```

**Подзаголовки в ВАЖНО:**
```
*ОПЛАТА*
*ОТМЕНА*
*ДЛЯ ОФОРМЛЕНИЯ*
*ВРЕМЯ РАБОТЫ*
*ОГРАНИЧЕНИЯ*
```

**Географические подзаголовки:**
```
*ДУБАЙ*
*АБУ-ДАБИ*
*ШАРДЖА*
*РАС-АЛЬ-ХАЙМА*
```

---

### Структура документа

**Порядок блоков:**
1. 💰 *ЦЕНЫ* — всегда первый
2. ➕ *ОПЦИИ* — если есть дополнительные услуги
3. ⚠️ *ВАЖНО* — всегда последний

**Разделители:**
- Между 💰 и ➕ — разделитель
- Между ➕ и ⚠️ — разделитель
- Между 💰 и ⚠️ (если нет ➕) — разделитель
- ВНУТРИ блоков — БЕЗ разделителей

---

### Списки

**Маркированные списки:**
```
• Пункт 1
• Пункт 2
• Пункт 3
```

**Символ:** `•` (U+2022, Bullet)

**Не использовать:**
- `-` (дефис)
- `*` (звёздочка — конфликт с жирным)
- `>` (цитата в Telegram)

| Элемент | WhatsApp | Telegram |
|---------|----------|----------|
| Жирный | `*текст*` | `**текст**` |
| Курсив | `_текст_` | `__текст__` |
| Зачёркнутый | `~текст~` | `~~текст~~` |
| Моноширинный | ` ```текст``` ` | `` `текст` `` |
| Разделитель | 15 тире | 18 тире |
| Пробелов после категории | 2 | 2 |
| Эмодзи | Снаружи `*` | Снаружи `**` |
