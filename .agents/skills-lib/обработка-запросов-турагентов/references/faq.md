# FAQ — Часто задаваемые вопросы

Полный справочник ответов на типичные вопросы по форматированию турпродуктов.

## ФОРМАТИРОВАНИЕ

---

### Q: Сколько тире в разделителе?

**A:** Зависит от мессенджера:
- **WhatsApp:** 15 тире `───────────────`
- **Telegram:** 18 тире `──────────────────`

**Почему именно столько?**
Это оптимальная ширина для мобильных экранов. Меньше — не выглядит как разделитель. Больше — переносится на новую строку и ломает вёрстку.

**Пример для WhatsApp:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED
```Стандарт```  2 800 AED

───────────────

⚠️ *ВАЖНО*
```

**Пример для Telegram:**
```
💰 **ЦЕНЫ**

`Базовая`  2 100 AED
`Стандарт`  2 800 AED

──────────────────

⚠️ **ВАЖНО**
```

**Как запомнить:** WhatsApp = 15 (короче слово), Telegram = 18 (длиннее слово).

### Q: Сколько пробелов после категории?

**A:** Всегда **2 пробела** между категорией и ценой.

**Почему?**
Один пробел визуально "слипает" категорию и цену. Два пробела создают чёткое разделение, улучшая читаемость.

**НЕПРАВИЛЬНО (1 пробел):**
```
```Базовая``` 2 100 AED
```

**ПРАВИЛЬНО (2 пробела):**
```
```Базовая```  2 100 AED
```

**Как проверить:** После закрывающих кавычек должно быть ровно 2 пробела перед ценой.

**Пример полного блока:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED
```Стандарт```  2 800 AED
```Премиум```  3 500 AED
```

### Q: Какие эмодзи можно использовать?

**A:** Только **3 эмодзи** для основных блоков:

| Эмодзи | Блок | Назначение |
|--------|------|------------|
| 💰 | ЦЕНЫ | Все ценовые блоки |
| ➕ | ОПЦИИ | Дополнительные услуги |
| ⚠️ | ВАЖНО | Критическая информация |

**Почему только эти?**
- Унификация всех материалов
- Мгновенное узнавание блоков
- Профессиональный вид без "мусора"

**НЕПРАВИЛЬНО:**
```
🎫 *БИЛЕТЫ*
🍽️ *ПИТАНИЕ*
🚗 *ТРАНСФЕР*
✨ *ОПЦИИ*
```

**ПРАВИЛЬНО:**
```
💰 *ЦЕНЫ*
➕ *ОПЦИИ*
⚠️ *ВАЖНО*
```

**Исключение:** В модулях для билетов можно использовать тематические эмодзи (🎢, 🎡, 🏛️), но это касается только отдельных модулей, не основного форматирования.

---

### Q: Где ставить эмодзи — до или внутри звёздочек?

**A:** Эмодзи **ВСЕГДА ДО** звёздочек, снаружи форматирования.

**Почему?**
Если эмодзи внутри `*...*`, в некоторых мессенджерах жирный шрифт не применится или применится некорректно.

**НЕПРАВИЛЬНО:**
```
*💰 ЦЕНЫ*
*⚠️ ВАЖНО*
```

**ПРАВИЛЬНО:**
```
💰 *ЦЕНЫ*
⚠️ *ВАЖНО*
```

**Пример полного блока:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED

───────────────

⚠️ *ВАЖНО*

*ОПЛАТА*
Полная предоплата
```

**Как запомнить:** Эмодзи — это "иконка" перед заголовком, а не часть заголовка.

---

### Q: Можно ли ставить разделители внутри ВАЖНО?

**A:** **НЕТ!** Разделители внутри блока ВАЖНО запрещены.

**Почему?**
Блок ВАЖНО — это единая секция критической информации. Разделители внутри дробят её на части, создавая впечатление отдельных блоков.

**НЕПРАВИЛЬНО:**
```
⚠️ *ВАЖНО*

*ОПЛАТА*
Полная предоплата

───────────────

*ОТМЕНА*
Бесплатно за 24 часа
```

**ПРАВИЛЬНО:**
```
⚠️ *ВАЖНО*

*ОПЛАТА*
Полная предоплата

*ОТМЕНА*
Бесплатно за 24 часа
```

**Как разделять подсекции?**
Используйте пустую строку между подсекциями — этого достаточно для визуального разделения.

### Q: Турагент не указал возраст. Делать расчёт?

**A:** **НЕТ!** Без точного возраста расчёт делать нельзя.

**Почему?**
Детские цены зависят от возрастных категорий:
- 0-2 года — часто бесплатно
- 3-11 лет — детская цена
- 12+ лет — взрослая цена

Границы категорий различаются у разных операторов!

**Что делать?**
Запросить уточнение у турагента.

**Пример запроса:**
```
Для расчёта детских цен, пожалуйста, уточните:
- Возраст ребёнка (полных лет на дату поездки)
```

**НЕПРАВИЛЬНО:**
```
Ребёнок: 800 AED (предположительно 3-11 лет)
```

**ПРАВИЛЬНО:**
```
Детские цены зависят от возраста:
• 0-2 года: бесплатно
• 3-11 лет: 800 AED
• 12+ лет: взрослая цена

Уточните возраст для точного расчёта.
```

### Q: Можно ли округлять цены?

**A:** **НЕТ!** Цены указываются точно, как в источнике.

**Почему?**
- Округление может привести к недоплате или переплате
- Турагент может проверить цену у оператора
- Потеря доверия к расчётам

**НЕПРАВИЛЬНО:**
```
```Базовая```  2 100 AED  (было 2 095 AED)
```Премиум```  3 500 AED  (было 3 487 AED)
```

**ПРАВИЛЬНО:**
```
```Базовая```  2 095 AED
```Премиум```  3 487 AED
```

**Исключение:** Если источник даёт округлённые цены — используйте их как есть.

### Q: Как группировать цены?

**A:** Зависит от типа продукта:

| Тип продукта | Группировка | Пример |
|--------------|-------------|--------|
| Туры | По эмиратам | Дубай, Абу-Даби, Шарджа |
| Питание | По типу пакета | Полупансион, Всё включено |
| Билеты | По категориям | Базовая, VIP, Combo |
| Экскурсии | По длительности | 4 часа, 8 часов, Full day |

**Пример для туров (по эмиратам):**
```
💰 *ЦЕНЫ*

*ДУБАЙ*
```Базовая```  1 500 AED
```Премиум```  2 200 AED

*АБУ-ДАБИ*
```Базовая```  1 800 AED
```Премиум```  2 500 AED
```

**Пример для питания (по пакетам):**
```
💰 *ЦЕНЫ*

*ПОЛУПАНСИОН*
Взрослый: 450 AED
Ребёнок (3-11): 250 AED

*ВСЁ ВКЛЮЧЕНО*
Взрослый: 750 AED
Ребёнок (3-11): 400 AED
```

**НЕПРАВИЛЬНО (туры по пакетам):**
```
*БАЗОВЫЙ ПАКЕТ*
Дубай: 1 500 AED
Абу-Даби: 1 800 AED
```

### Q: Когда делать 2 файла?

**A:** Два файла нужны **только для питания** (рестораны, ужины с шоу).

**Почему?**
Питание требует много визуальной информации:
- Фото блюд
- Интерьер ресторана
- Атмосфера шоу

Один файл для WhatsApp, один для Telegram — разный синтаксис.

**Для остальных продуктов — всегда 1 файл:**
- Туры — 1 файл
- Билеты — 1 файл
- Экскурсии — 1 файл

**Пример структуры для питания:**
```
Файл 1: restaurant_whatsapp.txt
Файл 2: restaurant_telegram.txt
```

**Пример структуры для тура:**
```
Файл: desert_safari_whatsapp.txt (или telegram)
```

### Q: Как указывать комиссию?

**A:** Комиссия указывается **отдельной строкой** в блоке цен или в конце.

**Формат:**
```
Комиссия: X%
```
или
```
Комиссия агента: X AED с человека
```

**Пример в блоке цен:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED
```Премиум```  2 800 AED

Комиссия: 10%
```

**Пример отдельным блоком:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED

───────────────

*КОМИССИЯ*
10% от стоимости тура
Минимум 50 AED с заказа
```

**Важно:** Если комиссия не указана в источнике — не добавляйте её самостоятельно!

### Q: Не указан мессенджер. Что делать?

**A:** По умолчанию используйте **WhatsApp**.

**Почему?**
- WhatsApp — основной мессенджер в ОАЭ
- 90%+ запросов приходят через WhatsApp
- Синтаксис WhatsApp проще

**Пример (по умолчанию WhatsApp):**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED

───────────────

⚠️ *ВАЖНО*
```

**Когда уточнять?**
Если в запросе есть признаки Telegram:
- Упоминание "телеграм", "тг", "telegram"
- Ссылка на телеграм-канал
- Username с @

### Q: В чём разница WhatsApp и Telegram?

**A:** Основные различия в синтаксисе:

| Элемент | WhatsApp | Telegram |
|---------|----------|----------|
| Жирный | `*текст*` | `**текст**` |
| Курсив | `_текст_` | `__текст__` или `_текст_` |
| Зачёркнутый | `~текст~` | `~~текст~~` |
| Моноширинный | ` ```текст``` ` | `` `текст` `` |
| Разделитель | 15 тире | 18 тире |

**Пример WhatsApp:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED

───────────────

⚠️ *ВАЖНО*
```

**Пример Telegram:**
```
💰 **ЦЕНЫ**

`Базовая`  2 100 AED

──────────────────

⚠️ **ВАЖНО**
```

**Ключевое отличие:** Telegram использует одинарные обратные кавычки для моноширинного, WhatsApp — тройные.

---

### Q: Моноширинный работает в Telegram?

**A:** **ДА**, но синтаксис другой!

**WhatsApp:** Тройные обратные кавычки
```
```Базовая```
```

**Telegram:** Одинарные обратные кавычки
```
`Базовая`
```

**НЕПРАВИЛЬНО для Telegram:**
```
```Базовая```  2 100 AED
```

Это отобразится как:
```
```Базовая```  2 100 AED
```
(кавычки будут видны как текст)

**ПРАВИЛЬНО для Telegram:**
```
`Базовая`  2 100 AED
```

**Как запомнить:** Telegram = 1 кавычка, WhatsApp = 3 кавычки.

### Q: Продукта нет в базе?

**A:** Сообщите об отсутствии и предложите альтернативы.

**Шаблон ответа:**
```
К сожалению, [название продукта] отсутствует в нашей базе.

Возможные причины:
• Продукт временно недоступен
• Другое название в системе
• Новый продукт, ещё не добавлен

Альтернативы:
• [Похожий продукт 1]
• [Похожий продукт 2]

Хотите расчёт по альтернативам?
```

**Пример:**
```
К сожалению, "Супер-сафари VIP Exclusive" отсутствует в нашей базе.

Возможные альтернативы:
• Desert Safari Premium
• VIP Desert Experience
• Exclusive Dune Adventure

Хотите расчёт по одной из альтернатив?
```

**Важно:** Не выдумывайте цены на несуществующие продукты!

### Q: Турагент просит скидку?

**A:** Скидки не в компетенции форматирования. Перенаправьте запрос.

**Шаблон ответа:**
```
Вопросы по скидкам и специальным условиям решаются индивидуально.

Пожалуйста, обратитесь:
• К вашему менеджеру
• В отдел продаж: [контакт]

Могу подготовить расчёт по стандартным ценам для сравнения.
```

**Что можно указать:**
- Действующие акции (если есть в базе)
- Групповые скидки (если прописаны)
- Сезонные предложения (если актуальны)

**Что нельзя делать:**
- Самостоятельно давать скидки
- Обещать специальные условия
- Менять цены из базы

### Q: Нужно ли время работы?

**A:** Зависит от типа продукта:

| Продукт | Время работы | Где указывать |
|---------|--------------|---------------|
| Аттракционы | ДА | В блоке ВАЖНО |
| Рестораны | ДА | В блоке ВАЖНО |
| Туры | НЕТ | Указывается время выезда |
| Билеты | ИНОГДА | Если ограничено |

**Пример для аттракциона:**
```
⚠️ *ВАЖНО*

*ВРЕМЯ РАБОТЫ*
Ежедневно: 10:00 – 22:00
Пятница: 10:00 – 00:00

*ОПЛАТА*
Полная предоплата
```

**Пример для тура:**
```
⚠️ *ВАЖНО*

*ВРЕМЯ ВЫЕЗДА*
Утренний: 08:00
Вечерний: 15:00

Трансфер от отеля включён
```

### Q: Можно ли другие эмодзи для модулей?

**A:** **ДА**, но только для специализированных модулей билетов и аттракционов.

**Разрешённые тематические эмодзи:**
- 🎢 — аттракционы, парки развлечений
- 🎡 — колесо обозрения, смотровые площадки
- 🏛️ — музеи, культурные объекты
- 🌊 — аквапарки, водные развлечения
- 🎭 — шоу, представления

**Пример модуля:**
```
🎢 *FERRARI WORLD*

💰 *ЦЕНЫ*

```Базовая```  295 AED
```VIP```  450 AED
```

**ВАЖНО:** Это касается только заголовков модулей! Внутри блоков используются стандартные эмодзи (💰, ➕, ⚠️).

**НЕПРАВИЛЬНО (эмодзи внутри):**
```
🎢 *FERRARI WORLD*

🎫 *БИЛЕТЫ*
💵 *ЦЕНЫ*
```

**ПРАВИЛЬНО:**
```
🎢 *FERRARI WORLD*

💰 *ЦЕНЫ*
➕ *ОПЦИИ*
⚠️ *ВАЖНО*
```

### Q: Как оформлять несколько вариантов одного тура?

**A:** Используйте подзаголовки для каждого варианта.

**Пример:**
```
💰 *ЦЕНЫ*

*УТРЕННИЙ ТУР (08:00)*
```Базовая```  1 200 AED
```Премиум```  1 800 AED

*ВЕЧЕРНИЙ ТУР (15:00)*
```Базовая```  1 500 AED
```Премиум```  2 100 AED

*НОЧНОЙ ТУР (20:00)*
```Премиум```  2 500 AED
```

---

### Q: Что делать с длинными названиями категорий?

**A:** Используйте сокращения, но понятные.

**НЕПРАВИЛЬНО:**
```
```Базовый пакет без трансфера```  1 200 AED
```

**ПРАВИЛЬНО:**
```
```Базовая (без трансфера)```  1 200 AED
```

или

```
```Базовая```  1 200 AED
*Без трансфера*
```

### Q: Как указывать цены в разных валютах?

**A:** Основная валюта — AED. Другие валюты указываются в скобках.

**Пример:**
```
💰 *ЦЕНЫ*

```Базовая```  2 100 AED (~570 USD)
```Премиум```  3 500 AED (~950 USD)

*Курс на момент расчёта*
```

**Важно:** Курс должен быть актуальным!

---

### Q: Нужно ли указывать срок действия цен?

**A:** Да, если цены сезонные или акционные.

**Пример:**
```
💰 *ЦЕНЫ*

```Базовая```  1 800 AED
```Премиум```  2 500 AED

*Цены действительны до 31.03.2025*
```

или

```
⚠️ *ВАЖНО*

Цены актуальны: 01.01 – 31.03.2025
Летний сезон: цены уточняйте
```
