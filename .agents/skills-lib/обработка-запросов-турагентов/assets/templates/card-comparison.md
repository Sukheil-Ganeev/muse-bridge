# Шаблон СРАВНИТЕЛЬНЫХ КАРТОЧЕК

## Назначение
Помощь клиенту в выборе между похожими продуктами. Используется когда клиент сомневается между двумя опциями.

## Когда использовать
- Клиент спрашивает "что лучше — X или Y?"
- Клиент не может выбрать между двумя аттракционами
- Нужно показать разницу между уровнями сервиса (Standard vs Premium)
- Клиент хочет понять, за что платит больше

## Правила форматирования (WhatsApp)
- Жирный: `*текст*`
- Разделитель: 15 тире `───────────────`
- Эмодзи только: 💰 ➕ ⚠️
- Таблицы НЕ работают — используй списки!
- Сравнение в формате "Критерий: Опция A / Опция B"

## ПРИМЕР 1: Ain Dubai vs Burj Khalifa (высотные аттракционы)

```
*AIN DUBAI vs BURJ KHALIFA*
_Сравнение высотных аттракционов_
───────────────

➕ *Ain Dubai:* Самое большое колесо обозрения в мире (250 м)

───────────────
*СРАВНЕНИЕ*

*Высота обзора:*
Ain Dubai — 250 м (вращающаяся кабина)
Burj Khalifa — 555 м (148 этаж At The Top SKY)

*Длительность:*
Ain Dubai — 38 минут (полный оборот)
Burj Khalifa — без ограничений (обычно 1-2 часа)

*Впечатления:*
Ain Dubai — плавное движение, 360° панорама, романтика
Burj Khalifa — захватывает дух, рекорды, культовое место

*Вид:*
Ain Dubai — Dubai Marina, Palm Jumeirah, море
Burj Khalifa — весь Дубай, пустыня, Downtown

*Подходит для:*
Ain Dubai — пары, семьи, любители спокойного отдыха
Burj Khalifa — все, кто хочет "галочку", фотоохотники
───────────────
💰 *ЦЕНЫ*

*Ain Dubai:* 40$ взр / 30$ реб (Observation)
*Burj Khalifa:* 45$ взр / 35$ реб (уровень 124-125)
*Burj Khalifa SKY:* 120$ (уровень 148)
───────────────
⚠️ *НАША РЕКОМЕНДАЦИЯ*

Для вас рекомендуем *Burj Khalifa*, потому что это must-see Дубая — все туристы хотят увидеть город с самого высокого здания мира.

Если важна романтика и неспешность — тогда лучше *Ain Dubai* (38 минут в кабине с панорамой).
```

## Как формулировать рекомендацию

**Основа рекомендации — запрос клиента:**

| Клиент сказал | Рекомендуем |
|---------------|-------------|
| "Едем с детьми" | Более семейный вариант |
| "Хотим экстрим" | Более адреналиновый |
| "Романтическая поездка" | Более приватный/атмосферный |
| "Ограничен бюджет" | Более доступный |
| "Первый раз в Дубае" | Must-see аттракцион |
| "Не хотим с толпой" | VIP/Premium опция |

**Формула рекомендации:**
```
Для вас рекомендуем *[Опция]*, потому что [связь с запросом клиента].

Если [альтернативное условие] — тогда лучше *[Другая опция]*.
```
