# Шаблон карточки для КЛИЕНТА

## Назначение
Карточка для отправки **напрямую клиенту**. Содержит ТОЛЬКО рекомендованные цены.

## Что показывать
- Рекомендованные цены (Recommended Rate)
- Описание продукта
- Условия и ограничения

## Что НЕЛЬЗЯ показывать
- B2B цены (закупка)
- Прибыль агента
- Комиссии

## Правила форматирования (WhatsApp)
- Жирный: `*текст*`
- Разделитель: 15 тире `───────────────`
- 2 пробела после категории
- Эмодзи только: 💰 ➕ ⚠️
