# Обработка запросов турагентов

## 1. Введение и философия

### Для кого этот скилл
- **Турагенты** — обрабатывают запросы клиентов, формируют предложения
- **Клиенты** — запрашивают информацию о турах, ресторанах, билетах напрямую

### Цель
Быстрая и точная обработка запросов на туристические продукты в ОАЭ с выдачей готовых карточек для мессенджеров.

### Типы получателей карточек

| Получатель | Что показывать | Что НЕЛЬЗЯ показывать |
|------------|----------------|----------------------|
| **Клиент** | Рекомендованные цены (Recommended Rate) | B2B цены, комиссии |
| **Турагент** | Рекомендованные цены + его прибыль | B2B цены (закупка) |
| **Внутренний расчёт** | Всё: B2B, Recommended, комиссия | — |

> ⚠️ **КРИТИЧНО:** B2B цены — это закупочная стоимость. Агенту показываем ТОЛЬКО рекомендованные цены для клиента и его прибыль (% от комиссии). Никогда не раскрываем закупку!

### Расчёт прибыли агента

**Формула (по умолчанию 50%):**
```
Общая прибыль = Recommended Rate - B2B Rate
Прибыль агента = Общая прибыль × 50%
```

**Пример:**
| Позиция | B2B | Recommended | Общая прибыль | Агенту (50%) |
|---------|-----|-------------|---------------|--------------|
| Взрослый билет | 128 AED | 145 AED | 17 AED | 8.50 AED |
| Детский билет | 105 AED | 115 AED | 10 AED | 5.00 AED |

**Применяется к:**
- Билетам (парки, аттракционы, шоу)
- Групповым турам (Ferrari World, IMG Worlds, сафари и т.д.)
- Комбо-пакетам (билет + трансфер)

> ⚠️ **ВАЖНО:** Расчёт прибыли возможен ТОЛЬКО если известны ОБЕ цены — B2B (закупка) и Recommended (рекомендованная продажа). Без этих данных прибыль агента указать невозможно!

### Типы продуктов
| Тип | Что включает | Особенности |
|-----|--------------|-------------|
| **ТУРЫ** | Экскурсии, сафари, круизы | Группировка по эмиратам |
| **ПИТАНИЕ** | Рестораны, ужин-шоу, бранчи | Группировка по пакетам |
| **БИЛЕТЫ** | Парки, аттракционы, шоу | Модульная система |

### 5 главных правил (запомни навсегда!)

| # | Правило | Пример |
|---|---------|--------|
| 1 | **Разделители** — ровно 15 тире | `───────────────` |

- [ ] Мессенджер указан/уточнён

- [ ] **B2B цены НЕ показаны** (если получатель — агент или клиент)
- [ ] Разделители = 15 тире
- [ ] После категорий 2 пробела
- [ ] Эмодзи только 💰 ➕ ⚠️
- [ ] Результат в .txt файле

### Критическое правило
> **Если мессенджер не указан — ОБЯЗАТЕЛЬНО УТОЧНИТЬ!**
> Форматирование кардинально отличается.

### Различия WhatsApp vs Telegram

| Элемент | WhatsApp | Telegram |
|---------|----------|----------|
| Жирный | `*текст*` | `**текст**` |
| Курсив | `_текст_` | `_текст_` (или `*текст*`) |
| Моноширинный | ``` `текст` ``` | ``` `текст` ``` |
| Зачёркнутый | `~текст~` | `~~текст~~` |
| Ссылки | Просто URL | `[текст](URL)` |
| Списки | `• ` (точка) | `• ` или `-` |

## 4. Типы продуктов

### ТУРЫ (экскурсии, сафари, круизы)

**Особенности:**
- Группировка вариантов по эмиратам (Дубай, Абу-Даби, Шарджа...)
- Один файл на весь продукт
- Обязательный блок ОПЦИИ в конце

**Когда использовать:** запрос на экскурсию, сафари, морскую прогулку, обзорный тур.

### ПИТАНИЕ (рестораны, ужин-шоу)

**Особенности:**
- Группировка по пакетам (Soft, House, Premium...)
- ДВА файла: Карточка + Меню
- Время работы и дресс-код обязательны

**Когда использовать:** запрос на ресторан, бранч, ужин с шоу, романтический ужин.

### БИЛЕТЫ (парки, аттракционы)

**Особенности:**
- Группировка по категориям билетов
- Модульная система (9 модулей)
- Отправка модулей по запросу клиента

**Когда использовать:** запрос на билеты в парк, аттракцион, шоу, музей.

## 5. Базовые правила форматирования

### Типографика

| Элемент | WhatsApp | Telegram | Когда |
|---------|----------|----------|-------|
| Жирный | `*текст*` | `**текст**` | Названия, цены, важное |
| Курсив | `_текст_` | `_текст_` | Примечания, уточнения |
| Моно | ``` `текст` ``` | ``` `текст` ``` | Коды, артикулы |

### Разделители

**Стандартный разделитель:** `───────────────` (ровно 15 тире)

**Где ставить:**
- После заголовка продукта
- Между логическими блоками (варианты, опции, условия)
- Перед итоговым блоком

**Где НЕ ставить:**
- Внутри одного варианта
- Между строками цен одной категории
- В конце карточки (последняя строка)

### Эмодзи

**Разрешены ТОЛЬКО 3 эмодзи:**

| Эмодзи | Значение | Где использовать |
|--------|----------|------------------|
| 💰 | Цена/стоимость | Перед ценой в заголовке блока |
| ➕ | Дополнительно | Перед доплатами и опциями |
| ⚠️ | Важно/внимание | Перед критичными условиями |

**Правило:** эмодзи ставится ПЕРЕД звёздочкой жирного текста.
```
💰 *Стоимость:*  ← Правильно
*💰 Стоимость:* ← НЕПРАВИЛЬНО
```

### 2 пробела после категории

```
Взрослый:⎵⎵1200 AED    ← Правильно (2 пробела)
Взрослый: 1200 AED     ← НЕПРАВИЛЬНО (1 пробел)
Взрослый:1200 AED      ← НЕПРАВИЛЬНО (0 пробелов)
```

## 7. Модульная система

Применяется для БИЛЕТОВ. Отправляй модули по запросу клиента.

| # | Модуль | Когда отправлять |
|---|--------|------------------|
| 01 | FAQ | Общие вопросы о продукте |
| 02 | Ограничения | Вопросы о допуске, росте, возрасте |
| 03 | Расписание | Вопросы о времени работы, шоу |
| 04 | Локация | Как добраться, где находится |
| 05 | Правила | Что можно/нельзя, дресс-код |
| 06 | Еда | Вопросы о питании на территории |
| 07 | Допы | Дополнительные услуги, апгрейды |
| 08 | Фишки | Лайфхаки, советы, секреты |
| 09 | Сравнение | Сравнение с аналогами |

**Правило:** не отправляй все модули сразу. Только релевантные запросу.

## 8. Критические правила

> Нарушение этих правил НЕДОПУСТИМО!

| # | Правило | Последствие нарушения |
|---|---------|----------------------|
| 1 | Разделитель = 15 тире | Сломается вёрстка |
| 2 | 2 пробела после категории | Неаккуратный вид |
| 3 | Только 💰 ➕ ⚠️ | Перегруз визуально |
| 4 | Эмодзи ДО звёздочки | Не сработает жирный |
| 5 | Уточнить мессенджер | Неправильное форматирование |
| 6 | Выдача в .txt файле | Клиент не скопирует |
| 7 | Цены в AED | Путаница с валютой |
| 8 | Детский возраст указать | Конфликт при бронировании |
| 9 | Дата актуальности | Клиент получит старые цены |
| 10 | Проверка перед отправкой | Ошибки уйдут клиенту |
| 11 | **B2B цены — ТОЛЬКО для внутреннего использования** | Раскроешь закупку агенту/клиенту |
| 12 | Агенту — рекомендованные цены + его прибыль | Агент узнает твою маржу |

## 10. Типичные ошибки

### Ошибка 1: Неправильное количество тире
```
──────────────     ← 14 тире — НЕПРАВИЛЬНО
───────────────    ← 15 тире — ПРАВИЛЬНО
────────────────   ← 16 тире — НЕПРАВИЛЬНО
```

### Ошибка 2: Один пробел после категории
```
Взрослый: 1200 AED   ← НЕПРАВИЛЬНО
Взрослый:  1200 AED  ← ПРАВИЛЬНО
```

### Ошибка 3: Эмодзи после звёздочки
```
*💰 Стоимость:*  ← НЕПРАВИЛЬНО (жирный не сработает)
💰 *Стоимость:*  ← ПРАВИЛЬНО
```

### Ошибка 4: Лишние эмодзи
```
🏖️ *Пляжный тур* 🌴  ← НЕПРАВИЛЬНО
*Пляжный тур*        ← ПРАВИЛЬНО
```

### Ошибка 5: Выдача в code block
````
```
Текст карточки
```                  ← НЕПРАВИЛЬНО
````
Правильно: создать файл .txt и предоставить пользователю.

Подробный разбор ошибок: `references/troubleshooting.md`

## Быстрый старт для новичков

1. **Получил запрос** → определи тип (тур/питание/билеты)
2. **Уточни мессенджер** → WhatsApp или Telegram
3. **Открой шаблон** → `assets/templates/`
4. **Заполни данные** → цены, варианты, условия
5. **Проверь по чеклисту** → раздел 2
6. **Сохрани в .txt** → отправь клиенту

**Помни:** 15 тире, 2 пробела, 3 эмодзи, файл .txt!
