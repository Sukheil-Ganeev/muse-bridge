# Чеклист валидации карточки перед отправкой

Используй этот чеклист для проверки каждой карточки перед отправкой клиенту или агенту.

---

## 1. Проверка получателя

- [ ] Определён тип получателя: **клиент** / **агент** / **внутренний**
- [ ] B2B цены **НЕ показаны** (если получатель — агент или клиент)
- [ ] Формат подачи соответствует типу получателя

---

## 2. Проверка форматирования

- [ ] Разделители = ровно **15 символов** `─` (───────────────)
- [ ] **2 пробела** после категории (Взрослый:  XXX, Ребёнок:  XXX)
- [ ] Используются только разрешённые эмодзи: 💰 ➕ ⚠️
- [ ] Эмодзи стоит **ДО** звёздочки (💰 *Стоимость:*, а не *💰 Стоимость:*)
- [ ] Нет лишних пустых строк
- [ ] Выравнивание текста корректное

---

## 3. Проверка контента

- [ ] Цены указаны в **AED**
- [ ] Детский возраст указан (обычно **3-11 лет**)
- [ ] Указана дата актуальности или период действия цен
- [ ] Прописаны условия и ограничения
- [ ] Все обязательные поля заполнены
- [ ] Информация актуальна и соответствует запросу

---

## 4. Проверка на утечку данных

- [ ] Нет слов: **"B2B"**, **"закупка"**, **"себестоимость"**, **"нетто"**, **"маржа"**
- [ ] Нет наших внутренних комментариев и заметок
- [ ] Нет ссылок на внутренние документы
- [ ] Нет служебной информации о поставщиках
- [ ] Нет упоминания внутренних систем и процессов

---

## 5. Финальная проверка

- [ ] Мессенджер выбран правильно (**WhatsApp** / **Telegram**)
- [ ] Файл **.txt** создан в папке `D:/Downloads/`
- [ ] Текст корректно отображается в предпросмотре
- [ ] Карточка готова к копированию и отправке

---

## Быстрая проверка (для опытных)

```
✓ Получатель определён, B2B скрыты
✓ 15 символов ─, 2 пробела, эмодзи ДО *
✓ AED, возраст детей, даты, условия
✓ Нет B2B/закупка/себестоимость
✓ Файл создан, можно отправлять
```

---

**Важно:** Если хотя бы один пункт не выполнен — исправь перед отправкой!
