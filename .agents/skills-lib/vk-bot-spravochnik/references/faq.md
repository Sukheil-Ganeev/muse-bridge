# VK Bot API: FAQ (15 вопросов)

## 1. Чем отличается бот сообщества от user-бота?

**Бот сообщества** работает от имени группы/паблика через Community Token. Это легальный способ автоматизации, поддерживаемый VK.

**User-бот** работает от имени личного аккаунта. Это нарушение ToS VK — аккаунт могут заблокировать.

**Для бизнеса:** только боты сообществ.

## 2. Какой rate limit у бота сообщества?

Community Token: **20 запросов/секунду**. Этого достаточно для большинства задач. Для пакетных операций используйте метод `execute` (до 25 вызовов API за 1 запрос).

## 3. Long Poll или Callback API — что выбрать?

| Ситуация | Выбор |
|----------|-------|
| Разработка/отладка | Long Poll (работает на localhost) |
| Один сервер, до 1000 msg/min | Long Poll |
| Serverless (Lambda, Cloud Functions) | Callback API |
| Высокая нагрузка, балансировка | Callback API |
| MVP, быстрый старт | Long Poll |

## 4. Как получить Community Token?

1. Настройки сообщества -> Работа с API -> Создать ключ
2. Выбрать права: сообщения, фото, документы, управление
3. Скопировать токен

Токен не истекает, пока не отозван или не пересоздан.

## 5. Почему бот не получает сообщения?

Проверьте:
1. Сообщения сообщества **включены** (Настройки -> Сообщения)
2. Long Poll API **включен** (Работа с API -> Long Poll)
3. Тип события `message_new` **выбран** в настройках
4. Версия API: **5.199** (не ниже 5.131)
5. Бот использует **Community Token**, а не User Token

## 6. Как отправить фото в сообщении бота?

Трехшаговый процесс:
1. `photos.getMessagesUploadServer` -> получить upload_url
2. POST файл на upload_url -> получить server, photo, hash
3. `photos.saveMessagesPhoto` -> получить owner_id и id

Затем: `messages.send(attachment="photo{owner_id}_{id}")`

## 7. Сколько кнопок можно в клавиатуре?

| Тип | Максимум строк | Максимум кнопок в строке | Всего |
|-----|---------------|------------------------|-------|
| Reply Keyboard | 10 | 5 | 40 |
| Inline Keyboard | 6 | 5 | 10 |

Кнопка VK Pay занимает всю ширину строки.

## 8. Как обработать нажатие inline-кнопки (callback)?

Используйте тип кнопки `callback` (не `text`). При нажатии приходит событие `message_event`. Обязательно ответьте через `messages.sendMessageEventAnswer`:

```python
await bot.api.messages.send_message_event_answer(
    event_id=event_id,
    user_id=user_id,
    peer_id=peer_id,
    event_data='{"type":"show_snackbar","text":"Принято!"}'
)
```

Три варианта ответа: `show_snackbar`, `open_link`, `open_app`.

## 9. Как сделать рассылку подписчикам?

1. Получите разрешение: пользователь должен написать боту первым или нажать "Разрешить сообщения"
2. Отслеживайте `message_allow` / `message_deny` события
3. Храните список подписчиков в БД
4. Отправляйте пакетами по 20 с паузой 1 сек
5. Используйте `execute` для ускорения (25 отправок за 1 запрос)

## 10. Можно ли принимать платежи через бота?

Да, через **VK Pay**. Добавьте кнопку типа `vkpay` с hash-параметрами:

```
action=pay-to-group&amount=250&description=Desert+Safari&group_id=123456&aid=789
```

Проверяйте `client_info.button_actions` — не все клиенты поддерживают VK Pay.

## 11. Как использовать карусели?

Карусель — горизонтально прокручиваемые карточки (1-10 штук). Отправляется через параметр `template` метода `messages.send`:

```python
vk.messages.send(
    user_id=uid,
    message="Наши туры:",
    template=json.dumps({"type": "carousel", "elements": [...]}),
    random_id=0
)
```

Проверяйте `client_info.carousel == true`.

## 12. vkbottle или vk_api — что лучше?

| Критерий | vkbottle | vk_api |
|----------|----------|--------|
| Async | Да (asyncio) | Нет (sync) |
| FSM из коробки | Да | Нет |
| Типизация | Полная | Частичная |
| Комьюнити | Среднее | Большое |
| Сложность | Средняя | Низкая |

**Новые проекты:** vkbottle. **Простые скрипты:** vk_api.

## 13. Как деплоить бота в production?

**Long Poll бот:**
- Linux: systemd service (автозапуск, логирование)
- Docker: контейнер с `python bot.py`
- Node.js: pm2 process manager

**Callback бот:**
- Любой веб-сервер с HTTPS (nginx + gunicorn/Express)
- Serverless: Yandex Cloud Functions, AWS Lambda

## 14. Как бот работает в беседах (чатах)?

Бота нужно добавить в беседу. В беседах `peer_id = 2000000000 + chat_id`. Бот видит сообщения если:
- Упомянут через @ (club123456)
- Настроен доступ ко всем сообщениям (Работа с API -> Настройки -> Доступ ко всем сообщениям)

## 15. Какие ограничения у VK Bot API?

| Ограничение | Значение |
|------------|---------|
| Rate limit (Community Token) | 20 req/sec |
| Длина сообщения | 4096 символов |
| Вложений за сообщение | 10 |
| Кнопок в Reply клавиатуре | 40 (10 строк x 5) |
| Кнопок в Inline клавиатуре | 10 (6 строк x 5) |
| Элементов карусели | 1-10 |
| execute вызовов | 25 за запрос |
| Размер payload кнопки | 255 байт |
