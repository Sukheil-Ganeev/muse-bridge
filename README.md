# Muse Bridge

Используй свою подписку **Muse Code** в любом приложении, которое умеет
подключать «OpenAI-совместимый» провайдер (PI-Desktop, разные IDE и чаты) —
без API-ключа и без отдельной оплаты за токены.

Работает на **Windows, Linux и macOS**.

## Как это работает (простыми словами)

Подписка Muse даёт тебе право пользоваться моделями Muse. Но приложения вроде
PI-Desktop умеют разговаривать только через «OpenAI-совместимый» протокол.
Muse Bridge — это маленький «переводчик», который живёт у тебя на компьютере:

```
Приложение (PI-Desktop, IDE…)
        │  обычный chat-запрос (OpenAI-совместимый)
        ▼
Muse Bridge  (локальный сервер на 127.0.0.1:11471)
        │  переводит запрос в команду `muse exec`
        ▼
Muse Code CLI  (твоя подписка, твой логин)
        │
        ▼
Ответ возвращается обратно в приложение
```

Никакой API-ключ не нужен. Мост просто использует твой уже выполненный вход
в Muse. Текст запросов и ответов никуда не записывается (в лог пишутся только
метод, путь и статус).

## Что нужно

- **Python 3.9+**
- **Muse Code CLI** — установлен и выполнен вход (`muse login`) своей подпиской.

## Быстрый старт

### 1. Установи Muse Code CLI

С официальной страницы Muse (Windows / macOS / Linux), затем войди:

```bash
muse login
```

(логин/пароль вводишь сам — он нигде не хранится в этом проекте).

### 2. Скачай проект

```bash
git clone https://github.com/<твой-аккаунт>/muse-bridge.git
cd muse-bridge
```

### 3. Запусти мост и автозапуск

| Система  | Команда |
|----------|---------|
| Windows  | двойной клик по `install\windows-install.bat` |
| Linux    | `bash install/linux-install.sh` |
| macOS    | `bash install/macos-install.sh` |

Или просто запусти мост вручную:

```bash
python muse_bridge.py      # Windows: python muse_bridge.py
```

Проверь, что работает: открой в браузере
[http://127.0.0.1:11471/health](http://127.0.0.1:11471/health) — должен
показать `{"ok": true}`.

### 4. Подключи своё приложение

Добавь провайдера «OpenAI-совместимый» с такими настройками:

- **Base URL:** `http://127.0.0.1:11471/v1`
- **API-ключ:** не нужен (оставь пустым)

В **PI-Desktop** это уже готово: провайдер называется **Meta Muse**.

## Если после обновления приложения провайдер пропал

PI-Desktop иногда стирает настройки провайдера при обновлении. Восстанови их:

```bash
python restore/restore_muse_provider.py
```

(сначала закрой PI-Desktop, после восстановления открой снова и выбери
«Meta Muse»).

## Настройка с нуля через Codex

Хочешь, чтобы всё поставил Codex автоматически? Открой
[`SETUP-PROMPT.md`](SETUP-PROMPT.md) и вставь готовый промт в Codex.

## Структура проекта

```
muse_bridge.py              — основной мост (Muse → OpenAI-совместимый API)
codex_bridge.py             — запасной мост (ChatGPT/Codex подписка)
restore/                    — восстановление провайдера в PI-Desktop
install/                    — установка и автозапуск (Windows/Linux/macOS)
SETUP-PROMPT.md             — промт для Codex (настройка с нуля)
```

## Безопасность

- Проект **не хранит и не запрашивает** твои логины, пароли, токены и ключи.
- Твоя подписка Muse — только твоя. У каждого человека свой логин.
- Не добавляй в этот репозиторий файлы с ключами (`.env`, `key.txt`, `auth.json`
  и т.п.) — они в `.gitignore`.
