# R196 — отклонять управляющие символы в пути macOS plist

**Статус:** готово локально · без commit/push

**Начат:** 2026-10-04

## Цель

Не создавать LaunchAgent `.plist`, если путь к мосту содержит управляющие символы, запрещённые XML.

## Проблема

macOS-установщик экранирует XML-метасимволы, но не проверяет управляющие символы в пути к репозиторию. Такой путь записывается напрямую в `<string>` и делает plist недопустимым XML. Linux-установщик уже отказывает для управляющих символов до создания файла автозапуска.

## Сделано

- Добавлен тест на временной копии установщика с `\x01` в пути проекта.
- macOS-установщик теперь отказывает до создания LaunchAgent plist, если путь
  содержит управляющий символ.
- До исправления тест падал: установщик возвращал код `0`.
