# R496 — отклонять повторные номера раундов в очереди

**Статус:** done
**PR:** #64

## Цель

Проверять, что каждый номер раунда указан в таблице очереди только один раз.

## Проблема

Гейт отдельно сверял каждую строку с единственной спекой. Поэтому две
одинаковые строки с темой и статусом завершения могли пройти, хотя один
идентификатор раунда не должен указывать на две записи очереди.

## Сделано

- Добавлен тест с двумя завершёнными строками `R999` и одной соответствующей
  спекой.
- Гейт запоминает уже встреченные номера и сообщает о повторе.
