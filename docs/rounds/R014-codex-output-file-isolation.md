# R014 — изолировать временный файл ответа Codex Bridge

**Статус:** done · без commit/push
**Начат:** 2026-10-03

## Цель

Параллельные запросы к Codex Bridge не должны читать или перезаписывать ответ
другого запроса.

## Проблема

`run_codex` использовал один общий путь `tempfile.gettempdir()/codex-bridge-out.txt`
для всех запусков. HTTP-сервер многопоточный, поэтому команды могли
одновременно записать этот файл; один запрос мог вернуть текст другого. Файл
также оставался после вызова.

## Сделано

Каждому вызову выделяется отдельный временный файл ответа; он удаляется после
чтения, в том числе при ошибке запуска. Временный файл запроса также удаляется
на всех выходах.

## Проверка

- До исправления `python3 -m unittest discover -s tests -p test_bridge.py -k CodexOutputIsolationTests`: 1 ошибка; оба вызова прочитали `answer-A`.
- После исправления та же команда: 1 тест, `OK`.
- `python3 -m py_compile codex_bridge.py tests/test_bridge.py`: успешно.
