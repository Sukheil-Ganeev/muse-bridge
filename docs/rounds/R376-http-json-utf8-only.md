# R376 — принимать в HTTP POST только UTF-8 JSON

**Статус:** готово локально · без commit/push
**Начат:** 2026-10-06

## Цель

Отклонять JSON-тело POST, если оно закодировано не в UTF-8, в обоих мостах.

## Проблема

`json.loads(bytes)` автоматически распознаёт UTF-16 и UTF-32. Поэтому локальные
HTTP-маршруты принимали не-UTF-8 JSON вместо единственной сетевой кодировки,
допустимой для обмена JSON между системами.

## Сделано

Оба POST-маршрута теперь сначала строго декодируют байты как UTF-8, затем
передают текст парсеру JSON. UTF-16 и UTF-32 дают контролируемый HTTP 400 до
запуска CLI; UTF-8 сохраняет прежнее поведение. Регрессионный тест проверяет
обе кодировки в обоих мостах.
