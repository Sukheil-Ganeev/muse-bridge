# R011 — сохранить причину ошибки Muse из terminal.failed

**Статус:** done

## Проблема

Обычный и потоковый запуск разбирают события `run.terminal.failed`, но не
передают указанную Muse причину вызывающему коду. Вместо неё пользователь
получает только общее сообщение, что текст не был получен.

## Изменение

Если запуск не вернул текст, а поток событий содержит `run.terminal.failed`,
в исключении сохраняется его причина. Для запуска без такого события прежняя
ошибка остаётся без изменений.
