# R008 — очистка ресурсов при ошибке запуска stream exec

## Цель

Если `muse exec` не удалось запустить для потокового ответа, мост должен
освободить временный файл промпта и временный файл `stderr`, а исходная ошибка
запуска должна остаться видимой вызывающему коду.

## Проблема

`stream_muse` создавал оба файла и вызывал `subprocess.Popen` до защищённого
блока чтения потока. Ошибка запуска (например, `OSError`) выходила наружу,
оставляя файл промпта на диске и открытый файловый дескриптор `stderr`.

## Сделано

Подготовка `stderr` и запуск процесса теперь защищены очисткой при исключении:
удаляется файл промпта, закрывается уже созданный `stderr`, затем повторно
выбрасывается исходная ошибка.

## Проверка

- Новый тест заставляет `Popen` выбросить `OSError` и проверяет, что временный
  файл удалён, а `stderr` закрыт.
- До исправления тест падал: файл промпта оставался на диске.
- После исправления: 14 офлайн-тестов проходят. Полный набор содержит HTTP-
  тесты, но sandbox запрещает создание loopback-сокетов (`EPERM`); `pytest`
  отсутствует. `py_compile` затронутых Python-файлов проходит.
