# R146 — очистка prompt temp-файла при ошибке записи

**Статус:** готово локально · без commit/push  
**Начат:** 2026-10-04

## Цель

Удалять временный файл промпта, если его UTF-8-запись завершается ошибкой до запуска CLI.

## Проблема

`run_muse`, `stream_muse` и `run_codex` создавали временный файл до входа в блок
`try/finally`. Если запись промпта падала — например, на непарном Unicode
суррогате — пустой или частичный файл оставался в системной временной папке.

## Сделано

- Добавлены три регрессионных теста: каждый проверяет, что после ошибки записи
  временная папка пуста и дочерний CLI не запущен.
- Создание и запись prompt-файла перенесены внутрь уже имеющихся защитных блоков
  очистки во всех трёх путях.

## Проверка

- До исправления: новый набор — `Ran 3 tests`, `FAILED (failures=3)`; каждый
  тест обнаружил оставшийся `tmp*.txt`.
- После исправления: офлайн-контракты `test_bridge` — `Ran 29 tests`, `OK`.
- `test_install_scripts.py` — `Ran 1 test`, `OK`.
- `test_round_queue.py` — `Ran 1 test`, `OK`.
- Все 3 проверки `test_env_port.py` вызваны напрямую — `3 env-port checks: OK`.
- `python3 -m py_compile muse_bridge.py codex_bridge.py tests/test_bridge.py` и
  `git diff --check` — успешно.
- `pytest` в среде не установлен; пакеты не устанавливались. Сетевые HTTP-тесты
  полного набора в этом раунде не запускались.
