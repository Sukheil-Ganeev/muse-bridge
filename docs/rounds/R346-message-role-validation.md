# R346 — проверять роли сообщений до запуска CLI

**Статус:** готово локально · без commit/push
**Начат:** 2026-10-05

## Цель

Отклонять в обоих POST-маршрутах роли сообщений, которые не входят в набор
ролей Chat Completions, до формирования промпта и запуска CLI.

## Проблема

Мосты проверяют, что каждый элемент `messages` — объект, но поле `role` не
проверяется. Любое значение превращается в метку в текстовом промпте; например,
объект или строка с переводом строки принимаются как роль вместо понятного
ответа 400.

## Сделано

Добавлена регрессионная проверка для Muse и Codex: неподдерживаемая роль даёт
HTTP 400 и не запускает CLI. Допустимые роли — `system`, `developer`, `user`,
`assistant`, `tool`, `function`; если поле отсутствует, сохраняется прежнее
поведение с ролью `user`.

## Проверка

- До исправления: один тест, 6 провалов — оба моста принимали три неподдерживаемых
  значения роли и возвращали 200.
