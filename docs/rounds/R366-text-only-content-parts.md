# R366 — отклонять неподдерживаемые части content

**Статус:** готово локально · без commit/push
**Начат:** 2026-10-05

## Цель

Не выдавать успешный ответ, если в сообщении есть часть `content`, которую
текстовые Muse и Codex CLI-мосты не умеют передать модели.

## Проблема

Для массива `content` оба моста молча пропускали части не типа `text` и
запускали CLI с неполным сообщением. Например, запрос с вопросом и `image_url`
получал обычный ответ 200, хотя изображение модели не передавалось.

## Сделано

Оба POST-маршрута теперь до запуска CLI отвечают 400, если массив содержит
не-объект или часть с явным `type`, отличным от `text`. Текстовые части и
части без `type` сохраняют прежнее поведение, включая преобразование
нестрокового `text`.

## Проверка

- До исправления: новый регрессионный тест получил HTTP 200 на обоих мостах;
  оба CLI-runner вызывались после потери `image_url`.
- После исправления: 20 связанных проверок `unittest` прошли; точные команды
  и результаты остальных локальных ворот записаны в `OUT.md`.
