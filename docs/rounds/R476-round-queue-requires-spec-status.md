# R476 — завершённая запись очереди требует статуса в спеке

**Статус:** merged (PR #62)

## Цель

Не позволять очереди раундов показывать завершение, если соответствующая
спецификация не сообщает свой статус.

## Проблема

Проверка сравнивала маркер завершения с текстом спеки только при наличии строки
`**Статус:**`. Если эту строку забывали добавить, очередь с `✅` проходила
проверку без подтверждения состояния раунда.

## Сделано

- Добавлена регрессия: завершённая строка очереди и спека без строки статуса
  дают FAIL.
- Отсутствие статуса — ошибка только для строки очереди с `✅`; незавершённые
  старые записи без статуса остаются открытыми.
- Проверка распознаёт `merged` как завершённый статус; статусы добавлены в
  завершённые исторические спеки, которые очередь уже отмечала `✅`.

## Проверка

- До исправления: адресный тест упал, потому что незаполненный статус не
  создавал расхождение (`0 != 1` ожидаемых ошибок).
- После исправления: `PYTHONPATH=tests PYTHONDONTWRITEBYTECODE=1 python3 -B -m
  unittest test_round_queue` — 3 теста, `OK`.
- `PYTHONPYCACHEPREFIX=/tmp/muse-bridge-r476-pycache python3 -m py_compile
  tests/test_round_queue.py` — код 0; `git diff --check` — код 0.
