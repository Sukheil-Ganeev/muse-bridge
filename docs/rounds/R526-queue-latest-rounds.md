# R526 — очередь должна содержать четыре последние спецификации

**Статус:** ✅ сделано
**PR:** #70

## Цель

Не позволять очереди раундов незаметно отставать от последних спецификаций.

## Проблема

Проверка сверяет только записи, которые уже есть в `QUEUE.md`. Поэтому новая
спецификация может отсутствовать в очереди без ошибки. Сейчас R516 отмечен
завершённым в своей спеке, но пропущен в очереди, где остаётся более старый R476.

## Сделано

Тестовый гейт сравнивает номера в `QUEUE.md` с четырьмя самыми новыми
спецификациями. Очередь обновлена: R526, R516, R506 и R496.

## Проверка

До исправления адресный тест завершился одним ожидаемым провалом: гейт не
обнаружил пропуск R1010. После исправления `test_round_queue` прошёл: 8 тестов,
`OK`. `python3 -m py_compile tests/test_round_queue.py` и `git diff --check`
завершились с кодом 0. Commit и push не выполнялись.
