# R456: except → return/continue/break — подавленная ошибка ведёт в журнал

**Статус:** done
**PR:** #58


**Статус:** выполнено
**Семья:** silent-except-return

## Дефект

Обработчики `except`, чьё тело — единственный `return`, `continue` или `break`,
проглатывали исключение без следа: сбой невидим ни в логах, ни по выводу.

## Исправление

Перед терминальной строкой теперь стоит
`logging.getLogger(__name__).debug("suppressed %s", _exc)` —
поведение не меняется, ошибка становится видимой. Обработчикам без имени
добавлен `as _exc`; `import logging` добавлен в файлы без него.

Сайты: 5.

## Гейт

`tests/test_no_silent_except.py`: запрещены тела из единственного pass/return/continue/break
без строки журнала — обе формы семьи закрыты.
