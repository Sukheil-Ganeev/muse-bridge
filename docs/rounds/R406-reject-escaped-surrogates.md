# R406 — отклонять одиночные Unicode-суррогаты в промпте

**Статус:** готово локально · без commit/push  
**Начат:** 2026-10-06

## Цель

Отклонять запрос до запуска Muse или Codex CLI, если JSON содержит в тексте
промпта экранированный одиночный Unicode-суррогат, который нельзя записать как
UTF-8.

## Проблема

UTF-8-декодирование тела проходит, а `json.loads` превращает JSON-экранирование
U+D800 в одиночный суррогат Python. Оба моста затем передают собранный промпт
в текстовый временный файл с кодировкой UTF-8. Запись вызывает
`UnicodeEncodeError`, который
перехватывался как ошибка CLI и возвращался клиенту с кодом 502, хотя причина —
некорректный текст запроса.

## Сделано

Перед обычным или потоковым запуском мосты теперь проверяют, что собранный
промпт кодируется в UTF-8. При одиночном суррогате они отвечают 400 и не
запускают дочерний процесс. Обычный Unicode-текст не меняется.

  отвечали 502 вместо 400.
