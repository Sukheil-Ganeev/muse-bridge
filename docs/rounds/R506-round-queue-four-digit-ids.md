# R506 — проверять номера раундов длиннее трёх цифр

**Статус:** готово · **PR:** #66

## Цель

Сохранять проверку очереди раундов, когда номер превысит `R999`.

## Проблема

Тест очереди распознавал только `R` и ровно три цифры. Поэтому строка для
`R1000` и последующих раундов молча выпадала из проверки, включая проверку
совпадения статуса очереди и спеки.

## Сделано

- Добавлена регрессия на завершённый `R1000` с незавершённым статусом спеки.
- Разбор номера в строке очереди принимает одну или более цифр.

## Проверка

- До исправления: адресный тест упал — очередь не нашла расхождение для
  `R1000` (`0 != 1` ожидаемых ошибок).
- После исправления: `PYTHONPATH=tests PYTHONDONTWRITEBYTECODE=1 python3 -B -m
  unittest test_round_queue test_no_unbounded_subprocess` — 6 тестов, `OK`.
- Компиляция и `git diff --check` записаны в `OUT.md`.
- Commit и push не выполнялись.
