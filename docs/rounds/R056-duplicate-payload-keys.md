# R056: POST — дубли ключей в JSON-теле отклоняются 400

## Проблема

`muse_bridge.py` и `codex_bridge.py` разбирают тело `/v1/chat/completions`
обычным `json.loads`. Тело `{"model": "a", "model": "b", "messages": []}`
или `{"stream": true, "stream": false}` молча оставляет последнее значение —
клиент и сервер расходятся в том, какой запрос реально выполнен.

## Решение

Разбор тела через `object_pairs_hook`, бросающий `ValueError` на повторном
ключе; существующий `except` уже мапит ошибку разбора в 400 «bad json».

## Приёмка

- `python3 -m unittest tests.test_bridge` — новые контракты на дубль
  `model`/`stream` в обоих мостах (400, не тихий выбор последнего).
- Остальные контракты POST-боди без регрессий.
