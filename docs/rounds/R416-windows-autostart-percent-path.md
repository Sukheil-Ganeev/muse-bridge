# R416 — сохранять проценты в пути Windows-автозапуска

**Статус:** готово локально · без commit/push  
**Начат:** 2026-10-07

## Цель

Сохранить точный путь к `muse_bridge.py` в автозапуске Windows, даже если в
имени папки есть `%ИМЯ_ПЕРЕМЕННОЙ%`.

## Проблема

Установщик записывал путь прямо в `.bat`. При запуске этого файла `cmd.exe`
может раскрыть `%ИМЯ_ПЕРЕМЕННОЙ%` как переменную среды и подменить часть пути.
Из-за этого мост из папки с таким именем может не запускаться или запускаться
по другому адресу.

## Сделано

Добавлен небольшой генератор команды автозапуска: он удваивает `%`, выключает
отложенное раскрытие `!` и выдаёт UTF-8 `.bat` с переключением консоли на UTF-8.
Windows-установщик использует этот генератор и прекращает установку с ошибкой,
если файл автозапуска не удалось сформировать.

## Проверка

- До исправления два новых теста завершились ошибкой: генератора не было, а
  установщик записывал команду напрямую.
- После исправления: адресный набор установщиков — 6 тестов, `OK`.
- `py_compile` для нового генератора и изменённого теста — успешно.
- Выполнение `.bat` на Windows в этой среде не проверялось.
- Commit и push не выполнялись.
