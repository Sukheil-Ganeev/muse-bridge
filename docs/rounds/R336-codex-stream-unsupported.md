# R336 — явно отклонять потоковый запрос в Codex-мосте

**Статус:** готово локально · без commit/push
**Начат:** 2026-10-05

## Цель

Не возвращать обычный JSON как будто это SSE-ответ, если клиент просит
`stream: true` у Codex-моста, который потоковую передачу не поддерживает.

## Проблема

`codex_bridge.py` заявлен как мост без потокового режима, но поле `stream` не
проверялось. Поэтому запрос `stream: true` запускал Codex и получал HTTP 200 с
обычным JSON, который SSE-клиент не мог разобрать.

## Сделано

- Добавлен регрессионный тест: `stream: true` должен получить HTTP 400 с
  сообщением, что потоковая передача не поддерживается, не запуская Codex.
- После проверки тела и списка сообщений Codex-мост теперь явно отвечает 400
  на `stream: true`; другие запросы проходят прежний путь.
