# R009 — строгая проверка цифр Content-Length

**Статус:** done

## Цель

Принимать в `Content-Length` только непустую последовательность ASCII-цифр.
Отсутствующий заголовок по-прежнему означает тело длиной 0.

## Проблема

`int()` принимает формы, не разрешённые форматом HTTP-заголовка длины,
например `1_0` и `+10`. Из-за этого повреждённый заголовок проходил проверку
как корректная длина, хотя R003 заявляет строгий разбор.

## Сделано

Добавлен отдельный разбор значения заголовка: отсутствие даёт 0, а пустая
строка и любые символы кроме ASCII-цифр приводят к `ValueError`, который
обработчик превращает в HTTP 400.

## Проверка

- Добавлены офлайн-тесты для обычных цифр и недопустимых форм (`1_0`, `+10`,
  пустая строка и не-ASCII цифры).
- До исправления тесты недопустимых форм падали: `int()` их принимал.
- После исправления запускаются тесты `ContentLengthParsingTests` и
  `py_compile` для затронутых Python-файлов.
