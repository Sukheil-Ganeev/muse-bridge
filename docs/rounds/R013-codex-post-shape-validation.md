# R013 — Codex Bridge: проверка формы POST-тела

**Статус:** done · PR: TBD
**Начат:** 2026-10-03

## Цель

Некорректная форма JSON в POST должна давать ответ `400`, а не аварийно
завершать обработчик Codex Bridge.

## Проблема

После разбора JSON Codex Bridge сразу обращался к `payload.get()` и обходил
`messages`. JSON верхнего уровня не-объект, не-список в `messages` или
элемент `messages`, который не является объектом, приводили к `AttributeError`.
Проверки такой формы уже есть в Muse Bridge, но отсутствовали в Codex Bridge.

## Сделано

- Добавлена проверка, что верхний уровень JSON — объект.
- Если `messages` задан, он должен быть списком объектов; иначе возвращается
  `400` с коротким сообщением об ошибке.
- Добавлены три контрактных теста для этих некорректных форм.

## Проверка

- До исправления `python3 -m unittest tests.test_bridge.CodexPostValidationTests`:
  3 ошибки `AttributeError`.
- После исправления эта команда: 3 теста, `OK`.
- `python3 -m py_compile codex_bridge.py tests/test_bridge.py`: успешно.
